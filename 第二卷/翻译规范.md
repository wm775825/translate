# 第二卷翻译规范（继承第一卷统一译名）

## 内容与体例

- 逐章完整翻译正文、引文和脚注的解释文字，不以提要代替原文。参考文献的作者名、题名、刊名与出版定位保留原文，便于查找。
- 原书页码与 PDF 页码保留在 HTML 注释中。各章独立采用 1 起的脚注编号；全卷合并时为脚注加章节前缀，防止冲突。
- 章、节及段落的论证顺序依原文。跨页断句按语意接续；原书明确的长引文采用引用块。
- 原文的推测、否定、争议和限定语气全部保留。发现疑似原书误植或史实问题时，不擅自改写，必要说明另列“译校说明”。
- 本卷原书出版语境为 2007 年；“目前”“近来”“最新”等相对时间沿用这一语境。
- 图版和地图保留原图；图题及说明译为中文。图中专名保留原文以便对照。
- 正文用通行中文人名、地名；不确定或需要区分的术语，首见时附原文。书目不强行翻译作者姓名。
- 中文译稿须核对脚注引用与定义的编号、数量和顺序，检查本地链接，并确认源 PDF 未改变。
