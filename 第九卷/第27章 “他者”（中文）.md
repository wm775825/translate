# 第二十七章 “他者”

## 第一节 基督徒与犹太人的关系，1914—2000年

**丹尼尔·R. 兰顿（Daniel R. Langton）**

> 本章原书第483—513页；对应原PDF第484—514页。

若只是把1914至2000年称为犹太人与基督徒关系的重要时期，实在有些轻描淡写。两个关键事件是，1933至1945年纳粹大屠杀摧毁欧洲犹太人社会，以及1948年以色列建国。它们对现代犹太身份具有深远意义，也在传统态度与神学方面，向基督教会提出有力挑战。归根结底，任何讨论二十世纪基督教与犹太“他者”互动的概述，其范围与内容，都由这两件事决定。

首先必须处理的一个问题，是互动的边界。我们应当认识到，现代世界犹太共同体与基督教共同体一样，具有分散、分化的性质。启蒙运动以来形成的犹太“共同体”，包括极端正统派、正统派、保守派、改革派、自由派与进步派、重建派，以及各种世俗犹太人。一般认为，基督教可用宗教或神学来界定；犹太身份却更复杂，常以被认为非宗教的方式表达。锡安主义，也就是建立并维持犹太国家的运动，就是一例；其许多形式完全不具宗教性，甚至反宗教。此外，大屠杀六百万犹太受害者中，相当大一部分实际上并不在宗教意义上自视为犹太人，而是世俗主义者，或已经同化、具有犹太血统的基督徒。因此，尽管其中有固有危险，似乎仍有必要<a id="pdf-485"></a><!-- PDF page 485; original page 484 -->以尽可能广泛的意义谈论犹太文化。话虽如此，本节重点仍将是这一时期犹太人与基督徒互动中，明确具有宗教性质的层面。

纳粹大屠杀，是国家支持、有系统地迫害并杀害约六百万犹太人，以及数百万其他人的行动；实施者是德国人及其合作者，遍及社会各阶层，也遍及许多基督教国家。它向整个人类提出深刻问题，但不应因此淡化它对基督教造成的特定难题。今天，很少历史学家支持所谓“连续性论述”，即从一世纪耶稣早期追随者与其他犹太人之间产生的“蔑视教导”[^p485-1]和敌意，直接画出一条线，通向二十世纪以种族、伪科学及灭绝为特征的反犹主义。然而，基督教的反犹太教思想，虽不是充分原因，却无疑是一项必要原因。第三帝国虽然具有反宗教倾向，纳粹宣传者却迅速挖掘欧洲基督教文化表层之下丰富的反犹资源。例如，1936年慕尼黑版《马丁·路德选集》，收录了他1543年极其恶毒的论战文章《论犹太人及其谎言》。[^p485-2]这类材料强化种族主义宣传，也使一个表面上的基督教社会，能够对犹太人遭受的待遇视而不见。死亡营工作人员、流动杀人队成员，以及管理屠杀过程的官僚与技术人员中，都可以找到自称信仰基督教的人。东欧各地农民默许没收犹太人财产，并把犹太人受到的待遇，辩解为对古老“弑神罪”的惩罚。

在机构层面，天主教会因大屠杀期间的“沉默”，以及外交努力不足而受到批评。后来成为庇护十二世（1939—1958年任教皇）的欧金尼奥·帕切利，在纳粹掌权仅六个月后，便与其落实一项政教协定。它给纳粹政权带来国际信誉，并因承诺不干涉政治事务，严重削弱基督徒抵抗。庇护十二世任内，出于对无神布尔什维克的恐惧，为信众利益及外交理由而坚持一般中立政策，使梵蒂冈对于<a id="pdf-486"></a><!-- PDF page 486; original page 485 -->纳粹对待犹太人的做法，立场受到牵制。1942年圣诞讲话中，庇护十二世没有明确提及纳粹或犹太人，却谈到“数十万人，本身毫无过错，有时仅因国籍或种族，就被判处死亡，或者缓慢衰亡”。有人声称，教会通过外交渠道，并把许多人藏于修道院，挽救了数千犹太人的生命，但这些说法仍有争议；不过，战争将结束时，庇护十二世确实鼓励德国与匈牙利的教会代表，向纳粹受害者提供人道援助。

纳粹统治下的新教，因1933年德意志新教教会成立而更趋复杂；它是由路德宗、改革宗及联合地区教会组成的联邦。右翼派别“德意志基督徒信仰运动”取得控制。除主张因旧约与保罗书信具有犹太性质，应将其逐出正典外，“德意志基督徒”也支持雅利安种族至上教义。路德宗马丁·尼莫勒成立牧师紧急联盟，形成反对力量；1934年5月巴门教会会议建立认信教会，路德宗迪特里希·朋霍费尔是其主要牧师之一。他们在反对“德意志基督徒”与纳粹方面，有过一些成功，例如1941年与其他人一道向政府施压，使政府为针对精神病人与残疾人的安乐死计划寻找替代办法。然而，认信教会领导层分裂，对犹太人的态度也含混。尼莫勒从1937年起被监禁至战争结束；朋霍费尔1943年被捕，1945年被处死。纳粹充分利用新教内部缺乏团结与相互冲突的局面。少数抗议犹太人遭遇的新教领袖，往往即使在行动时，神学上仍对犹太教持负面态度。因此，朋霍费尔和尼莫勒一面教导基督徒不应迫害犹太人，一面又明确坚持，犹太人受苦，是上帝惩罚他们古时拒绝、杀害其子，并期待以色列归信基督教。[^p486-3]

大屠杀带来死亡与毁灭之后，1948年现代以色列国诞生，是二十世纪犹太人与基督徒关系中第二重要的发展。犹太国家这一概念本身，<a id="pdf-487"></a><!-- PDF page 487; original page 486 -->就挑战传统基督教与伊斯兰神学。许多世纪以来，犹太人被描绘为一种已被取代宗教的信徒，以及“弑神者”。他们顽固、乖谬，因此受罚，遭逐出自己的土地，失去政治权力，注定流浪世界。尽管如此，基督教思想中也一直并存着亲犹传统，因此，现代锡安主义事业得到各种不同的基督徒回应。

“基督教锡安主义者”一词，涵盖广泛群体与不同视角。一端是按字面理解圣经者，认为流亡者回归以色列，是预示基督再来的神圣计划的一个阶段；另一端是自由派思想家，其鲜明的普世合一精神，以及对大屠杀教训的内化，使他们无条件支持以色列国家政策。若把基督教锡安主义理解为对犹太民族浪漫化、神话化的看法，它在本节所涉时期具有重要影响。例如，宗教在1917年《贝尔福宣言》发布中发挥了作用。[^p487-4]这份文件公开表达英国政府支持“在巴勒斯坦为犹太人民建立民族家园”。阿瑟·贝尔福与首相劳合·乔治等英国政治家熟悉圣经，因此把支持锡安主义视为履行历史使命。英国军队正准备从奥斯曼土耳其人手中夺取耶路撒冷之际，宣告有意把土地归还古老以色列民族，在他们看来，是一项体现历史正义的宏大象征姿态。若只从宗教议程，甚至主要从宗教议程来解释宣言，会过于简单。然而，解释英国何以搁置当地阿拉伯居民的利益时，不能忽略此处宗教与政治的交会。这些居民约占人口90%，其中10%是阿拉伯基督徒。锡安主义领袖哈伊姆·魏茨曼在自述中总结，英国政治家“相信圣经；对他们而言，犹太民族回到巴勒斯坦是真实的，因此，我们锡安主义者在他们眼中，代表着一种他们无比尊重的伟大传统”。[^p487-5]二十世纪后半叶，基督教锡安主义者之所以受以色列历届政府欢迎，是因为他们<a id="pdf-488"></a><!-- PDF page 488; original page 487 -->公开支持政府政策，向以色列输送资金，以及来自俄国、东欧各国的犹太移民。

天主教会对锡安主义和犹太国家，采取更敌对的立场。1904年，庇护十世告诉政治锡安主义之父西奥多·赫茨尔：

> 我们不能阻止犹太人去耶路撒冷，但绝不能认可。耶路撒冷的土地……已因基督的生命而成为神圣。作为教会首领，我不能给你别的答复。犹太人没有承认我们的主，因此我们不能承认犹太民族……支持犹太人取得圣地，这一点我们不能做。[^p488-6]

1917年12月，协约国攻占耶路撒冷。梵蒂冈虽担心由新教徒控制，本笃十五世仍于1919年谈到，圣地脱离“异教徒统治”，“终于回到基督徒手中”，使“一切善良的人欢欣”。[^p488-7]但犹太人可能取得控制权，却引起另一种反应。1947年联合国讨论分治计划时，梵蒂冈支持耶路撒冷国际化；1967年六日战争后，又争取基督教圣地的国际地位。以色列1948年建国后，梵蒂冈拒绝承认；即使原文所记保禄六世1967年在以色列停留一天时，仍延续拒绝。若望保禄二世任内，传统立场有所软化；1980年，他公开提及以色列，以及犹太人民拥有家园的权利。罗马教会于1993年12月正式承认以色列国。

可以认为，国际层面犹太人与基督徒的和解，以及宗教间关系的发展，与以色列国出现、打破基督徒对犹太人的传统看法，关系至少不小于因大屠杀与“蔑视教导”而产生的内疚。1922至1948年，英国试图落实国际联盟的巴勒斯坦委任统治，既促进犹太移民、定居与自治机构，又维护巴勒斯坦所有居民的公民权。虽然形式上具有国际主义资格，委任统治者显然是基督教势力，也是十字军东征以来，当地首次出现的这类行政当局。然而，随着<a id="pdf-489"></a><!-- PDF page 489; original page 488 -->联合国承认以色列，基督徒对犹太人的政治统治结束了。1948年以色列独立战争，以及1967年六日战争，对多国阿拉伯军队取得的军事胜利，令人印象深刻，也出人意料。现代以色列国在军事与外交上高效有力，文化充满活力，也富有自信，与犹太人无国、软弱、寄生的负面形象形成对照。1967年战争还有一项意义：在许多犹太观察者看来，教会已是第二次没有对犹太人面临灭绝威胁发声。尚在萌芽的宗教间对话受到震动，最终仍恢复平衡，使基督徒更理解以色列对于犹太人的意义。新国家除带来神学挑战，也产生实际困境。大屠杀之后，基督徒面对一个敏感问题：如何看待以色列人与巴勒斯坦人之间的权力关系？在社会正义诉求与被指反犹偏见之间找到方向，证明十分困难。

近代犹太人与基督徒历史中若干争议事件，也最好放在大屠杀背景下理解。它们都反映犹太人对“大屠杀基督教化”的恐惧：他们认为，教会倾向于强调基督徒的受害与英雄行为，从而削弱犹太经验的独特性。七十年代以来，美国与西欧的犹太共同体机构，强烈维护被杀害同胞的记忆；与其他群体不同，这些犹太人被纳粹作为彻底消灭的对象，而且几乎没有外界援助。一些基督徒反过来谴责，认为犹太人在宣称垄断苦难。有时，这类批评也带有反犹意味。

1984年，奥斯维辛集中营内拟建加尔默罗修道院的计划宣布，引发共同体间危机。犹太团体认为，这项基督教默观与纪念计划，实际上是占用了犹太人在大屠杀中受苦的典型象征。随后十年，双方尖刻争吵、激烈论战。1989年情形跌至低谷：一名美国拉比身穿囚服，带领抗议者冲入营地，斥责拘住他的人是纳粹式反犹主义者；一名波兰枢机则公开警告犹太人，不要滥用对许多国家媒体的权力，提出不可能满足的要求。1993年，波兰主教团直接介入，教皇也致信，修女离开旧修院，问题似乎解决了；但争论又在<a id="pdf-490"></a><!-- PDF page 490; original page 489 -->1998至1999年重新燃起，一名天主教极端分子监督在同一地点竖起“十字架森林”。十字架德兰·本笃修女于1987年宣福、1998年封圣，同样遭到挪用犹太记忆的指控。这位加尔默罗修女于1942年在奥斯维辛被杀；犹太团体抗议，因为她虽改信天主教，却生来是伊迪特·施泰因，并且是作为犹太人在奥斯维辛遇害。更一般地说，为那些对犹太人态度可疑者宣福，引来许多批评。马克西米利安·科尔贝神父于1941年在奥斯维辛勇敢地代替另一名被判死者赴死，挽救对方生命；但1982年为他封圣，仍有问题，因为他战前曾主编刊有反犹内容的杂志。同样，提议为庇护十二世宣福，使那些对其战时教皇任期持负面解释的人深感不安。1987年，若望保禄二世会见奥地利总统库尔特·瓦尔德海姆，也令犹太团体愤怒，因为当时已有指控，把瓦尔德海姆与纳粹战争罪联系起来。

二十世纪犹太人与基督徒其他冲突领域，则源于更古老的争执。例如对改宗的态度，以及对犹太基督徒的态度。

从犹太人的角度看，改信基督教意味着背叛自身文化、传统与遗产；但对离教者的态度又很复杂，著名的丹尼尔修士案便说明这一点。波兰犹太锡安主义者奥斯瓦尔德·鲁法伊森，二战期间积极参加抵抗。他潜入德国警察机构，利用职位向当地犹太共同体预警纳粹计划，挽救约150人。遭逮捕后，他逃脱，藏身加尔默罗修道院，1942年改信基督教。即使1945年加入修会、取名丹尼尔之后，他仍保持犹太自我身份，1962年依据《回归法》申请以色列公民权。法官的裁决同情鲁法伊森，赞赏其战时表现，也承认按犹太宗教法，即 *halakhah*，他仍是犹太人。然而最终认为，改宗与过去的决裂过于深刻，不能依据《回归法》，作为犹太人给予他公民权。所谓犹太人的“泪水史”，仍对现代犹太心理有重要影响，是犹太国家中决定犹太身份的有力因素。

犹太基督教问题也充满争议。十九世纪“希伯来基督徒”往往紧密依附非犹太教会，七十年代却出现“弥赛亚犹太人”团体，<a id="pdf-491"></a><!-- PDF page 491; original page 490 -->与外邦基督教保持距离。希伯来基督徒传教士莫谢·罗森，开始批评“外邦化”对信耶稣犹太人的影响，希望强调犹太族群身份，于是在旧金山建立福音派团体，后来称为“犹太人为耶稣”，向全美外邦基督徒与犹太人传达信息。对更广大犹太共同体的许多人而言，这个团体几乎代表了弥赛亚犹太教本身，主要是因为它在校园与机场高调作见证，且常带对抗性。具有讽刺意味的是，对这类团体的反对，团结了经常分化的犹太共同体。1980年，犹太保卫联盟从洛杉矶一所弥赛亚会众中取走一卷《妥拉》，并在其会堂外示威，类似事件表明情绪何其强烈。犹太报刊一致谴责，认为这是欺骗性的基督教改宗策略，挪用了犹太宗教象征。参与宗教间对话的基督教领袖也有批评，既承认这冒犯犹太人，也因认为基督教被歪曲而不安。一个突出例外，是改革派拉比丹·科恩—谢尔博克。他在2000年《弥赛亚犹太教》研究中认为，弥赛亚犹太教可以视为犹太教的正当表达，因为它并不比重建派犹太人拒绝超自然上帝的观念更激进，而且许多信徒实际上比不少改革派犹太人更遵守宗教规范。[^p491-8]

离教引发的强烈反应与怀疑，有助于理解犹太人为何对宗教间对话有所保留。主要障碍是，许多犹太人认为，“对话”等于以更隐蔽方式，延续传统传教政策。德国犹太哲学家、神学家马丁·布伯（1878—1965），在开创性的《我与你》（1922）中，区别两种互动：“我—它”的独白，双方不平等，将对方当作资源；以及“我—你”的对话，双方态度具有相互性、开放性、直接性与当下的临在。他认为，宗教对话的关键，是承认他人信仰现实的奥秘。“我们不能评判他们信仰告白的意义，因为我们不像从内在了解自身那样，从内在了解它。”[^p491-9]这样的<a id="pdf-492"></a><!-- PDF page 492; original page 491 -->态度排除了怀着任何传教目的进行真正对话的可能。布伯在这方面对犹太人的影响有限，却深刻影响基督教思想家，尤其新教思想家。他的对话模式中许多特征，后来被宗教间团体采用，例如1942年在英国成立、旨在反对反犹主义并培养相互理解的基督徒与犹太人理事会。布伯无疑有助于思想气候转变，使大屠杀与以色列建国之后，多个新教宗派能够发表声明，建议停止使犹太人改宗的努力。

二十世纪教会官方宣言，在犹太人与基督徒关系的思想史上，代表了显著发展，堪称板块式转移；不过，也必须始终记住，这类文件读者有限。早在1947年，泽利斯贝格便发表跨宗派声明，谴责灌输反犹主义的基督教教导，以及不正当或强制性的传教。后来新教声明，通常采取非胜利主义态度，尊重圣经时代之后的犹太教，建议重新审视“弑神”等传统教会教导，并强调基督教的犹太根源。莱茵兰新教教会1980年会议，是特别突出的例子。它承认“基督徒对大屠杀的共同责任与罪责”，认可犹太人的自我界定、以色列永久蒙选及以色列国，拒绝教会已取代以色列的取代论教导；尤其重要的是，它明确谴责使犹太人改宗：“我们相信，犹太人与基督徒在各自蒙召中，向世界，也向彼此，作上帝的见证。因此，我们确信，教会不可用向世界各民族传教的同样方式，向犹太民族表达见证。”这类文件鼓励犹太人，更有力地与那些仍坚持传教立场的基督教机构交涉。美国浸礼宗1996年发表声明，称“我们把精力和资源用于向犹太民族宣讲福音”，引起国际上一片反对声。不过，对犹太共同体而言，最受关注的仍是梵蒂冈宣言。许多人认为，教皇对地球上最大基督徒群体的权威绝对，对未来关系至关重要。因此，天主教会1959年决定，从耶稣受难日礼仪中，删去用于贬称犹太人的“背信的”一词，受到欢迎。1965年《在我们时代》表达希望“培养并提倡……相互理解与<a id="pdf-493"></a><!-- PDF page 493; original page 492 -->尊重”，并指出：“教会虽然是天主的新子民，却不应把犹太人说成被天主弃绝或诅咒，好像这类看法出自圣经。”这份文件及后来其他文件，通常受到犹太团体欢迎，但他们也清楚表达进一步进展的期待。然而，1998年出版的《我们记得：对大屠杀的反思》，遭到相当多批评。批评者欢迎任何探讨大屠杀及教会在这一时期表现的努力，却不赞同文件替庇护十二世辩护、强调天主教英雄行为，也不赞同它似乎把“教会子女的错误与失败”，同教会本身的罪责区别开来。

基督教会态度的改变，在一定程度上与学术发展有关。十九世纪与二十世纪初，包括德国改革派拉比亚伯拉罕·盖格，以及英国自由派犹太教共同创办者克劳德·蒙蒂菲奥里在内的一些犹太作者认为，基督教学术严重歪曲古代与现代犹太教；耶稣应被视为某种犹太人，例如法利赛人，或律法时代的先知。[^p493-10]他们的作品却受到忽略。二战后，圣经与新约研究界更认真地看待犹太学术。部分原因，是少数美英基督教学者的影响，例如长老宗乔治·富特·穆尔与一位论派罗伯特·特拉弗斯—赫福德；他们强烈批评此前基督教，尤其德国学者，对“晚期犹太教”与法利赛人的描绘。[^p493-11]部分原因，是进入学界的欧美犹太学者，力图挑战支撑学术体系的某些基督教预设。还有部分原因，是居住于以色列之地的犹太历史学家，如约瑟夫·克劳斯纳与戴维·弗卢塞尔，能够不受拘束地写作；对他们而言，耶稣作为犹太人，是犹太民族遗产的一部分。[^p493-12]不论原因何在，所谓“犹太人重新认领耶稣”及相关发展的影响，有助于<a id="pdf-494"></a><!-- PDF page 494; original page 493 -->促成更广泛地从犹太视角，重新考察耶稣、使徒保罗及一世纪犹太社会。其后果之一，是遏制了为使耶稣显得彻底独创，而诋毁犹太教的做法。

犹太人的新约研究不断增加，对理解犹太人与基督徒关系的含义，也影响了神学家。美国天主教女性主义者罗斯玛丽·拉德福德·鲁瑟，在1974年《信仰与手足相残》及其他著作中，发展了英国圣公会人士詹姆斯·帕克斯，以及法国犹太历史学家朱尔·伊萨克的工作，将反犹主义的根本原因，认定为基督教。[^p494-13]鲁瑟相信，犹太人拒绝承认耶稣为基督，必然导致对犹太教的贬低，因此开始质疑强调基督神性的“高基督论”本身是否合法。她说：“反犹太教思想在基督教中发展成一种神学，成为基督论的左手。”[^p494-14]另一些人则认为，这样的修正仍不足够，需要系统重整基督教神学，以及犹太教在其中的位置。美国圣公会神学家保罗·范布伦1980至1988年的三卷本《犹太—基督教现实的神学》，是这一努力的高峰。他试图以单一盟约，统一基督教与犹太教的启示，并将教会首要使命，理解为保护犹太人忠于《妥拉》，以及拥有国家。不过，这些宗教间关系思想领域的里程碑，绝不能代表更广泛基督徒共同体，甚至一般基督教学界的态度。

就犹太人与基督徒关系而言，二十世纪有愈来愈多基督徒个人及机构，努力承认圣经时代之后犹太教的正当性与活力，并正视传统刻板印象，以及神学滋养的偏见。两种信仰共同体因共享起源，形成独特关系，由此产生偏见，也使彼此在神学上相处困难；双方对各自人民之间往往充满创伤的互动历史，又都具有长久记忆。这一切意味着，基督教与犹太“他者”的关系，仍然脆弱。

## 第二节 基督徒与穆斯林的关系

**戴维·托马斯（David Thomas）**

第一次世界大战爆发时，祈祷中的欧洲基督徒，对伊斯兰教并不怎么关心，因为穆斯林生活在遥远之地。但到千禧年之交，冷漠已经让位于与信仰邻人穆斯林的接触，也让位于对穆斯林极端分子威胁生计与生命的焦虑。二十世纪新教与天主教会最剧烈的变化，莫过于对伊斯兰教态度的变化；在基督徒与穆斯林共享的一千四百年历史中，也没有哪个时期的态度改变更加根本。它们源于一系列相互关联的因素，既包括伊斯兰世界经历的剧烈转型，也包括基督徒对非基督徒的新认识，以及与之接近的新行动。

1914年，几乎整个伊斯兰世界，要么由欧洲强国直接统治，要么在其势力范围内。奥斯曼帝国虽然实际上受到欧洲首都控制，仍构成唯一主要的主权伊斯兰实体；世界各地穆斯林，都把伊斯坦布尔的苏丹视为哈里发，即作为全球穆斯林共同体领袖的先知穆罕默德继承者，也是穆斯林团结与愿望的象征。战后帝国被肢解，尤其1924年哈里发制被废除，一切随之改变。昔日领土分成不同国家，在西方影响下，被迫迅速面对新的政治、经济、技术与文化现实。有些穆斯林热情拥抱改革，许多人却心怀戒备，意识到它可能威胁传统信仰。

二十世纪继续前进，欧洲强国也陆续放弃帝国，非洲与亚洲又出现一些拥有大量穆斯林人口的新国家，同样面对前奥斯曼领地所面对的现代性挑战。这些国家的穆斯林共同体，经常陷于两难：一面参与建立以欧洲价值与规范为基础的国家生活，一面又努力保留传统信仰和实践。虽然非洲等许多新国家的穆斯林，<a id="pdf-496"></a><!-- PDF page 496; original page 495 -->没有立即反应，南亚却将分离视为唯一解决办法，因此建立巴基斯坦，让穆斯林能够按自身信仰原则生活。

尤其在本世纪后期几十年，受到伊朗阿亚图拉霍梅尼象征性领导的鼓舞，穆斯林自信增长，世界各地穆斯林作为宗教情感强烈、抵抗西方影响的人，愈来愈显眼。原因极其复杂，其中突出者包括：新的石油财富，使部分阿拉伯国家政府能够资助伊斯兰传教；人们普遍失望于失败的世俗政府，渴望宗教价值带来的确定性；以及对西方伊斯兰世界政策的失望，尤其对以色列短视的忠诚，使人不满外来方式。

本世纪中期，一些知名知识分子，公开拒绝外来影响，呼吁回归宗教生活。埃及的赛义德·库特卜（1906—1966）是最尖锐的批评者之一；他在美国居住两年，使反西方态度更为激烈，诊断欧洲患有一种“可怕的精神分裂，使宗教与实际生活之间任何有效关系都告终结”。[^p496-15]其他人虽然没有如此直言，许多人也意识到，伊斯兰世界急需重新发现自己，或回到未经掺杂的经典教导，或在穆斯林生活的新处境中，重新解释这些教导。

当然，世界一些地区的基督徒与穆斯林，已经并存数百年。在中东、埃及与伊朗，基督徒共同体以宗教界定的受保护附属群体，即 *dhimmis* 身份，生活在穆斯林政府之下；欧洲东南部、菲律宾及西非部分地区，穆斯林则生活在人数更多的基督徒中间；尼日利亚两种信仰人数大致相等。正如可以预料，经过长期发展，人们形成某些共存方式，使两教信徒能在宽容与一定安全中继续生活。然而，这绝不意味着和平与善意始终存在：本世纪不同时期，黎巴嫩、苏丹、波斯尼亚—黑塞哥维那及科索沃的互相残杀，都被归为基督徒与穆斯林之间的仇恨，无论这种描述准确与否。以宗教名义犯下的暴行，不断提醒人们，<a id="pdf-497"></a><!-- PDF page 497; original page 496 -->宗教差异具有危险，两种都声称体现和平的宗教，也具有暧昧的力量。

穆斯林迁入西方国家，使西方基督徒深切意识到，两种信仰的差异，以及冷静重新评估如何相互尊重接近的迫切需要。二战后几十年，来自前殖民地与盟国、主要从事体力劳动的人，稳定涌入欧洲，尤其从土耳其进入德国，从阿尔及利亚与摩洛哥进入法国，从印度与巴基斯坦进入英国。[^p497-16]政府最初或许以为，他们会短期离开，或者逐渐融入接收社会。但多数人不仅留下，而且建立的生活方式，比起新环境，更接近旧环境。因此，穆斯林共同体成为西欧许多城市与城镇不可分割的一部分；他们的语言、食物、服装与敬拜场所，都是存在的鲜明标志。

无论起初受到积极欢迎，还是仅被容忍，他们长期存在，都要求社会与法律给予恰当对待。英国穆斯林于1988年强烈抗议萨尔曼·鲁西迪《撒旦诗篇》，以及书中对先知穆罕默德几乎不加掩饰的侮辱，震动了更广泛社会的许多人，使他们认识到穆斯林鲜明的宗教敏感，也看到一个尖锐差异：他们坚持保护所敬重的神圣真理，而许多教会参加者却通常表现宽容。法国1989年，两个穆斯林女孩因戴头巾表达信仰而被学校排除，说明了世俗化的法国国家，与把公开表达信仰视为生活一部分的穆斯林公民之间的巨大差别。两件事都提出根本问题，涉及在非穆斯林环境保存伊斯兰教的权利、言论自由，以及宗教与国家冲突。教会应当如何回应？

另一件使基督徒深切意识到穆斯林存在的事件，是1979年伊朗沙阿被推翻，以及在阿亚图拉霍梅尼领导下建立伊斯兰共和国。这个治国实验，凝聚许多穆斯林对以伊斯兰教导为基础政体的希望，既有什叶派，也有逊尼派。在许多方面，霍梅尼成为全球穆斯林领袖，也是强大、自立伊斯兰的象征。

<!-- PDF page 498; original page 497 -->



穆斯林自信恢复，二十世纪后期出现一些极端团体，愿意战斗、杀戮，甚至殉道，以推行伊斯兰原则和生活方式，清除西方影响与威胁，便不足为奇。同样，美国评论家塞缪尔·亨廷顿，也把伊斯兰集团与西方集团之间敌意不断增加，预测为不可避免的文明冲突的一部分。[^p498-17]无论极端穆斯林，还是亨廷顿，其分析和预测是否正确，都大有疑问；但他们所感受到的两种文化、信仰之间的分裂，表明了一个日益加深的问题：复兴的伊斯兰把具有基督教基础的西方视为对手，而其基要主义式的不妥协，又反过来被视为真实、当前的威胁。

教会二十世纪态度的变化，正是在这一背景下发生。二十年代，英国基督徒可以公开写道，伊斯兰是一种蒙昧、腐败的宗教，唯一补救方法就是大规模传福音。但到千禧年之交，言辞已经改变，虽然内心感受往往未变；基督教领袖有时称穆斯林为信仰伙伴，也回顾伊斯兰对现代欧洲文明基础的贡献。

本世纪早期，尤其在那些与殖民强国正式或非正式合作开展传教的教会中，基督徒通常认为，穆斯林信奉压抑性的信仰，需要福音。例如，为1926年英国国教会大会准备的一份报告，如下诊断伊斯兰的需要：

> 寻求光明的受教育阶层，需要基督的心意，以牺牲服务的崇高目的照亮生活；伊斯兰妇女受野蛮时代法律束缚，需要福音解放的力量，使她们在家庭与社会生活中取得应有位置；农民与不识字阶层，常依附这个或那个托钵僧团，需要认识上帝的父性，以及其寻求神圣之旅的目标；苏菲神秘主义者寻求上帝经验，需要被带到基督面前，认识他就是道路、真理、生命。[^p498-18]

<!-- PDF page 499; original page 498 -->



报告一再明确表示，整个伊斯兰世界都处于被动状态，只要抓住机会，就准备回应。这预示了荷兰传教士亨德里克·克雷默的思想；当时，他正为1938年印度南部坦巴拉姆的国际宣教理事会大会准备。克雷默写道：“就伊斯兰的组成成分与理解而言，必须称它为一种表面的宗教……可以说，伊斯兰是一种几乎没有问题、也没有答案的宗教。”[^p499-19]会上，克雷默依巴特思想，坚持基督教与其他宗教不连续，影响极大。但他并未完全占上风；会议最终声明，仍把以下问题留作开放讨论：“非基督宗教……是否可以视为在某种意义、某种程度上表现上帝的启示？”[^p499-20]

巧合的是，承认宗教之间连续性的与会者所持立场，今日会称为包容论，也在庇护十二世1943年《奥体》通谕中得到呼应，虽然听起来像一种勉强让步：“即使他们——一切非天主教徒，包括非基督徒——因某种无意识的愿望与意愿，可能与救赎者的奥体相连，仍然缺少天上如此众多、如此有力的恩赐与帮助。”[^p499-21]这里，天主教官方文件首次保留一种可能：教会之外的人，包括非基督徒，也可能得救。它间接表达的思想，重大地逆转了古老信条 *extra ecclesiam nulla salus*，即“教会之外无救恩”，并预示六十年代梵二的开创性教导。它也简要包含耶稣会神学家卡尔·拉纳（1904—1984）后来明确提出的见解：上帝通过基督，把恩宠赐给所有人，无论教内教外；凡回应者都可以称为基督徒，不自觉回应的人，则是“匿名基督徒”。[^p499-22]

拉纳从先验神学出发，得出这一见解。这使他有别于另一位思考基督徒与他人关系的伟大天主教思想家，法国学者路易·马西尼翁（1883—1962），后者<a id="pdf-500"></a><!-- PDF page 500; original page 499 -->多年沉浸于伊斯兰神秘思想，认识到穆斯林也是受圣灵引导的亚伯拉罕子孙。[^p500-23]

这一见解，接近二十世纪任何教会所发布、论及伊斯兰的最重要文件的教导；实际上，在此前历史中也没有比它更重要的文件。它可以看出上述学者及其他进步学者的影响。这份简短文件，于1965年10月28日、梵二将结束时颁布，题为《论教会对非基督宗教态度宣言》，通常按开头用语称为《在我们时代》。

其中关于伊斯兰的一段，详细描述穆斯林信仰与实践，并强调由此体现的与基督徒之间的联系：

> 教会也十分尊重穆斯林。他们敬拜独一、永生而自存、仁慈全能、创造天地、曾向人讲话的天主。他们努力毫无保留地服从天主隐秘的旨意，正如亚伯拉罕服从天主的计划；穆斯林热切愿意把自身信仰与他的信仰联系起来。虽然不承认耶稣为天主，他们却尊他为先知，也尊敬他的童贞母亲，有时甚至虔诚呼求她。此外，他们期待审判之日，以及死人复活后天主所给予的报偿。因此，他们十分重视正直生活，并敬拜天主，尤其通过祈祷、施舍与斋戒。[^p500-24]

传统天主教徒在这里找不到可反对之处，却可能对随后一句感到惊讶：“本神圣大公会议如今恳请所有人忘记过去，敦促大家真诚努力，达致相互理解。”[^p500-25]

这样的理想主义，或许会被认为不现实。如果如此，前面的描述也与它相称：凡可能在教会内引起反感的伊斯兰特征，都被省略，例如直接提及先知穆罕默德与《古兰经》。一份初看开放、欢迎的文件，实际上却把真实伊斯兰的特性淡化了。

不过，鉴于文件在介绍伊斯兰及其他信仰之前，对所有非基督宗教作出的一般声明，这又不可避免。声明说，教会虽然“不拒绝这些宗教中任何真实与神圣的事物”，却仍承认自己有义务“始终不渝地宣讲<a id="pdf-501"></a><!-- PDF page 501; original page 500 -->基督，他就是‘道路、真理、生命’”（《若望福音》14:6）。[^p501-26]这凸显一种紧张：希望接受他人为伙伴，同时又必须宣讲基督教真理。会议没有解决这一紧张，它也成为此后几十年基督教思想家的重大挑战。

会议期间，保禄六世于1964年颁布《祂的教会》通谕，热情提及穆斯林。继任者若望保禄二世，也在首道通谕《人类救主》（1979）中重申《在我们时代》的教导，后来又于《救主的使命》（1990）强调，圣灵存在于世界各地个人与社会中。然而，他也清楚表明，教会的首要任务是传教，与穆斯林及他人的对话，只是其表达之一：“开展并实行对话时，应当确信，教会是通常的救恩途径，只有她拥有救恩途径的圆满。”[^p501-27]教皇多次访问伊斯兰国家、欢迎穆斯林领袖，甚至于1986年10月27日，戏剧性地邀请世界各宗教代表，到阿西西共同度过和平祈祷日，都没有改变这一优先顺序。事实上，阿西西聚会中，各宗教团体分别祈祷。

天主教对其他信仰关系的新重视，表现为1964年教廷内部设立非基督徒秘书处；1988年改名为宗座宗教交谈委员会。依照职权，该委员会就《在我们时代》暗示的紧张，发表了文件，特别是1984年《对话与见证》及1991年《对话与宣讲》，[^p501-28]把对话解释为更广泛传福音任务的一部分。2000年，梵蒂冈另一部门信理部，在《主耶稣》中毫不妥协地说清这一关系：“宗教间对话，作为她福传使命的一部分，因此只是教会向万民传教诸行动中的一项。”[^p501-29]

新教教会也有明确向伊斯兰开放的姿态，不过方式没有那么鲜明。正式关系由<a id="pdf-502"></a><!-- PDF page 502; original page 501 -->世界基督教协进会发展起来。它先于1966年在黎巴嫩布鲁马纳、1967年在斯里兰卡康提，就与穆斯林见面是否适宜，举行预备咨询；随后，1969年在瑞士卡斯蒂尼组织首次会面，1970年在黎巴嫩阿贾尔通举行多宗教聚会。协进会与天主教明显不同的重点，在这些聚会中显现。其组成教会多样，无法以单一声音发言；1938年坦巴拉姆会议表现出的分歧并未消失。因此，它不发表权威训导式声明，而强调不同信仰在尊重中并存、实际合作的重要性。

1979年，协进会发表关于宗教间关系的关键文件《与现存信仰及意识形态信众对话的准则》。[^p502-30]其特点，是承认基督徒对于宗教间事务具有不同看法，因此提倡不同信仰合作，建立一个“共同体的共同体”，让尊重调和差异。

与天主教一样，协进会成员教会也认识到对话与传教之间的紧张，却同样无法解决。斯坦利·萨马尔塔1979年形象地概括：“对话从传教的子宫诞生；传教若要剪断脐带，承认日渐成长的孩子独立，同时又不否认两者关系，从来不容易。”[^p502-31]

天主教与新教的这些发展，发生于前述背景：穆斯林在本国与移居国愈来愈坚持自身，极端穆斯林团体愈加激进，西方普遍受到拒绝，也经常导致人们不信任基督徒对话姿态背后的意图。因此，教会最高层虽然认可并追求对话，但它对不止少数穆斯林究竟产生多大影响，仍值得怀疑。许多人把教会主动接近的姿态，与西方政府行动放在同一背景中看：1991年迅速解放石油丰富的科威特，几年后帮助波斯尼亚与科索沃穆斯林时，却做得太少、太迟。许多人拒绝对话，认为缺乏诚意；少数甚至用武力抵抗。只有一些人，主要是居住西方的知识分子，看到加深相互理解，以及通过进一步讨论增进诚实与尊重的好处。

<a id="pdf-503"></a>
<!-- PDF page 503; original page 502 -->



教会官方机构的进展，是否已被许多参加教会的基督徒，乃至他们的神父与牧师注意到，也必须追问。在两种信仰已并存数百年的地区，虽然探讨基督教与伊斯兰差异的专业宗教间会议成倍增加，官方教会声明，却很少使态度发生广泛改变。穆斯林成为邻居，或通过改宗、婚姻成为亲属，这些实际现实，使一些人意识到，需要认识并反思伊斯兰；但对许多人而言，即使临近2000年，这仍是边缘问题。2001年9月11日的暴行，使一切改变。它们以伊斯兰之名实施，使所有人集中意识到伊斯兰的强大力量，也给基督徒提出理解与合作方面更大的挑战，远超1914年前辈所能想象。

## 第三节 基督徒与佛教徒、印度教徒的关系

**戴维·奇瑟姆（David Cheetham）**

### 佛教徒

二十世纪基督徒与佛教徒关系的历史，丰富多样，反映许多地区差异与具体历史情境。因此，叙述这样多样的关系，无法采用统一方法，也难以轻易概括曾发生的相遇与讨论之复杂。在理论层面，可以介绍个别学者反思与他者对话、相遇时，所进行的概念对话或比较研究。有神论与非有神论宗教之间，显然存在差异，使这场讨论极富创造性；不过，参与工作的是基督教神学家多于佛教徒。[^p503-32]然而，除了“概念性”或纯神学相遇，要理解二十世纪基督徒与佛教徒的关系，<a id="pdf-504"></a><!-- PDF page 504; original page 503 -->也必须考虑十九世纪基督教传教活动的影响。这不仅有助于理解斯里兰卡等地具体的历史相遇，也有助于理解二十世纪后半叶反思“他者”时，经常伴随的“殖民内疚”。概括而言，基督教反思自身殖民过去，促成面对其他信仰的新姿态，也使一些人激进地迈向包容与对话。

西方有许多基督教宗教间团体，乐于“跨入”佛教传统，探索并吸收某些实践与禅修技巧，但其他国家未必如此。例如在印度，虽然与其他宗教对话，在南亚意识中本是更自然的倾向，基督徒却常因需要保存身份，而对对话有所节制。最近，表列种姓或达利特的改宗现象，使基督徒与佛教徒在争取这些群体时，出现一定竞争。斯里兰卡殖民时代基督徒与佛教徒紧张的历史与记忆，继续影响当代相互理解的努力，有时使“共同基础”成为痛苦、困难的观念。具有反讽意味的是，正是基督教传教士的行动，促使佛教徒采用更精细、更积极进取的“传教”方法，即所谓“新教式佛教”，既防御对手，也传播佛教。仿效差会方法，对建立佛教反宣传机制，证明至关重要。因此，这场纷争的一项结果，是产生了一些最强烈反对基督教及上帝存在的佛教论战，呼应更早佛教徒与印度教婆罗门传统之间的争辩。

然而，在斯里兰卡及柬埔寨等地，佛教徒反对基督教劝诱改宗的行动，并非源于真正的佛教“他者”传统，而是源于在强势基督教传教背景下形成的防御心态。如果要积极推进这些地方的基督徒与佛教徒对话，首先必须重建信任与尊重。斯里兰卡基督徒林恩·德席尔瓦（1919—1982）等关键人物，明显推动了这一进程，努力把主导气氛从谩骂转向对话。具体成果，是六十年代后期创办《对话》期刊。

<a id="pdf-505"></a>
<!-- PDF page 505; original page 504 -->



该刊发表文章，讨论许多重要主题，包括上帝存在、灵魂观念、共同伦理实践、修道生活、全球化，以及宗教中的妇女。另一位人物阿洛伊修斯·皮里斯，生于1934年，接替德席尔瓦主编《对话》，并于1974年在斯里兰卡建立图拉纳研究所，促进基督徒与佛教徒相互理解。

天主教传统中，基督徒与佛教徒相遇最重要的人物之一，是修士兼神父托马斯·默顿（1915—1968）。默顿受到佛教，尤其禅宗吸引，从学术与实践两方面，探索基督教神秘主义与佛教思想的相似之处。在基督教神秘主义中，他尤其亲近上帝超越一切人类理解与言说的观念；这类路径，有助于寻找与佛教传统的接触点。同样，其他人在接近佛教“空性”概念时，也强调基督教的“虚己”，也就是神性的自我倒空。

西方愈来愈受到“后现代状况”带来的迷失影响，人们又广泛关注“东方”禅修与灵性技巧，佛教因而扩大影响，吸引相当数量归信者，至少在禅修实践上如此。不过，西方改信佛教的人，仍少于西方国家中祖源可追溯亚洲的“族裔”佛教徒。此外，基督教神学反思也试图通过后现代神学，与佛教建立联系；“基督教佛教”之类用语，甚至在后现代神学思想中流行。例如，英国反实在论神学家唐·库皮特，呼吁建立“形式上佛教、内容上基督教”的新基督教。[^p505-33]过程神学强调“生成”而非“存在”，也发现自己与佛教世界观亲近。例如，北美过程神学家约翰·科布，是基督徒与佛教徒对话的重要人物，尤其与京都学派阿部正雄的对话。美国夏威夷大学于1980年创办《佛教—基督教研究》期刊及系列会议，后来转由佛教—基督教研究学会主持，提供另一个重要讨论论坛。然而，要确定足以支持<a id="pdf-506"></a><!-- PDF page 506; original page 505 -->有意义交流与进展的共同基础，并不总是容易。两者存在自我与无我、轮回与单一生命、借“恩典”或努力得救、罪与无明等差异。但这样识别两极，也可能误导，因为两种宗教内部的信仰与实践极其多样，有时反而彼此接近。例如，基督教的恩典或救主观念，可以与净土佛教阿弥陀佛传统中的类似观念对话。不过，一些人仍怀疑真正共同基础是否可能，并担心，寻找它可能牺牲不同传统的独特性，以及各自支持者的认同。因此可以问：“基督徒与佛教徒的探索，是否代表两种宗教内部真正相互靠近的运动，还是只是少数‘热心者’的关切？”只有时间能够回答。事实上，两种传统也可能都认为，对方只照亮自身传统某些领域，其他领域则不受触动，或仍“无可超越”；也就是一种互补性。皮里斯把佛教之智与基督教之爱结合，其深刻工作就具有这种互补性。然而，“互补”有时也可能意味着，基本世界观层面几乎不受挑战，两种传统只是各说各话。

展望未来，Whelan Lai与迈克尔·冯·布吕克警告：“孤立地看待特定成分……已经导致佛教—基督教对话中的错误评估与缺乏理解。”[^p506-34]研究任何一种宗教，都应记住，两者嵌入社会与历史之中，不能轻易提取某些实践或哲学世界观，来比较、对话。不过，在宗教层面，基督徒与佛教徒或许仍会围绕实在的本性、人类处境及其解决，继续相互接触。伊丽莎白·哈里斯援引肯尼斯·费尔南多主教的一句话，巧妙概括相遇的悖论：“基督教最强的一点，是它有一位救主；佛教最强的一点，是它没有救主。”[^p506-35]

### 印度教徒

十九世纪的一些人物，影响延伸到二十世纪，辨喜，即斯瓦米·维韦卡南达（1863—1902），就是一例。他1893年在芝加哥首届世界宗教议会发表雄辩演讲，对后来基督徒如何看待印度教，影响深远。这位有力代言人追随罗摩克里希纳，主张一切宗教同样有效，从而扭转基督教宣教反思中的“成全”观念。此外，他在不二论传统中理解耶稣，即耶稣只是终极实在的一种显现。辨喜也区别物质主义西方与精神、神秘的东方；这一想法虽然仓促、错误，却成为强有力的范式，持续影响流行偏见。另一位十九世纪人物，是雅利安社创办者达耶难陀·萨拉斯瓦蒂（1824—1883）；他有力表达了后来当代印度某些群体中出现的情绪。他猛烈批评基督教及其他宗教的排他主张，以及争取改宗者的政策。萨拉斯瓦蒂的著作，希望确立“纯粹”吠陀愿景与启示高于其他宗教的优越性；这类情绪，如今成为印度一些当代印度教基要主义团体的口号。

萨瓦帕利·拉达克里希南（1888—1975）是一位权威人物，他对印度教与他者关系的见解，受到辨喜及罗摩克里希纳影响。他也把吠檀多视为真正宗教的最终表达，涵盖并包容基督教与其他信仰中最好的东西。他1936至1949年担任牛津大学斯波尔丁东方宗教与伦理学教授，使印度教与基督教的对话，在更广泛宗教神学辩论中获得显赫地位。此外，圣雄甘地（1869—1948）对大众想象也有巨大影响。他钦佩耶稣，与其他伟大宗教人物一样，把耶稣视为爱与不害，即非暴力的典范。

批评基督徒与印度教徒对话的人指出，其中许多讨论具有学术性质，反映西方自由派基督徒的关切。对话的必要性，在多大程度上是印度教心灵中的真正问题？殖民过去的回声，也促使人们怀疑，“宗教间对话”是一种潜藏的帝国主义实践，不过是早先“比较”兴趣的进阶版本。另一些人则<a id="pdf-508"></a><!-- PDF page 508; original page 507 -->指出，必须认识到，在印度本土，对话伙伴不应仅包括高种姓婆罗门式的印度教表达，也应包括表列种姓、即达利特的独特困境与“神学”表达。正是在这些低种姓中，改信基督教的现象最明显，而且通常出于社会政治原因，多于真正接受福音信息。

观察二十世纪印度教徒与基督徒在印度的相遇，会惊讶于意见之多样：一些保守群体毫不妥协，严格区分基督教与“拜偶像”印度教的迷信；另一些人却吸收印度教观念，建立真正“印度”的基督教。许多情况下，这不只是文化适应。例如，基督徒与印度教相遇最独特的特征之一，是基督教静修院的发展。著名创新者包括亨利·勒索（1910—1973），后来取名阿比希克塔南达斯瓦米，在南印度建立萨吉达难陀静修院；还有英国本笃会士比德·格里菲斯（1906—1993），尝试依据印度教哲学重新解释基督教形而上学，更偏爱一元论而非二元论。出身孟加拉婆罗门家庭的天主教徒婆罗摩班达夫·乌帕迪亚耶（1861—1907）认为，基督教信息“必须披上印度教的衣裳，才能为印度人民接受”。[^p508-36]他试图说服梵蒂冈接受建议，却未成功。此外，P. 琴奇亚（1886—1959）主张，印度改信基督教者，应把印度教视为自己的“精神母亲”。[^p508-37]不过，并非人人同样热情，印度神学家Y. D. 蒂瓦里等其他声音，担心“广泛使用印度教术语，会削弱基督教信息”。[^p508-38]

印度产生了一些杰出基督教神学家，热切与印度教文化接触，并为基督教及其他宗教的辩论作出独特贡献。除上述人物外，还有S. 萨马尔塔、P. 德瓦南丹、A. J. 阿帕萨米，以及M. 阿马拉多斯。展望未来，克劳斯·克洛斯特迈尔作出大胆判断：“在教义上，印度以外的印度教非常自由；西方现代印度教徒对新思想的开放程度如此<a id="pdf-509"></a><!-- PDF page 509; original page 508 -->之大，以致对话几乎没有意义。”[^p509-39]这反映他的看法：印度教在他所谓“印度母亲”本土的实际处境，对于理解印度教，以及影响不同宗教、社会群体对话的复杂社会政治情况，至关重要。不过，印度本土印度教庞大而多样的性质，不应妨碍我们认真看待不断发展的离散印度教信仰与实践；它们必然影响未来相遇。此外，印度内外的一些团体，例如国民志愿服务团（RSS）与世界印度教大会（VHP），推动印度教的“闪米特化”，使它更教条化、更“民族化”，更重信经与传教，也将产生重要影响。另外，也许还应考虑，西方某些“新时代”思想分支，主要经六十年代大众文化，对刻板化“神秘东方”日益增长的兴趣。这些新兴、不断发展的变化，或许意味着，二十一世纪基督徒与印度教徒的相遇，将更加多样、复杂、充满挑战。

## 第四节 诸宗教神学

**戴维·奇瑟姆（David Cheetham）**

不能说，“诸宗教神学”作为基督徒的重要问题，只存在于二十世纪；但它所关心的问题，的确愈来愈突出、尖锐。原因可能包括：对其他信仰的知识增加，人口分散与离散经验，把多元文化带入西方城镇；还有全球化与传播革命的影响。在西方，对欧洲启蒙运动思想成果及西方理性的信心，或许也已崩塌；这些重要因素，使人更重视纯西方经典以外的洞见，也更向其他传统开放。此外，来自<a id="pdf-510"></a><!-- PDF page 510; original page 509 -->具有殖民过去地区的有力声音，给予基督教神学与实践新表达，常批评西方风格与方法。其中许多声音，尤其亚洲声音，对诸宗教神学作出了重要而有见识的贡献。[^p510-40]

有人把它视为近期出现的最重要议题，一位宣教学者说：“这是九十年代及迈入二十一世纪时，传教所面对的那个神学问题。”[^p510-41]然而，二十世纪产生了处理这一议题的多种方法；实际上，问题本身就有不同界定，既反映“神学”关切，也反映社会学、政治与伦理关切。因此，用复数意义的“诸宗教神学的各种形态”来表述，更具代表性。如果只是把二十世纪诸宗教神学，与前述现象或趋势联系起来，分析未免浅薄。若进一步把这一领域思想的发展，写成从较不“宽容”的传统观点，统一进步到更包容或更多元的观点，最好也只是误导，最坏则显得刻意按预定纲领编排。更准确的说法是：二十世纪基督徒对“宗教他者”的反思，具有极大创造性与多样性，也就是诸宗教神学形态极其众多。这未必全是原创；某些情况下，基督教传统中较常见的“排他”或“包容”立场，只是得到进一步阐发与探索，并受益于比早期更渊博的学识。

二十世纪基督教神学反思，受到多种因素影响，包括学术神学工作、传教士关切、印度等前殖民地区新兴神学家、比较宗教学生，以及宗教间交往的“先驱”。十九世纪传教学术开始大幅增加对宗教“他者”的知识，显然是比较宗教、继而宗教研究发展的重要因素；宗教间运动，则是另一分支。这些知识<a id="pdf-511"></a><!-- PDF page 511; original page 510 -->也深刻质疑了关于其他宗教的旧刻板印象或神话；过去，人们想象中的“对话”伙伴，往往正是这些形象。不过，一些更重要的神学贡献，其成因并不直接来自基督徒反思其他宗教。例如，二十世纪最有影响的神学家之一卡尔·巴特（1886—1968），把宗教视为“不信”，看似毫不妥协；主要原因却不是实际接触其他信仰，也不是反思非基督徒在基督教体系中的位置，而是强烈拒绝十九世纪末欧洲大学中，在他看来无能为力的神学自由主义。然而，将“赐予的”启示与自然神学、自由派神学分开，确实对诸宗教神学产生深远后果。保守派强调基督教与其他信仰彻底不连续，便拥护巴特观点。巴特的影响不可低估，他也常被归入“排他论”阵营，虽然这样的归类，实际上可能只是对其著作的狭隘解读。他的关切，在许多当代神学背景中留下痕迹，包括二十世纪后半叶的后自由主义神学，以及“激进正统”学派等。

例如，后自由主义的G. 林德贝克提出有影响的文化—语言模式，强调基督教共同体“文本内”而非“文本外”叙事的重要性，对“共同基础”或普遍理解的观念持怀疑态度。同样，天主教神学家加文·德科斯塔受到更“激进正统”神学策略影响，强调宗教话语属于特定传统，因此我们的出发点，从来不是凌驾不同宗教“之上”，而是在它们内部。此外，对宗教生活文化位置，或文化完整性的强调，也产生新的诸宗教神学；它们热切强调，与其他信仰相遇对话时，重要的是差异，而非共同性。例如，北美神学家S. 马克·海姆，创新地强调不同宗教目标的多重性质：存在不同的“救恩”，不能归约为单一救恩论本质。支持者认为，这样强调差异，会使基督教与其他信仰的相遇、讨论，更具刺激性、意外性与挑战性。

更包容或更具普遍主义倾向的诸宗教神学，源于十九世纪及<a id="pdf-512"></a><!-- PDF page 512; original page 511 -->二十世纪初传教士的经验，尤其在印度的经验。然而，部分传教士较早的比较工作，常流露出被许多人认为是殖民主义影响及优越感的东西，因此使人质疑参与宗教间对话的基督徒动机。不过，自十九世纪中期起，也出现传教士声音，希望更包容其他宗教传统，把基督教信息解释为“成全”其他宗教，也就是把它们视为福音的“预备”。J. N. 法夸尔1913年《印度教的冠冕》，细致表达了这种成全观念，成为诸宗教神学中“包容论”的经典表述。他的思想影响了1910年爱丁堡世界传教大会，尤其影响1928年耶路撒冷大会。1932至1933年间，有影响的平信徒海外传教调查，推出多卷本《重新思考传教》（1932），是一项前卫工作。它重新评估把传教理解为使异教徒改宗的传统观念，主张其他信仰继续存在具有价值，而非取代它们，或使人离开它们改宗。自由派热情欢迎，福音派严厉批评，由此引起重大争议，成为1938年关键性的坦巴拉姆世界传教大会背景。荷兰学者亨德里克·克雷默在会上推进巴特路线，强调基督教与其他信仰不连续。支持法夸尔等人的代表抵制这一看法，但克雷默的路线仍成为保守派思想的决定性里程碑。此后，多数保守派一直坚持这一立场，例如1970年《法兰克福宣言》。

天主教传统中，卡尔·拉纳是另一位主导二十世纪天主教对其他宗教反思的重大神学家，尤其深刻影响梵二（1962—1965）关于此事的思想与声明。拉纳的贡献极深，并非起于亲自接触其他信仰后的刻意反思，而是天主教传统内部的神学反思：上帝之爱，加上一种复杂独特的人类学，认为上帝恩宠存在于人性本身，即“超性存在状态”；进一步说，整个自然都“蒙受恩宠”。基督恩宠存在于其他宗教，因此可以把他者称为“匿名基督徒”；其他宗教也可理解为“救恩道路”。拉纳建议的精髓，虽远非全部，都进入梵二文件，<a id="pdf-513"></a><!-- PDF page 513; original page 512 -->对天主教传统的诸宗教神学产生根本影响。1964年《教会宪章》因而提倡对话，并认为其他信仰者，可以通过“蒙恩宠推动”、依“良心指引”的行动获得救恩。1965年《在我们时代》虽肯定基督作为“道路、真理、生命”的独特性，仍宣告，不可拒绝其他宗教中“真实而神圣”的东西。约在这时，印度天主教思想家雷蒙多·潘尼卡出版《印度教中不为人知的基督》（1964），试图在印度教不二论传统中，辨认隐藏的基督。这部重要的“包容论”著作，呼应五十年前法夸尔的某些思想，也一直具有影响。天主教传统其他重要包容声音，包括试图讨论宗教间“相互补充”的雅克·杜普伊。

七十年代初，英国哲学家、神学家约翰·希克，提出神学的“哥白尼式革命”，建议把所有宗教，都看作对其背后终极实在，即“实在者”的有效回应。他的假说，成为多元论立场的一项重要、精细表述，二十一世纪初讨论其他宗教时，仍具有显著影响。

通俗讨论中，描述或“归类”上述立场时，常采用排他论、包容论与多元论三分法。[^p513-42]这一范式仍将有用、有影响，却也受到批评：它把辩论限制在三个边界内，甚至因暗示从排他论进步到多元论，而过于带有预定纲领。未来某些诸宗教神学，可能不依赖这一范式，直接处理有关问题。这无疑会创造新的话语与思想，进一步丰富辩论。

显然，对其他宗教及其相互竞争的真理主张的思考，将继续在二十一世纪神学反思中扮演关键角色。此外，人民之间的分裂与恐怖行动造成当代政治紧张，也意味着，对不同文化、宗教关系的批判神学反思，以及更广泛反思，将愈来愈被视为重要任务。事实上，在基要主义与恐怖主义阴影下的世界，基督教共同体以外的人，最密切关注的，将是神学家如何面对<a id="pdf-514"></a><!-- PDF page 514; original page 513 -->当代挑战，回应“他者”，而非其他问题。一些神学家感到，迫切需要迈向更实际的神学。例如，天主教神学家汉斯·昆起草的“全球伦理”，于1993年世界宗教议会推出，口号是：“宗教之间没有和平，民族之间就没有和平。”此外，P. 尼特等人，也呼吁诸宗教神学回应正义与和平的需要。然而，反思的性质仍会多样；辩论将继续体现广泛关切，从更特殊、传统的立场，到更多元、普遍的立场，也伴随神学或思想潮流、认同关系的变化。此外，未来全球跨文化经验愈发熟练流畅，可以预期，非西方基督徒的声音，将越来越为这一重要神学领域的未来辩论，提供内容并指引方向。
