# 第十一章 非洲基督教：从世界大战到非殖民化

**奥格布·U. 卡卢**

> 原书第197—218页；对应原PDF第216—237页。

## 导言

1969年，教皇访问乌干达，发生了一件令人振奋的事。他告诉东道主：“你们必须拥有一种非洲基督教。事实上，你们拥有人的价值和独特的文化形式，它们能够成长，形成属于自身、真正非洲式的丰富表达。”[^p216-1]听众震惊不已，仿佛他正在扭转欧洲与非洲数百年关系的历史，宣布摆脱一种令人窒息的关系，转向承认宣教多元处境的新关系；仿佛欧洲人终于承认，传教士多年驻留之后，一种非洲式基督教表达已经出现。尤其非洲基督徒人数已经大幅增长，这次讲话使注意力从传入模式转向接受和转化方式及其后果。非洲人或许是富于音乐感的民族，其对教皇宣言的回应，可以从各种礼仪创新和音乐象征中追寻。这意味着，叙述非洲与福音相遇的历史，应优先重视非洲人的主动行动，同时采取普世、和平的讲述方式。

但在1914年，战鼓召唤欧洲人进入遥远战壕时，这一增长模式还不明显。1910年爱丁堡大会，没有一位非洲人受邀。西方传教兴趣集中于印度、日本与中国。在非洲，传教士的存在以据点式策略、社会距离和职业领域的主导为特点，种族关系颇为紧张。许多非洲人认为战争是白人的战争，不明白他们为什么不能彼此饶恕。人们很快意识到，英法攻击<a id="pdf-217"></a><!-- PDF page 217; original page 198 -->德国在非洲的殖民地，将使五十多万非洲人卷入为士兵，另有数百万人不幸成为搬运工与炮灰。第一次世界大战彻底重塑了非洲基督教的内部面貌。不过，战鼓响起之前，宗教版图已充满埃塞俄比亚派的喧声。他们表达非洲人的不满，敢于退出白人教会，开创真正非洲式的福音表达。到1914年，尽管有地区差异，其影响力已日渐消退；1914至1939年间，人们确实听到了埃塞俄比亚主义的绝唱。原因可以列举若干。在非洲离散群体中，更广泛的泛非思想日益突出。在中部非洲，奇伦布韦1915年叛乱失败，使首要地位让给罗马天主教徒；埃塞俄比亚派灵修转向杀戮和千禧年主义，也造成丑闻。在南非，两战之间的政治以强烈的阿非利卡人民族主义、侵占土地和政治操控为特点，引发非洲人明确的政治回应，超出宗教创业者的能力范围。在西非，随着政党出现，也发生从文化民族主义向政治民族主义的类似转移。在东非，非洲人在教会中主动行动的空间或许扩大，但战后白人定居者却取得许多经济与政治利益。他们受益于差会本国基地的虚弱。战争风声、战争、经济崩溃、政治不稳定，以及反基督教的共产主义和极权思想兴起等不利地缘政治力量之后，又接着发生六年战争。到1945年，这一切都影响了传教士的存在及组织结构。一些差会鉴于“年轻教会”新获得的自信，考虑大规模重组并缩减规模。

矛盾的是，两战之间宣教结构展现出高度韧性，因为“国际主义”成为新的战斗口号，鼓励青年大学生进入传教区。事实上，1919至1950年间，基督教价值与圣诗本土化的过程不断加强。另两个因素也推动了这一过程，即普世教会精神兴起，可以从国际宣教理事会的各种大会中看出，以及各国教会协进会的成立。但真正挽救宣教事业、确保其在一战后恢复的，是教育及其对大众的吸引力。

在追求“白人的力量”或识字之外，也可以从圣灵教会的合唱中，追寻非洲基督徒的主动行动，无论这些教会叫锡安派、阿拉杜拉还是罗霍。随着埃塞俄比亚主义失去光彩，非洲人表现出更强的灵恩主动性，从城市扩展至<a id="pdf-218"></a><!-- PDF page 218; original page 199 -->农村据点。相关文献不断增加，解释也日益多样。有观点认为，这些运动构成非洲基督徒的主动创造及其对世界基督教的贡献，在福音与文化交界处体现巨大创造力；也有人把它们视为对殖民基督教的尖锐回应，或类似货物崇拜的受压迫者宗教；有人认为它们反映对归属的追求，是白人种族主义环境中的避风港，或一种正在出现的混融灵修；有人认为它们利用新教易于分裂的性质；还有人认为，它们是初起政治民族主义的宗教面向，在城市化加深中，为失去原有依托的人群提供慰藉。少数学者则描绘出一种本土五旬节运动，以及对传教士福音的神学回应，不过特别强调“得胜的基督”（Christus Victor）。

作为对福音的圣灵性回应，这些属灵火焰在一战刚结束时大量涌现。它们与战后环境有关吗？显然，福音被译为本土语言，使人们重新关注传教士信息忽略或淡化的要素，帮助了这一浪潮。它们发掘《圣经》与本土世界观的共鸣。其惊人的吸引力招致迫害。应当指出，当时对福音信息的灵恩回应有三种不同类型：个别先知突然出现，又离去；他们不同于如雨后春笋般出现、与差会教会竞争的圣灵教会。早期五旬节运动在1906至1945年间也可追寻，且重要性日益增加。二十世纪七十年代的属灵之风，使它更加显著；但在六十年代非殖民化的失落出现之前，陌生方言早已在非洲基督徒灵修中占有重要位置。

到二十世纪五十年代中期，疲惫的欧洲在诸多不利力量迫使下收缩。有大量争论讨论非殖民化的原因与性质：它是杂乱无章的过程、创造性的事业，还是被动革命？权力移交或统治者更替，就构成uhuru，即自由与独立吗？传教士的态度摇摆不定，因为主角们正是教会学校的产物。有些人反对，认为这些“孩子”还没有成熟到能够自治；有些支持；还有人制定新的教牧培养策略，训练本土神父，联络重要平信徒，与民族主义者共舞，希望保住多年经营的影响。后来，一党制国家抛弃殖民宪法，脱离基督教根源，音乐便转成断奏。在非殖民化政治令人亢奋的气氛中，没有预言能够揭示这一趋势，因为宣教团体假装自己<a id="pdf-219"></a><!-- PDF page 219; original page 200 -->不同于殖民政府。因此，教会内部的非殖民化耗时更长，本土化呼声也转为要求暂停外来宣教的强烈诉求。1975年，世界基督教协进会大会在内罗毕召开，地点的选择与1969年教皇在坎帕拉的讲话一样意义重大。

本章旨在考察1914至1975年动荡时期塑造非洲基督教兴起的上述七个主题，同时兼顾分期与地区覆盖。本文主张，从1914年战鼓响起开始，埃塞俄比亚派的绝唱，逐渐让位于先知的晨呼、圣灵教会有力的合唱，以及早期五旬节派的陌生方言。但数百万非洲人仍唱着西方圣诗与合一的诗篇。第二次世界大战最终重塑殖民版图。本土化倡导者大胆坚持在教堂中敲非洲鼓。传教士适应变化，按立本土神父，与政治民族主义者共舞，直到曲调变成断奏。这一时期非洲基督教大规模增长，后来又在灵恩之风推动下进一步加速。当代非洲基督教的爆炸性发展，发生在传教士时代之后，却扎根于两战之间开始的灵恩活动。

## 战鼓与埃塞俄比亚主义的绝唱（1914—1939年）

战争环境的一个方面，是流言的作用，以及流言与现实混杂，煽动民众。战争爆发时，非洲人中流传白人统治即将终结。殖民官员极为担忧安全、控制与叛乱威胁。省级行政长官督促地方官员，建立关于潜在动乱地点和人物的情报档案。这加剧殖民政府与共同体之间的紧张。在宗教方面，它恶化了当局与埃塞俄比亚主义的关系，后者被看作披着宗教外衣的黑人民族主义。它与非裔美国人赴非洲宣教事业的联系，加之人们把它与守望台运动反权威的姿态混淆，使其更加可疑。詹姆斯·坎贝尔论述南非时指出：“黑人美国的观念，在非洲人中仍具有强大的想象力量……此外，非洲卫理公会仍纠缠于一个种族支配体系之内；<a id="pdf-220"></a><!-- PDF page 220; original page 201 -->在这一体系中，仅仅由黑人管理教会这一实质，就可能带有深刻的政治意义。”[^p220-2]马拉维流传说，一支入侵的美国黑人军队已抵达卡龙加，他们是弥赛亚，将使非洲人富裕、受教育并受尊重。[^p220-3]西蒙·金班古有一首歌提到权杖转手，鼓励信徒：“勇敢些，国度属于我们。我们拥有它！他们，白人，已经不再拥有它。我们没有人应当灰心。”比利时的刚果统治者听到的，却是叛逆，而非神学宣告。[^p220-4]津巴布韦的非洲正教会，根源于马库斯·加维思想，也招致负面回应。[^p220-5]一些地方官警告，秘密会社正在复兴，成为反白人的纽带。殖民政府畏惧秘密会社与神谕等宗教权力中心，对理性行政结构构成竞争。

除了流言，战争也进一步加剧非洲共同体内部紧张，因为它需要征募人员和搬运工，并赋予当地酋长动员壮年男子的特别权力。在肯尼亚，有些男子逃入丛林躲避招募；另一些则以皈依为借口，大批迁入教会据点或传教站，起初令传教士喜出望外。但传教士自己很快也被迫卷入冲突，所有办法都失效了。[^p220-6]第一次世界大战严重扰乱非洲宣教事业的结构与道德经济。

德国殖民地四个中心的地理分布，使整个非洲卷入战争，也决定各地区被要求提供的征募人数：肯尼亚、乌干达和南非，为坦桑尼亚战线提供四万多名士兵；赞比亚、马拉维与扎伊尔，为纳米比亚、卢旺达和布隆迪战线提供一万八千人；西非国家提供数千人，在多哥和喀麦隆服役。马达加斯加动员四万五千人前往欧洲服役，委婉地称为“志愿者”。[^p220-7]但真正扰乱<a id="pdf-221"></a><!-- PDF page 221; original page 202 -->非洲共同体与宣教工作，并造成巨大苦难的，是对数百万搬运工，即tenga-tenga的需求。矛盾在于，这暴露出传教士信息与伦理之间的落差，尤其当传教士组织残酷的制度，强征潜在皈依者，有时还使用欺骗手段时，显得背弃了自身原则。伊恩·林登写道：

> 如同在英国，招募官敲锣打鼓、吹号穿过村落。如果加入乐队的兴趣还不能吸引毫无戒心的非洲人走出茅屋，他们便许诺巨额金钱报酬。酋长欢迎这一摆脱难缠村民的机会，带着军官到他们的住处。非洲人被欺骗、被强征，参加一场与自身没有利害关系、也毫无兴趣的战争。[^p221-8]

桑给巴尔主教弗兰克·韦斯顿，在坦桑尼亚组织了数千人；苏格兰教会差会的J. W. 阿瑟，招募一千七百五十名基库尤人加入教会搬运队，在坦噶尼喀南部服役九个月。[^p221-9]许多人死于食物不足、艰苦跋涉和医疗匮乏。这是一场搬运工死亡人数多于士兵的战争。传教士，包括神父与修女，成为运输、补给与医疗单位的军人，并为政府承担诸多世俗事务，使堂区失去牧养。本地人不得不接手这一任务，这种机会并不令人羡慕：从头发里找出的虱子，不过掉在自己脚上。同时，德国人驱逐来自协约国的神父，许多英法殖民地也驱逐或拘禁德国传教士。战争中断差会的物资、邮件与资金。最终，非洲教会版图重绘，德国差会失去传教站，不得不面对严酷的两战之间时期，任由其他欧洲国家摆布。传教士学会从本地寻找资源以维持工作，比以前更多依靠本土资源开展宣教。

作为文化与宗教民族主义者，埃塞俄比亚派遭到压制。因此，奇伦布韦1915年起义时，显露出非洲人被迫参加毫无意义的战争所产生的无助与挫败。有一个故事说，在一次英德战斗中，一名困惑的喀麦隆人建议，白人应该打白人，黑人应该打黑人。奇伦布韦眼看非洲人大量被杀，预言战后黑人虽承受苦难，却不会得到多少回报，白人<a id="pdf-222"></a><!-- PDF page 222; original page 203 -->仍不会尊重他们；于是他袭击最近的白人庄园。关于这一类埃塞俄比亚主义，有许多推测；但这场起义是一个运动的绝唱。这个运动内部形态各异，却作为非洲人主动行动的一种形式，试图在政治与宗教领域重新取得主动权，创造一种独特、不受白人控制的非洲式福音回应。林登认为，起义之前，附近恩古卢迪的天主教蒙福会神父，尊重有尊严的奇伦布韦，把他视为非洲人“提升”的榜样。但他的失败与协约国的战争胜利，创造了新局面，使他不再被视为先知。

他说非洲人可能吃亏，并没有错；他说更多非洲人会因挫败而走向暴力反抗，也没有错。乔治·谢泼森统计，从1906年最后一次祖鲁班巴塔起义到1927年，发生了七起此类事件。[^p222-10]但另一些埃塞俄比亚派走了不同道路，其基督教形式也发展起来。地区条件很重要。在西非，运动在战后强烈的种族敌意中发展。尼日利亚1921年人口普查中，埃塞俄比亚派六个分支的人数合计，已构成第三大基督教形态。更重要的是，传教士人数增加，重组机构，以教育为工具，非洲人作出大规模回应。埃塞俄比亚派不得不加强自身教育计划，以展开竞争。但在影响波及殖民地的大萧条中，无论青年基库尤组织，还是哈里斯派、基督军教会／加里克·布雷德派，或本土非洲教会，都无法为这一成本高昂的事业动员足够资源。西方差会在这条战线上击败了埃塞俄比亚派。但非洲人又发起新的灵修形式，具有灵恩性质，挑战传教士基督教。

## 教理与圣诗：宣教基督教的本土化（1919—1945年）

战争结束充满矛盾。非洲人在教会中，以及维持殖民国家生存方面，尝到承担责任的滋味。但在非洲南部与东部，英国政府更感激白人定居者，给予他们更多政治影响力、土地与<a id="pdf-223"></a><!-- PDF page 223; original page 204 -->劳动力。退伍军人安置计划，把许多老兵安置在肯尼亚，给予大片土地。他们要求以税收迫使非洲人进入种植园劳动力队伍，低工资则使其保持脆弱。只有少数传教士发声，例如J. H. 奥尔德姆，抗议强迫劳动与重税。1919年，本土人口被强制实行基潘德，即身份证制度，仿佛这是他们充当如此得力搬运工的奖赏。差会转向教育，为定居者提供“受过训练的男仆、文书、工匠和医院护理助手”，一位坦率的苏格兰人如此承认。[^p223-11]

战后不久，差会重组，迎回一些讲德语的神父，并利用动荡环境夺取据点、扩大范围。整个时期，“丛林学校”成为传教士存在的标志。学校被用作传播福音、竞争、推行文明化、使殖民工业政策正当化、向农村扩展，以及使基督教价值本土化的手段。要读教理、唱救恩圣诗，必须识字。学校与教会共享空间，也同样重要。不参加主日学的人，星期一在学校受到鞭打。争论围绕课程、教育程度、本土人员使用、政府角色，以及教育与布道的关系展开。强调教育，会不会偏离引人归向基督的首要目标？一些传教士反对扩大教育使徒工作，另一些则视之为争取下一代的方式。许多人把教育视为投资品，反对把它当作消费品，让非洲人学习古典等学科；他们厌恶受教育非洲人的自负。课程应仅限于帮助他们在自身文化环境中应付生活，接受变革推动者的价值观，在西方与传统社会之间充当中介，并传递殖民文明化政策与工具。工业差会看来前景可观。两战之间，政府通过督学单位，以补助金控制教育质量，争论十分激烈。差会教会与政府合谋反对埃塞俄比亚派创办的学校，后者得不到认证与资助。

差会集中于师资训练与小学教育，矛盾不断累积。直到<a id="pdf-224"></a><!-- PDF page 224; original page 205 -->二十世纪四十年代，中学与文法学校仍然很少。许多扩张由非洲人推动：从战争、矿山和种植园归来的人，要求设立学校，认为这是发展的标志，是取得白人力量、解开纸张何以会“说话”之谜，以及适应新时代的办法。共同体建造校舍与教师住房，搬运行李，甚至预缴部分薪水。村落代表团不断要求办学，传教士因此写信回国，请求增派人员。或许战争经验使人们认识到白人技术的力量，或许多年来对传统风尚的冲击终于产生后果，也可能新的剥削模式削弱了最初抵抗。无论何种原因，出现了大规模归向基督教的运动。学校与教会的存在，成为共同体间竞争的工具。自尊的长老宁愿为自己的学校捐款，也不愿把子女送往邻村。竞争中的差会利用社区间较量，地方官则划定活动范围。迅速扩张迫使学校使用训练不足的教师。到四十年代，一些本土办学者资助中等教育；有时共同体提供基础设施，差会供应人员。1925年，尼日利亚东部奥尼查的丹尼斯纪念文法学校成立，本地人为圣公会筹集了大部分资金。菲尔普斯—斯托克斯委员会报告展现了杰出加纳人J. K. 阿格雷博士的能力，之后政府政策有所改变。但它依赖布克·T. 华盛顿的教育方式，受到非洲人批评，认为这限制了他们获得教育的范围。一战的一个影响，是为一些非洲青年出国寻找“金羊毛”打开空间。他们后来成为1945年后抗争的推动者。早在1937年起，恩纳姆迪·阿齐克韦在黄金海岸的新闻写作中，就能听到他们激烈的声音。二战后要求大学教育的运动，促使政府关注中等教育。

两战之间的历史，还有其他关键层面：差会日益关心学生的就业目标，许多学生转而为政府工作；城市化发展，带来许多道德问题；女子教育成为重要关切。对于福音的吸引力，必须加以细分。福音传播到村落，像芥菜种子的根一样，通过挑战文化改变共同体的土壤；福音与文化相遇，也造成不安。因此，尽管出现大规模归信，回应仍各不相同，守护祖先葫芦的人以<a id="pdf-225"></a><!-- PDF page 225; original page 206 -->迫害进行反击。事实上，一些教会和学校的赞助者并不皈依，因为他们为后代寻求的只是教育。小说家更准确地捕捉了这种气氛。

## 先知、锡安派、阿拉杜拉与罗霍的本土合唱（1914—1960年）

1918年起，流感蹂躏非洲，使人们应付贪婪欧洲势力的痛苦雪上加霜。有人推测，疫病触发了基督教版图的彻底重塑。斯威士兰锡安派的历史，体现一战至独立号角响起之间的非洲新趋势。1845年卫理宗抵达后，许多差会在这里活动，1880年圣公会、1887年路德宗相继到来。1904年非洲卫理公会（AMEC）进入，为该国带来一丝激进非裔美国人的气息；到1920年，组织数量已增至十四个。福音派从1911年起通过协商安排划分地区。三年之内，宗教版图出现新现象：乔安娜·恩克苏马洛（Joanna Nxumalo）从南非回来，她曾在那里任教，并皈依锡安派。其他人随后建立各自形式，这种热烈的福音主义迅速发展。非洲教会联盟把它们联系起来。据说，一名锡安派信徒于1914年治好太后兼摄政者拉博齐贝尼的某种眼病；这一神迹后，锡安主义与王权结盟。神学逐渐调整，把君主塑造成“所罗门王”式人物，把国土视为锡安。在这套创造出来的历史中，索布扎二世被描绘为从殖民定居者手中收回土地权利的工具。到二十世纪三十年代，宗教版图已被完全重新想象：斯威士兰传教士被视为定居者与殖民势力的代理人，独立教会则自居为斯威士兰人民首次表达宗教与政治变革愿望的工具。独立教会运动把宗教创新，与以福音语言表达的抗议、追求社会正义与政治自由结合。君主把复活节礼拜变成庆祝民族遗产的活动，确认了这一看法。狮子与羔羊卧在一起，产生一种新版本的非洲锡安派福音主义。

有几点需要考察，即从南非传到邻近地区的锡安主义的起源、类型与性质。它来自<a id="pdf-226"></a><!-- PDF page 226; original page 207 -->芝加哥城外的锡安城。约翰·亚历山大·道伊在那里创立基督教大公使徒教会，该会自称与阿苏萨街五旬节运动有关。1908年，道伊医治事工的一位受益者J. G. 莱克赴南非宣教，建立使徒信心会。1913年他返回美国后，领导权落到P. L. 勒鲁手中。勒鲁离开荷兰改革宗教会，在瓦克斯特鲁姆，即今姆普马兰加省，建立一座小堂，教导信心医治、在约旦河施洗和说方言。他把自己的信仰历程描述为渡向锡安，这一名称就此沿用。加入使徒信心会的其他非洲人，很快经历种族歧视，成立若干全由黑人组成的使徒教会。各团体都坚持保留锡安与使徒名称。二十世纪初，这一现象在非洲人中迅速发展。丹尼尔·恩科尼亚内（Daniel Nkonyane）接替勒鲁，保罗·马比利察和埃利亚斯·姆赫兰古等人也建立各自的锡安。索托人爱德华·莱昂把它带到巴苏陀兰，安德烈亚斯·肖科和塞缪尔·穆滕迪等罗得西亚工人回乡传教，恩格纳斯·莱克加尼亚内则在德兰士瓦传播。锡安主义逐渐发展出新形态，使分析变得困难，因此需要分类。例如，艾伦·安德森依据官方人口普查资料指出，南非非洲独立教会团体数量大幅增加如下；这些普查在种族隔离时期充满偏见。[^p226-12]

| 1913 | 30 |
| 1939 | 600 |

与斯威士兰一样，一些解释者着重于这一宗教形式中的抗议与分裂要素。土地与文化被剥夺，定居者统治和殖民主义下丧失政治权利，种族歧视与经济匮乏，无疑都造成心理压力，只有某种特定宗教形态才能帮助缓解。锡安成为收复被夺土地的梦想，成为不再有<a id="pdf-227"></a><!-- PDF page 227; original page 208 -->眼泪的地方。创办人的家成为朝圣中心、一种强大的仪式象征：锡安，归属之地。埃塞俄比亚派的一些主题可以重现，却得出不同结论。但这一宗教的主要特征，是突出体验，包括启示、梦境、异象与预言，重视口传，并使用本土知识、象征和仪式资源。通过歌曲、舞蹈、合唱与本土乐器，把传统敬拜方式带入教会，实现礼仪革命。人们有意识地在《圣经》象征与主题中寻求共鸣。领袖披上先知的外衣，个人则作为信仰大家庭成员充分参与。非洲人的共同体意识得以重建，治理结构按传统等级安排。在以医治为首要任务的宗教中，无论针对个人的先知指引，还是预告未来的预言，都是诊断与治疗极其重要的工具。这引发了先知与本土占卜者之间关系的争论。有人认为两种职分合流；另一些人坚持，形式虽相同，因为先知不仅是圣灵、也是祖先的代理者，内容却不同，更具基督教性质。锡安派创造大量具有象征意义的医治用品，如祝圣的棍杖、木片、布、茶，称为tea ya bophelo，即生命之茶，以及咖啡、铜丝、用于放出不洁血液的针、在病人身体上方迅速挥动的各色纸张、烟、沙、盐和水，有时还加入明矾。传统社会对巫术与法术攻击的担忧，通常列在求助事项之首。先知有时提供蓝布条，让人佩戴在隐秘处，防御可能以雷电形式降临的敌人攻击。

圣灵教会中，随着个人恩赐发展、内部差异增加，分裂频繁发生。因此，H. W. 特纳主张建立有力的分类，区分几种类型：活力主义型，使用神秘实践与来自亚洲的秘传书籍；本土主义型，大量采用本土祭仪；弥赛亚型，领袖声称自己是三位一体的一部分；以及复兴型，试图在非洲宗教形式外面披上基督教外衣，例如上帝主义（Godianism）。[^p227-13]守主日与守安息日两大类型，各自也有同样的分类特征。某些族群比其他族群更多支持<a id="pdf-228"></a><!-- PDF page 228; original page 209 -->这些教会，例如南非祖鲁人、尼日利亚约鲁巴人，以及肯尼亚卢奥人；按照1966年肯尼亚人口普查，后者被称为Abaroho，即“属圣灵的人”。

西非圣灵教会的兴起，显示非洲人对福音属灵层面的接受与转化，在1910至1930年及1930至1960年两个活跃时期，采取不同转向。它们或许受益于一战前刚开始的先知运动。阿拉杜拉，即“祈祷的人”运动，兴起于1918至1925年的流感疫情期间，其宗教意义大于政治意义。最早的基路伯与撒拉弗团体，源于圣公会内部一个坚持聚集祷告、为疫病受害者医治的祷告小组。主的教会（阿拉杜拉）、基督使徒教会等随后出现。整个非洲大陆，先知与属灵复兴的迸发，改变了基督教的性质、方向和速度。一个又一个地方出现先知人物，象征某种接受与转化方式。除非洲本土教会（AICs）外，这一时期还出现四种类型。第一，传统宗教内部的占卜者或宗教领袖，可能出人意料地转变立场，吸纳部分基督教象征与信息，创造新的综合；这常由白人扩张中应对流离失所或传统根基受威胁的压力所引发。祖鲁先知以赛亚·申贝，约1870至1935年，见证说：“我刚抵达科恩拉德老板家后，就感到要独自去祷告；那时近黄昏，天色渐暗。”[^p228-14]一个声音开始指引他，随后出现启示。殖民时期出现许多此类事工，构成锡安、阿拉杜拉与罗霍运动的背景。

第二类可用西非说明：一位先知从基督徒群体中出现，强调福音的圣灵与伦理要素，以加强共同体的福音化。有时，他以旧约先知的形象出现，留胡须、持杖，身穿长袍，带着十字架。韦德·哈里斯与加里克·布雷德受到最多学术关注，但还有许多人，例如黄金海岸的彼得·阿尼姆与参孙·奥蓬。除胡须和十字架、杖或圣水碗等标志外，先知还有某些独特特征：他们具有个人感召力，坚决反对传统宗教和徒有其名的信仰。他们认识到，当时的<a id="pdf-229"></a><!-- PDF page 229; original page 210 -->基督教化模式，不过以一种文化取代另一种文化，几乎没有触及核心效忠。仿佛非洲人创造一个外围，在那里与传教士信息对话，同时保留一个内部核心或震中，传统效忠仍占主导。先知把事工集中于个人与共同体效忠的内在核心。先知有时是锡安派的前驱，呈现祷告、医治等同样特征。但先知怀有信息，不愿建立教会，而急于通过话语与神迹施行拯救。许多人有创作短歌的恩赐。研究者找回并翻译了加里克·布雷德以母语卡拉巴里语创作的一百七十三首短歌。[^p229-15]其追随者在一次外出传道开始时，唱一首简单的歌：“耶稣来了，撒但逃走了。”反复吟唱时，布道者把圣水浇在神龛上，神龛便燃起火焰，使敬拜者震惊并归信。他们有些受过教育，有些没有；他们与传教士一样敌视传统宗教和挂名基督教的象征，却用神迹奇事显示自己的参与。他们对原初世界观的态度，展现一幅能力交锋的景象。人们典型地欢呼布雷德为“第二位以利亚”。约1914年布雷德出现之前，格雷博人韦德·哈里斯已于1910至1914年间，从利比里亚步行进入科特迪瓦与黄金海岸，传道、行神迹，为罗马天主教和卫理宗都带来巨大增长。他也创作许多短歌。他们的事工之后，教会相继形成。英法殖民政府害怕不受控制的个人感召力，把这些先知逐一追捕入狱。布雷德1915年以虚假指控被监禁，三年后去世。奇特的是，运动在他死后增长。同样，哈里斯被限制在帕尔马斯角，许多人前来探访、寻求支持；以其名义成立的教会不断发展。

第三类中，一个基督徒群体与国际福音派或五旬节宗派建立联系，因为在敌对的殖民环境中，它需要白人支持才能生存；差会教会借助世俗权力，迫害本土主动行动。一些本土基督徒曾联系信心会幕，使用其文献；但后者只通过邮寄开展宣教，信心派于是转向英国使徒教会。与信心会幕和使徒教会的联系，汇入了<a id="pdf-230"></a><!-- PDF page 230; original page 211 -->早期五旬节运动。例如，1928年，约鲁巴地区的先知巴巴洛拉，与信心会幕前成员联合，建立基督使徒教会。同一团体拒绝另一位先知约瑟夫·奥西特卢加入，因为他采用上帝的秘密名称，并持有其他神秘性教义立场。他于是成立主的教会（阿拉杜拉）。尼日利亚东部，一些信心会幕成员说方言，被逐出后于1934年创立耶稣基督教会，1939年邀请神召会接管；神召会分别自1925年和1928年起，已在科特迪瓦和达荷美活动。还应补充，宗派性五旬节运动到来之前，1906至1912年间，已有一些独立五旬节派传教士，试图在非洲各地立足，尤其肯尼亚西部、利比里亚和南非。因此，古典五旬节派与本土五旬节派，都很早出现在宗教版图上。黄金海岸也出现类似模式。[^p230-16]

同样引人注意的第四类，是1925至1935年间出现在差会教会内部的一轮轮灵恩复兴。例如，1927年，尼日利亚东南部伊比比奥人中的夸伊博差会，在一次周末退修中爆发复兴。同年，肯尼亚西部凯莫西的贵格会也出现复兴，以公开认罪、禁食、守夜和强烈的宗教情感为特征。长老无法约束他们，1930年将之逐出；他们组成非洲圣灵教会，此后蓬勃发展。也在三十年代，巴洛科莱，即“得救的人”，在圣公会中从卢旺达，经乌干达和苏丹，迅速传到肯尼亚与坦桑尼亚。它以强有力的基督论和悔改呼召，挑战传教士基督教；其标志歌曲《我们赞美你，耶稣》（Tukutenderaza Yezu），唱道：“我们赞美你，耶稣，上帝的羔羊耶稣。你的血洗净了我，我感恩，救主。”它引起许多不安，类似刚果天主教徒中的贾马运动。刚果地区遍布先知，即ngunza运动。西蒙·金班古于1921年被流放伊丽莎白维尔，后来死于那里，原文此处记为1952年；其他先知声称受其灵充满，积极反抗殖民当局。但刚果—布拉柴维尔持久的复兴，是布阿纳·基邦吉（Buana Kibongi）从1947年起领导的，始于瑞典圣约教会的一次领袖退修。基邦吉当时是学生，圣灵临到群体时，他受影响最深。他成长为<a id="pdf-231"></a><!-- PDF page 231; original page 212 -->重要领袖，把教会转变为刚果福音教会。他之所以成功，是因为其愿景是白人与黑人的合一，是布拉柴维尔所有教会的普世合一愿景，而瑞典人本来就愿意接纳敬虔主义传统。他一直活到1998年，得以长期提供领导与神学阐释。所有这些人物共同确立了一种灵恩灵修，后来界定非洲人对福音的回应：既保守、又属福音派，礼仪活泼，重视口传，处于不同类型的领导之下；它避开西方基督教的哲学枯燥，强调神迹、异象、梦境与医治。

## 非洲鼓声与非殖民化的失落（1945—1960年）

第二次世界大战对非洲影响巨大。它推动政治民族主义，确保到二十世纪六十年代，许多非洲国家已经出现；先是北非，继而其他法国殖民地，1957年起则包括英国殖民地。各地战时见闻，都推动民族主义运动形成。非殖民化过程，使传教士与殖民政府产生分歧。1967年，英国与爱尔兰差会会议秘书T. A. 比瑟姆写书，担忧非洲基督徒会在民族主义热潮中，重新转向原初宗教。[^p231-17]一些人反驳说，过程虽然杂乱，但在为新国家提供宪法的同时解散帝国，最能保护英国利益。这是一种有意的计算：通过宪法保护英国利益，并主动清算帝国。这一看法，与另一种论点或许相距不远，即在遏制政治中，非殖民化是危机管理中的机会主义回应。过程中，殖民政府抛弃了亲密的敌人，即传教士。不可回避的结论是，非殖民化并不意味着社会经济结构的根本改变。葛兰西以“被动革命”解释这种妥协：一个占支配地位的社会政治集团，若想维持权力，可能不得不改变行使权力的方式。非殖民化的目标，是回到非正式帝国，让过去统治者保留足够经济与技术资源，对未来发展施加强大影响；这只是有限的权力<a id="pdf-232"></a><!-- PDF page 232; original page 213 -->转移。被动革命，推动了分析当代非洲病症的现代化理论与依附理论。它也是市场被神化，以及掠夺性精英与跨国公司合作的根源。

本章的观点是，传教士对非殖民化采取了类似的策略回应，虽付出巨大代价，却也表现韧性并改变航向。例如，他们放弃反对现代性，转而拥抱它，寻求把它引向自由派神学的特征，这反映1960至1970年经济繁荣和冷战寒意下欧洲文化的转移。但殖民主义暮年，即1945至1959年，传教士对民族主义兴起的回应，与紧随其后的1960至1975年调整策略，在性质上不同。1966至1975年政治气候的巨大变化，迫使宗教版图发生重大改变。事情可追溯到二十世纪四十年代末：各国政党纷纷出现，非洲民族主义活动不断高涨。一种解释是，目标更明确的年轻一代走到前台，把传统统治者与温和派推到一边，沐浴在大众热烈拥戴的阳光中。阿尔伯特·卢图利等一些原本主张和解的人，因南非教会福音派内部的种族主义而幻灭，放弃种族合作理想。毫无疑问，1945至1954年间，传教士对民族主义的回应，因个人取向、官方或宗派机构政策，以及地区环境而异。后来又出现某种转变：传教士觉得政府与受其培养者都背弃了自己，无力阻止进程。一些在当地工作的传教士，试图以基督教与政治二分，利用现有设施遏止潮流。他们借助戏剧、公开辩论与讲座，劝基督徒远离政治，先求上帝之国，并宣称殖民主义只要受到适当约束，就有利于非洲人。道德重整团体在西非建立网络，灌输重要政治伦理。一些传教士，如原文称曾任布隆方丹总主教的威廉·凯里，毫不谨慎地表现敌意；另一些，如不屈不挠、为赫雷罗人发声的迈克尔·斯科特，则代表同情非洲事业者。机构态度总体各不相同：本国总部采取理想主义立场，对非洲人有一定同情，却谨慎得几乎没有实际意义。在当地，有些人担忧马克思主义前景或异教复兴，愤怒于非洲精英忘恩负义，决心限制损失。民族主义被描绘为不敬宗教，民族主义者则被认为过于不成熟，无法带领国家走向民主。一位苏格兰教会传教士于<a id="pdf-233"></a><!-- PDF page 233; original page 214 -->1947年在内部刊物上发表题为《没有宗教的民主》的文章，简明表达了这一点：“一个民族不会一夜之间学会把权力看成正义的仆人，而非主人。人民不会在一代人之间，就获得那种责任感、托付意识和正直；没有这些，腐败与贪欲很快就会威胁他们管理自身事务的一切尝试。”[^p233-18]监护时期太短，不足以为独立形成适当道德环境。这种谨慎情绪，可以从普世教会政治思想中追寻：1947年安大略省惠特比会议提出与年轻教会建立“伙伴关系”的说法，1948年阿姆斯特丹会议关心“负责任的社会”，直到1952年维林根会议，强烈的社会关怀才终于带来一次转变。

地区差异很多。西非蚊虫众多，却没有白人定居者社群，因此二十世纪五十年代中期，本土化政策居于主导。政策有三个方面：与民族主义者共舞，运用本土人员，以及寻求使基督教适应非洲文化，相信非洲人需要的是让自身文化成分接受“洗礼”。五十年代初培养的许多神父走在前列。后来，这种对非洲基督徒宗教主动性的狭窄理解将暴露局限；但当时，它构成被动革命武器库的一部分。在其他地方，国家试图使教会妥协，或直接把它纳入国家机器。中部非洲的比利时人，试图以天主教使统治正当化。萨拉查1940年的政教协定，承认并资助天主教会，使之成为在安哥拉与莫桑比克推动国家殖民目标的正式工具。两地反殖民统治的领导者，都来自非洲福音派阵营。在刚果，加丹加宗座代牧让·德昂普蒂纳主教的生涯，支持了效忠殖民统治的事业。同样，教会在卢旺达操纵宗教，已成为遭谴责的问题。在埃塞俄比亚，海尔·塞拉西皇帝以修订宪法，把正教会纳入国家结构，大主教进入摄政委员会与王室委员会。在东非，乌干达教会与民族主义者共舞，被推入公共领域；首次选举中，天主教徒基瓦努卡与新教徒奥博特相互角逐，收获多年激烈竞争的果实，也分裂了社会。利比里亚提供一个不值得羡慕的模式，国家架在<a id="pdf-234"></a><!-- PDF page 234; original page 215 -->基督教、共济会与真辉格党三条支柱之上，统治者向这三个权力中心低头。

非殖民化对各教会群体的影响，依若干指标而异：规模与教会组织、信徒在社会各层的分布及社会地位、继承的殖民关系模式、神学重点，以及国际联系。它也取决于脱离殖民统治的方式、新殖民结构的编织，以及政治组合中马克思主义的分量。任何因素，都可能因环境产生正面或负面影响。例如，刚果的蒙博托把除金班古派以外的基督教会，视为必须摧毁的危险，因为神明不容竞争。

民族主义者要求非洲教会非殖民化，传教士回应的核心，是采取后卫行动重新整备，利用本土人员和资源维持影响。这是宣教本土化政策的主旨。他们尝试多种措施：培养人力；通过教会合一和普世教会运动内部重组；在资金上平衡援助与自主，以克服依赖、培育管家责任；通过适应重新审视文化政策，在艺术与礼仪上催生受控制的主动创造；让更多基督徒参与政治，重新调整政教关系；鼓励神学反思；以及确立一种新的关系模式，以伙伴关系语言掩盖家长主义，从而试图沿旧路维持社会服务。这些措施合起来，将补救过去过度控制的后果，在扩大非洲人参与的同时，保留宣教结构核心。它们构成对非洲新国家崛起的民族主义所提出挑战的回应。1968年乌普萨拉普世教会运动的范式转移，帮助了这种反制。与会代表提出对宣教、科学与技术、现代性挑战、同其他信仰对话，以及正义与种族的新理解。对自由战士的支持引发内部争论，直到1975年世界基督教协进会内罗毕大会，才开始平息。同样，第二次梵蒂冈大公会议是重构教会宣教与社会服务政策的分水岭，虽然两千五百名主教中只有六十一名非洲人。多项教皇声明似乎以新声音向所有非洲人，不分宗派发言，释放了教会中的非洲活力。若望保禄二世呼吁文化适应与丰富，带来许多希望，直到人们发现，教廷控制和罗马礼仪范围的限制，缩短了绳索。尽管如此，基督教文化的复兴<a id="pdf-235"></a><!-- PDF page 235; original page 216 -->艺术仍留下持久印记：尼日利亚的凯文·卡罗尔神父、喀麦隆的埃塞尔贝特·姆文，以及非洲南部的约翰·格勒贝尔，培养了一批青年艺术家。福音派没有投入基督教艺术发展；他们援引反对雕刻偶像的经文，坚持自然更能表现上帝。肖像和风景，仍是福音派艺术的主要形式。对于把非洲传统主题带入基督教艺术持戒心的，不只是他们；一些天主教徒也反对教会中的新艺术形式。不过，在所有基督徒群体中，礼仪更新都达到可观深度：音乐、舞蹈、本土语言的使用，街区玫瑰经的激进化，以及围绕新礼仪实践成立社团。所谓街区玫瑰经，是经认可的男女平信徒设立街头祭台，在那里教邻里儿童念玫瑰经和学习教理。守夜活动与退修中心纷纷出现，令传教士震惊。

这些策略的细节无须一一重述。只需指出，自二十世纪六十年代起，教牧培养水平迅速提升。地区性与全非洲性协会成立，鼓励神学反思与圣经学校课程修订，极大推动神学教育。许多地方试验延伸式神学教育；第三世界神学家普世协会（EATWOT）的成立，则把世界一些地区的许多人聚集起来，而在那些地区，迫切问题恰是“吃什么？”（eat what？）。1973年雨季，世界基督教协进会在伊巴丹开会，探讨如何调整非洲教会资金供给，鼓励它们学习奉献。1974年8月，协进会信仰与教制委员会在阿克拉开会时，非洲正在进行的教会联合谈判，比其他各洲都多。南印度教会与锡兰的领袖巡访非洲，提供建议。除赞比亚之外，其余都失败了。以尼日利亚为例，神学与非神学原因共同挫败这一梦想。信心教会的继承者认为，联合宪章缺乏充分属灵性。其他次要教义问题也引起忧虑，但真正重大的问题，是个人冲突与竞争、尚未弥合的宗派敌意、对主教职位的争夺，以及族群因素。最后，一些卫理宗堂会把联合委员会告上法庭，而1967至1970年内战又使诉讼者四散。[^p235-19]东非的研究也证实，<a id="pdf-236"></a><!-- PDF page 236; original page 217 -->使非洲民族国家失稳的同样因素，也在基督徒群体中造成破坏。诚然，其中许多情况在非洲以外也可能发生，但关键差别在于，人们觉得教会合一是从外部强加的。

## 与民族主义者共舞（1955—1975年）

1965至1975年十年间的非洲历史，使1945至1960年提出的问题更加清楚地展开。人们越来越觉得传教士版本的本土化不能令人满意，且限制重重。传教士自己也承认，由于缺少负责任的本土人员，他们不确定是否准备交出权力。但他们同时见证本土圣灵教会的兴起：基督教富有吸引力，增长巨大，青年对灵恩灵修感兴趣。罗马天主教主教弗朗西斯·阿林泽等有洞察力的主教，创造官方认可的空间，让差会教会吸纳灵恩资源。礼仪试验在许多地方引起不安，“传统主义”阻碍进展。男女平信徒在教会中的作用也增加。原因可以列举许多：更多使用《圣经》和本地语言；梵二与乌普萨拉释放活力，解除往日限制，使礼仪非洲化成为可能；政府接管学校和医院，冲击教会优势，迫使它们回归真正使命；基督教左翼或非洲本土教会的竞争日益增强，迫使礼仪改变；主动吸纳精英的政策，又与新一批受训教牧人员和神学家的影响相结合。还应注意教会中母亲联合会、妇女公会等女性平信徒组织的力量。教会日益由平信徒参与，意义尤其重大，因为教会希望成员运用权势和人脉，成为信仰捍卫者。骑士团的设置，旨在吸引政治精英；后者则发现教会成员是可靠选民。很快，平信徒的社会与财政影响，在教会事务及决策中变得比预期更重要。从另一角度看，学者大力倡导非洲神学，新一代神学家的“民族主义”，反复批评宣教结构残余，以及尚未本土化的教会困境。为给非洲基督教命名，人们提出许多新术语，例如<a id="pdf-237"></a><!-- PDF page 237; original page 218 -->处境化、传统化、道成肉身和文化适应。非洲人希望有一种新教会，或更新的基督身体，以及与西方的新关系。天主教神父挑战独身制度，新教同僚则希望以棕榈酒或可乐果举行圣餐。《圣经》提供先例，既显示连续性，也提示原初宗教的灵性并不总与正典冲突。教会内部充满激荡，也有人从内部努力破坏这一有限的本土化计划。

教会之外，1960年起非洲国家权力增长，对政治不稳定、侵犯人权、环境退化与经济崩溃，产生重大影响。新国家披上基督教外衣描述目标，明显试图挪用其语言：民族救赎、经济拯救、政治称义、民族重生，以及国家神圣性。许多国家成为一党制，另一些成为军营式政权，把国家当作军营治理，还有一些转向马克思主义。教会感到震惊。撒哈拉以南四十四个国家中，十五个在独立后不久即倾向这一方向。但细看之下，没有一个实行纯粹马克思主义；冷战引入来自苏联、中国、古巴、美国与欧洲的各种左翼思想，非洲人也创造本土类型回应，如良知主义、非洲社会主义、人道主义、集中民主制等。在马达加斯加，尽管有拉齐拉卡的《红皮书》，教会仍兴盛。前伊比利亚殖民地的敌意很快减弱。南非支持的莫桑比克游击组织抵抗运动，与五旬节派接近；南非支持的安哥拉游击组织安哥拉民族解放阵线（FNLA），则与浸礼宗接近；与此同时，意大利圣艾智德团体的天主教平信徒，促成莫桑比克内战的和平谈判。在安哥拉和赞比亚，政治修辞对教会的伤害，不及错误经济政策与疾病。总体而言，国家权力的冒险主义，迫使非洲基督教的存在模式发生重大变化。这些问题最终都汇集到1971至1975年关于暂停外来宣教的争论中。世界大战之后，非洲基督教走向成熟。
