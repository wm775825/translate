# 《新教伦理与资本主义精神》翻译术语表

本文件用于统一初译术语。译稿先追求完整、准确、可读，后续可再按中文学术写法精修。

## 核心术语

- Die protestantische Ethik und der Geist des Kapitalismus: 《新教伦理与资本主义精神》
- Geist des Kapitalismus: 资本主义精神
- Kapitalismus: 资本主义
- kapitalistisch: 资本主义的
- Okzident: 西方
- Abendland: 西方
- Universalgeschichte: 普遍史
- Beruf: 职业 / 天职。涉及 Luther 或宗教意义时优先译为“天职”；一般职业结构中译为“职业”。
- Berufsethik: 职业伦理
- Berufskonzeption: 天职观念
- innerweltliche Askese: 入世禁欲主义
- Askese: 禁欲主义
- asketischer Protestantismus: 禁欲主义新教
- Wirtschaftsethik: 经济伦理
- Wirtschaftsethos: 经济气质 / 经济伦理气质。视上下文选择，避免机械重复。
- Lebensführung: 生活方式 / 生活操守。涉及伦理训练时可译为“生活操守”。
- Rationalismus: 理性主义
- Rationalisierung: 理性化
- rationale Betriebsorganisation: 理性的企业组织
- freie Arbeit: 自由劳动
- Bewährung: 证成 / 证明自身。宗教语境中常译为“证成自身”。
- Gnadenwahl / Prädestination: 恩宠拣选 / 预定论
- Rechtfertigung: 称义
- Sekte: 教派
- Konventikel: 宗教小团体 / 秘密聚会团体
- Kirche: 教会
- Kirchenzucht: 教会纪律
- Puritanismus: 清教主义
- Puritaner: 清教徒
- Calvinismus: 加尔文宗 / 加尔文主义
- Luthertum: 路德宗
- Pietismus: 虔敬主义
- Täuferbewegung: 再洗礼派运动
- Quäker: 贵格会
- Methodismus: 循道宗 / 卫理宗
