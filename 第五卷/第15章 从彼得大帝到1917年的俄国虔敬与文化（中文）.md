# 第15章 从彼得大帝到1917年的俄国虔敬与文化

克里斯·丘洛斯

## 范式与刻板印象

彼得大帝希望通过广泛的现代化改革改造帝国，帮助塑造了随后两个世纪的俄国历史。在这位伟大领袖的显著成就中，建造面向西方的欧式首都、建立常备军、引入规范税制，以及重组高等教育，往往遮蔽了其正教改革的重要性。世俗与宗教权威间的紧张，对俄国并不新鲜。17世纪中叶，强势的尼孔牧首与阿列克谢·米哈伊洛维奇沙皇，表面上围绕仪式改革而斗争，结局对遭罢黜的牧首、以及被分裂撕开的教会，都是灾难。接受改革者被视为合宜的正教基督徒，维护既有仪式者，很快被贴上旧信徒、旧礼仪派或分裂教会成员的标签（starovery、staroobriadtsy、raskol’niki）。1666—1667年分裂，虽产生俄国最富特色的某些宗教人物，包括自焚者与鞭笞派，但关于世俗权力最终居于最高地位的残余疑问，在1700至1721年间得到解决：年轻沙皇彼得没有补任新近去世的阿德里安牧首，随后颁布《宗教规章》，以神圣宗务院这一世俗行政机构取代牧首制。[^p369-1]

彼得去世时，教会改革尚未完成，却也未受挑战。整个18世纪，国家政策试图<a id="pdf-370"></a><!-- PDF page 370; original page 349 -->以启蒙思想的世俗语言，界定并限制正教基督教的机构与表达；这种思想在叶卡捷琳娜大帝时期达到顶点。叶卡捷琳娜把自己与伟大前任相比，自认为完成彼得的制度建设，上台不久便没收教会土地。女皇虽以解决国家日益严重的财政问题，为行动辩护，没收教产却象征俄国正教政治及经济权力的衰减。一个世纪之内，分裂、废除牧首制、设立世俗行政机构及丧失财产，使教会领袖衰弱而迷失方向，寻找恢复信仰失去的公共声望与独立的机会。19世纪，正教公共权威逐渐恢复，开端是被纳入一种初生民族主义的三位一体，成为尼古拉一世时期口号：“正教、专制与民族性”。这一著名箴言于1830年代初提出，把俄国身份的属灵、世俗及族群特质结合为三一公式；与其说它代表现实，不如说体现行政上的怀旧，以及对欧洲大陆自由主义、革命运动的回应。帝国内的俄罗斯人及少数族群，正对自己的语言、民俗与宗教遗产产生兴趣；这个等式表达对君主制及其两大支柱的强力捍卫。[^p370-2]

正教基督教对俄国历史的影响，以及在民族身份形成中的地位，始终位于最有争议、至本书撰写时仍未解决的文化与哲学辩论中心。一方可概括为斯拉夫派，包括19世纪中叶最初那群知识分子。他们支持正教、共同体主义及俄国特殊性的信念，植根于对一个界定模糊、非正教、个人主义而自私的西方“他者”的恐惧。斯拉夫派及思想继承者认为，正教赋予俄国人民（narod）关怀群体福祉的品质，与天主教及新教的个人主义、竞争和冷漠鲜明对立；后者把共同体的利益<a id="pdf-371"></a><!-- PDF page 371; original page 350 -->置于低位。斯拉夫派理想的中心，是以共同目标把人们聚在一起的家庭、教会与村社。西方派及继承者采取相反立场，有时主张俄国农民因村社而受苦，正教提供的则是缺乏宗教理解的仪式性实践。这些辩论的核心，是对彼得大帝受西方启发的改革具有根本不同的解释：它们究竟符合，还是背叛俄国的真正性格？[^p371-3]

19世纪中叶，俄国政治、社会与文化格局，濒临根本变化。1861年农奴解放，在“大改革”名下带来经济发展的期待与希望，其基础是初等教育、基本识字及交通、信息沟通的改善。“解放者沙皇”亚历山大二世所引入巨大变化的后果，一方面是社会文化多样化，另一方面，俄国人之间也依教育程度、与大城市距离及政治忠诚而更加隔离。大批受城市教育的教师前往帝国各个角落，带着支持自然界及人类文明最新科学范式的课本与插图；他们也带去有关宗教及迷信的流行刻板印象，强调民间信仰与实践的弊端。许多善意的教育者出身教士家庭，希望把同胞从永恒贫困中解救出来，藉经济、也往往藉政治上的自主，带领他们走向持久繁荣。[^p371-4]

自主的观念，与教会领袖的信念相伴：解放不应只限于农民，也应应用于<a id="pdf-372"></a><!-- PDF page 372; original page 351 -->负担沉重的彼得式政教关系公式。20世纪初，法律上政教分离及恢复已废牧首制，成为教会、世俗报刊及教区教士大会的核心议题。1905年动荡之际，尼古拉二世许诺召开两百余年来首次全国教会会议，宗教领袖及普通堂区教士遂忙于筹备这一重要事件。但一场接一场危机分散这位命运将尽的沙皇注意力，直到1917年2月退位，才为临时政府召集会议扫清道路。政教关系新动力，虽一度预示俄国正教前景良好，布尔什维克的胜利很快显示制度化宗教权威的限度，也显示自认为信徒的普通俄国人之虔敬具有韧性。[^p372-5]

1700—1917年间形成的正教虔敬与文化范式、刻板印象，倾向于二元对立：异教或虔诚、落后或进步、无知或明理。[^p372-6]

## 教会与国家

正教会已被1666—1667年分裂削弱，此后始终未能完全从彼得大帝强行使教会行政从属世俗权力的打击中恢复。沙皇起初较温和的处理，是暂不为已故阿德里安牧首任命继承者，最终却正式把教会重组于神圣宗务院之下；该院由精英主教组成，受一位世俗行政官领导。总检察官虽控制宗务院日常事务，院员仍保有教务权威。到1832年，尼古拉一世教育大臣谢尔盖·乌瓦罗夫伯爵（1786—1855年）创制“正教、专制与民族性”爱国口号时，教会远不像人们可能以为的，只是国家或皇帝意愿的仆人。某些主教的声望、信众敬礼喜爱的圣所及圣者，尤其奥普季纳<a id="pdf-373"></a><!-- PDF page 373; original page 352 -->修道院著名长老而形成的广泛、独立于正式教会的属灵生活，以及主教团中主张进一步独立于国家的思想潮流，都反驳了俄国正教批评者广泛持有的看法：教会不过是国家的婢女。[^p373-7]

18世纪，另一项帮助教会至少维持表面独立的重要因素，是训练未来教士的教育体系。它在彼得大帝时期引入，神学院与学生人数于18世纪后半叶显著增长。1814年建立以神学学院为顶端的四级神职教育结构，成为该世纪余下时间的范本。底层是宗教小学，吸引志向不超出诵经员职位的少年。天赋与愿望足够强者继续进入神学院，多数后来被授圣职为执事或司祭。少数优秀者升入帝国四所神学学院之一，即圣彼得堡、莫斯科、基辅或喀山，从而有把握获任主教等显职。宗教学校虽饱受条件恶劣、纪律残酷及教师训练不足之苦，到1860年代，神职教育仍成为堂区任职不可或缺的条件。大改革间接惠及俄国其他社会领域，却直接引发1867及1869年教会学校的广泛改革，旨在改善课程、居住经历，并从教士等级以外吸引青年从事宗教服务。人们十分关注这些改革的失败，最明显例子是1880年代开始的学生起事，使神学院几乎成为革命活动的同义词。更切中要点的是，解放农奴后在宗教学校受训的一批批教士，可能更敏感于信众的物质需要，以及堂区改革要求；这往往使他们与沙皇官员冲突。此外，激励这一庞大堂区教士群体的高度责任感，表现于极高质量的教区教士<a id="pdf-374"></a><!-- PDF page 374; original page 353 -->报刊，以及许多教区教士大会进行的复杂辩论。[^p374-8]

普通信徒的努力，也不应被忽视。他们以辛勤劳动与个人牺牲，为堂区教士、教堂，以及包括照顾贫困者在内的慈善事业提供资金。农奴解放，以及随后陆海交通和铁路改善之后，虔敬表达显著增加；正教信徒涌向近处及远方圣所。这些地点既对他们个人的世界理解重要，也对帝国合法性重要。信徒属灵表达与神职训练改善的合力，带来宗教复兴，恢复俄国正教的道德权威。信徒与堂区教士虽非始终团结，仍形成一种重要的信仰替代途径，以对圣彼得堡及莫斯科宗教、世俗权威的怀疑为支撑。同时，教会主教开始要求全国会议，决定从恢复牧首制到妇女堂区角色等广泛迫切问题。但他们未向下寻求支持，而宁可依赖神学与历史先例。1917年2月尼古拉二世退位数月后，临时政府召集首次全国教会会议，象征性地弥合了帝国时代奠基者兼礼仪大师所造成的创伤。遗憾的是，恢复牧首制及有关堂区生活的进步裁决到来时，广大信徒已与教会领袖如此疏离，以至十分愿意支持推倒正教等级机构的行动。然而，这些同样的信徒，并不愿放弃堂区或本地宗教生活。[^p374-9]

## 中心与边缘的民众虔敬

彼得大帝在教会内部造成另一种较不正式的分裂，与1666—1667年教会分裂毫不相干。这种分裂，存在于<a id="pdf-375"></a><!-- PDF page 375; original page 354 -->他希望塑造的信徒——受教育，并藉信仰效忠——与用来衡量这一理想的群体之间，即尚未受惠于沙皇改革、被认为蒙昧的广大民众。彼得改革从圣彼得堡向各省省会传播，民众虔敬与地点、教育水平及政治取向便不可分开。从18世纪起，社会与地理流动，使俄国社会各阶层的人接触更多，虽未必更亲近；19世纪最后数十年，交通及通信改善，进一步加快这一现象。

新的宗教分类背后，是“双重信仰”（dvoeverie）观念。这一词语首先用于中世纪讲道，后来逐渐成为俄国受教育精英偏爱的描述。到19世纪末，民族志学者把一种启蒙式居高临下的态度灌注其中，用来对待社会地位较低、只有基本教育的人。“双重信仰”成为乡村俄国所有问题的象征。在这些批评中，农民陷于相信迷信、黑暗力量、女巫、巫师及无所不在的邪眼的心态，成为18世纪俄国西化，以及19世纪和20世纪初现代化、工业化的重大障碍。这些批评未能理解，正教虔敬具有多种形式，使包括农民在内的所有俄国人，无论身在宫廷或最偏远村庄，都能为往往严酷而无意义的生活条件赋予意义。[^p375-10]

受教育与未受教育的正教信徒，共享许多东西。凡自认正教基督徒的俄国人，都把世界分为神圣与世俗空间，旨在使不完美的尘世生活重新神圣化，成为天国。[^p375-11] 宗教信仰与实践以正教神学为基础，具有高度个人化与地方性意义，从农民茅屋简单的圣像角（krasnyi ugol），到帝王宫殿的圣髑匣，都包含其中。农民若希望与家灵（domovoi）、林灵（leshii）、山灵（gornyi）<a id="pdf-376"></a><!-- PDF page 376; original page 355 -->及水灵（vodianoi）保持良好关系而获益，也会向喜爱的圣徒求助，以医治、保护并确保丰收。农民在这些民间传统、既定正教教导及圣者之间自如往来，依据信仰体系的规范，提高获得好运与丰饶的可能，其行为有自身理性。其宗教习俗，与受教育俄国人颇相似：后者寻求著名或不太著名属灵长老的劝告，朝圣时向全国及地方重要圣徒求恩，并持续迷恋不可见世界的奇妙力量。[^p376-12]

从最基本层面说，正教虔敬为彼得引入俄国、平凡的西方历法赋予节奏，也赋予人生阶段意义。每位信徒都应以连续不断的年度庆节标记岁月，把一年分为与圣诞节、复活节相联的两大斋期及庆期。此外，星期三和星期五留作斋戒与默想。“小传统”之下，有无数共同体及个人遵守的宗教节日，纪念堂区教堂、主保圣徒及灵验圣像。三项主要仪式纪念人生时间的流逝，也标记共同体生活的重要变化。帝国俄国惯于在出生后最初几日施洗，承认共同体增添新成员，以及父母双方、婴儿长大后各自承担的新责任。婚姻依靠父母及媒人的辨别力，确保匹配首先适合双方家庭，其次适合共同体，最后才是个人；虽然19世纪后期，准新娘与准新郎的考虑逐渐更受重视。在社会各阶层，寻找合适配偶的重要性，都主导青年时期。[^p376-13] 对农民，这需要占卜、适当行为及说媒专长相结合。对不断扩大的资产阶级，良好结合可能使人在不稳而变化的社会阶梯<a id="pdf-377"></a><!-- PDF page 377; original page 356 -->上升一级，因此必须十分谨慎，往往还要细密协商。对精英，门第与财富考量始终潜藏其中。无论地位如何，婚姻都带来生育、洗礼，以及为下一代寻找适合伴侣的期待。年轻夫妇渐入中年，逐渐接过上一代角色，开始等待最终命运。农民与沙皇同样重视适当的死亡，但后果十分不同。农民若过早、因暴力或非自然原因死亡，被认为会给曾居住的共同体罩上阴影；若自然死亡，亡者则作为共同体辅助性的属灵成员，为留下的亲人带来好运与保护。富裕俄国人对适当死亡的关切，从政治暗杀到对自杀的反应，无处不见。亚历山大二世先前多次遇刺未遂，最终被革命者杀害时，帝国宣传机器大量生产圣徒传式文献，配以圣像式图像，既要显示沙皇直到最后仍完全掌握自己的心智与宗教意识，也要遮掩皇帝遗体受损的程度。[^p377-14]

19世纪最后数十年，新工业在俄国各地兴起，农民进城镇谋职，也把传统及习俗带去。教会对城市传教的矛盾态度，导致未能争取知识阶层及新兴工人阶级；但正教力量仍在个人层面激励人们。[^p377-15] 宗教启发工人参与社会、创作艺术及从事革命活动。[^p377-16]

信徒使正教虔敬适应城市环境的新动力，实践遂获得新形式，往往转向更私人化的信仰。这一变化最终可能既促成1917年后教会在公共领域迅速衰落，也有助于正教以秘密信徒共同体的地下形式存续。

18与19世纪重要宗教发展之一，是受教育者对俄国正教会及其教导的不满蔓延。彼得对教会的攻击，主要仍属于政府权力范围，直到彼得·恰达耶夫（1794—1856年）著名《第一封哲学书简》发表，成为斯拉夫派、西方派及继承者至今未决争论的先声。恰达耶夫一举指出，俄国在历史上格格不入，与西欧遗产隔绝，被欧洲近亲蔑视，又受正教信仰拖累；这种信仰阻挡教育启蒙，造成严重后果。尼古拉沙皇迅速把他斥为狂乱疯子；恰达耶夫决定撤回指控，作正式弥补，却未提出足以压倒先前看法的相反论证。其批评及随后的撤回，激发1840年代关键哲学辩论，扩展至一切知识活动、艺术创造，最终到政治行动。批评家维萨里昂·别林斯基（1811—1848年），以及作家、出版人亚历山大·赫尔岑（1812—1870年），以直言批评俄国、主张仿效彼得大帝采取更欧洲化方向而著称；伊凡·基列耶夫斯基（1806—1856年）、康斯坦丁·阿克萨科夫（1817—1860年）、伊凡·阿克萨科夫（1823—1886年），以及阿列克谢·霍米亚科夫（1804—1860年），则成为“伟大斯拉夫传统”的拥护者。前一群体及继承者热爱西方式教育与制度，至少经济制度如此，政治上却未必；后一群体则偏爱表现为有机“共议合一”（sobornost）的正教共同体主义，并尊重严格遵守宗教与历史传统。[^p378-17] 两阵营虽似乎无法达成共同基础，却都深刻重视现代化的基石：教育与识字。

## 教育、识字与大众文化

在彼得以后俄国的各种发展中，19世纪最后数十年的初等教育扩张及识字传播，尤其充满希望。宗教与世俗精英都期待，基本教育能够使人民（narod）摆脱古老习俗，因为他们认为，正是这些习俗使人民无知贫穷。为达成属灵与道德启蒙及繁荣，1864年《教育条例》确立原则，最终形成全国世俗初等学校体系；不久，又有堂区学校与之并行。按照条例，初等教育主要旨在向人民灌输宗教及道德准则，同时提供基本读写与算术。1866年沙皇遇刺未遂后，支持政治体制被加入目标；但世俗小学仍保有深厚宗教成分，也满足农民对这种课程的广泛需求。宗教教育需求如此强烈，神圣宗务院遂于1884年设立并行的堂区学校体系，二十余年间与世俗学校竞争。初等教育虽快速扩张，堂区共同体在财政上却处劣势：它们擅长吸引学生，无法筹得永久校舍、受良好训练教师及基本教材的资金。1907年教育部新规，把拨款与严格质量标准相联，极少堂区能达到。结果，在尼古拉二世被推翻前十年，堂区学校数量及入学人数急剧下降。[^p379-18]

初等教育带来新的互动：一方是农民及城市下层，另一方是社会地位与知识水平高于他们的人。不断壮大的教师职业中，有教士及其女儿，与受世俗训练的教师一同工作；即使世俗学校，也要求讲授宗教教育。教师不同的世界观，为学生有限的经验带来新视角。这些人民教育者往往激发革命行动，希望藉改革社会政治制度，结束贫困与匮乏。到1890年代，地方自治机关的学校教师<a id="pdf-380"></a><!-- PDF page 380; original page 359 -->受到地方当局严密监视，以遏止乡村与城市愈涨的骚动、抗议；但堂区教师受学生处境及社会贬抑触动，同样可能传播激进手段，改变现存秩序。[^p380-19] 对堂区教师，改变始于堂区生活改革，往往进而要求推翻正教会等级结构，并主张公民不服从。警方记录，证明积极行动在堂区教师间传播，教士等级成员，尤其诵经员、执事等下级人员参与其中，也显示信众对这些文化启蒙者的深切忠诚。[^p380-20]

20世纪初，俄国初等教育发展虽不均，往往仅数年的基本教育，已成功在农民与城市下层工人中，造就数量可观的识字群众；到1917年，识字者超过成年人四分之一。识字不再只见于社会上层。新读者喜爱宗教故事、冒险故事、悬疑故事、传记，以及以廉价报纸呈现的时事；这些都是中等文化品位的大众读物，使文化精英皱眉。大众出版相关产业纷纷兴起，许多业主白手起家，其农民出身向俄国下层暗示：只要具备某种机智与冒险精神，便可能拥有未来前景。[^p380-21] 农民接触有关世界及俄国历史的世俗新观念，融合民间与城市文化。同时，正教虔敬表达愈发多样，也愈难为日益焦虑的神圣宗务院所控制。宗务院审查权1865年后削弱，1905年最终废除；从圣像到圣徒传等大众宗教物品的制作，不再那么拘泥既定风格，却仍同样遵循套式，并试探性地吸收正教对手旧礼仪派及宗派运动的影响。世俗与神圣图像自由混合，随处可见，尤以普遍使用的年鉴或农民历书为例：封面通常画农业场景，背景有教堂。翻过封里，读者可见宗教、世俗<a id="pdf-381"></a><!-- PDF page 381; original page 360 -->及农业年度的重要日期列表。新近识字的俄国人，只须基本阅读能力，便可从自己出生其中的传统文化，顺畅进入帝国晚期快速变化、世俗化的公民文化。对多数人而言，转变既非单向，也未完全完成，但仍意义重大。[^p381-22]

连《圣经》本身，在获取及解释两方面，也成为有争议的读物。整部圣书的现代俄语译本，直到1876年、卡尔·马克思《资本论》首部译本问世后不久，才获神圣宗务院批准；但《新约》及未经认可的《圣经》版本，1860年代已日益广泛流通。教会官员担心，未受神学训练的普通信徒拿到圣经，会作出错误的个人解释，并如路德宗革命那样挑战教会权威，因此努力控制《圣经》发行。1863年成立的俄国圣经传播协会、英国及海外圣经公会等团体，发展广泛的巡回售书网络，到19世纪末，每年帮助发行近一百万部圣经。教会当局常指责旧礼仪派及宗派领袖，以释经欺骗农民；普通信徒却不过是对信仰基本文本表现合理好奇。背离官方宗教、昔日从事文学写作的列夫·托尔斯泰，与弗拉基米尔·格里戈里耶维奇·切尔特科夫合作，发行以基本识字者易懂水平写成的宗教、世俗小册。正教领袖不愿积极看待农民对宗教知识的渴求，反而宁可看见对自身权威的挑战。[^p381-23]

俄国学习阅读之际，民间文化为戏剧，以及1908年以后的电影，提供熟悉主题、艺术形式及情节。现代戏剧于18世纪中叶传入俄国，在叶卡捷琳娜大帝时期迅速发展。受启蒙思想家影响，18世纪俄国戏剧高度风格化而世俗；除少数例外，一直如此，直至罗曼诺夫王朝覆灭。19世纪后半叶，戏剧演出向乡村传播，农民首次接触以陌生主题为内容的组织化演出。这些演出，往往由<a id="pdf-382"></a><!-- PDF page 382; original page 361 -->逃避地方当局的剧团上演，因为当局认为其作品威胁地方道德感受，或沙皇权威。1880年代经英国、德国传来的“人民之家”（narodnyi dom），把农民狂欢节的传统元素，与巡回剧团剧目结合。人民之家不只提供戏剧，也常设图书馆及茶室，供更严肃的聚会。[^p382-24]

电影出现，为不同社会阶层互动，提供大量机会与无限可能。1908年第一部俄国电影制作之后四年内，电影已进入各类人口：城乡、识字与不识字、富裕与贫困者，如今拥有能即时、同时分享的共同文化形式。民间故事、大众文学及传统民间版画（lubok）的现成主题，有助理想化并夸大宗教信仰在俄国生活中的作用。教会领袖支持禁止银幕表现正教教士与宗教仪式，因而无法利用这一新文化媒介促进自身利益、教导信徒或探究重要宗教问题。高级及堂区教士，愈来愈把电影视为礼拜的对手，也视为对青年施展催眠般影响的力量；青年被影片刺激、往往带挑逗性的主题吸引。电影表现民间传统时，常带负面色彩，与上层及其依附者的形象并不更好：他们喜爱不正当爱情、酗酒、奢侈，以及拒斥传统社会规范的新道德；这些都暗含颠覆性，也不在乎正教虔敬。[^p382-25] 沙皇当局虽深知电影力量，直到第一次世界大战爆发，才系统用作宣传。此前，他们走的仍是熟悉老路，企图把精灵塞回瓶中；如同教会，他们禁止独立电影人于银幕描绘或使用皇室图像，只有皇室形象制作者自己的宣传例外。主要例子，是1896年尼古拉二世加冕短片、<a id="pdf-383"></a><!-- PDF page 383; original page 362 -->1913年罗曼诺夫王朝三百周年相关的纪录影像及皇室虚构描绘，以及1907年起官方认可的《帝王纪事》（Tsarskaia khronika）。[^p383-26]

1917年10月开始，数部宗教主题强烈的影片上映，证实正教官员的担忧。布尔什维克上台前夕，两部曲《撒旦得胜》（Satana likuiushchii），成功迎合公众对神秘术及附体的迷恋，以及对宗教极端主义和一切德国事物的广泛敌意。主角路德宗牧师塔尔诺克斯，第二部则为其子桑德罗，过度苦修，同时又因自招的性欲折磨而受苦：他渴求已故妻子美丽的妹妹，并与她及一位不幸的驼背画家姻亲共居。某个暴风雨之夜，撒旦本人到访，突然摧毁其不安稳的家庭生活，大肆作乱，怂恿塔尔诺克斯诱惑妻妹，使她生下一子。[^p383-27] 次年，改编托尔斯泰故事的《谢尔吉神父》（Otets Sergii），表现另一种宗教苦难，以及革命前社会文化禁忌的摧毁。这部影片以同情且准确的方式呈现正教仪式，虚构一位前亲王因爱人成为沙皇情妇而立下修道誓愿的故事。亲王后来领受圣职，成为谢尔吉神父，以宗教讲道著称，吸引日增的仰慕者；有些妇女一见其炯炯目光及属灵献身，便为之倾倒。谢尔吉神父屈从肉欲后，以自伤惩罚自己，离开圣职，成为农民学校教师，以救赎灵魂。[^p383-28]

19世纪后期俄国新兴的学术学科，支持大众娱乐对民间文化的理想化。民族志尤其把研究焦点，置于农民日常习俗及特殊传统，试图发现并界定俄罗斯灵魂的本质。由此对物品、行为及信仰的编目，十分重视虔敬，尤其当它采取<a id="pdf-384"></a><!-- PDF page 384; original page 363 -->迷信形式时，从而为后世数代固定了双重信仰观念。[^p384-29]

## 现代化与民族身份

对俄国多数正教基督徒，信仰丰富多样的象征与仪式，提供初生民族身份的基础：始于当地堂区或村庄，扩展至整个帝国。[^p384-30] 大多数信徒虽不了解神学原理，仍把圣餐及礼仪置于宗教传统中心，想象自己与全帝国同信者共享这一圣事。对所有信众，堂区是俄国正教身份最易接近的表现；但1861年以后交通改善、识字传播，朝圣及相关文献，为大规模形成更广泛联系提供新机会。[^p384-31]

俄国农民宗教与世俗身份的汇合，可见于村庄历史，通常可追溯至神话事件，或获得神话般规模的事件：沙皇来访、灵验圣像自发显现，或与圣者接触。农民把村庄置于更大历史背景，就把小共同体连接到愈来愈大的整体，直至整个宇宙。[^p384-32] 从18世纪至20世纪初，彼得大帝超乎常人的形象，主导村庄故事。这位喧闹不羁的沙皇到访后，人们常兴建教堂，或取得特别圣像加以纪念；圣像有时就是沙皇亲赠。[^p384-33] 圣像也藉抵御灾祸的保护力量，在共同体历史发展中发挥重要作用。人们为特别圣像的所有权及使用权争执，向教区当局陈述理由，并把地方裁决上诉至<a id="pdf-385"></a><!-- PDF page 385; original page 364 -->神圣宗务院，从而强化共同体身份感。著名圣像原件若无法取得，或太远而不能暂借，人们便购买复制品，极为尊崇对待，同时与遥远正教世界建立象征联系。[^p385-34]

无论在世或已故的圣者，以及宗教圣所，为分散且不同的共同体提供另一种具体联系。随着识字传播，人们为这些非凡人物出版类似简短圣徒传（zhitie）的传记，为流行丛刊《圣三一小册》（Troitskie listki）吸引日增读者；它由莫斯科城外古老的圣三一—圣谢尔吉修道院，于1884—1917年出版。圣愚（iurodivye）、游方者（stranniki、podvizhniki），以及较为定居的属灵健将，成为故事中的男女主人公，构成连接各种社会背景信徒的人际网络。教士每周讲道使用这些传记，宗教庆节免费分发，宗教售货亭，尤其圣所，亦有出售。它们提供多重宗教生活范式，强化读者能够认作俄罗斯特质的宗教与社会品质。

许多故事表现拒绝接受命运、无视社会义务，选择孤独且往往奇异生活的男女，例如圣愚安德烈（1744—1812年）。他是俄国中部一位小地主之子，年少便决定走不同人生道路，依圣愚惯常方式赤身游历乡村，肩背长鞭与斧头。安德烈形貌奇特，遭当地儿童嘲笑，最终却有一批忠实信徒，敬仰其灵性与善行。死后，他的遗体葬于卡卢加梅晓夫斯克修道院，成为希望受益于其属灵力量者的朝圣目的地。[^p385-35] 这类人物故事有双重目的：宣传可敬礼其遗体、或经常体验其奇妙力量的圣所；也把来自各阶层、选择不同于出生所承受道路的俄国人，树为榜样。[^p385-36]

全年在圣所，都可见俄国各社会阶层，尤其在吸引大批朝圣者的年度庆节。

朝圣愈受欢迎，宗教与世俗出版物便为有意出发者提供目击叙述、旅行资讯及价格。全国插图宗教报《俄国朝圣者》（Russkii Palomnik）的读者，若想参加特维尔省卡申的安娜年度庆节，就能了解如何从莫斯科及圣彼得堡前往、需要哪些火车转乘、旅途多久——从两都出发均为13小时——以及哪些住宿价格合理且舒适。[^p386-37] 少见的列圣仪式，可能吸引十万以上朝圣者。1903年萨罗夫的塞拉芬列圣充满争议，使教会领袖与希望藉此显示神恩的皇室成员公开分裂；相关描述却也为未来前往新圣地的朝圣者提供指引。[^p386-38] 其中有准确旅程千米数、车票等级、阿尔扎马斯旅馆卢布价格，以及最后乘马车赴萨罗夫的细节；也推荐更便宜路线，包括从下诺夫哥罗德乘汽船沿奥卡河前往。[^p386-39] 圣像与圣者共同把识字及不识字俄国人，团结于共享的正教文化，并提醒他们，自己属于涵盖帝国所有地区的更大共同体。

个人信仰未必导向正教结论，宗派主义及不信宗教的持续增长即为证明。关键转折，是1905年《宗教宽容敕令》公布，减少对各宗派群体的限制，使其可公开实践信仰，不必害怕报复。[^p386-40] 完全脱离宗教，几乎全发生于教育较好的城市人口，并与反对现有社会政治规范相联。俄国伟大思想家，不断思考正教的象征及价值，<a id="pdf-387"></a><!-- PDF page 387; original page 366 -->即使拒绝它们、转向更有吸引力的世俗选择，也仍如此。俄国作家、艺术家及哲学家，努力调和两种倾向：一方面，他们偏爱自己认为具有救赎力量的正教信仰本质；另一方面，又拒斥制度化宗教。这种矛盾宗教立场，影响了“俄罗斯理念”；其本质主义的身份定义，既被染以宗教色彩，也被染以非宗教及世俗色彩，同样存在于主导苏维埃时期大部分时间的共产主义中。20世纪初，象征主义者主导俄国艺术界，其作品流露巫术、迷信及超尘世观念的影响，而这些与正教不可分离。20世纪最初十年“白银时代”的文化活动，深嵌于正教中的属灵与心理结构。[^p387-41]

俄国农民开始大批进城谋生，传统正教虔敬仍是强大力量。城市大教堂或许不如熟悉的村庄教堂亲切，但工人通过组织宗教阅读小组与唱诗班、在创作中使用宗教主题，并遵守传统正教习俗，维系属灵生活。[^p387-42] 正教虔敬未因识字与迁移而消失，反为从传统向现代生活过渡提供缓冲。然而，这种信仰忠诚未能阻止1917年后正教会迅速而毁灭性地衰落，因为高级教士、堂区司祭及信徒之间长期存在的鸿沟，在布尔什维克革命前的数年证明无法跨越。绝大多数俄国人信仰仍坚定，但对教会及教士缺乏信任，有利于一种分散化、民主化、地方化的信仰；它高度个人化，在1920年代反宗教运动中，也易于隐藏。[^p387-43]

俄国社会经历剧变，女性在正教会强加的严格框架内，机会增加。多数朝圣者是结伴出行的妇女，长时间离开家庭及家务责任。她们回村时，往往属灵上获得更新，分享所访<a id="pdf-388"></a><!-- PDF page 388; original page 367 -->异地及所遇奇人的故事。来自各社会阶层的少数妇女，选择更激进道路，形成在俗女修道团体或女性共同体（zhenskie obshchiny），不受修道院正式监督。这些虔敬女性的在俗共同体，提供其他地方无法获得的领导角色。在较传统的堂区生活中，妇女积极参与慈善及教育，却也愈发挫败地寻求官方许可，希望加入堂区议事会，并在各种礼拜中发挥更重要作用。更日常地说，全俄妇女无论社会地位，都是传统守护者，自任教导下一代，传递她们认为生存与繁荣不可或缺的习俗和信仰。男性中心的限制，虽贬低其成就，革命前妇女的努力仍于1917—1918年全国教会会议得到回报：她们获准成为积极的堂区议事会成员，参与本地宗教共同体大多数行政职能。罗曼诺夫王朝在政治舞台的时间将尽，各种民众虔敬挑战正教内较传统的元素；但反宗教运动在城乡释放破坏力量后，它们又成为信仰最强的支持来源。[^p388-44]

## 欧洲基督教背景中的俄国正教

比较欧洲基督教史，可凸显数世纪来各地信徒个人及共同体经历的压倒性共同点，尤其自命运攸关的18世纪以来。法国大革命帮助破除王室受神委任，以及受优待教会应享公共显位的神秘观念。法国教会世俗化，是革命者倡导民主价值的一部分，也是路德宗改革大胆不服从天主教会的逻辑后果。正如<a id="pdf-389"></a><!-- PDF page 389; original page 368 -->路德1517年的重大行动后，天主教会被证明只是西方基督教领域众多属灵与宗教选择之一；1789年事件之后，整个欧洲及俄国的教会，也面对政治社会上被边缘化的前景。俄国虽被描绘为迟至欧洲创新之后才跟进，但彼得大帝改革，以及叶卡捷琳娜大帝没收教地，都比巴黎事件早数十年。多数国家最终出现政教分离，教会社会职能由世俗福利及教育机构取代。俄国与欧洲近亲的差别，在于年代与极端程度；本质而言，世俗化及现代化对既有基督教信仰的影响相同。因此，现代的一项重要标志，是宗教在社会文化中边缘化，或主导信仰根本转型，以适应公众及个人对传统信仰实践形式的不满。关于这一过程的主要解释，强调主导教会从属于世俗政治权威，以及宗教继而退出公共领域。宗教机构过去通过慈善与教育履行重要社会职能，如今则面对政府或私人机构非宗派福利活动，以及师资更好、资金更充裕的国家中小学的日益竞争。[^p389-45] 19世纪，欧洲大部分地区在不同时间、以不同方式，都经历了挣扎：精英与平民传统生活方式，回应工业化及现代化带来的世俗化副产品。1800年的欧洲，与第一次世界大战结束时相比，在政治、社会和文化上根本不同；没有哪里比俄国更明显。它已经以法律上政教分离，以及对所有公共宗教表达采取愈益严格限制的办法，开始极端地与过去决裂。

1960与1970年代，学者开始质疑宏大、概括性的社会文化理论是否有用，世俗化概念也蒙上疑云。社会史家把注意力从精英移向从属阶层，对人民——农民与工人——及其信仰的研究，成为批评的中心。娜塔莉·泽蒙·戴维斯采取跨学科方法，开辟新途径，发现普通民众所谓<a id="pdf-390"></a><!-- PDF page 390; original page 369 -->“巫术／迷信”信仰。[^p390-46] 她提出，研究共同体实践与信仰，是为解释社会中未受教育、没有权力者，如何把“普世教会的象征及话语，整合为地方祈愿用途”；这与理性思想者混合、匹配及排除不同基督教经验要素的方式相同。[^p390-47] 1980年代末及1990年代，把这些理论框架应用于俄国后，学者发现，俄国与欧洲农民，在转型为现代工业民族国家前夕及过程中，理解周围世界的方式，惊人相似。[^p390-48] 19世纪后期至20世纪初精英的宗教变化，虽受到远少得多的关注，新研究仍显示：俄国教会主教团，面对城市化、人口流动，以及以革命解决社会经济问题等时事，反应远非铁板一块。此外，俄国文化精英及哲学家同样多样，合起来横跨宗教与政治谱系，从极端民族主义者到无神论者，从坚定君主主义者到共产主义者。

民族建构与民族身份，在1815年维也纳会议后点燃欧洲的两种观念，尽管具有某些特殊性，也未绕过俄国。语言、文学、宗教及神话，如同在西方一样，帮助团结俄国帝国欧洲部分的多样族群。正如杰弗里·霍斯金所见，俄国的独特处，在于形成国家意识，而非民族意识。皇室、其历史及仪式，是这种身份的政治焦点。19世纪将尽，公共仪式与庆祝，几乎完全聚焦于<a id="pdf-391"></a><!-- PDF page 391; original page 370 -->沙皇，把他视为臣民的象征父亲；这些臣民往往说不同语言，属于不同族群，实践不同宗教。[^p391-49] 能够推广替代身份的独立公共领域，或许比欧洲其他地方受更多限制，但它仍容许表达新的“作为俄罗斯人”的方式：与其依赖沙皇本人或正教，不如依赖帝国模式。面向高、低及中等文化品位读者的新兴文学市场，对传统提出最广泛挑战；它们或思索在多民族、多族群帝国中，统一身份的可能，或提出世俗的俄罗斯性观念，强调帝国广阔地理及历史成就。[^p391-50]

第一次世界大战前十年，俄国专制面对日益增长、似乎无法逆转的社会政治动荡，却未能为最终革命提供任何可行替代。彼得大帝创造了一个精神分裂式的俄国，在较古老的斯拉夫正教自我，与较新的西方自我之间不安摇摆，为帝国开辟新路，由此留下印记。相比之下，尼古拉二世沙皇宁愿依靠人民的斯拉夫正教根源，试图复兴过时的莫斯科观念：沙皇与人民在历史及命运上合一。在这一点上，这位命运将尽的沙皇顺从他所认定的臣民自然倾向：一种新型正教虔敬，既向往遥远过去，又利用现代技术的便利。
