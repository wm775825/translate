# 第10章 法国大革命的遗产：正教与民族主义

帕斯哈利斯·M. 基特罗米利迪斯

在格里高利五世第一次与第三次担任牧首期间（1797—1799年、1818—1821年），正教会激烈抵制西方思想对正教社会的影响。这使许多观察者产生一种错误印象，以为正教会与启蒙运动始终明确对立。于是，教会在制定教务、牧灵与教育策略时，长久以来容纳启蒙思想的传统，便被遮蔽了。事实上，正教会对1790年代末法国大革命和1820年代希腊革命的反应，所显示的是正教与民族主义之间的冲突。启蒙运动使教会面对一种世俗的普遍主义思想；撇开教义问题不谈，这种思想在某些情形下能够补充、甚至支持教会自身的普世价值。民族主义引发的冲突则不同：问题既涉及世俗价值与超越性价值的对立，也使基督教理想的普世性与民族主义的狭隘性相互对抗。这场冲突的历史，最终也就是正教会在19世纪的历史。

## 巴尔干民族主义

19世纪初，当巴尔干各民族揭竿而起、反抗奥斯曼统治时，民族主义对于正教便从理论问题变成现实问题。巴尔干长期持续的起义——先是1804年开始、断断续续进行至1830年的塞尔维亚起义，继而是1821—1832年的希腊起义——成为当地正教宗教共同体转变为现代民族的熔炉。这种转变也使地方教会共同体发生根本改造：它们原本是普世正教的分支，如今成为新兴民族的组成部分。巴尔干民族主义兴起所带来的长期教会后果，在塞尔维亚人的情形中尚未立刻显露，在<a id="pdf-251"></a><!-- PDF page 251; original page 230 -->希腊人的情形中却已经十分明显。1821年希腊革命对教会处境与教规秩序产生了重大影响。君士坦丁堡牧首格里高利五世否认并谴责这场革命，但这一后来备受争议的举动，并未能挽救他的性命。他于1821年4月10日复活节主日，以叛国罪被处死，吊死在牧首座的中央大门前；那扇门从此一直关闭。走上殉道之路的并非只有牧首。许多高级教士也在伊斯坦布尔被处决，其中有以弗所的狄奥尼修斯、尼科米底亚的阿塔纳西奥斯、德尔科伊的格里高利和安基阿洛斯的欧根尼奥斯；在埃迪尔内（阿德里安堡），前牧首基里尔六世也遭绞刑。塞浦路斯当地自主教会的首领基普里亚诺斯总主教、其他高级教士及许多显要平信徒，于1821年7月9日被集体处决。克里特岛遭遇类似灾难：当地教会首领格拉西莫斯都主教、七位主教和许多修道院院长被处死。塞萨洛尼基和拉里萨也有主教遇害。1821年3月，奥斯曼总督把伯罗奔尼撒的八位高级教士囚禁于特里波利斯；同年9月23日希腊人攻陷该城以前，其中五人已死于狱中。换句话说，希腊革命造就了大批新的信仰殉道者。这些人最终被民族主义的英雄殿堂吸纳为“民族殉难者”，从而推动正教自身思想与价值观的转变。

起义对教会造成的真正影响，后来证明也是持久影响，体现于教规层面的后果：君士坦丁堡教会中枢对起义诸省的主教与神职人员所行使的行政控制松动了。革命局势使下层神职人员获得更大力量，因为他们与各自共同体的生活紧密相连。一旦共同体起而反抗，无论君士坦丁堡颁布何种教规命令，当地司祭事实上都会成为起义领袖之一。司祭或执事亲自拿起武器、参加战斗的事例很多，有些人在革命军事领导层中崭露头角，以英勇著称，最终跻身希腊解放事业的殉难英雄之列。英雄执事阿塔纳西奥斯（1821年殉难），以及1825年阵亡、性情激烈的修道院大司祭格里高利奥斯·迪凯奥斯·帕帕弗莱萨斯，便是其中富有传奇色彩的例子。

主教团的处境更复杂，也更微妙。那些在土耳其人的暴怒中幸存的主教，以这样或那样的方式，在革命力量控制的地区支持<a id="pdf-252"></a><!-- PDF page 252; original page 231 -->革命。有些人成为革命文职领导层中的重要人物，在1822年埃皮达夫罗斯、1823年阿斯特罗斯和1827年特罗伊曾召开的国民会议中发挥重要作用。卷入革命熔炉的正教会高级与下级神职人员，以不同方式与正在形成的民族共同体站到一起。神职人员因此越过了民族主义的卢比孔河，离开正教基督教的普世教导；但他们可以提醒自己，自由与自由意志同样属于《福音书》教导的价值，以此安慰良心：“认识真理，真理必叫你们得以自由。”

尽管发生这些影响深远的变化，革命时期希腊的主教团从未质疑自己在教规上从属于普世牧首区。在希腊革命斗争的整个时期，积极参与革命政治的高级教士及其他神职人员，一贯坚持尊重信仰、维护正教教规，并保存民众的基督教道德。其中三位主教——安德鲁萨的约瑟夫、塔兰蒂翁的尼奥菲托斯和弗雷斯塞纳的狄奥多雷托斯——尤其积极参与革命会议的政治活动；约瑟夫还在1822—1825年担任宗教事务部长。各次会议特别重视宗教与教会秩序问题。每次会议表决通过的宪章，都在第一条承认正教基督教为新生自由希腊国家的“占主导地位的宗教”（ἐπικρατοῦσα θρησκεία），同时也在同一条规定，国家容许其他一切宗教及敬拜形式存在，并自由举行其宗教活动。值得注意的是，1827年在特罗伊曾拟定的《希腊政治宪法》第一条调换了次序：先宣布宗教信仰与敬拜自由的原则，再补充说，“基督东方正教会”的宗教是“国家的宗教”。

不过，革命时期希腊的宪制秩序没有超出这些规定。解放地区正教会的具体教会地位，在革命时期的希腊既未被提出，也未受到讨论。尽管与君士坦丁堡牧首座的行政联系已经中断，牧首的属灵权威却未遭质疑。希腊主教团在宗教礼仪中继续依教规纪念牧首之名。为表示尊重牧首的教规权利，在教会事务恢复正常之前，既不祝圣主教，甚至也不为下层<a id="pdf-253"></a><!-- PDF page 253; original page 232 -->神职人员举行授圣职礼。[^p253-1] 整个革命时期（1821—1827年），以及随后约安尼斯·卡波季斯特里亚斯短暂执政的时期，教会事务中可以辨认出两种总体趋势。一种反映了这一时期继续在希腊活动的正教主教团的态度：他们始终如一地坚持，教务的安排必须完全以教会教规为依据。1827年3月，应第三届国民会议主席的邀请，一个由五位主教组成的委员会起草了一份引人注目的文件，提出二十四项建议，以恢复希腊的教会秩序。其中，第一项和最后一项尤其突出。他们首先建议国民会议设立主教会议，负责在整体政治局势恢复正常以前管理希腊教会。五位主教强调，这只是临时的过渡措施。最后，他们明确申述自己对教会秩序的长期看法：无论如何，希腊教会及神职人员都不能设想，以任何形式脱离他们唯一知晓并承认的教规权威——君士坦丁堡的基督大教会。[^p253-2]

如果说上述态度代表教会整体的主流，那么这一时期的另一种总体趋势，则是各次国民会议及其设立的民政当局不断作出决定、采取措施，并表示关切，希望妥善安排教会事务。这一切意味着教会地位的根本变化：许多世纪以来，教会第一次发现自己受到民政权力的尊重、关心与爱护。大量措施和规章旨在帮助教会履行其应有的社会使命，其中包括经济援助与支持；它们却逐渐地、不知不觉而又不可逆转地把教会置于民政权力的庇护之下，使其成为国家的工具。这一切完全出于善意，实施者也真心相信，这些措施会为重生的希腊创造条件，使基督教精神和价值观繁荣起来。事实上，这一过程使正教会从教规良知的承载者——主教团在1820年代已清楚表达这种良知——转变为民族主义机构，最终将以对民族及民族主义价值的新<a id="pdf-254"></a><!-- PDF page 254; original page 233 -->信仰，取代其继承而来的基督信仰。不过，这说的是后来的发展。正教会内在的根本转变，是一个漫长而曲折的过程；在19与20世纪，它使东南欧的正教徒遭遇种种良心危机。

## 希腊教会问题的安排

希腊第一位国家元首约安尼斯·卡波季斯特里亚斯是一位虔诚的正教徒，十分关切这个刚从独立战争中诞生的国家能否恢复宗教秩序与基督教道德，其政府的有关举措也反映出这一点。他主要关切的问题之一，是维系新希腊国家境内的正教会与普世牧首区之间的行政联系。卡波季斯特里亚斯深信，如果切断这种联系，希腊正教这两个分支在教义上的共融也可能受到破坏。然而，1828年5月，牧首阿加桑格洛斯派遣牧首会议四位资深高级教士赴希腊，带去致“伯罗奔尼撒与爱琴海诸岛的神职人员和显要人士”的信件，要求他们重新归顺奥斯曼最高政府。这并不有助于总统实现善意的愿望。[^p254-3] 卡波季斯特里亚斯回了一封措辞尊敬、态度完全和解的信，拒绝牧首的劝告，指出希腊人民绝不可能放弃以如此巨大牺牲赢得的自由。与阿加桑格洛斯不同，他的继任者康斯坦提奥斯一世于1830年8月向希腊国家致以祝愿与祝福，但也对加尔文主义渗入希腊正教徒之中的消息表示忧虑。卡波季斯特里亚斯向牧首保证，希腊忠于正教及大教会。这又让康斯坦提奥斯有机会坚持要求：必须全面恢复希腊国家领土内教会与君士坦丁堡大教会之间的行政统一。[^p254-4]

事情便停留在这里。卡波季斯特里亚斯于1831年9月遇刺，不仅是希腊国家的重大悲剧，也是希腊教会与君士坦丁堡教会未来关系的一场悲剧。他处理教会问题的方式，大概是能够保证<a id="pdf-255"></a><!-- PDF page 255; original page 234 -->希腊与君士坦丁堡顺利解决教会问题的唯一途径。然而，当正教当局为现代政治与民族主义带来的挑战而苦恼时，希腊启蒙运动最重要的政治理论家阿达曼蒂奥斯·科拉伊斯，已经对这些困境和疑问作出明确回答。他的回答见于自己所编亚里士多德《政治学》的导言，该书出版于1821年，正是希腊独立战争开始的第一年。科拉伊斯借这部书，向身处战火中的同胞讲授自由公民的责任。他是第一位就教会问题提出明确民族主义立场的作者：

> 希腊目前已经解放的地区之神职人员……不再有义务承认君士坦丁堡牧首为自己的教会首领。只要君士坦丁堡仍因无法无天的暴君在此设治而受到玷污，他们就应当由神职人员和平信徒自由选举的教士会议治理，正如古代教会的做法，也如今日我们同信仰的俄国人之教会在某种程度上的做法。自由而自主的希腊人的神职人员，竟要服从一个由暴君选出、又被迫向暴君致敬的牧首之命令，这实在极不合宜。[^p255-5]

这段话十分引人注目。在科拉伊斯为希腊未来设想的自由而有序的共和国中，教会应处于何种地位？他为此提出八项条文，这段话构成第一条。他安排教会事务的建议，忠实反映了启蒙思想的蓝图：教会在自由与法治的政治秩序下，理当具有怎样的形态。然而，这样做也使教会服从于世俗秩序的要求及其优先事项。尽管他真诚相信并希望，教会能够恢复福音的纯洁，践行并教导真正的基督教价值，他实际上却使教会听命于民族主义；而民族主义，正是与现代国家相伴而生的新政治文化的主要内容。

1820年代，希腊的世俗与教会领袖都未听从科拉伊斯的劝告。颇为矛盾的是，后来把这些主张部分付诸实践、而且未必怀有相同目的的，并不是像他这样的自由主义共和思想家与政治家，而是在希腊首位国王奥托的摄政统治下，接管希腊王国行政事务的官僚。摄政政府最早采取的行动之一，也是<a id="pdf-256"></a><!-- PDF page 256; original page 235 -->体现新国家建国方略的一项鲜明举措，就是单方面宣布希腊正教会自主。这是一个政治计划的组成部分，旨在确认新王国的民族独立与国家主权。主权又与欧洲复辟时期正统主义模式下的专制统治相联。这就要求推行行政集权政策：不仅要打破地方寡头和各派利益集团的权力，使革命军队的首领服从军事纪律，还必须控制教会。摄政政府以1833年8月4日的一项法令，强行实施教会安排，宣布希腊正教会独立于君士坦丁堡母教会。新自主教会的首领，将由新王国信奉罗马天主教的君主担任；教会治理则交给王室任命的教士官员。这是极端的凯撒教皇主义，与正教会传统及神圣教规格格不入。[^p256-6] 这种强加给希腊教会的制度，出于政治考量，旨在同时加强民族独立与王室专制。但为实现这些目标，教会却被置于一种受新教启发、主张教会服从国家的埃拉斯都主义体制之下，也就是把德意志新教各邦及斯堪的纳维亚诸王国的政教关系模式，移植到希腊。

这一教会安排遭到广泛抵制。后来，政府又颁布法令，废除希腊大多数男修道院及几乎所有女修道院，使这套安排更加完整。1833年7月27日，居住在王国境内的约五十二位正教主教，在巨大压力下才同意拟议中的安排；他们仅坚持，所有有关法令都应明确加入尊重神圣教规的规定。然而，修士及社会各界仍加以抵制，乡村尤其如此，那里的人们确实担心信仰会受到败坏。在神学论辩层面，康斯坦丁·伊科诺莫斯领导了对单方面自主的反对。这位卓越的知识界领袖，深深忠于君士坦丁堡牧首座所代表的教规秩序。[^p256-7] 最著名的教会自主论神学支持者，则是曾在<a id="pdf-257"></a><!-- PDF page 257; original page 236 -->哥廷根受训、追随科拉伊斯观点的神学家狄奥克利托斯·法尔马基迪斯。他将在实施这套教会安排的过程中发挥关键作用。[^p257-8]

历任普世牧首均拒绝这一安排，认为它违反教规，并与被视为陷于分裂的希腊教会断绝共融。牧首座所反对的，主要是宣布自主时所采用的程序，而非自主本身：按照教会的教规与传统，希腊作为主权独立国家，有权拥有自主教会。不过，要找到使希腊教会获得自主地位的适当程序，花费了很长时间。1831年，牧首康斯坦提奥斯一世与米洛什·奥布雷诺维奇亲王或许没有遇到严重困难，便能就塞尔维亚公国建立自治教会的教规程序达成协议；[^p257-9] 但与希腊达成类似协议，却用了十七年。最终，在安西莫斯四世第二次担任牧首期间（1848—1852年），希腊国家与希腊教会无条件接受了牧首座认为符合神圣教规要求的条款，于1850年7月就希腊教会自主问题达成协议。1850年6月29日，普世牧首座回应希腊政府代表境内教会提交的正式申请，颁布一份《主教会议敕书》，授予希腊教会自主地位，由雅典都主教主持的主教会议治理。[^p257-10]

希腊教会自主问题最终解决时所采取的教规形式十分重要，因为它为正教在19世纪后期及20世纪处理类似情况确立了先例。但从基督教本身的历史来看，更重要的是，希腊教会自主问题确立了一种模式，并提供了教规依据，使普世正教会逐步转化为各民族的教会，获得正式认可。矛盾的是，这种转变的基础，原本是按新教模式建立、使教会服从国家的埃拉斯都主义教会体制；而普世牧首座在自身形式上的要求得到满足以后，也为各地方教会成为世俗权力的工具提供了教规认可。世俗权力则把教会编入民族主义事业的前列，以加强自身力量。

大教会始终坚定而毫不妥协地反对单方面宣布自主。这种反对集中体现了正教与民族主义的冲突，以及两者根本上的对立：教会坚决不接受民族主义的逻辑，因为按照这种逻辑，只要能够服务并促进民族的“更高”目标，就可以完全不顾所采用的手段。

## 塞尔维亚的经历

与希腊不同，塞尔维亚在把正教会纳入现代国家所联系的民族共同体时，走了另一条道路；这个现代国家，是从19世纪最初三十年反复发生的起义中产生的。在塞尔维亚，如同在希腊一样，反抗、族群冲突与战争的经验构成一座熔炉，把支离破碎的传统社会转变为现代民族共同体的基础。这种转变的运作方式，记载于马蒂亚·内纳多维奇大司祭的《回忆录》等史料之中。他叙述自己的生活、旅行及参与卡拉乔治起义的经历，显示出塞尔维亚基督徒继承而来的正教心态，如何成为现代民族自立与政治解放思想嫁接其上的底层基础。[^p258-11] 这或许可以解释，塞尔维亚正教被纳入民族自立体系的过程，为何完全遵循教规，始终满足大教会的形式要求，并赢得君士坦丁堡辖区内最重要的教会史家菲拉雷托斯·瓦菲伊迪斯的赞许。他谈到塞尔维亚教会时写道：“该教会在斯拉夫各教会之中，以忠于并尊重君士坦丁堡牧首座而卓然突出；遇有需要便请示牧首座，而且从未切断与它的联系。”[^p258-12]

因此，塞尔维亚公国代表境内教会提出申请，于1831年获得君士坦丁堡授予的自治地位。1878年《柏林条约》承认塞尔维亚为完全独立的王国以后，米兰·奥布雷诺维奇国王与贝尔格莱德的米哈伊尔都主教，分别于1879年4月27日和5月4日致函君士坦丁堡，请求教会自主。牧首约阿希姆三世与君士坦丁堡主教会议遂颁布敕书，正式<a id="pdf-259"></a><!-- PDF page 259; original page 238 -->予以批准。1919年，统一的南斯拉夫王国形成，原先管理塞尔维亚正教人口的不同教会辖区，汇集到同一国家疆界之内。除了塞尔维亚教会，此时还有卡尔洛维茨、达尔马提亚与卡塔罗，以及黑山的总主教区。作为确立新生塞尔维亚人、克罗地亚人和斯洛文尼亚人王国的一部分，王国政府致函君士坦丁堡，请求把这些不同辖区统一为一个塞尔维亚人牧首区。协议于1919年3月18日达成；1920年9月12日，即塞尔维亚诸圣庆日，塞尔维亚教会被宣布为牧首区。具有重大意义的是，新任塞尔维亚人牧首、原贝尔格莱德都主教迪米特里耶，于1924年8月28日在佩奇旧牧首座登座，以此象征性地重新承接塞尔维亚教会的全部历史。

这一过程颇为引人注目：它既尊重教规手续，从而保障教会和平，又以最有效的方式实现塞尔维亚教会的民族整合。在取得自主地位与牧首地位的过程中，塞尔维亚教会始终如一地体现出对教规秩序的尊重。这与19世纪后期及整个20世纪塞尔维亚民族主义史学反复提出的说法，形成鲜明对照；这些说法声称，普世牧首座曾压制塞尔维亚人的教会，并企图对他们实行“希腊化”。显然，这类主张是回溯性地重新解释历史记录的产物，主要依据某些西方观察者歪曲的叙述；这些观察者不了解、或未能理解东南欧正教教会政治的性质。[^p259-13] 然而，这些误解与歪曲满足了民族主义心理的需要，这也解释了它们为何在塞尔维亚及南斯拉夫主流史学中占有突出位置。[^p259-14]

## 罗马尼亚的经历

在民族主义伸张的时代，巴尔干政治逐渐形成了现代那种相当阴暗、难以令人称许的名声；塞尔维亚的教会转型模式，在正教世界没有找到追随者。相比之下，希腊单方面行动的模式，却很快得到罗马尼亚人与保加利亚人的仿效，在正教整体内部引起严重冲突与裂痕。

<a id="pdf-260"></a>
<!-- PDF page 260; original page 239 -->

1859年，瓦拉几亚与摩尔达维亚两个自治公国，经各自议会投票，联合于亚历山大·库扎亲王之下。这为巴尔干的教会冲突开辟了新的可能。库扎随即没收属于正教教会机构——包括圣墓教会与西奈山——的修道院土地及其他财产，在教会圈内引起强烈抗议。1865年，一项“按照各民族政治与思想进步的要求”宣布罗马尼亚教会独立的法案被提出。[^p260-15] 这使希腊教会自主的故事再度上演。强加给罗马尼亚教会的新制度，仿效希腊1833年的安排，使教会从属于国家，所有任命与决定都须得到国家批准。

在索弗罗尼奥斯三世牧首领导下，大教会早在1863年便对没收罗马尼亚修道院财产提出抗议，但没有效果。1865年，它对拟议中的教会新制度作出强烈反应，宣布其违反神圣教规，而且在教义上存在疑问。[^p260-16] 然而，罗马尼亚世俗国家建设的要求与民族主义力量，终究压过教会的教规良知。尽管库扎被推翻，另行选出的卡罗尔·霍亨索伦—锡格马林根亲王继位，罗马尼亚与君士坦丁堡之间的教会问题仍拖延了二十年，直到1885年才最终解决。1867年、1870年及1872—1873年间，曾有解决教会问题的尝试与建议，但都遭君士坦丁堡拒绝，理由是它们旨在服务世俗利益，因而与神圣教规不相容。1881年罗马尼亚被承认为独立王国以后，罗马尼亚主教团举行了一项具有重大象征意义的仪式，以确认他们赞同教会独立。1882年3月25日，他们隆重举行傅膏圣事所用圣膏的祝圣礼；这一特权，普世牧首座历来保留由自己行使。罗马尼亚主教团借此以最有力的方式，使本民族的独立愿望获得神圣性质，并将罗马尼亚民族主义的世俗抱负纳入正教宗教框架。牧首约阿希姆三世对这一举动作出严厉反应，于1882年7月10日致函指出：罗马尼亚主教擅取牧首座这项古老特权，不仅违反<a id="pdf-261"></a><!-- PDF page 261; original page 240 -->古老教规，而且出于一种“求新之欲”，严重危及正常的教会秩序。[^p261-17] 圣膏危机使罗马尼亚教会自主地位在教规上的承认推迟了三年；罗马尼亚既已成为主权王国，本来就有权获得这一地位。直到罗马尼亚教会首领、匈格罗—瓦拉几亚的卡利尼科斯，在罗马尼亚政府同意下致函牧首约阿希姆四世，后者才于1885年4月25日再颁一份主教会议敕书，正式批准其自主地位申请。[^p261-18]

罗马尼亚教会的民族主义动力丝毫未减，学术研究也试图重新建构一种独特的罗马尼亚教会历史。[^p261-19] 1892—1905年，罗马尼亚与君士坦丁堡两教会又因伊庇鲁斯及马其顿地区的教会管辖权发生冲突。罗马尼亚人基于语言上的亲缘关系，声称对说弗拉赫语的共同体拥有权利，希望将其置于罗马尼亚当局的控制之下。[^p261-20] 1925年，罗马尼亚自主教会在磋商后获得牧首地位，君士坦丁堡欣然同意。罗马尼亚自主教会升格为牧首区，成为第一次世界大战所造就的大罗马尼亚，表达并确立民族共同体的最后一项象征性行动。

## 保加利亚督主教区

在正教会内部，各种冲突突出显示出正教教规秩序与民族主义愿望之间的不相容；其中最严重的一场，围绕保加利亚教会问题而发生。这个问题虽然在19世纪第三个四分之一时期达到高潮，引发一场长期才得弥合的痛苦分裂，但冲突本身早已在酝酿，是保加利亚民族运动发展的副产品。对抗极为激烈，特别是在1872年分裂正式确立以后，以致它影响了对整个历史的理解，把当时的冲突、敌意与敏感情绪投射回过去，实际上抹去了东南欧基督教历史本身的意义。

<a id="pdf-262"></a>
<!-- PDF page 262; original page 241 -->

尽管整场冲突围绕教会管辖权与秩序问题展开，它在更大程度上却是一场受世俗抱负及权力考量驱动的冲突，几乎没有留下余地，让团结、仁爱与和平等基督教价值影响各方态度。

与希腊、塞尔维亚和罗马尼亚不同，保加利亚争取教会独立的斗争，先于现代国家的出现。在巴尔干正教的另外三个例子中，教会解放被视为民族独立的完成；对保加利亚民族主义者而言，争取自身教会的斗争，则是民族获得承认与解放的前奏。正因如此，他们的要求缺少教规依据，难以在神圣教规框架内得到满足。保加利亚争取教会解放的斗争，代替了政治解放运动；这解释了它的激烈程度，以及它何以走向极端。这场斗争始终受政治逻辑而非教会逻辑支配，必然导致两个主要当事方——保加利亚民族主义主教团与普世牧首座——无法沟通，更不用说理解对方立场。

克里米亚战争（1854—1856年）以后，保加利亚民族主义者首次提出某种形式的教会自治要求。普世牧首座对这些要求既非漠不关心，也并未置之不理。1861年和1867年，普世牧首约阿希姆二世与格里高利六世先后提出解决方案。第二项方案实际上是一份建立保加利亚自治教会的蓝图，拟使其管辖以保加利亚人为主的地区。[^p262-21] 保加利亚人认为这些建议不能令人满意。在俄国驻奥斯曼最高政府大使伊格纳季耶夫伯爵的积极鼓励下，[^p262-22] 他们于1870年2月取得奥斯曼政府的一道敕令，设立保加利亚督主教区：这是一个涵盖十三个保加利亚教区、名义上从属于君士坦丁堡的自治教会行政机构。[^p262-23]

保加利亚人欢呼奥斯曼的决定，视其为未来独立的先声；普世牧首座却予以拒绝，并着手<a id="pdf-263"></a><!-- PDF page 263; original page 242 -->召集正教诸牧首的大型会议，审议这一问题。会议在君士坦丁堡召开，会期从1872年8月29日持续至9月17日。普世牧首安西莫斯六世主持会议，参加者包括亚历山大牧首索弗罗尼奥斯、安提阿牧首伊埃罗塞奥斯、塞浦路斯总主教索弗罗尼奥斯，以及君士坦丁堡教会的二十四位高级教士。会议宣布保加利亚督主教区陷于分裂，并褫夺保加利亚主教中这场运动领袖的圣职。保加利亚方面的要求被认为缺乏教规依据，因而遭到拒绝：他们要求拥有自身独立的教会，并非基于政治独立——保加利亚仍是奥斯曼的一个省份——而是基于族群及民族的特殊性。会议把这种立场称为“族群主义”（ethnophyletism），并将其谴责为异端。[^p263-24]

尽管各方反复尝试解决问题，保加利亚教会分裂仍持续至1945年。[^p263-25] 保加利亚虽然于1878年成为自治公国，1908年成为独立王国，其教会却始终处于正教诸教会的共融之外，因为民族主义激情高涨到了无人愿意办理取得教会自主地位所需程序的程度。牧首座支持者与督主教区支持者之间、希腊人与保加利亚人之间的激烈情绪，在马其顿、色雷斯、东鲁米利亚，乃至君士坦丁堡本身引发严重冲突。20世纪初，“马其顿问题”激化（1903—1908年），人们为控制正教敬拜圣所及信徒的良心而流血。这一切使正教被视为民族主义的同义词，也为巴尔干政治赢得阴森的名声。争斗的焦点是权力与领土，而非宗教；其利害关系由现代国家设定，这些国家利用教会来进行自己的斗争。[^p263-26]

新当选的督主教斯特凡于1945年1月21日致函君士坦丁堡，请求牧首本雅明宽恕，并撤销加诸保加利亚教会的分裂地位；仅一个多月后，分裂便得解除。1945年2月25日，保加利亚重新受到欢迎，回到<a id="pdf-264"></a><!-- PDF page 264; original page 243 -->正教共融之中。[^p264-27] 直到两次世界大战的屠杀及其对巴尔干造成的血腥后果之后，1872年谴责“族群主义”的敕令，其全部意义才得以确立：这种意识形态不合基督教精神，与正教的教导及理想不相容。

保加利亚教会问题更广泛的意义，在于显示正教与民族主义的冲突能够走向何等极端。固然，在马其顿、东鲁米利亚与色雷斯，教会冲突与希腊及保加利亚民族主义之间的致命对抗交织，摧残当地普通人的生活；但普世牧首座与督主教区的对立，并不如某些历史学家所说，等同于希腊与保加利亚两种敌对民族主义的冲突。普世牧首座并非希腊民族主义的代理者。它曾坚决抵制希腊民族主义，后来处理罗马尼亚与保加利亚教会的民族主义表现时，也同样坚定。诚然，对于希腊和罗马尼亚，并未召开大型会议，谴责其单方面行动是取得自主地位的不合教规途径。这是因为，这两个教会及其政府在挑战教规、违反正教会生活中体现教规的手续方面，都没有像督主教区运动的主角们那样走向极端。保加利亚主教团与督主教区在早期活动时，并不受一个负责任的民族国家政府可能施加的任何约束；这可以解释民族主义热忱为何使他们走向极端，以致正式谴责不可避免。正教会在谴责“族群主义”时表达的教规良知，源自基督徒长期思考教会秩序的传统，并受到一整套教会法的规范。若无视这一法律体系，便有严重偏离信仰基本要求的危险。当世俗历史学家指责正教会借诉诸教规来掩饰自身特殊的民族主义动机时，往往未能理解的正是这一点。只有无视教会法所预设的基督教原则，这类批评才可能成立；而这些原则在视野上确属普世，在内容上具有超越性，并以建立一个普遍的信仰与赎罪共同体为目标。对“族群主义”的谴责提醒世人两件事：正是这些原则与民族主义不相容；而正教会作为基督教机构，<a id="pdf-265"></a><!-- PDF page 265; original page 244 -->有责任维护这些原则，无论其个别成员与代表有何人性的缺失——恰恰是这些缺失，最初才让民族主义与族群主义得以侵入。

## 安德烈·沙古纳

正教与民族主义的冲突，不仅限于志在独立的民族教会与普世牧首座之间的激烈对抗，也扰乱了地方层面的教会内部事务。正是在这里，两者冲突产生了最为强烈的良心危机。这一问题内在于正教迈入现代的过程；为说明它的这个方面，我们将举出两个来自正教世界边缘地区的例子。第一个见于安德烈·沙古纳的行动与著述；他于1846—1873年领导特兰西瓦尼亚的罗马尼亚正教会。沙古纳通过争取恢复该地区罗马尼亚教区的斗争，成为正教会乃至当地罗马尼亚民族的领袖。恢复教区意味着脱离卡尔洛维茨塞尔维亚人总主教的管辖；后者是哈布斯堡领地内所有正教徒的首领。那场运动明确显示了民族主义在教会中的作用；安德烈总主教也完全意识到，自身活动使他陷入何种矛盾。一方面，他的牧灵责任、对羊群的关切，以及面对特兰西瓦尼亚希腊礼天主教会的压力与诱惑时，巩固信众忠于正教的需要，都促使他通过建立自身教会机构，来确立正教共同体的身份；这一计划导致了与塞尔维亚正教教会当局的冲突。另一方面，他又知道，在基督教传统中，教会与某一特定民族之间并无必然的教规联系。[^p265-28]

然而，顺应时代精神，沙古纳逐渐相信，正教会本质上就是民族教会，因此其牧灵任务包括关怀羊群的民族身份与文化传统。同时，他不希望教会行使某种世俗政治领导权，而是把教会的作用看作使世界成圣的使命；正是这一使命，赋予民族教会存在的正当性。为履行此使命，教会必须保存其自主性、道德传统，以及<a id="pdf-266"></a><!-- PDF page 266; original page 245 -->超越性价值，因为沙古纳相信，只有如此，民族教会才能有效履行使命。[^p266-29]

## 正教与阿拉伯民族主义

在正教的东部边缘叙利亚，围绕古老安提阿牧首座控制权的争斗，演出了一场更为痛苦的悲剧，反映出民族主义在正教会中的后果。这里的冲突，外在表现为关于教会及主教团语言的对抗。在阿拉伯世界，民族主义之风最初于19世纪中叶数十年间，吹入接触过西方教育的阿拉伯基督徒之中；他们主要就读于传教士设立的学校，或正教教会当局庇护下开办的希腊学校。正是在这些圈子里，人们首先要求在教会中使用阿拉伯语，并支持以本地说阿拉伯语的人担任主教与牧首。阿拉伯正教民族主义者在这方面，如同此前的保加利亚人一样，受到俄国外交的有力鼓励；俄国在巴尔干与近东的帝国计划，把正教会视为极其有效的武器。1891年，再度有希腊人当选安提阿牧首，阿拉伯人的不满达到沸点。在俄国鼓励下，又借助君士坦丁堡与耶路撒冷旷日持久的教会危机，以及希腊在1897年对土耳其战争中的失败，阿拉伯民族主义者终于迫使生于塞浦路斯的牧首斯皮里东于1898年1月辞职。[^p266-30] 1899年，本地阿拉伯正教徒、拉塔基亚（老底嘉）的梅勒提奥斯当选安提阿牧首。此事被称为“阿拉伯民族主义的第一次胜利”。[^p266-31]

20世纪，阿拉伯正教徒曾数度尝试以类似方式取得耶路撒冷牧首座的控制权，但均告受挫。这些事件显示，随着19世纪开始的广泛变化，民族主义在多大程度上已成为正教会生活的主要动力。从正教转向民族主义，既是世界观也是生活态度的转变；这种转变更深层的意义，或许比正教其他任何地区的<a id="pdf-267"></a><!-- PDF page 267; original page 246 -->经历都更为清楚地，显露于20世纪初两位阿拉伯正教知识分子哈利勒·萨卡基尼与伊斯坎达尔·库布里西所面对的痛苦两难之中。两人以不同方式，从民族主义及其激发的热烈投入中，找到摆脱苦涩挫败感的出口。这种挫败感与他们的社会地位有关：他们属于脆弱的少数群体，随着奥斯曼在阿拉伯世界的统治衰落并消失，这一群体失去了从前的显著地位。然而，这种新近解放他们的民族主义投入，结果却与其正教基督徒身份不相容。尽管阿拉伯民族主义起源于正教基督徒共同体，事实证明，一个阿拉伯人若要把生命献给民族主义事业，就必须抛下自己的基督教信仰。[^p267-32] 这两位杰出思想家都作出了这种选择，以其生命经历，有力见证了正教基督教与民族主义之间的不相容。

## 普世牧首座的两难

正教的超民族中心——普世牧首座——也未能免受民族主义挑战的影响。尽管反对民族主义的悠久传统可以追溯至格里高利五世牧首，尽管1872年曾谴责族群主义，在马其顿针对督主教区的致命斗争，还是把牧首座卷进民族主义的漩涡。在19世纪之交，一代充满活力的年轻高级教士，以德拉马（后任士麦那）的克里索斯托莫斯与卡斯托里亚（后任阿马西亚）的格尔马诺斯为首，引导大教会与希腊民族主义结盟，以维护牧首座的权利。〔译注：原文为“19世纪之交”；按下文人物与年代，似指19、20世纪之交。〕这种联盟使他们与牧首约阿希姆三世（1878—1884年、1901—1912年在任）的策略发生冲突。后者深信正教会具有超民族性质，反对任何使牧首座认同某一民族国家政策的举措，即使那个国家是希腊。[^p267-33] 约阿希姆三世认为，保障正教共同体的传统特权，能够为基督徒人民在多元文化的奥斯曼国家中继续生存提供基础，因此坚持忠于帝国。他深深怀疑民族主义，认为其中蕴藏着冒险主义。然而，约阿希姆三世于1912年去世后，君士坦丁堡牧首座屈从于<a id="pdf-268"></a><!-- PDF page 268; original page 247 -->民族主义的诱惑。1908年青年土耳其党人起事之后，奥斯曼政治中的民族主义高涨，再加上巴尔干战争（1912—1913年）及1914年第一次世界大战爆发，把奥斯曼帝国境内的基督徒各民族及其教会，进一步推上民族主义的险途。大战刚结束、协约国占领伊斯坦布尔期间，牧首梅勒提奥斯四世（1921—1923年在任）公开支持希腊民族主义事业。

正教会如同先前的亚美尼亚教会一样，发现屈从民族主义诱惑须付出惨重代价：其共同体遭受殉难与流亡。1923年《洛桑条约》强令正教徒离开小亚细亚与东色雷斯，给基督教带来无法估量的悲剧：它以烈火与刀斧毁灭了两千年的基督教历史；这一历史的源头，可以追溯至圣保罗的宣讲、亚细亚七教会，以及4世纪希腊教父创造的牧灵奇迹。对土耳其社会而言，这也是一场重大悲剧，因为它剥夺了多元共存与宗教共生的丰厚遗产；这些遗产原本可能使现代土耳其更易接受宽容与尊重差异的教导。这场灾难之后，除了往昔伟大的历史建筑，土耳其境内留下的正教基督教遗存，只有普世牧首座本身，以及大伊斯坦布尔地区、爱琴海因布罗斯岛和特内多斯岛的羊群。土耳其东南部还有一些阿拉伯正教人口，继续隶属安提阿牧首区。小亚细亚内陆说土耳其语的正教徒，特别是拥有精美基督教艺术遗产的卡帕多基亚地区的正教徒，则被献给民族主义这个克洛诺斯，驱逐至希腊。在这段悲剧插曲之后，历任杰出牧首使君士坦丁堡牧首座重归其真正的传统：普世性，以及忠实恪守教规；它为正教世界提供了应对21世纪挑战所需的领导。

整个20世纪，民族主义始终是正教会面临的问题。该世纪绝大多数正教信徒生活在各民族教会的管辖之下，而这些教会又受到世俗国家的严密控制。国家大多利用教会，推进自身的政治与民族主义议程。在统治巴尔干及其他地区正教人口的新国家中，当地民族教会成为实现民族凝聚与思想整合的有效工具。基督教在这些地区所具有的象征和心理力量，以及<a id="pdf-269"></a><!-- PDF page 269; original page 248 -->教会早先作为地方共同体生活组织结构的历史，在教会被编入国家行政工具之后，便成为现代国家民族主义计划最有效的支撑。矛盾的是，这恰恰通过教会自主实现：自主使各民族教会摆脱君士坦丁堡，却又把它们交给世俗国家控制。

无论对地方教会还是地区性教会，世俗控制都有两个明显后果：首先，不可避免地牺牲某些基督教价值；其次，卷入民族主义仇恨与激情。当国家转而信奉共产主义与无神论时——俄国在1917年以后，巴尔干及东欧在1945—1990年间——从属于国家的真正含义便显露出来。这有时意味着殉道，最终反而有益于正教会的信仰及道德地位；它也意味着国家代理人渗入主教团，从而颠覆基督教价值。这是一个破坏性过程，人们以不断高涨的民族主义热情掩盖它，又通过胁迫使各教会与牧首区沦为棋子，用于宣传、压制、战争等不圣洁的目的，1990年代巴尔干的悲剧便是明证。国家对民族正教会的利用，也被输出到广泛分布的正教侨民社会。西欧、北美与大洋洲的这些群体，本来可以成为不同正教徒相遇与团结的场所，却往往成了民族主义对抗的舞台。

这些现象大多发生在教会政治的高层。在基层，另一种正教仍然存续：它以堂区敬拜、遵守基督教传统的生命历程礼俗，以及修道生活及其属灵见证为中心。这段零散的历史尚未被系统书写，其中某些部分比另一些更为人熟知。例如，以俄国奥普季纳修道院为中心的《爱善集》传统复兴，以及它对东欧其他正教会的影响，已广为人知，并与正教侨民社会神学思想的繁荣相联系。在地方教会民族化的时代，正教精神与传统如何存续，还有一个较少为人知的篇章，见于19世纪后半叶最伟大的希腊散文作家亚历山德罗斯·帕帕迪亚曼蒂斯（1851—1911年）。19世纪俄国伟大小说家果戈理、陀思妥耶夫斯基与托尔斯泰，其创作所受到的正教启发，在欧洲文化史上广为人知；但在希腊以外，帕帕迪亚曼蒂斯的成就远未如此熟知，也远未得到同样的赏识。帕帕迪亚曼蒂斯并不像俄国同行那样写作史诗性长篇<a id="pdf-270"></a><!-- PDF page 270; original page 249 -->小说，而是把无穷的才华投入大量短篇小说的创作。他以直接而朴实的方式，用真挚的人情——其质朴与描写力量无与伦比——记录日常正教经验，让它成为意义、慰藉、希望与美的源泉。在希腊或巴尔干文学中，没有其他作家比他更温柔、更深情地书写个人虔敬的表达、会众的敬拜，以及正教礼仪映衬于希腊山川诗意之中所产生的情感力量。帕帕迪亚曼蒂斯与同时代著名俄国作家一样，从《爱善集》遗产中汲取灵感。这一遗产在他成长的爱琴海岛屿世界继续存留，并为其小说提供主要素材。然而，在帕帕迪亚曼蒂斯的散文中，《爱善集》的启发是慰藉和救赎人类苦难的源泉，而非通过提出种种两难、撕裂人格的力量。20世纪后期，人们重新关注帕帕迪亚曼蒂斯，他的作品也吸引了齐西莫斯·洛伦扎托斯等重要希腊思想家。这是一个迹象：正教尽管因与民族主义相联而历经波折，其内在属灵核心依然强韧而富有生命力，能够在21世纪作为一种生活选择。[^p270-34]
