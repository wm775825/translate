# 第24章 现代灵修与东正教会

**约翰·宾斯**

基督教灵修研究考察教会如何理解自身、确立身份，以及如何运作。其基础是有关教会形成的叙事：这些叙事把教会的建立与圣灵的恩赐联系起来。第四福音书清楚地说明了这一点：复活之日，基督向门徒吹气，说：“你们受圣灵。”（《约翰福音》20:22）圣路加则记述，五旬节圣灵以风与火的形式降在门徒身上，教会的使命由此开始（《使徒行传》2:1—4）。这些叙述表明，圣灵以多种方式引导这个新形成的共同体，包括宣讲圣言、施行医治与彰显大能的奇事，以及建立有纪律、有秩序的共同体。灵修研究描述并考察教会如何存续、如何理解与界定自身、如何组织和塑造生活、如何与其他宗教共同体及周围社会交往，以及从何汲取活力与资源。它关注教会具体而实际的存在，而不是教会永恒不变的信息。这门学科处于神学、历史与社会学的交汇处，力求从教会自身的神学视角，清楚说明教会如何在历史中运作。近期一部基督教灵修史曾要求撰稿人牢记：“基督教灵修是在一般形式与专门形式中实际体验基督教信仰。灵修与教义可以区分，因为灵修所关注的并非信仰本身，而是信仰在宗教意识与实践中唤起的回应。”[^p601-1]

正教会与任何现代宗教共同体一样，内部丰富多样。在正教历史悠久的地区，传统的宗教表达形式<a id="pdf-602"></a><!-- PDF page 602; original page 581 -->仍在村落中延续，修道院与其他圣地成为民间虔敬生活的中心。在中东伊斯兰国家，身为少数的教会努力适应往往充满敌意、缺乏宽容的环境，并保护自身。在西方，以及越来越多的其他正教地区，以世俗主义、自由民主和市场经济为特征的文化，促使教会寻找表达自身生活的新方式。面对如此丰富而又令人困惑的教会生活形式，要辨认一种统一的现代灵修，或一种统一的正教灵修，似乎是不可能的。然而，正教会恰恰教导：存在一种统一的属灵传统，世代相传，并由此形成教会。正是这种坚定的信念，使分布广泛、形态多样的信徒群体享有共同生活。

正教这一统一的传统之流，有两个源头，即正教共同体在教会两千年历史中经历的两种不同经验。由此产生的灵修，可以分别称为“基督教世界”与“殉道”。[^p602-2]

为方便起见，尽管有些粗略，可以把东方基督教拜占庭帝国，也就是“基督教世界”的起点，定在312年：这一年，基督教开始受到君士坦丁皇帝（312—337年）的保护。这既带来了新的政教关系，也开启了拜占庭帝国的历史，直到1453年君士坦丁堡陷于土耳其人之手。在这一千多年的漫长时期，基督教皇帝与基督教牧首视彼此为合作者，共同创建、引导一个普世的基督教社会。在拜占庭体制下，形成了独特的基督教文化，包括建筑、文学、哲学、神学、礼仪、修道生活、圣像绘画、圣歌与法典。我们所认识的正教会，至少就其迦克墩派形式而言，是这一文化发展的产物。例如，金口圣约翰礼仪受到建筑、宫廷仪式和修道敬拜的影响，在14世纪形成今天所行的样貌。[^p602-3] 有人不满这种无所不在的拜占庭主义，担心它会使人保守地固守某种文化形式，而无法向新一代鲜活地呈现<a id="pdf-603"></a><!-- PDF page 603; original page 582 -->福音。另一些人则在拜占庭文化中看见希腊哲学探求与希伯来宗教敬畏的创造性结合，足以抵抗西方个人主义。[^p603-4] 拜占庭传统持续的创造力表现在许多方面，一个恰当的例子是，现代圣像画家放弃19世纪西化的画风，转而采用拜占庭范本庄严、简严的祭仪性形式。1204年十字军攻占君士坦丁堡后，拜占庭帝国虽然衰落，帝国梦想仍具有诱惑力，影响了中世纪后期的塞尔维亚、保加利亚，尤其是俄国。莫斯科作为继罗马和君士坦丁堡之后“第三罗马”的观念，助长了俄国的帝国雄心。亚美尼亚与埃塞俄比亚这两个4世纪建立的古老基督教王国，也共享拜占庭事业的理想。埃塞俄比亚的基督教帝国一直延续到1973年的军事政变。〔译注：原文作1973年，与第19章记述的1974年不同，此处照录。〕

在这种自信、甚至带有凯旋意味的文化之外，正教徒也经历了更严酷、更消极的遭遇。1453年，君士坦丁堡经过长期衰落，终于陷于奥斯曼军队之手；不久，穆斯林哈里发取代基督教君主，成为东方帝国的统治者。正教地区依旧属于帝国，但正教徒已从统治者变成被统治者。中东的安提阿、亚历山大与耶路撒冷牧首区，早在7世纪中叶阿拉伯军事征服时，就已开始经历这一过程。较近的时期，剧烈迫害重创各教会：土耳其在1895—1925年，俄国在1918—1990年，塞尔维亚及周边地区在1940—1945年，都发生过这种情况。后几个例子使我们有理由说，20世纪为信仰而死的基督徒，比其他任何世纪都多。整个正教地区的教会，因而承受了长期而具有破坏性的压迫。这其中既有相对宽容的时期，也有歧视和公然迫害；但在这些不同形式的压迫中，一种新的灵修逐渐形成：殉道者成为典范，基督徒生活成为对苦难的忍受。教会蒙召完整守护正教信仰的纯洁，所需的品质是严格、坚忍与不屈的意志。这种灵修与修道传统相互作用，苦修生活也被视为一种殉道。这种殉道灵修的影响，<a id="pdf-604"></a><!-- PDF page 604; original page 583 -->既见于许多修道院毫不妥协的严格作风，例如阿索斯圣山埃斯菲格梅努修道院悬挂的“正教或死”旗帜，也见于深厚的怜悯。伦敦俄国正教座堂的安东尼·布卢姆都主教，被问及共产主义统治下的俄国教会是否自由时，回答：“教会的自由，就是爱至于死。”

正教会的灵修由这两种巨大的共同体经验塑成，如今正进入生活的新阶段。20世纪最后十年，统治广大正教地区的共产党政府，以惊人的速度消失。新的自由与自决能力，突然落在教会身上；教会同时必须在民主、世俗主义、市场经济与个人主义成为文化常态的现代社会中运作。一个在专制、宗教、传统与群体性环境中形成的教会，必须重新界定自身，申明身份与自我理解。这是一次巨大的冲击。西方教会经过数世纪逐渐熟悉现代世界，也参与塑造了这个世界；但对东方而言，这种新的世界文化却突然到来。当然，希腊等国在一个多世纪前已独立，而在主要位于中东的另一些国家，基督徒依然是处境艰难的少数。然而，整体教会仍被骤然推入一个陌生而不确定的世界。[^p604-5] 现代世界向正教会提出的问题是：如何在新的自由环境中重申身份？如何与周围的新文化建立关系？能否发展新的灵修，使教会能够在现代世界中存续、见证并成长？

埃及科普特教会是成功适应现代社会要求的一个例子，尽管中东社会的现代性与西方有所不同。它以三种不同方式回应现代社会生活。这三者都源于开罗的主日学运动，并分别与三位现代科普特领袖相联系。第一位是马塔·米斯金，即“贫穷者马太”院长。他在纳特伦谷旷野的圣马卡里奥斯修道院建立修道共同体，以传统修道苦修生活为中心，同时开展积极进取的旷野经济开发。第二位是撒母耳主教，他与<a id="pdf-605"></a><!-- PDF page 605; original page 584 -->西方机构和教会合作，推动科普特人的愿望。最后，教宗谢努达三世帮助教会认识自身的身份与活力，由此赋予科普特共同体新的信心与政治意识。这些路径最初彼此竞争，后来协调合作，带来了科普特教会的显著复兴。这场包含三个方面的运动表明，成功的现代化，是在新的社会形态中重新激活传统，也就是一种“革命性传统主义”。埃及的教会复兴说明，正教会能够成为富有活力的传教共同体，既参与现代社会，又从传统汲取生命。[^p605-6] 现代正教灵修因而面对双重任务：首先复兴传统，其次建立结构，使教会能适应现代社会，并有效运作。

教会复兴的过程，始于努力理解教会究竟是什么。教会论是正教神学家着力探讨的主要课题之一，他们将其视为紧迫而困难的任务。在早期基督徒看来，教会是由上帝召聚的共同体，构成基督在地上的身体，并获得圣灵的能力。2世纪的安提阿的伊格纳提乌斯，把教会描述为以主教为中心、司祭与执事环绕的共同体，共同庆祝圣餐礼，使基督以饼酒形式临在，由此使信众成为教会，即基督的身体。每一个这样形成的教会共同体，都是完整无缺的。[^p605-7] 这种简单明了的理解，在随后数世纪逐渐被遮蔽。拜占庭帝国中，教会边界与帝国边界重合，教会因而成为一种机构，不再是独特的共同体。它开始承担创造文化的仪式功能，而不再向这种文化提出先知性的挑战。施梅曼说：“为了向帝国传福音，教会不得不使自己变成一种宗教。”[^p605-8] 彼得大帝以后的俄国，最清楚地体现了这一发展：教会由国家任命的总检察官主持的宗务院治理，而总检察官往往并非基督徒。教会仿照政府部门组织，教士也如同政府官员。除了这种<a id="pdf-606"></a><!-- PDF page 606; original page 585 -->教会生活的扭曲，压迫的经验还带来了其他更直接的危险：基督教教育受限，教会成员遭受经济处罚，教职选举也受国家影响。在共产主义俄国，教会作为机构遭到系统拆解。到1940年，革命前约150位主教只剩三位：牧首署理谢尔吉、阿列克谢都主教，以及负责政教联络的尼古拉·克鲁季茨基。

因此，正教神学家如此重视教会论，并重申伊格纳提乌斯对教会作为共融的清楚、简单理解，实在不足为奇。阿列克谢·霍米亚科夫（1804—1860年）认为，教会生活的基础在于地方共同体：人们因信仰聚集，在多元中形成统一，在爱中共同迈向与上帝的联合。他以俄语sobornost表达这一理解，这个词有时译为“共同体”，这里译作“共议合一”。[^p606-9] 尼古拉·阿法纳西耶夫（1893—1966年）、亚历山大·施梅曼（1921—1983年）和约翰·齐齐乌拉斯，即别迦摩都主教约安（1931年生），进一步阐发了这一丰富的神学传统。圣餐礼中，主教或其代表主持，共同体聚集，圣灵使饼酒的圣事转变为基督的身体与宝血，教会由此成为圣灵引导的共同体。这是一种有力量、有创造性的教会观：它保持与过去的连续，强调礼仪的重要，也能在不同环境中建立并维持教会共同体，为其生活提供明确基础。恢复礼仪的中心地位，不仅与西方教会的堂区圣餐运动有相似之处，也影响了合一运动。西方堂区圣餐运动把更新理解为重返初代模式，正教则把它理解为进入拜占庭礼仪的丰富传统，从而更新地方共同体。此外，西方鼓励经常领圣餐；东方虽然也越来越鼓励定期、甚至每周领受，却往往仍不频繁。正教礼仪也是有效的传教媒介：许多人最初受到敬拜的丰富、力量和纯粹之美吸引，继而委身正教会。

礼仪是拜占庭文化的伟大产物。在其他表达方式受到禁止的黑暗压迫岁月，它支撑着教会；如今又使新的生命萌发。现代灵修，始于对教会及其敬拜的默想。

如果说礼仪是形成教会的行动，那么修道院就是维系教会的场所。修道院远不只是特设的祈祷中心。它们保存并实践丰富、细密的礼仪传统，是地方虔敬生活、往往也是朝圣的中心；它们提供教育与训练，尤其培养教会领袖，因为主教来自修道群体；它们也常是地方经济、社会生活的中心。修道院以许多不同方式，为教会生活提供资源与活力。因此，教会需要兴盛的修道院。修道生活的中心，是希腊的阿索斯圣山。一千多年来，这里的壮丽景观、远离尘世的环境，尤其是深厚的修道传统，吸引着修士，使教会生活集中在这片小小的地域。禁止女性进入的规定，也凸显了它的独特性。20世纪大部分时期，阿索斯的修道生活持续而不可阻挡地衰退。修士人数从1903年的7432人，降至1971年最低的1145人。人们普遍预言它将消亡。庞大的建筑逐渐破败、空置。一位访客记述，他到访佐格拉富修道院时，被告知院中没有修士。约翰·朱利叶斯·诺里奇写道：“阿索斯正迅速死去。病已无可救药。没有希望了。”[^p607-10] 出人意料的是，随后的岁月却出现复兴。它始于隐修所和称为sketes的半隐修小聚落，一些著名灵修长老的教导与榜样，吸引了年轻修士。这些群体成长为新的共同体，逐渐迁入修道院，使各院重新有人居住，得到重建与更新。过去的“自律制”生活，即每位修士保有自己的财物、自行决定生活方式，逐渐让位于院长指导下共同生活的“共住制”。另有修士群体从色萨利的迈泰奥拉和优卑亚岛迁来，来自希腊及其他正教国家的初学修士也开始抵达。到2000年，山上修士已增至1642人。人数增长伴随着灵性更新；年轻而受过良好教育的修士，使各院既能培育有纪律的苦修生活，也能成为教会生活<a id="pdf-608"></a><!-- PDF page 608; original page 587 -->的中心。修道更新还从圣山向外传播。以法莲神父这位长老成为菲洛塞乌修道院院长。共同体壮大后，他不仅能派修士前往圣山其他三座修道院，还在美国与加拿大建立了至少16座修道院。[^p608-11]

修道生活的更新也发生在正教世界的其他地区，包括俄国、罗马尼亚与埃及。今土耳其东南部的叙利亚传统山区图尔阿卜丁，因政治压力导致基督徒人口减少，修道生活一度似将消亡。如今这种命运似乎可能避免；近期报告显示，该地区基督徒人数出现了幅度虽小、却可以衡量的增长。

现代正教神学的一支传统，在19世纪俄国发展起来。当地思想与社会的激荡，不仅引出了共产主义革命，也带来了正教神学思想中一场较为安静的革命。尼古拉·泽尔诺夫称之为“俄罗斯宗教复兴”，并以此为其著作标题，阐述其中一些作家的思想。在这一俄罗斯传统中，谢尔吉·布尔加科夫、帕维尔·弗洛连斯基、尼古拉·别尔嘉耶夫、格奥尔基·弗洛罗夫斯基，以及后来的弗拉基米尔·洛斯基、亚历山大·施梅曼和约翰·梅延多夫等神学家，留下了卓越的著作群。[^p608-12] 弗洛罗夫斯基以“向教父前进”概括一项神学纲领：研究教父，在他们那里寻找神学基础，使神学既忠于教父遗产，又能参与现代社会。一些过去很少受到研究的教父，由此渐为人知。由于这些学者的研究与出版，亚略巴古的狄奥尼修斯、宣信者马克西莫斯、新神学家西缅和格里高利·帕拉马斯，开始为更广大的基督教世界阅读、认识。翻译、注释与反思教父著作的工作仍在继续，出版数量不断增加，尤其经由纽约的<a id="pdf-609"></a><!-- PDF page 609; original page 588 -->圣弗拉基米尔神学院出版社。这种重新发现教父的过程，是东西方相互作用的结果，因为许多作者在共产主义革命后离开俄国，定居西方，尤其是巴黎与纽约。他们亲身经历了正教教父神学与西方批判性学术研究这两个世界。两种文化的相遇，使泽尔诺夫所说的俄罗斯复兴，发展成正教复兴。蒂莫西·韦尔的例子很有启发性：这位原属圣公会的牛津学者改宗正教，在本书写作时以狄奥克利亚主教卡利斯托斯的身份著述。他的作品广受阅读与重视，[^p609-13] 帮助把西方学术环境与严谨的正教神学结合起来，显示了西方正教在现代灵修中的关键作用。

神学更新一直忠于修道根基：人与上帝的相遇，发生在礼仪与苦修的环境中。这一神学传统就是静修主义，源于希腊语ἡσυχασμός，可以译作“把自己交付于静默”，描述人摆脱堕落生存中的种种幻象、进入上帝临在的状态。实现这一状态的方法，是苦修操练与耶稣祷文。祷文有若干形式，以《路加福音》18:13等新约经句为基础，通常是：“主耶稣基督，永生上帝之子，怜悯我这罪人。”持续反复诵念，可以引人进入静观状态。静修主义起源于早期旷野修道院，其思想见于拜占庭教父著作，尤其是格里高利·帕拉马斯（1296—1359年）。这种实践在修道院延续，阿索斯圣山尤为重要。1782年《爱善集》的出版，是现代静修复兴的一个重要时刻。《爱善集》（Philokalia，意为“爱美”）是篇幅庞大、内容多样的教父祈祷生活文选，收入3至15世纪的作品，由科利瓦派更新运动的成员编成。[^p609-14] 杜米特鲁·斯塔尼洛埃翻译并扩充的罗马尼亚文版，共12卷，达4650页。[^p609-15] 帕伊西·韦利奇科夫斯基于1793年把它译为斯拉夫文，隐修者费奥凡则在下一世纪译为俄文。本书写作时，英译<a id="pdf-610"></a><!-- PDF page 610; original page 589 -->仍在进行。[^p610-16] 这部文选为教父的神学教导提供全面概述，供那些寻求祈祷生活、实践祈祷操练的人使用。因此，把神学反思与修道实践结合起来的静修传统，浓缩在一句简单祷文和一部书中。通俗著作《朝圣者之路》描述一位匿名俄国农民发现静修主义的经历，显示传统这两种表达形式的适应能力。[^p610-17] 《爱善集》与耶稣祷文，使整个正教会得以重新领受拜占庭时期发展的神学传统；在重物质、受工作支配的现代社会，这为日益发展的修道生活提供了理论基础。耶稣祷文在东西方基督徒中传播，作为一种简单的祈祷形式，可用于不同层次：既可是一句迅速发出的“箭祷”，也可成为贯穿一生的静观生活方式。不过，不应高估它的使用程度，因为礼仪祈祷仍是修道虔敬生活的基础。

神学更新不仅发生于大学教授的研究、著述与教学，也成为平信徒中的大众运动。阿拉伯与奥斯曼统治下，基督教教育常受限制；共产党政府的控制更严。这些限制解除后，广泛的学习与研究渴望随之出现。教会设立了各种教育机构，往往由教士或平信徒主动推动，而非教阶领袖发起，因此具有大众基础。1907年，优西比奥斯·马托普洛斯神父在希腊成立“神学家兄弟会”，又称佐伊运动。其成员许多是神学毕业生，走遍希腊宣讲、教学，二战后在协助教会抵抗共产主义方面尤为有效。较近时期，俄国两位司祭——1992年去世的弗谢沃洛德·施皮勒神父，以及弗拉基米尔·沃罗比约夫神父——积极鼓励教育。共产主义垮台后，他们的教育事业迅速发展，成为圣吉洪正教神学学院；至本书写作时，已改为人文大学，并获国家教育部门认可。学生超过4000人，其中1442人为全日制。学院有13个地区中心，其中一个专为军人设立。全日制学生须未满35岁，男、女<a id="pdf-611"></a><!-- PDF page 611; original page 590 -->人数相近。圣吉洪的毕业生成为司祭、圣像修复师、教师、孤儿院等社会机构的工作人员、唱诗班指挥和主日学负责人，也有人留院任教。这所充满活力、不断发展的机构，显示正教徒教育需求与供给的增长，也为教会服务储备人才。[^p611-18] 其他正教国家也出现了类似倡议，例如埃及与埃塞俄比亚的主日学运动。所有正教会都重视教育，并让平信徒具备参与教会的能力；越来越多善于表达、信仰坚定的成员，受到装备，承担教会的传教与教导工作。

叙述现代正教灵修，一个不可或缺的部分是圣像虔敬的复兴。19世纪圣像常采用西化的自然主义风格，此后现代圣像画家努力恢复拜占庭绘画的风格与形式。俄国离散群体中的格里高利·克鲁格和列昂尼德·乌斯宾斯基，希腊的福蒂斯·孔托格卢，俄国的齐农神父，以及塞尔维亚的帕夫莱·阿克森蒂耶维奇，都表明传统拜占庭形式可以承载富有活力的当代表达。圣像属于教会的整体体系，是正教敬拜的一部分；但它们也受到基督教世界许多地方的欢迎，《弗拉基米尔圣母像》等图像得到广泛复制。对圣像兴趣的增长，说明正教灵修与虔敬对现代基督教的贡献，远远超出传统正教地区。传统主义者可能惋惜圣像离开了应有的礼仪环境，但其广泛传播，使人更深理解正教，也帮助正教融入现代宗教社会。

面对新政治自由提供的挑战与机遇，正教会的回应取得了显著成果。1990年，俄国有18座修道院、三所神学院，莫斯科有40座教堂。十年后，这些数字分别增至500座修道院、50多所神学院和莫斯科300座教堂，而且继续上升。拜占庭时期形成的完整教会传统，提供了连贯而多样、可以较容易重新领受的灵修体系。它在建筑<a id="pdf-612"></a><!-- PDF page 612; original page 591 -->形式、圣像与礼仪中的具体表达，使复兴迅速、显著，而且具有说服力。

正教徒常把自治的民族教会称为“地方教会”，以强调它们扎根于某一场所。正教灵修的力量，见于它能够植根不同文化与环境，既包括传统正教地区，也包括新的传教地区。它还为非正教教会的灵修传统，带来新的洞见与活力。前述不同历史经验，妨碍了清晰统一行政结构的发展。正教会往往适应其所处的政治秩序。拜占庭帝国早期，主要行政城市的五个教区享有公认的优先地位：罗马、君士坦丁堡、安提阿、亚历山大和耶路撒冷，合称“五大牧首制”。奥斯曼统治下，君士坦丁堡牧首则成为基督徒米利特，即民族共同体的首领。随着新国家独立，新的教会取得“自治”，这里有别于“自主”：前者虽独立管理内部事务，仍承认母教会的最终权威；后者则不受这种约束。然而，20世纪动荡的政治变化，使这个自治教会大家庭的体制，难以应对新正教共同体和新正教国家的需要。

对许多正教徒而言，最紧迫的挑战是西方教会的组织。[^p612-19] 从东方看，这是离散问题。Diaspora是希腊词，意为“散居”，此处指持续数世纪的由东向西迁徙。例如，伦敦首座希腊教堂于1677年建立，位于苏豪区至本书写作时仍称“希腊街”的地方。过去一百年，这个过程加速：人们逃离共产主义政权与世界大战的破坏；1974年土耳其军队入侵后离开塞浦路斯；逃离伊斯兰原教旨主义日益增强的中东；1990年起，又因边境管制放宽而离开东欧和俄国。至本书写作时，西方正教徒远超2500万，在许多地方，正教是少数仍在增长的宗教群体之一。许多正教会在西方设立教区，照顾离乡成员，结果形成令人困惑的多重管辖。这不仅违背<a id="pdf-613"></a><!-- PDF page 613; original page 592 -->一地只能有一位主教的教会论原则，也进入了历史上属于罗马牧首区、即教宗管辖的地域。西方正教会的许多成员，已是第二代、第三代当地国民，对现居国家的认同更深。另一些人则是西方改宗者，觉得教会的族群性质并不自然。越来越多西方正教徒认为，自己是西方基督徒，而不是东方基督徒；他们盼望形成一个本地的西方正教会，为不断增长的西方正教共同体提供共同身份，并鼓励其传教。西方正教会的迅速发展，意味着“东方正教会”这一称呼将越来越不合时宜。

美国对本土教会的渴望最为强烈，表达也最鲜明。当地向移民开放，使不同族群组成的正教堂区不断发展。1872年，旧金山建立俄国教区，很快发展成多族群教会。吉洪·别拉文于1898年、33岁时获祝圣为主教，设立新的教区，接纳阿拉伯人、希腊人、塞尔维亚人、罗马尼亚人与阿尔巴尼亚人。1907年，各教区召开第一次全美会议，以民主方式作出决定。[^p613-20] 这种统一后来瓦解，部分原因是个别堂区必须摆脱日益受俄国共产党政府控制的俄国教会，建立独立地位。1950年，世纪初曾与吉洪共事的列昂季·图尔克维奇担任主教，鼓励权力下放、平信徒主动参与、礼仪使用英语，并让女性进入神学院。他的榜样促进了独具美国特色的正教生活。1967年，原先名称冗长的“美国俄罗斯正教希腊大公教会”，改称“美洲正教会”（OCA）。三年后的1970年，莫斯科牧首区授予其自主地位。遗憾的是，其他牧首区没有追随莫斯科，大多数正教会仍不承认其自主地位。尽管如此，它通过圣弗拉基米尔神学院、广泛的出版事业和英语教会生活，仍具有影响力。这体现了一种强烈的美国本土正教传统：既仰望早期阿拉斯加正教传教士，尤其是阿拉斯加的圣赫尔曼，也充分参与现代美国基督教生活。在西方其他地区，<a id="pdf-614"></a><!-- PDF page 614; original page 593 -->正教会建立较晚，地方传统也较不成熟。

各牧首对新生美洲正教会的反应，显示在西方建立教会结构有多么困难。母教会重视、也需要其离散共同体。西方正教共同体往往由流离失所、或被迫离乡者组成。即使自愿移居，他们也珍惜与故土的联系，需要维持文化与民族身份。西方教区如今规模庞大、经济富裕，是东方民族教会中有影响力的一部分。对叙利亚正统教会、以色列与巴勒斯坦的教会等中东小教会而言，这些教区尤其宝贵：近期大规模移民，使故土教会人数减少、力量衰弱，依赖海外共同体的支持与成员。普世牧首尤为关切，因为451年迦克墩会议赋予他对“蛮族地区”正教徒的管辖权，这被解释为民族正教会地域以外的任何地方。因此，庞大的希腊离散教区不仅构成其信徒的主要部分，牧首区也声称有责任指导建立新教会的过程。教会论原则虽然要求建立统一的西方地方教会，仍有许多因素阻碍这一发展。

政治变动也给正教历史地区带来组织与身份问题。这里民族教会的边界，通常与国家边界重合。因此，教会与民族愿望彼此认同。巴尔干新国家争取摆脱奥斯曼统治时，这种关系具有创造性：教会促进民族语言、文化与制度的发展。在反抗奥斯曼帝国权威的民族主义斗争中，它们成为新国家塑造、认识自身的中心。然而，国家一旦建立，同一种认同便很容易变成狭隘、排他而不宽容的民族主义。原文所述1870年在君士坦丁堡召开的会议，认识到这种危险，谴责“新的、具有破坏性的民族性原则”，并把它确定为一种名叫“族群主义”的新异端。〔译注：本章原文作1870年；第10章相关会议记为1872年，此处保留本章年代。〕其错误在于过分强调教会生活的族群维度，使教会仅限于一个族群，而非一个地方——即某一地域内的所有族群。它因此违背了教会的<a id="pdf-615"></a><!-- PDF page 615; original page 594 -->大公性，因为教会容纳所有族群的人。[^p615-21] 1990年以来，许多国家都显现出族群民族主义的破坏潜力，巴尔干的遭遇尤其悲惨；但也必须承认，这里的教会曾勇敢地为和平与和解作见证。

新国家也挑战教会组织，迫使人提出：新国家是否必然需要一个新教会？在本书所述时期，乌克兰这个欧洲第二大国家的新共和国中，有四个教会：力量集中于东部的莫斯科牧首区、基辅的新牧首区、西部另一个自主正教会，以及同样位于西部的希腊礼天主教会。阿尔巴尼亚则提供了一个充分本地化教会的良好例子。这个仅有350万人口的小国，教会在1944—1990年共产党统治下遭受极端迫害，例如全国连续23年没有公开礼仪。共产主义垮台后，出生于希腊、曾任雅典神学教授与东非总主教、并参与合一运动的阿纳斯塔西奥斯·扬努拉托斯，于1992年获祝圣为总主教。他谨慎选择希腊族与阿尔巴尼亚族主教，坚持在教会场合说阿尔巴尼亚语，为所有人提供服务与关怀，不分族群或信仰。结果形成了充满活力的基督教共同体，拥有许多新培养的本地教士与本地领袖。总主教确保教会充分本地化的关切，促进了这个欧洲最贫困国家之一的正教复兴。

参与国际秩序，要求正教徒不仅界定内部教会关系，也界定与其他教会和信仰的外部关系。总体而言，后者并不良好。正教的历史记忆包括1204年拉丁十字军攻占君士坦丁堡，使拜占庭帝国衰弱，更无力抵抗土耳其人；原属正教的共同体被改造成与教宗共融的希腊礼天主教会；以及较近时期，资金雄厚、积极进取的西方基督教传教组织，进入原共产主义国家。这些经历，共同造成正教与其他教会之间关系的困难。

有迹象显示，许多合一关系中的冷淡正在缓和。2004年，罗马把金口圣约翰的圣髑归还君士坦丁堡——1204年十字军曾从那里将其掠走——这样的行动，是和解与希望的重要标志。

正教徒从合一运动开始便参与其中。1948年世界基督教教会联合会（世基联，WCC）首次大会，就有普世牧首区与希腊正教会的代表，后来俄国及其他正教会也加入。各方都从合作中受益，西方基督徒为俄国人抵抗共产主义迫害，提供了急需的支持。但正教徒常觉得，难以与同伴合作。由于罗马天主教会不是成员，世基联成员以新教为主；社会与政治行动，比教义讨论更受重视；互领圣餐被看作共同委身的见证方式，而不是协商讨论过程的终点；还有人谈论世基联时，仿佛它是超越宗派分歧的“超级教会”。这些紧张关系促使正教会决定，出席1998年哈拉雷世基联大会，但不与其他人共同敬拜，也不投票。为此，后来成立委员会，讨论正教未来如何参与；作者写作时，预计它将于2008年提交报告。对许多正教徒而言，其他教会令人怀疑，合一主义是一种严重的现代异端，威胁正教信仰的完整；然而，正教徒仍忠实参与合一运动，也纠正了运动中的某些西方预设。

除了正式参与世基联，正教还与其他教会进行多次双边、多边会谈。气氛有时热诚友善，有时冷淡猜疑。最显著的成果，是正式决定努力克服最古老的分裂之一：自451年起分裂东方基督教世界的迦克墩派与非迦克墩派正教会之间的分裂。经过1964—1991年的一系列讨论，代表得以宣告：“我们双方都保存了对我们的主耶稣基督的同一信仰。”[^p616-22] 完全共融尚未恢复，但在实践中，许多地方已有密切合作，甚至互领圣餐，叙利亚尤其如此。

<a id="pdf-617"></a>
<!-- PDF page 617; original page 596 -->

在宗教间对话方面，正教的贡献更多仍是潜力，而非现实；但它同样能够发挥重要作用，尤其在基督徒与穆斯林关系这一困难领域。两种信仰成长于相同的中东环境，此后一直进行“生活中的对话”。关系经历了不同阶段，包括暴力冲突和具有破坏性的法律歧视；直到近代，正教徒通常是其中的受害者。然而，在西方基督徒与穆斯林之间，正教徒占据着可能富有创造性、促进和解的位置。和穆斯林一样，他们在11至13世纪遭受十字军暴力，后来又在19至20世纪与穆斯林共同承受殖民列强的压迫。正教徒也能提醒西方人：他们忽略了中东基督徒共同体的需要。由于移民西方，以及激进伊斯兰原教旨主义的攻击，这些共同体急剧衰落，而西方国家与教会对其困境相对缺乏关切。

正教会面对组织问题。这些问题影响其灵修，也提出疑问：作为机构，教会是否具有适应能力与内部资源，发展一种能够满足西方正教徒需要的国际性灵修？这不仅要求一种包容性的地方灵修，帮助新民族国家形成，也要求一种合一灵修，能与其他教会乃至其他信仰共同体交往，在不损害正教独特见证的情况下，为合一对话作出贡献。

这些组织问题背后，是教会如何调整、发展与改变的问题。正教强调由礼仪形成的地方教会生活，并拒绝罗马教宗制那样的任何中央集权形式，因此便有一个问题：即使教会愿意，它又能怎样改变？像祝圣女性为司祭这样的问题，如何讨论、决定，由什么机构承担，很难看清。大多数正教徒确实会坚决反对，但至少也应存在作出这类改变的可能。拜占庭帝国时期，由皇帝召集、主教参加的大公会议，推动并促成传统的发展。它们不仅裁定教义，也处理纪律与法律事务。当代正教中，各民族教会的地方主教会议定期开会，处理纪律及其他事务；但更大的问题，需要普遍会议的<a id="pdf-618"></a><!-- PDF page 618; original page 597 -->权威。人们曾希望适时召开“神圣而伟大的泛正教会议”，1930年代至1990年间也举行过一系列筹备会议，却因共产党政府的垮台而中断。在作者看来，当时可预见的未来，召开会议的希望很小。

与缺乏普遍决策机构相对应的，是普世牧首权力的削弱。他曾是一个庞大、富裕、强大帝国首都的主教；本书写作时，这位正教资深主教所在城市的正教居民已不足2000人，其行动受到一个民族主义、反基督教的土耳其政府限制。政府规定牧首必须是土耳其公民，这严重限制牧首区自由，也使这一高位的候选人范围不断缩小。有人猜测，牧首区可能被迫离开传统首都，迁往附近的罗得岛，或更彻底地迁至日内瓦、纽约，从而确立其作为世界正教领袖、而非地方主教的身份。只有在现代伊斯坦布尔已无法维持这一机构时，才可能发生这种变化。中心的权力真空，带来多种后果。它使牧首能够行使一种独特的属灵权威。巴尔多禄茂一世登座时说，自己是“服从本国法律的忠诚公民”，其权力“始终纯属灵性，是和解的象征，是没有武器的力量，拒绝一切政治目标，与世俗权力欺骗人的傲慢保持距离”。然而，这并未阻止他与教会其他部分发生争执；1996年，君士坦丁堡与莫斯科因爱沙尼亚教会管辖权争议，一度中断共融。普世牧首在政治上不安全的处境中，忙于维护自身地位，妨碍了他在世界正教中发挥统一作用。

所有教会都必须应对科学发现与技术进步带来的新伦理、社会与经济问题。大多数正教徒摆脱政治压迫后，也直面这些多样的问题。正教伦理的基本路径，是依靠教会传统。伦理学在正教神学中，通常并不是独立的思想门类，而属于对属灵生活的整体理解。基督徒生活与伦理决策的资源，存在于源自教父的礼仪和神学传统中。这当然<a id="pdf-619"></a><!-- PDF page 619; original page 598 -->不是倒退，回望一个旧时代的思想；它相信，引导过历代教会的同一圣灵，将继续引导教会，以新鲜、切合当代而又与过去一致的方式说话。为这一传统作见证的教父，是处理这些现代问题的主要源泉。

有迹象显示，这种路径能够作出独特贡献。俄国共产党政府几乎刚一垮台，俄罗斯正教会就开始由主教、神学家和各领域实践者参与的讨论与研究。2000年，经过六年反思，俄国主教会议发表了一份篇幅很长的社会政策文件。立场虽然保守，但处理新问题时也显示出灵活性。例如，文件把同性恋谴责为有罪的倾向，却允许特定情况下离婚，也没有一概排除避孕；同时谴责堕胎与安乐死。这向正教徒表明，在维护传统教导的同时，可以、也应当创造性地处理困难的牧养处境。另一个参与领域是生态。1989年，普世牧首德米特里宣布，把教会年首日，即9月1日，定为保护自然环境的祈祷日。2001年，克里特岛举行了一次重要的国际环境会议。教父不仅强调，人有责任怀着感恩，把受造界奉献给上帝，也强调自然秩序将参与基督带来的最终救赎。这为参与此类问题提供了灵修与教义基础，显示创造性运用教父教导，可能产生丰硕成果。

对正教会而言，现代灵修具有明确的身份。1990年以来东欧突然发生的政治变动，已把各教会牢牢置于新的现代时代，带来表达、实践传统信仰的一系列机遇与挑战。正教信仰活在礼仪、苦修传统和教父教导中，是有生命、有创造力的信仰：它既在变化的世界中提供稳定，也提供参与这个世界的资源。西方正教传教的成功，以及正教灵修的许多特点对非正教徒与正教徒同样具有吸引力，都证明它切合现代世界。结构问题依旧尖锐，短期内似无解决希望，将妨碍正教会成为真正国际性、参与合一的共同体。所有宗教团体都不断面对转向内顾、保守反动与不宽容的诱惑；拥有丰富历史传统的正教会尤其如此。

<a id="pdf-620"></a>
<!-- PDF page 620; original page 599 -->

必须抵制这种诱惑，因为它与新约精神格格不入。更有希望的前景，是一个重新激活教父、礼仪与修道传统，牢固植根世界各地，并以积极而又真实体现正教的方式，与现代世界各种机构对话的正教会。我们敢于说，这就是现代正教灵修；我们盼望，它能在正教基督徒的实际共同体中，越来越占据主导地位。

本章开头曾提醒自己，灵修研究旨在辨明上帝的灵，如何引导它所召聚的教会。新的生命，会以出人意料的方式，在未曾预见的地方出现。“风随着意思吹，你听见风的响声，却不晓得从哪里来，往哪里去；凡从圣灵生的，也是如此。”（《约翰福音》3:8）共产主义以后教会的重新出现、修道生活的兴盛、苦修者与殉道者的涌现——这些赐给教会的礼物，既无法预测，也不能假定以后必然持续出现。在注意到教会生命迹象的时候，我们认识到，它的生命依靠上帝在其中的临在；同时，我们可以确信，圣灵未来的行动，性质虽然难以预料，仍值得信赖：祂会慷慨赐下恩赐。
