# 第6章 阿索斯山与奥斯曼人（约1350—1550年）

伊丽莎白·A. 扎哈里亚杜

拜占庭修道院既位于乡村，也位于城市，尤以君士坦丁堡为重镇，是宗教、文化、慈善和经济生活的中心。它们由一组建筑构成，除修士居室外，还包括主教堂（katholikon）、小堂、食堂、泉亭、面包房、库房和马厩。有些还为朝圣者与旅人设置客舍，并有医院及供养老人的济贫院。许多修道院设有图书馆和抄写室，在那里抄写手稿，特殊情况下还配以精美插图。修道院通常环以坚固的防御墙。多数拥有农地，既为修士提供食物，也带来收入，用于修道院的利益，常用于维护或改善建筑。院产大多通过皇帝捐赠和授予特权获得；这类特权常表现为免缴国家税赋。私人也向修道院捐献，通常换取身后的追思，以及为其灵魂得救所作的祈祷。捐赠一般不限于地产，也包括现金和珍贵物品。免税及持续不断的捐赠，使修道院能够通过购买取得更多财产。从十世纪起，院产大幅增加，除田地、葡萄园外，还纳入水磨、牲畜和鱼塘；此外，修道院也开始获得城市出租房产、作坊及船只。

修道生活受一些一般原则约束。共住制意味着共同体遵循平等的生活方式，所有修士遵行相同作息，在共同餐桌分享相同食物。另有自律制（idiorrhythmic，即依各自节律生活），允许较为个人化的生活方式，修士可以拥有私产。由于下文将分析的原因，这种修道形式在<a id="pdf-176"></a><!-- PDF page 176; original page 155 -->拜占庭最后几个世纪更为普遍，并在奥斯曼统治下继续流行。

圣山是拜占庭修道生活的特色，绝大多数位于小亚细亚。例如，比提尼亚的奥林波斯山（乌卢斯山，Ulus Dağ），古米利都地区的拉特罗斯山，以及以弗所附近的加勒西奥斯山。然而，1071年塞尔柱苏丹阿尔普·阿尔斯兰在曼齐刻尔特战役中战胜拜占庭人后，土耳其人推进小亚细亚，这些修道中心随之走向不可逆转的衰落。土耳其游牧民不久前才接受伊斯兰教，信仰尚浅；他们无视法律和规章，带着家人与畜群进入这片地区，沿途掠夺破坏，造成至少持续30年的浩劫。修道院几乎没有生存机会，珍宝引来游牧民的贪欲；他们洗劫修道院，将修士奴役或驱逐。后来在帕特莫斯岛创建神学家圣约翰修道院的克里斯托杜洛斯，留下生动记述，描述土耳其占领的野蛮，以及自己被迫放弃拉特罗斯山斯提洛斯修道院的经过。[^p176-1] 小亚细亚修道院的衰落，有利于阿索斯山。1204年后的拉丁统治时期结束时，这里的修道院以虔诚生活赢得了更高声望。[^p176-2] 此后，它们一直保持独特性质。在十四世纪末奥斯曼人征服马其顿期间，这一点对它们大有裨益：早期奥斯曼统治者为其灵性权威所打动，也急于履行虔诚穆斯林统治者应负的责任。他们开始奉行《古兰经》的宗教宽容原则，其前提是尊重基督徒与犹太人的宗教机构。依一项古老圣训（hadith），先知穆罕默德本人曾保护西奈修道院；人们也认为，圣战（jihad）期间应不打扰修士，敌对行动结束后，还应暂予免税。[^p176-3] 早期奥斯曼统治者奉行这些原则；更切实地说，他们也利用这些原则，争取当时视拉丁人为真正敌人的希腊正教民众。[^p176-4] 特拉比松地区的修道院，在<a id="pdf-177"></a><!-- PDF page 177; original page 156 -->1461年奥斯曼征服该地后，也在与巴尔干相似的条件下存续。

奥斯曼统治下，阿索斯山修道院的生活大体未受干扰。即使再没有皇帝捐赠，奥斯曼苏丹至少确认了它们对大部分地产的所有，并授予有利税收的特权。私人继续向各修道院捐献地产、现金和珍贵物品，其中包括瓦拉几亚沃耶沃达等显要人物。[^p177-5] 这一最受尊崇的宗教中心的吸引力，也延伸至出身较为卑微者；他们同样作出相当可观的捐献。一个值得一提的例子，是威尼斯属克里特的卡瓦拉雷亚修道院：1555年，院长将其遗赠给阿索斯山迪奥尼修修道院。[^p177-6] 奥斯曼在巴尔干扩张期间，阿索斯各修道院所得捐赠增加，因为正如下文将说明的，当时形势对捐赠有利。因此，阿索斯山在新主人统治下继续经济繁荣，仍是教育、文化和灵性生活的中心。

它受益于同早期奥斯曼统治者建立的谅解。如果相信一项由零散历史证据支持的阿索斯传统，这种谅解显然在奥斯曼征服马其顿之前就已存在。该传统称，在苏丹奥尔汗统治时期（1326—1362年），阿索斯修士因拜占庭破坏性的内战而灰心，断定君士坦丁堡不久便会落入奥斯曼人之手，于是派使者前往奥斯曼首都布尔萨（普鲁萨），请求苏丹保护。奥尔汗欣然答应，确认其地产所有，并授予进一步特权。穆拉德一世统治时期（1362—1389年），奥斯曼人将首都从布尔萨迁至埃迪尔内（阿德里安堡），阿索斯修士再次遣使，请求重新确认。虽然没有存世奥斯曼文书可以证实这一传统，它却保存了一个有趣细节：奥尔汗在布尔萨颁发的原始文书，存于文书署，修士后来还能够取得<a id="pdf-178"></a><!-- PDF page 178; original page 157 -->抄本。[^p178-7] 即使尚未发现这类抄本，这一说法仍指向阿索斯山与奥斯曼宫廷之间持续的联系。

这一故事的母题，出现于不止一篇涉及奥斯曼苏丹与巴尔干正教修士早期关系的叙述。例如，它见于十五世纪初亚泽哲奥卢·阿里的编年史。不过，在那里，故事涉及的不是阿索斯修士，而是塞雷附近普罗德罗莫斯修道院的修士。他们比阿索斯修士更有远见，竟早在奥尔汗之父、奥斯曼国家同名创建者奥斯曼的时代，就预见了奥斯曼征服！他们来到其宫廷，恳求保护，并获得一份敕令。[^p178-8] 然而，这纯属传说，因为奥斯曼在位时，其势力仅限于比提尼亚边境，与塞雷附近一座修道院发生联系的可能性微乎其微，实际上不可能。到了其孙苏丹穆拉德一世统治时，情况便完全不同。此时，奥斯曼已在色雷斯立足，以之为袭掠马其顿的基地。普罗德罗莫斯修士正是在这一背景下，首次同奥斯曼人建立关系；穆拉德一世于1372—1373年颁给他们的一份文书，证实了这一点。这似乎是苏丹首次为该修道院颁发文书，因为其中并未提到穆拉德一世效法父亲或祖父施恩于修道院，而按奥斯曼文书署的惯例，通常会作此说明。例如，穆拉德的孙子穆萨·切莱比和穆罕默德·切莱比向修道院授予权益时，就明确说，他们是在确认祖父给予修道院的特权。[^p178-9]

另一例可见于穆拉德一世在1386年确认帖撒罗尼迦附近一项提马尔领地授予的文书。它指明，最初由穆拉德之父奥尔汗，将领地赐给现有持有人之父。此人出身塞尔维亚贵族家庭，与阿索斯山圣保罗修道院关系密切。[^p178-10] 这一点本身，也进一步支持了如下看法：早在奥尔汗时代，阿索斯修道院与奥斯曼宫廷之间便<a id="pdf-179"></a><!-- PDF page 179; original page 158 -->开始建立联系。

如果回想十四世纪上半叶爱琴海的形势，这一推测便更为可信。阿索斯山多次遭土耳其人海上袭击；这些人未必是奥斯曼人，更可能来自爱琴海沿岸的各个埃米尔国，因为与奥斯曼不同，它们拥有小型舰队。有些修道院被洗劫、严重破坏或废弃，有些几乎永久消失。大量修士被俘，另一些则寻找新的地方继续灵性生活。在一次毁灭性袭击后，杰出的阿索斯神学家格里高利·帕拉马斯曾计划逃往耶路撒冷，最终却迁入防守坚固的帖撒罗尼迦。另一位杰出修士阿塔纳西奥斯永久离开阿索斯，在色萨利内陆创建了迈泰奥拉诸修道院；那里当时仍被认为超出土耳其人的袭击范围。[^p179-11]

约1350年，情况发生变化，此后土耳其人袭击阿索斯山的次数显著减少。同时，阿索斯山进入复兴繁荣时期：新修道院兴建，废弃或被毁的旧院则获修复、重新入住，如西蒙诺佩特拉和圣保罗修道院。迪奥尼修修道院建于1356至1362年之间，与此同时，库特卢穆修和卡斯塔莫尼图修道院得到重建。[^p179-12] 此时，阿索斯修道院已能在君士坦丁堡获得附属院。例如，首都的普西霍索斯特里亚修道院，转归瓦托佩迪修道院控制。这一转让的原因颇有启发性：一座繁荣的阿索斯修道院，正在救助一座贫困的首都修道院。[^p179-13]

这反映了阿索斯山命运的好转，但应如何解释？综合可能性，最合理的推测是：阿索斯修士与奥斯曼统治者奥尔汗达成协议，使各院获得一定保护。牧首菲洛塞奥斯提供了间接佐证。在一篇不晚于1360年写成的讲道中，他说，连那些不认识<a id="pdf-180"></a><!-- PDF page 180; original page 159 -->耶稣基督的异教徒——显然指土耳其人——都尊重、钦佩神圣修士辉煌的德行。原因之一，是修士善待一切在阿索斯寻求庇护，或因海难漂至岸边的人，无论希腊人、蛮族还是异教徒。牧首描述，修士毫不吝惜地为这些被迫来访者提供食物、衣服和住处，帮助修船；若船只已失，则提供装满物资的自有船只。[^p180-14] 阿索斯修士救助的对象包括土耳其人，这再次表明，在苏丹奥尔汗时代，阿索斯山与奥斯曼人之间存在友好关系。修士与奥斯曼统治者之间可能的调停者，是皇帝约翰六世·坎塔库泽诺斯（1347—1354年）。他不仅与阿索斯山联系极为紧密，还成为奥尔汗的岳父。[^p180-15]

另一个因素，是静修主义的胜利；1351年，在约翰·坎塔库泽诺斯主持下，布拉赫奈会议确认了这一胜利。它加强了阿索斯山在拜占庭及各正教民族中的灵性优势。其结果之一，是大量新修道院建立，吸引来自整个正教世界的修士。虽然创建这些修道院的动机主要是灵性的，物质考虑也在其中。阿索斯相对安全、较少遭土耳其袭击，越来越吸引捐献者。其灵性声望同样吸引奥斯曼统治者。正如我们所见，保护圣者和修道院，是他们伊斯兰义务的一部分；他们也不会看不到，这还是使基督徒臣民接受新主人的一种方式。静修者的避世态度，意味着修道生活从未成为正教抵抗奥斯曼向南巴尔干推进的中心。静修领袖格里高利·帕拉马斯定下了这一基调；他在1354年落入奥斯曼人之手，在奥斯曼宫廷受到礼遇，留下极佳印象，尽管他从未像敌人暗示的那样提倡合作。[^p180-16]

有必要确定，阿索斯修道院究竟多早便与奥斯曼人建立密切关系，因为这保证了这一备受尊崇的宗教中心延续存在。在<a id="pdf-181"></a><!-- PDF page 181; original page 160 -->拜占庭国家为生存而挣扎之时，阿索斯各院因同奥斯曼建立了共处安排而繁荣。向修道院捐赠地产的数量，不仅没有下降，反而有所增加。这些捐赠往往与其说是虔敬行为，不如说是一种保产方式：把财产置于与未来征服者具有特殊关系的修道机构保护之下。1371年马里查战役之后，土耳其武士不断涌入整个马其顿和南巴尔干，这一需要尤为迫切。[^p181-17] 塞尔维亚领主拉多斯拉夫·赫拉彭的家族史，很有启发性。他统治埃德萨（沃德纳）与贝罗亚，与沙皇斯特凡·杜尚（1331—1355年）有亲缘关系。[^p181-18] 他的地产并未直接交给阿索斯修道院，但继承人确保其领地内的宗教机构转归阿索斯控制，认为这样便能保护院产免遭土耳其袭掠。1375年，他的一名女儿及其丈夫、后来成为约阿尼纳专制公的托马斯·普雷阿林博斯，将埃德萨的加巴利奥蒂萨圣母教堂捐给大拉夫拉修道院，连同村庄、田地、园圃、商店、水磨，以及手稿、圣像、教会银器等动产；他们希望，归属阿索斯修道院，能够避免其沦为土耳其人的掠物。赫拉彭的另一名女婿、色萨利统治者凯撒阿莱克修斯·安格洛斯，在承认苏丹穆拉德一世的宗主权后，于1389年将帖撒罗尼迦的小修道院圣佛提斯，授予同城规模大得多的新修道院。然而，新修道院连同圣佛提斯，很快又归大拉夫拉所有。[^p181-19] 这清楚说明，在奥斯曼征服所创造的条件下，财产如何向阿索斯各院集中。

拉多斯拉夫·赫拉彭及其家族，与阿索斯山还有另一重联系。1356至1366年之间，其亲属安东尼奥斯·帕加塞斯退居圣山，购入并修复了已成废墟的圣保罗修道院；他剃度后取修名阿尔塞尼奥斯，最终成为院长。1385年，他的兄弟尼古拉斯·鲍德温·帕加塞斯，将位于<a id="pdf-182"></a><!-- PDF page 182; original page 161 -->埃德萨附近的梅索内西奥蒂萨修道院，连同其村庄、教堂和其他财产，捐给圣保罗修道院。对土耳其人的恐惧发挥了作用，因为埃德萨就在该年陷于苏丹穆拉德一世。这解释了鲍德温为何希望未来领主，无论基督徒还是穆斯林，都尊重捐赠行为，也透露了其不安处境。显然，他把梅索内西奥蒂萨及其财产交给阿索斯山上的兄弟，是在绝境中试图保护修道院，使其免受当时形势冲击。同一策略也见于较低社会阶层：少数尚存的自耕农中，有人将地产出售或捐献给阿索斯修道院。

有些人向阿索斯各院捐赠地产或钱款，金额常为约100枚海佩尔皮隆金币（hyperpyra），条件是换取每年收入。这种安排属于早已存在的终身供养制（adelphata），但在此时期获得新特点：例如，它成为一种可以为姐妹、儿子等第三人作出的投资。[^p182-20] 修道院所提供的，类似现代所谓年金。款项常以实物支付，对修道院更加有利，因为这为处置农业剩余提供了有利可图的途径。

许多人为了躲避连绵战争的苦难，到阿索斯定居，使修士数量增加。一次破坏性土耳其袭击后，圣涅克塔里奥斯之父带着两个儿子退入修道院；圣菲洛塞奥斯及其兄弟被征入耶尼切里军团，后来奇迹般获释，也在修道院避难。[^p182-21] 修士从受奥斯曼征服威胁的巴尔干各地前来，讲着不同语言，多数为斯拉夫语的某种变体，加强了阿索斯的民众性与跨地域性质。[^p182-22] 斯特凡·杜尚时代，塞尔维亚人在圣山的存在更为显著，挑战了希腊人的主导地位。1356至1371年，阿索斯由被称为“塞尔维亚首席长老”（Servoprotoi）的人管理。[^p182-23] 然而，塞尔维亚影响力在<a id="pdf-183"></a><!-- PDF page 183; original page 162 -->1371年马里查战役后下降；土耳其人在该战击败了塞尔维亚首领、创建西蒙诺佩特拉修道院的约翰·乌格列沙及其兄弟武卡申。

1420至1422年间，意大利人文主义者克里斯托弗罗·布翁德尔蒙蒂到访圣山；从其热情赞颂来看，当地修道生活组织得十分完善。这位佛罗伦萨教士记录了阿索斯各院修士人数之众，赞赏其生活方式。有些人在和平宁静中共住，有些人则完全独居，昼夜祈祷。[^p183-24] 不久后的1423年，阿索斯正式归于奥斯曼宗主权。契机是专制公安德罗尼科斯·巴列奥略将帖撒罗尼迦及其地区交给威尼斯；阿索斯修士拒绝接受拉丁主人，宁愿置身苏丹穆拉德二世（1421—1451年）的统治。[^p183-25] 然而，如果相信1444年11月短暂到访的古物学家安科纳的奇里亚科，这次易主丝毫没有干扰圣山的繁荣。瓦托佩迪、大拉夫拉和伊维龙的教堂及修道建筑之宏伟，给他留下深刻印象；丰富的修道院藏书令他惊叹，也激起了收藏者的贪欲。趁伊维龙院长恰好出使奥斯曼宫廷之际，他从一名可敬修士处取得普鲁塔克《道德论集》的抄本，为自己的成功颇感得意。[^p183-26]

即使在1453年之后，阿索斯各院仍为拜占庭贵族提供了安度余生的好地方。[^p183-27] 但并非所有加入修士行列的人，都为了圣洁氛围而来；也有人把它视为藏存钱财的手段。他们的活动有时引起奥斯曼法庭注意。一个著名例子是拉迪奇，他是塞尔维亚专制公斯特凡·拉扎列维奇的大切尔尼克，即总司令；后者于1427年去世后，他又为其女婿兼继承人乔治·布兰科维奇效力。[^p183-28] 拉迪奇为后者服务不久，约在1433年后便决定退居阿索斯；在“奥斯曼和平”保障当地秩序与稳定之时，塞尔维亚却正<a id="pdf-184"></a><!-- PDF page 184; original page 163 -->经历动乱：1427年斯特凡·拉扎列维奇去世，带来继承问题和匈牙利人的干预。拉迪奇在卡斯塔莫尼图修道院出家；他到达时，修道院被火灾毁坏，几乎荒废。由于其慷慨资助，修道院获修复、重组。他的其他赠产包括塞尔维亚一座银矿收入的份额；他也向瓦托佩迪和圣保罗修道院捐赠。其例表明，显要修士可以从安全的阿索斯山维护世俗利益，因为他如今已是奥斯曼苏丹的非穆斯林臣民，即齐米（dhimmī）。

拉迪奇显然能够把流动资产转移到阿索斯山。他对雅库布和迪米特里·耶雷米亚奥卢兄弟提起的一场诉讼，透露了这些资产的规模与构成。两兄弟曾在他那里存放35,000枚银币和6,000枚金币的巨款，以及数件金银器物。他后来归还这些财物，但据称，两兄弟又向他勒索1,000枚弗罗林金币，因此他求助奥斯曼法庭。拉迪奇以阿索斯的安全为掩护，开展银行业务。卡斯塔莫尼图修道院防守坚固，且受苏丹保护，[^p184-29] 是存放巨额钱款的好地方。

由于退居阿索斯，拉迪奇保全了巨额财富。这里也便于结交奥斯曼高官，如鲁梅利亚军事总督（beglerbegi）希哈布丁帕夏。他与之联系，以保护自己在新布尔多的利益，包括住宅和银矿。希哈布丁帕夏正是1441年征服新布尔多的奥斯曼军队统帅。拉迪奇提出，既然自己因居于阿索斯而成为苏丹的非穆斯林臣民，那么地产和银矿收入，都不应因奥斯曼征服受到影响。帕夏保证保护其收入，并答应将住宅财产问题提交苏丹议政会议。拉迪奇这类人物的存在，有助于解释，为何在拜占庭最后几个世纪及奥斯曼统治下，允许修士拥有私产的自律制，在阿索斯兴盛，共住生活方式则相对衰落。

另一个案例，揭示了阿索斯修道院的银行活动。它涉及末代塞尔维亚专制公拉扎尔·布兰科维奇之女马利亚—海伦娜。她是摩里亚专制公<a id="pdf-185"></a><!-- PDF page 185; original page 164 -->托马斯·巴列奥略的外孙女，也是波斯尼亚末代国王斯特凡·托马舍维奇的遗孀；其丈夫在1463年国家被征服后，为奥斯曼人处死。当时她只有17岁。她最后在奥斯曼领土内，与两位姑母同住：苏丹穆拉德二世遗孀玛拉·布兰科维奇，以及采列伯爵夫人卡特琳娜·坎塔库泽娜。两位姑母去世后，马利亚—海伦娜继承其财产，却难以追索，因为她们向阿索斯多座修道院作了遗赠；玛拉与这些修道院关系尤其良好。为了取回自认应得之物，马利亚—海伦娜诉诸伊斯兰法庭，指控克塞罗波塔穆修士持有30,000枚金币。据称，这笔钱由采列伯爵夫人的亲信仆人阿纳斯塔斯从女主人处取走保管，他后来成为该院修士。马利亚—海伦娜指控，阿纳斯塔斯死后，修士仍扣留本应归她的钱。然而，她完全无法证实指控。[^p185-30] 尽管如此，此事说明，一座阿索斯修道院可能存有何等惊人的巨款。远在十六世纪中叶之前，修道院充当储蓄银行，已是众所周知的事。1545年，苏丹苏莱曼罢免瓦拉几亚沃耶沃达拉杜尔，很快便传出后者已将巨额财宝送往阿索斯的消息。苏丹立即命令帖撒罗尼迦的桑贾克长官及卡迪法官，查出财宝，收回国库。[^p185-31]

在奥斯曼统治下，阿索斯各院因信众持续捐赠而扩大地产；它们通过终身供养制，将农业剩余换成现金，并作为存款场所。经营活动的另一个方面，是积极参与航运。阿索斯修道院的古老版画反映了这一点，常描绘船只驶近修道院船坞；部分修道院确实设有船坞。[^p185-32] 拜占庭时期，若干修道院拥有商船，实际从事出售农业剩余产品的业务，名义上却用于为修士运送食物，借此证明<a id="pdf-186"></a><!-- PDF page 186; original page 165 -->拜占庭皇帝授予税收豁免的合理性。[^p186-33] 多希亚里乌修道院的朝圣指南中，有一则可能上溯十一世纪的奇迹故事，[^p186-34] 显示修士为了把贸易呈现为蒙上帝祝福的事业，可以费多大心力。依故事，一艘载满院产谷物的多希亚里乌船只，在返航阿索斯途中被狂风吹至北非迦太基，当地正遭严重饥荒。修士卖掉部分货物，其余换成香料。回程时，逆风又将他们吹至君士坦丁堡；他们在那里出售香料、购买面包，而另一个奇迹确保面包到达修道院时仍是热的。奥斯曼统治下，已无须编造这种故事，因为修道院对自有船只开展贸易毫不隐讳，并为此获得部分关税豁免。[^p186-35]

阿索斯修道院的海运和商业活动，自拜占庭时期就很重要。拥有商船，带来取水或避风所需安全港口等实际问题。早在十世纪，大拉夫拉便未雨绸缪，从当时的拜占庭皇帝那里获得两座具有战略位置的岛屿：利姆诺斯附近的圣欧斯特拉提奥斯，以及优卑亚附近的吉姆诺佩拉盖西翁，亦称卡洛耶罗斯。

奥斯曼统治下，阿索斯各院似乎更重视河运，也许反映了其巴尔干利益的发展。早在十四世纪中叶，土耳其人以袭掠蹂躏马其顿之时，大拉夫拉的船只便已往来斯特里蒙河。[^p186-36] 这必定又是与奥斯曼人友好关系的一项迹象，因为没有其默许，沿河贸易便不可能进行。

卡斯塔莫尼图的塞尔维亚赞助者拉迪奇，捐给该院一艘在塞尔维亚摩拉瓦河营运的船。这是<a id="pdf-187"></a><!-- PDF page 187; original page 166 -->他同时捐给修道院的附近银矿收入份额所不可缺少的配套。[^p187-37] 这艘船是否沿多瑙河长途航行、进入黑海，再经海峡抵达阿索斯，看来不大可能，但也并非绝无可能。毕竟，很难想象修士会把塞尔维亚银矿产出的大量原银，囤积在修道院库房中。这艘船更可能在较近的地方贸易。我们知道，威尼斯人从杜布罗夫尼克取得巴尔干白银，[^p187-38] 贝尔格莱德也是另一出口地。阿索斯修道院似乎更愿同土耳其人交易。

阿索斯虽强烈反拉丁，却仍设法获得教廷在爱琴海水域代表——罗得岛医院骑士团——的某种保护。现知最早由罗得岛骑士团大团长颁发、允许私掠异教土耳其人及其臣民船只的许可证，另加一条规定：圣山（Mons Sanctus）正教修士的船只，应予例外。[^p187-39]

阿索斯经济的发展，以及随之提升的声望，反映在十六世纪中叶若干修道院开展的新装饰工程中。从1535年起，此后三十年，壁画艺术蓬勃发展，多位画家受邀为教堂、小堂和食堂绘制壁画。克里特的狄奥法内斯·斯特雷利察斯及其两个儿子，为大拉夫拉教堂和食堂（1535年），以及新建的斯塔夫罗尼基塔修道院同类建筑（1546年），绘制了优秀壁画；另一位克里特画家基尔·乔尔齐斯，装饰了迪奥尼修教堂；色诺丰修道院主教堂也绘上壁画（1544年）；来自底比斯的弗兰戈斯·卡特拉诺斯，则在大拉夫拉一座小堂的墙上留下美丽壁画（1560年）。[^p187-40]

这一繁荣在1568—1569年突然终结：苏丹塞利姆二世没收了帝国内全部修道院的地产，当然也包括阿索斯山。他听从了埃布苏乌德（Ebu’s-su‘ud）的建议，后者自1545年起担任帝国司法体系最高职位，即谢赫伊斯兰。这位人物年少时便于巴耶济德二世统治时期（1481—1512年）开始仕宦，先后效力四位苏丹，任职六十余年，被视为奥斯曼最伟大的法学家之一。他<a id="pdf-188"></a><!-- PDF page 188; original page 167 -->认真致力于将奥斯曼法律系统化、重新表述，使之更加符合伊斯兰传统。其努力主要集中于塞利姆二世之父、“立法者”苏莱曼统治时期（1520—1566年）；当时帝国正值鼎盛，需要为迫切的法律问题提供明确解决。[^p188-41] 某些问题涉及苏丹非穆斯林臣民的生活。埃布苏乌德指出，基督教修道院对地产并无合法权利，因为乡村土地属于统治者，不能为教堂和修道院的利益而使用。塞利姆二世实施其谢赫伊斯兰的神学解释，也有自身理由：没收院产，可以满足行政机构提出的预算需求。此时，他正准备远征威尼斯属塞浦路斯，需要额外财源。[^p188-42]

没收对修道院和教会当局都是严重打击。不过，仍有一条可利用的出路：他们可以赎回建筑、畜群，以及伊斯兰法认为适于私人所有的其他财产。地产问题更为微妙，因为严格说来它属于苏丹；修士获准保留、经营，但须在各项土地税之外，缴纳特别税。他们也可以保有其他财产，但条件是将其用于慈善，以及救济贫民和旅人。

塞利姆二世以修士逃税、侵夺农民土地以扩张院产的手段，作为没收阿索斯地产的部分理由。换言之，他们对某些地产的权利，本就存在不确定性。赎回院产后，修士不出所料地卷入一系列财产纠纷。这成为牧首耶利米二世（1572—1595年）的一项重大关切；他派亚历山大里亚牧首西尔维斯特前往阿索斯恢复秩序，并据此次使命，以牧首敕书形式颁发阿索斯各院院规。它实际上是一项改革圣山修道生活的方案，建议居首位的大拉夫拉恢复共住生活。牧首希望<a id="pdf-189"></a><!-- PDF page 189; original page 168 -->其他修道院效法，但这一倡议只取得有限成功。[^p189-43]

塞利姆二世没收阿索斯地产，标志着圣山历史的分水岭，结束了其两个多世纪的繁荣与声望。1541年斯塔夫罗尼基塔创建之后，再无重要的新修道院建立。此后，阿索斯修士有赖于摩尔达维亚和瓦拉几亚正教沃耶沃达的慷慨；从奥斯曼国家赎回院产所需的大部分款项，都由他们提供。圣山另一重要赞助者是莫斯科沙皇。十六世纪初，双方发展出更密切的文化联系；1589年俄罗斯牧首区建立后，联系进一步加强。[^p189-44] 这些正教统治者的支持，代表了“拜占庭共同体”长久的遗产，而阿索斯山曾是其中至关重要的中心。
