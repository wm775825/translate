# 第14章 俄罗斯帝国时期的俄罗斯东正教会（1721—1917年）

西蒙·迪克森

在革命动荡的压力下，彼得一世于1721年建立的俄国教会治理体制，在1917年迅速瓦解。8月5日，临时政府废除神圣宗务院。十天后，全俄教会会议在莫斯科召开，希望在危难时期确保强有力的领导。代表们在布尔什维克夺权前，已经决定恢复牧首制；11月5日，他们从选举产生的三人候选名单中抽签，选定吉洪都主教（别拉温），填补自1700年以来无人担任的职位。环境迫使吉洪忙于应付危机，无法作战略指导；但会议仍有许多实际重要问题可讨论。宗务院不仅保有婚姻与离婚管辖权，还一直管理自身的教区宗务法庭、教会学校及宗教书籍审查。[^p346-1] 然而，很少教会人士满足于单纯行政自治。[^p346-2] 许多人相信，彼得强行把世俗与神圣领域分开，扭曲了教会本质，使它陷入弗洛罗夫斯基后来所谓“巴比伦之囚”的时期：俄国“教会意识”被迫在“行政命令与内在恐惧的双重束缚”中发展。[^p346-3]

近来历史学家希望解释而非谴责，利用前所未有的档案开放机会，修正了许多传统刻板看法。新证据既然表明，把<a id="pdf-347"></a><!-- PDF page 347; original page 326 -->俄国教会斥为“停滞、腐败而思想贫瘠”，具有多大误导性，[^p347-4] 那么，理解这个远非铁板一块的机构，为何如此难以回应羊群的属灵需要，就更为重要，某种程度上也更加困难。神职人员社会构成等发展，固然不可避免地反映世俗改革与反改革模式的变化，[^p347-5] 本章却将指出，教会变化的主要动力，在于从俄国多民族帝国内外推动的复杂宗教竞争潮流。教会对这些挑战的回应，给自身使命造成的困难，并不亚于国家强加的限制框架。

## 宗务院体制的第一个世纪

如同其父，彼得一世（1682—1725年在位）试图削弱教会政治权力，利用其物质财富。他比阿列克谢·米哈伊洛维奇（1645—1676年在位）更有抱负，把宗教视为训练理性、勤勉臣民的工具。沙皇的战略虽始终明确，策略却有变化。1700年10月16日阿德里安牧首去世；此时距8月19日对瑞典宣战不久，距11月19日俄军在纳尔瓦战败还有一个月。彼得趁机暂时掌握修道院收入，并任命经验不足的乌克兰人斯特凡·亚沃尔斯基为牧首座署理。当时并未提出应废除牧首制，但显然希望斯特凡成为彼得的人。沙皇自大使团出访归来，提拔乌克兰人，不只是因为他们受过西方教育、能够驱散莫斯科的无知，也为削弱可能不忠的本土主教团。不过，斯特凡并非傀儡：1708—1712年，他写下、有时也宣讲公开批评沙皇的讲章。彼得这些年忙于战争，甚少顾及教务。1715年虽重新关注，直到1718年皇太子受审，才击溃多数期待沙皇死后恢复牧首制的反对者。如今，彼得在乌克兰人费奥凡·普罗科波维奇指导下，走向正式废制。费奥凡反对自己在罗马所受的耶稣会教育，转而推崇君主在教会中的崇高作用。这与彼得1698年在英国同<a id="pdf-348"></a><!-- PDF page 348; original page 327 -->吉尔伯特·伯内特主教交谈时首次听到的新教论证，有某些共通之处。1718年末受委托由费奥凡起草、1721年1月25日公布的《宗教规章》（Dukhovnyi reglament），主张合议体制比牧首制更适合俄国情形，因为牧首可能被误认为“某种第二君主，与专制君主本人同等，甚至更高”。2月14日首次会议上，彼得新设的宗教委员会改称“至圣治理宗务院”（Sviateishii Pravitel’svuiushchii sinod），意在同时呼应旧牧首的属灵光环，以及元老院的司法权威。新机构的“总主教主席”斯特凡·亚沃尔斯基并不信服，成为最早质疑其教规合法性的人之一。他试图保留礼仪中对东方牧首的提及，却未成功；自阿德里安去世以来，俄国教会名义上一直效忠这些牧首。[^p348-6]

宗务院领导层分裂，机构尚在萌芽，落实地方政策的能力也不比世俗权力更强，因此确立权威需要时间。1722年设立的平信徒总检察官，其影响随任职者能力而起伏。直到1740年代，惩治“迷信”的措施，[^p348-7] 才被改造成积极教导民众宗教的运动；也直到此时，宗务院才以日益标准化的官僚程序为基础，加强对教区行政的控制。[^p348-8] 该世纪中叶的成就，为新一代主教在叶卡捷琳娜二世统治期间（1762—1796年）的发展，提供平台。如同世俗领域，各省进展仍然参差不齐；改善神职表现所投入的力量，有时如此猛烈，以致难以否认主教专横的指控。[^p348-9] 然而，普拉通·列夫申和加夫里尔·彼得罗夫等高级教士，起初以讲道打动女皇，也部分认同她的启蒙改革追求，愿以同样理性的语言表达。[^p348-10] 1770年代末，普拉通短暂积极主持莫斯科教区事务，<a id="pdf-349"></a><!-- PDF page 349; original page 328 -->不仅清除了旧都令人头痛的流浪神职人员，也在这一过程中引进一个有争议、延续至1917年的职务：“良好秩序维护者”（blagochinnye，即教务督察）。这些受任命的监督者，取代选举产生的教士长老，成为教区宗务局的主要地方代理者。[^p349-11] 清除额外编制司祭的同时，留下者的素质提高了。普拉通重视神职教育，帮助经费不足的初级文法学校转型为专门神学院；全帝国入学人数，从1766年的4673人，增至1808年的29000人。俄国堂区司祭虽受教师粗暴对待，因深浸拉丁学问的课程而与羊群隔离，又因社会地位低微而贫困，专业准备却比以往更充分。[^p349-12]

启蒙时代或许使俄国教会在行政上更强大，但它的宗教宽容遗产更为复杂。伊丽莎白在位期间（1741—1761年），曾坚决打击因其父彼得一世时期迫害而形成的分裂教会共同体。教会与国家也共同发动改宗运动，1741—1755年间，使约43万人归入正教，绝大多数是伏尔加河中游的莫尔多瓦族（Mordvins）、楚瓦什人、切列米斯人及沃佳克人。[^p349-13] 然而，当人们发现，地方热忱者唯有使用上级从未打算采用的暴力，才达成目标时——19世纪将再度出现这一模式——这些举措是否明智，便受到质疑。叶卡捷琳娜二世治下，国家利益与启蒙信念结合，产生较温和的传教方式。南部新兼并领土的穆斯林，受到极为谨慎的对待。流亡的分裂教会成员，获准从波兰返回。怀疑宽容的教士虽然力图阻碍其影响，[^p349-14] 旧礼仪派仍于1782年获免双倍人头税，三年后又确认拥有选举、以及被选为城市官员的权利。1780年代，人们希望一种新的“同信制”<a id="pdf-350"></a><!-- PDF page 350; original page 329 -->（edinoverie），即允许旧礼仪派保留自身仪式，只须承认教会权威，能够使他们回归羊群。但到1818年，菲拉列特·德罗兹多夫已是担忧此事的主教之一：他们害怕，旧礼仪派反而利用长期相对平静，扩大人数与力量，到了足以“诱使”正教徒加入分裂教会的地步。[^p350-15]

菲拉列特是新思想潮流的主要代表，试图藉恢复使徒根源，并以独特俄国方式重述教导，来加强教会。[^p350-16] 对西方学术采取批判态度，经历了近六十年才形成。1760年代首先受到冲击的是乌克兰主教；苏马罗科夫把整个神职群体据称采用“不正确的地方方言”，归咎于其“可耻”影响。[^p350-17] 然而，俄国都主教普拉通仍要求正教学校用拉丁语授课，以维持教会在西方的学术声望；本地语言直到1808年以后才逐渐引进。要到1820年，叶夫根尼·博尔霍维季诺夫谴责费奥菲拉克特·戈尔斯基的神学，才成为典型态度。后者于1784年在莱比锡以拉丁文出版；前者指责它“在外国人面前，不仅使自己，也使整个俄国教会蒙羞”，因为“整页整页抄自路德宗神学家！！！”[^p350-18] 对外国学术的反感，与对时髦神秘主义的敌意日增相伴。亚历山大一世时期（1801—1825年），这种神秘主义在普遍基督教的框架下，模糊宗派区别。A. N. 戈利岑亲王宗教世界主义的象征，是1813年成立的俄国圣经公会，九年后便被废除。到此时，外国影响遭受前所未有的正教压力：耶稣会1815年被逐出圣彼得堡与莫斯科，1820年被禁止进入帝国；1822年，共济会与其他秘密团体一同遭镇压；该年代稍后，西伯利亚的英国传教事业受到<a id="pdf-351"></a><!-- PDF page 351; original page 330 -->正教教区当局敌意监视，大多于1830年代关闭。俄国教会不再满足于在自己的帝国内成为同侪之首，而希望居于主导；但按自身条件主导，始终难以实现。

## 其他信仰的挑战

表面看来，尼古拉一世时期（1825—1855年），是正教积极复兴的阶段，以教区扩张及国家支持的改宗运动为标志。过程从需要似乎最大的西部开始：1830年波兰起义之后，合一教会于1839年正式与正教“重归统一”。1840年代中期，又出现一波活动。自1843年起，未满18岁的五万名犹太新兵成为大力传教的对象，到1855年，约一半在军队中受洗。1845年，奥伦堡地区约八百名信奉异教的马里人受洗。在1836年建立的里加教区，菲拉列特·古米列夫斯基任主教期间，至少74000名拉脱维亚人及爱沙尼亚人，于1845—1847年归入正教。[^p351-19] 下个十年，1842年建立的喀山神学学院，成为N. I. 伊利明斯基教授传教事业的中心，用伏尔加与乌拉尔地区穆斯林儿童的母语，教导他们基督教。[^p351-20]

不能轻易否定这些运动。许多鞑靼人受洗时，对新信仰了解甚少；但其后代的基督徒身份仍十分牢固，足以在1920年代给苏维埃当局造成难题。[^p351-21] 然而，某些“改宗”出于暴力，或最终难以兑现的物质好处承诺，许多并不真诚：俄国人至少又在1875年和1946年两度庆祝合一教会“终结”，而该教会在本书撰写时仍很兴盛。同样令人不安的是，人们愈发感到，教会的其他宗派对手像旧礼仪派一样，力量充足，不仅可以维持自己的<a id="pdf-352"></a><!-- PDF page 352; original page 331 -->宗派身份，甚至足以诱使无知的俄国人，即使未公然背教，也陷入暗中侵蚀的错误。

因此，当过度的教士热忱引起社会骚乱，国家便撤回对正教劝人改宗的支持，教会不免感到不安。1848—1861年任波罗的海诸省总督的A. A. 苏沃洛夫亲王，公开不敬正教教士，甚至派兵包围里加主教府，阻止菲拉列特·古米列夫斯基进一步使人改宗。亚历山大二世秘密决定，解除混合婚姻中路德宗一方必须把孩子按正教施洗的义务；1865—1874年间，因此有三万至四万爱沙尼亚人和拉脱维亚人重返路德宗。[^p352-22] 只有在克里米亚，人们接受鞑靼人构成安全风险的看法。1852年，因诺肯季·鲍里索夫从那里抱怨，“占统治地位的宗教，在许多情况下只是名义如此”，因为“实际权利”掌握在“外来信仰，甚至非基督徒”手中。1856年关于清洗的传言，使随后十年间至少五十万、或许九十万穆斯林迁往奥斯曼帝国。[^p352-23] 别处主教则发现，1860与1870年代的省长愿为教会对手提供一定保护；有的是为维持和平，如外贝加尔；有的如突厥斯坦的米哈伊尔·冯·考夫曼，则把宗教视为私人领域事务。[^p352-24] 动荡时期，连分裂教会的旧礼仪信仰，也开始被沙皇政权视为保守价值的宝库，于是通向更广泛宽容的道路打开了。

教会机构过度扩展，把更适合学术生活的人推向充满敌意的边疆，或“染上”教会分裂的教区，主教们只能痛悔其后果。菲拉列特·古米列夫斯基于1842年抱怨：“〔里加〕一切都是异己，而我称为自己所有的一切，都在远方。”[^p352-25] 1865年，列昂季·列别金斯基从波多利亚写道：

“若上帝愿我留在这里，我就有责任反对邪恶。”但他丝毫不掩饰自己与波兰人“斗争”的苦闷。[^p353-26] 人们筹集巨款，把1837年从圣巴西略修会手中夺回的沃里尼亚波恰耶夫大修道院等地标，改造为一望可知的正教圣地。但大多数新教区，为其领袖提供的住宿明显低劣。1858年，著名苦修者伊格纳季·布良恰尼诺夫抵达斯塔夫罗波尔时宣称：“这处极其简陋不适的居所，破败至使主教完全无法居住。”[^p353-27] 如果这些抱怨只是列斯科夫《主教生活琐事》中所嘲笑的主教派头，便几乎不值得强调。但它们意味着更重要的事。许多重要教士孤立、缺乏安全感，又受到从日本到圣地等远隔各处俄国传教区悲观报告的打击，因而深信：即使在俄国本土，正教也濒于危险。

## 思想上的回应

为了加强教会，学者进一步推进菲拉列特·德罗兹多夫开始的探索，寻找真正的俄国正教。到1880年代，这一探索凝结成具有鲜明宗派性的“教会意识”（tserkovnost’），[^p353-28] 来自莫斯科、基辅、圣彼得堡及喀山神学学院的研究。第一步既是清除正教教导中的外来杂质，学生便受到鼓励，要“明确区分严格属于我们的，与一切理应与我们无关的”。[^p353-29] 依据1843年采纳的计划，作为主要第一手资源的教父文本被译出，与大量神学研究一起，发表于各学院学术期刊。根本学科是历史：它可以有效纠正对《圣经》的过度偏重；受益于当代德国的发展，技术上十分精细；又是旨在剥离层层非真实积累、寻求使徒根源的<a id="pdf-354"></a><!-- PDF page 354; original page 333 -->事业之理想工具。阿克顿勋爵或许未曾意识到，但这里确实有一种环境，历史“整整一代人都在侵入其他领域，把体系化为过程，并压过哲学”。[^p354-30]

然而，教会学者在某些方面成了自身成功的受害者。面对迅速累积的证据，界定正教独特性的尝试，失去最初清晰的焦点。编目工作既提供了安全避开哲学思辨的退路，也是有价值的研究准备——萨瓦·季霍米罗夫的宗务院图书馆及圣器库目录，三年中出了三版——[^p354-31] 但揭示的丰富内容令人难以驾驭，而且总可能还有更多有待发现。礼仪学者A. A. 德米特里耶夫斯基刚完成巴勒斯坦正教修道院手稿藏品研究，便开始考虑在西欧工作。[^p354-32] 1915年计划编辑斯拉夫语《圣经》“基本文本”的学者，提出考察约4300份《旧约》手稿。[^p354-33] 进一步工作的前景伸向无穷，得出确定结论的机会便愈发渺茫。多数正教学者无意中印证了特雷弗—罗珀的说法：任何学科的专家，“由于某种自然法则，都会日益深埋于自身教条的细枝末节”；但他们没有人会赞同，他宁要“富于成果的错误”、不要“毫无成果的准确”之偏好。[^p354-34] 俄国神学家若想“校正”礼仪书，就无法逃开教会分裂的阴影；那正是17世纪某些以“硕果”著称的错误所造成的。[^p354-35] 只要列举现有实践缺陷，仍被视为比提出改进更明智，犹豫与混乱便必然占上风。把《圣经》译为俄语的整个历史，可以概括为对错误的<a id="pdf-355"></a><!-- PDF page 355; original page 334 -->执著。自圣经公会瓦解以后，翻译一直充满争议；1841年发现G. P. 帕夫斯基未经授权的译本，又进一步损害其声誉。甚至1870年完成、距主要支持者菲拉列特·德罗兹多夫去世三年的官方版本，也不能免于不准确的指控。[^p355-36] 在正教应如何对待西方这一核心问题上，一位重要学者于1885年承认，尚未形成“任何确定纲领”。[^p355-37] 教会音乐的处境也不更清晰；作曲家尤里·伊兹韦科夫于1913年斥其为“矛盾观点、无法调和的思想，以及未经系统整理的积累所构成的一团乱麻”。[^p355-38]

更糟的是，神学研究所依的教父史料本身就充满分歧，必然引发争论，教会却找不到解决办法。各修会的竞争，曾是天主教改革的一项关键力量。正教不仅缺乏这种修会，其自称垄断真理的性质，也不利于意见多样。正如梅延多夫谈到较早时期时所写：“如果‘俄国’正教有什么特征，可以与拜占庭对基督教的理解形成对比，那就是俄国人紧张地关注，要保存从‘希腊人’那里接受的传统之每一字句。”[^p355-39] 因此，这项本质上富有创造力的事业，最大障碍是传统被认为不可改变；俄国学者试图捍卫它，却矛盾地不得不至少部分重新创造它。[^p355-40] 教义发展不被容许。早在1840年，A. N. 穆拉维约夫便把早期教会许多事尚“未确定”的处境，与自己时代“一切都已决定、分类并编目”相对照。他向牛津神学家威廉·帕尔默坚持说：“我们不可‘挪移地界’。我们如今不再生活在会议时代，彼时……事情还可以改变。”[^p355-41] 在<a id="pdf-356"></a><!-- PDF page 356; original page 335 -->这种气氛中，限制神学讨论的，与其说是世俗审查者，不如说是教士自己。斯拉夫派尤里·萨马林宣称：“正教没有体系，也不应有体系。”[^p356-42] 但依赖德国系统神学的俄国学者，很难在模仿与贬斥两极之间行进。他们的“驳斥神学”（oblichitel’noe bogoslovie），语调过于尖厉，以致引来弗拉基米尔·索洛维约夫针锋相对的回应：

> 你们神学院这种伪正教，与普世教会的信仰、或俄国人民的虔敬毫无共同之处；它没有任何积极成分，只有任意否定，是由先入为主的偏见滋养的论战之产物……因此，你们所有“正教”与整套“俄罗斯理念”，究其实质，都只是民族对教皇普世权力的抗议。但你们以谁的名义抗议？你们处境的真正困难，就起源于这里。[^p356-43]

## 牧灵上的回应

正教徒意识到自身学术不完备，仍打算以研究支持积极牧灵行动。1818—1821年宗务院的大型调查，确认了这种行动的必要，决定加强教会的教导职能（uchitel’stvo），以增加对一个主要不识字社会的影响。[^p356-44] 改善讲道，是明显的前进道路。年轻自由派尼古拉·屠格涅夫于1815年宣称，“没有比我们的讲章写得更好的了”，赞扬俄国主教的“天赋才智”及古典学问；但他又说：“不幸的是，我们很少有人读讲章。”[^p356-45] 只要多数讲章仍是精雕细琢的文学作品，而非简明训道，问题就很可能持续。尖刻的菲拉列特都主教于1833年问：“哪有一篇讲道长达七十页？又有谁会听到底？”[^p356-46] 讲道若要真正复兴，需要学者提炼真正正教的讲道学，需要主教鼓励<a id="pdf-357"></a><!-- PDF page 357; original page 336 -->教士掌握陌生活动，也需要司祭与羊群良好沟通。这些目标都无法迅速完成。让不称职的新手面对堂区信众嘲笑，或旧礼仪派资深经籍研习者（nachetchiki）的细密盘问，显然存在风险。但宗务院坚持激发牧灵投入，1840年代系统搜集神职表现资料。教会也日益关注当代社会问题，例如修道院院长费奥多尔·布哈列夫的著述，以及莫斯科期刊《正教评论》（Pravoslavnoe Obozrenie）。最重要的实际发展，出现于1880年后的城市。圣彼得堡积极行动的教士不满堂区进展缓慢；堂区里，往往难以说服教士承担额外负担。因此，他们于1881年成立“依正教会精神传播宗教与道德启蒙协会”，组织讲道团队，向城市人口传福音。该会从码头地区的 微小起步，发展至兴建自己的教堂，并积极到首都工厂及会堂传教。1887—1888年，约五万名工人参加遍布全城的161场讲座；到1904年，该会声称，六千场讲座已吸引总计两百万听众。[^p357-47]

人们也认为，讲道并不足够。1888年，安东尼·瓦德科夫斯基敦促圣彼得堡神学学院学生，“继续基督在人间的事业，向人显示生命的真正意义，帮助贫困者，医治悲伤的心，向囚徒宣告释放，使盲者得见，解放受苦者”。他指出，这些任务要求教士“少说多做”。[^p357-48] 安东尼言出必行，任主教期间始终亲自探访监狱。更多教士早已意识到，西方把罗马慈善的“丰饶”与俄国救济的“贫瘠”不利地相对照，因此认真尝试向穷人提供系统慈善。[^p357-49] 18世纪慈善事业核心的修道院施舍，<a id="pdf-358"></a><!-- PDF page 358; original page 337 -->已无法应付城市化的社会后果；批评行乞者认为，它“对当代条件而言过于理想化”。[^p358-50] 正如他们曾向西方寻求神学专长，把正教牧灵工作与当代新教及天主教实践相比较，也是自然之事。格莱斯顿在一项平行探讨中曾问：“较健全的体系，为什么不应享有那种组织的优势？较错误的体系，正是藉它从极度、近乎绝望的衰竭状态中恢复，至今仍能以大致平等的条件，至少同部分对手继续斗争。”[^p358-51] 基督教知识促进会（SPCK）及救世军，都曾吸引正教徒注意。但他们最终选择兄弟会（bratstva），以16世纪立陶宛及乌克兰为抵御拉丁教劝人改宗、捍卫正教而成立的组织为范本。这比1860年代建立、往往缺乏活力的堂区托管会，提供了更有成效的前路。圣彼得堡的亚历山大·古米列夫斯基神父，展示了可能取得的成就：1861年创办《基督徒精神》（Dukh khristianina）后，他又在首都最贫穷堂区之一“沙地”建立慈善团体。他对正教兄弟会的愿景，是“一个被基督之爱温暖、充满生命的正教徒基督徒联盟”，在这里成功实现，并广受欢迎。[^p358-52]

## 来自修道生活的推动

19世纪末，正教对其他信仰挑战的回应，虽仍有许多工作待做，已取得显著进展。然而，以神学研究为基础的牧灵举措，在教会内部始终不乏批评者。1840年，帕尔默在谢尔吉隐修院遇到一位修士，“反复说，祈祷与圣德比学问更有效”；当帕尔默提出教会两者皆需时，他给人的印象却是，“潮流早已过分流向知识培养”。[^p358-53] 帝国时期余下岁月，修道院提供一种<a id="pdf-359"></a><!-- PDF page 359; original page 338 -->不同的虔敬形式，与在俗教士的工作有别，有时还彼此竞争。

18世纪，人们几乎不会料到，俄国宗教复兴将乘着修道“圣德浪潮”而来。修道生活是《宗教规章》的主要打击对象；彼得直接继任者未曾缓和他对“无用”默观的敌意，男女修道人数遂从1724年的25207人，降至1738年的14282人，近乎减半。七年战争后财政急迫，促使叶卡捷琳娜二世于1764年没收修道院土地及农民，把反修道趋势推至逻辑终点。约496所俄国修道机构在这一过程中被废，其中136所为女修道院。[^p359-54] 除谢尔吉耶夫波萨德的圣三一大修道院、彼得一世在新都创办的亚历山大·涅夫斯基大修道院，以及莫斯科克里姆林宫楚多夫修道院外，女皇改革后，乌克兰以外仅余67所女修道院及319所男修道院，其中161所依新规章不获官方拨款。然而，低谷尚未到来。接下来的三十年，连剩余修道院有限的编制也难以填满。帝国公开不赞成入修道，加上莫斯科总领天使大教堂大司祭彼得·阿列克谢耶夫暗中攻击修道价值，阻碍志愿者立誓。阿列克谢耶夫是白衣教士的显要人物，急于损害普拉通都主教的声誉。[^p359-55] 如果波将金得逞，后果可能更严重。这位通晓神学的亲王，十二年前个人陷入危机时，曾引人注目地退居亚历山大·涅夫斯基大修道院；但在1786年，他主张全俄只需三所修道院供“普通修士”使用，其余应关闭，或改为医院、学校与救济院。[^p359-56]

这一阴暗图景，有助解释为何世纪之交，奥普季纳修道院仅住三位修士，其中一人还是盲者。[^p359-57] 然而，正是从卡卢加省这所修道院附属的隐修处，三位<a id="pdf-360"></a><!-- PDF page 360; original page 339 -->属灵长老（startsy）——列奥尼德·纳戈尔金、马卡里·伊凡诺夫，以及安夫罗西·格连科夫，后者为陀思妥耶夫斯基《卡拉马佐夫兄弟》中佐西马神父的原型——自1829年起，实现了“一种非正式的俄国文化重新整合，无论高层或底层形态，其方式都非帝国国家或知识分子所能效仿”。[^p360-58] 他们的灵感来自阿索斯山。帕伊西·韦利奇科夫斯基疏远基辅莫希拉学院传授给学生的经院哲学：“他们的灵魂内是黑暗与幽冥，舌上却有各样智慧。”[^p360-59] 他于1746年前往阿索斯山寻求属灵启迪，十七年后离去，在摩尔达维亚尼亚姆茨建立自己的修道院；1794年去世时，已吸引约七百位修士。其门徒从那里把静修传统的属灵指导传入俄国，启发许多19世纪杰出知识分子，从伊凡·基列耶夫斯基到列夫·托尔斯泰。[^p360-60]

长老对女性灵魂的关怀，只是俄国参与欧洲宗教女性化趋势的原因之一。有些女性最终获得足够圣德光环，能够提供自己的属灵劝导；[^p360-61] 但俄国多数修女出身平凡，志愿也朴素。个人动机往往不明，经济需要几乎肯定加重了许多农民女性献身上帝的属灵迫切感。运动规模毫无疑问。1850—1912年，男性修道人数，包括初学修士，从9997增至21201；但与女性从8533增至70453相比，这代表相对停滞。[^p360-62] 回应民众需求，叶卡捷琳娜二世在1764年世俗化后几乎立即批准第一批自主女性共同体。至1907年，已形成约217个，其中86个成立于1890年以后。1764—1894年建立的156个共同体中，三分之二最终成为正式女修道院；菲拉列特·德罗兹多夫领导的主教团，迟来地认识到，应该支持而非排斥这些有纪律、共同生活的典范。[^p360-63] 多数共同体规模不大，<a id="pdf-361"></a><!-- PDF page 361; original page 340 -->慈善活动也有限。然而，富裕创办人带来扩大活动范围的前景时，风险也随事业规模增加。1869年在莫斯科主教团支持下成立的弗拉德奇涅—波克罗夫仁爱姊妹共同体，不到五年便因债务崩溃；创办人米特罗法尼娅修女，原为普拉斯科维娅·格里戈里耶芙娜·罗森女男爵（1825—1898年），受到宗务院调查。[^p361-64] 有了这种丑闻，便可以理解，伊西多尔·尼科利斯基都主教为何阻止自己的追随者叶夫法利娅修女，把基辅附近的圣母入殿共同体改为女修道院；1885年，他也挫败了她想担任约五百位姊妹院长的愿望，理由是她“无法管理如此庞大的家庭”。[^p361-65] 尽管如此，下诺夫哥罗德举扬十字架女修道院等一贯管理良好的机构，仍极为成功，在快速工业化时期受益于地处俄国贸易路线中心。[^p361-66]

某些修道院虽以酗酒及不道德闻名，甚至促使沙皇本人于1901年发起宗务院调查，许多修道院直到旧政权终结，仍是充满活力的朝圣中心。小修道院易受通货膨胀及第一次世界大战征兵影响，西部战区者尤受重创。但许多大型男、女修道院，仍积极参与战争努力；此时，教会其他许多部分，却已深陷危机，下面即将讨论。[^p361-67]

## 帝国晚期的教会

到1900年，任何有思想的教士都不可能不知道，在俄国正教中竞相发挥影响的知识、属灵及牧灵力量。挑战在于把它们汇为富有成效的综合，以世俗<a id="pdf-362"></a><!-- PDF page 362; original page 341 -->权力能够接受的方式，协调主教团、神职人员及平信徒的利益。1880—1905年宗务院总检察官K. P. 波别多诺斯采夫，试图以更严格的中央控制解决问题。但如果说18世纪官僚化或许曾提高教会效率，此时情形却相反。帝国最孤立的堂区，也被不断增加的文书要求压得窒息。到1914年，卡累利阿司祭亚历山大·洛吉涅夫斯基神父，与维堡教区宗务局的通信次数，已是父亲在1880年代末的五倍。[^p362-68] 波别多诺斯采夫复兴“学者修道制”，同样充满争议；这一概念最初于17世纪借自天主教。总检察官希望，以一批苦修的学者行政人员，约束不守纪律的教士，挑战当代道德衰败。但雄心勃勃的高级教士在宗务院中随其调子“起舞”的形象，[^p362-69] 丝毫无助提高教会圣洁的声誉。旧政权最后几年，固然出现谢尔吉·斯特拉戈罗德斯基等坚韧领袖，也出现其追随者基普里安·施尼特尼科夫，以及同时代反犹人物伊利奥多尔·特鲁法诺夫等鲁莽激进者。前者1905年以后激化芬兰正教徒与路德宗关系；后者甚至于1907年攻击宗务院本身，使其导师安东尼·赫拉波维茨基总主教不得不得出结论：门生“全部文字作品，都见证其歇斯底里的疯狂”。[^p362-70]

到此时，宗务院体制已少有支持者。斯拉夫派教士A. M. 伊万佐夫—普拉托诺夫，早在1882年便要求恢复教会会议治理；但其事业直到二十年后才获得动力，尼古拉二世读到保守报纸《莫斯科新闻》对彼得一世教会改革的抨击。[^p362-71] 安东尼·瓦德科夫斯基都主教应邀评论时告诉沙皇，他“一直相信”，“迟早”俄国“舆论必将宣布，让神圣罗斯生活在如此反常的教会治理体制之下，是可耻而不可能的”。[^p362-72] 宗务院资历最深的成员，竟也质疑其<a id="pdf-363"></a><!-- PDF page 363; original page 342 -->权威，改革因而被普遍认为即将到来。然而，尼古拉在波别多诺斯采夫指导下，仍觉得召开教会会议在政治上时机不宜。平信徒把会议视为增加堂区事务发言权的办法；教士希望藉此立足教区管理；主教则意在削弱整个宗务院官僚机构。因此，沙皇忧虑会议制的颠覆潜力，远非毫无道理。但他处理教务缺乏把握。尼古拉原想把1903年萨罗夫的塞拉芬列圣，作为民族整合及神圣合法性的象征；但民众希望见到不腐圣髑的要求无法满足，反而引起尴尬。[^p363-73] 1906年3月，波别多诺斯采夫退休后，沙皇再度无意间招致各方面最糟的结果：继续拒绝召开会议，却批准设立筹备委员会。其公开记录揭示正教在关键原则上广泛分歧，却不提供解决机制，给批评者留下极诱人的攻击目标。[^p363-74]

缺少教会会议权威，教会易受1905年革命动荡冲击。1月9日“流血星期日”，格奥尔基·加邦神父领导的圣彼得堡俄国工人团体以悲剧收场：军队向和平、但未经批准前往冬宫的示威者开火。4月17日复活节主日，沙皇为防止反叛蔓延，颁布宽容敕令，使臣民在信仰事务上获得前所未有的个人选择。[^p363-75] 震惊的教会领袖陷入相互指责。2月，圣彼得堡改革派教士会见都主教，谴责正教“在这社会动荡时期”处于“不自然的无力”地位，波别多诺斯采夫斥他们为“鼓动者与捣乱者”。[^p363-76] 首相表示同情会议制时，波别多诺斯采夫又把其消息来源斥为“不谙现实”的“理想主义者”和“思想空论者”。[^p363-77] 自流血星期日起深居简出的总检察官，眼见自身世界崩塌：“所有人，无论世俗或教士，都发疯了。”[^p363-78] 安东尼都主教确实濒于崩溃。毫无根据的指控声称，他与维特阴谋勾结，使他愤慨。一位重要沙龙女主人声称：“一个想<a id="pdf-364"></a><!-- PDF page 364; original page 343 -->当共和国的独裁者，另一个想当它的牧首。”[^p364-79] 对这些指控愤慨不已的安东尼，于6月承认，自己的脑袋已经“完全裂开”。[^p364-80] 他困惑地看着同僚清算旧账。安东尼·赫拉波维茨基急于报复曾帮助在1895年把他逐出莫斯科神学学院的平信徒教授，把他们要求课程自主，斥为争取“在课堂否认耶稣基督神性的权利”；私下里，他建议解散学院，逐出叛逆学生。[^p364-81]

在如此恶化的气氛下，俄国公共生活政治化，必然制造更多教会分裂。加邦工会经验夭折后，许多成功的牧灵方法，似乎等同于社会主义。然而，官方不满未能阻止圣彼得堡及莫斯科革新派司祭，把教会改革要求与对工人物质需要更深入的投入结合。[^p364-82] 社会政治激进主义远不限于两都，在维亚特卡、斯摩棱斯克、喀山及弗拉基米尔等省级教区也很兴盛。即使在坦波夫，主教因诺肯季·别利亚耶夫虽是著名右翼人物，1906年9月教区教士大会仍认为，“人民追求更美好未来”有其正当性，并宣布同情解放运动，“只要它以和平手段，并依基督教原则进行”。[^p364-83] 但解放运动最著名教士人物的命运，显示了反对这类意见的压力。格里戈里·彼得罗夫神父，在1906年1月创刊的《上帝真理报》（Pravda Bozhii）中抨击社会不公，遭囚于修道院，以阻止其作为立宪民主党、即卡德特党成员，进入第二届杜马任职。1908年1月，在莫斯科都主教弗拉基米尔·博戈亚夫连斯基施压下——波别多诺斯采夫认为，1905年高级教士中只有此人仍保持清醒——彼得罗夫因“和加邦同样是个<a id="pdf-365"></a><!-- PDF page 365; original page 344 -->革命者”而被褫夺圣职。[^p365-84] 这位不肯悔改的讲道者反驳：“我信唯一、神圣、共议而传自使徒的教会，但我用全部力量与理智，拒绝那以正教为名的奴性修道式拜占庭主义，以及毫无灵魂的波别多诺斯采夫式凯旋主义（pobedonostsevshchina）。”[^p365-85]

左翼教士倾向于提倡缩短礼拜、使讲道更易理解，右翼则坚持维持正教礼仪的全套排场：精细的圣像游行，以及依应有主教威仪举行的漫长圣餐礼。右翼对社会基督教最大的投入，是接管教会长期禁酒运动的很大部分；对主张约束民众者，这是颇自然的事业。[^p365-86] 然而，右翼许多行动，却削弱而非稳定尼古拉二世伪宪政的官僚体制。1911年1月，伊利奥多尔在察里津修道院绝食，威胁使首相倒台。他鼓动教会摆脱彼得体制的紧身衣：“任何国家行为，不论公布新法、宣战，或农民与工人的参与，都不应未经教会预先建议与祝福而进行”；[^p365-87] 又要求解救沙皇，使其脱离奸诈大臣。斯托雷平不信任报刊，伊利奥多尔却毫不留情地利用它。他谴责《十月宣言》“使苦难深重的俄国淹没于鲜血”，要求处死维特，并鼓动俄国人自行执法：“我，修士伊利奥多尔，祝福你们从事伟大而神圣的事业，把亲爱祖国从无神论者、强盗、亵渎者、投弹者、煽动者、说谎记者及诽谤者手中解放；他们全受上帝诅咒，受世人谴责。”[^p365-88] 他把斯托雷平比作本丢·彼拉多，煽动1907年4月第四届君主主义大会的农民代表，要求强制转移私有财产。连亚历山德拉·博格丹诺维奇都感到不安，因为他似乎决意摧毁“不仅坐在各部里的人，甚至连各部的墙壁本身”。[^p365-89] 伊利奥多尔利用故乡顿河哥萨克地区桀骜自恣的传统，把<a id="pdf-366"></a><!-- PDF page 366; original page 345 -->1911年夏季的伏尔加集体朝圣，宣告为仿效17世纪起义者斯坚卡·拉辛、发动新民众运动的第一步。其支持者宣称：“顿河是人民愤怒之河。它若能说话，必有许多话要讲：纯真朴实的人民如何为真理斗争，如何成为‘受诅咒的罗斯’的敌人，最后又如何成为专制最强的支柱。”[^p366-90]

伊利奥多尔访问圣彼得堡时，特别留意让人看见自己出入为纪念喀琅施塔得的约翰而设的女修道院；约翰也是俄罗斯人民同盟的支持者。[^p366-91] 教会推举这位喀琅施塔得圣者，以对抗托尔斯泰；后者1901年被逐出教会，只是进一步激发了追随者的敬仰。但教会的努力适得其反，因为约翰神父本人意外成为敬礼对象。[^p366-92] 熟识其信徒的温和派圣彼得堡传教士D. I. 博戈柳博夫，为他们辩护：“诚然，他们教育有限，因此容易过分评价自己敬重的人与事物。然而，其意图良善，苦修上忠于正教，教会不必害怕他们的存在。”[^p366-93] 但宗务院并不这样看，1912年把约翰派（Ioannity）定为分立宗派，即鞭笞派（khlysty）。民众倾向于拒绝教会权威，转向自己选定的属灵导师，令重要教士惊惶；他们也同样批评伊凡·丘里科夫，即“伊凡努什卡弟兄”。受约翰神父启发，他广受欢迎的禁酒运动于1894—1913年，使数十万人走近福音；即使丘里科夫被逐出教会，运动仍延续至苏维埃时期。[^p366-94] 其他有感召力的人物，吸引较少追随者。教会无论多么警惕，都无法阻止愈来愈多俄国人放弃神学学院磨炼出的复杂正教形式，转向福音派新教令人安心的确定性。波别多诺斯采夫早在1880年就警告亚历山大二世，“群众”会受到V. A. 帕什科夫上校教导的诱惑，得出过分简单的结论：“漠视罪、空洞而幻想的信仰，以及对基督牵强而<a id="pdf-367"></a><!-- PDF page 367; original page 346 -->傲慢的爱。”[^p367-95] 福音派运动的确成为正教最有活力的对手。从1907年起，年轻浸信会讲道者威廉·费特勒，在圣彼得堡工人中经历“大收割与大聚集的季节”，以至“没有一场福音礼拜，不带来归信”。费特勒在瓦西里岛的福音堂，可容两千人；整个帝国的运动，或许拥有数百万信徒。[^p367-96]

宗派威胁有助解释，为何只有少数教士把1905年宽容敕令，视为和平、不受约束传教的机会。多数人如谢尔吉·斯特拉戈罗德斯基，反而感到被出卖：“经过一个世纪在法律保护、国家安全坚墙之下的和平生活，我们的教会如今毫无防御、无处遮蔽，径直冒险走向战场，面对敌人进攻。”[^p367-97] 正教学者长期援引教父权威，为国家干预、支持教会辩护。现在，他们沦为不体面的争斗，力图限制宽容敕令范围，并阻碍其地方影响。[^p367-98] 准确统计虽难确定，背教在西部边疆达到高峰；早先强加外来信仰的尝试，显露为虚假：到1907年，霍尔姆教区三分之一的“正教”人口，已改信天主教。[^p367-99] 比外流本身更有损害的，是威胁造成的态度。即使在教会最坏恐惧并未实现的教区，人们也持续认定灾难即将到来。[^p367-100] 1908年7月基辅传教会议上，多数人的危言耸听，使转离官方教会的修道院院长米哈伊尔·谢苗诺夫得以嘲笑教会：它愈来愈防御，依赖“外在”支持，退为“原始”传教工作，并深信面临将被对手“击败”的“危机”。[^p367-101] 像米哈伊尔这样著名的改革派人物，<a id="pdf-368"></a><!-- PDF page 368; original page 347 -->于1907年11月加入分裂教会，使旧礼仪派的主张更显可信：他们虽长期被斥为狂热反动者，实际上却是俄国宗教生活最有创造力的力量。的确，沙皇拒绝召开教会会议，使宗务院免于根本改革以后，可以被指责停滞的，已不是旧礼仪派，而是正教徒自己。

## 结语

1820年代走出相对宽容时期后，日益自信进取的俄国正教会，受到宗教对手挑战。尼古拉一世时期，改宗运动遭遇意料之外的抵抗，促使教士界定自身宗派立场，以便更有效地捍卫，并以真实神学基础支持愈发重视传福音的内部传教。然而，不可避免地依赖西方学术与牧灵方法，又使区分正教独特性的尝试复杂而有争议。修士与官僚都不信任抽象学问。政治家期待教会巩固沙皇政权，却惊惶发现，其传教可引起社会骚乱，研究会动摇宗务院权威，神职人员不断加强的牧灵投入，最终又激发社会与政治改革要求。1905年，政府面临崩溃威胁，把帝国安全置于教会满意之上。多数教士认为，4月17日宽容敕令，背叛了他们长期努力完善的宗派政策。教会领袖无法通过权威性教会会议，把共议性（sobornost）的要求导入正轨，反而卷入有害而政治化的争执。在愈益两极分化的教会内，辩论与羊群的属灵需要渐行渐远。旧政权结束时，无神论者与热忱者固然牢固占据民众宗教谱系两端，但即使1905年之后，多数俄国正教徒仍继续寻求民间信仰与基督教教义之间的和平调适，而这正是数世纪俄国宗教实践的特征。[^p368-102] 普通信徒往往比负责其属灵照管的人更宽容、更耐心、更能适应，因此，比吉洪牧首及其分裂而僵硬的教会，更能承受布尔什维克的冲击。
