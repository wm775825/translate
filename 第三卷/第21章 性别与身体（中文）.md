# 第21章 性别与身体

琳达·L. 库恩（Lynda L. Coon）

<a id="pdf-462"></a><!-- PDF page 462; original page 433 -->

在关于教会职分起源的著名论著中，塞维利亚主教伊西多尔（卒于公元636年）向一代代基督教祭坛侍奉者明确指示，应如何照料和培养司祭身体的公共形象。这些指示包括一节，讨论举行礼仪时如何控制男性的声音。伊西多尔在此劝诫司祭，不要口出淫言，要留心姿势和步态，在施行神圣仪式时注意发声的音高与庄重程度。司祭的声音应当清楚、朴素，充满成年男子的活力；不可发出粗鄙或滑稽的声响，也不可显得过分卑屈或高亢，过分破碎或纤弱。诵读员运用自己的声音作为工具，深入听者的心智。最要紧的是，完美的礼仪声音绝不能听起来柔媚似女子。为避免显得 femineus（“女性化”“像女人”），诵读员的举止必须充满 gravitas（“尊严”“力量”）。[^p462-1]

研究古典时代性别与性问题的学者，立刻就会在伊西多尔这部论教士的著作中，认出罗马人关于精英男性身体的观念遗存。[^p462-2] 事实上，罗马与西哥特西班牙之间的联系十分直接：塞维利亚主教借助一世纪修辞学家昆体良的演说技艺，来重塑当代司祭的形象。昆体良在《演说术原理》（约90年）中，细致教导初学演说者应如何束衣、摆放手指，以及庄重行走。他还着重讨论作为权力工具的声音：演说者应知道何处停顿、何时换气、何时加速或放慢。尤其是，熟练诵读员的朗读应当刚健庄严，声音绝不可滑向唱歌般的<a id="pdf-463"></a><!-- PDF page 463; original page 434 -->腔调或女性化的矫饰。[^p463-3] 对昆体良和其他罗马作者而言，拥有一张“公共之口”，即依法有权在特定场所——神庙、法庭、元老院议事厅、广场——发言，既标志着发言者的男性身份，也标志着其政治权威。那些没有这种公共之口的人——妇女、儿童、演员、奴隶——是 infames，“没有名誉的人”；若更贴近词源，则是“没有声音的人”。[^p463-4] 本章将发掘中世纪早期教士著作中所嵌入的古典性别建构遗存，其中包括为新的政治文化环境服务的伊西多尔。分析围绕身体及其部位——口、女阴和阳具——展开，以重建本时期重要文本对“生理性别”的医学与哲学理解，以及对“社会性别”的意识形态运用。虽然这里着重讨论教士，但司祭对于身体控制和纯洁的焦虑，也被传至世俗精英圈子，而且往往采取激烈竞争的形式。[^p463-5]

与古代晚期的前辈一样，中世纪早期教士吸收并传播古代的性别建构。伊西多尔在广为阅读和传抄的《词源学》（约636年）中，把“过度的爱”称作“女性式的爱”（femineus amor），向中世纪读者传达了一种古典罗马观念：任何过度都会使人女性化，包括对异性过于强烈的爱。[^p463-6] 过时的性史模型把罗马上层男子描绘为性享乐主义者，但实际上，他们应当“只与妻子发生性关系，即便如此，也不应太频繁”。[^p463-7] 在公共场合严格控制男性身体、肉体不可侵犯和个人生活节制，都体现着罗马精英男性（vir）的男子气概。教父作者及其中世纪早期后继者，很容易吸收了这一男性伦理，只是将它用于新的属灵事业。在罗马语境中，男子气概的核心，是保护公共名誉，避免受到软弱（mollitia）、被动受纳（pathicus）和太像女人（femineus）的指控。《词源学》呼应了男性对于软弱和过度的焦虑：“当一个男人削弱了自己性别的活力，以致使身体蒙羞时，他就是柔弱的〔mollis〕……他也会因性欲过度而使自己变得柔弱。”[^p463-8] 拜占庭作者则把宫廷宦官视为女性性欲的化身。在刻板描绘中，宦官的肉体柔软、白皙、散发浓烈麝香气味；他们的声音<a id="pdf-464"></a><!-- PDF page 464; original page 435 -->尖细刺耳，女性化的喉咙吞下过量食物和酒。因为宦官像女人，拜占庭文本常说他们在性方面受女人奴役，构成拉丁语 femineus amor 的希腊语对应。[^p464-9] 对罗马、拜占庭和西方中世纪作者而言，无法控制性欲，是女性气质的标志。

中世纪早期沿用古典拉丁语描述性行为方式、性活动和性器官的词汇，也揭示了两个时代的延续性。古典拉丁语有一百二十多个表示阴茎的词，其中许多都是迂回说法，连 penis（“尾巴”）一词本身也是如此。[^p464-10] 中世纪早期作者采用古典时代对男女生殖器的委婉称呼，例如 veretrum、lumbus、genitalia、libido、inhonesta、pars tegenda 和 pudenda，这里仅列数例。教士避免使用拉丁语性词汇中最猥亵的词，如 cunnus（女性器官）与 mentula（男性器官），并不令人意外。但这一选择未必源于拘谨。罗马各阶层虽在各种场合使用淫言，但确有一些明确场所——例如广场——不容精英男性说出 cunnus，因为礼仪与严肃自持要求如此。中世纪作者虽然避开罗马粗话，却会相当明确地描写从后部（in tergo）、在两腿之间（in femoribus）或在口中（in os）发生的淫行。

例如，悔罪书用生动直白的语言描绘各种性行为，其中一些呼应了古典用法。一部悔罪书用 semen in os miserit（将精液射入口中）描述口交的污秽；比起古典的 mentulam in os inserere〔将“鸡巴”（mentula）插入口中〕，这个说法稍少一些粗俗。[^p464-11] 罗马女性以人造阳具（fascina）插入性伴侣身体，中世纪女性则插入未说明具体形制的“器具”（machinae）。日耳曼法典沿用一些指代男性器官的古典借代词，如 virga（“棍杖”）、veretrum（“羞耻部位”），同时也添加新的说法，如 vectis（“撬棍”）。[^p464-12] 释经文本展示了指代阳具的完整隐喻谱系，包括“尾巴”（cauda）、“鼻子”（nasus）和“肢体中的肢体”（membrum membri）。lumbus 与 femur 在古代晚期都成为生殖器的重要同义词，无疑受到希伯来经书以“腿”和“腰”代称私处的影响。

希伯来语和希腊语经书的拉丁译本，往往强化了原文的情色与性别意味。例如，九世纪加洛林改革者、圣米耶尔修院院长斯马拉格杜斯（活跃于809—817年），抨击修士道德松弛时，常引用《箴言》18：9拉丁译本中的 mollis et dissolutus（“女性化而放荡”）一语，因为过度欲望使修士失去男子气概。[^p465-13] 这一拉丁表述具有强烈的古典色彩，属于用来压倒政治对手的丰富性辱骂词汇。[^p465-14] 对罗马人而言，选择 mollis 一词，会唤起“浓妆艳抹、性身份暧昧的年轻男子”的形象。[^p465-15] 拜占庭教士则利用古典希腊语中的女性化词汇：gynaikodoulos（“受女人奴役的男人”）、gynaikotraphes（“因由女人抚养而变得女性化的男人”）和 gynaiazo（“在性方面沉迷女人的男人”）。[^p465-16] 希腊语和拉丁语中存在这些延续，多少可在预料之中；但描述男性女性化的性别语言，在释经和修道文本中持续如此之久，仍令人意外。据斯马拉格杜斯说，真正的修士充满活力（vividus）、强壮（fortis）、刚硬（rigidus）；虚假的弟兄则软弱（mollis）、娇嫩（tener）、纤细（delicatus）。[^p465-17]

斯马拉格杜斯关于“软弱”修士的思考表明，圣米耶尔院长把身体习惯与服饰视为社会性别的标志。但他如何理解“生理性别”？性史学者曾提出，前现代思想家倾向于以“单一性别模型”理解人体：男性与女性位于同一个统一肉体结构的两端。[^p465-18] 按照这一模型，女性的生殖器与男性相同，只是向内翻转，因而较为低劣。直到十八世纪，欧洲人才提出以生物差异为基础的新模型。另一些医学史专家则认为，古典医学作者的身体观从未整齐划一到完全忽略基于解剖差异的“双性别模型”。中世纪作者对古典医学模型采取兼收并蓄的态度，所以，像伊西多尔在《词源学》中那样，自由援用单一性别与双性别两种范式，也不足为奇。[^p465-19] 当然，这两种古代模型仍都把男性放在生理／社会性别体系的顶端：单一性别模型声称女性是男性的内翻形态，是对男性常态的偏离，从而贬低女性；双性别模型则<a id="pdf-466"></a><!-- PDF page 466; original page 437 -->通过赋予男性差异以优越性，达到同一结果。[^p466-20] 无论如何，有一点很清楚：对于生理性别——生物上的区别——与社会性别——将文化铭刻于身体及其习惯的过程——之间的差异，中世纪作者与当代理论家同样困惑。中世纪早期男子书写身体时，把男女等级观念强加在身体的物质表面，因而将任何关于生物事实的讨论，都变成了关于性别意识形态的话语。

例如，伊西多尔在《词源学》中强调男女解剖结构的不同。只有男人有阴茎（veretrum），排出精液（virus）；也只有他们有睾丸，即男子气概的“见证者”。女性独有子宫和女阴——子宫之门——以接纳精液。[^p466-21] 宦官属于男女之间的类别，其特点是精液衰弱、不能生育。[^p466-22] 雌雄同体者被描绘成男女的怪异混合，在专论怪物和异兆的一节中讨论，从而凸显了一种古代希伯来观念：任何混杂都是可憎的。[^p466-23] 这些反常生物右乳如男、左乳如女；更引人注意的是，他们既能使他人受孕，也能自己生产。[^p466-24] 与雌雄同体者不同，真正的男人有胡须、胸部宽阔；女人的身体则胸窄、臀宽。[^p466-25] 女性有乳房（mammae），男性则有乳头（mamillae）。[^p466-26] 大腿（femur）是区分性别的主要部位；罗马和中世纪作者都认为，它是充满性意味的身体部分。[^p466-27]

毫不意外，这位主教对性别的意识形态运用，不断侵入他的解剖描述。男性欲望的所在是腰部（lumbi），女性的情色区域则在脐部（umbilicus）；这种位置差异进一步强化了女性受纳、男性主动的特征。[^p466-28] 此外，vir（“男人”）源于 vis（“力量”“活力”“权能”），因为据伊西多尔说，男性比女性更有活力。[^p466-29] 而 mulier（“女人”）则源于 mollier<a id="pdf-467"></a><!-- PDF page 467; original page 438 -->（“更柔软”），她服从男人，是因为男人拥有更强的 vis。[^p467-30] 伊西多尔为男性优越性辩护，依赖语言学依据，而非对女性解剖缺陷的攻击。他的基督教信仰使他不能强调女性身体固有的易腐败和缺陷性质，因为正如他强调的，上帝亲自造了第一个女人（《创世记》2：22）。[^p467-31]

伊西多尔对体液的讨论，最能衡量他在男女物质身体问题上的等级化处理。他吸收了希腊医学关于男性体液生成过程的范式，把精液描述为脑的滴液。[^p467-32] 按照这一古代理论，精液起源于脑，储存于脊髓，再从那里渗出至肾。在肾中，这种“淫秽体液”（obscenus humor）被欲望的热力煮熟，流向生殖器，再喷出体外。[^p467-33] 在这套哲学／医学体系中，欲望的热力把男性身体变成“人体浓缩咖啡机的出液口”。[^p467-34] 谈到女性体液，伊西多尔转而援引罗马博物学家的厌女文献，把经血比作传染物。主教认为，女性污秽的血液极其危险，能够杀死庄稼、使酒变酸、使铁生锈、使铜变黑。[^p467-35] 月经是一种“致命危险”，既因为它能改变物质，也因为它不受控制地突破身体边界。[^p467-36] 尽管伊西多尔对“女人的事”（muliebria）极为否定，但由于经血具有强大的转化能力，他无疑也对女性身体的这项自然功能怀有敬畏。

对身体物质性质——解剖结构及其相应功能——的研究，令主教着迷；《词源学》中对身体部位的细密探讨，足以为证。在整个中世纪，《词源学》是阅读和传抄最多的文本，仅次于《圣经》。[^p467-37] 它的影响遍及悔罪书、会议立法、圣徒传、修道注疏和释经等多种文类。在这部百科全书中，伊西多尔留给中世纪教会一套“人体语法”；若能正确解读，便会显露身体内在隐藏的<a id="pdf-468"></a><!-- PDF page 468; original page 439 -->创世真理，以及身体与宇宙的关系。[^p468-38] 身体映照着中世纪早期社会的政治与性别结构：某些部分统治，例如头；其他部分受统治，例如脚，正如男人统治女人、主人支配奴隶。[^p468-39] 解读这具等级化身体，是一种精英活动，主要由一小群享有特权的教士进行。

与当代性别理论家一样，伊西多尔及其后继者也认识到：把一具有阴茎、因而被确定为男性的身体，塑造成所谓“男人”这一文化产物的过程中，还受到其他条件影响。[^p468-40] 一位著名理论家曾将社会性别定义为“身体反复被赋予风格的过程，一组重复的行动”。[^p468-41] 中世纪早期教士习惯把男子气概等同于身体表演与肉体风格，他们会赞同这一说法。女性化的姿态会改变阳刚的面貌，松垮的腰带会使修士失去男子气概，奢华的发式则把男子变成惑人的生物。当代理论家还认为，社会性别是终身协商的过程，由年龄、阶级、性取向、国籍、帝国主义、族属，甚至身体在环境中的实际位置等条件塑造。对于中世纪知识人，宗教归属是性别构成中最重要的因素；紧随其后的是族属、年龄、阶级、亲族群体、仪式纯洁性，以及身体在空间中的位置。

通过《圣本笃会规》及后来的注疏重建的本笃修道生活制度节律，有助于理解中世纪早期的性别如何在具体环境中运作。在这一等级体系中，对女性化的焦虑无所不在，并非所有生理上的男性都是真正的男人；年龄、阶级、仪式纯洁性、身体不可侵犯性和距祭坛的远近，构成关键因素。按照会规，修道院是战斗与属灵危险之地，是对魔鬼战争的前线。同时，它又是摩西在旷野中的会幕（tabernaculum），是尘世污染之中的神圣容器。男性禁欲者若拒绝具有净化作用的院内空间（claustrum）和严格会规，放纵自己的欲望，便失去男子气概（molliti）。与他们相对，共住修士是训练属灵战技的“最强健的一类”（fortissimum genus）。因此，会规建立了一个充满性别难题的禁欲竞技场。强健的修士不断对抗“肉体与思想的恶习”（vitia carnis vel cogitationum），这些诱惑与女性化密切相连：自我放纵、欲望、<a id="pdf-469"></a><!-- PDF page 469; original page 440 -->懒惰和多话。通过这种斗争，他们确保自己的身体表现出庄重、尊严、自制和节俭这些男性化、也带有古典色彩的美德。一套细密的监视过程使本笃式男子气概规范化，因为上帝、天使和院长——院长本人是基督在尘世的化身——监视修士的每一个动作，连睡眠中也不例外：“要记得，天上的上帝始终看见他；无论在哪里，他的行动都在上帝眼前，天使时时将其报告。”[^p469-42] 从进入修道院之日起，修士就不再“有权处置自己的身体”。这句话在会规中出现两次（33.4、58.25），呼应保罗的著名解释：已婚基督徒对自己的身体没有自主权（《哥林多前书》7：4）。修士是与祭坛结婚的男人，因此，他们将自身肉体的控制权，交给警醒守望的天上等级体系。

本笃修士的身体，由此成为灌输这种等级秩序的场所。院内等级取决于多种因素：入院时间、年龄、阶级、身体不可侵犯性、纯洁性，以及座次安排。修士通过俯伏、低头、目光朝地等仪式，表现自己在这一宇宙尊卑秩序中的低位。年少修士的身体经常遭受责打，发言能力也受到严格限制，尤其在修院监视最严密的空间——祈祷所和食堂，两个专与口有关的场所。受到绝罚处分的修士，不得在祈祷所吟诵诗篇，因为违反会规者被排除于修道院最关乎地位的活动：说出圣言（logos）。[^p469-43] 会规细心控制修士口中进出的一切，因为吃、说和吟诵诗篇，都会引发关于仪式地位的焦虑。口是一个危险的孔口：它既是修道权力的工具，用以吟诵圣言，但它摄入食物时，又突破了内外世界之间危险的界限。除非院长特许，修士不得吃在修道院神圣范围之外制作的食物（《本笃会规》51.1—2）。此外，据各种悔罪书，口也是性孔口，是精液的被动接受者（semen in os miserit）。口可以同时从事神圣、世俗和淫秽的活动，使它成为最成问题、也最具支配力的孔口。即使闲谈也会玷污男性禁欲者，因为地位高的修士要排空身体中除圣言以外的一切。唯有祈祷、默想和对<a id="pdf-470"></a><!-- PDF page 470; original page 441 -->圣经文本的反刍，充满有力量修士的心智，并成为其禁欲男子气概的标志。祈祷所本身，也是完善修士身体的比喻，正如会规命令：“祈祷所应当名副其实；不得在那里从事或存放其他任何事物。”[^p470-44] 会规的主要目标，就是把践行者的身体化为圣言的仓库。

年龄也参与构造修道的晋阶体系：十五岁以下男孩，是院内最容易受到责打的人。他们在祈祷所犯错，就受“鞭打”（《本笃会规》45.3），又会在席间闲聊（63.18）。在本笃制度的纪律约束中，他们是正在成为“男人”的“男性”；[^p470-45] 这一过程的关键，包括控制口、进入祈祷所的资格，以及免遭身体攻击。年轻修士处于门槛上的地位，说明了他们可塑、柔软、可被穿透的性质。会规隐约暗示，而后来的注疏和悔罪书明确说明：男孩是性欲的对象；他们在修道院中的存在，既使其性别等级不稳，也强化这一等级。中世纪早期的科学，为本笃修院男孩在性别上的问题提供了依据。按照古典与中世纪早期医学，男性身体较热、较干，因此更稳定，也较少发生流泄；女性身体较冷、较湿，这种湿润突出了女性的不稳定和易变。[^p470-46] 小男孩的体温性质更接近女性，会规也始终把他们视为多话、放纵、可受穿透、缺乏纪律的人——全都是女性化的属性。

本笃式等级，与古典罗马生理／社会性别体系所建构的社会金字塔平行。在后者中，精英男子（viri）的权威，建立在口的运用上，包括演说与政治辱骂。一方面，在仪式认可的场所使用口的能力，以及使别人沉默的权力，是古典男子气概的标志。另一方面，粗鄙的政治和文学攻击，却集中于 os impurum，即“据说因口交而产生的不洁之口”。[^p470-47] 使政治对手闭嘴，是一种隐喻性的口腔强奸（irrumo），在以阳具为中心的罗马政治等级中，是强有力的支配象征。任何精英男子若允许自己的口被插入，就“损害了自身的性完整性、不可穿透性（pudicitia）”。[^p470-48] 为人吮吸阴茎属于下等人的性行为，是元老可能要求<a id="pdf-471"></a><!-- PDF page 471; original page 442 -->妓女为自己做、却绝不会要求上层妻子去做的事。罗马人对口的纯洁十分执着：“它是说话的器官，尤其是公共演说的器官。”[^p471-49] 居于上位的男子（viri），成功保护自身免遭言语、身体或性攻击，同时可以随意责打和／或在性方面插入低位的“他者”。[^p471-50] 精英男孩使这一古典生理／社会性别体系发生动摇，因为他们既是男性欲望的对象，又因出身高贵，在理论上不得成为性对象。因此，在这一罗马体系中，生理／社会性别同时以解剖结构和社会、经济、政治地位为基础。

同样，《本笃会规》制造了一套性别等级：上帝与天使居于天上的顶端，作为基督的院长是其中介与尘世掌权者，下接各级修士；他们的地位，取决于仪式性使用口的方式、进入祈祷所的资格及身体不可侵犯性。与古典罗马一样，性的口部使用是中世纪早期修道文化的一大禁忌；在某些悔罪书中，口交须终身补赎，因而比肛交、股间交或乱伦更严重。[^p471-51] 本笃性别金字塔的底层，是十五岁以下男孩（《本笃会规》70.4）。他们的口尚无完整的仪式力量，身体则可能受穿透，无论是责打的手，还是插入的阴茎。[^p471-52] 男孩的口属于湿润的男孩身体，所以发出的声音“像芦笛”“纤薄”；他们的吟唱无力穿透听众心智。相较之下，成年男子的声音厚实而有穿透力。[^p471-53] 上帝当然是本笃团体最有力的演说者；最接近他的修士，便是那些“更积极参与发言、下命令和赐福”的人。[^p471-54] 因而，最强大的修士，是最接近上帝的人：一个脱离肉体的声音。[^p471-55]

会规就像一本手册，教人在细密界定的禁欲男子气概中，完成从身体到声音的神秘跃迁。它也给中世纪早期身体的解释者提供其他重要启示。本笃修士的身体，离开其作为基督身体成员的身份，就没有意义；因此，其“存在论地位”“更像罗马法中的奴隶”。[^p471-56] 单个修士的仪式纯洁，是共同体关切的事情，因为任何<a id="pdf-472"></a><!-- PDF page 472; original page 443 -->身体受辱都会造成集体污染。一部七世纪会规详述了对被控引诱男孩的修士的惩罚：剃去头发，当众鞭打、加以锁链，由全体会众辱骂、吐唾；随后与同伴隔离，置于年长弟兄的严密监督之下，监视其每一个动作。[^p472-57] 于是，对等级的侵犯被铭刻于堕落修士的身体，使他成为警示违犯危险的可见标记。在这一体系中，修士身体类似于修道院未受污染的空间；因此，他身体的出入口，与修道院的出入口一样，都受严密监视。会规强调守门人（第66章）的重要性，并非偶然：他应是“睿智的老人”（senex sapiens），看守修道院最脆弱的地点——入口，也就是身体孔口的建筑对应物。悔罪书和教会法密切关注所有基督徒、特别是司祭、修士和修女的被动性孔口，即“接纳并臣服于阴茎的孔口”。[^p472-58] 司祭若接受肛门插入，便削弱教会，为其民众招来瘟疫和饥荒。[^p472-59] 修女从事同性性行为——有些使用人造器具（machinae）——则颠覆了上帝赋予的男女等级。[^p472-60] 一部盎格鲁—撒克逊悔罪书把精液玷污口腔称作“最恶之恶”（hoc pessimum malum）。[^p472-61] 考虑到口在修道事业中的作用，它受污染遭到严厉谴责，是可以理解的。不过，神圣身体内外界限的任何突破，也同样意味着共同体的破裂。

中世纪早期身体除了具有共同体性质，还具有双重性别：一重基于物质身体，另一重基于对肉体的超越。塞维利亚的伊西多尔把人界定为“双重的受造物——他既是内在的，也是外在的。内在的人是灵魂，外在的人是身体”。[^p472-62] 人的这两种本性紧密相连。事实上，内在的人随时可能在身体表面爆发出来。中世纪早期作者借助古典前辈的医学文献，为身体的多孔性忧虑，因为身体由许多呼吸小孔（spiramenta）组成，污秽物质可从中进入，精液等珍贵物质则从中渗出。[^p472-63] 大格列高利在影响广泛的<a id="pdf-473"></a><!-- PDF page 473; original page 444 -->《牧者之书》（约591年）中告诫读者：即使小罪，也会像脓疱一样爆发于皮肤表面。教宗认为，重大的堕落会使体内液体涌向生殖器，造成恼人而可耻的肿胀，成为内在欲望的外部表现。[^p473-64] 在这一形象体系中，身体外部是检验内部属灵状态的试纸。女性化的灵魂（mollitia animae）可能使外在的人犯罪。复活的肉身必须净除女性化，坚守男子气概。[^p473-65] 修道注疏者和圣经释经者极为重视这一内外范式，写作时常针对内在的人、外在的人，或二者兼及。

在这种双重人体构造中，外部器官各有内部对应。例如，胃是一个内在阳具，是烦扰不休、永不知足、对抗救赎的器官，是必须征服的对象。[^p473-66] 对中世纪身体解释者而言，胃之类的单一器官，可从三个层次阅读：医学层次，把它看作向肠道输送食物的器官；道德层次，把它看作过度情欲的借代；寓意层次，把它看作堕落人类不服从的比喻。因此，阅读身体是一种神秘行为，类似中世纪阅读经书的实践：熟练释经者采用三重策略，超越字面与道德内容，去解读隐秘真理。中世纪思想家把身体视为上帝宇宙的缩影，强调造物主以同样的物质——土、水、火、气——充实身体与宇宙，从而将两者结合。[^p473-67] 因此，阅读身体是一项奥秘事业，能揭开创世的秘密，暴露敌基督的危险。

中世纪早期释经者和医学作者，对人体部位的讨论范围广得惊人；有时，对其功能与意义的说明也令人震惊。教士常把教会极为关切的问题铭刻在身体部位上：异端、正统、得救、沉沦。有些部位与基督紧密相连，例如头；另一些则与敌基督结盟，例如阳具。塞维利亚的伊西多尔在《词源学》中，为中世纪早期女阴与阳具的解读奠定了基础。他的知识继承者，把主教对身体及其部位简练而道德化的考察，重新投射到寓意的奥秘世界中。在此过程中，他们把古典时代对性器官的看法，与基督教和希伯来传统对这些器官道德及上升至神圣层面意义的解释结合起来。

古典拉丁语的 vulva 一词，可指女性的子宫、阴道及外生殖器。[^p474-68] 罗马诗人在情色诗中避免提及女阴及其内外部分，辱骂文字的作者却将其描述为“恶臭、肮脏、湿润、松弛、嘈杂、多毛”。[^p474-69] 古典拉丁语中最污秽的词是 cunnus（“屄”）；禁忌之强，以致西塞罗谴责在元老院议事厅说出此词的精英男子。事实上，西塞罗自己也避免直接提及 cunnus，而写成“cum nos”。[^p474-70] 古典作者用外部身体的词汇，描写阴道与子宫的内部性质：子宫是口，阴唇是嘴唇，阴蒂是鼻子或舌头，子宫颈是脖颈；因此，每个内部器官都有一个可见的外部对应。伊西多尔注意到，当时说拉丁语的人用 labiae 指女性嘴唇，用 labra 指男性嘴唇；这种区别暗示 labiae 已与女性私处密切联系。[^p474-71] 在这种身体象征解读中，遮住女人的头，类似于遮住她的性器官；侵犯面纱，在隐喻上等于强奸。[^p474-72] 中世纪早期作者承继了关于女性私处的内外对应传统。据圣徒传记作者，圣女在面临强奸时，会运用身体隐喻表达愤怒。野蛮人群涌向基督教修院时，修女割伤自己的嘴唇和鼻子，显然是以此借代对私处的毁伤。[^p474-73] 毫不意外，面纱成为女性不可侵犯性最明显的标志；到了中世纪早期，它具有奇迹力量，可以挡住刀剑——刀剑显然是阳具的比喻，因为拉丁语“剑”（gladius）也是“阴茎”的俚语。[^p474-74]

伊西多尔《词源学》提供了中世纪早期女阴的标准医学定义：“vulva 得名于折门〔valva〕的类比，即腹部之门，因为它在那里接纳精液，或者因为胎儿从中出来。”[^p474-75] 作为一道门，女阴代表身体内外之间危险的缺口；折门的类比，则关乎器官内外层叠的结构。女阴是不可控体液即月经流出的部位，是受月亮节律支配的周期性渗出。[^p474-76] 主教认为这种与月亮相关的物质强大而可怖，因为他写道，接触这种血污（cruor），会使狗发狂，并溶解<a id="pdf-475"></a><!-- PDF page 475; original page 446 -->胶。[^p475-77] 女性无法控制自身的体液流出，是中世纪早期厌女观念的核心特征，也标志着男性与女性之间的关键差别。女性身体开放、多孔，容易受到“使其液化的侵袭”。[^p475-78] 理想男性身体则稳定、干燥、温热、边界分明。在寓意领域，干燥／男性与湿润／女性的对立，又被置于末世论光照下：堕落人类寒冷、麻木、受缚于大地，即女性化；当圣经的爱欲语言将其点燃，堕落灵魂便脱去寒冷而易变的本性，变得温热而轻盈，即男性化，向上升起，与其所爱者相会。[^p475-79]

伊西多尔的知识追随者之一、加洛林时期富尔达院长赫拉班·毛鲁斯（卒于856年），在巨著《论宇宙》（约九世纪四十年代）中，将导师对女阴及其体液的医学及道德化处理，在解释上又推进一步。[^p475-80] 对这位院长兼圣经释经者而言，尘世女阴具有强烈的肉欲性质，却也履行了“生养众多”的神圣命令；其奥秘对应物，则体现信仰的秘密与灵魂的内在性质，可以用于善，也可以用于恶。女阴的内层还象征教会最神圣的部分；“堕落异端试图闯入”这一空间，“却从母体中流产而出”。对赫拉班而言，子宫不可控制的体液，是偶像崇拜者和异端口中流出的桀骜而污秽言辞的绝妙寓意。异端像经血一样，被排出教会的内在圣所；他将这一圣所比作子宫。赫拉班对男女体液的矛盾处理，说明了加洛林教会对性别的等级化看待。他认为，精液因其繁殖性质而代表上帝的圣言；富尔达院长对男性体液的理解，是伊西多尔将男性种子解释为“脑的滴液”这一医学观点的寓意延伸。[^p475-81] 相反，他把月经等同于“偶像崇拜的淫秽与谬误的污染”。他推论，这种血污使整个大地在“谬误和偶像崇拜中”剧烈翻转。院长警告，正统信仰的男子不得接近经期女性，也不得与之交合，因为这样做就等于寻求与异教徒和异端的肉体结合。异端之口，像《箴言》5：3中妓女淫荡的口：崇拜偶像的嘴唇滴下蜂蜜，甜言蜜语诱捕可怜的男人。[^p475-82] 赫拉班在女性私处中，既解读出<a id="pdf-476"></a><!-- PDF page 476; original page 447 -->纯洁的隐喻——女阴的内层，也解读出堕落的隐喻——无法控制体液；这对一位独身修士来说，是一项令人惊异的活动。

古典作者鄙弃 cunnus 的污浊性质，却把阴茎，以及其隐喻对应物阳具，视为男性政治与性能力的最高标志。对于罗马人，性交时这一器官的冲刺动作（futuo），类似武器的敲打或攻击，因为性是对社会下位者的侵犯。[^p476-83] 在罗马世界，阳具本身具有多种辟邪功能，包括驱除恶眼；它采用各种物质形式：护符（fascina）、店铺招牌、灯、门铃和铺路石。[^p476-84] 它的一种古典委婉称呼 verenda，意为“引起敬畏或尊重的部位”，反映罗马人以阳具力量体现帝国统治的观念。阴茎最猥亵的称谓是 mentula（“鸡巴”），中世纪早期作者竭力避免使用。[^p476-85] 罗马人还以 nervus（“筋”“腱”）称阴茎或睾丸，因为其强韧有力；中世纪早期释经者也采用这一名称。[^p476-86] 如同女阴，阴茎也有外部对应：它是鼻子、脖颈、喉咙，甚至尾巴（cauda）。一位十一世纪作者把自慰导致的排精比作从鼻中擤出鼻涕；一位九世纪释经者则以“坚硬的尾巴”辨识敌基督。[^p476-87] 中世纪早期法典编纂者，对阴茎、睾丸遭切割毁伤怀有焦虑，为受损男性器官计算相应的人命价赔偿。[^p476-88] 对本时期圣经释经者而言，阳具仍保留若干令人敬畏的古典含义：它隐喻“圣灵的剑〔gladius〕”（《以弗所书》6：17），射精的能力则比喻传讲圣言（《路加福音》8：11）。圣言这把阳具之剑，穿入（irrumpo）恶习的内脏和人的心中。[^p476-89]

塞维利亚的伊西多尔用 veretrum（“羞耻的”“羞怯的”）指阴茎。这是古典委婉语，原本同时适用于男女器官。他给出的词源是：“veretrum 如此得名，因为唯独男人有它〔viri est tantum〕，或者因为精液由它排出；virus〔‘黏滑液体’〕就是从男人性器官流出的液体。”他指出，睾丸（testiculi）是“见证者”（testis）的指小词，用来储存精液；按照希腊<a id="pdf-477"></a><!-- PDF page 477; original page 448 -->医学，精液起源于脑。[^p477-90] 伊西多尔把 testes 纳入解剖词汇，反映了希伯来语对晚期拉丁语的影响：在《妥拉》（《创世记》24：2—3、47：29）中，作证要求宣誓者握住睾丸，以其见证自己所言真实。这种对男性身体的仪式运用，是主教熟悉的。[^p477-91] 女性私处兼具外层和内层，男性解剖器官则完全在外；因此，中世纪早期释经者把它们不可控制的肿胀与射出，视为内部恶习的外在表现。[^p477-92] 据加洛林作者、奥尔良的狄奥杜尔夫（卒于821年），即使一个警醒的男子，若因看见、触摸、甚至回想女人而排出种子，也遭受了“女性化的污秽”（immunditia mollities），使他把不洁之物泄在自己两腿之间（inter femora），甚至另一人的两腿之间。[^p477-93] 狄奥杜尔夫警告，这类女性化的人将不得进入天国（neque molles regnum Dei possidebunt，援引《哥林多前书》6：9—10）。不可控制的泄精使男人像女人，无法抵抗“使其液化的侵袭”；因为男子气概的试金石，就是拥有边界完整、稳定的身体。

修道服饰是预防女性化流泄和恼人勃起的手段，也成为中世纪早期禁欲者写作的重要主题。“你要如勇士束腰”（Accinge sicut vir lumbos tuos，《约伯记》38：3、40：2），是设计这种防护服饰的修道作者喜爱的经文。耶柔米描述施洗约翰和以利亚的文字也同样受欢迎：他们是束紧腰带、毛发浓密的男子，全身没有丝毫柔软或女性化，每一寸都刚硬而阳刚。[^p477-94] 约翰与以利亚超强的男性典范令赫拉班感到压力，他为当代“腰带松垮”的修道人物的男子气概而忧虑：“……〔未束腰的司祭〕在男子气概的道路上受到阻碍，被尘世欲望的污秽玷污，变得卑劣。”[^p477-95] 对赫拉班，紧身衣物是阳刚灵魂的象征标志。他对适当束腰的焦虑，映照了古典作者对于未能约束私处的男人的抨击。西塞罗、贺拉斯、普劳图斯、老普林尼和马提亚尔等各不相同的作者，都把“腰带松垮”（discinctus）视为“生活方式女性化的隐喻对应”。[^p477-96] 罗马诗人贺拉斯只需随口提及某人身着“低垂的短衣”，听众便会<a id="pdf-478"></a><!-- PDF page 478; original page 449 -->立即明白，诗人是在暗示穿衣者的性越轨。加洛林修道作者，包括在诗作中阅读并引用贺拉斯的赫拉班·毛鲁斯，显然多少熟悉罗马关于男子气概和有德男子公共举止的意识形态。他们把罗马男子气概观念，与希伯来关于束腰的教导结合：束腰既是禁欲男子气概的经文依据——以利亚和施洗约翰，也是祈祷的准备——《塔木德》中的摩西。适当束腰，使圣人能断绝世俗野心、征服淫欲的瘙痒（prurigo）、根除 luxuria（“过度”“性污染”）；游荡的阴茎正象征着这些恶习。[^p478-97] 十一世纪教士改革者彼得·达米安，推荐以束腰作为医治鸡奸的办法。[^p478-98] 束带保存着以节欲自律体现的男子气概：“司祭穿紧束的亚麻衣——并非以女性化方式，而是出于热忱——因为他们守持贞洁的决心。”[^p478-99] 院长推论，真正的男人以紧束亚麻布，约束四处游荡的阴茎那不稳定的性质。

与警醒修士紧束的腰相反，敌基督的阳具和睾丸，像女性体液一样不受拘束。继大格列高利的巨著《约伯记道德论》（约591年）之后，包括赫拉班在内的几位中世纪早期修道作者，把男性私处最恶劣的性质，投射到希伯来海怪贝希摩斯（《约伯记》40章）的可怖身体上，并将其等同于敌基督。[^p478-100] 它的“肢体中的肢体”（membrum membri），是一条坚硬的“尾巴”（cauda），是内在背教的外部表现。格列高利推断，贝希摩斯有许多睾丸，也就是传播其放荡教义的传道者，涌出谬误的恶毒精液，败坏人心。它的睾丸是一团缠结的筋（nervi），体现敌基督的混乱教义，以及诱捕正统信徒的力量。它的口与体液同样放纵，带传染性的言语感染人的精神。贝希摩斯／敌基督与其他异端形象一样，奇特地被女性化了：多话、失控、过度、充满 luxuria。它将 luxuria 注入男女的情色区域，从而支配他们：女性经脐部，男性经腰部。因此，这一释经解读，给修士束腰添加了一层新的、较为阴暗的意义：这是一项辟邪仪式，意在抵挡敌基督的感染。

正如赫拉班·毛鲁斯警告修道读者的：“某些身体部位被归于魔鬼。”[^p479-101]

考察身体及其部分——魔鬼般的阳具、排出异端的女阴、本笃修士的口——表明，中世纪早期生理／社会性别体系的关键，是保卫男性身体，使其免受女性化污染。这种女性化形式多样：精液不受控制地喷出、异端言辞肆无忌惮、低垂的短衣，甚至对异性过分热衷（femineus amor／gynaiazo）。但这种对女性化的恐惧，与启蒙运动以后据说基于更客观的生物学、精神医学和性学的性观念，相差究竟有多大？同性恋史家指出，“异性恋”一词最初作为一种性病理，出现于十九世纪末性学家的著作中。与其孪生词“同性恋”一样，异性恋也是一种病理，表现为对异性过度感兴趣，或寻求不以生育为目的的快感；任何中世纪研究者都能从这一“科学”定义中认出奥古斯丁神学的遗存。迟至1923年，词典仍把异性恋定义为“对一名异性产生的病态性激情”，呼应古典与中世纪早期 femineus amor（“过度的爱／女性式的爱”）观念。[^p479-102] 对男性因女性化的被动而丧失支配地位的恐惧，直到二十世纪“客观”的医学与精神医学话语中，仍持续塑造男子气概和性身份理论。

但与此同时，中世纪早期教士缺少维多利亚时代性学那种精细的性分类体系。九世纪加洛林王后图特贝尔加那场臭名昭著的审判，在这方面颇具启发。教士把女人——例如被丈夫洛泰尔二世（卒于869年）指控以鸡奸方式乱伦的图特贝尔加——纳入使徒保罗对与男宠同寝者的抨击之中（concubitores masculorum，《哥林多前书》6：10；《提摩太前书》1：10）。显然，在中世纪早期以男性为中心的性修辞中，并没有单独位置安放不守规范的女性。审判最初的指控称，王后扮演被动男宠，其兄长扮演插入的一方；兄妹进行股间交（inter femora，这是男性修道者偏爱的一种方式），并合谋调制堕胎药，毁掉以怪异方式受孕的胎儿。[^p479-103] 图特贝尔加的 stuprum（“玷污”“失荣”）<a id="pdf-480"></a><!-- PDF page 480; original page 451 -->被赋予的悖逆性质，汇集了教士和古典传统对性与身体的种种焦虑：对大腿的恋物式关注、女性过盛的性欲、乱伦、鸡奸、堕胎、孔口的误用，以及这种误用造成的政治共同体瓦解。[^p480-104] 伊西多尔对女阴的思考，也短暂出现在审判叙事中。作者兰斯的欣克马尔（卒于882年），援引当时关于女性解剖结构最可靠的医学知识，驳斥王后可以因肛交受孕的指控。[^p480-105] 而图特贝尔加在离婚程序中的行为，也凸显了一种理论：中世纪早期女性与古典时代女性一样，缺乏公共之口，即属于 infames。王后始终“被动，被迫沉默……她的审判由男性主教操纵；她请求获准退入修道院，进入面纱与沉默之中”。相比之下，她的丈夫洛泰尔则“是男性，也是主动者：他请求主教准许的，不是进入修道院，而是再婚”。[^p480-106]

洛泰尔寻求新妻的理由，揭露了教士建构男子气概与女性化背后更深的政治背景。作为世俗男子，洛泰尔被肉欲灼烧，无法控制性欲。他与妻子分离，教会顾问又不准他向女妾寻欢，于是向主教抱怨：自己的欲望需要一个合法出口。[^p480-107] 脆弱的世俗男性身体，与束腰严整的修道身体不同，极易遭受性欲侵袭和 luxuria（“过度”）的魔鬼诱惑；大格列高利说，这些力量直接打击男人的腰部。[^p480-108] 加洛林教士强调，对基督的爱不会在“肉欲之床”（in lectulo carnalium voluptatum）上找到。[^p480-109] 教士对于男子气概和身体控制的焦虑，很容易传入世俗精英圈子；甚至圣徒传作者也创造出新颖、虽不免生硬的形象：极端节欲的军阀，在梦遗后反复清洗，对婚床之乐惊恐不已，命令士兵上阵前先把剑刃磨钝。这一策略十分高明：它邀请世俗权贵读者内化禁欲的身体纪律与和平主义价值；同时，由于贵族男子的首要职责是生育继承人并持械作战，它也确保世俗身体永远达不到禁欲理想。[^p480-110]

斯马拉格杜斯的《圣本笃会规注》把世俗和修道男性身体之间的区别说得很清楚：“尘世的士兵沉迷激情和欲望，紧抓不放。”这些男人拥有“软弱而滑溜的武器”（infirma et lubrica arma）。相反，基督的战士“将肉体连同其激情和欲望钉上十字架”。[^p481-111] 他们是上帝“最完美的摔跤手”（perfectissimi luctatores），武器包括信仰之盾和救恩之盔（《以弗所书》6：16—17）。[^p481-112] 修士类似《以赛亚书》中的宦官（56：4—5），尽责事奉上帝，使他们得到“比儿女更好的纪念和名字……永远的名”。从斯马拉格杜斯到彼得·达米安（1007—1072），塑造修道男子气概的作者都喜爱这段经文。[^p481-113] 显然，这些属灵论著深嵌着与世俗世界的竞争，甚至使独身男子相信，自己在追求不朽的能力上，已超过那些能够生育的世俗同辈。通过阳刚的礼仪声音、受约束的私处，以及对身体边界的防守，圣人离开人“在身体中”的位置，进入神“在声音中”的领域。[^p481-114] 因而，对肉体的超越，才是真正检验男子气概的标准。[^p481-115] 在对罗马演说者男性权力的这种禁欲重塑中，达到完善的修士变得像基督；赫拉班·毛鲁斯称基督为“上帝的口，因为他是上帝的圣言”。[^p481-116]
