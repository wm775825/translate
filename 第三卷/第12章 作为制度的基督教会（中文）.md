# 第12章 作为制度的基督教会

托马斯·F. X. 诺布尔（Thomas F. X. Noble）

<a id="pdf-278"></a><!-- PDF page 278; original page 249 -->

我们生活在一个后教会时代。大众和学术调查反复证实，对特定教会团体具有强烈身份认同的人，越来越少。正如本卷大多数研究表明，近几十年来，中世纪研究者，已从几乎专注制度和高层神学，转向普通人及其生活体验。[^p278-1] 尽管如此，中世纪的基督教，与它藉以传播、运作的制度框架，仍不可分离。

本章将以概述方式，从爱尔兰讲到美索不达米亚，沿三条线索，尝试理解作为制度现实的教会。首先，考察制度存在本身的消长：新的教会等级体系创建，其他体系却遭破坏，乃至消失。其次，通过若干说明性例子，探索制度化教会实际上如何运作。第三，在相互补充的教会论、制度身份两个领域，选取一些切入点，追问教会如何理解自身的制度性质。换言之，我们将看到，对结构、职务、法律、观念的共同理解，如何跨越时空。

600年，罗马曾统治的大部分地区，都有运作中的教会等级体系；昔日边界之外，也可见微弱开端。到1100年，通过收缩、扩张的过程，状况已剧烈改变。让我们从东地中海世界出发，顺时针经过北非、西欧，再到东欧，考察全局。教会常受自身无法控制、也难以影响的力量冲击；伊斯兰教兴起、传播，是首要例子。有些地方，地方或区域政治起决定作用；法兰克、斯堪的纳维亚、斯拉夫统治者，将提供<a id="pdf-279"></a><!-- PDF page 279; original page 250 -->这种动力的例子。有时，大范围外交至关重要；德意志与拜占庭在东欧的竞争，正体现这一问题。

### 教会等级体系

以君士坦丁堡为中心的拜占庭帝国正教会，在一系列会议法令中形成，尤其第一次君士坦丁堡会议（381年）、迦克墩会议（451年）的法令；它们赋予君士坦丁堡在教会秩序中仅次于罗马的地位。这些规定，使君士坦丁堡超越更古老的安提阿、亚历山大教座，也超越耶路撒冷；后者的“牧首”地位——下文再论——真正形成于迦克墩会议。君士坦丁堡最初的问题，是本城主教，没有一个界定明确、其权威既获承认又切实有效的辖区。君士坦丁堡主教，即牧首，原则上对本都、色雷斯、小亚细亚，拥有省会主教权利（下文再论）。作为皇权的直接后果，他们也在亚历山大、安提阿牧首区行使一定影响。但到642年，阿拉伯征服削弱、有时切断了君士坦丁堡与叙利亚、巴勒斯坦、埃及的联系。九、十世纪，拜占庭牧首区又将影响扩展到保加利亚、塞尔维亚、罗斯。[^p279-2] 一侧收缩，由另一侧扩张弥补。此外，阿拉伯边境的状况，可能剧烈变化。例如，949至975年，拜占庭在安纳托利亚、叙利亚北部重新征服，促成约30个主教区恢复。[^p279-3] 西地中海也有变化。皇帝利奥三世（717—741年），为表示不满教宗反对其宗教、政治措施，把达尔马提亚、伊利里库姆，以及意大利南部、西西里的主教区，从罗马主教权下，划归君士坦丁堡主教。巴尔干主教区的命运，下文再谈；意大利诸教区，则因穆斯林征服西西里（827—844年）、劫掠半岛，以及意大利南部各种基督教权势人物崛起而受苦。拜占庭帝国，根本无法维持对意大利的权威。到十一世纪中叶，诺曼人征服意大利南部、西西里，又与教宗权结盟，使意大利南部归于教宗权威。究竟有多少主教<a id="pdf-280"></a><!-- PDF page 280; original page 251 -->在某一时刻属于君士坦丁堡管辖，并不容易确定；不过，出席会议的主教人数，可以在一定程度上显示教会影响范围，也可衡量军事、外交问题造成的破坏程度：

君士坦丁堡以东的土地、民族，处于极其复杂的教会、政治环境。从亚美尼亚到埃及的广大地带，有两种根本动力：古代晚期基督论争执的痛苦遗产，以及拜占庭先与波斯、后与阿拉伯人和伊斯兰教的斗争。雅各派、涅斯托里乌斯派基督徒，甘愿顺从穆斯林当局时，两种动力汇合了；穆斯林要求服从、纳税，却不介入基督徒之间的宗教斗争。麦勒凯派基督徒——名称源于malka，皇帝——在政治、神学上面向君士坦丁堡，结果在曾由自己主导的广大东方行省，变成日渐缩小、毫无权力的少数。[^p280-5]

东方最大的基督教团体，是以叙利亚为中心、以安提阿牧首为核心的雅各派教会。安提阿神学家拒绝迦克墩会议法令时，它开始兴起；在雅各·巴拉代乌斯（约500—578年）领导下，发展自身教导，整个运动也以他命名；[^p280-6] 阿拉伯征服期间，又摆脱君士坦丁堡控制。第一次尼西亚会议、第一次君士坦丁堡会议，赋予安提阿对叙利亚、巴勒斯坦、塞浦路斯、阿拉伯、美索不达米亚、波斯、印度的权威。直到七世纪，约有11个省会主教教省。阿拉伯征服，使依附安提阿的主教人数，从约158人，减至可能60人。阿拉伯半岛、波斯湾地区，几乎所有主教区都消失。750年以后，阿拔斯哈里发有时干预安提阿牧首，以及其在整个东方下属主教的任命。基督徒的契约之民地位，使教会难以公开、有效运作。[^p280-7]

东方的涅斯托里乌斯派基督教团体，包括那些在涅斯托里乌斯（451年后卒）及追随者<a id="pdf-281"></a><!-- PDF page 281; original page 252 -->于430年以弗所会议遭谴责以后，仍接受其教导的人。〔译注：会议年代原文作430年；以弗所大公会议召开于431年。〕一度，涅斯托里乌斯派与合一性论派争夺叙利亚；但449年失去埃德萨这个据点后，自由活动范围转移到美索不达米亚。在那里，他们在波斯统治下获得相当大的行动自由，因为波斯人不信任效忠安提阿的雅各派主教。到498年，塞琉西亚—泰西封的涅斯托里乌斯派教会总主教，宣称与其他东方牧首平等，但后者从未承认。他本人至少有四位下属主教；阿拉伯征服时的八个省会主教座，到1000年增至约20个。1200年，涅斯托里乌斯派主教，可能多达200至250位，分布从中国到阿拉伯。770年代，总主教驻地迁至巴格达；哈里发频繁干预其继任。[^p281-8]

亚美尼亚教会，在先是罗马—波斯、继而拜占庭—阿拉伯竞争的夹缝中形成。安提阿、君士坦丁堡、罗马，都曾在某个时期，宣称对亚美尼亚教会有权威；与此同时，亚美尼亚教会总主教，坚持与其他所有牧首平等。总主教座以埃奇米阿津为中心，下辖四五个牧首区；亚美尼亚在这一点上的术语，很不寻常。究竟有多少主教区，很难说。703年，总主教伊姆巴特与哈里发达成协议，由他保证本民族行为良好，换取事实上摆脱君士坦丁堡。随着哈里发国衰弱，九世纪至十一世纪初，亚美尼亚成为实际独立国家。教会是唯一的“民族”制度；塞尔柱突厥人注意到这一点，因此在十一世纪中叶征服当地时，使教会陷入无能为力的状态。[^p281-9]

耶路撒冷也有重要基督教团体。直到451年迦克墩会议，耶路撒冷主教才获承认为牧首。波斯、穆斯林征服造成巨大破坏，主教的地位，大量被雅各派、甚至涅斯托里乌斯派教会取代。不过，在东方牧首区中，唯有耶路撒冷的正式教会，仍保持麦勒凯派性质，也与罗马维持零星关系。638至691年，牧首宝座空缺，表明阿拉伯征服的影响。

哈里发欧麦尔一世（634—644年）同意尊重教堂、教士；除残酷的哈基姆（996—1021年）统治外，环境大体尚可忍受。[^p282-10]

皇帝控制亚历山大的时期，埃及宗教局势一直紧张。人口、教士多数属于合一性论派，正式教会却是麦勒凯派，即迦克墩派。埃及形成的独特基督教形态，通常称为“科普特”，名称来自礼拜所用的埃及方言。波斯人夺取亚历山大后，一位科普特牧首当选；但拜占庭收复该城时，他逃走了，直到641年阿拉伯人驱逐拜占庭世俗、宗教当局，才回来。牧首区原设亚历山大，后来迁至达姆鲁，再于1046年迁到开罗。牧首始终视自己与罗马、安提阿、君士坦丁堡牧首平等，似乎管辖约50至60位主教。科普特教会的重要成就之一，是把基督教传播到努比亚。除哈基姆统治期外，该教会兴旺发展。[^p282-11]

阿拉伯人从埃及边境到大西洋征服北非，似乎抹除了古代晚期繁荣的基督教文化。资料几乎完全缺失，可能使状况看起来比实际更暗淡，但北非似乎的确发生了中世纪早期基督教会最严重的收缩之一。少量基督徒肯定存续，十一世纪教宗格列高利七世（1073—1085年）还同其中一群通信，但有组织的教会消失了。[^p282-12]

西欧呈现多方面景象。现存资料分布不均，有时难以解释。总体上，这是扩张的历史，不过九、十世纪维京入侵，有时造成破坏。例如，832／833年建立的汉堡主教区，845年遭焚，主教座不久迁至不来梅。983年斯拉夫异教起义，暂时关闭勃兰登堡、哈弗尔贝格主教座。收缩最明显的证据，来自711至716年穆斯林征服后的伊比利亚半岛；不过，许多主教继任的中断，发生在最初征服很久以后。以下若干有代表性的继任断档，可说明情况：

追踪爱尔兰教会发展，因为资料相互矛盾、史学争论激烈而很复杂。争论围绕主教权威、世俗统治、修道权力三者的关系展开。[^p283-14] 整个中世纪早期，阿马、基尔代尔经常、爱奥那偶尔，宣称具有总主教／省会主教地位和权威，却很少有证据说明，这些主张有效。不过，即使无法看到实际如何运作，等级、教省的概念始终存在。至于资料问题，可以用叙事资料所列主教数说明：七世纪23位，八世纪25位，九世纪50位，十世纪48位。[^p283-15] 根据这类证据下结论，完全不可靠。一个由地区主教领导、不断成长、持续运作的爱尔兰教会，似乎无可争议；实际如何工作，却大有疑问。

由于资料更丰富，英格兰总体情况清楚得多，故事主线是持续扩张。罗马不列颠有初步教会组织；约450至600年，异教盎格鲁—撒克逊人定居，似乎抹除了后来英格兰地区的基督教结构，只在凯尔特色彩更浓的西部，留下零星残余。600年前后，不列颠经历两轮基督教化努力。从科伦巴（597年卒）563年创建的爱奥那修道院出发，爱尔兰传教士在苏格兰、诺森布里亚传播自身习俗，约635年建立林迪斯法恩主教区。597年，教宗格列高利一世（590—604年）派遣的传教士，在肯特登陆。格列高利依据罗马帝国文书，计划在伦敦、约克设置省会主教座，各配备<a id="pdf-284"></a><!-- PDF page 284; original page 255 -->12位下属主教。计划最终证明不切实际。肯特诸王所在地坎特伯雷，被设为省会主教座；罗切斯特、伦敦也很快设立主教座，到625年，约克同样升为主教座。遵循罗马、凯尔特习惯者之间的竞争，导致664年惠特比会议；与会教士、平信徒，决定采用罗马习惯。668年，罗马派狄奥多若任坎特伯雷总主教（668—690年）。抵达后，他发现伦敦主教有丑闻，约克主教任职不合规范，另有一位主教没有固定教座。经过耐心努力，狄奥多若建立了运作中的等级体系，包括两个省会主教座和另外12个主教区。英格兰政治地理细碎、维京入侵、缺乏可据以建立严密教会结构的城市核心，都使情况复杂。后世对狄奥多若的方案，有所调整。几个典型例子是：957年，诺福克、萨福克两个小教座，在诺里奇合并；909年，大型舍伯恩教区分割，新建克雷迪顿、韦尔斯教座。1046年，克雷迪顿与舍伯恩又在埃克塞特合并，韦尔斯教座则于1088／1091年迁至巴斯。[^p284-16]

欧洲大陆不同地区，教会发展很不一样。莱茵河以西、多瑙河以南，也就是原属罗马帝国的土地，大体延续，仅有一些调整。莱茵河以东、属于法兰克诸王国和帝国的日耳曼地区，显著增长。斯堪的纳维亚、斯拉夫地区，则是基督教世界的全新成员。

昔日罗马地区，帝国留下一个分布广泛的城市（civitates，原文释为罗马行省首府）网络，大部分从四世纪或更早，就有主教。高卢中部、南部，网络更密，教会辖区更小，主教往往是强大的地方人物。越往北，城镇、主教越少，单一主教权下的领土越大；无论好坏，教会结构与法兰克王政之间的联系，也越密切。政治动荡，无论何时何地，都威胁教会结构顺畅运作；七世纪后半叶，法兰克诸国教会受到破坏，但情况从未坏到同时代、或后世批评者声称的地步。[^p284-17] 八世纪，开启近两个世纪的稳定增长。

716年，巴伐利亚公爵接洽教宗，希望在本土创建教会等级体系。此后数十年，萨尔茨堡、弗赖辛、帕绍、萨本、雷根斯堡建立主教区。直到798年，在查理曼支持下，萨尔茨堡才升为省会主教座。在日耳曼北部、中部，盎格鲁—撒克逊传教士威利布罗德（约658—739年）、博尼法斯（约675—754年）的努力，在四方面至关重要。第一，乌得勒支、维尔茨堡、艾希施泰特、比拉堡、埃尔福特等地，新建主教区，虽然后两者未能延续。第二，两人都与关键法兰克统治者——加洛林宫相查理·马特（714—741年）、卡洛曼（741—747年）、丕平（741—751年）——建立了牢固、但并不总是轻松的工作关系，推动法兰克人，对境内教会进行结构改革。第三，两人都拜访罗马，与教宗权建立密切关系，成为教宗影响在阿尔卑斯山以北的代理人。第四，732年，博尼法斯获授披带（pallium），即教宗赐给省会主教、表示与罗马密切关系的白羊毛礼服；不久，他被任命为总主教，起初没有教座，后来设于美因茨。博尼法斯竭力建立省会主教等级体系，却在日耳曼成果有限，在西法兰克完全未成功，尽管他试图提升兰斯、鲁昂。其工作在以后几代，结出成熟果实。查理曼（814年卒）立遗嘱时，向21个省会主教座捐赠。到九世纪，每位省会主教——在法兰克通常称总主教，下文再谈——都必须向罗马求取披带。查理曼经过长期战争征服的萨克森，是增长的突出例子，主教区从零增至八个。[^p285-18]

十、十一世纪，西法兰克王国结构变化很少，东方却继续增长。在加洛林时代美因茨、科隆、特里尔、萨尔茨堡总主教座之外，又增加汉堡—不来梅，下辖四个新主教座，以及马格德堡，下辖五个。法国总主教赴罗马求披带的证据很少，德意志总主教却经常如此。此外，德意志统治者、主教，密切关注斯堪的纳维亚、斯拉夫邻人。[^p285-19]

加洛林传教士曾努力把信仰带入斯堪的纳维亚，却未取得持久成功。丹麦国王哈拉尔德·克拉克826年受洗，与哈拉尔德·戈姆松，即“蓝牙”哈拉尔德<a id="pdf-286"></a><!-- PDF page 286; original page 257 -->965年受洗之间，隔了许多年。斯堪的纳维亚各国的资料，都赋予国王关键角色；我们也能辨认德意志统治者、主教，英格兰国王、传教士的重要作用，以及教宗权的一些贡献。在哈拉尔德（961—985年）即位前，海泽比肯定已有主教区，奥胡斯、里伯可能也有，创建者是汉堡—不来梅总主教阿达尔塔格（937—988年）。到1060年，丹麦境内有九个主教区。1053年，教宗利奥九世任命汉堡—不来梅的阿达尔伯特（1043—1072年），为北方教宗使节、代理人。他似乎想成为某种北方牧首。1104年，隆德升为丹麦总主教座，遏止了汉堡—不来梅的野心。自十一世纪中叶，丹麦诸王一直试图为王国取得教会独立，部分为了摆脱德意志王权、教会影响。挪威的基督教化，始于“善王”哈康（921或935—960年）；他在英格兰埃塞尔斯坦国王（924／925—939年）宫廷长大，可能带一位英格兰主教回挪威。较晚传统，把中心角色赋予奥拉夫·特里格瓦松（995—1000年），以及奥拉夫·哈拉尔德松，即圣奥拉夫（1015—1030年）。必定包含真实成分的传说，把劝说冰岛人于999／1000年接受基督教的功劳，归于奥拉夫·特里格瓦松。国王克努特统治英格兰（1016—1035年）、丹麦（1018—1035年），又控制挪威大部，似乎开始规范教会结构，也许依据在英格兰所见。不过，直到1152年，尼达罗斯—特隆赫姆才成为省会主教座。瑞典情况远不清楚。奥洛夫·舍特科农（约994—1020／1021年）是首位受洗国王，传统上定于1008年；首个主教区于1014年设在斯卡拉。瑞典大部，直到十二世纪相当晚时仍奉异教，王国组织形成于那个时期，1164年乌普萨拉省会主教座的创建，也是如此。斯堪的纳维亚教会的成长，是非凡成就。[^p286-20]

斯拉夫世界，在历史、族群、语言，因而教会方面，都很复杂。两股强大动力，既帮助、也妨碍基督教化：地方政治压力，以及德意志—拜占庭竞争。九世纪，克罗地亚、摩拉维亚、波希米亚等地，虽有充满希望的开端，但世纪末的马扎尔入侵，造成重大破坏。扎实、有未来的工作，是<a id="pdf-287"></a><!-- PDF page 287; original page 258 -->十世纪的产物。我们先看巴尔干与波罗的海之间的一带领土，再转向基辅、罗斯。[^p287-21]

克罗地亚基督教化，始于古代，但六世纪阿瓦尔入侵，严重破坏早先成就。阿瓦尔战败后，萨尔茨堡主教、阿奎莱亚牧首，以德拉瓦河划分中南欧传教地区。因此，克罗地亚归阿奎莱亚，同时始终受到教宗重要影响。斯普利特重新建立省会主教座，首位已知主教、宁的格尔古尔，于860年由教宗尼古拉一世祝圣。几年后，克罗地亚人与教宗权，同日耳曼人路易（806—876年）争执；后者想在刚进入保加利亚境内的西尔米乌姆，即斯雷姆斯卡米特罗维察，建立省会主教座。在波希米亚、摩拉维亚，君士坦丁—西里尔（826—869年）、美多迪乌斯（约815—885年）兄弟，是摩拉维亚领袖向拜占庭请求派来的传教士。他们长久辛劳，使人改宗，却主要因东部德意志国王、巴伐利亚主教强烈反对，未能有效建立稳固教会结构。马扎尔入侵造成破坏，但一些基督教团体存续，在名义上隶属雷根斯堡主教。十世纪，普热米斯尔王朝整合当地，大体与德意志奥托诸王结盟；这一合作，产生了布拉格（973年）、奥洛穆茨，亦称奥尔米茨（1063年）两个主教区，都隶属于美因茨总主教。[^p287-22]

波兰教会形成得相当快。约964年，梅什科国王娶布拉格的博莱斯拉夫一世之女多布拉娃，966年受洗。968年，资料记载约尔丹主教（968—982年），似乎驻于波兹南，隶属马格德堡。马格德堡总主教，始终想向东扩展权威；梅什科992年向罗马献波兰于圣彼得，可能因此而起。他可能想争取教会摆脱德意志，或确认波兰独立。999年，奥托三世、博莱斯瓦夫·赫罗布里，在格涅兹诺建立总主教座，立即把克拉科夫、弗罗茨瓦夫、科沃布热格的新主教区，划归其下。数年后，波兹南脱离马格德堡，归属格涅兹诺。中世纪盛期，波兰教区在严重政治不稳定中，仍持续存在。[^p287-23]

再往南，便是保加利亚、匈牙利两个重要例子。保加利亚国家，始于680年代原始保加尔人与斯拉夫人的融合，双方都信异教。附近可能有一些基督教化、希腊化的斯拉夫人，但记录模糊。教会创建，始于鲍里斯汗（844／845—888年）时代，他于864年受洗，随即与教宗尼古拉一世（858—867年）通信；教宗回答了106个问题，却不保证设总主教座。于是，鲍里斯转向拜占庭，获得希腊主教。西缅汗（893—927年）时代，保加利亚教会，成为“拜占庭共同体”中的自主成员，总主教驻地在普雷斯拉夫、德里斯特拉间交替。总主教、主教通常是希腊人，由君士坦丁堡任命。皇帝巴西尔二世（958—1025年）对保加利亚发动大战，摧毁西部，严密控制东部。总主教座迁至奥赫里德，保加利亚关于牧首区的主张被取消。至少四个主教区，熬过巴西尔的进攻。[^p288-24]

异教马扎尔人，蹂躏中欧及其他地区，直到955、970年战败，才开始在潘诺尼亚平原定居，与当地斯拉夫人混合。971年，德意志皇帝与拜占庭讲和，972／973年，国王盖萨（997年卒）转向奥托一世，寻求结盟。匈牙利一侧，是敌对拜占庭人，得到新保加利亚盟友协助；另一侧，是野心勃勃的德意志人。主要由巴伐利亚指导的拉丁传教工作，流入匈牙利。局势复杂，也可从盖萨妻子绍罗尔特的身份看出：她是东方边境王公久拉的女儿，后者是一位希腊基督徒。盖萨及其子沃伊克，似乎于973年受洗。创建教会的关键工作，始于沃伊克（997—1038年），他更常以洗礼名斯德望为人所知。他于1000／1001年，成功在埃斯泰尔戈姆，即格兰，取得总主教座，下辖五个主教座；1008年，又在东部考洛乔取得第二个总主教座，最初下辖三个。虽然匈牙利最终成为拉丁礼国家，考洛乔始终向希腊影响开放。[^p288-25]

奥尔加女公爵954／955年，或可能946年前往君士坦丁堡之前，罗斯土地上肯定已有基督徒。阿拉伯地理学家说，早在944年，基辅就有教堂。她未能取得<a id="pdf-289"></a><!-- PDF page 289; original page 260 -->主教，于961／962年转向奥托一世；他派遣圣阿达尔伯特（981年卒），即后来布拉格首任主教。此人一事无成，不久即归。〔译注：此处原文如此，应与本卷第11章的布拉格的同名圣人区分；后者于983年就任、997年殉道。〕奥尔加可能因了解保加利亚的发展而有所行动。基辅王公弗拉基米尔（980—1015年），因与拜占庭结盟，于988／989年受洗，开始认真推进领土基督教化。罗斯何时取得首位主教，并不清楚；首次确凿记载见于1037年，但早至967年也可能。基辅圣索菲亚主教座堂，可能于1046年奉献，但不排除教座更早。十一、十二世纪陆续新设主教区，最终达到17个。基辅早期主教，多为君士坦丁堡任命的希腊人，但总主教通常自行任命下属主教，偶受罗斯统治者干预。[^p289-26]

### 教会结构

概述了教会等级体系从昔日罗马帝国向外扩展的创建过程，现在该举例，看看这些体系如何组织、如何工作。西欧证据，比其他任何地方都丰富，但诸多线索暗示，同样的基本原则适用于各处。罗马时代建立的等级体系，传给后世。典型情形，是在罗马行省首府城市设省会主教座，周围有数量不等的下属主教。在西方大部分地区，从加洛林时代开始，省会主教通常称总主教；其他大部分地区，则保留省会主教称号，东方部分地区又常用教会总主教及总主教座的称号。不过，整个基督教世界，都可见总主教；西方有时也把这一头衔，作为不含管辖权意义的个人荣誉授予。

教会基本结构，包括牧首区——其中包括通常不用牧首头衔的罗马教宗权——省会主教或总主教、主教、司祭。也有较低级圣职，通常包括执事、副执事、诵经员、驱魔员、司门员。东方常见领唱员，君士坦丁堡直到十二世纪，还有协助成年妇女受洗的女执事。最大的两个教会，是罗马与君士坦丁堡。

罗马主教与其他主教一样，由“教士与民众”选举。任何时期，选举过程都难以观察，竞争派别的构成、利益，也难确定。直到741年匝加利亚一世当选时，新教宗仍须获得君士坦丁堡皇帝确认，才能接受祝圣。虔诚者路易（814—840年）治下，加洛林人坚持，新教宗须先与加洛林皇帝重申amicitia, pax et caritas，即“友谊、和平、爱”的盟约，才可祝圣；但他们不要求过去拜占庭的确认权，只要求选举合乎教规。769年以前，“合乎教规”究竟意味着什么，很难说。该年一次罗马会议，有12位法兰克主教参加，试图把选举者限于罗马枢机教士（下文再论）。到816年，“民众”再次参与选举。直到十一世纪中叶，“民众”基本意味着罗马贵族；加洛林人在罗马影响渐衰，使合乎教规选举的要求，成为空文。1059年，尼古拉二世主持罗马会议，发布选举法令，把首要作用赋予枢机主教，同时为德意志皇帝保留模糊权利。十二世纪初，罗马枢机司祭、枢机执事，也取得选举权，形成52人或53人的枢机选举团；后来程序稍有调整，但这种选举机构延续至今。德意志皇帝，只有极少几次（963、964、1046年），废黜在位教宗、强立自己的候选人。加洛林统治者从不这样做；但十世纪，罗马贵族经常介入任命教宗的过程。[^p290-27]

礼仪管理，从罗马主教座堂、拉特兰圣若望教堂，以及其他“牧首”巴西利卡的祭坛向外展开；这些教堂的正式主礼者，虽然不是每日主礼，都是教宗。教宗不在时，近郊主教——奥斯蒂亚、韦莱特里、波尔图等郊区城镇的主教——按复杂轮值，在罗马主要祭坛举行礼仪。他们通常七位，是罗马教会的枢机主教。与主教座堂、牧首巴西利卡紧密相连的，是领衔教堂（tituli）；本期初约20座，期末28座。每座领衔教堂，有数位司祭，一位主持者为领衔司祭。他们就是罗马教会的枢机司祭，担任教宗主要顾问，也常被选为教宗。几个世纪里，教宗本人按固定轮值，在领衔教堂举行全年多达180次的驻堂弥撒，以可见方式，体现对<a id="pdf-291"></a><!-- PDF page 291; original page 262 -->“自己的”城市教会的监督。[^p291-28]

行政体系以拉特兰宫为总部，由少数高级官员、一批执事组成。例如，首席书记（Primicerius）领导公证员、档案部门；礼仪总管（Nomenculator）主管仪式；库务官（Arcarius）、财务官（Saccelarius）监督收入征集、支出。其他官员管理教会广阔地产，维护罗马教堂，世俗权威消失以后，又主持法庭。执事承担种种临时任务，经常出任使节，但首要职责是各种慈善服务。七位“地区”执事，管理罗马各区，是罗马教会的枢机执事。[^p291-29]

教宗实际权威，限于罗马及近郊主教区，尽管他们经常试图把权力扩及拉文纳、米兰，以及意大利北部其他教座。多年间，教宗逐步使罗马会议，成为治理意大利更有效的工具；会议数量显著增加，说明这一点：

通过授予披带，教宗对西方省会主教／总主教的权威增长。关键先例，是博尼法斯宣誓效忠，誓词与近郊主教相同。约800年起，省会主教当选后，通常向罗马求取、接受披带；原则上，在得到披带以前，不能行使省会主教职务，也不能登上主教宝座。这个正在形成的体系，象征所有主教权威，均被联结于罗马主教权威；但教宗实际权力，受制于无法控制总主教任命，以及对已获任命者相对缺乏强制能力。

教宗对整个西方教会的权威有限。古代以来，教宗要求“重大案件”交罗马仲裁；实际却很少能把案件纳入自身审理范围。《伪伊西多尔教令集》，是九世纪法兰克制作的一组非凡伪造文书，大大加强了教宗司法权威；但其根本动力，是加洛林世界的下属主教，试图限制<a id="pdf-292"></a><!-- PDF page 292; original page 263 -->省会主教权力，而非增强教宗权。[^p292-30] 格列高利派遣英格兰传教团，广为人知，但教宗在中世纪早期传教活动中的实际作用，是次要的。[^p292-31] 最早由教宗册封圣徒，发生于千年之交前后；不过，教宗在册圣中的角色，直到十三世纪才规范化。[^p292-32] 教宗始终派使节，向统治者、教会人士处理特定事务，但正式使节制度，到十一世纪才开始形成。[^p292-33] 教宗有两种强制纪律工具：绝罚，即使个人与教会圣事、其他基督徒的交往隔绝；禁令，即暂停某个地区大部分圣事服务，向特定个人施压。前者常用于重大案件，但直到1054年与君士坦丁堡决裂，以及格列高利七世多次绝罚德意志国王亨利四世以前，并不十分引人注目。中世纪早期，偶闻禁令，但真正突出，始于亚历山大三世1163年对苏格兰施行禁令。[^p292-34] 早在教宗开始在这些方面承担领导作用之前，加洛林人已向罗马寻求教会法、[^p292-35] 礼仪[^p292-36] 的权威指导。在圣像、圣灵发出等问题上，加洛林人与教宗同意保留分歧。大量赴罗马朝圣的人，提升了教宗声望，但他们是为在使徒、殉道者墓前礼拜而去。[^p292-37] 给总主教授披带，加强其与罗马联系，尽管谁能成为总主教，教宗起初几乎无权置喙。中世纪盛期的“教宗君主制”，在较早几个世纪里，只隐约可见。

君士坦丁堡的“大教会”，即圣索菲亚教堂，同样规模庞大、结构复杂，以直接、间接方式发挥影响。[^p292-38] 君士坦丁堡牧首，按以下方式产生：“驻都会议”（下文再谈）的省会主教，将三位候选人名单呈交<a id="pdf-293"></a><!-- PDF page 293; original page 264 -->皇帝；皇帝可择一，或另提第四人。随后，他在马格瑙拉宫宣布、授职，下一个星期日，新当选牧首，在圣索菲亚接受祝圣。西方没有这种突出的皇帝角色。牧首职责包括维护正统、镇压异端，牧灵及纪律管理，领导教会法庭，监督礼仪，控制教产，监督直接隶属牧首区的修道院，以及同皇帝打交道。

大教会在七世纪，也许有600名官员，后世也少不了多少。如同罗马，君士坦丁堡既有礼仪、也有行政方面；但各部门虽然高度细分，整个体系分隔却不那么严格，导致执事掌管司祭等不常规现象。官员称为archons，主要部门称offikia，起初由执事负责，后来由其他教士、甚至平信徒领导。五大治理部门，由五位执事组成的“五人组”（pentas）统辖，与罗马枢机执事有些相似。大管家（Great Oeconomos）掌财务、地产；圣器保管官（Skeuophylax）主管礼仪、仪式，负责礼服、器皿；大修院监察官（Great Saccelarius）控制首都及周边修道院；首席辩护官（Protecdicus）负责纪律、婚姻证书、避难权、悔改的背教者、外来改宗者；大文书总管（Great Chartophylax）领导文书处、档案部门。

正教会一个独特之处，是“驻都会议”（endemousa synodos）。它由任一时刻恰在君士坦丁堡的省会主教、主教组成，每周开会三次，由牧首主持；牧首缺席时，文书总管主持。主教座堂官员准备议程，协助讨论。会议至五世纪已经存在，十世纪变得重要。

牧首权威，因数种因素而复杂化。伊斯兰教兴起，是最大挑战。六世纪末至八世纪初，拜占庭引入军区治理制度，倾向于使世俗、教会地理分离。圣像破坏，损害牧首与某些省会主教的关系。[^p293-39] 权威扩展到保加利亚、罗斯等新地区，则受到地方敏感情绪，以及地方、帝国官员行动阻碍。

基督教组织中的数百个主教区，规模都小于几大牧首区。在不同时期，尤其西方，某些主教——通常但并非总是省会主教——被视为代理主教。[^p294-40] 也就是说，他们通常由国王、有时应地方教会坚持，被安置于教宗与其他主教之间的等级位置。梅斯、桑斯、兰斯、汉堡—不来梅、美因茨、特里尔、马格德堡、米兰、拉文纳，都曾在不同时期发挥此作用。雅各派教会，有自己的中间管辖形式。七世纪起，通常驻提克里特的东方马弗里安（Maphrian），为面向安提阿的东方地区，担任某种副牧首。[^p294-41] 不过，牧首、教宗、代理主教、省会主教，全都是主教。因此，我们该问：普通主教做什么？

至少从三世纪，主教就是各地基督教会的关键职员。其角色、职责，自然随时间发展。到中世纪早期，主教主要职能包括：通过教会会议治理；授予圣职；监督教士知识、道德训练；讲道、教导；反对异教徒、异端；祝圣教堂、祭坛；组织、主持礼仪；照顾穷人、寡妇、孤儿；管理本教会地产财富；直接或通过下属主持教会法庭；祝福地方教堂施行圣事所用圣油；每年、有时每半年巡视教区。

主教理应由本教区教士、民众选举，但数种因素，不利于地方、教士掌控过程。主教太重要、太有影响，统治者不可能不关心；地方贵族精英的政治、社会、经济利益，也与主教治理交织。拜占庭帝国内，皇帝处处积极干预，新兴基督教地区的统治者，也是如此。穆斯林当局仔细关注境内主教选举。法兰克、后来的德意志国王与皇帝，尤其关心任命，因为主教是王权行使的关键代理人。主教去世，主教座堂教士（下文再谈），向统治者请求准许举行选举。统治者通常任命巡视员，在新主教当选前，监督教座；“教座”一词，来自sedes，即“座位”。新当选者，被呈交<a id="pdf-295"></a><!-- PDF page 295; original page 266 -->国王，后者可以拒绝接受。拒绝权，等同指定权。921年，教宗若望十世告诉科隆总主教，“古老习俗”准许国王任命主教。[^p295-42] 十一世纪中叶，教宗拒绝这一习俗，促成叙任权之争。[^p295-43] 许多主教，尤其十、十一世纪的德意志主教，曾在王室礼拜堂服务，是统治者信赖的伙伴。德意志主教，往往来自少数家族。900至1046年，罗马贵族支配教宗权；意大利其他地区、法国南部的任命，也往往被城市精英控制。[^p295-44]

主教有许多助手（ministri），协助完成多重任务。教士长（primicerius）或领唱员（cantor）监督礼仪；学监（scholasticus）领导学校；保管员（custos），通常在圣器管理员（sacrista）、库务员（saccarius）协助下，监督主教座堂动产，从钱财到礼仪书籍、器皿、标志物。主管（praepositus），由内务官（camerarius）、文书官（cancellarius）协助，构成主要行政、财务官员。总执事（archdeacon）常充当主教的某种代理人。[^p295-45] 可能受禁欲、修道影响，至少四世纪起，主教座堂教士，有时组织为教士团（chapter），名称来自他们制定、采用的规章条款（capitula）。六世纪高卢，开始听说clerici canonici，即咏祷教士。并非每所主教座堂，都有咏祷教士团，也并非每个团体都属于主教座堂。梅斯的克罗德冈，开始规范咏祷教士生活；虔诚者路易816—819年的立法，则着手在整个教会范围，把这一阶层系统化。[^p295-46] 平均一所教会，可能有30至40位咏祷教士，但沙特尔有72位、讷韦尔60位、欧塞尔50位。[^p295-47]

主教治理的常规机制有两种。第一，省会主教理应每年至少召集下属主教开会一次；教区主教则每年与司祭会面，如可能，应在圣周四，即司祭来主教座堂领取圣油时。会议现存证据零散，却仍证明这是有效体系。法兰克世界，至少有<a id="pdf-296"></a><!-- PDF page 296; original page 267 -->169次会议，从博尼法斯时代延续至九世纪末，留有某种文献。[^p296-48] 本卷涵盖的整个时期，英格兰教会定期集会，有时具有“全国”意义，更常见的则是地方性会议。[^p296-49] 900至1100年，法国教会的不同部分，集会近160次；大多与加洛林前例、同时代德意志会议相比，规模较小，性质地方化。同两世纪，德意志举行近60次规模不等的会议。两地十一世纪的次数，都比十世纪大幅增加。972年起，伊比利亚教会一度旺盛的会议生活，也恢复活力，举行20多次会议，许多相当地方化。匈牙利、亚美尼亚、巴格达（涅斯托里乌斯派）、埃及，各有一次会议为我们所知。雅各派教会，至少集会三次。君士坦丁堡的会议传统，在869—870、901年的大型会议之后，所留痕迹不甚突出。[^p296-50] 不过，文献稀少的驻都会议日益重要，也许使现存记录造成错觉。主教确实与司祭会面，处理广泛的道德、灵性、纪律问题。加洛林时代，现存54份主教“章程”，大体反映教区会议的工作。[^p296-51] 人们怀疑，许多法国会议，以及部分德意志会议，也是教区会议。这些刊布不佳的记录，仍需更多研究。

主教治理的第二方面，是巡视所辖地区。通常每年一次，虽然立法有时要求两次。主教，偶尔其代表，在地方团体会见“会议证人”（testes synodales），通常七位。他们被认为品行正直，可能是平信徒，也可能是教士，须就谋杀、伪誓、通奸、乱伦、卖淫、盗窃、迷信，以及遵守斋期、节日等问题作证。个人也可能被检查，是否理解《主祷文》和信经。对于被这些证人告发的人，后来如何处置，证据不足。[^p296-52]

<!-- PDF page 297; original page 268 -->

主教、司祭，如何在自己权下的土地实行日常管理？东方及西方新基督教化地区，资料不是缺失，就是沉默。法兰克、盎格鲁—撒克逊统治地区，则有大量、虽然令人困惑的记录。中世纪早期教会史最复杂、最模糊的问题之一，围绕地方教会性质，以及主教与地方教会间的结构关系展开。地方教堂，无论洗礼教堂或简易祈祷所，原则上由主教在城外辖区建立，最初由主教座堂教士服务。渐渐地，地方教堂有了驻堂司祭，成为当地人定期听弥撒、受洗、安葬的地点。七世纪高卢，大部分人住在距教堂七英里内；稍后的英格兰，大部分人口距团体教堂五至六英里。[^p297-53] 王室、教会会议立法，试图保护这些教堂的完整。另外两种教堂，也散布乡村：平信徒在庄园创建的“私属教堂”，以及许多负责本地区“灵魂照护”的修道院建立的乡村教堂。[^p297-54] 出于不同原因，这两类教堂的持有者，不愿主教拥有过多权威。中世纪早期，修道院的牧灵照护逐渐衰退；叙任权之争的一项较有效成果，是限制平信徒控制地方教堂。数量大致如何？英格兰有数百所团体教堂；丹麦十二世纪有1000个堂区，许多无疑更早；基辅及周边，可能有400座教堂；梅斯这样的中型城镇，城内九座、城外11座、修道院村庄六座。[^p297-55] 换个说法，中世纪早期，许多地方的堂区制度稳定增长；一部分是王室、教宗政策的实施，一部分是坚定主教排除障碍的结果。

那么，主教如何对乡村教堂，不论何种性质，行使权威、影响？会议、巡视很重要，但更重要的是各种中间行政层级。法兰克世界，尤其教区往往很大的北部，有时任命乡村主教，<a id="pdf-298"></a><!-- PDF page 298; original page 269 -->在乡村地区（chora）代表主教权威。[^p298-56] 九世纪，乡村主教制越来越有争议，最终被废除。乡村权威，开始更直接地从主教座堂向外延伸。总执事开始管理主教座堂教士，逐渐在乡村取得地域管辖权。大型乡村教堂，有时被学者称为“母堂区”，通常由总司祭（archpriest）领导，往往负责较小教堂。随着越来越多乡村教堂独立设立，领土被划为由区长（dean）管理的区。区长定期巡视所属堂区，是主教巡视制度的简化版本。中世纪早期，欧洲没有任何地方，已完全形成堂区制，或总执事、总司祭、区长、区长辖区的结构。事实上，1100年的英格兰，主教与堂区之间，还没有中间行政层级。法国的制度，发展最完备。[^p298-57]

因此，许多力量，共同促成一个既有等级、又分工密集的体系；但也有抵消力量，以及影响不明确的因素。前者例如，高层政治对教会地理的损害。九世纪中叶，加洛林内战分割科隆、兰斯、特里尔等大型教区，使总主教艰难控制那些已属不同国王的下属主教。许多会议由国王、皇帝召集，他们把权力借给教会工作，却有时也支配教会。王室、贵族任命主教，经常推举杰出人物，也同样常让灵性、道德或知识才干平庸者，执掌教会体系的关键节点。私属教堂，是统一主教控制扩展的重大障碍，但没有控制这些教堂的精英同意，教会又无法工作。古老、根深蒂固的修道权利，几乎处处阻碍主教权威；某些修道院，如博比奥、贝内文托、克吕尼、法尔法、富尔达、蒙特卡西诺、圣但尼，更享有教宗赐予、免受主教控制的特权。[^p298-58] 许多主教，把收入中属于教士的份额，在自己与咏祷教士之间分配，分别称主教食俸（mensa episcopalis）、教士团食俸（mensa canonicorum）。咏祷教士，尤其德意志的，拒绝共同生活，领取个人俸禄（prebends），<a id="pdf-299"></a><!-- PDF page 299; original page 270 -->便往往分割教会财产、收入。[^p299-59] 加洛林人发展三管齐下的策略，使主教更紧密地依附统治政权，即豁免权、王室保护、护卫官制（advocacy）。豁免权，剥夺普通世俗官员的introitus、exactio、districtio，即进入、征收、司法管辖之权；享有豁免的领土，给予特权持有者——常为主教——相当大权力。王室保护，使主教处于统治者的法律、道德权威之下，也在一定程度上，隔绝地方政治纷扰。到802年统一要求实行的护卫官制，缓和了禁止征收对国家利益造成的损失。这存在某种交换：主教本人及领土，也须承担各种王室服务。主教可以行使铸币、征收通行税等“王室”权利，有些更被任命为伯爵。教会、世俗职责界线的模糊，无疑增强了主教权力、影响，却也可能危险地损害其宗教权威。“改革者”经常既反对世俗势力控制主教，也反对分配给主教的世俗角色。[^p299-60]

### 观念基础

最后，我们可从制度本身，转向教会论，即教会治理所依据的教义、思想观念。前面已注意，东方牧首区形成时，宣称与资历更老者平等；这种平等，实际上从未实现，但整个中世纪早期，东地中海基督教领袖，都用“五牧首制”（Pentarchy）说话：一个由罗马、君士坦丁堡、安提阿、亚历山大、耶路撒冷领导的五首教会，藉大公会议（351、381、451、553、680、787年），获得可见表现。[^p299-61] 〔译注：此处第一场会议原文列351年；本卷其他章节将第一次尼西亚会议定于325年。〕后三个牧首区，被吸收进伊斯兰世界，七世纪至十字军东征间，很少同其他同僚共同参与。余下罗马、君士坦丁堡，处于不安的张力中。君士坦丁堡牧首，愿赋予罗马某种荣誉优先，却不给予特定管辖或神学权利。[^p299-62] 对正教世界，君士坦丁堡的思路，是一个“拜占庭共同体”，<a id="pdf-300"></a><!-- PDF page 300; original page 271 -->即教会间的合作联盟，接受牧首指导，即使未必受其管辖。[^p300-63] 罗马则时而提出宏大主张，却难以转化为具体权利、权力。

教宗依据什么原则行动？利奥一世（440—461年）谈到自己的plenitudo potestas，即“权力的完满”；但话是在特定争执中说的，很难看出，他设想这种“全权”扩展多远，而且显然，几乎没有人服从他的主张。格拉修一世（492—496年）著名地宣称，世界由司祭的“权威”和国王的“权力”治理。Auctoritas、potestas，在罗马思想中含义丰富，因此他的话分量很清楚；但他及直到十一世纪的继任者，都无法使其实际生效。[^p300-64] 829年，加洛林主教在巴黎开会，重新解释格拉修之言，让主教阶层地位，高于加洛林诸王。[^p300-65] 这是其教会论的一部分：回溯主教同僚共治的古代理念，把教宗角色解释为合作，而非指挥。尼古拉一世（858—867年）对教宗特权，表述比任何前任更有力。致拜占庭米海尔三世的信，他说：

> 立即可知，使徒座的裁决，没有更高权威，不能由任何其他法庭处理，也无人能对其决定作出审判。世界任何地方，都应向此座上诉，这正是教规的意义。此座的裁决，不容再行上诉。[^p300-66]

尼古拉的大胆主张，可以与864年某些法兰克教士的呼喊对读，他们悲叹：“尼古拉教宗大人，使自己成为整个世界的主人。”[^p300-67] 法兰克人抗议，教宗缺乏父亲般仁慈、兄弟般友爱，又违反正义、理性、教会法。他们说，愿同他合作，却不愿被他命令。稍后，普吕姆的雷吉诺说，尼古拉“命令国王、暴君，权威超越他们，仿佛自己是世界之王”。[^p300-68] 如果看起来，可以从利奥<a id="pdf-301"></a><!-- PDF page 301; original page 272 -->一世，经尼古拉一世，画出一条通往格列高利七世令人惊叹的《教宗训令》（Dictatus Papae）的线，[^p301-69] 那也必须记得，还可画另一条线，把加洛林人的抱怨，同格列高利七世致梅斯总主教赫尔曼的激烈书信相连；该信回应德意志主教指控他严重越权。[^p301-70] 中世纪早期的西方教会论，仍是一项未完的事业。

### 书籍、观念与职务

最后，几类书籍，证明著名作者、教会人士，如何从制度角度思考教会。中世纪早期教会的法书，为其对规则、秩序的深切关心，以及强烈制度记忆，提供令人印象深刻的证据。加洛林盛期出现的汇编，很有启发。所谓《狄奥尼修—哈德良教规集》（Dionysio-Hadriana），约774年由哈德良一世赠给查理曼，现存91部手稿，地理分布极广。约800年的《达谢里教规集》（Collectio Dacheriana），现存51部；820年代安塞吉斯《敕令汇编》（Collectio capitularium），存54部。《伪伊西多尔教令集》主要修订本，见于108部手稿，另外45部包含大篇摘录。另有49种地方性重要汇编。[^p301-71] 这种不断学习、应用适当教会治理规则的努力，十分重要；许多文本的开头，也像反复吟诵般，惯常坚持：只有普遍传下来的古老规则，才可、也必须应用。[^p301-72] 十世纪出现杰出的教会法学家沃尔姆斯的布尔夏德（1025年卒），十一世纪后半叶，法律研究、论著大量增多。

历史的写作，旨在形成、传递制度意识与记忆。最著名的，是罗马从六世纪初写到九世纪末、后来又不时续写的《教宗列传》（Liber Pontificalis）。该书以庄重的一任任教宗继承，结合个人、制度细节。[^p301-73] 罗马《教宗列传》，<a id="pdf-302"></a><!-- PDF page 302; original page 273 -->在那不勒斯、拉文纳得到仿效。[^p302-74] 地方自豪感，以及也许罗马的范本，促成了兰斯的弗洛多阿尔德，[^p302-75] 不来梅的亚当（约1000—1072年）[^p302-76] 等人的主教史。

最后，还可提及礼仪注释。这些注释，从塞维利亚的伊西多尔《论教会职务》（De ecclesiasticis officiis），[^p302-77] 延续到梅斯的阿马拉里乌斯（约780—约850年）《礼仪书》（Liber Officialis），[^p302-78] 赫拉班（约780—856年）《论教士的培养》（De institutione clericorum），[^p302-79] 瓦拉弗里德·斯特拉博（约808—849年）《论起源与发展小书》（Libellus de exordiis et incrementis），[^p302-80] 再经十世纪各种文本，[^p302-81] 直到阿夫朗什的约翰（1079年卒）《论教会职务》（De officiis ecclesiasticis），[^p302-82] 都有某些共同点：倾向于阐释语言、术语，描述、解释教会等级体系的品级、职务，讨论礼服、器皿、书籍，分析弥撒、日课各部分，详述禁食规则、时间，描述礼仪年主要节日。这种显著相似，显示一种推动秩序、一致性的教会心态。文本差异，也很有意思。瓦拉弗里德·斯特拉博写出西方第一部礼仪史，我们再次遇到一种观念：过去，是现在和未来唯一可靠的向导。赫拉班特别强调教士培养，写出一种司祭手册；司祭，是教会与世界相遇的关键人物。[^p302-83] 主教则有另一类手册。维罗纳的拉特里乌斯《训言集》（Praeloquiorum）第四卷末几节及整个第五卷，构成某种“主教之镜”（speculum episcopi），充满明智建议，涉及主教职责，以及最可能遭遇的道德、政治挑战。[^p302-84] 欣克马尔写了一篇《若干条款》（Capitula quibus），后来扩为《论教堂与小堂》（De ecclesiis et capellis），作为下属代他巡视乡村时的手册。[^p302-85] 该书既是信息宝库，也是一扇窗口，让人看见一位伟大主教如何理解自身任务。欣克马尔之后一代，<a id="pdf-303"></a><!-- PDF page 303; original page 274 -->普吕姆的雷吉诺撰写《教区会议事务二书》（Libri duo de synodalibus causis）。[^p303-86] 这部书，把欣克马尔的论点概括化、普遍化，为主教所属教士，提供一本有价值、可操作的手册，帮助履行一项主要职责——巡视教区；也让我们看见，教会人士如何“从永恒的视角”（sub specie aeternitatis），也就是从制度角度思考。
