# 第05章 日耳曼的基督教诸形态

莱斯利·艾布拉姆斯（Lesley Abrams）

<a id="pdf-136"></a><!-- PDF page 136; original page 107 -->

《圣经》、罗马和爱尔兰等丰富因素相互结合，又与前基督教日耳曼过去的遗产交融，共同塑造中世纪早期日耳曼世界的基督徒生活。把一种语言分类套用于宗教和宗教实践，谈论日耳曼语使用者奉行的典型基督教，会造成误导，尤其面对如此辽阔的地区、如此多事的五百年。这里“日耳曼的基督教诸形态”，按地域而非族群理解，指在日耳曼语世界发展起来的教会与基督徒团体：最初处于旧罗马帝国内蛮族继承国的环境，后来则由于政治、经济力量及传教活动，扩展到远超旧边疆的新地区。

不过，最早的日耳曼皈依，确有族群维度。最初皈依者哥特人，接受了后来被谴责为阿里乌斯异端的教导。四世纪皈依后，阿里乌斯主义便与日耳曼基督教联系起来。七世纪，它仍在意大利伦巴德人中延续；但西班牙最后一位重要阿里乌斯派统治者、西哥特王雷卡雷德，到公元589年已接受大公信仰。有人提出，日耳曼诸民族进入罗马世界时，选择并继续坚持这种越来越不正统的基督教形态，作为宣示社会认同和文化独立的手段。[^p136-1] 最初哥特皈依时掌权的罗马皇帝，信奉阿里乌斯派，把首批皈依者引向主流教会不久便放弃的方向。但蛮族对阿里乌斯派的忠诚持续下来。其神学与组织内在而独特的品质，在一定程度上可以解释其受欢迎的原因；它像其他受希腊启发的传教一样，使用本地语言，也是原因之一。哥特人皈依后的成功，想必也促进阿里乌斯主义向<a id="pdf-137"></a><!-- PDF page 137; original page 108 -->其他日耳曼民族传播。然而，帝国教会谴责阿里乌斯派为异端时，西哥特、东哥特、汪达尔和伦巴德人仍坚持不变，有些甚至迫害大公派对手。日耳曼继承王国的阿里乌斯派基督徒，也许把一种纯属蛮族的基督教，看成防止被所在社会文化吸收的办法，尽管保留传统宗教本会更有力地达到这一目的。可以确定，它使分离主义通过另一套属灵力量与制度权威的地理格局，得到表现。

阿里乌斯派持续成功，表明一个即使不以族群构想、至少带有族群色彩的教会，可能发挥作用。不过，尽管比德在《英格兰民族教会史》中写到一个观念上的 gens anglorum，即英格兰民族，族群界定似乎并未显著标记日耳曼王国中取代阿里乌斯派的各教会。相反，如果它们向往共同文化，范本是罗马，而非日耳曼。不同中世纪早期政权，对“罗马”的理解不同，但它所唤起的军事荣耀、文化领导和属灵权威——过去或现在的——兼容性抱负，比更狭窄的身份界定，对教会和政治当局更加有用。

法兰克王克洛维（511年卒）皈依大公基督教后，大陆继承王国内的阿里乌斯派，败于当地人口的正统基督教。从此，基督教通过本地和外来的教会男女推动发展。在日益占主导的法兰克王国，高卢—罗马、法兰克与爱尔兰主教，以及传教修士，把基督教教导从城市带到乡村；基督教最初于帝国时期在城市建立，乡间则更为异教化。[^p137-2] 高卢—罗马崇拜，很可能与传统日耳曼实践在那里混合。七世纪，与墨洛温诸王，以及爱尔兰人科伦班创立的吕克瑟伊修道院有关的教会人士，把教会权威扩展到高卢东北仍属异教的地区。旧边疆地带重新基督教化，使团被派向弗里斯人，修道运动也帮助扩大法兰克在阿勒曼尼与巴伐利亚人中的权力。盎格鲁—撒克逊英格兰诸王国，自597年由意大利人、法兰克人和爱尔兰人传教，继而也输出传教士；七世纪末起，他们在旧帝国疆界内外活动。从八世纪末<a id="pdf-138"></a><!-- PDF page 138; original page 109 -->起，盎格鲁—撒克逊人、弗里斯人和法兰克人，把基督教传入萨克森。有时，这个过程被赋予族群意义：比德提到，盎格鲁—撒克逊教会人士希望把上帝之道带回欧洲大陆祖居地；[^p138-3] 十、十一世纪，类似的斯堪的纳维亚亲族感，可能激励了英格兰—斯堪的纳维亚传教者。

这些教会男女带来的影响，远不统一。此外，蛮族诸王先后皈依，各教会围绕王国政治当局组织起来，因而每个新教会都有自己的面貌。这些世纪形成的民族教会，于是表现出鲜明地域性。八世纪，英格兰人博尼法斯在大陆开展“正确”基督教的运动，以及加洛林人后来关心一致性和宗教实践统一，都是对这种多样过去的自然反应。罗马即使未必始终是实际典范，也始终是象征性原型。由于格列高利传教的遗产，早期盎格鲁—撒克逊教会尤其珍视罗马典范；加洛林国家也如此，八世纪末和九世纪，它敦促臣民宗教一致。十世纪，盎格鲁—撒克逊和奥托改革，立足于宗教统一是帝国原则的观念，大力针对差异。然而，尽管整个西欧有这种标准化冲动，诺曼教士1066年所遇见的英格兰教会，仍使他们感到乡土而陌生：未经改革，本土圣徒众多，既用拉丁语，也用本地语言表达宗教。直到十一世纪中后期的格列高利运动，才有了强制一致性的机制，如今由教宗界定；随后，十二世纪的各种运动，又促成更普遍的西欧教士文化。

考虑到宗教皈依的性质，通过罗列王室洗礼，或主教座、修道院创设，来勾勒基督教在日耳曼诸民族间的发展，虽属传统，却同样误导。然而，国王在皈依中的作用，巩固了世俗权力与基督教权威之间关键而持久的联系；主教座建立虽不一定说明人口皈依已经完成，制度化教会的形成，却确实标志新宗教发展的重要一步，因为它在实体与象征两方面，重新绘制地域权力地图。主教座中心，<a id="pdf-139"></a><!-- PDF page 139; original page 110 -->像修道院一样，为传教者的培养与供养提供基地。英格兰的教区很大，尽管中心与边界在政治战略性时刻移动，总数从750年到1100年却差不多。在大陆，较小的古代城市主教座，反映不同的权力与人口格局。新创设从法兰克中心向外延展。690年代起，为弗里斯人建立主教座；730与740年代，博尼法斯在巴伐利亚、黑森、图林根重建本世纪早期已设的主教座。主教座创设伴随加洛林军事扩张：查理曼征服萨克森、强迫其皈依后，805年起建立八个萨克森教区。948年，奥托一世沿帝国边界建立一连串主教座。修道创设，也随主教活动向东、向北扩展。

然而，浪潮抵达斯堪的纳维亚时受阻。没有已知修道院，是为了在丹麦、挪威或瑞典皈依中发挥作用而创立；直到十二世纪新修会到来，修道生活才成为重要力量。九世纪中叶，汉堡—不来梅早有传教努力，但丹麦教区直到948年才设立；即便如此，也要等到丹麦王“蓝牙”哈拉尔德大概于960年代皈依后，才能实际运作。瑞典在九世纪也由汉堡—不来梅传教，却抵抗皈依直到十一世纪，届时基督徒国王庇护下，设立若干教区。挪威主教座，可以说是奥拉夫·特里格瓦松王（约995—1000年）依据既有行政区划，在英格兰帮助下划定的。冰岛是一个独特的无王社会，999年以民众决定皈依，1056年获得首位具有地域辖区的主教，五十年后设第二教区。1103／1104年，北方省会主教座在当时属于丹麦的隆德建立。

能否说，这些不同民族共享一种皈依经验，或一种独特基督教形态？识别“日耳曼”基督教的尝试，通常不主要关注教义特色，而关注世俗文化的侵入影响。然而，一种特别“日耳曼”的基督教这一前提，从一开始就遇到方法问题。且不谈前几个世纪，受民族主义和意识形态驱动、令人不快地试图识别原初泛日耳曼性的努力，近来确立日耳曼基督教“品牌”的尝试，列出一张特征对照表，一边是“异教”特征，另一边是“真正”基督教特征。按此观点，传教者允许皈依者保留前者，<a id="pdf-140"></a><!-- PDF page 140; original page 111 -->牺牲后者，基督教便“日耳曼化”。[^p140-4] 暂且不论应期待皈依包含什么，下文还会讨论，界定何为“真正”基督教、何为纯粹日耳曼，作为这种方法的基础，本身就极成问题。环境变化，自然会影响活的宗教。基督教早因合法化，以及随后纳入罗马帝国而发生重大转变，到600年，已积累丰富的适应非基督教环境经验。至于日耳曼诸民族，皈依很久以前，就与凯尔特和罗马世界接触。缺乏资料，使人难以精确识别，其社会哪些方面早于这种接触，源自纯粹日耳曼过去。皈依也不可能是这一阶段唯一的变化因素。日耳曼诸民族承担西欧和不列颠大部分地区的世俗领导时，经历重大改变；皈依前、中、后多重影响，使宗教改变的效果，难以与社会动荡、迁徙、经济发展和政治权威转型的一般效果区分。制度化教会本身，同样受到这些发展的影响，不亚于接纳文化背景不同的新民族所受的影响。

传教政策深刻影响皈依者所采用宗教的性质，但并非所有日耳曼民族，都以同样方式皈依。有些地方，例如昔日高卢，或英格兰中西部，皈依似乎自然发生：非基督徒在基督徒之间定居，经婚姻等正常社会过程融入。更广为人知的是，日耳曼世界多数其他皈依，被描述为自上而下：统治者常与世俗顾问商议后接受洗礼，人民随后皈依。它们虽由政治推动，却可以和平发生；偶尔也有暴力，有时极端暴烈。这种自上而下的“民族”皈依，显然通过集体洗礼推行。由于其集体性质，可能并不期待立刻而彻底的改变。千禧年思想也许相关。集体洗礼具有末世论逻辑，600至1100年间不同阶段，尤其迫切。有些情形，皈依者对教义理解虽浅，道德生活也未臻完善，传教者或许仍可自我安慰，<a id="pdf-141"></a><!-- PDF page 141; original page 112 -->数以千计新受洗的灵魂，至少在世界末日将带来的大审判中，拥有得救机会。另一方面，即使奉国王命令皈依的人，宗教问题也可能敏感、充满争议。宫廷诗人“惹事诗人”哈勒弗雷德，献给挪威王奥拉夫·特里格瓦松的诗句，一面肯定相信基督，一面表达冲突与遗憾。[^p141-5]

圣徒传、历史和传教书信，描绘早期福音宣讲，包括详细记录由构想英格兰皈依的大教宗格列高利所发的指示。601年一封信中，格列高利敦促英格兰王埃塞尔伯特，压制偶像崇拜，推倒异教建筑和圣所。[^p141-6] 另一封信则指示传教者梅利图斯，摧毁偶像，但保留建筑：“取圣水洒在这些圣所，修建祭坛，把圣物置于其中。”从前献给魔鬼的动物，应在那里宰杀为食物，赞美上帝；“〔人民〕应改变心意，舍弃祭献的一部分，保留另一部分……因为他们把祭品献给真上帝，而非偶像，这些就不是同样的祭献。”[^p141-7] 这种适应，被视为日耳曼民族皈依特别鲜明的特征，并被认为从圣所处理，扩展到异教文化一切方面，创造一种或“有名无实”，或“前基督教与基督教广泛混融”的基督教。[^p141-8] 但这种替代政策，并非日耳曼异教场所独有，例如东地中海，较少情况下也在西地中海，早已用于古典神庙。[^p141-9]

在字面和比喻意义上，为异教与基督教建立共同基础，无疑有助于两者转换。然而，教会在多大程度上接受长期适应或混融，并不那么清楚。宗教混融，严格说是试图调和不同信仰或实践，但常被用于指宗教生活中“随意拣选混搭”的态度，无疑存在。务实包容也存在：十世纪以前的丹麦人，只是那些据说接受基督、却继续像从前一样崇拜<a id="pdf-142"></a><!-- PDF page 142; original page 113 -->诸神的皈依者中的一个例子。[^p142-10] 但混融与包容，虽与多神论相容，却违背基督教一神论。尽管禁令的修辞十分发达，人们不大可能立即而普遍地认识到，基督教某些方面不容商量。不过，为制止偏离，教会可调整基督教信息的表达，回应异教关切和感受，同时不损害教义完整性或礼仪一致性。例如，异教徒认为，超自然在群体生活中具有实用作用，期待神明介入，使今世成功。基督教上帝不仅可以做到，还能提高承诺：提供来世救恩。如此迁就异教思想，在多大程度上被视为稀释基督教真实性——如果这一概念有用的话——并威胁基督救赎人类的核心信息，必因具体情境、个人想法而异。

讲道和书信，多少显示教会人士认为平信徒应如何过基督徒生活。格列高利教宗敦促肯特王埃塞尔伯特（560—616年），“以卓越纯洁的生活，劝勉、威吓、吸引、纠正臣民，并为他们树立善行榜样，坚固其道德”。[^p142-11] 教宗的传教者奥古斯丁，从英格兰来信，询问个人行为问题：孩子出生后多久，丈夫可以与妻子性交？月经期间的妇女，能否领圣餐？[^p142-12] 有些历史学家，也许像最初受众一样，不愿认真看待这些问题；但传教文本坚持，基督徒生活对每个人都有深刻含义。皈依者，以及后来所有受洗者，都必须知道信经，即应当相信什么，以及主祷文，即应向上帝祈求什么。[^p142-13] 两者概括信仰根本，以本地语言教授。精深的基督教思想，无疑只限于极小精英；但若留存证据代表现实和实践，而非一厢情愿，所有皈依者，都被期待以新方式生活，并理解基督教核心信息。

我们永远无法真正掌握，教会人士期待皈依过程包含什么。就零碎证据所能判断，异教和基督教不应被看成<a id="pdf-143"></a><!-- PDF page 143; original page 114 -->同一副牌的两张牌，即一种可界定为“宗教”的实体之不同版本。在异教社会，使超自然与人间世界相接的神圣活动，渗透公共和私人行为，旨在解释、控制作用于共同体的力量。日耳曼社会原初状态中，习惯文化与传统宗教也许不可分；但到皈依时，与基督徒接触，很可能已使异教徒意识到世俗与宗教之间的界线，同时又不清楚应划在哪里。因此，把异教社会的不同线索，分别标作“宗教”和“其他”，是时代错置。但由此引申出，文化延续必然说明日耳曼地区基督教纵容异教，并不成立，因为被认作日耳曼文化中“异教”的许多事物，如今并不落入大多数宗教定义。把传统实践中的“宗教”与非宗教因素分开，想必是传教者较困难的任务之一。皈依基督教，显然不能意味着彻底改造生活的一切方面，尽管此前这些方面都曾与超自然相连。“基督教”与“异教”的界线，必然不一，由教士容忍的限度决定。600至1100年，尽管“正确”基督徒生活的定义越来越明确，地域弹性仍有空间。某些文化习惯遭教士批评，例如把女儿放到屋顶治发热，受到七世纪英格兰《狄奥多若悔罪书》谴责；另一些，如999年冰岛的杀婴，却被容许。[^p143-14] 对某些人，例如797年致诺森布里亚一位院长的阿尔昆，传统歌曲不合基督教：“英格尔德与基督有何相干？”[^p143-15] 对另一些人，如命人将其写下来保存的查理曼，则不是。[^p143-16]

试图理解中世纪早期异教与基督教的互动，就必须面对一连串使问题复杂的对立：现实与理想、民间与专门人士、乡村与宫廷。我们当然受制于资料。异教声音经过基督教过滤，规范性宣言和学术文本，也比具有代表性的描述更易留存。此外，上下层之间，社会距离显著。乡村劳动人口与异教决裂的方式，必定不同于那些坐在蜜酒<a id="pdf-144"></a><!-- PDF page 144; original page 115 -->长凳上的人。修道教堂提供的基督徒经验，也不同于地方圣井。日耳曼世界不同环境，为教会驱散其所谓异教黑暗的道路，提出不同挑战。但无论宫廷或乡间，过程至少有一个相同方面：可以按格列高利建议，保留熟悉的旧形式，填入基督教意义。

皈依从王廷与贵族圈向外扩散时，社会下层的基督教化，自然较慢。传统日耳曼异教具有万物有灵性质。精灵推动支配农业年、确保社会存续的自然大过程，景观充满形而上的能量，体现神话力量。为回应这种宇宙观，基督教教士必须创造一种新的民间理解，解释使世界活跃的自然与超自然力量。圣徒崇敬接过部分职能：从七世纪诺森布里亚的“最虔诚基督徒国王”奥斯瓦尔德，他受敬奉的头颅可能呼应早先崇拜，到十一世纪挪威圣奥拉夫，他像奥丁一样红须、持斧的形象，被抬着巡游田野，确保丰产。基督教虽把大部分形而上能量集中在建筑中，圣徒仍能像从前神灵、精怪与祖先那样，将地方景观纳入自身神圣范围。

基督教来到历史悠久的农业社会。关于农作丰产与家庭生活的仪式，深植于男女不同领域。生存的迫切关切当然始终存在，皈依后继续表现于民间传说——乡村对前基督教过去的集体记忆——和巫术之中。[^p144-17] 教会虽反复谴责民间仪式及其施行者，但某地正式皈依数世纪后，教会规章仍禁止大量所谓异教遗存，表明这是一场不断失利的斗争。教会并不总有能力提供足够牧养教导与监督，强制推行禁令，乡村尤其如此。不过，把这些仪式看成保存了一种独立于基督教的古老异教，未免过于乐观。反复谴责“迷信”，大概不主要指残留异教，而指未经许可的民间施行者及做法，它们被禁止为不合基督徒规范。教规文献甚至暗示，教士也有未经认可的参与。从600至1100年这一时期之始到<a id="pdf-145"></a><!-- PDF page 145; original page 116 -->结束，教会不断试图根除这些行为，使自己成为社会与超自然关系的唯一组织者，却未成功。然而，随着乡村教士服务增加，民间信仰与文化，可以越来越多地置入基督教框架。[^p145-18] 保守乡村社会中，以圣水烤面包、埋入田间，或把基督教礼仪、异教神明与草药相结合的咒语，大概确实保存了前基督教习俗的片段。但它们作为异教“遗存”的意义，不如作为格列高利指示效力的证明：将咒语力量的功劳归于上帝，使其无论源自何处，都成为基督教的。扎根本地语言共同体的地方司祭，吸收民间仪式，显示基督教在整个社会层面的成功，不只在博学者之间。不过，将仪式写下来保存的，仍是博学者。

社会顶层的武士贵族接受新宗教，提供另一些机会。例如，盎格鲁—撒克逊贵族“无意放弃自己的文化”，而是“愿把传统、习俗、趣味与忠诚，投入新信仰的表达”。[^p145-19] 下文将见，基督教热情采用英雄社会的外衣，以本地语言与世俗表达重铸文化，为基督教故事着色。上帝可被描写为征服异教土地的“罗马之王”；[^p145-20] 使徒可被写作上帝的侍从（thegns），“远古岁月里，天穹之下受敬重的十二位强大英雄”。[^p145-21] 像民间习俗一样，精英文化也转而表达基督教身份。例如，十一世纪初英格兰与丹麦王克努特的宫廷诗歌，表现出所谓“文化上的异教性”。[^p145-22] 克努特本人虽资助教会、到访罗马，其诗人却在基督教处境中使用传统异教语汇，为新近征服英格兰的丹麦人塑造身份。“世俗”不应等同“异教”，英雄文学风格，也不应掩盖内容与既有基督教著述之间普遍的一致。

颇像早期基督教爱尔兰的教会，斯堪的纳维亚与冰岛基督教，对前基督教信仰格外宽容，也特别感兴趣。事实上，我们自以为知道的许多日耳曼<a id="pdf-146"></a><!-- PDF page 146; original page 117 -->异教知识，都通过这些渠道传下来。[^p146-23] 复杂的神话诗歌与散文、传说历史，以及以皈依前时代为背景的短篇和萨迦形式的历史小说，被写在羊皮纸上。有时采用拉丁语，例如十三世纪初丹麦人文法家萨克索的著作；[^p146-24] 但主要采用古诺斯语，最著名作者，是冰岛人斯诺里·斯图鲁松（1179—1241年）。斯诺里在诗学论著《埃达》中，为神话知识辩护，只给了极简略的理由：大洪水抹去关于上帝的知识后，这类“世间理解”取代真正智慧。[^p146-25] 他记述男女诸神，出于务实的好古兴趣：年轻诗人需要知道神话叙述，才能施展技艺。[^p146-26] 另一方面，许多同属十三世纪的萨迦，近距离、具体地描绘普通前基督教人物，举行祭献，与诸神交涉，死后又从坟丘作祟。设定在皈依转折点的故事，包含“高尚的异教徒”，把他们描写为正确基督徒生活的先驱，从而浪漫化异教，使其与基督教和谐。历史叙述也有鲜明异教色彩，例如十三世纪冰岛定居史《定居者之书》（Landnámabók），把一项法律归于十世纪定居者乌尔夫廖特。该法规定异教祭司如何处理法律案件：臂上戴至少两盎司重、沐浴祭牛鲜血的银环；又详细列明向诸神起誓的措辞，指导人们如何对待地灵。[^p146-27] 这些图景无论是真实实践，还是想象重构，大体都不带道德褒贬。萨迦的“前基督教背景与知识”“非基督教兴趣与价值观”，体现了对异教过去这种带同情的培育；[^p146-28] 有人据此论称，十三世纪冰岛仍未在显著程度上吸收基督教。但这种晚出的文学异教展示，彻底立足于基督教思想，也由基督教学问塑造。这些基督教文学中，真实异教残留与好古重构各占多少，仍将继续争论。

盎格鲁—撒克逊诗歌，也赋予贝奥武夫这样的“善良”异教徒文学生命，但在冰岛和丹麦<a id="pdf-147"></a><!-- PDF page 147; original page 118 -->以外，日耳曼异教对书面文化影响很小，其他地方几乎只为禁止它而记载。例如，比德讨论时间时，只简述古英语诸神，在《教会史》中也只留下科伊菲故事等少数教义式固定段落。[^p147-29] 中世纪早期西方对古典过去的态度，也许更能与冰岛容忍本土异教的现象相比。毕竟，法兰克人把罗马的特洛伊起源，也据为己有。当然，始终有人反对研究古典文化。七世纪末或八世纪初，英格兰教会人士阿尔德赫尔姆，批评爱尔兰人热衷男女诸神，以及“〔世俗〕哲学家令人烦扰的迂回曲折”。[^p147-30] 但八世纪末、九世纪，尽管不安地意识到危险，加洛林学者仍以基督教前辈保存的材料为基础，运用古典学问，增强新帝国的罗马性。九世纪法兰克学者赫拉巴努斯·毛鲁斯说：

> 我们阅读异教诗人，手持世俗智慧书籍时，若发现有用之物，就应把它转用于我们认可的教导（dogma）；但若发现关于偶像、爱情和世俗事务的多余事物……就把它们剪除。[^p147-31]

不过，加洛林复兴的学者，取用古代异教的贱金属，将其转成基督教黄金；[^p147-32] 中世纪冰岛人，则主要通过使本土古老神话世俗化，而非基督教化，把它们从异教环境中解放出来。

其他有日耳曼根源的社会，似乎并不特别关切前基督教过去的异教身份，但我们可以追问，冰岛培养异教传统，是否反映一种其他地方更早就已经历、只是证据更难存续的模式。然而，中世纪冰岛的特殊条件，有助于解释异教过去为何能在那里如此详细、富于暗示力量地活下去。有人以异教消失较晚解释，但斯诺里距正式皈依已超过两百年；仅依留存材料判断，与皈依相隔类似时间的英格兰历史写作，并未对旧方式如此自在。如同英格兰，冰岛在皈依以前已经有人定居。

然而，盎格鲁—撒克逊身份的起源，牢牢处于基督教时期；欧洲大陆继承王国各自的认同，则在日耳曼皈依前、中、后，罗马人与蛮族汇合中形成。相比之下，冰岛的民族认同，在异教时期形成。没有王权，家族网络便提供社会、法律与文化基础。十二、十三世纪文字习惯真正扎根时，作为作者与受众的主教、司祭、酋长和普通农民，其地位，早已在前基督教过去确立。因此，民族与地方认同，都依赖宣告与祖先的联系，而这些祖先的异教身份无可否认，尤其因为999年酋长大会投票接受皈依，具有公开性质。同时代欧洲对传奇故事的热潮，以及贵族赞助本地语言文学，无疑也发挥作用，鼓励独立于教士文化的文学。[^p148-33] 此外，冰岛教会作为制度，深深嵌入世俗社会，其书面文化因此可能比日耳曼世界任何其他教会，更反映本土非教士生活不受拘束的兴趣与态度。

不过，在所有日耳曼社会，一些祖传文化与宗教的参照点都保留下来，例如星期名称与王室谱系。哥特、伦巴德、盎格鲁—撒克逊、斯堪的纳维亚和冰岛环境中，现存谱系显示，像凯尔特世界一样，把世系追溯至神与英雄，是广泛共享的习惯。[^p148-34] 早期诺森布里亚许多王室名字中的前缀“Os-”，最初意为“神”或“神性”；可比较古诺斯语单数 ás、复数 aesir，后者指诸神家族。约450至550年制造、见于英格兰、斯堪的纳维亚和北欧其他地区的薄金饰片，像钱币圆片，刻有动物和人形，被解释为王朝宣传，尤其依附沃登／奥丁的标志，表现诸神与尘世权威的联系。[^p148-35] 斯诺里·斯图鲁松在《埃达》序言，讲奥丁如何率众从色雷斯来到萨克森、威斯特法伦、法兰西、日德兰、瑞典和挪威，在各地立一子为王。[^p148-36] 这类故事，为王权存在提供逻辑，也可能是盎格鲁—撒克逊谱系追溯沃登<a id="pdf-149"></a><!-- PDF page 149; original page 120 -->或塞阿克斯诺特的背景；这类谱系，八世纪初已有书面证据。前基督教日耳曼民族，如同许多其他文化，似乎认为神裔出身赋予王朝特殊力量与统治权威。放弃旧神，有割断这些神圣根源的风险；但谱系中的沃登／奥丁，被解释成古代人物、抽去神性后，就可以安全地为基督徒使用。[^p149-37] 然而，把历史或谱系早期层次中的诸神，简单视为异教时期传统顽强残存，未免天真；这些谱系后来还加入一批大陆出身的祖先英雄。谱系赋予王室祖传分量，作为确认正当性的工具，名称会依时尚和政治需要增删。古典和圣经文学范本，都发挥作用。盎格鲁—撒克逊晚期英格兰，以及十二世纪起的冰岛，好古式谱系不断向过去延伸，持续寻求权威，欣然纳入耶稣、特洛伊人、挪亚和亚当。[^p149-38]

我们对传统日耳曼宗教所知甚少，却可见国王与诸神有特殊关系。例如，十世纪末哈康伯爵，被诗歌描绘为以某种婚姻形式占有挪威土地；土地被看作奥丁遗弃的妻子、一位女神。[^p149-39] 统治者居于神与人民之间，因而负责确保生存与成功，但这种中介地位，并非日耳曼异教独有。四世纪一枚纪念章，描绘上帝之手将王冠戴在君士坦丁头上，体现这一主题在基督教西方的起点。[^p149-40] 一派观点认为，日耳曼社会皈依前，国王处在神与凡人之间的位置，深刻影响中世纪西方形成的基督教统治。[^p149-41] 然而，中世纪早期把国王看作神圣中介、崇拜守护者的观念，显然是常见思维，从多种传统获得思想支持。王权修辞清楚表明，日耳曼过去传下的任何影响，都伴随罗马、《旧约》《新约》和爱尔兰关于君王感召力由神恩赐予的观念。它们的信息一致：国王代表上帝在世界中的权威，并负责使臣民预备进入天国。

国王作为通向超自然渠道的地位，意味着他可以决定人民的宗教归属。因此，他自然成为传教者和上文自上而下皈依的目标。他的皈依可能割断旧神联系，却允许一种以基督教界定的新属灵与世俗领导形成。各种策略，确保国王不失去前基督教时代“内在的神圣化倾向”；[^p150-42] 事实上，教会谨慎地将其制度化。例如，从八世纪后半期起，教会运用傅油仪式，宣示并控制君王的特殊品质。此后，周期性改革为国王阐述崇高的属灵身份，为其教会首领地位提供意识形态支持。立法既陈述，也展现其权力的世俗与属灵范围。英格兰深受加洛林和奥托世界影响，其国王埃塞尔雷德（978—1016年）的一项法律，表达常见思想：“基督徒国王，是基督在基督徒人民中的代理人，他必须尽最大努力惩治对基督的冒犯。”[^p150-43] 维京战争造成极端危机时，埃塞尔雷德下令全国施舍、禁食、祈祷；还发行一批便士，一面刻上帝羔羊，一面刻象征圣灵的鸽子。[^p150-44] 大陆上，兼具军事与神圣联想的圣枪，在十世纪成为奥托王权的象征。1002年奥托三世死后，继位斗争中，候选人之一巴伐利亚的亨利，曾短暂囚禁一位大主教，因为后者试图阻止他取得这件关键王权器物。[^p150-45] 这一时期，国王在世俗权力与道德力量上的显著扩张，由基督教意识形态、仪式和象征证成、维持并展示。

拥有圣物，有助于表现王室与超自然力量之源的联系，建立王室圣徒崇敬也如此。盎格鲁—撒克逊英格兰，以及后来的斯堪的纳维亚，尤其推动王室圣徒。王室崇敬为统治家族宣称神圣性，也能在国王被亲族中竞争者杀害、无法报仇时，提供“维护荣誉的解决办法”。[^p150-46] 七世纪诺森布里亚受崇敬的被杀国王，生前看不出特别圣洁；其断首躯体、离身头颅与流洒王血的力量，可能取自<a id="pdf-151"></a><!-- PDF page 151; original page 122 -->前基督教的王权神圣传统。[^p151-47] 从基督教角度，更常规的是，几位早期盎格鲁—撒克逊国王退位，进入修道院或前往罗马。但退隐修道，与王权的军事面向不相容，同时代法兰克态度清楚表明这一点；因此，女性有机会成为王室的“宗教专门人士”。[^p151-48] 墨洛温和盎格鲁—撒克逊王后、贵族妇女，在皈依叙事中发挥重要作用，许多成为圣徒。由王室领导的女性修道团体增多，使妇女得以参与教会文化，也以新工具继续王朝政治。这些力量，尤其七世纪的法兰克与盎格鲁—撒克逊，以及十世纪、十一世纪初的奥托人，通过重要宗教机构发挥。[^p151-49]

王室男子，自然也常在教会精英中任职。像罗马世界一样，社会最高层继续提供主教；修道生活和救恩许诺，也吸引贵族的想象。世俗贵族投入资源，带来一波创设高潮，土地占有与支配策略，容纳他们的既得利益。若教会捐赠被当作受亲族权利支配的个人财产，就能避免庄园资源流失，使资产留在家族。由平信徒担任或世袭的院长职，使家族成员继续掌管宗教机构，最大程度减少主教介入。以主要王室或贵族利益建立的修道团体，无疑可以发展为虔敬和学问中心；同时，也能通过礼仪、艺术和建筑展示，同样彰显上帝与创办者的荣耀。

修道团体，无论由主教还是世俗人士创立，都有一定机会留下创设记录，地方教堂的起源却模糊得多。私属教堂，即由平信徒私人占有，而非服从集中或团体支配的财产，反映根深的产权与庇护观念，是这一时期西欧大部分时间的常态。私属教堂可以买卖，尽管人们是否真把它们视为像其他领主财产一样“属于”主人，并不确定。[^p151-50] 遗嘱，例如九世纪中叶法兰克妇女<a id="pdf-152"></a><!-- PDF page 152; original page 123 -->埃尔肯弗里达向特里尔和普吕姆捐赠财产的遗嘱，记录教堂的继承、受赠与处置。[^p152-51] 随着时间推移，这些教堂变为地方共同体的崇拜建筑，到十二世纪成为堂区中心。私属教堂起源的证据虽难寻，其很早提出的管辖难题，却见于大陆主教与教区内教堂主人之间的紧张记录；主人既可能是平信徒，也可能是教会人士。博尼法斯严厉谴责平信徒“以暴力”（per violentiam），从主教、男女院长手中夺取教堂，占有“基督宝血买来的财产”。[^p152-52] 然而，在英格兰，宗教团体似乎直到十世纪，才面对这类私人教堂的明显竞争，[^p152-53] 尽管资料存续可能扭曲图景。在斯堪的纳维亚，不来梅的亚当一段热情评论，暗示十一世纪私人教堂迅速增殖；[^p152-54] 由于普遍缺少集中机构、地方领主权强大，这可能可信。私人教堂可由世袭司祭服务。十世纪末或十一世纪初，诺福克一位妇女的遗嘱规定：“我的教堂应享有自由，由我的司祭伍尔夫梅尔在此咏唱；他的后嗣，只要具有圣职，也如此。”[^p152-55] 教会持续谴责教士婚姻，但在许多地区，直到本章时段后期仍未奏效；因此，这类教士家族的记录零星，并不奇怪。领主建堂，既发生于乡村，也发生于城市。伦敦圣尼古拉斯阿孔，即哈康，以及圣马利亚伍尔诺斯，即伍尔夫诺斯教堂，似乎保存了大概属于十或十一世纪的平信徒业主名字，提供证明。[^p152-56] 约1100年一份名单，列出个人加入坎特伯雷基督教堂宗教团体时捐出的伦敦教堂，其中包括布里赫特梅尔，称 senator，大概即 ealdorman，地方高级长官。[^p152-57]

在这些条件下，平信徒与宗教利益的紧张，不可避免。世俗贵族因占有、庇护教堂，承担广泛宗教责任。另一方面，教会人士因拥有大量土地，像平信徒一样行使世俗权力，也扶立国王。周期性的改革，不断划定、重划<a id="pdf-153"></a><!-- PDF page 153; original page 124 -->世俗与教会之间的界线，恰因两者重叠、不易分离。八世纪起，教会立法，试图切断世袭原则与院长任命的联系，反对把教会收入保为私人财产。教会法日益推翻家族权利，限制贵族权力，扩展主教或国王的集中权威。人们逐渐认为，把教会直接置于国王保护下，可以补救平信徒支配上帝领域的问题。但到1100年，改革已确立教堂属于上帝、而非国王的观念。世俗控制任命，受到猛烈谴责，尽管并非始终成功。然而，王室和贵族财富，仍通过资助祈祷、赞助艺术家与学者，涌入作为安葬和纪念中心的教会。

拉丁语，是传播基督教文化的主要语言。600年以后，只有北欧和西欧所用的日耳曼语言，留下书面证据。皈依前，多数日耳曼民族用卢恩字母书写本地语言文本，字母主要适合刻在木头上。皈依后，卢恩书写在法兰克地区消失，却在英格兰各种物品上延续，包括钱币、基督教纪念物，以及鲁斯韦尔十字架这样的虔敬雕刻，偶尔也出现于文学环境。斯堪的纳维亚数千块卢恩石，证明皈依后，本地语言卢恩书写仍受欢迎。[^p153-58] 在英格兰，非卢恩文字的本地语言，发挥尤其活跃的作用。帮助向英格兰人传教的爱尔兰人，有丰富本地语言传统可利用；而富有影响的坎特伯雷大主教狄奥多若（668—690年）是希腊人，很可能把东方教会容纳本土语言的态度带到英格兰。西方似乎对本地语言有两种态度。一种是轻蔑，或充其量犹疑。本地语言文化，被称为 rustica 和 barbara，即乡土、蛮族，充满世俗价值，而且最初当然属于口头文化。把宗教材料从拉丁语译出，不仅冒世俗污染之险，也可能引入错误，把人危险地引入歧途，正如多产本地语言散文作者埃尔弗里克（约950—1010年）所言。[^p153-59] 另一方面，基督教向日耳曼世界扩展，为本地语言提供新机会。毕竟，传教者必须讲道、教导，<a id="pdf-154"></a><!-- PDF page 154; original page 125 -->并与王室、贵族赞助者沟通。例如，英格兰的罗马教会人士，虽有法兰克译员相助，要履行这些职能，仍须懂英语。597年抵达不久，英语便经历从口头到书面语言的重要转变。大陆和斯堪的纳维亚的传教者，其中许多是英格兰人，也面对用无文字语言教导平信徒和教士的同样难题；当地语言也转用于基督教，尽管未必书面化。[^p154-60] 例如，比德强调，人们能用自己的语言诵读信经和主祷文，多么重要；[^p154-61] 但其书面文本，直到本章时段较晚才出现。英格兰最早存世的本地语言书面文本，是七世纪肯特与威塞克斯的四篇法律，或许反映教会希望以帝国联想，抬高国王。

担心误解与歪曲，可能使人不愿完整翻译《圣经》。虽然据说比德在735年临终时，还在把《约翰福音》译成英语，十世纪末，埃尔弗里克却忧虑《旧约》译本，会让“愚人”误解如今应怎样生活。[^p154-62] 古英语译本仅存福音书、《旧约》最初七卷和《诗篇》。八世纪末，一份莱茵法兰克语手稿，保存了本地语言《马太福音》。英格兰八世纪初已有语言和表达都属本土的宗教诗歌见证。比德讲述，住在惠特比修道院、不识字的牧人凯德蒙，创作“敬虔而宗教性的歌曲”：“凡经解释者使他从圣经学到的，他都很快转成极悦耳、动人的英语诗歌，那是他的母语。”[^p154-63] 英格兰传教者创立的富尔达等机构，大概把这种影响传到大陆。九世纪初起，出现几种福音书诗歌改写，“不逐字，而按意义”；[^p154-64] 包括古撒克逊语《救世主颂》（Heliand）和《创世记》，以及九世纪中叶魏森堡的奥特弗里德的《福音书》（Liber evangeliorum）：“法兰克人为什么……不该用法兰克语赞美上帝？”[^p154-65] 这些<a id="pdf-155"></a><!-- PDF page 155; original page 126 -->宗教诗歌的赞助者与受众，仍有争议，难以确定。诗句可能与王廷有关，当然也适合不识字的平信徒受众；也可设想，在神圣日课或餐厅中被朗读。[^p155-66] 以本地语言诗歌重述教义，显示例如洗礼等基督教观念，如何转为故事，使礼仪成为“一种令人信服、近在身边的事物”。[^p155-67]

然而，最早存世的古高地德语文本，是词汇表。与英格兰不同，大陆最初使用本地语言书写，可能只限于翻译练习；到九世纪，才以更丰富的书面形式，反映继续兴盛的口头文化，尽管存续偶然性可能使图景失真。此外，大陆还留下本地语言洗礼誓言、信经、主祷文、认罪文、誓词、地界条款，以及巫术—医疗材料。九世纪英格兰也有其中许多类型，同时还存在大量本地语言特许状、王室令状、贵族遗嘱、租约和其他实用文书。到盎格鲁—撒克逊晚期，英语已是“许多书面事务的普通语言”。[^p155-68] 文书记录虽本质上属世俗，与政府和地方领主权运作相连，却都有某种教会起源。宗教机构率先以文字和概念，表述财产交易；教会人士的读写专长，又使地方和全国权力管理越来越精细成为可能。

某些本地语言文本，例如《本笃规章》译本，显然为专门的教会受众而作。本地语言圣徒传，在盎格鲁—撒克逊英格兰和中世纪冰岛尤其流行，其中部分，也许大部分受众，也是教士。其他作品传播更广。加洛林复兴虽主要关注拉丁学问，查理曼那部可惜今已佚失的“本国语法”，[^p155-69] 仍是一个宏大教育与社会塑造计划的组成部分，受基督教统治理想启发。教会会议坚持，应经常以本地语言讲道，向平信徒详细教导：地上行善者将获天上报偿。这些牧养目标，也见于本地语言诗篇，例如九世纪论最后审判的《末世篇》（Muspilli），<a id="pdf-156"></a><!-- PDF page 156; original page 127 -->鼓励基督徒悔改、行善。[^p156-70] 英格兰国王阿尔弗雷德890年代著名的识字与翻译计划，同样扎根基督教价值，明确采用本地语言，鼓励平信徒学习阅读母语。[^p156-71] 某些选定作品的英语版本，有些由国王本人翻译，旨在使民众，包括部分教士，更易获得基督教智慧。他们觉得拉丁学问过于艰深，由此陷于罪恶，危及王国命运。892年开始的大型历史著作《盎格鲁—撒克逊编年史》，显示英语已成为多么重要的拉丁语替代。十世纪后半期，宗教改革鼓励英格兰本地语言文学更有活力。约970至1025年间抄成的四部主要册页本，大多改编圣经故事、将其诗歌化，代表比大陆存世者规模更大、技艺更成熟的本地语言诗歌群。[^p156-72] 同时，埃尔弗里克及同时代伍尔夫斯坦——1002至1023年任约克大主教——以节奏散文创作的讲道和圣徒传，使本地语言在宗教教导服务中，达到新的典雅与雄辩高度。1066年后，拉丁语和法语取代英语，成为文化与政府语言，本地语言书写却未从教会环境消失。英格兰—诺曼宗教机构，继续以英语编写《盎格鲁—撒克逊编年史》、讲道及其他教导作品。[^p156-73]

获得读写能力后的某个阶段，纯娱乐作品也被写下来。有些大概长期以各种口头形式流传，才由教会抄写者落笔；围绕《贝奥武夫》处境与年代的争论，说明这一过程何等模糊。[^p156-74] 故事描绘的虽是想象过去，却从日耳曼传说库取材，围绕狄奥多里克、埃尔马纳里克等四、五、六世纪历史人物，在英格兰、法兰克和斯堪的纳维亚出现；尤其加洛林帝国使兼容性的日耳曼共同身份，在政治上更有吸引力以后。[^p156-75] 阿尔弗雷德有一本如今佚失的这类“撒克逊歌曲”，并将其背熟；[^p156-76] 古英语诗集中存世的五首诗，显著呈现日耳曼传说。在以《贝奥武夫》为代表的英雄体裁中，大陆只留下<a id="pdf-157"></a><!-- PDF page 157; original page 128 -->《希尔德布兰德之歌》一首，大概因为当地本地语言书写受限得多；九世纪开花后，十世纪似又凋萎。[^p157-77] 相比之下，有人认为，英格兰十、十一世纪英语的成功，不只是教会文化本地语言化，也是创造政治民族的关键一步，因为“普通人”能通过本地语言，接近中央政府和地方行政机制。

在丹麦、挪威与瑞典，人们认为，非卢恩读写和传统拉丁学问，随外来教会人士抵达。但本地语言保有位置，尤其在虔敬与机构运作的实践中。十二世纪末起，宗教、法律和历史文本，开始以采用字母书写的本地语言记录；纪念、所有权宣示和巫术，仍用卢恩文字。斯堪的纳维亚模仿英格兰本地语言书写，却未达到其程度。另一方面，如前所见，冰岛母语向新方向发展。除了上文十三世纪诗歌、散文，十二世纪留下的法律汇编、历史、圣徒传和语法论著，都证明本地语言的地位。最初来到当地、努力为哥特、法兰克、英格兰、撒克逊和北欧人创造基督教词汇的传教者，大概无法想象中世纪后期这种文学繁荣，以及世俗读写的政治与社会影响。自教会人士最初面对如何用潜在皈依者能懂的语言传达基督教概念以来，本地语言书写，已走过漫长道路。

600至1100年，使用日耳曼语言的民族，差异多样、分布广泛。他们既住在西欧主导王国，也住在政治世界边缘的小国。有些最接近罗马帝国影响，600年前就已成为基督徒；另一些相距更远，到十二世纪仍在放弃传统宗教的过程中。到1100年，中世纪早期教会各具特色的基督教诸形态，越来越让位于更普遍的基督教世界。要在这几个世纪寻找“日耳曼”经验，必须承认外部影响的广度、期间变化的规模，以及生活经验的多样性。基督教诸形态，不仅在时间和空间分离，也在社会层面分层；不同基督教化节奏，使不同地区和社会阶梯两端的<a id="pdf-158"></a><!-- PDF page 158; original page 129 -->经验各不相同。此外，教会界定基督徒生活时，不断移动目标；自身也未达到宣称的标准，并非始终有资源，帮助实现会议、悔罪书与讲道表达的目标。因此，日耳曼世界的基督徒及其教会，多姿多样，但确实共享皈依经验。600至1100年，外来教会人士不断走向日耳曼世界某个地方，面对异教徒。任何一个时刻，从兰斯、罗切斯特到雷克霍尔特，总有某处传教者正在应对一项任务：引入外来宗教，并以基督教方式重新解释传统社会。随着环境变化、基督教迈向第二个千年，改造传统文化的过程不断上演，每一次都有新的因素发挥作用。
