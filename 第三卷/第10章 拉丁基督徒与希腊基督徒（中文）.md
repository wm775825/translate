# 第10章 拉丁与希腊基督徒

蒂娅·M. 科尔巴巴（Tia M. Kolbaba）

<a id="pdf-242"></a><!-- PDF page 242; original page 213 -->

本章开始时，正值古代晚期结束；阿尔卑斯山是地中海文化与山北文化之间的一道巨大分界。罗马与君士坦丁堡，彼此之间的共同点，比它们各自与北方日耳曼群体的共同点更多。君士坦丁堡皇帝在罗马仍有足够权威，可以逮捕反抗其政策的教宗；教宗派驻皇廷的使节（apokrisiarios），也是罗马的重要人物。然而，到1100年，教宗本人往往来自阿尔卑斯山以北，西方很少有人懂希腊语；罗马承认的皇帝权威，如果有，也来自德意志。拉丁世界与西北欧日耳曼世界共同发展、相互适应、融为一体，在形成自身等级体系的同时，已经失去对帝国、拜占庭统治方式的理解。教宗在西方教会中的角色和威望，超出拜占庭人的理解；皇帝在东方教会中的角色，则使拉丁基督徒困惑、震惊。神学和仪式差异，加深了普遍的疏离感，最著名的反映，见于十字军编年史。因此，描述七至十一世纪希腊与拉丁基督徒的关系，似乎就是书写罗马天主教会与希腊正教会分裂的历史。然而，这句话潜藏着过多的后见之明。从结局——分裂——出发的叙述，往往过分强调早期分歧，忽略友爱合作；往往依赖那些“解释”分裂起源的资料，忽视那些默认、或明确表示根本不存在分裂的资料。这样便会使本应层次丰富、清晰可辨的两社会及其教会图景，变得平板模糊：它们由共同过去连接，却因中世纪早期不同经历而日益疏远。

### 600—751年：三次入侵

七世纪，穆斯林开始建立一个改变基督教世界结构的帝国。到八世纪初，他们控制了地中海东岸、南岸和伊比利亚半岛。讽刺的是，这样一来，六、七世纪困扰罗马、君士坦丁堡关系的一个问题，反而得到解决：帝国不再需要，在东方反迦克墩派人口与罗马迦克墩派领袖之间维持平衡，因为前者此时大多处于穆斯林统治之下。[^p243-1] 然而，这种新局面并未缓和两地关系，反而使争执增多。早在阿拉伯入侵以前，君士坦丁堡牧首就已要求承认，本教座与罗马地位平等，包括在东方拥有普遍管辖权，对应罗马在西方的管辖权。[^p243-2] 但六世纪，君士坦丁堡牧首使用“普世牧首”（oikoumenikos）称号时，罗马提出抗议。[^p243-3] 教宗坚持，君士坦丁堡没有合法根据，要求本教区以外的权威；罗马在整个基督教世界的首位，则建立在使徒彼得的地位上。[^p243-4] 阿拉伯入侵以后，君士坦丁堡成为唯一不受穆斯林统治的东方牧首区，因此其东方首位权主张更具说服力，教宗的反对也更激烈。

阿拉伯入侵，也以其他方式促进君士坦丁堡与西部行省分离。东部帝国为自身生存而战，所剩资源很少能够西送；伦巴德入侵，又使罗马、拉文纳成为伦巴德海洋中的孤岛。教宗领导意大利北部应对入侵。围城时组织罗马防御、供应，并与“蛮族”攻击者谈判的教宗，并非只有格列高利一世（590—604年），虽然他最著名。这种积极行动的结果，是教宗自主权与威望进一步上升。

这一时期的第三次入侵，进一步破坏拉丁与希腊基督徒之间的交通。六世纪中叶至七世纪中叶，斯拉夫群体在巴尔干诸行省和伯罗奔尼撒定居。除塞萨洛尼基这个最后的希腊基督教前哨外，周边领土都属于多神教斯拉夫人。帝国横跨该地区、从君士坦丁堡经塞萨洛尼基，再通向亚得里亚海<a id="pdf-244"></a><!-- PDF page 244; original page 215 -->港口的陆路，被截断了，日常人员和信息流动大幅减少。斯拉夫海盗也破坏海上交通。五、六世纪，某些艺术形式、神学观念、制度形式和文学倾向，曾在整个地中海世界共有；七世纪，这种共同性大为削弱。此外，巴尔干直到六世纪还不罕见的拉丁语使用者和拉丁教会，在斯拉夫入侵后消失；这意味着部分双语、双文化中介的丧失，他们曾在地中海拉丁、希腊两端之间，构成一种可渗透的膜。

随着各自世界缩小，东西方人的世界观也趋于狭窄。在意大利，帝国及其希腊文化，与教宗、贵族和民众的日常关切，越来越无关。与此同时，东部帝国通过退守有限核心地带、以宽阔边境实施纵深防御，熬过了七世纪。旧有横跨地中海的帝国和教会，曾包含众多民族、文化和仪式；收缩后的新帝国，大体讲希腊语，宗教实践的差异更少。人们以一种信念自我安慰：他们的苦难，是上帝净化其选民的方式。然而，若上帝的眷顾和帝国存亡，取决于他们的纯洁，任何偏离就必须被消除。按照这种看法，反对迦克墩会议的人，受不信者统治，是罪有应得；仍留在帝国内的“偏离者”，也必须被纠正。例如，犹太人必须受洗，必要时可以强迫；容忍偏离，就是冒着招致上帝愤怒、危及帝国世界（oikoumene）生存的风险。[^p244-5]

不过，罗马并未偏离。圣彼得在罗马，他的继承者也在，是正统信仰的首要捍卫者。680—681年，主教齐集君士坦丁堡，谴责希拉克略（610—641年）及其继承者的一志论。教宗阿伽托（678—681年），从罗马向第六次大公会议送来教义书信，阐释耶稣基督具有两性、两意志、两种运作的正统教导。会议在正式议事录，以及致皇帝、教宗的信中，赞扬并认可他的教导。[^p244-6] 这种教宗威望，得益于教宗的自主性；教宗之所以领导对一志论的抵抗，是因为皇帝无法控制他们。然而，对教宗的广泛钦佩，仍抵不过东西方联系的减少。赞扬阿伽托的同一次会议，西方教座代表竟少到可能使东方主教<a id="pdf-245"></a><!-- PDF page 245; original page 216 -->以为，西方教会正在萎缩成一个人数很少的群体。[^p245-7] 这是危险的错觉。拜占庭人忽略西北欧基督徒，没有理解这些北方人，如何使西方教会重新充满活力。教宗的羊群，向北寻找新羊，因而增长；这些羊对东方基督徒知之甚少，也不尊重东方皇帝，却以君士坦丁堡人无法理解的方式，聆听罗马牧者的声音。[^p245-8]

此外，远距离赞扬教宗，尤其对会议召开前已经解决的教义问题加以赞扬，也许很容易；纪律教规却是另一回事。第五、第六次大公会议没有提供这类教规；从第四次大公会议到七世纪末，世界已大为变化，帝国教会人士需要适应变化的规则。因此，皇帝查士丁尼二世（685—695、705—711年）于692年在君士坦丁堡召开会议，称为特鲁洛会议，或第五六次会议。[^p245-9] 虽然正式说来，五大牧首区都有代表，但在签署最终教规汇编的220位主教中，183位来自君士坦丁堡牧首区，只有十位属于罗马管辖，且全都来自伊利里库姆。通常，教宗会派遣有权代表圣座行事的使节；但特鲁洛《议事录》上，只有教宗驻廷使节的签名。他是教宗常驻或接近常驻君士坦丁堡的代表，却无权在大公会议上代表教宗。[^p245-10]

总之，第五六次会议由东部帝国的主教组成，集中处理帝国教会关心的两个问题：在缩小的领土内，重新组织、保存帝国教会等级体系，以及统一帝国内部的礼仪、实践。前者与拉丁人关系不大，他们也几乎不加注意；后者却激怒罗马。东方主教执着于一致性，确信君士坦丁堡的习惯应为规范，因而谴责各种与己不同的罗马习俗。此外，会议第1条教规，把教宗霍诺里乌斯一世（625—638年）列入一志论异端名录；第36条教规，则确认迦克墩会议第28条，规定君士坦丁堡牧首“应享有与<a id="pdf-246"></a><!-- PDF page 246; original page 217 -->旧罗马教座相等的特权，在教会事务上，同样受到尊崇，居其后为第二位”；罗马从未接受这一教规。[^p246-11] 教宗塞尔吉乌斯一世（687—701年）拒绝签署《议事录》后，查士丁尼二世派帝国官员前去逮捕。罗马民众在拉文纳和五城区军队支持下，保卫教宗。这名官员非但没有抓走教宗，自己反陷生命危险，只因教宗保护，才得以脱身。东方教会中，皇权无所不在、居支配地位；西方教会中，则没有统一的世俗权力挑战教宗权；两者差异显而易见。教宗也由此再次颂扬自己及前任，是对抗皇帝暴政、捍卫正统信仰的人。[^p246-12]

教宗不仅保护正统信仰，也保护正统信徒。伊斯兰入侵迫使大批东方迦克墩派基督徒流亡，许多人定居罗马、意大利南部和西西里。八世纪，圣像破坏成为帝国政策时，更多讲希腊语、行希腊礼的人，迁居罗马牧首区。他们的影响相当大：678至752年，13位教宗中，有11位是来自叙利亚、西西里或君士坦丁堡的希腊语使用者。虽然这似乎并未对他们面对皇帝的态度产生多大影响——他们捍卫本教座特权，并不亚于罗马出生的教宗——但他们体现出一个罗马对东方教会、帝国高度了解的时代。罗马众多希腊修道院，也加强了这一时期较高程度的希腊文化影响。[^p246-13]

### 751—843年：教宗与法兰克人

对拜占庭帝国来说，七世纪充满创伤，八世纪则逐步走向新的平衡。穆斯林和阿瓦尔军队，在君士坦丁堡城墙下被击退；行省军政合一的军区制度，提供了稳定防御。帝国虽然大幅缩小，却已有些余裕，思考自身在世界上改变了的位置。八世纪以圣像破坏时代著称，圣像破坏又常被视为剧烈冲突时期，但近来的解释挑战了这种看法，开始把它理解为“危机之后的稳定巩固<a id="pdf-247"></a><!-- PDF page 247; original page 218 -->时期”，而非“持续120年的危机”。[^p247-14] 相比之下，拉丁教会尚未走出危机；稳定、巩固还未到达意大利。为寻求更大安全，教宗采取了改变世界的行动。

749年，面对伦巴德威胁复起，教宗转向北方寻求保护。753年，教宗斯德望三世（752—757年）成为首位越过阿尔卑斯山、进入法兰克王国的罗马主教。他在那里与丕平三世（751—768年）结盟，为丕平及诸子加冕、傅油；后者承诺保卫圣彼得的教产。[^p247-15] 丕平的继承者、加洛林诸王，尊重教宗，以罗马礼仪、神学、教会法为典范；法兰克军力，则使教宗权得以巩固对君士坦丁堡的独立，又不至屈从伦巴德人。800年圣诞节，教宗利奥三世（795—816年）为查理曼加冕为罗马人的皇帝，把本教座的权威、威望，投向这位来自法兰克的“罗马人的皇帝”。这些行动的长远影响巨大。

但当时人是否清楚，教宗已经一劳永逸地选择这位西方皇帝，而舍弃君士坦丁堡的罗马人皇帝？罗马人与君士坦丁堡人，对法兰克人仍怀有某种共同的居高临下态度。尽管双方都承认，法兰克人已重要到不可忽视，却没人料想他们会思考。在西方的Romani与东方的Romaioi看来，法兰克人都只是忠心却野蛮的教宗仆人。这一点，他们错了。为法兰克国王效力的某些人，并非不识字的武士，而是能够思考、阅读、争辩神学的学者，甚至会不同意教宗。第七次大公会议（787年），即第二次尼西亚会议，就提供了这种分歧的契机。785年，伊琳娜皇后（780—802年）、其子君士坦丁六世（780—797年），以及牧首塔拉修斯（784—806年），寻求罗马支持召开会议，恢复圣像敬礼。教宗哈德良一世（772—795年）派代表前往尼西亚，却无人征询法兰克人的意见。会议驳斥圣像破坏派论据，颁布自身的圣像敬礼教义，教宗代表签署，教宗也为之欣喜。不过，他似乎没有把787年的《议事录》送给法兰克国王。法兰克人却以某种途径，得到《议事录》的一个拉丁译本，并以为这份文书是会议的正式记录。[^p247-16] 查理曼的学者们大为震惊。也许，考虑到尼西亚会议没有法兰克代表，<a id="pdf-248"></a><!-- PDF page 248; original page 219 -->即使译文准确，他们也会拒绝尼西亚会议的决定；实际得到的译文，却错得令人遗憾。[^p248-17] 他们把所发现的问题列成清单，送往罗马。[^p248-18] 奥尔良的狄奥杜尔夫又撰写了更完整、有条理地反驳787年《议事录》的著作，《查理国王驳会议书》（Opus Caroli Regis contra Synodum，即《加洛林书》）。虽然哈德良驳回其论点，赞扬会议，法兰克教会领袖却没有忘记此事；东方第二轮圣像破坏时期，问题再次出现。825年一次会议上，虔诚者路易（814—840年）及教士表明，他们仍坚信，希腊人在第七次大公会议上走得太远。他们引述教宗格列高利一世，重申图像的教导作用：“圣经对于识字者是什么，图像对于无知者就是什么；无知者从图像中，看见自己必须做的事。”[^p248-19] 但他们也继续主张，敬礼圣像就是偶像崇拜。

查理曼和路易的神学家博学多识，对自身能力充满信心，却受拙劣译文牵制，也缺乏对东方传统的理解。在这些方面，他们预示了后来的继承者：那些在十一世纪罗马、君士坦丁堡分离中，发挥重要作用的北方教会人士。

九世纪，法兰克人与教宗的不同意见，也不只在第七次大公会议的反应上。基督教信经的核心处，法兰克与罗马就存在分歧。六世纪末或七世纪初，法兰克教会接受对尼西亚—君士坦丁堡信经的一项增补：原文“我信圣灵……由父所出”之后，加上“及子”（拉丁语Filioque）。东方从未接受这一增补，罗马当时也尚未接受。教宗利奥三世（795—816年）虽然明确赞同“圣灵由父及子所出”的神学命题，却命令法兰克人停止在信经中诵读“及子”，还把没有“及子”的“正确”信经，刻在牌板上，立于圣彼得教堂。[^p248-20] 换言之，至少在信经形式上，罗马与君士坦丁堡立场一致，反对亚琛。七、八世纪罗马与君士坦丁堡之间的双向交往，正在<a id="pdf-249"></a><!-- PDF page 249; original page 220 -->让位于教宗、拜占庭人、法兰克人之间的三方关系。

### 843—996年：教宗、拜占庭人与法兰克人的三角关系

整个九、十世纪，罗马、君士坦丁堡两大教座的竞争持续不息，因为教宗不断宣称有权裁判其他牧首，而牧首们也不断反对。由此产生的某些争执，确实十分著名，对罗马教宗、君士坦丁堡牧首的关系史至关重要。九世纪所谓“佛提乌斯分裂”中，教宗一再宣称管辖权，甚至及于其他牧首；牧首则以同样强烈的否认相抗衡。四婚危机也提出同样问题：牧首因皇帝第四次结婚而将其绝罚，教宗却给予特许。教宗也继续反对东方牧首使用oikoumenikos称号；西方认为，只有教宗才有“普世”权威。这些冲突在许多方面很重要，但大多重演教宗权与牧首权的长期争议。[^p249-21]

这一时期的新特点，是教宗、拜占庭人、法兰克人三方的关系。八世纪和九世纪初的教宗，始终反对圣像破坏，接纳来自帝国的圣像敬礼派难民，并在第七次大公会议发挥作用，因此进一步积累了在君士坦丁堡的声望。这种尊重，显然是拜占庭传教士在斯拉夫地区，愿意承认教宗在中欧管辖权的原因之一。此外，教宗支持拜占庭在潘诺尼亚传教，也是教宗与东法兰克统治者，争夺当地教会控制权的斗争一部分。[^p249-22] 同时，拜占庭人与法兰克人在保加利亚，也直接接触。这里的争论，同样并非总是教宗与法兰克传教士站在一边、拜占庭人站在另一边。虽然教宗支持、有时还控制拉丁传教事业，法兰克人却向斯拉夫人讲授罗马仍未接受的“及子”说。罗马与法兰克人，在“及子”、世俗统治者在教会中的角色，以及圣像使用等方面，仍有差异。与此同时，君士坦丁堡牧首佛提乌斯<a id="pdf-250"></a><!-- PDF page 250; original page 221 -->（858—867、877—886年在任），发表声明，列举法兰克传教士在保加利亚的错误教导，以“及子”为首。不过，他知道罗马教宗尚未接受这项信经增补。[^p250-23] 在这一时刻，不可能预见以后几个世纪的联盟与分裂。

另一方面，强大的力量正推动教宗权与法兰克人更加接近。最重要因素，仍是法兰克统治者能够提供保护。843年《凡尔登条约》以后，查理曼帝国分裂，削弱了九、十世纪法兰克人在罗马的影响，但另一种选择并不诱人：教宗权被罗马贵族家族间的争夺支配，教宗宝座被当作胜利战利品之一。教宗权威望因此受损。要恢复教宗在整个欧洲的声誉，需要剧烈改变。

### 996—1100年：西方教会的转变

变化来自阿尔卑斯山以北，一群有志于教宗独立的人，在新统治王朝奥托王朝支持下行动；后者有效干预教宗选举。这种干预，巩固了教宗与北方人的联盟，切断了仍把罗马与君士坦丁堡连接的大部分纽带。奥托王朝在意大利的介入，与早先加洛林人的努力，有两项根本区别。第一，奥托诸帝企图控制意大利南部，因此与拜占庭人为敌，程度超出加洛林人。由此产生的政治、军事敌意，又助长其他敌意，克雷莫纳的柳特普兰德那篇恶名昭著的谩骂，就表明这一点。他记述自己代表奥托一世——936年为王，962—973年为帝——出使君士坦丁堡的经历时，德意志人对“希腊人”（Greci）、“罗马人”（Romaioi）对德意志人的轻蔑，始终显而易见。第二，奥托王朝处理争议教宗选举及教宗权腐败的办法，与加洛林人不同。他们把本国改革者安置到教宗宝座；这些“改革者”对于平信徒在教会中角色的观念，实际相当激进。由此开始的西方基督教制度转变，将使教会在以后几个世纪中分离。尽管过程断续，十世纪末和十一世纪的总体趋势，是德意志统治者、教士更多地介入教宗权。无论<a id="pdf-251"></a><!-- PDF page 251; original page 222 -->德意志皇帝与教宗的斗争，最终谁胜谁负，罗马内部强烈的德意志影响，都进一步加深旧罗马与新罗马之间的裂痕。1014年，亨利二世（1002—1024年为王）加冕为皇帝时，罗马诵唱的信经加入了“及子”。这件事本身重要，也象征更广泛的运动：随着十一世纪推进，德意志教会改革者，从影响教宗权走向控制教宗权。拜占庭人则把德意志影响，视为对古老教座的某种篡夺。这一时期，出现一些简短的《罗马与君士坦丁堡分裂史》，开头便描述这种日耳曼人的接管：

> 第七次会议闭幕后……〔教宗〕利奥从法兰克腹地召来一个叫查理的人，为他加冕为皇帝……随查理来的一些人是异端……他们进入罗马，就开始败坏上帝的子民，说至圣圣灵不仅由父所出，也由子所出，并教导人们奉献无酵饼。他们还说其他与教会传统不相干的胡话。[^p251-24]

即便这种记述，以及类似记述，在历史上并不准确，却反映了拜占庭人对罗马遭遇的普遍看法：从前文明、可敬的社会，已被涌入的蛮族淹没。

教宗改革初期，也恰逢诺曼人征服意大利南部拜占庭与伦巴德土地。教宗改革与诺曼征服，共同构成希腊、拉丁教会代表之间那次最著名会面的背景。1053、1054年，德意志改革教宗之一利奥九世（1049—1054年），正在意大利为保住宝座而战。他寻求君士坦丁堡援助，既对抗改革运动的反对者，也对抗意大利南部的诺曼人；后者威胁圣彼得共和国来之不易的独立。同样与诺曼人交战的君士坦丁堡皇帝，愿意结成联盟。利奥选择席尔瓦—坎迪达枢机主教洪贝尔特，率使团赴君士坦丁堡商议。洪贝尔特是改革运动的典型：一位北欧人，随德意志教宗来到罗马，为改革目标撰写了可观的论战作品。此外，他本已对希腊教会怀疑，因为知道希腊人批评拉丁人在圣餐中使用无酵饼（azymes）。[^p251-25] 他对<a id="pdf-252"></a><!-- PDF page 252; original page 223 -->罗马实践的任何批评都愤怒不已，尤其鄙视君士坦丁堡牧首米海尔·凯鲁拉里乌斯（1043—1058年）。后者以反对无酵饼著称，丝毫不愿承认改革者版本的教宗首位权。洪贝尔特前往君士坦丁堡时，已准备应付牧首的顽固。

然而，从君士坦丁堡看来，“及子”是创新，教宗要求本牧首区以外管辖权是傲慢，在圣餐中使用无酵饼不合法，而德意志人是蛮族。凯鲁拉里乌斯反对与教宗权结成任何联盟。洪贝尔特一面同皇帝商谈和平、结盟，一面把牧首当作一个顽抗的下属主教，结果是灾难性的。几个月里，双方相互怠慢，为礼仪程序争吵，围绕无酵饼及其他问题互相指控；最后，洪贝尔特大步走进圣索菲亚教堂，把绝罚诏书放在祭坛上。凯鲁拉里乌斯则召开君士坦丁堡驻都会议，谴责教宗使节。

1054年的这些事件，并不标志分裂最终发生，却凸显了中世纪其余时期持续争执的几个问题：仪式、神学差异（无酵饼、“及子”）；教会论差异（教宗的全权，plenitudo potestatis，与罗马、君士坦丁堡、亚历山大、安提阿、耶路撒冷代表共同参与之大公会议的权威）；以及缺乏友爱、相互尊重。最后一点最重要。洪贝尔特懂一点希腊语，却不熟悉东方教会历史，不尊重希腊文化，也毫无理解希腊传统的愿望。只要希腊人的实践、教义与罗马不同，就必定是希腊人错。凯鲁拉里乌斯同样轻视拉丁仪式和文化。他致东方牧首的信，把拉丁司祭剃须这样的抱怨，列入罗马教会“显然不合法、受禁止而可憎”的习俗，开了一个不幸先例。[^p252-26] 洪贝尔特使团没有达到目标。1059年，教宗接受诺曼人统治意大利南部，助长了持续数百年的侵蚀过程，使希腊、拉丁基督徒间最后的双语、双文化桥梁，渐渐消失。

不过，十一世纪，缺乏友爱、尊重，仍只限于少数人。上述罗马、君士坦丁堡之间的任何决裂，都未牵涉很多人。洪贝尔特与凯鲁拉里乌斯彼此的轻蔑，<a id="pdf-253"></a><!-- PDF page 253; original page 224 -->甚至并非所有同级教会领袖都认同；[^p253-27] 还要过一段时间，这种态度才会更深入羊群。罗马、君士坦丁堡高层教士的冲突，无疑重要，但十字军东征前的几个世纪，讲希腊语、行希腊礼的基督徒，与讲拉丁语、行拉丁礼的人之间，也有积极接触。这些接触的故事，显示出对差异的认识，但少见冲突，合作、相互钦佩却很常见。下面简举几个来自修道世界的友好例子。

十世纪末，共住修道生活开始在阿索斯山蓬勃发展。[^p253-28] 当时建立的修道院中，有大劳拉修道院（963年）；[^p253-29] 创办人阿索斯的亚他那修（约925—约1001年），提倡共同生活。其修道院规条，大部分依据君士坦丁堡斯图迪奥斯修道院的《规章》（Typikon），但亚他那修也拥有《圣本笃会规》的希腊译本。拉丁、希腊修道院之间，修道传统差异很大；不过，亚他那修使用《本笃会规》，是两种文化共享文本的众多例子之一。毕竟，东西方修士的许多理想，来自共同的圣经与早期修道经典基础。[^p253-30]

阿索斯的亚他那修那部《圣本笃会规》的译者，很可能是意大利南部的一位希腊人。[^p253-31] 阿索斯有来自西西里、卡拉布里亚的意大利—希腊修士团体；至986年，西西里修士已在那里。[^p253-32] 这种意大利南部修士，往往在不止一种意义上是译者：他们能把文本从一种语言转入另一种，也能把手稿从一地移至另一地。其中少数人，不仅双语，也兼通两种文化，实际占据两世界之间的空间。

大劳拉修道院创建不久，拉丁修士也在阿索斯定居。[^p253-33] 圣亚他那修最初把他们接入自己的修道院，后来又帮他们建起自己的修院。这所拉丁修道院，<a id="pdf-254"></a><!-- PDF page 254; original page 225 -->遵循本笃会规，其生活方式得到希腊邻居钦佩。一个多世纪里，这些拉丁修士，在希腊修道生活的腹地兴旺发展。与意大利南部、中部的希腊修士一样，他们成为解释者、翻译者。后来，君士坦丁堡一所阿马尔菲修道院的同道，也发挥相同作用。[^p254-34]

希腊、拉丁修士之间更多的互动，也发生在西方修道中心。意大利南部，罗萨诺的尼洛等圣人，延续了一个世纪前开始的希腊修道复兴。尼洛与阿索斯的圣亚他那修同时代，出生、教育、礼仪都属于希腊传统，却也钦佩圣本笃、大格列高利，并为西方皇帝、教宗提供建议。[^p254-35] 他约910年出生于卡拉布里亚的罗萨诺，在希腊教会传统中受教育，成为著名的希腊教父解释者和圣歌作者。约957至980年，他在卡拉布里亚北部创立不止一所修道院。约980年，又离开卡拉布里亚北行，先到卡普阿，再到蒙特卡西诺修道院捐给他的修院。尼洛及同道，住在卡西诺以北仅几公里处，15年间（980—995年），与拉丁修士保持密切、友好关系。这位卡拉布里亚人创作赞美圣本笃的圣歌，与自己的修士，在蒙特卡西诺教堂通宵礼拜时吟唱。圣歌显示，他读过格列高利《本笃传》的拉丁原文。[^p254-36] 蒙特卡西诺一位新院长上任后，尼洛与该修院关系恶化，他和追随者遂前往加埃塔附近的塞尔佩里。[^p254-37] 约1001年，他最后一次迁移，在罗马东南创建格罗塔费拉塔修道院，并于1004年在那里去世。罗马其他希腊修道院，或被废弃，或交给拉丁修士后很久，格罗塔费拉塔仍是罗马附近希腊修道生活的孤岛。后来的院长，经常担任教宗权与帝国之间的中介。他们讲希腊语、行希腊礼，却接受教宗权威，居住意大利，是理想的沟通者。

尼洛虽然选择不在罗马定居，却认识、钦佩那里的其他希腊修士，尤其居住于<a id="pdf-255"></a><!-- PDF page 255; original page 226 -->圣阿莱克修斯修道院的人；该院在990年代达到鼎盛。[^p255-38] 修道院历史始于977年，教宗本笃七世（974—983年），与被迫逃离叙利亚的大马士革迦克墩派总主教塞尔吉乌斯，共同复兴一所以塔尔苏斯的圣博尼法斯为主保的施济所（diaconia）。罗马没有足够希腊修士填满新修道院，教宗便作出激进决定：同时接纳希腊、拉丁修士，由希腊院长领导。第二位院长利奥（981—999年）任内，修院的主要主保，从圣博尼法斯转为圣阿莱克修斯。这里的修士，实现了“希腊、拉丁灵修的完全融合”，中世纪或现代其他修道院，都无可比拟。[^p255-39] 数名成员，后来成为拉丁教会有权势的人物；其中两人成为圣徒。一位是卡萨诺的格列高利，来自意大利南部、讲希腊语的修道领袖，约987年带部分门徒前往罗马，后来成为德意志一所修道院的院长。另一位是布拉格的阿达尔伯特。他是一位讲拉丁语的斯拉夫人，原任布拉格主教，989年与世俗权力冲突后逃离。他出发前往耶路撒冷朝圣，却先到罗马、蒙特卡西诺；在后者，他遇见罗萨诺的尼洛，被劝说放弃朝圣、进入修道院。然而，阿达尔伯特想加入尼洛的团体时，这位卡拉布里亚人拒绝了。他说，阿达尔伯特是拉丁人，不适合希腊修道院；于是写信把他推荐给圣阿莱克修斯院长，后者是尼洛的朋友，也是希腊人。阿达尔伯特遵照安排，在那里住了几年，直到992年被迫回布拉格教区。他的影响继续留在圣阿莱克修斯；该院成为司祭训练中心，培养准备前往拜占庭—斯拉夫传统与拉丁传统交汇地区的人。院中希腊、拉丁习俗和语言混合，正适合这样的人。

这种友好、富有成果的互动固然重要，但圣阿莱克修斯修道院，以及罗萨诺的尼洛这样的人物，都不典型。罗马多数希腊修士，活动于希腊世界，不懂拉丁语，也无特别愿望了解；另一边，很少拉丁人懂希腊语。[^p255-40] 尼洛坚持，来自德意志、受过教育的拉丁人阿达尔伯特，不属于自己的希腊团体，这就向我们表明圣阿莱克修斯的独特。更南面，讲希腊语、行希腊礼的修士，与拉丁人的接触更少，多数生活在希腊语言<a id="pdf-256"></a><!-- PDF page 256; original page 227 -->和仪式的世界里。意大利—希腊圣人受到世俗荣耀诱惑时，这种诱惑，表现为拜占庭使者邀请他们前往皇廷。罗萨诺的尼洛面对这样的邀请，因害怕在首都受到尊崇而拒绝。[^p256-41] 据圣徒传作者说，卡萨诺的圣格列高利离开意大利南部拜占庭土地，也出于类似原因：巴里的帝国总督，想带他去君士坦丁堡觐见皇帝。[^p256-42] 对尼洛、格列高利传记的作者而言，无论在皇廷邀请的故事中，还是其他地方，君士坦丁堡皇帝，都是世上最高权威。[^p256-43] 总之，意大利—希腊修道生活，既紧密联系更东方的希腊修道传统，也紧密联系帝国。

希腊、拉丁基督徒的互动，也并非都像尼洛与蒙特卡西诺的关系那样友好。任何持续接触拉丁人的希腊人，都会注意到仪式、纪律差异。拜占庭中期最著名的这种意识，产生于九世纪后半叶保加利亚的法兰克、拜占庭传教士竞争：法兰克人试图在保加利亚人中建立西方习俗、礼仪、教义，各类拜占庭传教士则试图建立东方的。在竞争中，拜占庭传教士注意到法兰克教会若干在他们看来属于教义、纪律的错误。不过，这场冲突很快结束，从未牵涉整个西方教会，此后几个世纪也少有回响。[^p256-44]

在竞争性较弱的情境中，罗萨诺的尼洛与蒙特卡西诺院长、修士，也意识到彼此差异。据尼洛传记作者说，院长邀请他和同道来访时，引述圣经中狮子与牛一同躺卧的话；尼洛则以巴比伦哀歌作答：“我们怎能在异乡，唱耶和华的歌？”但他还是答应了拉丁院长的请求。他写好赞美圣本笃的圣歌后，与修士来到蒙特卡西诺教堂，整夜诵唱日课。[^p256-45] 本笃会修士，被尼洛圣歌和希腊礼拜之美打动，围拢过来提问。其中两个问题，源于希腊、拉丁实践的差异；后世反拉丁的东方人，会把它们列入庞大的抱怨武库。一位卡西诺修士问尼洛，<a id="pdf-257"></a><!-- PDF page 257; original page 228 -->只要一年其他时候节制身体、持守斋戒，一年吃一次肉，又有什么不对？尼洛答得尖刻、讽刺：只要其他时候都健康，一天打断自己的腿，又有什么不对？[^p257-46] 另一位修士问起安息日禁食：拉丁教会周六禁食，希腊教会不禁。[^p257-47] 这是严重问题吗？这一次，尼洛的回答，充满基督教思想中绵延不绝的一种精神：禁食、吃肉都次于友爱。他说：“吃的人，不可轻看不吃的人；不吃的人，不可论断吃的人，因为上帝已经接纳了他们双方。”禁食与否，不是问题；问题是，禁食或进食，究竟意在何为。[^p257-48]

也许，这主要体现的并非尼洛本人的温和态度。我们的记述，出自格罗塔费拉塔一位修士之手，写于尼洛死后最初20年内某时，目的是教化该院修士。[^p257-49] 他们应从此事学到什么？他们神圣的创办人，得到拉丁人钦佩，也反过来钦佩拉丁人；拉丁、希腊之间的差异，并不重要。格罗塔费拉塔修士，生活于希腊、拉丁世界之间，服从教宗，却在习俗、仪式上保持希腊传统，这一教训至关重要。倘若领袖不培养其传记作者提倡的、对拉丁习俗的宽容和尊重，格罗塔费拉塔就无法生存。

传统上，罗马、君士坦丁堡教会分离的历史，是这样讲述的：中世纪早期，拜占庭人与西方人接触稀少，罗马所属教会与君士坦丁堡所属教会，在仪式、习俗上逐渐分歧。例如，拜占庭经历圣像破坏争论后，圣像成为其虔敬生活的核心，西方却从未以同样方式尊崇图像。同时，西方教会受“日耳曼理想”影响，[^p257-50] 更加以教宗权为中心。十一世纪，希腊人与拉丁人恢复经常接触，不能不注意这些差异。中世纪很少有人，能以近似文化相对主义的眼光看待差异，因此双方也往往谴责差异。接触增加，了解和<a id="pdf-258"></a><!-- PDF page 258; original page 229 -->谴责随之增加。这种对教会间差异的意识，与十字军及其他接触引发的族群仇恨相结合，导致至今未获弥合的“分裂”。

这一故事的许多细节，固然无法否认，叙事本身却因以“分裂”为目的论终点而有缺陷。中世纪早期，报告拉丁、希腊人友好交往的资料，与报告冲突的资料一样多。如果总在寻找“分裂”的起源、原因，我们就会转向那些告诉我们何以“分裂”的资料。但这些资料揭示的，只是早在“分裂”“完成”数百年前，就已存在的原因。那么，约1050至约1300年，究竟什么改变了？变化的并非那些“原因”，如圣餐饼的差异，或信经加入“及子”，而是人们还愿不愿意把这些差异视为无关紧要之事。这种意愿的丧失，源于双方的历史发展：接触增加而产生敌意，对仪式、神学上哪些差异可以接受，意见也随之改变。这些变化，要到十二世纪，随着十字军东征，以及教会法、神学的革命性发展，才会到来。
