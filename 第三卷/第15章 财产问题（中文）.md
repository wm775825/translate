# 第15章 财产及其问题

罗斯玛丽·莫里斯（Rosemary Morris）

<a id="pdf-356"></a><!-- PDF page 356; original page 327 -->

本笃会蒙特卡西诺修道院主巴西利卡的巨大青铜门，至今仍非凡地见证其中世纪早期地产财富。36块门板，刻有十二世纪初，修道院拥有、或宣称拥有的庄园名称。前四块列出“圣本笃领地”（Terra S. Benedicti）41项地产，是该院核心财产，约1105—1115年提出权利主张；后面大多数门板，可联系奥德里修斯二世任院长时期（1123—1126年）。这些主张，并不夸张：《执事保罗登记簿》（1131—1133年编）所含620份卡西诺契据中，约300份，涉及门上列出的庄园。[^p356-1] 修士热衷展示地产财富，因为对他们，如同所有中世纪早期地主，财产不仅是经济资源，也是社会资源。教会想实现的一切——祈祷、礼仪、讲道、改宗、慈善——无一不需要财产。土地所有权，对机构，如对个人，也界定地位，是创造、表达权力的手段。[^p356-2] 宗教机构在危险世界，如何取得、维持、保护财产，以及如何使用，关乎生存，意义深远。能否成功周旋于以土地所有权为中心的人际关系网络，同样如此。许多事情，取决于教堂、修道院，如何在自身需求、权利，与其他要求间平衡：一方是周围平信徒团体，为其精神、经济支持奠基；另一方是较远世俗权力，试图<a id="pdf-357"></a><!-- PDF page 357; original page 328 -->为自身目的，规范修道、在俗教会。本期教会财产持有者，面对诸多挑战；本章主要关注这些挑战，以及应对策略。

### 资料问题

中世纪早期，少有教会机构，像蒙特卡西诺那样炫耀财产，但所有机构，都关心记录自己认为正当拥有的东西。不过，研究本期财产的困难之一，是权利主张常未写下。在远离地中海罗马书面文化的地区，“从记忆到文字”的进程，缓慢扎根；即使文字文化发达得多的世界，也仍有口头程序。个人、群体记忆的力量，依然强大。[^p357-3] 943年，一连串激烈交锋后，拜占庭阿索斯山修道团体，与平信徒邻人的边界，终于确定；过程重要部分，是沿边界行走，依当地人记忆、修士主张，以及帝国测量员安置的正式界标，达成边界应在何处的协议。许多土地争端文书中，口头证人，证明土地范围、现有和过去所有权，作用关键。[^p357-4]

不过，我们对中世纪早期教会地产的认识，大多仍来自文书，尤其记录取得、处置、保护的契据、特许状。契据一词，可涵盖产权文书，以及赠与、租佃、出售、争端解决的书面记录。但契据，从不是对土地采取行动本身的工具，而是关于已经完成之事的“程式化记录”、备忘。因此，契据代表当事人整个口头协商过程的终点，可能掩过相关财产的重大难题。它可在所记事件后数日，甚至数年才写成；有价值证人的签名、画押，提供法律支持，也常在以后多年，继续寻求。盎格鲁—撒克逊切尔西会议（816年），强调<a id="pdf-358"></a><!-- PDF page 358; original page 329 -->“以圣十字标记强化”的文书，不可侵犯。[^p358-5] 所以，契据及其他土地正式文书，虽仍是研究产权的主要资料，却必须视为人为制作的产物。契据汇编也一样，尤其恰称“叙事契据集”的作品，如修士约翰十二世纪《沃尔图尔诺编年史》，包含约200份涉及意大利中部沃尔图尔诺河畔圣文森佐修道院土地的文书版本。法尔法类似事业，是卡蒂诺的格列高利（1060年生）《法尔法编年史》，收录约3000份地产文书。[^p358-6]

保存、抄写，乃至伪造契据，所费的心力，证明其重要。许多契据、遗嘱、租约，被抄入珍藏的福音书。[^p358-7] 西方已知最早的契据集，是日耳曼洛尔施修道院九世纪汇编，抄入前世纪数百项财产交易。瑞士圣加仑修士，把文书存放在标有罗马数字的抽屉；阿索斯档案，则常装袋，保持相关财产的地理整体性。拜占庭文书，也如西方总括契据（pancartes），即“巨型契据”，罗列、概括财产、权利。十一世纪末，将军格列高利·帕库里亚诺斯，为保加利亚南部巴奇科沃的创院，制订《规章》，列出所有涉及拟捐土地的金玺诏书，即帝国特许状，并声明，副本不只应保存在本院，也应存于君士坦丁堡圣索菲亚，以策安全。[^p358-8]

建立、保存土地书面文书的目的，十分清楚。勃艮第《马尔西尼契据集》（1045—1144年）说，是为了“把我们现今所做，交付文字，使不守纪律的后人，不致侵犯前人所为”。[^p358-9] 财产，逐渐被视为可以永久拥有，<a id="pdf-359"></a><!-- PDF page 359; original page 330 -->保存的书面契据，或摘要，可作证明。公开口头仪式、见证典礼，对占有期限，不超过当事人最长记忆的情形，很有作用；书面文书，则把期限无限延伸至未来。此外，契据除有望保障安全占有，也赋予持有人转让土地的权利；这对他们，以及可能合法提出要求的他人，都是极重要问题。[^p359-10]

因此，契据证据，虽然常主要谈土地，而非所得财富，谈边界，而非资源，令人不尽满意，却仍是讨论中世纪早期教会地产的基础。没有契据，如中世纪早期爱尔兰，就极难确定基督教机构，如何建立、得到支持。[^p359-11] 不过，圣徒传作者，认真写明，甚至定位主人公创办的机构，为那些没有契据、存在往往短暂的机构，提供另一视角。例如，若非冗长、极详的《加勒西翁山圣拉撒路传》，这位圣人在小亚细亚西部，于十一世纪中叶建立、很快获得皇帝庇护及大量财产的一系列修道院，将完全不为人知。同样，只有十一世纪意大利游方圣人索拉的多米尼克（约951—1031年）的传记，才让我们知道，阿布鲁齐山区一系列小机构，全部未能长存。有些显然强大的修道院，我们却一无所知。列蒂附近大救世主修道院，可能匹敌强邻苏比亚科、法尔法，但缺乏文书，使其历史模糊。[^p359-12]

### 稳定与充足

本期土地取得、开发的地方戏剧，在暴力、战争背景下上演。事实上，欧洲许多地方，贵族行为普遍的暴力常态，在哪里结束、战争在哪里开始，常难分辨。八、九世纪维京袭击西北欧，波斯、穆斯林征服近东、<a id="pdf-360"></a><!-- PDF page 360; original page 331 -->小亚细亚，随后七至十一世纪穆斯林劫掠地中海、爱琴海，以及六至十世纪马扎尔人、斯拉夫人、保加尔人攻击巴尔干、中欧、意大利，使人几乎不断体验到，对生命、财产广泛、极端、陌生的恐惧。从不列颠到亚美尼亚，教会编年史，都讲恐怖、破坏、流血的故事。但实际损失的证据，常相矛盾；维京背景下，所谓“破坏性中断论述”，仍有热烈争论。[^p360-13] 据说，爱奥那院长布拉特马克，825年因拒绝透露圣科伦巴富丽陵墓所在，被维京人杀害；岛上却没有考古破坏证据，凯尔特十字架，也不像东罗斯塔尔巴特的皮克特遗址那样受损，仍然矗立。约克的阿尔昆（804年卒），可以写圣卡斯伯特教堂“洒满上帝司祭的鲜血”，林迪斯法恩修士，却保存著名福音书、圣卡斯伯特圣髑。事实上，他们定居达勒姆前，在英格兰东北似无方向的游荡，也许实际是巡行自身庄园。但沃尔图尔诺圣文森佐遗址——881年10月10日遭穆斯林洗劫——发掘，却显示不仅有肆意破坏，也有猛烈掠夺：大圣文森佐修道院教堂毁坏严重，直到十一世纪仍是废墟；地下教堂一层木炭、客人食堂受热内爆的玻璃碎片，都说明大火广泛。金属、珐琅、碎玻璃，也证明工坊及产品被劫。897年，听闻穆斯林即将进攻，法尔法修士，急忙把书籍、礼仪珍宝，分送罗马等地。维京攻击西法兰克、中法兰克最烈时，许多圣髑、珍贵书籍被转移安全地；后来未归还，却常因有权势的平信徒、教会利益方，想把它们代表的精神力量，留在新地点。[^p360-14]

财产损害有两方面：建筑及其装饰、陈设，或严重受损，或完全丧失。英格兰北部<a id="pdf-361"></a><!-- PDF page 361; original page 332 -->韦尔茅斯、贾罗、惠特比修道院，九世纪消失，直到诺曼征服以后，才重建。[^p361-15] 另一项长期可能严重的损害，是教士、修道团体流散，领土所有、控制受到威胁。圣文森佐修士逃往卡普阿，流亡33年。法兰克，圣旺德里耶、瑞米耶日修士，八世纪中叶逃走；“诺曼底”的利雪、巴约、埃夫勒，从九世纪后半叶至十世纪末，都没有主教。特里尔圣马克西明修士，882年为避维京，逃入城内，修道院、档案被毁。爱琴海方面，961年终于从穆斯林手中收复克里特，965年收复塞浦路斯。因此，从十世纪起，整个欧洲、近东，基督教修士、司祭的重要关切，是重建信仰，恢复教堂，修复物质损失，重新建立支撑机构的土地基础。幸运免于直接生命、财产威胁的人，也背负税赋，用以付钱打发劫掠者。853年，法兰克国王秃头查理（840—877年）命令评估教产，几乎肯定意在估量未来支付维京款项的分担。估计845至926年，付出40000磅白银，大部分由教会筹集。[^p361-16]

不过，负责献给教会的土地，无论主教、司祭、咏祷教士、修士、修女、隐修士，大多数困难，并非来自“异教徒”，而是同教基督徒。攻击使既有状况加剧，并未创造新状况。[^p361-17] 困难源于教会人士、平信徒共处的地理、社会、政治世界，也源于两群体活动，常无明确区别，尽管阶层区分正形成。[^p361-18] 最根本挑战之一，是确保有足够财产，支持获献的教会机构。西欧，教堂、修道院的区别，常模糊。伦巴德意大利小型洗礼教堂，由共同生活的教士服务，经常被称为monasteria，即修道院，或abbatia，<a id="pdf-362"></a><!-- PDF page 362; original page 333 -->即修院。爱尔兰主教，有时被称“院长”；布拉加的马丁（约520—580年），在西班牙的主教座，也设于修道院。就财产充足而言，关键是有关单位规模。大型修道团体，必须得到充分供养；在俗教会主教，也需要足够土地，以及产品、收入，支撑职责内的创堂、讲道、堂区管理。即使最卑微的乡村司祭，也须有足够财产，维护教堂建筑，养活自己，以及家人；后者在拜占庭确定如此，西方也常见。[^p362-19]

修道院创建时、以及日后，规模差别极大，可以极小。十世纪末拜占庭立法，设想到不足十位修士的修道院；九世纪阿索斯修道团体史，就是微小隐居所、独居者，从岩石环境勉强种出作物，维持贫乏生存的历史。这种边缘修道生活，也见于其他地理艰难之地，尤其意大利山区、凯尔特西方。[^p362-20] 这些人与少数追随者面对的，就是纯粹生存问题。另一些地方，问题是供给越来越多参加共同生活的人。极端例子，是阿索斯大劳拉，十世纪中叶，建于不宜居的土地；创办人圣亚他那修（约925—约1001年），竟设想容纳80位修士，后来又允许增加40位。但到1030年，该院似已有约700位；1102年文书，又提“修士大增”。1054年拉撒路去世时，他在加勒西翁山创建的各院，分别约12至40人。在完全不同农业背景中，奥托时期女修道院格尔布施泰特，985年创立，估计约1075年24人，十二世纪120人。一些加洛林修道院更大：赫拉班·毛鲁斯任院长（822—829年）时，富尔达及附属院，约住600修士。这些数字，很可能未包括平信徒仆役；十二世纪初，伊利约50修士的团体，可能应再加同数仆人。[^p362-21]

因此，财产是任何新修道机构生存、或主教区继续工作的必要前提。为促机构繁荣，地产须位于可提供食物，以及衣着、制造、建筑原料的地方。礼仪所需，也必须供应；照明用油、蜂蜡，以及弥撒用酒，至关重要。但若按字面追求独处，修道院地理位置，常极不方便。十世纪末、十一世纪，阿索斯修道院地产，越出圣山，扩向色雷斯、马其顿富饶农业平原，不可避免损害早期创办人理想；但这是因为，山地本身不丰产，不可能供养巨大人数。[^p363-22] “不便的地理”，也可能出自捐赠人无可指摘的动机。沃尔图尔诺圣文森佐原有领地，是贝内文托公爵吉苏尔夫一世（689—706年）、阿里希斯二世（758—760年），赠予沃尔图尔诺上游谷地约300平方公里、低产山区，很快不敷所需。但九世纪初，已积累卡普阿周边沿海、贝内文托附近、阿普利亚平原的庄园。这些地产，不仅生产有用农业盈余，也让修院获得盐、鱼，接触贝内文托与北非间发展中的贸易。[^p363-23]

英格兰，伊利岛周围不起眼的沼泽，原是修院七世纪创立时的土地核心。970年，埃塞尔沃尔德主教重建以后，到《末日审判书》（1086年）时，已补充六郡116村的自营地，即直接经营土地，以及约1200宗依附保有地。组织很妥善，满足修院需要。克努特王（1016—1035年）治下，院长莱奥夫西格，据说“为全年供应教会，指定食物贡纳（feorms）……为此选取……以格外丰饶、田野多产而闻名的村庄”。[^p363-24] 每个有关庄园，提供一周食物；伊利岛本身庄园，保留应付短缺。这一制度，很适合修道团体稳定、<a id="pdf-364"></a><!-- PDF page 364; original page 335 -->规律的需要。一些庄园，似专门畜牧：1086年，伊利岛多丁顿，有100多头牛、24匹母马；修道院自营庄园，另有2000头猪、9000只羊。此外，除食物贡纳，地产还缴实物租，盐、木材、蜂蜜，以及《末日审判书》调查官记下的95000条鳗鱼。[^p364-25] 许多超出自身需求，可在公开市场出售获利。

可持续的地产基础，对主教区同样重要。勒芒主教贝尔特拉姆616年遗嘱，显示其土地范围非凡：塞纳河谷、波尔多地区、桑通日、奥弗涅、洛林、勃艮第、普罗旺斯、比利牛斯，约300000公顷。规模可能很大程度上，源于克洛泰尔二世（583—629年）试图补偿主教区北方土地损失；但仍强调，主教可为极重要地主，重视生产资产多样化。[^p364-26] 更地方性的例子，是680年创建的英格兰伍斯特主教区。到《末日审判书》时，它拥有伍斯特郡约四分之一土地，在邻近格洛斯特、沃里克两郡，也有大量地产。680至880年，主要取得埃文、塞文河谷优质土壤地区；也在伍斯特郡北部、西部拥有林地，提供建筑材料、野味，以及利润丰厚的德罗伊特威奇盐场燃料。九、十世纪，又取得教区外、远至牛津、伦敦的财产。但广泛分散，也带来实际问题：需要大规模、适当的开发、保有安排、管理、运输设施，要求机构投入相当资金、关注、专门知识。[^p364-27]

那么，如何最好地分配产品，供给宗教团体需要？拜占庭《规章》，常规定教士、修士，以及其服务的穷人、朝圣者，食物、衣着配额；也安排礼仪开支，尤其圣器、照明。[^p364-28] 西方，<a id="pdf-365"></a><!-- PDF page 365; original page 336 -->院长、修士，或主教、主教座堂教士，如何分配资产，却引起大量冲突。主教财产，有时几乎按个人事务处置。圣威尔弗里德（709年卒）晚年，把北约克郡里彭主教座堂宝库，分为四份：一份给罗马圣母与圣保罗教堂，一份给穷人，一份给曾陪他流亡者，第四份给赫克瑟姆、里彭院长，“购买国王、主教的友谊”。[^p365-29] 服务主教座堂、大教堂的咏祷教士，常有个人俸禄，即教产的一部分，供个人生活；不能卖，却能传给别人。因此，欧坦主教座堂咏祷教士阿尔布因（1109年卒），可以在侄子、同为咏祷教士的法尔科同意下，把部分“自己的”财产，留给其他教士；法尔科将“依世袭法”，继承其俸禄。[^p365-30]

修道院情况更复杂。《圣本笃会规》，要求个人贫穷，巨大团体需求，却显然必须满足。《恳请书》（Supplex libellus，812—817年），是富尔达修士，向查理曼、虔诚者路易提交的一系列痛苦抱怨，控诉院长拉特格尔（802—817年）妄自尊大，痴迷建造“巨大、不必要”的新教堂；包括指责他削减衣食配给，把本应用于供养修士的地产，租给平信徒，为宏大工程换取现钱。穆瓦扬穆捷修士，通过王室巡察使——图勒主教弗罗塔里乌斯（813—837年），及默兹河一带圣米耶尔院长斯马拉格杜斯（约840年卒）——向查理曼申诉，称宁愿挨饿、被迫离院，也不再相信院长伊斯蒙杜斯，许诺提供足够地产供养的谎话。问题有时，通过契据出现专为修士“餐桌”（mensa）供给的条款解决，即指定地产，供养团体，而非院长。806年，赫雷里希赠地普吕姆，明确只供兄弟生活，声明每年自己的追念日，还应额外加餐。许多平信徒捐赠人，都像他一样规定：若院长侵占土地，就归还其继承人。其他修道院，则内部达成协议。伊利一份十一世纪末文书，说明流入修道院产品中，兄弟享用的份额，包括每年最少<a id="pdf-366"></a><!-- PDF page 366; original page 337 -->200头猪，指定庄园的黄油、奶酪，700夸特小麦、1000夸特麦芽，以及衣服费70镑。[^p366-31]

更广泛的问题，是什一税。这种对所有产品征十分之一的普遍税，最初为支持由司祭施洗、安葬的教堂而立，后来也为主教讲道、慈善提供资金。即使《赫斯塔尔敕令》（779年），在加洛林西方使其强制化，缴纳似也未统一。拜占庭没有这类义务，虽有向教会人士惯常缴实物（kaniskia）的某些证据。什一税，应由主教、持有应纳税土地的修道院、私属教堂主人，还是教产承租人征收、管理，始终未满意解决。但问题很重要，因为可能涉及财产利润很大部分。例如，十世纪托斯卡纳加尔法尼亚山谷，卢卡主教授出的约30村什一税，可能超过除最大庄园以外，所有地产的年租。[^p366-32]

因此，教会财富的起源、维持，根本是土地及其产品、收入。但总有人批评修道院似乎永不满足地取得土地，也有人担心，灵性生活与持有、管理教产，是否相容，或土地究竟怎样管理最佳。这些关切，都有实际含义。比德734年《致埃格伯特书》抱怨，本可用于设主教区、推动信仰宣讲的财富，被赠给修道院。十世纪拜占庭，皇帝尼基弗鲁斯二世·福卡斯（963—969年），批评修道院积累无法有效耕作的土地。英格兰十世纪“改革者”，反复反感修道院、主教座堂个人俸禄的“腐败”，希望强制共有财产规范。遵循本笃会规的修道院，对允许院长、兄弟直接参与地产管理感到不安，因此设立大量<a id="pdf-367"></a><!-- PDF page 367; original page 338 -->租约。例如，到1066年，格拉斯顿伯里修道院半数以上土地，已租佃出去；诺曼征服后，盎格鲁—撒克逊承租人被取代，导致大量地产损失。[^p367-33]

### 所有权与保有权

不过，教堂、修道院的土地，并非存在于某种平行宇宙。大部分某时曾属平信徒，全部仍以复杂方式，与未献给上帝服务的周边财产交织。最难处理的问题之一，是捐地者虽常为个人，却不孤立；人人有家庭，非罗马世界，又有更广亲族，因此赠与，影响广泛。拜占庭，个人赠予、遗赠私产的权利，以及以纵向继承为主、规定继承份额的规则，早由罗马法确立。日耳曼西方大部的习惯法，则更重远为广泛的横向群体权利。拜占庭教会法，有世俗立法全力支持，强调继承人有义务，完成已故创办人开始的教堂、修道院，甚至须出租、出售自身财产，以完成工程。没有任何规定，让他们能挑战捐赠人意图，即使后者没留遗嘱。[^p367-34] 这种相对简单，与萨利安王朝德意志，形成鲜明对比。施瓦本茨维法尔滕修道院，复杂的创建史，是一项有益警示。1089年前某时，库诺、柳托尔德伯爵，活得比所有兄弟都久，决定创院。库诺有三个非婚生儿子，不能继承；柳托尔德无子。他们给予补偿，取得姊妹维特贝尔格之子的同意。1092年，柳托尔德仍在，却被众多针对捐地的要求包围：另一姊妹玛蒂尔达的两个儿子，另外五位已故兄弟的儿子，以及另两位兄弟亲属；后两人，经祖母提出要求，祖母与柳托尔德、库诺之父鲁道夫伯爵有亲。因此，<a id="pdf-368"></a><!-- PDF page 368; original page 339 -->针对这所修道院财产的权利触角，跨越数代，沿父系、母系亲属，向前后延伸。[^p368-35]

这类要求，可能严重损害教会。989年，明斯特教区博尔格霍斯特修女，在奥托三世法庭败诉：创办人贝尔塔与前夫所生女儿贝尔特海达，称继承权遭剥夺。稍后，约1035年，勃艮第公爵罗贝尔一世，把沃韦财产“赠”第戎圣贝尼涅修道院；约30年前，勃艮第伯爵奥托—威廉，早已把它赠该院，但罗贝尔声称，自己从叔祖、奥托—威廉继父勃艮第的亨利继承，因此现在才是正当处置。克吕尼最初200年文书，显示相同财产，似不止一次获赠；连同大量弃权文书，即正式放弃土地要求，必定反映一个常很漫长的过程：不满亲族，试图推翻家人赠与，或设法把赠地、放弃土地要求的功劳，归于自己。事实上，十一世纪，法国西部向教会赠地，常援引“亲属认可”（laudatio parentum），防止后来争讼（calumniae）。[^p368-36]

因此，家庭、亲族，常难接受赠教会土地，可能永远丧失。克吕尼、戈尔兹契据中，大量土地以请求授益形式（precaria），给予受领人终身，有时及其子女，用益或简单使用，只收象征租金，说明修士很清楚此点。许多土地，曾属受领人亲属，因此不仅让家族继续控制，也以缓和最终赠与的不快，巩固修道院、平信徒邻人的友谊、联盟。有些教会舆论，虽猛烈批评precaria——查理·马特（741年卒）因此遭谴责，也许并不公正；圣旺德里耶院长特奥特辛德（约840年），因如此授出三分之一院产遭攻击——原因也许更多是受赠者，不被视为修院“朋友”，而非<a id="pdf-369"></a><!-- PDF page 369; original page 340 -->授益本身必然有害。[^p369-37] 拜占庭，平信徒“保护者”（charistikarioi）参与修道地产管理，十一世纪遭安提阿牧首约翰激烈攻击；但某些证据显示，对许多修道院，这是有益安排。[^p369-38]

不过，拜占庭、西方许多教堂、修道院，实际上仍是创办人财产，后者按自己认为适合的方式安排。窥见加尔法尼亚“小世界”，可说明“私属教堂”的含义、问题。八份坎波里圣马利亚教堂契据，涵盖761年教士、后为司祭的贡杜阿尔多与兄弟创立，至约850年。776年，他已向教堂佃户签租约；780年，把教堂、大部私产赠卢卡主教，却与两位侄子，保留土地用益，每年租一索里都斯。机构后来转入侄子们手中。同时，家族兴旺；到850年，坎波里20多所房屋，约三分之二，属于贡杜阿尔多家族、或其教堂。家族最后见于848—849年契据：拉基普兰多、安德烈亚·迪·贡迪，非法占据另一亲属拉奇斯赠教堂的土地，称属于自身继承份额。几周后，两人与堂亲，把所有财产卖给主教；849年，又连同拉奇斯赠地一半，租回自己。因此，经过一系列要求、妥协，很难说贡迪家族，仍如创立时那样“拥有”坎波里圣马利亚。但创院给予家族相当声望，他们仍在其命运中保有权益；从未施加破坏性控制，也似接受按教会法，归主教控制。[^p369-39]

再看奥托国家大型私属修道院（Eigenklöster，原文释为私属教堂），呈现不同视角。问题有二：第一，很难说其地位，如何符合所有宗教机构，都应由教区主教监督的会议教导；第二，<a id="pdf-370"></a><!-- PDF page 370; original page 341 -->面对强大所有者的要求，修道院处境困难。最极端者，是君主创建的机构。私人、王室创院，当然遍及西方乃至拜占庭，但奥托德意志比例极高，处境兼有利弊。王室修道院，可享自选院长权，但须王室批准；据说不得被转让，且享王室保护，因此完全免于主教监督、控制。[^p370-40]

王室庇护，对这些受宠修道院、教座的地产捐赠，影响巨大。936年，在萨克森亨利一世国王墓地创建的奎德林堡女修道院，很快获赠聚落及周边土地；奎德林堡及另13个列名地点，全部农产品、收入的九分之一；另五处全部产品；两所王室猎场猎物的十分之一；设市场、铸币厂、通行税站的权利；以及莱茵地区英格尔海姆王庄，每年十车酒、40大蒲式耳蜂蜜。968年升为总主教区以前，马格德堡圣莫里斯修道院，从奥托一世（936—973年），取得40多份契据，广泛获赐销售、税赋十分之一，尤其新征服的斯拉夫、波希米亚地区，另有牧场、森林权。[^p370-41]

但王恩代价高昂。王室服务（servitium regis），不只为国王祈祷、院长主教出席宫廷、提供外交代理人，也须为巡行君主及宫廷，提供大量食物、物资，以及军队士兵。威斯特法伦韦尔登修道院土地簿显示，全年王室接待所需：八头牛、43头猪、十头小猪、30头乳猪、195只鸡、95块奶酪、870枚蛋、面包、燕麦、172罐啤酒，以及碗、饮器。《铠甲骑兵清单》（Indiculus loricatorum），是皇帝奥托二世（973—983年）在意大利南部科特罗内战败后，981／982年颁布的动员令，征集2000名武装骑兵，四分之三，由主教、院长提供；特里尔总主教，须出70人，<a id="pdf-371"></a><!-- PDF page 371; original page 342 -->赖歇瑙院长60人。科尔韦、马格德堡等院，虽享Burgbann，即强制当地依附农民修防御工事、取得司法收益的权利，也须驻守暴露的王室防线。997年，马格德堡总主教吉塞尔赫尔，亲自领导阿尔讷堡驻军一个月。[^p371-42]

当然，王室食物租，以及为军队提供士兵、物资，并非别处未知。盎格鲁—撒克逊英格兰等其他巡行国王，肯定以接待为宗教机构应尽义务。拜占庭皇帝罗曼努斯一世·莱卡佩努斯（920—944年）治下，一份财政文书，涉及从伯罗奔尼撒修道院，为军队征马；拜占庭修院，也极热衷取得免供草料、食物及帝国军队住宿的特权。早在1072年，伊利已为国王提供40名骑士；但奥托例子显示，要求极端时，会发生什么。744年埃斯廷会议所定，教堂、修道院，只应拥有“必要”土地的原则，无法维持。奥托帝国王室修道院、主教区，为履行对统治者义务，需要的财产，远超基本生存。[^p371-43]

### 财产与政治

王室要求，最终来自一种信念：统治者有义务，为人民利益，保护教会及其机构；教会人士，就有回报义务，促进王国福祉。互惠观念，一路渗透社会。没有不求回赠的赠与，土地也一样。此外，若世俗世界需求，要求转让、授出王室财产，即使由私属教堂、修道院持有，也不能免于没收。[^p371-44]

然而，东西方教会舆论，不只视一切献地神圣不可侵犯，也认为谁可进入、取益，应受严格控制。

教产性质、及其合法用途的内在悖论，有助解释许多君主，尤其法兰克国王，看似矛盾的行为。欧塞尔主教艾恩马尔，虽支持查理·马特732年阿基坦战役，查理仍没收其土地，分给追随者；他又赐侄子于格，巨量教产。继任者卡洛曼，在埃斯廷会议宣告，“因战争、他族进攻”，无法全部归还教产。虔诚者路易、秃头查理，都热心改革教会，却没收教产，赏赐追随者。相隔半个世界，十一世纪自称“第十三使徒”的皇帝阿莱克修斯一世·科穆宁（1081—1119年），命令熔化教会珍宝，资助在巴尔干抗击诺曼人的防御战，在教内激起风波。[^p372-45] 国王、世俗贵族，需要财产、产品、收入，表达、增强权力声望，赏赐忠实追随者，以及在紧急时动用。教产，从未免于此类用途。他们在主教团的亲属，也仿效；这些人不只控制教区在俗司祭及其土地，也强调对修道院管辖权，表达自身权力。

不过，教产容易受攻击、蚕食、没收，使院长、主教极为忧虑。[^p372-46] 除最坚决掠夺者外，最成功防御，是建立家族、友谊纽带，让教堂、修道院不孤立。可在教会环境，复制家庭关系：如加洛林两位欣克马尔，兰斯、拉昂主教，彼此近亲。伊维龙创立最初40多年，院长（hegoumenoi）也互有亲缘，沿袭其格鲁吉亚故乡，早已建立的家族修道模式。精神关系、基于友谊的联系，也重要，拜占庭尤其如此。克吕尼，那些<a id="pdf-373"></a><!-- PDF page 373; original page 344 -->赠地、或与之形成土地保有关系的人，被引导觉得，圣彼得本人，已成为邻居。[^p373-47]

不过，要保护教堂与修道院，使之免受那些攫取管辖权、赋税、资源、人力或土地的平信徒及教会人士侵扰，还有一种更为持久的办法：取得豁免或免役特许状。这类文书通常由君主、有时由教宗授予，旨在机构周围创造一片“清净空间”，禁止敌对者进入其地产；更常见的情况则是仅禁止王室或主教的代理人进入。相关赋税与义务也常被“回收”，交还财产持有人。豁免与免役有时确实遭到无视，尤其是持有教宗特许状的机构离罗马很远的时候；但它们在本时期如此普遍，必定说明具有实际用途。[^p373-48] 这里再次显示出书面文字对于确立教会权利的重要性。个别教堂与修道院借助这些文书，努力确立不可侵犯而持久的地域权利，使关于教产地位的一般原则获得具体的地理形式。在这一过程中，一项原则缓慢形成：平信徒虽然始终通过灵性、敬拜、家庭、友谊及土地保有的纽带与教会相联，却不能再做教会的所有者，而须把自己视为保护人。

因此，教堂、修道院，取得、保护生存必需财产的策略，常使其与周围平信徒团体、较远世俗权力，妥协、适应。但到1100年，另一长期道德问题，再次突出。独处、隐修生活，始终是东西方修道遗产的一部分。拜占庭，隐修士缓慢被纳入修道结构；十一世纪西方，以意大利、法国南部为中心的新隐修运动，却重新迫切追问：真正灵性，与持有财产，是否相容？贫穷，而非财产，成为教会新的集结号。[^p373-49]
