# 第八章　基督教教育

**多米尼克·朱利亚（Dominique Julia）**

## 识字、阅读与信仰

新教宗教改革及随后的天主教改革，一个根本特征，是坚持：不能说明自身信仰的人，就不能自称基督徒。因此，路德把要理问答视为“每个基督徒都绝对必须知道的东西；不懂的人，不应被视为基督徒，也不能领受任何圣礼”。[^p162-1] 新教与天主教，都在宗教和教学之间建立强烈联系，贯穿整个近代早期。要理问答以独特问答形式，表达信仰必需的教义真理，包括十诫、信经和主要祈祷文，被视为基本著作，编排便于儿童记忆。路德甚至要求，把它写在牌板（Tafeln）上，悬挂于教堂、学校和家中。引用福音书及保罗书信的《家规表》（Haustafel），规定基督徒对教会当局、君主、父亲或家长，以及妻子对丈夫的社会义务。随着时间发展，这种强制宗教教育，推动书写，更重要的是阅读技能，尽管各地区、各国学习方式不同。有些地方，基督教真理学习严格以教会为中心，完全口传，只在星期日要理课记忆，不通过书籍或学校。例如，天主教法国不懂法语的地区，儿童用地方语言或方言学习，或者读印行译本，或者由教士根据主教认可的官方文本口译。1640至1660年，出现许多奥克语译本，也有巴斯克语、布列塔尼语和弗拉芒语要理问答。达克斯主教1752年指出：“<a id="pdf-163"></a><!-- PDF page 163; original page 148 -->牧者和教师讲授要理，从不为教语言，而为使宗教得到理解与记忆；这只能、也应当用民众自己听说的语言进行。”[^p163-2]

路德宗瑞典在教堂或家庭学习基督教真理；信徒皆祭司的逻辑，使家庭成为教学机构。1686年教会法规定，每个人都应能阅读、理解《圣经》，甚至儿童、农业工人和仆役，也应亲眼看见圣经中上帝的诫命。从十七世纪六十年代至十九世纪初，庞大识字运动以家庭训规牌（原书作Hustlava），提醒基督徒职责义务的墙上牌示，以及《诗篇集》为基础。1695至1819年，后者不少于二百五十版，发行超过一百五十万册。这一大规模运动只教阅读，不在学校，而在家中。领圣餐前的考核中，各路德宗牧区的牧师，经常检查阅读能力和要理知识。从最早存世记录，可得三项结论。第一，瑞典约1660年会阅读者占人口百分之四十，约1690年升至百分之七十，1750年后达百分之八十至九十。第二，早在十七世纪八十年代，便确立先学阅读、再记要理的次序，人们因此从书中学习信仰。最后，同期最年轻年龄组男女儿童的阅读差距，大体消失。[^p163-3]

瑞典事例虽特殊，资料却充分，促使我们思考横贯欧洲、不能用宗派差异解释的文化边界。过去三十年欧洲各地研究，记录西北欧，包括英格兰、低地、莱茵地区及法国东北的识字进步。显然，所得比例不精确，因为资料未必可比，也可能掩盖区域内部城乡、男女及职业差距。乡村中，篱垣田野地区，分割、隔绝、主要交通路线较少，与谷物平原差异明显；平原更易遭军事入侵，也更容易传播文字。不过，整体而言，西北欧<a id="pdf-164"></a><!-- PDF page 164; original page 149 -->经济较先进、人口更密、城市化更高，这些因素决定性地促进识字。虽然区域内部差距持续，反映教育机构脆弱，以及某些地区文字使用仍新，到十八世纪末，总体男性识字率已超过百分之七十，许多城镇更高。整个欧洲，地区格局实际勾画古老文化边界，例如圣马洛至日内瓦一线，分开较先进的法国北部、东北部，与识字少得多的西部、南部；施特拉尔松德至德累斯顿一线，则区分德意志东西。即使在识字少得多的南欧，意大利北部利古里亚、皮埃蒙特和伦巴第，也与大体不识字的中南部形成对照。

实际上，识字率不均来自经济、社会与文化因素的复杂结合。近期所有研究都强调，不能把进步或落后归于单一原因。除财产所有权，大地产地区如东普鲁士、波美拉尼亚和意大利南部文盲更多，以及城市一般领先乡村，那不勒斯王国却非如此，之外，还需强调三点。第一，语言多样性可能妨碍教育政策成功。普鲁士非德语人口，尤其波兰语人口最集中地区，也最抵制德语教学；苏格兰盖尔语区，十七、十八世纪读写率最低。法国南部通常只说、只懂奥克语，几乎无人会读写；人们通过神父、教士教师或传教士等中介，使用印本或手稿，背诵要理、圣歌和圣诞颂歌。一般只有精英学法语，把掌握法语视为文化融入的主要手段。但还需指出，法国南部加尔文宗与天主教差别显著。天主教圣统制选择口传牧灵，用集体歌唱和记忆，以民众本族语接触他们，礼仪语言本身却仍不为民众所懂。胡格诺派则选择法语，作为读经和吟唱诗篇的神圣语言。因此，撤销《南特敕令》以后，多菲内及<a id="pdf-165"></a><!-- PDF page 165; original page 150 -->塞文出现的男女“先知”用法语表达，就不足为奇；仿佛对这些受感动却不识字的人，只有这种语言能带有神介入的标志。

第二个现象也值得注意。比较天主教与新教社群识字率，并不必然得出新教一直进步更快的结论。诚然，英格兰清教徒相信上帝积极临在日常生活，加强其灵性自省与自律，激发十七世纪写自传和日记的愿望。贵格会也相信个人完善通过日常自律逐渐实现，到十八世纪下半叶，所有人都能在婚姻登记签名；英格兰其余人口，五分之二男子和三分之二女子却不能。德意志北部路德宗奥尔登堡沿海堂区，所有男女会阅读，百分之七十男子、略低于百分之五十女子会写字。这种异常高比例，既来自各社群大量建校，也来自路德宗牧师严格监督，经常家访，检查阅读能力。这里，教会政策与学校要求，造成近乎全民识字。[^p165-4] 然而，史家也许太快认定，改革宗城镇整体优于天主教城镇。差别未必单由宗教造成；在解释识字史的复杂因素中，难以分离某种信仰的优势，差异可能更多来自社会经济，而非宗教。十七世纪英格兰某些时候，清教信息反而在识字较少的城市环境更受欢迎。莱茵中部天主教科布伦茨，十八世纪末，百分之八十六男子和百分之六十女子在婚姻登记签名。性别差别似主要因低层乡村妇女入城当女仆。高比例来自极密小学设施，每堂区一校，人口多而分散者有数校，以及七至十一岁儿童近乎普遍入学；十八世纪末特里尔选侯敕令要求如此。科布伦茨数据，很可能适用于同期整个天主教莱茵地区，因为科隆、波恩和美因茨同年入学率类似。路德宗自由城市<a id="pdf-166"></a><!-- PDF page 166; original page 151 -->施派尔1771至1795年的识字比例，估计男性百分之九十五、女性百分之六十八，仅稍高于科布伦茨。[^p166-5] 无论如何，这些数字要求重新审视天主教国家教育落后的旧观念。在德意志这一地区，宗派紧邻且竞争，可能共同促进新教和天主教识字。宗教边界迫使双方参照彼此界定自身，持续分化又相互依赖，结果反而彼此模仿。

最后，地方政治制度也可能影响识字。史家都强调，十八世纪某些山区“共和国”在推动识字方面的作用。亲族与联盟网络结合，维持代代更新、连续的短期和永久迁移链条，迁移者包括识字教士、教师与流动印刷品商贩。在法国阿尔卑斯的新教凯拉、天主教布里昂松地区，或奥属伦巴第科莫湖周边山谷，都发现异常高的男性识字率，可达百分之八十。解释这一现象，不仅要考虑当地经济，小块土地、工匠众多且经常外迁，以及教学方式密集，村落学校与家庭非正式学习，也要考虑社群会议集体治理的重要性；会议自主管理法律、经济和财政问题。这种特殊人际环境，至少可能激发男孩在正式学校之外学习、自学的愿望。瑞士纳沙泰尔州有类似条件：村庄直接民主，以地方政治权力、经济平等和自由劳动条件为基础，促进正规教育，以及家庭、职业内部自学。[^p166-6] 这片新教土地由纪尧姆·法雷尔引入加尔文宗，十六或十七岁首次领圣餐前的考试，既是学校教育结束，也是进入成人生活的仪式。考试在教堂举行，面对社群及其民选代表。受评价的不仅是牧师教学，也是整代人的教义真理知识；这些真理不仅在教会、学校，也同样在家庭阅读、记忆、理解，并融入个人与集体价值体系。

## 初等学校教育

无法详述近代早期学校发展的一切细节。学校在章程、资金、教师及就读形式方面差异极大：资金来自圣俸、社群捐款、个人家庭或宗教遗赠；教师可能是平信徒、教士或修会成员；入学可能由国家强制，也可能不强制；可能男女同校，也可能分校。应注意，即使十八世纪卡斯蒂利亚等识字较少地区，学校读物出版数量也惊人。巴利亚多利德座堂教士团出版的识字课本（cartillas），含主要基督教祈祷文，十八世纪下半叶每年印三十至四十万册。1740至1761年，马德里书商善会出版赫罗尼莫·德罗萨莱斯《基督徒卡托》超过五十万册，这既是宗教读本，也是识字课本。它们大概以多种方式，用于学校、家庭与要理课。[^p167-7] 尽管相当部分运往美洲，无疑，无论何处使用，都有助于达到最低限度识字。

关于学校运作，可提出三点。第一，不应忽视政治、市政及教会当局，普遍决意塑造基督徒生活规范、消灭乞讨与流浪，两者密切相连。十七世纪普遍建立济贫工场、总收容院或劳动惩戒所，意在把穷人移出一般社会，让他们工作，因为懒惰被视为恶习之母。这不只是经济需要，也是在机构围墙内建立道德秩序：劳动义务，加上忏悔与情绪控制，会为穷人提供得救途径。但教育也包括在内，教师给机构“收养”的儿童基本学校教育与宗教基础，工匠师傅教实际技能。此外，禁闭约束流浪者，同时伴随强烈的普遍济贫教育努力。同样虔诚的贵族、法官、官员和商人圈子，同时支持工场“禁闭”与免费慈善学校。天主教法国，十七世纪下半叶，圣体会、耶稣会创设的圣母会，以及<a id="pdf-168"></a><!-- PDF page 168; original page 153 -->相关詹森主义团体的影响，加强这些倾向。最著名的是让—巴蒂斯特·拉萨尔所创基督学校修士会的学校。德意志北部的慈善学校和孤儿院，也追求类似目标。路德宗敬虔派作用重要，尤其受奥古斯特·赫尔曼·弗兰克创设的哈勒孤儿院影响。该院有自己的印刷所，广泛发行低价宗教文本，1720至1735年，印行不少于三十九版《新约》，以及约二十三版小开本家庭《圣经》。

新教与天主教欧洲在规训、教育孤儿和穷人子女的运动中，当然有差别。路德宗敬虔派强调《圣经》、诵诗篇、直接接触经文，以《圣经》教阅读；家庭强化这些要素，必然加强宗派认同。但也能列出两方教育活动的许多相似。所有机构，都旨在让学生养成基督徒生活规范，热爱真理、服从、勤奋工作，并掌握更“实际”的知识。学生日益增加，教学机构以近代早期权力结构的典型方式回应，通过奖惩，按能力、表现及量化“等级”区分个人。检查控制学习的重复作业，也融入相互及等级监督体系。教学近似分析科学，拆分时间空间，使教师不受阻碍地关注微观细节，立即发现不守规则者。高度仪式化的时间表，以固定讲授、练习和祈祷划分一天，排除混乱。为加强教师对儿童的权威，又设相似仪式化奖惩。学校隔绝外界和城市喧闹，内部划出特定课堂区域，实行严格学习程序，每个学生有指定位置。同一级每个儿童教材相同，期末考试或持续评估，明确显示能否升学。现代教学法由此出现，来自对城市不同阶层、构成“民众”的散漫学生群体，强加秩序与一致的需要。1790年法国，基督学校修士会学校为三万五千名学生提供教育，分布<a id="pdf-169"></a><!-- PDF page 169; original page 154 -->在其设校的一百零八个城镇，平均占七至十四岁男孩四分之一；人口少于一万的城镇，更高达百分之四十。显然，修士会教学方法的影响，远超机构本身。

第二点，是小学教师职业专业化。近代早期初期，教师训练仍以家族世袭为主，儿子向父亲学课堂基本职能与任务，然后继任。但十七世纪末，新教和天主教都开始关注专业师资训练。敬虔派又发挥开创作用。弗兰克在哈勒设多种师资训练所，其中1717年创立的预备教师训练所，旨在为哈勒各校培养未来小学教师。其影响超出哈勒：牧师克里斯托夫·申迈尔和约翰·尤利乌斯·赫克尔，分别在斯德丁（1732—1737）和柏林（1748），努力建立同类“师范所”。后者1753年获认可，为“王室选侯领地乡村司事与教师师范所”，既收寄宿生，也收贫穷工匠，在日常工作之外上几周或几个月职业课程。但这些举措仍较私人、地方化，紧随创设机构的具体需要，影响和成效有限。[^p169-8] 天主教方面，拉萨尔为基督学校修士会创设的小学教师非圣职机构，相较修会有两个创新：修士禁止学拉丁文，也禁止进入教士阶层。双重禁令保留较“平民”的来源，避免转向精英中等教育，十八世纪末某些修会如虔修会，就出现这种转向。修士从学校最佳学生中招募，要求“聪明、性情虔诚，且被认为准备好时，自己也愿进入团体”。这些出身普通的教师，是教会当局与需要受教、受造就平信徒的中介，必须有明显区别于一般民众的生活方式。《礼仪与基督徒生活规范》，旨在使这些被形容为“全是平信徒、未受教育、智力至多中等”的修士，养成随后传给学生的社会行为：基督教道德和其职位所要求的“端庄”，以及控制<a id="pdf-170"></a><!-- PDF page 170; original page 155 -->情绪与激情，施罚时不愤怒、不急躁，只以“纯正、仁爱、公正、适当、温和、不具攻击性且审慎”的方式进行。[^p170-9] 供教师使用的手册，如1720年《基督教学校管理》，细节如此丰富，以至修士无需思考某种情况应做什么、如何做；技能只在执行规则。

第三点，是开明政府普遍改革教育的运动。虽然不如军队、财政、司法等传统国家领域现代化受重视，十八世纪下半叶，德意志各邦、奥地利和意大利半岛，显然有越来越多法律，试图把整个教育系统置于国家控制；其理由是儿童应属于国家。改革核心，是设师资训练学校，即师范学校（Normalschulen），由萨冈奥思定律修教士团长依纳爵·冯费尔比格倡议。费尔比格直接受柏林牧师赫克尔启发，1765年应普鲁士总督要求，提出西里西亚小学规则。早在1764至1765年，布雷斯劳就建立培训教师的“示范”学校；但其计划尤其在奥地利发展。1774年12月6日总学校敕令，要求各省设一所师范学校，作为其他学校典范，并确保天主教学校师资培训。[^p170-10] 两三个月的课程，每周十一小时“理论”，包括宗教，即要理、《圣经》与基督徒伦理，以及阅读、书写和算术。但最重要的是教学实习：未来教师在师范学校或邻近机构，学习费尔比格方法。改革成功，在于这些学校迅速建立，不仅在奥地利各省、哈布斯堡王冠下斯拉夫与匈牙利领地，也在奥属尼德兰与伦巴第；十八世纪最后数十年，培养大量新教师。[^p170-11] 模式显然也超越哈布斯堡边界，在巴伐利亚、美因茨、科隆和特里尔选侯国，以及艾希施泰特、施派尔主教领地，都能见其要素。在所有这些地方，通晓天主教启蒙思想的教士指导师范学校，使其发挥文化先锋作用。

## 中等与大学教育

转向中等学校和拉丁文教学，天主教、路德宗、加尔文宗与圣公会机构的相似，显著超过差别。1650年，它们共享类似人文主义遗产：从菲利普·梅兰希通的学校与教会条例，到让·施图尔姆的斯特拉斯堡示范文理中学，以及加尔文的日内瓦学校和慈运理的苏黎世学校；所有这些，又借鉴十五世纪末共同生活弟兄会确立的方法。此外，耶稣会1599年《教学规程》，深受十六世纪初巴黎大学“巴黎方式”（modus parisiensis）影响。宗派边界两侧，皆有同样依次分班、讲授与练习，包括问答、辩论、散文仿作；都以古典修辞，以及“正直与德行”理想，作为培育基督徒基础；都分较小组，维持秩序、避免班级过挤；都以作文、奖项和公开背诵的竞争，丰富学校生活。所学文本及次序也相同，尤其西塞罗《书信集》，作为拉丁作文范例，以及维吉尔和贺拉斯。不过，天主教可能更严格排除被认为淫荡或猥亵的古典作者。路德宗学校视泰伦提乌斯为最有用的拉丁会话作者之一，耶稣会通常完全禁止。新教学校无疑更常教希腊文；希腊文《新约》是最常读文本之一，仅次于伊索克拉底《演说集》。当然，两侧教材不完全相同，但必须考虑学校读物市场兴起，有专门作者、书商和印刷者。路德宗与加尔文宗国家，荷兰学者格哈德·约翰内斯·沃西乌斯十七世纪初所写的希腊文、拉丁文语法，广传荷兰、德意志北部及法国加尔文宗学院。耶稣会则忠于曼努埃尔·阿尔瓦雷斯神父的语法，常译为本地语言，或由耶稣会士修订的德斯波泰尔旧手册。不过，教材明显趋向标准化，或为简明清楚，或因某教学修会偏好。天主教与新教学校的重大区别，首先体现在<a id="pdf-172"></a><!-- PDF page 172; original page 157 -->宗教教导问题上。

拉丁学校、学院和文理中学的发展，都根本联系领邦教会与现代国家成长。三十年战争破坏以后，德意志新教诸侯希望复兴基督教教学，以恢复宗教秩序、保障社会政治稳定。教育臣民也成为优先事项，为国家和教会提供所需行政人力。拉丁学校尤其在领邦教会推动与权威下恢复，地方或中央宗教事务委员会负责组织治理。但依据基督教君主权观念，诸侯也可能命令全面巡学，例如1642年萨克森—哥达，或1648年以后不伦瑞克。监督增强及巡查报告，使我们看到宗教学习的根本重要。这些学校积极参与地方教会生活，大量时间用于圣歌，尤其吟唱诗篇。校内第二重要职位通常是领唱，既在教会礼拜指挥合唱，也主持葬礼歌唱，学生护送并庄严陪伴从死者住宅到墓地的行列。除了主日与节庆，学生每周到教堂两三次，歌唱、祈祷、听讲道；每年领圣餐四次，此前在校长面前为罪求赦，校长劝他们改正生活。新教拉丁学校与天主教差别，较少在用本地语背要理，耶稣会学校也背彼得·卡尼修斯的小要理，而更多在阅读经文：低龄读《箴言》或《传道书》，年长者读福音书或《旧约》章节。学生背诵摘录，抄入专门习字本。塞巴斯蒂安·卡斯特利奥以圣经对话训练儿童语言与道德的四卷著作等，也补充其圣经教育。

宗教同样深入天主教学校。要理教义解释，与礼仪年所庆祝奥迹的解释交替；耶稣会低年级用本地语，后来用拉丁文授课。不可避免，强调<a id="pdf-173"></a><!-- PDF page 173; original page 158 -->天主教会权威和教皇至尊权，背诵重要，公开辩论磨炼竞争意识。这种宗教教育不允许直接接触《圣经》，除星期日讲道所给注释。但礼拜堂和学校走廊挂图画版画，激发想象，主题常强调新教拒绝的教义与场景：圣体奇迹、见证善功必要的圣徒殉道者，或圣母战胜异端。重要庆日上演以《旧约》、殉道者或耶稣会圣人故事为题的戏剧，提供可效法的视觉与口头教学范例。灵修读物和祈祷书，许多出自耶稣会士，用于加强虔敬，鼓励按信仰行为。神父也指导学生灵修，圣母善会给许多寄宿生额外神操与慈善启蒙。学生受鼓励经常领圣事，每月告解、每周领圣体。经常朝拜圣体、狂欢节四十小时朝拜，以及基督圣体节盛大城市游行，进一步加强圣体重心。耶稣会也鼓励敬礼圣髑，尤其从地下墓窟转移圣人遗骨时，举行壮观仪式。总之，新教较朴素克制的敬拜，对应于耶稣会激发的凯旋精神。

除宗教礼拜形式差别，另有跨越宗派边界的区别。各地教学机构都有等级，大致对应所在城镇的行政、经济和人口重要性。实际上，学校网络1650年前已大体建成，随后主要靠扩展高年级教学加强，提供大学层次课程，却无权授大学文凭。一些拉丁学校因此变成高级文理学校（gymnasia illustria）。对新学校的社会需求，主要来自小城精英，他们希望孩子先在家附近就学，再送大机构。财政有限，小城只能支付一至三名教师。中等学校，无论英格兰文法学校、德意志拉丁学校，或法、西、意<a id="pdf-174"></a><!-- PDF page 174; original page 159 -->各地学院，质量不可避免差异很大，同样班级名称可能掩盖完全不同水平。法国各省学生转巴黎学院，常被要求重读，甚至降级。天主教国家，教学修会或教区教士团体的教学规程，有时通过标准化调节水平差异。整个十七世纪，城镇既为教师招募，也为财务原因，经常请修会、团体管理学校。但不同团体学校间，始终有质量差异。耶稣会设校策略优先政治首都、主要大学及经济中心，公开目标是通过精英，夺回被异端毒害的地区。其财务要求，也一般排除小城设校，除非特殊条件。借政治当局协助，耶稣会常能建立围绕本会大学的中学网络，例如西属尼德兰杜埃的昂尚大学学院。但有时遭到世俗大学团体猛烈抵抗，例如巴黎，它们好不容易才维持自己的中等学校。耶稣会几乎完全主导西普鲁士领地天主教部分、上巴伐利亚、奥地利和帝国西北的拉丁教学；后者包括南尼德兰、列日亲王国、科隆总主教区和威斯特伐利亚。但十七世纪，其他修会也开始承担较普通学校，尤其奥思定会、静修方济各会与小兄弟会。[^p174-12] 法国同期，祈祷会与教义会各接管二十多所学院，多在人口不足一万城镇，或因耶稣会拒绝邀请，或因市议员反对一个特别宣誓服从教皇的修会到来，如强烈高卢主义的特鲁瓦。意大利半岛，巴尔纳伯会、虔修会和索马斯卡会到来，逐步加强中学网络；它们常同意进入较普通城镇，尽管中央当局不愿批准小学校。有时，加尔默罗会、道明会，以及新近的欧德会、圣若瑟传教会和瓦朗斯圣体司铎等，扩大学校修会范围，尤其在十七世纪末以后，当<a id="pdf-175"></a><!-- PDF page 175; original page 160 -->小城越来越难以吸引主要教学团体。有些地方，如布列塔尼，学校仍由教区司铎掌握，常由主教荐举资助，也部分充作教区神学院。至于新教学校师资，必须谨慎看待反复流传的描述：教师穷困、不稳定，只是等牧职空缺，才暂留教学。细查具体职业轨迹，发现拉丁学校教师留任远比史家过去设想久。例如，不伦瑞克公国十七世纪第三个二十五年，三分之二教师在同地同职超过五年，十分之四超过十年。

关于中等学校，还有三点。第一，各校学生社会面貌差异，似乎加大，尤其受寄宿学校影响。它与私人家庭教师，是社会及财富精英偏好方式。十八世纪，英格兰三分之一乡绅、四分之一贵族接受私人家庭教育。私人教师与寄宿学校也常结合，学生带家教入校。到十七世纪末，特权者不再像十六世纪常见那样，不确定地寄住私人家庭或教师房间，而住专门建筑。意大利贵族学院、法国大型耶稣会和祈祷会寄宿学校，如拉弗莱什、路易大帝、蓬塔穆松和朱伊，以及英格兰九大公学，都提供广泛补充课程。除传统课程，还教舞蹈、歌唱、绘画、战事技艺，即剑术和骑马，以及贵族和商人都有用的数学、会计与书法。寄宿学校给特权者两大好处：儿童在监督下，获得严格道德与智力教育；又通过受控制的精英环境，获得重要处世经验。英格兰精英很大部分读过公学，并非偶然，其中伊顿与威斯敏斯特最受青睐。

第二点，是教学内容逐渐分化。十六世纪制定的人文学科课程，<a id="pdf-176"></a><!-- PDF page 176; original page 161 -->越来越脱离科技演变，也越来越不符合不同社会群体需求。达朗贝尔为1753年《百科全书》写“学院”条目，认为青年为学一种死语言，损失人生最好的十年。他主张教历史、外语、几何和物理实验。无论如何，精英原有学徒训练，出现一定“学校化”。十七世纪初，蒂宾根曾设贵族学院，因战争中断；本世纪后期，地方政治领袖，如1678年都灵、1688年沃尔芬比特尔、1699年南锡—吕内维尔，推动新学院，教舞蹈、绘画，以及骑马、剑术、长矛与火枪操练等军事技能，还有未来军官有用的算术、几何、攻防筑城、历史、地理和外语。通常在常规拉丁学校或私人家教学习后，青春期入学。[^p176-13] 招生长期有两特点：国际性，接受许多在“壮游”中的外国贵族；跨宗派，实行事实上的普世合一，加尔文宗、路德宗和天主教徒共同生活。

实际上，在十六世纪末传统人文主义模式之外，十八世纪发展出各种私人和公共举措，回应不同社会群体职业需要，提供更广教育选择。过去要长期跟军事工程师、建筑师实践，或在大西洋、地中海港口贸易站学习的训练，如今转为专业学校教学。模式极多样：曼彻斯特、纽卡斯尔或伦敦基督公学等古老文法学校，以数学和航海更新课程；各国同时出现不同技术训练，通常包括寄宿及补充课程。国家常支持军事技术部门的预备学校，包括海军、炮兵、工程兵；不久也有土木工程师、建筑师和商人预备学校。天主教国家，这类学校尤其由基督学校修士会发展，因为如前所述，会规禁止其成员学拉丁文。

培训天主教教士的神学院，也应列入专业学校。它们最初只是即将受按立者短期避静的普通场所，有些后来逐渐成为完整教学机构，使只有部分未来神父再上大学。发展虽非普遍，无疑受到神学冲突，尤其反詹森主义《独生子》诏书争端推动。主教希望控制教士培养，确保神学院教授的神学立场。法国遣使会和圣叙尔皮斯会，因而尤其认真遵循罗马指令。总之，中高等教育开始形成两条轨道：大学大体教“纯”科学，专业学校，如培养“外科医生”的学校，教应用科学与技术。但大学也必须面对专业知识的社会需求，体现为教席增加，尤其德意志大学，在政治经济学、现代语言、行政科学及本国民法等领域增设职位。毕业人数相对初次注册人数的比例上升，也很重要。社会对某些专业技能的需求，与大学培养牧师、法官、律师、医生等专业人士的供给，越来越平衡。

## 国家的作用

最重要的，也就是中等教育整体发展应强调的第三点，现代国家越来越依照“教会在国家之内”的原则，把教学视为自身独占管辖范围。诚然，汉诺威王朝英格兰的国家，反而降低对中高等教育的兴趣，不把它们视为国家事务。大学自然科学教学等改革，只是局部，主要取决于内部因素，如文科课程组织、教学方法和大学财务。联省共和国也如此，坚决的联邦体制与地方主权基础，排除普遍改革。但前文已提到萨克森—哥达、不伦瑞克和普鲁士等德意志邦国，早期就广泛改变教育，尽管成果未必符合雄心。这些改革既想为国家行政提供称职、<a id="pdf-178"></a><!-- PDF page 178; original page 163 -->忠诚的人力，也想建立各级协调的教育层次体系。

新教地区，史家正确强调敬虔派在1694年哈勒大学创立中的作用。但也应注意，勃兰登堡边区伯爵、霍亨索伦家族腓特烈三世，本人是加尔文宗，希望创立明显区别于邻近萨克森选侯国莱比锡、维滕贝格正统路德宗大学的路德宗大学。哈勒很快成为培养普鲁士教会与国家官员的主要机构。敬虔派神学院成为有效抵制路德宗正统的中心；与此同时，创新法学院教重商行政学派的政治经济理论，哲学院引入自然法，以德语代拉丁文教学，也推动课程现代化。[^p178-14] 汉诺威选侯借鉴哈勒许多特点，1737年创设哥廷根大学，作为国家机构，主要训练公务员。它吸引贵族，整个十八世纪占学生百分之十至十五，比例相当高，也吸引富裕中产阶层；但不拒绝外国天主教学生，允许公开实践信仰。三因素尤其使哥廷根成为现代大学典范。第一，神学传统上高于其他学院的特权，从一开始就削弱，因为章程禁止以“异端”观点告发教授。限制审查，与其说要破坏教会权威，不如说要消除神学纷争，尤其正统派与敬虔派路德宗之间。第二，国家保留教授任命权，各学院只能提名，大学传统权力因而大减。最后，教学范围显著拓宽。作为核心的法学院，不仅教罗马法，也教德意志习惯法、封建法、宪法、帝国法及法律史。哲学院继续提供一年级基础课，又增许多学科：经验心理学、自然法、政治、自然史、纯粹及应用数学，包括军民建筑、历史及相关的地理与外交研究，以及古典与现代语言。

天主教地区，改革始于十八世纪二十年代，皮埃蒙特维托里奥·阿梅代奥二世广泛颁令，禁止所有<a id="pdf-179"></a><!-- PDF page 179; original page 164 -->修会教士，包括耶稣会，在中等学校教学。转变首先是集权，把教学事务控制权从都灵大学移走；其次趋向统一，规范学校行政、教师资格和课程。中央奖学金学校“诸省学院”（Collegio delle Provinzie）建立，按各省人口密度，更客观地授奖，意在引入择优原则，吸收市民阶层优秀学生，重组统治阶级，创造新公务员精英。观念迅速传播，随着各国驱逐耶稣会而扩展到全欧洲：葡萄牙1759年，法国1764年，西班牙1767年，那不勒斯王国1768年，随后1773年《主与救主》（Dominus ac Redemptor）诏书完全废除耶稣会。欧洲最大教学修会被取缔，给若干国家带来深刻断裂，严重影响年轻一代宗教教育与指导，也引发公共教育的根本重审、重组。现代化依据三原则。第一，公共教育和国民教育概念兴起，认为整个教学机构都属于国家领域，可能直接与教会冲突。例如1783年，约瑟夫二世决定创设一系列“总”神学院，使未来司铎独立于主教团受训；从此，司铎被视为负责地方公民秩序的国家官员。第二，出现新的教师队伍，教育、效忠关系与招募方式，都与修会成员根本不同。最后，国民教育方案更新课程，重新评价“人文学科”体系。这里无法探讨立法与现实可能有的差距。但运动动力，似乎较少来自倡导者的语言，不论行政实践观念，还是“开明”专制的新政府形式，而更多来自现代国家长期建构过程；国家需要越来越多有技能行政人员服务。此后，天主教和新教教士，都将被视为国家行政者，这一转变将在法国革命十年进一步加速。
