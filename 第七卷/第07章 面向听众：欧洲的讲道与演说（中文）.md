# 第七章　面向听众：欧洲的讲道与演说

**约里斯·范艾纳滕（Joris van Eijnatten）**

在“漫长的十八世纪”，讲道作为传播媒介，承受了前所未有的社会与思想压力。报纸、期刊、小说、公共讲座、咖啡馆、辩论俱乐部、学术社团等其他渠道，迅速接手其教育和道德训诫功能，听众也开始转移注意。然而，整个时期，讲道仍是公共教导的主要途径，地位显著，面貌多样。以下论述分四节：“呈现”描述1660至1800年讲道的一般形态；“目标”考察其宗旨；“传统”讨论宗派式讲道；“转变”则概述十八世纪讲道如何成功回应挑战。

## 呈现

讲道仍主要服务于聚集教堂的有组织听众，但整个时期，也有著名的非正式集会，包括敬虔派小聚会和复兴聚会。挪威汉斯·尼尔森·豪格（1771—1824）等敬虔派平信徒讲道者，步行长途，违法传讲，并常因此入狱。主流机构之外，也有女性讲道者，例如贵格会和不从国教的敬虔派；教会内部私人圈子，尤其福音派中，也有妇女讲道。地点通常是公开或秘密的教堂，但也可能是田野、公园、公共大厅或集市。卫斯理发现圣公会讲道台不向自己开放，便转到露天，坚持半世纪，直至八十八岁，每天三四次。卫理宗通过巡回讲道绕开官方渠道，<a id="pdf-144"></a><!-- PDF page 144; original page 129 -->摩拉维亚弟兄会，即赫恩胡特弟兄会，也同样如此。但多数讲道，仍由既有教士在规定时间、固定地点举行。

年复一年，福音信息向城市与乡村会众宣讲，听众规模、性别、职业和社会地位各异。社会差别重要，也许比过去更甚。一位法国神父，称一群听众为“我的姊妹”，却不得不称另一群为“诸位夫人”，并非特例。在西欧商业化的中产社会，也常有受过高等教育的律师、法官、政治家和学者听众，例如约瑟夫·巴特勒（1692—1752）年轻时讲道的伦敦卷宗教堂，或乌得勒支瓦隆教堂，雄辩讲道者面向讲法语的上流社会。宫廷讲道是排他的盛事，由口才最好、报酬最高者登台；即使有礼仪规程，显贵仍可能派仆人提前占据最佳座位。凡尔赛若知道耶稣会士布尔达卢下午讲道，早晨六点便有人占座。乔治·怀特菲尔德（1714—1770）这种富有感召力、极受欢迎的讲道者，吸引更多人，主要来自中下阶层，又通过广告和报纸报道，接触更广大公众。[^p144-1] 听众在讲道前、中、后的角色，从积极参与到被动消费不等：有人叫喊、颤抖、俯伏，有人看报，有人从头睡到尾。内心驱使和社会义务，是听讲道的明显理由；但在香水与假发盛行的时代，也可能是与适婚对象调情、展示最新时装，或仅仅听新闻的借口。好讲道是近代早期式“资讯娱乐”，优秀讲道者和剧院名演员一样值得一看。十八世纪四十年代，英格兰有句话：“没听过法里内利唱歌、福斯特讲道的人，没有资格进入上流社会。”[^p144-2]

讲道在上午、下午，有时晚上举行，通常每星期日及节庆日都有。将临期、四旬期特别讲道，以及传教讲道，是天主教世界的特征；应时讲道却跨越宗派。场合包括官方庆典、君主周年庆、哀悼日、战争开始或和约签署。疫病、短缺、天灾、火灾和天象征兆，都在讲道中得到解释，最后一类随时间推移较少出现。1755年11月里斯本地震<a id="pdf-145"></a><!-- PDF page 145; original page 130 -->这样的重大灾难，引发讲道台上的多种神学解释。每种人生礼仪，包括洗礼、告解和婚姻，都有讲道；死亡和入修院也提供其他机会。堂区日常起伏和报纸消息，又引发有关饮酒、跳舞、奢侈、轻浮及其他种种恶习的讲道。记述或庆祝重要政治、教会事件，例如王子出生、教会会议开幕的讲道，偶尔会发展成大部头历史、年表和家谱。书目学家有时难分它们究竟是讲道，还是参考书。

遵循特伦托建议，多数天主教讲道指南认为，星期日弥撒中以本地语言讲十五至三十分钟，就已足够。特别讲道是独立于圣体礼的城市盛事，时间明显更长。无论如何，讲道规则常被突破，尤其新教讲道台，长达两小时并不罕见。天主教通常不把讲道视为公共礼拜主项；一些新教徒也如此，虽然理由不同。摩拉维亚领袖尼古劳斯·路德维希·冯亲岑多夫伯爵（1700—1760），认为礼仪功效至少与讲道相当。他相信，歌唱救恩、诵读《圣经》，对信徒聚会同样重要。这并不妨碍这位富天赋、想象力、但稍显无序的灵性领袖，发表大量即兴讲话与演说（Reden、Ansprachen）。柏林、伦敦、荷兰共和国和宾夕法尼亚的听众认真抄录，随后出版。

1660至1800年，出版讲道数量庞大。这些刊物未必代表讲道者实际提供给听众的内容，通常反映城市多于乡村。拟出版的讲道，一般在讲完后扩写润色。敬虔派奥古斯特·赫尔曼·弗兰克（1663—1727）是例外：学生记录，他通常只是草草审阅，便付印。应时讲道是最常印行的类型之一，却一年只在讲道台出现数次，因此我们对寻常主日讲道的了解，比期望少。对出版商而言，讲道是值得投资、能向匿名公众出售的商品，但商业情境通常比简单供求规律复杂。天主教节庆讲道尤其常<a id="pdf-146"></a><!-- PDF page 146; original page 131 -->由组织者付费，分发或作为礼品，正如葬礼讲道通常由死者亲属出资。无论如何，包括讲道在内的教导文献，需求很大。把出版讲道读给不识字者听，可能有助于识字。“普通人”讲道和儿童讲道越来越常见，多为便宜的十二开本。社会教育改革理想日益发展，市场也开始提供面向农民、海员、士兵、夫妇、青年、年轻女士和老人的讲道，农民尤其占重要位置。

讲道出版者从乡村牧师，到大学教授、主教和教区监督都有。如果相信序言，出版是为教导会众，协助天赋较低或经验不足的同僚。它也补充微薄收入、推进教会或学术职业，普遍而言，巩固讲道者声誉。想从外省到巴黎、从巴黎到宫廷的人知道，必须先建立一定讲道名望。身后出版很常见，由亲属、朋友或同僚发行，供人购买保存作纪念。新期刊书评者批评这种做法，因为少有作品符合其文学趣味标准，而且已故作者遗憾地无法接受纠正。一些著名口头讲授专家，为谦逊作榜样，在遗嘱要求销毁手稿。荷兰加尔文宗牧师伯纳德·斯迈特赫尔特（1665—1739）就留下这种指示；他围绕《以赛亚书》42章3节“压伤的芦苇，他不折断”这一单独经节，所讲一百四十五篇，之所以仍以十七卷四开本存世，只因为虔诚门徒在教堂费力抄录。从柏林到伦敦，抄录都是获取名讲道者文本、制作许多有利可图盗版的主要手段。

出版讲道可以广泛借用他人演说作品，口头讲道也常如此。这种抄用未必受责备。圣公会主教团特意建议年轻讲道者这样做，几乎没有神父否认引用博叙埃段落的用途。忙碌、缺经验、乏想象力、不善表达，或只是懒惰的教士，都善用讲道集，寻找相关主题、合适段落、贴切引文，甚至完整讲稿。消费文化因而延伸至讲道；英格兰似乎存在由职业写手供稿、贫困教士购买的讲稿市场。[^p146-3] 印刷媒介增多，甚至使<a id="pdf-147"></a><!-- PDF page 147; original page 132 -->讲道成为收藏品。帝国女伯爵埃莱奥诺雷·楚施托尔贝格—施托尔贝格（1669—1745），欣赏葬礼讲道的安慰作用，搜集约两万五千种不同文本。[^p147-4] 嘉布遣会普罗科普·冯滕普林（1608—1680）是多产畅销作者，超过两千六百篇讲道，分三十卷出版，冠以Eucharistiale（圣体）、Poenitentiale（忏悔）、Orationale（祈祷）、Mariale（圣母）和Decalogale（十诫）等典型题名。德累斯顿路德宗宫廷讲道师弗朗茨·福尔克马·莱因哈德（1753—1812），讲道集不少于四十二卷，于1815至1821年出版；据说每星期日向三四千人讲道。多产作者还有许多，有些听众远超本国，例如英格兰非国教人士菲利普·多德里奇（1702—1751）、苏格兰长老派拉尔夫（1685—1752）与埃比尼泽（1680—1756）·埃尔斯金兄弟，以及德意志路德宗约翰·雅各布·兰巴赫（1693—1735）。十八世纪末，讲道合集系列更流行，例如多有译本的格奥尔格·约阿希姆·措利科费尔（1730—1788）或休·布莱尔（1718—1800）讲道。各国都有持续畅销作者，但这一时期西欧最受尊崇者之一，无疑是约翰·蒂洛森（1630—1694）。他的讲道以英、法、荷、德文反复出版，影响无所不在。

## 目标

一些天主教讲道者，把讲道类比为圣体圣事。雅克—贝尼涅·博叙埃（1627—1704）在1661年以《马太福音》17章5节“这是我的爱子，我所喜悦的；你们要听他”为题讲道，就如此理解：祭坛象征基督身体的真实，讲道台代表基督话语的真实；听众通过圣体体验“内在讲道”，又通过讲道见证“外在讲道”。[^p147-5] 把演说与其他视听传播方法结合，能增强近代早期讲道的影响。耶稣会、祈祷会和嘉布遣会的传教讲道，有时融入精心表演，配旗帜、游行、合唱，以及在壮观舞台前进行的戏剧动作。福音派则把灵性文本配上生动曲调。如果加尔文宗对经文的冗长阐释与应用，似乎离这种热闹很远，多数乃至所有讲道的目标和形式，其实相当接近。为本章概述起见，可把近代早期讲道视为有关基督教信仰的口头论述，旨在<a id="pdf-148"></a><!-- PDF page 148; original page 133 -->教导并激励会众，常常但不总是围绕《圣经》文本的释经、解释和应用。它可以是详尽教义论述、长篇经文注释，或简短教化性训讲。

在新教和天主教两场改革中，讲道都被视为内化信仰所必需。十六世纪新修会落实特伦托改革，耶稣会尤其始终是重要讲道者，至少直到1773年被解散。十七世纪也产生许多讲道极活跃的团体，如嘉布遣会，以及法国遣使会，又称文生会，专为向乡村穷人布道而设。传教司铎专长讲道，能够适应全然不同的公众。法国重要传福音者雅克·布里代纳（1701—1767），在各地城镇村庄举行二百五十六次布道，招摇穿行街头、大声摇铃，召集懒散居民。[^p148-6] 尽管修会作用突出，整个时期的讲道总体产出，仍相对从修会转向教区教士。

尽管敬虔派和启蒙批评者反教权，讲道教士的自我形象大体未损。特伦托会议后通常由耶稣会士写作的讲道指南，着力扩展讲道者自我意识，强调至高神明与卑微讲道者间令人不安的鸿沟。后者是主的使者，有人说是天使，把救恩消息带到尘世悲谷。要在上帝与听众之间中介，讲道这一崇高职务最需要谦卑、服从，以及自觉不配。[^p148-7] 人们极重讲道者的召命、虔敬与谦卑，因此，宗派时代的讲道改革，涉及讲道者多于听众。新教和天主教中，都有丰富的讲道者自喻：色彩鲜明者包括食物贩子，给初学者奶、给进深者硬食；招待基督徒宴席的旅店主人；以及为患病者施灵性医治的医生。

讲道经常结构严密，分段和分目复杂。不过，随着时期推进，较少人工雕琢的安排日渐常见。讲道越来越受到<a id="pdf-149"></a><!-- PDF page 149; original page 134 -->文学标准影响，并相信，简单思想用简单语言表达，更能打动人心。讲道结构可以依据《圣经》或道德主题的逐步论述，改革宗通常从某一经节的释经出发。天主教讲道者则更愿按外在主题组织。在德意志，流行的“等级讲道”（Ständepredigt）映照社会秩序，依次审视各社会等级、年龄群和职业。另一受欢迎类型，是“字母讲道”。例如，耶稣的名字让富想象力者，发挥字母“I”隐含的预表意义，联想到雅各、约瑟、约书亚、以赛亚，以及拉丁文“义者”（iustus）、“审判者”（iudex）和“光照者”（illuminator）。[^p149-8] 改革宗选择主题较少受限制，喜用连续释经（lectio continua），围绕一卷《圣经》或一部要理问答，形成系列。路德宗中，符腾堡格奥尔格·康拉德·里格尔（1687—1743）对《马太福音》讲了不少于一千次，仍只到第十九章。还有其他构思方法：圣公会福音派约翰·牛顿（1722—1807），以亨德尔《弥赛亚》所用经节，出版五十篇讲道。路德宗必须使用固定经课，按礼仪年安排讲道，使欠缺才思者处于不利。因此，讲道者使用修辞方案，让讲道呈现不同形式，或借助轶事、寓言、例证，以及古代异教与教父引文集，确保变化。

加尔文宗讲道者遵循约翰内斯·霍恩贝克（1617—1666）等较早理论家，把讲道视为“解释并应用《圣经》、以造就教会为目的的神圣行动”。[^p149-9] 宗派时代多数讲道者都会赞同，讲道应向听众传递知识和道德教导。敬虔派菲利普·雅各布·施本尔（1635—1705），在1675年《敬虔愿望》中批评过度铺陈。这部有影响力的紧急改革呼吁，把神学反思与实际态度结合；他坚持讲道核心目标是造就信徒（Erbauung），首先必须易懂清楚。德意志哲学家克里斯蒂安·沃尔夫的追随者，极重理性论证、精确术语和透明安排，正为反击他们认为缺乏形状的敬虔派演说。普鲁士腓特烈·威廉一世甚至试图推广沃尔夫式讲道，于<a id="pdf-150"></a><!-- PDF page 150; original page 135 -->1739年正式规定教士使用约翰·古斯塔夫·莱因贝克的讲道学。实际上，施本尔前后的讲道学作者都强调清楚，多数承认讲道既有认知目标，即信仰知识，也有行动目标，即虔敬生活。

本时期的变化，首先是相较教义教导，更强调道德造就；其次，是采用被认为最适合向具体听众传达永恒信息的方法。有效传达日益受到重视，把《圣经》佳音传给现代世界这一持久的解释学问题，也使人认为，讲道语言与内容必须适应听众。本时期杰出改革者约翰·洛伦茨·冯莫斯海姆，原书所记生卒年为1639—1755，同施本尔一样强调造就。他认为，只有论证清楚才能启发理智，只有受启发的理智，才能塑造意志。讲道必须令人信服；按他富影响力的观点，这意味着《圣经》与理性不应、也不可能冲突，讲道台演说与世俗演说遵循同样修辞原则，最重要的是，讲道者必须针对具体环境的具体听众。苏格兰长老派休·布莱尔，是另一位同样权威的作者，他把讲道演说称为“以最有利于使人确信、加以说服的方式，呈现真理的艺术”。[^p150-10]

除莫斯海姆和布莱尔，本时期主要讲道学作品，还包括夏尔·罗兰的《论美文的教学与研习》（1726—1728），以及费讷隆的《论一般雄辩与特别论讲道雄辩的对话》，写于1681年、1718年首次出版。两书在欧洲广被阅读引用。费讷隆认为，讲道演说旨在教导心智、改善道德，途径是分别向理智、想象与情感，进行证明、描绘与感动。让—西夫兰·莫里（1746—1817）之于天主教，如同莫斯海姆之于新教；其《论讲道台雄辩》在1777至1851年出过十三个法文版本。这些书被学院和神学院规定使用，也供实际讲道者利用。其他辅助包括各种讲道集（Postillen）：有些连续注释一卷《圣经》，有些按主题或字母排列可供讲道素材，作百科全书式概览，有些是附讲道索引的神学论著。参考工具还包括象征图像词典、百科全书、辞典，以及比喻、寓言、对偶、历史集，许多冠以“金矿”“宝库”<a id="pdf-151"></a><!-- PDF page 151; original page 136 -->或“珍馐”等奇特题名。教育兴趣增长，最终催生简单讲道规则的解说，以及专门讨论讲道的杂志与期刊。

不能打动情感的讲道，被认为贫瘠。本时期福音派也持同样信念，使用一切可用讲道技巧，包括反问、对偶和反复，追求唯一大目标：让男女直面自身罪恶，唤醒良心，带来归信，从地狱拯救他们。这样的简单语言讲道，因即兴发表而更有效；即兴成功，可能被视为神圣感动的标志。乔治·怀特菲尔德便是大师，以伟大演员般技巧，现场讲过约一万八千篇，随时储备大量轶事。他声音宏亮，按本杰明·富兰克林计算，理论上能在露天传至数万听众。荷兰阿民念派、苏格兰加尔文宗等群体，一致坚决反对在讲道台逐字读稿。相比之下，许多改革者越来越支持背诵、甚至照读，因为即兴并不保证雄辩，休·布莱尔却是明显例外。多数天主教理论家似乎偏好背稿，但法国堂区神父或奥地利堂区牧者中，是否有超过少数这样做，值得怀疑。毕竟，博叙埃不背讲稿，费讷隆也反对此做法。不过，所有作者都同意，即使预备即兴，也应事先在书房认真准备。

祈祷日讲道，可能是最常见的新教应时讲道，奉世俗当局之命，在战争和灾难期间举行，求神援助、承认共同罪恶、抵御神罚。这类“耶利米式哀诉”，直到本时期末才不再流行；后来的讲道不再反省民众罪恶、预言神即刻介入，而讨论社会道德缺陷，以及天意所警示、迫近而内生的国家衰落。祈祷讲道在新教欧洲，与天主教巴洛克节庆讲道，发挥相似的“国家认同塑造”作用。奥地利1663年以后，为本国主保圣人举行的利奥波德讲道，使民众意识到奥地利是由一个统治家族领导、具有凝聚力的国家单位。[^p151-11] 不同讲道有不同目标。天主教圣人讲道（Heiligenpredigt），或<a id="pdf-152"></a><!-- PDF page 152; original page 137 -->节庆讲道，目标有二：唤起对圣人事迹的钦佩，鼓励敬奉；又激励效法其德行。它与葬礼讲道密切相关，后者旨在赞美死者、安慰遗属、教导听众。葬礼讲道包含死者生平概述，因而具有特殊性。它尤其常见于帝国中部路德宗，却绝不限于此；1700年前后数十年，越来越变成纯粹颂词。只有贵族和富有市民，负担得起讲道者竞相制作的华丽印本。它们饰以精美肖像、希伯来文和希腊文字体，甚至葬礼音乐，以对开或四开本，成为死者碑铭，是家属少量定印、奢侈而可携的墓碑。罗斯托克神学家海因里希·米勒（1631—1675）等批评者，以双关把“葬礼讲道”（Leichpredigten）贬为“轻飘讲道”（Leichtepredigten），批评这一体裁日益赞颂死者，而非鼓励生者。[^p152-12] 但华丽葬礼讲道印行风尚，约1750年以后才衰退，部分回应对死亡态度的变化；天主教中仍繁盛到十八世纪八十年代，只是规模稍小。

十八世纪末，讲道集中于改善会众道德状况，因而涉及公民、社会和私人生活各领域。教士现在能谈哲学、自然、政治与经济。例如，围绕一棵树的“自然讲道”，可以想到为后代利益种树的无私者。[^p152-13] 经济讲道可以讨论商业欺诈、吝啬、卫生益处，以及迷信对农业的危害。其他主题包括腓特烈二世、耶稣会、政治革命、宫廷腐败、航运及出版自由。当然，讲道长期用于政治目的。革命以前，法国教士有义务把行政和法律指令告诉主日会众；1695年起，弥撒将结束时从讲道台宣读政府公告。开明政权和革命，都未改变讲道台的政治功能。奥属尼德兰的约瑟夫二世，典型地用讲道台传播皇帝敕令与法规。还可以说，讲道在另一意义上也是、且仍是政治性的：作为公共言说，它本身具有政治性质，因为反映关于宗教、<a id="pdf-153"></a><!-- PDF page 153; original page 138 -->公共领域和政治权力之间关系的预设。现在转向这后一种“政治”意义。

## 传统

1660至1800年这一个半世纪的讲道史，曾被描述为从“巴洛克”转向“新古典”。这是合理视角之一。对关注修辞理论的文学史家，这种对照可能更重要；对关注特伦托会议后天主教与路德宗正统教义差异的神学家，则未必。没有办法能完全满意地整理本时期多样的演说景观。本章所用“宗派式”和“文雅式”标签，只要能说明近代早期讲道与政治变革、传播过程和公共舆论发展的关联，就有帮助。从这一视角，“宗派式讲道”可视为以权威和服从为前提的公共领域的延伸；“文雅式讲道”则反映以自由、温和和善于表达等启蒙德行为基础的公共领域。

当代研究倾向把讲道置于产生它的历史环境，视为传播手段、暗中维系有时颠覆社会政治秩序的修辞工具，以及反映宗教心态的话语方式。[^p153-14] 十九世纪史家对十七世纪后期和十八世纪讲道尤其苛刻，这种评判风气直到最近才开始消退。传统讲道长期被归为旧式虔敬，或被指晦涩、难以接受。十八世纪创新，则被贬为实际、功用、道德说教而肤浅，或被看作启蒙心智那种沉着理性与所谓世俗主义的反映。早在十八世纪，人们已把迂腐、浮夸、好争辩、冗长归于宗派式讲道；改革动力也催生最早的讲道演说历史概述。[^p153-15] 新方法支持者遗憾变化太慢。讲道确实显著改变，却很渐进，也有其限度。到本时期相当晚，仍有大量讲道者坚持传统方式；怀念“教父”时代的传统派，对熟悉的旧讲道仍需求很高。

因此，本时期大部分时间，仿十七世纪范例、精心铺陈、结构严密的讲道，远为常见。加尔文宗通常采用分析方式，花大量篇幅解释单字与论战。文本仔细划为大段、小段、总论、分论，以及众多标题、要点、教义、用途与改进，注意“是什么”“何种性质”和“有多大”。这类讲道显得任意，因为几乎任何经节，都可能被用来证成任一论证，或装饰任一主题。十八世纪初路德宗讲道者，常用经文汇编遍搜《圣经》，引述或讨论哪怕仅与题目稍有关系的段落，或强调不同经文中的相似词语。天主教讲道也可能同样盘根错节。

关键是，对宗派讲道者，以及想必相当部分听众而言，《圣经》内容如同其宗派解释的权威性一样，都是不言而喻的。批评者指出，讲道台，尤其天主教讲道台，唤起地狱恐惧，巩固既有教权；但它也回应共同信念与预设。[^p154-16] 把《圣经》当作神言宝库搜求，诉诸学术传统，被认为是尊重并光大基督教传统。不过，这不意味着他们展示学问时有所节制。宗派式讲道印页，随处散见希伯来、希腊与拉丁词句；页边和注脚常引迈蒙尼德至格劳秀斯等名家，也引声望微小者。天主教“巴洛克”讲道同样把信仰真理视为当然，使用经文未必是解释它，而是展开道德论点。经文、主日或节庆经课，常只是展开或装饰主题的机会。节庆讲道作为礼仪一部分，发挥仪式作用，是诸多装饰之一；流行的文字游戏，主要为增加所庆祝圣人的荣耀。因此，尽管特伦托偏重圣事神学、宗教改革强调圣言神学，强调天主教巴洛克与新教分析式讲道的相似，大有道理。两者都爱比喻：巴伐利亚耶稣会士受难周讲道，谈榨出鲜血的酒榨，路德宗则发挥“灵性的油库”。天主教讲道者可用<a id="pdf-155"></a><!-- PDF page 155; original page 140 -->“类比的、悲剧的、乡野的、仁慈的”号角，攻打耶利哥城墙；新教讲道者则同样热切地吹响全民悔罪号角。

延续根深蒂固的中世纪习惯，各种宗派讲道者，不论天主教、路德宗或加尔文宗，都喜爱寓意、深义、象征、预表与徽像。因此，德语世界流行“徽像讲道”，形象运用大量图像与明喻，使听众内化徽像意义。最著名代表之一，是维也纳宫廷讲道师、奥思定会士圣克拉拉的亚伯拉罕，本名约翰·乌尔里希·梅格勒（1644—1709）。他用民众语言讲道，尤其丰富运用图像、机智、双关、字谜、轶事和徽像。路德宗也用这种形式。瓦伦丁·恩斯特·勒舍尔（1674—1749）把《主祷文》比作坚固建筑，带听众走过庭院、礼拜堂、文书处、阁楼与军械库，以比喻其中各项祈求。[^p155-17] 教义、礼仪与学术传统，深刻影响宗派式讲道。直到十八世纪末，天主教讲道中的经文，常与故事、寓言、例证起同样作用，也如罪人受罚、祈祷获应允、神迹发生的民间故事，或巫师、魔鬼、巨人与水妖传说，或格言谚语的历史，或为道德教导而嘲笑各社会等级和家庭关系的闹剧。[^p155-18] 直到巴伐利亚主教约翰·米夏埃尔·赛勒（1751—1832）改革，天主教讲道才更明确以《圣经》为中心。

西班牙的宗派讲道，体现为“奇思式”（concetto）讲道。它分成许多段落或条目，利用不寻常思路、对偶、双关与新奇意象，构成充满离题与旁支的复杂演说设计。这种曲折但连贯的结构，带听众和读者沿意外路径抵达预定目的，从而领会宗教真理。它经那不勒斯传入意大利，直到十八世纪相当晚仍繁盛；虽受欢迎，制作显然费力，一旦缺乏才能，就退化为曲折卖弄机智、虚饰学问。耶稣会士何塞·弗朗西斯科·德伊斯拉（1703—1781），在1758年流浪汉小说《著名讲道者坎帕萨斯的赫伦迪奥修士，又名索特斯传》中，讽刺自己认为堕落、无趣味的当代讲道。这本书使矫揉造作的讲道，得了“赫伦迪奥主义”（gerundianismo）的贬称，却遭<a id="pdf-156"></a><!-- PDF page 156; original page 141 -->西班牙宗教裁判所禁毁。大不列颠新古典风格发展较早，多少掩盖了宗派式讲道持续流行的事实；其代表尤其是英格兰清教与苏格兰加尔文宗讲道。同样受到批评的，是零散拉丁文和希腊文、文字游戏，1660年一位批评者说，尽是“出去、退回、前进之类东西”，[^p156-19] 以及冗长释经、笨重风格、复杂分段。

## 转变

十八世纪讲道者发现，必须体会善于表达、受过教育听众的感受，并调整论述。英格兰与法国是革新的摇篮。十七世纪英格兰皇家学会圈子，提倡新古典“朴素风格”；法国的法兰西学院，则为在成员面前所讲的最佳讲道，颁发雄辩奖。英格兰与约翰·蒂洛森之名相联，他适时要求合理改革。吸引力一部分在于诉诸理性，一部分在于掌握新古典风格。他作为讲道者，符合文雅、知情城市公众的期待：他们欣赏其切实论述，没有令人不安的情绪主义与多余装饰，用朴素而优美散文传达道德信息。他回避论战与狂热，结构清楚、风格动人、语言适度，又诉诸“合理宗教”，使其在新教欧洲影响非凡。从爱丁堡到柯尼斯堡，改革者声称，蒂洛森几乎结束“虚假修辞”、假装博学、多余离题、牵强比喻、糟糕机智和粗俗语言的时代，预告简朴、简短、清楚、合理、温和与“自然”安排的新时代。吉尔伯特·伯内特说，讲道者应力求“清楚而高雅风格的朴实”。[^p156-20]

法国一批杰出讲道者，受古典修辞手册启发，确立高雅风格标准。因此，法国宫廷讲道长期享有罕见地位，被视为文学文化作品；甚至伏尔泰这样苛刻的人，也让人在用晚餐时朗读马西永讲道。路易十四挑选优秀讲道者，荣耀本国与天国的统治，赞助并欣赏讲道的精密安排、丰富创意、机智、成熟风格、优雅措辞和出色表达；但一些批评者认为，它们太经常服务演说者虚荣，而非上帝荣耀。伟大<a id="pdf-157"></a><!-- PDF page 157; original page 142 -->文体家与演说大师，是通常被誉为“法国德摩斯梯尼”的博叙埃。他在宫廷或巴黎教堂即兴，以讲道的热忱、独创、清楚与生动，抓住听众，主题包括天意、教会合一和法国国王义务。他与布尔达卢、马西永构成法国宫廷讲道三杰，精湛掌握演说技巧，影响法国及国外后代。三人各具风格：博叙埃凭深刻洞见和有力修辞，耶稣会路易·布尔达卢（1632—1704）则凭逻辑与论证，抓住听众。后者被称为“讲道者之王、国王的讲道者”，忠于道德训诫，毫不回避斥责贵妇的懒散和廷臣的野心。让—巴蒂斯特·马西永（1663—1742）同样重道德，探察内心与激情，心理洞见丰富。1700年前后数十年，法国新教讲道也繁盛；欧洲胡格诺派或瓦隆讲道者中，以雄辩闻名者比例异常之高。法国让·克洛德（1619—1687）、荷兰共和国雅克·索兰（1677—1730）、柏林伊萨克·博索布尔（1659—1738）等人，用“综合”方式展开经文主题，避开推测与抽象，强调道德造就。克洛德1688年《论讲道的构成》简明切要，在欧洲广为阅读。

十七世纪末、十八世纪初，德意志敬虔派主张，讲道目的与其说道德训诫，不如说使人归信、内化信仰，并在日常生活表现出来；原书对此时段的措辞，见本章译校说明。敬虔派的词汇受《雅歌》启发，针对它认为主流“正统”风格的深奥形式主义、多余装饰和贫瘠论争，提出更简单、更合《圣经》、更实际的选择。路德宗主教埃里克·蓬托皮丹（1698—1764），是众多传播这些观念者之一，其活动在丹麦。约1750年后，西班牙詹森主义者尤其受布尔达卢启发，同样率先改革讲道。[^p157-21] 敬虔主义、詹森主义、英法模式、文学与美学发展，以及知情、善于表达、文雅公众持续增长，合力逐渐导致普遍批评宗派式讲道。改革者认为，讲道不为肯定或确认威权宗派社会秩序，而应传递实际信息、改变行为，把简单信念与道德知识，印入听众和读者心中。福音派强调个人选择与经验，欧洲各国改革者则都<a id="pdf-158"></a><!-- PDF page 158; original page 143 -->努力把经文信息具体化，适应“民众”的理解。讲道成为传播载体，形式与内容都反映，也因而传播关于社会秩序、改善与文雅社会的新观念。人们也越来越把讲道视为文学产品，一种除专业能力之外，还需要文学技艺的论述；兴起的期刊媒介用大量篇幅评论讲道。[^p158-22] 十八世纪重新评价修辞，将其作为研究人性的工具，特别关注口头话语、论证与手势对听众的作用，讲道演说由此受益。

因此，要求简朴清楚、赞许更“综合”讲道方法的呼声，在西欧与中欧教士中日益引起共鸣。面向听众的努力，不限于优雅言辞、诉诸理性和常识。讲道更短、更精要，主题式设计取代分析式。改革者普遍同意，成功雄辩反映演说者道德品性，必须充分注意作为“行动泉源”的激情。“动情式”风格拥护者尤其认真看待情感，极力强调古老格言：讲道者必须先亲身感受希望听众感受的东西；唯有说心灵语言者，才能打动他人心灵。詹姆斯·赫维（1714—1758）和约翰—卡斯帕·拉瓦特（1741—1801），以亲切语言、动情风格，以及独白、感叹和“感伤式”结语等修辞手段，把自身宗教热忱传给听众。

讲道学作者有力主张，称职讲道比以往更依赖讲道者的社会经验，以及切中要害的心理观察。套用亚历山大·蒲柏，十八世纪理论家认为，讲道者在《圣经》之外，应研究的适当对象就是人。新教启蒙运动较激进的所谓“新神学派”，赋予讲道鲜明道德性质，把教义限于对上帝、德行与不朽的认识，赞扬其总体目标为培养智慧、道德和宗教幸福（Glückseligkeit）。约翰·约阿希姆·施帕尔丁，是蒂洛森众多热心读者之一，著有1772年畅销书《论讲道职务的有用性及其促进》，认为讲道只有“引导基督徒走向虔敬与心灵安宁”，才有用。这类观念不限于德意志。法国文学批评家让—弗朗索瓦<a id="pdf-159"></a><!-- PDF page 159; original page 144 -->马蒙泰尔（1723—1799）坚持，不必用教义困扰到教堂的人，因为其在场已证明他们是基督徒；讲道目的，应把忠诚基督徒转为有德行的礼拜者。[^p159-23]

一种受到约翰·戈特弗里德·赫尔德（1744—1803）等人尖锐批评的解释学，把经文看作历史上已经过时、却保存真理内核的外壳。耶稣和使徒曾使真理适应同时代人的有限理解，如今必须重新适应十八世纪末听众较高的能力。这意味着攻击前人使用的“迦南语”，诸如“可怒之子”“披戴基督”“在割礼的字句中”等难懂说法，成为其过时的象征。为反击这种“东方主义”，德意志讲道者可以使用威廉·亚伯拉罕·特勒1772年的《阐明基督教教义的新约词典》。据该书，“归信”只是古老说法，意思是“自我改善”。讲道者因此成为会众教师与“启蒙者”。约翰·弗里德里希·威廉·耶鲁萨莱姆（1709—1789）等人的讲道，广受欧洲受教育公众欢迎；对他们而言，讲道是启蒙、道德正直与灵性平静的主要媒介。

讲道者如今常特别回应其认为在上层社会中无谓泛滥的无神论。护教学成为突出主题，莫斯海姆等人就作过“嘲笑宗教者的愚昧”讲道。讲道若应重新阐述、捍卫经文意义，也必须有用。这种功用强调，使某些人谈论圈养牲畜的好处，恰好在圣诞节讲；或活埋可能性，在复活节讲；或承诺更健康、更长寿的医学理论。总体而言，公众善于表达，愿接受道德指导，却能自由挑选灵性牧者，牧灵工作成功回应这一发展，重新确认讲道作为主要口头传播手段的地位。讲道者更愿有效、公开地接触听众，而非在制度环境中认可传统假设。一个结果，是国教会之外讲道越来越受尊重。旧制度暮年，复兴运动和传教会的独立讲道，已成为受重视的宗教演说方式。

原书第142页在讨论德意志敬虔派时，写作“around the turn of the seventeenth century”。依本章叙述及所涉人物活动时期，本稿将此处理解为十七世纪末、十八世纪初，并在正文如此译出，保留原措辞于此供核对。原书第135页所列莫斯海姆生卒年为1639—1755，正文已标明系原书记载。
