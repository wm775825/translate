# 第32章 榜样

休·麦克劳德（Hugh McLeod）

<a id="pdf-619"></a>
<!-- PDF page 619; original page 618 -->



在基督教历史的每个世纪，都有自己的圣人。他们被同信者视为圣洁的男女，也被宗教权威树立为榜样。然而，圣洁的观念不断演变：某一代人眼中的圣人，在另一代人看来，或许并无多少圣洁可言。如果说圣人是非同寻常的个体，那么数量更多的，是那些被人视为、或被树立为榜样的人：他们显示，在某种职业中，作一名基督徒意味着什么。在这方面，随着某种职业在基督教思想中的地位改变，人们的看法也可能发生根本变化。

关于早先各世纪的基督教圣人，已有许多重要著作；[^p619-1]但迄今很少有人尝试探索20世纪的圣洁观念，以及这一世纪基督徒被给予、或自行选择的榜样。[^p619-2]由于相关二手研究匮乏，本章只是对这一主题的初步探索，范围也限于西方世界所认可的圣洁观念与榜样。

## 圣人

2003年10月20日，教皇若望保禄二世向前来罗马参加加尔各答德兰修女宣福典礼的朝圣者讲话，称她为“20世纪最伟大的传教士之一”：

> 主使这位来自欧洲最贫穷地区之一的朴实妇女，成为蒙拣选的器皿（参见《使徒行传》9:15），向整个世界宣讲福音；她所凭借的不是布道，而是每天向穷人中

<a id="pdf-620"></a>
<!-- PDF page 620; original page 619 -->



> 最贫穷者所作出的爱德行动。她是一名使用最普世语言的传教士：爱的语言，不知界限，不作排斥，除了最遭遗弃的人，不偏爱任何人。

他接着指出，她从祈祷以及“静默地默观耶稣基督、祂的圣容与圣心”之中获得力量。他也把她形容为“生命的传教士”：

> 她始终挺身捍卫人的生命，即使她的话不受欢迎……她的微笑本身，就是对生命说“是”：一个喜悦的“是”，出于深刻的信仰与爱，也在苦难的熔炉中得到净化。每天清晨，她在基督十字架脚下，与玛利亚联合，重新说出这个“是”。被钉十字架的耶稣所感到的“渴”，成为德兰修女自己的渴望，也成为她走向圣洁之路的动力。

教皇最后宣称，德兰修女“真正是一位母亲”：“是穷人的母亲，也是孩子们的母亲。她也是许多女孩与年轻人的母亲；他们以她为精神导师，参与她的使命。”[^p620-3]

迈克尔·沃尔什说，若望保禄“不断谈论圣人，以及他们在西方文明的建立与保存中所起的作用。在他眼中，也在许多人心目中，圣人是基督徒生活的典范；教会通过正式的宣福、封圣程序，把他们摆在信众面前，供人效法”。[^p620-4]德兰修女去世仅六年，便获宣福。可以推想，教皇把她视为最高的女性榜样：她是修女，却也是母亲；她苦修，却又充分投入一座大城市的生活；她性情温暖、充满爱，也捍卫传统天主教教义，尤其关于避孕与堕胎的教导，若望保禄在讲话中曾间接提及这两项。她于1910年在斯科普里出生，父母为阿尔巴尼亚人，原名阿格尼丝·博亚丘（Agnes Bojaxhiu）。尽管教皇称她为“朴实的妇女”，她的父母却生活宽裕，并给她良好教育。她一生大部分时间在印度度过，起初在洛雷托修女会经营的学校教书。1950年，她创立仁爱传教修女会，专门服务加尔各答穷人中最孤立、最匮乏的人：最初为贫民窟儿童提供学校教育，后来照顾濒死的乞丐、麻风病人及孤儿。一些印度教徒认为，这些工作是劝诱改宗的一种形式，曾加以反对。她克服这种反对之后，首先得到当地<a id="pdf-621"></a><!-- PDF page 621; original page 620 -->报纸的肯定，继而得到印度政府、教皇保禄六世的肯定，最后得到西方媒体关注，成为国际名人。

许多被梵蒂冈选为榜样的人，在广大天主教徒中，只得到有限认可；德兰修女却并非如此。她在世时，就被广泛视为活圣人，去世之后仍继续受到爱戴与崇敬。2004年7月，互联网约有240,000处提到她。这远不能与耶稣基督的390万处、乔治·W.布什的220万处，或披头士乐队的180万处相比；不过，她大致与卡尔·马克思、阿道夫·希特勒相当，又遥遥领先于她取修会名时所效法的里修圣德兰。一家美国天主教网站，设有“读者讲述德兰修女如何启发自己”的栏目。其中既有治愈疾病的奇迹故事，也有考试成功的故事；但主要强调的，还是她的谦卑、自我牺牲与怜悯。一名读者写道：“德兰修女以怜悯与关怀爱所有人，按他们本来的样子爱他们；圣人与罪人都一样。”[^p621-5]

德兰修女或许将在历史上，被记为第一位靠电视而享有世界声誉的天主教圣人，尤其归功于马尔科姆·马格里奇1969年为英国广播公司制作的纪录片《为天主作美事》（Something beautiful for God）。然而，她所体现的圣洁方式，与许多19世纪、甚至18世纪圣人，并无多大不同。歌手鲍勃·盖尔多夫有一句很能说明问题的评论：他曾想亲吻她，后来才明白，她只允许麻风病人吻她。[^p621-6]同样是一部英国纪录片——克里斯托弗·希钦斯的《地狱天使》（1994）——最有力地宣传了德兰修女批评者的看法；这也显示，英国电视对宗教的处理方式已经改变。指控集中在三点：她反对避孕与堕胎所造成的有害后果，远远超过她所做的任何好事；她所办机构的医疗照护水准，往往很差；她在争取有权势的赞助者时，为残暴独裁者与腐败商人增添了体面。第一点并不甚成立：德兰修女是一名保守天主教徒，一生忠于自己1920年代成长时所受的信仰教育，并认为忠实的天主教徒，必须接受教会全部教导，不能任意挑选。人们可以反对保守天主教立场，但若以为一名保守天主教徒能够、或应当另作他想，就未免天真。其余批评则更有<a id="pdf-622"></a><!-- PDF page 622; original page 621 -->根据。不过，希钦斯所谴责的做法，既可视为她的修会历史所造成的结果，也反映了她那极为传统的天主教信仰。仁爱传教修女会从一无所有，发展为世界性组织，依靠的是一心一意、无论何处都争取赞助者的做法，而不追问政治问题。在这一点上，她们遵循了天主教慈善工作中由来已久的传统；直到1960年代以后，这些传统才开始广受批评。

若望保禄二世不仅是德兰修女的朋友，也敬仰20世纪最广受欢迎的男性“活圣人”。2002年获封圣的比约神父（Padre Pio），同样遵循传统模式。事实上，与他相比，德兰修女的神奇能力就显得相当平淡了。他于1887年出生于意大利南部的一个贫穷家庭，成为嘉布遣会修士，1918年身现圣痕。人们主要因为他能行奇迹而尊崇他；据称，他能同时现身两地，也能凌空悬浮，此外还作为听告解神父享有盛名。人们说，他能预见未来，曾蒙赐天堂异象，还曾在第二次世界大战期间，以奇迹阻止美军轰炸其修道院。圣人的画像，也被认为具有神奇效力。1990年代，据称每年有一百万朝圣者，前往他生活与去世的修道院。[^p622-7]

天主教会有正式的宣福与封圣程序。若望保禄二世简化了这些程序；这位经常旅行的教皇，访问一个新国家时，喜欢宣布该国某位儿子或女儿获宣福。他在教皇任期最初11年中所作的宣福，数量超过20世纪7位前任教皇的总和。[^p622-8]当然，政治考虑对于哪些候选人能够达到目标，起着重要作用。例如，宣福与封圣反映梵蒂冈对某个民族或族群的认可，也常用来传达与当代现实相关的历史立场。伍德沃德详细讨论的一个突出例子，是第二届梵蒂冈大公会议后期，“进步派”主教试图以共同欢呼的方式，直接将若望二十三世封圣；“保守派”则反称，庇护十二世更有资格。保禄六世决定，两项申请都应调查，但应遵循正常程序。[^p622-9]正式取得圣人地位的人，大多是神父或修女。除殉道者之外，平信徒圣人并不多见；<a id="pdf-623"></a><!-- PDF page 623; original page 622 -->已婚圣人尤其罕见，正如伍德沃德围绕“圣洁与性”的讨论所显示的。[^p623-10]

当然，也有许多人未被认定为圣人，却仍被树立为其他平信徒的榜样；稍后我会再谈一些例子。新教教会没有认定圣人的程序，圣人在新教生活中的作用，也远小于天主教或东正教。不过，新教当然拥有自己的信仰英雄。他们提供杰出的范例，显示在某个时代、某个地方，作一名基督徒意味着什么。

新教的理想变化得比天主教更快。然而，在相当长的一段时期，即19世纪后期到约1960年间，最广受认可的新教基督徒理想形象，是传教士。新教主日学用传教士的英雄故事吸引学生，并把著名传教士的传记，奖给出席最勤、或知识最丰富的学生。电影甚至也赞颂传教士，例如《六福客栈》（1958）；直到1960年代，对基督教传教事业较具批判性的看法，才开始成为通行观念。

这部电影根据艾伟德（Gladys Aylward，1902—1970）的生平改编。她出身伦敦工人阶级，因教育程度不足，被中国内地会拒绝；但仍自行前往中国，于1932年对日战争期间抵达。她加入一位年长女传教士的工作，后者在偏远山区经营一间客栈。客栈既是传福音的基地，也用来收容孤儿。按照英国《主日学纪事报》的说法，她在那里的壮举，成为“我们这个时代，基督徒虔诚奉献与英雄主义最惊人的故事之一”。她最光辉的时刻，是带领一百名孤儿“翻山越河”，抵达一个尚未被日军占领的省份，得到安全庇护。她反对女童缠足的行动，对于确立她作为基督徒女英雄的声誉，也同样重要。[^p623-11]

英格丽·褒曼在银幕上扮演艾伟德时，她仍健在；她与德兰修女、比约神父一样，都可被称为“活圣人”。的确，她可称为那个时代典型的新教圣人。艾伟德传奇最突出的重点，是孤独的个人蒙上帝呼召，去从事特殊工作，并在压倒性的困难面前，坚持自己的天职；这些困难甚至包括强大宗教权威的反对。在这一点上，她的<a id="pdf-624"></a><!-- PDF page 624; original page 623 -->故事与德兰修女有许多共同之处。更具新教特色的，则是浓厚的冒险因素：人们期待新教圣人是有所行动的男女；对艾伟德而言，这还包括遭到日军枪击。此外，还有她反对缠足的工作。20世纪早期，新教传教士虽然分为优先强调社会福音者，以及优先强调个人归信者，但即使后者也相信，社会改革是基督教信息的一部分，基督教会带来一个更人道、也让妇女得到更好待遇的社会。

1960年代，人们对传教士的态度发生变化，甚至有人呼吁暂缓传教。随着欧洲大部分殖民帝国终结，基督教内部舆论对传教与殖民主义之间的联系，也愈来愈持批评态度。非基督教或反基督教舆论的声音同样变得更强，常把传教谴责为一种文化侵略。自由派基督徒十分愿意接受这些论点，保守福音派却大体拒绝；结果，新教传教事业愈来愈由后者主导。他们接受了对殖民主义的许多批评，也承认非洲与亚洲基督徒有权管理自己的教会，并使敬拜形式适应当地文化。然而，他们不能接受任何削弱“大使命”迫切性的主张。自由派致力于社会改善，福音派关心使人归信；这种旧有分歧，在1960年代及其后进一步加深，也不可避免地反映在不同的榜样选择上。

20世纪下半叶，最广受敬仰的新教英雄，或许是小马丁·路德·金（1929—1968）。对于大多数自由派及许多福音派而言，民权运动是20世纪基督教圣战的最高典范；它所使用的基督教武器，是非暴力抵抗。金的演说鼓舞人心，反复运用圣经语言与母题，被视为把《圣经》应用于当代政治的杰出例子。他是美国的摩西；正如他在遇刺前夕的最后一次演讲中所说，他已经登上山顶，却不能进入应许之地。他的死至今仍有谜团，也确立了他的殉道者地位。金的自由派神学，与艾伟德的神学大不相同；但他同她一样，相信自己蒙受神圣呼召。1956年，蒙哥马利抵制公交车运动期间，他受到死亡威胁之后，上帝对他说：“马丁·路德，起来捍卫公义，起来捍卫正义，起来捍卫真理。

看哪，我必与你同在，直到世界的末了。”[^p625-12]金的传奇中，一个耐人寻味之处，是人们试图根据他的性行为败坏其声誉，却几乎没有产生影响。新教徒高度重视家庭，不认为独身本身有什么功德，却期待婚姻中的忠贞。狂热反共的联邦调查局局长J.埃德加·胡佛，相信金是共产党员，或至少受到共产主义影响。因此，联邦调查局在金开展运动期间所住的旅馆房间安装窃听器，希望找到足以败坏他名声的证据。监听并未证明金是共产党员，却证实他有通奸行为。然而，利用这些证据攻击他的企图，在当时就失败了；1968年他英年早逝之后，这些证据也几乎没有损害其英雄声誉。

殉道者在很大程度上，能够免于那些追随多数显赫人物的猜疑与指控。因此，20世纪另一位最有资格获得新教圣人地位的人，是迪特里希·朋霍费尔，也就不足为奇。他于1945年被纳粹杀害；不过，其声望是在《抵抗与顺服》（Widerstand und Ergebung）出版之后，才迅速上升。这部书于1953年以《狱中书简》（Letters and papers from prison）之名译成英文。金与朋霍费尔代表一种日益扩大的趋势：把那些为反抗暴政、或压迫性的社会制度而献出生命的人，奉为最高的基督徒英雄。他们不仅可以被看作信仰事业的殉道者，也可以被看作为全人类事业殉道的人。[^p625-13]

有些新教徒认为，金与朋霍费尔太过政治化，或者神学上不够保守；对于他们，最受欢迎的英雄，很可能是美国布道家葛培理（1918年生）。不过，即便葛培理，在某些美国基要主义者看来，仍然过于自由派。1949年的洛杉矶布道大会，使葛培理成为美国最著名的奋兴布道家。他与哈里·杜鲁门的接触，起初出师不利；随后与艾森豪威尔建立融洽关系。此后多年，与葛培理保持友好关系，被认为是美国总统或总统候选人不可缺少的一环。他于1954、1955年在伦敦和格拉斯哥举行的布道大会，使他成为国际明星；到1960、1970年代，他能在德国与韩国吸引庞大听众；到1980年代，他甚至在莫斯科讲道。除了布道技巧，以及成功避开那些困扰许多大众布道家的丑闻之外，他独特的人气还有另外三个<a id="pdf-626"></a><!-- PDF page 626; original page 625 -->方面值得注意。首先，他的个人形象，是吸引力的重要组成部分：人们认为他温暖、轻松而友善，是一个可以愉快地陪你打一轮高尔夫球的人。事实上，葛培理十分热爱高尔夫；他甚至是在佛罗里达一座球场的第18洞果岭上，感受到作传道人的呼召。其次，他善于在神学的钢索上保持平衡。他的神学一直足够保守，能保持大多数福音派同道的尊重；但与此同时，他表达信息的方式，随年岁而趋于温和，也包含足够多普遍能被接受的套话，使总统与一般美国公众都感到有吸引力。第三，他显示出很强的适应能力。他承认，传讲救恩信息虽是压倒一切的需要，也必须与愿意聆听新思想、尝试新方法的态度结合。他的根源在“圣经地带”的基要主义，早期的许多言论，与较近时期“电视布道家”的言论并无多大差别。第一个重大转折点，是1957年的纽约布道大会：他声明，愿意与任何愿和他合作的教会共事，包括一些在他朋友看来，自由派到无可救药的教会；他还邀请马丁·路德·金，在一次大会上发言。其实，早在1954年，他就已坚持只向不实行种族隔离的听众讲道。1980年代，他开始谈论生态问题、取消第三世界债务、裁军，以及在穷人很少得到充分律师协助的情况下，继续保留死刑的危险。[^p626-14]《时代》杂志把葛培理列入20世纪一百位“英雄与偶像”，主要是因为他象征着美国人乐于想象的美国，也因为他有能力为总统和战争赋予正当性。[^p626-15]

## 政治家、战士、和平缔造者、商人……

如同其他世纪，圣人与殉道者在20世纪也是最高的基督徒英雄；不过，基督徒还有许多其他榜样可以选择。其中包括基督徒政治家、战士、和平缔造者、商人、慈善家等早已确立的类型，也包括更具20世纪特色的人物，例如基督徒运动员与演艺人员。还有一些更有争议的人物：如同19世纪一样，民族主义英雄也在其中，例如<a id="pdf-627"></a><!-- PDF page 627; original page 626 -->克罗地亚的斯捷皮纳茨大主教。他们象征本民族的事业，却被敌对的邻人痛斥。

自称基督徒政治家，或者被追随者如此看待的人，持有极为不同的政治立场；其中有些人声称拥有这一称号，几乎所有其他人却都会拒绝承认。在这里，应当区分两类人：一类是许多虔诚的基督徒政治家，他们没有为选举目的利用自己的宗教；另一类则把宗教塑造成公共形象的必要部分，试图吸引上教堂的选民。1920、1930年代，斯坦利·鲍德温、蒋介石、阿道夫·希特勒等差异极大的政治家，都刻意培育虔敬的形象。1940、1950、1960年代，欧洲许多最有权势的政治家，例如康拉德·阿登纳、阿尔契德·德·加斯佩里、罗贝尔·舒曼与夏尔·戴高乐，都以实际践行天主教信仰著称；西班牙和葡萄牙的独裁者佛朗哥与萨拉查，也同样如此。1980年代，罗纳德·里根竞选获胜的一个关键因素，是他对保守新教徒的强大吸引力。

希特勒使用宗教语言，偶尔参加教会礼拜，尤其在1932至1934年间；通常，人们把这视为一种玩世不恭的机会主义。他当时尚未掌权，或尚未完全控制局面，因此需要争取各教会支持。这在我看来，仍是对其动机最好的解释，尽管理查德·施泰格曼—加尔在较近的一部著作中，认为他的宗教虔诚是真诚的。[^p627-16]然而，可以确定的是，他说服了许多新教徒，也在较小程度上说服了天主教徒。一厢情愿的想象，在这里无疑起了作用。如同多数政治运动，许多人渴望相信，自己的领袖是真诚的，而且与自己抱持同样的信念。后来成为认信教会领袖、又成为集中营囚犯的马丁·尼莫勒，在1933年宣称：“如今领导德国的，是基督徒，而非国际无神论者。”1933年4月20日，一名柏林牧师在纪念希特勒生日的礼拜中，称他为“在我们身心最深困顿之时，上帝差给我们的领袖”，并声称，他不仅是“演说家”，也是“传道人”与“唤醒良知的人”。一名后来醒悟的前追随者，则生动地描摹了希特勒如何赢得许多基督徒的信任：

> 他毫不拘束地使用基督教词汇，谈全能者的祝福，谈各基督教教派如何成为新国家的支柱。他敲响钟声，拉开风琴的全部音栓，把声势做足。他摆出一副极为严肃的神情，仿佛历史责任已沉重得令他不堪负荷。他向新闻界，尤其教会报刊，提供虔敬的故事。例如，报上说，他曾向几位女执事展示自己破旧的《圣经》，宣称从上帝的话语中，汲取完成其伟大事业的力量。他能够让自己的嗓音带上一种虔敬主义的音色，使许多宗教人士欢迎他，把他当成上帝差来的人。[^p628-17]

在两次世界大战之间、政治环境极不相同的英国，保守党领袖斯坦利·鲍德温，也曾刻意争取教会支持，而且相当成功。他于1923至1924年、1924至1929年及1935至1937年，三度任首相。虽然是圣公会徒，他的家庭也与卫理宗有联系；他强调这些非国教派根源，以争取那些过去支持自由党、正在寻找新政治归宿的选民。1924年鲍德温大获全胜，据说，这也是第一次有大量非国教派选民投票支持保守党。他所呈现的基督徒政治家形象，一部分建立在诚实、可靠、直率的印象之上，烟斗正是这种形象的象征。按党内一条口号，他是“你可以信赖的人”。1920年代，他的基督教政治着重阶级和解，反对他所称工党的对抗性政治，也反对同党中一些更激烈反工会的保守派同僚。1930年代，他的主要主题则是捍卫民主、个人自由与基督教文明，反对共产主义和法西斯主义的极权。[^p628-18]

1920、1930年代的“基督徒政治家”，大多属于右翼。除英语世界外，社会主义、甚至自由主义政治，仍往往倾向反教权，甚至世俗主义；不过，瑞典有“基督教社会民主主义者”，德国与瑞士有“宗教社会主义者”。在英国，工党运动中最受敬仰、1915年去世的凯尔·哈迪，是一名基督教社会主义者。两次世界大战之间的重要人物，也延续了这一传统，例如<a id="pdf-629"></a><!-- PDF page 629; original page 628 -->1929至1931年任外交大臣的阿瑟·亨德森，以及1931至1935年任工党领袖的乔治·兰斯伯里。克莱门特·艾德礼曾把兰斯伯里比作甘地，历史学家A.J.P.泰勒则称他为“现代政治中最可爱的人物”。在众多崇拜者与批评者眼中，他都具有基督教社会主义圣人的地位。批评者认为，他太像圣人，因而不能成为有效的政治家。1935年党代表大会上，工会领袖欧内斯特·贝文对兰斯伯里和平主义的那次著名攻击，主要意思就在这里；它促使兰斯伯里辞职。据说，贝文评论道：“兰斯伯里穿着圣人的衣裳，等着殉道，已经很多年了。我做的，不过是把柴堆点着。”政治中的圣人，不大可能得到普遍敬仰；但兰斯伯里十分受欢迎，因为他被视为罕见地诚实、正直的政治家。他住在伦敦东区，与选民生活在一起。1920年代，任贫困的波普勒区区长时，他与其他区议员，因拒绝缴纳法律要求的款项而入狱；他认为，波普勒居民无力负担这些款项。一位传记作者评论道：“他不追求个人财富或社会地位。最重要的是，无论公共生活还是私人生活，他都实践基督教原则；这些原则激发了他的社会主义、和平主义、国际主义，以及对妇女权利的支持。对社会正义奔放的热情，对民主不可动摇的信念，支撑着兰斯伯里一生在地方政府与全国舞台上的公共服务。”[^p629-19]

“基督徒政治家”难免会作出一些决定，让崇拜者失望，甚至震惊。因此，最受敬仰的政治人物，常常是那些从未获得、或者从未追求政治权力的运动推动者。现代社会运动的原型，是起源于18世纪后期的废除奴隶贸易运动。19世纪又带来更多类似的人道主义运动，往往由基督徒领导，并大量运用圣经论据。20世纪，圣经论据较少处于前台；但基督徒继续在多种运动中发挥突出作用，包括争取和平、种族正义，帮助难民与政治犯，以及减轻饥饿，等等。职业活动家的生活，大起大落，也可能与国家、甚至教会发生紧张关系。许多受基督教信仰激发的活动家，都因得不到教会<a id="pdf-630"></a><!-- PDF page 630; original page 629 -->高层支持而失望。小马丁·路德·金去世以后，成为20世纪最受敬仰的基督教运动领袖；他也有过这种挫折。例如，他著名的《伯明翰监狱来信》，就是受到该城许多白人神职人员的批评所激发。金最主要的力量基础，始终在黑人教会；他也从北方白人教会得到极为重要的支持。不过，还有一些基督徒活动家，与所属教会的关系紧张到无法忍受。达尼洛·多尔奇是一个突出例子。从1950年代开始，他在贫穷的西西里岛西部村庄改善生活条件，挑战黑手党的权势；这些工作受其基督教信仰激发，最终却因为未能得到支持，而使他与天主教会决裂。

战士与和平缔造者，在基督教历史中都有自己的位置。20世纪的血腥冲突几乎从未中断，自然也不乏这两种人物；基督徒战士在生前，不可避免地获得更多赞誉，和平缔造者则在去世之后，更温暖地受到追念。第一次世界大战英军总司令，道格拉斯·黑格爵士元帅，就是一个例子。他在苏格兰长老宗传统中长大，却不抱宗派偏见。他坚定相信，在对抗普鲁士军国主义这一邪恶的战斗中，自己是上帝的代理人。他经常寻求上帝与随军牧师的指引；后者也是他最亲密的知己。他极其重视随军牧师在英国军队中的作用。自1928年去世之后，黑格的领导，包括其对神圣指引的依赖，受到严厉批评；但在战争期间及刚刚结束时，他却是民族英雄，在许多人眼中，也是一名模范基督徒。[^p630-20]

基督徒也在多种和平缔造工作中表现突出。取得象征性地位的人物，包括以非暴力方式抵抗压迫政府或社会制度者，例如同获诺贝尔和平奖的马丁·路德·金与德斯蒙德·图图；努力减轻战争残酷、在战后促成和解者，例如奇切斯特圣公会主教乔治·贝尔，他在第二次世界大战期间谴责对德国城市的饱和轰炸，战争中与德国抵抗运动人士建立联系，战后又与德国教会维持密切关系；也包括拒绝战争者，例如奥地利天主教农民弗朗茨·耶格施泰特，他被纳粹处决，是因为<a id="pdf-631"></a><!-- PDF page 631; original page 630 -->拒绝作战；又如越南战争期间入狱的贝里根兄弟。此外，还有担任调解者的人，例如2002年诺贝尔和平奖得主吉米·卡特。他也是近些年来唯一一位宗教真诚性无人怀疑的美国总统。亨德里克·赫茨伯格在一篇网络文章中评论道：“在当基督徒还没成为时髦之前，卡特就是基督徒了。”

卡特自1980年竞选落败、离开总统职位以后，便投身多种人道主义与和平事业。赫茨伯格接着说，卡特的领导风格，“从本质上看，无论过去还是现在，宗教性都强于政治性”，并宣称：“吉米·卡特是个圣人。”他随后的解释，很好地说明了，为什么卡特有资格被视为一位具有鲜明新教特色、属于20世纪后期的圣人。论点的核心，是卡特是个行动者。他对和平、民主或减轻贫困，“并不只是说说”，而是冒险，以“坚持不懈”与“顽强”，使它们成为现实。这种新教式圣人观还有一个特点：赫茨伯格在呼吁将卡特“封圣”时，并未声称自己的候选人完美无缺。他承认，卡特有“自以为是”的毛病，讲话常常过长，有时还涉及不合宜的话题。[^p631-21]

基督徒商人，是19世纪的典型人物。到了20世纪，这种形象较少见，既因为商业的变化，也因为基督教的变化。像“伟大慈善家”泰特斯·索尔特爵士这样的人，在布拉德福德附近建起模范村索尔泰尔，通常掌管家族企业。在其中，他们有很大自由，可以把追求利润，与实现自己的宗教或政治愿景结合起来。他们许多人白手起家，常被奉为模范基督徒，既因为积累财富时所表现的精力、进取心与自律，也因为财富被用于善事。随着由职业经理人管理的大型有限责任公司，日益占据主导，这类仁慈倡议的空间便受到限制。赞颂成功商人，原本是新教的特长。例如，一位卫斯理宗牧师，就为索尔特写了一部热情洋溢的传记，相当明确地把他树立为青年男子的榜样。另一方面，从19世纪后期开始，社会福音的影响日益扩大，也使新教传道人对表面慷慨的商业巨头更加怀疑，更倾向于透过其<a id="pdf-632"></a><!-- PDF page 632; original page 631 -->雇员的眼睛看待他们。莱因霍尔德·尼布尔前往纽约协和神学院任教授之前，曾在1920年代于底特律担任牧师。他对亨利·福特自命仁慈的姿态，极为尖刻；主要的批评是，无论福特做过多少好事，他仍是一个独裁者。同样的批评，无疑也可以用于19世纪工业界的许多英雄。

戴维·杰里米对20世纪英国商业与宗教联系的研究显示，在知名商人中，已知曾以某种程度参与宗教生活者的比例，从1907年的50%，降到1955年的36%；同期，商人在教会平信徒领导层中的比重，也有所减少。整个时期，始终有一些商人是杰出、投入极深的基督徒；但很少有人像上一个世纪的许多前辈那样，被视为榜样。杰里米研究了1932至2000年间担任卫理公会大会副主席的男女平信徒，发现1950年之前商人占压倒性多数，之后则由各类专业人士占主导。一个有趣的发现，是获得这一殊荣的商人，往往相对不知名，却以地方传道人的身份享有声誉；他们比知名巨头，例如极富有的兰克家族成员，更容易被选中。[^p632-22]

另一方面，娱乐业的巨大增长，体现在电影、电视与职业体育之中，也带来新型的基督徒榜样。基督徒运动员，起源于19世纪后期英国与美国的“肌肉基督教”。他是业余运动员，往往还是学生；代表“公平竞赛”与“团队精神”等价值。为了获胜，他会表现出充分的“勇气”与“坚忍”，但也“输得起”。体育是完整人生的一部分，而且确实是重要的一部分，因为上帝不只给人心智与灵魂，也给人身体。然而，体育毕竟只是人生的一部分，不应优先于其他更重要的事物。[^p632-23]到20世纪早期，这些理想大多受到威胁。对那些在最受欢迎的运动中占据主导影响力的<a id="pdf-633"></a><!-- PDF page 633; original page 632 -->职业运动员而言，它们似乎没有多大意义。此外，竞争在各个层次的体育中，都发挥愈来愈大的作用；体育也愈来愈成为个人运动员、社区及国家赢得声望的来源。较早的基督徒体育英雄之一，是1880年代的英格兰板球运动员C.T.施达德（C. T. Studd）。他很早便放弃运动生涯，到中国作传教士；晚年甚至后悔，自己曾把那么多时间，花在板球这样不重要的事情上。

把施达德与英国三级跳远运动员乔纳森·爱德华兹相比，可以看出20世纪人们对体育及其意义的看法，改变了多少。爱德华兹于1995年打破世界纪录，2000年获得奥运冠军。他的保守福音派神学，与施达德相去不远；他也像施达德一样，感到自己蒙召作传福音的人。不过，他回应这一呼召的方式，却很不相同。其传记作者说：“他始终把自己的运动才能，理解为上帝的恩赐……与多数运动员不同，积累财富与名声，从来不是爱德华兹从事体育的首要动机……他觉得自己是在回应作传福音者的呼召，是一个穿着钉鞋、为上帝作见证的人。”沿着这种天职观念的逻辑，他作出运动生涯中最有争议的决定之一。他长久拒绝在星期日参赛，1992年却取消了这一限制，因为意识到许多重大赛事都在那天举行，自己因此被排除在顶尖行列之外。他不可避免地受到福音派同道的背教指控，也被宗教怀疑者斥为虚伪。但他为这一决定辩护，称它不仅出于对《圣经》的新理解，也因为上帝通过同一教会某位成员所作的梦，向他传达了信息。爱德华兹相信，上帝密切关心他的运动生涯，并通过成功与失败向他说话。当一次伤病以出乎意料的速度康复时，他确实把它看作神迹，而非仅仅一种比喻。[^p633-24]

爱德华兹被树立为年轻基督徒的榜样；另一些运动员或球队，则被实实在在地视为基督教的斗士，代表自己的宗教参赛。苏格兰两支最主要的足球队，格拉斯哥流浪者与格拉斯哥凯尔特人，在其历史的大部分时期，分别具有新教与天主教身份；足球也成为该国宗派敌对的主要焦点。

天主教徒长期被排除在流浪者队之外，不能为其效力。凯尔特人偶尔聘用新教球员，但与天主教会的联系尤其密切。俱乐部由一名圣母小昆仲会修士创办，凯尔特公园球场曾用于举行露天弥撒。1930年代，球员与管理人员前往卢尔德朝圣；在早年，每当取得重大胜利，还会发电报通知教皇。[^p634-25]

作为天主教代表的个人体育斗士中，最著名的是有“虔诚者”之称的吉诺·巴尔塔利。他是1930、1940年代杰出的意大利自行车手；主要对手福斯托·科皮同情共产主义，使他的胜利更添特殊意味。在天主教与共产主义冲突最激烈时，庇护十二世赞扬巴尔塔利，称他是坚定天主教信仰的榜样。1948年环法自行车赛期间，在比赛的关键时刻，意大利总理阿尔契德·德·加斯佩里给他打来电话；据说，总理提醒这位天主教车手，这场比赛具有政治和宗教意义。之后，他取得环法胜利。天主教报刊把巴尔塔利塑造成模范家庭男子；当科皮卷入一场广为报道的婚外情时，这种反差更显鲜明。[^p634-26]

现代体育的许多方面，使寻找基督徒榜样十分困难；在电影、电视与通俗音乐世界中，寻找这种榜样则更难。不过，正因为这些领域对20世纪生活的影响如此巨大——首先在美国，继而愈来愈扩展到全世界——寻找榜样也更加迫切。有些、也许许多歌手与演员，以自己的方式具有深厚宗教信仰，却很难成为榜样。埃尔维斯·普雷斯利就是一例。直到1950年代，人们一般仍期待娱乐界明星，无论私下的信仰或行为如何，都应对本国宗教保持尊重；但其中很少有人，可以被用来作为虔敬的典范。1960年代，一种更加公开叛逆的艺人风格出现了。约翰·列侬宣称，披头士“比耶稣基督更受欢迎”，又在歌曲《想象》中呼吁无神论与无政府状态，就是一个例子。相形之下，克里夫·理查德、帕特·布恩等基督徒身份最明确的艺人，所呈现的公共形象，是讨人喜欢、正派诚实，却也平淡寡味。基督徒艺人，或许更容易在1940、1950年代获得发展。最好的例子，也许是宾·克罗斯比。他是一位享誉世界的歌手、<a id="pdf-635"></a><!-- PDF page 635; original page 634 -->广受欢迎的电影演员，也是一名忠实的天主教徒。1944年歌舞片《与我同行》中，他饰演纽约贫民窟里轻松、迷人的查克·奥马利神父；这一角色不仅为他赢得奥斯卡奖，也带来一次教皇庇护十二世的私人接见。

## 结论

最后，应当注意一个显著的缺席：20世纪的基督徒榜样中，作家与其他知识分子相对稀少。这不是因为教会当局不感兴趣。尤其庇护十二世认为，身为教皇，必须了解科学、技术与艺术的最新发展。他经常向各类大会发表讲话，并主持接待各种知识分子的活动。也不能说，基督徒知识分子很少，甚至不能说，知识界中的基督徒，比其他社会群体中更少。很可能在大多数时期，坚定信教者与坚定不信教者，在知识分子中所占比例，都高于一般人群。1993至1994年，法国近代早期史名家让·德吕莫，就能集结一支实力雄厚、同时具有基督徒身份的历史学家队伍，请他们撰写宗教信仰与历史研究实践之间的关系。[^p635-27]毫无疑问，在许多其他学术领域，也同样可以做到这一点。受到认可的榜样之所以稀少，一部分是因为，重视独立性与正直品格的作家和艺术家，不愿被征用来协助别人的计划。1930、1940年代最伟大的英国小说家格雷厄姆·格林，就反对被称为“天主教小说家”，表示自己是“一个恰好是天主教徒的小说家”。

不过，在20世纪的大部分时期，思想与艺术创作世界中，最受瞩目的人物，确实往往不是基督徒，甚至反对基督教。这种情况也随时间而有所变化。例如，阿德里安·黑斯廷斯在关于20世纪英格兰基督教的历史著作中，把约1935至1960年视为基督徒文化英雄最丰富的时期，与世纪早期及较晚的年代，形成鲜明对照。他指出，这一中间时期，艾略特、格林、沃等诗人与小说家，汤因比、巴特菲尔德等历史学家，都广受欢迎；尤其受到欢迎的，还有<a id="pdf-636"></a><!-- PDF page 636; original page 635 -->C.S.路易斯的基督教护教著作。第二次世界大战期间，宗教广播的数量剧增，路易斯在其中发挥重要作用。黑斯廷斯也指出，威廉·坦普尔不仅作为知识分子、社会改革者，也作为普世合一领袖，享有独特声望。他先后任约克大主教与坎特伯雷大主教时，发挥了广泛影响；其后继者无人可比，前任中也极少有人能够相比。[^p636-28]这一名单还可以加上剑桥大学天文学教授阿瑟·爱丁顿爵士。他既是杰出的研究科学家，也擅长向公众普及知识；在1920、1930年代英国所起的作用，与理查德·道金斯在1980、1990年代的作用，有些类似。区别在于，爱丁顿是贵格会徒，致力于阐明科学与宗教之间的积极关系。肖尔维与伊莱尔，为法国提出了类似的年代划分。伊莱尔把1930年代称为“基督教思想与文学的黄金时代”；其中杰出者，包括哲学家马里坦、诗人克洛岱尔，以及小说家莫里亚克、贝尔纳诺斯等广为人知、备受敬仰的人物。[^p636-29]

1960年代以来，西方基督教危机中一个重要、却迄今几乎未被探索的面向，是这类基督徒文化英雄的数量日渐减少。1960年之后，基督徒作家、艺术家与知识分子对大众的影响，在波兰、苏联等国家最为强大；在那里，基督教与持不同政见联系在一起。
