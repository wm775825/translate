# 第八章 第一次世界大战

**迈克尔·斯内普**

> 原书第131—150页；对应原PDF第150—169页。

## 导言

尽管第一次世界大战是一件影响巨大的全球事件，天主教与新教历史学家却未能给予它充分研究。虽然已有大量著作讨论教会参与战争的情况，它们往往局限于相对狭窄的国家或宗派视角。这一倾向妨碍了对相互关联的主题的辨识，也掩盖了战争对整个西方基督教的广泛影响。

这些研究的覆盖面并不均衡。例如，关于英国及其自治领教会的著述很多，涉及奥匈帝国天主教徒与新教徒的研究却很少。同时，研究往往沿着相当僵化、容易预料的路径展开。以法国战争经历为例，直到最近，教会历史学家的精力才从考察全国“神圣团结”的神话与实际，转向战争对法国人宗教习惯和信仰的影响。至于德国和英语世界有关教会与战争的历史研究，连这样有限的进展都尚未出现。在德国，学术兴趣主要集中于新教教牧人员的“战争讲道”与“战争神学”。这种关注，既受到第二次世界大战引发的负罪感影响，也来自一种历史追问：试图在威廉时代德国的精神与文化中，寻找第三帝国的起源。

类似地，英国和美国关于战争年代基督教的历史研究，也过度集中于教会及其领导层，并深受两次世界大战之间和冷战时代和平主义的影响。在德国、英国与美国，教会的战时态度与活动，都成了<a id="pdf-151"></a><!-- PDF page 151; original page 132 -->大量严厉而自以为是的批评的对象。例如，按照J. A. 摩西的说法，1914年欧洲交战列强的属灵领袖，并非由于各自的历史与处境而选择支持世俗政权；他们和这些社会的其他领袖一样，“全都屈服于粗俗民族主义的陶醉，如格拉森的猪群一般，冲进第一次世界大战的末日灾难”。[^p151-1]

这种倾向虽然为道德训诫与相互指责提供了充分空间，却严重妨碍我们理解教会在第一次世界大战中的作用。它尤其掩盖了一个根本事实：教会是依据十九世纪的经验与观念，来理解战争及自身在战争中的角色，而不是依据二十世纪后续几十年更为谦抑的精神。因此，德国新教教牧人员容易把战争看作上帝引导的德意志民族对抗外国对手的斗争的最后阶段。这场斗争始于一个世纪前反抗拿破仑的解放战争，并于1871年通过战胜法国和国家统一，取得了不稳固的胜利。同样，许多法国天主教教牧人员把战争理解为上帝对第三共和国公开奉行世俗主义精神的审判，也是上天赐予的机会，使教会重新在法国社会中取得核心地位并界定其性质。此外，交战国的主要教会最初几乎普遍期待，战争的理想主义与忧虑将带来灵魂的大丰收，并成为抵御现代世俗化倾向的有力解药。随着1914年最初的乐观消退，这种期待固然有所减弱，但当战争加剧时，另一些更为复杂的预测似乎变得可信。例如，在英国与北美新教中，自由派神学及社会福音的流行，使战争被广泛解释为推进上帝之国在人间实现的手段。这个国度具有社会、经济与国际层面，要求在全球战争的烈火熔炉中，锻造一种新的团契与牺牲精神。

## 教会与战争

尽管十九世纪的历史与思想影响深远，欧洲<a id="pdf-152"></a><!-- PDF page 152; original page 133 -->国教会压倒性的支持战争态度，也有更加深厚的历史根源。德皇威廉二世兼任普鲁士国王和普鲁士教会首长，因此是德国新教最重要的教会权威来源。战争爆发时，他召唤臣民祷告，强调了这一地位。由于王座与祭坛之间的联盟依然牢固，新教教牧人员在德国新教诸邦又事实上具有公务员身份，他们证明自己无愧于1813年和1870至1871年先辈的继承人。他们充满好战情绪的战时讲道，以及对1917年“色当日”成立、激进支持战争的“德意志祖国党”的明显拥护，证实“没有哪个人口群体比德国新教教会更热烈地支持战争”。[^p152-2]在英国，乔治五世作为英格兰教会领袖，沿袭前任君主的悠久传统，宣布全国祈祷日。尽管英国内部教会与国家之间的实际距离，比国家强烈支配教会的德国新教环境稍大，英格兰和苏格兰的国教会仍几乎同样热心地支持战争。许多适龄教牧人员甚至不愿仅担任随军牧师，而是入伍成为医务勤务兵或战斗士兵。

与旧世界的族群和宗派纽带，使欧洲教会的立场成为影响美国及大英帝国自治领基督徒战争态度的重要因素。美国讲德语的路德宗信徒缺乏支持美国站在协约国一方参战的热情，这是可以理解的；德裔与爱尔兰裔天主教徒的支持也有限，尽管1917年耶稣受难日美国宣战后，天主教圣统迅速采取了爱国立场。几乎顺理成章地，对美国参战最强烈的基层支持，来自英语新教宗派，即圣公会、卫理宗、公理宗和长老宗。加拿大与澳大利亚的情况类似，宗派和族群因素也影响教会对战争的立场。与英国本土及美国一样，两地的天主教圣统总体支持战争。但加拿大法裔天主教徒和澳大利亚爱尔兰裔天主教徒，相较于英语新教徒，更不愿不惜一切手段<a id="pdf-153"></a><!-- PDF page 153; original page 134 -->争取胜利。1918年，天主教占多数的爱尔兰及其教牧人员成功抵制征兵制的实施，尽管这一抵制颇具争议；同年3月，法裔加拿大人反对征兵，在魁北克市引发了致人死亡的骚乱。征兵问题也暴露出澳大利亚深刻的族群与宗教分裂：在1916年10月与1917年12月的征兵公投中，主流新教教会力挺征兵，甚至赋予其神圣意义；而反对强制服役一方最有争议的倡导者，则是出生于爱尔兰的墨尔本天主教总主教丹尼尔·曼尼克斯。

在以新教为主的国家中，天主教少数群体的忠诚与投入，可能引发一些棘手问题；但多数天主教交战国的政府，也不能把天主教徒的忠诚视为理所当然。即使在天主教会与哈布斯堡王朝仍保持密切、相对友好关系的奥匈帝国，天主教徒对战争的支持也并非毫无保留。二元帝国的高级教牧人员往往坚守天主教会与哈布斯堡王朝的历史联盟，但波希米亚、斯洛文尼亚和克罗地亚的许多天主教教牧人员，深入参与民族主义运动；这些运动后来促成帝国于1918年秋战败解体。在法国与意大利，天主教徒和反教权人士数十年冲突留下的恶劣遗产，使罗马的“坏教友”所组成的反教权政府，不得不密切留意天主教舆论。“坏教友”是罗马法国学院院长杜谢纳蒙席一句令人难忘的形容。[^p153-3]法国战前社会激烈的宗教与政治分歧，著名地被纳入全国的“神圣团结”；战争爆发时，普恩加莱总统宣布这一团结已经到来。英勇的士兵神父数以千计地为祖国作战、牺牲，这一形象固然是有力的天主教宣传，但备受赞誉的“神圣团结”内部，合作与善意有着明显限度。一些天主教人士要求履行十七世纪的预言，公开将法国军队奉献于耶稣圣心；普恩加莱总统自然没有理会。许多反教权人士强烈不满教会从战争中获取精神资本。反教权报刊乐于传播关于教牧人员欺诈、装病逃避职责的传闻，并大肆利用教皇含混的立场，<a id="pdf-154"></a><!-- PDF page 154; original page 135 -->以及天主教讲道中的一种倾向：像普法战争灾难时期一样，把当前冲突描绘成对背弃信仰的法国民族的公正惩罚。

法国“神圣团结”的实际情况固然需要附加许多限定，意大利的局势却明显更差。梵蒂冈与意大利王国的关系仍受罗马问题困扰；在意大利于1915年5月参战之前的几个月里，主战派与梵蒂冈对奥匈帝国的态度又明显冲突。因此，当时的形势并不利于天主教会与意大利自由派统治集团表现和解。意大利宣战前几个月，一些较保守的民族主义者试图争取天主教徒支持干预战争，收效甚微；相当一部分天主教舆论，尤其意大利农民，整个战争期间都顽固坚持中立主义。许多意大利天主教徒对本国背信弃义、指挥失当的反奥匈与德国侵略战争明显缺乏热情，在这一点上，他们实际上与社会主义同胞同行。本笃十五世于1917年8月发表《和平照会》，数周后意大利军队便在卡波雷托溃败；这一时机，使反教权人士更确信早已有之的怀疑，即教会在破坏而非支持意大利的战争努力。尽管存在这些指控，只有在卡波雷托及随后德国、奥匈军队推进之后，意大利才出现较强的民族凝聚感，天主教徒才普遍对一项此前鲜有人拥护的事业表现热情。

天主教会在几乎所有主要交战国国内政治中的地位，即使不算困难，也相当微妙；也许只有在被占领的比利时，它才能享有与民族事业完全认同的好处。尽管本笃十五世不愿谴责德国入侵及随之而来的暴行，比利时首席主教、梅赫伦总主教梅西耶枢机，却成为民族抵抗精神的化身。早在1914年9月选举本笃十五世期间，梅西耶便与科隆的哈特曼枢机发生尖锐交锋。阿尔贝一世国王与比利时政府不在国内时，他继续抵制德国对苦难祖国的政策，尤其是强行将比利时平民遣往德国劳动，以及居心叵测地扶植弗拉芒民族主义。梵蒂冈对梅西耶的作为颇为戒备，协约国及其同情者则自然<a id="pdf-155"></a><!-- PDF page 155; original page 136 -->大加赞扬。事实上，梅西耶枢机战时在协约国如此著名，以至本笃十五世的一位近年传记作者，说协约国把梅西耶塑造成“某种‘对立教皇’”。[^p155-4]他1914年圣诞节的牧函，慷慨激昂地题为《爱国与忍耐》，确实在意大利被广泛用来争取天主教徒支持参战。

在1914年圣诞牧函中，梅西耶这位令人敬畏的首席主教宣称：“基督的宗教使爱国成为一条律法；一个人若不是完美的爱国者，也就不可能是完美的基督徒。”[^p155-5]这封牧函的事例，引出了教会战时作用最根本的一个方面，即德国圣经学者阿道夫·戴斯曼所说的“精神动员”。[^p155-6]十九世纪后半叶固然见证了民族主义运动在欧洲各地的推进，以及各种民族主义意识形态的发展，但必须认识到，即使不与某一宗教传统相联系，许多民族主义形式仍具有强烈的情感感召力，而这种力量主要来自对宗教语言与主题的挪用。即使在十九世纪形成激进世俗民族主义的法国与意大利，世俗爱国者的词汇也往往充满宗教回响。意大利民族主义者长期为“尚未收复的意大利”，即仍处于哈布斯堡统治下的意大利领土而愤懑；战争到来时，法国世俗爱国者也能高唱“神圣团结”的诞生，并在1916年关键的凡尔登战役期间，把连接这座堡垒城市与法国其他地区、岌岌可危的公路，尊为“神圣之路”。

法国天主教徒有自己独特的民族认同，以法国是“教会的长女”为核心，并由战斗性的圣母敬礼，以及对耶稣圣心和图尔的圣马丁的敬礼支撑；而在德国与英国，民族主义仍主要扎根于强有力的文化新教之中。战争环境下，新教教会人士很容易使用民族蒙拣选和上帝旨意之类的语言。例如，赫里福德主教约翰·珀西瓦尔曾是圣公会中少有的布尔战争反对者，1915年却称英国及其盟国为“预定的工具，要<a id="pdf-156"></a><!-- PDF page 156; original page 137 -->拯救欧洲的基督教文明，使之免遭野蛮无情的军事异教主义征服”。[^p156-7]同样，战争爆发时德国表现出的空前团结，也被热烈描绘成一次新的五旬节；这种团结最典型的表现，是帝国议会一致通过战争拨款。一位牧师于1915年说：“帝国的使徒们在8月4日团结一致地站在一起，德皇以最恰当的话表达了这种同心：‘我不再看见政党，我只看见德国人！’”[^p156-8]

由于在道德神学领域共同继承了奥古斯丁传统，交战国的天主教与新教教会人士，很快便各自援引正义战争理论，以彼此冲突的论证，证明本国事业的正义性。然而，也许难以避免的是，冲突的规模、强度与不确定性，还助长了更为狂热、带有末世色彩的战争解释。德国宗教宣传者往往渲染法国的堕落、英国的嫉妒与虚伪，以及俄国东方式的愚昧与残暴；而德国对协约国、甚至中立国平民犯下的一长串骇人暴行，则使协约国的宗教宣传更加狂热。德国教会人士固然大肆抨击英国海军封锁的残酷、在欧洲战场部署异教殖民地部队所构成的文化背叛，以及协约国在非洲和亚洲严厉对待德国差会与传教士，但与德国自己的战时暴行相比，这些宣传素材实在单薄；德国的行为为协约国提供了更为鲜明的宣传内容。1914年德军推进比利时与法国北部时所采用的野蛮、系统性的反游击手段，德国对被占领比利时的处置，以及整个战争期间以潜艇和齐柏林飞艇攻击平民目标的战略，都使德国迅速被妖魔化。德国率先使用毒气，又与不信基督并实施种族灭绝的土耳其人结盟，更使其处境恶化。在英语国家，1915年加拿大一名军士在伊普尔附近被钉上十字架的传闻，以及《野兽》《德皇是“路西法”吗？》之类论述威廉二世道德品性的著作，都助长了把德国视为邪恶极致的观念。美国参战时，德国暴行已经使美国布道家比利·桑迪相信：“如果把地狱倒过来，你就会<a id="pdf-157"></a><!-- PDF page 157; original page 138 -->看见底下盖着‘德国制造’的印记。”[^p157-9]1918年胜利渐近时，锡拉丘兹大学校长J. R. 戴向学生宣告：“如果我们能把柏林的野兽交给上帝，说‘主啊，请向这个东西倾泻猛烈的愤怒’，那将是一件幸事。”[^p157-10]

由于德皇被紧密地与敌基督联系起来，而德国又被普遍认为已堕入异教和基督教以前的野蛮状态，圣战语言很快自发地在协约国流行，盖过较为审慎的正义战争论述，并与大众的十字军修辞融合。土耳其参战，以及十九世纪欧洲广泛存在的、对十字军往事的怀古兴趣，为这种修辞提供了传播基础。但圣战图景绝非协约国所独有。在德国新教徒中，这场巨大斗争也被广泛解释为上帝旨意再次闯入德国历史。1914年8月4日英国参战前数小时，德皇宫廷讲道者恩斯特·德里安德博士在柏林大教堂讲道，以《罗马书》8:31“上帝若帮助我们，谁能敌挡我们呢？”为经文，宣称德意志民族正在保卫“德国的信仰与德国的虔敬”，对抗俄罗斯帝国和法兰西第三共和国那些没有文化、野蛮而缺乏纪律的群众。[^p157-11]同样，阿道夫·冯·哈纳克援引当时自由派新教极为流行的上帝之国神学，于1916年宣称，德国战争目标的崇高使战争本身圣化；这些目标就是确保德国有权对国际事务施加有益影响，从而推进上帝之国在人间实现。

历史学家几乎无不反感教会在道德动员中那些往往令人恐惧的言辞；许多人急于谴责，反而忽略了其意义：对于这些历史上属于基督教的社会而言，这种动员是全面战争的重要组成部分。十九世纪通常不被视为宗教战争的时代，但自1792年以来，欧洲多次血腥而持久的冲突，都证明战斗性的宗教热情仍具有动员社会投入战争的力量。

1792至1815年，在法国西部、意大利南部、西班牙、葡萄牙、蒂罗尔与德国北部，宗教在激励并维持人们反抗法国共和政权和拿破仑统治方面，发挥了关键作用。随后，西班牙卡洛斯战争、意大利统一战争和普法战争，也都显示宗教仍能激发民众抵抗，尤其是在保守天主教社会中，尽管并不限于这些社会。英语社会也并非没有这样的经验。美国内战和较近的布尔战争表明，在其他破坏性极强的战争中，战斗性的新教形式同样能帮助公民军队继续作战。

无论欧洲教会在十九世纪丧失了多少阵地，在1914至1918年的任何西方交战国，基督教都不是无足轻重的道德力量。欧洲许多地区的教会成员比例或礼拜出席率，可能很低或正在下降；尤其天主教会，自法国大革命以来，在许多天主教社会宪制重组中遭受打击。但始终如一的无神论者或世俗主义者，仍只是欧洲人的一小部分。基督教仍构成欧洲大多数地区公共与个人道德的框架；在民间层面，基督教人生礼仪仍广具吸引力，即使在教会其他影响很弱的地方，例如新教背景的柏林工人阶级中，也是如此。鉴于基督教广泛而持久的吸引力，共同的宗教身份在大多数交战社会都是重要的团结基础，尤其在面对外来威胁、需要民族团结时。最能说明这一现象的，恰恰是一个反面的例子，即意大利：国家未能争取天主教会的坚定支持，成为战争大部分时期的一大障碍。美国也明显体现了这一点。1917年4月6日以后，美国主要教会形成强烈爱国的共识，使一个此前大体支持中立、语言多样的社会，开始觉得一场在地理与心理上都遥远的战争，既切身又必要。尽管教会在促进民族凝聚方面作用显著，其对“国民士气”这样难以捉摸的事物的相对贡献，几乎无法量化。然而，分别研究德国新教与加拿大卫理宗的独立研究，都得出结论：教会的讲道与活动，在战时为许多人提供了意义与支持。甚至有人认为，德国牧师成功传播其崇高的战争观，有助于维持一种广泛的<a id="pdf-159"></a><!-- PDF page 159; original page 140 -->错觉：德国的精神力量足以抵消协约国在物质上的巨大优势。此外，随军牧师的作用在英国、美国，甚至意大利军队中获得新的强调，也表明教会对认可、颂扬战争努力的重要性；他们的工作日益被认为既是宗教牧养，也是激励士气。

除共同而深刻地在思想上支持战争之外，教会还以许多实际形式支持本国战争。高级教牧人员与平信徒不仅向自身群体证明战争正当并争取支持，也很快投入国际舞台上持久的宣传战。战争爆发时，梵蒂冈内支持协约国的游说力量明显薄弱：协约国中仅俄国与比利时派有代表，普鲁士、巴伐利亚和奥匈帝国却各有使节。因此，1914年末，英国政府被说服放弃延续数百年的政策，恢复与圣座的正式外交关系；这一发展又促使世俗的法国第三共和国政府派出自己的非正式代表。法国与英国天主教徒不仅协助以梵蒂冈为中心的秘密宣传战，也投入争取国际天主教舆论的宣传战。在法国，这项工作由天主教对外宣传委员会承担，其出版物包括1915年4月的《德国战争与天主教》。在英国，知名天主教徒为英国天主教信息协会撰文；其月刊《通信》以多种语言出版，在美国天主教教牧人员中广泛流传。德国在中立国的宣传协调者、天主教中央党领袖马蒂亚斯·埃尔茨贝格推动德国天主教徒也投入论战，通过《德国文化、天主教与世界大战》等刊物，反驳敌国同宗教徒的指控。

与天主教宣传战同时，彼此敌对的新教教会人士也在战争初期争取中立国，尤其是美国的舆论。英国宣战仅一周后，阿道夫·冯·哈纳克便向一群来访的美国人哀叹，只有德国与美国仍致力于保存盎格鲁—撒克逊文化，而英国为支持其“蒙古—莫斯科”死敌，已经出卖了自己。[^p159-12]

<!-- PDF page 160; original page 141 -->



更具争议的是，1914年8月末，哈纳克与另外二十八名参与德国宣教运动的神学家，联合发表《告海外福音派基督徒书》，旨在保护协约国属地及德国海外殖民地中的德国宣教工作。同年10月，哈纳克又与另外九十二位德国学者和神学家，在《法兰克福报》发表《告文明世界书》，否认德国对战争负有责任，并辩护说，德国军国主义是民族伟大不可分割的一个方面。无论这些倡议对中立国新教舆论有何影响，其最直接、最重要的效果，是凸显国际新教神学学术共同体中已经形成的分裂。所有这些倡议，都遭到英国教会人士与学者公开而有力的回应，而英国设在惠灵顿大楼的宣传总部又支持和推动了这些回应。

不过，教会参与战争远不止在国内外进行道德劝说。它们为减轻战争苦难，有时甚至增加苦难，所付出的物质努力，其规模和种类都惊人。红十字会在许多国家与教会关系密切；除其人道工作之外，教皇还在平民与战俘的国际救济工作上花费八千二百万里拉，几乎使梵蒂冈破产。在这些国际性和超国家组织的活动之外，各交战国教会也筹集并花费巨款，为平民与军人开展宗教和福利工作。例如美国的联合战时工作募捐运动，是为期九天、全国性、跨教会的筹款活动，颇具讽刺意味地始于1918年11月11日，筹得惊人的一亿八千八百万美元。在法国，天主教会投入各类战时事业，但并不总是本着“神圣团结”似乎要求的精神，与世俗当局合作。德国教会也投身福利工作，新教与天主教妇女慈善组织，与犹太及世俗妇女组织一同加入“全国妇女服务组织”。但如同法国的“神圣团结”，战时德国实际的团结，往往达不到战时友爱与和解言辞的高度。在新教福利工作较占优势的东线，天主教随军神父往往批评并提防新教同僚经营的、号称“超宗派”的士兵活动所。

<!-- PDF page 161; original page 142 -->



教会不仅为受战争影响的人提供救济与支持，也积极直接为战争提供资源。英国和美国教牧人员纷纷劝同宗信徒购买战争公债；比利·桑迪向美国同胞解释，这是为了帮助美国陆海军的枪炮挖掘霍亨索伦王朝的坟墓。教会本身也作出投资。1915年6月至1917年2月间，英格兰教会六个机构共购买四百五十万英镑政府债券；德国战争期间接连发行九次战争公债，仅前三次，就从普鲁士邦教会获得近一千三百万马克。教会除了出资，也在招募人员方面发挥重要作用，尤其在最后才不得已实施征兵的英国与加拿大，以及直到战争结束都成功抵制征兵的澳大利亚。在英属东非，当地劳力对于区域内对德作战不可或缺；甚至在这里，圣公会传教士也积极招募数千名本地搬运工，有些还编为“基库尤教会志愿队”等单位。比属刚果东部的天主教传教士也意识到海外差会的军事潜力；白衣神父会组织信徒，防备预期中德国从坦噶尼喀湖对岸发动的入侵。同样，法国政府日益把辽阔的法属西非视为西线及其他战场的兵源库；当地同会传教士，也同样热心地劝说皈依者加入法国殖民地部队。

阿尔丰斯·迪普龙认为，在第一次世界大战的强度与规模之下，“西方重新发现了圣战”，而且“双方都必须声称上帝站在自己一边”。[^p161-13]但一战的宗教性质，并不只是崇高的推论或爱国的赋义；在某些战区，冲突切实反映出激烈而历史悠久的宗教仇恨。在东线，战事从一开始就伴随旧有宗教敌意的复燃。奥匈帝国为其语言多样、以天主教徒为主的军队向教皇求祝福，因为他们即将出征，对抗东正教的塞尔维亚与俄国。虽然未获祝福，但人们知道庇护十世同情奥匈帝国对塞尔维亚的主张；他认为塞尔维亚的影响如同一种“腐蚀性疾病”，有传染到<a id="pdf-162"></a><!-- PDF page 162; original page 143 -->天主教中欧的危险。[^p162-14]战争发展中，俄国入侵并占领奥匈帝国的东加利西亚，强迫当地天主教徒改宗，监禁天主教神父、教师与伦贝格总主教，这都是粗暴的俄罗斯化政策的一部分。值得注意的是，同盟国则利用俄国内部少数族群在宗教上的不满加以反击。1915年占领华沙后，德国人在该市大学设立天主教神学系；两年后夺取里加，德国不仅在拉脱维亚这一地区恢复路德宗教会制度，还于1918年4月将东正教主教座堂重新祝圣，改供路德宗礼拜。

东线战争若往往带有宗教战争的色彩，协约国对抗土耳其的战区也同样如此。土耳其参战的同时，于1914年11月14日宣布对协约国列强发动吉哈德，即圣战。这一宣告部分出于德国推动，也依据奥斯曼统治者对逊尼派哈里发职位的历史权利主张。土耳其的宗教裁决，希望利用奥斯曼苏丹近来鼓励的泛伊斯兰情绪，列举法、俄、英帝国内穆斯林受到的压迫，不仅号召逊尼派，也号召什叶派穆斯林。世界上一半以上穆斯林生活在协约国统治下，因此奥斯曼圣战的颠覆潜力十分明显。战争期间，圣战号召远传高加索和刚果，助长了印度西北边疆及埃及、利比亚边境的战斗性伊斯兰力量，甚至引发英属印度军队中以穆斯林为主的团级部队哗变。但奥斯曼帝国若准备把战争当作宗教战争，其敌人也准备如此。西方协约国政府为避免疏远阿拉伯民族主义者或本国穆斯林臣民，刻意回避把中东战事比作当代十字军东征；但在协约国记者，以及在加里波利、巴勒斯坦和美索不达米亚作战的军人中，这类观念无疑十分流行。1917年12月协约国夺取耶路撒冷，英国报刊将其欢呼为狮心王理查梦想终于实现，毫不令人意外；罗马全城教堂也唱《谢主赞美颂》庆祝。土耳其与协约国战争的宗教性质，<a id="pdf-163"></a><!-- PDF page 163; original page 144 -->也表现在土耳其的基督徒臣民经常支持进入奥斯曼帝国南北边境的协约国军队。这一因素不仅助长土耳其对亚美尼亚人的暴行，也推动战时在叙利亚和黎巴嫩迫害聂斯托利派、雅各派及马龙派基督徒。

## 战争年代的宗教

战争引发的宗教敌意，表明十九世纪欧洲文化的世俗化程度有限；伴随战争出现的宗教复兴，也说明了这一点。在德国、英国和法国，战争最初几个月，正式宗教活动显著复兴：教会礼拜出席人数增加，领圣餐者增多，朝圣队伍扩大，尤其法国前往地方圣地的朝圣者明显增加。随着战争持续，这种高涨的正式宗教参与明显回落；这一事实常被视为战争年代宗教热情转瞬即逝的证据，甚至被用来说明战争进一步促使欧洲社会世俗化。但在冲突数月、数年间不断加深，数百万信徒入伍或被征召、数千教牧人员离开教会从事各种战时服务、教会正常生活模式全面中断的背景下，对此类结论必须持怀疑态度。事实上，其他指标似乎表明，战争初期的宗教复兴只是转而采取较少依赖定期正式礼拜的形式。战时德国就反映了这一情况：新教教堂一边失去被政府征用的管风琴音管，一边发现堂会礼拜对古老而熟悉的赞美诗的需求日益增长。此外，汉堡与柏林传统上不参加教会活动的地区，在整个战争期间举行宗教葬礼的比例大幅上升。汉堡从1913年的百分之五十五点三九上升至1918年的百分之八十；柏林同期从百分之六十五点五五上升至百分之八十点五三。[^p163-15]

后方的宗教激荡，也体现在人们广泛相信那些声称上帝直接<a id="pdf-164"></a><!-- PDF page 164; original page 145 -->介入战争的轰动故事。1914年9月，德军在巴黎郊外及时被击败，在法国被广泛称为“马恩河奇迹”；对法国天主教徒而言，这一胜利证明了圣母为本国代祷。在英国，西线战争头几个月的严酷教训，由“蒙斯天使”的故事得到安慰。这一传说为英国早期的一次败绩增添积极色彩，实际灵感却来自伦敦《晚间新闻》的一篇短篇小说。1917年夏，厌战情绪日渐明显时，又流传泰晤士河上空出现“和平天使”的故事，不过较少为人所知。最著名的是，在血腥动荡的1917年，圣母玛利亚在葡萄牙法蒂玛显现，告诉见到异象的人每日念玫瑰经，“为世界获得和平，并使战争结束”。[^p164-16]至少在葡萄牙，这些异象对国内政治产生巨大影响，帮助1917年12月军事政变推翻阿方索·科斯塔激烈反教权的政府取得正当性。

各交战国军队中，也能看见这种宗教激荡及广泛复兴的证据。十九世纪欧洲宗教生活看来日益女性化，因此，在这些压倒性地由男性组成的环境中，人们广泛重返宗教，其意义不应低估。法国军队以战前天主教复兴为背景，加之战争带来的恐惧与不确定性，形成了整个战争年代都十分明显的、更强烈的宗教意识。图尔的圣马丁、圣米迦勒、圣毛里修斯及贞德等军事圣徒和被视为圣徒的人物广受欢迎，反映了这种虔敬；法国士兵也从新出现的“战壕圣母”敬礼中寻求安慰与保护。在1916年实施征兵制和索姆河战役之前，崇高的民族使命感、军中较高比例的教会参与者，以及对死亡和受伤的自然恐惧，也共同促成了英军中的宗教复兴浪潮。各国士兵无处不在的求保护心理，自然催生了对宗教用品无穷无尽、又常常流于迷信的需求。英国和美国军人常把《圣经》与祈祷书当作护身符携带；新教士兵和天主教同袍一样，除佩戴五花八门的世俗护符外，也佩戴玫瑰念珠、圣衣和显灵圣牌。西线战场成为各种宿命论述滋生的<a id="pdf-165"></a><!-- PDF page 165; original page 146 -->沃土；这些论述包含的宗教与哲学立场，从极端加尔文主义一直到科学决定论。战场也产生许多传说，讲述路边受难像在天意保护下安然留存；至少在英国及其自治领军队中，还出现一位在无人地带照料伤员的“白衣战友”。这些故事甚至带上预言性质。阿尔贝的“金色圣母”，即一尊从大教堂穹顶上倾斜伸向索姆河战场、保持该状态三年多的雕像，在英国、法国和德国军队中，都引发许多关于其坠落与战争结束之间关系的不同传说。

战争年代充满活力、虽极为混杂的宗教性，在纪念无数阵亡者的活动中获得鲜明而持久的表达。有些文化历史学家专注于招魂术的发展，把它视为传统文化韧性的证据；但在这方面，更有意义的是基督教，或许尤其天主教，持续满足丧亲者需要的能力。德国战后纪念物普遍而有意识地融入天主教“圣母怜子像”的象征；英国许多以法国和比利时路边受难像为原型的市民纪念碑，也显出天主教影响。战争还促使英国新教徒更多为亡者祷告，并重新评估炼狱神学。战争有两个格外引人注目的巧合：它结束于十一月，按罗马天主教传统，这是炼灵月；停战协定又签于图尔的圣马丁庆日，法国天主教徒很快便指出了这一点。在法国，尽管也存在另一套世俗共和主义表达方式，天主教会仍“出现在纪念活动的每个层面”，[^p165-17]从为亡者举行弥撒、设立堂区纪念物，到在西线旧战场建造宏伟的新纳骨堂，无不如此。事实上，在纪念战争和进行战争这两方面，法国天主教徒与共和派都至少部分和解：市民纪念碑上常装饰十字苦像，巴黎总主教也为国家无名战士的灵柩祝福。当然，幸存者有许多事值得感恩；特别是在法国，教堂中大量还愿铭牌的文字，反映了这种感激。即使在德国，<a id="pdf-166"></a><!-- PDF page 166; original page 147 -->归来的士兵也常希望以实际形式表达感谢。二十世纪三十年代初，马尔平根的圣母朝圣地增建了一座小堂，缘于当地一位退伍军人的努力；他曾在前线许愿，若能在战争中生还，就为圣母玛利亚建一座小堂。

## 教会与和平

第一次世界大战对西方基督教最有意义的方面之一，是梵蒂冈及某些超国家新教组织，显然未能动员各教会反对战争。十九世纪天主教国家对教皇个人的崇敬日益增长，制度权力也不断集中于教皇之手；1917年颁布新《教会法典》，标志着这一进程。但本笃十五世显然无力争取国际天主教力量支持通过谈判实现和平。庇护十世于1914年8月突然去世后，被描绘成战争的悲剧性牺牲者；其继任者则常被描绘成和平的殉道者。意大利统治集团暗中图谋对付他，双方众多批评者又广泛指责他主动或被动地偏袒一方；他接连推动谈判和平的努力最终也遭挫败。从长远看，本笃十五世的这些磨难反而带来了声誉，尤其第一次世界大战的历史著述多带反战基调。例如，约翰·波拉德在本笃传记中认为，这位战时教皇确实有资格被称为伟大人物，因为“他在一切领域追求和平，真诚、坚定而勇敢”。[^p166-18]然而，这种解释似乎过度受到西欧视角影响。圣座固然谨慎处理与西方协约国的关系，但衡量这一基本上务实的政策时，也必须考虑其对奥匈帝国的关切，以及对东正教俄国固有的不信任。前者表现于1915年梵蒂冈与德国一道，试图阻止意大利侵略奥匈帝国；后者则表现为持续担忧：俄国一旦获胜，可能把影响扩展至君士坦丁堡，振兴其东正教牧首区，并加强东正教在东南欧与天主教竞争的地位。事实上，梵蒂冈对奥匈帝国的关切，以及明显的恐俄态度，甚至隐含在本笃著名的1917年8月《和平照会》的内容与发表时机之中。

照会内容是在与德国及奥匈政府磋商之后拟定的。值得注意的是，它提出的和平解决方案，基本上只是恢复战前状态；这一方案有利于处境艰难的二元帝国。此外，照会发表时，俄国正滑向无可挽回的军事失败。照会主张建立独立波兰，也承认了这一因素：新国家将主要由天主教徒组成，其领土大部分将从战败、瓦解的俄罗斯帝国西部划出。

战争不仅破坏、扰乱了各种基督教国际主义，也暴露出基督教和平主义内在的薄弱。在主流教会中，和平主义最有力的支持者，是英语世界的自由派新教徒。至少从表面看，在决定命运的1914年夏天，这些群体的反战动力似乎很强。在神学层面，阿道夫·冯·哈纳克近期的著述，为基督教和平主义提供了学术基础；人们也日益相信，教会能够、并且应该为促进国际友好做得更多。在这方面，1907年海牙和平会议最重要的附带成果，是在英德紧张关系加深的背景下，开启两国教会引人注目的对话。通过教会增进大英帝国与德意志帝国友谊的正式机构已经成立，英格兰教会和平联盟又于1911年建立，英德关系的前景似乎充满希望。1914年1月，英国著名浸礼宗人士、资深反战活动家约翰·克利福德，甚至认为可以有把握地宣称：“军国主义属于黑暗时代，与我们的时代不相容。它必须消失。它正在消失。”[^p167-19]这种乐观也传到大西洋彼岸。次月，曾慷慨资助英德教会和平工作的钢铁巨头安德鲁·卡内基，捐出两百万美元成立教会和平联盟，推动美国教会中日益发展的和平运动。国际前景看来如此美好，以至卡内基甚至规定了“当和平完全确立，不再需要为这一事业做任何事情时”，这些资金应如何处置。[^p167-20]当然，极具苦涩讽刺意味的是，一次国际新教<a id="pdf-168"></a><!-- PDF page 168; original page 149 -->和平会议，原定于1914年8月3日至4日在康斯坦茨举行，主要议程就是建立新的“通过教会促进国际友好世界联盟”。此外，下周还计划在列日召开相应的天主教和平会议，主要目标是促进法国与德国教牧人员的友好关系。

战争当然以旋风般的力量与突然性，袭击了这个颇为乐观的世界，把近期在英德交流中发挥重要作用的学者与教会人士，都卷入漩涡。甚至参加过康斯坦茨会议的克利福德，也被卷走。这位反对布尔战争的老活动家，登上招募集会的讲台，宣称当前战争是“自由力量与奴役力量”之间的斗争。[^p168-21]在战争的熔炉中，尤其英国、美国与加拿大实行征兵制之后，情况已很清楚：在英语新教徒中，基督教和平主义除了在其传统而相对较小的支持群体，即公谊会，以及更边缘的门诺派、基督弟兄会、普利茅斯弟兄会和耶和华见证人等团体中，并没有强大的群众基础。当然，在更具宗派性的团体中，良心拒服兵役常常出于与外界分离的考虑，而非利他动机；只要工作条件适当，他们的良心顾虑未必延伸至拒绝在战争相关产业劳动。事实上，连公谊会在服兵役问题上也出现分裂，大西洋两岸许多适龄贵格会信徒，都放弃传统的和平见证而入伍，这也反映了战争造成的矛盾。

## 结论

第一次世界大战对西方基督教的总体影响虽然难以判断，仍可提出一些看法。显然，鉴于战争是一场影响深远、涉及众多基督教传统的全球事件，必须在国际与跨宗派层面评估其影响。从这一角度出发，可以得出一些有意思的结论。毫无疑问，从政治上看，天主教会似乎在冲突中获益颇多。首先，东方历史宿敌最终受挫：不仅战斗性东正教的幽灵<a id="pdf-169"></a><!-- PDF page 169; original page 150 -->从东欧被驱散，圣地也摆脱了土耳其数百年的控制。此外，战争改善了教会在许多西方国家的处境。它为美国天主教徒催生了新的重要全国性组织，使梅西耶枢机成为英勇抵抗的国际象征，并帮助摧毁葡萄牙一个恶毒反教权的政权。在法国与意大利，尽管困难依旧，共同的战争经历最终有助于改善教会与其他反教权政府的关系，使天主教政治家更易进入政府，也证明动员民族投入战争时，天主教支持不可或缺。此外，中欧帝国的战败瓦解也带来益处，尤其共同面对布尔什维克俄国的危险，有助于巩固教会与新独立国家占主导地位的保守民族主义之间的联盟，波兰和匈牙利尤其如此。德意志帝国政治与教会体系的崩溃，也有利于天主教会及其中央党，使它们能在魏玛共和国更为平等、尽管不稳定的环境中，发挥更大的影响与权力。最后，教会领导层在国家和国际层面采取的不同姿态，产生了双重、虽非预期的效果：向同时代的爱国者表明教会支持战争，也向更具批判精神的后人表明教会支持和平。

然而，新教的情况更加复杂。欧洲传教士被迫离开，使许多非洲基督徒初尝自主的滋味，感到兴奋；但对德国新教国教会来说，惨痛的战败带来国教地位的终结与士气低落。这一此前不可想象的战争结局，激起了一种明显而危险的民族复兴渴望。此外，战争似乎在新教神学领域助长了对自由派乐观主义的初步反拨；这种反拨后来在两次世界大战之间巴特的新正统神学中开花结果。但自由派新教精神在英语世界显然依然存在，表现为雄心勃勃的社会与教会重建计划，以及对国际联盟、对1914年8月在康斯坦茨成立的世界联盟的新希望。最后，就大众基督教而言，战争鲜明显示出它在先进、据称已经世俗化的欧洲社会中的力量与活力。但同时，也暴露出它一贯的混杂性，以及它与制度性教会之间既暧昧又矛盾的关系。
