# 第十五章 欧洲第二次世界大战中的天主教与新教

**安德鲁·钱德勒**

> 原书第262—284页；对应原PDF第281—303页。

意大利比萨对暴力、战争、疾病和革命并不陌生。二十世纪又依次带来民主、海外战争、革命、独裁，最终是本土战争。到1944年，墨索里尼独裁已在国内政变面前垮台，盟军从南部入侵，德国盟友则从北方占领，迎击这一推进。比萨本身此时驻有德军。1944年6月17日夜，英国轰炸机攻击该城，燃烧弹接连落在中心中世纪广场，火势很快蔓延。混乱中，奇迹广场珍宝之一、几个世纪装饰古老墓园墙壁的“黑死病大师”巨幅壁画，部分被火焰吞没，许多永远失去。

壁画作于十四世纪，宏伟描绘中世纪意大利所有社会等级：成群男女，美丽高贵者、卑微低贱者，教士与主教、贵族、教士、工匠和穷人，一同卷入对死亡与审判、诅咒与救恩的怪诞沉思。仅一代以前，这种图景或许显得遥远、野蛮；但在二战地狱中，它即使被焚毁，也以可怕的新生命说话。在这里，公民、教会与世俗生活的等级权威，被打破、分裂，又在新的永恒秩序中重新组合，常完全出乎我们的意料。最后审判中被称义的人，可能是世间无足轻重的劳工；被罪玷污、遭定罪者，却可能是王公或主教。

中世纪基督教神学醉心辩证法，把命题排列、对置，使之交战，走向胜败。正是这种坚持，五百年前使埃克站到路德对面，又以不可阻挡的力量，产生<a id="pdf-282"></a><!-- PDF page 282; original page 263 -->天主教与新教相互对立的新分裂。二十一世纪初，我们仍以论战精神回看二战悲剧：教皇、主教、教士与广大信徒，甚至整个教会及基督教本身的言行，都要被审判，送往天堂或地狱。空气仍充满辩护、指控、开脱、道歉、定罪与封圣；因为那段时期在心中尚未冷却。但我们手中仍只有碎片。在这张公共与秘密、个人与集体生活的密网中，机构、官僚体系、个人和家庭，都尽可能实践、持守基督教信仰，留下许多矛盾言行，对灾难作出截然不同的回应。很难为这种复杂性找到共同形式，甚至难以衡量所见。我们只能反省自己知道得何其少：每个人生、每个共同体中，必然发生过的私人良心抉择，以及权威机构、修会、家庭和堂会内部的秘密谈话，我们知道多少？

## 先知发声的无力与求存的决心

首先，不能把基督教在二战中存续视为理所当然。从天主教观察者角度，德国政府在国外被广泛视为一种极权统治与思想明显敌视基督教的力量；它违背保护宗教权利的承诺，日益迫害信徒。其盟友意大利也违背对教会的保证。民主国家不同，英国政府历史上属新教，如今几乎各方面却实际世俗化。法国政府宽容，但仍倚重反教权传统，绝非天主教特殊盟友。与这一切相对的，又有苏联权力：它公开宣称要消灭宗教本身，冲突之初参与摧毁波兰，在波罗的海采取侵略行动，并在1941年夏德国入侵后承受欧洲战争主要重压。基督徒进入新战争时，早已深陷疑虑。

两个传统的教会领袖，都承认有责任判断正义与非正义。新教毕竟是圣言与<a id="pdf-283"></a><!-- PDF page 283; original page 264 -->讲道的信仰。天主教则可把自身呈现为权威结构，由高位者以通谕和声明引导信徒。但两者如今发现，过去最自信给予世界的，恰是最脆弱的任务。谁来付出这些话语与权威的代价？当政治权力如此无情、残酷地对付普通男女信徒时，教会如何与之周旋？抗议会带来改变，还是仅给受压迫者带来更严重苦难？后人竭力理解，却仍难充分体会：1939年在教会承担正式责任者，心中这种恐惧何其真实。对身处占领军疆界之外者，它常使人软弱；对面对本社会敌人者，它简直令人瘫痪。

面对如此巨大、无法克服的现实，教会领袖决心，无论如何必须在尚存教堂、仍为信徒施行的圣事圣礼，以及仍活着的会众的祈祷与心中，保存信仰。因此，他们走上谨慎、计算与周旋的道路；批评者却认为，这可能背叛各背景人们所认可、希望听见的先知力量，甚至正义本身。对他们，根本问题不只是向堕落世界阐明正义，而是更基础的：教会实际上如何生存在这一可怕新格局中？保存信仰是教会任务，世界动荡时，其使命就是存续。

历史学家常想判断教会批评还是同情政治秩序，合作还是抵抗。但许多天主教或新教领袖的核心关切，反而是按教会自身原则维持其完整，维系自身救恩叙事：确保仍向信徒施行圣事圣礼，仍说神圣话语，仍按世代传统举行仪式。这是不同语言，也是独特身份。人们常说，教会生活在世界中，却不属于世界。这种抽象说法或许无助，也确实引出许多问题，但它表达一种被感知的双重性、区分与边界标定。新教与天主教会既不只是机构，也不只是民众运动，而两者兼是。受压时，它们自然尽可能坚固划界，转向内部；但压力越大，内部犹疑越多，矛盾爆发。期待任何教会都呈现一致<a id="pdf-284"></a><!-- PDF page 284; original page 265 -->形态，要求过高。已经建立的中心也无法维系，一切分崩离析。一位教区主教，对处境与责任的理解不同于另一位；一名神父采取特定路线，同僚可能支持，也可能批评。平信徒冒着神父不赞同的风险，采取在自己看来仍体现基督徒良心的行动。但也有时分界瓦解，主教、教士与平信徒成功以新形式重组关系，在构成、性质和目的上，可能更敏锐、更向外开放。德国可以想到聚集在赫尔穆特·詹姆斯·冯·毛奇与彼得·约克·冯·瓦滕堡周围的异议团体克赖绍圈。[^p284-1]这一非凡群体，旨在为战后国家规划道路，包括三位秘密向一名主教报告的耶稣会士，一名独立行动的新教牧师，以及其他有些信教、有些不可知论的人。

## 战争的正当性

1939年9月初，德国、波兰、法国和英国开战，教会人士普遍承认有责任判断本国政府路线是否正义。同时，他们已参与冲突，因为各国军队都配有随军牧者，引导、支持必须出征的人。但自由国家与独裁国家，情况截然不同。英国宣战消息恰逢主日上午礼拜，神父或牧师常在礼拜中告知会众。多数人认为战争必要、不可避免，连和平主义者也未形成一致批评运动。论辩已经穷尽；希特勒不愿和平，战争似乎无法避免。[^p284-2]他们带着正义的顺风参战，不是因为希特勒在国内所为，虽然清楚知道，而是德军不断背弃保证、跨越国界。对德国人民本身，也没有强烈敌意；他们被认为受暴政压制，这不可能是他们的<a id="pdf-285"></a><!-- PDF page 285; original page 266 -->战争。也有人决心确保教会坚持自身独立路线。对奇切斯特主教乔治·贝尔等人，支持开战决定还不够，战争也必须以正义方式进行。教会不是“国家的精神辅助机关”。[^p285-3]英国舆论日益敌视德国人民时，贝尔否认德国人都因自己无法控制的政府的战争罪行，而成为非正义者。后来，他也公开批评英国政府毁灭性轰炸政策。但在这些问题上，他常孤立无援。

德国如何？教会必须先衡量自身处境的政治现实，才可能作判断。天主教地区从未是纳粹核心地带，如今教会当局更清楚自己的脆弱。1933年协定仅买来少许时间与喘息。1937年，庇护十一世发表愤懑的通谕，列举德国政府对协定的背弃。[^p285-4]新教内部，则已为教会及福音完整而顽强斗争六年。多数人悄然接受一个新的统一国家教会，大体与政治国家结盟。一股获得某些政治庇护的少数运动，赞成纳粹与新教融合。另一个人数可观、意志坚决的少数派坚持抵抗这一融合，同时反复表达忠于国家，绝非反国家抵抗运动。1938年9月，这一异议少数派，即认信教会领袖发布声明，表达当时欧洲希望和平而非战争的情绪；在其他社会看来，本来足够无害。但对只需微弱借口便可打击他们的国家当权者，它却招致报复。新镇压浪潮留下深刻印记，[^p285-5]他们不再敢涉足这一领域。

对多数天主教与新教教牧人员，战争本身已足以使他们承诺支持，不是明确支持本国政府，<a id="pdf-286"></a><!-- PDF page 286; original page 267 -->及其政策，而是支持危难中的德国人民：无论身处何地，他们越过边界看见的，都是决心使本国战败的强大敌人。与人民团结的语言，绕过了对政治问题更复杂的衡量，成为欧洲基督教论述的特点。它表达牧养之爱，而非明确政治结盟。

## 梵蒂冈与日内瓦：基督教国际主义与中立困境

梵蒂冈再小也是国家，战争时国家必须有政策。此外，1929年梵蒂冈与意大利签订的政教协定，要求教皇在冲突时中立。务实而言，1939年新战争中，有充分理由引导庇护十二世正式宣布中立。他面对独特而严峻的现实组合：一方面，教皇统治欧洲、或许世界最小的国家，瑞士卫队本质只是装饰性的警察力量；另一方面，他是基督在世代表、全球各洲天主教信徒的最高领袖。数十年来，许多国家天主教徒因忠于教皇，遭惩罚与羞辱。如今，天主教徒生活在所有交战国，教皇必须表明，无论各国政府政策如何，他不偏爱其中任何一方。

但中立不只是前提，也是必须构造的政策，其痛苦将在实际应用与权衡中显露。一战时，本笃十五世在脆弱的国家外交表面之下，进行调停、推动，争取改善与正义。1939年9月也可看出，教皇若不能动员力量影响列强平衡，仍能运用其下尚存的谨慎活动空间。1939年9月至1941年夏，庇护十二世发现，这种外交有利于中立政策。[^p286-6]此后，<a id="pdf-287"></a><!-- PDF page 287; original page 268 -->对苏战争的新现实及对新恐怖的衡量，更要求中立：他怎能谴责德国，而不谴责苏联？但越来越多批评者很快觉得，中立与其说为积极领导提供前提，不如说造成道德禁锢。

显然，选择中立并非仅对天主教徒有用。1939年，新教普世教会运动已发展到若干组织汇合的阶段；它们数十年来忙于联合新教传统，使之在世界发出共同声音，日内瓦被广泛视为制度性家园。象征意义明显：日内瓦也是红十字会与国际联盟所在地。普世新教虽不是国家，其官员却奔走于中立国家；这个国家参战方式，限于资助交战双方，并自然地为冲突提供不可或缺的“润滑油”。

新教普世运动两大动力“生活与工作”和“信仰与教制”，即将以世界基督教协进会之名重大合并。1939年，这一名称已通行，但完整暂名更谨慎，是“筹建中的世界基督教协进会”。各教会权威在此保留代表，维持普世讨论，尽管开战实际终止彼此一切直接联系。这里也开展安静而有目的的外交，许多线索聚集于维瑟特·胡夫特一人。他是自信、果断的荷兰人，特别关心那些此刻仍为和平而反对本国政府的德国人的秘密工作。他是严谨、爱追问、却有同情心的东道主。在他看来，日内瓦是秘密外交行动的安全据点，也是各种网络冒险穿越欧洲边界时相会之地；更提供另一套超国家行动语言，回应边界封闭、交战的世界。对他，这不只是民族冲突，而是思想战争：一些德国人反对本国政府之深，不亚于其他国家与之作战的人。[^p287-7]这使他成为英国贝尔主教的盟友。

## 占领的经验

无论周围建立何种高层权威结构，新教与天主教徒的日常经验，首先由本地及本国社会中的经历界定。西欧德国入侵至1940年夏末已成功完成。低地国家、丹麦、挪威和法国，此后被占领近五年。这些是闪电战，数周结束。东部，德国疆界从波兰扩展；西欧战败后，又于1941至1944年深入苏联，直到苏军以骇人代价遏止进攻，开始把德军逐回德国腹地。因此，对大多数天主教与新教徒，战争不同于一战由数十万征召部队维持前线的消耗战，而是占领经验。各国情况独特，但可区分东欧与西欧被占领国。东线从一开始，就是毫无保留、怜悯与人性的战争，几乎不顾国际公约。占领现实是全面驱逐、剥夺财产、囚禁，以及毫不犹豫的大规模谋杀。德国占领西欧也残酷可怖，但依据不同思想认识，容许某些务实协调。没收、监禁、报复与驱逐等暴力手段，确实日益严厉、一贯，但使用频率、任意程度与规模都较低。

占领欧洲的历史学家发现，两种传统的总主教、主教、教务监督和总会，向当时占领权力表达忠诚与服从，随后转向内部；若有抗议，很可能为宗教青年组织或学校辩护。这容易被呈现为捍卫利益，而非诉诸正义原则；事实上，寻求先知勇气证据的后人，也不甚钦佩。但不能因此认为，它与批评、反对甚至抵抗的相反情绪完全不相容。教会寻求保存一种完整身份，其根源并非当权力量，语言与存在方式独特不同，因而保持了一种平行现实，以及男女<a id="pdf-289"></a><!-- PDF page 289; original page 270 -->可以各自取用的伦理与属灵资源。教会仍可能是自主空间，保留某种思想与行动自由。在这一限定下，出现各种与政治社会互动的模式，涉及所有职位与层级的教会人士，从热情合作到异议，甚至抵抗。在极权或受恐吓武力威胁的社会，这种存在所提供的可能，具有特别分量与现实性。过去很少关心基督教的人，如今以新的认真态度转向它。

### 波兰

1939年秋，德国政府占领波兰西部与中部。西部波兹南、波美拉尼亚与西里西亚，以及原文所列中南部地区，住有九百万波兰人、六十万德国人；第二地区“总督辖区”，包括华沙、克拉科夫和卢布林的中部，住有一千二百万波兰人。第一地区几乎立即发生大规模没收与向东驱逐；随后，总督辖区也被向德国本土遣送劳工。

第一地区有波兰最古老的格涅兹诺与波兹南总教区。首席主教赫隆德枢机向梵蒂冈发出两份报告，极详尽列举随后袭击的性质与规模。盖世太保关闭格涅兹诺总教区公署，把副主教软禁家中，调查总教区档案，直接没收公署财政。主教座堂参议会被驱散，刚修复装饰的宗座圣殿被警察关闭。士兵占据神学院，一名将军搬进总主教宫；座堂法政牧师被赶走，退休神父被逐出宿舍。格涅兹诺修女院清空，改成犹太拘留中心；当地圣三堂遭亵渎，物品被搬走。敢登讲坛的神父直接被拖走。赫隆德列出十名被枪杀神父、一名被殴致死者、一名死于强迫劳动者、两名死于监狱者，以及一名轰炸受害者；还有更多人在狱中遭可怕苦难。被驱逐者，他一无所知；其他人在集中营。有些转入地下，尽可能继续工作。神父常出现在修路架桥、田间和运煤<a id="pdf-290"></a><!-- PDF page 290; original page 271 -->车上的劳工队，“甚至参与拆毁犹太会堂”。家庭离开教堂时被捕，每个堂区都有神父失踪，格涅兹诺半数堂区已无教士。比得哥什仍有讲道，却用德语，弥撒后另加为希特勒祈祷。但教堂开放，人们仍涌入领洗、告解、领圣体。婚礼被全面禁止。学校宗教教育取消，十字苦像移除，各类天主教社团关闭。破坏圣像的报告不断：亵渎、污辱、征收、驱逐、流放。女性修会受到尤其严厉的攻击。[^p290-8]

波兰公教进行会中心波兹南，也发生同样情况：报纸取消，印刷所压制，学术机构关闭，广场出现行刑队。“整个领导阶层”被剥夺财产、逐出总督辖区，只有劳工和仆役不受干扰。波兹南的驱逐突然、残暴，每夜五百至一千五百人消失：“谁也不敢脱衣，因为限令离开的时间，近来已缩至几分钟。”许多人被分离带往德国，包括够年龄工作的男孩和漂亮女孩。其余用运牛车厢送往总督辖区；那里已大体被炸毁，农村被掠夺殆尽，人口严重过剩。赫隆德写道：“这一切都意味着灭绝，是以魔鬼般恶意构思、以无与伦比残暴实行的灭绝。”[^p290-9]

这些事情并未保密。前华沙天主教通讯社负责人、如今在伦敦担任波兰方面总统随员神父的卡钦斯基蒙席，其报告在罗马发表。德国报纸捏造波兰情况时，他坚决反驳，指其伪造、向世界撒谎，倚仗“人类轻信，以及经常遗忘的天赋”。[^p290-10]

1940年1月21日至22日夜，梵蒂冈广播电台向美国播出公报，随后以修改版本，用德语、西班牙语、葡萄牙语等重播：“教廷近来收到、并得到极充分证实的报告，说他亲爱的波兰再度承受殉道者命运，圣父对此深感痛苦，这已不是秘密；他仍满怀信心，坚信波兰必然复兴。”[^p291-11]

### 法国

法国也陷落，并被分区：北部包括巴黎的占领区，由德国当局治理；南部维希区由同情、顺从的傀儡国家统治，几乎立即以政府所在地维希，以及总统、退休将军贝当之名为人所知；东南另有小块意大利占领区。

法国天主教徒以各自方式反思六周便摧毁国家的灾难，这一戏剧性事件，引出对战败前所肯定的一切的鲜明争论。法国崩溃，毕竟也是一个特定国家体制第三共和国的崩溃，其政治家厌恶天主教权力。1870年以来，教会在全国公民生活中的存在被有意限制，被赶出法庭与学校，同时社会离婚率上升、出生率下降。法国共和主义很少努力克服古老反教权主义，以及对整个宗教的猜疑。正如德国基督徒在社会民主主义中找不到多少参与鼓励，法国天主教徒也难以在法国共和主义中找到位置。有些人宣称战败是对民族的审判，呼召回归上帝；在这一呼召中，维希政权带着欢迎微笑，敞开通往权力走廊的门。有些主教甚至抱怨，它以家庭、劳动、服务、悔罪与牺牲的新修辞，偷了自己的曲调。数十年来，天主教主教首次受到政客追求。对维希人物，协作的吸引力明显：这一实质上与占领者合作的国家，从一开始就虚弱，始终摇摇欲坠，需要建立可辩护的道德<a id="pdf-292"></a><!-- PDF page 292; original page 273 -->信誉。教会可说是国内残存最显著的公共机构与民众运动。把基督教附着于维希，是努力获得公众认可与道德正当性；并不是贝当在其他方面多关心教会，也不是维希要使国家教士化。如今给教会的一切，是为协调，而非出于信念。

许多主教似乎回应了示好。他们不能拥抱战败，也无法使时光倒流。普遍认为维希政权合法，基督徒应适当服从依法构成的权威。1940年11月，热利耶枢机欢迎贝当到里昂，宣称：“贝当就是法国，今天的法国就是贝当。”[^p292-12]1941年1月15日，枢机与总主教再度聚会，更有保留地肯定忠诚，谨慎把“合法权力”改称“既定权力”。[^p292-13]互惠举措顺理成章地跟进：1882年消失的公立学校宗教教育恢复，世纪之交被逐的修会获准返回。

教堂钟的命运，或许表现法国与注定受难的波兰的占领差别。波兰钟被禁鸣、运走、熔化；南特德军最初担心钟声可能号召起义，但很快放宽，赶上布列塔尼主保圣安妮庆日。波兰公共宗教被全面消灭，法国却有些模糊。德国人同意允许“纯宗教”游行，这自然引发不确定：何谓纯宗教？有些堂区神父因做了邻区神父不受阻碍的事而被捕。天主教青年运动遭禁，更因是青年运动，而非天主教；但有时改成体育俱乐部，当男女青年成队骑车穿越乡间，很难确定这是宗教，还是“超出宗教”。有时被禁，有时<a id="pdf-293"></a><!-- PDF page 293; original page 274 -->获准。这种对宗教表达与活动的混淆，或操控，不只存在世俗当局与教会之间，也存在教会内部。昂热主教告诉教士，应是宗教和道德性的，而非政治性的。1941年，他禁止一次母亲节礼拜，后来解释，原因是翻译意外。[^p293-14]

主教大体顺从，但不宜过于自信地概括。昂热主教顺从，南特主教却固执。当地德军司令部请求使用主教座堂为士兵礼拜，他拒绝，因为这是新教礼拜，在此处举行将是丑闻。主教毕竟应该辨识宗教问题。但此时，图尔与布尔日主教座堂早已用于这类礼拜。[^p293-15]巴黎总主教絮阿尔特别配合德军，参加全国委员会。神父在十个省级委员会任职，另二百人在市镇和县级工作。[^p293-16]

时间也带来态度变化，占领更加严酷。广泛忠诚宣示之内，某些独立生活仍找到呼吸空间。很快，法国天主教的差异，甚至矛盾，并不难发现。教士更明确成为民众不满的声音。有些占领初期即积极参与各种非法计划，有时获得上级默许，有时不顾其谴责。图尔圣马丁主教座堂主任罗班法政牧师，曾任随军神父，一度是战俘，为逃亡战俘提供庇护。后来，帮助扩展至犹太人和抵抗者，一条逃亡路线悄然从圣马丁延伸，经图尔宪兵队莫雷尔上尉，到阿泰堂区拉库尔神父、卢瓦尔河畔埃夫尔的莱尔米特神父，以及德拉谢的佩昂神父。代价很高。罗班幸存，后来任布卢瓦主教；莫雷尔被驱逐、处决；拉库尔与莱尔米特也被送往德国，从此消失；佩昂1944年2月被捕，在图尔遭盖世太保酷刑杀害。[^p293-17]修会中，持续可以听到<a id="pdf-294"></a><!-- PDF page 294; original page 275 -->批评：道明会士让·梅迪厄，以及耶稣会士加斯东·费萨尔、皮埃尔·夏耶与斯坦尼斯拉斯·菲梅的声音。有人从中看到天主教抵抗的根源。

### 挪威

1940年4月9日，德军突然占领挪威。国内虽有同情纳粹的民族统一党，却只是约四万三千人的边缘组织，过于虚弱，不能据此建立有效合作政府。挪威人压倒性敌视新权力，国王与政府流亡，常转向国教会，组织批判性回应。回应能有相当一致性与活力，很大程度归功于奥斯陆主教艾文德·贝格拉夫。

贝格拉夫专研政治伦理，战前已从德国新教同道的命运学到许多；奥斯陆主教主持年度主教会议，也使他在教会地位资深。他积极参与普世运动，朋友跨越许多传统与边界。战争爆发时，他忙于外交，探求是否仍能谈判和解。这少获赞赏，也很快被政治军事形势抛开；但本国被占领时，他找到更持久角色，把教会保持独立于不义政府的义务，与为人类寻求正义的同等责任紧密结合。工具就在身边：《奥格斯堡信纲》提供充分根据，使之精炼新政治神学；他所理解的路德，宣讲不服从的责任。他也利用正式结构的可能。纳粹教会部门从一边发指令，他新设的基督徒协商会（Kristent Samrad）便准备反驳。合作政府首脑维德孔·吉斯林自封最高主教，引发全教会忠诚危机，随后又因青年组织进一步紧张；近八百名牧师，即总数百分之九十三，完全切断与国家联系，主教随后跟进。1942年复活节，他们从讲坛宣告，不再享有正式地位与收入，也不再履行官方职责，转为人民的教会。

<!-- PDF page 295; original page 276 -->



运动在教会内部并非毫无争议。约六十名牧师继续维持国教，却鲜获会众支持。他们批评辞职者不过建立“贝格拉夫教会”；但这时可以看出，贝格拉夫本人已不甚控制事件，因为警方把他软禁家中，直至占领结束。这不是严酷囚禁，他也利用它，写出一系列切中问题的书。[^p295-18]1945年5月8日德军离开挪威时，约一百三十名牧师曾遭逮捕，但无人死亡，贝格拉夫也幸存。

## 欧洲犹太人的驱逐

欧洲被占领区教会，常抗议把青年男子遣往德国劳动；但后人写得更多的，是教会如何回应新德国当局迫害犹太人。

希特勒1933年1月上台后，几乎立即，德国以外便广泛知道犹太人在其统治下的困境。数月内，西欧与美国基督徒也广泛谴责。[^p295-19]1938年秋冬以前，回应难民危机的各种尝试协调不佳，在推动者看来羞耻地不足；但不能仅据此认为，他们无法清楚认识迫害意义，或基督徒应如何谴责。如今，1941年秋起，被占领欧洲的基督徒，在自己城镇中面对犹太家庭的大规模驱逐。

即便如此，接收、核实与解释信息，对教会当局似乎与对政府一样复杂。1941至1942年，许多人仍在评估传来的报告。若干历史学家<a id="pdf-296"></a><!-- PDF page 296; original page 277 -->认为梵蒂冈非常了解事态，但1942年，它似乎并不比其他政府或权威机构知道更多。[^p296-20]官员认为有理由犹疑。维瑟特·胡夫特后来回忆，日内瓦最初收到的是“相当神秘的信息，用希伯来词语躲避审查，难以解释”。到1942年末，碎片开始形成清楚整体，但即使此时，仍超出负责任者的相信能力。他又回忆，信息似乎“无效”，因为简直“不像真的”：“我必须承认，几个月后，收到的信息才完全进入我的意识。”促成这一点的，不是阅读报告，而是遇到一名瑞士商人；他赴俄出差时，德国军官曾邀请他亲眼观看大屠杀。胡夫特决心尽力促使政府明确回应，却发现极难推进。世界基督教协进会秘书处与世界犹太人大会合写的新备忘录，不过消失在国际官僚机构办公室中，毫无可见效果。[^p296-21]

德国教会无法组织一致回应。迪贝利乌斯、科赫、武尔姆与马拉伦斯等负责任职者的正式言辞，与迪特里希·朋霍费尔、威廉·冯·佩希曼、玛尔加·莫伊泽尔等人的愤懑之间，横着巨大鸿沟。纸面上，他们不共享基本词汇；生活中，接触又尴尬难堪。这些零散努力，没有形成清楚明显的形态。我们所见，是有意累积的备忘录、专家意见（Gutachten）与公开声明，来源各异，许多具有团体、总会或其他制度性质。教会领袖把它们作为反迫害证据，常作出过度声称。另一些学者则指出，这些资料中的妥协、失败、沉默<a id="pdf-297"></a><!-- PDF page 297; original page 278 -->与背叛；在他们看来，英勇抗议只是个别声音，沉没于宗教反犹主义、推诿、幻想与回避的海洋，无人理会。

权威机构可以声称代表性，但谨慎历史学家不能不加批判地接受。正式言辞当然可能激发正式或非正式行动，但其意义首先仍在集体体系的外交政治中，不易知道它在更广阔、有人生活的社会留下何种印象。无论声称多宏大，如何把声明同日常经验相连？我们仍只能抓住稻草，只继承片段与一瞥：柏林街头无人注目的瞬间，悄然递给拉比的一封配给券；符腾堡六十一所私人住宅，整个战争都藏着犹太人。[^p297-22]

柏林格吕贝尔牧师领导、低调有效的救济与难民机构，1940年12月被盖世太保关闭。他本人幸存，同伴叙尔滕博士几周内却被送进达豪，后来遭杀害。犹太人被命令佩戴黄星时，观察者记录了一些同情行为。维恩肯与贝尔宁主教，试图争取让犹太裔天主教徒在教堂内摘下黄星，连这也遭拒。1941年10月15日，德国开始驱逐犹太人。只有纳粹“德意志基督徒”运动表态支持新措施。贝尔宁认为严酷，再求改善，这次得到保证，很快却发现毫无价值。1941年11月，主教团抗议强迫犹太人离婚，主席贝特拉姆总主教却插入限定，谈及“犹太人对德国文化和民族利益的有害影响”，削弱声明。到1943年2月，混合婚姻中的基督徒也被驱逐。天主教主教谨慎地分别同情贝特拉姆，或艾希施泰特主教普赖辛；后者与法国萨利耶日一样，受过法律训练，从希特勒政权开始，就要求更强硬路线。如今，普赖辛要求对“一般犹太人”问题明确发言。[^p297-23]旁边又有反犹的格勒贝尔总主教激烈言辞。此外，<a id="pdf-298"></a><!-- PDF page 298; original page 279 -->柏林座堂主任利希滕贝格每日为犹太人祈祷，直至1941年10月被捕。审讯中，他回答，这些措施违反道德法，反转通常对《罗马书》第十三章命令的理解，为自己的反对辩护，并要求与被遣送者同遭驱逐。1943年10月出狱，立即由盖世太保押往达豪，却途中去世。[^p298-24]

主教、教士与平信徒密切交织。明爱会格特鲁德·卢克纳从弗赖堡帮助犹太人越境瑞士；她也于1943年11月被捕，送进集中营。柏林主要由犹太人居住的罗森大街，妻子们高声公开抗议，丈夫获释。这是突出事件，有人认为它表明可以做到什么，但它是特例。[^p298-25]

认信教会残存机构，直到1943年才组织回应：经过大量争论，几位平信徒写匿名声明，送给本地主教，也送给符腾堡武尔姆主教。1943年3月12日，武尔姆本人致信教会部，说这些措施“长久以来使我国许多群体，尤其基督徒群体，心情沉重”。担心外国政府借德国异议做文章，教会人士一直保持克制，但不能继续沉默。他于7月和12月再发两信，既送政府部门，也秘密传至各堂区。他毫不含糊，指出这是一种“未经法律定罪”而实行的“迫害与毁灭”政策，特别谴责对基督教婚姻中人士的待遇。他宣告：“这些目的，与已经针对其他非雅利安人采取的灭绝措施一样，以最强烈方式违背上帝诫命，摧毁我们全部西方思想与生活的基础，尤其我们关于上帝赋予人的生存权和尊严的根本信念。”[^p298-26]1943年10月，认信教会普鲁士总会发牧函，否认国家除罪犯或战时敌人外，有权杀人：“仅因属于外来种族，或<a id="pdf-299"></a><!-- PDF page 299; original page 280 -->年老、精神疾病，或是罪犯亲属而杀人，不能被视为行使上帝委托国家的权威。”[^p299-27]

法国教会对大迫害的回应，同样不可避免地零散。法国犹太人被命令戴黄星时，有公众同情的证据；但为驱逐奠定行政基础的1941年犹太人口登记，获得接受。教会领袖日益倾向允许此类行动原则，仅要求实践中施以仁爱。1942年7月巴黎首批驱逐开始，舆论反对，主教分裂。马赛与格勒诺布尔主教明确支持政策，多数宁愿沉默。里昂热利耶总主教是律师、威权主义者，钦佩佛朗哥，如今热情支持贝当，也同若干犹太官员保持友好。热利耶承认经济反犹主义的理由，却不接受种族论证。8月23日，萨利耶日总主教在图卢兹主教座堂讲坛宣读新牧函，宣布犹太人是他们的弟兄。尽管省长禁止，全教区各教堂仍宣读。南区五名主教抗议，三十多名没有；更重要的是，占领区无主教公开或私下抗议。多数承认存在犹太“问题”，萨利耶日和泰阿斯连这种说法也不接受。[^p299-28]

10月29日，絮阿尔与热利耶在维希会见贝当。会议充斥忠诚宣示，也标志对迫害关注减退。教会本身随后确有让步收益，天主教学院与其他高等教育机构获新补助，新教神学院也得到一些。此后驱逐不再像当年夏天最初几次那样规模大、引人注目。热利耶也许公开表态后不知如何推进，也许缺持久力量或意愿，最可能觉得问题热度已退。不论如何，他不会为之冒险破坏新协作。

很难衡量这些发言取得何效。萨利耶日的话广泛传播，引起振奋，抵抗刊物出版、天主教书店散发、自行车队跨国土传递。更远处，BBC广播，甚至远在<a id="pdf-300"></a><!-- PDF page 300; original page 281 -->纽约也发出这些声音。此后，抵抗运动显然更注意迫害。这也足以鼓励天主教报刊进一步发声，尤其直言的《基督徒见证》。若干修会积极行动。巴黎熙雍圣母会修女安排约四百五十名儿童藏于家庭，里昂同会修女忙于伪造身份证件。马赛嘉布遣会士皮埃尔—马里·伯努瓦神父，1942年11月后设法把约三万犹太人转移意大利区，又使四千人越境瑞士。夏耶与格拉斯堡两位天主教神父经营的“基督徒友谊”，尽可能把人分散到修会院舍与同情的天主教家庭。但这种事业不能持久。1943年春，盖世太保搜查该组织办公室，夏耶本人被迫躲藏。[^p300-29]

法国新教堂会为受迫害者行动，格外有力。天主教势力支配社会，新教徒长期感知自身脆弱，往往迅速认识对其他少数群体的责任。1941年3月，同时担任维希全国委员会成员的马克·伯格纳，致信达尔朗及大拉比伊斯拉埃尔·莱维，信件公开发表。他也很可能在那个夏天驱逐开始时，推动热利耶提出抗议。新教组织CIMADE，在玛德莱娜·巴罗与J. 德尔佩什领导下，积极藏匿、营救犹太人。或许更突出的是塞文地区散居小共同体的新教徒，他们在那里生活数代，甚至自十六世纪以来，迫害深刻刻入历史与身份。后来，他们甚至接收来自东欧的犹太移民。在勒尚邦、圣日耳曼德卡尔贝特等共同体，教师、牧师与公务员等地方负责人，表明小型而有同情心的公民社会，面对有组织恐吓与持续侵入，能够做到什么。战末，三千居民的勒尚邦，已藏过五千犹太人。[^p300-30]

荷兰教会当局，试图用尽一切反对驱逐。新教<a id="pdf-301"></a><!-- PDF page 301; original page 282 -->教会联合代表1940年10月24日抗议解雇犹太官员，从讲坛宣读，三天后又发宣告。《几乎太迟》小册子很快秘密散发全国两三万份。荷兰改革宗教会总会，1941年9月发表关于犹太人的牧函。1942年7月，天主教主教与新教领袖会面，致电帝国专员，抗议驱逐，警告准备公开反对。德国人因此提出交易：保持沉默，便释放所有1941年前皈依基督教的犹太人。乌得勒支总主教约翰内斯·德容不能接受这种区分，新教徒则倾向接受。德容立即发表为所有犹太人发声的牧函，随后遭报复。[^p301-31]所有非雅利安天主教徒被驱逐，包括皈依者艾迪特·施泰因。梵蒂冈黯然记下这一教训。

英国与美国公开抗议。原文记，1941年12月17日，英国政府在议会发表声明；约克大主教在上院加上愤怒谴责。[^p301-32]当人们发现所做太少，坎特伯雷大主教1943年3月在上院猛烈发言，要求政府允许团体签证，尽可能营救犹太人。[^p301-33]胡夫特鼓励这次介入，却收效甚微。新设基督徒与犹太人理事会，要求政府做更多，也为两种信仰持续关系建立牢固基础。同时，耐心而持续的工作，继续支持已抵英国海岸的犹太人。

## 第二次世界大战的遗产

战后，许多观察者认为，极权与冲突时代实际上使教会恢复活力。战前常听说，德国基督教在认信运动见证中，找到新的迫切感；战时又有人说，荷兰<a id="pdf-302"></a><!-- PDF page 302; original page 283 -->基督教也恢复社会身份与委身意识。一部分活力进入普世事业，并形成三年后促使世界基督教协进会诞生的新自信。西方新教在恢复民主的西欧，可能更容易觉得自身得到证明，拥抱未来。但1917年以来萦绕基督徒想象的共产主义恐惧，如今因战争结果，变成必须面对的可怕现实；共产主义已到门前。波兰、匈牙利、捷克斯洛伐克和德国东区基督徒，如今必须生活于新格局、新强加秩序之下，其后是空前强大苏联的全部重压。

就此而言，1939至1945年塑造新教与天主教徒生活的许多争论，并未随纳粹德国毁灭而终结，只是采取新形式。同时，二战成为他们持续自我辩护文化中的决定性经验，反复回顾。基督教既已存续，就必须表明自身是完整无损地存续。在这一背景，他们从漩涡中提取的名字与经历，为自我理解作出新而鲜明的贡献。有些名字退居背景，另一些在集体反思中重新焕发活力。新教与天主教的神学想象，许多方面已改变。不到二十年，界定那时代基督教的，不再是权威人物之名，而是年轻德国牧师迪特里希·朋霍费尔的新探索：他致命地卷入政治抵抗，在牢房写下惊人新鲜、富于远见的文字，并于冲突结束前不久被处决；[^p302-34]或是法国年轻女子西蒙娜·薇依神秘而有目的的理智精神，她与朋霍费尔一样，选择离开安全的美国，返回欧洲面对危险，甚至死亡。[^p302-35]两人都强烈委身于自由、开放地生活在世界，也感觉在正统与权威构成的教会内占有一席之地，<a id="pdf-303"></a><!-- PDF page 303; original page 284 -->必然既受限制，又痛苦地脱离他们希望投身其中、喧嚣前进的人类洪流。他们的人生与著述阐明这一令人不安的困境，因此也给后世基督徒，同样给历史学家，留下警示。
