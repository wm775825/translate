# 第十二章 加勒比与欧洲的非洲离散群体：从奴隶解放前到当代

**罗斯维特·格尔洛夫（Roswith Gerloff）**

> 原书第219—235页；对应原PDF第238—254页。

加勒比基督教史可以划分为四个主要时期，彼此有所重叠：1492年起相当单一的西班牙天主教，以及1620年起的英国国教会；十八世纪中叶起福音派或非国教传教士到来，包括摩拉维亚弟兄会、卫理宗、浸礼宗、公理宗与长老宗；1833年起的奴隶解放后时期，欧洲各宗派在当地巩固与发展，同时与不断涌现的独立黑人基督徒团体和非洲宗教保持不安的紧张关系；以及1870年后争取政治、经济与宗教独立的斗争，包括从英国帝国干预与影响转向北美影响，以及1962年后的国家独立。由于本丛书前几卷只简略讨论加勒比地区，本章在聚焦二十世纪之前，将较详细地处理早期历史。

当代宗教人类学和社会学研究谈论“流动中的宗教”，或跨境迁移与跨文化转化的过程，指的是塑造一个“多重处境世界”的动态、相互、暂时且多维的创造。这意味着，应把宗教视为文化与属灵现象；其“被视为理所当然”的本质，[^p238-1]其实来自跨文化、跨国家的相互影响、互动，以及对新环境、新发展与新相遇的持续适应。这里强调的是“一种理解宗教的新模式，重视过程与实践者，胜于形式与内容”：宗教，包括不同的基督教形式，回应不断变化的环境，并参与建构和<a id="pdf-239"></a><!-- PDF page 239; original page 220 -->重构文化与民族身份。[^p239-2]非洲大陆就是一个例子：它经历了跨大西洋奴隶贸易这种前所未有的强迫流亡的创伤，又在二十世纪下半叶全球化背景下，经历加速的非洲人跨洲迁徙。如今，西方世界面对本土宗教来到自身海岸，这些宗教又与处境化的基督教解释相互滋养。西方也不得不承认，这些当代形态并非新事物，在多面的历史中早有先驱。墨西哥湾与拉美大陆之间的加勒比地区，就是一例；历史与神学研究常忽略它，未充分肯定其独特经验。三百年来，这些岛屿在政治、经济和宗派方面，都是欧洲列强，尤其西班牙、英国、法国、丹麦与荷兰的“猎场”。然而，不同岛屿基层受压迫的共同体，包括原住民及从非洲、亚洲迁入者，在抵抗、争取生存与人的尊严时，对于塑造人们的经验、表达和身份协商，施加的影响，并不亚于试图对他们进行社会控制的欧洲主要国教与非国教差会。因此，当代跨境迁移过程的复杂性，必须参照这一过去，尤其西方殖民扩张与西方宣教运动来理解，反之亦然。可以把这段动荡历史，看作促成南方现代基督教全球性转型的因素，不仅在加勒比，也在非洲与亚洲。跨大西洋循环中双方的跨文化移植，以及基督教在不同处境中重新解释信仰的能力，共同形成一种认识：传统与活动相互覆盖、重叠、交融，在边缘创造新形式，从而挑战所有边界、排他教义与中心的有效性。

至少对曾被强迫离开故乡的人及其后裔而言，“非洲离散群体”概念已经成为切实赋予力量的工具，其基础是《圣经》的出埃及意象，以及忍耐、生存和坚守人的价值的历史。一些欧洲学者质疑这一用语，因为过去的<a id="pdf-240"></a><!-- PDF page 240; original page 221 -->强迫流亡与当今从非洲自愿移民之间存在历史差别，也因为从释经与语言角度看，这一概念可能引起犹太历史中受迫害的负面联想。但我们优先重视黑人自身的表达：几个世纪以来，他们受《圣经》解放故事启发，认同寻求“应许之地”的以色列，并发展出身体、文化与属灵的手段抵抗奴役。对奴隶而言，尤其十八、十九世纪加勒比和北美强烈的埃塞俄比亚思想兴起后，“非洲离散群体”概念确认了变化中的连续性，使他们得以采取另一种权力与命运解释，因此可用于描述过去和现在的过程。值得注意的是，如今大西洋两岸的非洲与加勒比青年，越来越受泛非主义和非洲中心主义所阐明的类似概念与价值引导。

西班牙天主教虽奴役原住民，并在其灭绝后奴役输入的非洲人，至少没有否认他们的人性；它以背诵形式教授称为《基督教教理》的“主要真理”，并允许他们受洗。相反，新教列强处于由制糖体系新技术、廉价劳力供应，以及同贸易对手竞争推动的资本主义经济中，把非洲奴隶仅视为动产与财产。尽管输入的黑人人口在各岛都占绝大多数，他们却不得接受识字或基督教信仰教育，也不得受洗。英国国教会作为种植园主阶层的教会，自1625年起在巴巴多斯，1634年起在尼维斯、安提瓜与蒙特塞拉特，1655年起在牙买加，成为占主导地位的基督教团体。教牧人员与教友从根本上同既得利益相连，无意处理奴隶骇人的处境，也无意把他们纳入公民社会。受贵格会抗议影响的人道努力，例如1701年成立的海外福音传播会（SPG）的工作，也无力改变整个从属与残酷体系。[^p240-3]不过，这一时期最显著的特点，“不是国教会未能对奴隶开展宣教，而是它对殖民社会中自由白人成员的生活，也没有产生任何影响”。[^p240-4]

在这种教会生活以欧洲思想、仪式与价值支配，并剥夺人的文化与灵性为背景的环境中，出现另一种宣教，以个人关怀和照顾奴隶为动力：1732年起的摩拉维亚弟兄会，1783年起的非裔美国浸礼宗，1787年起的卫理宗，1807年起的公理宗，以及1827年起的长老宗。《海岸与岛屿》[^p241-5]提到这种福音派宣教的五个据点或条件：一、应种植园主邀请进入的地方，摩拉维亚弟兄会利用了这一途径；二、城市自由奴隶的重要性，他们是卫理宗的出发点；三、加勒比内部强迫或自愿的奴隶迁徙的意义；四、军队所发挥的作用，例如非裔美国浸礼宗人士利尔，从美国逃往牙买加；五、1789年起各个以伦敦为基地的差会设立的传教站。[^p241-6]

从欧洲中心视角看，加勒比奴隶解放前的运动，被解释为十八世纪末人类政治、经济与哲学根本变化的一部分。非人道强制最终在道德上受到谴责，在法律上被废除。但柯廷指出，两类不同法案在时间上被便利地区分：废除奴隶贸易的法案于1807年通过，废除奴隶制度的法案，则分别见于英国1833年、法国1848年，原文将古巴与巴西均记为1880年。[^p241-7]解放到来时，带来了没有平等的“自由”、没有文化认可的“宽容”，以及缺乏基本人性尊重的宗教多元。工业革命、技术、粮食生产与国际贸易的新发展，继续保证欧洲社会政治利益的支配地位，使原有种族主义模式延续到十九和二十世纪。“反奴隶制运动……与自由放任资本主义携手并进。”[^p241-8]

但从非洲离散群体、奴隶与获释奴隶的角度看，故事必须换一种方式讲述。从一开始，就存在被动与主动的抵抗，常以宗教为动力。残酷镇压没有带来永久屈服，也没有熄灭自由精神和<a id="pdf-242"></a><!-- PDF page 242; original page 223 -->解放希望。除逃亡奴隶战争外，三百年间还发生五十多次重大奴隶起义，无一例外以逮捕、报复和处决告终。在非人待遇中，非洲人仍坚持自己的宗教世界观：“被连根拔离故乡后，他们维持了部分身份，由此填补教会只以不充分方式加以关照的真空。”[^p242-9]

试想，反对旧有教会传统的白人非国教传教士，如果不与非暴力黑人抵抗结盟，至少能够同情它，会是怎样！确有少数人如此，受到重经验、传福音热忱、平等信念与实践道德的引导。[^p242-10]但福音派宣教主要仍集中于奴隶的个人归信。在一个全然失去意义、充满破坏的世界，他们宣讲救恩福音，对种植园生活处境与要求具有同情和意义，因此帮助受压迫者获得个人完整与道德行为。他们不需要“组织化”宗教，把皈依者变为有效向他人传福音的人，因而迅速扩展。他们无意间在《圣经》与非洲—克里奥尔要素之间，引入一个跨文化接触面，虽还不是综合。这样，他们对既有体制和种植园主利益构成严重威胁，后来这将迫使他们在反奴隶制运动中采取明确立场。但在当时，他们对基督教的理解，仅指个人与上帝的关系，完全不涉公民或政治事务，反而使非洲人成为更有用的仆人。因此，在奴隶制问题上绝对中立，成为宣教政策的必要条件。此后几年，当他们自身也卷入冲突与迫害，仍认为鼓励暴力是不负责任的，只主张通过制度改革“改善”现状。但在奴役与不公问题上的这种“宣教渐进主义”，以及传教士对认真开展跨文化相遇的暧昧与无能，无法使黑人基督徒满意。传教士“抽象地接受黑人平等，却拒绝界定黑人生活的文化表达”。[^p242-11]

作为突出例子，我们集中讨论1783年进入牙买加、1812年进入特立尼达的黑人浸礼宗的宣教、策略与神学。[^p242-12]

他们吸收城乡大众，成为当局和种植园主对待奴隶的态度与做法最严厉的反对者，影响十九世纪整个解放前后时期，并引入一种解放与文化相互转化的黑人神学。关键人物是乔治·利尔（George Liele，亦作Lile），常被称为“黑人解救先知”。他生为弗吉尼亚奴隶，1773年主人释放他，使其运用属灵恩赐；1775年，他获按立及许可，向受压迫者宣讲、歌唱救恩。后来，他逃到牙买加，取得传道许可，1784年在金斯敦赛马场创立第一所“埃塞俄比亚浸礼教会”。在英国浸礼宗到来前三十年，他与其他美国获释奴隶，已为公开的非洲式基督教表达及“非洲灵魂的自由”奠定基础。他们因资金不足，又须对抗加剧的迫害和法律限制，包括1807年起的限制及1816年《牙买加奴隶法》，并希望使宣教纳入更有秩序的浸礼宗模式，因此向伦敦浸礼宗差会（BMS）求援。威廉·尼布等传教士自1814年起抵达，提供协助，而非监督。因此，1828年去世的利尔，有意无意地促成加勒比三项关键发展：一、黑人浸礼宗与英国浸礼宗之间总体友好的联系，尼布后来成为1833年英国议会废奴运动最直言不讳的倡导者，证明白人也转而投入黑人自由事业；二、本土浸礼宗运动诞生，促进非洲本土与基督教传统共生；三、为政治斗争准备肥沃土壤。

利尔及同工是没有正规教育的新教传教士，其影响却远超最初传道范围，因此应注意加勒比与非裔美国人之间的密切联系。他们绝不孤立。解放后，来自美国、巴哈马、圣多明各及新生海地共和国的黑人巡回传道人持续进入，加强宗教与文化网络，并在不同国家环境中创造不断更新的黑人基督徒抗议模式；这一切远早于泛非主义出现。

1824年，伦敦在当地建立主教制度，两个主教座分别设在巴巴多斯与牙买加。经过长期拖延，这是一项认真尝试，要使英国国教会摆脱对种植园主阶层的依赖，但收效甚微。无论福音传播会，还是年轻的圣公会差会，都无法推动“本土教会”，以<a id="pdf-244"></a><!-- PDF page 244; original page 225 -->在岛上受训的教士取代外籍教士。卫理宗最初主要从城镇“自由有色人”中吸收皈依者，也接触白人定居者，逐渐成为混血中产阶级的教会。到1824年，它已在加勒比各地建立据点。[^p244-13]担忧白人上层的暴力敌意，他们选择政治被动与虔敬温和。

黑人与白人浸礼宗则不能如此概括。威廉·尼布体现英国慈善家威廉·威尔伯福斯和托马斯·福韦尔·巴克斯顿“对待奴隶制的态度”。1823年，巴克斯顿在下院宣称：“奴隶制违反英国宪法与基督教宗教的原则”，因此必须在英国各属地逐步废除。[^p244-14]没有英国权力平衡的这种转移，解放不会到来。但过程中更重要的是黑人浸礼宗；白人浸礼宗越来越与其激进立场不一致。利尔依据《圣经》提出的新社会愿景，培育了社会与政治意识；但把它实际应用于持续压迫的现实，废除奴隶贸易后对自由与社会政治认可的进一步追求，以及基督教价值与非洲宗教实践的融合，都使他们偏离浸礼宗差会的官方立场。许多黑人浸礼宗信徒开始保持双重身份：在差会中是体面的基督徒，在岛上后院则是自由的本土浸礼宗信徒。

1831年圣诞期间，牙买加蒙特哥贝经历旱灾、洪水、饥荒与疫病后，爆发“浸礼宗战争”。最初，浸礼教会执事、富于个人感召力的领袖萨姆·夏普，把它组织为非暴力奴隶罢工。它把争取宗教自由解释为社会自由，形成一种新的宗教与政治领导形式，以“有组织的抵抗”回应“有组织的压迫”。[^p244-15]计划事先不为传教士知晓，虽宣称他们为盟友，却利用众多浸礼堂会的网络；这些堂会受《圣经》与热切祷告激励，亲自掌握事务。起义最终导致戒严，以及对<a id="pdf-245"></a><!-- PDF page 245; original page 226 -->叛乱者的无情报复，白人福音派也因被指合作而遭殃。1832年5月，夏普被公开绞死。传教士遭叛国罪起诉，却未能定罪，一些人离岛。欧洲基督徒终于被迫采取明确立场，再也不能以向奴隶制让步、承认无可争辩的财产权为工作前提。种植园主暴力回应，成立短命的“殖民地教会联盟”，试图把浸礼宗逐出岛屿，煽动暴民攻击非国教礼拜堂；[^p245-16]但在变化的社会气候中，联盟被当局取缔。1833年8月，英国议会通过《解放法》。起义的目标与策略，“把牙买加推入当时的革命主流，即争取法律保障的个人自由的斗争。它们迈出通向普选与民族独立那条漫长、曲折道路的第一步。”[^p245-17]

解放前，黑人及自由有色人基督徒的抵抗，确保其在十九、二十世纪继续。1834年8月1日，无一例外地被庆祝为“禧年之日”，依据《利未记》第二十五章。[^p245-18]此时，牙买加一半获释奴隶自称卫理宗、浸礼宗、摩拉维亚弟兄会或长老宗。他们认为基督教保护基本自由与平等。差会教会似乎给他们提供自尊、“以英国非国教模式为基础的体面”、[^p245-19]急需的教育、获得土地的协助，以及向上的社会流动。此前宗派冲突已让位于某种彼此容忍与合作，因此连圣公会也被接受为能够给予黑人与混血中产阶级体面及政治影响的教会。各教会都扩展。但热情过后，多数人发现，自己在社会政治和经济上并未获释，所设想的黑人与白人差会之间跨文化伙伴关系，也没有实现。希望开始消退，让位于幻灭。1834至1838年“学徒制”时期，被非洲人视为半奴隶制；该时期后，种植园主仍用惯常手段控制劳动力。因劳力短缺而从印度<a id="pdf-246"></a><!-- PDF page 246; original page 227 -->次大陆输入契约劳工，地区内及地区间的自愿迁移，以及英法为持续从西非迁入人口而制定、部分带强迫性质的方案，都便利了进一步剥削；但也增强流动人口的适应力，使他们接触新的、甚至革命性的思想。

1840至1870年，欧洲差会开展人道项目，在议会及其他教育补助支持下建立学校，并创立神学训练学院：圣公会于1830年设科德林顿学院，浸礼宗于1843年设卡拉巴学院。它们也前往非洲。不过，除浸礼宗外，它们在培养本土领导方面惨淡失败。1853年，黑人神父罗伯特·戈登申请在故乡牙买加参加圣公会事工，主教却劝他去非洲工作。[^p246-20]在它们看来，只有警觉监督、严格道德纪律，以及宣讲“纯正无染”的基督教福音，才能使黑人摆脱“异教”仪式与“迷信”，防止教会生活和神学混融。面对贫困、天灾与疾病，传教士热心“改善”底层处境，却忽略其他已经运作的力量和补救方式。基于肤色、文化优越感与社会地位的种族主义，在十九世纪下半叶甚至更加强烈。

只有浸礼宗，尤其本土浸礼宗，走向不同道路。按照特纳的说法，“本土浸礼宗”是众多团体的统称，黑人在其中“发展出内容上或多或少属于基督教的宗教形式，相比黑人或白人的正统教会，更贴近他们的需要”。[^p246-21]这些团体遵循会众制、非等级化原则，聚居数百个“自由村”，形成由非洲“妈妈”与“爸爸”领导的地方体系，采用增加独立成员身份的“班票与领袖”制度，并常以不合正统的方式表达信仰。1990年以来斯图尔特、戈登、西格尔、劳森、奥斯汀—布鲁斯等人的研究，[^p246-22]阐明这一存续至今的持久遗产。这也呼应二十世纪中叶以来，关于离散群体各地保留非洲要素的争论，或阿莱恩所称“变化中的非洲连续体”。[^p246-23]它证实两种相冲突的宇宙观、文化与神学，一种欧洲式，一种非洲式，在相遇和跨文化互动中，不断因与<a id="pdf-247"></a><!-- PDF page 247; original page 228 -->非洲持续联系而更新，开启相互滋养的过程，容许不同传统创造性综合，也使不同程度的混融不可避免。[^p247-24]柯廷针对1830至1865年提出“两个牙买加”的说法：本土浸礼宗已成为“另一种与欧洲传教士基督教竞争的宗教”。[^p247-25]

举两个例子即可。一是迈亚尔（Myal），牙买加一种有组织的非洲敬拜形式，也是最早有记录的非洲—克里奥尔宗教。[^p247-26]它提供对奥比亚、巫术或邪灵的保护，维护非洲“人生礼仪”，并成为医疗与医治实践的源泉。另一例，是本土浸礼宗把罪理解为巫术，“归为反社会者具有破坏性、使人疏离且以自我为中心的执念”。[^p247-27]黑人基督徒凭借现实感，把罪理解为破坏共同体的邪恶，包括奴役、不公、贪婪、不道德，以及现行制度中的双重标准。人通过归信得解放，通过洗礼得洁净，通过基督中的救恩得救赎。

这里简要比较本土浸礼宗神学，与五旬节运动的“黑人根源”，以及二十世纪初非洲本土教会的特征。五旬节运动和非洲本土教会，同样出现在寻求更好生活的穷人与移民中。与口传文化相近的共同要素，可以概括为：在敌对、暴力社会中重归属与亲属关系的灵修；把敬拜视为令人“感到美好”的事件与生命庆典，使每个人都成为参与者；把音乐、舞蹈、梦境、异象及其他出神现象[^p247-28]融入共同生活；个人委身于道德规范和“圣洁”；回应人们身体及社会需要的医治事工；把传福音理解为关照整个人，不把物质与灵性二分，并赋予力量打破种族、性别、阶级与文化壁垒；在基层开展、充满活力且给予日常生活意义的神学；在领袖、堂会与祷告会之间发展互助网络；以及对<a id="pdf-248"></a><!-- PDF page 248; original page 229 -->上帝之国中自由与正义的强烈末世期待，内含政治潜力。甚至当时当地黑人领袖被贴上“自封”标签这一事实，[^p248-29]也与一百年后欧洲教会及世俗当局对五旬节派牧师带偏见的接纳相对应。从西方角度看，他们仍无正当资格。

1842年，牙买加浸礼宗协会脱离伦敦差会独立，设立卡拉巴学院培训本土教牧，并创办牙买加浸礼宗差会。顺应时代潮流，他们开始赴非洲宣教。但黑人不满宣教立场中的双重标准，成员减少。尼布1845年去世后，浸礼宗差会秘书爱德华·B. 安德希尔，可称为“在牙买加问题上最后一位进步的英国浸礼宗声音”。[^p248-30]四十年代初，迈亚尔主义复兴，抵抗进一步的西方基督教化。因此，1860至1861年大复兴爆发，出人意料。它开启一个可称为基督教与非洲要素首次共生的过程，始于摩拉维亚弟兄会，传至卫理宗与浸礼宗，既受白人参与者推动，也同样受非洲—克里奥尔热诚信徒推动。威尔莫把它称为民间宗教的力量，彰显自身，“使身心维系在一起，抵御宇宙一切破坏性要素；换言之，是存在的力量、生存的力量”。[^p248-31]它受英美大觉醒影响，其戏剧性冲击来自非洲基督徒情感与身体的投入。归信基督、弃绝罪、祷告、医治和身体表现，都是组成要素。因此，最初欢迎复兴的福音派，开始害怕占据礼拜者的“狂烈之灵”，认为它与“内在平安喜乐”的灵相反，类似1906年阿苏萨街复兴所呈现的“冲突范式”。对牙买加复兴的口述研究仍太少，书面记录全出自白人。[^p248-32]不过，这一事件似乎与阿苏萨街以前非洲、亚洲及拉美类似、却较少宣传的“圣灵浇灌”及“神迹奇事”一致，参见《使徒行传》2:11。[^p248-33]在<a id="pdf-249"></a><!-- PDF page 249; original page 230 -->加勒比，它激发基督教更新，带来大量《圣经》，[^p249-34]并成为非洲宗教以不同混融程度大量涌现的分水岭。它使该地区呈现深刻宗教性，并确立解放思想与《圣经》意象，作为政治社会发展的指导原则：“一种在加勒比历史中体现出来的圣经诠释学。”[^p249-35]

1865年莫兰特贝起义凸显了这一点，它是通向变革、独立与黑人民族主义的里程碑，也说明本土与正统浸礼宗之间的疏离。主要抗议者把属灵与文化价值结合，作为社会抗议和政治解放的工具。圣托马斯的有色人地主、独立浸礼堂会成员乔治·威廉·戈登，进入政界，围绕人权、社会正义和土地分配，抨击总督爱德华·J. 艾尔。自由非洲人、浸礼宗执事保罗·博格尔支持戈登，于1865年10月带领群众游行至莫兰特贝法院，抗议中央政府。示威者与官员之间爆发暴力，军队和战舰被调来；数百名黑人，包括儿童与孕妇死亡，动乱遭残酷镇压。戈登与博格尔均被捕，经军法审判后处决。现代牙买加尊他们为民族英雄。艾尔总督被召回，但事件激起关于其行为是否正确的激辩。“牙买加问题”，连同对再次发生“印度兵变”或重返“野蛮”的恐惧，影响了后来给二十世纪造成可怕后果的伪科学种族理论。牙买加成为英国直辖殖民地。

十九世纪末，留存的非洲文化要素，体现于众多非洲—克里奥尔宗教中。有些反对基督教，在西方差会影响之外保持相对完整；另一些把非洲世界观与基督教解释融合，有效找到适应新社会环境与生活条件的办法：牙买加的康文斯、库米纳与波科马尼亚，特立尼达的尚戈与拉达，海地伏都教，古巴桑特里亚，以及圭亚那约旦派。真正的基督教创造，如特立尼达、格林纳达与圣文森特的圣灵浸礼宗，以及牙买加复兴派，后来影响加勒比人迁往欧洲的过程。

1870年起，随着英国国教会失去国教地位、美国在当地势力上升，以及美国福音主义新一波传教浪潮抵达，加勒比社会改变。不到三分之一人口属于圣公会，且常有双重成员身份。只有在巴巴多斯，英国国教会仍保持无可争议的权威，被称为“小英格兰”，这也体现于后来的移民模式。1893年设立的西印度圣公会教省，从未遏止基督教及非基督教团体进一步增殖，包括南部地区的印度教与伊斯兰教。它仍是由种族和阶级界定的“白人教会”，与卫理宗及摩拉维亚弟兄会一样，不支持本土领导。欧洲基督教宗派无疑助长了社会和种族分层的延续。在十九世纪后期至1962年独立之间，可以观察到争取自决的四股潮流：政治运动，宗教上的自由追求，加维主义与泛非主义的解放哲学，以及五旬节运动的爆发。

社会经济方面，一战打断欧洲甜菜糖生产，使1919年后蔗糖经济略有恢复。但两战之间的经济困苦，使工人脆弱，导致民众动乱，并催生工会与全国劳工运动，例如牙买加曼利和布斯塔曼特、特立尼达埃里克·威廉斯组织的运动。可持续发展仅从国际关系及依赖“先进”“第一世界”经济的角度来讨论：“奴隶制结束后，接着是殖民统治的束缚；殖民统治结束后，接着是充满漂浮不定的幻灭感的民主。”[^p250-36]

宗教上的自由追求，可以从新兴复兴主义中观察；它把救赎观念带入牙买加街头与后院。“锡安复兴”希望医治个人与共同体，把核心基督教要素与特定非洲—克里奥尔观念融合。其医治事工“虽为传教士所厌恶”，却依据《圣经》实践。[^p250-37]我对牙买加圣安早期五旬节使徒运动的研究，发现其内含复兴派要素，包括医治恩赐、梦境与异象、灵的附身、秘密语言或“陌生方言”、歌舞、预言，以及在<a id="pdf-251"></a><!-- PDF page 251; original page 232 -->海中施行浸礼。[^p251-38]二十世纪七十年代，英格兰有带复兴派特征的堂会，如今已被五旬节运动吸收。不同的是，圣灵浸礼宗融合基督教与约鲁巴宗教，与五旬节派竞争，至今仍在伦敦拥有大堂会。所有这些运动，包括复兴主义之父亚历山大·贝德沃德的弥赛亚式行动，都抛开组织化宗教，对《圣经》实践、“在圣灵中”的自主，以及对人类救恩的信仰，作出新鲜、甚至不寻常的表述。

世纪之交，新的福音派差会抵达，包括救世军、守安息日派与圣洁教会。牙买加救世军在拉格伦·菲利普斯领导下，转为“光明旅”；他去世后，又转为国际城市差会，成为由两位女主教领导的著名牙买加五旬节教会，在北美、巴哈马，后来在英国设有分支。[^p251-39]基督复临安息日会原为美国白人宗派，1903年起在加勒比建立，经过多年，凭借女先知怀爱伦的反种族主义立场、医疗教育活动与末世教导，转变为真正的“第三世界”运动，对二十世纪五十年代以来英国复临派产生深远影响。英国黑人复临派培育赋权神学，重共同体与平信徒，并把社会关怀纳入传福音的理解。圣洁运动，尤其巴巴多斯的卫斯理圣洁教会与朝圣者派，也来到英国；它们同样继承反奴隶制传统，与穷人工作，采取非等级结构，并推动女性解放。

加维主义发展出一种以神学为动力的政治解放哲学。这里可见与南非类似的发展：非洲本土教会既包括“圣灵教会”，即锡安派，也包括埃塞俄比亚教会。马库斯·加维1887年生于牙买加，在卫斯理卫理宗传统中成长，却深受罗马天主教影响，游历广泛。他在哥斯达黎加、巴拿马与厄瓜多尔工作后，1912年来到伦敦，接触泛非主义。1914年，他返回牙买加，组织世界黑人进步协会，旨在把所有离散非洲人联合为自治的“一个伟大整体”。其黑人民族主义的先驱，是泛非主义者关于“宣教移民主义与种族命运的黑人神学”；[^p251-40]这类人物包括爱德华·威尔莫特<a id="pdf-252"></a><!-- PDF page 252; original page 233 -->布莱登，原文也称他为牙买加人；他与非裔美国人中的其他人士，在非洲“故土”与离散非洲人之间建立牢固联系。加维对加勒比文化与政治的影响，无论怎样评价都不为过；在宗教方面，他也培育《圣经》愿景。在他支持下，安提瓜人乔治·亚历山大·麦圭尔创立非洲正教会，影响及于乌干达与肯尼亚。重要的是，二十世纪三十年代起，牙买加拉斯塔法里运动开始尊他为首要先知之一。到1973年，其“非洲属于非洲人”的格言，已内化为“内在国度”；拉斯塔法里信徒也迁往欧洲，并邀请最古老的非洲基督教会之一埃塞俄比亚正教会，进入英格兰与加勒比。这一运动强烈影响英国年轻的非洲—加勒比世代，并继续挑战黑人五旬节神学。许多黑人青年如今转向伊斯兰民族组织。

长期以来，无论欧洲还是加勒比的学院神学，都因认为全球五旬节运动不够体面而忽略其爆发；加勒比五旬节运动的出现，也常被解释为美国白人的输入，与政治和发展无关。事实远非如此。奥斯汀—布鲁斯指出，在浸礼宗退出后，“下层阶级需要一个强大组织，推动其生活重获活力”。[^p252-41]我自1973年起研究英国黑人教会运动，发现五旬节派与复临派，是加勒比基督徒迁移中最强的力量。这些发现，也与近来有关亚洲、非洲和拉美五旬节及灵恩教会的研究一致。[^p252-42]1980年，韦德诺亚把牙买加五旬节运动解释为一种积极力量，帮助人们应对独立后剧烈社会文化变迁：“技术经济发展、城市化、日益富裕和社会流动、对社会进步的新期待、中产阶级扩大、更民主的政治，以及物质主义。”[^p252-43]二战终结欧洲支配，迫使英国拆解庞大帝国，“促使新国家从殖民子宫中诞生”。[^p252-44]黑人五旬节运动，可视为这些<a id="pdf-253"></a><!-- PDF page 253; original page 234 -->本土斗争不可分割的一部分，在视野不断开阔中，反抗并超越过去的霸权。

颇具讽刺意味的是，1948年后大多数赴英加勒比移民，自认是“祖国的孩子”：他们是曾在军队中反法西斯的英国公民，如今应伦敦交通局、餐饮业协会及国民医疗服务体系邀请，帮助重建英国经济。西印度的失业与灾难促成这一过程，而关闭赴美大门的《麦卡伦—沃尔特法》又使之加速。但新来者一开始就遭遇文化冲击，在住房、劳动、教育，甚至教会中，面对种族歧视。五旬节派回应这种被拒经历，为人们提供“属灵之家”、自尊、“圣洁”纪律下的生活、信心与全面保护。主日敬拜成为主面前欢乐的聚会，在一周艰难中庆祝祝福。既有宗派中的黑人加入独立团体，或保留双重成员身份。他们深知，自己属于一个因大西洋两岸持续往来而保持活力、反对英国单一文化主义的扩张运动。他们创造象征空间，让“圣徒”找到一种不同于英国社会历史上强加身份的认同，其来源并非特殊性，而是共同人性。[^p253-45]因此，英国黑人五旬节神学，从来不只是美国福音主义的分支，而是经受时代风暴的真正加勒比创造。

现代英国的主要组织，包括源于美国白人、持三位一体信仰的上帝教会，1918年在牙买加起步；以及最大的非裔美国五旬节教会“基督里的上帝教会”，1952年起开展工作。独一神论五旬节，即使徒运动，自1955年起跟进，非洲本土教会则在六十年代进入。加勒比布道家与主教[^p253-46]备受尊敬。加菲尔德·T. 海伍德是W. J. 西摩的朋友、早期非裔美国五旬节领袖中的巨人；人们记得他1931年访问牙买加，成为阿苏萨街的活记忆。加勒比五旬节派起初需要美国认可，英格兰的五旬节派也一样，最初与美国总部密切联系。但很快，适应<a id="pdf-254"></a><!-- PDF page 254; original page 235 -->新处境的过程开始：一些堂会希望自主，另一些因种族或性别问题分离。这又与牙买加类似，例如当地五旬节使徒运动必须摆脱美国分支的白人至上主义；[^p254-47]英格兰黑人五旬节派也开始反对美国白人支配，这项任务仍未完成。总体而言，只有那些在“故乡”已经充分本土化的教会，才成功巩固英国工作。目前，新约上帝教会仍由田纳西州克利夫兰治理，其部分领袖正试图克服依然内在的种族主义，推动组织真正“国际化”。遍布英国、以黑人为多数的教会，有些组织成教会协进会，有些与英国机构互动；除上述团体外，还包括最早的非洲卫理宗、圣公会大公派五旬节教会、来自尼日利亚与加纳的各类非洲本土教会，以及不断发展的非洲灵恩教会；后者属于1980年起全球化背景下世界五旬节运动的“第三波”。

非洲与加勒比基督徒之间搭桥，仍远不尽人意。非洲加勒比福音联盟认为，许多非洲本土教会过于沉浸在非洲传统宗教中，令人遗憾地重演历史。激进黑人学者虽在加勒比历史与神学中运用非洲遗产，却似乎避免介入当代非洲人的事务。英国教会与非洲离散群体的对话，例如1978年起伯明翰黑人与白人基督徒伙伴关系中心推动的对话，并未如期待般进展：文化与神学上以白人为主的教会，仍留在自身领域，黑人教会则开始模仿西方宗派主义。二十世纪八十年代起，欧洲大陆英语与法语非洲教会数量增加，主要属于新灵恩类型。加勒比与非洲教会跨越欧洲国家的国界和语言壁垒，开展充分互动，例如近期成立的非洲取向基督徒共同体协进会所发起的互动，仍处于萌芽阶段。
