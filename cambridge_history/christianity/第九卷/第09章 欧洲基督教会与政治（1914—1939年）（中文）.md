# 第九章 欧洲基督教会与政治（1914—1939年）

**马丁·康韦**[^p170-1]

> 原书第151—178页；对应原PDF第170—197页。

如果在1939年夏天考察欧洲基督教会的权力与影响，大体会得出悲观结论。无论在欧洲仅存的少数议会制国家，还是在日益成为新常态、种类繁多且数量不断增加的威权、准威权或彻底独裁政权中，基督教会、政党与价值观的影响，似乎都比第一次世界大战爆发以来的二十五年前显著衰退。在欧洲许多地方，社会主义仍扎根于十九世纪起源时期的反教权文化，却已成为重要的选举力量，并不时在许多国家执政。此外，第一次世界大战后社会主义的分裂，产生了战斗性的无神论共产主义；尽管它一再未能把权力扩展到苏联疆界以外的欧洲地区，到二十世纪三十年代，仍已成为欧洲政治中持久存在、在某些地方颇为重要的力量。不过，最具戏剧性的趋势，无疑是出现了一些独立于基督教思想、甚至明确敌视基督教思想的右翼政治形式。右翼这种“去基督教化”的某些因素，至少在十九世纪中叶已然可见，但第一次世界大战后才具有鲜明的重要性。意大利法西斯主义与德国—奥地利纳粹主义，都是不同思想影响的混合物，彼此不一，且极不稳定；其中源自天主教，以及德国情况下源自新教的基督教思想，都占有重要位置。然而，到二十世纪三十年代，两者都已发展为某种国家权力形式：它们不愿直接挑战教会权力，也争取基督徒舆论，同时却在统治精英和地方官员中普遍存在<a id="pdf-171"></a><!-- PDF page 171; original page 152 -->敌视有组织教会和独立基督徒行动的态度。

从某些方面说，这种悲观并不恰当。在英国，除北爱尔兰和苏格兰低地外，虽然不存在明确的宗派政治形式，圣公会价值观仍以较不显眼但切实的方式影响保守党，各种宗派，尤其非国教新教宗派与天主教，也影响着工党。在环境十分不同的爱尔兰自由邦，情况大体类似：两大主要政党，统一党与共和党，都接受天主教对新国家政治的文化影响。波兰、匈牙利，以及1938年德奥合并之前的奥地利，其半威权政权也逐渐认可与天主教会和解的好处，匈牙利还包括与新教教会和解。此外，在天主教欧洲许多仍实行议会制的国家，即比利时、荷兰、瑞士，以及1939年灭亡前的捷克斯洛伐克，天主教政党在国家和地方政治生活中都占有重要地位。更直接的是，1939年春西班牙内战中国民派获胜，结束世俗的共和政权，建立佛朗哥独裁统治；它与二十世纪三十年代初以来在葡萄牙确立的萨拉查政权一样，给予天主教会及其附属机构大量特权与权力。同样，1939年3月统一的捷克斯洛伐克国家崩溃，促成一个威权斯洛伐克国家的建立；在约瑟夫·蒂索领导下，它具有浓厚的天主教，甚至教士政治色彩。[^p171-2]

然而，大多数欧洲基督徒眼看本大陆在二十世纪三十年代初到四十年代初之间，断续却无情地从多边外交走向局部冲突，最终走向全面战争，感受到的主导趋势，大概仍是基督教价值观在公共与政治生活中的边缘化。苏联、纳粹德国与法西斯意大利的教牧人员和平信徒活动者遭受歧视，有时遭迫害；1936年西班牙内战初期，共和派控制地区又出现反教权暴力。这些似乎都标志着欧洲在无情的世俗化道路上又迈进了一步。不过，<a id="pdf-172"></a><!-- PDF page 172; original page 153 -->这一问题比教会与其思想对手之间的斗争更为深刻。二十世纪最初几十年，许多欧洲国家围绕教会公共角色产生制度与政治冲突，表明双方的边界始终受到争议：一边是现代国家机构普遍涵盖社会的范围和理性化抱负，另一边则是构成二十世纪欧洲基督教会的特殊混合体，包括教会等级体系、平信徒组织，以及社会和经济机构。在这种情况下，政教冲突并非不可避免，却也不容易避免。为回应这一威胁，天主教会，以及行动更迟疑的新教教会，通过鼓励建立基督教政党，进入大众选举政治的新领域；这些政党在1914年前取得了若干重大选举胜利。[^p172-3]然而，第一次世界大战后，基督徒政治动员的黄金时代似乎已经过去。新政党争夺基督徒的政治忠诚，侵蚀宗派政党的选民基础；思想和社会阶级的分裂，也削弱了宗派团结的理想。因此，到二十世纪三十年代末，不仅不可能佯称教会置身政治之外，也很难说它们在政治中正在获胜。

然而，选择何种年份作为终点，从来不是中性的。如果不选1939年，而选1949年或1959年，便会出现相当不同的图景。战后欧洲的分割，固然把苏联对教会独立、甚至有时对宗教实践本身的不容忍，延伸到中欧腹地；但在非共产主义欧洲的其余地区，基督教政治迅速取得更有影响力的地位。从第三帝国崩溃，到二十世纪六十年代末、七十年代初社会政治动荡之间的二十年里，基督教民主党派通常以天主教徒为主，也在一些国家具有跨宗派性质；它们取得显著政治优势，世俗右翼，某些情况下还有左翼，则付出代价。其选举成功归功于基督教思想的程度，可能低于政党领袖乐于相信的程度；但这些政党的崛起，推动了二十世纪四十年代末西欧政治生活中可以称为宗教“重新居中”的过程。诉诸基督教价值观，成为冷战时代精神的一部分；教会等级体系，尤其教皇制度，在公共生活中更加显著；基督教的教育、社会与福利组织网络，<a id="pdf-173"></a><!-- PDF page 173; original page 154 -->在许多欧洲人的日常生活中发挥重要作用。这种战后基督教，尤其天主教优势地位的许多原因，在于第二次世界大战及其长期余波；但它也很大程度上有赖于此前几十年间，基督教会在制度和思想上的变化。虽然不利的时代环境阻碍了这些创新立即发挥作用，它们仍使基督教政党得以在1945年后，以自信而强大的力量登上政治舞台。[^p173-4]

因此，本章讨论的1914至1939年，在二十世纪欧洲基督教政治史上，并不具有明显的统一性质。从十九世纪视角看，这一时期欧洲政治生活中独特的基督教力量，似乎正在经济、思想与军事冲突的动荡中瓦解；但从战后几十年的角度看，它又是一个形成期：基督教运动与组织逐渐成功阐明一种现代民主政治形式，后来在二十世纪下半叶的非共产主义欧洲发挥重要作用。当然，两种解释实际上都成立。它们也说明了二十世纪欧洲宗教与现代化之间关系的复杂性。宗教信仰史学家早已表明，简单把现代化等同于世俗化，会使人误入歧途。从十九世纪中叶起，规模巨大的社会经济变迁，在短短几代人之间改变了几乎所有欧洲人的生活，也扰乱了教会和宗教实践此前在欧洲许多生活领域中的中心地位。教会与新城市社区人口失去联系，公共和私人机构接管了其许多社会职能，挑战基督教价值观的信仰体系也随之出现。但与此同时，这些过程加速形成了信仰更加坚定的信徒共同体，鼓励新宗教信仰形式的发展，并为教会传播信息提供了新手段。因此，现代化实际上并未把宗教信仰与民俗服饰、马车一起送进博物馆，而是开启了一个竞争时期：既有基督教各宗派之间的竞争，也有它们与其他争取二十世纪欧洲人心智的意识形态和运动之间的竞争。

这些现代化过程的不同结果，在二十世纪初和中叶欧洲基督教政治的不同格局中清楚可见。马德里、巴塞罗那等一些大城市大体去基督教化的面貌，与荷兰及德国西部工业地区宗派组织更为扎根的地位，形成对照。在欧洲农村，法国南部大部分地区及意大利中部一些地方的世俗政治，也与西班牙中北部、德语瑞士的基督教政治运动的持久性大为不同。因此，若把这一时期欧洲基督教政治的演变简化为衰退或复兴的单一叙事，就无法充分说明宗教信仰程度和政治文化的众多差异。此前半个世纪，基督教会在欧洲各国的宪法与公共地位，沿着极不相同的道路演变。在北欧大部分地区，新教教会仍与政治及宪制秩序紧密相连；而在以天主教为主的欧洲各国中，那些十九世纪后期教权与反教权力量斗争最激烈的国家，教会与国家则作为彼此猜疑、常常敌对的机构相互对峙。这些差异又反映在基督徒政治动员的不同模式中。斯堪的纳维亚大部分社会几乎全由新教徒构成，教会地位大体不受挑战，因而妨碍了独立基督教政治的出现。相反，1914年前西班牙、葡萄牙与法国激烈的政教斗争，则把宗教信仰与政治投入紧紧联系起来。民族认同与宗教认同之间复杂的联系，又构成多样性的一个来源。1900年至二十世纪二十年代，许多民族国家逐渐取得完整国家地位，尤其芬兰、挪威、波罗的海诸国、波兰、捷克斯洛伐克和爱尔兰；在这些国家，争取民族独立的世俗斗争，常与宗教和宗派身份问题不可分割。因此，一战后波希米亚对天主教哈布斯堡统治遗产的拒绝，使新生捷克斯洛伐克国家染上新教色彩；而在爱尔兰，从英国统治和暴力内战中艰难诞生的自由邦，则促成天主教与某种特定爱尔兰民族主义定义之间的持久结合。[^p174-5]

尽管存在上述多样性，欧洲基督教政治中最明显的分界，仍在于两类国家之间：一类是从低地国家横贯欧洲、延伸到中欧与意大利北部的中央地带，基督教政党在公共生活中十分显著；另一类是北欧与南欧国家，清晰可辨的基督教政治传统不太明显。比利时、荷兰、德国西部、瑞士和奥地利，尽管常经历创伤性的政权更替，整个二十世纪上半叶仍保持基督教政治的连续性；第二次世界大战后政治环境较为稳定时，这一传统得以充分发展。在这些地区，基督教政党的影响，与更广泛的社会“支柱化”进程不可分割；在这一进程中，宗派机构承担了广泛的社会和经济职能。十九世纪末成立的基督教福利组织、工会、妇女组织及农民联盟，在全国和地方生活中一直占有重要位置，直到二十世纪六十年代宗教与社会发生断裂，并为政党建设提供了组织基石。[^p175-6]这与南欧天主教国家，尤其西班牙、葡萄牙和意大利，形成鲜明对照：支持教权与反教权者之间“文化战争”的历史遗产和现实，使教会及其附属机构的社会地位受到更多争议。另一些国家则又不同，尤其共和制法国和北欧议会制国家；国家与地方政府机构的支配地位，使教会的中介角色边缘化，也抑制基督徒以独立政党形式进行政治动员。

从某些方面看，这一分界沿着天主教统一结构，与新教更加多样、内部分化的格局之间的边界展开。最简单地说，基督教政治动员在中欧天主教徒占多数的地区最强，并非偶然。从十九世纪中叶到二十世纪中叶，等级化且日益统一的天主教会的现代发展，对天主教政党的出现产生多重影响。这些政党以对教会机构的组织忠诚，以及共同属于天主教<a id="pdf-176"></a><!-- PDF page 176; original page 157 -->“想象的共同体”的身份，维系在一起。促成天主教政治兴起的因素，在新教中大体缺乏。且不论天主教会与各新教宗派资源上的不平衡，新教教会更分散、更地方化的结构，也阻碍了纪律严明的政党的出现，而这种政党是大众政治动员时代取得成功的必要条件。例如，瑞典自由教会运动在1914年前名流主导的议会政治中发挥重要作用；1917至1918年宪制剧变后，它被大众政治吸纳，这一作用随之衰退。[^p176-7]瑞典自由教会运动决定不把自己转变为政党，而让成员以个人身份参与不同政治组织，也反映天主教与欧洲各路德宗、加尔文宗之间更广泛的性情与神学差异。天主教会在一系列精力充沛的教皇领导下，强调一种包罗万象的天主教世界观；新教宗派则主要把精力集中于教义和内部组织事务。这并不排除政治参与，却使此类行动往往集中于特定议题，而非建立独立政党。

然而，也不应过度强调天主教徒与新教徒的二分。二十世纪初活跃于欧洲、数量庞大且不断增加的新教教会，内部取向从某些群体严格的不问政治，到北欧某些国教会的高度政治化，跨度很大。加尔文宗的反革命党（Anti-Revolutionaire Partij）的例子，表明新教政党在荷兰支柱化社会中可以发挥强大作用。[^p176-8]此外，其他欧洲国家没有明确的新教政党，并不意味着新教徒在政治议题上保持中立。在天主教占多数的国家，诸如捷克斯洛伐克和法国，新教少数群体的政治存在感与影响力，超过其人口比例；对许多新教国家选举资料的考察，也显示积极参加教会与支持特定政党之间的联系。新教对欧洲政治的这种“影子效应”，<a id="pdf-177"></a><!-- PDF page 177; original page 158 -->在危机时期又由更明确的政治动员所加强。二十世纪二十年代的德国清楚体现了这一点：主要属于路德宗、以普鲁士为取向的各邦教会，是魏玛共和国世俗原则最公开的反对者之一，并为反共和右翼的动员提供社会与思想焦点。[^p177-9]

因此，1914至1939年欧洲基督徒政治参与的模式，并无简单逻辑可循。相反，存在着一系列相互重叠、有时彼此矛盾的趋势，其相对重要性随宗派、时期，尤其地点而变化。不过，超越这些无法化约的差异，最重要的共同主题，是基督教力量嵌入二十世纪欧洲的社会政治结构。十九世纪政教关系中，两个相互竞争的权力时而合作、时而竞争、时而冲突；经过这一过程，二十世纪初和中叶的主要特点，则是政教边界日渐模糊。国家对宗教，尤其对教会非宗教活动的介入不断增加；但基督徒作为集体和个人对政治领域的参与也同样增加。如前所述，这一参与形式多样，成败程度各不相同。然而，到二十世纪中叶，在苏联疆界及其1945年后势力范围之外，出现了双重结果：基督教力量在欧洲政治生活中持久确立；在国家与社会日益复杂的互动中，教会及其附属机构也巩固了重要、且常有特权的对话者地位。

这两种结果都不是预先注定的。在欧洲从1914年走向第二次世界大战混乱、时常喧嚣失序的演变中，它们也都不显得很可能出现。因此，若要探究基督教力量何以嵌入二十世纪政治，就需要在一定程度上跳出更为熟悉的两战之间欧洲叙事。第一次世界大战的复杂遗产、共产主义与法西斯主义的出现，以及二十世纪三十年代初的经济萧条，对基督教政治演变的作用，都比乍看之下所预期的有限。影响更大的，是在战争、<a id="pdf-178"></a><!-- PDF page 178; original page 159 -->思想冲突与政权不稳的喧嚣之下持续展开的长期政治变迁。在这一过程中，三个因素尤其重要：各教会共同体中结社原则的活力；欧洲基督教内部的思想与社会变化，它们加强了宗教信仰与政治投入之间的联系；最后，欧洲政治本身的变化，为基督徒政治行动创造了更有利的环境。

这三个主题中，第一个或许最不需要解释。至少从十九世纪中叶起，欧洲基督徒生活最普遍的要素之一，就是把宗教实践的仪式转化为一个边界可辨的信徒共同体；其成员通过日常生活中的价值观和选择，展示对自身信仰的归属。从教会面向全民的抱负，转向巩固一个规模较小的信徒次级共同体，这一变化在不同宗派和地区的速度各异。但到二十世纪最初几十年，其结果是在属于教会的人与有意识或默默不属于教会的人之间，建立一道相对固定的围栏。围栏内外的人口比例差别极大：在荷兰南部以天主教为主等一些共同体中，宗教归属几乎覆盖所有人；而在法国中部某些地方，参加教会的只是少数。不过，比人数更重要的，是正式或非正式地属于信徒共同体所产生的投入感。以教会为节点，周围聚集了广泛的附属机构，从学校与福利组织，到体育俱乐部与青年团体。欧洲社会由此在内部划分为天主教徒、新教徒，以及社会主义者、自由派等非宗派群体所组成的次级共同体，这种“支柱化”现象的程度各不相同。它在天主教欧洲的一些地区最为明显，例如低地国家、德国西部与奥地利，但几乎到处都能发现痕迹。瑞士历史学家乌尔斯·阿尔特马特提出一个颇具影响的说法：天主教徒建造了一个“隔离区”，保护信徒免受世俗现代性的陌生价值观侵袭。[^p178-10]然而，支柱化虽然是对现代性的反应，也成为欧洲基督徒共同体进入现代世界的载体。通过建立自成一体的天主教，以及在<a id="pdf-179"></a><!-- PDF page 179; original page 160 -->较小程度上的新教宗派组织的支柱化结构，欧洲基督徒得以对现代欧洲的社会结构施加强大影响。

这一支柱化进程的政治后果相当重大。十九世纪后期，许多欧洲国家基督教政党的迅速发展，很大程度上得益于它们能够在宗派协会网络之上，建立政治上层结构。一战后情况仍然如此。两战之间欧洲的主要天主教政党，尤其德国中央党（Zentrumspartei）、奥地利基督教社会党（Christlich-Soziale Partei）和比利时天主教党（Union Catholique Belge–Katholiek Verbond van België），很大一部分稳固性，来自它们与其说是自立的政党，不如说是地方上扎根于众多天主教社团的机构。[^p179-11]实际上，天主教共同体，以及某些地区的新教共同体，在政治领域迅速而有力地动员的能力，与其他政治传统之间存在差距。意大利与西班牙都清楚体现了这一点：一战后意大利动荡的政治中，意大利人民党（Partito Popolare Italiano，PPI）迅速扩张；西班牙第二共和国时期，西班牙自治右翼联盟（Confederación Espanola de Derechas Autonomas，CEDA）迅速发展，均受益于天主教结社生活提供的组织框架。两战之间天主教政党的竞选文献，反复以堡垒比喻受围困的共同体，这主要是一种修辞手法；但其力量来自宗派团结感，而这种团结感由构成许多欧洲天主教徒生活结构的宗派学校、工会和福利组织所产生。[^p179-12]

然而，到两战之间，这些政党的鼎盛时期在许多方面已经过去。有些政党仍有可观的选票支持：例如，荷兰天主教国家党（Rooms Katholieke Staatspartij，RKSP），从1920年至二十世纪六十年代，每次全国选举据估计都获得荷兰百分之八十至九十天主教徒的支持。但更常见的，<a id="pdf-180"></a><!-- PDF page 180; original page 161 -->则是德国中央党及其巴伐利亚对应政党巴伐利亚人民党，虽缓慢却显著地衰退。1920年，它们赢得近百分之六十三的天主教选票；到1932年11月，这一比例已降至百分之四十七。[^p180-13]1914年前的天主教政党，主要是防御性组织，常在教士严密控制下建立，目的是团结信徒，维护特定宗派利益，抵御被认为来自敌对政府，以及无神论的自由主义和社会主义的威胁。一战后，这种政治动员模式不再同样有效。教牧人员受到教皇新的属灵优先事项影响，普遍倾向于退出对政治生活的直接参与。平信徒也更加自信，更不愿在政治问题上接受教士指挥。新一代天主教与新教平信徒领袖已经成熟；在他们看来，政治行动与其说是捍卫教会利益，不如说是依据基督教信仰原则，介入当代政治与社会问题。然而，从防御性团结转向更广泛政治投入的心态变化，不利于统一原则。基督教政治超越保护教会和信徒的范围，思想及社会经济利益的分界，也开始破坏曾是第一代基督徒政治动员显著特征的团结。

因此，两战之间的时代，出现多种不同、且常彼此竞争的受基督教启发的政治组织。在危机时刻，最明显的是西班牙第二共和国支持与反对教权的争执中，绝大多数天主教徒团结在一个政治组织，即西班牙自治右翼联盟之后。[^p180-14]但在其他时候，基督徒阵营内部的分歧往往浮现。在德国，中央党希望成为所有天主教徒的政治中心，即Zentrum，这一抱负却受到一战及其余波释放的离心力量削弱。一些天主教徒拥抱新的共和秩序，另一些则接近反魏玛右翼思想家提倡的威权观念。南部与西部许多农村和小城镇天主教徒，参加反对新政权的抗议运动；天主教工会成员则与新教同行共同组成一个基督教工会<a id="pdf-181"></a><!-- PDF page 181; original page 162 -->联合会，即德意志工会联合会（Deutscher Gewerkschaftsbund，DGB）。[^p181-15]因此，中央党虽然延续下来，并作为地方和全国执政党在魏玛共和国发挥重要作用，其政治凝聚力却日益受到各组成利益集团间紧张关系的破坏。新教阵营也大体如此。主要路德宗与改革宗，即加尔文宗教会，与战前德意志帝国联系密切，这使它们在环境迥异的魏玛共和国中失去政治归宿。许多人最初支持作为主要右翼政治组织的德意志国家人民党（DNVP），但一部分人更积极地参与共和政治，另有许多人则逐渐倾向反共和、民族主义的极右翼，最终包括纳粹党，即国家社会主义德意志工人党（NSDAP）。[^p181-16]

然而，法国提供了这种政治多元化最持久的例子。与欧洲许多其他地区不同，1914年前法国没有占主导地位的天主教政治组织。一战后仍然如此。二十世纪二十年代后期的全国天主教联合会（FNC）等组织，声称代表全体法国天主教徒，但天主教阵营内部的地区与思想分歧，与这一宣称相矛盾。十九世纪反共和主义的遗产，虽因一战期间天主教徒与共和派所谓“神圣团结”而有所缓和，仍相当强烈；天主教徒在二十世纪三十年代兴盛的极右翼运动与刊物中十分显著。相反，另一些天主教徒则与新教少数群体一样，积极参与第三共和国的政治生活。天主教社团的务实逻辑，例如法国基督徒工人联合会（CFTC）工会成员的逻辑，使他们拒绝过去的不参与立场，转而参与共和国的政治及社会经济机构。此外，第一次出现了一个接受共和国、寻求在其内部作为天主教力量开展工作的政党，即人民民主党（PDP）。这种初具雏形的基督教民主主义，在天主教阵营内仍属少数潮流，但其存在本身，就表明自世纪之交以来，法国天主教内部政治<a id="pdf-182"></a><!-- PDF page 182; original page 163 -->分化的程度。[^p182-17]

不过，与教牧人员一再发出的警告相反，政治分裂并非软弱的标志。两战之间基督教政治组织的多元性，在许多方面反映了基督徒对政治领域参与的加强。1914年后席卷欧洲的多重危机，既有国际与国内危机，也有社会经济与思想危机，摧毁了十九世纪相当明显的基督徒不参与政治的态度，也加速了基督徒，尤其天主教徒内部的民主化。一战军队中男性服役所具有的平等经验，以及战后许多国家扩大男性、有时也扩大女性选举权，侵蚀了1914年前天主教政治组织中鲜明的、对社会上层与教士上级的恭顺精神。基督徒工人和农民大多并不打算放弃基督教信仰，却越来越决心把自己的政治未来掌握在手中。德国DGB、意大利工人联合会（CIL）和法国CFTC等基督教工会迅速扩张，既表明物质不满的压力，也表明基督徒工人阶级的社会自信。[^p182-18]农村正在发生的解放过程也如此。二十世纪二三十年代，欧洲许多地方政治中的一个持续主题，是农村人口对城市统治者的不满；在他们看来，统治者忽视了许多欧洲小农面对的外国竞争、生产过剩、债务与税收问题。基督教政党在许多农村地区拥有强大选票基础，不可能不受这些压力影响。因此，德国和奥地利等国的宗派农民组织，在基督教政党内部维护自身群体利益时，变得更具战斗性。

此外，在欧洲许多农村地区，新的抗议运动和极右翼政党也挑战基督教政党；它们声称，要保护农村利益，抵御恶意资本势力和缺乏同情心的城市官僚的行动。

物质压力与选举竞争的共同作用，在很大程度上解释了一战后许多基督教政治为何语调更为急迫、愤怒，有时甚至纯属煽动。但与此同时，这也反映了前述三个因素中第二个因素的影响：欧洲各基督教宗派内部的社会与思想变化，如何促使宗教信仰和政治投入更直接地联系起来。基督教评论者常不厌其烦地强调，“私人”宗教与“公共”政治之间的划分，很大程度上是十九世纪自由派思想家的创造。十九世纪后期，这一区分常对基督教会有利，因为它划出一道边界，国家当局在试图规范宗教事务时，不应越过。但在两战之间更为流动的政治环境中，日益壮大的基督徒活动者、知识分子和社会运动阵营中的许多人，拒绝这种区分；他们的抱负不再是保护宗教免受政治侵扰，而是把宗教带入政治。一战大屠杀象征着一种普遍的“文明危机”感，似乎证明自由主义社会模式已经破产，必须提出独特的基督教解决方案。这个目标兼具属灵与政治层面，更常是两者的混合。两战之间，许多基督教组织和个人心中，一方面希望使欧洲“去基督教化”的人口重新归信，另一方面又希望建立某种“基督教之城”，让基督教价值观重新占主导；两种抱负并存，关系却常不安稳。但两者共同体现了一种更整体、更不愿妥协的心态。许多基督教政治远未与当代社会和解，而是通过反对自由社会的价值观，以及由此产生的左右两翼世俗政治思想，来界定自身。

这种反主流文化的战斗性，在欧洲不同宗教文化中采取不同形式。在北欧路德宗地区，宗教布道运动谴责现代世界的种种罪恶，以及国教领导层与之同谋。这类复兴运动往往止步于明确政治参与之前，但按照原书的记年，它们于1938年促成挪威基督教人民党（Kristelig Folkeparti，KrF）的建立。该党从<a id="pdf-184"></a><!-- PDF page 184; original page 165 -->本国西部路德宗地区的根据地出发，为挪威政治带来新的基督徒战斗精神。[^p184-19]在荷兰，尽管主流新教长期与政治秩序紧密相连，二十世纪三十年代亨德里克斯·科莱恩领导下的加尔文宗反革命党，仍谴责当代社会被认为存在的社会无政府状态，以及自由主义、社会主义和共产主义中唯物主义与无神论邪恶所构成的危险。[^p184-20]在两战之间德国动荡的环境中，这种在思想上对现代社会结构与精神的反感，不可能不采取更激进的政治形态。许多新教教牧人员和平信徒，起初把魏玛共和国视为民族战败的非法产物，因而疏离；1925年新教徒兴登堡当选总统，使这种情绪有所缓和。但教会这种谨慎参与共和国的做法，在二十世纪三十年代初政治危机中迅速受到破坏，许多新教教牧人员和选民转而支持纳粹党领导的“民族反对派”。[^p184-21]

基督教更具战斗性的性质，在天主教阵营中表现得最为明确。这很大程度上归功于教皇制度的努力。自十九世纪中叶起，现代教皇形象的建构加快：教皇既是天主教会的最高领袖，也是国际天主教信徒共同体的属灵领袖。但这一过程，直到二十世纪最初五十年才充分展开。在庇护十一世（1922—1939）坚定领导下，教皇制度努力把自身统一原则贯彻到欧洲颇为多样的天主教文化的人员、结构与优先事项之中。把可靠人物任命到关键教会权威职位，与许多欧洲国家签订称为政教协定的条约，使天主教属灵及教育活动获得更大自由，虽仍受教皇指导，以及大量建立公教进行会等体现教皇教义与属灵重点的组织，都是建构一种更鲜明以罗马为中心的天主教的组成部分。[^p184-22]这些行动的核心，是对天主教会在现代世界中地位的自信。沿着前任教皇，尤其庇护九世，<a id="pdf-185"></a><!-- PDF page 185; original page 166 -->良十三世与庇护十世的声明，庇护十一世建立起一种包罗万象的天主教教导，不仅涉及信仰与道德，也涉及社会的经济和政治原则。他最重要的两篇通谕，是1925年的《在首要之事中》（Quas primas），以及1931年为纪念良十三世《新事》通谕四十周年而颁布的《四十年》。在其中，庇护把天主教呈现为现代世界种种弊病唯一而自足的解决方案。教会与天主教平信徒的角色，不是同当代社会妥协，而是在其中成为真理的堡垒。[^p185-23]

庇护十一世坚定追求这一愿景，结出的果实，是在其继任者庇护十二世（1939—1958）任内，教皇制度取得欧洲天主教中极为显著的中心地位。然而，现代教皇权力与声望这一历史高峰，至少同样有赖于许多欧洲社会中天主教社会与思想性质的演变，而不只是教皇制度为自身利益作出的努力。十九世纪后期以来建立的天主教专门教育机构网络，以及面向青年、妇女和特定社会经济群体的大众组织，塑造出自我意识更强的天主教平信徒。值得注意的是，在这些环境中成长起来的男女天主教活动者，走在二十世纪二十年代公教进行会等属灵运动的前列，随后常主导三十年代的天主教政治和思想运动，并在第二次世界大战后建立的基督教民主党派中，占据许多领导职位。这一代欧洲年轻天主教徒，常有中产阶级和知识分子背景，为两战之间的天主教注入新活力与战斗性。波兰的“复兴”（Odrodzenie）、立陶宛的“未来”（Ateitis）、法国的《精神》（Esprit），以及比利时法语区的“基督君王”（Christus Rex）等不同运动，都是蓬勃发展的天主教学生与知识文化的表现。它们拥抱教皇不妥协的语言与象征，拒绝既有天主教政党中长辈更谨慎的做法。天主教大学处于这一过程的中心。荷兰奈梅亨、比利时鲁汶、西班牙萨拉曼卡和葡萄牙科英布拉等大学，以及意大利天主教大学生联合会（FUCI）等学生组织，推动形成了一批天主教知识分子，<a id="pdf-186"></a><!-- PDF page 186; original page 167 -->他们在新托马斯主义教义的确定性中受教育，对现代世界的批判毫不宽容。[^p186-24]

也是这一代年轻的天主教活动者，为二十世纪三十年代天主教政治定下更具战斗性的基调。1929年华尔街股灾后经济萧条，以及左右两翼极端政治运动兴起，共同促成一种更激进的天主教政治，既敌视自由议会主义，也敌视经济资本主义。魏玛共和国最后几年，中央党逐渐转向默许否定共和民主；比利时莱昂·德格雷勒领导的民粹、反议会雷克斯运动，以及极右翼弗拉芒民族主义的弗拉芒民族联盟（VNV）双双成功，都是天主教阵营新情绪的表现。[^p186-25]但最具戏剧性的表现，发生在奥地利和葡萄牙。二十世纪三十年代初，这两个共和议会制国家，分别在恩格尔贝特·陶尔斐斯和安东尼奥·萨拉查领导下，转变为威权政权。两人都有鲜明的天主教背景，起初都获得教会圣统及天主教社会、政治组织的相当支持。实际上，两种政权在实践中对天主教关切的同情，都不如众多辩护者所说的那样。不过，它们都大量借用天主教象征，并大肆宣扬其威权政治结构和社会经济社团主义制度，据称受到教皇思想启发。[^p186-26]天主教徒支持陶尔斐斯与萨拉查政权，以及1936年后支持西班牙佛朗哥政权，反映出二十世纪三十年代天主教政治的威权倾向。尽管仍有基督教民主主义者寻求与政治左翼和解，三十年代天主教<a id="pdf-187"></a><!-- PDF page 187; original page 168 -->政治参与的重心主要位于右翼，而且常是反议会右翼。[^p187-27]这并不等于支持法西斯主义。天主教舆论，尤其意大利和德国以外的舆论，主要敌视他们认为与法西斯、特别是纳粹政权相联系的国家崇拜和“褐色布尔什维主义”。相反，三十年代许多参与政治的天主教徒，期望在法西斯主义与自由民主之间开辟“第三条道路”。面对自由社会的无序冲突，以及共产主义和法西斯主义强制推行的集体主义，天主教徒提倡一种新的社会模式，重视家庭、工作场所和地方共同体等中介机构。让工人与雇主代表共同参与的社团主义机构，将取代资本主义的阶级冲突；天主教属灵价值观居于主导，则将为现代社会恢复失落的统一。[^p187-28]

若按字面全盘接受这些含糊的天主教社会政治“革命”模式，就会犯错。天主教激进分子的反民主言辞，往往比行动更强烈。不过，三十年代的激进语言仍有意义，因为它表明，天主教政治已从世纪初相当有限的宗派利益议程，发展为更具抱负的政治愿景。短期而言，这为天主教徒支持战时在维希法国、斯洛伐克和克罗地亚建立的威权政权，铺平了道路。[^p187-29]但从长期看，其更持久的遗产，也许在于战后几十年的天主教政治。1945年起，意大利、德国、法国和低地国家的天主教政党与运动表现出的活力与自信，很大程度上得益于短期因素，尤其许多年轻天主教激进分子，战时参加了反法西斯与反外国占领的抵抗。但更深层地看，这可视为一种更积极介入政治的天主教取向终于成熟，其准备在此前二十年已然展开。

然而，1945年后基督教在西欧政治生活中的优势，并不单是基督教会内部变化的产物，也反映欧洲政治的演变更加<a id="pdf-188"></a><!-- PDF page 188; original page 169 -->容纳具有鲜明基督教性质的力量。其中最直接明显的变化，无疑是一战前后代议政治形式的深化与增加。中欧帝国灭亡，以及许多西欧国家选举权往往大幅扩大，本身并没有创造新的民主文化。一些国家的女性虽占人口多数，仍没有选举权，部分原因是据说她们容易受教士影响。此外，二十世纪二十年代匈牙利、意大利与西班牙建立威权政权，也大幅逆转了此前几年的进展。尽管如此，一战后，代议政治扩展到捷克斯洛伐克、波兰和波罗的海诸国等中东欧新国家，并向下延伸到地方政府及社会经济组织形式，显然有利于那些最能把松散支持者转化为可靠选民队伍的政治团体。[^p188-30]如前所述，基督教会拥有庞大的结社结构与宗派团结意识，非常适合在这一多重选举的新世界中竞争。中东欧新国家最初举行的若干次选举中，基督教政党取得成功；欧洲许多地区地方政府与工作场所选举中，基督教政党和工会的成功，也体现出同样的动员、组织能力。

两战之间大多数欧洲国家政治的多党性质，也有利于基督教政党。英国逐渐走向大体上的两党制，几乎独一无二；其他地方的比例代表制，鼓励几个主要政党发展，没有一个能在选举中取得绝对多数。这对基督教政党有利。虽然它们有时能成为第一大党，例如二十世纪二十年代的比利时与奥地利，但通常很难获得绝对多数选票。不过，它们作为处于左右极端之间政治中间地带、可靠且选票稳定的力量，在随后的联合政治中处境有利，可以发挥重要影响。例如，在<a id="pdf-189"></a><!-- PDF page 189; original page 170 -->荷兰、比利时、捷克斯洛伐克，以及魏玛时期德国的多党政治中，基督教政党几乎是全国执政联盟不可或缺的组成部分，也参与众多地区与地方政府。

欧洲政治格局的第二项、较不明显的变化，是反教权，尤其反天主教政治的衰退。十九世纪后期曾担任战斗性世俗主义旗手的自由主义运动，一战后影响往往下降。同时，社会主义对宗教的态度也缓慢变化。社会主义与基督教政党之间的选举竞争，尤其在城市，往往很激烈。但相互辱骂之下，也可看见试探性和解的迹象。许多欧洲社会主义政党的思想，迟疑却逐渐脱离第二国际相当扁平化的马克思主义，因而得以重新评估对教会的态度，过去反教权语言的缓和反映了这一点。因此，当社会主义政党确实取得相当政府权力时，例如一战刚结束的德国，以及二十世纪三十年代中期的斯堪的纳维亚国家，基督徒对政府立法攻击教会的担忧，大体证明是不必要的。即使在法国，共同忠于共和世俗主义，是把激进党、社会党与共产党粘合在一起的因素之一，使它们于1936年组成上台执政的人民阵线政府，但也没有重演1914年前的政教冲突。只有在西班牙，支持教权与反教权的斗争，仍保有其政治中心地位和暴力潜力。第二共和国时期，共和左翼政党的主要目标之一，是立法削弱天主教会的社会影响；而天主教政党自治右翼联盟，则团结起来维护教会及其附属机构。但这种冲突远超议会政治。教会占据何种地位，已成为更广泛冲突的决定性问题之一：一方主张建立现代世俗西班牙，另一方维护天主教和君主制西班牙。在加泰罗尼亚、埃斯特雷马杜拉和安达卢西亚等地区，以及马德里和巴塞罗那等大城市，围绕教会财产、教牧人员与修会在教育和福利中角色的冲突，深植于日常生活结构。正是这种地方现实，在很大程度上解释了为何1936年夏反共和军事起义后，政治两极分化转为社会暴力。一些共和派地区的神父和修会成员遭到暴力攻击，而社会主义者、共产主义者和<a id="pdf-190"></a><!-- PDF page 190; original page 171 -->无政府主义者，则成为佛朗哥控制的西班牙境内天主教与国民派力量镇压的对象。[^p190-31]

然而，西班牙以外过去数十年教权与反教权战争的缓和，很迟才反映到基督教政治的心态之中。人们仍担心心怀恶意的政党与国家官僚威胁基督徒利益，这种恐惧依然是锻造宗派团结的重要粘合剂。因此，整个两战之间时期，天主教政党修辞的标准内容之一，就是必须团结抵御无神论自由主义和社会主义的危险；教牧人员在全国与地方选举之前，定期向信徒发布指引，又有力强化了这一点。教育改革和国家资助教牧人员程度等技术性、却常极具象征意义的问题，引起立法冲突；围绕新建教堂、世俗葬礼与婚礼、举行宗教游行及节庆的地方争议，也有其社会暗流。这些都使教权与世俗势力冲突的心态延续，即使它已大体失去往日的激烈。反过来，一旦此类冲突消失，或被新的政治问题吸纳，基督教政治往往也失去相当一部分凝聚力。在爱尔兰自由邦，埃蒙·德·瓦莱拉的共和党，与威廉·科斯格雷夫领导、更谨慎且亲天主教的盖尔人协会党，后来重组为统一党，之间的分裂，是内战的主要遗产之一；这场内战伴随爱尔兰于1921年事实上取得脱离英国的政治独立而发生。因此，科斯格雷夫政府在1932年选举中失利、德·瓦莱拉领导的共和党政府成立后，出现了激烈的天主教反政府浪潮，尤其是埃因·奥达菲领导的蓝衫运动。但后来，共和党领袖德·瓦莱拉愿意争取天主教舆论，最明显的是1937年宪法赋予天主教会特权地位，实际上使爱尔兰政治中的教权与反教权维度消退。践行宗教与不践行宗教的天主教徒，以及新教少数群体之间的社会文化差别仍然存在，但关于天主教会角色的争论，大体从主流政治辩论中消失。[^p190-32]

反对国内政治对手的动员所产生的基督徒团结，又受到战斗性无神论苏联这一较遥远威胁的加强。战后初期中欧的革命动荡，在基督徒阵营留下长期恐惧；后来苏联成为欧洲政治中有影响力的力量，又为这种恐惧提供新焦点。欧洲大多数国家成立了规模虽小但声势很大、与苏联紧密联系的共产党，它们又在二十世纪三十年代中期参加法国和西班牙的人民阵线运动，有助于塑造出苏联与共产主义威胁基督教欧洲的夸张形象。人民阵线时期，共产党颇为乐观地试图接近进步基督徒舆论，除极少数人外均遭拒绝；而人们认为内战期间西班牙共和政府受共产主义支配，也成为西班牙国内外天主教徒支持佛朗哥事业的重要因素。[^p191-33]在许多方面，共产党人已成为过去犹太人和反教权敌人的新化身。1941年6月德国及其盟国入侵苏联时，纳粹必然把军事行动包装为反对苏联敌基督的基督教十字军。东线战争帮助第三帝国内的基督徒舆论与纳粹战争努力结合；而在欧洲其他地方，对苏联的外部斗争，与对受共产主义影响的抵抗组织的内部冲突合流，诱使一些天主教团体与纳粹部队合作。[^p191-34]

过去教权与反教权争执的衰退，与基督徒对新旧敌人的持久恐惧结合，加速了许多欧洲国家基督教政治的“常态化”。基督徒对现代政治过程的根本敌意，自十九世纪末以来已在减弱，两战之间则几乎完全消失。尽管一些新教教派和不妥协的天主教团体继续拒绝任何政治参与，主流基督教却已接受参与公共领域不仅必要，而且有利。因此，基督教政治逐渐失去1914年前总是萦绕其周围的例外或紧急性质。基督教政党不再为捍卫某种自称超越政治、或置身政治之外的事业，周期性地突然进入政治舞台，而是默默地、<a id="pdf-192"></a><!-- PDF page 192; original page 173 -->常常不自觉地走向政治生活中的永久存在。它们在地方行政与全国联合政府中的作用，使自身及其对手，都习惯把声称受到基督教原则启发的政党，视为欧洲政治的正常组成部分。

一战后欧洲的社会演变，进一步推动了这一过程。由职员、商人和小企业主构成的小资产阶级扩张，工人阶级又因技能群体、族群和性别而发生内部分层，形成层次更多的社会格局。十九世纪无产阶级与资产阶级的两极对立，被一个多极协商过程吸纳，至少也变得更加复杂；不断变化的社会力量联盟彼此协商，同时各自与国家建立更密切关系。这一更复杂的社会框架，往往有利于基督教政党和社会经济组织，它们得以充当特定社会群体利益的维护者。基督教工会摆脱世纪末许多社会天主教所具有的家长式束缚，迅速发展，尤其在被社会主义工会忽视的工人中。大型基督教妇女组织也从属灵与慈善起源，发展为在社会和福利问题上为妇女利益清晰发声的行动组织。最重要的是，自十九世纪末起，基督教组织特别善于接触在其他政治阵营中缺乏明显归属的新社会群体。亚伯拉罕·凯珀在荷兰为其反革命党争取的“小人物”（kleine luyden）广为人知；在两战之间欧洲许多地区，这类人在基督徒阵营中也日益显著。[^p192-35]为满足佃农、小企业主和白领雇员等群体特定需要而设计的宗派组织，履行广泛的社会职能，包括为农民建立采购与销售网络，为自雇者组织保险，以及向家庭发放福利。

这些非宗教却不可或缺的活动，使基督教社会与政治组织深植欧洲生活，超越信仰仪式与宗派政治忠诚的范围。从这个意义上说，政党只是一个更广泛过程最显眼、却未必最重要的要素；在这一过程中，基督徒共同体逐渐在许多<a id="pdf-193"></a><!-- PDF page 193; original page 174 -->欧洲国家承担广泛的社会、经济与文化角色。在这方面，教会、学校、福利组织、青年运动、工会，以及蓬勃发展的基督教报刊，都是不断扩展的基督教机构群岛的组成部分，成为全国和地方公民文化结构的一部分。如前所述，这一过程并未发生于欧洲所有地区。但在从低地国家延伸到意大利东北部的天主教欧洲中央地带，天主教机构构成的支柱化共同体涵盖大量日常生活，成为个人、家庭、社区与更广泛公共及经济世界之间的主要中介。

正是基督教机构这种全面涵盖生活的性质，使它们在政治体制变化面前大体保持韧性。二十世纪二十年代德国魏玛共和国更以国家为中心的民主文化，以及两战之间在匈牙利、奥地利等国建立的威权政权，都没有实质性破坏宗派机构的社会角色。[^p193-36]相反，二十世纪二十年代中期起的意大利法西斯政权，以及1933年后的德国纳粹政权，其核心抱负之一，就是彻底重塑个人与民族国家的关系。无论其他方面有何差异，法西斯与纳粹独裁都敌视介于公民与族群或民族共同体之间的中介机构。因此，两种政权都以不同热情和不同成功程度，试图压制、拆解、吸纳宗派机构，并以与国家及唯一执政党相连的新组织取代。但两种政权都决定与教皇签订条约，这使目标变得复杂，并在一定程度上与之矛盾：条约实际上确认天主教会退出政治，同时保证教会在法西斯和纳粹体制内拥有受限制的制度独立。教皇愿意签订1929年《拉特兰条约》和1933年7月《帝国政教协定》，反映出两战之间教皇参与国际外交时新获得的自信；但两项条约都无法终结政权与教会之间深层的制度冲突。[^p193-37]整个二十世纪三十年代及战争期间，法西斯与纳粹当局，都以其特有的前后不一方式，采取<a id="pdf-194"></a><!-- PDF page 194; original page 175 -->恐吓与宣传攻击，间或作出让步；这反映两种政权内部对教会态度的多样性，以及政策制定的波动。

回顾起来，法西斯、纳粹政权与教会之间众多的制度冲突，似乎足以证明法西斯主义与基督教根本不相容。但这将是一种误导性的简化。基督徒拒绝法西斯、尤其纳粹教义中的国家和种族崇拜，确有强烈的思想层面；例如瑞士加尔文宗神学家卡尔·巴特的著述，以及庇护十一世1937年向德国天主教徒发表、直言不讳的《极度关切》通谕，都反映了这一点。德国纳粹国家内部个人与集体的异议行动中，基督徒活动者也十分突出，例如新教神学家迪特里希·朋霍费尔和所谓克赖绍圈。但对德国与意大利大多数基督徒来说，他们不信任法西斯与纳粹宣传的反教权倾向，最多也只是在面对被认为特别违背基督教信仰的政策时，如德国安乐死计划，偶尔谨慎地集体抗议。除这些分歧，也存在思想上的重要契合与共同利益。大量新教平信徒和教牧人员投身纳粹事业，反映新教阵营中深植的愿望，希望宗教与民族结合。希特勒认可，并在某种程度上分享这些感情。纳粹主义内部的反基督教潮流，大体被排挤到边缘，至少直到战争最后几年党卫队崛起之前如此；政权也经常诉诸一种暗含新教色彩、却大体脱离宗派的基督教语言与象征。意大利也一样，运动早年的世俗、反教权法西斯主义，后来让位于颇为机会主义地争取天主教舆论。尽管1929年条约签订后，教会与政权仍有冲突，教会和许多天主教平信徒仍明确支持墨索里尼的民族主义修辞与扩张性外交政策。尤其在活跃于天主教学生运动的知识分子中，例如日后成为教皇保禄六世的乔瓦尼·蒙蒂尼，对法西斯主义的思想与行动，始终保持谨慎态度；但只有1940年起政权在军事上不断失败之后，<a id="pdf-195"></a><!-- PDF page 195; original page 176 -->大多数天主教徒的态度才转向疏离法西斯主义。[^p195-38]

因此，欧洲基督教会与法西斯政权关系的复杂现实，既包括适应与支持，也包括不信任与反对。不过，从这一不安稳的关系中，教会最终成为胜利者。纳粹与法西斯革命虽然侵蚀教会独立，并在两国创造出更集中的政治文化，却始终未能把教会变成政权附庸。因此，当法西斯和随后的纳粹统治在军事失败推动下崩溃时，基督教会及其附属组织，成为后法西斯时代最强大的政治和社会机构之一。意大利的天主教民主党（Democrazia Cristiana），以及德意志联邦共和国的基督教民主联盟（CDU）和基督教社会联盟（CSU），成为战后时代占主导地位的政党，从而能够为战争混乱中重建的意大利和德国，打上鲜明的基督教印记。意大利共和国与德意志联邦共和国给予宗派机构和组织相当的独立，也提供一个政治框架，使基督徒，通常是天主教徒政治家，占据许多主要权力职位。[^p195-39]

二十世纪下半叶，德国、意大利及非共产主义欧洲许多其他地区的宗派社会环境得以延续，表明政治现代化过程与基督教政治之间更广泛的联系。有关欧洲从十九世纪后期到二十世纪中叶政治现代化的叙述，常以工业增长与国家权力扩张带来的革命性变化为主线，这是可以理解的；这些变化，使个人脱离既有忠诚关系与共同体。在英国等国家，这表现为渐进的政治适应；在其他地方，尤其德国，则产生一系列差异极大的政治体制。然而，强调变化的迅速，以及工业化与政治革命的破坏性影响，可能遮蔽更长期的<a id="pdf-196"></a><!-- PDF page 196; original page 177 -->适应与演变过程。其中最重要的，是基督教政党和宗派组织，如何成功进入政治机构、准国家组织及社会经济团体之中；到二十世纪中叶，这些机构构成并规范着欧洲公民的生活。这种成功并非普遍。在法国，共和世俗主义政治文化的韧性，妨碍了专门天主教政治的发展，尽管宗派组织在许多社会经济生活领域，取得了更重要角色。在英国，单一议席选区选举制度巩固了保守党与工党的政治优势，把宗教政治推向全国生活中政治与地理的边缘。此外，在斯堪的纳维亚，二十世纪三十年代起社会民主主义取得主导地位，使国家承担欧洲其他地方由宗派组织承担的许多社会角色。

因此，欧洲政治现代化没有单一路径。但第二次世界大战后形成的、版图缩小的西欧，后来在萌芽中的欧洲联盟机构内逐渐结合；其中许多地区，基督教政治，以及更广义的基督教社会政治组织形式，都具有重要影响。基督教民主党派，以及各类宗派工会、妇女联盟和青年运动，可能起源于十九世纪后期反对自由主义现代性价值观的反应，但二十世纪上半叶，它们实际上成为欧洲现代性最有影响力的塑造者之一。无论在全国和地方政治，还是更广泛的社会经济社团主义结构、教育体系、医疗与福利供给中，基督教机构都是欧洲国家结构不可分割的组成部分。反过来，这种基督教影响，也反映在第二次世界大战期间及之后，非共产主义欧洲各地形成的政治与社会秩序之中。即使宗教实践水平下降，对基督教道德准则与外在仪式的尊奉，仍然十分普遍。众多国教、半国教或仅仅享有特权的教会，使欧洲公民文化长期具有基督教外观，并把欧洲其他信仰的力量，甚至可见度，推向边缘。以保守民主为主的政治结构，把议会主权与向准国家社会经济机构下放许多职责结合起来，反映出基督教社会政治教导的印记，也为基督教组织提供许多位置。当然，这一切并非全是基督徒的成就，也不可能<a id="pdf-197"></a><!-- PDF page 197; original page 178 -->完全阻止，更不用说扭转，更深层的文化、社会与经济现代化过程所产生的影响。但在政治领域，自十九世纪中叶以来看似通向世俗化的大道，最终抵达的终点，在西欧许多地方，对基督教会比对其对手更为有利。
