# 第12章 基督徒与异端

彼得·比勒（Peter Biller）

<a id="pdf-190"></a>
<!-- PDF page 190; original page 170 -->

“应当唤起教会的力量，消灭近来已在世界许多地方萌生的各种异端邪恶。”[^p190-1] 这份1184年教宗教令的开头，表达了1200年前后几十年，教会人士对异端危险的普遍看法。异端与牧灵不足相结合，构成拉丁教会的一场异常危机。但这里被称为邪恶与异端的群体，自认为良善而属基督。他们几乎未留下神学藏书和行政档案，无法像教会或修会那样，为历史学家提供重建叙述的资料。因此，本章考察这些群体时，不得不大量采用教会的语言和视角，先从主要的考古遗存入手，即大量含有教会观点的手稿书，然后追问，这些文本如何塑造并重塑群体形象。

这意味着，须看主教座堂教士团和宗教会院的藏书，再看学校与大学神学及教会法教学所产生、所使用的作品。[^p190-2] 《圣经》抄本含有被认为指称异端及其特征的段落，如披羊皮的狼；另有较早积累的教父反异端著作，尤其针对二元论摩尼教，以及<a id="pdf-191"></a><!-- PDF page 191; original page 171 -->中世纪的词典、伊西多尔《词源》中，对教会、宗派和异端的重要定义。十二世纪，文本大量增生，将旧语言和主题，与出现新异端及异端者的观念结合；有些直接描述或反驳特定新异端。历史和编年史简述当代异端，可敬者彼得和克莱尔沃的伯尔纳有正式论异端书信。彼得还写了一部针对当代异端者、逐条反驳教义的论著，使论战专著这一体裁重新活跃，后来继承者甚为重要。伯尔纳又改用《雅歌》中小狐狸毁坏主之葡萄园的段落，狐狸就是异端。会议法令处理当代异端，格拉提安《教令集》则把大量材料按辩证方式安排。十三世纪，内容进一步扩充，例如1184年教令成为格列高利九世1234年《教令五书》，即《教令集续编》中异端专节的一部分。但也有新体裁：为讲道增色的例证故事集，有时出现异端。法国南部通过讲道直接对付异端，得到小册子帮助，列出其错误及可用来反驳的经文；意大利中北部则出现庞大、博学的论战专著，协助与异端辩论。十三世纪三十年代，正式宗教裁判兴起，主要由多米尼克会及较少的方济各会承担，催生技术文献：手稿载固定格式，供嫌疑人宣誓说真话、受问讯、受判，也记录讯问及判决。

中世纪盛期异端存在的一部分，恰恰就是如此：在这些文本中的勾勒，以及存在于那些抄写、阅读、讨论，并用于教学、讲道和宗教裁判者的头脑中。此方面的一般史，需要描述文本如何传播和使用，例如伯尔纳《雅歌评注》反复被抄写，进入欧洲众多熙笃会及其他会院；《教令集》和《教令五书》在教会法学校被讲授、评注；异端讯问记录受到严密保管，有时成为偷窃或销毁阴谋的目标。还须描述文本中异端、异端者及宗派不同的呈现方式。光谱一端阴暗模糊，另一端清晰耀眼，却仍有扭曲。模糊一端，是受《圣经》中披羊皮的狼、<a id="pdf-192"></a><!-- PDF page 192; original page 172 -->小狐狸等动物隐喻，以及“异端邪恶”“行在黑暗中”等套语支配的文本。较清楚一端，是讯问记录：问题出自聪明、善于观察，却概括化的典型行为模型，宗教裁判官把这些行为归给法律和悔罪分类中的“异端信奉者”，嫌疑人据此回答。神学反驳也在这一端：必须准确表现异端观点，却把人简化为一系列神学命题。前异端者或接近群体之人的知识，尤其受重视。最佳例子，是拉涅罗·萨科尼1250年的论著。[^p192-3] 他做过十七年卡塔尔派，如今成为多米尼克会士，写出简明而知识丰富的叙述。同时，著作受正在形成的“剖析宗派”文学惯例塑造，依教会对宗派与真教会类型划分的一项要素组织：宗派以分裂、多元为特征，教会则以合一为特征。

两端之间有许多程度和表现类型，教士心思、阅读与观察相遇，又产生许多奇异转折。最重要的特色之一，是把不属于异端自身的词语，强加到他们身上。稍后我们将更直接描述这一时期两大异端，即卡塔尔派与瓦勒度派，仍继续用教会词汇。但首先须确立，两套词汇表达的是两种现实：异端自己的说法，与教会人士的说法。卡塔尔派精英称“善男”“善女”，瓦勒度派精英称“弟兄”“姊妹”，到了教会人士语言中，都成为异端；瓦勒度派友人成为信奉者，卡塔尔教会或诸教会、瓦勒度宗教修会，成为宗派或异端。当然有例外，萨科尼等少数作者保留许多自称；两套词汇也偶尔重合，如卡塔尔信奉者，以及“卡塔尔”这个名称，源于意为纯洁的希腊词。他们偶尔这样自称，却并不常见，[^p192-4] 可能来自君士坦丁堡说希腊语的波格米尔派，稍后将谈到。还有许多复杂性未能在此详述，例如朗格多克，卡塔尔派是最典型的异端，瓦勒度派<a id="pdf-193"></a><!-- PDF page 193; original page 173 -->只占少数。这反映于地方用语：宗教裁判官只称前者“异端”或“异端者”，不再限定，较少见群体才用“瓦勒度派”“瓦勒度主义”专名。

教会词汇以多种方式操纵现实。明显的是，使异端运动成为邪恶；较不明显、也更有意思的是，掩盖正统与异端运动的相似性。若称“小兄弟会”与“里昂穷人会”，很容易想到方济各会与瓦勒度派的相似；后一群体一旦进入教会异端词汇，相似就被遮住。[^p193-5] 词汇也提供框架，鼓励教会人士通过名称、历史与教义理解异端身份。根本影响来自伊西多尔《词源》。它列举异端，为每种提供三项：名称，如摩尼教；名称来源，常是创始人，如摩尼；主要异端教义的数语概述。教士看到当代被禁的里昂穷人会，便能轻易纳入模型，聚焦近期创办人瓦勒度，给修会及其成员加上“Valdenses”或“Valdesia”，即瓦勒度派或瓦勒度主义之名。看到主要教义为神学二元论的当代卡塔尔派，他可能聪明地与摩尼教二元论比较，却难以辨明其历史。期待创始人而找不到，他仍试图运用伊西多尔模型，称之摩尼教徒，暗示其历史和起源。

约1260年，上下奥地利多瑙河、恩斯河和伊布斯河沿岸，有四十余村，男女在家中聆听属于穷人会的弟兄讲道，在其指导下学习《圣经》段落；到1390年，许多村仍如此。邻近有塞滕施泰滕、圣弗洛里安和克洛斯特新堡等许多修院，其至今完整的图书馆，保存宗教裁判官汇编和论战反驳书：《帕绍匿名集》（约1266年）与《当人们睡着时》（1395年）。两者描述这些<a id="pdf-194"></a><!-- PDF page 194; original page 174 -->瓦勒度异端，称其披羊皮的狼，宣讲邪恶教义。[^p194-6] 人的现实，与文本中化为贬义词的现实，确实就住在隔壁。

若必须以这类文本书写真实异端史，怎能信任？例如，一组材料涉及“自由之灵”异端。1311年维埃纳会议《致我们》（*Ad nostrum*）法令，列出其据称持有的教义。嫌疑人受问时，说自己曾作为宗派成员如此相信并实践；但研究表明，他们是在重复宗教裁判官根据该法令提出的表述。恐惧与酷刑结合，使人对诱导问题表示同意。更广而言，会议法令基础模糊，告解供词又有虚构性质，两者结合，表明“自由之灵”异端多少是教会想象出来的。[^p194-7]

现代历史学对这一宗派的解构，令人信服。但模式不能用于较大宗派。卡塔尔派和瓦勒度派的证据如此多样，又有少量自身材料保存，其真实性无可怀疑。教训应是谨慎对待文本，因为它们与群体之间，总隔着一定角度。因此，下节将依这些文本，接近中世纪盛期两大异端运动，最后评论文本的主要扭曲。

巴黎大学学术神学家中，有时也发现并谴责异端。标签还有其他用法，最著名的是教宗与腓特烈二世皇帝斗争，皇帝在1245年里昂会议被定为异端。但教会所谓“危险异端与宗派”，通常指现代历史学家称为“民众异端”的卡塔尔派和瓦勒度派。约1200年，著名神学家里尔的阿兰撰四卷论著，捍卫天主教信仰，对抗敌人；他各用一卷讨论犹太人和穆罕默德追随者这两种非基督教信仰，另各用一卷讨论卡塔尔与瓦勒度这两大基督教信仰。近半世纪后，一部宗教裁判官手册开头的问题，显示同样关注：“你见过异端〔即卡塔尔派〕或瓦勒度派吗？”七十年后，在<a id="pdf-195"></a><!-- PDF page 195; original page 175 -->十四世纪初伯尔纳·居伊的审判与宗教裁判手册中，主要关注仍是卡塔尔派和瓦勒度派，虽增添意大利使徒派、法国南部贝居安派等较小运动；后者是一位激进方济各会神学家的追随者。[^p195-8] 本章将追随教会长久以来的首要关切，只讨论两大宗派。

里昂穷人会起源已见第三章，此处仅简述。[^p195-9] 应把它放在同时代其他追求使徒生活、贫穷游行讲道者的运动中理解。多数这类运动，如后来圣方济各追随者，最终成为教会内部修会。这场由里昂富裕市民商人瓦勒度发起的运动，有几年一直在教会内，获里昂主教座堂教士团支持，并在1179年第三次拉特朗会议得到有条件认可。[^p195-10] 最独特的是，创办人能读本地语言，却不通拉丁文，因此委托地方抄写员与教士，将若干《圣经》卷册和教父段落译为罗曼语。瓦勒度和追随者开始讲道。他们轻忽教会法要求，即平信徒讲道须寻求地方教会许可，加上讲道批评教士，先导致困难，后于1184年被逐出教会。虽有两群人在英诺森三世任内与正统和解，穷人会此后仍成为遭禁的异端宗派，其存在与分支偶尔可见，主要通过宗教裁判。《帕绍匿名集》保存许多零散、未组织的信息；另一匿名作品《论里昂穷人的生活……》，可能出于十三世纪末，依据一位被瓦勒度派试图招为弟兄的叛离司祭的供述，对存在一百余年的运动作出值得注意的正式描述。[^p195-11]

这些文本提示，这基本上是一场由教会产生、在某些意义上仍处于其中的运动，存在于两个层面。一层基本是秘密托钵修会：男女放弃世俗生活，加入宗教修会，正式发贫穷、贞洁、服从三愿，穿会衣，此后在会舍中依作息祈祷、受教。词汇与教会内修会相同，称弟兄姊妹，发愿，属于一个修会，定期开总会议；会议每年在意大利北部与法国南部举行，集合两地及德意志弟兄。另一层是友人，属于天主教普通平信徒的一个分群。与其他天主教平信徒一样，他们在地方教堂受洗、参加弥撒、告解、结婚和接受丧礼，却秘密在家接待弟兄，在两个领域重复地方教会提供或进行的活动：听弟兄讲道、训诲，向他们告罪。正统平信徒既向本堂司祭也向托钵修士告解，提供一个有趣平行。虽有瓦勒度派司祭职分及圣周四纪念性祝饼的记载，他们并未广泛试图取代教会圣事，或使友人远离圣事。一定程度上，仍在将自己逐出教会的教会内过圣事生活，同时又批评、拒绝其许多部分，对宗教改革后的人，可能完全矛盾；却是里昂穷人会及友人实际生活的现实。

运动多快成形？最早追随瓦勒度的男女，放弃普通生活，四处讲道；这种方式在某时凝结为正式修会。一位妇女1246年的供词提供线索：她对宗教裁判官说，约1206年曾在卡斯泰尔诺达里，与瓦勒度派妇女共同住四年；这是称姊妹的早期用语。她和她们一样穿衣、吃喝、祈祷并做其他事情，这一表述暗示，正式会院生活当时已存在。[^p196-12] 秘密化随有效镇压推进，缓慢且零散地到来；公开讲道随之减少、消失，积极保密措施出现。弟兄伪装手工业者旅行；德意志弟兄翻越阿尔卑斯山赴伦巴德总会议，伪装成<a id="pdf-197"></a><!-- PDF page 197; original page 177 -->朝圣者；地方友人接待弟兄，再护送至安全会舍，夜间讲道和听告解，形成复杂秘密体系。到十三世纪四十年代，仍可瞥见姊妹公开或在友人家讲道，此后却几乎从文本中隐形。最可能的原因，是牧灵活动缩减、保密成功，而非从运动中消失。[^p197-13]

游行讲道和劝化，使运动传播范围超过中世纪其他异端。1218年已到德语区；一直随德语人口传播，1300年前到波罗的海。似乎未进入德意志西北或斯堪的纳维亚，却向东传至波兰、波希米亚、特兰西瓦尼亚和匈牙利西部，在奥地利、波希米亚扎根最深。现代人最强烈记住的，是朗格多克卡塔尔派数量；这也许有误。大多数现存宗教裁判记录来自朗格多克，德语区却只有残片。将文学证据中的估计，与残存的1335至约1353年波希米亚北部裁判中的讯问、处死人数，以及伯尔纳·居伊在朗格多克审理异端的处决数比较计算，提示这些地区的瓦勒度派，可能超过朗格多克卡塔尔派。[^p197-14] 瓦勒度派也传至勃艮第、西班牙北部、多菲内、皮埃蒙特、伦巴德、托斯卡纳及意大利南部，但除皮埃蒙特外，密度不相当。

证据极少照亮第一次传道、首次进入某地区。通常，宗教裁判揭露的，是已存在一段时间的运动的瞬间面貌。秘密归附弟兄的关系，代代传下。父母一方，或亲属友人，会告诉孩子，这些人秘密周游世界，与他们一起便可得救，然后带孩子去向弟兄告解，年龄大概与首次在本堂<a id="pdf-198"></a><!-- PDF page 198; original page 178 -->告解相近。他们被鼓励与宗派内的人结婚。归属很大程度上是家族事务，其中叛逆孩子可能反而只想做天主教徒。男女在宗派内的地方活动，往往符合较一般的性别规范：男性较多护送，女性较多接待，有时也在当地劝化。许多友人住乡村，贫穷至中等，职业是农夫、磨坊主，以及鞋匠裁缝等小中型手工业者；但也能看到地位财富更高的人。[^p198-15] 例如，来自牢固瓦勒度家庭的两位友人，三个手足成为瓦勒度弟兄，于1319年被伯尔纳·居伊判刑。[^p198-16] 法国王室记录显示，两人各有逾七十图卢兹镑财产。[^p198-17] 友人给弟兄钱，《论里昂穷人的生活……》说，总会议所收大多数款项来自德意志，1400年前后宗教裁判又揭露富裕城市友人。[^p198-18] 将早期评论与晚得多的审判结合，可设想十三世纪该书写成时，德意志南部和奥地利就已有相当富裕、完全逃过发现的城市友人。

审判记录显示，弟兄在夜间讲道中教授某些异端：杀人和宣誓永远是罪，因此战争与刑事司法也是罪。他们说没有炼狱，圣徒无代祷能力，不应祈求。主要关注道德，而非教义：不要作恶伤人，不犯罪，不说谎。关于具体夜间场合的回忆，通常不包含《帕绍匿名集》等论著所强调的内容，<a id="pdf-199"></a><!-- PDF page 199; original page 179 -->即弟兄热切关心教导，使追随者熟记《圣经》，能够背诵，再转教他人。匿名作者也描述了一种将弟兄使命与身份置于教会历史中的叙事，它后来开始见于伯尔纳·居伊的审判，再见于1335年皮埃蒙特宗教裁判。历史第一阶段，基督与使徒时代，教会贫穷谦卑；第二阶段始于《君士坦丁赠礼》接受财富，教会衰落；第三阶段瓦勒度兴起，以谦卑恢复或延续使徒贫穷。文本和口传混合保存，促成历史版本多样；一版设定有小群蒙选者，将使徒与瓦勒度联系起来。[^p199-19] 整个中世纪，极少数女性受问时，记得这段历史。这提示，少数女性友人可能在保存记忆、为地方共同体提供身份方面，发挥特殊作用。[^p199-20]

卡塔尔派虽同样遭教会迫害、被标为异端，却与瓦勒度派很不相同。[^p199-21] 他们并非由天主教会内部形成，而是西方有利的本土属灵潮流，与东方波格米尔派在西方成功植入的拉丁表现形式，汇聚而成。波格米尔派对神性及物质世界起源，持激进观点，存在于拜占庭帝国及希腊语、斯拉夫语环境。早期波格米尔派，尤其保加利亚一支，持所谓“温和二元论”宇宙观；十二世纪另一观点发展起来，与德鲁贡提亚的波格米尔派有关，主张绝对二元论，两者下文均将解释。

西方卡塔尔派最早可确定的年代，是约1140年的莱茵地区、十二世纪六十年代的朗格多克，以及约1170年的意大利中北部，<a id="pdf-200"></a><!-- PDF page 200; original page 180 -->意大利南部则是十二世纪九十年代。东方起源在西方史料某些最早名称中留下痕迹：“卡塔尔”源于意为纯洁的希腊词，可能来自君士坦丁堡希腊语波格米尔派；“保加尔人”的各种变体，则表示起源于保加利亚的温和波格米尔教会，并与之联系。西方卡塔尔派的确切年代和起源，虽无法确定划出，却显然早于最初记载，也清楚具有东方起源。有些现代学者很急于缩小其东方起源和国际性，并尽可能推迟西方兴起时间。伯尔纳·汉密尔顿是例外，这里追随其建议。[^p200-22]

一个拉丁波格米尔／卡塔尔教会，在君士坦丁堡形成，成员为到来的法国北部人，可能出于1096至1097年或1101年的军事远征。卡塔尔仪式的拉丁版本，大概也在这里产生；十二世纪上半叶，君士坦丁堡也与部分希腊文亚里士多德拉丁翻译相关。法国北部人返回，建立法国北部卡塔尔教会，1167年出现首位具名主教。此后的传教活动不显眼，可能因为传教士在语言文化上都是西方人，宣讲温和二元论，在十二世纪早期法国禁欲游方讲道者中，并未特别引人注意。向北传播至莱茵地区者，大概又在十二世纪六十年代渡海，向英格兰进行一次未成功的传教。法国北部人也在朗格多克和意大利传教。约1170年，君士坦丁堡希腊语波格米尔派领袖尼基塔斯，或称尼金塔，赴西方传教，照亮运动。他的教会已经转向绝对二元论。1167年，他主持朗格多克总会议，劝服出席者接受绝对二元论；数年后另赴意大利，也劝服部分当地人。会议有君士坦丁堡、法国北部、朗格多克和伦巴德诸教会首领出席，鲜明见证国际性；朗格多克设两个新教区，则表明这些年的扩张。接受绝对二元论的西方卡塔尔派，因而更显<a id="pdf-201"></a><!-- PDF page 201; original page 181 -->激进异端特征，而意大利许多人仍坚持温和二元论，成为十三世纪分裂和争斗的根源。

激烈镇压限制了卡塔尔派在欧洲西北部的存在；到十四世纪中叶，除皮埃蒙特山区少数地点，南部卡塔尔派大多也被扑灭。其间一个半世纪以上，它却在南欧许多地方繁荣或存活：朗格多克、西班牙北部、伦巴德、托斯卡纳、意大利南部和达尔马提亚海岸。可瞥见这一时期活动的文本中，最突出的是朗格多克丰富审判记录，以及前述意大利多米尼克会士萨科尼1250年的描述性论著。朗格多克审判显示，该运动在此人数远多于瓦勒度派，对贵族和城市精英也有更明显吸引。十三世纪三四十年代受问老人的记录仍存，回忆可追溯到十二世纪最后约二十年，却还不够早，触及最初传教。其年轻时代，卡塔尔派已安顿下来，常在家族中传承。他们说，1209年十字军到来前，它公开存在，此后逐步秘密化。证词中，卡塔尔派不停移动，有时住树林的小屋和帐篷，从一处安全住所转到另一处。

这些及相似文本，描绘温和二元论的神学：一位上帝及其两个儿子基督和魔鬼；上帝虽创造四元素，塑造此世界的却是魔鬼。绝对二元论中，则有两个永恒本原，一善神、一恶神；前者创造遥远的另一世界，后者创造此世界。后者世界的人由身体、灵魂和灵构成。灵魂从另一世界堕入邪恶此世，恶神将其囚禁于男女、鸟兽邪恶的物质身体。“慰藉礼”保证受礼者死后，灵魂获释并回归另一世界，前提是避免性行为、杀生、食用交配产生的食物及其他重大罪。这些受礼者，就是朗格多克的“善男”“善女”，许多现代历史学家称其“完美者”，选用了一个当时相当少见的词。[^p201-23] 十字军与<a id="pdf-202"></a><!-- PDF page 202; original page 182 -->宗教裁判到来之前，一些善男善女住在特定会舍。同一性别的禁欲宗教人士共居，穿独特黑衣，过祈祷禁食生活，每月有告明小罪的礼仪，难免让人想到天主教会院。卡塔尔各教会具有类似教区的领土边界，也有少量结构平行和差异：每个教会的全男性等级，由主教、长子——将继任主教——幼子——将继任长子——及执事构成。

只有这一等级体系和善男善女，构成卡塔尔教会。普通平信徒中相信他们的人，不是教会的一部分。他们未受慰藉礼，还在通过结婚、生育、吃禁食之物和杀生，与邪恶世界合作。这是根本分野。天主教会与瓦勒度弟兄，都以劝勉、告解和补赎，使普通人少犯罪、多行善；卡塔尔派却没有相应安排。当然，这些极端而纯粹的基督徒并不鼓励犯罪，这种说法只是论战者的谎言。但其神学没有改善信众道德的理由。信奉者虽往往不显示、或未被要求显示对二元论神学理解深刻，却对这一点很清楚。问到异端向他们讲什么时，他们反复回答：卡塔尔派讲教义，瓦勒度派讲道德。

卡塔尔派的核心是知识。随着时间推移，学校和新大学为天主教会产生越来越经院化的神学，卡塔尔神学也发生相似、只是较难得知的变化。约1214至1215年，科莫卡塔尔派告诉一位与之同住的教士，伦巴德和托斯卡纳的卡塔尔派，会送优秀学者到巴黎学习逻辑辨析与神学论说。[^p202-24] 意大利北部城市某些平信徒圈子教育程度高，异端直至约1250—1275年仍享有许多自由，因此教义讨论活跃。不同卡塔尔群体之间，以及卡塔尔与天主教之间，大量论战交流，在天主教反驳专著及一部卡塔尔著作《二本原之书》中留下痕迹。它们表明，在这些精密的思想环境中，卡塔尔<a id="pdf-203"></a><!-- PDF page 203; original page 183 -->神学因一般新学问，也因面对天主教攻击而重新武装，变得更经院化。这与引用福音的瓦勒度弟兄简单劝善的世界，相距很远。

至此，本章试图确立，教士头脑和文本中的异端，与被如此标记、自称良善基督徒的运动，如何平行且交错存在。这是在描述，而非解释。“为什么有异端？”多数有学问教士，会以圣保罗的天意解释回答：“必须有异端，使你们中间经得起考验的人显明。”〔《哥林多前书》11:19〕《帕绍匿名集》讨论异端缘起的章节，直接列出一长串帕绍教区司祭弊端：把圣餐带到酒馆，不让产后妇女领圣餐，等等。第三、第四次拉特朗会议，即1179与1215年前后，多数改革教会者认为，异端源于缺乏受良好教育、有效的讲道者。专业宣道兄弟会多米尼克会，起源于朗格多克反卡塔尔讲道，是最大表现；十三世纪五十年代匿名《论审问异端者》的一句话，对具体成因及平行性也极有启示：瓦勒度派主要到方济各会、多米尼克会不到的人群和地方。[^p203-25] 这些与现代历史学家讨论1200年前后的牧灵危机，以及教会为应对危机而改革，相互契合。现代研究另一个显然有说服力的观点，也值得重复：西欧最终的异端分布图，部分由另一张地图产生。中央权力强、愿意镇压的地区，如英格兰、佛兰德和法国北部，驱逐异端；缺少这些条件的地区，则一度有其存在。

其他模式与对比，仍难解释。卡塔尔派被消灭，瓦勒度派存活至十六世纪。卡塔尔派比瓦勒度派更吸引精英。尽管卡塔尔派早入欧洲西北，瓦勒度派又持续存在于南欧部分地区，最终卡塔尔派最强在南欧罗曼语区，瓦勒度派在1400年前则最强于北欧及东北欧德语区。

讯问证据告诉历史学家的，是已经存在、安顿的异端共同体，而非最早建立它们的传教；因此，试图描述和解释的人，难以掌握早期使命。这是本章最后主题的主线。除把人和运动转置为异端者、异端与宗派的基本操作外，教会文本对这些人的表现，还有哪些不足或扭曲？

讯问记录保留对裁判官问题的回答；最好的情况，往往其实相当不错，是保存其感兴趣的知识：表示罪责程度的行为，如某人听异端讲道多少次，而非难以证明的内心状态。这是不完整的图景。多数现存记录问的是追随者，而非讲道的异端，其教义基础往往不深。再加异端神学书普遍失传，以及论战专著把异端表现为一串负面要点，而非整体，便产生缺乏神学统一与连贯的印象。如果只依天主教平信徒讯问，而没有高层神学文本，来评价天主教会统一和连贯，其信仰也会显得杂乱，可惜我们没有这样的讯问。这并非否认，杂乱本就是天主教徒与异端“实际宗教生活”的一部分。但总的说，天主教传世证据呈现体系而非杂乱，异端证据则呈现杂乱而非体系。历史学家应警惕由此产生的虚假对比。

至少有极少量神学或仪式文本保存，档案则没有。圣费利克斯—德—卡拉曼卡塔尔会议记录，让我们瞥见划界委员会工作；[^p204-26] 论战者萨尔沃·布尔奇说，卡塔尔派花大量金钱，赴会议调解和平。[^p204-27] 一封瓦勒度信件，则显示正式而详细的准备、<a id="pdf-205"></a><!-- PDF page 205; original page 185 -->代表任命，以及1218年贝加莫瓦勒度会议前交换书面立场的情况。[^p205-28] 我们也知道，瓦勒度派带钱参加总会议，正式提交财务账目。[^p205-29] 这些运动作为处理金钱、拥有书面记录的组织，整整一面消失了。少数瞬间画面，构成的群体十分具体，与某些教会文本中模糊的宗派形象，相距很远。

最后是危险及其范围。《帕绍匿名集》包含一项警告：瓦勒度派比其他宗派更危险，因为传播更广，几乎无地没有。这使人想到《为废除》开头，说异端在世界许多地方萌生，提醒我们警惕以警告为首要目的的文本中的地理夸张。匿名作者也向相反方向行进，建立于一套古老的教会与异端对比之上；塞维利亚的伊西多尔《词源》，最有影响地把它传入中世纪盛期。这些对立包括：教会长存，异端新奇；教会普世，异端只在少数国家；教会信徒众多，涵盖各等级，异端信者少，来源阶层范围更窄、更低；天主教信仰不分裂，合一且完整，而宗派却超过七十种，这是依据伊西多尔所列六十八种作的约数。[^p205-30]

教会文本既可夸大，也可缩小异端。缩小，意味着低估连贯性、规模、力量和分布，强调内部裂痕。相反两种倾向中，后者更隐蔽有害，因为与宗教裁判和秘密活动的一项特性，以及现代史学一种趋势结合。一旦迫害开始，运动便秘密化。它们被发现，只是有时；教会知道其事，只是一部分。现代历史学家急于把中世纪教会人士看作夸大其词的幻想者，主要注意其夸张，却忽略<a id="pdf-206"></a><!-- PDF page 206; original page 186 -->其缩小。合理地说，这些“异端”运动通常更多、更大、更连贯、更有组织，超过教会手稿中那些说法，以及宗教裁判记录偶尔探照、极少落到黑暗一角加以照亮时所显示的程度。
