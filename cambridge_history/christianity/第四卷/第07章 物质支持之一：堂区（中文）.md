# 第7章 物质支持之一：堂区

布里吉特·雷斯尔（Brigitte Resl）

<a id="pdf-119"></a>
<!-- PDF page 119; original page 99 -->

十三世纪，欧洲各地兴建宏伟主教座堂，哥特式建筑大获成功，现代艺术史家对此赞颂甚多。“哥特式图像”似乎捕捉了“大教堂时代”的精神，体现十二、十三世纪欧洲的思想抱负、艺术发展和工艺水平。[^p119-1] 但这一切由谁付钱？历史学家探讨教会机构的物质支持，恐怕最常关注贵族庇护，以及为准备“善终”而作的捐赠。然而，持续每日向共同体提供宗教服务、供养和教育教会人员，以及建造、日常运转和修缮复杂昂贵的建筑，都需要更多、更稳定的供给。教会从起源起，就依赖坚实的经济基础及共同体的持续支持，才能保证服务。为此，它逐渐建立强制性与自愿性贡献的一系列实践和规则，在平信徒与主教座堂、堂区教堂、修院、医院等众多教会机构之间，形成复杂的联系与相互依赖。

中世纪平信徒支持教会的许多特色，来自数百年间的渐进发展。但十三世纪，这些物质支持体系出现若干重要变化。其关键一部分可视为教会法扩张，使过去的习惯做法得到法律上的正式确立；另一部分则是捐赠<a id="pdf-120"></a><!-- PDF page 120; original page 100 -->性质和数量的新趋势，源于当时更广泛的社会文化变化。[^p120-2]

叙述教会物质支持的各种形式时，人们常区分非自愿与自愿贡献。这对初步了解或许有帮助，但两者界限始终模糊。此事数百年来主要依习惯行事，这并不奇怪；即便教会法学家竭尽所能，也未能建立清楚稳固的规则，最终正式确定应缴教会的各种款项。什一税就是模糊性的好例子。依据《旧约》，献出年产十分之一，在早期基督教会原是自愿支持；八世纪起，它被明确规定为强制义务，此后又受到一系列进一步规范。什一税主要来自农产，却不放过任何收入，无论多小。基本原则虽早已确立，其运用的各方面仍须不断监督和改进。像一切税款一样，应缴者常寻找逃避或不足额缴纳的机会；对于城镇居民可能取得的利润，这尤其容易。与此同时，在法律专家日趋活跃的时期，整个十三世纪，人们都在仔细审查体系漏洞，以便堵住。[^p120-3] 1215年第四次拉特朗会议规定，缴什一税优先于其他税赋（第54条）；它也填补一个特别明显的弱点：不再容忍把地产交给获豁免者耕种、以逃避什一税的广泛习俗（第53条）。英格兰成文法提供了法律眼光愈加精细的好例子，力求发现并澄清潜在混乱与争执，例如羊白天在一个堂区内吃草，夜间却在另一个堂区圈养，该如何处理。[^p120-4] 尽管许多堂区信徒试图减少<a id="pdf-121"></a><!-- PDF page 121; original page 101 -->每年的什一税，几乎没有人实质反对这一体系本身，这仍值得提及。[^p121-5]

丧亡献纳或丧葬费的习惯变化，说明许多信徒试图逃避什一税。教会要求信徒去世时缴纳这些费用，假定他们必须补偿一生积欠的什一税；乡村通常交一头牲畜，城镇则交最好的袍服或相似物品。[^p121-6] 但拒缴应纳款项的平信徒，并非教会资金、尤其什一税持续面临的唯一重大风险。堂区教堂还面对另一风险：平信徒与教会庇护人，包括主教，试图转移其部分收入。第四次拉特朗会议1215年力图制止这一习俗（第32条）。早在1179年，第三次拉特朗会议就规定，未经教宗同意，不得将什一税转让给平信徒。[^p121-7]

除什一税外，另一主要收入，尤其在堂区，是基本宗教服务的收费，例如婚礼、洗礼、丧礼、忌日纪念，庆祝圣诞、复活和圣灵降临等大节，以及教堂献堂节或诸圣节等特定节日。不过，这些缴纳究竟是强制还是自愿，并不完全清楚。第四次拉特朗会议似乎试图处理这一问题，规定一切圣事都必须免费施行，与习惯相反；但同一条教规又说，平信徒不得拒缴惯常奉献（第66条）。尽管存在根本模糊，这些收费显然对教士收入不可缺少，必须维持。例如，《温彻斯特法规》规定，所有成年堂区信徒“必须在四个节日，亦即圣诞节、复活节、庆节和教堂献堂节，缴纳应付及惯常的奉献”。[^p121-8] 但这样一来，它们显然又违背教会立法关于免费提供服务的总体精神。

十三世纪，教宗不仅更有力地控制平信徒向地方教会的缴纳，教会开支也成为审查与立法对象。例如，什一税原应均分给主教、堂区穷人、教堂建筑，以及本堂司祭或其他圣俸持有人。到十三世纪，主教分取什一税的做法虽已废弛，他们却取得其他向堂区取款的权利，例如巡视时，要求堂区为本人及随从提供食宿的接待供给权。[^p122-9] 另一方面，堂区成功保留什一税的最大份额，却面临严格的支出规定，例如必须为堂区教堂建筑留出资金。十三世纪法规再次提供许多例子，说明这一问题的重要；违反规则的记录，则像往常一样，显示立法者为何必须一再重申要求。[^p122-10] 堂区信徒不仅通过什一税中特定份额承担教堂建筑费用，也直接负责堂区教堂结构的某些部分。[^p122-11]

平信徒较自愿提供给教会的支持，还有大量其他赠与和缴纳。金钱、财产和物品向宗教机构的转移，根本上以互惠为基础：共同体提供物质条件，使教会能够供应属灵服务。捐赠者不仅希望获得教会许诺的属灵报偿，也希望分享共同体身份，由此提高社会地位。日常礼仪、大节和特殊场合，都会募捐。为增加收入机会或提高特定地点的吸引力，个别机构引入额外节日，或取得新圣髑。基督圣体节是极成功的礼仪创新，十三世纪后期，尤其十四世纪初，迅速传遍欧洲，<a id="pdf-123"></a><!-- PDF page 123; original page 103 -->获得教士和平信徒热烈欢迎。[^p123-12] 它也为采用这一节日的机构创造可观收入。同样，朝圣者习惯在造访的地点参加礼仪时留下礼物。因此，吸引朝圣人流极其可贵，以至有人伪造圣髑或编造相关主张。另一种吸引更多人、增加捐赠的办法，是提供大赦。人们获许诺，在指定教堂参加特定礼仪，可以额外扣减灵魂预期在炼狱停留的天数。为确保参加教会活动者知道这些附带特殊益处的场合，授予特权的文书会公开展示。

这些以及大多数其他平信徒捐赠，都与当时的来世观有关。自始以来，希望或期待在来世取得益处，就是平信徒支持基督教会的主要动力，但十三世纪出现了一些重要创新。雅克·勒高夫甚至称十三世纪为“炼狱的胜利”。[^p123-13] 灵魂在这一空间停留不同时长、接受净化，而这一时期，人们对它的界定和想象更加具体。这种信念塑造了平信徒向教会机构捐赠的模式。[^p123-14] 为避免在审判日加入前往地狱的“山羊”，而能跟随“绵羊”进入天堂，中世纪基督徒也可以生前通过祈祷、施舍和捐赠教会，补偿自己的罪。[^p123-15] 中世纪较早时期，受益者通常是修院；到十三世纪，托钵修会、堂区教堂和追思弥撒基金，成为常见受赠对象。

这些转变，是当时欧洲经济变化的直接结果。十一世纪以来，城市人口激增、新财富出现，为平信徒捐赠带来新方向。变化有时一代人间便可发生，十三世纪维也纳富裕家庭的做法，就说明这一点。维也纳精英的重要成员霍恩马克特的奥托，到1250年已为自己和家人建立稳固的经济物质基础，<a id="pdf-124"></a><!-- PDF page 124; original page 104 -->也投入资金供养城市宗教共同体。然而，他最偏爱的机构，是附近乡村山谷中的熙笃会海利根克罗伊茨修院。儿子格赖夫效法父亲，虔敬方式却也显出重要新倾向。他偏爱“河岸圣母”私人小堂，即父亲一所城内住宅中的圣母小堂，后来成为重要城市教堂，获得城市精英大量支持。父亲退居海利根克罗伊茨，并请求葬在那里；格赖夫却把时间和金钱投入城市医院，这一机构实际上由他更早的祖先创设。[^p124-16]

从乡村转向城市机构，从修道转向市民机构，是一种新趋势。人们希望将可自行决定的捐赠，与必须交给所属堂区的什一税不同，给予自己共同体内部、可加监督的机构。中世纪后期全欧洲，都可见富裕市民建立私人小堂。英格兰最早的例子表明，批准此类赠与的主教，起初视之为临时安排，并要求所有人也参加堂区礼仪。[^p124-17] 多种机构试图提供过去由堂区供应的服务，反映捐赠者希望更密切控制那些受托照料其灵魂的教会机构。

十三世纪，自愿支持宗教机构，不仅性质改变，数量也改变。更多人能够捐赠。英格兰王家行政部门开始忧虑，宗教机构掌握的土地过多。1279年《死手法》通过规范土地向宗教机构的转移，试图遏制这一流动。[^p124-18] 欧洲多数地区都有类似干预的记录。但捐赠量持续增加，不能仅视为负担得起捐赠的人增多，也反映平信徒参与教会的总体增长。这一发展始于格列高利改革，在十二、十三世纪持续加强。

十三世纪订立遗嘱也更普遍。遗嘱通常包含某种宗教捐赠，有时与<a id="pdf-125"></a><!-- PDF page 125; original page 105 -->丧礼或忌日纪念相关。这类捐赠似乎是自愿支持的典型；与丧亡献纳不同，法律没有强制要求，但捐赠者认为，灵魂得救有此必要。为保证遗嘱获法律承认而需要的见证人，不仅可能确保立遗嘱者死后心愿得到执行，也可能施加压力，使其符合期待。1419年，前维也纳市长鲁道夫·安格费尔德记录遗嘱时，三名见证人先后三次询问，他是否确定不向任何教会机构捐赠，之后才接受其决定。[^p125-19] 同样，十四世纪英格兰遗嘱中，丧亡献纳已成为惯例。[^p125-20]

平信徒向教会提供物质支持的另一重要方面，即参与并资助慈善，也在十三世纪发生重大转变。照顾穷人是教会职责，什一税本应拨出一部分作此用途，但公众也更直接地参与济贫。慈善遗赠是准备来世的另一关键部分，形式多样：捐给宗教机构、设立追思弥撒基金及其相关慈善安排、资助教育机构，或资助桥梁等公共工程。尤其在十三世纪，平信徒创设医院大增，慈善捐赠由教堂转向这些医院。与前述变化一样，这里改变的是实践的外在形式，而非背后属灵意图；原因仍在经济社会条件的演变。医院能更有效、更具体地济贫，尤其在较大聚落；相较于专门宗教性质的会院，平信徒创办者也更能控制其运作。从礼物交换模式来看，捐给医院可能特别有吸引力，因为机构既能持久、反复执行捐赠者意愿，也有相当多的人为其灵魂祈祷。一份维也纳城市医院文书，可以说明物质支持的新方向。在这份署年1268年的文书中，院长与医院兄弟团体向公众请求<a id="pdf-126"></a><!-- PDF page 126; original page 106 -->协助承担日常开支，并许诺所有捐赠者可获得多方权威所授大赦，从地方主教、总主教，直到教宗。这份文书显然是伪作，却制作精良，必定出于十三世纪末或十四世纪初，甚至附有真正的维也纳市印。值得注意的是，其制作恰逢医院建筑群的主要建设阶段，其中包括一座庞大、装饰华丽的哥特式教堂。[^p126-21] 捐赠者既能从石造建筑中，也能从大赦许诺的未来报偿中，看到自己的钱换来什么。

不过，害怕因生前犯罪而永受诅咒，或希望拥有私人小堂及司祭以保证领受圣事，并不能完全解释人们对教会机构的慷慨支持。炫耀性消费、展示个人财富的观念，也不足以解释，尤其涉及十三世纪大主教座堂及类似庞大工程的资助时。个别捐赠者确实会出资制作彩绘玻璃，或捐赠华丽礼仪用品，为建筑群作出惊人的贡献；但协助教士长和座堂教士团，还需要多得多的投入。在这方面，也须考虑通过创造地标和共同体象征所表达的市民自豪感。无论主教及教士团与城市居民的关系有时多么紧张，当时人确实将主教座堂视为共同体身份的标志，极其希望为建设、维护和装饰出力。例如，索尔兹伯里新主教座堂兴建时，不仅亨利三世国王慷慨支持，相当大一部分地方居民也按自身财力，以不同方式捐赠。[^p126-22] 类似地，十三世纪，全欧洲都有宏伟主教座堂建成。[^p126-23] 细看共同体在这一世纪向教会提供的物质支持，我们同样不妨从这些伟大艺术品出发。
