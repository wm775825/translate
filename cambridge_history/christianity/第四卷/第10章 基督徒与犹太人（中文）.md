# 第10章 基督徒与犹太人

奥拉·利莫尔（Ora Limor）

<a id="pdf-155"></a>
<!-- PDF page 155; original page 135 -->

用“边界”一词讨论犹太人，颇为复杂。与穆斯林一样，犹太人在基督教信仰之外；但与穆斯林不同，他们身处基督教社会内部。与异端一样，犹太人存在于基督教社会中；但与异端不同，他们不被视为信仰身体的一部分。这三类群体代表三种不同边界，每种都决定了对边界所界定群体的不同态度。然而，基督教世界并不认为三者完全分离，对一个群体的态度，会延伸至对其他群体的处理。例如，十字军明确针对异国的教会敌人——穆斯林——却影响并恶化了对基督教境内敌人——犹太人——的待遇。同样，十三世纪开始密集打击异端派别，也使基督徒与犹太人之间的屏障更坚固。

此外，犹太人在基督教世界中，存在于两个并不完全重合的层面：具体的人与神学形象。神学或释经意义上的犹太人，[^p155-1] 存在于基督徒的想象与思想中，作为具有固定不变特征的内部实体，构成基督教世界观不可分的一部分；这种认识也决定了对活着的犹太人的态度。而且，即使“真实”的犹太人不在基督教社会，他们仍作为想象中的内部“他者”发挥作用。边界与想象中的犹太人这两个概念，都是理解中世纪、尤其十三世纪基督徒与犹太人关系的关键。

<!-- PDF page 156; original page 136 -->

中世纪早期，多数犹太人生活于伊斯兰地区，主要犹太文化创造也发生在那里；进入第二个千年后，犹太人却经历“欧洲化”。各种犹太文献反复出现“〔宁可〕在以东之下，也不在以实玛利之下”的说法，显示犹太人更愿生活于基督徒而非穆斯林中间。[^p156-2] 记录通常专注灾难、逆境及偏离常态的事件，对平静日子默然略过。尽管如此，史料仍使我们推知，到十三世纪初，犹太人已融入环境，共同体繁荣，与基督徒的关系大体如邻里。除宗教实践外，他们在衣着、语言甚至习俗方面，通常几乎难与基督徒区分。犹太人主要住在城市，从事商业和金融活动，大受欧洲城市化增长之益。通常可以区分三大群体：德意志犹太共同体这一大群体，包括法国北部和英格兰；再征服后的西班牙犹太中心，包括法国南部；以及意大利一个不同而独立的群体。[^p156-3]

一般来说，犹太人是基督教社会中唯一获准存在的少数群体。他们遍居基督教西方，处于相对宽容状态。这既受到圣奥古斯丁阐明的根本基督教神学原则启发，也出于当局维护法律与秩序这一可以理解的愿望。宽容和稳定，会被偶发的不宽容打断，极端时成为暴力袭击，仿佛永恒摆动的钟摆，越来越偏向不宽容。划定边界的需要变得迫切，<a id="pdf-157"></a><!-- PDF page 157; original page 137 -->恰恰因为两群体在空间、社会和文化上的接近。基督教世界团结的观念越牢固，犹太人受到的待遇越差。迫切划清边界、标明谁在内部谁在外部、防止群体间任何可能接触，是十三世纪基督教针对犹太人立法和措施的首要特色。基督徒与犹太人双方都需要边界，以保存各自独特身份；但十二世纪起，尤其十三世纪，边界往往伴随对犹太人各方面生活的限制，成为基督教转变为“迫害社会”的主要表现。[^p157-4] 这一过程最终导致犹太人被完全逐出原居土地。因此，十三世纪初犹太人尚遍居欧洲，到中世纪末，即1500年，西欧却只有意大利及德意志帝国少数地区仍有犹太人。中世纪教会立法维护犹太人受保护、并在基督教世界中获得最低限度体面生存的权利，若干教宗也颁保护诏书。[^p157-5] 犹太人得以留在基督教世界并获保护的神学理由，见于诗句：“不要杀他们，以免他们忘记你的律法；要以你的能力使他们四散。”（《七十士译本·诗篇》58:12）换言之，犹太人保证基督徒不会忘记自己的信仰，而这一信仰可见于犹太经书。但只有保持奴仆般、低下的地位，犹太人的存在才可容忍。这既是保护的基础，也是限制的理由。

在此问题上，最根本、最著名的文书，是《Sicut Iudaeis》诏书，也称《犹太人宪令》（*Constitutio pro Iudaeis*）。它于1120年由加里斯都二世首次颁行，随后由多位教宗重颁。[^p157-6] 诏书重申，<a id="pdf-158"></a><!-- PDF page 158; original page 138 -->“犹太人见证”教义的神学原则，是给予保护、禁止虐待犹太人及侵犯其权利的基础，尽管他们顽固、不肯承认真理。不得强迫其改宗，但任何已经改信基督教的人，不得反悔重新做犹太人。当然，上述一切，仅在他们不阴谋反对基督徒和基督教的条件下适用。

教会对犹太人态度的重要里程碑，是英诺森三世于1215年在罗马拉特朗宫召开的第四次拉特朗会议。会议讨论基督教世界迫切问题：教会地位、实体转变教义、卡塔尔异端传播，以及重启十字军的尝试。主要目标，是加强基督教世界的统一与一致，更鲜明划定基督教社会边界。会议总共七十条法令，有关犹太人的四条，应置于这一更广背景中理解。[^p158-7] 四条规定确定教会政策，对欧洲犹太生活影响很大：限制犹太人可收利息率；禁止其担任对基督徒享有权威的职位；禁止自愿受洗的犹太人继续遵行犹太习俗；并试图通过区别衣着，尽量减少犹太人与基督徒的接触。共同特色，是着眼两群体的联系，尽可能限制互动。

服装法令，是会议有关犹太人规定中最著名的一条。会后不久，英诺森三世致信法国总主教及主教，要求执行衣着规定，前提是不危及犹太人生命。教宗由此确认基督教会政策的双重面向：必须维持并保护犹太人，同时尽可能使其与基督徒分离。反复请求执行，表明法令并未立即、普遍落实。不过，“犹太人佩章”，即所有犹太人在公共场合必须附于衣服的识别标记，是这一法令的直接结果，佩戴义务持续数百年。[^p158-8]

另一种使基督徒与犹太人隔离的办法，是把犹太人划入专门居住区。最初，像任何少数群体，犹太人倾向聚居于自己的街区。中世纪早期，统治者希望犹太人到城里定居时，会在较好地段设置犹太街区，靠近市中心、市场或河流。阿什肯纳兹诸城如此，再征服后的西班牙亦然。中心位置有经济、社会和文化意义。中世纪城市很小，会堂靠近主教座堂或其他教堂，两群体始终接触。犹太街区并不封闭，也不排他。有些城市没有特别的犹太街区，另一些则犹太人与基督徒杂居。十三世纪起，尤其十四世纪，为限制双方接触，人们开始要求犹太人住在分离区域。[^p159-9] 将犹太人迁往完全分隔街区的进程，有时选在偏僻、不卫生的地方，直到中世纪后期才加速，最终导致“犹太隔都”建立。这种现象源于十六世纪意大利，对犹太人边缘化起到关键作用。

建立分隔、封闭犹太街区，是一种内部驱逐。更激烈的办法，是将犹太人完全逐出基督教领土。驱逐原因各异，通常混杂宗教、经济和政治动机，但无疑表达欧洲基督徒与犹太人关系最极端的一面，更准确地说，是基督徒试图彻底消除这种关系的趋势。然而，许多被驱逐者仍留在天主教世界，主要在意大利和波兰。自基督教诞生，基督徒就以文字阐述自己与犹太人的差别，形成庞大体裁；它与许多具体作品一样，称为“驳犹太人”（*Adversus Iudaeos* 或 *Contra Iudaeos*）。[^p159-10] 从二至十六世纪，约有二百四十部基督教<a id="pdf-160"></a><!-- PDF page 160; original page 140 -->作品属于这一体裁，数量表明主题对基督教的重要，许多出自著名思想家。犹太世界也从九世纪开始发展平行体裁，十二世纪以后尤其显著，称为“胜利文学”（*Nizzahon Literature*），作品达数十部。它可视为基督教作品的镜像，表达基督教施加的神学压力。[^p160-11] 但与犹太教的论争，并不限于特定体裁，几乎存在于中世纪各种作品：教士讲道、书信、历史编年、诗歌、宗教戏剧，尤其《圣经》评注。视觉艺术也成为明显的论战工具。

十二世纪，“驳犹太人”体裁繁荣，既是总体文化复兴的一部分，也是教会关于基督教社会构想的大胆表达。与犹太教的论争强化并系统化，应视为当时思想和传教趋势的一部分。这些论战作品虽自称旨在说服对手，却不用对方语言写作：基督教作品用拉丁文，犹太作品用希伯来文；而且许多言辞咄咄逼人，甚至恶毒，很难说是建立信任和理解的好方法。因此，应将之视为内部说服工具，即在内部面对姊妹宗教所提出的问题，以巩固信徒信仰。

直到十三世纪，论战文学大多围绕经文及其解释，仿佛一家人争论如何正确理解共同文本、其中故事、人物与预言。基督教阅读赋予文本预象义和寓意义，促使犹太人坚持忠于经文字面的历史阅读。但双方也都存在向对方阅读和释经开放的态度。有些基督教学者，如圣维克托的雨果（卒于1142年）和<a id="pdf-161"></a><!-- PDF page 161; original page 141 -->圣维克托的安德鲁（卒于1175年），甚至正因犹太释经忠于希伯来原文，即“希伯来真理”（*Hebraica veritas*），而认为它更优越。[^p161-12]

经文争论贯穿中世纪，延续至近代。但十三世纪，作为基督教密集传教、攻击信仰边界外所有人、包括犹太人的一部分，论战发生根本变化。新的传教与论战攻势，主要由新近成立的托钵修会策划和主持。修士担任传教士、论战者、游方讲道者、大学学者和宗教裁判官，所有职能都旨在保卫信仰堡垒，鲜明界定边界。[^p161-13]

多米尼克会的一项创新，是将《塔木德》带入两教论争的核心。早在托钵修会诞生前的十二世纪，克吕尼院长“可敬者”彼得，就在1144年的《驳犹太人根深蒂固的顽梗》（*Adversus Judeorum inveteratam duritiem*）中提出，当今犹太人已不同于过去，教会因此无须容忍他们。[^p161-14] 彼得依据彼得·阿方索（Petrus Alphonsi）1108或1110年的《对话》描绘当代犹太人；该书利用《塔木德》传说，证明犹太信仰的愚昧。[^p161-15] 与《圣经》不同，基督徒不熟悉《塔木德》，它也未译成他们的语言。这是犹太内部文本，此前基督徒几乎不干预犹太内部事务。十三世纪托钵传教把它变成核心攻击对象，指称犹太人并不按《圣经》，而是按《塔木德》生活；他们不是《新约》故事中的犹太人，而是“塔木德犹太人”。[^p161-16] 这场攻势的先锋，<a id="pdf-162"></a><!-- PDF page 162; original page 142 -->是改信基督教的犹太人。他们尤其能接触《塔木德》文本，攻击也有多个方面。一项指控是，《塔木德》充满异端和亵渎。尼古拉·多宁在1240年巴黎辩论中试图证明这一点，指控被接受为真，导致1242年法国焚烧二十四车《塔木德》。[^p162-17] 另一项论点是，《塔木德》贤哲认识耶稣，也承认其福音真实，证据藏在《塔木德》传说中。这是1263年巴塞罗那辩论策划者采用的策略，也是拉蒙·马尔蒂（Raimundus Martini）1278年巨著《信仰之匕》（*Pugio fidei*）的基础。[^p162-18]

将《塔木德》视为指导犹太生活的异端文学，使基督徒眼中的犹太人形象进一步恶化，预示犹太文化自治终结；其中也可见基督教审查制度的种子，后者将在以后发展兴盛。在巴黎，基督徒把原用于对抗基督教内部异端的宗教裁判体系，施加于犹太人。与宗教裁判一样，控诉、证词、证据和结论均由教士掌握，执行判决则交给世俗当局。

宗教论争不只是文学现象。两群体在文化与空间上的接近，促成持续活跃的对话，表达其宗教世界的活力。普通教士、甚至平信徒之间自发、偶然、通俗的交锋，自然几乎不留痕迹。信息可间接见于禁止平信徒辩论的教会规定，[^p162-19] 以及少数非典型作品，如1286年《马略卡辩论》，呈现十三世纪平信徒商人之间的辩论。[^p162-20]

十三世纪一项创新，是把辩论正式变成公共事务，由托钵修士策划编排，成为旨在<a id="pdf-163"></a><!-- PDF page 163; original page 143 -->证明基督教真理的某种示众审判。包括1240年巴黎辩论、1263年巴塞罗那辩论和1269年第二次巴黎辩论。[^p163-21] 这些辩论都涉及改信基督教的犹太人，除提出《圣经》证据，也都讨论《塔木德》。最精密的是巴塞罗那辩论，1263年7月在阿拉贡国王庇护下举行，历时四天。其复杂精深，不仅取决于议题，也取决于参与者。犹太方是当时西班牙最伟大的拉比纳赫马尼德；基督教方是原为犹太人、后入多米尼克会的巴勃罗·克里斯蒂亚尼，以及一批托钵修会学者，由博学的前多米尼克会总会长佩尼亚福特的雷蒙领衔。议程清楚表达两教争论核心：弥赛亚是否如基督徒所信已经来临，还是如犹太人所信尚待未来？弥赛亚是上帝，还是确实为人？弥赛亚来临后，是否仍须遵守律法诫命？[^p163-22] 1286年在马略卡与犹太人辩论的热那亚商人英盖托·孔塔尔多，一句话概括差别：“除弥赛亚以外，我们与你们没有分歧；我们说他已经来，你们说他还会来。”[^p163-23] 弥赛亚主题是一根线，将讨论连至其他根本问题：神性——上帝是一，还是三？——童贞女生子，甚至犹太人的历史处境，即持续流亡如何证明其错误。然而，商人言论的前半句也值得注意：除弥赛亚外，犹太人与基督徒处处相同。十三世纪末，地中海混合城市中，仍有人如此断言，而托钵修士和其他教会代表，恰恰希望对这种主张树立屏障。

公开辩论体现十三世纪基督教的传教热忱，但犹太对手仍受到尊重。至少巴塞罗那如此，纳赫马尼德获言论自由，甚至参与确定议程。其他传教方法，则包括基督教讲道者强制在会堂宣讲，主要由托钵修士承担，如巴勃罗·克里斯蒂亚尼和雷蒙·卢尔。[^p164-24] 然而，对犹太人及其文化的新兴趣，也产生新型基督教学问，值得注意。马尔蒂庞大的《信仰之匕》表面为传教而作，同时也体现对犹太文学的学术兴趣，预示中世纪后期的基督教希伯来学。尽管旨在论战，它仍具有交流和对话的一面；犹太人与基督徒持续文化互动、著作跨语言跨文化翻译，以及《圣经》诠释、哲学和科学上的对话，都表达这一点。

公开与书面论战主要面向有学识的基督徒，视觉艺术的表现却人人能懂，影响更广。[^p164-25] 教会与会堂，即 *ecclesia* 和 *synagoga* 的拟人形象，广见于当时雕塑和绘画，表达姊妹宗教同时冲突而又互补的状态；两形象互相解释，缺一不可。[^p164-26] 这种较平静形象之外，还有传达更负面信息的形象，如该隐和加略人犹大：后者是背叛、贪婪的首恶，按其姓名所暗示，成为“犹太人”的化身。同样，教会讲道所用例证，如雅各布斯·德·沃拉吉内《黄金传说》中的加略人犹大故事，依据据称属于过去犹太人的传统特征，把当代犹太人描绘得极为负面。[^p164-27]

犹太人作为历史和神学存在的复杂形象，也有末世论层面。根深蒂固的基督教信念认为，犹太人确实拒绝见光，但末日将承认基督教真理，其戏剧性改宗，会预示天国降临人间。十三世纪弥赛亚期待升温，对基督即将再临的盼望加强，尤其在受菲奥雷的约阿希姆（约1135—1202年）教导影响的托钵圈子中，使犹太人改信基督教成为迫切事务。针对他们的积极传教，也应放在此背景下理解。[^p165-28]

中世纪改宗通常单向发生，即从犹太教转向基督教；教会传统上继续反对强迫改宗。但单向改宗并未消除基督徒根深蒂固的恐惧：基督徒可能改信犹太教。克莱孟四世在1267年《心怀忧扰》（*Turbato corde*）诏书中，命多米尼克会与方济各会调查犹太人试图劝基督徒改宗的报告，后来的教宗也重申这一命令。[^p165-29] 新成立的宗教裁判机构采取措施，防止犹太人影响那些原为犹太人、现已改信基督教的人。犹太人与基督徒之间的性关系，被视为异端，参与者被判火刑。合理推测，公开辩论与论战作品一样，主要为了内部宣传，强化信徒信仰。1413至1414年的托尔托萨公开辩论则不同，它被设计为使犹太人改信基督教的武器，期间确有数百人改宗，表达了十三世纪犹太教所不具有的软弱与被迫害感。[^p165-30] 城市商人阶层成长，使犹太人逐渐被挤出商业，北欧尤其如此；许多人转向放债，经济上不可缺少，却在神学和社会观念中受鄙视。渐渐地，这一职业成为犹太人的识别特征。放债加强了<a id="pdf-166"></a><!-- PDF page 166; original page 146 -->犹太人与君主的联系。君主需要信贷，对犹太人收入征重税，并以保护回报。[^p166-31] 依赖当局进一步削弱犹太人地位，有些情况下，当其用途耗尽，就被逐出王国。[^p166-32] 受鄙视的职业，加上直接联系当局，使犹太人蒙上罪与剥削的色彩，进一步增加敌意。此外，城市化、基督教社会贸易金融活动增强，以及贫富差距扩大，使基督徒把自身罪疚感推到犹太人身上，将之变为基督教社会的替罪羊。[^p166-33] 高利贷又叠加于将犹太人描绘成迫害基督徒、杀害基督之人的撒但化形象。十二世纪起，尤其十三世纪，犹太人形象更加负面，撒但化特征更清晰。如果过去他们被视为盲目、因而无知行事，如今则被看作蓄意作恶，具有根深蒂固的魔性、乖谬和背叛本性。[^p166-34] 这种魔鬼化形象的激进表达，是仪式谋杀、仪式食人即血诬，以及亵渎圣体的指控，常继之以针对犹太人的暴力袭击。

最早有记录的犹太人被控仪式性杀害基督徒，通常是儿童，发生于十二世纪中叶，<a id="pdf-167"></a><!-- PDF page 167; original page 147 -->即1144年的诺里奇。[^p167-35] 此后至1290年犹太人被逐出英格兰，已知至少十四起诬告，包括1255年林肯血诬，显示观念很容易在基督教土壤扎根。十二世纪后半叶，欧洲大陆也出现诬告，如1171年布卢瓦案，约四十名犹太人最终被烧死，尽管根本没有发现失踪基督徒的尸体。[^p167-36] 1235年富尔达，仪式谋杀诬告又增加一项指控：将基督徒血用于仪式，通常用来烤逾越节无酵饼，即 *matzot*。[^p167-37] 这种扩展版血诬，无疑是中世纪基督徒与犹太人关系中最黑暗的一环。诬告在整个基督教世界获得信者，先在北欧，随后也到伊比利亚。诚然，并非所有基督徒都相信，犹太人会为仪式杀害基督徒儿童、使用其血。国王、教宗和基督教学者，持续高声反对，甚至试图揭露虚假，却未能根除这一信念，或阻止其蔓延。[^p167-38]

除血诬外，十三世纪后期又出现圣体诬告，即1290年的巴黎案。其前提，是相信犹太人以欺骗手段获得圣体，随后加以虐待和亵渎。[^p167-39] 著名故事都以圣体产生奇迹告终，使犹太人违背自身意愿，最终证实基督教信仰。仪式谋杀与圣体这两类诬告，都重演被归于犹太人的原初、永恒之罪，即钉死耶稣。按诬告逻辑，犹太人明知耶稣是弥赛亚，仍杀害他；又因信仰命令，不断杀害其身体，即圣体，以及其信徒。目前已知，至少一百八十起血诬<a id="pdf-168"></a><!-- PDF page 168; original page 148 -->曾针对犹太人提出，另有约一百起圣体诬告，许多造成犹太人死亡。[^p168-40]

关于诬告为何出现，有多种解释。有些到犹太世界寻找起源，认为是基督徒误解犹太习俗或信仰；另一些则到基督教世界寻找，把它们与实体转变教义的确立，以及怀疑该教义引发的焦虑等联系起来。[^p168-41] 后来又增加井水投毒的指控，如黑死病期间，以及以黑魔法摧毁基督教等。基督教公众愿意接受针对犹太人及其著作的指控，体现时代气氛与基督教虔敬的性质；这种虔敬尤其强调耶稣作为人的痛苦，以及对其母童贞女玛利亚的崇敬。[^p168-42] 对犹太人的指控，反映基督徒基本焦虑，以及基督教意识中非理性因素加强。诬告也显示，犹太人虽数百年来都是基督教社会的少数群体，有时甚至受迫害，基督教想象却仍以全部原初活力，保存信仰根基处的原初创伤，即钉十字架的创伤。在基督徒想象中，犹太人仍是迫害者，基督徒仍是被迫害者。对犹太人而言，无数指控在两教间造出不可穿透的边界，其破坏性影响，显见于中世纪后期，延续至近代。
