# 第23章 镇压与权力

约翰·H. 阿诺德（John H. Arnold）

<!-- PDF page 375; original page 355 -->

沃尔姆斯城的编年记录者告诉我们，那是我主1231年：

> 蒙神允许，一场悲惨的瘟疫、极严酷的判罚降临。来了一个名叫康拉德·多尔斯的托钵修士，完全不识字，属于宣道兄弟会；他带着一个名叫约翰的在俗男子，此人独眼、残疾，实在极其卑劣。两人开始……首先在穷人中，声称知道谁是异端；他们开始烧死承认罪行、却不肯离开其教派的人……他们定罪的许多人，临死时全心呼求我们的主耶稣基督，甚至在火中，仍竭力呼喊，恳求上帝的圣母及众圣徒帮助。

后来，马尔堡的康拉德，加入多尔斯与约翰。康拉德是一位司祭，曾任匈牙利的圣伊丽莎白（1217—1231年）的告解神师，以严苛闻名，直到她不久前去世。此后，由第二位康拉德带领，且获教宗权威支持，三人继续工作：

> 的确，承认异端者——许多无辜者，为活命也如此——须剃去耳朵以上的头发，并按〔宗教裁判官〕所愿，始终以此模样行走。真正拒绝〔认罪〕的人，则被烧死。他们的意志，处处得逞，因为康拉德弟兄，是识字之人，且极善言辞。

编年史作者说，这三个宗教裁判官，都是“不称职、没有怜悯的法官”，据说夸口：“一百个无辜者中，只要有一个有罪，我们也会把他们全烧死。”[^p375-1]他们确实这样烧人。

这些发生于中世纪德意志、美因茨总教区的事件，可能是中世纪最早调查异端的宗教裁判实例。其他有关马尔堡的康拉德活动的记述，强调几乎无人能逃脱其掌握；因为只有承认<a id="pdf-376"></a><!-- PDF page 376; original page 356 -->异端，并牵连他人，才能获得自由。这十分符合某种时代图景：狂热宗教裁判官，追捕倒霉的受害者，不加区别地起诉，逼供，并尽可能多地判处死刑。残酷、冷峻、不合逻辑，是“信仰时代”的阴暗面。人们很容易想象，这样的时代，不仅坚决要求宗教一致，也必然敌视一切文化偏离，不重视个人自由，无情强制严格的性与社会规范。几乎无法想象，更具压制性的社会。

然而，在轻易接受这种流行的中世纪镇压形象之前，应更仔细考察美因茨周围的事件。上引编年史，由匿名教士，在迫害发生前后写成，显然痛惜康拉德的作为。此外，美因茨总主教，曾极负面地向教宗报告其行动，说自己曾警告康拉德：“如此大事，应更温和、审慎地进行，但他拒绝了。”[^p376-2]康拉德指控若干有权势贵族为异端；但1233年，案件提交美因茨的主教、贵族会议时，指控遭驳回。三天后，康拉德被杀；多尔斯与约翰，也遭类似命运。教宗最初写信，称康拉德为殉道者；但不同于后来某些遇害宗教裁判官，他并未封圣，大概因为恶名过甚。事实上，他死后一年，一次教会会议上，一位主教“突然说出这些话：‘马尔堡的康拉德师傅，应该被挖出来，当作异端烧死。’”[^p376-3]康拉德或获教宗认可，但这不意味着，整个教会欢迎其行动，也不意味着，每个教会人士赞同其观点、方法，更不意味着，其社会中的世俗权力支持他。作为这场“瘟疫”的结局，沃尔姆斯编年史作者记载，一位教宗使节宣布：今后，“涉及异端调查之事，圣父的传承、法律与《圣经》，如今及永远，都须严格遵守”。[^p376-4]不加区别的迫害，应由有条理地施行法律取代。

原本纯黑的图景，如今或显为更复杂的灰色。黑暗中世纪的形象，今天仍常见，尤其在大众文化中，也影响某些历史研究。然而，这一形象，有自身的历史。它尤其在<a id="pdf-377"></a><!-- PDF page 377; original page 357 -->宗教改革剧变之后形成。十六世纪起，新教史家，在更早时代的异端中，寻找改革根源，把当代斗争，与过去迫害相联系，描绘无所不能、压制严厉的公教会。这一视角的某些成分，继续影响十九世纪晚期、二十世纪，奠定中世纪镇压研究基础的历史著作。然而，近来的研究，部分因更同情中世纪公教，而尝试修正这一形象。[^p377-5]历史学家强调，中世纪教会具有多样性，主张可在中世纪思想中，辨认一定程度的宗教宽容；在镇压无可争辩地存在之处，则强调中世纪人，在多大程度上，把异端及其他偏离，视为对社会、救恩的深刻威胁，因此采取行动。这样看，宗教裁判官，较少是镇压的狂热者，而更多是有教育的教会人士，按条理工作，试图挽救羊群的灵魂。

这些修正，十分重要。不能、也不应以马尔堡的康拉德的活动为代表，把整个中世纪教会一笔抹黑。但同时，康拉德的恐怖统治，确实发生过；有人因被认为违反信仰而遭杀害；这也并非教士领导狂热迫害异说的唯一场合。此外，教宗以教会法统治，取代康拉德的狂热，并没有给德意志带来温和的宗教多元秩序；而是把不受约束的宗教暴力，换成更微妙，却可以说更强有力的教义管控框架。新教改革者，为中世纪教会所画的耸人图景，应予放弃；但这并不必然意味着，应在其位置，挂上一幅苍白的宽容、和谐水彩。我们需要的，是能表现更复杂明暗层次的画面。

## 镇压的发展

R. I. 穆尔提出一项有影响力的论点：十二、十三世纪，对异端、犹太人、麻风病人及其他群体的迫害，在中世纪社会中，变得习以为常，并制度化。[^p377-6]这<a id="pdf-378"></a><!-- PDF page 378; original page 358 -->并非因为遭迫害群体本身，发生了客观变化；他们对基督教的“威胁”，并不比从前更大。穆尔所谓“迫害社会的形成”，有两个相互关联的原因。一是新生国家官僚机构的发展，使镇压得以制度化；二是litterati，即有自觉意识的受教育教士、行政人员阶层兴起，大部分官僚机构由他们运作。他们在修辞上，把认定的“局外人”，作为一个集体妖魔化，以强化自身精英地位的合法性。

穆尔关于识字精英兴起的理论，或许不能说明全部。沃尔姆斯编年史作者，把马尔堡的康拉德的权力，部分归于识字；但多尔斯却被称为“完全不识字”。不过，该描述所用的词——laicus totalis，字面为“十足的平信徒”——显示，教士对平信徒及其智识能力的观念，如何影响文化与宗教变化。十一世纪、十二世纪早期，描述异端爆发的资料，倾向把平信徒，表现为相当简单、没有区分的群体：或是轻信的羊群，容易被异端首领的巧舌迷惑；或是虔诚信徒，对异端教派施加正义暴力。后一类记述，有时或反映某种现实；但平信徒敌视异端，并非源于对宗教多样性的天生反感，而是源于教会恰在这一时期，教给他们，尤其教给世俗当局的态度。教会反对异端，以及其他群体的第一种武器，是言语。十二世纪，卡特里派异端，在朗格多克占据强势时，最初反应，是向当地派遣有力的正统讲道者，克莱尔沃的伯尔纳（1091—1153年），是其中最著名者。十二世纪神学家，在讲道集，以及为讲道者提供材料的论战文本中，提出一种教会统治理论：它不仅涵盖基督教，也声称对犹太教拥有某种管辖权，并宣告伊斯兰教，是一种基督教异端。这些观念，在十三世纪，尤其英诺森四世（1243—1254年）时期，进入教会法。[^p378-7]抽象论证之外，又辅以修辞。描绘异端的多种套语，变得常见：异端者疯狂、受迷惑，其异说像癌症或疾病蔓延；异端是毒药，暗中起作用；在假虔敬的遮蔽之下，最恶劣的性与<a id="pdf-379"></a><!-- PDF page 379; original page 359 -->灵性越轨，被指为正在发生。[^p379-8]例如，异端被指控，举行秘密淫乱聚会，杀害儿童，亲吻魔鬼肛门；整个中世纪，不同时间、地点，反复出现这一指控的全部或部分，包括一位编年史作者，对马尔堡的康拉德所迫害者的记述。[^p379-9]

这些关于邪恶的幻想，为随后的暴力，作了必要准备。妖魔化修辞，使人害怕那些被认定的局外人，把他们置于共同体纽带之外。敌意形象，在群体之间渗透：异端淫乱、杀婴的故事，与同样诞生于十二世纪的犹太人仪式杀童幻想，显然相似；十五世纪，某些地区的巫术，也开始与杀童相联系。异端被比作毒药；犹太人、麻风病人，则被恐惧为投毒者，尤其1321年，法国“发现”投毒水井阴谋，据称犹太人付钱，让麻风病人施毒。对性污染的恐惧——犹太人与基督徒之间，麻风病人与健康者之间，娼妓与嫖客之间，鸡奸者与其他男性之间——是反复出现的主题。异端、犹太教、巫术、鸡奸，某些时候，其所谓威胁，被混为一谈，尤其十五世纪。最荒谬的例子之一，或是某些评论者声称，亵渎圣体的犹太人，正与胡斯派异端联手。这套修辞暗示，在某个层面，这些越轨者相互联系，联合于同一个撒但阴谋中，攻击基督教世界。

不过，教会不只传播修辞，也颁布法律。可以通过若干立法里程碑，追踪镇压的制度化。十一世纪对异端的回应，在观念、实践上，基本是地方性、个别性的。某位主教，或写信问另一位，如何处理困扰自己教区的特定异端群体；但几乎没有“教会政策”的意识。事实上，恰因缺乏统一政策，才寻求建议。因此，行动各不相同：有的取消共融，但暂容异端存在，这是列日主教瓦佐约1048年所给的建议；有的与异议者辩论，如1025年的阿拉斯；有的未经正式程序，直接处死，似由平信徒动手，如约1028年的蒙福尔特。但十二世纪后期，情形改变。第三次拉特朗会议（1179年），诅咒若干具名异端群体，并以旨在争取地方世俗<a id="pdf-380"></a><!-- PDF page 380; original page 360 -->权力协助的措施，对付他们。教宗诏书《Ad abolendam》（1184年）、《Vergentis in senium》（1199年），分别确立：平信徒必须与教会合作，追究异端；异端本身，是一种叛逆，因此同时威胁世俗与教会权威。后来对《Ad abolendam》的注释，把《约翰福音》中耶稣的话，作为应给异端何种“相应惩罚”的指示：“人若不常在我里面，就像枝子丢在外面枯干；人拾起来，扔在火里烧了。”（15:6）1215年第四次拉特朗会议，在开篇界定基督教信仰时，以长篇异端谴责，框定其内容，并引入在象征上，把犹太人与其居住的基督徒共同体分开的措施。此后几十年，直至十四世纪，欧洲各地教区会议，不断阐发、扩展第四次拉特朗会议，关于异端、犹太人，以及正统基督教实践正式要求的措施，例如每年告解。

专门针对宗教异议的措施，在十三世纪中叶发展，最突出者，是宗教裁判。反异端宗教裁判，最初出现于十三世纪三十年代早期，利用一种新的法律程序，即职权调查（inquisitio）；它发展于英诺森三世任期最初几年，并由第四次拉特朗会议正式确立。最初的裁判，如马尔堡的康拉德的行动，缺乏纪律与明确目标。但很快，更精细的安排出现。影响重大的教会法学家佩尼亚福特的雷蒙德（卒于1275年），在1242年塔拉戈纳会议上，详细界定异端越轨；纳博讷会议（1243年）、贝济耶会议（1246年），再加指示。约1248年，第一部真正的宗教裁判手册写成；1252年，《Ad extirpanda》诏书，给予酷刑使用以教宗认可。十四世纪二十年代早期，著名多明我会宗教裁判官伯尔纳·吉，编成《宗教裁判实务》（Practica inquisitionis），与稍后的尼古拉·艾梅里克手册一道，成为此后数世纪宗教裁判活动的模板。教宗宗教裁判官，起初主要在法国南部、德意志部分地区、意大利北部，针对卡特里派与瓦勒度派。但随后几个世纪，其目光移向更广领域：镇压方济各会属灵派，骚扰贝居安女子，即自发采用近似修道生活的平信徒，尤其女性；著名地消灭圣殿骑士团；可以说，先在十四世纪德意志构造出所谓“自由之灵派”，再加以迫害；到十五世纪，又把部分注意力，投向巫术，同时继续追究德意志、皮埃蒙特残存的瓦勒度派。偶尔，也有犹太人、鸡奸者、神秘主义者，被卷入审讯。

十五世纪最后时期，独立、由国家支持的西班牙宗教裁判所，开始针对伊比利亚半岛，来自犹太教与伊斯兰教、受到怀疑的改宗者。

这一连串渐趋强烈的年代与实践，或有些误导，把镇压表现为按方案不断上升。发展并非这样计划：没有一个长期方案，要制造迫害社会；教宗只是间歇性地带头，指导以其名义进行的活动；整个几个世纪，教会始终是多样实体，有时在某地区接纳，另一区域却起诉同类事物。酷刑虽获许可，与世俗法一样，但十五世纪以前，使用相当有限，尤其因为教会法学家，十分清楚它可能产生虚假供认。没有中央镇压机构；作为常设教宗机关的“宗教裁判所”，直到十六世纪才建立。然而，中世纪宗教裁判官，在工作中相互合作，汇集自己保存的大量审判记录，撰写手册，概述共同任务。许多人，但并非全部，来自多明我会；调查异端，只是其修道任务之一，例如伯尔纳·吉，把大量时间用于编写会史。同时，教宗宗教裁判以外，也有其他迫害机制：例如，主教能够，也确实运用职权调查，追究本教区异端；此外，还有主教、总执事对堂区的巡察，有时起诉违反信仰的各种“弊端”，从性越轨到使用魔法。个别镇压实例的回响，也可能远超对少数人的处罚。我们再次可能怀疑：所见究竟黑白分明，还是笼罩各种灰度？问中世纪教会，究竟多么压制，是合理的；但问题，也可稍作改变：教会对信仰潮流，行使何种权力？

## 迫害的机制

教会武器库中，最引人注目的，是十字军：起初用于东方伊斯兰世界，十三世纪起，也在欧洲内部，针对异端地区。1209至1229年，征服朗格多克的尝试，以及十五世纪，针对波希米亚胡斯派发动的十字军，都是残酷镇压，使用最粗暴的武力，间或由狂热宗教热忱滋养。但十字军，是钝器。它以重击，使朗格多克丧失政治自由，<a id="pdf-382"></a><!-- PDF page 382; original page 362 -->图卢兹的雷蒙七世去世后，该地区归入法国统治；然而，异端并未由此根除，只是从宫廷、城镇，移到森林、山地。多年十字军之后，卡特里派，依靠平信徒支持者，获得日常供给；又凭与意大利松散的制度联系，获得灵性支持。要根除异端，必须使用更细密的宗教裁判工具。大体到该世纪中叶，卡特里派已被铲除，但某些残余，一直延续到十四世纪相当晚的时候；瓦勒度派异端，也在南欧延续至宗教改革。[^p382-10]

宗教裁判做到、十字军未做到的，是磨损、最终撕裂支持异端教派的社会组织。宗教裁判官进入某地，会向民众讲道，提出选择：未来两周内，自愿前来，为自己的异端罪过，求取宽恕，惩罚将只是轻微补赎；若继续等待，直到被传唤或逮捕，惩罚就重得多。出现在宗教裁判官面前时，还必须说出别人的名字。与基督徒奉命向本堂司祭所作的年度告解，形成鲜明对照，裁判供认，既向内，也向外。承认自身罪过，并不足够；还须指出、列举、详述他人的行动。这种制度，破坏共同体依赖的信任，尤其当共同体试图逃避侦察时。十三世纪中叶，很快就能在裁判记录中，看见邻人威胁或恳求另一个邻人，不要说出共同活动。后来的证据，还显示，有些人利用裁判官到来，解决仇怨，或真或假地告发邻居中的敌人。通过这种威胁与劝诱的细密混合，宗教裁判，腐蚀了异端支持者的团结。有时使用密探；十四世纪，裁判官已善于强迫、诱骗嫌疑人供认。十三世纪中叶起，宗教裁判把供认档案，化为强大武器；不同裁判官，在几十年间，可以汇总、交叉对照、查阅，利用过去越轨的文字记录，在多年后使人落网。[^p382-11]

但对十字军与宗教裁判，也必须指出其有限性。十字军本质上是一场战争，而战争总须结束。阿尔比十字军，本身并不是连续二十年的暴力，而是一串残酷冲突，不均匀地分布于这二十年。如前所述，宗教裁判并非常设法庭，而是在特定时间、地点的特定任务。十三世纪中叶，涉及范围广，覆盖法国南部许多地区，以及别处；短短几年，至少八千人，可能多达其五倍，遭审问、判决。但后来的裁判，人数少得多，以百计，而非以千计；裁判官也总在特定时段活动。十五世纪英格兰主教，以职权调查对付异端时，受询人数更低，使用更零星。这两种镇压武器，要有效运作，都十分依赖世俗支持；这种支持，并不总能获得。法国王权，直到南方战争的最后几年，才肯介入；《巴黎条约》（1229年）后，立即通过的大量立法，旨在强迫贵族，打击此前忽略或支持的异端。理论上，裁判官享有广泛、非常权力；但实践中，没有地方世俗支持，其工作至少困难，最糟时，甚至自身危险。上文已见康拉德及助手的结局；他们并非唯一被对手杀害的裁判官，纪尧姆·阿尔诺于1242年，维罗纳的彼得于1252年，也遭同样命运。法国、意大利、德意志裁判官，在不同时候，还遭较低强度的威吓、骚扰、集体抵抗。

就反异端斗争而言，可以说，在某些时间、地点，能辨认出迫害社会：十三世纪中叶的朗格多克，以及稍后的意大利城邦，根除卡特里派；十四世纪德意志部分地区，主要针对瓦勒度派、所谓“自由之灵派”；十五世纪英格兰，较间歇地针对罗拉德派。对反犹镇压，也可作类似说法：间歇性暴力——仅举少数，1095至1096年德意志等地，十二世纪中后期英格兰的零星事件，十三世纪九十年代德意志，1320至1321年法国，十四世纪九十年代西班牙，十五世纪早期再度发生于德意志——被欧洲各地大量反犹教会立法串联。立法尤其集中十三世纪，此后周期性重申。近来<a id="pdf-384"></a><!-- PDF page 384; original page 364 -->研究，却较少强调反犹太教情绪的持续、病态性质，而更多强调不同群体，如何把针对犹太人的镇压暴力，用作政治工具：从1290年英格兰驱逐犹太人之前、十三世纪与英格兰王权斗争的男爵，到十四世纪法国反对税收的大众政治抗议。[^p384-12]同样值得注意，中世纪晚期英格兰，反犹态度，仍发挥某种文化“工作”，例如乔叟《坎特伯雷故事集》及各种宗教剧；此时，这种仇恨的假想对象，已离开英格兰海岸一个多世纪。仇恨脱离所谓目标，显然被用于特定目的。本书大部分时期的巫术起诉，也可作同样判断：早些世纪，本来罕见；许多案件，与针对权势人物的阴谋相连，本质上属于特定政治斗争。即使十五世纪，著名《女巫之锤》写成时，也如此。[^p384-13]事实上，海因里希·因斯蒂托里斯，撰写《女巫之锤》，并非体现当时对巫术的态度、政策，而是试图重新塑造它们。此前，他曾试图说服因斯布鲁克当局，起诉自己认为潜藏当地的大批女巫，却被当局嘲笑，逐出法庭。[^p384-14]

因此，开篇美因茨的镇压实例，在某种意义上，比我起初所说的更具代表性：康拉德在特定时期，恐吓特定区域；但镇压发生于政治紧张局势中，这种局势，最终又限制其活动。人们有办法，个人或集体抵抗这类权力。例如，受宗教裁判官审问者，有时试图只供出死者作为同谋。宗教裁判开展的早期，若干城镇，一度成功把裁判官逐出城墙。还有几次，群体试图偷走、销毁裁判官的文书记录。十四世纪初，卡特里派支持者，倾向只二三人一起，与完美者会面，希望若裁判官来访，有限的潜在证人，能更容易<a id="pdf-385"></a><!-- PDF page 385; original page 365 -->应付过去。方济各会讲道者伯尔纳·德利雪，曾著名地在法国南部，领导反对宗教裁判的大众与法律抗争。他固然失败，后来还因巫术被判刑；但他能够尝试，且获得一定支持，已说明裁判官并无绝对权力。因此，镇压机制，以多种方式，受地方政治、态度变化左右。可以说，意识形态虽有意，国家机构却即使不算软弱，至多也不稳定。以这些方式行使权力，从未获得足够物质资源、政治支持，使之真正制度化、常规化。世俗意见，可以在某些时间、地点，被动员起来，制造、排斥“局外人”；但不能持续，也不总达到促成暴力或法律行动的程度。镇压始终发生于特定情境，而非普遍常态。

那么，更细密的镇压工具如何？关于讲道，也可作类似判断。针对“局外人”最有力、有效的讲道活动，例如十四世纪末西班牙文森特·费雷尔（约1350—1419年）的反犹宣传，或十五世纪意大利城市中，锡耶纳的贝尔纳迪诺（1380—1444年），对鸡奸、巫术等的谴责，同样具体，具有地方性。它们引人注目，恰因欧洲各地，并未原样重复，也因个别讲道者，在煽动听众上，异常有效。镇压修辞虽倾向把基督教世界的假想敌，连成一个集体威胁，却不意味着，所有态度，都被导向同一方向。例如，十五世纪最初十年，在巴塞尔，多明我会神学家莱茵费尔登的海因里希，在迫害本城贝居安共同体中，发挥关键作用；当地方济各会士，曾试图保护她们，但失败。1416年，同一个海因里希，却因向多明我会院平信徒工人，作“鸡奸式”求欢，而被城市当局调查。不过，他的修会成功维护了他。[^p385-15]这些事件中，异端与鸡奸相遇，却远非预想的勾连方式。“多头怪兽”的修辞，可放大任何单项威胁，却不意味着，所有中世纪教士，更不用说平信徒，都认为犹太人、异端、麻风病人、同性恋者等，始终合谋。若真如此，他们几乎不可能在任何时候，允许犹太共同体<a id="pdf-386"></a><!-- PDF page 386; original page 366 -->住在身旁，也肯定不会向中世纪后期发展起来的众多麻风病院，施舍。甚至异端，也可被另眼看待，平信徒听众，也可能质疑讲道者对其罪行的谴责。例如，有些场合，明显与瓦勒度“教派”无关的平信徒，仍谴责处死一位瓦勒度派讲道者，认为他显然过着圣洁生活，不应遭此命运。[^p386-16]

因此，教会耸动的宣传，并非总有直接效果。平信徒听众，无论大众还是精英，有时会被狂热讲道者，煽动参与镇压；但也能忽视，甚至拒绝此类号召。也并非每位教士，都按同一讲稿宣讲。教会等级体系，寻求教义、态度一致的基督教世界；但实践中，欧洲各地基督教差异甚大，不同支流，体现不同态度。巴塞尔方济各会士，试图保护贝居安共同体，免遭多明我会攻击，只是众多例子之一，显示不同基督徒生活方式间，可能出现的张力，以及张力所能促成的多样性。不过，这种多样性，并非无限；指出中世纪教会之屋，有许多住处，并不意味着主体建筑不存在。它确实存在，而且需要权力、权威建造。但较粗暴的镇压努力，并不能充分代表这些权力的复杂性质。

## 正统的塑造

如前所述，人们认罪时，马尔堡的康拉德与同伴，会给他们剃头。另一资料明确指出其目的：供认后，这是强加于认罪者的“补赎标志”。[^p386-17]罪责、供认、补赎，聚焦个人，也是教宗在十三世纪强化的更广泛悔罪体系的一部分。第四次拉特朗会议要求年度告解；平信徒的告解神师，会按罪行，以及罪人履行能力，指定适当补赎。通常是反复念《主祷文》《圣母经》、斋戒、施舍、朝圣。这些实践，通常被称为“私人”补赎，并非意指<a id="pdf-387"></a><!-- PDF page 387; original page 367 -->秘密，而是其效果向内，仅针对个人。然而，康拉德施加的补赎，性质不同：它明显公开，既试图培植私人痛悔，也同样试图施加公众羞耻。这类补赎，成为宗教裁判对付异端的关键特征，虽未完全沿用美因茨的残酷形式。裁判官能对定罪者，施加多种补赎，包括长期监禁、前往遥远圣所朝圣——朝圣者必须带回书信，证明确实到过——以及重额罚款、没收财产。但最常见的，是强制佩戴十字：两个黄色十字，分别缝在衣服前后，在规定期间，始终佩戴，可能一年、两年、十年，或终身。裁判官以使人被烧死闻名；某种意义上，并非不当。重新陷入异端，或“顽固”坚持异端者，会被送上火刑柱；教会“放弃”照管其灵魂，也向他人发出严厉警告。但阿尔比十字军，以及十三世纪四十年代最后的卡特里城堡陷落后，死刑相对罕见。伯尔纳·吉所作判决，保存至今：六百余次裁决中，四十一人被送上火刑柱；更多人，则立即，或经一段监禁后，须佩戴黄十字。[^p387-18]

烧死人，显然是镇压。它最有效地使人沉默，也恐吓其直接支持者。但用十字标记人，是性质颇不同的行动。问题并非它是否“更仁慈”，而是它更复杂，更明确向外、面向整个社会，成为可被解读的符号。整个中世纪后期，教宗裁判官，都作这类判决。英格兰主教，起诉罗拉德派时，也让定罪者，列队走向教堂、市场，有时手持柴捆或其他补赎标志，显示罪责。使越轨身体，在公众面前可识读，也见于别处：犹太人须在衣服上，戴特殊徽记；麻风病人，须携铃，宣告自己到来；十四世纪起，娼妓常被命令，穿条纹兜帽等特殊服饰，以示区别。这些符号，可以理解为，使“局外人”可见，因而把他们排除于社会接纳之外。但这类惩罚，还有另一用途，使人类学上整齐的“内群体”“外群体”区分，复杂起来。欧洲各地，教会<a id="pdf-388"></a><!-- PDF page 388; original page 368 -->法庭，经常判人公开补赎，最常针对私通、通奸等性罪。通常，获罪男女，会在市场与教堂周围，被鞭打着行进，有时只穿内衫，手持白杖或蜡烛。这类场面，在中世纪堂区，颇为常见。因此，对异端、犹太人、娼妓、麻风病人的标识，以及对犯异端或其他罪者，施加更严厉的公开补赎，与共同体生活的其他规管方面，构成一条连续谱。

首先，这表明，教会反异端及其他越轨的文化武器，虽或只在特定场合，得到积极支持，但支撑它们的世界图景——越轨之罪、共同体排斥、等级管控——却得到更广泛、较被动的接受。这个意义上，镇压大体是常态，远超烧死异端、处死鸡奸者等引人注目的事件。研究者还指出，职权调查法律程序的发展，最初针对性罪的管控，起先在教士中，后来范围更广。十二世纪，罪的观念，越来越与犯罪相连，从而使以强制手段处置，有了正当理由。第四次拉特朗会议引入职权调查，容许教士依职权（ex officio）行动，在没有特定控告人的情况下，搜寻罪行，例如堂区内的性不道德。理查德·弗雷尔指出，这些发展，既形成一个“迫害社会”，也形成一个“起诉社会”。[^p388-19]起诉并非全由教会进行；德意志、意大利北部，严重性罪，包括鸡奸，常由世俗当局处罚。但这些事务，仍深受教士观念与修辞影响。

1150至1350年的发展，即穆尔“迫害社会”的巩固，不仅涉及异端，甚至也不只涉及更广泛地镇压“局外人”。重要背景，是教宗权威主张，缓慢而不断增强，在英诺森三世治下达到显著优势；随之，各欧洲王国中，教会与世俗权力的关系，也发生变化。识字精英，是这些发展的组成部分；他们对智识、文化权威的要求，支撑其寻求的改变。但这里所述转变的核心，有两个要素，或促使我们思考：

<a id="pdf-389"></a>
<!-- PDF page 389; original page 369 -->

权力不只是镇压，使言语沉默、行动消失；也具有生产性，培植新的思考、观看、说话、行为方式。第一，是司法程序改变，集中体现于英诺森三世发展职权调查。无论调查异端、教士姘居、平信徒性越轨，还是巫术，与此前控告程序（accusatio）、检举程序（denunciatio）或神判相比，职权调查，都给教会提供了一套等级性强得多的法律治理机制。能够不凭地方共同体支持，依职权行动，积极使用官僚文书，以及提取供认的技巧日益狡黠，使调查成为强大、又精细的工具。它把治理对象，作为个人，而非集体处理，将他们纳入治理的文字机器。在这里，它与第二要素相连：灵魂照管（cura animarum）的范围改变。十二世纪，教会对平信徒属灵生活的关注增长；十三世纪，尤其进入教会法立法。普遍要求年度告解，提供良好堂区牧职，扩大以改革平信徒听众为目标的讲道，都显示教会精英，看待羊群的方式改变。十一世纪、十二世纪早期的异端报告，倾向把平信徒，表现为相当被动、易受摆布的一“团”，被异端首领少量的“酵”败坏。但宗教裁判的使用，接触到这一“团”内部的个人，逐一审问，发现平信徒的越轨行为，比先前想象更多样、复杂。这是更广泛转变最锋利的一端：试图把更充分、更细致、更针对个人的属灵纪律，施于民众。平信徒的经济、性、属灵行为，都将受到前所未有的管控。在某些镇压时期，例如十三世纪朗格多克、十五世纪早期英格兰，教会不仅试图限制异端传教者的活动，也试图禁止平信徒讨论基督教信仰，或传播俗语宗教文学。某一时期，可能只被视为松懈或轻微越轨的行为，到中世纪晚期，可能染上更危险的色彩。例如，亵渎性言语，长期受教会作者谴责；但十五世纪，有些地方，不再只把它视为应责备堂区居民的坏习惯，而纳入刑事立法，甚至宗教裁判追诉。何种行为可能构成越轨，其范围改变了。

因此，镇压的发展，不仅使人沉默、受压。中世纪盛期与晚期，它也有助于产生新的认识：平信徒<a id="pdf-390"></a><!-- PDF page 390; original page 370 -->是什么，应当是什么。迫害不同“局外人”，又带来更多生产性效果，在不同时间、地点，以不同方式，锻造、划定正统。一位较赞许地叙述马尔堡的康拉德活动的编年史作者，列出受迫害者的“谬误”。有些是异端行为的刻板印象，例如以“最恶劣的方式”，大概在肛门处，亲吻魔鬼；但另一些，更值得注意地平常：贬低教会权威，无视教士关于血亲婚姻的规定，节日工作，耶稣受难日吃肉。[^p390-20]这些罪，肯定不限于任何可辨认的异端“教派”成员，而是平信徒中，普遍存在的过失。编年史作者对这类“罪行”的报告，属于改革世俗生活的更广努力，把原可视为松懈或怀疑的行为，描绘为严重违反信仰。类似过程，也在其他领域运作：诬指犹太人亵渎圣体的反犹故事，被用来强化对实体转变奇迹的信仰，强调其重要性。麻风病在身体上的可怖表现，被当作警戒例证，展示人们所谓的性罪，如何在身体上留下痕迹，从而鼓励告解、补赎。迫害瓦勒度派，强调讲道归教士所有；追捕所谓自由之灵派，划定寻求神秘共融的正确、错误方式；起诉罗拉德派，强化圣事与圣徒崇敬，也给兰开斯特政权，提供一个有用的恐怖对象，借此巩固自身合法性。十五世纪女巫审判，虽比前几世纪更常见，规模却远不及近代早期猎巫狂潮；推动它们的，是起诉当局，而非一般民众，对魔鬼活动的信念。对海因里希·因斯蒂托里斯、约翰内斯·尼德等猎巫手册作者而言，相信魔鬼，强化相信上帝，也强化在这不安定时期，必须由教会权威领导道德改革的信念。女巫那些恶魔般的越轨，是反击怀疑、反教士主义的有力方式。[^p390-21]

欧洲确实成为迫害社会；但迫害多半局限于特定时间、地点，常与其他政治争端相连。中世纪教会、世俗统治者，从未拥有那种能够维持现代迫害社会的国家机器，例如斯大林时期的俄国、二十世纪后期的德意志民主共和国，或<a id="pdf-391"></a><!-- PDF page 391; original page 371 -->作者撰写本章时的朝鲜。宗教身份与国家治理的联系，也从未像宗教改革、反宗教改革的血腥剧变所造成的那样紧密。十六、十七世纪的巨大动荡，虽产生更多关于宽容的抽象讨论，但在实际层面，宗教改革后，镇压宗教差异的意愿、机会，都比此前更大。中世纪欧洲，也不仅是迫害社会；镇压机器，始终只是生产、细化正统身份的更大机制的一部分。然而，同时，在鼓动人们恐惧“局外人”的耸动故事中，在把鸡奸与异端、巫术与魔鬼崇拜混同的做法中，以及在宗教裁判程序的发展中，它也为后来时代的黑暗，奠定基础。
