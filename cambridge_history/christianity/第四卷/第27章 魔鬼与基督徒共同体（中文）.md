# 第27章 邪魔与基督徒共同体

阿兰·布罗（Alain Boureau）

<a id="pdf-440"></a>
<!-- PDF page 440; original page 420 -->

对撒但的焦虑，在中世纪中途，充分扎根；它与对魔鬼崇拜者、党羽的无情迫害，互为因果。基督教始终意识到魔鬼存在；最早描述，见于《创世记》，以及《新约》基督在旷野的段落，[^p440-1]把他表现为引诱者、试探者。魔鬼[^p440-2]是敌人、仇敌，周围有邪魔、党羽与其他追随者。邪恶宫廷，与天上宫廷相对，其形成过程，众所周知：一群天使，随撒但堕落，继续服侍他。一种基本二元对立，把肉身、野心、绝望的诱惑，如约伯最终抗拒前的处境，与爱上帝、怜悯、希望的召唤，相对照。道成肉身的基督，是这一对立中的主导形象，坚定、胜利地抗拒魔鬼及其永无止境的恶行。中世纪中途起，对基督的敬礼，把注意力，集中到与邪魔战斗。努力效法耶稣，意味着不断争战；但与基督自身战斗的艰难、力量悬殊相比，这仍微不足道。需要对抗的邪恶，如此广大，很可能促成十二世纪出现的“卡特里”异端；人们却太容易把它们，只看作一种古老、遥远的错误，被输入、传播。

多种因素，改变这种简单二元对立。早在《旧约》，已出现与撒但没有明确联系的隐晦邪恶力量，例如《多俾亚传》的阿斯莫德，《约伯记》《以赛亚书》的莉莉丝，《利未记》的阿撒泻勒，以及《圣经》各卷中的山羊形萨堤尔。基督教史上，数世纪的<a id="pdf-441"></a><!-- PDF page 441; original page 421 -->灵性指导，创造或确认一种感觉：在人类世界之内，或附近，有强大、多形态的邪魔临在。但民众，并未因此意识到，魔鬼在开展任何精确、有组织的行动；他在一般共同体思想中，确实地位很小。[^p441-3]格列高利大教宗讲的轶事，很有名：[^p441-4]一位修女，吃一片莴苣前，未谨慎地画十字，立刻被藏在菜叶中的魔鬼附体。这种看似“土朴”的“流行病学”观念，并非全无经文基础：在加大拉人之地，基督把名叫“群”（Legion）的恶灵，藏进二千头猪群，六千邪魔，被抛入海中。[^p441-5]人们普遍相信，邪魔接近、密集，居于清朗尘世天空之上，浓厚、幽暗的大气层。这也与众天使堕落的故事相容，或在字面意义上，与传统对堕落位置的界定相容：天使从至高天（Empyrean），即尘世受造物可及的最后领域，一直被抛到环绕地球、最低、最暗的天层。

因此，魔鬼在基督教中，历史古老；但关于魔鬼的学问，即魔鬼学，似乎近得多。当然，圣保罗早已把辨别善恶诸灵，列为教会的奠基特征之一，后来产生驱魔员这一教会职务，至今仍存。基督教最初几个世纪，被附者，即energumens，能为魔鬼计划作证，提供有用知识。人们也能重构某种有关魔鬼、恶天使作为的教父与神学学问。但只有一门自主学科，不只关心邪魔存在及行动，更关心魔鬼与人形成的关系，以及发现恶灵、区分被附者与蒙启示者的方法时，才可谈“魔鬼学”。古老的辨识恶灵“恩赐”，逐渐由更实际的知识，取代或至少细化，成为以粗略教义为基础的技艺。专门论著出现，传达知识、集体经验，是新学科兴起的具体征兆之一。

因此，长期以来，人们把魔鬼学诞生，定于第一部已知实践、理论论著，即1486年，多明我会宗教裁判官海因里希·因斯蒂托里斯，出版的《女巫之锤》。[^p442-6]此前，当然已有其他裁判官手册，最著名的，是伯尔纳·吉约1323年的手册，[^p442-7]及尼古拉·艾梅里克约1376年的手册；但追捕邪魔及其术士盟友，在其中，并非如此核心，优先者是真正的异端追捕，以及程序技术问题。这一断代的好处，是能使魔鬼学开端，与大规模猎巫所见“魔鬼狂热”的开端，一致。

然而，近来研究，尤其阿戈斯蒂诺·帕拉维奇尼·巴利亚尼团队，以及皮埃雷特·帕拉维、[^p442-8]玛尔蒂娜·奥斯托雷罗的工作，已表明，更早的实践、理论魔鬼学形成的关键时刻，应在十五世纪三十年代末。此时，瓦莱发生最早一批细密的巫术审判，也出现程序教义著作，例如文书长约翰·弗伦德，关于瓦莱女巫的报告，多明我会约翰内斯·尼德的《蚁巢》（Formicarius），匿名《加扎里人的谬误》（Errores gazariorum），以及多菲内法官克洛德·托洛桑的论著。巴塞尔会议（1431—1437年），可能在经验、教义的冲突中，发挥关键作用。[^p442-9]事实上，直到此时，巫魔夜会（Sabbath），才与起诉魔鬼崇拜者，系统相连。教义是新的：中世纪教会，在正式、牧灵工作中，始终谴责或拒斥魔法实践，却轻蔑地把它，看作空洞迷信。魔鬼用诡计，使意志薄弱者，相信其力量；实际上，力量仍有限、自然。这里“自然”，按经院意义理解，涵盖上帝所造的一切。

因此，必须承认，对魔鬼崇拜者的大规模迫害，确实始于中世纪。早期有部分独特之处，“术士”大多是男性；文艺复兴时期，女性成为主要受害者。但对魔鬼的焦虑，并不只源于<a id="pdf-443"></a><!-- PDF page 443; original page 423 -->巫魔夜会观念，在受迫害者、迫害者双方中的普及；即使它暗示这一崇拜可能扩展，确实加剧狂热。“魔鬼会堂”的观念，开始扎根：一个具有全部分支、自有“灵性指导”的反教会。顺带值得注意，这种令人不安的聚会形象，出现在第四次拉特朗会议（1215年）等，对教会实践规定更严之后不久。

对魔鬼的焦虑，似乎早于这些要素被发现。十四世纪初，教宗及欧洲大王权，组织若干涉及魔鬼联系的审判，数量显示关切程度。须注意，新型指控，恰出自使这种联系成为可能的权力机构。此前，口头把被告比作魔鬼，是惯例；如今却针对具体行动，而这些行动，被认为没有与魔鬼勾结，就不可能完成。此外，与近期迷恋相关的一个重要征兆，是约翰二十二世于1320年秋，请十位神学家、教会法专家，判断魔法实践、召唤魔鬼，是否应定为异端。这很可能表示，教宗想为新立法铺路；他准备的教义跃进，需要极严肃的教义工作。

教宗问题及十份回答，保存于梵蒂冈图书馆博尔盖塞第428号手稿，安妮莉泽·迈尔，曾加以追索，[^p443-10]本文作者，则全文刊出。[^p443-11]前三个问题，下文还将讨论，显然涉及未明确与魔鬼学相连的不同巫术；第四问，却很直接：“那些向邪魔献祭，意图说服它们，迫使某人按自己愿望行事的人，或召唤邪魔的人，应视为异端，还是仅仅魔法实践者？”大多数受询神学家，虽有所保留，咨询仍产生显著结果：认可“异端事实”这一新概念。一位专家，恩里科·德尔·卡雷托，甚至勾勒一种有效的撒但<a id="pdf-444"></a><!-- PDF page 444; original page 424 -->圣事：其描述，源自十三世纪后半叶，产生的圣事契约理论。

对魔鬼活动的这类忧虑，引来不同解释。R. I. 穆尔强调镇压假说；卡洛·金茨堡认为，源于教士、大众两种文化互动。我则提出，这一过程，来自两个古老观念的结合、复兴、互动：与魔鬼订约，以及魔鬼附体。撒但契约，是古老观念，早见于著名的狄奥菲卢斯传说。十三世纪，由于政治、神学原因，它获得新鲜、可怖的现实性。第一千纪之初，人口数量、密度，大规模增长后，组织共同体生活的方式，增多、重叠，包括乡村、城市共同体，堂区、领主辖区、诸侯国、王国等。封建制度核心的复杂、多层财产归属，使一物多主的情形增加。经历极端竞争，导致休耕地、发展可能逐渐减少后，十三世纪，不同制度体系间，出现冲突、紧张时期。各主权，试图确立自身，却既无制度，也无意识形态手段；该世纪末起，社会、经院知识两个世界，陷入激烈政治辩论，亚里士多德《政治学》的到来，更加剧之。世俗、宗教统治者，都恐惧阴谋、密谋，例如十四世纪初，著名的圣殿骑士团迫害。神学方面，十三世纪三十年代起，圣事因果理论，逐渐发展，把注意力，集中到上帝与人类的契约观念。此说自然削弱，关于圣事恩典的教会、施职者理论。

超自然力量附于人身的观念，在十三世纪，也获得新实质。熙笃会的人观，与亚里士多德哲学，共同引发人类学兴趣，关注个人统一体的强项、弱点；这一概念，此时已是圣事教义的要义。精神失常者、蒙启示者、疯癫者、梦游者、狂喜者，显得格外鲜明，[^p444-12]仿佛人类处境的一面面凹镜、凸镜。个人的灵魂、身体，<a id="pdf-445"></a><!-- PDF page 445; original page 425 -->被视为更直接承接超自然影响的容器。人的个体力量，使他能抵抗自身脆弱；但自主性，也使他面临被撒但支配的危险。

直到十三世纪末，神学对邪魔，兴趣甚少，因为它们未提出特别的思辨问题；撒但及其堕落，则引发关于恶、预定、神圣天意的反思。最著名的例子之一，是圣安瑟伦于十一世纪末，写成的《论魔鬼的堕落》（De casu diaboli）。但更受关注的，仍是神圣计划及其对人类的后果，而非魔鬼地位。彼得·伦巴德约1140年写成、为大学学习提供框架的《四部语录》，仅简略谈及邪魔：讨论限于第四卷中，它们在地狱的命运；第二卷，只有一条孤立评述，引人注意。

十三世纪七十年代后，情形似乎骤变。第一部伟大经院魔鬼学作品，大概是托马斯·阿奎那《论恶》（De malo）中，关于魔鬼的长篇讨论，[^p445-13]很可能发表于1272年，接近其生命末尾。[^p445-14]这一题的十二条，大幅更新《神学大全》《四部语录注释》中的零散论述，形成完整、原创的教义体系；历史学家，大多低估其意义。[^p445-15]十二条对应十二问，可分四组。第一，问邪魔本性：第一条，“邪魔是否具有按本性与之结合的身体？”第二，三条讨论魔鬼、恶天使堕落的情形：第二条，“邪魔因本性，还是因意志而恶？”第三条，“魔鬼犯罪时，是否渴望与上帝平等？”第四条，“魔鬼是否在受造第一刻犯罪，或可能在那一刻犯罪？”第三，六条讨论<a id="pdf-446"></a><!-- PDF page 446; original page 426 -->邪魔堕落后的能力：第五条，“邪魔犯罪后，自由选择，能否重归善？”第六条，“魔鬼犯罪后的理智，是否昏暗到会出错或受骗？”第七条，“邪魔知道未来之事吗？”第八条，“邪魔知道我们内心思想吗？”第九条，“邪魔能通过改变物质实体的形式，改变物质实体吗？”第十条，“邪魔能使物质实体，发生位置移动吗？”最后两问，集中于邪魔对人的权能：第十一条，“邪魔能在内、外感官方面，影响灵魂的认识能力吗？”第十二条，“邪魔能影响人的理智吗？”

应注意，这组引人深思的问题，并不只是综合神学家对邪魔的意见，而是一系列有论证、也大胆的立场。1277年，若干方济各会士，尤其拉马尔的威廉，很快攻击它。不久，另一神学家、巴黎在任硕士法尔科的彼得，以四个极长的辩论问题，[^p446-16]讨论恶天使，细致指出：哪些地方，阿奎那更倾向哲学家，而非教会圣师，尤其奥古斯丁。最后，十三世纪八十年代初，方济各会的彼得·约翰·奥利维，在《四部语录》第二卷注释中，写七个长篇问题，讨论天使堕落。[^p446-17]阿奎那与奥利维的对立观点，为邪魔的新思考，提供基础。但并非仅是两个人冲突，其他神学家，也参与探索。九十年代初，多明我会硕士巴黎的约翰，又名让·基多尔，[^p446-18]讨论《四部语录》同一段落，为托马斯教义，提供重要补充。这些作品，共同聚焦当时主要争论，组成丰富、重要的文献群，为进一步魔鬼学研究，奠定坚实基础。[^p446-19]

经院对魔鬼、邪魔兴趣的复兴，可归于多种原因。首先，卡特里派及其他十三世纪二元论异端，持续保持<a id="pdf-447"></a><!-- PDF page 447; original page 427 -->力量，可能使人，需要在教义上，回应其基本主张之一：邪恶造物者，即魔鬼，以邪魔充满世界，统治它。1320年十位受询专家之一，雅克·福尼耶，在蒙塔尤地区，细密进行宗教裁判调查，曾亲身接触二元论广泛传播。[^p447-20]早在1241年，巴黎大学，就谴责一命题：“恶天使自受造之初便恶，从来不曾不是恶。”[^p447-21]很难知道，这项没有注明对象的谴责，针对谁。按字面看，似有一种异端，主张与神圣创造相对的邪恶创造。彼得·伦巴德，在《四部语录》中，提到某些人的意见：“他们说，天使被造为恶，并立即堕落。有些人认为，堕落天使，并非凭自己的自由意志偏向恶，而是因为上帝，把它们造为恶。”[^p447-22]阿奎那在《论恶》，指出1241年的错误命题，却未看出其中，暗指邪恶本性或邪恶创造。对他而言，问题在于，撒但立即运用自由意志，选择犯罪：

> 某些近代思想者，竟大胆宣称，魔鬼在受造第一刻，便已邪恶；显然不是因本性，而是因自由意志的行动，使他犯罪。但当时，在巴黎任教的全体硕士，都谴责这一立场。[^p447-23]

第二，早期异教知识的发现，以及古代、阿拉伯新柏拉图主义思想近来取得的声望，使邪魔与古代灵神（daimones）相混合。后者把世界，理解为由有等级的中介存在者充满；灵神具有自然、超人力量，与撒但无关。十三世纪末，“分离实体”问题，在宇宙论中，出现新面貌。天使、死者灵魂，均归此类，两者都<a id="pdf-448"></a><!-- PDF page 448; original page 428 -->没有物质身体，与天体，共处于第一运动天球以内、月上空间。尤其通过《原因论》这一中介，希腊—阿拉伯逍遥学派宇宙论，接纳理智体有别于物质、能动理智的观念。这一转向，为基督教思想，提出新挑战；但早在十二世纪，伯尔纳·西尔维斯特里斯著作中，已见痕迹，虽着墨不多。他是这一“复兴”时期，少数坚定柏拉图主义者之一。在《论宇宙全体》（De mundi universitate）中，[^p448-24]他区分月亮之上的善灵，以及所谓“随从邪魔”（satellite demons），后者诱人作恶，居于大气幽暗地带。天使与古代灵神的混同，也因人们希望，把天使看作已从至高天下降、密切参与人间事务，而持续。因此，约1240年，多明我会的圣康坦的盖里克，声称天使有两处居所：一依本性（ex natura），在至高天；一依职能（ex officio），在大气幽暗区域。堕落后，邪魔只保有依职能所占的地方。[^p448-25]

此外，十三世纪，对邪魔的思考，也因其在宏大历史图景中，可能发挥的作用，得到修订。这幅图景，由方济各会属灵派的末世论建立，以菲奥雷的约阿希姆预言为基础。时日渐近，魔鬼将产生新的助手敌基督，由重组的邪魔队伍支持。（据《启示录》中的约翰，[^p448-26]在末世上帝统治前的短暂时期，基督把这群邪魔，从囚禁中释放。）因此，邪魔被拉出不受时间影响的阴惨状态，成为救恩故事的积极参与者。

最后，十三世纪经院哲学，对天使作重要研究，[^p448-27]把它们置于一个巨大范式中心。该范式，统合普通人、受特殊眷顾者，尤其童贞女玛利亚，<a id="pdf-449"></a><!-- PDF page 449; original page 429 -->以及作为人的基督、天使，探究人类限度、潜能。新分类，使灵魂、天使更接近；按蒂齐亚娜·苏亚雷斯—纳尼的说法，赋予人“潜在天使性”，进而促进对天使学的需要。但任何关于天使意志、理性的问题，都必须在恶天使堕落的背景下讨论。意志、理性，何者优先，是多明我会圣师托马斯，与方济各会士争论的核心之一；或许恰是这一争论，促使前者，不顾难处，系统研究邪魔。总体而言，经院对邪魔的兴趣，无疑首先由其代表的边界案例驱动，而非迷恋魔鬼力量。

面对邪魔威胁，必须迅速、有效行动；但这是矛盾目标，因为有效性，预设缓慢、困难地确立真相。这一时期，教宗有多种司法选择，涉及不同程序、司法权限、调查形式。教会倾向发展以调查为基础的职权调查程序，而非控告式程序。这符合英诺森三世自1198年起，教令所开启的运动，最终形式，见于第四次拉特朗会议（1215年）第八条教规。众所周知，十二世纪以前占主导、后来延续于英美普通法的控告程序，把提出指控，交给特定案件的控告者，后者也可能承担后果；法官、陪审团，只作裁决。诉讼分两阶段：先谨慎构成案件，严格界定，即罗马术语litis contestatio，争讼确定，然后审议。职权调查，则倾向由法官或君主，依职权提出指控，继起于从归罪传闻而来的“名誉受损”。过程包括先后两次调查：先确定fama，即个人的好坏名声，决定起诉或释放；再拼合与该名声相关事实的真相。

多种司法机构，可处理召唤邪魔者：众多主教法庭、宗教裁判法庭、教宗临时委员会。通常认为，教宗约1233年，为反异端创设宗教裁判，长期保持这一功能，招募的法官，更像神学家，而非法律家。激烈争议，玷染中世纪宗教裁判形象，以至难以理性看待。有些中世纪学者，并非无据地努力反驳：不能把它与看似疯狂的<a id="pdf-450"></a><!-- PDF page 450; original page 430 -->迫害，直接相连。爱德华·彼得斯，展示一个黑暗神话，如何随时间包围宗教裁判；[^p450-28]理查德·基克赫费尔，一篇出色文章，则质疑其制度性实在。[^p450-29]事实上，一般意见，常把1542年建立的罗马宗教裁判所，尤其1481至1482年成立、作为国家机构的卡斯蒂利亚宗教裁判所的严酷现实，与中世纪宗教裁判，有限、常混乱的努力，相混淆。但它确实存在；基础虽弱，仍是强大机构。圣座任命裁判官，但他仍与原属修会，直接联系，常是多明我会，也有方济各会，较少为加尔默罗会。日常职责，也使他直接接触世俗当局。

在此背景下，附体、召唤故事，变得更可信、更重要；我们也注意到，对邪魔的思考，发生转变：不再相信其能力有限。主要有三项特征。第一，人们发现，邪魔有某些行为、与人交往方式，赋予其权力，尤其契约、撒但圣事，使自然力量汇合。令人安心的魔鬼幻觉观念，消失。第二项特征，确认邪魔活动扩大：恶行受害者、同谋，不再只是vetule，即轻信妇女，而是全人类，因为人类体质脆弱，易受超自然影响。最后，强烈末世思潮，显示邪魔释放入世的最初征兆。解读这些征兆的不确定性，由一套教会似已接受的调查、镇压过程，抵消。

然而，猎巫与经院魔鬼学之间，显然有一定连续性。《女巫之锤》描述的荒唐，多在叙事部分；其教义部分，仍在经院魔鬼学界限内。因此，或可拒绝主导研究的两个相反史学观点：一是有人试图，彻底否认中世纪存在猎巫；二是相反地，认为猎巫，直接表现中世纪教会、王权的镇压、压迫倾向。经院理性，<a id="pdf-451"></a><!-- PDF page 451; original page 431 -->既不是抵抗疯狂的根本原则，也不是错误的起因。至多可以说，一贯探究、持续修订传统类别的欲望，以及寻求真理时，日益以个人为中心，打开令人不安的思想区域，唤醒古老邪魔。创造人的学问，这一经院真正的创新，付出了代价。

当然，仍须理解：一方是新魔鬼学、程序形成，另一方是系统迫害魔法实践者、巫师开始，两者为何相隔一个世纪。[^p451-30]我们看到的汇合力量，如何实际显现？应注意，世俗当局，有时教会当局，也不愿诉诸职权调查程序。反宗教裁判的反应，有充分证明，却不能解释一切。十六世纪如此活跃的世俗法院，本可自行承担与邪魔战斗。我的假说，是新魔鬼学，只提供看似可信的论据，形成一个复杂、有条件的概念。它可如下表述，也把上文新提议汇合：“当危险时期临近，邪魔拥有巨大潜能，能够利用个人对超自然影响的易感性，以及人们愿意组成异端团体、结为撒但宣誓同谋的倾向，摧毁基督徒共同体。”连词“当”表示的假设或时间条件，普遍获承认，符合末世的共同知识。但相信末日已近者，是少数，尤其方济各会属灵派、贝居安女子。十四世纪中，这种心态，可能越来越接近人们所感的真实；当然，必须提1348年大瘟疫，及其反复出现。显然，不宜认定，瘟疫大屠杀之后，只有一次单一创伤；更应设想，征兆渐积，使末日临近，越来越可信。只有现代经济学家，能够衡量十四世纪一十年代，标志世界“小冰期”开端的动荡规模、持续时间；但它们当时，已使宇宙遍布恶兆。该世纪末，1378年大分裂，又赋予我所述命题中，关于摧毁基督徒共同体的一项内容，以现实意义。西方<a id="pdf-452"></a><!-- PDF page 452; original page 432 -->曾经历多次教宗分裂，但这一次，深刻影响一个比从前，更深入基督徒日常生活的机构。此外，不同国家教会、王权，支持这位或那位教宗，给人一种深刻、或许不可弥合的断裂印象。帕拉维奇尼—巴利亚尼团队提出假说：结束分裂的康斯坦茨、巴塞尔会议，[^p452-31]在传播新巫术教义中，发挥重要作用。这与我的解释一致。

魔鬼契约观念的激进更新，导致一种看法：存在由宣誓反对基督教统一的敌人组成的异端群体，巫师或召唤邪魔者，只是其中例子。十四世纪，人们越来越确信，改宗不可能；这强化一种想法：各异端之间，有威胁性、隐蔽的等同性。瓦勒度派，经历两百多年错误，仍遍布欧洲；伊斯兰教，持续存在并扩张；犹太人坚持信仰，也成为近来“改宗失败”信念的主要受害者。十五世纪西班牙，可怕的“血统纯洁”（limpieza de sangre）法律，可能对应一种确信：犹太人改宗，只是表面、欺骗。

因此，中世纪末，基督教历史，深受对邪魔的执迷标记。邪魔侵入经院哲学的凯旋，无疑是其瓦解，以及与世俗当局重新合谋的最重要因素之一；它给后者，带来过多加强控制的机会、理由。基督教知识的自由，付出沉重代价。
