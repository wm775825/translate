# 第20章 宗教生活的边缘：隐士与幽居者、悔罪者与第三会成员、贝居安女子与贝格哈德男子

沃尔特·西蒙斯（Walter Simons）

<a id="pdf-331"></a>
<!-- PDF page 331; original page 311 -->

过去约五十年间，中世纪基督教史研究的目光，已超出教宗、主教、皇帝、国王、圣徒和修士等熟悉人物。过去的叙述，由这些人物构成；那个时代最持久的理想，也由他们表达。如今，历史学家常把卑微的乡村司祭、勤勉的修女，以及组成编年史中“基督子民”（populus Christi）的广大平信徒，纳入考察。视角的转移，不仅扩大画面，也使我们认识到，在教会制度与常规社会边缘活动的个人和共同体，曾起到怎样的作用。本章考察一群多样而重要的人。他们难以简单归类，却都与修道生活有着宽泛联系。作为隐士、幽居者、平信徒“悔罪者”、贝居安女子和贝格哈德男子，他们身份模糊，跨越社会中平信徒与修道者这两类身份的边界。尽管他们自认正统基督徒，且常被赞为极度虔诚，却倾向于抗拒纳入修道生活的正式结构；约1100年以前，他们在官方记录中几乎不留痕迹。但在本卷涉及的时期，他们的人数、影响和公众地位，都大幅增长。中世纪晚期，有时把他们的生活称为“中间道路”（via media）或“第三身份”（status tertius）；现代学者则创造了“半修道性”一词。[^p331-1]研究这种生活，能揭示宗教献身的多种表达方式，既显示修道理想如何启发平信徒宗教生活，也显示人们如何开始质疑、乃至颠覆修道理想。

## 隐士与幽居者

这种生活的先例，远可追溯到早期基督教妇女奉献于神的守寡生活；隐士更是修道制度本身的基础。中世纪早期，修道机构遍布西方，确立个人成全的标准；非正式的宗教生活方式，逐渐不再引人注目，但无疑并未消失。公元一千年后不久，当时的资料，先在意大利中部，继而在欧洲西北部，开始报道众多隐士和幽居者：有人寻访他们，求取灵性指导；他们也以“巡游讲道者”身份，行走各地。很快，隐士便成为追求福音性或“使徒性”贫穷的新运动的先锋。他们的苦修、讲道和个人榜样，自上而下重新激活教会思想。隐士彼得在第一次十字军动员中的作用，众所周知；但在他以前，另一个隐士、拉谢兹迪厄的阿德莱尔姆，约在1080年，已在西班牙收复失地战争中，率领基督徒军队作战。[^p332-2]十一世纪至十二世纪早期诞生的许多修士会与守规咏祷教士会，都起源于这类苦修游行者的活动。仅举最重要者：罗穆阿尔德（卒于1027年）创立的卡马尔多利会、约翰·瓜尔贝特（卒于1073年）创立的瓦隆布罗萨会，以及阿鲁埃兹会（特朗卢瓦的罗杰，约卒于1095年）、丰特夫罗会（阿尔布里塞尔的罗贝尔，卒于1117年）、格朗蒙会（米雷的斯蒂芬，卒于1124年）、普雷蒙特雷会（克桑滕的诺伯特，卒于1134年），当然还有大沙特勒兹修院（科隆的布鲁诺，卒于1101年）与熙笃修院（莫莱姆的罗贝尔，卒于1110年）。这一时代建立的修院，很少有不声称自己起源于隐修处的。

很难想象，这种生活在实践中如何进行。运动最早的一些领袖，可能受希腊隐修传统启发；他们在意大利南部，亲自接触到这一传统。[^p332-3]这是十一世纪东西方社会、文化接触加强的更广泛格局的一部分。其他人则利用<a id="pdf-333"></a><!-- PDF page 333; original page 313 -->西方传统为特定修士提供的个人独居机会。例如，《本笃会规》说，这些人“不再受初入修道生活时的热情驱动，而是在修院中久经考验，借众人帮助，学会与魔鬼争战；装备齐全之后，离开弟兄们的战阵，进入旷野，单独作战”。[^p333-4]即使在以严格、有序的团体修道生活闻名的克吕尼，也有不少修士，独居林中小室；可敬者彼得任院长时（1122—1156年），会前往探望。[^p333-5]退隐于eremum或desertum，即荒野，是苦修史的常见主题，但不应始终按字面理解。这个时代备受赞颂的隐士，少有真正独居者；毕竟，唯一彻底成功的隐士，就是没有留下任何文献记录的人。[^p333-6]然而，不论这些人原先是修士、咏祷教士，还是平信徒，都共同渴望恢复与原始教会、古代旷野教父相联系的非正式苦修，也恢复基督退到山上独处的榜样，并进一步效法他的整个生活。因此，他们有时热心讲道，在我们看来或许自相矛盾。为实现这一理想，他们常拒绝修道惯例传统上规定的某些准则，例如团体纪律、定居一处，甚至会规这一概念本身。米雷的斯蒂芬，把超越修道模式、重返《圣经》纯洁性的努力，鲜明结合起来：他拒绝被称为咏祷教士、修士或隐士，因为倘若借这些名号“荣耀自己”，他的“荣耀就算不得什么”（《约翰福音》8:54）；他坚持，“除福音之外，没有别的会规”。[^p333-7]《论教会内各类修会与生活方式小书》的匿名作者，于1121至1161年间在<a id="pdf-334"></a><!-- PDF page 334; original page 314 -->列日写作，认为在“最初的时代”（prima aetas），隐士便“欣然”以这种非正式方式，侍奉、敬拜上帝，效法的是：

> 义人亚伯，住在树荫下，专心放牧羊群……那时人很少；上帝既认为他配得称义，他独自侍奉上帝，也就适宜。他通过放羊，仿佛确立了独修生活；羊这种动物，无疑喜爱安静。

他又带着辩护意味补充：因此，当时隐士享有的行动自由，并无可非议：

> 若这一类人中，显出某种多样性，各自安排不同生活，有人独居，有人二三人或更多人共居；有人生活较轻省，有人较艰苦，如同古代隐士间的多样性；又若每个人运用选择的权力，按照自己的意愿或能力，作尽可能多的尝试，旁人都不应因此不安；主也不会为此定他们的罪。[^p334-8]

女性独居者，要取得这种自由困难得多。她们倾向于留在同一处，通常住在附属于堂区教堂或修院的小室，可能终身封闭其中。像男性隐士一样，女幽居者未必独居，而可能有一个或多个同伴：极少数情况下，是男性隐士；[^p334-9]更常见的是仆人，或由主要女幽居者教授阅读与宗教知识的女孩。这一模式有许多变体。关于迪西博登贝格的女幽居者尤塔（1092—1136年），与异象家宾根的希尔德加德（1098—1179年）共同生活初期的几份引人入胜的资料，便说明这一点。尤塔是法兰克尼亚施蓬海姆伯爵之女，十四岁时，从当地总主教手中领受“神圣修道生活的会衣”，并寻找寡妇乌达，作为自己的导师（magistra）。乌达与她，一同住在尤塔寡母的居所。八岁的希尔德加德，由父母奉献于修道生活，也在那里加入她们。一段时间里，她们非正式地以幽居者身份共居；最终，尤塔、希尔德加德<a id="pdf-335"></a><!-- PDF page 335; original page 315 -->和另一位少女，于1112年11月1日，在附近本笃会迪西博登贝格修院的幽居小室，经历庄严的砌墙封闭仪式。此时二十岁的尤塔担任导师，其他人是“弟子”。1136年，她去世后，“在继承她导师职分的尊荣方面”（in honore magisterii），“无人被认为比希尔德加德更配得”。后者最终成为一个传统修道共同体的女院长，也凭自身成就，成为著名的灵性领袖。[^p335-10]这个例子充分说明，女幽居者的小室，可以成为修道生活的肥沃温床、女孩的学校——里沃的埃尔雷德（1110—1167年）对此发展深感遗憾，因为它妨碍默观[^p335-11]——也可以成为一种可敬传统的传承之处，由一代女性传给下一代。十四世纪，男性隐修生活开始衰落时，女性独居者已成为许多城镇的常见景象，尤其在低地地区、英格兰、法国和德国。布拉班特的梅赫伦与鲁汶，都是中等城市；前者十四世纪至少有五处幽居小室，后者十六世纪初期至少有七处。[^p335-12]少数女幽居者，得到近乎制度性捐产的支持；但更普遍的，是依靠个人收入——许多人出身贵族或城市显贵家庭——以及来访者的馈赠。人们向这些“活圣人”请教广泛问题，既包括神学，也包括实际生活。[^p335-13]

## 悔罪者与第三会成员

隐修生活久负声誉；这一时代兴起的其他非正式宗教生活类型，却并非如此。后者吸引的人数更多，尤其在平信徒之中。

<a id="pdf-336"></a>
<!-- PDF page 336; original page 316 -->

倾向改革的本笃会修士、格列高利改革的辩护者圣布莱斯的伯诺尔德（卒于1100年），在编年史中热情评论道：

> 此时〔1091年〕，德意志王国许多地方，共同生活蓬勃兴盛；不仅极虔诚地生活的教士、修士如此，平信徒男子也如此。他们极热心地把自身与财产奉献于共同生活；虽在衣着上不同于教士、修士，却被认为功德丝毫不逊……不仅有大量男子，也有大量妇女，服从教士或修士，献身这种共同生活。[^p336-14]

这些是新式的平信徒修士与修女（conversi、conversae）：他们成年后，以不识字者身份进入修院，在修道共同体旁边，组成一个独特群体，有自己的会衣、习惯和工作。所有新建或改革后的修会——最初是瓦隆布罗萨、希尔绍，随后是熙笃会等——都向实行这种新式修道生活的平信徒男子，有时也向女子，敞开大门。许多其他资料证实，他们后来在人数上超过唱经修士与修女。[^p336-15]但伯诺尔德随后，又欢迎另一群寻求生活转向（conversio）的平信徒：

> 在这些村庄，无数乡村姑娘，弃绝丈夫与尘世，生活在一位司祭的权威之下；甚至已婚者，也献身虔敬生活，以极大的敬虔，始终服从修道者。这种生活安排，在德意志尤其兴盛，整个村庄都接受修道生活，平信徒不断以圣洁的生活方式，彼此扶助（praevenire）。[^p336-16]

伯诺尔德或许把愿望当成现实，夸大了这一现象的规模；但他正确辨认出一种新兴社会趋势。此时，最偏远的聚落，已获得自己的教堂或小礼拜堂；社会各阶层，都能接触基督教教义的基本内容，隐士及其他改革者的讲道，更生动表达这些内容。有些信徒因此尝试，在修院<a id="pdf-337"></a><!-- PDF page 337; original page 317 -->围墙之外，在自己家中，以独身者或夫妻身份，过成全的生活。关于这些新尝试的证据，起初既稀少，又零散。维琴察的圣德西德里奥乡村兄弟会，约在1186年成立，以促进宗教性的共同生活与相互支持；其成员从1216年起，被视为“悔罪者”。《拉昂世界编年史》在1178或1179年条目中，提到伦巴第市民，或许是谦卑派成员：他们提倡“某种宗教生活方式”，衣着朴素，仍住在家中。列日由倾向改革的司祭“口吃者”朗贝尔带领的一群虔诚礼拜者，构成“秩序井然的方阵”，也是例子。朗贝尔于1175／1177年写道，他们在家中“反思教堂里听到的内容，彼此督促实践”；他把《使徒行传》译成俗语，“帮助他们做好工作”。《使徒行传》，常被用作新宗教生活方案的蓝图。[^p337-17]

十二世纪末，这些基层活动，凝结成众多“运动”，努力克服自己与教会之间往往紧张的关系。意大利的谦卑派，因平信徒讲道得罪教会当局，但于1201年，获得教宗认可，成为由教士、修女和平信徒三支组成的修会。伦巴第的“贫穷公教徒”，是与教会和解的瓦勒度派成员；自1207／1208年起，他们继续使命，但受到教会新加的限制。[^p337-18]意大利北部、中部的许多其他人，则用悔罪的语言，表达自己的努力。这源于古老且受教会法认可的悔罪者身份：罪人内在的生活转向，以某些外在标志显现，包括特殊、朴素的衣服，遵守七次日课，不服兵役，以及更严格的斋戒。1221年，罗马涅的一些“悔罪弟兄姐妹”群体，采用一套称为《生活志向纪要》（Memoriale Propositi）的共同惯例。[^p337-19]悔罪者作为平信徒男女，自然归主教管辖；但不久，对他们的监督，越来越多落到圣方济各追随者手中。方济各曾写<a id="pdf-338"></a><!-- PDF page 338; original page 318 -->两封劝导悔罪者的“书信”，被视为“悔罪者会”的规章。[^p338-20]十三世纪后半叶，人们普遍相信，圣方济各在创立小兄弟会及与之相联系的圣克拉拉姐妹会后，还创立了悔罪者的“第三”会。随着小兄弟们日益介入悔罪者生活，首位出身方济各会的教宗尼古拉四世，于1289年批准《生活志向纪要》的修改版，作为他们的正式会规；同时建议选择一位方济各会士，担任巡察员，即宗教监督者。这使他们与小兄弟会的紧密联系确立下来。[^p338-21]

整个中世纪及近代早期，这个新“第三会”，始终是一个形态相当松散的统合组织，容纳多种群体与个人。其中一些人，因圣洁生活或灵性教导，在当地深受敬重，例如科尔托纳的玛格丽特（卒于1297年）、福利尼奥的安杰拉（卒于1309年）。[^p338-22]从长远看，在这一组织支持的众多创举中，影响最广泛的，或许是十三世纪最后几十年，第三会内部“守规”分支的发展：一些悔罪者，通常是女性，组成近似修院的共同体。十五世纪欧洲几乎每座城市，都散布着这些姐妹的小型会院。她们采用尼古拉四世的会规，作为基本原则；它足够灵活，能适应各种理想，从教学、在医院照料病人，到较为封闭的默观生活。选择后一种方式的姐妹，最终开始遵守传统修女的严格禁院制度。[^p338-23]

与此同时，与方济各会附属组织相似的悔罪者组织，也相继出现，尤以多明我第三会为代表。其地方先例，可追溯到十三世纪；1405年，教宗批准其会规，此时距离最著名成员、锡耶纳的圣加大利纳（卒于1380年）的活动，已过了一段时间。[^p339-24]

## 贝居安女子与贝格哈德男子

本章最后考察的平信徒宗教运动，是贝居安女子。她们兼有上述许多特征，却又独具特色，因为几乎全由女性组成。贝居安生活的性别特征，令当时人和现代学者，都深感突出；这些特征，在很大程度上，既解释她们的成功，也解释她们的困境。

这一运动的起源多样。有些女性，如瓦尼的玛丽（1177—1213年），与家人同住——她以贞洁婚姻的方式生活——投身善工、祈祷和悔罪，与意大利悔罪者的方式十分相似。另一些，如于伊的朱埃塔（1158—1228年），延续幽居者传统，从自己的小室，为城市共同体提供灵性指引。还有一些，如圣特雷登的“奇迹者”克里斯蒂娜（1150—1224年），以游行施行奇迹者、非正式讲道者身份活动。低地地区南部及相邻法国、德国地域，更多这样的女性，没有留下姓名。支持她们的教士与平信徒，视她们为“虔修妇女”（mulieres religiosae），尽管她们并不过修院生活，也并不具有正式修道身份。她们没有修院会规，但这并未妨碍维特里的雅克（约1170—1240年），以同样适用于禁院修女的措辞，描述列日教区的这些女主人公：

> 她们为基督轻视肉身的诱惑，因爱天国而鄙弃世间财富，以贫穷、谦卑献身<a id="pdf-340"></a><!-- PDF page 340; original page 320 -->天上的新郎；尽管家境富裕，仍以双手劳动，挣得粗淡饭食。[^p340-25]

另一位早期贝居安女子的重要支持者、海斯特巴赫的凯撒里乌斯写道：“她们爱上帝，甚至超过许多住在禁院中的人。她们在人群中，过隐修生活；在世俗人中，过属灵生活；在追求享乐者中，保持童贞。争战越大，恩典也越大；更大的冠冕，将等候她们。”[^p340-26]

这种“在世间”的宗教生活观，不要求正式誓愿，也不要求弃绝个人财产，自然承接十二世纪对内在灵性、人与神的个人关系的重视，以及对形式主义日益增长的批评。不过，新颖之处是：如此众多女性实践这种生活，并逐渐自行组织起来，几乎不受男性或教士监督。约1230年起，非正式共居的贝居安女子，开始共同置产，推选其中一人担任领袖，与当地司祭约定，确保定期——最好专门为她们——举行礼拜。最早的“贝居安院区”由此产生。到十三世纪七十年代，它们已覆盖整片街区，以围墙与城市其他部分隔开。贝居安女子围绕教堂，住在小屋或较大居住单位内，开办学校，经营纺织业，尤其为贫困或年老妇女，设立收容医院。中世纪及近代早期不同阶段，低地地区某些共同体，容纳数百名贝居安女子。其中最大的梅赫伦圣加大利纳院区，十六世纪上半叶，住有一千五百余人。[^p340-27]欧洲北部、中部的其他地区，她们通常居住于分散在城市中的小型会院；但在那里，选择贝居安<a id="pdf-341"></a><!-- PDF page 341; original page 321 -->生活的女性，总数也可能相当可观。[^p341-28]然而，这一运动主要自发成长，多方面抗拒制度化，因此从未存在一个贝居安“修会”。原则上，每个地方共同体都独立自主，少有院区彼此维持紧密联系。模仿这种生活的男性共同体，被称为贝格哈德（beguini、beghardi）；它们独立发展，但规模始终不大。

贝居安理想迅速传播，在很大程度上，归功于少数有影响力的教士。面对异端运动，尤其卡特里派显见的进展，他们把贝居安女子，推举为正统虔敬的活榜样。维特里的雅克所属的朋友圈，在十三世纪最初几十年，或领受司祭职，或加入新修会，都热心在平信徒中，大力开展使徒工作。这个圈子包括他曾经的导师尼韦尔的约翰（卒于1233年），后者的同伴兼老师利鲁的约翰（卒于1216／1217年以后），尼韦尔的吉多（卒于1227年），以及年轻一代的著名圣徒传作者、学者康坦普雷的托马斯（约1200—约1272年）。[^p341-29]他们都曾在巴黎学习，接触与领唱者彼得（卒于1197年）及其门生相关的新牧灵神学。其门生包括讲道者讷伊的富尔克（卒于1202年），以及后来的教宗英诺森三世（1198—1216年）。这些人，都曾以司祭身份，为低地地区贝居安共同体提供指导，或撰写传记，记录个别贝居安女子的事迹。他们以及不少其他修道人，例如维莱尔的熙笃会士和若干多明我会士，在地区与国际层面，为贝居安生活争取合法地位，取得教宗口头许可，以及支持个别院区的众多主教特许状。[^p341-30]

但贝居安院区的广泛吸引力，也根植于更广泛的社会、文化变化。低地地区与莱茵兰蓬勃发展的城市经济，为单身女性提供前所未有的就业途径：纺织劳动、医院工作、教学。佛兰德、布拉班特和荷兰的城市官员<a id="pdf-342"></a><!-- PDF page 342; original page 322 -->与封建领主，有时协助建立院区，因为这些女性既满足实际社会需求，又提供廉价劳动力。[^p342-31]对女性而言，院区有望在危险环境中，提供安全庇护，让志趣相投的女性相互支持，也使她们能在弥撒、每日时祷、虔敬操练、歌舞和写作中，表达宗教志向。布拉班特的哈德维赫（十三世纪）、马格德堡的梅希蒂尔德（约1208—约1282年），以及玛格丽特·波雷特（卒于1310年），是这一环境中诞生的丰富、多样的俗语神秘文学，最著名的贝居安作者；但她们无疑并非仅有的作者。[^p342-32]

支持这些发展的教士，看到司祭职能与平信徒女性虔敬之间的和谐互补；反对者却看到异端、绊倒信众的丑闻（scandalum），以及颠覆教会权威的可能。民众最初同样抱持怀疑。“贝居安”之名，并非像有时被认为的那样，源于Albigensis——十三世纪称呼异端者的拉丁词——也并非源于列日司祭“口吃者”朗贝尔的名字，虽然后者被误认为运动的创始人。它实际源于词根begg-，意为低声含糊地说话或喃喃祈祷。因此，beguina原指假虔诚者：一个自称虔敬，话语却含混不清、因而不可信的女人。尽管贝居安女子后来，把这一侮辱之名，作为荣誉标志，在有关她们为劝勉而作的非正式讲道、教学、异象能力与神秘主义的争论中，原本含义仍十分鲜明。对女性在这些领域拥有权威的深刻猜疑，于十四世纪早期突出显现：1310年，波雷特因被指控持有异端而遭处死；维埃纳大公会议（1311—1312年），又谴责不服从管束的贝居安女子。同一时期，城市经济衰退，减少对女性劳动的需求，使社会政策趋于严厉；这种同时发生，并非偶然。北欧许多地区的贝居安共同体，关闭大门；少数接受“正式”会规，例如方济各第三会会规。但在低地地区，<a id="pdf-343"></a><!-- PDF page 343; original page 323 -->规模较大、关系广泛的院区，几乎完整保存下来，有些甚至延续到二十世纪；贝居安的组织方式，也启发了新虔敬运动等新尝试。[^p343-33]

## 结论

制度性与非正式权力来源之间的自然张力，始终是基督教宗教生活中，推动反思和更新的创造性源泉。中世纪盛期、晚期，教会与国家发展出更复杂的治理机构，更多人口获得教育和写作能力，这种张力很容易爆发为冲突。教会越来越重视由教士训导权进行教导，非正式宗教生活，因此提出特殊难题。十三世纪，贝居安女子和女性第三会成员兴起，又把性别问题，加到权威与正统、对神的认识，以及物质世界中的道德纯洁等复杂问题之上，使难题更尖锐。[^p343-34]然而，有些当时人，仍怀着信心与乐观，欢迎新兴的平信徒虔敬。雅克有一段名言：

> 我们不只把弃绝尘世、转入修道生活的人，视为修道人；凡在福音会规之下侍奉主、在唯一至高无上的院长之下有序生活的基督信徒，我们也可以称为守规者。[^p343-35]

在这种整体视野中，统一胜过分裂，相互影响才是常态。历史学家即使不认同这一视角，也承认，这一时代非正式宗教生活的繁盛，有助于把原本仅属修士的观念和实践，传播到广泛社会阶层。中世纪末，悔罪意识、苦修与自愿贫穷的原则、对受难时祷的默想，以及当然包括阅读、书写灵性文字的能力，都已成为平信徒虔敬不可分割的部分。
