# 第14章 法律及其运用

珍妮特·L. 纳尔逊（Janet L. Nelson）

<a id="pdf-328"></a><!-- PDF page 328; original page 299 -->

“法律”一词，具有一种迷惑性的一致外观。它可以被说成是“特定政治意识形态、甚至宇宙观”的产物。[^p328-1] 然而，即使在给定传统、地理环境、制度背景中，其运用、含义，也远不一致。研究历史中的法律，就是研究变化。本章主题，即中世纪早期教会法律，或教会法，实际是一种成分各异、参差不齐的混合物，难以用中世纪后期、或现代法律的预设分类。希腊语canon，字面是量尺，因而引申为规则；东西方都沿用此词。到600年，四、五世纪大型会议颁布的教规，广泛被视为权威。此后，西方中世纪早期各教省、王国，没有单一权威，负责发布、教授、解释教会法规则。主教不时通过会议立法；私人、地方倡议，不断编纂、流传法律汇编；主教则作为法官，应用法律。东方情形，也并非很不同。如今学者，已意识到，即使证据集中出自君士坦丁堡，地方活动、多样性仍普遍存在。东西方，教会法、世俗法，在实践中相关，皇帝立法中，世俗、教会关切也重叠。对教会，如对西方世俗统治者，《狄奥多西法典》（438年），在本章大部分时期，仍是偶尔参考依据；东方，《查士丁尼法典》（534年），则始终是教会法、世俗法的基础。[^p328-2] 不过，这些法典，尤其因为规模庞大、难以使用，从未构成全部被视为法律的内容。东西方，节本、选编都不断增多。

教会一取得永久财产，教会人士就关心，如何从世俗法获得产权保护。[^p329-3] 东方，至少官方层面，罗马国家、法律传统的延续，维持个人转让财产的权利，也维持教会作为团体持有人、永久占有的权利。西方，帝国国家已被多个较小、更具人身性质的权力替代；教会掌管者，实际首先是主教、院长，必须设计新的生存策略。他们须承认家族更广泛、持久的要求，制订更灵活的条件，如请求授予用益的契约（precariae）、封赐地产（beneficia）等，以作适应。[^p329-4] 现代教会法史家，常把私属教堂，视为教会标准下降、世俗贪婪暴力的不幸副产品。另一种更理解当事人的解释，则视之为适应策略：设计一套相互交织的法律安排，而非“体系”，让平信徒支持教会，稳定宗教服务供给，并承担成本。[^p329-5] 相互同意而建立的安排，对当时利益、需求、预设而言，运作有效。换言之，在国家相对薄弱的世界，法律顺应社会关系纹理，同时赋予贵族、农民共同体一定谈判力量。这种适应策略，远非日耳曼独有，而是从意大利南部到爱尔兰，遍及中世纪早期西方。

西方对中世纪早期环境的类似适应，也见于多种倾向：把教会人士之间的等级关系，理解、进而以法律表述为双方配对，以相互服务、保护相联。同样从八世纪起，有两个好例子：德语地区，越来越常要求司祭，用本地方言向主教宣誓效忠；新主教，则须向总主教宣认信仰、服从，作为祝圣条件。[^p329-6] 从晚期罗马帝国继承的教会法，所提供的制度、任命，更不用说官僚职务结构，无法维持中世纪早期教会等级体系。人对人的忠诚，在以领主关系维系的社会关系世界，是一种替代、可行模式，北欧尤其明显。这种模式，<a id="pdf-330"></a><!-- PDF page 330; original page 301 -->自下而上，影响、改变西方教会结构各层关系。

本时期开始，普世教会有自己的模式，即牧首区五牧首制。[^p330-7] 四、五世纪，关于它们等级次序，存在不同传统；罗马主教，一贯确认本教座荣誉首位，其他牧首区——君士坦丁堡、安提阿、耶路撒冷、亚历山大——大体承认此表述。[^p330-8] 奥古斯丁反映日常用语，把与罗马牧首区范围相当的“西方教会”，同其余四牧首区组成的“东方教会”区分。[^p330-9] 630、640年代阿拉伯征服，使安提阿、耶路撒冷、亚历山大的政治控制，脱离基督徒。君士坦丁堡要求与罗马“同等优先”，[^p330-10] 被认为可与罗马荣誉第一相协调。因此，教宗首位权，并不被理解为意味着实际法律权威，可受理其他牧首下属的上诉，或推翻其决定。西方内部，大格列高利以后约一个世纪，教宗也普遍效法他，以会议方式行动，用兄弟口吻致信主教。这些办法，适应了限制教宗意愿、或能力，不能一味发号施令的实际条件。八世纪，条件开始改变：教宗与西方基督教世界各部分，接触更广、更多；西方教会人士、统治者，在自身使用、运用法律时，也更常寻求教宗建议、支持。拉丁基督教世界，在内部维持以教区为基础的地域秩序、获得平信徒资助，在外部开展传教，运作日益有效；其结果，是不同教会、主教与修道院、等级体系不同层次、相互竞争的基督教统治者之间，展开竞争，推动越来越多人，赴罗马寻求正义、裁决。[^p330-11] 八至十一世纪不同时刻，教宗权作为法律制度，从被动转为主动；不过，多数时候，教宗是有人发问，才开口。直到本章时期末，对教宗裁判的需求，才形成足够持续的压力，催生制度化回应，以及相应代理人、机构；教会史的新阶段，随之开始。

中世纪早期西方特有——因为在那里格外必要——的适应策略，最后还有同样重要的一项：教会用自身法律，创造受祝圣王权这一新的保护性政治权力模式。[^p331-12] 在此背景下，法律与教会专长，即通过礼仪施行个人祝圣，相互结合；又加上教会重新塑造的相互忠诚信念，发生于忠诚者与国王之间。王室加冕礼核心，是候任国王宣誓承诺正义，然后由主教傅油，平信徒领袖在场，并公开同意。这一仪式，八世纪以后，在盎格鲁—撒克逊英格兰、法兰克，都有连续历史，九、十世纪进一步完善。[^p331-13] 除其他意义外，它也是西方中世纪早期教会人士运用法律的一项非凡举措，东方没有对应现象。

不过，东西方的基督教君主制模式也有许多相似之处。在东方，皇帝召集为教会立法的会议；在西方，国王扮演着类似角色，但参与制定教会法、承诺维护它并有时以世俗制裁支持教规的，不只是教会人士，往往还有平信徒集会。尤其从八世纪起，东西方自视为新选民代表的“新大卫”式立法者，都大量借用《旧约》，有时甚至逐字引用。在东方，法律为臣民和皇帝唤起一个“象征宇宙”；[^p331-14] 在西方许多规模较小的宇宙中，王国与地区的法律兼有教会和世俗成分，发挥“潜在集结号”的作用，表达并重塑政治与社会身份。[^p331-15] 为地方教会提供经费的组织方式，则呈现出典型差异：东方似乎调整国家财政安排来供给教会；西方从八世纪起要求平信徒向当地教会缴纳什一税，并将其理解为牧灵照护的回报。[^p331-16]

现代学术中，西方中世纪教会法——这种研究史未涵盖东方——常被视为<a id="pdf-332"></a><!-- PDF page 332; original page 303 -->教会国家坚定、一贯权力的特征。[^p332-17] 这是理查德·萨瑟恩对中世纪中期“成长时代”的看法。他描述“原始”中世纪早期教会时，却没有法律的位置；那个教会“组织能力有限”，沉迷神判、“华丽仪式”，其仅有治理，“尤其受无意义流变的诅咒支配”：“作为一门学问，教会法在1050年以前，几乎尚未开始。”[^p332-18] 再比较詹姆斯·布伦戴奇如今已成经典的教会法叙述：中世纪早期“孤立主义、特殊主义”，反映于教会法“向内看”的性质；同时，“问题……是法律太多……众多规则，相互矛盾、过时、不可操作……冲突、不一致的迷宫”。[^p332-19] 两位卓越历史学家，一位看不到合适的教会法，另一位看见太多不合适的；他们都谴责中世纪早期教会法，不够真正“中世纪”——意思是中世纪后期——同时又不够现代，即不是国家支持、系统化、专业化、大学教授的法律。本章主张，约600至约1100年间，某些教会人士，知道如何在迷宫中行走：他们制作、运用适用于自身世界、因而具有其独特性的教会法，使教会能作为制度，在政治上维持自身，并通过与平信徒合作，而非宣称支配，行使社会权威；毕竟，换个角度，平信徒就是教会。[^p332-20]

### 691—692年特鲁洛会议：背景与意义

七世纪末，经历许多激荡后，东西方神学争论已平静。法律方面，到了协同行动的时候。东方皇帝查士丁尼二世（685—695、705—711年），691年召集会议于特鲁洛，即皇宫穹顶厅堂教堂，其意图完全传统主义：恢复帝国光辉岁月的立法传统。[^p332-21] 迦克墩以后，没有新的纪律教规颁布；如今，要确认、普遍公布查士丁尼一世553年第五次<a id="pdf-333"></a><!-- PDF page 333; original page 304 -->大公会议，以及680—681年第六次会议的决定。[^p333-22] 102条教规，少数涉及神学，无一有争议；重点是为生活中的基督教立法，针对教士、平信徒的条款，数量大致相等。新的查士丁尼，决心恢复基督教世界形式上的统一。[^p333-23] 许多教规，东西方都能接受，也非新规：例如，禁止买卖圣职、施行圣事收费（第22、23条），或把堕胎作为杀人谴责（第91条）。春季仪式中，平信徒异性装扮受谴责（第62条），如六世纪伊比利亚西北布拉加的马丁主教所做；不过，懂得变通的教士，直到十二世纪，仍容忍罗马有类似行为。[^p333-24] 相比之下，691—692年禁止的若干行为，听来具有城市、甚至首都色彩，西方教规没有对应：司祭开酒馆，甚至更糟，为卖淫牵线（第9、86条）；教士观看赛马、戏剧；妇女洗浴时，教士或修士进入浴室（第24、51、77条）；法律学生实行异教仪式（第71、76条）；诱惑人的发式（第96条）。东西惯常实践的差异，也许更明显，但差异原因，也很明显：西方没有地方像君士坦丁堡。这些教规的主要目标，显然是更鲜明地区别司祭、平信徒生活方式；同时，强调正确施行圣餐、圣所纯洁（第69、76、81条），并规范显然发生于首都的、在私人小堂及家中举行礼仪的实践（第31、59条）。再次确认君士坦丁堡享有与罗马相等特权、罗马荣誉为首（第36条），虽重翻旧账，却少有实际问题。关于执事、司祭授任，列出不同规则，也显然如此：东方容忍已婚男子任职，与西方原则上四世纪以来坚持、实际却广受违反的独身要求，并列呈现（第13条）。还须结合第3条——禁止司祭再婚，把此规定称为“仁慈、体谅”的中间道路——以及禁止主教结婚的第12条来读。[^p333-25] 依我看来，这些教规，让人把这组问题，视为<a id="pdf-334"></a><!-- PDF page 334; original page 305 -->习俗差异，因而可容忍，就像不同禁食日，或留须、剃须一样。

特鲁洛教规，只以希腊语发布。[^p334-26] 但不应因为语言改变，就认为东西方已普遍缺乏理解。罗马教宗、众多教士都懂希腊语，很容易理解文本。教宗塞尔吉乌斯（687—701年），拒绝认可特鲁洛“错误的新创”，也许所指，是第31、59条处理的东方城市“家庭教会”（见上）。[^p334-27] 不过，教宗君士坦丁（708—715年），710年访问东方时，接受了这些教规；这是统一的壮观姿态，反映会议本身的精神。[^p334-28] 当时，无人会怀疑，这是直到二十世纪末，最后一次这样的教宗访问；因此，把特鲁洛会议解读为分道扬镳，需要某种刻意。

约500年，小狄奥尼修把大型教会法汇编，“系统地”、而非按年代，分为会议法令、教宗教令；这种区别，表示的并非矛盾，而是教会立法的互补形式。特鲁洛会议援引会议权威，却寻求教宗确认。习俗确有差异，例如，“性感”图像，[^p334-29] 在691—692年被禁止（第100条）；以羔羊、而非人形表现基督的圣像，也被禁止（第82条）。西方没有对应关切，不只因为圣像画家较少，也因为圣像在个人虔敬中，不那么居于核心。第31、59条禁止私人小堂、家中举行礼仪，似指城市住宅。西方647／653年沙隆会议第14条，却在完全未提教宗的情况下，谴责一项长期实践：权势者（potentes）在乡间庄园建祈祷所，任命教士，聚集物质资源（facultates），蔑视主教监督、控制。[^p334-30] 626／627年克利希会议第3条，禁止司祭宣誓结社、反对主教，或密谋伏击他，称“即使世俗法律也禁止此事”，实际援引迦克墩第18条；[^p334-31] 但特鲁洛会议援引的迦克墩教规，<a id="pdf-335"></a><!-- PDF page 335; original page 306 -->并不包含这一条，因为主教安全，几乎不被视为问题。缺席有其故事，新出现的内容，也有。673／675年波尔多会议第1条，有尖锐现实感：“教士必须谨慎穿许可的会衣，不得拥有、携带长矛及其他武器，也不得穿平信徒服装。”[^p335-32] 这不是简单重复惯常教士服装规定，而是新表达一种关切，在七至十世纪及以后西方教规中，不断回响。[^p335-33] 东方，有国家组织的军队保护教会人员，没有会议谴责武士教士。

七、八世纪东西教会共享什么、又因何分歧，比较对《旧约》律法的接受，便清楚。特鲁洛第65条，禁止若干现代学者视为异教、民俗起源的实践；但“跳火”、巫术、偶像，让人想起玛拿西王的恶行。[^p335-34] 约西亚王从犹大、耶路撒冷“清除”这些“可憎之事”，此后“遵照摩西的全部律法”治理人民。[^p335-35] 不过，691年这种回声微弱；拜占庭教会法，仍主要由大公会议法令构成。皇宫小堂最珍贵的圣物，虽是摩西杖，却不是提醒皇帝法律属于摩西律法，而象征尘世统治，映照上帝的宇宙统治。[^p335-36] 相比之下，八世纪初爱尔兰《大古法集》，确把古爱尔兰法，视为对《旧约》律法的字面补充；爱尔兰教规在守主日、饮食禁忌、性不洁等问题上，也充满“圣经倾向”。[^p335-37] 部分受爱尔兰影响，八世纪法兰克人、巴伐利亚人，形成自身强烈的圣经倾向。《旧约》律法，成为新以色列须逐字遵循的东西；源自圣经、此前只被教会人士零散规定的什一税，在八世纪中叶几乎同时，获得巴伐利亚、法兰克统治者强化。[^p335-38] 拜占庭皇帝<a id="pdf-336"></a><!-- PDF page 336; original page 307 -->加冕礼中，有祈祷援引《旧约》受膏国王的典范，却无人想到，真的给皇帝傅油。[^p336-39] 八、九世纪西方，教会人士通过直接借用《旧约》，重新创制国王傅油礼，又把祝圣仪式，确立于教会法，并从中推导王室职责；九世纪法兰克人，还据此推导主持祝圣之司祭的权威。[^p336-40]

四世纪前，基督教护教者，在伦理、社会责任问题上，以含糊、不具体的圣经律法诉求，就能取得权威指导。此后，教会人士必须明确陈述规范，以推导更精确、实用、合时的裁决，并规定追诉、解决争端、提出上诉的明确程序。这意味着，第一，细化规范教士职能、行为，以及主教管辖形式、限度的规则；第二，澄清教会与世界协商自身安身之处的条件。前者的关键，是让教士等级体系，具有更强制度结构、连贯性；后者则是以法律界定教会物质资源，以及教会相对于平信徒的权威。同样，对这些问题的法律解释，不可避免发生冲突，而且频繁到成为贯穿本章整个时期的线索，至少西方如此。不过，不应把教会谈判地位看成软弱，也不应认为，其作为“脆弱渡槽，让古典世界的文化蓄水，流向封建欧洲新宇宙”的“可塑性”，是侥幸逆势取得的危险成就。[^p336-41] 教会牢固植根于罗马、后罗马基础；它能动用法律，顽强维持“穷人的产业”，抵御权势者贪婪，证明自己绝不脆弱。[^p336-42]

西方主教，须承担新责任。环境强加更重牧灵负担，实际涉及行政职能，也给主教带来未必不受欢迎的法律事务。七世纪法兰克统治者、八世纪巴伐利亚人，发布世俗的所谓“蛮族”法律，及／或敕令，明显<a id="pdf-337"></a><!-- PDF page 337; original page 308 -->受《狄奥多西法典》影响；主教为此提供建议，常特别涉及教士、依附者。有人认为，教会本身也受罗马法约束。高卢南部居民，使用《法典》不同版本，自称Romani，表示此事；675年，克莱蒙一位主教援引《法典》，为自己拒绝在复活节前的星期六，出席国王法庭辩护。[^p337-43] 到查理曼、虔诚者路易时代，教会人士对王室立法的参与，前所未有地深入。但有些人，也猛烈批评“旧法”残酷，无论罗马或蛮族法律。799年，即将出任奥尔良主教的狄奥杜尔夫，敦促说：只有法官法庭兼有仁慈、正直，才配让基督临在。[^p337-44]

约600年，一份法律文书范式的作者，发现“罗马法所教导”与“地方〔pagus〕习俗”相合，似乎惊喜地感叹。[^p337-45] 正在这种“习惯”背景下，仲裁常成为诉讼替代；家族、朋友（amici）从中斡旋，达成既符合习惯法、又在社会上有效的庭外解决。这是新基督教法律的实际运作：非正式、基于共识，也是一种庇护形式。法律与社会关系纠缠，其运作因而具有表演、象征性质，涉及权力协商。我们也许称为私人领域的范围，以古典罗马人所谓公共领域为代价增长；但这并未让教会法多余，恰恰相反。

主教会议，是中世纪早期教省、王国范围教会的主要立法者。西班牙有大量600年后教规汇编留存，直到711年穆斯林征服，中断这一系列；高卢约680至743年有断档，博尼法斯742年写有80年间隔，略有夸张，但此后，八世纪后期、九世纪的会议，数量、频率不断增长，又有莱茵河以东会议记录补充。盎格鲁—撒克逊王国，则有约60次850年前亨伯河以南会议的<a id="pdf-338"></a><!-- PDF page 338; original page 309 -->提及，但会议决定详细记录，仅少数；诺森布里亚会议，有11次提及，800年以后没有。[^p338-46] 十、十一世纪东西法兰克，如英格兰一样，有若干会议决定记录，更多主教判决记录，却很少现存法令，因而少有证据，说明裁决依据的规范文本。[^p338-47] 尽管如此，总数仍令人印象深刻。我们应以更积极心态，重新审视布伦戴奇所谓中世纪早期教会法太多的主张。当时教会人士，为什么制作如此多教会法汇编？答案是，法律文本用途很多，至少可辅助记忆；他们赋予的权威，除实际意义外，也具有图腾、启发意义。汇编编排、索引有缺陷，编纂者是否仍希望，它们被查阅、应用？八世纪以后，如此多汇编采用系统组织——不是按年代罗列，而是按主题，分为带编号的标题，列于目录——这一事实，说明实用目的，是用途之一。

### 早期教会法汇编

600至800年西方编制的教会法汇编，有三部，无论本身还是影响，都尤其值得关注。[^p338-48] 所谓《古高卢教规集》（Collectio Vetus Gallica），可合理归于六世纪末、七世纪初里昂主教埃特里乌斯，采用“系统”编排。[^p338-49] 11部手稿，来自加洛林帝国内各地，年代在查理曼及九世纪继承者治下。这些数字，至少证明加洛林时期有人使用，也暗示加洛林、墨洛温时代联系紧密，类似礼仪方面<a id="pdf-339"></a><!-- PDF page 339; original page 310 -->可以证明的联系。[^p339-50] 《西班牙教规集》（Hispana），包含直到迦克墩的早期会议法令，续以非洲、高卢、西班牙会议，末附从达马苏到格列高利一世的教宗文本；这是七世纪西班牙编制的编年汇编，后来在法兰克世界大量重新利用。[^p339-51] 八世纪初爱尔兰的“系统”《爱尔兰教规汇编》，在大陆相当广为人知，尤其摘录形式。[^p339-52] 67个编号标题，汇集的文本，不仅取自圣经，也取教父、会议法令、教宗书信；其特色，是加入一些爱尔兰材料：悔罪书、格言、会议教规。开头序言，坦率得有趣，自称“最令人喜悦”，许诺“造就读者”：“若其中某些内容，看来不协调，应选被判断为更有权威的文本。”但没有说明，如何判断权威。作者继续说，考虑到会议文本数量庞大，

> 又见多数笨拙作品，晦涩而几无用处，其余则纷杂不一，破坏多于建设，我便从庞大文献森林中，汇集一卷，作简洁、充分、和谐的阐述。我加了许多，删短许多，许多原样保存，又不顾词句顺序，把许多内容从一种意思释放到另一种；所有努力，只为一事：这些文本中，似乎受到推荐的，不应归于我的判断。我在每条证言前，放上作者名。不过，读者查阅我们因必要而置于开头的总标题时，不应忽略仔细注意编号；留意编号，就可毫不迟延，找到所需主题。[^p339-53]

在爱尔兰背景中，这部汇编究竟如何使用，不清楚。作者设想有读者，但教化不等于裁判。悔罪书横跨礼仪、法律，也许某些“证言”，用于修道反思。至少有一条，可能出自对修女行为的争执。依第45题第14条：“罗马人（Romani）说：……穿戴童贞女衣服的童贞女，应被<a id="pdf-340"></a><!-- PDF page 340; original page 311 -->隔绝于男子视线之外，如此生活直到死亡。”这种“劝告闭居”，十一世纪前爱尔兰，没有对应；它与爱尔兰修女“同教会男子并肩工作”，以及妇女前往朝圣的证据，也不协调。[^p340-54] 其他爱尔兰教规，却明显代表当地教会法，例如修道院统治者，具有领袖（princeps）地位。[^p340-55] 另一些，想必用于解决争端。第32题第17条，援引《旧约》妇女押撒、底拿，认可妇女对财产的权利，使其可把财产赠给教会。第46题讨论婚姻，含30条独立教规，其实用性，至少转至大陆背景后，可由独立存在的《三十章汇编》（Collectio XXX capitulorum）说明；它现存不少于22部手稿，年代在九至十二世纪。[^p340-56]

### 加洛林时期

制作法律文本是一回事，了解、运用，又是另一回事。一项对中世纪早期教会法手稿的典范研究显示，八世纪以前，各地现存文本都少；此后证据集中于“法兰克诸王国”。[^p340-57] 某些汇编，似只流通单一区域，另一些影响跨区域；有时，教会会议推动传播，更常见的制作、传播原因，似在一位主教的努力。加洛林人提供的，是联系、紧迫感、政治动力，使教会法文本的广泛传播，取得突破。

774年3月，查理曼留下部下，继续围攻伦巴德首都，意外南行罗马。教宗哈德良赠他一部加有补充的狄奥尼修教规集，卷首有一首似仓促写就的离合献诗，赞颂国王为教会保护者，呼吁他“永远热爱神圣法律”。[^p340-58] 几年后，查理曼才认真处理礼物。《狄奥尼修—哈德良教规集》，从未获“官方”地位；九世纪，<a id="pdf-341"></a><!-- PDF page 341; original page 312 -->其他汇编手稿，仍继续抄写。[^p341-59] 不过，789年亚琛会议颁布的一组法令《总训诫》（Admonitio generalis），很可能由阿尔昆编制；他大量取用狄奥尼修汇编，沿袭从古代晚期会议提取教会法的长期实践。《训诫》前59章，选取“我们看来更必要的教规条款”，首先须由主教实践、宣讲，再借王室巡察使（missi）协助执行。“上帝既给予本国如此多荣誉〔honores〕，愿他永远以保护，保存我们及王国”；为此，查理曼将“像《旧约》约西亚王一样努力，唤回上帝交给他的王国，敬拜真上帝”。这些“更必要条款”，先从秩序规则开始，强调主教团结：不得接纳被其他主教绝罚者共融（第1条，参第56条）；省会主教对下属、主教对乡村助手（corepiscopi）的权威（第8、9条）；坚持教士、修道生活的独特性（第26、27条，参第52条）；确认主教权威，不许修士、教士密谋反对牧者（第29条）。接着，宣告教会人士与平信徒在法律上分立：教士须由主教或教会人士审判，不能由平信徒审（第28、38条）；但有限定：只有声誉经证实的平信徒，能指控教士；只有声誉经证实者，能指控主教或高贵出身者（第30、35条）；低下地位者，完全不能指控（第45条）。末尾杂项禁令，包括不得侵吞“属于穷人的奉献”（第47条）、不得鸡奸（第49条），以及针对无知、不服从司祭的规定（第55、58条）。

其余被称“有用”的条款（第60—82条），是一串取自《旧约》法书，以及《新约》回应的训令；这种圣经印记，将成为查理曼教会立法标志。[^p341-60] 包括维持和平、和谐（第62条）；公正裁判、避免贿赂（第63条）；不得伪誓（第64条）、行巫术（第65条）、贪婪（第66条）；“在祖国内”（infra patriam），除依法外，不得杀人（第67条）；保持教堂清洁、适当校正书籍，以正确祈祷（第71、72条）。又具体规定各种正确行为、信仰（第78—82条），其中<a id="pdf-342"></a><!-- PDF page 342; original page 313 -->第81条，是守主日规则，把军队运输、给养工作（ostilia carra vel victualia），以及安葬死者，列为例外。最后一节，放弃分条形式，转成引述圣保罗的小讲道，把教会法包入基督教伦理；作者却始终不忘实际需要：教会须区分教士、平信徒，维持等级内部秩序，尤其主教、省会主教权威；国家须保障军事需要，主张对法律负总体责任，尤其禁止仇杀的第67条。《训诫》纲领，在法兰克福会议（794年）进一步声明中扩充，为后来加洛林教会法定向。[^p342-61] 不同主教、主教与教士、教士与平信徒，以及高低地位平信徒之间的竞争利益，被明确承认，却由清楚界定的等级体系容纳、控制。四、五世纪大型会议法令，以及中世纪早期教宗教令书信——后者焦点常更窄，却同样普遍适用——规定结构、程序，用以审判、解决权威界线模糊、或受争议时产生的纠纷。

正是在边界、断层线上的地方案件里，其他教会法证据，以较不直接、间歇却强烈的光，照亮教会秩序的日常斗争，以及人们对怎样基督教式生活的竞争解释。802年，查理曼因“一份传入我们耳中的报告”，深忧“修道院里的污秽……尤其一位行鸡奸的修士〔其活动〕，威胁使所有基督徒毁灭”。[^p342-62] 几条之后，出现其敕令唯一一次直接提及判例法：主教负责审判乱伦者，“但若有人拒绝接受主教关于其补赎的判决，就须带到我们面前，记取弗里科加于上帝修女的乱伦事件所立的惩戒榜样”。[^p342-63] 数年后，查理曼把依法从一位犯“乱伦及其他恶行”者没收的土地，赠予普吕姆修道院。[^p342-64] 如何对待高贵、有产的寡妇，也提出困难问题。《训诫》第59条规定，“任何主教，不得擅自为寡妇披面纱”。[^p342-65] 818年会议要求，寡妇在决定<a id="pdf-343"></a><!-- PDF page 343; original page 314 -->披面纱以前，应征求主教，以及“亲族、朋友”（parentes et amici）的意见。[^p343-66] 教会人士几乎人人出身贵族，理解亲族的担忧：寡妇向教会赠地，可能使家族土地流失，而这些妇女，在教会中仍保有权益，作为“女守护者、女管理者”（excubatrices et administratices）；主教为通常男性的职能，找出女性形式。这被称为“有害的自由”。巴黎会议（829年）规定，不可允许寡妇继续居家，有机会“各处往来，危及自己的灵魂”，而应进入女修道院，闭居于主教监督下。贵族妇女，往往有自己的主意；美因茨会议（888年），便让披面纱寡妇，可选择留在家中。无论居家、入院，有产寡妇本身，也是炙手可热的财产，容易遭求婚者劫持。主教反复抨击这些劫掠者（raptores），但只要女方亲族同意、男子悔罪，又常愿宣告，寡妇后来与劫持者的婚姻合法。

兰斯总主教欣克马尔（845—882年），是教会法专家，写了一部反对这类劫持者的论著，也对其他涉及妇女、性的棘手案件，提出法律意见。[^p343-67] 王后特奥特贝尔加被指控鸡奸式乱伦，引出特别冗长、细致的讨论，结论是女士无罪，因此其夫、国王洛泰尔二世，不能离婚、再娶。[^p343-68] 斯德望伯爵，则急于解除因政治而不便的婚约，希望乱伦疑虑，能提供法律根据。欣克马尔指出，王国已被丑闻震动，审慎得出结论：斯德望与未婚妻，应分开，但他已送出的婚姻财产，应留在年轻女子父亲手中。这种法律应用，无疑有些操纵，与其归于犬儒，不如说出于真正关心社会和平。[^p343-69] 婚姻，是教会人士具有强烈专业兴趣的主题；加洛林时期，教会介入明显增加。但有些案件，风险高得教会人士难以处理。贵妇诺尔特希尔德<a id="pdf-344"></a><!-- PDF page 344; original page 315 -->822年阿蒂尼会议向虔诚者路易皇帝抱怨，丈夫长期给予自己inhonesta，即不光彩的待遇；皇帝把案子交主教，后者立即称对这类事情缺乏专长，转交“平信徒、已婚男子的裁判”。欣克马尔写道，这些人很高兴，自己对妻子的权利，如此获承认。[^p344-70] 834年，虔诚者路易之子洛泰尔叛乱的最后阶段，一位贵族修女格尔贝尔加，是路易前内廷总管的妹妹，在沙隆被洛泰尔部下抓走，控以巫术，由洛泰尔顾问的妻子们组成法庭审判，装入酒桶，投入索恩河。[^p344-71] 没有教会人士，留下为此主张权利的记录：遇到大人物、高层政治，他们审慎挑选法律战场。值得注意的是，查理曼教会立法禁止离婚，八、九世纪法兰克文书范式集，却有多部抄录离婚程序范式。这是否意味着，平信徒实践，与教士公证员勾连，继续违背教会法？[^p344-72]

在一个社会上至关重要的领域，主教，乃至教宗本人，应用法律惩罚的机会，出现在“游荡”妻子恩格尔特鲁德案中。她是马特弗里德之女，离开丈夫，投奔其一位附庸；尼古拉一世绝罚了她。[^p344-73] 另一方面，尼古拉保护特奥特贝尔加王后，认定她受残暴丈夫羞辱、冤枉，因而获得威望。哈德良二世，则赦免曾站在丈夫一方、后来悔改的教会人士，科隆总主教贡特尔。现存唯一一部九世纪末抄本，似为哈德良对此事的会议讲话；其后附有最早的教宗所用伪教令汇编，以教宗管辖权为主题。[^p344-74] 这些来自所谓《伪伊西多尔》汇编。[^p344-75]

<!-- PDF page 345; original page 316 -->

《伪伊西多尔》，无疑是本期最大汇编，也是引出最多现代学者评论的一部。过去一代，理解大有进展；如今承认，它不是单一汇编，而是若干不同汇编。作者受多种关切推动，写作历经一段时间（830年代中期至约850年），却可证明，在同一处、藏书丰富的地点工作；背景，是约830至847年反复撼动加洛林帝国的王朝内部冲突，以及精英内部分裂、谋利邻人从外利用的伴随苦难。[^p345-76] 诸作者共同目的之一，是给主教法律保护：抵御高层政治攻击，最坏情形是罢黜；地方经济攻击，即平信徒索地者，或利用教座空缺的下属教士，窃取教产；制度颠覆，如司祭、修道团体不服从；制度压迫，如省会主教的新要求；或这些威胁的组合。

据此目标，可以解释作者工作方法的四个特点。第一，热衷确立主教在教会内部的法律权威。汇编开头，放置召开教会会议的礼仪程序（ordo）：

> 主教座位排成冠形〔即圆圈〕后，省会主教选出的司祭，便坐在主教背后，好同他就任何问题，给出判断、解决案件……随后，平信徒进入，是经相应挑选、被认为配参加的人……〔然后，主教共同祈祷：〕“我们在此，主啊，圣灵，我们在此，虽然被罪牵累，却以你之名，为特定目的聚集。来到我们中间！……教导我们，必须做什么！……成为我们裁决的护卫、启示者、实行者。不要让我们破坏正义……”[^p345-77]

礼仪强化法律：会议权威，来自圣灵。

第二项重点，是确定教会案件正确的刑事程序。平信徒不得指控教士，下级不得指控教会上级；定主教罪，须有72位主教<a id="pdf-346"></a><!-- PDF page 346; original page 317 -->作证。[^p346-78] 另一方面，任何涉及教会权利的案件，主教都对平信徒有管辖权。[^p346-79]

第三特点，是汇编某些部分，反复强调教宗权威。例如，任何受控主教，有权向教宗上诉；以及一项原则：“神圣罗马教会，拥有所有教会的首位，主教最高事务，涉及主教的裁判、争端，以及教会更重要问题，必须总向它，如同向首脑呈报。”[^p346-80] 前述第一点，即会议礼仪暗示圣灵为会议权威来源，又受到一项反复主张的限定：教会会议合法性，来自教宗召集、或批准。[^p346-81]

第四点，与前一点不可分，是强调教宗法律权威的文本，均为伪造、篡改：这些教令书信，托名一系列早期教宗，包括某些殉道教宗。既无真实文本，支持相关主张，是否便是急迫需要不受法律约束？这些博学造作者，极为务实，努力确实旨在应对当代紧急问题。850年代初，罗马已采用一两篇伪文；兰斯的欣克马尔本人，也用其中一些，尽管他激烈谴责别人伪造。[^p346-82] 不过，也许最早使用者，是苏瓦松、拉昂主教，欣克马尔的两位下属；他们各有与省会主教争执的理由。

如何解释九世纪中期这些虔诚欺骗者的心态？虽非最早伪造教会法者，他们却以惊人规模伪造。[^p346-83] 伪造，是教会法专家思想工具箱的一部分，使其能在古老引文链中，插入独创环节。一旦如此改进，这些看似正确、与最佳教规材料相伴流传的法律文本，本身承载的力量、确信，<a id="pdf-347"></a><!-- PDF page 347; original page 318 -->就使其特别吸引某些教会精英；对这些人，法律作为传统知识，构成一套准则。智慧、原则的较量，使用这些闪耀修辞武器。但《伪伊西多尔》在九世纪实际生活中，意义如何？它们“也许是教宗权有史以来，收到最受欢迎的礼物”？[^p347-84] 历史学家在此，尤其须警惕后见之明，因为太多解释，沐浴在十一世纪不合时代的光线下。的确，造作者工坊关闭约200年后，教宗君主制段落，在罗马受到广泛注意；然而，九世纪教廷的态度，从谨慎肯定，到漠不关心，各不相同。

### 兰斯的欣克马尔（806—882年；845—882年任兰斯总主教）

与教会同僚、下属进行法律交锋，没有人比兰斯总主教欣克马尔更娴熟。他大量书写教会法，既作描述，也立规范，又深度参与九世纪主要教会法潮流，值得多花些篇幅。对他而言，省会主教权利，是在原则、实践上，牢控下属的手段。[^p347-85] 他先因苏瓦松主教罗塔德管理教区不善，后又因不服从省会主教本人，将其绝罚；罗塔德手持《伪伊西多尔》武器，向尼古拉一世上诉，因而令他愤怒。[^p347-86] 秃头查理置身事外，教宗遂恢复罗塔德职务；欣克马尔愤恨抱怨，此举并非循法（non regulariter），而是凭权力（sed potentialiter）。[^p347-87] 第二宗主教不服从案，涉及总主教自己的同名侄子、拉昂主教。这次，老欣克马尔得以安排法律胜利，因为小欣克马尔，870年被疑与查理叛乱的儿子勾结，命运因此<a id="pdf-348"></a><!-- PDF page 348; original page 319 -->被国王凭权力（potentialiter）注定。871年8—9月，杜齐会议，由欣克马尔总主教主持，八位总主教、14位主教参与裁判，又以合法程序（regulariter），解决此事。[^p348-88]

处理不听话的司祭，较容易，因为高层政治没那么突出；但即使司祭过错，法律上也可能棘手。欣克马尔广泛著作，记录八案，其中一位受控犯罪司祭，转向民事裁判（iudicium civile），尽管这类案件，理应“不由地方法庭〔mallus〕、或民事法官，而由主教、教会会议裁判”。[^p348-89] 另一位，被总主教及同僚定罪，向教宗上诉。[^p348-90] 欣克马尔写道，这种上诉，对阿尔卑斯山以北主教，后果严重：即使判决合法，也可能找不到使节赴罗马，或找不到合适证人，前去反驳司祭的虚假辩护。[^p348-91] 凡细节已知，九世纪被控犯罪司祭的罪行，总涉及性。一代后，特里布尔会议（895年）主教，痛苦抱怨：这类案件中，主教收到充满司祭谎言的教宗书信，教宗轭担，vix ferendum，即“几难忍受”！[^p348-92] 因向罗马上诉产生的紧张，此时成为教士生活的永久特征。与其说预示格列高利改革的大问题，不如说揭示早在十一世纪之前，就存在、此前却潜伏的教会生活深层特征；事实上，加洛林时期起，罗马与其他西方教会往来增多，这些就成为永久现象。此后，各级教士，都知道在教廷有朋友，可能带来好处。另一方面，新制度尚未建立，也未在任何教士思想中被设想。上诉数量仍少，教会法可按熟悉方式工作；九世纪后期、十世纪，罗马与各教省之间，某种类似旧有自我调节的平衡，仍在维持。

对犯罪司祭案件的法律程序，欣克马尔深信，自己可依靠无可指摘的教宗实践权威，即宣誓、助誓人。他的《论犯罪司祭》（De presbiteris criminosis）开篇，<a id="pdf-349"></a><!-- PDF page 349; original page 320 -->以教宗利奥三世为典范；他在790年代末，被控包括性罪行在内的犯罪，据“查理皇帝敕令集第一卷第34条”，在12位主教助誓人支持下，以洗冤宣誓，为自己澄清。[^p349-93] 敕令续说，“依此榜样”，受疑司祭，应以自身宣誓，以及“三位、五位、七位品行良好、来自邻近的司祭”的誓言，证明清白。欣克马尔这里引用利未人本笃的汇编，如今已知，后者大量伪造。这条“敕令”就是伪造；现代编者还往伤口撒盐，指出欣克马尔“照例”弄错编号，实应第35条。[^p349-94] 他是否知道文本为伪造？紧随其后，涌出大量真实教会法引文，包括《狄奥多西法典》一条，是纯粹炫耀？他最后说，法兰克教会遵循这些程序规则，已70多年，是否明知而虚报习惯法律实践？进一步援引权威，坚持“任何人，都不得不知法律”，[^p349-95] 是否虚伪？

欣克马尔的教会法知识，也许比严厉批评他的法律史家，更有限、模糊。他随时尽可能，采用进入自己视野的文本；但其对“习惯传统”（mos consuetudinarius）实际为何的理解，也许比现代批评者承认的，更符合自身经验。宣誓、助誓人，只是阿尔卑斯山这一侧天主教程序的一方面，带有真正借用、适应地方性法兰克世俗实践的印记。特别疑难案件，不用七位，而用六位助誓人，让第七人接受神判，检验誓言真假。[^p349-96] 鉴于利奥三世案件程序，很容易相信，800年也有助誓人，查理曼又把这同等级更低教士的习惯程序结合。欣克马尔常凭记忆引用，有时细节略错。即使本人有时伪造，他也共享同时代人的预设：有时必须重建规范合法行动（regulariter）的规则，因而这样做是正当的。[^p349-97]

<!-- PDF page 350; original page 321 -->

加洛林时期，司祭、执事在受职时，向主教作三重承诺（professiones、proposita）：定居、服从、守法，类似修士发愿时，向院长的三重承诺。实践未必依赖王命，虽然查理曼显然想统一（《总训诫》第26条）。利未人本笃，为此提供一条伪敕令。[^p350-98] 但这种承诺起源，深植“习惯传统”。现实中，维系教会等级的纽带，不只是、或主要不是职务、义务的法律概念，而是庇护者或领主与依附者之间，保护／恩惠、忠诚的人身联系。九世纪初巴伐利亚，出现司祭向主教作本地方言效忠誓，就在此背景中。法律史家注意到，一项变化：从承诺实施特定法律行动，转向更根本的“忠诚意向”。[^p350-99] 也许，当时人心中，这种“根本区别”不那么分明；正如向查理曼宣誓fidelitas者，视承担义务，既非常具体，又极其广泛，既法律，也超法律。加洛林国家，对违背忠诚处60索里都斯罚金，实际执行必定不同，仅因几乎所有人都付不起，但象征分量巨大。类似地，司祭被约束忠于主教，知道自己在经济、政治上，如弱者（pauper）之于强者（potens），依附于他。[^p350-100] 他确实受约束。十世纪，这种义务，以拉丁语，转化为《罗马—日耳曼主教礼典》中的礼仪形式，并广为传播。[^p350-101] 但至少查理曼时代起，它已与一种观念相联：司祭的教堂，是主教授予的教产。[^p350-102]

教堂权利竞争时，欣克马尔决心应用法律。一个强大家族，要求讷伊庄园，他替兰斯提出反要求，一部分通过政治行动，一部分回顾庄园过去百年历史，一部分汇集世俗、教会法律42条的材料。[^p350-103] 更广泛的问题，则是兰斯教会，对下属主教区、或其他教省的<a id="pdf-351"></a><!-- PDF page 351; original page 322 -->若干教堂，拥有创办人权利。引人注目的是，苏瓦松、特鲁瓦、拉昂这些政治炽热的教座，争端最烈。书信记录的实际纠纷，使秃头查理被众多申诉（clamores）包围，因而寻求现有最佳法律意见。[^p351-104] 欣克马尔回答，教会法清楚区分：教区主教正常的授职、管理权（potestas、dispositio），与拥有dominium，即领主权者的权利。平信徒领主，“男子、女子”皆有，对自建教堂及其中圣髑，拥有领主权（senioratus），尤其赠出教堂、推荐教士接受授职的权利；这也暗示，女性同样可拥有教堂。[^p351-105] 司祭虽在自身教堂有权利，包括什一税、份地收入，却向其领主（seniores），负有精神服务（obsequia spiritalia、spiritalia ministeria）。[^p351-106] 至此，都很清楚。问题是，实际理解中，potestas很容易滑成senioratus；欣克马尔自身术语，也曾如此滑动。[^p351-107] 只有各方都被羞耻恐惧驱动，才能运转。[^p351-108] 而有欣克马尔这样的主教，也许他们常确实如此。不过，他是以教会法学者，而非单纯邦葛罗斯式乐观者、或根深蒂固保守派身份，找到良好论据，尤其古老法兰克教规——奥朗日441年、奥尔良511年——以及很新的沃尔姆斯829年教规，论证领主权在教会经济中的位置合法。他“理性、长远而言有建设性”地拒绝让主教权依赖所有权，为十一世纪动荡后，以保护权（ius patronatus）形式出现的法律妥协，提供基础。[^p351-109]

### 在边疆

法律的运用，纵向深入教会日常存在，即乡村生活、物质文化。另一些九世纪中叶的运用，则横向延伸，通往基督教世界的邻人、潜在新成员。

<a id="pdf-352"></a>
<!-- PDF page 352; original page 323 -->

边疆上，摩拉维亚人、保加尔人，都受到东西方争取。其统治者，分别向君士坦丁堡皇帝，以及巴伐利亚、弗兰肯一带的东法兰克国王，申请传教士。当传教区域相遇、竞争，传教士面对陌生习俗，一边君士坦丁堡牧首，一边教宗，就被请教：改宗基督教，究竟意味着什么。牧首佛提乌斯（858—867、877—886年），[^p352-110] 以长篇教义书信回答保加尔人。尼古拉一世，则以106条教规形式，回答法律、习俗建议，其中八条关于大斋期，例如是否可以狩猎，十条关于婚姻，例如婚前男子可否向未婚妻，展示将作为聘礼的牛、马。尼古拉的《答复》，确实逐项回答保加尔问卷，说明保加尔人必定相当了解教宗法律专长，以及使法律灵活延展的能力。这的确是法律应用于牧民社会的突出例子；那里男女都穿裤子（第59条），教宗被问及，并未谴责。教宗抓住机会，强调所谓“希腊”习俗，与罗马教会实践的差异；867年致法兰克主教书，谴责希腊人对“拉丁人”的指控，又有相应回声。[^p352-111] 不过，九世纪后期，东西关系深变。佛提乌斯893年或不久后去世，皇帝利奥六世寻求、获得和解。利奥先后四婚引起的教会法困难，在西方回响甚微。九、十世纪之交，教宗在自家后院被敌包围，只能低调：与东方缓和，依传统与主教共识，与任何掌握意大利世俗权力者合作。拜占庭方面，佛提乌斯曾挑战教宗权，参与君士坦丁堡较肮脏的政治，向主教、教士索取效忠誓，以以色列大祭司自况，“也许梦想一种司祭王权”；利奥六世（886—912年）则以一系列新律，重申皇权，按查士丁尼风格，“登上讲坛”，“裁定教会法问题”。[^p352-112] 东西方似乎都恢复常态。

### 旧法律的新世界

悔罪，是引起布伦戴奇贬评中世纪早期教会法“向内看”性质的领域。[^p353-113] 的确，悔罪必然涉及内省，但近来研究，已在悔罪实践这个具体问题上，重新评估八、九世纪与十二世纪根本对立的刻板看法。[^p353-114] 事实表明，从加洛林时期到格列高利改革，悔罪是教会法应用的核心。悔罪规定，与礼仪、[^p353-115] 圣徒传一起，让历史学家能摆脱仅有规范性证据的困境。普吕姆的雷吉诺（915年卒），约906年应特里尔总主教要求，编成教会法汇编，也寄一份给美因茨总主教。[^p353-116] 第一部分，先录欣克马尔主教章程，续以详述主教巡视、监督司祭的教规。全书近1000条，大体按主题分两部分，大量内容用于悔罪规则。[^p353-117] 相关敕令摘录，取自安塞吉斯汇编。[^p353-118] 雷吉诺的世界，虽不再产生新敕令，却仍能使用旧敕令。

沃尔姆斯的布尔夏德（1025年卒），同雷吉诺一样，并非超前出现的格列高利改革者，而是回应教区关切的法律传统主义者。[^p353-119] 约1015年《教令集》，含1700多条教规，分20卷，可真正称为系统编排，虽然各卷篇幅不均。与雷吉诺一样，布尔夏德汇编，大体围绕悔罪组织，例如第六卷各种杀人行为及相应补赎，第十卷<a id="pdf-354"></a><!-- PDF page 354; original page 325 -->各种巫术及适当补赎。[^p354-120] 但雷吉诺作为学者、流亡院长，仿佛从高处，平静观察教会习俗多样；布尔夏德贴近地面的视角，却把“混乱、多样、无序的法律和补赎”，[^p354-121] 视为有待解决的问题。他是主教，痛切了解地方失序；完成《教令集》数年后，为自己的主教家属团（familia，即沃尔姆斯及周边的家中人员、依附者），写下条例（lex），便清楚说明：“其中任何护卫官、代理人、官员、或其他人，都不得对他们〔家属团〕，强加新东西；相反，要让所有人知道，只有同一法律，为富人、穷人共同适用。”[^p354-122] 《教令集》旨在减轻司祭困难。雷吉诺给盘问者40个问题；布尔夏德提供精细区分的190个，嵌入悔罪礼仪背景。书既教导，也实用。发现教规责罚过重，他就“依仁慈”（secundum misericordiam），按经济能力，提供折换补赎。[^p354-123] 发现差异、矛盾，则通过改进文本，“调和”它们。[^p354-124] 这也符合加洛林传统。他取用《伪伊西多尔》，但不多；其关切是牧灵，因而局限教区。

许多人有类似关切，因此1100年前，《教令集》已在特里尔、艾希施泰特、科隆、康斯坦茨、帕尔马、米兰、诺南托拉、卢卡、贝桑松、兰斯、图尔、昂热图书馆存在。[^p354-125] 悔罪程序，见于各种书籍。[^p354-126] 据记载，具有神恩感召力的德意志主教，通过神判，祈求、应用超自然力量，作出裁决。[^p354-127] 十一世纪后半叶，新教会法汇编，大量借用《伪伊西多尔》的教宗教令；此时，它们已因古老而获合法性。教宗格列高利七世（1073—1085年）著名《教宗训令》，与其说宣言，不如说备忘录，同样<a id="pdf-355"></a><!-- PDF page 355; original page 326 -->借鉴前人。[^p355-128] 但法律虽古老至九世纪，如今应用的背景，却是新的。1054年分裂，粗暴打破可敬的现状，标志教宗对东方的新强硬。[^p355-129] 学术异端、民间异端，也在新战线，引发教宗管辖。[^p355-130] 格列高利七世治下，法律范围，不只按《伪伊西多尔》涵盖教士、修士阶层，也及于高低所有平信徒。新网络创建，新代理人、机构被调动；教会法、民事法，都濒临专业化。最后，同样重要的是，教宗权由法律推动的声音，传向新听众，许诺新的正义运用。[^p355-131] 精神服务日益表现为法律服务，其提供，受到更中央化的指导；正如“检查一切世俗、教会治理，将成为教宗权职分内的领域”。[^p355-132] 布尔夏德的“主教欧洲”，仍有漫长未来；但其上，已有越来越集中、主动的教会政府，重新把“罗马”“教会法”，联结于西方基督徒意识中。
