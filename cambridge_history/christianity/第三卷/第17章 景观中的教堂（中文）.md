# 第17章 景观中的教堂[^p392-1]

多米尼克·约尼亚—普拉（Dominique Iogna-Prat）

<a id="pdf-392"></a><!-- PDF page 392; original page 363 -->

克吕尼修士鲁道夫·格拉伯（1047年卒），作为史家的名声，来自近乎执迷地关注，基督诞生、受难一千周年之际，各种非凡事件。他记录衰老世界解体的种种征兆：彗星、饥荒、天降鲜血、基督徒背教皈依犹太教，诺曼人、匈牙利人、撒拉逊人入侵，耶路撒冷圣墓教堂被毁，异端一波波出现。反过来，他也发现，上帝与忠实子民订新约的征兆，世界真正更新的痕迹。值得注意，重生证据，都与此世紧密相联：寻获圣髑、和平会议、无暴力区的建立，建设“教堂的白色外衣”，朝圣地之旅，匈牙利国王斯德望改宗，推动基督教世界东扩，又打开陆路耶路撒冷通道。千年之后第三年临近，世界各地建造、重建教堂，象征甩掉“老年的破衣”；格拉伯看来，预示广泛修道改革计划。总体观察后，他确实举出修道建筑、建造者，尤其克吕尼。为突出现行修道改革，使世界神圣化的活动，又加各地发现圣髑的叙述，仿佛修道时代“教堂的白色外衣”，正给古代殉道者，提供一座圣髑匣，使其终于能“向信徒目光显露自身”。[^p392-2]

中世纪异端史家，早已注意，格拉伯赞美的“教堂白色外衣”，并非毫无<a id="pdf-393"></a><!-- PDF page 393; original page 364 -->争议地缝制而成；不和谐声音，质疑是否根本需要礼拜场所。《孔克圣福瓦奇迹书》，讲巴扎地区一位农民，谴责向某物祈祷的“愚蠢”；在他眼中，那不过“集市摊棚”（attegia forensis）。[^p393-3] 更北，1025年阿拉斯会议，活跃于卡佩王国、萨利安帝国交界、颇有影响的康布雷主教热拉尔，纠正某些异端；除其他偏离信仰外，他们认为，“上帝圣殿……并不比卧室更高贵”。[^p393-4] 效法1022年奥尔良被判火刑的教士，这些不具名异端，否认“容器能够界定内容”。[^p393-5] 激进立场，直接延续拉丁教父传统，后者极谨慎赞扬纪念建筑；它也迫使对手，对此展开前所未有的教义探究。十二世纪，在与圣维克托的于格（1142年卒）、彼得·伦巴德（约1100—1160年）、托马斯·阿奎那（1225—1274年）相关的大型圣事综合背景下，出现密集神学反思以前，十一世纪前半叶正统论战者，已开始重申建筑传统古老，教会以之为摩西会幕、耶路撒冷圣殿的预表对应。最重要，他们努力界定，专供礼拜的建筑，与其他人手建筑，究竟有何不同。正是在此背景下，首次出现一种可称教会性“附加因素”的教义表述，界定教堂为“卓越场所”，上帝在那里“更为临在”，“恩典更丰盛倾流”。[^p393-6]

### 中世纪西方的礼拜场所：圣洁性与神圣性之间

如何走到这一步？原指信徒集会的ecclesia，为何在拉丁语世界，也指礼拜场所？明明还有许多称呼，厅堂（aula）、巴西利卡、上帝之家（domus Dei）、主的居所（dominicum）、建筑（fabrica）、场所（locus）、圣殿（templum）等，为何偏选含混一词？教堂建筑，何时、为何<a id="pdf-394"></a><!-- PDF page 394; original page 365 -->成为教会制度，在社会上可见不可或缺的要素？教堂逐步、普遍进入社会景观，实际代表基督教长期持有价值的巨大逆转。本章首先，概述一种教会论的缓慢演变；它借圣事教义，使中世纪西方特有的容器、内容混合，获得辩护，容器是作为纪念建筑的教堂，内容是作为共同体的教会。其次，评估神圣者在石建筑中物质化，带来的社会效果。

#### 人的圣洁性

圣经传统，对把神圣者定位于某处，极为矛盾。一方面，雅威毫不迟疑宣告，神显地点，可以“圣洁”（《出埃及记》3:4—5；《约书亚记》5:15），甚至“可畏”（《创世记》28:10—20），因为是“天门”。另一方面，也不乏与耶路撒冷圣殿建造者所罗门一致的断言：人手建造的房屋，绝不能容纳上帝（《武加大译本》《列王纪》第三卷8:27）。这又引奥古斯丁认为，上帝“无处所”、或“超出处所”（illocalis）。[^p394-7] 最后，不要忘记基督本人宣告，他与父的国，不属“这个世界”。

此外，教会从古代晚期罗马世界，继承某些法律范畴；其意义，对理解人与土地关系，尤其把握“圣洁”“神圣”“宗教性”等修饰语，至关重要。无论它们长期如何影响民事、教会法表述，仍须强调：早期基督教，明显想与一切古代神圣性决裂，无论异教神庙，还是多种异教泛神形式。基督门徒，属于一种“去地域化”宗教，与此世联系极少。若最初几个世纪，某些地点确实开始获重视，既非主动追求，也经过中介。变化非主动，是因古代晚期世俗当局，承认教堂某种特殊性质。君士坦丁起，许多后来纳入438年《狄奥多西法典》的法律，试图决定，<a id="pdf-395"></a><!-- PDF page 395; original page 366 -->逃入教堂避难的奴隶、逃亡者的命运。为说明，为何基督徒集会处，可享过去神庙的特殊地位，立法称教堂为“至高上帝的圣殿”，宣告祭坛“神圣不可侵犯”，把侵犯避难权，作为“亵圣”惩罚。[^p395-8] 因而，基督教场所的神圣性，首先在民事法中获承认。

至于中介，就是某些非凡人物，即“极特殊的死者”——圣徒；他们遗骸，在此世受敬礼，正因代表通往上方来世的接触点。经过非凡词义演变，基督教拉丁语locus或loculus，除原义外，也指圣髑，甚至存放圣髑的圣龛；为圣徒建的场所，此后被想成巨大的石制圣髑匣。缓慢发展，到八世纪达顶点，确立规则：没有圣髑，就不能有礼拜场所。由此，形成一种特有“基督教”空间，由广大网络中的各极、重心划定；圣髑从源头圣地、罗马，经亚琛、图尔、欧塞尔等众多中转圣地，分布到广泛散落的地方。这一现象，对基督教地域观念首次发展，极重要，也标志新文类诞生，即圣髑迁奉记；最早例子，是九世纪初艾因哈德《圣彼得与圣马尔凯利努斯迁奉记》。新空间，按互补两层组织，使教会成为地方、普世的衔接点。微观层次，是圣徒小乡土（patria）：圣髑抵达（adventus），被迎入安息处中心（occursus），圣徒遂把自己的物质环境，与周边区别。宏观层次，是基督教世界，按“使徒分区”（divisio apostolorum）逻辑，组织为多重圣徒、使徒乡土；该逻辑，先用于伪经《使徒行传》，又由塞维利亚的伊西多尔（560—636年）《诸父生卒记》，给予规范形式。[^p395-9] 此前，“基督教世界”指基督门徒共同体，如今获得特定地理意义，最早<a id="pdf-396"></a><!-- PDF page 396; original page 367 -->见于八世纪最末，安吉尔贝尔特（814年卒）的著作。[^p396-10]

#### 场所的神圣性

圣徒遗骸，不只让礼拜场所圣洁，也让其神圣。圣徒传、奇迹记中，corpus，即身体一词，进入sacer，即神圣的语义领域，并不罕见。圣徒身体、所占空间之所以“神圣”，因为圣髑参与教堂及周边的祝圣仪式。这一礼仪发展，历史漫长、复杂。最初几个世纪，信徒集会纪念基督牺牲的场所，没有特别祝圣；是首次圣餐礼，“祝圣”建筑，并把圣髑安置祭坛内，如米兰革尔瓦修斯、普罗塔修斯圣髑，安布罗斯将其等同《启示录》所述殉道者灵魂（6:9）。[^p396-11] 六世纪罗马，出现新的双重仪式：驱魔，净化建筑中的魔鬼存在；安奉圣髑。高卢—法兰克礼仪，最初用两个分立程序：一为祝圣祭坛、教堂，一为庄严安奉圣髑。渐渐融合，最早已知例子，是594至650年间《圣阿芒礼序》。在这次或多或少成功的协调基础上，奉献礼又增祝福礼仪器物、装饰、礼服，以及点亮建筑。八、九世纪，是重要转折。加洛林君主追求礼仪统一，罗马、高卢礼接近、混合，《罗马礼序》第42号，实现结合。[^p396-12] 随后，合成仪式，进一步丰富；840年代《祝圣教堂礼序》，十世纪中叶收入《罗马—日耳曼主教礼典》（第40号），十一世纪传至罗马，十三世纪又稍有增补。[^p396-13] 漫长发展结束，原先<a id="pdf-397"></a><!-- PDF page 397; original page 368 -->只由圣餐牺牲组成的奉献仪式，已成拉丁礼最辉煌仪式之一。

840年代，是统一教堂祝圣礼综合、在全帝国实施的时期，又逐渐传遍拉丁基督教世界；这一十年，也出现仪式注释《十二支蜡烛意味着什么》（Quid significent duodecim candelae）。[^p397-14] 它让我们联结礼仪、教会论，理解背后社会学问题；就在这一论述背景，ecclesia确立为表示教堂建筑的专门术语。拉丁基督教选择此词，后果重大；东方仍以不同词，区别集会场所naos，与信徒共同体ecclesia。匿名作者已暗示：Ecclesia，即教会共同体，与ecclesia，即教堂建筑，维持一种转喻关系，容器指内容，内容亦指容器。后来数百年，这种概念混合，成为众多微妙解释对象。它说明，教会制度，如何借代表自己的建筑，在社会景观中建立可见存在。正是在此动力中，十一世纪，寓意女性形象Ecclesia，开始等同一座建筑，适合把基督教子民，分为教士、平信徒两群。[^p397-15]

#### 教会改革时代礼拜场所的圣事化

九世纪之后，十一、十二世纪改革时代，是界定礼拜场所教义的第二重要时期。格列高利派教士，有建设基督教社会的共同计划。对他们，欲属于教会，须在教堂之内；欲进入精神圣殿，须先通过石建筑。

不过，有内，先须有外。有基督徒，即教会这一圣事共同体的活石；还有其他人。属于<a id="pdf-398"></a><!-- PDF page 398; original page 369 -->基督身体者，与不属于者之间的裂痕，1050年代起，清楚见于弥撒正经注释，尤其这句：“使它为我们，成为你至爱之子、我们的主耶稣基督的身体与血”（ut nobis corpus et sanguis fiat dilectissimi tui domini nostri Jesu Christi）。释经者引奥古斯丁“在大公教会之外，没有真正祭献之所”，限制性地界定“我们”（nobis），排除“其他人”，即一切异端、犹太人、异教徒，通常也包括穆斯林。[^p398-16] 相应地，从1020年代，直到十二世纪后半叶出现的卡特里派，非正统运动，反对一切教会中介；他们拒绝混合容器、即教堂，与内容、即教会，坚持不可能把上帝，定位于砖石建筑。

最初经院神学《大全》，在这些辩论的沃土形成，把圣经视为一座大主教座堂。按三重解释意义，圣经建筑——诺亚方舟、摩西会幕、以西结圣殿、所罗门与大卫圣殿，都是教会预型——不仅是可描绘的建筑，即历史意义，也成为思考基督教社会的必要框架，即寓意意义，甚至思考每位信徒精神生活的框架，即道德意义。因此，不只是把全社会，描述为主教座堂，更尤其是把整个受造界，按建筑结构构成；圣维克托的于格《论圣事》，正做到这一点。在1050至1150年，关于礼拜场所的教义思考中，此书极重要。论述围绕三项主要关切。

第一，关于十一世纪后半叶，图尔的贝伦加尔（约1010—1088年）引起的圣餐争论。从九世纪帕斯卡修斯·拉德贝尔图斯（约790—约860年）、科尔比的拉特拉姆努斯（约870年卒）争执起，可粗分两立场：一方持圣餐“实在论”，认为祝圣形色，即饼、酒，真实转为基督身体、血；另一方“象征论者”，包括贝伦加尔，认为所谓转化，只是表象，圣餐目的，是追念教会创建时基督牺牲，不须真正重演。实在论者至少官方获胜，间接影响礼拜场所问题。形色真实转化，<a id="pdf-399"></a><!-- PDF page 399; original page 370 -->也称“转变”，甚至1140年起，称“实体转变”（transubstantiation），后果是不只提升祭献时刻，即弥撒，也提升地点，即教堂。两者都被认为，有前述“附加因素”，独一无二地揭示神圣者。

第二，平行论述，思考圣事因果。彼得·伦巴德坚持，圣事实现自身所象征：“它们通过表示恩典，而产生恩典。”圣维克托的于格，提出“预备性因果”概念：圣事建立条件，使受领人，准备好接受恩典，类似器皿、或任何为实现内容而必要的容器。应用于作为建筑的教堂，这种器皿—圣事观念，意义得到充分评估。

第三，思考圣事因果，同时伴随圣事分类。区分七大圣事（sacramenta）：洗礼、坚振、圣餐、悔罪、临终傅油、圣职、婚姻，以及一系列较小圣仪（sacramentalia），包括祝福圣水、覆灰。界定为七件，并非毫无困难；例如，长期有疑问，奉献教堂，是否应算大圣事。多次犹豫后，奉献礼被排除，或更准确，通过有趣地划分第一件圣事、洗礼，部分纳入：象征共同体的建筑受洗，与信徒受洗，区别开来。沙特尔的伊沃（约1040—1115年），在影响广泛的奉献讲道中，解释教堂祝圣，是过程第一步：建筑应先受洗，让信徒也能依次受洗，其他圣事，也可在其功能空间施行。[^p399-17] 换言之，教堂受洗，使其准备好，实现其他圣事；没有它，就无圣事场所，因此无基督教共同体。

### 神圣的空间化

教堂建筑，像个人一样受洗，也如此被圣化。漫长教义发展后，早期经院神学，遂确认了教堂建筑的，<a id="pdf-400"></a><!-- PDF page 400; original page 371 -->可以说“人格化”。结果，反而带回起点：圣化的是人，而非地点；它充分说明，教父时期至1150年代，基督教内部价值逆转。与天上之城不可言说的居所相比，教堂原被视为不重要的物质必需，如今却如此强烈进入景观，成为组织、控制人群的核心场所。

这里勾勒的，礼拜场所圣事教义逐渐形成，不只是教会史一章。教会、社会范围相同，中世纪西方，又没有世俗归属标准，因此也是整个社会史一章，还是地域观念长期界定的关键一章。故须从教会教义，转向社会实践。一个例子，足以说明转焦必要：前述约1050年起，释经者为界定弥撒正经“我们”，援引奥古斯丁“在大公教会之外，没有真正祭献之所”；“真正祭献之所”观念，似迅速从教义，进入实践、法律性质文书。1030至1070年，普罗旺斯某些创堂、赠产契据作者，主张“房屋”（aula），因容纳教会，而称教堂，由基督、使徒、教父，设立为“真正祭献之所”。文本必须说很少，却惊人地反复强调，圣事行为、实现场所的联系。若向上帝献祭，是值得的行动，就应在专为此设的地方举行。[^p400-18]

#### 教堂作为一个整体

礼仪释经者，如瓦拉弗里德·斯特拉博（约808—849年），840年代开始书写建筑演变史；在这一渐进演变终点，教堂被认为是神圣者“适当”的场所。[^p400-19] 这里涉及两阶段：早期基督教建筑，以复数出现；随后，把原分散于多建筑的功能，集中一处。

早期基督徒没有理由为集会、祈祷及共享餐食专门建造场所；圣餐礼正是起源于这种共同餐食。像使徒一样，他们长期满足于在房屋中以小群体聚会，并按需要改造建筑结构。考古资料所能证明的最早“教会之家”（domus ecclesiae）位于叙利亚的杜拉－欧罗波斯，年代为三世纪初。它只是一所住宅，有两个房间特别适应共同体的需要，一个用于集会，另一个用于洗礼。罗马的拜占提斯领衔教堂（Titulus Byzantis）在二世纪初只是一间店铺内的简陋小室，后来成为教会之家，吸收同一街区相邻的住宅，到五世纪形成了以圣约翰和圣保罗为主保的巴西利卡。为适应人数增长与敬拜需求，并在集会中区分教士与信徒、男子与妇女，教会之家的形态发生变化，成为具有大型集会室、专门用于教会活动的厅堂（aula ecclesiae）。从四世纪起，它们经常采用当时最普遍的世俗建筑形式，即巴西利卡。

当然，《米兰敕令》（313年）时，教会厅堂，只是共同体建筑之一。早期建筑，实际包括三种功能分立结构，可以相联，如早期主教建筑群，却未形成单一建筑整体：严格意义礼拜场所，由祭坛界定；殉道者小堂，建立于圣髑；洗礼堂，以洗礼池为中心。中世纪早期教会建筑的主要转变，是聚合、联系、按等级组织这些不同功能重心，形成单一建筑，即教堂，结合洗礼、殉道者或圣徒、圣餐各区。六世纪末，大格列高利在罗马圣彼得的政策，清楚表现了别处以不同速度完成的形态变化。他把祭坛升高几级，予以突出；关键是直接放在安奉圣髑的地下墓室上方，使基督、圣徒形成纵向、等级关系。后来九至十一世纪，同样根本的一步，是把洗礼池，装入已容祭坛、圣徒墓室（confessio）的建筑。

<a id="pdf-402"></a>
<!-- PDF page 402; original page 373 -->

类似不同要素混合，也是教堂祝圣礼核心。840年代起，在整个拉丁世界获接受的仪式，聚焦一点，即祭坛，使基督、圣徒，亲密却有等级地关联。一切从这一神圣重心向外延伸：一方面，通过祝福、祝圣，礼仪小册、后来主教礼典中的仪式，扩及墙壁、钟、祭坛布等众多物件，共同成礼拜场所这一整体；另一方面，祝圣的集体空间本身，扩至近旁为基督徒死者保留的周边。960年代起，主教礼典，记录祝圣墓地礼序，补充教堂奉献礼。[^p402-20] 由此开始一种动态空间衔接：祭坛、教堂为中心，同心地带环绕形成，墓地、兼具避难功能的教堂庭院、堂区、教会领地；各自重要地影响聚落选址，以及居民如何成群、受控。

#### 聚落选址，以及居民的分组与控制

因此，中世纪西方神圣空间化，是更广社会史的一部分。过去50年，聚落考古贡献，深改其范式；无论愿否，发现迫使中世纪学者，重审对“封建社会”、及教会角色的思考。

这种深刻更新，是把居住环境问题历史化，挑战古代聚落固定、教会结构古老的预设。十九世纪从罗马庄园直通中世纪村庄的主张，如今已一致被拒；不过，一些古代晚期史家，仍错误地认为，“教会组织基督徒专属墓地，三世纪中叶已完成”，[^p402-21] 并认为，堂区，或任何以礼拜场所为中心的信徒聚合，从四世纪起，就在结构上与建堂相联。

<a id="pdf-403"></a>
<!-- PDF page 403; original page 374 -->

但1970、1980年代以来，结构古老的旧说，与乡村考古教训碰撞：整个中世纪早期，聚落位移，实际反复发生。人口直到八至十三世纪，才按各地不同速度固定；考古学家、历史学家，工作尺度不同，解释也不同。伊丽莎白·扎多拉—里奥精彩表明，史家的村庄，不同于考古学家的。宏观、大范围解释体系中，史家把永久定居，与大型社会转型、封建社会出现联系；各作者分析，年代从850年代至千年之交不等。按皮埃尔·图贝尔“筑堡聚居”（incastellamento）模式，十、十一世纪，萨比纳、拉丁姆聚落转变、土地重组，是领主想把人口，聚集于山顶设防地点，以更好控制。城堡，成为新社会组织中心；罗贝尔·福西耶，又概括为广泛“单元化”（encellulement），把民众牢牢固定于城堡、教堂、墓地、堂区周围的“单元”。按他所说，单元聚集、控制、统治人。这种模式，不能让考古学家满意，因为难以发掘对应、相联现象，如集中聚落、防御设施、聚落边界。因此，最多只适用于西欧“幼年”。经历最初千年，在有限领土中流动、迁移之后，北欧十一、十二世纪，实际呈现不同聚落固定范式：住房兼牛棚的集群，不归因于城堡、教堂。

#### “依教堂集聚”（Inecclesiamento）

最近两项研究，米歇尔·洛韦尔斯，进一步把教会对单元化的贡献系统化，提出inecclesiamento。仿incastellamento而造，旨在描述，教会作为制度，创造社会空间的过程。

为充分理解这一见解，须强调：约850—900年开始的过程，与早期基督教，起初对任何<a id="pdf-404"></a><!-- PDF page 404; original page 375 -->尘世居住环境纠葛，毫不关心，形成绝对矛盾。早期共同体，继承罗马地域结构，尤其城市、行政区，却除尽量短暂寄居此世的物质需要外，不赋其他意义。为描述古代至中世纪的变化，有些史家，直接说从空间纽带，转向社会纽带。它意味着，越来越抛弃古罗马土地组织模式；后者“基于有界、正交规范、稳定的空间理解，这种理解，深受格网丈地〔centuriation〕实践影响”。[^p404-22] 很早，教会就以自身方式，促成地域解绑。例如，主教争夺一所未祝圣祈祷所控制时，教宗格拉修一世（492—496年）主张，“不应以界限、或预先决定的地点，界定教区”。[^p404-23] 按此逻辑，构成教区的，不是领土，而是信徒存在，以及共同体、主教统一权威之间的人身联系。

这里无法详述，理解如何逆转，但须指出，800年代初，教宗权，通过具有明确边界、公共结构的“圣彼得共和国”地域性、原国家框架，建立完全不同的基督徒—世界关系观。因此，最早中世纪地域性，既是加洛林、奥托、萨利安诸王皇帝的贡献，也同样来自兼任精神、世俗领主的罗马教宗。王国、帝国，自然混合政治、教会结构；800至1050年，东法兰克、中欧教区创建史可证，因为既靠王室契据，也靠教宗诏书。从此看，颇醒目的是，洛塔林吉亚教宗利奥九世（1049—1054年），受帝国权力实践熏陶，开始后来改革教宗权的典型趋势：大规模教宗出行，祝圣祭坛、教堂，以及墓地、教产等空间，边界由仪式性巡行标定。如此，他给当时“罗马自由”，赋予<a id="pdf-405"></a><!-- PDF page 405; original page 376 -->地域现实，把祝圣地点、空间，变成罗马实际的“复制体”。因此，他是一位面向土地的教宗，许多紧接继承者，如乌尔班二世（1086—1099年），也是如此。教会，此后将在土地上，显现其存在。

#### 依附祭坛、教堂的区域

教会与其他控制土地、人口的结构，共同促成一种新地域组织模式：从祭坛、教堂中心，向外以扩大同心圆，展开一系列教会地带。

首先是墓地。古代至中世纪，生者、死者关系完全逆转，深改地形。数百年以城外墓地分隔之后，死者缓慢被纳入生者世界。聚落考古，揭出漫长过程，各地年代不同，大体至少三阶段：野外墓地，经聚落内部埋葬的过渡，走向教堂周边祝圣区坟墓集中。最初，coemeterium只指坟墓本身；直到六世纪，修道世界，才首次出现基督徒与非基督徒分开的集体埋葬。更晚，墓地才通过祝圣，专留基督徒；四世纪起“近圣徒安葬”（ad sanctos），与葬在经仪式祝圣区域，没有关系。如上所说，最早墓地祝圣礼，见于十世纪主教礼典，但十一世纪中叶以前，实际几乎没有文献例证。直到十二世纪，教会法学者才界定基督徒墓地，为因已故信徒遗骸而丰厚的场所。这种限制性死者空间定义，应放在同时代驱逐异端、犹太人、穆斯林背景；三者，是罗伯特·穆尔强调的“迫害社会”的典型形象。

加泰罗尼亚、塞普提马尼亚，对抗伊斯兰的前线，九、十、十一世纪，农民共同体建立、重建，见于大量“祝圣契据”，清楚说明，如何围绕新祝圣教堂，组织共同体空间。例如，985年11月15日，塞尔达尼亚伯爵奥利瓦及妻<a id="pdf-406"></a><!-- PDF page 406; original page 377 -->埃尔芒加德，邀请乌赫尔主教萨拉，祝圣瓦尔福戈纳圣克里斯托福尔教堂。契据明定堂区边界（termini parroquiae），墓地、避难区（sacraria），设于教堂“周围范围”（in circuitu ecclesie）。[^p406-24] 同心地带，以教堂为中心，构成确定的circuitus，即环域；词语既唤起古罗马，靠行走界定财产的司法实践，也唤起携圣髑，仪式绕行墓地的祝圣。教堂周边第一圈，留给死者；其次，是sacraria，30步范围，供生者寻求避难、神圣保护。类似结构，有时成为村庄核心，称sagrera或cellera；某些考古学家，甚至称“教会村庄”。

最外同心区域，是堂区。十世纪最后三分之一，如何理解此词？“堂区”（parochia），长期指与今天完全不同的地形单位。不同于史家长期看法，罗马地产、中世纪堂区之间，没有延续。划定堂区，是一种无先例的空间标界方式，中世纪创新，九、十世纪仍在发展，十一、十二世纪才成熟。早期parochia，又可指宏观整个教区，或微观巴西利卡、教堂；直到十二世纪，才获明确、独特地域意义。这与信徒向教堂集中的复杂历史结束，相吻合；此时，教堂被视为，用圣事界定共同生活基督徒的核心：洗礼、死亡，或多或少定期参加圣餐牺牲，悔罪者和好、重新纳入。中世纪堂区形成，有两主要因素。第一，什一税，加洛林起强制，须缴给礼拜场所；因此，堂区首先是土地财政单位，信徒在其范围，为教堂“运转”提供所需，即教职人员需要、建筑维护。兰斯的欣克马尔（约806—882年），在无疑最早系统讨论教产的<a id="pdf-407"></a><!-- PDF page 407; original page 378 -->《论教堂与小堂》汇编，强调此面向。[^p407-25] 第二因素，是墓地。加洛林起，信徒被要求，葬在缴什一税的地方。很长时间，“自然”堂区成员，就是缴税、又葬于同一堂区者；因此，中世纪思想，常混合墓地、堂区。

#### 圣徒的土地与修士的空间

最后，应谈克吕尼修士地域政策。他们是大教会领主，拥有罗马圣彼得、保罗圣髑，以罗马模式为灵感。例子象征一种普遍现象：教会自由（libertas ecclesiae）的地域化。

克吕尼契据、后来契据集，汇集约5000份1120年前文书，见证910年创院后最初两世纪，积极取得地产的政策。十一世纪后半叶，修士在此土地基础，组织“领主管控的地点、圈域”。[^p407-26] 第一阶段，把土地、教堂、城堡、磨坊等不同财产，纳入单一、共同教会结构，并创建依属机构、或“区长辖区”（decania）网络。这些多功能场所，同时是农业、贸易、商业中心，隐修所、朝圣教堂。随后，以修道院教堂，以及安放彼得、保罗圣髑的主祭坛为中心，网络被安排于影响圈；克吕尼圣洁性，在圈内确立绝对不可侵犯。[^p407-27] 首先，修道院豁免，须落到土地上。1080年使节阿尔巴诺的彼得、1095年乌尔班二世——原克吕尼大副院长——两位罗马权力代表，在现场庄严行动，即为此。他们以仪式，划定克吕尼“神圣禁域”（Sacred Ban），即圣彼得管辖区，用道路相联的界标、十字架，赋予物质形态。很快，又加两重影响圈：帕斯卡尔二世（1099—1118年），1107年诏书，设免通行税、无城堡的地带，让朝圣者、客人、<a id="pdf-408"></a><!-- PDF page 408; original page 379 -->商人，自由往返克吕尼。最后，卡利克斯图斯二世（1119—1124年），1120年授予豁免，使克吕尼成为管辖几个堂区的“微型教区”。

设克吕尼“神圣禁域”数周后，乌尔班二世在克莱蒙—费朗，发出著名号召，十字军解放圣地。1099年征服后，这片基督教故事起源的土地，确实被重新祝圣；耶路撒冷解放礼仪，可为证明，因为大量取自奉献教堂的程式。[^p408-28] 象征性回归根源，仿佛格拉伯“教堂的白色外衣”，如今将披在基督本人尘世寄居的地点。圣殿毁灭，长期铭刻于拉丁教会记忆，十字军收复的尘世耶路撒冷，被比作新教堂；像长期废弃礼拜场所，恢复基督教圣洁那样，得到净化。因此，最早基督教中心，被当作教堂，关联基督的地形，由奉献礼重新确立。教堂始终被理解为天上耶路撒冷形象，如今在期待未来再临之际，为尘世耶路撒冷，重新注入生命。
