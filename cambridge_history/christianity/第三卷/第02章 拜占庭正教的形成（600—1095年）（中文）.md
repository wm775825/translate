# 第02章 拜占庭正教的形成（600—1095年）

安德鲁·劳思（Andrew Louth）

<a id="pdf-075"></a>
<!-- PDF page 75; original page 46 -->

## 引言

公元600至1095年，是拜占庭帝国发生巨大变化的时期。最重要的原因，是伊斯兰教在七世纪前期兴起，以及此后东方持续存在一个阿拉伯帝国。伊斯兰教给拜占庭世界带来沉重冲击，帝国用了将近两个世纪才恢复过来。不过，这种恢复也部分得益于阿拉伯帝国自身的变化：750年，首都从大马士革迁到巴格达，它变成一个更加面向东方的社会，减轻了拜占庭所受的压力。关于最初的600至850年，传统历史资料十分稀少，许多问题因而无从知晓。九世纪起，拜占庭帝国开始复苏；十世纪及十一世纪初，马其顿王朝治下的帝国向外扩张，恢复了部分昔日荣光。教会也分享着这种扩张与繁荣的新气象，得以在843年摒弃圣像破坏、实现“正教的凯旋”后形成的正统意识之上，进一步发展。这种正在形成的正教意识，体现于艺术与学术、修道复兴与传教扩展等领域。后一时期的资料较为丰富，使我们能更深入地了解基督教的不同面向，以及帝国的其他方面。因此，本章讨论600至850年的前半部分，主要按时间顺序展开；讨论后一时期的后半部分，则更多采取专题方式。

## 历史概览：600—850年

本章所述时段开始时，拜占庭帝国仍清楚呈现着查士丁尼一世（527—565年）所恢复的基督教罗马帝国面貌。它仍在一定程度上可以<a id="pdf-076"></a><!-- PDF page 76; original page 47 -->自称地中海帝国，囊括几乎所有濒临地中海海岸的地区，尽管它对西班牙的控制相当脆弱。然而，到600年，这幅基督教罗马帝国的图景已经在瓦解。斯拉夫人开始越过多瑙河，定居于巴尔干半岛各地，拜占庭人称这些地区为“斯拉夫人区”（Sklavinias）。在更好战的阿瓦尔人领导下，斯拉夫人开始威胁拜占庭的统治，围攻帖撒罗尼迦，并于626年进围君士坦丁堡。他们在巴尔干的存在，像楔子一样插在拜占庭帝国两个首都罗马与君士坦丁堡之间，阻碍东西方沟通。在东方，地中海帝国历代形态的传统敌人波斯，正准备发动进攻。602年，福卡斯（602—610年）推翻莫里斯皇帝（582—602年），波斯帝国便以此为借口入侵拜占庭帝国，614年攻占耶路撒冷，吞并从叙利亚到埃及的东方行省。在这些从拜占庭手中夺取的行省中，波斯沙阿发现了基督徒内部的分裂，并试图加以利用。

### 基督论争议[^p076-1]

这些分裂可追溯到迦克墩大公会议（451年）。会议试图使基督徒在基督道成肉身的问题上取得一致，确认基督具有两种完全的本性，即人性与神性，却只有一个实存（hypostasis，即位格）。大多数东方基督徒仰望亚历山大里亚牧首区利罗（410—444年），从他那里寻求理解基督的指引。迦克墩会议诸主教认为，他们对基督论的界定表达了区利罗的理解，但许多人不同意，拒绝接受迦克墩。这些反迦克墩者，被对手称为“单性论者”。尽管拜占庭当局不时加以迫害，他们在会议后几十年里不仅存续下来，还发展壮大，叙利亚和埃及尤其如此。耶路撒冷陷于波斯不久，沙阿霍斯劳二世（590—628年）决定利用这一局面，支持叙利亚、亚美尼亚、美索不达米亚西部的反迦克墩派，以及618年落入波斯手中的埃及反迦克墩派。安提阿的反迦克墩派牧首“赶骆驼者”亚他那修（595—631年），欢迎这个“迦克墩黑夜”的结束。

这促使拜占庭皇帝希拉克略（610—641年）与君士坦丁堡牧首塞尔吉乌斯（610—638年）采取对策。他们与<a id="pdf-077"></a><!-- PDF page 77; original page 48 -->西奈和埃及的主教商议，提出一种妥协公式，即“一能论”（monenergism），希望使迦克墩的支持者与反对者和解。这项妥协维持迦克墩关于基督有两性、一位格的主张，另加一项细化：基督只有一种运作，希腊语为 energeia；亚略巴古的狄奥尼修——活跃于六世纪初——称这种运作为神人共同的，即“神人运作”（theandric）。628年，希拉克略成功入侵波斯，引发宫廷叛乱，沙阿被推翻；他还从泰西封取回了由耶路撒冷掠走的真十字架圣物。希拉克略带着这件圣物，在收复的行省举行凯旋巡行，以一能论为基础，提议与反迦克墩派重新联合，似乎取得了一些成功。不过，一能论最成功的地方是埃及。633年，原籍格鲁吉亚法西、被希拉克略同时任命为亚历山大里亚牧首和埃及奥古斯都长官的居鲁士（631—642年），与埃及反迦克墩派——人称狄奥多西派——达成重大和解，并以九章《合一协约》加以表述。居鲁士向君士坦丁堡的塞尔吉乌斯报告成功，后者又转报教宗霍诺里乌斯一世（625—638年）。然而，一位杰出学者兼修士索弗罗尼乌斯（约560—638年）的反对，使这项成就蒙上阴影。他认为，《九章》纯属异端。索弗罗尼乌斯带着异议前往君士坦丁堡，再赴罗马，但只促成塞尔吉乌斯在634年的《裁定》（Psephos）中，禁止讨论基督运作的数目。此时，索弗罗尼乌斯已是耶路撒冷牧首。638年，塞尔吉乌斯撰写、希拉克略颁布的《信仰阐述》（Ekthesis），进一步调整一能论，确认基督是一位格、两本性，却只有一个神圣的意志。这一教义称为“一志论”（monothelitism）。它激起的反对，由索弗罗尼乌斯的一位弟子、当时住在北非的认信者马克西穆斯（约580—662年）领导；索弗罗尼乌斯此时已去世。反对运动在649年的拉特朗会议达到高潮。会议似乎由马克西穆斯筹划，教宗马丁（649—655年）召集，谴责一能论、一志论，以及支持这些异端的教会人士。

然而，到这时，拜占庭帝国已遭到比波斯人严重得多的敌手打击，那就是在伊斯兰教之下联合起来的阿拉伯部落。先知穆罕默德632年去世后，仅仅不到十五年，他们便击溃波斯帝国，夺取拜占庭的东方行省，而且这一次再未归还。638年，耶路撒冷陷落，由索弗罗尼乌斯向哈里发欧麦尔一世（634—644年）交城。一志论争议发生在拜占庭战败的背景下，削弱了<a id="pdf-078"></a><!-- PDF page 78; original page 49 -->它所提供的、与如今已受伊斯兰教统治的反迦克墩派联合的可能，也削弱了拜占庭在这种联合基础上反击的任何机会。马克西穆斯在拜占庭宫廷受审的记述中，明显流露出一种看法：他在神学上的顽固，简直等同于叛国。审判导致他被判异端，遭受肢体残害，662年死于流放。[^p078-2] 到680—681年第六次大公会议上，拜占庭帝国正式放弃一能论与一志论时，倭马亚帝国已牢固建立，以大马士革为首都。

### 正教的界定

尽管七世纪政治处境绝望，矛盾的是，它却是拜占庭神学最伟大的时期之一。认信者马克西穆斯反对帝国提出的那些基督论权宜之计，依据的是一种神学视野：它把希腊神学的教义、哲学、禁欲与礼仪诸线索汇集起来，成就至今无可匹敌。他后来对一切拜占庭神学，都产生了深远影响。不过，马克西穆斯的影响，最初并不显现在没有理由对他怀有好感的君士坦丁堡，而是在陷于伊斯兰教之手的地区，尤其巴勒斯坦。在那里，伊斯兰教撤除了对任何一种基督教的政治支持，迫使不同基督徒群体界定并捍卫各自立场，既面对其他基督教立场，也面对别的宗教选择，尤其伊斯兰教。[^p078-3] 最著名的迦克墩立场表述，见于当时任巴勒斯坦修士的大马士革的约翰（约675—约749年）的著作，尤其三部分组成的《知识之泉》，其中最后一部分，以一百章概述基督教教义。约翰也是传统圣像敬礼的著名捍卫者，见下文；同时还是新式礼仪诗歌、尤其卡农颂（canon）的杰出作者。这类诗歌后来丰富了迦克墩派，或称“梅尔基派”修士的日课，即支持拜占庭皇帝——malka——的修士的日课。到八世纪中叶，约翰捍卫圣像的声名已传至君士坦丁堡，他在754年的希耶里亚会议上受到严厉谴责；但直到九世纪中叶正教恢复之时，首都似乎才详细了解他的著作。大约同一时期，约翰也曾参与创造的修道日课诗歌之丰富形式，传到君士坦丁堡。颇具讽刺意味的是，“拜占庭<a id="pdf-079"></a><!-- PDF page 79; original page 50 -->正教”的定型表述，并不在首都形成，实际上根本不在帝国之内。

七世纪末、八世纪初，拜占庭人多次试图恢复信心：皇帝采用君士坦丁、查士丁尼这样的名字，意味着新的开端。691—692年，查士丁尼二世（685—695、705—711年）在皇宫穹顶厅——拉丁语 trullus——召开会议，试图完成此前553年、680—681年在君士坦丁堡举行的两次大公会议的工作，因为那两次会议只颁布了教义法令。这次会议似乎认为自己是第六次会议的延续，尽管后来被称为“五六会议”（Quinisext），或特鲁洛会议。它制订102条教规，构成对拜占庭教会整个教规传统的总结。其态度保守而防御性强，肯定君士坦丁堡传统，反对罗马——尤其在教士独身问题上——与亚美尼亚的传统，禁止与犹太人接触，也禁止各种残留的异教做法。阿拉伯人的军事压力仍在持续：674至678年，他们封锁君士坦丁堡，718年，这座城市又面临一次围攻。七世纪末、八世纪初各位皇帝在位相对短促，也表明局势不稳定。717年，利奥三世（717—741年）即位，标志着一段长期政治稳定的开始；这种稳定延续于其子君士坦丁五世（741—775年）治下，父子合计在位近六十年。其间，拜占庭帝国开始恢复力量。这也是圣像破坏第一阶段的时期，皇帝下令摧毁并禁止宗教图像。

### 圣像破坏

关于圣像破坏的起源，以及最初事件的先后次序，争议很多。两部历史资料——尼基弗鲁斯的《简史》和狄奥法内斯的《编年史》——都把圣像破坏的引入，归因于皇帝对726年基克拉泽斯群岛地震的反应。这次地震在忒拉和忒拉西亚附近，又隆起一座岛屿；前两岛本身也是早期火山活动的产物。利奥惧怕神怒，便命人移除皇宫铜门上的基督圣像。然而，当时那里是否存在基督圣像，远不清楚；直到730年，牧首日耳曼努斯才因帝国政策辞职。不过，似可确定的是，拜占庭的圣像破坏是皇帝敕令的结果，而非对某种群众运动的回应。到八世纪初，宗教艺术无论在公共还是私人领域，都已在拜占庭社会占据重要地位。移除所有宗教绘画艺术，必然产生深远<a id="pdf-080"></a><!-- PDF page 80; original page 51 -->影响。人们眼中的景象骤然改变：世俗描绘和皇帝图像得以保留，但原先以马赛克、壁画、木板画和织物图样描绘的基督、上帝之母与圣徒——也许还有雕像，尽管这方面证据很少——都不再存在；唯一获准的宗教图像，是十字架标志，它本身也是帝国的象征之一。这暗示，圣像破坏背后的一个动机，也许是毫不含糊地宣示皇权，使其免受各种神圣形式提出的竞争性要求影响。关于利奥三世治下帝国圣像破坏的进程，证据很少；事实上，资料更多谈到740年君士坦丁堡地震造成的广泛破坏。

关于神学上对利奥破坏圣像敕令的反应，我们所能了解的，仅限于日耳曼努斯的一些书信和论著，以及大马士革的约翰三篇反圣像破坏论。约翰在倭马亚王朝治下的巴勒斯坦安全地写作。这些论著，特别是约翰那些充满教父引证的作品，利用了七世纪基督徒对犹太人反对圣像敬礼所作的回应。这些回应，是伊斯兰教占据政治优势时兴盛的宗教争辩的一部分。犹太人论称，第二条诫命禁止敬奉圣像；利奥在现已佚失的敕令中，似乎也提出同样异议。基督徒则回答，第二诫禁止的是偶像崇拜，即把受造物作为上帝敬拜，却不禁止敬奉神圣男女的画像，他们的圣洁表现着自己与上帝的亲近。人们把俯伏礼，即 proskynesis，区分为两种：一种表达唯独应当归于上帝的敬拜（latreia），另一种表达尊敬（timē），可以用于圣徒，甚至神圣物品。圣巴西尔的名言“对形象所表示的尊敬，归于其原型”，也经常被引用。八世纪的圣像敬礼捍卫者，特别是大马士革的约翰，又在这些论证之外，从根本上诉诸道成肉身：上帝本身不受界限限定，但当他道成肉身、成为人时，就使自己可以被限定；如今，他既已成肉身，便可以被描绘。事实上，既然成了肉身，他就必定能够被描绘。

741年利奥去世，其女婿阿尔塔巴斯杜斯短暂争位后，由儿子君士坦丁五世继位。资料把君士坦丁描写成亵渎神圣的恶人。然而，近十年间，他没有进一步推动圣像破坏，而是忙于击败阿尔塔巴斯杜斯，利用阿拉伯人日渐扩大的内战——750年阿拔斯王朝由此建立——并应对帝国的瘟疫和地震。然而，754年，他在君士坦丁堡对岸亚洲海滨的希耶里亚宫召开会议，<a id="pdf-081"></a><!-- PDF page 81; original page 52 -->批准圣像破坏。此前，他曾向诸主教传阅一组“诘问”（peuseis），提出关于圣像的各种问题。会议本身颁布一份长篇“定义”（horos）。这份定义得以保存，是因为787年举行、如今被视为第七次大公会议的会议，曾对它逐条反驳。这份定义，把反对圣像的论证带到彻底的神学层面。它不说圣像是偶像，而说基督的圣像不可能成立：要么它描绘的是与神性分离的基督人性，这意味着涅斯托里乌斯主义；要么它描绘的是与神性混合的基督人性，这意味着单性论。因此，描绘基督等同于异端。另一个论证提出，基督真正的形象是圣餐：饼和酒领受司祭祝福，成为基督身体和宝血的形象或预型。

希耶里亚这次自称“第七次大公”的会议作出决定后，君士坦丁五世似乎加强了对反对圣像破坏者的迫害。他还打击修道身份，强迫男女修士结婚并放弃誓愿。然而，即使在圣像敬礼派的史料中，也没有证据表明，君士坦丁对圣像敬礼派和对修士的迫害彼此关联。一种颇有道理的观点认为，圣像敬礼派殉道者中最突出的圣小司提反（约713—764年），是因涉嫌参与叛乱阴谋而遭处死，并非因为捍卫圣像本身。[^p081-4]

775年君士坦丁五世去世，由儿子利奥四世（775—780年）继位。利奥的妻子伊琳娜是雅典贵族女子。利奥于780年去世，伊琳娜成为年幼儿子君士坦丁六世（780—797年）的摄政。保罗四世（780—784年）去世后，伊琳娜任命官僚塔拉修斯为牧首（784—806年）。787年，尼西亚举行第七次大公会议，重新确认圣像敬礼。塔拉修斯急于和解，凡放弃先前圣像破坏立场的教士，都很容易复职；但这使他遭到更激进圣像敬礼派的宽纵指控，尤其是与后来人称“斯图迪奥斯修院的狄奥多若”（826年卒）有关的修士。同一批修士，也强烈反对君士坦丁于795年与妻子马利亚离婚，以迎娶宫廷女子狄奥多特。讽刺的是，她正是狄奥多若的表亲。伊琳娜也优待狄奥多若，邀请他和修士们，从比提尼亚的萨库迪翁修道院来到君士坦丁堡，复兴金门内侧的斯图迪奥斯修道院。

伊琳娜安排刺瞎、废黜儿子后，于797年亲自登上皇位，是唯一这样做的女性，但<a id="pdf-082"></a><!-- PDF page 82; original page 53 -->仅仅五年后便遭废黜，由尼基弗鲁斯一世（802—811年）继位。他的统治以败于保加利亚人之手而不光彩地结束；保加利亚汗克鲁姆把他的头骨制成嵌银酒杯。尼基弗鲁斯的儿子，在同一次战役中受伤，后来由令人失望的米海尔一世·朗加贝（811—813年）接替；813年，利奥五世（813—820年）将其废黜。一年多一点，利奥就在君士坦丁堡召开会议，重申希耶里亚会议的权威，重新推行圣像破坏。牧首尼基弗鲁斯（806—815年）被迫辞职，狄奥多若及斯图迪奥斯修道院的修士被驱散、流放。尽管利奥恢复了希耶里亚的决定，圣像破坏的性质和所涉问题却已改变。争论不再是圣像能否存在，而在于能否敬礼圣像；有些挂在墙壁高处、敬礼者无法触及的圣像，获准保留。斯图迪奥斯的狄奥多若对圣像的辩护，转而以敬礼圣像上所描绘的实存——“位格”的神学专门用语——是否合法为核心。这一位格在圣像与原型中是同一个。视角转变的一个原因，很可能是利奥希望获得法兰克人的支持：后者在794年法兰克福会议上，拒绝圣像敬礼，却未赞同彻底的圣像破坏。

820年利奥去世，圣像破坏的执行不再那么严格，被流放者也获召回，但米海尔二世（820—829年）拒绝批准圣像敬礼，至少在君士坦丁堡城内如此。其继承者狄奥斐鲁斯（829—842年）治下，对圣像敬礼派的迫害似乎加剧。其中著名的两人，是来自巴勒斯坦的修士兄弟狄奥多若和狄奥法内斯；他们脸上被烙上破坏圣像的诗句，诗的质量还很差！842年狄奥斐鲁斯去世，圣像敬礼再次恢复，又由一位为儿子摄政的寡居皇后推行，这次是狄奥多拉及其子米海尔三世（842—867年）。与815年一样，君士坦丁堡的驻都主教会议重申了一次八世纪会议的法令；这次所确认的，是第七次大公会议，即第二次尼西亚会议。新牧首美多迪乌斯一世（843—847年）主持的驻都会议作出决定后，843年大斋期第一个主日，在圣索菲亚大教堂神圣礼仪开始前，以《正教会议宣言》（Synodikon of Orthodoxy）予以宣告。它正式颂扬正教及其捍卫者，咒诅异端及异端分子。以后，每年大斋期第一个主日，都要重复这项仪式；起初在君士坦丁堡，最终遍及拜占庭世界。这一天后来被称为“正教主日”。拜占庭世界内部虽仍有一些反对圣像的力量，圣像敬礼此后却始终是拜占庭的政策。

## 拜占庭正教的诸面向：850—1095年

### 牧首制度

600至850年间，皇帝轻易便能找到顺从的君士坦丁堡牧首，支持后来被宣布为异端的宗教政策：先是一志论，继而圣像破坏。人们也许会以为，这会损害牧首制度本身的地位。然而恰恰相反，九世纪的牧首职权，远比两个半世纪以前强大。

这似有几个原因。与600年相比，850年的牧首管辖权，在多方面都更加明确，也更加广大。第一届君士坦丁堡大公会议（381年，教规3）与迦克墩大公会议（451年，教规28），虽赋予君士坦丁堡大主教仅次于罗马主教的“荣誉特权”（ta presbeia tēs timēs），后者更规定，这些特权与罗马“相等”，君士坦丁堡居“第二位”，但最初并未赋予他十分明确的管辖范围。没有清楚的地域，大主教便没有一批所属主教，可按第一届尼西亚会议（325年，教规5）的设想，召集定期会议。因此，他的会议权威逐渐通过所谓“驻都主教会议”（endēmousa synodos）行使，由当时碰巧身在君士坦丁堡的主教组成。成员虽不断变化，但有宫廷在场，仍可以依靠。这个会议逐步取得权威，以至九世纪时，815年重新实行圣像破坏、843年重新恢复圣像敬礼，都可由驻都会议的一次集会批准。到这时，它已成为常设性更强的机构。其力量又得到前来君士坦丁堡避难的主教，甚至牧首的补充：他们的教区有的已陷于伊斯兰教，有的经常受阿拉伯军队侵扰，或被斯拉夫人占领。

阿拉伯人征服东方行省，也使君士坦丁堡的管辖范围更加清楚。迦克墩会议曾赋予它祝圣邻近本都、亚细亚和色雷斯诸行政区省会主教的权利。不过，从五世纪初金口约翰的时代起，君士坦丁堡就已声称自己有权祝圣，因而最终监督小亚细亚诸省会主教；安提阿牧首区对此提出异议。但东方陷于伊斯兰教后，安提阿的梅尔基派牧首，要么受阿拉伯人统治，要么流亡君士坦丁堡；无论哪种处境，都无法再争议君士坦丁堡对整个小亚细亚的管辖。利奥三世又进一步扩大了牧首的<a id="pdf-084"></a><!-- PDF page 84; original page 55 -->管辖范围。罗马拒绝执行圣像破坏，利奥为报复，将罗马传统上对伊利里库姆，即多瑙河以南巴尔干西部的管辖权，移交君士坦丁堡。751年拉文纳落入伦巴德人之手后，君士坦丁堡牧首的管辖范围，实际上已与拜占庭皇帝统治的疆域重合。因此，牧首及圣索菲亚教堂的教士，成为整个拜占庭帝国教会权威的枢纽。

牧首宫廷发布圣徒传式宣传，巧妙消除或遮掩异端的污点。《圣小司提反传》《圣约安尼基乌斯传》（约754—846年），以及牧首塔拉修斯、尼基弗鲁斯的传记，都出自牧首宫廷，描绘了一幅牧首在抵抗圣像破坏时发挥高尚作用的图景。[^p084-5] 因此，经历圣像破坏之后，牧首职在权力与声望两方面，都大为增强。843年，狄奥多拉皇后任命美多迪乌斯牧首恢复圣像敬礼。尽管斯图迪奥斯修士声望很高，自称取得胜利，美多迪乌斯仍能推行自己的政策。这部分是利用了修道派内部的分裂：第二阶段圣像破坏期间，圣狄奥多若与圣约安尼基乌斯的支持者之间，已出现分歧。

此后几个世纪，牧首职的权力与威望继续发展，成为拉丁西方与拜占庭东方日益疏远的一个因素。无论是牧首佛提乌斯（858—867、878—886年）与教宗尼古拉一世（858—867年），还是牧首米海尔一世·凯鲁拉里乌斯（1043—1058年）与教宗利奥九世（1049—1054年）之间的冲突，都必须有一部分归因于牧首权与教宗权观念的相遇。两者在七、八世纪各自发展，后来又在已经相互独立的政治体制中继续发展，都以牧首或教宗本人为中心。[^p084-6]

牧首也因马其顿王朝时期拜占庭帝国的扩张而增加权威，尤其因为自九世纪起，拜占庭影响通过建立迪米特里·奥博连斯基所谓的“拜占庭共同体”，向外传播。[^p084-7] 拜占庭向东扩张，与亚美尼亚建立联系。亚美尼亚<a id="pdf-085"></a><!-- PDF page 85; original page 56 -->没有代表参加迦克墩会议，后来逐渐进入反迦克墩阵营。因此，与亚美尼亚的关系，以及任何将其并入拜占庭帝国的尝试，都涉及神学和宗教习俗问题，类似于与拉丁西方之间提出的问题。[^p085-8] 从佛提乌斯开始，诸牧首不可避免地参与其中。拜占庭基督教向斯拉夫人传播，则使牧首获得一种特殊的突出地位。斯拉夫诸民族，从保加利亚开始，虽接受拜占庭基督教，却没有被并入拜占庭帝国，而是加入拜占庭共同体的松散联盟。在这个“共同体”中，牧首的权威比拜占庭皇帝更明确，因为保加利亚大主教，以及基辅和全罗斯的省会主教，都由牧首任命；例外是保加利亚拥有独立牧首的大约一个世纪。[^p085-9]

### 学问：从佛提乌斯到普塞洛斯

九世纪出现了所谓“马其顿复兴”，或“拜占庭的第一次人文主义”（le premier humanisme byzantin）的开端。[^p085-10] “马其顿”这个修饰词容易误导，尤其因为早在867年马其顿王朝建立者巴西尔一世登上，或篡夺皇位几十年前，学术复兴就已经充分展开。与大致同时的加洛林复兴一样，它以一种技术革新为标志：采用草写小写体抄写文学手稿；也以古典学问复兴为特征，尽管东方古典学问从未像西方那样衰落。现存最早以小写体抄写文学手稿的见证，是835年所谓《乌斯片斯基福音书》，出自斯图迪奥斯修道院。圣狄奥多若的修道改革，很可能包括建立类似抄写室的机构，抄写圣经、礼仪和教父文本；但这个孤立的见证，不足以证明以小写体抄写文学作品是该院的创新，尽管斯图迪奥斯一定是最早采用这种书体的地方之一。

这次复兴包含几个方面。我已经提及宗教方面，即重新发现教父著作，并使其便于获取。其起源可追溯到几个世纪以前，<a id="pdf-086"></a><!-- PDF page 86; original page 57 -->追溯到七世纪的基督论争辩，以及八、九世纪的圣像破坏争辩。在这两种情形中，诉诸教父，都需要严肃学术研究，确保所引权威确实可靠。阿道夫·冯·哈纳克甚至把第六次大公会议，即第三次君士坦丁堡会议（680—681年），称为“古物学家与古文字学家的会议”。[^p086-11] 所有这些会议提出的教父引文选集，展现了当时可资调用的广博学问。想到第三次君士坦丁堡会议的教父们，整整一个会期都在聆听教父对基督在园中痛苦挣扎的解释，实在令人敬畏。狄奥多若的修道改革，也复兴了人们对大圣巴西尔（约330—379年）《大禁欲集》（Great Asceticon）的兴趣，以及对其他禁欲著作的兴趣。例如，与六世纪加沙沙漠修士巴尔萨努菲乌斯、约翰和多若狄乌斯有关的作品，以及西奈的圣约翰的《阶梯》。后者又称约翰·克利马库斯，很可能活跃于七世纪初。

在文献方面，另一个面向是希腊古典学问的恢复。最能显示这次复兴广度的单一丰碑，是君士坦丁堡牧首佛提乌斯的《万卷书》，又称《书库》（Myrobiblion／Bibliotheca）。这是一部由人们所谓“书评”组成的文集，有时大段摘引所评作品，合计约280篇。佛提乌斯说，作品是在他出使阿拉伯人之前仓促写成，书中也多处可见匆忙的痕迹。全书没有结构，世俗和宗教书籍交错出现。他讨论的宗教书籍比世俗书籍更多，却倾向于更详细地讨论世俗著作，结果宗教部分不足全书的一半。选书原则也不清楚：这是佛提乌斯能找到的全部书籍，还是他感兴趣的书？从其他著作可见，他知道的当然不止于所收各书；从《万卷书》中，也能搜集许多其作品未被收入的作家资料，例如柏拉图。诗歌作品的缺席，尤其引人注意。佛提乌斯的其他著作包括一部《词汇集》；这本身就表明，阅读古代文学的人数，已经多到需要这样的辅助工具。此外还有书信，以及《安斐洛基亚》（Amphilochia）。后者讨论《圣经》和教父作品中的问题，据说是基齐库斯省会主教安斐洛基乌斯向他提出的。它们代表一种神学反思体裁，最早由认信者马克西穆斯广泛采用，见其《疑难集》（Ambigua，其中许多篇也写给一位基齐库斯主教）及各种“问答”。这种体裁后来在拜占庭流行，米海尔·普塞洛斯（1018—1081年）也参与创作。

支撑这种学问的教育结构，仍不清楚。参照西方情形，认为存在牧首学校或修道院学校的说法，已遭到质疑。[^p087-12] 同样清楚的是，传统教育体系在阿拉伯征服之后的某个时候崩溃。但教育必定仍可获得，尽管水平未必很高；现有证据表明，八世纪至少在君士坦丁堡，人们掌握文学希腊语的程度似乎不佳。

十世纪马其顿复兴的大多数表现，不在本章讨论范围：例如君士坦丁七世“生于紫室者”（913—959年）治下编纂的政治和行政资料、《苏达辞书》，以及《帕拉丁诗选》，尽管其中也能搜集神学与宗教材料。下一个世纪，米海尔·普塞洛斯及其弟子兴盛起来，取用哲学、尤其新柏拉图主义的资源。这种对学问的积极兴趣，有时公开带有异教性质，暴露出“外学”（hē thurathen paideia）与“内学”之间形成的裂隙；拜占庭人所谓“内学”，即基督教教义与禁欲神学。普塞洛斯免于直接谴责，他的学生约翰·伊塔洛斯（约1025—1082年后）却没有。1082年，阿莱克修斯一世·科穆宁皇帝（1081—1118年）治下，他因异端与异教受审、被定罪。阿莱克修斯为确立正教守护者身份而推行的举措，包括向《正教会议宣言》添加内容，其中谴责“那些钻研希腊学问、受其塑造的人：他们不仅把它当作一种教育训练，还追随其中空洞的意见，相信它们为真”。[^p087-13]

### 修道生活

修道生活从一开始就是拜占庭社会的突出特征。四世纪，它先在埃及迅速兴起，继而遍及罗马帝国东西方其他地区。四世纪埃及沙漠的修道生活，后来被视为一种修道黄金时代。五世纪，人们大概在巴勒斯坦，编成埃及沙漠教父的故事和言论集，希腊语称 Gerontikon，拉丁语称 Apophthegmata Patrum。这些集子成为世代传承的修道智慧核心。从一开始，言论集就有其他材料补充：圣徒传记，<a id="pdf-088"></a><!-- PDF page 88; original page 59 -->例如圣大安东尼的传记，与帕科米乌斯和凯撒里亚的巴西尔有关的修道规章，以及《劳苏斯史》《埃及修士史》等其他埃及修士记述。[^p088-14] 后来，更多作品加入这一文献群。例如，斯基托波利斯的区利罗（约525—559年后）通过多篇圣徒传，记述巴勒斯坦修道生活的起源；加沙大禁欲者巴尔萨努菲乌斯和约翰——均约卒于540年——及其弟子多若狄乌斯——活跃于六世纪中叶——的书信；约翰·莫斯库斯（约550—634年）和耶路撒冷的索弗罗尼乌斯走访各修道场所的游记《灵修草地》；最后，还有大概属于七世纪的巨著《神圣攀登的阶梯》，作者约翰生于579年前、卒于650年后，任西奈“燃烧荆棘”修道院院长，因其作品而得名“克利马库斯”，即“阶梯者”。

从一开始，就出现三种始终具有拜占庭特色的修道形式。首先是独居修士，远离人类社会生活：有的像圣安东尼（251年？—356年）那样深入沙漠，有的像圣柱修士西缅（约390—459年），住在柱子，即 stylos 的顶端；住在偏远山洞的修士，也被称为柱修士。其次是生活在团体中的共住修士，名称来自希腊语 koinos bios，即“共同生活”。他们有的远离人群，例如帕科米乌斯（约290—346年）在塔本尼西创立的修道院；也有的住在城市，例如巴西尔在凯撒里亚创办的团体。此外，还有追求独居生活，却接受长上指导，每个周末相聚、交往并领圣餐的修士；这类群体称为劳拉，后来也称 sketes。由于独居生活通常需要先在团体中准备，共住修道院成为独居者及一组组劳拉的母院，并不罕见。著名例子有西奈修道院，以及犹太沙漠的圣撒巴大劳拉。两者在整个拜占庭时期都兴盛不衰，至今仍然延续。

七、八世纪，是拜占庭修道史的黑暗时期，主要因为缺乏资料。除了约翰的《阶梯》，以及从认信者马克西穆斯和西奈的阿纳斯塔修的禁欲、神学著作中所能搜集的材料——这些都属于七世纪——几乎无所凭依；而且，这一切材料，都来自已经或不久就要陷于伊斯兰教的地区。帝国剩余疆域内部的修道生活，很可能遭受了相当大的破坏。620年代，波斯军队横穿小亚细亚时，许多修士逃走，马克西穆斯也在其中。阿拉伯人在此后一个世纪，对小亚细亚大部分地区的侵扰，<a id="pdf-089"></a><!-- PDF page 89; original page 60 -->很可能阻碍了重新定居。不过，有证据显示，八世纪修道院仍在奥克森提乌斯山和奥林波斯山两座圣山及周边存续。这两座山都在马尔马拉海以南，离首都不太远。君士坦丁堡的修道院，很可能受到七、八世纪城内人口严重减少的影响；这种减少由持续流行的瘟疫和反复发生的地震造成。君士坦丁五世打击修道生活，必定进一步削减修士人数，但程度无法判断。另一方面，斯图迪奥斯的狄奥多若等修道改革者的传记，给人一种八世纪末修道生活衰败的印象，或许不应过分当真，因为这是修道创办者传记中的常见套式。

不过，九世纪确实开启了一个修道改革时期，其中狄奥多若及其对城内斯图迪奥斯“先驱圣约翰”修道院的恢复，发挥了核心作用。[^p089-15] 该院的安排，详载于 typikon，即创设文书，成为后来拜占庭修道生活的范本，尤其影响十世纪起阿索斯山新建的修道院，由此可见其重要性。798年，伊琳娜皇后邀请狄奥多若接管斯图迪奥斯修道院。他以该院为中心的改革，常被看作试图恢复四世纪大圣巴西尔所确立的修道传统。这无疑是其灵感之一：与巴西尔一样，狄奥多若重视共住修道，不鼓励独居；巴西尔《禁欲集》的一个修订本，也出自斯图迪奥斯。但狄奥多若还从其他地方汲取灵感。他与巴西尔不同，极其重视由修士选出的院长，认为院长应是他们的属灵父亲。这显示帕科米乌斯的影响，也让人想到圣本笃。院长应通过定期教导修士——狄奥多若的许多这类教导仍存——以及 exagoreusis，即“袒露心思”，履行属灵父亲的职责。在这一做法中，每个修士向院长敞开心灵，坦陈自己的思想，不仅是罪，并领受指导与赦免。加沙沙漠的禁欲者巴尔萨努菲乌斯、约翰、多若狄乌斯，以及西奈的约翰，也影响了狄奥多若的修道理想。他引入的斯图迪奥斯修道原则，还包括修道院不得拥有奴隶，必须释放他们；禁止饲养雌性家畜；切实强调<a id="pdf-090"></a><!-- PDF page 90; original page 61 -->贫穷和手工劳动；以及提倡学问，抄写教父手稿和礼仪文本。斯图迪奥斯诸修院遵循的礼仪祈祷次序，到六世纪就已确立：夜间直到黎明有午夜祷、晨祷（orthros）与赞美经；白天在第一、第三、第六、第九时辰举行礼拜；日落举行晚祷，之后是寝前祷。不过，大概在狄奥多若生前，斯图迪奥斯日课就采用了七世纪末以来巴勒斯坦的做法，以礼仪诗句补充修道日课，尤其卡农颂：一组配合晨祷中《旧约》颂歌而唱的诗节。

特别在十世纪，修道创设得到皇帝支持，尤其尼基弗鲁斯二世·福卡斯（963—969年）和约翰一世·齐米斯基斯（969—976年）的支持。帖撒罗尼迦以北伸入爱琴海的半岛，其上新建的修道院尤其如此。人们以部分代整体，称这半岛为“阿索斯山”。最早的一座是大劳拉，964年，阿索斯的圣亚他那修在尼基弗鲁斯·福卡斯皇帝支持下创立。阿索斯山的修道团体逐渐获得独特的属灵权威，延续至今。

十、十一世纪，整个拜占庭世界涌现大量新的修道团体。斯图迪奥斯改革影响很大，却非独占地位。另有一些创办者，以自己的方式利用丰富的拜占庭修道传统，包括里拉的约翰（约876—946年）、“宣讲悔改者”尼孔（约930—约1000年），[^p090-16] 加莱修斯山的拉撒路（约981—1053年），[^p090-17] 以及帕特摩斯的赫里斯托杜洛斯（1093年卒）。新神学家圣西缅（约949—1022年）的经历横跨千年之交。他深刻的禁欲与神秘神学，以及与牧首权威的冲突，体现了制度权威与修士感召力之间潜在的紧张；也表明修士与同时代社会联系的一种方式：提供属灵指导。

### 礼仪、艺术与虔敬

843年宣告“正教的凯旋”，标志圣像破坏失败，最终深刻改变了宗教艺术在拜占庭的地位，并进一步影响不久将接受拜占庭基督教的斯拉夫国家。最初，这种影响缓慢显现，无疑是因为<a id="pdf-091"></a><!-- PDF page 91; original page 62 -->人们担心激起圣像破坏派的反扑。但最终，拜占庭教堂中取代圣像的十字架被移除，重新安置圣像。867年圣周六，圣索菲亚教堂半圆后殿内，上帝之母圣像取代圣像破坏时期的十字架，举行奉献仪式。牧首佛提乌斯宣告：

> 她把色彩的芳华与宗教真理相融合，借着两者，以神圣的方式为自己塑成神圣之美，并且可以说，承载着一幅完整而完美的虔敬图像。人们看见，她不只以美丽胜过世人，更以不可言喻的尊严之美，超越其他一切比较。[^p091-18]

如今，在拜占庭教堂使用艺术，成为必须，而非可有可无的装饰。逐渐地，一套相当固定的艺术装饰模式形成了。不过，其基础早已由礼仪解释铺垫：对礼仪仪式，特别圣餐神圣礼仪，以及举行礼仪的教会空间的解释，可以追溯到四世纪。这种解释在托名亚略巴古的狄奥尼修的作品中进一步发展，他的全部神学都有礼仪处境；但对整个拜占庭时期特别有影响的，是认信者马克西穆斯的《秘仪释义》（Mystagogia），[^p091-19] 以及君士坦丁堡牧首日耳曼努斯（715—730年）那部题名奇特的《教会史与奥秘观照》。后一题目或许可以译作“教堂里发生的事及其隐秘意义”。[^p091-20] 这些解释的基础，是教堂分成圣所与中殿两部分，由 templon，即圣所屏障分隔。它包括低栏与一道门，后来又加上柱子和横梁；现代正教教堂特有的实体圣像屏，是中世纪后期的发展。这样分开的教堂，象征天与地，因此教堂建筑本身象征整个宇宙；教堂是小宇宙，人也是如此。圣像破坏结束后，通常呈十字形、中殿上覆穹顶的教堂，其装饰由这种基本认识决定。穹顶上描绘统治宇宙的全能者基督，即 Pantocrator；光线透过穹顶底部小窗进入，再向上反射，照亮他的形象。教堂其余部分，逐渐以壁画或马赛克圣像装饰，描绘《旧约》《新约》圣徒、天使，以及救恩历史的场景，特别基督和童贞女的<a id="pdf-092"></a><!-- PDF page 92; original page 63 -->生平。于是，宇宙中满是人物，或者更确切地说，宇宙由人物构成。这承接了一种早已稳固的基督教传统：用活的生命理解宇宙，而非用异教古代的天体。[^p092-21] 圣像也用于私人虔敬，从而把教堂装饰表达的宇宙维度，带入私人领域。

### 异端[^p092-22]

大公会议所界定的拜占庭正教，在关于上帝本性与道成肉身的各种异端之间，代表一条中道。圣像破坏失败后，这类异端大多不再困扰拜占庭人。取而代之的，是一些被称为二元论的异端：它们认为，宇宙并非一位至善上帝的创造，而是同样具有终极地位的善恶力量冲突的产物。这些异端被称为保罗派（Paulicians）和波格米尔派（Bogomils）。保罗派被追溯到七世纪末一位亚美尼亚人，马纳纳利斯的君士坦丁；不过，他们的名称，很可能来自八世纪初在亚美尼亚重新创立该派的某位保罗。波格米尔派出现较晚，得名于十世纪保加利亚一位名叫波格米尔的司祭，其名为狄奥斐鲁斯的斯拉夫语形式。关于他们的信仰，我们依赖正教对手的反驳，尤其九世纪西西里的彼得反保罗派的著作；十世纪某位科斯马斯讨论波格米尔派的讲道；以及十二世纪初欧西米乌斯·齐加贝努斯的《教义全副武装》。这很不理想，因为这些正教作者都把他们看成某种摩尼教徒，并据此呈现其信仰。然而可以确定，这些拜占庭异端，与遭查士丁尼迫害后转向东方发展的摩尼教徒，没有历史联系。像很可能受波格米尔派启发、十二世纪中叶在西方出现的二元论异端卡特里派（Cathars）一样，这些“异端”的根源，或许在于反抗制度化教会、追求福音的纯洁。保罗派信仰的核心，是相信作为属灵存在的耶稣基督。他们拒绝《旧约》，以《新约》或其大部分为依据；拒绝圣事、十字架敬礼、圣徒崇敬与圣像，而专注于一位属灵的基督。很容易理解，在一位正教<a id="pdf-093"></a><!-- PDF page 93; original page 64 -->对手看来，这种拒绝物质的态度，何以具有摩尼教二元论的味道。据说，他们由一位被视为使徒的最高教师，即 didaskalos 领导，这只会加强人们把他们当作摩尼教徒的看法。波格米尔派也许有更发达的二元论教导。他们的主要威胁，似乎来自那种使徒式简朴生活的吸引力，促使别人前去寻求他们的属灵指导。

## 结论

这一时期形成的“拜占庭正教”，根源十分古老，其性质也充满两面性。因为，这种正教成为并被确立为帝国政策，而拜占庭国家至少在抱负上，是专制的。它几乎不容忍质疑正教的人；事实上，基督教异端的权利，比犹太人更少。犹太人作为他们所拒绝信仰之真理的“常在见证”，尚有一点有限保护。然而，在本章时段的前半期，皇帝及其顾问所采纳为正教的神学立场——一能论、一志论，最后是圣像破坏——最终都被当作异端拒绝。843年宣告“正教的凯旋”，意在为那段时期蒙上一层帷幕，清楚表明“拜占庭正教”的性质。《正教会议宣言》使这一宣告成为每年的礼仪事件，后来又变成科穆宁与巴列奥略诸皇帝所宣称的正教的政治宣言。然而，后来所谓“拜占庭正教”，并非在首都锻造，而是在边缘形成：在拜占庭帝国边界，或边界以外的地区。不过，只有当马克西穆斯、阿纳斯塔修、约翰及其他这些神学家，被拜占庭传统接受，他们才留下影响；而拜占庭传统，则越来越由君士坦丁堡发生的事界定。这种对多样性的压制，是一整套视野的一部分，无疑代表着贫乏化：乡间与首都以外城市的声音被淹没，质疑拜占庭正教的声音也被淹没。但它被确立为传统，又使人得以探索希腊东方基督教反思积累的丰厚资源，留下至今仍值得关注的遗产。
