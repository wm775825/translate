# 第18章 出生与死亡

弗雷德里克·S. 帕克斯顿（Frederick S. Paxton）

<a id="pdf-412"></a><!-- PDF page 412; original page 383 -->

面对出生、死亡，中世纪早期基督徒，主要依靠文化的两个根本特点：出生、死亡、复活，在信仰中的核心地位；家族在思想视野、社会组织中的重要性。这一时期，多数基督徒，逐渐把新生儿洗礼，视为进入教会、亲族、基督教社会的必要、正常入门。同时，礼仪专家，把古代较简单的葬礼、追念，扩为充分细化的过渡礼，协助从生者共同体，走向已故信徒共同体的每一步：为死亡本身，准备身、魂；妥当处置遗骸；监督灵魂，成功进入有福者行列。新旧信徒，也放弃多种古老程度不一的葬俗，几乎普遍采用，在定居区核心教堂内外，简单安葬。由此，生者、死者，成为同一共同体成员，在时空统一。总体上，从洗礼开始，为基督徒准备死亡、照管来世福祉的事务，催生非凡的精神、世俗交换体系：以赠与为基础，由人、祈祷、财产流通推动的救赎经济，是时代最显著特点之一。[^p412-1]

拉丁西方，政治、制度分散，使救赎经济，呈现最多样表达。东方教会，部分因更接近帝国晚期基督教传统，部分因在内外直接面对伊斯兰，保持较保守。东方基督徒，从未采用某些西方发展出的仪式，<a id="pdf-413"></a><!-- PDF page 413; original page 384 -->如专为临终者傅油。不过，所有基督徒都信，生者能够、也应该，借以死者之名施舍、诵诗篇、献弥撒，为其带来安息、慰藉，求罪获赦，减轻来世痛苦。因此，生者投入大量资源，照顾死者，最常以捐产给教会机构，尤其修道团体的形式；其“自愿”贫穷，使之有资格受施舍，又代生者、死者，照管真正贫者。[^p413-2] 努力的成效，通过来世异象传播，向生者显露亡者苦难；也通过死者显现，求生者帮助，或感谢以其名义的祈祷、施舍。[^p413-3] 但此世发生的事，同样重要，而且历史学家更易接触：救赎经济，也在个人、家族、教会机构间，产生全新关系类别。基督徒生平，从洗礼象征的死亡、重生，经身体死亡，至最终复活。途中，人们抓住一切机会，建关系网，既反映、又塑造，对新生的许诺、死亡的恐惧、复活的希望的回应。

证据，大多来自教会人员记录，修士、教士，较少修女、女咏祷教士，以及帮助传播信仰的少数贵族、王室平信徒男女。视角虽有限，尤其经考古检验、扩充后，仍充分证明，神学、礼仪、法律、习惯，如何影响、或未影响，基督教世界的出生、死亡经验。不过，调查这些问题的社会、宗教史，较新，各地研究程度不同。拉丁基督教，远多于希腊，更不用说其他东方、非洲教会。最完整研究，在盎格鲁—撒克逊英格兰，其基督教历史，几乎正吻合本卷年代。因此，要尝试涵盖全部地方变体，仍有许多工作。“救赎经济”概念，也非要界定所有<a id="pdf-414"></a><!-- PDF page 414; original page 385 -->中世纪早期基督徒，对出生、死亡的全部宗教回应，只想在足够宽广、涵盖现有知识，又为未知差异、共同性留余地的框架，指出时期某些特征。另一框架，是地理、年代、基督教化程度，此处密切相关。600年，基督教主要仍限旧帝国边界。此后，从罗马、君士坦丁堡，也从爱尔兰、萨克森、基辅罗斯等区域中心，向新人群传播。1100年，已达欧洲西、北、东边缘，开始回流，进入穆斯林统治数百年的旧基督教领土。中世纪早期基督教成熟，其特殊救赎经济，也随之成熟。

欧洲基督教化，是根本历史过程之一，却没有让基督教自身不变。帝国晚期基督教，已是高度协商的产物；七至十一世纪宗教实践，常混合地方传统、官方规范观念。出生、死亡，像婚姻一样，对家庭影响众多，尤其如此。它们向来是家族事务，因为家族，尤其强大家族，总想按明确世系，传递财产、权力。但这也适用于闭居男女宗教团体，实际上构成精神家族，常既是基督教化最成功的代理人，也是最普遍的产物。更复杂的是，个别司祭、修士、修女、女咏祷教士参加宗教生活，也深刻影响血亲；血亲常是其终身所在团体的创办人，又始终是施主。最后，妇女向来在出生、死亡中作用巨大，男人又控制宗教生活，基督教化，不可避免沿性别线，产生紧张。

因此，用于标记、圣化生命开始、结束的独特实践，并非简单强加，而是数百年间，等级体系内外男女，常仔细协商。往来让步，使出生、死亡的基督教化，格外动态，相互强化平信徒、宗教家族（familiae）的地位、影响。因此，即使最充分基督教化的回应，仍尤其<a id="pdf-415"></a><!-- PDF page 415; original page 386 -->代表经历者的个人、社会承诺。例如，婴儿洗礼成为应然规范，同时嵌入父母权力、家族利益结构。死亡、安葬、追念，充分基督教化，同时让家庭，尤其富裕强大家庭，显著控制自身在救赎经济的位置。男性教士、修士，虽管理体系，女性仍处关键：教育孩子，创立修道院，担任女院长、修女、女咏祷教士；某些时地，更主要监督礼仪追念，即构成整个体系枢纽的，正式宗教性亡者纪念。[^p415-4]

### 出生、死亡与属灵亲缘

希腊—罗马一些医学作者，虽讨论受孕、妊娠、分娩，古代医生在分娩时，通常把事情，交给产妇、接生婆、女性亲属。[^p415-5] 基督教发展后，教会人士，也这样做；即使中世纪后期，男医生首次争取产床旁的位置，情形也从未真正改变。[^p415-6] 出生本身基督教化，最显著标志，是圣徒、象征，进入促进受孕、保护产前、产中、产后母婴的常见咒语、护符、祈求。例如，古代分娩带、腰带，通过与耶稣之母马利亚相联，基督教化。[^p415-7] 但耶稣诞生、敬奉其母的重要，无法克服男性教士，对亲密接触妇女的矛盾；教士“男性化”，使其不易进入这一根本女性领域。因此，分娩仍是家庭、女性事件，基督教司祭，既不在场，也不为其举行仪式。

司祭与分娩保持距离，意味着妇女、接生婆、家人，惯常在教士视野之外，决定堕胎，以及<a id="pdf-416"></a><!-- PDF page 416; original page 387 -->新生儿能否存活的问题。[^p416-8] 接生婆可能受托，判断新生儿是否健康；若否，终止其生命。至少西方，明确准许她们，为即将死亡的婴儿施洗。健康婴儿之母，通常首先通过禁止产后立即参加教会礼拜，感受信仰影响。东西方，都让产妇，长达40天不得参加，以提醒分娩本质不洁，沾染血、罪。[^p416-9] 母婴脱去生产的仪式不洁后，便可、也日益参加洗礼。原为死亡、重生仪式，洗礼只缓慢与生命开端相联。[^p416-10] 即使四世纪末，也远更可能在临终，而非健康婴儿出生后施行，因为通常只有经过漫长慕道准备、学习者，才受洗。但600年，婴儿洗礼，已成全基督教世界接受的规范，中世纪早期，又传给新改宗民族。[^p416-11] 这也许并不顺利。盎格鲁—撒克逊墓葬证据暗示，为濒死婴儿施洗，可能强化对婴儿鬼魂恶意的旧恐惧，甚至使一些人，不给健康婴儿施洗，至少基督教化早期如此。[^p416-12] 即使后来，许多孩子，也必因洗礼教堂遥远、父母不在意，长时间未受洗。不过，到十二世纪，英格兰、别处，一般惯例，已是出生后尽快受洗，无论是否濒死。[^p416-13]

洗礼，尤其伴随坚振、圣膏傅油后，使受领者，成为日益基督教化社会中，一个基督教家庭成员。东方，孩子直到受洗，才获得完整个人身份；这种态度，在希腊乡村，仅以“那个男孩”“那个女孩”，称未受洗孩子的习惯中，仍延续。[^p416-14] 仪式创造人格的力量，在西方，也许感受<a id="pdf-417"></a><!-- PDF page 417; original page 388 -->没那么强；本期家庭，一直按祖先，而非圣徒给孩子命名。但毫无疑问，中世纪早期，各地洗礼，都成社会、宗教身份基础。[^p417-15] 例如，九世纪初，查理曼洗礼改革，强调新受洗者，不只是教会忠信者，也是领主的fidelis，同一个词，也指“附庸”。[^p417-16] 大量现存九世纪文书，为堂区教士说明正确洗礼程序、信仰基础教导，雄辩证明加洛林改革者，认真想触及尽可能多普通基督徒。[^p417-17] 成功奠定西欧基督教化最后阶段，以及宗教理解、社会实践深刻交融的基础；这种交融，是救赎经济核心，十、十一世纪表现最充分。

婴孩不能自己说话，须由他人代言。最初由父母，但六世纪以后，越来越由其他成人，八世纪，拉丁、希腊教会都明确禁止父母，担任婴儿洗礼保证人。[^p417-18] 过程中，保证关系，成为教父母制度。新社会现象的典型形式，六至十世纪形成，1100年完全成熟，创造多重关系：孩子与教父母、施洗教士，教子女与教父母亲生子女，亲生父母与孩子教父母。这些复杂纽带，在重叠个人、群体网络中，为人身关系神圣化，留下巨大空间，也能影响关系，界定谁可婚、谁不可，谁可信，谁监督基督教家庭、社会新成员成长。各方都获益：孩子获得核心家庭之外，潜在代言人、保护者；父母、教会人士，在控制、约束孩子方面，互获支持；家庭得以选择，<a id="pdf-418"></a><!-- PDF page 418; original page 389 -->照看孩子的男女；教会，则让更多人，接受洗礼作为个人、社会、宗教身份，绝对正常的特征。[^p418-19] 家族力量，也由教会无法控制保证人增多，得到证明，西方尤其如此。教会认为一位足够，家庭却不满足；例如，这促使拉丁教会，把坚振、洗礼分开，让家庭另有机会，通过新保证人，扩大属灵亲族。[^p418-20]

教会人士虽立法反杀婴，却接受弃婴，是近于生存线社会的一部分，尤其把孩子留在教堂、修院门口，而非简单暴露荒野。[^p418-21] 这些孩子，通常被养作仆人，救赎经济中，作用至多很小。正式交予宗教团体、奉献入院的儿童，作用大得多。童年奉献制度，六至十一世纪稳定增长，后者达到顶峰。像洗礼保证、教父母关系，把孩子作为奉献（oblatio）交教堂、修院，在亲生、属灵家庭间，缔结互惠关系。孩子本身就是礼物，承诺终身服务新家庭；伴随入院的其他礼物，也帮助供养团体。同时，修院给他们闲暇，以终身祈祷，服务亲生家庭的生者、死者。[^p418-22] 关系如此珍贵，最富裕家族，几乎总为自家修院（Familienklöster）捐产，可在那里安葬，团体专为其今生、来世福祉服务。国王、皇帝，也把老修道院，纳入王室、帝国领域，增加照管灵魂的男女。其他人，则通过献子、赠产现有贵族或王室修院，参与其中。这些团体，是救赎经济的清算中心，记录生者礼物、义务，照管此世信仰行为，为死者带来慰藉。

### 以基督徒的方式死亡

基督教兴起的世界，死亡像分娩，是私人、家庭事务，医生、宗教人员，都不参与。病况无望，医生通常退出；男女祭司服务神，而非普通人。很长时间，基督教教士也一样，让普通人，继续那些容易带入新信仰的习俗。亲人可能给最后一吻，或尝试接住临终者最后一口气。死后，生者合其眼、口，清洗尸体，以香油、药草涂抹，裹尸布，或穿适合社会地位的衣服。队伍伴遗体到城外墓地，教士在则诵诗篇；通常安于有容纳死者建筑的家族墓区。丧亲者，像前基督教祖先，在死后第三、第九、第四十日及周年追念，常在墓旁宴饮。[^p419-23]

直到四世纪末、五世纪，才开始改变。教会人士讲道，反对以奢侈墓宴，展示财富、权力，敦促把给死者的食物、酒饮，转施穷人。[^p419-24] 也反对自残式悲痛、过度哀号，希腊教父金口约翰，称为“女人的疾病”。[^p419-25] 米兰的安布罗斯，劝受洗者欢喜期待死亡，因为意味着罪的结束；稍年轻的同时代人，如希波的奥古斯丁，却不同意。洗礼不保证救赎，只有上帝能保证；正确回应，应是恐惧，面对人有罪、上帝审判。这要求教士牧灵回应，形式是最后领圣餐，作为旅途食粮（viaticum）；325年第一次尼西亚大公会议，原授悔罪者，五、六世纪，扩至所有基督徒。[^p419-26]

600年形成的死亡仪式，在希腊正教传统，持续至今，包括最后圣餐，以及为临终者诵念祈祷，强调所有基督徒，<a id="pdf-420"></a><!-- PDF page 420; original page 391 -->共同必死，在罪意识、悔罪需要，与圣餐礼庆祝精神间，取得平衡。[^p420-27] 西方众多王国、地方教会，促进一系列死亡、临终礼仪创新。七世纪，西班牙西哥特教会，发展复杂临终悔罪礼，身魂转化如此彻底，以致若康复，须终身退居修院。爱尔兰，摩西传统的仪式洁净，深刻影响教士；司祭把高卢病人傅油礼，变成死亡准备，为十二世纪临终傅油圣事，奠基。法兰克高卢、盎格鲁—撒克逊英格兰，大格列高利《对话录》流行，其中弥撒减轻亡信徒苦难的故事，促成为亡者特献的祈愿弥撒，创制、普及。[^p420-28] 七、八世纪，爱尔兰、盎格鲁—撒克逊传教士，开始彼此、并与故乡修道团体，约定死后特定次数的祈祷、诗篇、弥撒。约800年，加洛林礼仪书开始收入临终痛苦礼，可能源自东方修道传统，在灵魂最“危险时刻”，诵诗篇驱邪。[^p420-29] 为助最后斗争、拒魔鬼，团体吟诵天堂居民名号，有节奏呼求三位一体、马利亚、天使、先知、列祖、殉道者、认信者，以及所有在世圣洁男女，织起祈祷歌网，协助灵魂离去。

八世纪后期、九世纪，加洛林国王、皇帝改革教会、社会，促成各发展综合。[^p420-30] 改革言辞偏爱罗马传统，成功让弥撒，以及圣咏等某些教士、修道文化要素，符合真实、或想象的罗马实践。但死亡方面，罗马只提供综合的一块，虽重要：一套源于帝国晚期凯旋基督教的古罗马死亡礼。它不称临终圣餐为旅途食粮，而称<a id="pdf-421"></a><!-- PDF page 421; original page 392 -->“义人复活时的捍卫者、代言人”；饼酒，不是灵魂赴来世的食粮，而是属于得救共同体的标记，最后审判时呈验。[^p421-31] 历史虽模糊，长期延续，证明奥古斯丁立场，并未抹掉拉丁西方，早期死亡乐观的一切痕迹。凯旋诗篇、救赎神学，想必在一个由强大虔诚者支持的教会，激起共鸣；这些人，自视以色列诸王、古代基督教皇帝的继承人。纳入综合后，拉丁仪式，获得部分东方同样的平衡、复杂，让审判恐惧，不压倒赦免希望。

加洛林改革者，反对为临终者傅油，认为无经文根据；但九、十世纪，常经爱尔兰文本、传统，仍普遍使用。他们希望，以共同仪式建共同体，但共同体塑造仪式，与仪式塑造共同体同样多。活动所成综合，不只反映官方立场，也反映流进、流出广阔王国的无数地方传统。九世纪末，临终礼形成，把帝国基督教凯旋诗篇，与中世纪早期悔罪、净化关切，混成共同传统，又包括悔罪、赦罪、傅油、领圣餐；每项，都切断与此世联系，以礼仪准备进入天堂。

### 生者与死者的共同体

思考、或亲历死亡，无论多难，基督徒不断创造新方式，与死者建立、维持共同体。最重要，是圣徒、这些“极特殊死者”的崇敬；他们是自然、属灵个人及家庭，强大且有力临在的保护人。圣髑完整，不腐败，以及治病能力，既证明复活，也强力抵消面对死亡、解体的恐惧。[^p421-32] 圣徒崇敬<a id="pdf-422"></a><!-- PDF page 422; original page 393 -->兴起，比任何因素更促成，生者城市、城外死者墓地的古老界限，最初瓦解。一方面，圣龛吸引礼拜，最终吸引人定居墓地；聚落又常成新城市核心，卢瓦尔河畔图尔，清楚可见。[^p422-33] 另一方面，先圣髑，后想葬其近旁者的身体，死者开始进入城墙；起源可追溯君士坦提乌斯皇帝，357年把使徒路加、安得烈圣髑，带入君士坦丁堡，以及米兰的安布罗斯主教，393—394年把博洛尼亚殉道者圣髑带入城内，又分赠鲁昂主教维克特里修斯。[^p422-34] 600年后，主教经常葬在所服务主教座堂。[^p422-35] 新基督教化、主要乡村的北方，圣髑吸引死者，进入新堂区体系的教堂、庭院墓地。到1100年大体完成，过程与古代彻底断裂，重组基督教世界景观。

生死汇聚，与其出于设计，不如偶然；禁止城内葬人的旧法，数百年仍在册，各地发展不同。例如，君士坦丁堡，君士坦丁城墙外墓地，一世纪后，被狄奥多西二世新墙圈入。死者仍不得进旧城核心，却安居西面新旧墙间。东方别处，旧模式延续，但查士丁尼瘟疫、600年后斯拉夫人到来，引发人口收缩，让科林斯、雅典、萨尔迪斯等城，把死者葬在城中心。[^p422-36] 西方，界限处处倒下；盎格鲁—撒克逊英格兰记录最佳。七世纪萨顿胡宏伟、费解的墓葬，可能实际回应基督教扩张：“亲斯堪的纳维亚、反基督教”国王，把增加税收、控制贸易所获财富，投入精美随葬品、葬礼，抵消新信仰影响。[^p422-37]

<a id="pdf-423"></a>
<!-- PDF page 423; original page 394 -->

八世纪，英格兰异教葬停止，基督徒死者，开始集中教堂周围，简单墓穴，无随葬品。九世纪、十世纪后期，异教维京人到来，只带来暂时、地方性的其他葬法复归，因为新人群很快，被基督教社会吸收。[^p423-38] 如别处，英格兰基督教化完成，几乎正与城乡，普遍在教堂内外安葬一致。[^p423-39]

不过，基督教社会空间，只包括生者，以及与共同体保持良好关系而死者。东西方，安葬按道德尺度布置，最圣洁死者居中，其他按各自圣洁资格，环绕排列：圣徒、主教、院长、修士、虔诚而富有的平信徒男女。[^p423-40] 加洛林人，试图禁止教堂内葬，自己又刻意选低微安息处，远离祭坛、圣髑，却少成功。[^p423-41] 大体上，死亡经济，再造生者社会等级。自杀者、杀人者、绝罚者、异端等关系不良者，被安置未祝圣土地，远离生死基督徒。例如，盎格鲁—撒克逊墓地研究，揭出堂区边界，广有刑场、墓地，常与古坟丘相联。这些未获共同体接纳的死者，被留给那些被认为盘踞前基督教亡者空间的恶魔、龙。[^p423-42]

### 记住与遗忘死者

安葬后，注意力转向纳入仪式，尤其引导灵魂，进入有福死者共同体的追念。古代死后第三、第九、第四十日纪念，在所有东方教会，持续至今。第三日，因复活象征，西方也延续；拉丁教士，却把第九日与前基督教罗马习俗相联，因此改第七日，纪念安息日。

<a id="pdf-424"></a>
<!-- PDF page 424; original page 395 -->

亚里士多德教导，男性胚胎40日后获灵魂；希腊传统认为，尸体肉身分解，也需40日。因此，死后第四十日追念，植根于一种从子宫开始、在坟墓结束的生命观。[^p424-43] 拉丁教士，却改为第三十日。变化首次获推荐，在大格列高利《对话录》：他提出死后连续七日、30日献弥撒，称septinarius、tricenarius，成为修道追念典型特征。[^p424-44] 不过，40日，在拉丁教会仍以大斋期保留，对应古代为复活节洗礼，正式准备的时段；也见于产妇返教堂前等待40日。因此，即使西方，生命始末联系，仍持续。

760至762年，一群教会人士在加洛林王室的阿蒂尼庄园正式承诺，死后相互追念。不久，修道团体开始与其他修院订立类似约定，也让平信徒男女在临终时发愿，死于修道院病室、葬于共同墓地。参与者的姓名被记入名册，到十二世纪，名册最多可有40000条。[^p424-45] 为亡者诵读诗篇和举行弥撒，再加上对穷人的施舍，使救恩经纶的最后一块拼图归位。闭居的男女自身已“对世界死去”，同时又与由生者及死者组成的施主网络相联，在其中促成交换。他们接受给穷人的馈赠，自身也被包括在穷人之中，回报则是为捐赠者及其亡亲的灵魂祈祷；这些人在属灵意义上已被纳入修道及教会家族。面对死亡时，驱动他们的焦虑可能与信心同样强烈；但无论动机如何，他们的行动都像圣徒的行动一样，帮助联结起生者与死者的共同体。

但基督教追念的终极目标，不是记住，而实际是遗忘死者，让其安息，让生者继续。救赎经济全部要素，都朝此目标：“帮助生者与死者分离，缩短后者在净罪惩罚中的停留……最终让<a id="pdf-425"></a><!-- PDF page 425; original page 396 -->生者能够遗忘亡者”。[^p425-46] 过程中，家族围绕亡者记忆，形成、重组，尤其十、十一世纪，快速社会变化，让新家族进入拉丁基督教世界前列；其追念，代表自身历史、未来意识。[^p425-47] 此外，妇女常在维护家族纪念中，扮重要角色。德意志尤其如此：谁记住、祈祷，甚至为谁、向谁祈祷的控制，直到本期末，主要仍是家族、甚至女性事务。[^p425-48]

十、十一世纪修道改革运动，接纳救赎经济，在勃艮第克吕尼，达到最发达形式；它处于可能是基督教世界，有史以来最密集的生死关系网震中。比任何教会，克吕尼接纳最多奉献儿童、最多施主礼物，安葬、追念最多修士、平信徒。[^p425-49] 奥迪洛院长（994—1049年）时，尤其如此；他又设诸灵节，把祈祷益处，扩及各地所有基督徒，并使高度发展的临终、安葬、追念形式成熟。[^p425-50] 十一世纪末，修士几乎不断为亡者礼拜，以其名义，供养衣食、照顾成千上万人。

不过，救赎经济达高峰，一些核心特征，也开始遭反对。首先保加利亚，十世纪末，追随波格米尔司祭的宗教异议者，除其他外，拒绝洗礼，尤其婴儿洗礼、司祭权威、圣髑崇敬。[^p425-51] 西方1000年后，也有声音反婴洗、什一税、圣髑，以及基督教安葬、为亡者祈祷的效力。[^p425-52] 所有情况下，主张者都被称异端。甚至本笃修道传统内部，潮流也转变。熙笃会<a id="pdf-426"></a><!-- PDF page 426; original page 397 -->虽不拒绝克吕尼全部特征，却想摆脱旧本笃会与贵族的纽带，以及挤掉私人祈祷、默观的漫长追念礼；这种意向，极具吸引，削弱旧体系。十二世纪初，可敬者彼得院长，须捍卫克吕尼方式，不只对抗熙笃会，也对抗洛桑的亨利、布吕伊的彼得等激进异议者。他们拒婴洗、整个救赎经济，主张生者，不能为死者做任何事。[^p426-53]

基督教世界领袖，虽希望所有人，自觉通过洗礼相联，以基督教术语理解临终、死亡、死者，但六至十二世纪这五百年，他们只缓慢、且仅在满足家庭需要时，才把这些最亲密家族事务，纳入影响。早期赠与经济，让位于利润经济，托钵修士等新专家，以及照顾亡者的新约定方式，出现。[^p426-54] 其中，颁授大赦，最终助燃新教宗教改革，拆解大部分救赎经济。不过，早期产物，重大、持久。信徒以基督教方式理解出生、死亡、死者，程度必大不相同，却没有有力替代。在出生时，没有用教士取代接生婆，洗礼却在深度、虽从未完全基督教化的文化中，成为不只宗教、也社会身份必需。教父母关系，成为基本制度，建立孩子、教父教母，以及各自家族终身联系。其他关系，与闭居男女、其服务圣徒的关系，即使奉献儿童实践衰退，仍居文化中心。十二世纪，几乎任何意义上的普通基督徒，都为新生儿求洗礼，临终求告解、其他圣事，死后求安葬祝圣土地、宗教专家礼仪追念。各地基督徒死者，与生者共享空间；生者视<a id="pdf-427"></a><!-- PDF page 427; original page 398 -->死者，仍为家庭、共同体成员，期待关心、帮助。改革者质疑某些特征，其他人全盘拒绝许多，但中世纪基督教出生、死亡文化，大体已建立。最有力证据，是1100年时，抵抗任何要素，从婴洗到为亡者祈祷，都被同时视为异端、现行社会秩序叛逆。
