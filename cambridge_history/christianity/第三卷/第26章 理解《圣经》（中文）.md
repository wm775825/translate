# 第26章 理解《圣经》

居伊·洛布里雄（Guy Lobrichon）

<a id="pdf-559"></a><!-- PDF page 559; original page 531 -->

作为查理曼的顾问，阿尔昆（卒于804年）认为，自己能向主人介绍修辞学与道德哲学的一切精微。在著名的《论修辞与美德的对话》中，他安排自己与这位未来的法兰克皇帝交谈。他谨慎地让主顾提出恰当问题，以显其贤明；作为教师，自己则调动所教授的古典拉丁修辞艺术的全部资源，作出回答，更好地说服这位王家听众。修辞学家从异教古代汲取证明所需的例子，阿尔昆却展示圣经例证。[^p559-1] 用意很清楚：《论修辞对话》中的朝臣，不仅讨好一位志在文事的国王，也借此热情宣告古典学问在法兰克诸国的持久价值、基督教文学的胜利，以及《圣经》高于文学史上一切其他杰作的绝对首位。

当然，这只是宣传。但《对话》究竟真为查理曼而写，还是专供学校使用的虚构，并不太重要。短短几行，它便动摇了通常接受的两个观念：阿尔昆曾编定一部《圣经》——我们的教师竟“忘记”引用自己版本的《创世记》！——以及教士圈外普遍不懂圣经。只需提及<a id="pdf-560"></a><!-- PDF page 560; original page 532 -->该隐与亚伯、亚希多弗、户筛、帖土罗和腓力斯这些人物，虽然教师会口头展开，就足以使听众理解故事。但阿尔昆没有止步于此。他还确认《圣经》作为文学作品的地位，传统“自由学艺”技术可以照常应用于它；也许还邀请听众认识到，《圣经》可为高等学习提供资源。总之，他迫使现代读者重新评价查理曼时代知识的连贯性。他从《创世记》《撒母耳记下》《使徒行传》取三个例子，使修辞学三类型的分析分类，对应律法之前、律法之下、恩典之下三个时代的历史次序。换言之，他构造了世俗科学和圣经智慧的演进图式，直接通向历史在基督教中的完成。

若接受对阿尔昆的这一解读，《圣经》及其释义，就不再能被局限于观念世界和高深神学争论。我们知道，《圣经》有自己的历史，其释义也随历史涨落而改变；因此，它值得史家重新关注，近来已有一些学者尝试重新确立其历史地位。[^p560-2] 在基督教中世纪早期，理解《圣经》不只是从课堂到教堂中殿，或在属灵交谈中，向愿意倾听者教学、解释；也意味着使《圣经》成为群体乃至整个社会身份的参照点，实际上把它确立为奠定生活基础及规范的书。解释圣经，就像戴上圣经的眼镜，使人类历史正确聚焦。以下简要概览一段复杂历史：文本及其传递的历史、读者与听众的历史，也是人们适应并吸收神圣经书的历史；后者仍是西方历史最鲜明的特征之一。本章将说明，中世纪早期基督徒社会如何为自身利益，进一步肥沃圣经使用与解释这片本已丰饶的土壤；也说明基督教化后的西欧社会，如何摆脱拜占庭诠释传统，颇为费力地形成解释艺术的共识，并以自身方式促成1000年起欧洲的分化。

### 犹太人与基督徒的共同遗产

《圣经》把犹太人与基督徒的神圣经书，汇成一部巨大文集；最初几个世纪便以 bibliotheca、scriptura sacra、scriptura divina 等词称之。拉克坦提乌斯（约卒于320年）和维罗纳的芝诺（约卒于375年），是最早写到 historia sacra，即神圣历史的人。[^p561-3] 他们把《圣经》理解为历史序列，类似同时代凯撒里亚的优西比乌（约卒于340年）通过创造普世世界史文类，而赋予关键特征的历史序列。自六世纪起，人们承认《圣经》属于东方帝国与欧洲西方基督教王国的共同遗产。随着基督教世界边界扩大，抄本流通数量也不断增加。它的传播满足多重需要：教堂的需要——君士坦丁一世曾命凯撒里亚的优西比乌制作约五十部《圣经》，配给君士坦丁堡教堂；[^p561-4] 基督教教师的需要——卡西奥多鲁斯（卒于580年）把圣经研究纳入文学学习；最后，还有兼具属灵关切与明显奢华品味的富裕贵族的需要。圣耶柔米对藏书爱好者过度奢侈的斥责，证明罗马精英热衷这些珍贵书籍。自五世纪起，他们获得《列王纪》等书的抄本，例如奎德林堡的古拉丁译本残卷，[^p561-5] 更常见的是福音书，如包含《路加福音》《马可福音》的《维也纳抄本》。[^p561-6] 四、五世纪起，《圣经》开始进入权贵家庭，又迅速扩散至基督徒和犹太人中越来越广泛的社会群体。神圣经书承担许多角色：礼仪崇敬与展示的物品；有时是被认为具有辟邪能力的护符，如七世纪《科伦巴的战书》（Cathach）诗篇抄本；文化工具——《诗篇》逐渐成为贵族阶层的识字课本；私人虔敬的辅助——这时常缩为四福音书（tetraevangelion）或受难叙事，如似乎曾属阿尔弗雷德国王之妻的《农纳明斯特书》；[^p561-7] 以及善政的镜鉴，<a id="pdf-562"></a><!-- PDF page 562; original page 534 -->自查士丁尼一世至中世纪结束，皇帝、国王和诸侯都有义务勤加运用。[^p562-8] 事实上，耶路撒冷、罗马、君士坦丁堡及其他各教会的所有基督徒共同体领袖，都从《圣经》这一源泉汲取教导的基本原则。因此，一切传教负责人，也使用同一来源。结果，《圣经》注定滋养最热切的改革、变革和建设公共福祉的愿望。直到1229年一项地方法令以前，没有人敢限制接触它。[^p562-9]

### 统一的媒介？

人们可能以为，共同以《圣经》为参照，意味着神圣经书发挥社会统一的媒介作用。事实远非如此。无论希腊文还是拉丁文，《圣经》历史都以文本多样为特征。圣经正典并不容易确定，希腊语东方如此——比较亚历山大里亚的亚他那修367年第39封节期书信——，拉丁西方也如此——比较六世纪初高卢南部一位教士编写的《格拉修敕令》。[^p562-10] 七世纪前夕，《圣经》以多种语言流通，每种语言又有数种同时并存的不同版本与形式。还应注意，东西方正典严格说并不相同：除凯撒里亚的阿雷塔斯（约卒于940年）等极少数注释者的著作外，十四世纪以前，《启示录》既不在拜占庭礼仪正典中，也不在其圣经正典中。西方各“圣书”的排列，经过很长时间才固定，从地中海一端到另一端差别甚大。其使用史，在昔日罗马帝国、拜占庭帝国，以及科普特埃及、叙利亚、亚美尼亚和罗斯的基督徒社会中，循不同道路发展。此外，西方一旦拥有足够拉丁译本，就放弃最早犹太—基督徒的三种语言：希腊语、阿拉米语和希伯来语。《武加大译本》这一拉丁版本，在五至七世纪的意大利逐渐取代早先版本，其胜利进展不仅证明西方基督徒很快认为求助希伯来文本已过时，也表明他们同样抛弃了<a id="pdf-563"></a><!-- PDF page 563; original page 535 -->《七十士译本》和《新约》的希腊语。少数西方《诗篇》抄本包含转写的希腊文本，但始终伴随两种乃至三种拉丁译文。《诗篇》是流通最广、最熟悉、研究最多的圣经书卷。[^p563-11] 这一现象尤其引人注目，因为希腊帝国臣民在抄写完整或部分《圣经》、汇编教父引文时，从未考虑拉丁语言或拉丁教父是否有用。但在罗马教会，虽然双语延续了一段时间，罗马人的语言仍在既定神圣语言之间，开辟新道路。塞维利亚的伊西多尔（卒于636年）把拉丁语与希伯来语、希腊语列于同等地位时，实际上承认了它在西方的主导。

自七世纪起，东地中海语言在服从罗马的教会中的事业，已告失败。从此，圣经的词语和名字，对希腊人与拉丁人，不再指向同一实在，也不再承载同样意义。诚然，几个世纪里，少数学者尝试掌握希腊语。例如，为理解罗马教会与希腊人间酝酿的冲突，教宗利奥九世（卒于1054年）约五十岁时决定学习希腊语。[^p563-12] 其他人，如九世纪或许有赫拉班·毛鲁斯，十二世纪则较确定有斯蒂芬·哈丁和尼古拉·马尼亚科里亚，曾向当时使用希伯来语、希腊语者请教，但这些活动意义如何，较不清楚。事实仍是，直到十五世纪，不懂希腊语与不懂希伯来语一样，既不困扰教师，也不困扰异议者。无论东西方，都无人呼吁返回圣经原始语言。比德得以修订早期《使徒行传注》，是由于特殊机缘：爱奥那或威尔茅斯—贾罗有一部希腊文、拉丁文双语《使徒行传》抄本。连同七世纪坎特伯雷的希腊人，他是少数认识到，返回基督教最辉煌母语具有用途的学者之一。[^p563-13] 基督徒翻译亚里士多德的人，或许<a id="pdf-564"></a><!-- PDF page 564; original page 536 -->在古代西方帝国和东方的学术中心发挥重要作用，但我们对这些作品如何被接受，以及流通多广，同样所知甚少。例如，改宗者约翰·斐洛波努斯（约490—约570）翻译的作品，似乎直到十六世纪才引起“拉丁人”兴趣。八世纪占据罗马教座、具有叙利亚根源的教宗，为何不向近东朋友求助，如埃德萨的狄奥斐鲁斯、叶海亚·伊本·比特里克？他们已着手把亚里士多德的希腊文著作重新译为叙利亚语。那时，教宗文书局不是仍使用希腊语吗？欧里亚克的热尔贝尔，即后来的教宗西尔维斯特二世（卒于1003年），难道没有利用在科尔多瓦汇集、而他旅居加泰罗尼亚时本可接触的阿拉伯语资源吗？又为何在九世纪获得拉丁译本的大马士革的约翰，成了十二世纪伟大学术运动以前，最后一位被译为拉丁文的希腊作者？无疑是因为西方人认为，无论在法律还是圣经释义中，自己不再需要这些关于解释艺术与技术的学术贡献。他们不再向希腊人期待任何东西。

### 一部法律之书？

《圣经》是犹太人的律法，即《妥拉》，却绝非所有基督徒的法律。不过，约600年，当西方王国被服从罗马的基督徒赢得，从哈德良长城到莱茵河，再至地中海与莫扎拉布王国的大西洋海岸，许多归信民族都把《圣经》视为界定基督徒身份的奠基之书。不要忘记，它仍是犹太人与基督徒最原初的法典，包含上帝自己的律法；尤其对于罗马传教士使之归信的民族，更承担这一角色。托莱多的尤金二世（卒于657年）谈圣经时写道：“遵守为宜，违犯有害。”[^p564-14] 因此，其中所定规则，对读者应像法律汇编一样具有约束力。正如名称所示，《新约》在《圣经》中居首位：尤金逐一列举其作者，却对《旧约》作者缄口不言。[^p564-15] 基督教的胜利本身，为这种优先次序提供根据。但既如此，为何将整部《圣经》列为正典，而非仅《新约》？

因为整部《圣经》既描述基督徒生活规范，也提出一般道德教导。

罗马帝国法学家从未屈从于把圣经与法律书籍相连的诱惑。君士坦丁仅相当含糊地提出“至圣的律法”。[^p565-16] 他的政治精明，使他阅读圣经时，与其视为规范，不如用以强化对其战胜敌人的基督教解释。[^p565-17] 实际上，对他313年在米尔维安桥所见异象的寓意解释，奠定了基督教历史建构。〔译注：原书此处作313年；本书第一卷对米尔维安桥战役的叙述为312年。〕相反，狄奥多西在394年（？）明确提及“使徒教导与福音教义”，将其作为帝国全体公民的生活准则。[^p565-18] 从君士坦丁到狄奥多西，对《圣经》的运用似乎发生根本变化：护教性辩解，让位于规范性规定。但应注意，狄奥多西只是唤起基督教教义，回避提及具体《旧约》法律。圣像破坏危机期间，一些拜占庭法学家试图把源于圣经的法律加入罗马法。最能说明问题的文献《摩西律法》，编于七至九世纪之间，汇集《出埃及记》《利未记》《民数记》《申命记》的引文。[^p565-19] 除十一、十二世纪某些修道圈子外，该书成效有限。在西方，只有七、八世纪爱尔兰教会敢流通援引《圣经》的规定。[^p565-20] 大陆王国所用法典，无论东哥特、西哥特、勃艮第、法兰克还是伦巴德，无论早晚，都没有屈从这一倾向；因为这实际上会使摩西律法优先于基督之法，而后者不可化约为任何法律体系。自保罗（《哥林多前书》12：6—11）以来的整个基督教传统始终认为，基督之法既关乎知识（scientia），也同样关乎智慧与生活纪律。[^p565-21]

### 受控制的文本？

《圣经》因被视为受神启示，始终享有特殊地位。在中世纪，这使主教群体失去任何<a id="pdf-566"></a><!-- PDF page 566; original page 538 -->对于《圣经》的特殊权威：没有哪一种机构——大公会议、主教会议、任何法院——是校正圣经文本、从而界定正确解释所不可或缺的。解释属于两类人：一类已经去世，却拥有极大权威，即教父；另一类仍在世，发挥重大个人属灵影响，制度权威却极小，即修院和主教座堂学校的教师，他们守护释经记忆，担任神学正统顾问。

早期教父著作提炼出可辨认的圣经教导，颇似教堂的内部装饰；通过诺拉的保利努斯（卒于431年）和普鲁登修斯（约卒于410年）的描述，[^p566-22] 或利奥六世皇帝（卒于902年）对君士坦丁堡图卡莱奥斯修道院的记述，我们可以想象这些装饰。[^p566-23] 但没有什么暗示，释经写作或图像制作受到制度控制。君士坦丁一世命凯撒里亚的优西比乌制作圣经抄本时，首要关心是配备基督教礼拜场所，而非制作以自己命名的版本。[^p566-24] 不过，不同文本数量如此庞大，确实引出问题。现代学者尚未切入主题，便面临关键选择：所谈的是什么圣经文本，哪一部《圣经》？当然是《武加大译本》，因而是拉丁文本。对中世纪注释者，有关紧要的异文，仅限于拉丁传统。但应注意，加洛林圣经改革并未到达伊比利亚半岛，也几乎未触及不列颠群岛和意大利图书馆。尚未证明它在法兰克王国以外有持久影响；即使在王国内，也无法改变礼仪习惯，早于《武加大译本》的版本或西哥特版本仍然并存。教师引用《七十士译本》、西马库斯、“另一版本”（alia editio）、“某些抄本”（quidam codices），或提起“狄奥多田译本”（translatio Theodotionis）、“另一译本”（alia translatio）时，[^p566-25] 其实是在忠实复述耶柔米；耶柔米权威之大，使人认为不必追查来源本身。尽管如此，一位九世纪匿名爱尔兰作者，直言需要以希腊文为基础修订通行拉丁版本；<a id="pdf-567"></a><!-- PDF page 567; original page 539 -->但没有证据表明，他本人曾动手做过任何事。[^p567-26] 既无“标准圣经”，问题就在何处找到一部文本优良的完整《圣经》。在富尔达，赫拉班·毛鲁斯遵循受阿尔昆启发的新版本；弟子埃尔坎贝尔特，则与阿尔昆团队修订的《约翰福音》保持距离，虽然他知道其中异文。[^p567-27] 因此，各人所依据的圣经文本版本不同。欧塞尔的海莫注释《启示录》时，似乎遵循“阿尔昆式”文本，却常毫不犹豫地偏离；继任者欧塞尔的雷米吉乌斯，也不介意注释非阿尔昆版本的《创世记》。[^p567-28] 约1109／1112年，斯蒂芬·哈丁着手获取尽可能好的文本，由此表明，他知道十一世纪中叶罗马的同类尝试并未完全成功。十二世纪第二个十年，巴黎圣经注释者更为务实，满足于使用手边任何文本；抄写者也不再费力指出正文与注释者所用文本的差异。

### 圣经的解释

现在转向解释本身。[^p567-29] 中世纪早期的用法，继续区分两类解释：亚历山大里亚式与安提阿式。亚历山大里亚释经的指导原则，早在亚历山大里亚的克莱孟（卒于215年）时便已形成，由奥利金（约卒于253—254年）系统化，再为亚他那修（卒于373年）、亚历山大里亚的区利罗（卒于444年）和盲者狄迪穆斯（卒于398年）运用。奥利金依照人性分为身体、灵魂、精神，区分三种“意义”，与后来拉丁作者所说字面义、寓意义、道德义三分，十分接近。安提阿释经以<a id="pdf-568"></a><!-- PDF page 568; original page 540 -->撒摩撒他的卢基安（卒于312年）、金口约翰（卒于407年）、居鲁士的狄奥多勒（约卒于466年）著作为代表，重视“字面”，即词源、语法、文体，以及历史解释。不过，实际更加复杂。释经基本原则，早在第一代基督门徒已显露：他们与犹太传统竞争，力求与之区别，必须界定自身相对于摩西律法的确切位置；像一切激进者一样，他们声称自己就是律法的完成。基督言语、事迹和行动，被汇集为他们称作《新约》的文集，被理解为实现犹太旧律的应许，例如，《出埃及记》3：1—6燃烧的荆棘，成为童贞玛利亚的预象（typos）。这种基督教完成原则，东西方共享，又特别在西方受到预言对应原则强化。人们相信，不仅新旧约之间，而且在世界历史核心，都有文学与历史形式上的平行。因此，古代异教宗教与犹太教历史，被理解为基督教历史的前奏。基督教世界编年史文类，由凯撒里亚的优西比乌首先建立；圣耶柔米对他的重读，使基督徒能够把历史和异教文化要素，与基督救赎的犹太—基督教叙事相结合。[^p568-30] 新旧约叙事图像组，经常出现在教堂，如罗马圣母大殿、拉文纳新圣阿波里纳雷教堂，[^p568-31] 以及四世纪起的雕刻匣，如布雷西亚圣髑匣。它们的连贯性，又被世界史分期强化：三个时期，即律法前、律法下、恩典下；七个时代，即亚当至挪亚、挪亚至亚伯拉罕、亚伯拉罕至大卫、大卫至巴比伦之囚或先知、先知至基督、基督至时间终结；以及依先知但以理异象（《但以理书》2章）划分的四大帝国，通常是巴比伦、波斯、希腊、罗马。[^p568-32] 〔译注：原文称“七个时代”，随后实际列出六段，译文照录。〕人们认为，自世界开端，一长列先驱人物，或揭示上帝创造计划实现的又一步，或展示人类试图建立自己历史的新颖而徒劳的尝试。因此，摩西是最初立法者（primus legislator），这一序列在基督中完成，继而由其代理人罗马教宗延续。对此的确信，从未动摇。在<a id="pdf-569"></a><!-- PDF page 569; original page 541 -->教宗与皇帝直接对抗、各自声称统治世界的叙任权之争正酣时，康斯坦茨的伯诺尔德（卒于1100年）提醒帝国一方：教宗至上权的根本依据和合法性，直接来自《圣经》本身。[^p569-33]

### 圣经解释受到控制吗？

叙利亚语、科普特语、拉丁语文化，只有通过译者才认识《圣经》；而希腊文化直接承继最早基督徒团体的遗产。两者是否以同样方式理解圣经严格的“字面义”？耶柔米打开字面解释之门，展示基督徒这方面的能力，可与异教修辞学家竞争。但他刚编好为此必需的词典，其概要见《希伯来名字释义》，拉丁作者便觉得不必继续追随其足迹：接受已有成果，不靠希腊人也能行。罗马失去帝国权力中心地位，又被蛮族破坏，这一历史挫败也凸显：需要从沉重的当代现实中略加超脱。奥古斯丁及其追随者倡导追求不可见、不可言说之物，以补偿世界之恶，为生存指出道路。既如此，为何还要像耶柔米一样，执着追索字面义？

于是，解释者共同体又裂开一道缝，这次是南北之间，围绕犹太—基督教世界的原初问题：《圣经》究竟应遵循到何种程度？具体说，对《旧约》，即基督徒接受文本中最古老部分，该怎么办？[^p569-34] 在最初几个世纪，这是关键问题，既因为基督教的犹太根源，也因为许多追随者来自完全不懂犹太教的世界，特别是不列颠群岛、弗里西亚和德意志。大格列高利教宗忠实追随奥古斯丁思想，劝告其使者、首任坎特伯雷总主教奥古斯丁（约卒于604年），避开字面义，重在属灵义。[^p569-35] 说服<a id="pdf-570"></a><!-- PDF page 570; original page 542 -->大陆教士并不困难，因为他们早已习惯如此；相反，这违背岛屿实践，爱尔兰修士几乎无法接受。两个特殊问题——664年惠特比会议处理的历法，以及816年切尔西会议上遭盎格鲁—撒克逊主教禁止的爱尔兰讲道——揭示问题规模之巨。在政治竞争表象之下，还能辨认出同样严肃的辩论：是否按字面遵守规定的律法？爱尔兰人退却了，但仍彼此劝诫，应按《旧约》，一字不差、毫不妥协地实践基督教训诫。[^p570-36] 总体而言，回到圣经的语言与历史来源，即使未被完全禁止，也遭到决定性贬低；相反，属灵义，这种古代寓意的淡化发展，成为既定规范。

希腊人、坎特伯雷总主教塔尔苏斯的狄奥多若（668—690），把基于安提阿取向著作的教导带入不列颠。他对奥利金并无好感：在受他影响的作品中，作为竞争学派亚历山大里亚领袖的奥利金，未被提及。例如，考察他如何解释《约翰福音》10：3“Et vocem meam audient”（“它们要听我的声音”），会发现解释十分具体：“东方牧人的习惯，是走在羊群前面唱歌。”《利未记》11：5那神秘的 chyrogrillius，即蹄兔，也以最字面的方式解释：这动物像猪，却更小，在西奈山陡坡漫游。《民数记》11：5的 pepones，则被描述为埃德萨出产的巨瓜，大得骆驼载两只也很困难。[^p570-37] 诚然，岛屿作者并未等到大格列高利使者到来，才广泛实践字面解释。但狄奥多若及同伴，很可能被迫向大陆影响的复兴让步；后者的圣经解释模式，主要由寓意和道德范型支配。679或680年哈特菲尔德会议教规，实际上显示向亚历山大里亚方法靠拢。[^p570-38] 不过，西方直到很晚，才发展出写实及观看与图像接近的技术；拜占庭<a id="pdf-571"></a><!-- PDF page 571; original page 543 -->圣像敬礼派，却因勤练 ekphrasis，即生动描绘这一修辞文类，而极力倡导这些技术。[^p571-39] 《维也纳创世记》大概于六世纪君士坦丁堡抄写装饰，为某位皇族成员制作，或由其作为供物献出；[^p571-40] 它显示，文字与按字面表现的图像，不必借助伴随注释，也可相互支持。这种对圣经书卷的简单使用，在君士坦丁堡长期延续，直至十一、十二世纪著名的“饰带式福音书”。[^p571-41]

### 东西方之间的断裂

理解基督教古代和中世纪早期的拉丁释经，无须求助东方公式。从地中海一端到另一端，从地中海到北大西洋海岸，文类与解释模式各不相同。以摘句集为例。自加沙的普罗科皮乌斯（约465—529）六世纪发展这一文类起，“释经片段汇编”，类似灵修文学的百章集或“章节”，便主导拜占庭学术中心。许多原有作品中，存世的有归于大马士革的约翰的八世纪《神圣平行集》，以及九、十世纪《蜜蜂集》系列；后者在圣经与教父摘句集中，加入赫拉克利亚的尼基塔斯（卒于1100年）的世俗格言（gnomai）。如同君士坦丁堡牧首文法学家约翰七世（837—843）为证明恢复圣像破坏而汇编的圣经、教父引文集，这些摘句集兼具教学、属灵和政治用途。[^p571-42] 拜占庭统治者对创新的强烈不信任日益加剧，传统的主导，使解释者被引入释经摘句集文类，教师的工作随之僵化。[^p571-43] 692年，在查士丁尼二世君士坦丁堡宫殿举行的特鲁洛会议，为释经创造力划下持久界限。十世纪初阿雷塔斯短暂迸发之后，这种创造力退避保加利亚沙皇领地，直到十一世纪末与十二世纪的科穆宁时代，才在君士坦丁堡恢复活力。

西方作者长期接受摘句集的限制。法国利居热修士德芬索尔，在632至约750年之间写成《火花书》，解释说导师乌尔西努斯——有人认为他就是欧坦《圣莱奥德加尔传》的作者——命他撰写，并教他方法。他利用了一座良好图书馆，因为能引用米兰的安布罗斯、奥古斯丁、耶柔米、伪克莱孟、伪居普良、阿尔勒的凯撒里乌斯、普瓦捷的希拉里，以及拉丁作者熟悉的希腊作家奥利金、凯撒里亚的巴西尔、凯撒里亚的优西比乌，甚至罕见引用的以法莲等人的恰当段落。他说，标明来源，是为了避免混淆真作与伪作。[^p572-44] 但自八世纪起，拉丁作者开始摆脱摘句集文类的约束；最明显的疏离标志，是聚焦一两位教父：比德着手处理奥古斯丁文献，弗洛鲁斯汇集保罗书信释经著述时，则有意转向圣耶柔米。[^p572-45] 他们也优先采用注释与讲道；加洛林注释者重视以末尾颂荣可辨的讲道文类，并将解释拉丁古典作品的方法用于阅读圣经，产生圣经“注释”，也许受拜占庭链式注释（catenae）影响。

六至八世纪，西方又发生另一种分裂。那些已被称为教父的作者，其作品广泛可得并被使用；先是安布罗斯（卒于397年）、耶柔米（卒于420年）、奥古斯丁（卒于430年），很久以后又有大格列高利（卒于604年）。他们划定一种特属西方的解释领域，既不理会“犹太化者”的呼吁，也漠视东方各学派，既非亚历山大里亚式，也非安提阿式，而是罗马式。罗马帝国395年分裂、476年从西方消失，也许注定崩塌；罗马城410年遭破坏，也许跪倒蛮族之前，但又有何妨？对圣奥古斯丁，魔鬼之城与上帝之城，从此加入一场战斗，按律法生活的基督徒必有善果，虽此世尚存便无法取得。对于那些知道如何观看、看透单纯表象的人，<a id="pdf-573"></a><!-- PDF page 573; original page 545 -->绝无理由怀疑教会的胜利。因此，自六世纪起，两道断层划分了两大解释领域。西方基督徒意识到一道兼具语言与教义性质的断层，迅速把他们与仍懂圣经原始语言的东方分开。他们不仅不弥合分歧，反而贬斥拜占庭城市持续辩论的不良观念，用希腊名称编列异端危险，最后又欢呼君士坦丁堡皇帝将他们从意大利的东哥特主人手中解放；东哥特人犯了顽固坚持异端之错，是阿里乌斯（约卒于336年）的继承者。受此榜样鼓舞，法兰克人约550年、西哥特人587年以后，赶紧清除最后的阿里乌斯派，并安排由元老卡西奥多鲁斯传递的奥古斯丁解释取得胜利。

从此，几乎形成两个各自独立的圣经欧洲、两个诠释学欧洲，彼此对立：北方与岛屿欧洲，以及南方欧洲。一方追随退隐伯利恒的隐修士圣耶柔米，另一方自认属于治理北非希波团体的奥古斯丁主教一脉。一方致力私人或通过礼仪进行的集体默想，受字面主义乃至基要主义启发，以象征主义滋养；它喜欢用来自以西结异象的标准动物象征介绍福音书作者——人代表马太、狮代表马可、牛代表路加、鹰代表约翰——，而非采用其“肖像”。它提倡成文道德规范，宣称不受尘世压力影响，倾向限制、至少界定社会变化力量的范围。另一方则自认具有指导性、意志性与组织性，更多把圣经用作改造社会的杠杆。一方可称修道式，另一方则是主教式。

这一二分，使我们能够描述两种圣经解释模式。北方解释者，尤其西北方及其在大陆的追随者，从科伦班到皮尔明，都赋予字面解释优先地位。他们从圣耶柔米，以及随塔尔苏斯的狄奥多若到英格兰的东方作者那里，获得灵感与权威；有些甚至借用耶柔米的名字。[^p573-46][^p573-47] 转向寓意解释时，他们始终优先采取基督论意义。他们似乎无意改造世界，而是通过使世界脱离时间性来拯救它。这种<a id="pdf-574"></a><!-- PDF page 574; original page 546 -->优先采用字面释经的做法，后果重大：它诱发某些形式的基要主义。中世纪早期，字面解释方式最易爆发的发酵因素，大概就是东西方圣像破坏；伴随它的，还有礼仪、尤其圣餐象征主义。我们知道，君士坦丁堡圣像破坏者主张，祝圣饼酒以外，没有真正的基督圣像。[^p574-48] 敏锐的注释者很清楚这一危险。比德受威尔茅斯—贾罗的凯奥尔弗里德影响，决心采用更灵活的释经方法，将 littera，即字面，所包含的语文学与历史两方面结合。对他而言，字面为教导提供入口，引导读者通过从创造到时间终结的圣经历史，重新阅读当代与人类历史。采用这一方法的岛屿作者不止比德。据其自述，神秘的凯德蒙受奥古斯丁《教导初学者》启发，勾勒了同样的教理进程。[^p574-49] 实际上，比德站在罗马影响范围一边：他反对岛屿激进主义，努力推进一种更能与当代社会价值和解的修道生活。但不可误判，比德仍属例外，虽然声望足够高，使许多九世纪匿名作者庇护于他的权威名下。

其他注释者，主要来自南方，虽无法完全避开字面义，却尽快将其置于一旁，转向道德义。这一解释模式在讲道中表达，旨在给予团体道德教导。这些大陆教会解释者追随大格列高利，陪伴、支持，偶尔也指导欧洲社会的运动；这些社会在圣经遗产中认出自身。现在，我们来看一小群激进修士主导的岛屿积极行动，与大陆古老主教机构支配所引起的分裂。

### 西方的修道影响

八世纪中叶至九世纪中叶，受到本笃式修士压力，并回应法兰克人无法容忍的某些不规范，特别是阿里乌斯主义的变体，<a id="pdf-575"></a><!-- PDF page 575; original page 547 -->以及东方圣像破坏者和圣像敬礼对手的极端行为，法兰克王国发生重要逆转。认为上帝之子由父创造的教义性阿里乌斯主义，已在西方消失，却仍困扰中欧传教士，因为当地许多民族过去曾接受阿里乌斯观念。一些传教者确实随身携带反阿里乌斯论著，例如著名《拉金德鲁迪斯抄本》所收作品。[^p575-50] 嗣子论教导基督是被上帝拣选并收纳的人，强调上帝超越性与基督人性之间的距离，很可能来自安提阿式解释，使一些人把耶稣故事读作某种人类历险。某些安提阿学派东方释经者，如撒摩撒他的保罗，其著作表现出滑向嗣子论的倾向，支持了这一联系。八世纪后半叶，托莱多一群人传播这一教导，使法兰克人十分不安，查理曼宫廷因而以相当猛烈的方式攻击。阿里乌斯主义及其嗣子论变体这两例，显示字面解释的危险；圣像破坏亦然。圣经禁令是危机发起者的主要依据，利奥三世皇帝欣然援引《圣经》，为反图像政策辩护。[^p575-51] 西方不甚理解这些论点，法兰克人决定暂时保留判断为宜。

修道生活融入西方社会，以及博尼法斯、萨尔茨堡的维吉尔、赫拉班·毛鲁斯等修士，与教会控制之间的密切联系，使修道与主教传统的界线变得模糊。[^p575-52] 大陆修道中心采纳奥古斯丁路线，例如安布罗修斯·奥佩尔图斯、阿尔昆，使两种圣经诠释方法融合。他们熟悉比德著作，此后系统诉诸历史（historia），比较、对照并重新连接古代罗马与新帝国的过去，从而丰富字面义。圣经再次成为历史书，旨在证明法兰克基督教的胜利。预象解释的伟大艺术此时兴盛，惠及查理曼及诸子，这个新世界的管理者。英格尔海姆壁画表现《旧约》在《新约》中的完成，显示基督教历史本身，从君士坦丁至查理曼，已经达到崇高<a id="pdf-576"></a><!-- PDF page 576; original page 548 -->完善。[^p576-53] 虔诚者路易宫廷显示出实践四种“意义”、即圣经四层解释的姿态：字面义、属灵义、道德义，以及上升义。[^p576-54] 但是否真有人考虑按《圣经》治理，则是另一回事。通常，博学教导让位于敷衍实践。约820—830年，普萨尔莫迪的特乌特米尔向朋友都灵的克劳狄乌斯寄去关于《列王纪》的问题清单，请这位主教既留心字面，也追索寓意或道德意义作答。[^p576-55]

### 九世纪爱尔兰释经的影响

所谓“爱尔兰释经”的教师，以培养修道精英为目标。他们从七世纪西哥特人汲取的，远比通常承认的多，尤其是问答问题（quaestio）方法，又将其推向新方向。九世纪中，爱尔兰人逐渐被大陆人削弱，只剩昔日影子。加洛林学者期待从爱尔兰释经传统中获得的，与他们向西哥特传统所求相同：手册，即“圣经参考书”，有时加以重抄。事实上，他们吸收并消化岛屿诠释方法：阿尔昆、瓦拉弗里德·斯特拉博、欧塞尔的海莫与海里克，都熟练掌握爱尔兰释经，驾轻就熟地采用惯用公式——人物、时间、地点——、七数组合，如七层天，以及套语，如 et reliqua（其余等等）、aliter（另一解释）、alii dicunt（另有人说）。他们也最终抽空其属灵潜力，认为它不能被吸收进自己服务的帝国：帝国由巨大意志力组织，与爱尔兰教师工作的环境截然不同。他们查考圣经，一方面提取道德范例，特别是能作为帝国精英榜样的形象，例如赫拉班阅读《列王纪》的方法；另一方面提取长期有益于上帝选民和以色列王国之民的仪式习惯，因为他们自认是其继承者，尤其是教会强制征收的供物与什一税，以及使崇拜空间和物品神圣化的奉献礼、祝福礼。雷米吉乌斯谈到<a id="pdf-577"></a><!-- PDF page 577; original page 549 -->《申命记》法律时说：“这些全按字面理解，对人间法律（in iure humano）价值极大。”但人们也承认，有些相当严厉的训令，不能按历史字面（iuxta historiam）遵守；[^p577-56] 因而建议只对部分、而非全部训令照字面行事。雷米吉乌斯如此注释：

> “妇女不可穿男子衣服”〔《申命记》22：5〕，即不可僭取讲道职分……伏巢的母鸟象征历史，其中心藏有属灵义或寓意义，即刚孵化的雏鸟……“只可取雏，不可取母”〔22：7〕，意为应舍弃字面，追随寓意，尤其当表述艰难或粗俗时。[^p577-57]

借助常识原则、避免简单化、偏向“较难的解答”（solutio difficilior），属灵释经很快从后门重新出现。事实上，在欧塞尔的海莫和富尔达的埃尔坎贝尔特著作中，这种解释作为警戒原则介入，纠正当时的诠释执念。

西方学者采用的释经方式，取得辉煌成功，可与伟大教父注释的广泛流通相比。九世纪第二个四分之一，法兰克人受益于与君士坦丁堡外交关系恢复，得以摆脱岛屿指导。约翰·司各脱·爱留根纳尝试输入希腊教父教导，尤其翻译认信者马克西穆斯（卒于662年）和伪狄奥尼修（五世纪后半叶），其他人则翻译金口约翰。但向东方开放十分短暂，[^p577-58] 也未获对等回应，因为君士坦丁堡学术圈继续不信任西方。认信者马克西穆斯似乎曾读奥古斯丁，但到九世纪，君士坦丁堡对他的认识，仅来自<a id="pdf-578"></a><!-- PDF page 578; original page 550 -->摘句集。至于耶柔米，早已被遗忘；他的继承者，八、九世纪爱尔兰和法兰克教师，甚至不再值得拜占庭作者屈尊明确引用。

### 人人可得的《圣经》？

释经方法似乎确由实践者的宗教归属决定。但它用于《新约》时，与用于《旧约》时同样稳定吗？此外，人人都可掌握，还是仍为专家特权？约1015年，阿基坦降下血雨，卡佩国王虔诚者罗贝尔为之忧虑；沙特尔主教富尔贝尔回答，解释自然世界与天上领域的技术完全相同，关键在于找到类比模型。在充满潜伏奥秘、但这些奥秘理应被承认为有意义的宇宙里，问题是如何破译初看时隐藏的东西。释经要求思考语言，以及解释技术的必要性，因为解释者必须使 vox，即物理发声，转化为有意义的话语（sermo）。这一九世纪问题持续存在，直到十一、十二世纪之交仍被提出。[^p578-59]

当然，也可以只满足于字面。对富尔达的埃尔坎贝尔特，字面提供简单的道德教导，有时必须效法。面对义人亚伯与弑兄弟者该隐的选择，善人会毫不犹豫地追随前者。[^p578-60] 修士的召命，诚然使他们走向更高思考，但其中有风险：寻求更深意义，是否反而暴露一种可耻的好奇（curiositas），正是圣保罗所谴责的？[^p578-61] 这一问题根本而重要，被反复提出。加洛林修女吉斯拉和罗特鲁达，请阿尔昆毫无保留地传授圣经知识；他同意，因为认为这属于修道生活的培养。[^p578-62] 但十一世纪初，当佛兰德斯、法兰西岛、香槟和法国南部的<a id="pdf-579"></a><!-- PDF page 579; original page 551 -->小型文本共同体，把《圣经》从既定天上权威——教父——和尘世权威——主教、院长——控制中夺出时，又该怎么办？圣经基要主义重新扩散，以实践启示话语、坚持真正使徒生活（vita vere apostolica）为基础，扰乱并动摇传统解释。1025年，阿拉斯异议“异端”只是要求阅读，至少聆听圣经，却被怀疑想摆脱教会控制，毫无中介地直接饮取福音活水。[^p579-63] 相反，1022年奥尔良被定罪的教士，似乎支持一种令同时代人厌恶的秘传主义。[^p579-64] 新解释引发不同学术与政治回应，只有一条古老原则经受一切考验：审慎与智慧不等于好奇。知识意味着良知。十二世纪第二个四分之一，阿贝拉尔与克莱尔沃的伯尔纳之间的争论，当然也重提这一区分。

### 更新

十一世纪后半叶，拉齐奥和法国北部两个地区，分别由不同群体激发反应。意大利中部由联系枢机团的教士领导，法国北部则由城市学校教师领导，他们与推动西欧扩张的新精英相联系。符合十一世纪初“文本共同体”的希望，[^p579-65] 圣经的未来从此与改革观念紧密相连。[^p579-66] 这一演变迅速兴盛，在1060至1115年大量生产圣经注释和评注的过程中爆发。巴黎的朗贝尔、塞尼的布鲁诺、兰斯的布鲁诺、坎特伯雷的兰弗朗克、拉昂的安瑟伦、贝伦高杜斯、圣奥梅尔的朗贝尔等教师，尝试开辟新路，处理与十一世纪后半叶罗马改革者相同的主题。他们同样重读经书，从中提取若干重要指导原则。第一条要求区分神圣与世俗。这一根本<a id="pdf-580"></a><!-- PDF page 580; original page 552 -->分隔，见于前人都熟悉的《以西结书》22：26，是其行动基础；赖兴瑙的贝特霍尔德约1080年哀叹皇帝行为时，再次提醒这一点。[^p580-67] 第二条提醒，追求更高、更崇高之事（altiora、superiora），需要谨慎，并呼吁返回最好意义上的寓意解释。兰弗朗克攻击图尔的贝伦加尔和新逻辑学家时，就利用这一原则。[^p580-68] 第三条则唤起基督再临与时间终结，激发反应。[^p580-69] 这大大扩大了在俗教师与修士间的鸿沟：前者认识到，面对西班牙和圣地朝圣、十字军的新经验，传统圣经教学越来越不足，因此更积极追索字面和历史义；后者则依预象原则，努力在天上建城。围绕改革核心、或许也是此后每次改革核心的三组圣经书卷——保罗书信、《启示录》《雅歌》——，注释者兴趣日增；他们偏好世界史宏大图式，并借可敬的比德恢复教会历史视野；这些都是约1100年变革的标志。学者运用新的圣经解释技术，为八世纪末岛屿教师曾试验的注释文类，发现新用途。[^p580-70] 他们澄清文类和话语形式，完善导论（introitus）技术，调整学科等级，把圣经书卷纳入其中，使其接受与伦理学、逻辑学、自然学作品相同的分析，并以当时重写编年史的同样精神，重新阅读圣经。[^p580-71]

### 尾声

目睹第一次十字军出发与归来的一代，获得新的历史意识：所有教师都必须<a id="pdf-581"></a><!-- PDF page 581; original page 553 -->透过世界史重新思考《圣经》。预象思维在这一时期达到顶峰。它以同一和恒常重复为原则，原会产生使人停滞的决定论；但又吸收“完成”的观念，使过去记载成为当下预示，推动历史向前，由此更为丰富。形象式或预象式思维，既不特别属于日耳曼，也不特别属于法国或英国；它使一切运用它的民族受益。对约1100年的社会，《圣经》再次成为历史书，是变革灵感的来源，有时也是激发变革的动力。掌管这一更新的，不再是帝国统治者，不是国王或诸侯，而是改革后教会的领袖，他们与新的教会权力掌握者——主教——相联系。就在此时，historiae divinae，即神圣历史，重新广泛流行，而 biblia 也成为描述全部经书的标准词。[^p581-72] 同时，西方世俗精英发现前所未有的力量，努力用“圣战”观念，证明并净化其谋求世界支配的冲动。所幸，新知识阶层足够明智，没有加入；他们已经开始取用希腊古代和拜占庭的战利品。
