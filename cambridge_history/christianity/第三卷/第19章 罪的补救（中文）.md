# 第19章 罪的补救

罗布·梅恩斯（Rob Meens）

<a id="pdf-428"></a><!-- PDF page 428; original page 399 -->

人是有罪的受造物。即使乐园中，人也违背主命令而犯罪。堕落后，不只思想、言语、行为犯罪，也受原罪影响。基督教恩典，可通过洗礼，除去原罪；普通基督徒，虽也许极想守神律，实际却从未完全成功。仅少数圣徒，能避免一切罪。因此，须决定如何处理罪。本章六至十二世纪，可以辨认基督徒应对此问的重要发展。

七世纪，爱尔兰院长库米安（约632年活跃），为悔罪裁定集写序，列12种罪的补救，或其所称“创伤疗法”，附圣经引文，支持效力。清单从洗礼起，续爱德（caritas）、施舍果实、流泪、认罪、身心苦修、改正行为、圣徒代祷、仁慈与信德之功、使他人改宗得救、赦免他人罪，最后殉道苦难。[^p428-1] 他并非首创，而依据西方修道奠基人之一、约翰·卡西安（约360—430年）的《会谈集》。[^p428-2] 卡西安作品、库米安序言，广为阅读，清单颇熟知。另一清单，依据希腊教父奥利金（约185—约254年），《利未记讲道》列七种：洗礼、殉道、施舍、宽恕他人，以讲道、善工改善<a id="pdf-429"></a><!-- PDF page 429; original page 400 -->他人生活，丰盛的爱，最后，通过悔罪（per paenitentiam）。奥利金说，最后尤其艰苦、辛劳（dura et laboriosa）。[^p429-3] 清单东西方皆知。拉丁西方，九世纪奥尔良主教狄奥杜尔夫（约750—821年），采用于主教章程；继任者约拿（约760—约841年），采用于平信徒教育论著《论平信徒的教养》（De institutione laicali），也独立流通。[^p429-4] 两清单主要区别，是较长一份，没有正式悔罪礼。卡西安、库米安，都未提赦罪的正式教会程序。卡西安写给修士，他们已过悔罪生活，不必正式悔罪，可解释省略。库米安也主要面向修道读者，省略也许另有原因，暗示七世纪爱尔兰，程序尚未稳固建立。

奥利金、卡西安，提多种获赦罪途径，从爱上帝、邻人的感情，或流泪，至洗礼、悔罪等正式礼。下文以较正式程序为核心，许多要素会各扮角色；但须记住，非正式补救，始终重要，正式悔罪，也不易与非正式区分。[^p429-5] 墨洛温女修道院，女院长、资深修女，似参与悔罪过程，听修女认罪、指定补赎，可能也面向院外男女。可以称正式悔罪，但加洛林主教，肯定强烈反对此做法。[^p429-6]

### 洗礼、殉道与公开悔罪

先从卡西安、奥利金，及后来沿用者，都列首位、显然最<a id="pdf-430"></a><!-- PDF page 430; original page 401 -->重要的洗礼开始。含义众多，归依始终核心：离恶行，转向献身上帝的生活，以死亡、重生象征；净化，则表示赦免一切既往罪。[^p430-7] 但600年后，没有证据表明，人为利用赦罪效力，推迟洗礼。婴洗普遍接受、独立悔罪礼发展后，“病床洗礼”似衰退、消失。[^p430-8] 罪获赦与洗礼观念，对西北欧诸族基督教化重要，可见七世纪后半叶，坎特伯雷总主教狄奥多若（668—690年）《悔罪书》，对大陆日耳曼传教颇实用。他强调，洗礼赦罪，却不终止既有婚姻。[^p430-9] 另一明显用于传教地区的文本，稍异地表述：改宗前缔结有罪婚姻者，不可拆散，因为罪已在洗礼获赦。[^p430-10] 但加洛林时，这层意义似减弱。查理曼调查洗礼，产生大量文本，更强调作为教导、教育工具，以及仪式本身；赦罪，似不居作者思维前列。[^p430-11]

奥利金列举的第二条途径是殉道。“血的洗礼”被视为最完美的洗礼，能赦免一切罪，使人立即与上帝共融。殉道者死后，成为上帝与普通信徒之间特别蒙恩的代祷人。在古代晚期，他们甚至在被处决之前就能代求，帮助减轻别人的补赎重担。[^p430-12] 对中世纪早期的拉丁西方而言，殉道并不是切实可行的选择；这也许反映在卡西安将它列为最后一项、<a id="pdf-431"></a><!-- PDF page 431; original page 402 -->奥利金则列为第二项的差别之中。不过，人们可以选择禁欲的宗教生活，也就是这种不流血的殉道。转入宗教生活，就等于选择一生的悔罪操练，因此conversio与悔罪可以互换使用。这或许正是公开悔罪礼不适用于教士与修士的原因：他们的归依已是一种第二洗礼，无须再接受另一种第二洗礼，即正式悔罪礼。

600年，大多数地区，有某种证据，说明存在赦免基督徒严重罪行的公开礼。但能否根据会议决定、奥古斯丁著作，重建一个统一基督教公开悔罪体系，很可疑。七世纪亚美尼亚，仍有公开悔罪，分两级；但与拉丁西方不同，不是主教专权，司祭、教师（vardapet），也可施行。[^p431-13] 拜占庭，有迹象至少仍知公开悔罪，却无证据，仍在实践。[^p431-14] 希腊修道院，向较有经验的基督战友，敞开良心、受精神指导，已成日常。[^p431-15] 后来，传入平信徒，修士成受欢迎的灵魂知己，为其听告解。[^p431-16] 西方高卢、西班牙、意大利，600年公开悔罪，显然非经常宗教生活；甚至可问，是否曾经常如此。高卢600年，似主要作死亡准备，即临终悔罪。[^p431-17] 图尔的格列高利（594年卒）历史、圣徒传，却能见取自该礼的要素，有时高度政治化。墨洛温高卢，国王、主教，用悔罪礼词汇，为政治目的服务，加洛林继任者，将继续。[^p431-18]

### 罪行的补赎定额

昔属罗马地区，似某种公开悔罪礼，留下痕迹；从未属帝国的爱尔兰，似非如此。主教角色，不如高卢、西班牙主导，教会生活，更聚焦修道院。[^p432-19] 六世纪起，出现修道背景文本，意在听平信徒告解；像拜占庭，修士精神权威，吸引院外罪人。最古老《安布罗斯悔罪书》（Paenitentiale Ambrosianum）、芬尼安（549年卒）《悔罪书》，很早为爱尔兰所知，未必当地写成，明显源于修道，却无疑也用于平信徒。例如，芬尼安规定，教士谋伤、杀人，须半年仅食饼、水，平信徒只须一周，因为“他属此世，今世罪责较轻，来世报偿也较少”。[^p432-20] 文本列罪、适当补赎，协助听告解者，决定对痛悔罪人，施何种要求。既处理谋杀、致残等暴力，也处理如前例，仅有伤害意图、未行动。另一核心，是人的性，以详细规范管理。[^p432-21] 定期告解深入爱尔兰社会多远，难确定。例如，古爱尔兰法，虽有教会影响，允许离婚、再婚；悔罪文本，却有极严婚姻标准，不许任何离婚。[^p432-22] 这暗示，修道定期告解，影响有限。

彼得·布朗近来提出，这类文本，仔细平衡罪与补赎的方式，反映产生它们的社会，对权威、权力的看法。晚期罗马社会，正义、<a id="pdf-433"></a><!-- PDF page 433; original page 404 -->恩典、大赦的帝国观念，支撑宏大公开悔罪礼；爱尔兰及周边凯尔特王国，社会秩序则远少分化、等级。和平，靠不断调解、协商，“横向”维系；过程，反映于罪、救赎概念。罪被视为侮辱上帝，社会关系又围绕荣誉、侮辱，上帝就不能不惩罚任何罪，连无意犯下者也不例外。[^p433-23] 这为理解手册仔细给罪定额，提供有吸引力的角度；过去，常比作所谓蛮族法，以赔偿金，防受害者发起仇杀的法律义务。

大格列高利（590—604年），描绘“来世”轮廓，认为轻微罪（parva minimaque peccata），即使无意，也须净罪之火消除时，爱尔兰修士科伦班（615年卒），把当地发展出的“悔罪疗药”（medicamenta paenitentiae），带到大陆。[^p433-24] 遵循为上帝离乡的爱尔兰动力，即peregrinatio per Dei理想，他到高卢，给墨洛温诸王、贵族，留下深刻印象。禁欲生活、道德严立场、悔罪疗法，吸引追随者、物质支持，得以建修道家族。传记作者博比奥的约拿（约659年卒），说他抵达一片悔罪荒地，显然夸大。到来前数十年，尤其勃艮第，已有更新教会纪律、平信徒道德生活的努力。[^p433-25] 至少阿尔勒的凯撒里乌斯（542年卒）起，高卢已有不在主教前，经过公开正式礼的悔罪形式。他区分paenitentiam accipere、paenitentiam agere，前者正式进入悔罪者身份，后者是施舍、禁食等非正式补赎。[^p433-26] 因此，某些方面，科伦班接续墨洛温已有趋势；近来，其对<a id="pdf-434"></a><!-- PDF page 434; original page 405 -->当地的影响，以及“悔罪创新者”角色，已获重估。[^p434-27] 但死后40年，博比奥的约拿，仍选择突出其悔罪创新，不能轻忽。悔罪，不只是约拿核心主题，也是科伦班《共住会规》的主题。他又编写院外用悔罪手册；我们只由博比奥两份晚抄本得知，却影响大量后作。因此，修道生活、悔罪，对他紧密相联。他及效仿者众多修道院中，告解不限院内，教士、平信徒似纷纷来认罪。欧坦主教勒奥德加尔（约616—679年）、宫相埃布罗因（680／681年卒），两位公开悔罪者，在吕克瑟伊流放补赎，因此不必惊讶。[^p434-28] 必有新东西，吸引男女；可能一是听告解者，充分具备能力，二是罪人能确信，告解、补赎后，罪确实获赦。严格闭居的科伦班修士，纯洁声誉，强化两方面，也提升其代祷地位。[^p434-29] 科伦班、爱尔兰及后来盎格鲁—撒克逊离乡修行同道，创院多位乡村，使其成为法兰克北、东部，罗马化较少地区，基督教化的有力工具。

爱尔兰传教，也必从七世纪起，把较私密听告解，传入英格兰。可敬者比德（735年卒），略理想化描述，卡斯伯特（约636—687年）任梅尔罗斯副院长时，常骑马访邻村，宣讲正确生活。他如此有说服力，听众无人“敢向他隐瞒心底秘密，全都公开承认罪，因为知道，绝不可能瞒过他；又依他要求，结出相称悔罪果实，<a id="pdf-435"></a><!-- PDF page 435; original page 406 -->洗净所认的罪”。[^p435-30] 段落说明，修道院可成邻村牧灵中心，尤其讲道、听告解，对堂区照护重要。[^p435-31] 威利巴尔德（760年代活跃），为前院长博尼法斯（约675—754年）写传，描述英格兰司祭、教士，到村庄、家中讲道。[^p435-32] 大陆盎格鲁—撒克逊传教，讲道、悔罪，似紧密相联，托名博尼法斯的讲道，可见。[^p435-33] 爱尔兰悔罪文本，必在英格兰流通，但唯一可追痕迹，是七世纪后半叶，坎特伯雷的狄奥多若手册，采用scottorum libellus，即爱尔兰小书。[^p435-34] 他在拜占庭东方长大，赴英任总主教前，在罗马希腊修道院，住过很久。[^p435-35] 虽不总赞同源于爱尔兰的英格兰习俗，却不反对听告解方式，只注意缺正式悔罪、公开和好：“本省〔英格兰〕，没有公开和好仪式，因为没有公开悔罪。”[^p435-36] 他也反对修士听告解，认为是在俗教士特权；反对本身，突出修士作用。[^p435-37] 因此，他虽观察与罗马、希腊东方所知习俗不同，却不根本反对爱尔兰传来的方式。细节虽异，手册仍延续旧爱尔兰传统，也尊重大巴西尔（约330—379年）《教规书信》所代表的东方传统。[^p435-38]

这种起源爱尔兰、邻区，后传高卢、英格兰的听告解方式，常按手册定额，称“定额悔罪”。有人称“私人悔罪”，稍具误导，<a id="pdf-436"></a><!-- PDF page 436; original page 407 -->因为常涉及相当公开性；也有人依某些资料，称秘密悔罪。[^p436-39] 沿文本亲缘、手稿传统，可见它循科伦班及追随者脚步，传往法国北部、莱茵地区、德意志南部的东法兰克。意大利，究竟由博比奥传播，还是加洛林统治后，由法兰克引入，仍不确定；西班牙，明显是后者。[^p436-40] 依现存文本、手稿，罗马、意大利南部，十世纪才开始使用。英格兰，则似在阿尔弗雷德大帝（871—899年）及继任者，恢复维京入侵破坏之后，从法兰克重新引入。十世纪所有英格兰悔罪书，都有加洛林影响。康布雷主教哈利特加尔（817—831年）的悔罪书，甚至译为古英语。[^p436-41]

### 主教与修士

八世纪后半叶起，含悔罪书的手稿，数量明显增加。因此，加洛林诸王，强化基督教角色，即所谓文艺复兴、改革，似影响牧灵手稿制作，也可推知，影响悔罪过程。前已见改革者，讨论正确洗礼，争论悔罪、告解，不足为奇。最初，引入托名芬尼安、库米安等爱尔兰院长，或匿名流传的新权威文本，未引问题。悔罪书，附于《古高卢教规集》等汇编，教规又被纳入悔罪书，往返相取。九世纪初，主教开始质疑权威，尤其常匿名、指定补赎不同，似引批评。也是此时，<a id="pdf-437"></a><!-- PDF page 437; original page 408 -->主教通过编制专门教导作品，即《主教章程》，加强掌控地方教士。[^p437-42] 又试图重建，自己认为古代基督教处理悔罪者的方式：公开悔罪。这种“传统的发明”，似误导史家，对古代晚期悔罪的理解。[^p437-43] 加洛林主教，引入公开、秘密之别，主张秘密罪，可秘密补赎；公开罪，须由主教控制，通过公开礼纠正。人们似直到此时，才意识到，与教规集、圣事书所述古礼，有所不同；例如，博尼法斯、教宗匝加利亚（741—752年），讨论恢复悔罪司祭职务时，并未意识。[^p437-44]

九世纪，西方主教加强正式悔罪掌控，拜占庭却朝不同方向。西方强调文本传承的权威传统；东方，对斯图迪奥斯的狄奥多若（826年卒）等修士，权威首先体现于活人。隐修士、院长的典范生活，与文本同样权威，因为上帝命令，既在文本，也在行为表达。[^p437-45] 修士遵循模仿基督生活的圣教父传统、榜样，必然遵上帝命令。西方，权威、文本重点，强化主教、司祭所体现等级；东方，等级体系，因圣像破坏失信，狄奥多若等修士，反而体现修道美德。争论之后，拜占庭修士，似主导悔罪实践，与西方争取控制的主教相反。西方，罪的处理规则，写入手册；东方，灵性导师，更信自己指导罪人的能力，因此无早期手册。大巴西尔所谓《教规书信》，<a id="pdf-438"></a><!-- PDF page 438; original page 409 -->虽规定处理罪人，可能仍读、使用，却不知何处、如何理解。不过，七世纪塔尔苏斯修士、后来坎特伯雷总主教狄奥多若，在手册用巴西尔教规，说明希腊世界仍用。本期东方，最早专为帮助听告解者，选择适当补赎的文本，是所谓kanonarion或protokanonarion。传统托名“斋戒者约翰”牧首（595年卒），可能不早于九世纪中叶。[^p438-46] 西方文本，更关心简述罪、建议补赎；kanonarion，更仔细界定罪，多性方面。后来托名狄奥多若的作品，可能非他本人，而源于九世纪斯图迪奥斯系修道院，也谈盗窃、盗墓、巫术等。[^p438-47] 如巴西尔书信，影响难评，因为仍缺传播、实际使用知识。

### 悔罪与加洛林人

加洛林社会，悔罪日益重要。面对战争、自然灾害，查理曼（768—814年），亲命帝国所有教堂，诵悔罪连祷，补赎显然激怒上帝的法兰克人之罪。异象描绘，大人物、普通人，甚至皇帝，为罪在来世受折磨。[^p438-48] 813年重大改革会议，悲叹公开悔罪消失、现有手册无权威。哈利特加尔、赫拉班·毛鲁斯（约780—856年）等主教，试编符合权威会议古教规的手册，补后者。[^p438-49] 《达谢里教规集》，本期最重要汇编之一，尤其强调悔罪，以及《主教章程》等，<a id="pdf-439"></a><!-- PDF page 439; original page 410 -->试取代旧式手册，却只部分成功。九世纪，旧文仍抄，新文也用旧文编成，只更强调出处。

前述爱尔兰影响，尚有疑问；加洛林，则更可确定。许多教会中心，按主教章程，拥有一部或多部；保存手册的特定手稿，其内容也明显暗示，预备用于牧灵。[^p439-50] 不必据此设想，平信徒频繁告解。告解一般是领圣餐准备，人们应在复活节、五旬节、圣诞大节，每年领一至三次；此时告解，可能有某种集体性质。有人认为，悔罪有“警察监督性质”，不太可能定期实行；更多作为控制手段，而非牧灵工具。[^p439-51] 但此论似片面。司祭，可不只居中于平信徒、上帝，也调解个人、社会。手册许多罪，公开性强，必造成扰乱、丑闻（scandalum），如杀人、暴力、通奸、醉酒。可能隐瞒，但小共同体，不大可能常有；即使有，也很快疑及具体人。避难权，给罪人安全处，图尔圣马丁巴西利卡，一位不知何罪的已定罪教士，即寻庇护。[^p439-52] 此时，地方司祭，居中逃亡者、受害方，悔罪可能助解决争端。例如，克利希会议（626／627年），要求逃亡者，承诺为罪补赎，才可离堂。[^p439-53] 《巴伐利亚法》规定，入教堂避难者的处罚，应“在司祭建议下”（cum consilio sacerdotis）决定。[^p439-54]

<a id="pdf-440"></a>
<!-- PDF page 440; original page 411 -->

艾因哈德（约770—840年）《书信》中，可见前宫廷人士，为逃入自己所建教堂者，出面干预。[^p440-55] 手册常见，司祭为法官、调解人的比喻，极适合此背景。

当然，手册也有较少公开丑闻的罪，人也可能不受社会压力，而认罪。在教堂、修道院，寻身体疗愈者，把自己交修士、司祭、圣龛以前，可能先告解。[^p440-56] 讲道文献，如九世纪托名博尼法斯汇编，原文括注《布利克林讲道集》，或埃尔弗里克（约955—约1020年）、伍尔夫斯坦（1023年卒）讲道，悔罪都居核心，常详述不悔者在地狱，等待的魔鬼惩罚。[^p440-57] 伍尔夫斯坦明确要求，“按书所教”，补赎罪，很可能直接指手册。[^p440-58] 若无平信徒实际效果，很难相信，这类讲道会写成、继续使用。但不能忘，实际处理罪、罪人的方式，可能多样得令人困惑；教会法、会议立法理论，只是不完美反映。

悔罪礼的政治用途，也证明重要。虔诚者路易皇帝（814—840年），甚至两次公开补赎；822年阿蒂尼，833年与诸子内战，军队战场遗弃自己后，在苏瓦松被迫如此。[^p440-59] 其他高贵者，也受强压。约794年，阿奎莱亚的保利努斯（约730—802年），让伦巴德贵族艾斯图尔夫，选择入院补赎，或接受严厉公开悔罪。[^p440-60] 852年美因茨会议，判劫人妻的阿尔布吉斯，严厉悔罪，杀五人的巴托，终身补赎。[^p440-61] 虽不知能否强迫高地位罪人履行，案件<a id="pdf-441"></a><!-- PDF page 441; original page 412 -->必在教会、世俗精英中，广有回响。此外，悔罪礼要素，广泛被更世俗的归服礼（deditio）采用。尤其加洛林至十一世纪，贵族被迫以仪式臣服他人，吸收如此多悔罪要素，有时难分世俗、教会礼，例如亨利四世皇帝（1056—1106年）在卡诺莎受辱。[^p441-62] 但非所有贵族，都须被迫悔罪。路易822年，似全出自愿；阿尔昆（804年卒）、艾因哈德等宫廷人士，也以罪，思考身份。艾因哈德自称“罪人艾因哈德”（Einhard peccator）。[^p441-63]

### 悔罪仪式

争端解决的“礼仪细化”，与教会悔罪本身，日益繁复同行，手册中的礼序，可作证。最早爱尔兰书，没有规定如何听告解、赦罪的礼仪；八世纪起，越来越多附录，十世纪起，也单独作为杂抄本短篇出现。过程更可见，可能推动主教加强掌控；如前强调，它在加洛林社会，影响广泛。九世纪后期起，悔罪文本，似更多存于主教规章集，而非较早常见牧灵手稿。普吕姆的雷吉诺（915年卒），十世纪初，为主教调查所编手册，悔罪很重要。约1000年，沃尔姆斯主教布尔夏德（1025年卒），编巨型教会法集，把悔罪裁定，与会议立法并列突出。[^p441-64] 后来汇编，常专留悔罪部分，直到沙特尔的伊沃（约1040—1115年）、格拉提安（1160年卒），选择省去。

<a id="pdf-442"></a>
<!-- PDF page 442; original page 413 -->

有人说，世俗归服礼日益重要，部分受悔罪礼影响；但九、十世纪悔罪礼的丰富，暗示世俗、宗教两领域，繁复仪式都日益重要。

因此，九世纪起，西方悔罪、告解，似越来越受司祭、尤其主教监督。动态的公开悔罪形式，其繁复礼仪，聚焦主教强大地位，十世纪洛塔林吉亚，尤其如此。[^p442-65] 但富尔达圣事书等，也证明修道院继续参与。[^p442-66]

拜占庭，却日益由修士主导，应联系修道在社会角色改变。修道生活，越来越城市化，修士、平信徒互动，大幅增长。[^p442-67] 新神学家西缅（949—1022年），[^p442-68] 主张：“修士以前，唯主教，经使徒继承，有捆绑、释放之权。但时日过去，主教不用、或滥用权力。这个令人敬畏的职分……于是转予上帝选民，即修士。”[^p442-69] 869年反佛提乌斯会议，生动显示差异：首席佩剑官（protospatharius）狄奥多若，应教宗使节询问，确认已告解；使节问，向谁，是否司祭；他答，不知道对方是不是司祭，却知道已剪发，并在柱上住了40年。[^p442-70]

### 结论

有人认为，十一世纪起，悔罪性质剧变。文本对罪的描述、所定<a id="pdf-443"></a><!-- PDF page 443; original page 414 -->补赎，主要禁食时段，都关心“外在行为”；可折换更短、更严禁食，也可变为祈祷、付款。据说，十一世纪后半叶，外在性让位于更重“内在性”，形成重内心动机、过于行为的罪观，真诚痛悔，也压倒禁食、其他行为所提供的补赎。格列高利七世（1073—1085年）关心真悔，预示十二世纪，彼得·阿伯拉尔（1079—1142／1143年）等探究者，深入人心秘密。[^p443-71] 但看早期文本，尤其定额表所附教导、礼仪论著，就立即清楚，已有强烈倾向，考察罪人内在动机、被引犯罪的情境、悔改真诚。因此，罪、悔罪观的“内在性”，并非十一、十二世纪发明，虽经院文本，确实更敏锐探索。内心重要性，一直不同程度，属于传统，实际未必充分发挥。经院方法，对灵魂照护影响，必远更大；但大学者罗伯特·格罗斯泰斯特（约1170—1253年）的悔罪论，也显示简单定额需求，并未随新文本消失。[^p443-72] 历史远不如过去设想那样，单一、不断进步；这让调查人们认罪、补赎的不同方式，更丰富、有益。[^p443-73]

回看本期，有几项主要发展。第一，东西方修士，都在告解实践发展中重要。但九世纪起，路径分开；希腊世界，更由修道主导，西方，在俗教士、司祭、<a id="pdf-444"></a><!-- PDF page 444; original page 415 -->主教，却越来越能控制过程。西方悔罪，似更受文本“编写脚本”；各种罪、补赎行为，详加描述，九世纪起，发展繁复礼仪。同时，越来越多生活层面，被看作罪、悔改问题：不只婚内外各种性行为、饮食、大量暴力、巫术，也包括欲望、嫉妒、愤怒。确可说，世界日益“罪化”。[^p444-74] 本期末，大部西欧堂区结构发展，加上告解、悔罪文本增多，为定期告解奠基，十二世纪已确实存在。中世纪后期，虽仍多种悔罪形式，在俗教士控制、监督过程的努力，却导致更强调正式方式。
