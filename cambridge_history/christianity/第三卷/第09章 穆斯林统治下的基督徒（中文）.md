# 第09章 穆斯林统治下的基督徒

西德尼·H. 格里菲斯（Sidney H. Griffith）

<a id="pdf-226"></a><!-- PDF page 226; original page 197 -->

到公元732年，也就是先知穆罕默德去世仅100年后，阿拉伯军队已经以伊斯兰教之名，巩固了对阿拉伯半岛以外大片领土的霸权。这片地域，涵盖古代晚期罗马帝国、波斯帝国的广大部分，其中有许多属于不同宗派的本土基督教团体。他们全都进入穆斯林统治之下，但从人口看，直到十一世纪相当晚的时候，许多地方仍以他们所属的宗教为多数。在西班牙（安达卢斯）、罗马帝国原有东方诸牧首区，以及波斯美索不达米亚，都有强大的基督教团体。[^p226-1] 希吉拉，即伊斯兰纪元最初四个世纪中，穆斯林哈里发的大多数基督徒臣民，逐渐采用了阿拉伯语；与此同时，视当地情形，他们也不同程度地保留传统语言、教父语言和礼仪语言，供教会使用。

### 《古兰经》及早期伊斯兰教中的基督徒

《古兰经》最初以其所称的“明白的阿拉伯语”，向人们传达上帝话语时，听众之中就有讲阿拉伯语的基督徒（《古兰经》16:103、26:105）。事实上，《古兰经》预设，《讨拉特》和《引支勒》在听众意识中具有优先地位，并坚持说，相对于此前的神圣启示，它本身是“一部以阿拉伯语印证〔以前经典〕的经书，警告作恶者，向行善者报喜”（《古兰经》46:12）。《古兰经》中，上帝告诫穆斯林：“如果你怀疑我们降示给你的，就去问那些在你之前诵读经典的人。”（《古兰经》10:94）

<a id="pdf-227"></a><!-- PDF page 227; original page 198 -->

《古兰经》预设读者熟悉《旧约》《新约》主要人物的故事，以及丰富的犹太、基督教传说、信仰和习俗。它也警告基督徒，宗教上不要过分，不要“追随一群人的妄想；他们过去迷失，也使别人迷失，自己又偏离正道”（《古兰经》5:77）。它对基督教信仰与实践提出批评。这类经文中，直接向基督徒说话、内容最全面的一节说道：

> 有经的人们啊，不要在宗教中过分；关于上帝，只可说实话。弥赛亚、麦尔彦之子尔撒，只是上帝的使者，是他传给麦尔彦的言辞，是来自他的精神。你们应信上帝及其使者，不要说“三”。停止吧！这对你们更好。上帝只是独一的上帝；他崇高无比，绝不会有任何事物成为他的儿子，无论在天上，还是在地上。上帝足为监护者。（《古兰经》4:171）

这种批评显示了对基督教教义相当程度的了解；而《古兰经》又预设，直接听众中有基督徒，因此便产生一个问题：穆罕默德时代阿拉伯半岛的基督徒，究竟是什么人？文本本身却没有为解答提供多少帮助。它有一次提到“福音之民”（《古兰经》5:47），约14次提到“拿撒勒人”，在这些语境中，显然指基督徒。但事实上，《古兰经》从不使用“基督徒”一词，而大多把基督徒连同犹太人，归入它所说的“有经人”或“经典之民”（《古兰经》中共54次）。

阿拉伯语《古兰经》谈到“那些说‘我们是拿撒勒人’的人”（《古兰经》5:14、82）时，所指想必是讲阿拉伯语的基督徒。这里的阿拉伯词al-Naṣārā，可能反映同源叙利亚词Naṣrāyê，意思是“纳佐拉人”或“拿撒勒人”；生活在波斯帝国的东叙利亚作者，常在叙利亚语作品中用此词称呼基督徒，尤其在转述非基督徒对基督徒的称呼时。可以合理推测，阿拉伯语／《古兰经》的用法，也沿袭了这一习惯。虽然早期穆斯林也接触到埃及、埃塞俄比亚的基督徒，但在伊斯兰教最初宣讲的直接地理环境中，较大的阿拉伯语基督教团体，都与西奈、巴勒斯坦、外约旦、叙利亚、美索不达米亚南部，甚至阿拉伯半岛南部的教会团体有联系。他们所属的团体，其礼仪、教义和教会联系，最初都属于阿拉米语传统。

在西奈、巴勒斯坦和外约旦，拜占庭式正统信仰自五世纪中叶起，正式占据主导地位，众多国际性修道团体以希腊语为主要教会语言；当地教会所用的阿拉米语方言，则是基督教巴勒斯坦阿拉米语。[^p228-2] 在叙利亚和美索不达米亚，本地基督教团体横跨罗马、波斯帝国边境，普遍拒绝拜占庭帝国正统信仰；这里作为主要教会语言的阿拉米语方言，是叙利亚语。

穆罕默德时代，大多数讲叙利亚语的基督徒，接受的基督论表述，呼应亚历山大的圣区利罗（444年卒）早期神学，并在安提阿的塞维鲁（约465—538年）的希腊语著作，以及马布格的斐洛克塞努斯（约440—523年）的叙利亚语著作中，得到最充分的阐明。他们也推重纳尔赛（503年卒）、大巴拜（551／552—628年）的叙利亚语作品；后两者反映了一个世纪前，摩普绥斯提亚的狄奥多若（约350—428年）原用希腊语阐发的立场。[^p228-3] 在讲阿拉米语或叙利亚语的民众团体中，主要有三个基督教宗派；这些团体中讲阿拉伯语的同教者，很可能就是《古兰经》听众中的“拿撒勒人”。后来基督教、穆斯林作者，都会把这三个宗派称为“麦勒凯派”“雅各派”“涅斯托里乌斯派”。[^p228-4]

直到七世纪最后几年，伊斯兰资料对基督徒的注意，仍仅限于某些条约文本和约定条件中，偶尔提到教堂、教会人士及其公开仪式；这些条件使征服后的日常生活得以延续。后来，这些条款经过汇集、编辑，获得正式效力，成为《欧麦尔盟约》。穆斯林法学家逐渐认为，这份法律文书，为《古兰经》关于有经人的一般训令，提供了某种权威性规定；即穆斯林应与他们作战，“直到他们亲手缴纳人头贡税（al-jizya），并表示顺服（ṣāghirūna）”（《古兰经》9:29）。[^p228-5]

穆斯林—基督教对抗中，一种象征性的公开现象，明显宣示了伊斯兰教在已经稳固占领的土地上，争取社会霸权的要求，也标志着严肃的宗教间讨论开始。这就是哈里发阿卜杜勒·马利克（685—707年）及其诸子、继任者，大致在八世纪最初三分之一时期开展的行动：从<a id="pdf-229"></a><!-- PDF page 229; original page 200 -->文化和政治方面展示伊斯兰教，从而在象征上把阿拉伯人占领的土地，纳入新的政治效忠关系。从宗教角度看，这项展示伊斯兰教的计划，有两个主要特点。积极方面，是借石材、灰浆和钱币，在各地公开宣示伊斯兰信仰的清真言，即沙哈达（shahāda，作证）；消极方面，则是相应开展抹除基督教公共象征的运动，尤其针对无处不在的十字架。积极展示中，最引人注目的举措，是哈里发阿卜杜勒·马利克在耶路撒冷，为伊斯兰教建造的纪念建筑——圆顶清真寺；其明确反对基督教的铭文，基本取自《古兰经》。[^p229-6] 不过，后续影响也许最深远的政策，是哈里发欧麦尔二世（715—720年）推动所有穆斯林平等的计划，无论他们是阿拉伯征服者，还是新改宗者。[^p229-7] 这一政策，成为八世纪中叶促成阿拔斯革命的运动政治纲领的一部分，开启古典伊斯兰文化成长、发展的时代。就社会而言，这些变化也影响了哈里发治下的基督徒。它们很可能使皈依伊斯兰教，成为比以往更具吸引力的社会选择，尤其对那些更积极向上流动的基督教家庭。到阿拔斯革命时期，历史条件开始有利于阿拉伯半岛外被占地区的基督教团体，既努力适应伊斯兰文化，又用新政体自身的语言方式，抵御其宗教挑战。

### 阿拉伯语基督教

文化适应的第一步，是教会采用阿拉伯语。出于若干原因，似乎麦勒凯派团体最先迈出这一步；他们的教会、文化中心，是耶路撒冷及其周边修道体系。[^p229-8] 不久，其他教会也纷纷效法。到九世纪中叶，麦勒凯派、雅各派和涅斯托里乌斯派，都能熟练使用阿拉伯语；到十世纪中叶，埃及科普特人也加入这一行列，并逐步走向十三世纪阿拉伯语基督教文献主要生产者的地位。[^p229-9] 八、九世纪，伊斯兰世界基督教团体所制作的阿拉伯语文献，数量<a id="pdf-230"></a><!-- PDF page 230; original page 201 -->最多的，无疑是圣经、教父著作和各教会礼仪经典的翻译。这些译本大多以希腊语、叙利亚语原文为基础。可以认为，这种翻译活动，加强了伊斯兰世界基督教团体的身份认同，正如同一时期巴格达穆斯林学者中相应的翻译运动，塑造了阿拔斯精英的文化生活；两者都发生于古典阿拉伯—伊斯兰文化的形成时期。[^p230-10]

正是在这一背景下，八世纪，基督教团体在文献中回应伊斯兰宗教挑战的觉醒，开始出现。最早文本出自叙利亚／巴勒斯坦，使用希腊语、叙利亚语和阿拉伯语。起初，叙利亚语作者以启示文学的方式，回应伊斯兰教的建立。他们借助圣经《但以理书》的预言段落，解释新的社会政治安排。[^p230-11] 总体上，他们认为，伊斯兰征服是对基督徒罪行的惩罚，有其期限，最终将随着弥赛亚统治的恢复而结束。这类文本中，最著名的是《伪帕塔拉的美多迪乌斯启示录》，八世纪最初几年原用叙利亚语写成。[^p230-12] 它很快被译成希腊语、拉丁语，又经这些版本迅速进入近代早期欧洲语言，对中世纪西方基督徒伊斯兰观的形成，产生巨大文学影响。〔译注：本句“近代早期”与紧随的“中世纪”时序，依原文保留。〕但不久，被征服地区的基督徒，便开始以护教乃至论战短篇，回应伊斯兰教的召唤；这些作品使用希腊语、叙利亚语、阿拉伯语，主要面向基督徒读者。

西方人最熟悉的短篇，载于大马士革的约翰（约749年卒）在巴勒斯坦撰写的划时代希腊语著作《知识之泉》，其中《论异端》部分第100章。[^p230-13] 学界对这章论“以实玛利人的异端”的文字，是否确出约翰之手，讨论很多；但它显然出自八世纪麦勒凯派环境，极可能就是约翰本人的作品。其重要性在于，作者固然敌视伊斯兰教，也不避讽刺歪曲其教义、实践，却显然掌握丰富知识，尤其了解伊斯兰教对基督教信仰和行为的看法。事实上，他讨论的题目，将在此后数百年里，成为穆斯林／基督教护教与论战的标准议题。不过，他的作品也是<a id="pdf-231"></a><!-- PDF page 231; original page 202 -->伊斯兰世界中唯一一部使用希腊语的同类作品。此后，从九世纪起，关于伊斯兰教的希腊语基督教文本，都产生于拜占庭；其性质压倒性地属于论战，以至掩盖了护教层面。[^p231-14] 主要目的，是贬低，乃至嘲弄穆罕默德、《古兰经》和伊斯兰教。750年代以后，基督徒用叙利亚语、阿拉伯语撰写的作品，则有所不同。这里，护教是主要关切。这种护教，常常以伊斯兰教自身的宗教表达方式，向基督徒和穆斯林推荐基督教，或某种基督论表述的真实性。作品固然常含论战成分，例如主张伊斯兰教并非真宗教，但其首要目标，是以理据捍卫基督教，或某一特定基督教信经表述。

伊斯兰教的挑战，使讲叙利亚语、阿拉伯语的基督徒，提出了一系列此前在基督教思想中未曾出现的护教与神学策略。在这一背景下，对圣经与《古兰经》的解释、传统基督教神学与伊斯兰传统之间，相互作用，催生出面貌新颖、并不熟悉的基督教神学。它们相当程度地促进了两者日益疏远：一方是西方基督教世界讲希腊语、拉丁语的基督徒，另一方是伊斯兰共同体中主要讲叙利亚语、科普特语、阿拉伯语的基督徒；到中世纪盛期，这种疏远将成为双方敌意的重要特征。

东方的若干教会团体，即讲阿拉伯语的基督徒和穆斯林都称为麦勒凯派、雅各派、涅斯托里乌斯派的那些团体，直到穆斯林时代，才最终界定各自独立的宗派身份。穆斯林以阿拉伯语询问他们的教义差异，他们自己的基督教对手也提出质疑；主要正是对此作出回应的需要，迫使各宗派代言人，用阿拉伯语尽可能清楚地阐述彼此不同的基督论。对基督徒而言，新现象不仅是同穆斯林谈话改用阿拉伯语，他们彼此间的交流和争论，也开始用阿拉伯语进行。

伊斯兰教兴起之前，涅斯托里乌斯派和雅各派，已经是社会上可以辨认的团体；其通行名称，为希腊语、叙利亚语作者广泛使用。但那些后来被对手称为麦勒凯派的人，<a id="pdf-232"></a><!-- PDF page 232; original page 203 -->是在第三次君士坦丁堡会议（680—681年）之后，才于伊斯兰时代成为社会学、教义上独立的基督教团体。现代，“麦勒凯派”这一名称，仅用于“希腊礼天主教麦勒凯派”（Rūm Catholiques）。最初的麦勒凯派，大部分讲阿拉米语、阿拉伯语，维护从第一次尼西亚会议（325年），到第三次君士坦丁堡会议的前六次大公会议正统信仰。他们生活在伊斯兰世界；尽管成员遍及哈里发国，耶路撒冷主教座和圣地修道院，成为其教会归属的参照中心。他们的教父、礼仪遗产，主要属于希腊语传统，首要神学家是大马士革的约翰；约翰的教导很快以阿拉伯语广为传播，最初见于狄奥多若·阿布·库拉（约755—约830年）的著作。[^p232-15]

哈里发国在近东地图上划出新的文化、地缘政治界线以后，情形便不同于伊斯兰教兴起之前：涅斯托里乌斯派和雅各派——包括科普特人、埃塞俄比亚人、亚美尼亚人——成为基督徒中的多数；相比之下，新生的麦勒凯派团体，此时规模小得多，其拜占庭同教者又在伊斯兰世界边界之外。到公元九世纪，所有这些教会团体都已能用阿拉伯语发声；他们开展翻译，撰写神学、护教、论战短篇，不仅回应伊斯兰教的宗教挑战，也常回应彼此。[^p232-16]

九世纪三宗派的阿拉伯语基督教作者，如麦勒凯派的狄奥多若·阿布·库拉、雅各派的哈比卜·伊本·希德马·阿布·拉伊塔（约851年卒）、涅斯托里乌斯派的安马尔·巴斯里（约850年活跃），不仅论证基督教而非伊斯兰教是真宗教，也论证自己宗派的神学、基督论表述，代表真正的基督教。这些团体中后世的作者，如雅各派的叶海亚·伊本·阿迪（893—974年）、涅斯托里乌斯派的尼西比斯的以利亚（975—1046年）、麦勒凯派的亚历山大的欧提基乌斯（877—940年），也都沿袭这一做法。与此同时，穆斯林学者、作者注意到这种发展。阿布·伊萨·瓦拉克（约860年卒）、穆尔太齐赖派教义学家阿卜杜勒·贾巴尔·哈马达尼（1025年卒），以及安达卢斯论战作者伊本·哈兹姆（994—1064年）等人，开始认真考察身边的三个基督教宗派。事实上，这时所有雅各派、涅斯托里乌斯派，都生活在伊斯兰世界内部，只有麦勒凯派，以及较晚的马龙派，在<a id="pdf-233"></a><!-- PDF page 233; original page 204 -->哈里发国以外有同教者。因此，若从团体形成的角度，而不单从神学、基督论面貌看，近东三个传统基督教团体的标准宗派定义，全都以叙利亚语或阿拉伯语表述。这些定义，在各宗派作者撰写的编年史和历史著作中最为清楚；他们借这些作品，为本团体在穆斯林统治下的经历发声。他们属于伊斯兰文化世界，与西方讲拉丁语、希腊语的基督徒隔绝，并在很大程度上疏远。颇能说明问题的是，十字军时代以后，后者越来越多地来到伊斯兰世界，却与当地基督徒分开生活，而且关系往往紧张。

### 穆斯林统治下基督徒的文化

从巴格达到科尔多瓦，基督徒的团体生活，逐渐丧失从前占主导地位的公共存在，基督徒也逐步融入已经清晰可辨的“伊斯兰世界”。阿尔伯特·胡拉尼恰当地描述道：

> 到伊斯兰纪元三、四世纪（公元九、十世纪），一种清晰可辨的“伊斯兰世界”已经出现。周游世界的旅人，凭所见所闻，便能判断某地是否由穆斯林统治、居住……于是到十世纪，近东和马格里布的男女，生活在一个以伊斯兰教界定的宇宙中……时间由每日五次礼拜、每周清真寺讲道、每年斋月斋戒与麦加朝觐，以及穆斯林历法标示。[^p233-17]

伊斯兰世界的基督徒采用阿拉伯语后，阿拔斯王朝第一个世纪的神学作者，如阿布·库拉、阿布·拉伊塔、安马尔·巴斯里，共同用阿拉伯语形成了回应伊斯兰教挑战的独特神学。这种神学，兼具分量相当的论战和护教成分，既回应穆斯林挑战者，也同时针对伊斯兰世界其他基督教团体中的神学对手。其论述因此具有清晰可辨的文献、概念面貌，不易被误认为其他论述共同体的基督教神学。在用阿拉伯语有理据地阐述三位一体、尤其道成肉身的教义时，他们试图<a id="pdf-234"></a><!-- PDF page 234; original page 205 -->运用当时伊斯兰思想关于上帝属性——《古兰经》所谓“上帝的美名”——之本体地位讨论的术语，表述三位一体；道成肉身，则用《古兰经》先知论的独特语言表述，再辅以对各团体传统基督论表述的辩护。这一神学发展，成为伊斯兰世界阿拉伯语基督教神学论述的传统；此后数百年，许多作者加以改进，但直到现代，几乎从未放弃。它只有在阿拉伯语伊斯兰环境中，才具有意义、可理解性和说服力，难以转译成西方神学语言。它也支撑了一种基督教对穆罕默德、《古兰经》和伊斯兰教的评价方式，与同时期基督教西方希腊语、拉丁语或其他语言中的几乎所有表述，都极为不同。[^p234-18] 其中存在这样的意愿：不仅承认挑战，也承认这是一个机会，可以运用宗教他者的范畴，以新的调式，表达基督教对自身真实性的主张。

因此，基督徒适应伊斯兰世界生活的第一个阶段，不仅带来新的教会语言，也开启新的神学发展。第二阶段，大致从850延续到1050年，哈里发国、尤其巴格达的基督教学术，为整个伊斯兰世界的知识生活作出重大贡献。早期神学发展，甚至在伊斯兰世界以外的基督徒中，都几乎无人知晓；相比之下，本土基督徒对巴格达希腊语—阿拉伯语翻译运动的贡献，却广为人知，常获西方学者讨论。[^p234-19] 时至今日，西方历史学家仍很可能熟悉“阿拉伯基督徒”的名字，如侯奈因·伊本·伊斯哈格（808—873年）、叶海亚·伊本·阿迪（893—974年）、阿布·阿里·伊萨·伊本·伊斯哈格·伊本·祖尔阿（943—1008年）。这里仅举三位，他们积极参与，把希腊—罗马世界的哲学、科学、医学著作译成阿拉伯语，通常以希腊语原著较早的叙利亚语译本为基础。亚里士多德的许多作品尤其重要；其阿拉伯语译本，对于法拉比（870—950年）、伊本·西那，即阿维森纳（980—1037年），以及伊本·鲁世德，即阿威罗伊（1126—1198年）等世界级阿拉伯语哲学家的思想发展，发挥重要作用，更不用说犹太人摩西·迈蒙尼德<a id="pdf-235"></a><!-- PDF page 235; original page 206 -->（1135—1204年）、基督徒巴尔希伯来（1226—1286年）等博学的非穆斯林阿拉伯语学者。[^p235-20] 当然，这些名字，大多是通过另一场翻译运动，为中世纪盛期西方学者熟悉的，即十一、十二世纪与科尔多瓦、托莱多、巴塞罗那等中心相关的翻译运动。那里，希腊语哲学家、科学家的作品，从阿拉伯语版本译成拉丁语，又点燃另一场知识复兴。[^p235-21]

在叙述征服至十二世纪初——基本上直到西方十字军闯入伊斯兰世界——期间穆斯林统治下基督徒的历史时，不能忽视他们在人口上的强大存在；即使在巴格达这样的典型伊斯兰地点，也同样如此。这座763年建成的城市，原意就是卓绝的伊斯兰城市，却逐渐拥有数量可观的教堂、修道院，甚至一个基督徒街区。[^p235-22] 在这一时期的阿拔斯社会，基督教医生、科学家、文官、宫廷官员和知识分子随处可见，许多人来自显赫的涅斯托里乌斯派家族。[^p235-23]

亚里士多德哲学家、逻辑学家、雅各派的叶海亚·伊本·阿迪（974年卒），可作为一个典范，说明至少在十世纪巴格达这样伊斯兰世界中心的某些地方，共处（convivencia）能够达到多高程度。任何关于当时知识生活的叙述，如果至少没有提到这位基督教哲学家，都不完整。他曾在一代人的时间里，领导巴格达亚里士多德学派圈子。他本人师从涅斯托里乌斯派基督教逻辑学家阿布·比什尔·马塔·伊本·优努斯（940年卒），以及穆斯林哲学家法拉比。后来，叶海亚又教导了一整群学生，有穆斯林、有基督徒，有雅各派、有涅斯托里乌斯派；历史学家今天仍熟悉他们的名字，视他们为白益时代人文主义“伊斯兰文艺复兴”的重要人物。[^p235-24] 从叶海亚本人的作品可知，他设想一种社会：献身知识和科学的穆斯林、基督徒，可以携手追求哲学。他说，他们也应关注教堂、清真寺的礼拜，目标是“使人关心永生”。[^p235-25] 人们不能不注意，他选择了跨宗教词汇，表达自己的理想。但伊斯兰社会许多人，无论基督徒还是穆斯林，<a id="pdf-236"></a><!-- PDF page 236; original page 207 -->实际上都不满某些极享特权的地方，团体之间关系如此融洽。许多基督徒抱怨迫害和虐待；许多穆斯林则不满非穆斯林享有言论自由。

谈到这里，可以引述公元十一世纪作者阿布·阿卜杜拉·伊本·穆罕默德·胡迈迪（1095年卒）所编西班牙阿拉伯人传记辞典中的一段有趣文字。他记述一个叫阿布·欧麦尔·艾哈迈德·伊本·穆罕默德·伊本·萨迪的人，十世纪末、叶海亚·伊本·阿迪死后不久，来到巴格达。阿布·欧麦尔在那里，两次参加城中著名穆斯林学者的聚会，却发誓永不再去，因为所见使他震惊。据说，他这样讲述自己的经历：

> 我第一次参加聚会，看见各色群体汇聚一堂：逊尼派穆斯林与异端，以及各种不信者——拜火教徒、唯物论者、无神论者、犹太人、基督徒。
>
> 每一群体都有领袖，阐述本派教义，并加以辩论。无论来自哪一群体，每逢领袖抵达，全体便起身迎接，一直站到他坐下，然后才落座。聚会挤满人，大家知道不会再有人来时，一位不信者说：“你们都同意辩论，所以穆斯林不得依据你们的经典或先知言论反驳我们，因为我们不信经典，也不承认他。我们只能凭理性论证，以及观察、推论能够支持的根据相互辩论。”众人就都说：“同意。”阿布·欧麦尔说：“听见这话，我就不再参加那个聚会。后来，有人告诉我又有一场讨论会，我去了，发现他们的做法，与那些同伴相同。从此，我不再参加论辩者的聚会，再也没回去。”[^p236-26]

显然，阿布·欧麦尔可视为阿拔斯后期穆斯林传统主义者的代言人；在叶海亚·伊本·阿迪时代，他们很可能占多数。他明确反对伊斯兰共同体不同宗教团体的知识分子之间，那种极其融洽、而叶海亚本人热衷促进的交流。

十二、十三世纪，阿拉伯基督教文化发展的重心，从巴格达和东方，向西转移至埃及。科普特人直到十世纪，才开始用阿拉伯语撰写神学，把<a id="pdf-237"></a><!-- PDF page 237; original page 208 -->教会书籍译成占主导地位的文化语言。我们知道名字、最早经常用阿拉伯语写作的科普特人，是塞维鲁·伊本·穆卡法（约905—987年）。在阿拉伯语世界，他的护教作品，是抄写最频繁、流传最广的阿拉伯语基督教文本之一。[^p237-27] 塞维鲁·伊本·穆卡法以后，阿拉伯语迅速成为科普特人的主要语言；他们后来制作的阿拉伯语文本，比哈里发国其他所有基督教团体加起来还多。

公元十三世纪，埃及迎来了许多人所谓阿拉伯基督教文学的黄金时代。[^p237-28] 一个卓越的基督教抄写员、作家家族的活动，象征了这一时代；他们统称“阿萨尔诸子”（Awlād al-ʿAssāl），活跃于该世纪中期（1230—1260年）。其中有三位主要人物：阿斯—拉菲、希巴图拉和穆塔曼；他们开展了令人瞩目的手稿搜访计划，抄写、翻译，并用阿拉伯语创作原创基督教神学著作。[^p237-29] 他们工作的一项突出特点，是明显的跨教会性质：无论作者是涅斯托里乌斯派、雅各派还是麦勒凯派，只要能找到，就不懈搜求最优秀的阿拉伯语基督教论著。其中的穆塔曼，在权威著作《宗教原理纲要》中，论述所有基督教团体、宗派，虽然神学不同，却同样宣认对基督的信仰；他可能受一位较早作者启发，即阿布·阿里·纳里夫·伊本·尤姆恩（983年后卒），一位属于巴格达雅各派叶海亚·伊本·阿迪圈子的麦勒凯派人士。[^p237-30]

最后，科普特人中还有沙姆斯·里阿萨·阿布·巴拉卡特，常以伊本·卡巴尔之名为人所知（1321年后卒）。他用阿拉伯语撰写了一部几乎可称基督教神学百科全书的作品，汇入来自各团体许多早期作者的文本。这部作品，几乎就是一部涵盖阿拉伯语基督教神学及教会实践从起源到十三世纪的工具书。[^p237-31] 他称其为《黑暗中的明灯》。这个题名，让人想到穆斯林统治下基督徒日益经历的种种困难、限制，尤其在十字军东征之后，以及埃及马穆鲁克长期统治（1254—1517年），乃至更广泛的阿拉伯语伊斯兰世界中，基督徒人口开始长期衰减的岁月。

### “契约之民处境”的悲哀

伊斯兰共同体最初五百年中，穆斯林统治下的基督徒，无疑开启了基督教历史的新篇章；西方历史学家，却迟迟没有细读这一篇章。从内部看，基督教生活、思想，都有引人注目的发展，清楚见于近东三个主要基督教宗派的阿拉伯语文本。从外部看，基督徒对古典伊斯兰文化成长、发展的贡献，在许多方面非同寻常。但尽管有这些成就，直到十字军时代，基督徒在哈里发国的经历，虽构成强大、忠诚的宗教见证，事实上却并不全然幸福。自伊斯兰征服伊始，基督徒就不断见证，他们在穆斯林手中遭受的多重苦难。编年史和其他文类，持续记录了长久的剥夺，乃至间歇性的迫害。

穆斯林统治下基督徒的历史，是一部持续、尽管渐进的衰减史。几个世纪里，他们在许多被征服地区的人口，从十字军时代之前的绝大多数，到奥斯曼时代，缩减为伊斯兰世界大部分地区中具有一定规模的少数。因而，穆斯林统治巩固的历史，也是基督教在伊斯兰共同体中公共存在衰退的历史。除了新的宗教效忠，对被统治基督教团体中寻求向上社会流动者具有吸引力，从而造成自然流失以外，这种渐进衰减的直接原因，很难确指。但其中有一个因素，尚未获得应有的学术关注，即伊斯兰法理论上规定的基督徒社会处境；最方便的名称，也许就是新造词“契约之民处境”（dhimmitude）。

《古兰经》谈到，应向生活在伊斯兰世界的有经人征收特别人头贡税（jizya），他们缴纳时，应表现出相应的顺服、低下社会姿态（《古兰经》9:29）；后来，这些要求由《欧麦尔盟约》的条款加以规范。历史上，这项税被解释为一种代价：伊斯兰政府因此对伊斯兰社会中的有经人，承担特别的“保护”（al-dhimma）或责任；相当于为依附者负责，而且这个阿拉伯词的动词词根，也并非没有贬抑意味。具有这种地位的人，被冠以阿拉伯语形容词dhimmī，意指处于伊斯兰政府保护和责任<a id="pdf-239"></a><!-- PDF page 239; original page 210 -->之下的人，新词dhimmitude即由此而来。[^p239-32] 穆斯林治下的基督徒人口，被视为契约之民；他们往往通过自己的领袖接受治理，这种安排，可借用奥斯曼晚期的名称，称为“米利特制”。“米利特”（millet），是阿拉伯词milla（复数milal）的土耳其语形式，在这里表示“宗教宗派或信经共同体”，同时含有某种政治或“民族”的独特性。[^p239-33] 阿拔斯时期，理论上，正式的基督教领袖，是居住巴格达的涅斯托里乌斯派教会总主教／牧首。

毫无疑问，直到十字军时代，伊斯兰世界的契约之民，都是“二等公民”。支配他们生活的法律限制，要求他们居于从属地位，往往还规定穿戴特殊服饰、停止公开展示宗教；当然，更不得招徕穆斯林改宗。此外，基督徒的财富、建筑、机构、地产，常遭没收。[^p239-34] 因此，随着时间推移，主教区、教堂、修道院和学校数量逐渐减少，成为伊斯兰教被确立为政体公共宗教所固有条件的牺牲品。这些处境，必然使基督教团体等契约之民群体处于风险中；尽管人数众多，他们仍成为社会学意义的少数群体，是受到歧视、限制，有时甚至迫害的从属人口。相应地，这种不利生活处境，不可避免地促使他们既形成适应的论述，也形成抵抗的论述；既尝试哲学或宗教上的接近，也创作思想颠覆和殉道的文学。

殉道传记，在穆斯林治下基督徒中很受欢迎。讲述伊斯兰时代殉道者，即所谓“新殉道者”的少数作品，大多有意识地在描述苦难、尤其人物讲话时，唤起对古代殉道者的记忆：那些人在君士坦丁（324—337年在位）以前，遭受罗马皇帝迫害。新的殉道传记，以希腊语、叙利亚语、科普特语、阿拉伯语，甚至伊斯兰西班牙的拉丁语写成，叙述基督教殉道者与穆斯林当局之间致命的冲突，细节丰富，几乎不经意间，就包含了穆斯林治下基督教生活<a id="pdf-240"></a><!-- PDF page 240; original page 211 -->沉浮的记述。[^p240-35] 在殉道者与迫害者的文学交锋中，殉道者总能胜过审问者。对作为契约之民的基督徒读者而言，这里的潜台词并不隐晦：尽管表面种种现象似乎相反，他仍应确信，基督教确是真宗教。作品也清楚暗示，基督徒实际上拥有圣经和理性论据，可以证明自身道德上的优越；只要已经确立的伊斯兰教，其压迫性权力允许听众接受，就能接受有说服力论证所必然导出的结论。不过，穆斯林治下基督教团体的殉道叙事，事实上相对较少。基督徒虽处于契约之民地位，却参与伊斯兰世界的文化生活，这意味着殉道传记惯常传达的信息，也必须借其他文类表达。

哈里发国讲阿拉伯语的基督徒中，一种流行的通俗护教、论战文类，经常描写一位修士或其他基督教显要人物，在哈里发或埃米尔宫廷中接受盘问。[^p240-36] 这些由基督徒写给基督徒的文学对话，有时基于众所周知的历史会面，往往则只是以历史形式呈现的、合乎现实的虚构。如同殉道传记，作品中的修士总能战胜审问者。不能忽视的是，在引人入胜、充满机智交锋的故事背景中，这些叙事确实为穆斯林惯常向基督徒提出的宗教问题和挑战，提供了现成答案。这一特点，也许解释了为什么这些作品，在穆斯林治下基督徒中长盛不衰。

穆斯林一方，也持续产生反对基督徒、基督教的论战短篇。[^p240-37] 从九世纪到十字军时代，尤其在十三世纪蒙古入侵、1258年巴格达遭摧毁以后，伊斯兰关于宗教间关系的著述中，可以察觉一种明显趋于强硬的态度。伊本·泰米叶（1263—1328年）的《正确的答复》（al-Jawāb al-Ṣaḥīḥ），预示了后来将出现的立场；该书确立了对待契约之民的一种鲜明、影响广泛的强硬做法，将在后来更具传统主义色彩的穆斯林圈子中，产生巨大影响。[^p240-38]

十三世纪埃及阿拉伯语基督教文学的黄金时代以后，基督徒当然继续用阿拉伯语写作，也常在<a id="pdf-241"></a><!-- PDF page 241; original page 212 -->伊斯兰社会中担任显要职位。但此时，他们文化的独特面貌已经形成，为求生存而斗争的起伏，吸收了教会越来越多的精力。奥斯曼时期，以及后来的殖民统治下，许多穆斯林治下基督徒，与伊斯兰世界以外的基督徒结成保护关系。实践中，这一步往往又使他们进一步分裂；随着许多东方基督徒移居西方，这种情形也加快了现代的人口衰减。
