# 第11章 北方边疆：基督教与异教的正面相遇

伊恩·N. 伍德（Ian N. Wood）

<a id="pdf-259"></a>
<!-- PDF page 259; original page 230 -->

### 基督教、偏离与异教

到四世纪末，罗马帝国在官方层面已经基督教化。四、五世纪跨越其边境的蛮族，虽原本信奉异教，大部分很快接受了基督教。到六世纪，这一宗教甚至传播到昔日帝国边界以外。凯尔特西方，尤其爱尔兰，以及日耳曼腹地的图林根人地区，都能发现基督徒。另一方面，即使在旧有核心地区，基督教也绝非整齐划一的宗教。教会领袖或许希望如此，但仅举罗马、君士坦丁堡、亚历山大三位主教，他们对自身宗教的界定，就经常不同。此外，不同地区、群体，采用不同教义和组织模式，既有社会结构，是重要原因。这一点，在爱尔兰这样独特的地区最明显，但基督教世界每一部分，都有自己的实践：既有自己的礼仪，也各自依附不同圣徒和崇敬活动。基督教化的深度，同样令人关切。许多意在保证丰收、安全分娩，预测天气或驱邪的基督教以前习俗，并未放弃；有些实际上直到近代很晚的时候，才会被放弃。重要主教自身的宗教投入，远比大多数居民强烈，他们对宗教及其要求的理解，也与多数平信徒大不相同。西班牙极西部，布拉加的马丁（约520—580年）在一部著作中，猛烈抨击迷信习俗；此后几代教士，面对信仰远不纯正的会众，都取用这部作品。但即使在阿尔勒这样高度城市化的中心，凯撒里乌斯（542年卒），也不认可同城市民的基督教水平。后来的作者，一直延续到十一世纪沃尔姆斯的布尔夏德（1025年卒）及更后世，都摘录凯撒里乌斯<a id="pdf-260"></a><!-- PDF page 260; original page 231 -->和马丁的训诫，因此形成一幅多少同质化的偏离习俗图景。[^p260-1] 实际上，偏离必定与正统一样多样。而且，资料呈现的基督教偏离形象，常使历史学家认为，它界定的是异教，而非基督教。例如，八世纪《迷信与异教习俗清单》（Indiculus Superstitionum et Paganiarum），讨论nodfyr，即两根木棒相互摩擦取火——想必是在特定场合——等习俗时，针对的是基督徒从事的活动，尽管这些仪式起源于异教。[^p260-2] 基督教既不整齐划一，也不纯然无杂。讨论它与异教的交界，必须承认这一点。

进入当时或昔日罗马领土的日耳曼移民，大多数很快改宗，有些却没有。迁往不列颠、定居于后来盎格鲁—撒克逊诸王国的人，继续信奉异教，是不寻常的例子。但这未必意味着，他们的宗教仍是传统形式。关于早期日耳曼宗教，所知很少，也看不出一套连贯信仰。对特定神祇的依附，似乎存在明显地区差异；十三世纪冰岛人斯诺里·斯图鲁松（1179—1241年）著作中那种众神体系观念，何时形成，远不清楚。现代学者熟悉的沃登、托尔、弗雷等神及其地区变体，在中世纪早期资料中，其重要性并不超过我们几乎一无所知、可能在黑尔戈兰受崇敬的福西特，或名字成为英语“复活节”（Easter）词源的埃奥斯特蕾。[^p260-3] 古典和中世纪早期资料，至少同样重视祭祀地点，尤其圣林或物件，最著名的，是大陆撒克逊人的伊尔明苏尔，尽管这根“伊尔明之柱”究竟为何物，并不清楚。假如地点在日耳曼异教中，确如资料暗示那样居于核心，迁徙必然扰乱既有信仰体系。盎格鲁—撒克逊人，不可能把圣林从日耳曼带到不列颠。同时，一到不列颠，他们就遇上以司祭和教堂为中心的既有宗教——基督教。比德（735年卒）谈及盎格鲁—撒克逊异教时，所言不多，却暗示有庙宇、祭司，虽然可能数量有限。十一世纪以前，关于大陆日耳曼异教的资料，几乎完全没有这两者的迹象；例外是弗里西亚西部等曾属罗马，或深受罗马、基督教邻人影响的地区。因此，<a id="pdf-261"></a><!-- PDF page 261; original page 232 -->可以追问，盎格鲁—撒克逊异教，有多大程度是在盎格鲁人、撒克逊人定居不列颠以后，才形成的。[^p261-4]

### 比德的《历史》

英格兰人基督教化的历史，屡经讲述，一个重要原因，是比德提供了无与伦比的叙述。他之前，没有历史学家如此直接聚焦传教历史；他的记述，却影响了八世纪以后的作者。[^p261-5] 就事实而言，他提供的基本轮廓，恐怕永远不会被推翻。[^p261-6] 英格兰传教的主要阶段，始于596年，大格列高利（590—604年）从罗马派遣奥古斯丁和同伴出发。从597年抵达肯特开始，奥古斯丁取得显著成功，不得不再派更多传教士。他登陆后的第一个圣诞节，数千人受洗，但国王是否包括在内，并不清楚，也可能国王早已受洗。此外，由于埃塞尔伯特在英格兰南部的政治支配地位，基督教迅速越出其王国边界。然而，616年国王去世，遏止了最初成功；此后近20年，传教扩展与背教交替发生。除肯特以外，最显著的例子在诺森布里亚。国王埃德温（616—633年）娶埃塞尔伯特的孙女，在620年代中期改宗；但他战死，直接导致异教复兴。630年代以后，传教活动又出现新来源。563年，科伦巴在苏格兰爱奥那岛建立爱尔兰修道院，传教士从这里出发。艾丹（651年卒）以此为基地，在奥斯瓦尔德国王（634—642年）时代，向诺森布里亚传教。奥斯瓦尔德，以及后来其弟奥斯维乌（642—670年），都像埃塞尔伯特一样，在英格兰人中拥有某种霸权，因此也帮助基督教越出本国边界。

如今已清楚，比德的叙述，淡化了英格兰人基督教化的若干方面。[^p261-7] 他实际上把传教士描述为罗马人或爱尔兰人，只稍许提及法兰克人也发挥作用；其他资料，尤其法兰克圣徒传，可以加强这一观察。另一方面，比德不承认不列颠人在基督教化过程中有任何贡献，甚至明确指责<a id="pdf-262"></a><!-- PDF page 262; original page 233 -->他们，没有向最早几代盎格鲁—撒克逊人传教。不过，有证据显示，不列颠东部某些地方，原有基督教存续下来，[^p262-8] 可能影响新来者。西南不列颠人影响英格兰邻居，则可以肯定。[^p262-9]

比德塑造后人对盎格鲁—撒克逊人基督教化的理解，也不只在于着重罗马人、爱尔兰人。[^p262-10] 他描述罗马传教与爱尔兰传教，方式迥然不同，主要由于手头资料。他主要透过大格列高利书信，呈现罗马传教，图景较正式，几乎带有法律主义色彩。相反，艾丹传教的形象，本质上属于圣徒传，由圣人形象主导；比德很可能取材于艾丹的林迪斯法恩修道院流传的传统，或更广泛的诺森布里亚传统。结果，历史学家有时把两种传教对立起来：罗马传教被认为不适应肯特——对他们而言，必定是极陌生的世界；爱尔兰传教，则被认为在诺森布里亚的部落世界如鱼得水。这种对比，也许有几分真实；但差异至少部分由资料造成。罗马官僚组织与爱尔兰神恩感召的对比，在一定程度上，是比德所依赖两类资料的对照产物。这在奥古斯丁本人形象的描绘中，尤其重要：从墓志铭可知，他曾被视为行奇迹者，但奇迹没有被记录；也许因为正如我们所知，格列高利严令他不要谈论这些。传教史有时确实可以很有效地分为神恩感召与组织两类，但这些范畴，是否有助于理解盎格鲁—撒克逊人的基督教化，并不清楚。

### 传教与教会制度

这两种路径在某个传教史阶段，确有意义，那就是七世纪末、八世纪和九世纪初；当时，莱茵河以东的日耳曼广大地区，以及今奥地利东部及边境，先后基督教化。加洛林在这些地区的传教史，很容易从教会制度角度讲述。撒克逊的基督教化，可以被描述为<a id="pdf-263"></a><!-- PDF page 263; original page 234 -->查理曼（768—814年）与异教撒克逊人之间的一系列战争；几乎每次法兰克重大胜利后，都有洗礼和教堂创建，但查理曼注意力一旦转向别处问题，又会出现撒克逊人的军事报复和背教。[^p263-11] 一首约777年写成的《论撒克逊人改宗》（De Conversione Saxonum），最清楚地显示了查理曼误判形势的程度。诗歌描写国王驯服撒克逊人、使其基督教化的成功，后来证明，是一篇为时过早的颂词。[^p263-12] 此外，查理曼两次以撒克逊相关立法巩固胜利；第一次可能颁于782年，强硬推行洗礼、什一税。两项行动都使形势恶化，导致撒克逊人进一步抵抗；也引起加洛林帝国内部批评，尤其阿尔昆主张，必须充分教导以后才能施洗，什一税更应晚得多才开始征收。[^p263-13] 直到785年以后，撒克逊领袖中最成功的维杜金德归顺、受洗，才可能有相对连续的教区建立史。

尽管撒克逊遇挫，使阿瓦尔人基督教化时，仍犯了类似错误；阿瓦尔人是一支匈人族群，五世纪在匈牙利一带立足。796年，在最终摧毁阿瓦尔王国的行动中，召开了一次会议，处理洗礼施行问题。如同撒克逊，征服后不久就征收什一税，再次引起异教反抗。此后当地基督教化的历史，在资料中体现为萨尔茨堡主教派遣司祭、建立教堂。最完整的版本，以非凡细节，记录于约870年撰写的《巴伐利亚人与卡兰塔尼亚人的改宗》（Conversio Bagoariorum et Carantanorum）。[^p263-14]

### 传教士及其传记

军事行动、教会立法、洗礼、征收什一税，以及建立教堂、教区，充斥撒克逊人与阿瓦尔人基督教化的官方叙述。与此同时，还有一部平行的<a id="pdf-264"></a><!-- PDF page 264; original page 235 -->神恩感召史，见于圣徒传。[^p264-15] 它始于查理曼统治前近一个世纪：盎格鲁—撒克逊人威尔弗里德于678年、威利布罗德于690至739年在弗里西亚传教。另一位英格兰人博尼法斯，接续他们的事业；他716年有过一次未成功的旅程，718年抵达大陆，754年在弗里西亚北部向多库姆居民传教时死去。博尼法斯的门徒施图尔姆、卢尔、乌得勒支的格列高利，以及更重要的莱布温、柳德格尔、威勒哈德，继续这一工作，并扩展至撒克逊。卢尔任美因茨主教（754—786年），施图尔姆任富尔达院长（747—779年），柳德格尔（804—809年）、威勒哈德（787—789年），分别任明斯特、不来梅首任主教；他们都可以同教会组织的制度史联系起来。

但另一方面，这些人物的圣徒传，在某些方面呈现的传教图景，并不完全符合查理曼传教政策的官方历史。早在七世纪，威利布罗德就在法兰克世界之外，决定展开传教工作；这个决定是在爱尔兰作出的。博尼法斯也仍在威塞克斯时，就决定向盎格鲁—撒克逊人的大陆亲族传教。威勒哈德延续这一传统，约770年诺森布里亚教会会议派他前往弗里西亚。他似乎直到生涯相当晚期，才引起查理曼注意。换言之，在法兰克国王制定传教战略之前，传教士已在活动。至少一位，传教部分是为了抢在查理曼行动以前。据莱布温（约773年卒）传记，他向撒克逊人讲道，敦促他们在法兰克邻人入侵、强行推行基督教以前，先行改宗。[^p264-16]

圣徒传记录，很有助于补充法律、书信和编年史证据，使我们掌握的图景，更加鲜活直接。不过，将它们作为事实来源，也存在问题，原因却不是人们常以为圣徒传难用的那一种：八、九世纪传教圣徒的传记，并未塞满奇迹，事实上大多叙事极为克制。然而，这些文本，都旨在传达特定信息。[^p264-17] 例如，《博尼法斯传》呈现一系列不同的圣人解释，受到法兰克政治，以及个别<a id="pdf-265"></a><!-- PDF page 265; original page 236 -->基督教中心需求的影响：其中有他的主教中心美因茨、弗里西亚城市乌得勒支，以及他创建、后来安葬于其中的富尔达修道院。博尼法斯始终希望向撒克逊人传教，却从未达到目标。尽管他最终在向弗里斯人传教时被杀，大陆生涯的大部分时间，却用于组织、改革东法兰克、巴伐利亚、黑森、图林根广大地区的教会。这些地方都已基督教化，但博尼法斯的加洛林主君，出于政治原因，希望把它们描绘为半异教地区。八世纪中叶，巴伐利亚、黑森、图林根的统治者，曾反对加洛林统治；诋毁其合法性的方式之一，就是说他们对教会支持不力。因此，《博尼法斯传》夸大了他的传教成就。第二部传记尤其如此，它从乌得勒支立场出发，大大夸张了他的传教活动程度。

其他圣徒传作品，也有不同方面的倾向。例如，阿尔昆（804年卒）似乎借《威利布罗德传》，提出传教活动的典范。[^p265-18] 在他的记述中，主人公从不用强力，完全依靠讲道。虽然传教士自身有时成为暴力受害者，报复却留给上帝。阿尔昆同期书信，也表达这种观念，尤其致阿瓦尔传教领袖之一、萨尔茨堡的阿恩（785—821年）的信。《威利布罗德传》虽有重要章节，描述试图使丹麦国王改宗，以及同福西特、瓦尔赫伦圣所守护者的冲突，但其事实内容用处不大；然而，文本仍使我们深入了解阿尔昆的思想。在某些方面，后来的传教圣徒传作者，其思想更有意思：九、十世纪及十一世纪初，他们经常自己就是传教士。因此，在柳德格尔《乌得勒支的格列高利传》、林贝尔特《安斯加尔传》、奎尔富特的布鲁诺《布拉格的阿达尔伯特传》中，我们看到传教士透过一位受尊崇楷模的生平，探索自己的传教观。林贝尔特、布鲁诺的叙述，很可能有相当可靠的根据；柳德格尔的作品，则值得怀疑。但文本仍很重要，因为它揭示作者对传教工作的态度；这一例子中，其立场与阿尔昆很相近。

### 女性与传教

了解女性在传教中可能发挥的作用，许多证据也来自圣徒传。[^p266-19] 她们当然不讲道，尤其绝不在异教徒面前讲道；事实上，她们很少真正身处传教先锋。然而，博尼法斯书信揭示，他依赖女性通信者，以祈祷、提供书籍给予支持。最著名的是，他请萨尼特女院长埃德堡，用金字抄写《彼得书信》，以打动异教徒。[^p266-20] 女修道院虽然即使曾有，也极少实际位于传教地区，却能发挥重要作用，不只制作书籍、礼服，也深化周边乡村的基督教化。

另一方面，历史和圣徒传叙事，也有女性在异教社会推动基督教的证据。嫁给异教国王的基督教公主，能为打开传教机会发挥宝贵作用。英格兰最为明显：异教徒埃塞尔伯特，娶了法兰克基督教公主贝尔塔；他们的孙女，又嫁给诺森布里亚异教统治者埃德温。但社会地位较低的妇女，也能有影响。根据《莱布温传》，这位确实未获法兰克官方支持的圣人，依靠撒克逊贵族家族，尤其妇人阿瓦尔希尔达的帮助。[^p266-21] 圣人侄子阿尔特弗里德所写的《柳德格尔传》，基本以家族史方式，构想弗里西亚基督教化的历史。[^p266-22] 柳德格尔母亲一方的曾祖母，是坚定异教徒，曾试图把自己的孙女交付仪式性溺杀；相比之下，他父亲一方的祖母，却是坚定基督徒，因把自己的兄弟交给威利布罗德、培养为司祭而著称。更深入异教地区，林贝尔特《安斯加尔传》，叙述两位可能来自弗里西亚的基督教妇女，弗里德堡及其女儿卡特拉；即使向瑞典贸易站比尔卡的传教已经崩溃，她们仍勇敢坚守信仰。[^p266-23] 编年史里看不到这样的人物，立法资料中更没有。圣徒传至少让我们短暂瞥见，女性在异教、基督教交界处，可能发挥的作用。

### 语言的证据

还有一种重要信息来源，能够照亮传教活动，即语言学。[^p267-24] 词语可以揭示观念的某些起源。耐人寻味的是，莱茵河以东地区的基督教词汇，暗示把宗教带入、确立于当地的，并非圣徒传所暗示的盎格鲁—撒克逊人，也并非某些学者主张的爱尔兰人，而是法兰克人。实际上，确有少数迹象，说明法兰克主教在莱茵河以东传教，尤其马斯特里赫特的阿曼杜斯和桑斯的伍尔弗拉姆。[^p267-25] 不过，语文学证据暗示，法兰克教士的影响远为持久，可能由相对次要的人物，长期施加。

因此，不同线索汇合，形成一幅极其复杂、并不总相一致的传教活动图景，延续至虔诚者路易（814—840年）统治初年。法兰克人、盎格鲁—撒克逊人、爱尔兰人的相对贡献，可以争论；查理曼及主教团的官方政策，相对于具有神恩感召力的个人影响，其重要性也可以争论。图景虽并非不断成功，证据却显示，基督教正越来越远地扩展到莱茵河以东，进入多瑙河中游。总体印象是乐观的。

### 斯堪的纳维亚：已知世界的边缘

820年代，虔诚者路易比父亲走得更远，支持向丹麦人传教。[^p267-26] 最初，事业由埃博领导；他于816—834年任兰斯总主教，846—851年任希尔德斯海姆主教，后来因支持路易叛乱的诸子，活动受到中断。但此前，他已看到修士安斯加尔接手自己的传教事业；安斯加尔在864年致日耳曼人路易的信中，也肯定回顾埃博的成就。安斯加尔最初在丹麦，以及829年以后梅拉伦湖一带的斯韦亚人中，取得显著成就。比尔卡岛考古，为九世纪初基督教团体的发展，提供了鲜明支持。[^p267-27] 然而，<a id="pdf-268"></a><!-- PDF page 268; original page 239 -->865年后不久，传记作者林贝尔特记录安斯加尔生平时，却呈现很不同的图景。[^p268-28] 对他来说，向丹麦人传教，是一次令人不安、驶入险境的航程。林贝尔特的看法，部分受一代人挫折影响，这些挫折主要由维京侵袭造成。安斯加尔向丹麦人、斯韦亚人传教，不仅遭到抵抗，另一件同样令人沮丧的事是，他831年升任主教后的传教基地汉堡，于845年遭洗劫。因这场破坏而被并入其教区的不来梅，也在约860年受到攻击。

但林贝尔特对传教工作的敏感，还有另一层面。他对安斯加尔生平的记述，由梦境、异象主导，这些原先由圣人本人记录。有时，它们的语调带有末世论意味，让人感到圣人在世界边缘工作。《马太福音》既把向地极宣讲福音，与世界终结联系起来，林贝尔特真心害怕，就不足为奇。不过，这种恐惧，又与他亲身经历北方传教地相结合。如同师长安斯加尔，他曾在丹麦人、斯韦亚人中工作；但这并未使那个世界，对他而言少一分奇异。学者往往假定，中世纪想象中的怪物，并非真在近旁，林贝尔特却完全预期会遇到。他写信给科尔比院长拉特拉姆努斯，询问碰到犬首人（cynocephali）时，该把他们当动物杀死，还是当人使其改宗。拉特拉姆努斯长篇答复，颇为非凡，结论是：既然他们有社会生活、具有理性，就应被视为人，并接受洗礼。[^p268-29]

林贝尔特在未知边缘工作的感觉，标志传教史的重大转变。在此以前，我们所知的传教活动，主要面向传教士相当了解的民族。诚然，596年前往肯特时，坎特伯雷的奥古斯丁及追随者曾极为恐惧；但大部分传教士，工作于与既有基督教国家接壤的异教民族中。进入斯韦亚人的土地，却意味着进入基督徒不熟悉的国度，尽管商人显然已与那里贸易。在这一背景下，犬首人的争论才有意义。当然，把犬首民族与斯堪的纳维亚世界相联，也可能有根据：海泽比港的发掘中，发现了出奇逼真的<a id="pdf-269"></a><!-- PDF page 269; original page 240 -->动物面具。[^p269-30] 不过，古典民族志，通常把犬首人置于东方、美索不达米亚和印度之间。九世纪中叶以后，北方传教不再只意味着接触异教徒；北方世界，如同波罗的海东岸地区，开始被视为鲜明的“他者”。

十一世纪末，不来梅的亚当撰写汉堡教会史，尤其其传教活动及由此获得的管辖权时，发现资料在888年林贝尔特去世以后，就断了。维京活动，似乎使九世纪末几十年、十世纪最初十年间的传教，几近崩溃。总主教乌尼（913—936年），确实恢复了一部分教区传教活动；然而，十世纪基督教在斯堪的纳维亚传播的主要成功，并非汉堡—不来梅教会之功。丹麦不可逆转的基督教化，开始于这一时期，司祭波波使“蓝牙”哈拉尔德改宗，可能在约960年。[^p269-31] 但波波不是汉堡教会的人，因此亚当尽快略过其成就，就像他忽视十世纪后期、十一世纪盎格鲁—撒克逊传教士对丹麦、瑞典基督教化的贡献一样。重建这一基督教扩展故事，依靠保存在英格兰、斯堪的纳维亚的零散信息，无法形成连贯叙述。[^p269-32] 基督教传播到挪威的证据，同样零碎；不过，诺斯人与英格兰的接触，似乎使维京人把宗教带回故乡。“美发王”哈拉尔德之子哈康，在埃塞尔斯坦宫廷长大，传教士似乎随他返乡。但政治竞争，使挪威基督教化并不顺利，而被战争、流血打断；这些死亡，可被解释为殉道。尽管历史曲折，挪威国王奥拉夫·特里格瓦松，似乎确在冰岛基督教化中发挥作用。这个独立岛屿的居民，觉得与其不断遭奥拉夫骚扰，不如在阿尔庭全体大会上，同意按自己的条件接受基督教；传统上，这次大会在1000年举行。[^p269-33]

不来梅的亚当对斯堪的纳维亚基督教化的记述，主要反映其自身教会制度的立场。[^p270-34] 他省略来自别处传教士的成就，因为把这看作侵犯汉堡—不来梅的管辖权。亚当时代，汉堡权威尤其敏感，其总主教阿达尔伯特（1043—1072年），渴望在北方建立牧首区，使本教区获得遍及斯堪的纳维亚、北方斯拉夫地区的管辖权。阿达尔伯特的继任者利马尔（1072—1101年），也是亚当历史著作的受献者，此外还是格列高利七世及其改革的主要批评者。考虑到亚当的偏见，其信息该如何理解，并不总容易确定。他描述斯堪的纳维亚最著名的部分，是乌普萨拉一座奉祀托尔、沃登、弗里科的庙宇。[^p270-35] 大规模考古调查，迄今未能发现任何近似其所描述建筑的遗迹；很可能，这段描写是想把当地人刻画得尽可能极端、奇异，以败坏他们的声誉。

### 重新思考波罗的海南岸的传教

亚当的沉默，似乎常出于有意；但因个人偏见、立场而没有传递信息的作者，并非只有他。梅泽堡的提特马尔（1018年卒），十一世纪初写作时，对同时代皮雅斯特王朝波兰统治者“勇敢者”博莱斯瓦夫（992—1025年），很少抱有好感；无疑因为后者威胁奥托帝国东部边境，也就威胁他的教区。不过，提特马尔记述了博莱斯瓦夫之父梅什科，约964年与波希米亚统治者之女、基督徒多布拉娃结婚。[^p270-36] 他评论，这位女子名字意为“善”，视之为皮雅斯特统治者后来改宗的预兆。基督教在波兰建立的细节，大体不为我们所知。[^p270-37] 但到博莱斯瓦夫在位时，教会已根基稳固，统治者的确在境内外捍卫基督教。

博莱斯瓦夫支持过两位传教士；他们在陌生社会工作的经历，在某些方面让人想起安斯加尔<a id="pdf-271"></a><!-- PDF page 271; original page 242 -->和林贝尔特。第一位，布拉格的阿达尔伯特，是波希米亚主要家族之一斯拉夫尼克家族成员。[^p271-38] 他在马格德堡受教育，983年被任命为布拉格主教。城中基督教水平使他震惊，五年后弃职，退居意大利。992年，他被迫返回，两年后再次离开；995年，公爵屠杀他的亲属，使他再不可能回去。阿达尔伯特此前已对传教表现出兴趣，似乎曾在匈牙利人中工作一段时间。因此996年，他出发前往波罗的海地区，途经皮雅斯特国家，创建缅济热奇修道院。他向北行至格但斯克附近，但影响甚小；然而，未及返回，就在997年殉道。博莱斯瓦夫取得其遗体，安奉于格涅兹诺。

阿达尔伯特的生涯，立即引起注意。后来出现的各种文本，其年代、作者尚有争论，但似乎殉道后很快，就有一部韵文传记问世。它又几乎立即成为另一部作品的范本；后者如今被认为来自亚琛—列日地区，却曾被归于约翰·卡纳帕里乌斯，即罗马圣博尼法斯与圣阿莱克修斯修道院院长，阿达尔伯特曾在该院居住。这第二部传记，似乎又启发另一位圣徒传作者奎尔富特的布鲁诺；他约1004年撰写阿达尔伯特传，四年后修订。此后不久，又出现另一部短得多的记述，可能写于缅济热奇。

阿达尔伯特为何引起如此关注，原因不清楚，尽管所有记述都把他描绘为非凡人物，激起强烈敬仰。博莱斯瓦夫·赫罗布里，既因个人原因，也出于政治考虑，热衷培养对他的纪念，也很明显：十一世纪最初数十年中的大部分时间，博莱斯瓦夫与皇帝亨利二世（1002—1024年）冲突，任何提升自身基督教资格的机会，都必定受到欢迎。最容易理解的是布鲁诺的兴趣。他同样非凡。[^p271-39] 他是梅泽堡的提特马尔亲属，曾在意大利奥托三世宫廷待过一段时间，后进入罗马圣博尼法斯与圣阿莱克修斯修道院，在那里必定充分了解阿达尔伯特的工作。他此前已表现传教兴趣，目睹两位朋友出发前往斯拉夫传教地区，并承诺为他们的传教活动，取得教宗许可。不巧，在他行动之前，他们就被杀。当他本人出发传教时，部分动力是<a id="pdf-272"></a><!-- PDF page 272; original page 243 -->未能替朋友取得许可的愧疚。他对二人被杀所写的记述，清楚表现这一点。另一方面，他的《阿达尔伯特传》，实际是在探索传教实践：传教士不应显得与传教对象不同，而应“入乡随俗”。他设想，阿达尔伯特被拒绝的一个原因，是太容易被辨认为来自另一个社会；于是让阿达尔伯特说出一段非凡讲话，建议自己与同伴，尝试像他们想使之改宗的人那样生活。[^p272-40] 不过，有些东西不能放弃，尤其正确施行礼仪；这不仅因为教规要求，也因为礼仪及其物件，似乎能为传教地的传教士提供某种安心。耐人寻味的是，尽管细致分析拟传教的社会，布鲁诺仍像林贝尔特一样，设想自己被犬首人包围。带着这些准备，并已在罗斯人、佩切涅格人中传教以后，他前往阿达尔伯特最后传教的地区，同样于1008年殉道。

安斯加尔、林贝尔特、阿达尔伯特、布鲁诺，都呈现为在陌生世界工作的人。值得注意的是，至少三位、也许所有人，都写下自己的传教观，方式是记述希望效法的圣人。[^p272-41] 这些作品探索作者自身态度、实践，在一定程度上具有自传性质，使我们得以了解九、十、十一世纪传教士的某些经历、期待，也清楚显示当时传教地区多么陌生。这不同于在已经正式改宗、却标准松懈的人群中工作，也不同于在世代与基督徒为邻的部落中工作；那些部落虽信异教，却并非未知之数。不可低估九世纪以后传教士面对陌生世界的程度。

他们工作的世界之所以陌生，也不单因为地理上远离古老基督教中心。阿达尔伯特、布鲁诺都在斯拉夫人和波罗的诸族（Balts）中活动。斯拉夫异教，似乎与日耳曼诸族的异教极不相同。日耳曼世界，很少有庙宇、祭司的证据；[^p272-42] 斯拉夫人却拥有一批威严的神祇，虽然多属地方神，却与大型<a id="pdf-273"></a><!-- PDF page 273; original page 244 -->庙宇群和成形的祭司阶层相联。[^p273-43] 日耳曼世界唯一可比的例子，都在可能以罗马神庙、基督教堂为范本的地区。假如不加质疑地接受不来梅的亚当对乌普萨拉的描述，就可拿它与斯拉夫异教庙宇群相比；后者也可能确曾影响前者。斯堪的纳维亚与波罗的海南岸斯拉夫地区的联系，有充分证明。

资料保存了斯拉夫祭祀地点的非凡描述，尤其梅泽堡的提特马尔对雷特拉的记述，[^p273-44] 以及萨克索·格拉马提库斯对吕根岛阿尔科纳——斯文托维特崇敬中心——的记述。[^p273-45] 据称，雷特拉在森林中有一处三角形围地，里面竖立大量神像，祭司在那里主持抽签占卜。这种记述，以及例如博绍的赫尔莫德（约1180年卒）提供的其他庙宇、仪式描写，[^p273-46] 都可合理联系考古证据；后者倾向于证实，斯拉夫异教与日耳曼诸族的异教，存在根本区别。因此，德意志帝国教士，甚至布拉格的阿达尔伯特这样一位自身是斯拉夫人、却成长于所谓基督教国家、又在梅泽堡受教育的人，觉得异教斯拉夫世界如此陌生，就不足为奇。〔译注：本章前文写阿达尔伯特受教于马格德堡，此处原文作梅泽堡。〕当然，斯堪的纳维亚也许不如斯拉夫地区陌生，但它位于已知世界极边缘，给安斯加尔、林贝尔特带来了自己的恐怖。

### 不来梅的亚当时代的异教徒与基督徒

阿达尔伯特、布鲁诺出发，并非只要在斯拉夫人中工作，而是要深入其领土，甚至进入不讲斯拉夫语的波罗的诸族地区。其实，近家得多的地方，就有斯拉夫异教徒。到1000年，大陆日耳曼世界已经基督教化，斯堪的纳维亚大部也是如此。斯拉夫人中，保加利亚人——除社会最高层外，都讲斯拉夫语——波希米亚人、波兰人、罗斯人，以及马扎尔人，都已基督教化。然而，波罗的海斯拉夫人，大部分仍奉异教。十一世纪的大部分时期，即使居于奥尔登堡、梅克伦堡地区的瓦格里亚人、阿博德里特人等斯拉夫部落，仍给近邻汉堡教会带来问题。阿博德里特传教史，我们最熟悉的是其王公戈特沙尔克<a id="pdf-274"></a><!-- PDF page 274; original page 245 -->（1066年卒）的生涯。父亲送他去吕讷堡修道院受教育，但听闻父亲遭一名撒克逊人杀害，他便抛弃信仰，出发复仇。不过，后来又恢复信仰，娶丹麦国王斯温·埃斯特里德松之女，与总主教阿达尔伯特结为朋友，为他在阿博德里特人中传播基督教，直到在伦岑殉道。[^p274-47]

戈特沙尔克之死，只是北方斯拉夫人基督教化与背教交替的漫长历史中的一个事件。这段历史，既与宗教有关，也同样关乎政治，即各斯拉夫领袖与德意志、丹麦国王，以及萨克森公爵之间的关系。这些冲突占据亚当《历史》第三卷的大量篇幅，也充满实际上续写亚当历史的博绍的赫尔莫德的整部编年史。两人都记述汉堡总主教使波罗的海南岸基督教化的尝试；他们的历史充分显示管辖权野心，也点缀着戈特沙尔克生涯这样的片段。赫尔莫德本人，在斯拉夫人中担任基督教司祭，一边叙述恢复教区的困难——这些教区在他当时的政治、宗教冲突中被摧毁——一边提供亲眼见到的异教及其祭司权力的记述。例如，奥尔登堡主教座，在1066至1159年一直空缺。赫尔莫德还顺便提到，德意志骑士修会成立，以及由此而来的波罗的海十字军之前，最后一批伟大传教主教中的一位：班贝格的奥托（1102—1139年）。

随着波罗的海十字军，北方传教史发生变化。虽然查理曼对待异教撒克逊人的方式，可以看出十字军观念的萌芽，但八、九世纪，没有任何事物可比十二世纪的修道或军事修会。此前，传教无疑有官僚组织的一面，却由个别传教士的个人神恩感召力加以平衡。但传教地区本身，也变了。七、八世纪传教士，面对的不列颠或莱茵河彼岸诸族，与基督教世界有强烈、往往长期的联系；九、十世纪的传教士，则工作于至少起初远不熟悉的地区。此外，斯拉夫地区的宗教，乃至波罗的海南岸诸族的社会结构，都与加洛林或奥托帝国很不同。再加上基督教世界，至少一度在维京人、马扎尔人身上，遇到武力相当的对手，就很容易理解，为什么<a id="pdf-275"></a><!-- PDF page 275; original page 246 -->九、十世纪传教士，在资料中似乎缺少七、八世纪前辈的乐观。使莱茵河以东诸族基督教化，这项一度看起来相对直接的任务，已变得远更复杂、出乎意料。北方斯拉夫人及其波罗的海邻人的基督教化，需要新的路径，也许不足为奇。
