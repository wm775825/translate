# 第28章 圣徒及其崇敬

朱莉娅·M. H. 史密斯（Julia M. H. Smith）

<a id="pdf-609"></a><!-- PDF page 609; original page 581 -->

628年，波斯人在基尔库克处决一位基督徒修士。阿纳斯塔修之死，在拜占庭与萨珊帝国数十年冲突中只是一段小插曲，但他的命运并不寻常。[^p609-1] 他原是波斯士兵，从琐罗亚斯德教改信基督教，在耶路撒冷附近修道；通过默想早期基督教殉道者的壁画，强化新身份，继而动身，寻求死于昔日同袍手下。斩首三年后，同院修士设法取回他的头颅；带回巴勒斯坦修院途中，头颅开始施行奇迹。在绝望时代，阿纳斯塔修已成为基督教胜利的强力象征。638年耶路撒冷陷于阿拉伯人后，修道团体逃至罗马，也带走其头颅。那里很快将其殉道和奇迹记述，从希腊文译成拉丁文。七世纪后半叶，故事传至英格兰；九世纪末又以古英语获得新形式，证明他在整个中世纪早期基督教世界广受欢迎。[^p609-2]

一位教士记录713年罗马发生的戏剧性事件，开篇说：“每逢想起我们的主耶稣基督通过其蒙福殉道者阿纳斯塔修所行的奇迹，我便心惊，腹中战栗。”故事涉及一名被安置于女修院的年轻女子；人们认为，一位遭她拒绝的求婚者唆使魔鬼附身。父亲狄奥彭图斯，是来自奥斯若恩的叙利亚主教，求助于东方故乡这位著名圣徒，将女儿带入一座教堂，殉道者头颅置于其祭坛。她颈上挂着圣徒一颗牙齿，却未驱走魔鬼；整整一个月，她胡乱挣扎，体内魔鬼高声辱骂基督、圣徒与教士。最后，狄奥彭图斯与<a id="pdf-610"></a><!-- PDF page 610; original page 582 -->全体修道会众聚集，悔罪祈祷，殉道者使人感到其临在。圣髑前一支蜡烛被吹灭，奇迹般重燃；这一信号使礼仪代祷愈加强烈。魔鬼嚎叫与修士吟唱交替，女孩扭动、腾身，终于魔鬼承认被阿纳斯塔修击败，离开了她。随后，“夜间第三时，女孩跪在主耶稣基督圣像前，近半小时；起身时，心智和身体已治愈，站在圣坛前，领受我们主耶稣基督的身体和血，从那时便痊愈了”。[^p610-3]

这则宇宙性戏剧故事，引我们认识中世纪早期圣洁人物的事迹与声誉。约600年，基督教圣洁观已有悠久历史。[^p610-4] 到那时，希腊语 hagios、拉丁语 sanctus，主要用来指那些被基督徒认为以某种方式分享神性、其地位通常获得礼仪承认的人，即圣徒；但这从非两词唯一用途。本章追溯这一演变，直至约1100年。把圣徒及其崇敬置于尘世过去与末世未来的交点，可显示他们对于中世纪早期当下不断变化的政治文化条件，具有极敏锐的适应性。也可强调，他们能使任何阶层、年龄、性别的信徒，在尘世烦忧中直接体验神圣。本章提醒注意，圣徒及崇敬如何补充教会机构的圣事与司祭职能，进而把圣徒行奇迹解释为在天上与尘世间传导神能的“避雷针”。略述背景之后，分析先从在世圣人开始；随后，随着时间焦点逐步拉长，转向死者，再转向基督教起源的遥远时代，最后到达故事起点耶路撒冷。

### 背景

中世纪神学家很少停下来详论圣徒及其崇敬。缺少持续反思，所显示的并非轻视，而是几乎一致认为，这是基督教实践的正常部分。自约<a id="pdf-611"></a><!-- PDF page 611; original page 583 -->1965年起，圣徒，无论在世圣男圣女，还是死者的崇敬，都吸引中世纪历史、艺术、文学、礼仪学者大量关注。其他学科，包括铭文学、姓名学、钱币学，也作出贡献。[^p611-5] 面对庞大文献，读者须记住两点。第一，不应只关注圣徒生平及生前死后事迹的叙事文本，因为它们会歪曲圣徒在中世纪早期基督教中的地位。[^p611-6] 一方面，它们忽略成百上千位圣徒，除了极简短礼仪记录，再无其他纪念。大多数圣徒从未成为叙事纪念、圣髑崇敬或任何非礼仪虔敬表达的对象。[^p611-7] 另一方面，文学纪念也不能保证礼仪崇敬，更不用说民间欢迎程度。第二，把圣徒崇敬视为单数统一现象，并不恰当；即使同一圣徒，崇敬也有多种形式。将这一多面现象错误地同质化、静态化，无助于理解。本章勾勒其中若干变化。

早在600年以前，基督教圣徒身份的观念、场所与表达，已凝聚为直到十三世纪仍具规范性的形式。在教会获得和平，即313年君士坦丁《米兰敕令》之后，约一世纪间，各基督徒团体逐渐而痛苦地适应从受迫害少数到占支配地位多数的转变。竞技场殉道不再是基督徒身份最高表达，神圣少数者的其他类别便涌现。圣洁与禁欲、制服内外痛苦和魔鬼紧密相连，偶尔也与使异教徒归信的成功——传教士——，或教义形成——所谓教父——相连。神圣表达的主导方式发生决定性变化，此后多数圣徒成为隐修士、修士或修院创立者，因为他们体现宗教重塑后的愿望，并在生前最完整地实行。关于起源、身份和过去联系的紧迫问题，也被重新思考协商。新的凝聚方式形成，既把地方共同体编织在一起，又<a id="pdf-612"></a><!-- PDF page 612; original page 584 -->赋予它们在已成为帝国性救赎历史中的位置。奇迹是否在其中起作用，曾颇有争议。圣徒崇敬不仅成为身份与合法性的关键标志，也在迅速变化的世界中，触发对神圣显现的冲突。[^p612-8]

约600年，这些争议暂时失去一些激情，尽管大格列高利一世教宗（590—604）对于当代奇迹的地位，仍持复杂态度。[^p612-9] 基督教凡已扎根之处，圣洁的表达就共享共同特征，同时受地方特点调节。圣洁在人身上显现，无论生死，都标示那些公认与基督格外亲近的人。人们一致认为，他们以两种主要方式，充当天界与尘世的导管。其一，在天庭担任辩护者，为求助者代祷；借奇迹，解除困扰个人的沉重苦难，如疾病、毁容、畸形，囚禁、附魔、无子等；或解救整个共同体，克服火灾、饥荒、洪水和其他灾难。其二，凭预言远见或属灵洞察，面对面，或通过梦境异象，说出基督徒上帝的话。他们预告重大未来事件，毫无畏惧地直言警告权贵或懈怠者，识破烦乱良心、隐秘罪行或尚未被承认圣徒的隐藏真相。

在世者通过严厉禁欲操练，以及按字面效法基督式生活，达到这种亲近。他们经历的是活着弃绝的“白色殉道”，而非骇人酷刑与死亡的“红色殉道”。[^p612-10] 死者无论是否殉道，都是灵魂已直接与基督同在乐园者；但他们的墓地，若已知所在，也仍保有其临在，是圣洁的热点。其力量常通过实物为中介：骨、发绺、布线、私人物品，以及液体或近似流体，如油、洗涤水、尘土；它们或来自圣祠，或接触过圣体，甚至从中渗出，如血或 myron，即拜占庭圣徒特有的芳香膏油。通常，生前著名者去世时，也受到高度注目，标志死后<a id="pdf-613"></a><!-- PDF page 613; original page 585 -->崇敬立即开始。但整个时期，受到公开支持、知名度高、文学与礼仪文献丰富的死者崇敬，始终与非正式虔敬竞争。后者如今仅凭偶见铭文、地名、涂写而被记起；某些地方，它们构成早期强烈地方归属文化的底层，后来被政治色彩浓厚的全国性崇敬覆盖；其他地方，则是后来崩解的基督教所留残迹。[^p613-11] 圣徒代祷吸引力如此之强，以致不仅“近圣安葬”（ad sanctos），即尽可能靠近圣祠，是备受追求的特权；同一圣徒也很容易通过搬移身体部分、设立礼仪节日、抄写文本，而在多地复制。

简言之，约600年，已存在一套继承而来的“人格化”圣洁显现方式，配有强化或约束它的文本话语与仪式。虽然环境不断改变，这套方式在此后五百年，始终是实践和再现圣徒身份的强大脚本。

### 圣人

古代晚期是在世圣人的时代。[^p613-12] 约600年，从爱尔兰、威尔士到叙利亚、波斯，圣人的魅力性临在，体现于奇迹、直言，以及特别善于化解共同体紧张，受到广泛讨论、书写与批评。[^p613-13] 但他的生涯并未随古代终结，而继续兴盛；到约1100年，我们会发现，他仍在任何古代晚期基督徒都无法想象的环境中活跃。演变有三大方面。首先，中世纪早期基督徒生活规范与实践，与古代同样具有强烈性别性质，圣人也不例外。其次，继承的文本范例仍具说服力。第三，这些古代先例的分量，常与当代政治和制度要求形成尖锐张力。

性别维度须先略提。古代晚期圣女为数很少，也罕获传记关注。有些装点贵族家门美德，另一些则为地方共同体谦卑<a id="pdf-614"></a><!-- PDF page 614; original page 586 -->代祷。少数寻求效法沙漠禁欲的严酷，或悔改卖淫生涯；她们借异装改变性别身份，得以不被察觉地生活于埃及或叙利亚修道院，这本身已足够奇妙，证明其圣洁。[^p614-14] 这些暧昧人物确实引人注目，热闹生动的事迹叙事，从希腊语、叙利亚语传播至拉丁语、阿拉伯语、亚美尼亚语、斯拉夫语和古英语。但虽然文本流行，这些挑战性别规范的女性，更多激发默想和想象，而非成为中世纪早期女性虔敬的现实榜样。[^p614-15] 与“扮作修士的女性”死后广为人知相反，约600年以后，极少圣女的典范性足以值得写成文本。约600至约1100年，希腊圣徒传以女性为主者，勉强只有百分之十；拉丁西方则明显较高，约百分之十五。[^p614-16] 尽管修辞上常说，“赐奖者上帝慷慨而平等地将赏赐与胜利冠冕赐给两性”，女性在被认定显出圣洁的人中，始终仅占很少部分。[^p614-17]

不过，一些重要发展确认，古代晚期这种重新赋予性别的女性禁欲，牢牢局限在书页上。拜占庭九、十世纪，极少数圣女，不是共住团体修女，便是君士坦丁堡内外以安静虔敬和善行度日的虔诚已婚平信徒或寡妇，其家庭中的谦卑被认可为圣洁。在其他地方，尤其威尔士、布列塔尼和意大利，无论拉丁语还是希腊语地区，任何类型圣女的记录都付阙如，再次证明圣洁的性别性质。在拉丁西方其他地区，圣女几乎总见于修院，而非家庭，集中于法兰克和德意志、盎格鲁—撒克逊英格兰、爱尔兰。她们最常是献身守贞、出身贵族或王室的女性；任家族所创女修院院长的生涯，使其环境具有王朝性，却非家庭性。[^p614-18]

西方这一主导模式唯一的偏离，自十世纪起出现在最高社会层。当女性圣洁被用来帮助根基不稳的统治者维持王朝稳定时，婚姻之外，就必然也包括母职。但生育本身，并未使玛蒂尔达（卒于968年）、阿德莱德（卒于999年）、苏格兰的玛格丽特（卒于1093年）成为圣女。她们都把母职与个人虔敬结合，效法当时的主教理想：勤于私人敬礼、慷慨施舍、兴建教堂、为宽恕代求、释放囚犯。[^p615-19]

圣女若更常是来自早先时代的文学建构，而非社会现实，一个原因是，禁欲起源的英雄时代没有留下既权威、又可实践的角色范例；另一个则是女性在中世纪早期性别秩序中的从属地位。圣男情况完全不同。少数圣者的传记既维护规范，也激发愿望；在此意义上，中世纪早期男性圣洁，仍深深依赖通过个人禁欲努力接近上帝的继承理想。[^p615-20] 它也始终与主导政治结构和权力意识形态紧密相连，有时相合，有时相抗。

古代晚期圣徒传“经典”的持久影响，不限于引用亚他那修《安东尼传》、叙述卒于356年的圣人；苏尔皮基乌斯·塞维鲁所写图尔修士主教马丁（卒于397年）传；大格列高利对蒙特卡西诺创立者努尔西亚的本笃的记述，原书此处记其约卒于480年；或斯基托波利斯的区利罗《萨巴斯传》，叙述卒于532年的巴勒斯坦大禁欲者。虽然这些作品确实被大量引用，更值得注意的是，修士和隐修士用它们指导自己追求基督徒生活。774年，西哥特贵族维蒂扎（卒于821年）在查理曼宫廷经历剧烈宗教转变；试验不同禁欲生活后，最终选择《本笃会规》。改名本笃，不仅拥抱本笃式修道精神，也使自己融入创始之父的角色。两百年后，蒙特卡西诺修士收留著名、虽脾气多变的希腊隐修士罗萨诺的尼洛（约941—1004）。撒拉森人袭击意大利最南端拜占庭行省，迫使他北上。他故乡卡拉布里亚缺乏牢固地方修道传统，因此主要从书本学禁欲，将所读以近乎<a id="pdf-616"></a><!-- PDF page 616; original page 588 -->基要主义的字面方式，应用于自身处境。蒙特卡西诺修士也迅速把客人放入熟悉的古圣人叙事，吸收进自己的本笃传统：“他们仿佛听见、看见伟大安东尼从亚历山大里亚而来，或者更确切地说，是伟大本笃，他们神圣的立法者与导师，从死者中复活。”[^p616-21]

使尼洛非凡的，不只是长期隐居；传记作者也惊叹于他所行的大量奇迹。古代晚期圣人虽常施行戏剧性奇迹，如医治、驱魔等等，千年之交的东西方圣人，却很少再有如此规模。除了继承而来对奇迹是否适当的疑问，还存在其他自具强大逻辑的宇宙观，拜占庭尤其如此。[^p616-22] 穆斯林征服帝国大片土地与圣像破坏争议，这双重创伤，迫使“何种圣洁显现在神学和政治上可以接受”的问题，以无可回避的尖锐形式出现。九、十世纪拜占庭基督教逐渐重塑，取得深刻不同的特征，打断与圣像破坏前过去的简单连续，却也使遭迫害的圣像敬礼者有机会被重塑为圣徒，成为变动时代连续性的灯塔。禁欲生活同样深受影响，受到更多制度规管，重视内在化的属灵指导。行奇迹的能力，或把奇迹归于他人的意愿，逐渐衰减。[^p616-23] 在此环境，圣人比早先更少忽视或扰乱主教、世俗统治者等其他权力权威。他们既容易成为批评者，也容易成为顾问；既可能是独居隐修士或住柱的柱头修士，也同样可能是修道团体组织者。十世纪末，行奇迹的拜占庭圣人，与其是血肉现实，也同样可能是虚构；十二世纪，他们已成为嘲弄对象。[^p616-24]

拉丁世界在世行奇迹者的轨迹不同，原因数种而相互重叠。首先，东方大体维持禁欲与高级教会职务的区别，<a id="pdf-617"></a><!-- PDF page 617; original page 589 -->西方却模糊了这一点。[^p617-25] 基督教逐渐远越昔日罗马行省，进入日耳曼、凯尔特和斯拉夫地区；行奇迹修士作为传教主教，往往留下强烈印象，因为奇迹有助补充讲道。[^p617-26] 拜占庭圣人与地方主教互相对照，西方主教却常常就是当地圣人。中世纪早期西方由镶嵌般的“微型基督教世界”构成，主教获得极大权威，其他圣人因而边缘化。[^p617-27] 此外，在司祭阶层积极帮助下，加洛林王朝宣称，自己是神恩流向法兰克人民的首要渠道。加洛林国王与主教共同建立覆盖大陆全部拉丁基督教的帝国，共同彻底占有一切圣洁形式，以致压制圣人。他的魅力，与神权王权相抵触。加洛林禁欲始终被国家支持的修道生活牢牢限制，无法通过奇迹或预言显现。[^p617-28]

十世纪末，西欧政治宗教景观剧变，圣人得以重返舞台。我们在西地中海山地腹地发现他们；除了尼洛，还有许多人直接从六世纪圣人生平汲取隐修灵感，不理九世纪重新塑造的宏大本笃传统。比利牛斯山南部和亚平宁高谷，帝国统治崩解为一片相互竞争的小公国；其统治者无力有效宣称，自己继承支持加洛林皇帝及奥托后继者的神权意识形态。为补偿神圣性不足，他们与当地圣人结盟，自任庇护者和支持者。西洛斯的多米尼克（Dominic of Silos，卒于1073年）便是一例。他先在里奥哈山区隐修，后成为圣米良—德拉科戈利亚的改革院长，直到与纳瓦拉国王加西亚失和。流亡后，卡斯蒂利亚的费尔南多一世争取他，1041年将西洛斯破败修道院交给他修复，正位于极不安全的<a id="pdf-618"></a><!-- PDF page 618; original page 590 -->基督教—穆斯林边界。[^p618-29] 他任院长时，效法马丁、安东尼、本笃，行奇迹保护修院财产，或医治当地百姓，名声大振。[^p618-30]

西方行奇迹圣人，在平信徒庇护下被重新创造。十二世纪初，其活动范围又扩大，往往带有牢固领主权意味：他可能创立新修会，成为主教，或如克莱尔沃的伯尔纳（卒于1153年），施行大量奇迹，用以反异端、宣讲十字军。在伯尔纳身上，行奇迹本领的制度表达，再达新峰。[^p618-31]

用所谓魅力与权威的对立描述中世纪基督教史，是错误且非历史化的。圣人能够，也常重新调节政治关系；但他的在场本身，就是显著权力，其作为文本主角的再现，又是同样重要的另一种权力。他与自己生活、或受纪念的世界相连，绝不分离。中世纪早期圣人，偶尔也有圣女，获得与神的特殊联系，以预言和奇迹显现；他是个人禁欲准备、文本范例、政治机会和社会需要，组成的复杂精细平衡网络的产物。更根本地，他也来自一种先在信念：神的行动可能迸发于活人行为，个人能够承载天赐力量。600至1100年，这些前提虽只间歇实现，但圣人即使在社会中潜伏，在文本中仍充满力量。

### 圣徒的形成

1073年多米尼克去世，修士把他葬在院内，但墓可供平信徒接近。当地多人来访，出现少量奇迹。到1076年，墓地获得足够关注，使地方主教将遗体迁入修院教堂；这次迁奉引发新圣祠一阵医治。然而，修士很少注意他迅速增长的死后力量，1088年祝圣新教堂时，<a id="pdf-619"></a><!-- PDF page 619; original page 591 -->只把他列作一座次要祭坛的共同奉献对象。但一人携镣铐闯入，感谢圣徒，使典礼中断：他曾被穆斯林囚禁在约二百公里外，多米尼克救他脱身。从此，死后崇敬迅速增长。朝圣者从越来越远的地方来墓前，在圣祠守夜一夜或更多；修士举行弥撒时，他们疾病痊愈，或附身魔鬼离去。远离西洛斯处，有些人得到帮助，逃出穆斯林伏击和牢狱；另一些在本地获愈，再前往圣祠感恩。约1100年，多米尼克朋友格里马尔德，直面修士对身边圣徒的矛盾态度，写下生平及死后奇迹。[^p619-32]

多米尼克的死后生涯提醒我们，从圣人到有崇敬的圣徒，转变可能充满含混，而死后作为“圣徒”受崇敬，也有多重面向。不过，仍可作些概括。第一，崇敬关乎生者、而非死者的理想、愿望和政治。政治、社会、文化要求，对生前圣洁的认可已有约束；认可少数人能从坟墓显出与上帝异常亲近时，约束更大。第二，只有极少数圣徒通过死后奇迹显现；即使如此，其宇宙性能量也很少持续很久，多是短暂爆发。像火山，任何时候，沉寂或熄灭的奇迹崇敬，都多于活跃的；往往圣徒死后数十年、乃至数百年，才骤然迸发。第三，用文字宣扬死后奇迹本领，本身就是重塑神圣景观的权力行动。六、七世纪拜占庭一批长篇奇迹书，正面挑战各类不信者；九世纪加洛林核心地区类似书籍，则成为制度导引圣洁的一部分；十一、十二世纪法国的作品，是世俗权贵相互竞争环境中，各圣祠竞争的产物。[^p619-33] 它们都回应神圣性质与所在地的具体焦虑。

有时，将死者可能主动促成向圣徒身份的转变。传教士阿曼杜斯（约卒于675年）知道，墓地崇敬关系新修院的成功，<a id="pdf-620"></a><!-- PDF page 620; original page 592 -->便把遗体留给自己在埃尔农创建的修院，宣布任何敢迁走遗体者，都将受绝罚与永罚。[^p620-34] 温彻斯特改革修士主教埃塞尔沃尔德（卒于984年），是一位志向高远的学者，而非简单的圣人；他很可能曾向弟子交代，后者约十年后写出导师传记，开启其崇敬。[^p620-35] 同时代另一位与修道生活相连的主教，伍斯特的奥斯瓦尔德（卒于992年），为教堂造圣龛，却留空，宣告“他为尊荣上帝而建，且自己十分清楚，谁的遗骸将葬在其中”；多年后，他自己的骨骸被置入。[^p620-36] 预先安排葬礼，也可能有帮助。尼孔“你们要悔改！”（Ho Metanoeite），在伯罗奔尼撒作民众讲道者、呼吁悔改的生涯颇有争议；约1000年将尽时，他召斯巴达全体市民与修士到临终床前，确保自己在众目之下离世。消息传开，人人赶来：

> 一人急于取走蒙福者头上脏乱发绺的一点，另一人取胡须一点，还有人取旧斗篷或山羊皮外衣的一块。对所有人，能带走任何碰过神圣遗体皮肤的东西，都是伟大光荣之事，可解除苦难和各类疾病。[^p620-37]

曾被尼孔赶出城的斯巴达主教，立刻介入，确保葬礼符合圣徒身份，也由此重新申明自己的权威。

其他时候，朋友与同伴可能在崇敬形成中发挥关键作用。阿纳斯塔修一位同伴，将亲见处决的记述直接传给传记作者。围绕较平静临终床的人，知道应留意珍贵渗出物、香甜“圣洁气味”、遗体不腐，以及其他生理圣迹。巴尔蒂尔德王后，后来自己也被视为圣徒，向停柩的努瓦永的埃利吉乌斯（卒于660年）告别时，注意到血从其鼻流出。“主教和至为基督徒的王后一见，便迅速放上亚麻巾，仔细收集各处流出的血，为更好保存恩赐，将巾分成三片。”[^p620-38] 831年，萨尔迪斯的优西米乌斯死在美多迪乌斯<a id="pdf-621"></a><!-- PDF page 621; original page 593 -->（卒于847年）怀里；后者后来任君士坦丁堡牧首，见证圣人遗体不腐：

> 直到今天，圣人仍美好。他双颊红润，眉形端整，额无皱纹，四肢触之柔软，仿佛死亡未使他僵硬；既不冰冷，也不腐解，肉体发亮。玫瑰色皮肤湿润如活人，额头如疼痛者般凝结汗珠，即使死后，也清楚显出他为基督所受、并留下印记的苦难。[^p621-39]

若公众获准参加葬礼，死者圣徒身份还可用更戏剧性的方式宣布。587年，法兰克王后转禁欲者拉德贡德下葬时，“被魔鬼附身的人叫喊，承认这位上帝圣女，说她正在折磨他们”。[^p621-40] 十世纪初，莱斯博斯的虔敬主妇托迈斯，曾预言墓前会有奇迹。死后四十天，一名被“凶猛魔鬼”附身者在那里治愈；这向安葬她的修院前庭所属修女团体发出信号，应将遗体迁入教堂，那里很快报告更多奇迹。[^p621-41]

不过，崇敬未必在死亡后立刻开始。斯图迪奥斯的狄奥多若（卒于826年），间隔十八年；温彻斯特的埃塞尔沃尔德，间隔十二年。埃塞尔沃尔德为提升主教座堂，971年把一位年代久远的前任主教斯威森（Swithun，卒于863年），变成行奇迹圣徒，配以精美圣龛、专门祷文与弥撒礼文、两个节日、多种传记版本，包括拉丁散文与诗体、古英语，以及细心编成的奇迹集。[^p621-42] 间隔也可远长于斯威森。理查德院长（卒于1046年），将凡尔登贫困的圣瓦讷修院变成富有强大的中心，后来又成为本城主教。很久以前，圣瓦讷曾是主教座所在；理查德“发现”昔日主教墓，包括约500年去世的瓦讷，又从笔下把他塑造成死后行奇迹的强者。[^p621-43]

圣瓦讷的理查德，承继一项约800年开始的西方传统，将正式认可圣徒身份交给主教。

加洛林试图禁止崇敬情况不明的人物，因而赋予主教在本教区授权崇敬的权利。[^p622-44] 这一规范努力总体成效有限，却仍给温彻斯特的埃塞尔沃尔德、圣瓦讷的理查德等有力主教机会，控制崇敬，或借宣称前任圣洁而强化地位。[^p622-45]图勒的热拉尔（卒于994年），生前广受敬重，死后被称为行奇迹者。1049年，当时图勒主教布鲁诺当选教宗，取名利奥九世；翌年，昔日主教座堂教士请他确认热拉尔圣徒身份。他听取生平和奇迹证据，咨询罗马主教会议后，宣告热拉尔配“列入、称名并在圣徒中受崇敬”，指定每年纪念日期。[^p622-46] 利奥九世并非第一位介入圣徒形成的教宗：原书记载，1032年本笃八世已准许卡马尔多利修士，在创立者罗穆阿尔德（卒于1027年）墓上筑坛；他是毫不妥协的禁欲隐修士、道德改革者和修院创立者。[^p622-47] 利奥也不是最后一位。[^p622-48] 正式化的圣徒形成，惯常或涉及广泛愿意到某人墓前求奇迹，伴随程度不同的主教鼓励和礼仪纪念；或对于不行奇迹的圣徒，则反映主教改革计划。因此，教宗参与是既定实践的一项新颖、尊贵附加，并非取代。它带有浓重政治性质，1100年以后很久仍然如此。

拜占庭主教和牧首的参与，继续不规则。君士坦丁七世“生于紫室者”（945—959）虽命编圣索菲亚《圣徒纪略集》，作为应受礼仪崇敬者的权威清单，使崇敬文本标准化成为可能，但直到十三世纪末，也未出现正式牧首宣布圣徒身份的程序。[^p622-49] 然而，这不必然意味着崇敬总获共识，“虔敬者”西缅的例子可以说明。新神学家西缅（卒于1022年），决心使昔日<a id="pdf-623"></a><!-- PDF page 623; original page 595 -->属灵导师、斯图迪奥斯修士“虔敬者”西缅（Symeon Eulabes，约卒于986年），被接纳为圣徒。他写传记与圣歌尊荣导师，纪念年节“如同一切其他圣徒”，为其绘圣像，引公众注意这位新圣徒；君士坦丁堡牧首同意，在每年节日送蜡烛和香。但其他人认为公开崇敬过度，否认其圣洁。1003至1008年，牧首会议三次辩论赞成与反对。新神学家西缅即使遭流放，仍坚持决心，如此向导师祈祷：“你把基督承载在自身里面，你爱他，他也如此爱你。你的圣洁等同使徒，已由高天之声向我显明；你如今来护卫我吧。”但主要对手，只走到圣像前，刮去“西缅”名字前的“圣”字，便将圣像降为普通肖像，立即取消其圣徒身份。因此，新神学家西缅大量著作中，尊荣导师的作品未能存世，也就不奇怪。[^p623-50]

可见，圣徒形成是微妙事业。动力不同，结果难料，也可能引发争议；它是中世纪早期基督教模糊生死、时间与永恒界限的一种方式。成功崇敬把天上力量带到人间，失败则消失，几乎不留痕迹。久已去世者可以“复活”，支撑制度后继者的权威诉求；圣人死亡，对其共同体却可能是高度不安时刻。崇敬无所不在，掩盖了其形成的偶然性。

### 极其特殊的死者

求助死者、撰写纪念文本、组织礼仪崇敬的人，把自己的天上庇护者加入东西方共享、已有数世纪的圣徒群体。它通过逐层积累增长，扩充很久以前形成的核心。[^p623-51] 尽管奇迹圣徒崇敬引人注目，中世纪早期圣徒身份的基石，始终是“极其特殊的死者”，即殉道者和<a id="pdf-624"></a><!-- PDF page 624; original page 596 -->使徒，其天上来世在基督教最早时期便已确定。[^p624-52]

殉道者圣祠在晚期罗马帝国的分布，极不均衡。它们虽是基督徒城市身份、平信徒宗教热情，以及持续提高行为标准努力的焦点，但所在地只部分反映三世纪、四世纪初迫害者热忱的差异。[^p624-53] 除地方记忆失落造成的损失外，遗骸“寻获”、四世纪中叶以后从一地至另一地的“迁奉”，以及圣髑收藏者活动，都改变殉道者崇敬的地理分布。[^p624-54]

文本传播带来进一步错位。四世纪后期以来，各教会与其他共同体分享本地殉道者，形成越来越长的纪念名单。约600年，在文本和纪念形式上，许多殉道者崇敬已具有礼仪分布，与遗骸所在地或原殉道地相距甚远。这种分离在中世纪早期扩大。殉道者增多，宗教节日日历愈加拥挤；原先仅为名单名字的殉道者，获得自己的生平故事。殉道传文本，无论多么虚构，被汇集成越来越充实的文集。[^p624-55] 较近圣徒与“重新发现”的前辈加入其中，使拉丁圣徒纪念历（martyrologies，按历编排的节日清单）、殉道传集（passionaries）、圣徒传集（legendaries，通常按历收各类圣人生平），以及希腊圣徒纪略集、圣徒月传集、月课集，规模增加；后两者分别按历收生平，和圣徒节礼仪诗歌、祷文。

搜集圣徒殉道者信息，有时与收集其圣髑相伴。文本和圣物增多，多重诉求、冲突叙事也随之发展；支持者无不相信，即使竞争者或中世纪后怀疑的批评家未必如此。这种囤积死者文字和实物标志的行为，满足许多需要：多位代祷者、稳固天上庇护、政治声望，<a id="pdf-625"></a><!-- PDF page 625; original page 597 -->虔敬展示、安慰与医治。但它也回应对于圣洁当下意义的观念变化，以及对过去认知的转移。两者在九世纪尤其突出。拜占庭圣像破坏危机的一个结果，是重新连接早期基督教过去；那时过去已遥远得不再引起争议，人们重新关注古老殉道者与圣徒，把他们视为真实共享遗产的标志。西方加洛林对在世圣人的敌意，使死者圣洁更受重视，促使许多古老文本的散文风格和内容“更新”，也促成大型“历史性圣徒纪念历”编纂，以历序简述数百圣徒与殉道者生平。[^p625-56]

虽然新成员不断加入，罗马时代殉道者始终居于中世纪早期圣徒虔敬核心。十世纪末君士坦丁堡，帝国官员“改写者”西缅（Symeon Metaphrastes，约卒于1000年）编成十卷希腊文集，按礼仪年排序，包含抄录、修订或新作的圣徒传、重要圣髑迁奉记录，以及基督与玛利亚主要节日文本。其中百分之五十五，即148篇中的81篇，涉及殉道者。[^p625-57] 同时，西撒克逊的同代人、恩舍姆的埃尔弗里克（约卒于1010年），也为类似场合制作古英语讲道与圣徒传。他的选择中，百分之四十一，即54篇中的22篇，是殉道叙事。[^p625-58] 两人自然都收入许多本地圣徒，但两部文集重合的部分，仍清楚显示东西方共享的殉道遗产。[^p625-59]

殉道者崇敬的意义，在基督教于中世纪早期退缩或扩张的地区，尤其清楚。最低限度，古老圣祠帮助地方基督徒共同体，在变化世界中确认身份。穆斯林征服埃及和叙利亚很久以后，埃及西部沙漠阿布米纳的米纳斯崇敬，以及罗马—波斯边地鲁萨法的塞尔吉乌斯崇敬，仍持续存在，正处于这一背景。[^p625-60] 基督徒感到威胁时，殉道崇敬也提供抵抗压迫的象征，如<a id="pdf-626"></a><!-- PDF page 626; original page 598 -->阿纳斯塔修的故事所示。虽然其崇敬在阿拉伯入侵后从巴勒斯坦消失，东方教会仍崇敬许多其他死于波斯人之手的基督徒。[^p626-61] 穆斯林统治，又使殉道传统重新活跃，成为当代行动与文本的模板。九世纪巴勒斯坦和西班牙，随着改宗伊斯兰、融入阿拉伯文化规范加快，逐渐缩小的基督徒团体，有力运用殉道意识形态，积极动员早期基督教过去，强化身份，把近期遭穆斯林统治者杀死者视为殉道者。[^p626-62] 无论拉丁语、希腊语、阿拉伯语或格鲁吉亚语，这些“新殉道者”叙事共享同一参照框架，回望古代，向备受困扰的听众许诺未来救恩。

基督教扩张的地区，殉道者具有很不同的回响：唤起权威过去，连接遥远地方和人物。七世纪英格兰东南坎特伯雷，与十一世纪挪威特隆赫姆，传教活动都成为传播罗马殉道者崇敬的重要媒介。[^p626-63] 此外，教宗利用罗马众多殉道圣祠，发放本城早期基督教遗产的标志，为其他地方崇敬中心扎根。最初，他们只愿交出接触性圣物，如触过墓的布、圣彼得锁链锉屑等；九世纪教宗则更乐于赠予遗骸。[^p626-64] 这些圣物标示罗马联系，约1100年以前绝非司法管辖意义，却确有文化意义，也表达尊重罗马是真正基督教的源头。

在归信进行中的地区，殉道模板也可另作运用。许多地方，归信国王横死后，很快被视为殉道者，且常为积极行奇迹者，使新的基督教形态扎根本土殉道传统。诺森布里亚国王奥斯瓦尔德（634—642）、挪威奥拉夫·哈拉尔松（卒于1030年）、波希米亚瓦茨拉夫（卒于929／935年）、罗斯王公鲍里斯与格列布（卒于1015年），都被广泛颂扬为各自新兴民族基督教的象征。[^p626-65] 随拉丁与正教基督教扩展，殉道崇敬重新得到活力与安排，以适应新政治形势。

唯有爱尔兰人略显超然。他们归信相对和平，没有产生本地殉道者；比起外来圣徒，更关心本地圣徒，据八世纪清单，共七百五十位。[^p627-66] 十二世纪，完整殉道者崇敬才随教宗主导的基督教进入爱尔兰。《戈尔曼圣徒纪念历》编于1166—1174年，注意到早期爱尔兰名录漏掉“世界其他地方的众圣徒”，于是汇成巨大圣徒总集，包括圣经、罗马、不列颠、英格兰和爱尔兰圣徒，共三千四百五十名。[^p627-67]

殉道崇敬部分意义，来自这些人物几乎完全缺乏历史资料。事实上，最著名者中的凯瑟琳、科斯马斯与达米安、乔治、玛格丽特，也无法证明曾是历史人物；极冷僻者中同样如此。但正因此，殉道崇敬格外灵活，能够无尽迁移、重造。德米特里乌斯以奇迹保护七世纪帖撒罗尼迦市民免遭斯拉夫与阿瓦尔攻击而著名；他可能是本地殉道者，也可能不是，该城究竟是否拥有其遗体，仍不确定。医师圣徒科斯马斯与达米安，可能融合三对不同圣徒身份，却丝毫不妨碍其医治崇敬在君士坦丁堡增长，再广传地中海及更远地区。

使徒和福音作者，比殉道者更可塑；其圣经叙事结束后的生涯，成为冒充史实的想象传说素材，因此格外有用。宣称使徒起源，能压倒那些靠较晚管辖权依据而试图控制的教会。因此，亚美尼亚历史上的传教者“启蒙者”格列高利虽在四世纪生活，自五世纪中叶起，他们却强调使徒达陡最先向其讲道，以反驳拜占庭迦克墩主义，这十分便利。约1100年，面对已知起于七世纪的英格兰约克总主教座的管辖诉求，苏格兰人强调自己拥有使徒安德烈圣髑，鼓励在圣安德鲁斯圣祠建立主要朝圣中心。九世纪“发现”使徒雅各在孔波斯特拉的圣髑，同样改变了西班牙神圣地理<a id="pdf-628"></a><!-- PDF page 628; original page 600 -->与教会等级。[^p628-68] 827年威尼斯从亚历山大里亚盗取福音作者马可圣髑，也产生同样重要的后果：获得圣髑，使新兴城邦能够同时拒绝罗马与君士坦丁堡管辖，并采用马可象征狮子，作为独特商贸身份的标志。[^p628-69]

圣经所有人物中，玛利亚在传说神话中被阐发最多。与使徒、福音作者不同，她的崇敬发展缓慢。她被赋予丰富教义意义，却长期从属于基督论教义，又是有力的政治符号。此外，她没有墓、遗体，或圣徒崇敬其他通常特征。人们竞相“寻获”相应身体标志，如乳汁小瓶、乳牙、腰带和长袍，填补空缺；关于她肉身升天的教义，也以东西方不同方式发展。她因此不同于圣徒，后者被认为灵魂已至乐园，身体却尚未抵达。

她作为保护者和可信守护者的名声，发展尤其缓慢，虽然在拜占庭比西方早得多。六世纪起，关于她的奇迹故事逐渐渗入西方，被译成或重述为拉丁文。拉丁礼仪和释经对其母亲角色的阐发，九世纪才开始，十一世纪加速，同样建立于拜占庭先例。罗马在许多方面居于东西方中间，却比君士坦丁堡更早发展玛利亚的政治图像。拜占庭基督徒自认为她626年救大城免于阿瓦尔围攻以来，便确信其奇迹能力；但西方直到十一世纪末，奇迹代祷才成为敬礼特征。因此，直到本时期最末，她的崇敬才终于在虔敬、个人，以及教义、公共各方面无所不在。玛利亚负载极强象征，又普遍得足以在任何地方本地化；其母职与中介属性，使她在东西方都居圣徒等级顶端。中世纪盛期最流行的圣徒崇敬，足足孕育了一千年。[^p628-70]

<!-- PDF page 629; original page 601 -->

玛利亚崇敬承载沉重神学，属于反证一般规则的例外：圣徒崇敬如此深嵌中世纪早期基督教宇宙观，其存在理由无须明确说明。但这不应使我们忽视，遥远过去死者的崇敬，如何提供身份、权威和共同体来源，帮助所有中世纪早期团体应对巨大变化。其象征属于文化遗产，常为当下服务而重写，因此也经常受到话语重估与政治修订。“极其特殊的死者”，除提供虔敬确信和奇迹援助，也把过去固定于现在，以使人安心面对未来。圣徒年代越远，越具权威，其崇敬也越开放于重塑。

### 旧耶路撒冷与新耶路撒冷

约1090年，坎特伯雷修士约瑟前往耶路撒冷圣地祈祷。自古代晚期起，朝拜远近圣祠作为属灵更新，便自然伴随圣徒崇敬；尽管有政治、也常有财务困难，耶路撒冷始终居于神圣地理中心。[^p629-71] 但约瑟所访城市，与希律之城，甚至135年哈德良重建之城，相似已很有限。十一世纪朝圣者绕行君士坦丁（306—337）和查士丁尼（527—565）兴建的巨大巴西利卡；如今它们半已破败，所在城市也受穆斯林控制数世纪。但朝圣者对于到达后所见景观，已熟悉其理想形式。不仅因为路线与圣祠描述自四世纪已流通，基督教礼仪年周期也以象征形式绘出这一行程，并移置于东西方主要教堂。[^p629-72] 仿圣墓教堂独特圆形建筑而建的教堂增多，意味着许多朝圣者上路以前，已先在预期中到过圣地。圣地又像圣人，容易由可触、便携碎片代表；其他人因此也在装满朝圣“纪念物”的圣物匣中，与它相遇——一把把<a id="pdf-630"></a><!-- PDF page 630; original page 602 -->泥土、石头，以及从基督生死地点圣祠带回的小瓶油。例如六世纪一位朝圣者搜集、标签整齐的卵石，便保存于罗马教宗私人小堂的“至圣所”。[^p630-73]

但耶路撒冷虽激起种种情感，约瑟与其他西方人一样，知道若不访君士坦丁堡，朝圣就不完整。十一世纪最后几十年，西方人已十分清楚，帝国之城收藏着“无可比拟的圣髑宝藏”。[^p630-74] 罗马分发圣髑，君士坦丁堡却囤积它们。四世纪建城时，该城殉道者匮乏，到600年圣髑已丰富，后来数世纪更增。它获得代表四百七十六位圣徒的三千六百余件圣物，在穆斯林征服中东后，成为基督教宝藏“王者的、不可动摇的安全家园”。[^p630-75]

> 这座城的金银、大理石与铅、挂毯与丝绸，令人惊叹，胜过世界一切城市；又因所藏圣徒遗体，尤其我们主耶稣基督最珍贵的遗物，被认为比世界其他地方都多，远比世界其他荣耀更加荣耀。

第一次十字军之前不久，一份详列该城圣物宝库内容的拉丁清单，如此开篇。[^p630-76] 君士坦丁堡积聚殉道者和使徒圣髑，令人惊异；基督、受难及玛利亚的遗物，更以最有力方式支持皇权、保证帝国正统。它们使大城在质和量上都不同于他处，为其带有末世色彩的修辞称号“新耶路撒冷”，赋予可触内容，也给拜占庭皇帝外交议价的王牌。[^p630-77] 西方人羡慕地瞠目观看；约瑟也尽力以剩余旅费，买下一件使徒安德烈圣髑作纪念。

西方迷恋拜占庭圣物收藏，反映对身体部分及相关物品的专注，却忽略了拜占庭人认为至少同样重要的圣洁象征：圣像。约1100年，圣像已在拜占庭<a id="pdf-631"></a><!-- PDF page 631; original page 603 -->神学中牢固确立为神性的适当标志，因而是代祷、奇迹、保护的导管，但并非从来如此。它们七世纪末才突出。拜占庭帝国面对穆斯林攻势求存，圣像变得极具争议；自720年起，争斗爆发，争论除圣餐之外，何种基督再现神学上可接受，以及圣徒崇敬的视觉中介可有何种角色，若确有角色的话。843年图像最终恢复地位，确认圣像本质上神圣，为其在崇敬与神学中的权威作用开路。圣像与文本、圣髑辩证互动，把圣徒崇敬带出教堂，进入家庭或战场，赋予每位圣徒明确视觉身份；即使同一圣徒，西方也缺乏这种身份。圣像破坏之后，圣像能确立、也能取消圣徒身份，新神学家西缅试图为“虔敬者”西缅建立崇敬所引争议，便是一例。[^p631-78]

圣像破坏争论对重新界定拜占庭圣徒崇敬居于核心，在拉丁世界的反响却小得多。约800年前后，圣洁的视觉再现确实触动一些西方思想家，但希腊文与拉丁文翻译困难，使平等参与争论很难。尽管东西方商业政治联系加强，圣像始终未在西方虔敬中扎根，这正反映宗教身份分化。对拜占庭，圣像破坏是以最深层方式，剧烈重定社会与神圣关系；对西方，则只是一个不再由相同源泉注水的文化水库表面的涟漪。[^p631-79]

圣像与圣髑，都以可触形式传递圣徒的天上临在。因此，它们与充当人神象征桥梁的圣餐，必然具有关系，尽管间接。当西方后来讨论这一关系时，辩论不是围绕圣像，而是圣髑。圣髑与圣餐饼有许多共同点：两者无论分出多少代表性片段，都代表完整整体。此外，若无圣徒遗骸，就在祭坛置祝圣饼的习惯，也暗示两者可比。因此，<a id="pdf-632"></a><!-- PDF page 632; original page 604 -->1100年前后，当偏离常规的实践或知识思辨，将目光转向圣餐时，圣髑作用受到前所未有审视，并不奇怪。[^p632-80] 但理性界定身体部分圣髑，相对于基督教核心圣事的中介与奇迹作用，仍未能穿透支撑圣徒崇敬的丰富传统实践和未言明预设。

诺让的吉贝尔对此观点尤其强烈。约1120年写作时，他从基督身体在圣餐中的完整性出发，注意并痛斥那些不可信、却无限增殖的基督和圣徒身体部分遗物，力图使圣徒崇敬重回早期教规标准。他失败了，但分析前提仍值得强调。他清楚区分“教会实践并教导的事项……如洗礼和主的圣饼圣事”，与“另一些有实践，却不教导的事项，如禁食和唱诗习惯”。他说，前者“凭权威始终无差别地实行，各地不变……指导它们及从中学得的教义相同”；东西方胸襟开阔的基督徒，都可能接受这一说法。[^p632-81] “其他事项”并非“我们得救最高的必要之事”，而以“多样性”为特征。把圣徒崇敬归为“有实践、无教导”的事项，吉贝尔指出其本质：圣徒敬礼补充基督徒与上帝的圣事关系，却不由正式教义界定，也未在圣经释义中勾勒；相反，悠久实践赋予其权威，多样性是其标志。虽然他呼应数世纪以来验证个别圣徒资格的关切，却坚定维护一般原则：“圣徒是值得我们敬重尊荣的人，以回报其榜样和保护。”[^p632-82]

吉贝尔概括圣徒及崇敬在基督教传统中的位置，指出自古代晚期未变的持久特征。但1100年的圣徒与崇敬，无论话语、图像、礼仪，还是<a id="pdf-633"></a><!-- PDF page 633; original page 605 -->行动，已不同于600年。基督教地缘政治变化，与数世纪流逝相结合，使认知与实践的多样性大为增加。不断演变的罪之补救，以及活生生禁欲圣洁与教会、世俗制度权威之间始终易变的关系，也起同样作用。便利与批评，都影响人们如何以文本、可触物件中介、迁移、再现圣徒力量。“有实践、无教导”，圣徒与崇敬始终能够无尽重造：赋予圣洁，始终根植于活人共同体的需要，即以能使世界获得意义的方式，在身边找到神圣。
