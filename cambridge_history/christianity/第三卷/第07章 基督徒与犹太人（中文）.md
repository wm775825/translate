# 第07章 基督徒与犹太人

巴特—舍瓦·阿尔伯特（Bat-Sheva Albert）

<a id="pdf-188"></a><!-- PDF page 188; original page 159 -->

在漫长的犹太—基督教关系史中，中世纪早期是一个既采纳、又延续教父和会议反犹态度，以及基督教罗马帝国犹太人立法的时期；这些立法，已汇入狄奥多西二世《法典》（公元438年）。法典承认犹太教合法，保护犹太人及其财产，同时也使其受到各种歧视。

蛮族诸王和教会，确实认可这些四、五世纪法律与会议教规，但往往无力执行。此外，这一时期出现完全新鲜之事：王室——西哥特西班牙——或帝国——拜占庭——颁布敕令，推行强迫皈依。然而，蛮族征服西方虽确实影响西方犹太人的处境，伊斯兰教的胜利，后果更大。约600年，希腊、意大利中部、小亚细亚、叙利亚、巴勒斯坦、北非和埃及的犹太人，受拜占庭控制；意大利北部、高卢、西班牙的犹太人，则受正统派或阿里乌斯派蛮族国王统治。到1100年，近东、北非、埃及，以及西班牙部分地区的犹太人，全部生活在穆斯林征服的土地上。

此外，拜占庭压制，以及950年后德意志皇帝征服意大利北部和中部，继而莱茵河谷和斯拉夫东方商业扩张，推动了查理曼治下已开始的迁徙。因此，除里昂、马孔、索恩河畔沙隆和阿尔勒较古老的团体，九世纪初凡尔登已有犹太商人。十世纪末，显要犹太人从卢卡迁往美因茨；默兹河地区，以及亚琛、梅斯、特里尔、克桑滕和诺伊斯，也有犹太人存在的证据。顺流而下，科隆、波恩、美因茨、<a id="pdf-189"></a><!-- PDF page 189; original page 160 -->沃尔姆斯和施派尔，都有团体，还可加上美因河畔班贝格、内卡河畔海尔布隆、萨勒河畔梅泽堡，以及多瑙河畔雷根斯堡。更东方，易北河畔马格德堡，以及布拉格，也出现团体。[^p189-1] 法兰西的利摩日，尤其香槟地区的兰斯、特鲁瓦、桑斯、欧塞尔和香槟沙隆，可追踪犹太人踪迹；香槟后来成为重要犹太学术中心。鲁昂也有犹太人，1066年后，诺曼犹太人从那里移往伦敦。德意志帝国内，这些新团体享有特许，有时取代古代晚期罗马立法，有时附加于其上。这种对犹太人的新政治立场，将维持几个世纪，却大体并不有利于他们。总之，中世纪早期，见证了西欧和中欧众多新犹太团体的建立。

就基督徒对犹太教态度的演变而言，中世纪早期是过渡阶段，在两种反犹态度间摆动。第一种忠实维持教会和基督教罗马法的立场；第二种同样宣称继承教父，却从中汲取更敌对、更压制性的倾向，也许使其超出基督教罗马立法所规定的歧视限度。遗憾的是，除拜占庭和拜占庭意大利，犹太资料匮乏，[^p189-2] 阻碍我们直接接触这些“他者”，[^p189-3] 以及他们对两种立场的反应。在西方，两种态度，分别由最后的教父大教宗格列高利（590—604年）和塞维利亚的伊西多尔（636年卒）代表。

格列高利尊重传统，严格遵守《狄奥多西法典》。他采纳奥古斯丁的观点，赋予犹太人守护经典的角色；这些经典，恰恰证明基督已经降临，以及犹太人终将在末世自愿皈依。格列高利建议以讲道争取皈依，因为他<a id="pdf-190"></a><!-- PDF page 190; original page 161 -->认为，促成真诚皈依，讲道比强制有效。[^p190-4] 此外，他命令为皈依者提供司法或经济帮助，鼓励改宗。[^p190-5] 特拉奇纳犹太人，被当地主教赶出会堂；他保护他们，不顾主教阻挠，允许另建会堂。巴勒莫主教没收会堂及全部所属建筑时，他也作同样回应，卡利亚里亦然。[^p190-6] 但格列高利仍毫不犹豫，严禁犹太人占有基督徒奴隶，或向犹太人出售这些奴隶，[^p190-7] 偶尔也发表对犹太人颇怀恶意的评论。[^p190-8]

不过，教宗态度公正。他起草著名的 Sicut Iudaeis，即《正如对犹太人》书信，后来带有某些极重要变体，指导数世纪教宗对犹太人的政策。格列高利确认：“正如犹太人〔Sicut Iudaeis〕不得胆敢在会堂行使超越法律许可的自由，也不应使他们蒙受已经获准之权利的任何损失。”[^p190-9] 他斥责特拉奇纳主教这类无端侵害犹太人的人时，书信语气更同情犹太人。犹太人也十分清楚，教宗会为他们伸张正义，毫不犹豫投诉迫害自己的教士。原则上，虽然这个原则确有一些臭名昭著的例外，<a id="pdf-191"></a><!-- PDF page 191; original page 162 -->[^p191-10] 后来的教宗，采纳大格列高利反对通过强制，使犹太人皈依、促成犹太人和基督教世界得救的立场。

塞维利亚的伊西多尔，虽宣称极为敬佩教宗，在这方面实际上没有追随他。他以公开敌视犹太人的态度，为教父时代收尾，认为他们是最后一个不响应皈依召唤的民族。[^p191-11] 两位教父性情不同，无疑影响其对犹太教的反应；但细心阅读他们的教士，确实在著作中发现两种矛盾立场。两者都会指导、决定未来态度；后者经常在两种教父权威之间交替摆动。

本章分三部分，追溯这一时期犹太—基督教关系的演变，展示这些教会政治立场与措施，如何不规则地来回摇摆。第一部分，描述西哥特西班牙和拜占庭帝国使用压制措施、引入强迫皈依。第二部分，勾勒墨洛温诸王（约500—751年）、加洛林继承者——东法兰克为768至911年，西法兰克王国直至987年——以及从奥托一世（936—973年）至亨利四世（1056—1106年）的德意志皇帝，较为温和的立场。第三部分也是最后一部分，讨论重要的 Contra Iudaeos，即反犹太教论战文学。这类文学继承重要的反犹著述与释经传统，整个中世纪早期，继续启发同类写作。第二、三部分，也使我们一窥十字军时代初启时犹太人地位变化的开端，以及十二世纪复兴开始时，反犹太教论辩的演变。

## 压制与强迫皈依

西哥特王雷卡雷德587年皈依正统基督教，伦巴德人七世纪随后跟进之后，犹太人——那“硬着颈项的民族”——长期成为西方唯一宗教异议者。因为阿里乌斯派消失以后，西方基督教直到<a id="pdf-192"></a><!-- PDF page 192; original page 163 -->十一世纪，未再出现重大异端运动。八世纪末、九世纪初西班牙的嗣子说，很快消失。作为仅存的抗拒者，其顽固被认为延迟基督最后降临，因此，犹太人有理由害怕日益加强的皈依努力。拜占庭帝国确实继续面对宗教异议者，尤其圣像破坏的支持者或反对者；但即使按罗马法犹太教合法，在西哥特西班牙和拜占庭，一切宗教异议者，包括犹太人，都被视为对政治共同体的威胁。从此，犹太人常须在受洗与自行流亡或遭驱逐之间选择。

### 西哥特西班牙

中世纪早期对犹太人最狂热、残酷的压制，发生在西哥特西班牙。历史学家仍努力辨明这种激烈迫害的动机；它已不啻反犹主义。[^p192-12] 不过，最后几位西哥特王埃尔维格和埃吉卡，确曾提出干预犹太人的理由。

埃尔维格于680年，在可疑情形下登位，意图赢得强大西哥特教会支持，且毫不掩饰。在第十二次托莱多会议（681年），他恳请教士“洁净王国”，清除妨碍它的罪，“而高于这一切”，要追逼犹太人，批准新近颁布的反犹法律。[^p192-13] 西哥特人587年皈依正统基督教后，犹太人的法律地位逐步恶化。这些措施在多大程度上影响日常生活，并不清楚；法律不断重复、愈发严厉，确实使人怀疑其效力。雷卡雷德皈依后，第三次托莱多会议（589年）召开，大格列高利祝贺国王在那里通过反犹立法。[^p192-14] 616年，西塞布特王出于真诚信仰，下令强迫皈依。朋友塞维利亚的伊西多尔，偏好劝服而非强制，批评了他，却仍断定，不论何种方式的皈依，都不可撤销。[^p192-15] 伊西多尔之后，会议教规与王室立法，既以严苛，也以充满仇恨的措辞为特色。雷凯斯温特（654年）和埃尔维格（680年）的法典，对犹太人毫不宽容。

教会如何影响这种反犹态度，长期受到争论。[^p193-16] 西塞布特强制皈依，以及伊西多尔的反应，前面已经提及。此外，伊西多尔主持的第四次托莱多会议（633年）教规60，命令将犹太儿童与父母分离，交基督徒教育。同一会议，不只禁止犹太人，也禁止皈依者担任公职。[^p193-17] 这是否意在利用犹太人害怕子女被夺走的心理，鼓励他们皈依，以消灭西班牙犹太教？排除皈依者与犹太人的基督徒后裔，明显带有世袭族群歧视色彩。无论如何，会议与王室立法越来越压迫：第六次托莱多会议（638年）前夕，该城犹太改宗者须宣誓信仰告白（professio），放弃犹太教及其法律，保证不再与旧教友交往、不再遵守其教导，并保证违法者会被处死。[^p193-18] 654年，托莱多犹太人又被要求公开宣誓（placitum）。[^p193-19] 裁决众多，尤其第十二、十六、十七次托莱多会议，即681、693、694年的裁决，以及埃尔维格、埃吉卡的立法，特别凶狠。埃尔维格寻求教会援助，把反犹法律交第十二次会议批准。犹太人与子女必须受洗；又因禁止遵守犹太法律、节期，他们无法再实践犹太教。[^p193-20] 只有国王，有权宽赦改宗者。[^p193-21] 教会也许对这些立法退缩，埃尔维格警告：任何教士若被发现疏于执行，即遭绝罚，罚金一磅黄金。[^p193-22] 最后几次托莱多会议，即693年的第十六次与694年的第十七次，由埃吉卡王召集。王国正陷入严重社会经济危机，饥荒、<a id="pdf-194"></a><!-- PDF page 194; original page 165 -->瘟疫、奴隶逃亡，接连发生。国王停止迫害改宗者。他坚信，王国救恩在于信仰，自己有义务以有益疗法医治社会病患；洗礼即使出于强迫，也会使受洗者进入恩典状态。因此，他寻求教会支持，医治王国：必须根除偶像崇拜，但最重要，“必须粉碎犹太人可诅咒的背信”。[^p194-23] 最后，国王在第十七次托莱多会议（694年）前论称，自己已穷尽劝服手段，犹太人却未守诺。因此，他依靠教会促进正义。他指控，犹太人沾着基督之血，图谋毁灭国土；因此，要没收财产，将他们分散西班牙各地，永远降为奴隶。[^p194-24]

然而，教会与王权近乎完全共生，以及君主制的制度性脆弱——西哥特诸王未能建立世袭王朝——不足以充分解释西哥特反犹太教态度的极端性。不过，这些在蛮族王国中例外的措施，仍是孤立现象。其意义，在于部分进入沃尔姆斯的布尔夏德，以及沙特尔的伊沃（约1040—1115年）重要教规汇编，[^p194-25] 后来又被格拉提安（约1159年卒）保留。但教会法学家并不认可后来那些明显违背基督教传统的托莱多教规，包括禁止犹太教实践、奴役犹太人。教会法只采纳第四次会议（633年）教规，虽加强此前会议立法的歧视，仍保留伊西多尔赋予的法律地位；他是主持该会议、后来被尊为圣徒的主教。

### 拜占庭

查士丁尼一世皇帝（527—565年），虽在以他为名的著名法典中，颁布十分严厉的反犹法律，真正下令强迫犹太人皈依、以实现宗教统一的，却是634年的希拉克略皇帝（610—641年）。当时，拜占庭正面对伊斯兰教，接收大量波斯基督徒难民，而末世<a id="pdf-195"></a><!-- PDF page 195; original page 166 -->期待，[^p195-26] 在波斯人、继而伊斯兰教胜利的刺激下，又加重了基督徒对犹太人的敌意。[^p195-27] 不过，这项措施似乎仅在北非得到执行：[^p195-28] 到691年，特鲁洛会议，即第五六次会议，仍批评犹太人与基督徒的关系过于友好，不合与会教父的心意。[^p195-29]

圣像破坏派皇帝利奥三世（717—741年）统治时，这一问题再次出现。与希拉克略一样，利奥打算消除一切宗教异议，认为宗教一致可以保障政治稳定。第二次尼西亚会议恢复圣像崇敬时（787年），也间接谴责了利奥三世的反犹立场，理由是被迫皈依者无论如何仍在秘密奉行犹太教；只有真诚的皈依才被认为有效。[^p195-30] 八世纪的圣像破坏派皇帝迫害他们的正统派对手，后者也同样迫害前者。此后，皇帝迫害小亚细亚的混合宗教派别和其他教派，企图彻底消除包括犹太人在内的一切异议者。保罗派在拜占庭—阿拉伯边境建立了国家，并与阿拉伯人结盟；巴西尔一世（874—886年）对他们发动的战争，加深了他对异端的敌视。与此同时，阿莫里乌姆出现一个教派，信奉一种犹太—基督教式、清教主义的一神论。巴西尔一世自称异议者的敌人，[^p195-31] 寻求教会帮助，掩饰自己的卑微出身，以及为登上皇位所犯的罪行。按照他自己的说法，他曾召集著名拉比举行辩论，试图说服他们；这一方法失败后，便实行强制洗礼（约874年）。不过，巴西尔一世拟定、旨在取代《查士丁尼法典》的《巴西利卡法典》（886年），仍沿用后者的反犹立法，在若干严厉限制下承认犹太教的合法存在。他的儿子利奥四世（886—912年），后来放弃了父亲的反犹政策。〔译注：此处皇帝序号原文如此；886—912年在位者为利奥六世。〕然而，篡位皇帝罗曼努斯一世·莱卡佩努斯统治时，迫害又告恢复。932年，罗曼努斯命令强迫改宗，并赋予这一命令法律效力。一些犹太人逃往中亚可萨人的犹太教王国；拜占庭<a id="pdf-196"></a><!-- PDF page 196; original page 167 -->意大利的犹太人则受到迫害。最后，科尔多瓦哈里发宫廷中的犹太大臣哈斯代·伊本·沙普鲁特出面干预，才结束了这一轮事件。

此后直到第一次十字军东征，犹太人一直和平生活；帝国甚至接纳了逃避埃及法蒂玛统治者哈基姆（996—1021年）迫害的犹太人。十一世纪初，帝国陷入一连串危机：1028至1081年的53年间，先后有13位皇帝登基。1071年，塞尔柱突厥人重创拜占庭，拜占庭失去了小亚细亚、亚美尼亚和卡帕多基亚的大片土地。与这些危机相比，犹太人问题便显得不那么紧迫了。

由此看来，这些使犹太人改宗的不同尝试，都只取得局部、暂时的成功，也未获立法的最终确认。尽管困难重重，帝国皇权仍然稳固，拜占庭直到十一世纪还是强国。拜占庭的皇帝教宗主义，保证了皇帝能够继续强加反犹政策。犹太教的永久法律地位——虽受歧视，却仍然合法——与皇帝敕令强迫改宗之间的矛盾，可以解释为什么所有这些改宗都只是暂时现象，最终归于失败。

### 较为温和的做法：墨洛温王朝、加洛林王朝与德意志帝国

在墨洛温时期的法兰克，犹太人很少受到侵扰。[^p196-32] 法兰克教会会议的立法，[^p196-33] 确认了埃尔维拉会议（300—306年）禁止基督徒与犹太人共餐的规定；不过，这一措施恰恰说明，此类交往正在发生。犹太人还被禁止担任公职，以及出售、占有基督徒奴隶，或为他们施行割礼；[^p196-34] 这些措施源自古代晚期教会会议的先例和《狄奥多西法典》。查理曼（768—814年）统治时，反犹立法短暂沉寂；虔诚者路易（814—840年）在位时尤其如此，里昂总主教阿戈巴尔德（840年卒）甚至指责他对犹太人<a id="pdf-197"></a><!-- PDF page 197; original page 168 -->过分优待。[^p197-35] 822至827年间，路易向拉比多纳图斯和他的侄子撒母耳颁授《犹太人敕令》（Praeceptum Iudaeorum）。这一特许保护他们的人身和财产，免除货物运输税，并使他们免受神判。更前所未有的是，它禁止基督徒劝说犹太人的奴隶皈依基督教。[^p197-36] 另一道旨在惠及犹太商人的“敕令”，许诺保护他们，并免除兵役；一位宫廷高级官员“犹太人事务长官”（Magister Iudaeorum）负责为犹太人主持司法。[^p197-37] 秃头查理（843—877年）统治时，环境稍不利一些。巴黎—莫城会议（845—846年）确曾认可西哥特的反犹教规，[^p197-38] 不过，在加洛林诸王，以及德意志皇帝奥托一世（936—973年）、奥托二世（973—983年）和亨利四世（1056—1106年）治下，几乎没有针对犹太人的人身迫害。[^p197-39]

1090年，亨利四世略加修改，确认了主教吕迪格尔·胡奥茨曼于1084年授予施派尔犹太团体的重要特许；此举预示了十二世纪初犹太人社会地位的变化。为了鼓励犹太商人定居，胡奥茨曼划出一个街区供他们居住——周围筑墙保护——并划给他们一块墓地，允许他们的首领，即会堂长（archisynagogus），裁决犹太人之间或涉及犹太人的争端。此外，他允许他们在城内自由经商，雇用男女基督徒仆役（圣日除外），并有权参与保卫、加固自己的街区。[^p197-40] 可以说，主教授予他们一种最优惠待遇；他还承诺，倘若帝国另一座城市制定类似文书，就给他们更为有利的特许。

然而，教会与王室的立法此前已经禁止犹太人雇用基督徒仆役和服兵役。况且，犹太人处境这种表面上的改善，实际很不稳固。特许在实践中可能遭撤销，也必须得到授予者继任人的重新确认。后来，仅仅以取消既有自由或拒绝重新确认为威胁，就为经济勒索打开了道路；在随后几个世纪，这种勒索沉重压在<a id="pdf-198"></a><!-- PDF page 198; original page 169 -->犹太团体身上。也许后果更严重的是，这些特许突出了犹太人的异质性。居住区的隔离和设防——无疑也是应他们自己的要求——固然提供了日常保护，却也使他们在暴乱中成为更显眼的目标。十一世纪末的情形确实如此：城市经济竞争越来越激烈，十一世纪后半叶的教会改革和第一次十字军东征（1096—1099年），共同点燃了更为炽烈、从此也更具反犹色彩的民众宗教热情。在反犹者看来，被指控杀害上帝的犹太人，没有因其针对救世主的罪行受到追究，反而获当局优待，甚至享有经济优势。从此，犹太人只靠这些特许得到保护，命运取决于保护者；而这些保护者面对敌对势力和反犹骚乱，有时不愿行动，有时无能为力。1096年夏季，十字军和部分城市居民，尤其在德意志地区犯下的屠杀，虽未重演，但在此后几个世纪，犹太人仍不断遭到暴力迫害、勒索，后来又被驱逐。

### 《驳犹太人》文献

整个这一时期，都有人撰写《驳犹太人》（Contra Iudaeos）文献，包括论战著作、辩论录（通常出于虚构）、圣经注释，甚至圣徒传记。这些作品延续教父《驳犹太人》文献的传统，主要取用其中耶柔米、奥古斯丁、大格列高利和塞维利亚的伊西多尔的释经材料。事实上，直到十二世纪，几乎所有反犹论证都以《旧约》的寓意注释为基础。值得注意的是，七世纪至十一世纪初，拉丁基督教世界中，严格意义上题为《驳犹太人》（Contra或Adversus Iudaeos）的论战作品很少。[^p198-41] 相比之下，拜占庭帝国此类著作很多，希腊语和叙利亚语作品也比<a id="pdf-199"></a><!-- PDF page 199; original page 170 -->拉丁基督教世界的作品更有独创性：它们的论证方式随着历史与神学危机作出调整。

这类文献对犹太—基督教关系的演变有什么影响？显然，阅读这些作品容易助长读者——主要是教士——的反感，有时也被用来为严格说来违法的反犹措施辩护。不断重述教父文献中大量反犹段落，不可避免地使犹太人问题一直受到关注，尽管犹太人口比例微不足道，实际上并不存在“犹太化”或因信仰而皈依犹太教的威胁：[^p199-42] 已知的改宗者，只有加洛林宫廷的首席礼拜司铎博多（839年），以及一位名叫韦策林的德意志教士（1106年）。〔译注：原文此处作1106年，后文叙述同一人的改宗及书信论辩时作约1006年。〕

另一个问题是，中世纪早期，反犹太教的态度是否转向了反犹主义。这是个棘手问题，因为二者之间的转变，发生得难以察觉。[^p199-43] 无休止地重复《旧约》所列举的犹太人罪行，以及无数次指控他们杀害上帝——这些指控也在受难日礼仪中反复出现——损害了犹太人的形象。按照这些论述，上帝过去对他们的爱已经结束，他的拣选转向了基督徒，即“真正的以色列”（Verus Israel）。《福音书》和保罗书信的某些经文，很容易被用于反犹注释，[^p199-44] 激起非理性的感情：犹太人被认为受到上帝鄙弃，因此不可避免地也受到上帝真正信徒的鄙弃。

七世纪，塞维利亚的伊西多尔《据新旧约论大公信仰驳犹太人——致妹弗洛伦蒂娅》（De fide catholica ex veteri et novo testamento contra Judaeos ad Florentiam sororem suam），[^p199-45] 居于西方论战文献之首。这部长篇著作，在题材选择、论证方法和语调方面，都承袭教父，尤其耶柔米和奥古斯丁的论战。全书分为两部分：第一部分试图证明，基督由童贞女所生，以及直到复活为止的生平事迹，都已在《旧约》中预告；并称犯罪、不信的犹太人，已经因<a id="pdf-200"></a><!-- PDF page 200; original page 171 -->圣殿被毁、政治独立丧失和流亡而受到惩罚。第二部分则力图证明，基督降临以后，《旧约》的律法已经失效。伊西多尔的作品大获成功：十一世纪以前制作的抄本，现存21部；九世纪又被译成古高地德语。[^p200-46] 各章很短，先列圣经经文，再附简要解释，解释受到耶柔米、奥古斯丁、大格列高利作品启发，或直接援引它们。这部著作毫无独创性，因为伊西多尔唯一的目的，就是以论战式释经武装教士读者，使其对付犹太人。[^p200-47] 犹太人也出现在伊西多尔的其他释经著作中，而且总以贬损形象出现。[^p200-48] 他的反犹论战在西哥特西班牙后继有人，尤其见于托莱多的尤利安（644年生）的著作；尤利安本人出身犹太人，却因为犹太人坚持不肯承认弥赛亚已经降临，攻击他们比伊西多尔更为猛烈。[^p200-49]

在拜占庭，七至九世纪困扰帝国的三场重创，加剧了反犹论战：希拉克略对波斯的战争（627—629年）；穆斯林在近东、埃及、北非和西班牙的胜利（622—711年）；最后是圣像破坏危机（约725—787年、814—843年）。拜占庭著作把这些灾祸全归咎于犹太人，指控他们帮助波斯人、跻身伊斯兰教最早的追随者，并煽动穆斯林反对基督徒；甚至有人声称，伊斯兰教起初就是两个犹太人编造出来的；[^p200-50] 最后，又指控他们挑起圣像破坏。基督徒的失败，推动反犹著作大量涌现，[^p200-51] 将犹太人与穆斯林归为一类。希腊语和叙利亚语论战作者认为，基督受难以后，罗马人战胜了犹太人，这就预示罗马人的拜占庭继承者，在悔罪以后，也必将战胜伊斯兰教。从七世纪起，东方基督徒以反犹言辞，隐晦攻击伊斯兰教：他们试图借此鼓舞信徒士气，同时淡化<a id="pdf-201"></a><!-- PDF page 201; original page 172 -->基督徒的军事失败。[^p201-52] 叙利亚语著作《达马斯的战利品》和《犹太人帕皮斯库斯、斐洛与一位修士的对话》，受到西奈的阿纳斯塔修所著、影响广泛的《驳犹太人辩论》（Dialexis kata Ioudaioon，七世纪后半叶）启发；阿纳斯塔修是西奈山圣凯瑟琳修道院院长。这部迅速广为流传的作品，讨论传统主题：三位一体，以及先知预告的耶稣降临；也涉及犹太人对图像和祭仪物件的敬奉问题。[^p201-53] 考虑到作品写于圣像破坏运动之前，可见它旨在面对犹太教和伊斯兰教，为图像辩护。这些论战作者中最重要的，是美索不达米亚的麦勒凯派主教狄奥多若·阿布·库拉（约755—约830年）；他攻击犹太人为“万国之中最可憎的民族”。[^p201-54]

阿拔斯王朝时期，开始举办“议会”（majlis），即由哈里发或显要穆斯林邀请三大宗教代表参加的学术讨论或辩论。虽然辩论者理应遵守礼貌规则，犹太人却抱怨，自己同时受到基督徒和穆斯林的贬损；穆斯林有时还让他们负责核查基督徒引述圣经是否准确。[^p201-55] 一位科普特牧首，拿他们与牛、驴作比较，认为他们还不如牲畜；提比里亚的修士亚伯拉罕援引《古兰经》，提醒他们，耶稣曾把一些犹太人变成“猴子和猪”；法蒂玛王朝的维齐尔伊本·基利斯（977年以后）本人由犹太教改宗，却极度蔑视他们。[^p201-56]

拜占庭的圣像破坏派在争论初期，声称图像是《旧约》谴责的偶像。因此，恢复图像使用的第二次尼西亚会议（787年），把圣像破坏派与犹太人、撒马利亚人归为一类。[^p201-57] 在七、八世纪拜占庭的《驳犹太人》文献中，对真十字架、圣髑和圣像崇敬的辩护，逐渐加入传统反犹主题：弥赛亚信仰、耶稣的神性、杀害上帝、犹太人受罚等。[^p201-58] 其中的核心论点宣称，犹太人敬拜金牛犊、<a id="pdf-202"></a><!-- PDF page 202; original page 173 -->法版，以及会幕的祭仪物件，自己就犯了偶像崇拜之罪。[^p202-59] 受尼亚波利斯的莱昂提乌斯启发，狄奥多若·阿布·库拉指出，摩西、大卫和所罗门都曾使用图像；他试图借此唤起东方基督徒和穆斯林共有的反犹偏见，使圣像破坏丧失信誉，[^p202-60] 尽管穆斯林本身也和犹太人一样，强烈反对图像及以十字架为敬奉对象。

拜占庭与伊斯兰教的冲突，在基督徒和犹太人中都激起了弥赛亚期待。在《伪美多迪乌斯启示录》（叙利亚语；希腊语改写本约675年）的作者看来，犹太人和阿拉伯人都是上帝施罚的工具，但拜占庭终将获胜；在该书的希腊语版本中，罗马帝国的不可战胜，仍仅限于对犹太人的胜利。[^p202-61] 犹太作者则期待拜占庭人最终失败，并以自己用希伯来语撰写的启示录予以反驳：[^p202-62] 他们称希拉克略为阿尔米卢斯——弥赛亚之敌的名字——将他的失败解释为犹太弥赛亚时代即将到来的预兆。

加洛林文艺复兴也产生了一批有独创性的作品，尽管这一时期的作者并不以独创性自居。《驳犹太人》式论战，大多出现在他们的圣经释义中，因为撰写圣经注释，在加洛林时代极受重视。耶柔米的释经遍布对犹太教的谴责；奥古斯丁《上帝之城》则包含他关于基督教世界中犹太人命运的根本论述。这些著作滋养了加洛林释经中的反犹太教态度。

不过，对希伯来语圣经文本和犹太释经的兴趣，也出现了复兴。耶柔米去世近400年后，人们重新渴望了解犹太人对经典的认识；这种兴趣已经不像耶柔米那样，局限于希伯来语知识。在里昂，总主教阿戈巴尔德与西哥特人弗洛鲁斯、阿莫洛组成的学者圈子，对耶柔米不熟悉的犹太书籍内容产生了兴趣。《驳犹太人》文献第一次利用圣经时代以后的犹太资料，服务于论战目的；这是值得注意的尝试，但直到十二世纪才有人重新接续。

杰出的加洛林学者、奥尔良的狄奥杜尔夫（821年卒），着手编制一部拉丁语圣经，要求比耶柔米译本——即《武加大译本》——更忠实于圣经文本的“希伯来原真”（hebraica veritas）。他请来一位犹太人协助；此人可能已皈依基督教，通常被称为“伪耶柔米”，著有关于《列王纪》和《历代志》的《问题集》（Quaestiones）。他的作品包含大量犹太传统，中世纪读者却归之于耶柔米，因为他们认为，只有耶柔米具备足够的希伯来语知识，能够撰写这些作品。[^p203-63] 狄奥杜尔夫想必已经得知，耶柔米的拉丁译本并非总能准确传达希伯来语圣经的意义，因此请一位“希伯来人”（hebraeus）注释耶柔米的译文。这位“希伯来人”，正是这里的伪耶柔米；凡耶柔米译本有所铺陈、而希伯来原文没有相应文字的地方，他都标上h.[ebraeum] non habet，即“希伯来〔文本〕无〔此〕”。然而，狄奥杜尔夫的圣经，未能获得这项近乎科学的事业本应得到的成功，现存抄本仅五部。

其他加洛林文人，也表现出对希伯来语圣经文本的兴趣，尤其是都灵的克劳狄乌斯（827年后卒）、里昂的阿戈巴尔德，[^p203-64] 以及里昂的弗洛鲁斯。值得注意的是，这些“希伯来学者”中的三人——狄奥杜尔夫、克劳狄乌斯、弗洛鲁斯——都是西哥特人，阿戈巴尔德也可能如此。因此可以追问，他们对希伯来语圣经的兴趣从何而来，又有什么动机。的确，许多问题仍有待满意解答。加洛林人热衷研究《旧约》，无疑植根于一种政治意识形态：把查理曼视为新大卫，把虔诚者路易视为所罗门；篇幅所限，我无法在这里讨论这种圣经比附的起源或意义。不过请注意，借用犹太释经的情况，恰好见于伪耶柔米的《问题集》，以及都灵的克劳狄乌斯、赫拉班·毛鲁斯（约780—856年；他也利用了伪耶柔米）和吕克瑟伊的安杰洛穆斯（约850年）关于《撒母耳记》《列王纪》的著作。[^p203-65][^p203-66] 这种兴趣，或许反映了<a id="pdf-204"></a><!-- PDF page 204; original page 175 -->查理曼和虔诚者路易时期，犹太—基督教关系较少敌意的氛围；这一氛围也体现于授予犹太商人的特许。不过，我们必须警惕，不能仅凭授予个别犹太人的特许，或阿戈巴尔德、阿莫洛的反犹辱骂，就过于仓促地断言犹太人在宫廷中拥有影响力。前者只惠及少数犹太商人，后者则是掩饰不多的宣传行为。

尽管这些释经者关注犹太资料，他们的作品仍充斥反犹注释，常把犹太人描述为残酷、背信、嫉妒、忘恩负义等等；有些注释，甚至散发出酷似反犹主义的气息。[^p204-67] 赫拉班·毛鲁斯的反犹太教态度停留在文献之中，里昂的阿戈巴尔德和阿莫洛（840—850年任总主教），则着手在里昂教区及更广泛的法国南部，使犹太人与基督徒在社会生活中隔离。在他们看来，犹太人的影响太大，犹太—基督教关系也过于友善；他们意在说服虔诚者路易撤销对犹太人的保护。826至850年间，他们搜集那些在自己看来最可笑的犹太传统，如以神秘方式计算上帝身体的尺度，[^p204-68] 或他们认为具有冒犯性的材料，如《耶稣生平》（Toledot Jeshu）中的内容。[^p204-69] 阿戈巴尔德最想做的，是败坏那些使奴隶改宗、又吸引基督徒皈依犹太教的犹太人的声誉。不过，他也毫不退缩地攻击他们在宫廷中有权势的保护者，甚至把科尔比修道院院长、查理曼的堂亲瓦拉列为目标。[^p204-70]

这种攻击本身不会造成太大影响，因为虔诚者路易鄙视阿戈巴尔德，后者也乐于回敬同样的感情。[^p204-71] 然而839年，宫廷首席礼拜司铎博多皈依犹太教的丑闻，为阿戈巴尔德的立场提供了理由。把西哥特会议的反犹立法引入加洛林帝国，突然显得势在必行。阿莫洛负责推动此事；他自称每天同犹太人讨论，熟悉《耶稣生平》，也了解有关犹太弥赛亚被囚于罗马地下牢房的犹太传统；他认为，这些传统显然<a id="pdf-205"></a><!-- PDF page 205; original page 176 -->违背福音和基督的弥赛亚身份。[^p205-72] 阿戈巴尔德失败之处，阿莫洛却成功了。他作为犹太教专家，参与巴黎—莫城会议（845—846年），促成会议采纳第四次托莱多会议的两项决定：禁止优待犹太人（第74条教规），并命令将犹太儿童与家人分离，交由基督徒抚养。[^p205-73] 此外，会议保留了第四次托莱多会议第60条教规的原有措辞，要求与父母分离的是犹太儿童，而非犹太人已经受洗的子女。[^p205-74] 倘若法兰克贵族没有拒绝认可巴黎—莫城会议的大部分教规，这项决定将会导致犹太教消失。加洛林《驳犹太人》文献的独创性，直到十二世纪才再有继承者。

十一世纪初，辩论重新出现，形式通常是一位犹太人与一位基督徒之间虚构的讨论，主题是基督教的真理与犹太教的虚妄。最早的辩论，是皇帝亨利二世宫廷教士亨利，与皈依犹太教的教士韦策林之间的书信往来（约1006年）。这些信件的主题，仍是犹太—基督教论战的传统问题：基督降临后犹太律法是否仍有效、耶稣的弥赛亚身份、道成肉身、三位一体，以及上帝对基督徒的拣选取代对犹太人的拣选。改宗者的语气咄咄逼人：他称基督教信仰应受诅咒，称基督徒对手为蠢人。但值得注意的是，韦策林的信很短，他的对手却长篇答复，使基督教一方占据优势。[^p205-75] 1093年，在第一次十字军东征即将彻底改变犹太—基督教关系之前，威斯敏斯特修道院院长吉尔伯特·克里斯平写了《犹太人与基督徒的辩论》（Disputatio Iudei et Christiani），极受欢迎。这部作品并无独创性，不过，双方辩论者承诺保持冷静，讨论也难得地平和进行。处理道成肉身问题时，吉尔伯特通过区分<a id="pdf-206"></a><!-- PDF page 206; original page 177 -->神性与神的位格，论证上帝成为人的可能性，呼应了坎特伯雷的安瑟伦在《上帝为何成人》（Cur deus homo，1095—1098年）中的论证。安瑟伦也曾在这场辩论的哲学方面帮助吉尔伯特。这些哲学论证，为犹太—基督教对话打开了新的思想视野。传统圣经释义仍将是辩论中公认的武器，但此后会有一种新工具相伴：理性（ratio）。于是可以追问，诉诸理性能否使犹太人与基督徒走向接近；十二世纪将关心的，正是这一问题。
