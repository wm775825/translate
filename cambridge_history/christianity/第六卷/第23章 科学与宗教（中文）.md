# 第23章 科学与宗教

作者：安·布莱尔（Ann Blair）

**原书未编号谢辞：**作者感谢安东尼·格拉夫顿、莫德凯·费因戈尔德，以及本卷编者提出的有益意见。

本卷讨论的宗教转型时期，在时间上大体对应于一系列重要的科学发展，传统上称为“科学革命”。人们通常认为这一时期始于哥白尼在《天体运行论》（1543年）中发表日心说，止于牛顿在《自然哲学的数学原理》（1687年）中提出物理定律。[^p448-1]在这150年间，约1200年传入拉丁西方后一直占主导的亚里士多德自然哲学，受到多方攻击，逐渐失去对课程体系的支配。人们提出各种替代权威，以及对自然的新解释。但到1650年，占据主导的新哲学，是机械论哲学，其前提是：一切现象，都可以解释为物质粒子的运动，遵循能够通过经验观察、实验加以研究的数学定律。

关于科学革命的历史研究，数量庞大。[^p448-2]除对核心人物与文本的详细研究外，还有丰富的研究成果，强调这些发展的社会、文化及思想背景。在这些背景因素中，宗教长期以来，一直被承认为格外重要的因素，至今仍然如此。

跨时代的科学与宗教关系史研究，早于科学史成为专业学科；从一开始，它就特别关注近代早期，把这一时期的某些发展，视为<a id="pdf-449"></a><!-- PDF page 449; original page 426 -->冲突的典范，例如伽利略事件，也把另一些视为合作的典范，例如“新教与科学”。尽管较近的科学、宗教互动研究，已不再采用如此鲜明对立的论点，近代早期，仍是格外丰富的研究领域。[^p449-3]十六、十七世纪，宗教与科学的新发展，共同动摇了经院哲学把亚里士多德主义与中世纪基督教结合起来的综合体系，并引发广泛的新互动。

## 中世纪的遗产

十三世纪，欧洲新建立的大学，接受了亚里士多德哲学，才使亚里士多德主义与基督教的经院综合成为可能。这一接受过程，并非没有问题。亚里士多德学说，初次在拉丁西方传授，就引发一连串谴责，至1277年达到顶点。巴黎主教艾蒂安·唐皮耶，把217条命题斥为不敬虔，因为他担心，人们正从亚里士多德学说中，推导出这些命题。[^p449-4]1277年的谴责，凸显了亚里士多德哲学与基督教信仰之间的若干紧张。亚里士多德，可以被解读为既支持世界永恒，也支持灵魂会朽灭。不过，托马斯·阿奎那，巧妙避开冲突，主张亚里士多德的结论是：单凭理性，无法裁定这些问题。阿奎那既不否定理性，也不否定亚里士多德的权威，而是论证，人的这些知识来源，必须由启示权威补充；启示则教导创造及灵魂不朽。

自然规律的必然性，是另一个重大紧张点。即使近代早期，亚里士多德主义让位于新哲学，这个问题也仍以不同形式出现。经院哲学，区分上帝的绝对权能与命定权能，既承认上帝有能力暂停自然规律，也承认实际上，上帝选择遵守这些规律。这一区分，使人们能够从自然原因出发，研究上帝在既定秩序中行使的权能，而不显得否认神的全能。[^p449-5]

托马斯·阿奎那等人，提出了这些化解冲突的办法。因此，到1325年，亚里士多德已在巴黎大学文学院，<a id="pdf-450"></a><!-- PDF page 450; original page 427 -->以及大多数其他大学的课程中，牢牢扎根。神学系与地位较低的文学院，在制度上分开，使哲学家能够在不同情境中，取得程度不一的、不受神学束缚的独立性。在巴黎，索邦神学院势力强大，哲学家遵守1277年的禁令；在帕多瓦大学，没有神学系，只有地位较高的医学院，哲学家享有很大独立，以激进的亚里士多德主义闻名。帕多瓦传统，一直延续到十六世纪，并日益引起教会反弹。帕多瓦教授彼得罗·蓬波纳齐（1462—1525年），在《论灵魂不朽》（1516年）中，得出结论：单凭理性，可以证明灵魂会朽灭，而非不朽。1518年遭教皇谴责后，他出版《辩护书》，纳入证明灵魂不朽的正统论证，并不再发表其他以极强自然主义方式，论述占星与奇迹的著作。[^p450-6]本世纪更晚些时候，切萨雷·克雷莫尼尼（1550—1631年），解释亚里士多德的世界永恒观时，并未使之基督教化，还否认上帝干预月下世界。他因此受到宗教裁判所调查，却仍保住帕多瓦大学的高薪职位。[^p450-7]

十六世纪，某些经院环境，曾给哲学家提供的制度及思想独立机会，正在减少。整个十六、十七世纪，自然哲学，都以宗教动机证明自身正当性，也受到宗教信念塑造。早在第五届拉特朗大公会议（1512—1517年），教会就要求哲学家，积极支持宗教教义，例如规定必须以哲学论证灵魂不朽。[^p450-8]宗教改革者，设计了新的课程，使自然哲学服务于宗教教义的需要。特伦托以后，天主教会，一方面通过教育，另一方面通过宗教裁判所及《禁书目录》，加强控制哲学著作的宗教正统性。

重新强调哲学必须虔敬，其动力并不只来自宗教。人文主义运动，同样敌视经院哲学，以及它所认为的亚里士多德主义的不敬虔。彼特拉克（1304—1374年），嘲讽亚里士多德主义贫乏无果，并重申1277年提出的、基督教对亚里士多德的经典反对理由。彼特拉克，没有提出取代亚里士多德的哲学，但他反对过度依赖亚里士多德及其方法，<a id="pdf-451"></a><!-- PDF page 451; original page 428 -->为其他人提出替代方案，开辟了道路。[^p451-9]

## 文艺复兴对虔敬哲学的寻求

人文主义者，以重新发现失传已久的古代文献闻名。其中，既有亚里士多德的古代注释，为“哲学家”提供新的、往往带批判性的视角，也有截然不同哲学传统的文本，尤其斯多亚、伊壁鸠鲁及柏拉图主义著作。此外，还有第欧根尼·拉尔修等人的学说汇编，介绍其他思想家的观点；后者著作，往往已不存世，例如前苏格拉底哲学家与毕达哥拉斯派。这么多替代传统，可以研究、仿效，亚里士多德不再是唯一选择。长期存在的宗教反对理由，可以用来证明转向其他权威的正当性，而这些权威，似乎更容易与基督教教义协调。

马西里奥·费奇诺（1433—1499年），推崇柏拉图，发展出一套足以与亚里士多德抗衡的完整哲学体系。除大量翻译、注释柏拉图外，他在约1474年写成、1482年出版的《柏拉图神学》中，提出了自己对基督教与柏拉图主义的综合。他把这种“虔敬哲学”，与他认为不敬虔的经院亚里士多德主义，对立起来。[^p451-10]费奇诺重申圣奥古斯丁的论证，认为柏拉图关于个体灵魂不朽，以及神圣造物主创造世界的教导，使其哲学，更容易与基督教协调。但二者并非完全契合，因为柏拉图相信灵魂轮回，而且《蒂迈欧篇》描述的创造，并非从无创造，而是以既有物质塑成。

柏拉图哲学，始终是一种吸引少数思想家的选择，例如法国的桑福里安·尚皮耶（约1470—1539年）、德意志的雅各布·波墨（1575—1624年），直至“剑桥柏拉图主义者”亨利·莫尔（1614—1687年）、拉尔夫·卡德沃思（1617—1688年）。后两人，把柏拉图主义，视为对抗机械论哲学之唯物主义解释的武器。[^p451-11]不过，反宗教改革教会，重新强调传统正统，导致弗朗切斯科·帕特里齐的著作，<a id="pdf-452"></a><!-- PDF page 452; original page 429 -->遭到谴责。费拉拉在1578年、罗马在1592年，曾为他设立柏拉图哲学教授席位，后来罗伯特·贝拉明，撤销了这些席位，因为他认为柏拉图主义，比亚里士多德主义，更危害基督教。[^p452-12]

人文主义运动，重新推向前台的另一位科学权威，是卢克莱修。他的《物性论》，提出伊壁鸠鲁学说，认为自然世界，由原子的随机运动及聚合形成。虽然许多人，仍把伊壁鸠鲁主义，与不道德、不敬虔联系起来，法国奥拉托利会士皮埃尔·伽桑狄（1592—1655年），却成为使卢克莱修基督教化的支持者。与卢克莱修不同，伽桑狄主张原子由神创造，上帝赋予其运动；他又引入天使及理性灵魂，补充世界的物质性结构。他认为自己的体系，比亚里士多德体系更加虔敬，优点之一，是能更好解释圣餐中发生的变化。[^p452-13]伽桑狄这一特殊原子论，虽然追随者不多，其论证，却为人们接受笛卡尔的机械论哲学，铺平道路。后者在许多具体问题上，虽然与之不同，也同样假定，世界可以解释为运动中的物质粒子。

尤斯图斯·利普修斯，受到斯多亚派吸引，不仅将其运用于政治哲学，也用于自然哲学，同样宣称，所得结果，比亚里士多德主义更为虔敬。[^p452-14]以自然主义闻名的前苏格拉底哲学家，也成为某些“新哲学”的基础，这些哲学，也宣称自己更加虔敬。例如，贝尔纳迪诺·特莱西奥（1509—1588年），以热、冷两项原则的相互作用，解释自然世界，并引入遍布世界、源于神的普遍精神，使体系基督教化。其弟子托马索·康帕内拉（1568—1639年），把世界精神思想，推向泛感知论的极端，将整个宇宙，想象为一只有生命的动物；上帝在其中，无处不在，并内在于世界。因此，自然充满对应关系及神的信息，自然哲学家可以解释它们尤其借助占星术。但特伦托以后的教会，并不相信这两种虔敬主张。特莱西奥的著作，在他死后的1593年，遭到谴责；康帕内拉，则在意大利监狱度过约三十年，1634年获释后，逃往法国。[^p452-15]

文艺复兴释放了大量哲学实验。在其中，另一种策略并不转向古代哲学权威，而是诉诸宗教启示与《圣经》，为真正虔敬的自然哲学奠基。特奥弗拉斯图斯·邦巴斯图斯·冯·霍恩海姆，自称“帕拉塞尔苏斯”，表示自己超越了古代医学百科全书作者塞尔苏斯。他拒绝把亚里士多德与盖伦结合起来的传统医学体系，支持化学疗法，并宣称神圣启示与经验观察都支持自己的选择。整个近代早期，许多人都鄙视帕拉塞尔苏斯，把他与放荡习惯、阿里乌主义异端及巫术活动联系起来，有时并不公允。[^p453-16]不过，他的追随者在其身后搜集手稿、出版著作，在不顺从正统的新教思想家中引起热烈反响。这些人因宗教迫害而被边缘化、趋于激进，尤其集中于中欧。激进的帕拉塞尔苏斯主义者，赞扬他的著作同时汲取恩典之光与自然之光，把神学与哲学真理结合起来。[^p453-17]在这种宗教、哲学改革的乌托邦愿景中，千禧年主义经常存在，正如在较主流的新教思想中一样。[^p453-18]

一些天主教、新教思想家，也试图以《圣经》权威，为“最合乎基督教”的自然哲学奠基，但没有那么激进。他们拒绝亚里士多德的解释，采用经文解释。例如，地下泉水的来源，并非亚里士多德所说水汽凝结，而是《传道书》1:7提到的，海水返回其源头。[^p453-19]“最合乎基督教”的策略，还包括强调上帝作为创造者何其伟大，创造了如此丰富、多样的万物；相比之下，理性却无力理解许多自然现象。承认人的无知，以便更好地赞美上帝荣耀，直到十七世纪，都仍是具有宗教倾向的自然神学的特征。[^p453-20]

文艺复兴时期，新哲学大量涌现，而且往往明确反对亚里士多德，却没有影响亚里士多德在学校、大学等传统教育环境中，作为首选权威的地位。[^p453-21]

特伦托大公会议，把托马斯主义对亚里士多德主义与基督教的综合，提升为正统教义。因此，在大多数天主教机构，偏离亚里士多德，就可能招致不敬虔的指控。尤其耶稣会士，明确宣誓效忠亚里士多德。[^p454-22]新教大学，虽然起初尝试寻找替代者，也很快确立亚里士多德为课程骨干。[^p454-23]不过，在十六世纪教育大扩张中，天主教徒与新教徒，为学生编排亚里士多德学说时，都把其自然哲学置于基督徒虔敬的背景之中。一位方济各会士编写的早期教科书，把哲学论述与赞美上帝的诗篇交织在一起。这种形式，没有成为常态，却表明作者对于“原样端出”亚里士多德，感到不安，尤其当入门教科书，面对的是广大、缺乏经验的读者时。[^p454-24]新教教科书，则仿效梅兰希通，通常赞美自然哲学，认为它揭示上帝仁慈的眷顾，能够激发虔敬。[^p454-25]

无论拥护还是反对亚里士多德，文艺复兴自然哲学家，都宣扬研究自然的虔敬性质。自然哲学，可以论证上帝存在、伟大，以及人应当敬拜他也能成为抵御不敬虔与无神论的堡垒；许多同时代人，都担心后两者日益增长。[^p454-26]某些表述，或许只是在修辞上重复长期通行的论据；但在大多数情况下，宗教动机，对于激发文艺复兴反亚里士多德哲学的创新，确实居于中心。[^p454-27]无论如何，虔敬动机与自然神学论证，远比亚里士多德主义，以及基于其他古代权威的文艺复兴“新哲学”，存在得更久。十七世纪机械论哲学战胜这些对手时，也同样以基督徒虔敬，以及赞美上帝的伟大与眷顾，来表述自身。[^p454-28]整个近代早期，各宗派基督徒，都使用自然神学论据，证明研究自然的正当性。声称基督教某个特定派别，例如路德宗<a id="pdf-455"></a><!-- PDF page 455; original page 432 -->或加尔文宗，比其他派别更乐于研究自然，似乎值得怀疑。天主教自然神学，虽然较少为人了解，也同样值得进一步研究。[^p455-29]

## 新教与科学

科学与宗教关系的历史研究，起源于达尔文学说传播的最初几十年。当时，宗教界激烈反对进化论。这场争论，最著名的是冲突论：约翰·威廉·德雷珀，在《科学与宗教冲突史》（1874年）中直白阐述，安德鲁·迪克森·怀特，在《基督教世界科学与神学交战史》（1896年）中稍作缓和。但同一时期，也出现了一些同样经典的、关于科学与宗教合作的历史论断。其中包括皮埃尔·迪昂认为1277年的谴责，为近代拒绝亚里士多德开辟道路；还有日内瓦博物学家阿尔方斯·德·康多尔，率先提出，新教特别有利于科学。[^p455-30]

新教与科学具有特殊关系的观念，流传甚久。马克斯·韦伯把新教与资本主义联系起来，进一步助长了它；罗伯特·默顿，则在《十七世纪英格兰的科学、技术与社会》（1937—1938年）中，作出最详尽阐述。此后几十年，数量惊人的学者，多数专研十七世纪英格兰，争论了默顿论题的不同表述。[^p455-31]这些争论，帮助人们更精确地把握一些历史范畴，例如十七世纪英格兰新教的多样性：一端，是往往敌视研究自然的严格清教徒；另一端，是广教会派或纬度派。他们希望避免宗教争论，这也是皇家学会核心自然哲学家群体的特征。不过，关于新教哪些本质特征，<a id="pdf-456"></a><!-- PDF page 456; original page 433 -->可能有利于科学的长期讨论，如今似乎不再站得住脚。不同论者，把更强的理性主义、重视体力劳动、乐观精神，以及拒绝既有权威、魔鬼及超自然事物等，都归于新教。[^p456-32]一方面，历史学家，如今倾向于原则性拒绝对宗教运动作本质主义概括；而且，欧洲及其他地区的历史研究，地理范围大为扩展，更凸显了从十七世纪英格兰这样的个案，作普遍推论的危险。另一方面，二十世纪八十年代以来，神创论运动，以及它基于宗教、反对达尔文进化论的论证，越来越受到公众注意，尤其在英语世界。这清楚证明，新教与科学，存在发生冲突的可能。最后，正如下节将详述，一些较近的研究，着重于近代早期欧洲天主教环境中的科学，动摇了康多尔及默顿论断最初所据的数量假设，即新教在科学上占优势。[^p456-33]

即使搁置早期“新教与科学”的许多论点，以及它们经常带有的宗派动机，仍可在这一标题下，讨论关于新教环境中，宗教、科学具体互动案例的大量研究。新教在不同背景中，采取不同形式；缺乏统一性与中央宗教权威，是其界定性特征之一。新教，并不包含某种特别有利于科学创新的先天倾向。路德与加尔文通常被认为总体缺乏研究自然的兴趣。[^p456-34]但两派的教育需求，都使自然哲学教学制度化。十六世纪五十年代，在斯特拉斯堡的希罗尼穆斯·赞基，以及七十年代，在日内瓦的朗贝尔·达诺，分别教授自然哲学，出版教科书。他们公开把《圣经》权威置于哲学家之上，却仍强调寻找《圣经》与亚里士多德的一致。[^p456-35]梅兰希通，为路德宗机构建立示范课程时，给予自然哲学重要地位，因为它能揭示上帝在自然<a id="pdf-457"></a><!-- PDF page 457; original page 434 -->世界中的眷顾。[^p457-36]梅兰希通，尤其关心天文学，特别把它看作占星术的辅助。他在维滕贝格任教，无疑有助于当地对哥白尼产生兴趣。[^p457-37]第一批掌握哥白尼体系，并用它编制新天文表的天文学家，便聚集在维滕贝格；他们编成了1551年的《普鲁士星表》。围绕伊拉斯谟·赖因霍尔德形成的哥白尼“维滕贝格解释”，是一种假设性解释：用哥白尼理论进行计算，却否认日心说描述的，是真实物理现象。[^p457-38]

最早坚定支持哥白尼者之一，约翰内斯·开普勒，也属于路德宗。他在梅兰希通建立课程体系的图宾根，接受教育。[^p457-39]开普勒，寻求行星分布、大小与距离背后的数学和谐，其深刻宗教动机，广为人知。他最初在《宇宙的奥秘》（Mysterium cosmographicum，1596年）中，用一系列完美柏拉图多面体，解释行星的排列。不过，他本人严格的经验标准，使他质疑自己使用行星资料的方式；在该书后来的版本中，详细脚注，尤其反映了这一点。最终，他放弃这一方案，转而在《宇宙的和谐》（Harmonices mundi，1619年）中，提出基于音乐和谐的另一方案。书中，也顺带包含了后来称为“开普勒行星运动定律”的数学关系。[^p457-40]开普勒，投入巨大精力，研究第谷·布拉赫积累的观测资料，因为他确信，上帝必定按照优美的数学计划，创造了天体及其运动。作为虔敬、正统的路德宗信徒，开普勒甚至试图，在天界某些三重结构中，发现三位一体的逻辑，却不在意那些似乎与日心说相抵触的具体经文。[^p457-41]

不过，其他路德宗信徒，拒绝哥白尼学说时，经文反对理由，确实发挥作用；第谷·布拉赫本人，就是例子。他以提出一种地心与日心相结合的宇宙体系为荣，认为它保留了哥白尼学说的优点，却避免了其明显缺点，也就是与<a id="pdf-458"></a><!-- PDF page 458; original page 435 -->一切已知物理学原理，以及若干经文的直接解释，相冲突。[^p458-42]新教对哥白尼学说的反对，一直持续到十七世纪末；保守的荷兰加尔文宗人士，援引经文，拒绝哥白尼学说，以及与之联系起来的笛卡尔主义。这些思想立场，往往受到政教内部权力斗争的推动，并导致莱顿大学神学系，在1659年谴责笛卡尔主义。[^p458-43]

对于《约书亚记》10:12等难解段落，新教释经原则，允许广泛的不同解释；与天主教原则不同，它不要求仅因某种解释属于传统，就必须遵守。有些新教徒支持字面解释。保守加尔文宗神学家吉斯贝尔特·武修斯，例如认为暗示圣灵不能、或不愿在《圣经》中说真话，是不恰当的。但许多人则解释，经文适应了希伯来听众的理解能力。除加尔文本人采用适应原则之外，伽利略关于哥白尼学说的论证，也通过1636年出版的《致克里斯蒂娜大公夫人书》拉丁译本，为人所知。加尔文宗人士，还提出其他解释：格劳秀斯沿用犹太释经，认为这一段是诗意夸张；也有人认为太阳停止，是视觉错觉。

鉴于某些天主教徒，在1633年伽利略受谴责以前，以及此后，尽管有禁令，仍支持日心说，宇宙论立场，就不能简单对应于特定宗派归属。近代早期思想家，通常具有深刻宗教信仰，却在每个宗派内部，导向了对哥白尼学说的不同立场。这部分取决于他们更愿因数学秩序、理性简洁的美，赞叹上帝，还是更愿因一种更神秘、复杂，又得到字面及传统读经方式支持的自然秩序，赞叹上帝。

十七世纪英格兰，曾被用作新教与科学具有特殊关系的主要证据，今天仍是丰富的研究领域。广泛的科学活动，从“数学实务者”的实用研究，到皇家学会为阐明机械论哲学各方面而进行的实验，都可以归于一种科学有益于人类的愿景；弗朗西斯·培根（1561—1626年），最著名地阐述了这一愿景。在未完成的《伟大的复兴》（Instauratio magna）中，他设想了一项道德、哲学改革计划，<a id="pdf-459"></a><!-- PDF page 459; original page 436 -->以恢复亚当失去的、对自然的支配。培根区分了伦理上的支配，与自然及技术上的支配：前者在人类堕落后，不再赋予人类；后者却从未被禁止，实际上，是一项尚未完成的神圣命令。他勾画了一种集体科学研究的方法，通过比较大量个别事实或“事例”，得出可靠的自然概括；这些事例，来自观察及有目的的实验。[^p459-44]培根本人，既没有完成任何此类研究，也未能获得原本期待的王室经费，但其方法论宣言，成为此后数代人的强大灵感来源，尤其在英格兰，但并不限于此。培根谨慎地警告，不要混合科学与神学，尽管其乌托邦作品《新大西岛》，以教会等级为模型，描绘科学工作者的组织。他的不同追随者，都赞同道德与哲学改革，紧密相连，却以不同方式理解这种联系。[^p459-45]

一个受培根愿景启发的团体，围绕波兰出生的加尔文宗人士塞缪尔·哈特利布形成，称为“事务联络处”（Office of Address）。它抱有激进的社会、宗教改革愿景，往往具有千禧年色彩；自然哲学方面，则专注于帕拉塞尔苏斯主义、占星术，以及夸美纽斯的泛智学。这个群体，在空位期兴盛，王政复辟后，却被边缘化、趋于离散。1662年，另外两个非正式群体的成员，即牛津的“1645年小组”，以及围绕罗伯特·波义耳的“无形学院”，请求国王批准，成立皇家学会。

皇家学会会员，人数众多，分散各地，却由约二十位活跃伦敦会员组成的核心群体运作。他们着重使自然哲学，免受政治、宗教争论，以及失去王室青睐的风险影响。[^p459-46]他们专门报告“事实事项”，即观察与实验的记述，希望人们对此，不会有分歧。[^p459-47]皇家学会成员，接受了经过调整的笛卡尔机械论哲学，把一切自然现象，解释为惰性物质粒子的运动。忠于培根愿景，他们把实验性的机械论哲学，呈现为良好基督徒虔敬的堡垒。他们揭示神的眷顾，贯穿整个自然，以此对抗被视为日益增长威胁的<a id="pdf-460"></a><!-- PDF page 460; original page 437 -->无神论。他们冷静研究事实，也用来抵御宗教狂热，因为后者，草率“想象”超自然干预等事情，并带来危险社会动荡的风险。[^p460-48]

英格兰实验研究者，详论有机世界精巧的美，例如胡克1665年《显微图谱》中，以显微镜观察所见；也详论行星的数学规律，例如牛顿1687年《原理》所作的杰出论证。“物理神学”（Physico-theology），开始用来描述许多物理学或自然哲学著作；这些作品，把自身表述为论证自然界中，神的眷顾、权能与仁慈。[^p460-49]某些自然神学表述，如此强调以理性理解神的行为，以至启示似乎只用于确认自然宗教已经得出的真理。[^p460-50]另一些人，例如罗伯特·波义耳，则通过坚持人的理性有限，强调上帝伟大。[^p460-51]波义耳1691年临终时，捐资设立系列讲座，以延续自己的计划：针对不信者、无神论者，证明基督教，而不卷入内部教义争论。此后几十年，自然神学，一直是波义耳讲座喜爱的主题。

较近的研究，考察艾萨克·牛顿的全部作品，从著名数学著作，到大量神学、炼金术手稿，强调其深刻宗教动机。[^p460-52]牛顿确立物理定律，是努力揭示上帝在整个自然与历史中的作为。这既包括规则的定律，也包括偶尔的直接干预，例如维持行星运动持续所需的干预，以及历史中的奇迹时刻。但牛顿，把自己的宗教观点，保留为私人意见，有充分理由：这些观点，反对三位一体，是当时官方不能容忍的非正统思想。[^p460-53]

十七世纪英格兰，为实验机械论哲学与自然神学的发展，提供了沃土。王政复辟后的英格兰，可以容纳从高教会派<a id="pdf-461"></a><!-- PDF page 461; original page 438 -->圣公会到清教主义的一系列新教信念，却不包括天主教徒、非国教派及阿里乌派。清教徒塞缪尔·哈特利布、保守圣公会信徒罗伯特·波义耳、隐藏自身阿里乌派观点的艾萨克·牛顿，以及倾向自然宗教的约翰·洛克，都能把宗教信念带入哲学工作，感到自己参与了一个广义的培根式计划：通过研究自然，改革社会。自然神学，之所以成为如此成功的框架，恰恰因为它也容纳了从理性主义到更纯粹宗教性的广泛动机。

十七世纪英格兰，是科学与宗教和谐合作的好例子，却也建立了一些思想结构，后来将给二者关系带来问题。自然神学，为宗教信仰，提出科学基础，假定创造行为，证明了神的权能、智慧与眷顾。当达尔文的自然选择进化观，挑战这一假定时，十九世纪晚期，以及此后的许多人，突然觉得科学与宗教，是不可调和的敌人。两百多年间，英格兰自然神学，广泛而成功的吸引力，掩盖了复杂变化产生的紧张。这些变化，涉及神学与日益独立、专业化的自然科学的地位，也涉及新教内部不同派别之间的关系。在达尔文冲击下，紧张公开爆发，科学与宗教战争的隐喻，遂占据主导。

## 天主教科学

德雷珀与怀特，都是新教徒，乐于把天主教指出为科学、宗教冲突的首要来源；但伽利略事件以前，并没有迹象显示这种冲突。在许多方面，天主教会，以及其中世纪前身，为自然哲学发展，提供了有利环境，却不是像迪昂所论证的，通过1277年谴责来实现。那些早期谴责，原意是阻止亚里士多德进入大学课程；倘若托马斯·阿奎那，未能成功、巧妙地使其基督教化，谴责可能真会达到目的。相反，教会通过采用亚里士多德方法论的许多特点，并在神学教学本身提出自然问题，推动科学发展。由此激发的争论与讨论，包括<a id="pdf-462"></a><!-- PDF page 462; original page 439 -->形式或性质的增强、减弱，以及运动的性质等问题。[^p462-54]此外，教会为教区教士与修会教士，提供教育机会及终生职业，往往使他们有自由，追求科学兴趣。最后，神学系，与文学院、医学院在制度上分开，也常使哲学与医学，免受明确的神学规制。正如前文所述，教会在拉特朗大公会议，确实想让哲学服务于神学，例如论证灵魂不朽。但除了谴责蓬波纳齐，以及1488年谴责、逮捕皮科·德拉·米兰多拉，反宗教改革以前，教会很少干预哲学；这两次事件，也都通过发表辩护著作而解决。

为应对新教威胁，教会在1559年，颁布首部《禁书目录》。早期目录，列入异端作者的全部著作，包括科学作品；后来的版本，则有所缓和。例如，格斯纳、富克斯等新教徒的自然史著作，经过修订，就可以阅读。[^p462-55]科学作品，经常跨越新教—天主教分界，双向出版、传播、阅读。

损害更大的，是特伦托大公会议关于释经的规定，旨在确保天主教会，团结对抗新教：天主教平信徒，不得解释《圣经》；天主教的解释，必须尊重教父与教会圣师的传统解释。这些原则，源于与新教的神学冲突，既不是针对自然哲学问题，也非出于这类动机，却通过谴责伽利略，对天文学与自然哲学，产生了巨大影响。

关于伽利略事件的历史研究，极为庞大。各种解释，从完全归咎于反宗教改革教会，到认为应由伽利略本人及其尖刻性格负责，不一而足。研究考察了教会派系，即耶稣会与道明会之间，以及哲学派系之间，复杂的政治关系。后者包括伽利略与沙伊纳、格拉西，以及围绕卢多维科·德莱·科隆贝的亚里士多德主义“鸽子派”的争论。研究还讨论个人性格的作用：乌尔班八世，觉得自己对伽利略的信任，遭到背叛；罗伯特·贝拉明，对自然哲学有特别兴趣；伽利略，则希望在<a id="pdf-463"></a><!-- PDF page 463; original page 440 -->美第奇宫廷发展事业。[^p463-56]伽利略事件，涉及复杂交织的多种原因，其中许多带有偶然性。但它也源于深刻的思想冲突：谁控制经文解释，以及反宗教改革教会，要求何种科学证据，才肯放弃传统读经方式。在地球运动问题上，这些紧张迟早会爆发；伽利略《两种世界体系的对话》（1632年）的出版时机，促使结果走向冲突。当时，哥白尼学说，尚未得到大批天文学家支持，也缺乏像牛顿物理学那样，能解释它的物理体系；伽利略的《对话》，有助于推动两者形成。但反宗教改革教会，倾向于严格执行特伦托规定的解释原则。[^p463-57]

甚至在特伦托以前，尼古拉·哥白尼，就担心天主教会如何接受日心说；他自己，在波兰弗龙堡担任主教座堂教士。他把著作推迟到去世当年才出版，将它献给教皇保禄二世，原文如此，称其有助于教会的历法改革计划，并收入舍恩贝格主教的支持信。哥白尼并不知情的是，路德宗人士安德烈亚斯·奥西安德，可能应印刷商要求试图通过附加序言，使著作更易被接受。他违背哥白尼本人的实在论主张解释日心假说，并非描述实际世界，只是一种优美的计算工具。结果，或许也得益于这些预防措施，《天体运行论》出版，并未引起天主教、新教双方的教会反应。这是一部艰深的专业著作，能读、愿读的人都很少。两项早期天主教回应，显示反应范围之广：道明会士托洛萨尼，在特伦托以前的一份手稿中，提出批评；而1584年，西班牙奥古斯丁会士迭戈·德·苏尼加，却赞同日心说，并解释了若干难解经文。不过，苏尼加的解释，在1616年遭到谴责。[^p463-58]

伽利略，为容许、甚至支持地球运动，而提出的经文解释论证，始终谨慎地未予出版。但贝拉明，<a id="pdf-464"></a><!-- PDF page 464; original page 441 -->知道1615年以手稿流传的《致克里斯蒂娜大公夫人书》中的论证。伽利略援引奥古斯丁的权威，认为那些似乎表示地球静止的段落，是为了适应希伯来人的理解能力，应根据地球运动的证据，重新解释。[^p464-59]贝拉明则坚持：虽然教父未直接讨论地球运动，传统解释仍有约束力，除非、直到人们对地球运动，提出确证；而他确信，这样的证明不可能。1616年，日心说，被谴责为“在哲学上愚蠢、荒谬，正式构成异端，因为它在许多地方，明显违背圣经的意义”，但并未提及伽利略。[^p464-60]促成这次谴责的，是加尔默罗会神父保罗·安东尼奥·福斯卡里尼，不谨慎地出版了支持哥白尼学说的新释经。

约十五年后，伽利略与乌尔班八世友好交谈，又持有一份证明他不受任何不当行为嫌疑的书面证书，自信已掌握哥白尼学说的确证，并获准把它作为假说，发表讨论。在《对话》中，他的确在最后一页，承认自己对宇宙论问题无知；但在此前数百页，他一直嘲讽亚里士多德主义对地球运动的反对，并试图从潮汐运动，证明日心说。1633年，伽利略被控既违背1616年法令，也违背一项特别命令他停止教授哥白尼学说的、未经签署的禁令；后者在宗教裁判所档案中发现伽利略本人并不知情。他被判“强烈涉嫌异端”，受到软禁。1642年去世前，他在最后几年，写成一部关于运动物理学的论著。

谴责伽利略，对天主教徒能够教授、捍卫何种宇宙论，产生持久影响。按照原文记载，直到1833年，哥白尼终于从《禁书目录》中除名以前，天主教徒不得公开支持日心说。[^p464-61]近代早期天主教徒，对宇宙论问题，首选第谷的地心—日心体系；它在观测上，与哥白尼体系等价：除地球之外，所有行星围绕太阳，太阳则<a id="pdf-465"></a><!-- PDF page 465; original page 442 -->围绕静止地球。更常见的是，1687年牛顿使日心说得到确立之后，天主教徒选择转向其他科学工作。十七世纪耶稣会，以培养优秀天文学家闻名；他们致力于观测，完全避开宇宙论。[^p465-62]克里斯托弗·克拉维乌斯，努力提升混合数学学科的地位以后，耶稣会长期特别活跃于数学科学，并继续处在许多数学学科教学、研究的前列。[^p465-63]许多天主教教堂建筑，被用作天文测量仪器。[^p465-64]伽利略本人，虽然公开受辱，仍在意大利培养了一派追随者；他们研究运动物理学，而非宇宙论。[^p465-65]弗朗切斯科·雷迪（1626—1698年）、马尔切洛·马尔皮基（1628—1694年），也继续开展解剖、医学研究。这一传统，对威廉·哈维关于血液循环的研究，起了重要作用；其著作为《心血运动论》（De motu cordis，1628年）。[^p465-66]

在意大利以外，教会，也扶持创新自然哲学家的事业，例如至小兄弟会士马兰·梅森，以及奥拉托利会士伽桑狄。布莱兹·帕斯卡，先从事物理研究，例如大气压力研究，后来才转向更严格的宗教立场及詹森主义，后者则始终受到教会敌视。勒内·笛卡尔因为机械论哲学，可能带来不敬虔后果，而同时遭新教与天主教机构谴责，但他自视为虔诚天主教徒。实际上，人们把他发展新哲学的动机，归于一次与反宗教改革枢机贝吕勒的谈话。[^p465-67]笛卡尔把著作寄给自己求学过的拉弗莱什耶稣会学校，显然希望他们把其思想，纳入课程。他谨慎地维持良好天主教徒身份；解释自己为何不出版宇宙体系著作《世界》时，明确提及伽利略受到的谴责。不过，笛卡尔主义传播，对普及哥白尼学说，起了重大作用。经过最初抵抗、谴责，甚至巴黎大学，也在十七世纪九十年代，把笛卡尔主义纳入课程。近代早期天主教徒，<a id="pdf-466"></a><!-- PDF page 466; original page 443 -->从事的多样科学研究、取得的多样成果，并不具有某种可辨认的天主教性质；他们甚至未能一致同意，按教会法令，拒绝哥白尼学说。

## 尾声

遵循科学与宗教关系史研究的主要方向，这篇简短概述，主要讨论宗教对科学的影响，尤其采用科学史家的研究。要从塑造近代早期宗教变化的众多力量中，分辨科学的作用，需要另一种专业知识。不过，对科学解释的新信心，无疑是推动十七世纪晚期，宗教理性化及自然宗教发展的重要因素。
