# 第六章　欧洲世界的新教教士群体

**安德鲁·R.霍姆斯（Andrew R. Holmes）**

宗教改革从根本上改变了教士的宗教作用和社会地位。新教改革者坚持信徒皆祭司，尽管这一原则很少真正实现，并拒绝把按立视为圣礼。表面上，这似乎降低教士地位，但凭借按立的象征意义、大学教育，以及通过婚姻与不断兴起的中产阶层建立联系，新教教士仍然是特权群体。他们作为家庭的虔诚家长，其家庭安排有助于界定社群中宗教与社会上受人尊重的生活标准。在苏黎世，他们以适当行为和虔敬为范例，反映威权国家的要求；托比·巴纳德则指出，十八世纪爱尔兰的圣公会牧师家庭，应成为“微型的虔敬共同体”。改革者所设想的、受过教育的堂区教士理想，最终实现，但过程漫长复杂。如近代早期欧洲其他文化变化一样，传统影响、理想与现实不断互动，往往比革命性改变更重要。

1660至1780年，前一世纪的宗派仇怨渐渐平息，启蒙运动也给欧洲宗教生活带来温和影响。欧洲教会开始巩固社会地位，在新教国家，人们广泛接受上述对教士地位与职能的一般理解。然而，显然必须以复数看待1660至1780年的欧洲新教教士群体。经济、地理和文化差异，塑造某个堂区或教会所召请的牧师类型，以及他可能如何开展牧灵工作。不同教会组织形式，即教会论，也影响教士与会众的关系，以及他认为自己能做或不能做什么。国家性质及内部权力关系，则决定世俗当局与教士在任命、晋升、<a id="pdf-125"></a><!-- PDF page 125; original page 110 -->教育和收入等问题上的具体联系。破旧中世纪制度的残余，又给国教会留下财产权及堂区收入归属等长期问题，使事情更复杂。在瑞典、英格兰、尼德兰及许多德意志邦国，堂区结构构成政治社会组织基础，也是使民众基督教化的主要手段，由此提供牧师履职的正式环境。自愿性及受迫害新教教会的地位，则更复杂，其教士领袖的职能与地位相当不确定。在法国和匈牙利等新教徒遭坚决迫害的地区，教士权威严重削弱，教会内部权力越来越委托平信徒承担。

神学发展同样塑造新教教士，既影响其对召命的理解，也影响讲道内容与风格。本时期教士中较趋新的部分，从冗长教义讲道，转向较轻浅、强调道德与共同利益的训讲。另一方面，传统派和福音派则分别专注宗派正统，或宣讲唯独通过基督而获得个人救恩，以抵消道德讲道的影响。后者是敬虔派和福音派新教复兴的突出特点。这场复兴在哈布斯堡迫害面前兴起，又受到人口流动相关社会变化、城市增长及工业革命初期问题塑造。就新教教会的灵性生活而言，复兴使信徒更热切、更积极投入基督教信仰，深刻影响许多牧师理解并实践召命的方式。路德宗敬虔派领袖菲利普·雅各布·施本尔担心，教牧职务只被视为国家的延伸，与平信徒日常生活无关。他本人是忠诚的路德宗牧师，希望提醒教士承担牧灵责任，并通过小型团契实现信徒皆祭司，从而改革教会。宗教复兴最初虽是东欧与中欧受迫害新教少数派自我保存的手段，却在西部成为不可缺少的牧灵策略。社会经济变化挑战教会如何服务周边人口时，传福音与牧灵关怀，便比维持宗派结构更重要。敬虔主义和福音派运动，既增强受其影响教士的神圣召命感，也通过提高平信徒自信，<a id="pdf-126"></a><!-- PDF page 126; original page 111 -->以及产生卫理宗和摩拉维亚弟兄会等新宗派，挑战既有教士地位；这些新宗派对教牧职务有独特且多变的理解。因此，1660至1780年间，出现了对国教新教教士宗教与社会地位的重要挑战。

在这一广阔背景下，本章考察1660至1780年欧洲新教教士的结构与经历，以及其在教会与社会中的地位如何随时间发展。以下五节讨论教士生活的关键方面：社会出身、教育、任命方式及后续职业轨迹、收入水平，以及在国家和地方社群中的地位。贯穿全章的问题，是能否把这一时期新教教士称为专业职业群体。我们将清楚看到，近代早期新教教士处境暧昧：一方面，是对召命及其在堂区共同生活中地位的传统理解；另一方面，是逐渐把自身看成独立职业群体成员的意识。

## 社会出身

各国家与领地在地理文化上差异广泛，几乎无法为近代早期新教教士编制统一的群体人物概况。历史学家根据现有证据得出的结论又相互冲突，使问题更复杂。然而，教士招募确实反映其来源社会的社会文化特征，仍可指出一些一般特点。新教教士主要来自中等或中下阶层，即较富裕农民和城市中产阶层，贵族或贫苦农民很少。奈杰尔·阿斯顿指出，人们决定成为教士，原因多样：个人宗教信念、次子希望取得地位与体面收入、延续家庭传统的愿望，以及社会晋升前景。随着时间发展，教士之子在新教教士中的比例增加，形成内部自我补充过程。十六与十八世纪，教士之子都是符腾堡牧师的最大来源，分别占百分之六十三和百分之四十四。十七世纪晚期至十八世纪初，德意志各领地超过三分之一的路德宗教士，<a id="pdf-127"></a><!-- PDF page 127; original page 112 -->是牧师之子；瑞典1680至1740年的比例，为百分之四十至四十五。十八世纪伦敦教区下级教士的社会出身，也符合这一模式：教士家庭占百分之三十五点四，专业职业家庭百分之三十点六，下层民众百分之十九点四，土地乡绅百分之十二点四，小贵族百分之一点二，教师百分之一。更广泛地看，从十八世纪二十年代起，大学教育成本增长与内部自我补充模式，使英格兰教会新招募者的社会地位开始上升。虽然自我补充重要，研究德意志城市的学者却指出，教士只是广泛受教育城市中产阶层的一部分，与接受法律训练、担任国家职务者相联系。通婚进一步巩固其在这一社会群体中的地位，提供现成的社会与经济上升结构。

认为城市中产阶层垄断新教教士来源，会造成误导。尼古拉斯·霍普指出，1700年以后，德意志各邦与斯堪的纳维亚多数路德宗教士，来自“教士家庭、较富裕农民、手工业者，以及少数公务员家庭”。上、下级教士都是“极普通的社会出身”。这有助于解释晋升与养老安排，例如，新任牧师娶前任的寡妇或女儿，凭借持续占有牧师住宅和教产田，保障自身经济前途。勃兰登堡—普鲁士路德宗国教会的教士，百分之九十八为“乡村平民出身”，其余百分之二来自较低层乡绅。更值得注意的是，这一地区近一半教士的社会背景，没有记录，表明其父亲可能是工匠或农民。农业持续在近代早期经济中居于核心，也反映于其他地区的招募模式。爱尔兰圣公会人口属于少数，因此国教会紧紧依靠新教国家和地方土地社会。平信徒占有什一税，以及婚姻模式，强化这一联系；例如唐郡一百一十八位有圣俸教职的教士中，六十八人出自土地阶层，或与之联姻。在长老派主导的东北部，十八世纪服务阿尔斯特大会的六百一十九位牧师中，百分之七十一是农民之子，百分之二十是教士之子，百分之四是商人之子，百分之一来自其他背景，百分之四来源不详。这一概述说明，教士并非来自社会最高或最低阶层，而是来自广义的<a id="pdf-128"></a><!-- PDF page 128; original page 113 -->中间阶层。不过，教士群体的社会面貌，很大程度取决于其来源地的经济文化条件。

## 教育

对欧洲新教教会而言，受教育的教牧群体是不可缺少的要求。教士不只施行仪式，也要教导上帝之言；要教得好，就必须受教育。到十七世纪初，改革者已取得重大进展。1600年，梅克伦堡只有四分之一牧师未受学术训练；到十七世纪四十年代，英格兰多数地区四分之三的教士已大学毕业。加尔文宗根基更深的地区，数字更高：1619年，普法尔茨百分之九十四的牧师受过正式神学教育；到1630年，尼德兰只有百分之一没有适当资格。不过，内乱可能使理想倒退，十七世纪四五十年代英格兰尤其如此。坎特伯雷教区1637年百分之八十七教士大学毕业，到1662年却降至百分之六十六。此后，英格兰教会教士教育程度提高，多数英格兰和威尔士教区，在按立以前要求大学教育证明。这不意味着所有受按立者都必须取得学位；偏远地区，有学位的教牧可能很少，例如威尔士圣戴维兹教区，1750至1800年驻地教士仅百分之五点九有学位。非国教新教宗派维持受教育教牧的理想，可能更热切，尽管某些情况下效果较差。最成功的例子之一，是1690年成立的阿尔斯特大会。仿效苏格兰长老派，大会从十七世纪最后十年起，要求候选人大学毕业；1702年又决定，除非毕业后再读神学四年，否则不得进入考核。

国教会教士通常在本国大学求学，并不令人意外。中欧二十九所领邦大学中，十五所为路德宗；斯堪的纳维亚与波罗的海地区，也有哥本哈根、乌普萨拉和多尔帕特等类似学府。神学生是学生中最大群体，教会持续显著影响未来教士的生活。德意志西南部蒂宾根大学的神学生，是任何其他学院学生的两倍；其中不少于三分之一，<a id="pdf-129"></a><!-- PDF page 129; original page 114 -->因候选人过多，必须在教会以外谋职。十七世纪五十年代，瑞典大学训练取代教区中等学校教育以后，地方教区仍监督大学教育。英格兰和爱尔兰国教会教士，分别在牛津、剑桥，以及都柏林三一学院受教育。就学期间，未来圣公会教士得以与乡绅交往，建立后来谋求堂区时不可缺少的联系。

虽然学生地理流动性自十七世纪初有所下降，许多未来教士仍在出生国以外受教育。W.R.沃德指出，斯洛伐克人去耶拿，德意志人去英格兰与尼德兰，瑞士人去索米尔、海德堡、赫尔博恩、莱顿和弗拉讷克，匈牙利路德宗去维滕贝格，改革宗同胞则去尼德兰、瑞士和牛津。被领邦大学排除，以及遭到积极骚扰，使获容忍的不从国教者和受迫害新教徒，必须另觅教育机会。为维持受教育教牧的理想，英格兰旧不从国教派建立自己的学院。随着时间推移，这些机构推动教义保守性淡化，十八世纪三十年代起，一些福音派学院又成立，以抵抗这一趋势。虽然对非国教力量发展重要，各学院规模和教育水准差异极大。其他非国教或受迫害群体，则不得不在外国训练。阿尔斯特长老派因被都柏林三一学院排除，必须前往苏格兰，尤其格拉斯哥，接受大学教育。在哈布斯堡领地，出国更加必要，尽管也有建立国际联系的好处。匈牙利改革宗尤其很早建立这些联系，并在整个时期保持。人们设立专门助学金资助匈牙利学生；沙罗什保陶克、瑙吉埃涅德和德布勒森的学院，也得到外国捐助。法国未来新教牧师同样因迫害而必须海外求学；在日内瓦贝内迪克特·皮克泰秘密帮助下，他们在洛桑建立神学院，于1727至1809年运作。

教士教育与训练，并不因大学就读结束而终止；教会当局继续监督，直至按立。等级制教会对候选人的监督，不如长老制严格。英格兰与爱尔兰教会的按立考试通常<a id="pdf-130"></a><!-- PDF page 130; original page 115 -->要求不高；某些德意志邦国，一旦荐举权人把候选人任命到圣俸教职，宗教事务委员会考试便只是形式，尽管不必然表示他无法胜任。在长老制教会，区会和称为“内部评议”（privy censures）的牧师会议，更能确保标准维持，并培养群体认同。1660至1690年，斯图亚特君主在苏格兰强加主教制，却未完全拆散长老制。1690年长老制全面恢复以后，苏格兰总会1698年以法案，确立区会对未来教士学生的考试，即“考核”（trials）。不出所料，阿尔斯特也采用苏格兰模式；尽管1660至1690年受到圣公会当局骚扰，长老派仍维持区会细致监督。不过，为躲避国家注意，按立时间与地点不向会众公布。1672年，总委员会拟定详尽的考核与按立规则。考核可能持续七个月，包括：面向民众的讲道；称为“共同题目”的指定练习，主题涉及新教信条、长老派原则、论战和牧灵问题；辩论；解释《圣经》中的矛盾；以及外语、历史和神学考试。下一世纪，这套制度略作修改，却大体不变。1770年，阿尔斯特大会通过五项有关教士许可和训练的规则，确保候选人在大学至少就读四年。候选人必须修自然哲学与道德哲学课程，并由区会考核科学、希伯来文、希腊文、拉丁文、逻辑、形而上学、自然与道德哲学、神学和教会史。这些考试分三次区会会议进行；若候选人已在大学读满四年，则只需一次。

所选科目显示，欧洲新教教士在多大程度上受到时代价值和优先事项塑造。教士应受的教育，既反映启蒙关切，也反映古典教育的吸引力。这些规则也暗示，教士教育与预备的理论和实践，有时差距极大。不论出于何种原因，到十八世纪初，苏格兰教会当局已很少坚持必须上神学课。1711年总会法案进一步使事情复杂，规定教士应学习<a id="pdf-131"></a><!-- PDF page 131; original page 116 -->毕业后再读神学六年。不过，这不意味着在大学全日制就读，而是在区会监督下私人研习；其间，见习者在堂区学校任教，取得收入。学生必须这样做，凸显大学教育的经济负担。家境普通者根本无力长期在大学读书。霍普表明，路德宗德意志有明显差距：有才能、关系良好的精英，接受五至十年教育；贫穷按立候选人，却至多接受两年神学教育，课程本身还取决于讲师意愿。

除了苏格兰和爱尔兰长老派教会，多数欧洲新教教会，并不坚持把经过证明的神学能力，作为新教士必要资格。如前所述，英格兰教会只要求文科大学教育证明。直到十七世纪相当长时间以后，拥有神学学位的路德宗牧师仍很少。此外，资格类型有明确等级：城市牧师或蒂宾根毕业生获硕士，教区监督或宫廷讲道师获博士。即使提供神学教育，也反映教会当局的价值，以及特伦托会议后形成、往往已经过时的宗派政治。不过，由此产生的所谓路德宗经院神学，在十七世纪受到改革宗神学，以及更注重灵性与虔敬的新取向影响而削弱，为敬虔派牧灵神学获胜奠基。这些发展，使尼古拉斯·霍普正确提醒，不应夸大神学的“强制力量”。十七世纪末、十八世纪初，多数受按立者偏好“惯常与牧灵”教义，而非论争教义。除神学教育不足，针对堂区现实生活的实际训练，按阿斯顿的话说，“不是极少，就是根本没有”。由此呈现的，是通常缺乏处理神学问题的装备，又在几乎没有正式实际或牧灵训练的情况下，被投入堂区事奉的教士。

这一模式也有例外，教会当局曾试图改善未来教士的监督、教育与实际训练，可以列举若干例子。第一，斯堪的纳维亚有培训路德宗教士牧灵神学的传统；考虑民众对国教会的依恋，这似乎取得<a id="pdf-132"></a><!-- PDF page 132; original page 117 -->良好成效。第二，爱德华·边沁于1763至1776年任牛津神学教授，每年为圣公会按立候选人讲课，提供《圣经》概论和希腊文基础。使教士教育更切合实际的最重要尝试，则伴随敬虔主义与福音派兴起。敬虔派警惕旧式路德宗经院神学，要求回归《新约》教会的简朴。他们认为，教士训练不应集中于枯燥神学或讲道学，而应关注《圣经》、祈祷、讲道、探访，以及组织祈祷会。这些关切反映于1694年成立的哈勒大学课程。直到1727年，每年八百至一千两百名学生在哈勒接受教育，接触敬虔派精神与实践。英国福音派也开创教士教育新方式。最显著的机构之一，是1768年在威尔士建立的特雷韦卡学院，为亨廷登伯爵夫人联会培养巡回讲道者。它没有直接先例，但保留新教普遍信念：受教育教牧更受社会尊重，也更能推荐福音。其新意在于，目标是预备人从事教牧，而非训练智力。古典学问和教义并未被忽视，但讲师集中于个人宗教生活与护教学。从1768年至1791年结束，学院教育了二百一十二名学生，绝大多数进入教牧职务。虽然没有规定学制，许多人只短暂就读，特雷韦卡仍显示福音派带来的气氛变化，并为1780至1830年英格兰组织更健全、管理更规范的福音派学院提供范例。受教育教牧仍不可少，但现代社会兴起带来的挑战，要求用新方法预备人去服务它。

## 任命与职业轨迹

牧师获任会众的方式，反映宗派教会论及政教关系性质。符腾堡教会当局高度自主，直接任命牧师填补空缺。更具绝对主义的国家，中央政府则极力控制所有教职荐举权。1688年瑞典《教会法》把荐举权从贵族转给王权。到1693年，芬兰一百九十九个堂区中，不少于<a id="pdf-133"></a><!-- PDF page 133; original page 118 -->一百七十八个，荐举权掌握于君主之手。类似地，普鲁士国王腓特烈1701年的王室宣言规定，平信徒荐举权人所作的一切牧师任命，必须获国王宗教事务委员会确认。其他国教会中，十六世纪宗教安排却造成更复杂局面，使堂区任命权从教会转出。1830年英格兰教会的荐举权分布，反映此前一个世纪的格局：平信徒百分之四十八，座堂及堂区教士百分之二十四，主教百分之十二，王权百分之九，其余百分之七分属其他群体。不过，全国数字掩盖地区差异。坎特伯雷教区二百七十九个堂区，百分之六十荐举权在教会手中，其中一百零五个，仅由总主教掌握。

平信徒荐举权产生多种问题，可能损害堂区牧师的牧灵成效和教会独立。梅克伦堡荐举权人故意选择没有学位的牧师，确保自己控制堂区。尼德兰改革宗地位较弱，使城市执政集团与教会，在牧师任命和讲道内容上发生冲突。[^p133-1] 苏格兰同样复杂而充满争执，会众召请理想与地主、王室荐举现实相冲突。自宗教改革以来，教会领袖就主张会众有权召请自己的牧师；1690年长老制确立时，也采用某种会众召请形式。尽管1707年合并条款保证，议会不干预苏格兰宗教安排，议会仍于1711年通过《苏格兰荐举权法》，把空缺堂区的提名权，交给合法荐举权人，多数是地方地主。重新强加荐举权，煽起会众纷争；总会偶尔任命“巡回委员会”，使之加剧。这些特设牧师团体，负责把地主违背地方会众与区会意愿所提名、不受欢迎的人选，强行安置到堂区。问题还在于，荐举权争论各方，对关键事项并无一致看法；反对者尤其无法同意，哪些群体有资格召请牧师。争论也有强烈社会政治层面，因为控制荐举权的是包括王室在内的大地主，损害了组成苏格兰堂区委员会对应机构——土地所有者委员会——多数的中小<a id="pdf-134"></a><!-- PDF page 134; original page 119 -->地主利益。

会众召请制度在非国教宗派中，通常运作更顺，但即使如此，究竟谁有权选择牧师，也存在重要分歧。英格兰长老派做法多样，随会众不同，“民众”可能指受托管理人、经常捐款者，或大多数听众；有时现任牧师直接指定继任者。与公理宗和浸礼宗相比，英格兰长老派对教士任命有更崇高的理解。前两者把填补空缺，看作牧师个人与会众之间的交易；长老派则强调区会在按立中的重要性，仪式有时延续两天。类似地，十七世纪晚期，阿尔斯特长老派通过区会向牧师发出召请，却常有问题：牧师不足，区会决定批准哪一召请时，必须裁定几个会众各自的需要。十八世纪，召请程序趋严，区会进一步巩固过程控制；阿尔斯特大会还引入某种社会分层，规定牧师只有同时得到三分之二成员，以及承担其三分之二津贴的捐款者支持，才能获任。虽然长老派和独立教会理论上比主教派更平等，“民众”究竟包括哪些人，仍由时代的等级观念决定。

牧师任命方式，显然影响职业轨迹和晋升机会。即使长老派与公理宗，也形成明确报酬等级；某些会众，尤其城市会众，成为候选人竞逐对象。十七世纪欧洲各主教制教会，出现可辨识的教士职业结构。未来教士常从教师起步，可能逐渐升至主教，再升至捐产更丰富的教区，乃至首席主教。英格兰教会主教收入排名，以坎特伯雷为首，年入七千英镑，其后是林肯等教区，一千五百英镑，直至布里斯托尔等贫穷教区，年入四百五十英镑。虽然十八世纪英格兰主教团日趋贵族化，这并<a id="pdf-135"></a><!-- PDF page 135; original page 120 -->不意味着，获任主教者缺乏必要的牧灵和行政才能。坎特伯雷总主教通常智力出众，在清楚的职业结构中形成良好行政能力，从堂区事奉，到座堂领俸教士，再到主教职位。爱尔兰教会也如此，既有清楚的教区等级，也有明确晋升途径；英格兰获任者通常先任总督随行牧师，爱尔兰人则通常先任座堂主任牧师。平均而言，一位爱尔兰主教先后服务两个教区，各约十年，调动最频繁发生于初次任命阶段。相较法国主教任命，英格兰和爱尔兰体制中的晋升，更渐进，也更依据明显能力，而非贵族出身；因此英格兰主教往往比同时代法国主教年长。[^p135-2] 虽然明确职业阶梯显示一定专业化，初次任命与晋升，除候选人能力，还取决于庇护网络、推荐和家族关系。因此，任命是影响力与已证明能力的混合产物。

虽然等级结构提供清楚晋升阶梯，助理牧师职位也可能如英格兰一样成为第一步，多数教士的生活仍很艰难。缺乏家族影响和庇护者支持的毕业生，往往被安置到偏僻、捐产贫乏的乡村圣俸教职，可能陷入贫困、隔绝与孤独。许多人成为助理牧师，由在任圣俸持有者支付报酬，替其履行堂区职责；他们经常必须靠极微薄收入，既维生又保有某种体面。彼得·弗吉恩（Peter Virgin）认为，乔治王朝晚期英格兰不少于五分之一助理牧师，一生都会留在此职。德意志各邦与斯堪的纳维亚许多路德宗教士，也面临同样孤独的生活，尤其东勃兰登堡，教职收入低、语言问题严重；波罗的海地区教士，又缺乏足以舒适生活的农业技能。爱尔兰圣公会教士被压倒性多数的天主教人口包围，通过通信、阅读及少量旅行减轻孤独；但陪伴来自私人友谊，而非正式安排。教会确实让有能力者有机会升到令人眩目的主教高位，或富裕城市会众；然而，多数牧师最多只能希望取得足够生计，许多人处于孤立而令人气馁的境地。

## 收入

教士收入主要来自两类：依法征收，或自愿捐助。国教会采用前者，但像任命一样，政教关系的确切形式，决定付款方法。日内瓦改革宗牧师由尊敬的牧师团直接任命，领取每年三十镑固定公共薪俸。符腾堡路德宗牧师，也像尼德兰国教会牧师一样，直接由国家支付固定工资。但在政教关系更复杂的国家，教士必须应付复杂而令人沮丧的什一税制度。什一税理论上只是堂区年度产值的十分之一，但分成不同种类、以不同方式征收支付后，就更复杂。本时期，现金支付逐渐成为常态，但较乡村地区仍保留作物、劳务或其他实物支付。普鲁士、苏格兰与英格兰的什一税，又常转让给平信徒所有者，使事情更复杂。苏格兰各堂区由土地所有者委员会监督，包括主要地主与堂区长老会成员，负责收取当地称作teind的什一税，支付牧师津贴的大部分，并维护会堂、牧师住宅、学校和教产田。什一税以实物或现金支付，传统上在收获时征收。堂区什一税持有者通常是大地主，依法必须把部分税收交给委员会，由后者支付牧师。但什一税是可继承财产，许多持有者抵制足额支付牧师应得份额，因而牧师处境脆弱。

苏格兰例子显示，什一税制度复杂，宗教与世俗优先事项也相冲突。税收价值取决于诸多因素：气候、土壤、人口密度、法律框架、堂区居民是否愿意缴纳、中世纪捐产遗产，以及更广泛政治环境。例如，在东、西普鲁士、梅克伦堡与波美拉尼亚各地，平信徒什一税持有者的权势，使地方路德宗教士贫困，又无望纠正。普鲁士牧师的困境，迫使他们实际上成为庇护者的雇员，容易与堂区信徒疏离。什一税缴纳额陡降，教士津贴<a id="pdf-137"></a><!-- PDF page 137; original page 122 -->在瑞典和芬兰则因大北方战争，以及1700至1721年七次严重歉收，价值大幅下降。这些因素使各地教士收入极不相同，迫使教士依靠其他来源。爱尔兰佃农生活艰难，什一税难收，教士便任命什一税代理人，授权收取堂区规费；代理人可保留超过与教士约定金额的全部款项，作为报酬。

欧洲多数新教教士，并非奢侈豪华的代表。即使符腾堡路德宗教士，在国家内部比欧洲其他新教教士更舒适，仍有百分之三十收入低于公认维生水平。许多英格兰国教圣俸持有者必须任教、务农或从事其他工作；爱尔兰教士则通过葬礼讲道、施行人生礼仪收取小额费用、与有钱人联姻，有时甚至主持非法婚姻，补充收入。收入不足和缺乏牧师住宅，促成备受讨论、可能引起不满的兼任与不驻地问题。英格兰1705至1776年，兼有多个堂区的教士，从百分之十六增至百分之三十六；贫困是一个原因，也可能与按立人数减少有关。但不驻地或兼任，不必然造成牧灵疏忽，因为许多教士只是住在邻近堂区，或雇用助理牧师。爱尔兰某些教区极穷，使兼任更有理由。例如1712年，费恩斯教区九十九个堂区，只有三十二个为教士提供任何收入。[^p137-3] 法定报酬方式不平等，有时形成双层制度。传统上吃亏的是助理牧师，如前文英格兰例子所示，他们可能一生贫穷而脆弱。不过，也有改善收入的措施。1704年成立、旨在提高小圣俸收入的“安妮女王恩赐基金”，虽有缺点，仍在1713至1844年支付三百四十万一千六百英镑。基金发挥作用，更重要的是地价上涨，以及圈地法案引起的什一税折算收益，使十八世纪英格兰教士平均收入显著增长。据估算，1736年约一万零五百个圣俸教职中，五千六百三十八个年值不足五十英镑，其中百分之二十不足十英镑；到十九世纪初，全部教士只有三分之一，年入低于一百五十英镑。增长最大的是<a id="pdf-138"></a><!-- PDF page 138; original page 123 -->下级教士。例如，永久助理牧师职，即拥有捐产、让助理牧师具有一定任期保障的职位，同期收入增长惊人的百分之六百八十六。

相比国教会，欧洲非国教教会总体较穷，津贴筹集与支付更不稳定，收入差距更大。受迫害法国新教牧师尤其如此，常常只能希望会众给一张床过夜。阿尔斯特等较稳定地区，十七世纪晚期许多长老派牧师也面临严重欠薪，但强大教会法庭制度，至少能强迫一部分拒付者缴纳。1674年，安特里姆会议决定，最低年津贴三十镑，并要求会众提供住宅、燃料、土地和谷物。津贴常以实物支付，除现金外，还包括泥炭、土地、燕麦、劳务和其他物品。欠薪虽仍普遍，到十七世纪九十年代，规则已对收入产生良好影响，平均津贴升至三十三镑九先令六便士。最低津贴1753年增至四十镑，1770年增至五十镑。但差距仍在：到十八世纪九十年代，只有两个会众的牧师收入超过一百五十镑，一百三十一位牧师年入不到六十镑。如同国教会，总体经济、政治与社会发展，决定约定津贴能否实付。例如因歉收，1717年爱尔兰鲁特区会只有一名牧师领到津贴。英格兰旧不从国教派的津贴，也差异极大。1690年调查显示，牧师实际年入从四十先令到一百镑不等，平均二十至四十镑。这种收入在歉收或经济困难时，几乎没有余裕，许多牧师必须另觅收入。十八世纪之交，各种基金成立，以减轻非国教牧师经济压力，但主要责任仍属地方会众，对许多人负担沉重。也许颇具讽刺意味的是，爱尔兰长老派和英格兰旧不从国教者，都从王室获得称作regium donum，即“王室恩赐”的年度补助，部分为确保其政治安分。这在爱尔兰具有象征意义，十八世纪多次增加，但每名牧师实际分得<a id="pdf-139"></a><!-- PDF page 139; original page 124 -->始终不多：原书记1689年六百镑分给八十个会众，每个十五镑；会众增多以后，1702年每位牧师只分八镑，而足够的年津贴为四十镑。此处金额与平均数的算术疑点，见本章译校说明。1800年通过大不列颠与爱尔兰《合并法》后，政府大幅增加捐助，远超以往零星加款，部分是为了在1798年叛乱以后，确保长老派忠诚。

如果法国胡格诺派、英格兰非国教派和爱尔兰长老派，经常难以供养牧师，新成立非国教群体的问题就更严峻。卫理宗巡回讲道者依靠免费食宿，以及班会、季度会议所组织的每周一便士捐款。反映卫斯理本人信念，这一制度以自愿原则和联会体制相互作用为基础；集资是传福音的手段，而非目的本身。像其他根基较稳的教士一样，卫理宗讲道者也试图靠其他途径补充收入，包括出售自制药品，尽管1770年通过禁令，不许额外收入。地方讲道者经济如此困难，许多人未成为巡回者；1741至1765年接受的两百名讲道者，实际有一半未能成为终身教牧。十八世纪晚期，随着期望提高，资金匮乏变得尖锐，制度越来越显露脆弱。毕竟，正如戴维·亨普顿所说，整个制度依靠“节俭、善意与情感纽带”，而财务问题很容易使这些基础紧张。

## 在国家与地方社群中的地位

依宗派国家内部的具体权力平衡，教士经常属于国家机器，其教育成就及与世俗精英的家族联系，又强化这一地位。学者认为，中欧路德宗职务自十七世纪出现“官僚化”，形成一种“实际上只是另一名中层官员”的教士。[^p139-4] 瑞典卡尔十一世以1688年《教会法》剥夺教士独立，使其在教会纪律方面，按迈克尔·罗伯茨判断，沦为“国家在公共政策问题上的纯粹代理人”，为十八世纪平信徒控制教会铺路。无疑，教士代表国家承担各种行政司法职能，有时几乎无法与世俗权威区别。不过，<a id="pdf-140"></a><!-- PDF page 140; original page 125 -->也存在高估国教教士政治化的危险。教士并不只是国家仆役，许多情况下甚至并不部分如此。他们有自己的召命与责任意识，常与国家政策目标相冲突。多数人更关心治理堂区、收取津贴，以及照顾信徒灵魂的实际事务。本时期国家或许不断扩展影响和结构，却还没强大到能够系统干预复杂的传统堂区生活与日常教牧工作。

自愿或受迫害新教教会的教士地位，又与依法确立的教士不同。由于地理集中，教会结构稳固，阿尔斯特长老派牧师在地方社群中地位突出。政治上更重要的是，不列颠与爱尔兰非国教牧师，因被国家权力结构排除，经常站在共和政治前列。估计六十三名阿尔斯特长老派牧师，卷入1798年旨在推翻英国统治、建立独立爱尔兰共和国的叛乱。匈牙利与法国处境较不幸的教士，政治活动空间受到严重限制，平信徒因而接替其社群政治领袖角色。

教士的社会出身、教育、任命方式、职业轨迹和收入，如何影响其地方地位？总体而言，其地位暧昧。一方面，地方教士凭教育、按立和收入，与众不同，代表官方宗教；若属国教会，也代表国家。符腾堡和瑞典缺乏庞大贵族，使教士能与乡绅平等交往，在地方社会占据显著位置。英格兰教士社会经济状况改善，导致十八世纪所谓“乡绅化”，到乔治王朝晚期，他们有意识地融入“有产等级体系”。更一般地说，教士知道自己属于受教育中产阶层，高于乡村堂区的狭隘与无知。这种高地位及日益认同社会精英，可能使他们疏远本应照顾灵魂的平信徒；正是这种忧虑，使施本尔寻求让路德宗牧职更回应堂区信徒灵性与实际需要的方法。不过，脱离现实的危险，又因以下事实而缓和：

多数新教教士深入乡村生活，服务当地人，分享其喜乐悲伤，耕作同一土地，面对同一天气。尼古拉斯·霍普认为，德意志与斯堪的纳维亚路德宗牧师的地位，来自属于地方教士家族，而非原先社会出身。他们是地方宗教改革传统的守护者，家族持续占有牧师农场，又强化这一传统。中欧、英格兰及爱尔兰东北等许多地区，倾向任命当地人填补空缺，更加强地方性。与地方社群密切联系无疑有益，但传统、礼俗、荐举权人干涉，以及近代以前堂区生活的封闭，也可能妨碍牧师改革非正式实践与信仰。

一般而言，教士与平信徒关系相互依存。平信徒提供薪资、在公共礼拜中专心聆听，作为回报，期待牧师主持每周礼拜、妥善讲道、探访病人，并留意堂区生活重要变化。牧师的无知或算计、平信徒的狭隘，或更广泛社会变化，打破传统做事方式时，教士与平信徒之间的平衡便受扰乱。例如，相较法国体系性的反教权主义，不列颠反教权事例，通常来自地方冲突，而非对体制的批评。只有从十八世纪六十年代起，随着教士经济地位提高，以及出任治安法官，争端才普遍起来。但卡勒姆·布朗指出，在苏格兰，由于教士与民众共同承受经济现代化带来的艰难，对教士的敌意“几乎完全不存在”。

上述发展是否促进新教教士专业化，很大程度取决于采用何种尺度。除垄断讲道，他们还具有近代早期专业职业的其他标志：专门教育训练、属于拥有自身语言与象征的明确职业群体的意识，以及对自身在更广泛社群中作用的清晰认识。显然，尽管思想、经济和政治环境变化，他们仍投入若干固定职责：讲道、要理教导、牧灵探访，以及主持人生礼仪，包括洗礼、坚信礼或首次圣餐、婚礼和葬礼。敬虔主义与福音派运动，确实使<a id="pdf-142"></a><!-- PDF page 142; original page 127 -->这些职责履行得更彻底、更专注，但不应贬低那些不持同样观点、却在常常艰难且令人气馁的环境中尽力而为的教士。可以说，新教教士永远不可能只是专业职业群体。正如更广义的基督教与文化关系一样，牧师属灵召命与对此召命的世俗理解之间，其确切关系始终暧昧。然而，个人正是在这样的环境中决定成为教士；他们在属灵召命与世界要求之间经历的挣扎，才是基督教传统研究者应当始终关注的事情。
