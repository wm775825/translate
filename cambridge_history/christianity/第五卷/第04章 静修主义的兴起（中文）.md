# 第4章 静修主义的兴起

迪尔克·克劳斯米勒

十四世纪二三十年代，迅速缩小的拜占庭帝国深受内争之苦，正教会也被一场激烈争论所震动。这场争论最终重新界定了古代晚期形成的传统三一教义：1351年，一次教会会议规定，不仅上帝超越的本体在真正意义上是神圣的，他在世间的作用或神能同样如此；会议并谴责另一种主张——认为这些作用是受造的——为异端。这项会议决议反映了阿索斯山修士格里高利·帕拉马斯在与一连串对手论战时发展出的神学模式；其中最著名的对手，是卡拉布里亚修士巴尔拉姆，以及文人学者格里高利·阿金迪诺斯和尼基弗鲁斯·格里高拉斯。这些人被逐出教会，帕拉马斯本人却在1359年去世后不到十年便被封为圣人。至本书成书时，他已被视为正教会的权威之一；二十世纪神学家重新发现他的著作，对于建构当代正教发挥了关键作用。[^p122-1]

帕拉马斯与其对手争论的最后阶段，具有高度抽象的特点，并广泛引用教父文本作为论据。然而，争论的起点绝非纯粹学术问题。帕拉马斯提出有关神圣作用的见解，是为了解决一个具体问题：如何使神秘体验的真实性，与强调上帝不可接近、拒斥一切声称看见上帝本体之说的传统神学相协调。帕拉马斯及其盟友如此关切这一问题，是因为他们奉行所谓静修方法（hesychastic method）：一组心理与身体相结合的技巧，其目的在于使心智摆脱一切纷扰的念头，并引发以光的形式看见上帝的异象。

这种方法最早见证于十三世纪，在整个十四世纪的拜占庭修士中极为流行，尤其是在阿索斯山；小亚细亚失守后，这里已成为正教修道生活最重要的中心。静修主义的倡导者认为，自己才是东方正教修道传统的真正继承人，尤其继承了强调必须时刻防备罪恶念头的流派。[^p123-2] 与此同时，他们不赞成其他修道生活模式，特别批评两类修士：一类专注苦修和咏唱圣咏；另一类像帕拉马斯的对手巴尔拉姆一样，强调智识活动对修士的重要性。静修者指责前者忽略“内在之人”，贬斥后者追逐世俗智慧，使人偏离对神圣者的寻求。静修者的自我描绘及其对另外两种模式的批评，影响如此之大，以致他们的观点成了叙述拜占庭晚期灵修的正统版本。[^p123-3] 以下讨论将考察促成这一叙述形成的过程，尝试澄清静修主义与拜占庭灵修传统之间的联系，确定静修者与非静修者争论的性质，以便更为均衡地理解这一新运动的兴起。

## 伪西缅与意大利人尼基弗鲁斯

任何有关静修主义的讨论，都必须从两篇阐述如何引发异象的具体技巧的论著谈起。第一篇在手稿中被错误归于十一世纪神秘主义者新神学家西缅名下，其写作年代只能暂定为十二世纪末或十三世纪初。[^p123-4] 相较之下，第二篇的作者则是一位情况较为清楚的历史人物——意大利人尼基弗鲁斯；他在皇帝米海尔八世统治时期（1259—1282年）于阿索斯山修道，并激烈反对皇帝亲西方的宗教政策。[^p123-5] 十四世纪，这些文本大为流行，被广泛视为<a id="pdf-124"></a><!-- PDF page 124; original page 103 -->权威。[^p124-6] 渴望神秘体验的修士为何受到吸引，并不难理解：尼基弗鲁斯将自己的教导呈现为一种面向初学者的“学问”或“方法”，简易、迅速、有效，而且不受魔鬼干扰。[^p124-7] 然而，我们还须追问，他和他的读者为何把这种体验视为修道生活的核心。新神学家西缅的著作提示了一种可能的答案。西缅批评了只有少数特殊人物才能获得异象的传统观点，主张每一个修士都能够、也应当体验神圣者。[^p124-8] 这种激进立场似乎随着时间推移而更加普遍，因为它又出现在十二世纪神秘主义者君士坦丁·克里索马洛斯等较晚的灵修作者笔下。[^p124-9] 然而，西缅本人属于能够自发获得此类体验的人，并未提出实现这一目标的具体方法。[^p124-10] 尼基弗鲁斯说，有人自发获得异象，但大多数人需要教导，他所指的很可能就是这种情况。[^p124-11] 对这一状况的判断，构成了伪西缅和尼基弗鲁斯的基本理由：他们希望通过自己的教导，使普通修士也能获得这类体验。[^p124-12]

静修主义如何运作？两位作者都向读者许诺，只要遵循一套包括坐姿、控制呼吸和呼求耶稣之名的祈祷程序，就能在心中获得异象，类似使徒在他泊山见到基督显容的体验。[^p124-13] 尽管如此，两篇文本并不相同。伪西缅建议修习者凝视肚脐周围的部位，直到那里充满光明、变得透明，使观看者能够看见发生变容的心脏。相比之下，呼吸和耶稣祷文仅被顺带提及。尼基弗鲁斯则完全不提观脐，而专注于另外两个要素。他敦促读者专注呼吸从口至心的路径，并随呼吸一起，将心智“送下”到心脏之中。

他声称，通过屏住呼吸，修习者可以把心智留在心内，防止它游荡，或被念头分散注意力。达到这一状态者，随后应不断呼求耶稣基督之名，使心智有所专注，并压过可能涌现的一切“新”念头。尽管有所不同，伪西缅与尼基弗鲁斯显然都在同一框架内运作：观脐和控制呼吸这两种技巧，都赋予感官知觉与想象以重要作用。此外，它们都与身体紧密相连：专注心脏不只是集中精神的手段，人们相信，它牵涉实际器官，并对其产生影响。[^p125-14]

静修主义的成功，充分表明这些技巧十分有效。然而，仅凭有效性，还不足以解释阿索斯山和其他地方的修道共同体为何会采用它们。伪西缅的论著让我们得以了解早期静修者面临的难题。它远不只是一部简单的祈祷手册；“方法”的描述属于精心构建的论证的一部分，作者借此争取当时修道论述对它的认可。他在序言中宣布，将向读者介绍三种不同的祈祷实践，以便他们作出明智选择。他使用的标准是“专注”（προσοχή）和“祈祷”（προσευχή）：有效的专注，应能发现并捕捉罪恶念头；有效的祈祷，则应随即将它们清除。[^p125-15] 赋予“专注”以核心地位，指向修道生活中的一条特定传统；它最早见于约翰·克利马库斯的《天梯》，后来在西奈的赫西基奥斯与菲洛塞奥斯的《灵修诸章》中得到展开，成为主导主题。[^p125-16] 分析伪西缅的论证，可以揭示静修主义与“西奈”灵修之间极为复杂的关系，并有助于理解静修方法产生的背景。

这篇论著的编排十分直接：三章分别介绍每种实践的“特性”与效果。第一种实践的追随者直立站着，将内在和外在的目光向上投向天空，随后在心中想象天国的辉煌，直至身体感官能够以光、气味和声音感知它。[^p125-17] 相比之下，<a id="pdf-126"></a><!-- PDF page 126; original page 105 -->第二种实践要求心智严格控制感官，并检验一切进入的念头，察看是否存在魔鬼干扰。[^p126-18] 第三种实践即静修方法，其追随者被要求坐下，将内外目光投向肚脐部位，在体内寻找心的位置。他们被告知，最初会体验到黑暗，但最终心智“看见心内的空气，并看见自身全然明亮，充满辨识力。从此，每当念头升起，心智便在它尚未完成、形成图像之前，通过呼求耶稣基督将其驱逐、消灭”。[^p126-19]

第一种实践被判为最差：它不能使人达到德行与无情欲的境界，还可能导致疯狂，因为追随者并未学会区分真实异象与魔鬼幻象。对第二种实践的评价则积极得多。依作者之见，它与其说错误，不如说不完整，因为它专注反驳来自外部的魔鬼念头，却忽略处理那些已经存在于心内的念头。因此，它仍然无效，永远不能使修士彻底摆脱情欲。毫不意外，第三种实践实现了这一点；作者认为，专注于心使修习者获得辨识力，因为他能够看见心内的一切，因此可以轻易识别并通过祈祷摧毁所有魔鬼念头：不仅是来自外部的，也包括已经在内部的。

乍看之下，作者的论证似乎十分直截了当，但细看便会发现明显的反常之处。依照他的高下排序，静修方法理应与第二种实践更为接近，然而，它反倒与第一种有着显著相似性：在这两种实践中，作者都说修习者采取特定姿势，将想象力与身体感官投向同一对象，并期待神秘体验。第二种实践完全不具备这些特征：身体和感官知觉未获积极作用，也不存在异象成分。正如我们所见，作者确实通过辨识力这一共同主题，将静修方法与第二种实践联系起来，从而得以把自身立场同第一种实践比较，显示其优越性。然而，与第二种实践的重合，只出现在静修方法描述的后半部分；到这里，它已不再与第一种<a id="pdf-127"></a><!-- PDF page 127; original page 106 -->实践相对应。作者借“心智看见……自身全然明亮，充满辨识力”这句话，实现了从一个框架向另一个框架的转换。由此，辨识力并未像第二种实践那样与检验念头相联，而是被附加于一种产生异象体验的技巧之上。因此，共同标准“专注”，掩盖了实现这一目标的方式之间的根本差异。实际上，正因为“专注”在文本中被赋予不止一种含义，它才可能发挥这种作用。正如我们所见，作者在序言中将其界定为发现一切即将进入心内的念头，并判断其性质和来源的能力。然而，这个词后来只在讨论以“检验念头”为基础的第二种实践时，才按这一含义使用。另一方面，在第一种实践中，它意味着聚焦于一个对象，即天空。这种用法显然与作者开篇的定义毫无关系，却使他后来能够将两种观念合而为一：在第三种实践中，对肚脐的“专注”产生了变容之心的异象，同时也使存在于心内的一切魔鬼念头显现出来。他之所以能够这样做，是因为静修方法区别于第一种实践的“转向内在”，使他得以混同两种“心”：作为异象体验对象的心，与作为念头“所在之处”的比喻的心。[^p127-20]

作者巧妙利用概念和术语上的歧义，理由十分明显：尽管自己的方法性质根本不同，他仍想使其获得第二种实践倡导者所规定的价值体系的认可。事实上，这篇论著很可能正是为回应第二种实践支持者的攻击而作；作者抱怨，他们自视为“专注者”（προσεκτικός），批评他人不够专注。第二种实践只关注进入心内的念头，毫无疑问，这是对西奈传统作者约翰·克利马库斯、菲洛塞奥斯，尤其是赫西基奥斯教导的歪曲描述。[^p127-21] 与此同时，第三种实践的描述又大量逐字借用了赫西基奥斯的《灵修诸章》。[^p127-22] 根据以上讨论，作者很可能是为了强化自己显然并不成立的主张，才插入这些引文：声称自己属于这一传统，只不过对它有所改进。

伪西缅为何如此费尽周折？在整个拜占庭时期，都可见通过强烈想象产生感官体验的祈祷实践。例如，在牧首美多迪奥斯所写的九世纪《认信者狄奥法内斯传》中，年轻圣徒和新娘通过专注于嗅觉来“追寻”基督：他们将基督想象为芬芳，最终获得回报，鼻中奇迹般地闻到“真实”的香气。[^p128-23] 圣徒传记传统将这类体验视为毫无问题，几乎从不提出辨识力的问题。这种不加顾虑的态度，与古代晚期及拜占庭灵修文献中的观点形成鲜明对比。[^p128-24] 灵修文本的作者不仅因魔鬼欺骗的危险而强烈反对运用想象，还批评一味追求异象体验，以及伴随而来的对道德完善及其实现途径的漠不关心。[^p128-25] 显然，伪西缅专注异象体验，为传统的内心省察实践不留位置，因此置身于传统灵修论述之外。他试图通过这些操作，克服自身立场的边缘地位，使其能够被这一论述接受；在他的文本中，这一论述由第二种祈祷实践代表。为了达到目的，他采取了复杂策略：尽管第一种实践与静修方法明显相似，他仍将其作为一种独立方法加以介绍；随后，他与灵修传统一致，称这种方法误入歧途，危及修习者。[^p128-26] 这样一来，作者便能表现出自己了解、并在口头上认可对运用想象的反对意见，从而掩饰自己的立场实际上与那些借想象追求异象体验者几乎完全相同。

伪西缅的操作，为静修主义在灵修主流中争得一席之地。然而，两种传统的结合显然仍停留于表面，只有颠覆第二种实践赖以成立的概念框架，才可能实现。尼基弗鲁斯在其手册中明确表示，对静修者而言，免受魔鬼攻击并非通过筛查念头、运用辨识力实现，而是通过<a id="pdf-129"></a><!-- PDF page 129; original page 108 -->强烈的想象活动完全排除这些念头；这种活动取代了其他一切心智活动。[^p129-27]

伪西缅的论著使我们了解静修运动的最早阶段：它当时尚未广泛传播，必须努力争取认可。十三世纪末、十四世纪初，静修主义在阿索斯山迅速扩展。据说，尼基弗鲁斯吸引了许多门徒，其中包括菲拉德尔斐亚的狄奥莱普托斯（约卒于1325年），后者是当时重要的宗教权威之一。[^p129-28] 然而，下一代中最重要的人物，无疑是西奈的格里高利。他卷入土耳其人征服小亚细亚西部的动乱，后来成为修士，先在西奈山度过数年，随后前往阿索斯山隐修。之后，他在色雷斯创办修道院，得到保加利亚统治者伊凡·亚历山大（1331—1371年）的赞助。1346年去世时，他已拥有大批门徒，其中有不少斯拉夫人，将静修主义带到保加利亚和塞尔维亚。[^p129-29] 格里高利向不同的阿索斯山修士写了若干部祈祷手册，宣传静修方法。[^p129-30] 在这些文本中，他提到此前的两篇论著，但显然，他的教导更多取自尼基弗鲁斯，而非伪西缅：重点是呼吸和耶稣祷文，完全不提观脐。他自己的体验，则体现为对颤抖、喜悦感等身体反应的强烈关注。

## 西奈的格里高利

格里高利的祈祷手册，是静修主义在阿索斯山及其他地方传播的证据。然而，它们也表明，这一传播并非简单强加于人的过程，而是彼此调适的过程。毫无疑问，最早形式的静修主义对传统修道生活构成了巨大危险。尼基弗鲁斯不仅阐述了让“普通”修士获得异象的技巧，还声称，学习这些技巧不需要灵性导师的帮助。[^p129-31] 若认真按这一主张实行，<a id="pdf-130"></a><!-- PDF page 130; original page 109 -->便会彻底瓦解修道者进入共同体的既定养成过程。按这一过程，初学者必须服从一位资深修士的权威，对其毫无疑问地顺从。这种行为培养谦卑德行，避免修士日后炫耀自己的成就而扰乱共同体。与之相反，尼基弗鲁斯声称，初学者读几页文字便已足够，可以取代灵性导师。西奈的格里高利论述这一方法的著作，性质则截然不同：他将异象体验限于已有高深修为者，并强调初学者必须服从资深修士的辨识判断。[^p130-32] 毫不奇怪，格里高利还敏锐地意识到魔鬼可能干预，因此拒斥一切“具有形状”的异象；尼基弗鲁斯则完全不关心修习者所面临的危险。[^p130-33] 从这一对照可以看出，格里高利旨在驯化这个新运动，使其与传统权威结构相容。

西奈的格里高利通过自己的教导，促进了这一新运动在阿索斯山的成功。在当时的圣徒传记中，他确实以异象体验问题的裁断者身份出现。[^p130-34] 然而，毫无疑问，许多人仍与静修主义保持距离，甚至对其排他性心怀不满；伪西缅的一项主张恰好概括了这种排他性：教父们一旦发现这一方法，便抛弃了其他一切。[^p130-35] 一组反对者，是那些专注守斋、不眠等苦修实践，并更喜欢传统圣咏吟唱而非静修方法的修士。尼基弗鲁斯的论著对他们大加攻击，西奈的格里高利也在著作中反复批评他们。[^p130-36] 两位作者在论证中都依赖伪西缅将静修方法等同于西奈灵修的做法；他们所谓苦修者忽略内在维度的指控，直接取自传统的“专注”论述。[^p130-37] 也有<a id="pdf-131"></a><!-- PDF page 131; original page 110 -->迹象表明，静修者反过来被指责松懈；格里高利的传记作者，刻意将圣徒初次接触这一方法时的他，描绘为一位极其严格的守斋者。[^p131-38] 不过，总体而言，苦修者似乎并未对新运动构成严重威胁。

## 卡拉布里亚的巴尔拉姆

事实证明，远为危险的对手是卡拉布里亚修士巴尔拉姆。约1330年，他离开故乡来到拜占庭东方，很快便凭借对正教神学传统的了解，以及对哲学和科学的兴趣而获得声望。[^p131-39] 十四世纪三十年代中叶，他在君士坦丁堡和帖撒罗尼迦结识了一些修士，了解了静修方法及其效果。[^p131-40] 他认为静修者的观点，轻则错误，重则属于异端，遂以使他们摆脱谬误为己任。[^p131-41] 然而，他刚着手行动，便遇到激烈反对；反对者由格里高利·帕拉马斯领导，后者出身君士坦丁堡贵族家庭，已在阿索斯山成为修士。[^p131-42] 帕拉马斯与巴尔拉姆并不陌生；两人此前已就逻辑在神学论述中的作用交换一系列信件，论战色彩日益浓厚。[^p131-43] 现在，帕拉马斯写成一部三分的论著《为以神圣方式静修者辩护》，为处境困难的静修者提供了一整套论据。[^p131-44] 与此同时，巴尔拉姆似乎也以一系列著作表达自己的见解。然而，一旦得知帕拉马斯的论著，他便撤回<a id="pdf-132"></a><!-- PDF page 132; original page 111 -->这些文本，加以修订，以回应帕拉马斯的批评。[^p132-45] 帕拉马斯于是又撰写第二部论著，编排与第一部相同，但更直接地处理巴尔拉姆的书面论述，并反复加以引用。[^p132-46]

巴尔拉姆究竟要达到什么目的？遗憾的是，他著作的两个修订版本都已佚失，必须从其他史料重建其内容。重建的明显起点，是帕拉马斯对其立场的反驳。帕拉马斯两部论著最后、也是最长的部分，处理了巴尔拉姆的一项主张：对上帝的寻求，终点在于理解他与一切受造存在完全不同。帕拉马斯的反论是，人能够超越自然能力，或因为心智具有超越自身的能力，或因为上帝借圣灵的恩赐，使人能够接近自己。[^p132-47] 这种编排反映了该问题对静修者的核心重要性。然而，我们必须谨慎，不能只通过静修者的眼光看待巴尔拉姆。他自己的著作似乎采用了很不一样的组织方式：他反对异象体验的《论光》，似乎是这一主题的第一篇，接着才是合题为《论祈祷与人的完善》的论著。[^p132-48] 这种差别表明，巴尔拉姆关注的重点另有所属。他更早的著作，尤其是致静修者伊格纳提奥斯的两封信，以及致帕拉马斯的第二封信，也支持这一解释。这些文本显示，巴尔拉姆最初与其说关心光的异象本身，不如说关心它未能对获得异象者产生他认为灵性进步所必需的效果：治死并制伏灵魂中情欲的部分，唤醒理性能力，使人能够正确判断，驱除谬误和<a id="pdf-133"></a><!-- PDF page 133; original page 112 -->自欺。[^p133-49] 显然，对于在静修体验中发挥重要作用的情感和身体，巴尔拉姆持否定态度。帕拉马斯在第一、第二部论著各自的第二部分处理这个问题，试图表明情感未必有罪，也能够被圣化。[^p133-50] 然而，对巴尔拉姆轻视情感的认识，必须以其高度重视理性的态度加以平衡。在基督教新柏拉图主义的传统中，巴尔拉姆主张，对这个世界结构的知识，以共同观念的形式铭刻于人的灵魂；这些观念在推论性思维的层面上，再现了神圣心智内在的创造原理。[^p133-51] 在已佚的《论人的完善》中——这是他这组著述的最后一部分——他提出了与这一框架相符的人上升至上帝的模式。他坚持认为，人首先必须让分析和逻辑能力接触各类知识，唤醒沉睡的理性，之后才能通过“收合”思想，进入合一而直觉的理智认识，从而超越纯粹人的层次。[^p133-52] 这种逐级上升的模式，无疑是巴尔拉姆教导的核心。[^p133-53] 帕拉马斯在反驳中攻击这一模式，认为它试图使修士偏离其真正召唤；他将这种召唤等同于实践静修方法。[^p133-54] 他把相关讨论置于两部论著的第一部分，并分别题为“追求学问在何种意义及多大程度上有益”，以及“真正修士应当关心的真正救恩知识是什么，或反对那些声称世俗教育所得知识真正使人得救者”。[^p133-55] 由此，他给人一种印象：巴尔拉姆倡导智识活动，完全处于修道传统之外。

然而，这种印象具有误导性。在致友人格里高利·阿金迪诺斯的一封信中，巴尔拉姆为《论祈祷与人的完善》辩护，回应批评说，他所做的不过是对七世纪修士兼灵修导师认信者马克西莫斯的观点进行“释义”，意在确认后者的立场。[^p133-56] 阿金迪诺斯乐于接受这一点，尽管他也批评巴尔拉姆对马克西莫斯作了选择性且偏斜的解读。帕拉马斯则反过来，以<a id="pdf-134"></a><!-- PDF page 134; original page 113 -->只顺带论及马克西莫斯，而且主要置于祈祷语境中的方式，改变了巴尔拉姆的原意。[^p134-57] 因此，仅依赖帕拉马斯，便不可能重建巴尔拉姆的论述重心。所幸，我们还有其他同时代史料，可帮助阐明这场争论。这些史料表明，巴尔拉姆远非意在宣扬世俗主义；他把自己视为一种真正修道传统的代表，并认为静修者正在威胁这一传统。

## 西奈的格里高利与“言辞智者”

巴尔拉姆并不像帕拉马斯希望我们相信的那样孤立。早在1307年，菲拉德尔斐亚的狄奥莱普托斯就遇到一些追求“世俗”智慧、拒斥静修方法的人。[^p134-58] 西奈的格里高利最初也受到阿索斯山“更有学问”的修士反对；他们指责他标新立异，试图将他逐出圣山。[^p134-59] 狄奥莱普托斯彻底拒斥对手立场，其反应与帕拉马斯十分接近。[^p134-60] 相比之下，西奈的格里高利的回应细致得多，使我们能够了解另一种模式，以及双方争论的性质。格里高利在《论诫命、教义、警告与应许，并论念头、情欲与德行，又论静默与祈祷的各篇论说》中处理这一问题。这是关于各种灵修主题的一系列简短论述，最可能写于1327年，以下称《论说》。[^p134-61] 该书开篇便谈到人性：“在获得纯洁之前，不可能像我们原先那样，依本性成为或恢复为理性者（λογικός）……因为与感官知觉（αἰσθητική）相联的非理性习惯，已经压倒了我们。”[^p134-62] 格里高利在这里提出一种人性模式：人同时拥有推理能力和本身不具理性的感官知觉。前者是人所特有，后者则为人与动物共有。两者通过严格的等级关系联系起来：理性控制感官。然而，这种关系<a id="pdf-135"></a><!-- PDF page 135; original page 114 -->只存在于堕落之前；堕落之后，感官知觉开始压倒理性。因此，理性失去作用，人也被拉低到无理性禽兽的层次。这就规定了人的任务：回到上帝创造时为他们安排的理性存在状态，从而重获真正的人性。就其本身而言，格里高利的说法完全属于传统。[^p135-63] 然而，对一个静修者来说，选择这一框架却令人惊讶，因为它没有为静修体验所核心关注的超自然维度留下位置，也与感官在这种体验中所发挥的积极作用相冲突。

格里高利选择“理性”这一主题，无疑意义重大：文集的第一章，尤其是第一个词，常常引出主导主题。[^p135-64] 分析文本可以发现，格里高利正与一些修士争论；后者将智识活动视为灵性上升不可分割的一部分，并借“理性”的论述来证明自身生活方式的正当性。格里高利接受这套论述属于基督教传统，却质疑对手对它的占用，转而为静修者自己主张这一传统。在第二章，他写道：“只有圣徒显为依本性具有理性的存在，因为他们是纯洁的；‘言辞智者’（τῶν ἐν λόγῳ σόφων）中，无人拥有纯洁的言辞（λόγον… καθαρόν），因为他们从起初便〔让〕恶念（λογισμοί）败坏了理性能力（λογικόν）。世俗智慧那物质的、多言的灵，将抽象思考（λόγους）带给较有智识者（γνωστικώτεροι），将恶念（λογισμοί）带给较粗鄙者，从而拒绝与那以不分割、单一的知识（γνῶσις）呈现的位格性智慧及观照同住。”[^p135-65] 这一段接续了“理性”作为人类自然状态的主题。格里高利现在引入“圣徒”，作为已达到这一状态的具体群体，与另一个未能达到此状态的群体——“言辞智者”——相对照。他的论证围绕“纯洁”这一概念展开；第一章已将它作为维持或恢复人类理性的前提。现在，“圣徒”被赋予这种品质，“言辞智者”则被指以“念头”（λογισμοί）败坏理性；在修道论述中，这个词带有<a id="pdf-136"></a><!-- PDF page 136; original page 115 -->罪恶和魔鬼作用的含义。[^p136-66] 对抗这些念头、努力达到无情欲的境界，传统上被视为通向完善的第一步。格里高利暗示，致力于获取抽象知识的“言辞智者”，完全没有控制非理性的冲动，因此在自己的人生中重演了亚当的堕落。这样一来，他便能将他们此后的一切活动描述为“非理性”。

该章后半部分表明，格里高利并不满足于这种迂回批评。他在那里将“抽象思考”归于“言辞智者”，并改称其为“较有智识者”，而把“恶念”归于另一个群体——“较粗鄙者”。然而，他又同时将这两种思想过程追溯至“世俗智慧之灵”，也就是魔鬼，从而把两者联系起来。这一安排的目的十分明显：它使他得以拒绝将智识追求（λόγοι）视为成圣的资格。格里高利随后又将这种“世俗智慧”与“位格性的智慧”，也就是神圣圣言，相对照。这两种智慧与知识不仅彼此不同，而且相互排斥：从事前者，就无法上升至后者。单就这一对照而言，在静修文本中或可视为常见之说。[^p136-67] 然而，在《论说》的语境中，它却令人惊讶，因为异象体验是神圣恩典的结果，属于超自然层次，在所选的“理性”框架中并无位置；这一框架严格限于人性的领域。这种反常在下一章更为明显：格里高利得出结论，只有“对恩典的感知（αἴσθησις）”，而非“对念头的反思”和“对事物的必然性证明”，才可视为真理知识。[^p136-68] “对恩典的感知”是《论说》中首次明确提及静修体验，因此也表明，“圣徒”就是静修者。相比之下，“证明”和三段论推理显然与“言辞智者”相联。显而易见，与异象不同，这类追求涉及运用人的理性；由此，“言辞智者”有理由认为自己更具理性，因此高于静修者。[^p136-69] 作为静修者，格里高利必须拒绝这一结论。我们已经看到，理性的恢复须通过战胜恶念来实现，而格里高利否认“言辞<a id="pdf-137"></a><!-- PDF page 137; original page 116 -->智者”获得了这种胜利。现在看来，即使获得这一胜利，人也只有停止三段论推理，并总体上停止运用理性能力，才能保有“理性存在”的地位。

《论说》中处理邪恶“念头”的部分，证实了这一点。第60章将这些“念头”追溯至堕落造成的“单纯记忆”的“分裂”；原先单纯的人，由此在能力上成为“多样的”“复合的”。[^p137-70] 第61章又说，人可以“通过恒常记念上帝，促成原初状态的恢复；这种记念借祈祷牢固建立，并通过与圣灵交融，从自然层次提升至超自然层次”。[^p137-71] 从这里可以看出，格里高利以静修祈祷实践来理解“单纯记念上帝”。在论祈祷的著作中，他明确将“记念上帝”等同于“不断呼求耶稣之名”，[^p137-72] 并告诫修习者，除“单单对耶稣纯洁、单纯而无形的记念”之外，不应允许任何事物进入心内。[^p137-73] 现在，这种实践被投射回人的原初状态，实际上把亚当变成第一个获得异象的静修者，并把堕落解释为异象体验之前提——单纯记忆——的崩溃：亚当受到魔鬼诱惑，任自己分心，因此“忘记”上帝。这便可以得出结论：虽然“理性”属于亚当的自然构成，却始终被超越。较早的作者中已经存在这种观点，但格里高利的静修背景使他从中推出了激进结论。[^p137-74] 在他的框架中，人越善于运用心智能力，就越不具“理性”，因为运用这些能力本身就等于败坏它们。只有通过静修实践排除念头，才可能恢复原初状态，紧接着便会发生异象体验。格里高利明确表示，人的“自然”状态不过是一个过渡点：从这里，人要么倒退至“非自然”，要么前进至“超自然”。[^p137-75]

这种巧妙解释的理由很清楚：它使格里高利能够切断“理性”与智识追求的一切联系，从而将“理性”概念纳入自己的模式。值得注意的是，第<a id="pdf-138"></a><!-- PDF page 138; original page 117 -->60、61章将“记念上帝”与罪恶念头相对照，并不像第2章那样，将智识追求和学问作为独立类别提及。然而，这种差别只是表面的，因为第2章已将智识追求和罪恶念头这两类活动，追溯至同一个作用者，从而把它们等同起来。在静修框架内，这完全说得通，因为一切念头只要分散了对耶稣祷文的专注，便都是坏的。智识追求（λόγοι）显然在这一框架中无立足之地；它们之所以被引入，只因为在格里高利对手的模式中曾具有重要作用。

格里高利试图更清楚地界定这两个类别之间的关系，但其说法含混而矛盾：有时，他将两者混为一谈，如第2章所说，两者都来自这个世界的“物质之灵”；另一些地方，他似乎又把恶念与智识追求区分开来，前者归于魔鬼的作为，后者则来自“物质”。[^p138-76] 这种两可态度的原因在于，灵修作者通常会区分怀有罪恶念头的“纵情感官者”（σαρκικοί），以及完全依赖人的能力的“智识者”（ψυχικοί）；依圣保罗所言，后者不接受圣灵及超自然维度的存在。[^p138-77] 格里高利自己在第22章也提到这一观念，将从书本获得、被他以保罗的措辞称作“变成愚拙的智慧”的人类知识，与直接来自上帝的超自然知识相对照。[^p138-78] 然而，在关于此问题的纲领性论述中，格里高利不愿承认一个区别于魔鬼和神圣者的“中性”人类领域有可能存在。

为了强调这一点，格里高利构造了二元对立：静修者简短、重复的耶稣祷文所体现的神圣单纯与合一，反复同魔鬼的多样与分裂（διαίρησις）相对照；后者则与“言辞智者”冗长的智识追求联系起来。[^p138-79] 然而，这种整齐对称，并不像格里高利希望读者相信的那样不证自明。细读第2章，会发现他隐约承认另一套框架。“与位格性的智慧同住（συνοίκησις）”一语，唤起《所罗门智训》7:28：“上帝所爱的，只有与智慧同住（συνοικοῦντα）的人。”在这段文字中，传统上被认同为<a id="pdf-139"></a><!-- PDF page 139; original page 118 -->基督的智慧，以教师身份出现，赐给人对“万有的无误知识”，以及“聪明”和“学问知识”。[^p139-80] 这一段不仅为基督徒的智识追求提供正当性，还将智慧之灵界定为“具有多个部分”；这种描述令人想到，格里高利形容魔鬼的“世界之灵”时所用的“多言”一词。把超自然知识描述为“单一”“不分裂为部分”，则借自伪狄奥尼修斯《论教会阶序》中的一段著名文字；该段解释希腊语“修士”（μοναχός）一词，称其意味着修士过着“不分裂为部分、保持单一的生活；这种生活在将分裂事物神圣地收合为一个似神的单一体及爱神的完善之中，使他们合一”。[^p139-81] 这一段深受新柏拉图哲学影响，采用了它对推论性思维与直觉的区分：前者发生在理性灵魂中，后者则是更高能力“理智”（νοῦς）的功能。然而，在新柏拉图主义中，推论性思维并不被视为通向更高层次的障碍，反倒是其前提；通过不断增强的抽象过程，人的心智从多样符号上升至这些符号背后单一的实在。

在《论说》开头，格里高利只含蓄影射这一观念，直到第127章才正式讨论。在这篇异常冗长的章节中，他为修士灵性发展的不同阶段，分别使用“语法家”“演说家”和“哲学家”等名称：

> “语法家”，是那些致力于实践生活（πρακτικός）的人，也就是说，他们以身体（σωματικῶς）参与行动的世界；“神圣演说家”，是那些观照自然（φυσικῶς）的人，也就是说，他们处于知识与万有存在之理（τοὺς λόγους τῶν ὀντων）之间，也就是说，他们通过理性进行区分的能力（διαιρετική），在灵中将必然性逻辑运用于普遍者（τῶν ὄλων ἐν πνεύματι）。“真正的哲学家”，则是在自身中以可感、直接的方式，拥有与上帝超自然结合的人。[^p139-82]

在这里，格里高利提出一个灵性上升的三阶段体系：对抗情欲、追求德行之后，是通过<a id="pdf-140"></a><!-- PDF page 140; original page 119 -->研究上帝在受造界留下的印记来寻求上帝，然后才是神圣者的神秘体验。当然，这种体系本身完全属于传统；它最早在古代晚期形成，见于许多拜占庭时期的灵修文本。[^p140-83] 然而，它显然与静修主义的修道生活模式相冲突；在后者中，达到无情欲与获得神秘体验之间，没有中间阶段的位置。转向第127章澄清这些阶段关系的部分，这种不相容就更为明显。代表最高阶段的“哲学家”，被描述为神秘主义者。然而，此前被呈现为静修方法结果的异象体验，现在却归于那些先通过观察受造界，推知上帝为万有唯一原因的人。[^p140-84] 认识到全部受造界来自同一原因，确立了合一；但这是一种通过智识活动，而非单靠祈祷达到的合一。这种智识活动必然具有“区分性”，因为只有按种与属的框架，将各个存在者分类，才可能看出它们形成统一整体。格里高利讨论“演说家”的作用时，明确表示：“依那些‘真正的言辞智者’之见，演说家通过概括性知识，简明地把握万有，既区分又联结它们，如同一个身体，从而依差异与同一，显示它们具有相同价值。”此外，他也可被称为“真正的逻辑学家”，而“非仅仅运用必然性逻辑者”。[^p140-85] 在这里，“区分”与“统一”、“差异”与“同一”，都处于辩证关系，而非相互排斥。毫无疑问，第127章旨在纠正前三章。此前，是静修“圣徒”与堕落的“言辞智者”整齐对置；现在，却出现了第三类“真正的言辞智者”。此外，格里高利此前暗示人类智慧必然与虚荣和物质事物相联，现在却将对物质的爱，与对上帝“关于自然的”智慧的爱相对照。[^p140-86] 格里高利谨慎强调，正确的自然观照并非仅运用希腊逻辑，也具有灵性维度。然而，这些限定显然无助于使灵性上升的三阶段体系与静修框架更加相容；正如我们所见，<a id="pdf-141"></a><!-- PDF page 141; original page 120 -->静修主义所排斥的，是智识活动本身，而不仅是受到败坏的智识活动。

那么，格里高利为何感到不得不将这一体系纳入自己的模式？我已经指出，它是修道传统不可分割的一部分。然而，他的来源还可以进一步确定。他在第127章谈论“演说家”时，以“真正的言辞智者”为权威，无疑指向七世纪灵修作者认信者马克西莫斯。他说演说家“将五种分立的普遍与一般属性加以区分和联结，而道成肉身的圣言曾将它们联结起来”，直接改写了马克西莫斯《疑难解答》中的一段著名文字。[^p141-87] 人们早已注意到，格里高利的《论说》大量借用马克西莫斯的术语与观念，却将此视为静修者中马克西莫斯思想复兴的标志。[^p141-88] 分析其论证，提示了另一种解释：格里高利之所以提到马克西莫斯，是因为他面对的对手，正借用马克西莫斯的框架证明智识追求的正当性。事实上，马克西莫斯也是以下观点的主要倡导者之一：理性是人的本质组成部分，若人要实现上帝为其安排的计划，就必须发展理性；只有这样，人才能脱离禽兽层次，为神化作好准备。[^p141-89]

此时，我们可以回到巴尔拉姆，以及他自称为马克西莫斯“释义者”的主张。我们已经看到，巴尔拉姆同样宣扬逐级的灵性上升，强烈强调“人的完善”，并支持智识活动与科学探究。因此，毫无疑问，他所倡导的模式，与格里高利的对手相同。马克西莫斯之所以对他们如此有用，是因为他使用了亚里士多德发展出的“属”与“种”等哲学、科学范畴。[^p141-90] 当然，在马克西莫斯的著作中，观照已不再等同于科学探究，亚里士多德的术语也不再具有严格的技术性质。然而，只要仍使用这些术语，就保留了将灵修论述带回其“科学”根源的可能。这使巴尔拉姆及其他志同道合的修士，得以构造一种容纳学术追求的修道生活模式。

格里高利的《论说》，尤其是第一章和第127章，证明这一策略取得了成功：即使无法将对手的框架整合进自己的灵性上升版本，格里高利仍感到必须加以回应。[^p142-91] 必须将《论说》置于争夺灵性权威的背景中理解。[^p142-92] 他提到“言辞智者”时，想到的不仅是人的理性，也是人运用语言的能力。他选择“演说家”一词，显然是因为它的含义：“言辞智者”和“真正的言辞智者”都会表达并传授思想，但并非所有圣徒都如此。《论说》中有大段文字，以明显带有经院式特征的方式进行区分与分类，表明格里高利感到有必要证明自己作为“言辞智者”的资格。[^p142-93] 从《论说》可见，格里高利将自然观照理解为对自然现象的象征性阐释；例如，他描述了三一如何反映于人的构成之中。[^p142-94] 毫无疑问，他的方法比对手更接近马克西莫斯的原意。[^p142-95] 然而，这一点在格里高利的论证中并未发挥作用。他反而试图限制对手模式的影响。通过坚持“真正的言辞智者”应当专注于“概括性学问”和最普遍的范畴，他明确表示，人不应浪费时间研究细节和个别物种。

## 帕拉马斯与静修主义的胜利

现在转向巴尔拉姆的直接对手帕拉马斯，可以发现，其论著与西奈的格里高利《论说》具有许多共同特征。帕拉马斯同样不能接受世俗智慧在道德上是中性的，而暗示它来自魔鬼。[^p142-96] 此外，他声称，献身世俗智慧的人不具“理性”，因而不能进入更高的理智认识阶段，因为这种智慧“产生不稳定、易于变化的知识，从而败坏灵魂思维过程（τὸ φρονοῦν）的推论性与可分性”。[^p142-97] 这一说法<a id="pdf-143"></a><!-- PDF page 143; original page 122 -->针对巴尔拉姆关于人可以通过试错磨炼理性能力、获得知识的信念，与西奈的格里高利的一项看法十分相近：人的分析思维能力，只有始终不被运用，才能得到保存。其结果，再次是颠覆新柏拉图主义逐级灵性上升的模式。然而，与西奈的格里高利不同，帕拉马斯拒绝讨论马克西莫斯的灵修遗产。这使他能够把巴尔拉姆的存在论框架，以及本来完全可以接受的“收合”推论性思维的观念，说成具有世俗性质，与修道灵修不相容。[^p143-98] 因此，他可以把以下结论斥为荒谬：具有学术兴趣的修士因为恢复了人性，已经准备好接近上帝，静修者却仍停留在禽兽层次。[^p143-99]

帕拉马斯的论战无疑比西奈的格里高利更有效，但代价是牺牲了拜占庭灵修传统的大量内容。[^p143-100] 几乎可以肯定，同时代人会将帕拉马斯的论证，理解为不仅拒斥巴尔拉姆，也拒斥马克西莫斯本人。必须把帕拉马斯对修道传统的态度，置于日益激烈的辩论背景中理解；争论使他不断采取更激进的立场。这些立场在许多方面回到了运动的开端：帕拉马斯像尼基弗鲁斯一样，完全不关心神秘体验的危险，而西奈的格里高利则谨慎得多。[^p143-101] 将帕拉马斯与伪西缅比较，也可得出类似观察。我们已经看到，伪西缅以静修方法取代传统的“检验念头”，从而实际上消除了辨识力在修士灵性上升第一阶段的作用。现在，帕拉马斯将这一做法扩展至全部阶段。在谈论对抗情欲时，他拒绝巴尔拉姆关于修士须运用心智，区分真理与仅有真理表象之物的主张。他反而断言，修士应当避免作独立道德判断，只须遵从教父训诫，<a id="pdf-144"></a><!-- PDF page 144; original page 123 -->尽管这显然与巴尔拉姆无疑曾引为权威的马克西莫斯的教导相矛盾。[^p144-102] 在自然观照的层次，帕拉马斯用以惊奇、敬畏之心观看受造界的建议，取代了分析思维的运用；然而，在马克西莫斯的框架中，这属于推论性推理之前的感官知觉层次。[^p144-103]

帕拉马斯并不准备完全放弃“知识”。他一方面拒绝巴尔拉姆所谓教父以“光”比喻知识的主张，另一方面又声称，这光是知识的传递者。[^p144-104] 然而，这一主张使他陷入困境，因为静修者显然并不具备巴尔拉姆和其他学者修士所理解的知识。因此，帕拉马斯最终竟将缺乏知识赞为积极品质。他问道：“基督徒所拥有的上帝知识，以及由此产生的救恩，是通过哲学知识而来，还是通过那借无知废除这种知识的信仰而来？”这样，他便在信仰与无知之间建立了如此紧密的联系，使后者成为得救的前提。[^p144-105]

帕拉马斯对巴尔拉姆修道生活模式的回应，以毫不留情为特点，却很难称为连贯一致；显然，他的兴趣更多在于有效反击对手，而非阐述自己对理性作用的观点。[^p144-106] 此处不宜深入分析帕拉马斯的论著；这些文本给阐释者造成巨大困难，不仅因为篇幅冗长，也因为它们的性质。依古代修辞规则，帕拉马斯似乎经常对某些立场作出让步，实际上却只是为了预先回应一切可能的反对意见。[^p144-107] 尽管如此，我们似乎仍可以稳妥地说，在与学者修士的争论中，帕拉马斯并未显著推进静修主义的论证。他的重要性也不在于<a id="pdf-145"></a><!-- PDF page 145; original page 124 -->将静修主义传播为一种修道生活方式；在这一方面，西奈的格里高利显然发挥了大得多的作用。[^p145-108] 帕拉马斯的主要成就，是为静修异象提供神学基础，并使整个正教会接受这一基础。

我们已经看到，巴尔拉姆否认静修者的核心信条，即人能够通过异象体验神圣者。因此，他起初将异象解释为魔鬼幻象，后来解释为想象的产物。[^p145-109] 当使静修者摆脱错误的努力毫无成效时，他便指责他们复活了古代晚期麦萨利派的异端；该派声称，自己能够以感官感知上帝的本体。[^p145-110] 这类指控对静修方法的实践者构成巨大危险，因为被禁的二元论教派波格米尔派，也被认为持有类似立场。[^p145-111] 为了反击巴尔拉姆，帕拉马斯发展出一套概念框架，在他看来，它使静修体验与传统的神圣超越性观念相协调：他区分了受造存在无法触及的上帝本质，以及同样神圣、却可以被分有的上帝荣耀或作用。[^p145-112] 巴尔拉姆在其反静修著作的第二次、也是最后一次修订中，不仅否认这种区分存在，还声称，连神圣荣耀异象这一观念本身也是异端。[^p145-113] 他的论据来自一个先例：十二世纪教士布拉赫奈的狄奥多若受异端审判的案件。与帕拉马斯一样，狄奥多若为了证明神秘体验的正当性，区分了上帝本体与荣耀，却仍被定为异端。[^p145-114] 然而，这一巧妙策略未能说服同时代人。1341年，巴尔拉姆先被阿索斯山修士集会逐出教会，随后又被牧首会议逐出，后者还命令销毁其著作。[^p145-115] 巴尔拉姆的失败，并不立即意味着帕拉马斯获胜。本质与作用的区分，仍然引起高度争议；帕拉马斯<a id="pdf-146"></a><!-- PDF page 146; original page 125 -->受到格里高利·阿金迪诺斯的攻击；后者此前一直保持中立，甚至不赞成巴尔拉姆攻击静修者。后来，君士坦丁堡知识分子尼基弗鲁斯·格里高拉斯也加入反对。[^p146-116] 然而，帕拉马斯及其追随者也战胜了这些反对意见，最终使其教义获得普遍认可。

帕拉马斯及其同道为何如此成功？从同时代人对其活动的记述看，他们显然构成一个组织紧密、目标一致的群体。[^p146-117] 此外，其中数人原本出身贵族，与君士坦丁堡精英保持联系。[^p146-118] 然而，布拉赫奈的狄奥多若截然不同的命运，表明修士在拜占庭教会和社会中的作用发生了更根本的变化。十一、十二世纪，圣索菲亚教堂的辅祭出任大多数重要主教座，并垄断神学论述；修士则受到严密控制，大体被边缘化。[^p146-119] 然而，这一体系未能在1204年帝国崩溃后延续下来。十三世纪后期起，修士不仅在教阶中居于要职，也站在反对与拉丁教会合一的最前线。[^p146-120] 这有助于解释，阿索斯山修士何以能够采取前所未有的举措：在君士坦丁堡会议尚未处理相关事务之前，便发布教义声明，将对手逐出教会；也有助于解释，他们何以在随后十年中战胜教士与平信徒的一切反对。值得注意的是，格里高利·帕拉马斯成为帖撒罗尼迦总主教，他的两位盟友伊西多尔·布希拉斯和菲洛塞奥斯·科基诺斯，以及西奈的格里高利的门徒卡利斯托斯，都成为君士坦丁堡牧首。

静修方法在拜占庭晚期的成功，确实令人惊讶。其倡导者能够颠覆、挪用或压制早已确立的其他灵性生活模式，并将自己呈现为正教修道生活唯一的真正代表。然而，这种成功导致丰富的拜占庭灵修传统收窄：帕拉马斯战胜巴尔拉姆，最终也意味着拒斥认信者<a id="pdf-147"></a><!-- PDF page 147; original page 126 -->马克西莫斯，以及他的逐级上升观念；在这一观念中，神化之前必须先恢复人失去的理性。随着理性受到贬抑，并被排除在基督徒生活之外，东方修道生活呈现出鲜明的原教旨主义特征。与现代各种原教旨主义一样，这一发展很可能可以通过拜占庭晚期的政治不稳定来解释：当社会与文化受到来自四面八方的攻击时，拜占庭人转向内在，努力保存那“纯粹”的内核。
