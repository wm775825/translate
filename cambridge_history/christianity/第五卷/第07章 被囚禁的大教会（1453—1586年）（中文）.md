# 第7章 被囚禁的大教会（1453—1586年）

伊丽莎白·A. 扎哈里亚杜

依拜占庭法思想，国家有两个支柱：[^p190-1] 皇帝（basileus）与牧首；前者行使政治权力（potestas），后者行使教会权威（auctoritas）。1453年5月29日，奥斯曼人攻占君士坦丁堡，意味着拜占庭国家的终结。然而，皇帝虽已不复存在，普世牧首区却延续下来，尽管这仅仅因为征服者的宗教允许它存在。

在最终陷落之前，拜占庭已在奥斯曼阴影下存在半个多世纪。这为普世牧首带来一系列问题：构成君士坦丁堡牧首区核心的色雷斯与南巴尔干大多数都主教座和主教座，已受土耳其统治，君士坦丁堡成为奥斯曼领土中央的一座孤岛。不过，希腊正教会的代表仍在这些地区存在、活动。这一局面根源于曼齐刻尔特战役（1071年）之后，当时小亚细亚大部分地区转入塞尔柱土耳其人控制。到十四世纪末，塞尔柱已成为遥远记忆，安纳托利亚的主导力量是奥斯曼；他们已征服色雷斯和巴尔干的大部分地区。塞尔柱与奥斯曼都奉行《古兰经》承认“有经人”——即犹太人与基督徒——的原则。[^p190-2] 在塞尔柱苏丹统治下，正教会得以延续，在安纳托利亚若干城镇设有都主教与主教。奥斯曼苏丹同样保护正教共同体，深知这会提高<a id="pdf-191"></a><!-- PDF page 191; original page 170 -->自己在基督徒中的声望。他们的政策有一项鲜明特点：取得曾落入拉丁统治的原拜占庭领土时，最先采取的措施之一，便是恢复正教教会当局。同样，苏丹保护修道院，并给予教会和修道院地产税收豁免；有时，通过授予提马尔领地，保证都主教和主教的收入。[^p191-3] 君士坦丁堡牧首与神圣会议，共同提名小亚细亚、巴尔干各城的都主教与主教；但获提名者在赴任、进入羊群之前，必须取得苏丹许可。[^p191-4] 即使这还不完全属于合作，也意味着希腊教士承认奥斯曼权威。君士坦丁堡最终陷落后，正教会反而获得了更大的统一：不仅得到苏丹正式承认，在行政上也处于同一政治体制之下。

君士坦丁堡对基督教与穆斯林世界，都具有象征意义。穆罕默德二世以征服者身份入城，宣布这里成为帝国首都，实现了穆斯林一个古老梦想。然而，城市已无人居住，因为胜利军队奴役了居民。苏丹立即采取措施，重新招徕人口、修复建筑。[^p191-5] 这一决定经过数年才具体落实；其间，阿德里安堡仍是实际首都。征服者至早在1460年，才将宫廷与帝国行政机构从旧都迁入新都。相比之下，早在1454年1月，他便已任命根纳迪奥斯·斯科拉里奥斯，[^p191-6] 填补空缺的牧首座。君士坦丁堡其他宗教共同体——犹太人和亚美尼亚人——直到数年后才正式组织起来，[^p191-7] 由此立即可见，恢复牧首区是苏丹的优先事项。

东方的亚历山大里亚、安提阿、耶路撒冷三牧首区，自七世纪起便处于伊斯兰统治之下，为征服者依自己宗教原则决策提供了必要先例。[^p192-8] 然而，恢复牧首区也有纯粹务实的考虑。苏丹正确地判断，普世牧首留驻君士坦丁堡，会鼓励希腊人定居。[^p192-9] 穆罕默德深知，新都需要具有城市生活经验的居民，而希腊人中不乏此类人口。为此，他反复使用奥斯曼行之已久的强制迁居措施（sürgün）。大部分移民来自福凯亚、雅典、阿尔戈斯或莱斯博斯等希腊地区。[^p192-10] 穆罕默德二世也认为，任命根纳迪奥斯这样强烈反拉丁的人担任牧首，有助于赢得正教臣民好感。

根纳迪奥斯就任普世牧首的具体情形仍不清楚，原因有二。首先，事实很快被神话扭曲；这些神话旨在表明，即使不信者，也无限尊重正教信仰。其次，同时代证据实在太少。只有三位同时代人留下了关于这一重要事件的记述：为穆罕默德二世撰写传记的伊姆布罗斯希腊显要克里托布洛斯，教会官员狄奥多若·阿加利亚诺斯，[^p192-11] 以及根纳迪奥斯本人；即使他们，也未详述细节。他们把牧首区的恢复描述为完全出乎意料的事件，归因于苏丹的宽宏、仁爱与善意，并强调他尊重牧首职位及其本人。三人都属于反合一阵营，有意无意地希望将苏丹对正教的慷慨，与罗马天主教居高临下的态度相对照。他们还希望影响希腊舆论，使其支持苏丹，因此选择忽略其决定在很大程度上符合伊斯兰政治传统这一事实。[^p192-12]

十六世纪史料在叙述牧首区恢复时，依赖“创设神话”，后来的史料又加以重复。这些叙述旨在颂扬苏丹对牧首制度的深切尊重，以及对根纳迪奥斯个人的喜爱。它们为根纳迪奥斯任命安排的历史背景，是想象的产物：据称，事件发生在攻陷君士坦丁堡后立即，但据根纳迪奥斯本人证言，当时他正与许多其他俘虏一道，从君士坦丁堡被押往阿德里安堡。进一步的润饰，又把任命安排在苏丹宫中，随后由若干廷臣护送牧首返回住所。“神话”坚称，整个程序符合旧有宗教传统，即先由神圣会议选出牧首，再由君主接受、确认；同时代证据却表明，事实恰恰相反：苏丹先任命根纳迪奥斯，会议随后才接受、确认其意志。[^p193-13]

根纳迪奥斯在奥斯曼首都阿德里安堡被囚数月，后来，受雇于宫廷或奥斯曼财政机构、富有且有影响力的拜占庭人出面干预，才使他获释。他们即使不亲自认识根纳迪奥斯，也必定听说过这位君士坦丁堡反合一派领袖。这些人物包括苏丹秘书德米特里奥斯·阿波卡夫科斯和托马斯·卡塔沃莱诺斯；两人也都曾奉苏丹之命出使外国。很可能正是他们向苏丹建议，根纳迪奥斯适合填补空缺的牧首座。[^p193-14]

依所有受任者的惯例，无论获授宗教、军事还是行政职务，根纳迪奥斯应当从苏丹处获得了一份称为“贝拉特”（berat）的特别敕书，[^p193-15] 列明职责与特权。授予根纳迪奥斯的贝拉特未能保存，现存最早的牧首贝拉特，年代为1483年和1525年。[^p193-16] 不过，它们仍能<a id="pdf-194"></a><!-- PDF page 194; original page 173 -->帮助推测根纳迪奥斯敕书的内容；但必须记住，这些文书颁于相对稳定时期，根纳迪奥斯的任命却发生在混乱过渡期，其中包括新奥斯曼首都的建立。它们不支持这样的传统说法：根纳迪奥斯获得的贝拉特是谈判结果，赋予普世牧首区和希腊正教会广泛特权。[^p194-17] 相反，它们表明，任何特权都是授予牧首个人，而非普世牧首区，因为当时伊斯兰法不承认“法人”。[^p194-18] 它也不承认正教会本身，而将之等同于希腊共同体，或十九世纪开始为人所称的“米利特”（millet）。[^p194-19]

牧首特权包括：对教阶的权威，以及管理教会和修道院财产；就婚姻、离婚、继承，对希腊正教羊群适用罗马家庭法；向希腊正教民众征税的权利，下文还将详述；最后，还有部分免税权。最后一项让步，属于苏丹鼓励首都重新聚集人口的一般措施。[^p194-20]

根纳迪奥斯重组牧首区，是荒废的拜占庭城市转变为奥斯曼伊斯坦布尔的一部分。牧首必须面对新社会政治条件造成的一系列问题。最日常、却无疑重要的，是安全问题。苏丹最初将宏伟的圣使徒教堂赐给他，作为牧首区新驻所；但由于城市陷落后周边荒无人烟、犯罪猖獗，根纳迪奥斯无法继续使用它。牧首转而取得至福圣母教堂，那里更为安全，希腊人已经开始重新定居。[^p194-21]

牧首会议即使并未像传统所说，在拜占庭首都陷落后立即重建，也在根纳迪奥斯就任不久后恢复。[^p194-22] 如同拜占庭时代，它仍由<a id="pdf-195"></a><!-- PDF page 195; original page 174 -->牧首行政机构的主要官员，以及居于首都附近、或因其他原因到访的都主教组成。在这一机构帮助下，根纳迪奥斯试图解决羊群苦难带来的问题。由于苏丹的措施，君士坦丁堡聚集了相当数量的希腊正教居民，却形成一个结构松散、彼此缺少联系的社会。从各希腊地区强迁至首都的人，集中定居，构成具有一定凝聚力的街区。[^p195-23] 然而，原君士坦丁堡居民的情况不同。1459—1460年，苏丹命令尚未返城者立即返回，无论他们在陷落前还是陷落后离开；此后，原居民回归的人数不断增加。[^p195-24] 苏丹分给他们住宅，却不是旧居，因为旧居已经被土耳其人、其他希腊人或其他族源者占据。另一些君士坦丁堡人通过不同方式赎身后返回，使情况更加复杂。这个过程漫长而零散，人们往往单独返回，而非全家成群，因为一家人通常被分给不同主人，流落各地。这严重扰乱了家庭生活。许多男女以为配偶已经死亡，再次结婚；一旦原先判断被证明错误，他们便被指控重婚。[^p195-25]

根纳迪奥斯及其直接继任者，以人道理解和宽容处理这类婚姻问题，运用“权宜宽免”（κατ᾿ οἰκονομίαν）的法律原则。[^p195-26] 除社会混乱外，基督教信仰本身似乎也处于危险中，因为改宗伊斯兰教相当频繁；若教会严格执行婚姻法，改宗人数只会增加。

婚姻问题上的困难，只是牧首行政机构内部更深层紧张关系的征兆。这些问题构成了<a id="pdf-196"></a><!-- PDF page 196; original page 175 -->狄奥多若·阿加利亚诺斯自传性著作的内容，生动展示了根纳迪奥斯任内的教会政治。阿加利亚诺斯早已是新牧首的亲信，获擢升为重要的大档案保管官。这一职位的职责之一，是监督正教共同体的婚姻，也是牧首所能授予的最有利可图的职位之一。阿加利亚诺斯很快遭到牧首行政机构其他成员攻击，后者得到能够出入苏丹宫廷的希腊共同体显要支持。根纳迪奥斯无法控制局势，选择于1456年辞职。这确立了一种延续至十九世纪的模式：辞职之后，再度复位。根纳迪奥斯本人分别于1456、1463及1465年三次辞职。[^p196-27] 这一模式背后，是不同牧首官员集团对职位及其利益的竞争；他们都希望把自己的候选人推上牧首座，以维护既得利益。

十五世纪七十年代，牧首开始对奥斯曼国家承担财政义务，情况进一步恶化。同时代史料彼此矛盾，很难确定这些义务何时、如何产生。不过，清楚的是，作为穆罕默德二世重新聚集君士坦丁堡人口的措施之一，根纳迪奥斯及其直接继任者免缴一切税赋。但随着城市人口逐渐充实，这些豁免逐步调整，并约于1471—1472年取消。[^p196-28]

这一时期，大致与首次提及牧首向苏丹国库纳税的记载吻合，但究竟由哪位牧首开此先例，仍不清楚。倡议似乎并非来自苏丹，更可能最初由围绕牧首座争夺地位的某一派提出。在纷乱的相互指控中，最可信的结论是，责任在特拉比松人共同体。他们的帝国于1461年陷落后，在君士坦丁堡定居，想扶持自己的候选人西缅。据一位匿名编年史家，他们向穆罕默德二世提出支付1,000枚弗罗林，要求罢黜自1466年任牧首的马可·克西洛卡拉韦斯，以西缅取代。苏丹继母、穆拉德二世遗孀、塞尔维亚公主玛拉·布兰科维奇因此出面干预，她也<a id="pdf-197"></a><!-- PDF page 197; original page 176 -->有自己的候选人，即菲利普波利斯都主教狄奥尼修斯。她亲自拜见苏丹，提出2,000枚弗罗林，说服他罢黜西缅，改任狄奥尼修斯。后者任牧首四年，又被西缅取代。此后数十年，这2,000枚弗罗林成为牧首每年向苏丹缴纳的贡金。1483年西缅第三次登上牧首座时，所获贝拉特便规定了这一数额。至耶利米一世就任（1522—1546年），金额已升至3,500枚弗罗林。[^p197-29] 奥斯曼文书称它为 maktu，即定额款项，希腊人则泛称“哈拉吉”（kharadj）。同时代人明确指出，征收数额不断增加，是相关派别为争夺牧首座出价更高的结果。约1500年，人们为这一竞价过程创造了新的希腊词“加价竞逐”（ἐπανέβασις）。[^p197-30]

除年贡外，牧首还开始向苏丹进献“皮什凯什”（pişkeş），即任何从苏丹处获得贝拉特者按惯例所送的礼物；牧首的礼金为500枚弗罗林。这项税费也起源于十五世纪七十年代，通常仅在登上牧首座时缴一次；若新苏丹即位，牧首须取得新的贝拉特，就必须再缴。都主教与主教就任时，也进献礼金，数额依其主教座的重要性而不同。[^p197-31]

牧首对奥斯曼国家的财政义务，严重损害其良好声誉，所谓“世俗显贵”（archontes）对教会事务的干预，也有同样作用。这些人是正教共同体中有影响力的成员。我们已经看到，城市陷落之后，阿德里安堡的显贵曾参与恢复牧首区。牧首区在君士坦丁堡重新建立，并在奥斯曼国家框架内发展为一个小型权力中心后，越来越吸引希腊显要。这部分出于社会声望的考虑，但管理牧首收入，又提供了更实在的回报。穆罕默德二世的希腊秘书德米特里奥斯·阿波卡夫科斯，从阿德里安堡迁往君士坦丁堡，代表牧首<a id="pdf-198"></a><!-- PDF page 198; original page 177 -->狄奥尼修斯一世，掌管牧首教会的财政。牧首感念阿波卡夫科斯的恩情，因为后者在城陷后曾安排将他从奴役中赎出。同时代人确信，只要狄奥尼修斯仍任牧首，牧首财政便会掌握在阿波卡夫科斯手中。[^p198-32]

阿波卡夫科斯这类显贵，通常同奥斯曼财政机构有联系，掌握大量资本，可能参与包税和海关、制盐等国家垄断行业。他们常有亲属改宗伊斯兰教，在奥斯曼国家获得高位。因此，显贵能够为希腊正教教士居间斡旋，有时取得有利结果。然而，这一角色也使他们能够直接干预牧首区的活动与业务，甚至非正式地参与会议。当牧首开始向苏丹纳年贡，便越来越依赖这些显要；他们可以借钱给牧首，也可以作为交换，施压以推进自身利益，而这些利益常与教会理想不相容。牧首区欠玛拉·布兰科维奇7,000枚弗罗林；我们已经看到，她曾向苏丹提出2,000枚弗罗林，期望让自己的候选人登上牧首座。[^p198-33] 随着时间推移、奥斯曼国家索取税赋增加，显贵影响日益扩大，损害了牧首区的地位与声望。[^p198-34]

积极的一面是，这些显贵仍依恋正教传统，帮助希腊文化延续。他们支持学者与教师，维持希腊学校，创建教堂，有些本人也受过良好教育。托普卡帕收藏、年代属穆罕默德二世统治期的希腊文手稿，反映了他们的趣味。臭名昭著的希腊银行家兼商人米海尔·坎塔库泽诺斯，虽属稍晚时期，却是有启发性的例子。尽管绰号“魔鬼之子”（Şeitanoğlu），他仍深度参与牧首区事务。1575年，依苏丹穆拉德三世命令被处死后，他留下了一批非凡的古典及神学手稿。[^p198-35]

持续强调希腊文化，解释了为何十五、十六世纪的大多数牧首来自希腊语地区，最常见的是君士坦丁堡、伯罗奔尼撒或特拉比松。由此，也能理解塞尔维亚人牧首拉斐尔一世（1475—1476年）这一特殊案例。他未获希腊共同体支持，却设法登上牧首座。同时代人竭力强调其族源，称他为塞尔维亚人、保加利亚人、斯基泰人，或干脆称“蛮族”。他们既谴责其酗酒，也批评他不懂希腊语，因而需要翻译。没有希腊显贵支持，拉斐尔无法缴纳苏丹年贡，被投入监狱。这是一则警示故事，表明牧首区远非真正普世，而是明确属于希腊人的机构；这一结果，很大程度上源于显贵的影响。[^p199-36]

依苏丹授予牧首的贝拉特，牧首权威覆盖1453年前隶属普世牧首区各领土上的全部正教居民。当然，其中也包括教会与修道教阶的所有成员；其结构保持不变，即都主教、总主教、主教，牧首及主教的高级官员与职员，司祭，以及修道院长、修士和修女。由牧首与会议选出的都主教、总主教及主教，构成奥斯曼认可的宗教当局，就任时均获贝拉特。奥斯曼行政机构不理会低级教士，即 papades；他们依附都主教与主教，从其手中承包管理堂区教堂。有些资本较多的司祭，能够包领不止一座堂区教堂。在奥斯曼统治下，司祭职业相当经常地世袭。[^p199-37] 都主教、主教与堂区司祭，构成传统教会行政网络。此外，还有由牧首直接任命的特派代表（exarchs），管理散布于普世牧首区辖境内、由牧首<a id="pdf-200"></a><!-- PDF page 200; original page 179 -->直接管辖的村庄、岛屿或小城镇。特派代表一职在拜占庭时期已经存在，十六世纪起更加重要。[^p200-38]

拜占庭时期，国家为教士——包括低级教士——提供固定收入；[^p200-39] 奥斯曼统治下，他们的收入则直接来自信众所纳税费。征收这些税费，是苏丹授予的特权，显然延续了拜占庭称为 kanonikon 的教会税：向一地区居民、司祭和修道院征收，以负担都主教或主教的费用。奥斯曼时期，税收机制呈金字塔形：底层是普通信众，顶层是普世牧首。税收不仅供养教士，也用于履行对奥斯曼国家的财政义务，即都主教、主教和牧首为贝拉特支付的授职礼金，以及牧首向苏丹缴纳的年贡。人们反复向信众提起这些义务，以证明征税合理。苏丹贝拉特也提到这些税费，但强调其属自愿，不得强迫任何人违背意愿缴纳。然而，所有教会税最终都成为定期、强制的负担，还引入新税，如教士受职时向主教缴纳的受职金（embatikion），以及一种特别献礼（philotimon）。此外，教会还向集市征税。[^p200-40]

牧首税的征收，有时招致都主教与主教反对。在这种情况下，牧首会请求苏丹干预；只要苏丹认为税收合法，便提供必要支持。若牧首区财政陷入严重困难，牧首便组织特别巡行，亲自收税。这时，他须获得苏丹特别文书，命令奥斯曼地方当局协助足额征收欠款和本年度税款，不接受欠款人的任何借口。巡行期间，牧首<a id="pdf-201"></a><!-- PDF page 201; original page 180 -->有显贵陪同、协助。[^p201-41] 此外，为开辟新收入来源，牧首开始组织范围更广的巡行，前往奥斯曼疆界之外、却有正教人口的地区，如多瑙河诸公国。[^p201-42] 遗憾的是，留存的零散信息，远不足以确定牧首究竟从教士处收取多少税款。会议关于这些事务的决议，又常被修改或撤销，更难得出哪怕略有统计效力的结论。[^p201-43] 唯一确定的是，数额依各地主教座繁荣程度而不同。

除常规与特别税收之外，牧首另有收入来源。按贝拉特规定，他负责监督都主教、主教、修道院长乃至司祭的财务管理，包括在当地教堂主保圣徒节日举办集市等一般活动。教士管理的葡萄园、水磨、田地、园圃，甚至圣泉（hagiasmata），也在牧首职权之内。修道院仍拥有相当重要的地产，有时具有完全所有权（mülk），但更多只是使用权（tasarruf）。通常，修道院长管理院产，但本人受牧首直接管辖。都主教座、主教座及堂区教堂，也有地产。牧首似乎从其农业产出中取得十分之一。他还可能继承未留继承人或遗嘱的司祭、修士的财产。[^p201-44] 牧首及所有教士的另一收入来源，是洗礼、婚礼等宗教仪式完成后收到的礼物。

奥斯曼帝国的都主教与主教，收入依赖希腊正教人口，因此，他们只能设驻于<a id="pdf-202"></a><!-- PDF page 202; original page 181 -->希腊正教共同体人数足以承担主教座费用的城镇。理论上，这些主教座数量相当多，因为普世牧首区仍将某些已无实际任职者的都主教座名称，用作荣衔。例如，十六世纪威尼斯希腊正教共同体的教堂，享有早已停止运作的菲拉德尔斐亚都主教座的地位与称号。统计教会主教座时，奥斯曼文书更为可靠，因为其主要目的十分务实，即登记教士的财政义务。现存最早列举主教座的奥斯曼文书，年代为1483年，载57处；下一份来自1525年，减至50处。然而，一份1641—1651年间、逐项列出向苏丹国库缴纳授职礼金数额的都主教座和主教座清单，仅载40处。[^p202-45] 这可能夸大了衰落程度，因为当时更多使用牧首特派代表制度，而他们似乎不向苏丹缴纳授职礼金。即使奥斯曼文书不准确、不完整，也不能忽略其中所记主教座数量的减少。乍看之下，它似乎表明希腊正教人口显著下降。若确实如此，这发生在1530至1580年奥斯曼人口大幅增长之后，随后出现普遍衰退。希腊正教人口受打击尤其严重，因为十六世纪末经济危机促成的改宗伊斯兰，又加剧了人口下降。基督徒因贫困而无力缴纳非穆斯林特别税，大规模改宗便成为一种出路。[^p202-46]

面对改宗伊斯兰带来的物质吸引，正教教士手段有限：改宗可免除非穆斯林税赋，摆脱齐米身份的屈辱，并开启社会晋升机会，甚至可能进入统治阶层。面对这些诱惑，教士只能坚持，坚守旧有信仰才是得救的唯一保证；他们也不忘宣传<a id="pdf-203"></a><!-- PDF page 203; original page 182 -->背弃伊斯兰教的刑罚是死刑，以加强这一讯息。土耳其统治时期正教圣徒传偏爱的母题，是基督徒改宗伊斯兰后，悔悟归回原信仰，遂在穆斯林手中殉道。这是一个古老主题，可追溯至阿拉伯征服初期，即改宗开始威胁东方正教会之时。860年在巴勒斯坦拉姆拉殉道的基督徒阿拉伯人阿卜杜勒·马西赫的传记，是很早的例子。他生为基督徒，加入阿拉伯军队，与拜占庭作战；后来悔悟，向司祭告罪，先到耶路撒冷外的圣萨瓦修道院避难，继而前往西奈山圣凯瑟琳修道院，并成为院长。他重返基督教的事最终被发现，遭拷打、处死。[^p203-47] 土耳其统治下，改宗伊斯兰者再次增多，这一模式重现；人物、时间和地点改变，情节却相同。十四世纪初，拜占庭贵族学者狄奥多若·梅托希提斯所写的《年轻圣米海尔传》，便是一例。米海尔幼时被俘，带往埃及，改宗并加入马穆鲁克军队，后来因悔恨重返基督教，最终殉道。年轻圣狄奥多若的故事十分相似，却反映奥斯曼征服南巴尔干时，土耳其人征集基督徒男孩服军役的情形。狄奥多若尚是孩子，便在色雷斯被土耳其人俘获，带到小亚细亚，与许多希腊少年一样改宗伊斯兰。他后来意识到错误，在梅拉吉纳被焚烧殉道。然而，奥斯曼征服完成很久以后，这类殉道仍在继续。十七世纪克里特人年轻圣马可便是例子：他改宗伊斯兰后又背弃，于1643年5月在伊兹密尔被焚烧殉道。[^p203-48] 正教会用这些殉道事迹警告信众，改宗伊斯兰具有危险：这种行为必然引起悔恨，而悔恨只能通过殉道得到平复。

<a id="pdf-204"></a>
<!-- PDF page 204; original page 183 -->

对正教会地位的另一威胁，来自日益强大的奥斯曼宗教学者集团——乌莱玛（‘ulema）。在“壮丽者”苏莱曼统治初期（1520—1566年），问题达到顶点。奥斯曼神学家主张，君士坦丁堡并未和平投降，而是抵抗后被武力攻占，因此依伊斯兰圣法，当地正教居民无权享有现存权利。严格说来，他们及其子女应被降为奴隶，教堂应改成清真寺。[^p204-49]

一位高官将神学家的决议与计划详情告知牧首狄奥莱普托斯一世，后者立即求助相当熟识的大维齐尔，恳请其为正教共同体干预。消息传开，首都希腊共同体大为惊恐。牧首与大维齐尔秘密会面，协调行动。向奥斯曼行政机构许多高官赠送厚礼后，牧首在两位显贵陪同下，亲自出席苏丹议政会议。遵照大维齐尔建议，他解释说，拜占庭首都是有条件地向穆罕默德苏丹投降的，苏丹因此给予居民特殊特权。随后，他被要求提供证人佐证。牧首请来两名住在阿德里安堡、自愿赴伊斯坦布尔作证的人；据称，他们都是102岁的耶尼切里老兵，曾在围攻拜占庭首都的苏丹军队服役。牧首再次出席议政会议，这回由两位德高年迈者陪同；他们立即证实，拜占庭首都曾和平投降。苏丹听后，拒绝考虑神学家的建议，重新确认正教会及共同体原有特权。[^p204-50]

这一叙述未必完全真实，却包含事实内核。穆斯林神学家重新审视如下问题，是很自然的：七十年前被武力夺取的奥斯曼首都，为何如今仍有繁荣的希腊人口，并拥有若干教堂？这一<a id="pdf-205"></a><!-- PDF page 205; original page 184 -->事件也揭示了当时牧首区充满自信的精神状态。牧首被描绘成能够凭外交技巧、行贿手段及宫廷人脉，成功化解最困难局面的人物，完全值得共同体最热情的支持。与此同时，似乎逐渐形成一个传说：君士坦丁堡，或至少其中一部分，并非被武力攻取，而是在谈判后向土耳其人投降。它旨在为牧首区与希腊共同体，在奥斯曼统治体制内提供更高程度的合法性。十七世纪著名奥斯曼旅行家埃夫利亚·切莱比也知道这一传说。他写道，金角湾希腊渔民享有穆罕默德苏丹给予的特权，因为他们曾将阿亚门至费内尔门之间的街区交给苏丹。[^p205-51]

乌莱玛未能剥夺希腊共同体的特殊地位，表明普世牧首区已在何等程度上成为奥斯曼体制的一部分。1525年，苏莱曼一世授予狄奥莱普托斯的继任者、牧首耶利米一世（1522—1546年）的贝拉特，尤为鲜明地体现这一点。在特别强调伊斯坦布尔荣耀的事由陈述部分，苏丹解释，任命牧首，不仅为了监督基督徒的宗教习俗，也为了向奥斯曼帝国外的地区任命都主教与主教，如希俄斯、克里特、瓦拉几亚、摩尔达维亚和俄国；这些地区的正教基督徒需要都主教或主教时，会求助于驻在受上帝保护的奥斯曼首都的普世牧首。[^p205-52] 在某种意义上，牧首行使着与苏丹并行的权威。1517年，奥斯曼征服叙利亚与埃及，使安提阿、耶路撒冷和亚历山大里亚三东方牧首区同受奥斯曼统治，进一步促进了这一局面。在灵性与教义事务上，它们名义上一向服从普世牧首区权威，如今则受到更有效的控制。普世牧首在这方面获得苏丹支持，因为牧首权威的地理范围扩大，也会提高奥斯曼首都的声望。这也许并非巧合：正如西欧人称苏莱曼一世为<a id="pdf-206"></a><!-- PDF page 206; original page 185 -->“壮丽者”，希腊人也把同一称号给予他统治下的一位牧首约阿萨夫二世（1554—1565年）。[^p206-53]

始终存在的，是君士坦丁堡牧首区与罗马的不和。1483—1484年，牧首西缅一世主持一次“普世”会议，废除了1439年在佛罗伦萨签订的教会合一。[^p206-54] 十六世纪中叶，据称牧首狄奥尼修斯二世（1546—1556年）批准凯撒利亚名衔都主教米特罗法内斯访问梵蒂冈；会议对此严厉责斥牧首，他能保住职位已属幸运。[^p206-55] 1582年，教皇格里高利十三世派威尼斯人利维乌斯·切利尼赴君士坦丁堡；除其他任务外，他拜访耶利米二世，解释教皇不久前实行、此后以其名字相联的历法改革。牧首含糊应对，既显出宗教保守，也显出对罗马的传统猜疑。[^p206-56]

另一方面，牧首们与新教徒建立联系。奥地利使馆的路德宗随行牧师施特凡·格拉赫，在君士坦丁堡居住五年（1573—1578年），充当路德宗与耶利米二世之间的中介。虽然这些接触未在神学层面产生积极结果，却促成马丁·克鲁修斯的《土耳其希腊志》（Turcograecia），使西欧人了解“被囚禁的大教会”所面对的问题。[^p206-57]

耶利米二世的个人作用，主导了十六世纪后半叶的牧首区历史。[^p206-58] 尽管任期屡遭困扰，两度被罢免，他仍活跃于国际舞台，是首位访问欧洲东北部的普世牧首。他远赴波兰及莫斯科罗斯，意图在当地因宗教问题分裂的民族之间调停。旅程的高潮，是建立新的俄罗斯正教牧首区，以莫斯科为驻所；耶利米<a id="pdf-207"></a><!-- PDF page 207; original page 186 -->在1588年返程途中，曾停留于此。翌年，君士坦丁堡牧首会议与安提阿牧首约阿希姆、耶路撒冷牧首索弗罗尼奥斯五世，共同批准这一重大事件。这意味着，一个地域辽阔、人口众多国家的宗教当局，正式承认了普世牧首区的灵性领导。[^p207-59]
