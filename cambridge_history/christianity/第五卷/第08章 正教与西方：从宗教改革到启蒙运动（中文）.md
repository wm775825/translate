# 第8章 正教与西方：从宗教改革到启蒙运动

帕斯哈利斯·M. 基特罗米利迪斯

1453年这一剧变的历史界标，结束了东西方基督教之间的神学与哲学接触。十四世纪及十五世纪初的知识联系和交流，曾将经院哲学引入拜占庭，并使东方的拉丁语知识在有限程度上复兴。欧洲文化中的希腊语地区，以君士坦丁堡、米斯特拉和特拉比松为中心，加上威尼斯统治的克里特与塞浦路斯，都经历了各自形式的十五世纪文艺复兴。1453年之后，这种文化的幸存者在西方避难，为西方文艺复兴作出独特贡献。东方在奥斯曼统治下，教会、文化与灵性生活却转向根本不同的方向。征服使希腊语正教世界封闭近一个半世纪，中断了与西方文化的一切交流。离去的人几乎从不返回，与正教世界分享其经验所得。正教与西方的联系，主要掌握在耶稣会等拉丁传教士手中；正教徒将其宗教、教育和政治活动，谴责为西方无端的侵入。双方对抗尤其尖锐的一幕，发生于巴勒斯坦圣地监护权之争。方济各会与正教圣墓兄弟会的敌对，在十七世纪激烈到成为欧洲外交问题：法国支持天主教事业，耶路撒冷正教牧首则向俄罗斯沙皇，以及瓦拉几亚、摩尔达维亚等地的正教诸侯，寻求支持与保护。[^p208-1]

天主教对正教的另一压力，来自教皇格里高利十三世于1581年在罗马建立圣亚他那修希腊学院。其正式目的，是把来自正教东方的青年培养为教士和教师，再让他们返回原籍服务。改宗天主教，以及成为促使东方各教会最终与罗马合一的人员，是训练不可分割的一部分。为便利这一过程，希腊学院及其校友，与欧洲正教地区合一派教会的发展紧密相联。罗马希腊学院对学术发展贡献甚大，培养了两位在希腊学术和文学中留下印记的重要作者：莱昂·阿拉提奥斯（1587—1668年）与涅奥菲托斯·罗迪诺斯（1576/77—1659年）。由于这类学者通过写作或传教——罗迪诺斯则两者兼有——为西方教会从事宣传，正教徒将希腊学院视为敌对机构；它的运作，进一步疏远了正教与天主教。[^p209-2]

## 正教与新教的对话

以上便是十六世纪之交，正教对中欧新教教会表现出好奇和一定开放态度的广阔背景。双方共同敌视天主教，是促使正教徒与新教徒接近、尝试彼此理解的重要因素之一。史料记载的首次倡议，发生于1558年：君士坦丁堡牧首“壮丽者”约阿萨夫二世，派帖撒罗尼迦人辅祭德米特里奥斯·米索斯前往维滕贝格，搜集新教教导的资料。这一使命使宗教改革领袖之一、希腊学家菲利普·梅兰希通，得以于1559年致信牧首，概述新教基督徒的基本信仰。为了让牧首了解得更充分，他随信附上希腊文版《奥格斯堡信纲》。信中，他先感谢上帝，使东方基督教会在如此多的不幸中得以保存，并向牧首保证，新教基督徒虔诚遵循《圣经》、历次大公会议教规<a id="pdf-210"></a><!-- PDF page 210; original page 189 -->以及希腊教父的教导。他还说，他们拒绝无知拉丁修士的迷信，恳请正教牧首不要理会真理之敌对新教基督徒的诽谤。[^p210-3]

德米特里奥斯·米索斯将梅兰希通的信和《奥格斯堡信纲》译本送到君士坦丁堡，但牧首与会议大概并未被新教徒自称的“正统”所打动，避免作答。1560年梅兰希通去世后，新教徒与君士坦丁堡牧首区的直接联系，中断十余年。不过，正教世界开始感受到新教影响。经特兰西瓦尼亚、瓦拉几亚与摩尔达维亚诸公国，新教关于教授《圣经》的思想传入正教世界。德国宗教艺术对十六世纪后拜占庭绘画的影响，尤其值得关注；阿索斯山迪奥尼修修道院食堂外墙著名的《启示录》循环，便体现了丢勒与老卢卡斯·克拉纳赫版画的影响。[^p210-4]

“壮丽者”约阿萨夫任内未果的接触，在耶利米二世·特拉诺斯第一次任牧首期间（1572—1579年），获得了更为实质性的后续。这次倡议并非来自维滕贝格，而来自图宾根。契机是1573年，杰出路德宗学者施特凡·格拉赫获任驻伊斯坦布尔奥地利使馆随行牧师。他带来图宾根大学两位著名教授——大希腊学家马丁·克鲁修斯与神学家雅各布·安德烈埃——写给耶利米牧首的两封信。由此开始了牧首与图宾根教授之间的通信，一直持续至1581年，超过牧首的第一任期。图宾根教授共写八封信，牧首回信五封。除信件外，新教教授还寄来六份《奥格斯堡信纲》，收件人包括牧首、后来成为普世牧首的贝罗亚都主教米特罗法内斯、牧首学院院长狄奥多西奥斯·齐戈马拉斯，以及另一位资深学者、后来取得菲拉德尔斐亚名衔都主教职位而居于威尼斯的加布里埃尔·塞韦罗斯。最后一份<a id="pdf-211"></a><!-- PDF page 211; original page 190 -->则寄给教会富有的平信徒赞助者米海尔·坎塔库泽诺斯。显然，图宾根教授正为自己的观点争取正教舆论。双方以希腊语通信，留存信件极好地记录了教义交流中的神学思考水平。教授概述新教教义时，强调两教会的一致之处：共同信仰唯一救主耶稣基督，接受《圣经》作为信仰基础。他们补充说，正教与新教教会的分歧，属于次要问题；牧首在回信中却强调分歧，指责新教徒引入新说。他强调，正教信仰不仅建立于《圣经》，也建立于大公会议与教父，警告单靠《圣经》的信仰可能导致谬误。1575年，牧首在约翰·齐戈马拉斯及其他正教神学家协助下，撰写《奥格斯堡信纲》的驳论，寄给新教神学家。通信延续至耶利米第二任期（1580—1584年），但1581年，牧首要求图宾根教授不要再以教义问题烦扰他，因为他们丝毫不愿遵从教会真正教导，尤其对于口头尊重、行动却不尊重的教父。牧首以如下建议结束通信：新教教授若愿，可以出于友谊给他写信，却不要再以教义打扰。[^p211-5]

这些早期的试探与相互了解，并未在正教会留下重大印记。宗教改革史早期，两教会交流最伟大的成果，是马丁·克鲁修斯于1584年在巴塞尔出版的巨著《土耳其希腊志》。这是十六世纪形成的有关正教会、希腊文化及语言状况最重要的史料，至本书成书时，仍是这些主题取之不尽的信息宝库。耶利米二世任内的早期接触，体现了对新教徒的怀疑，而非<a id="pdf-212"></a><!-- PDF page 212; original page 191 -->正教与天主教交往中常见的不安全感，甚至敌意。十七世纪初，在牧首基里尔一世·卢卡里斯任内经历极具戏剧性的事件后，对新教的态度才会改变。不过，在转向这一充满争议、最终以悲剧结束的故事之前，有必要先将正教与西方的关系，置于君士坦丁堡陷落后一个半世纪中，教会适应奥斯曼统治的历史之内。

## 1453年之后的正教会

1453年的征服，摧毁了正教会作为君士坦丁开创的基督教帝国机构的存在形式。教会不再通过傅油和加冕，为世俗之剑的掌握者赋予合法性，也不再以灵性引导使尘世秩序神圣化。它转而尝试适应伊斯兰秩序，接受奥斯曼王朝的主权，忠诚服从现存非基督教权力。作为交换，牧首及高级教士等教会领袖得到伊斯兰国家认可，却并非作为受统治基督徒人口的制度性代表，而是以个人身份，作为奥斯曼国家行政代理人，负责监督“不信者的错误宗教习俗”。[^p212-6] 正教宗教领袖必须以这一身份履行职责；对国家而言，这包括确保苏丹的基督徒臣民忠诚顺服，定期征收、上缴税款。在政治服从、制度地位含混的总体安排中，以普世牧首为首的教阶，努力在基督徒共同体内保存教会组织、宗教实践和灵修传统。在几个世纪非基督教统治的变迁中维系信众、保存自身，直到十九世纪中叶奥斯曼改革最终承认其为代表正教社会的集体机构，这些成就并不微小。它们既反映集体记忆的力量与教会内部社会教化机制的效力，也反映昔日新罗马基督教帝国<a id="pdf-213"></a><!-- PDF page 213; original page 192 -->象征遗产的持久力量。为确保生存，教会必须尽力履行牧灵、慈善及教育任务。

根纳迪奥斯二世·斯科拉里奥斯受征服者穆罕默德任命为牧首后，最先采取的行动之一，是在君士坦丁堡重建高等学校；这一点颇有意义。在这所牧首学校中，基督教学问、希腊语培养，以及某种人文典籍训练，都服务于文化传统的延续，力求不论教会在政治秩序中的制度地位如何含混，都能保障其生存与连续。[^p213-7] 然而，反常地位的代价沉重。“监督不信者错误宗教习俗”的职位，是可由出价最高者取得的行政职务，成为教阶高层持续动荡的根源。买卖圣职与腐败，是无法避免的后果。1454至1600年间，牧首座至少更换36次，涉及24人；任期往往只有数月，甚至数周。这又引发其他问题：纷争与暗中攻击，与其说使信众震惊，不如说助长了国家贪欲，损害教会。最富戏剧性的表现，是教堂不断被没收、改作清真寺，成为教士与信众持续痛苦的根源。这一做法于1586年达到顶点：牧首区被逐出至福圣母修道院，牧首自1456年以来一直以此为驻所。流放罗得岛的耶利米二世，于1586年返回伊斯坦布尔，却发现自己悉心装饰的牧首教堂已变为清真寺；编年史家记道：“他便痛哭。”[^p213-8] 十六世纪末，正教共同体普遍绝望、士气低落，也反映于牧首学院的状况，当时教学几乎停止。[^p213-9] 这种危机与衰落，是基里尔一世·卢卡里斯登场时教会处境的广阔背景。基里尔六度登上金口约翰的牧首座，开启了教会的风暴时期；尤其第二至第六次任期，跨越1620至1638年。他是四位伟大的<a id="pdf-214"></a><!-- PDF page 214; original page 193 -->奥斯曼时期牧首之一，与根纳迪奥斯二世、耶利米二世和约阿希姆三世并列。他是一位富有才华、感召力和远见的人物，登上牧首座时，已具有更新教会、重振信仰的策略。

## 基里尔·卢卡里斯：一位新教牧首？

基里尔于1572年生于克里特坎迪亚（伊拉克利翁），原名君士坦丁·卢卡里斯。[^p214-10] 他接触了威尼斯统治晚期岛上的人文主义文化，但家庭对正教的强烈虔敬，使他走向独身修道生活。他可能在克里特最重要的正教机构安加拉索斯修道院开始初修；其兄弟马克西莫斯后来担任该院院长（1619—1641年）。年轻的卢卡里斯是个不安于现状的人，终生如此。他在威尼斯继续学业，受教于基西拉主教马克西莫斯·马尔古尼奥斯，后者在神学教导中坚定捍卫正教、反对天主教。君士坦丁还进入帕多瓦大学，随切萨雷·克雷莫尼尼学习新亚里士多德哲学。他于1595年毕业，同年年底在君士坦丁堡，由表亲、亚历山大里亚牧首梅勒提奥斯·皮加斯按立为辅祭和司祭；皮加斯也曾是安加拉索斯兄弟会成员。按立后不久，基里尔随牧首参加耶利米二世于1596年在君士坦丁堡召开的会议。会议谴责1595年布列斯特—立托夫斯克地方会议表决通过的正教与天主教“虚假合一”，并派两名特使赴波兰，将君士坦丁堡与亚历山大里亚牧首区的决定告知波兰国王西吉斯蒙德三世，参加布列斯特—立托夫斯克第二次会议。代表亚历山大里亚的特使之一，就是卢卡里斯。这次旅行，为他终生反对耶稣会的斗争作了准备。他与在波兰、立陶宛同受迫害的新教徒结成共同阵线，奠定了与新教接近的基础。至1600年，他至少两次长期出使波兰、乌克兰和立陶宛，为当地正教事业工作。他重组维尔纳正教学校，又在利沃夫创办一所。1600年正教遭严酷迫害时，他几乎<a id="pdf-215"></a><!-- PDF page 215; original page 194 -->丧命，君士坦丁堡教会的特使尼基弗鲁斯则失去生命。1601年，皮加斯去世后，年仅三十岁左右的卢卡里斯，当选亚历山大里亚牧首。他居于正教会地位第二的牧首座，继续反对拉丁人在正教地区的宣传。1612年，他再赴俄国西南部，途中停留伊斯坦布尔。涅奥菲托斯二世被罢黜后，普世牧首区会议请他暂代君士坦丁堡牧首。他同意并任职一个月，却发现若正式当选普世牧首，附带的财政义务过于沉重，于是辞职，继续前往俄国。

1614年返回亚历山大里亚后，卢卡里斯仍为天主教徒在东方不懈劝人改宗的活动深感困扰。他制定捍卫正教的总体策略，争取欧洲新教势力，构建反对罗马的共同阵线。这一早期阶段，他转向英国，与先后两任坎特伯雷大主教乔治·阿博特、威廉·劳德通信。主要成果，是圣公会为亚历山大里亚教会的一位教士提供奖学金，赴牛津接受神学训练。1617年，米特罗法内斯·克里托普洛斯因此来到英国，停留五年；其秘密任务，是争取正教与圣公会可能的合一。他后来游历欧洲其他新教地区，似乎也由这一动机驱使。[^p215-11] 克里托普洛斯旅行期间，牧首在亚历山大里亚忙于同著名新教学者与高级教士通信，包括荷兰神学家兼政治家大卫·德·威廉，以及居住伦敦时改宗新教的斯帕拉托大主教马尔坎托尼奥·德·多米尼斯。这批信件很重要，因为它显示，卢卡里斯深受本教会实践所困扰，认为其中一些做法陈旧、迷信，远离真正的基督教信仰。他渴望回到以《圣经》和圣灵权威为基础的“福音单纯”。他批评自己在耶路撒冷见到的正教信众行为，认为近乎偶像崇拜；也对希腊与拉丁教会赋予教父过多权威表示疑虑，坦言自己觉得<a id="pdf-216"></a><!-- PDF page 216; original page 195 -->宗教改革的教义，比正教与天主教教义更符合《圣经》精神。[^p216-12]

这些关切反映了卢卡里斯更深的灵性与教会焦虑，源于基督徒良知的要求，以及身为使徒继承者，对广大羊群信仰状况的责任感。这种强烈的牧灵责任伴随他来到君士坦丁堡。1620年11月4日，会议投票推举他登上普世牧首座，基里尔一世的任期由此开始；会议称他“以德行与智慧著称”。[^p216-13] 此后虽有短暂中断，他任职至1638年。这是相对较长的一段牧首任期，不仅以广泛的牧灵、行政工作为特点，也以其在真正泛欧洲范围内，推行抵抗天主教对正教世界持续压力的总体策略为特点。[^p216-14]

后世评价卢卡里斯在希腊东方与正教史上的地位，几乎一味强调其反罗马总体策略的政治面向。这一策略以正教和新教结盟为前提，最终却使牧首成为新教势力的囚徒。这种评价相当狭窄，而且明显片面，暴露了提出者的西方背景，以及主要将他视为政治人物、而非教会人物的兴趣。更完整的视角，还须纳入他在教会内部为各领域注入新生命的繁忙工作。国际政治并非基里尔唯一、甚至首要的关切；与新教结盟反对罗马，只是其保护和复兴正教会政策的一部分，旨在走出十六世纪末的危机与衰落。教会复兴才是首要目标，新教联盟是捍卫正教的重要武器，而非目的本身。

基里尔任期的记录，清楚体现其政策深层的正教动机。少有牧首颁发如此多的会议敕令与其他牧首文书，反映其改革精力；这些努力用于改革或重建<a id="pdf-217"></a><!-- PDF page 217; original page 196 -->修道院、封圣、解决主教管辖权问题，以及主持宗教书籍出版。[^p217-15] 这些活动构成了教会传统牧灵工作的实质。他还采取另外两项重大倡议。首先，他请来帕多瓦旧同学狄奥菲洛斯·科里达莱夫斯，重组、提升奄奄一息的牧首学院。[^p217-16] 这位杰出的新亚里士多德主义者认真执行牧首委托，自1624年起重新设计课程，在宗教与希腊学问之外，加入拉丁语与哲学。他开创的新亚里士多德主义传统，经弟子传播到希腊东方的其他重要学校，成为巴尔干基督教各民族共同的哲学教育，直至一个半世纪后启蒙运动到来。科里达莱夫斯不可避免地同当时保守的教育当局冲突，也分享了牧首的动荡遭遇与失败命运。

基里尔第二项重大倡议，具有真正革命性：首次将印刷机引入伊斯坦布尔，为信众需要出版宗教作品。1627年，他邀请在伦敦学习印刷术的凯法利尼亚人尼科德莫斯·梅塔克萨斯，在君士坦丁堡建立印刷所。在英国大使托马斯·罗伊爵士帮助下，印刷机被运入土耳其，设在英国使馆附近，以求保护。这是希腊世界第一台印刷机。在牧首监督下，它开始印行宗教书籍，多为反天主教论著。然而，数月之后，耶稣会在法国驻奥斯曼大使塞西伯爵协助下，煽动耶尼切里士兵洗劫印刷所；他们未能逮捕梅塔克萨斯，便摧毁印刷机。[^p217-17]

随后十年，君士坦丁堡牧首与罗马教会展开全面斗争。1628年7月，教皇乌尔班八世亲自主持传信部会议，决定不懈打击牧首，直至将其除去。[^p217-18] 为求支持，基里尔不得不依赖驻伊斯坦布尔的新教徒大使，包括英国、奥地利和荷兰大使。这些驻奥斯曼朝廷的大使，<a id="pdf-218"></a><!-- PDF page 218; original page 197 -->尤其是英国的托马斯·罗伊爵士及其继任者彼得·威奇爵士，以及荷兰的科尔内利乌斯·哈加，支持基里尔应对耶稣会及后来嘉布遣会的阴谋。牧首的敌人指控他不忠，将其牧灵工作说成出于政治动机，试图使奥斯曼当局转而反对他。他们还指控他属于异端，夸大其新教倾向，煽动会议内部分裂，希望将其罢黜。比宗教论据更有效的，是大量钱款；这些钱帮助同名的贝罗亚都主教基里尔·孔塔里斯，在会议中建立反对卢卡里斯的派别。

1627年末，罗伊离开君士坦丁堡。基里尔交给他一份真正配得上国王的临别礼物，献给其君主查理一世：一部称为《亚历山大抄本》的《圣经》手稿。同时，信奉新教的奥地利大使屈夫施泰因，被一名天主教徒取代。因此，基里尔的主要支持者只剩荷兰大使哈加。然而，牧首很快成为支持者的囚徒。作为支持的交换，哈加与荷兰使馆牧师安托万·莱热——两人都是坚定的加尔文主义者——施压牧首，要求在教会中引入新教措施和教导。支持的代价，具体表现为由牧首发布一篇基督教信仰告白。有人认为，文本由日内瓦加尔文派牧师起草，经莱热修订，使之显得更接近某些正教教义要求，再呈交牧首签署。基里尔似乎又作了若干修改，并于1629年签署。同年，拉丁译本在日内瓦以《君士坦丁堡牧首基里尔基督教信仰告白》为题出版，随后出现英、法文译本。标题明确说，告白得到东方教会其他牧首同意。1633年，希腊文版也问世。[^p218-19]

这篇《告白》相对简短，由18条组成，后附四组问答，涉及基督教信仰基本原则。[^p218-20] 正文<a id="pdf-219"></a><!-- PDF page 219; original page 198 -->18条或章中，三条，即第1、6、7条，在三一、道成肉身、原罪及其传递等基本教义原则上，完全符合正教。然而，许多其他条款，如第2、3、9、17条，在《圣经》、教父和会议传统的权威，教会论、预定论、唯独恩典称义、圣事数量及圣餐等问题上，完全呈现新教面貌。其中，第2与第17条关于《圣经》权威和圣餐的观点，完全出于加尔文主义。另一些条款，尤其第4、5、8、16、18条，对正教传统较为调和；其措辞可容纳正教对于《圣经》神圣默感、创造、护理、圣徒与圣像、洗礼及死后生命等问题的感受。关于读经与圣像的第1、2、4问，也是如此。第3问关于《圣经》正典，却是激进的加尔文主义：将《旧约》卷数减至22卷，同时完整接受《新约》。

《告白》出版，引起罗马天主教界震怒，也使正教徒深感忧虑。牧首本人从未明确承认自己是作者，但直到去世，也没有通过会议决议或书面形式，正式否认或谴责署其名出版的《告白》。所谓“卢卡里斯信仰告白”的作者身份，至本书成书时仍未解决、备受争议。当时及后来正教界的主流看法，是加尔文派出版时冒用了牧首姓名。同时代人的反应支持这一点。基里尔仍获亚历山大里亚牧首格拉西莫斯·斯帕尔塔利奥提斯忠实支持，尽管后者拒绝了加尔文派于1628年提出的教会合一试探。耶路撒冷牧首狄奥法内斯同样深信基里尔正统，于1630年从雅西致信俄罗斯正教徒，予以保证。当然，新教徒，尤其哈加身边的加尔文派和日内瓦牧师，以为宗教改革终于将在东方教会展开，但这种热情并无根据。

虽然被逐出伊斯坦布尔，耶稣会仍于1634年在法国大使马尔什维尔支持下，说服卢卡里斯的私敌、贝罗亚都主教基里尔·孔塔里斯，在会议中发动反抗，暂时罢黜牧首。会议几乎立即使他复位，但1635年5月，他又因孔塔里斯而被逐，流放希俄斯与罗得岛。然而，1637年4月，他再次回到普世牧首座，开始最后一次任期。1630至<a id="pdf-220"></a><!-- PDF page 220; original page 199 -->1637年间，君士坦丁堡会议三次罢黜、重新选举基里尔。杰出的君士坦丁堡教会史家曼努埃尔·格德翁认为，会议坚持使卢卡里斯复位，使其共有五次任期——若计入1612年暂代，则为六次——具有决定性意义：最有资格作判断的机构，即君士坦丁堡牧首区教阶，确认他信仰正统，认可他对本教会教义与传统的忠诚。[^p220-21] 然而，教会危机深重。1637年8月17日，基里尔致信日内瓦共和国及教会的牧师、参议员和执政者，感谢他们支持正教，同时哀叹教会遭耶稣会及敌人孔塔里斯围攻；后者已向土耳其人支付20,000塔勒，企图罢黜他。但牧首信靠基督：“主若是我的光明与救主，我还怕谁？主是我生命的护卫。”[^p220-22]

尽管牧首忠诚、斗志旺盛，逆境最终仍无法克服。次年，即1638年6月，他因被控秘密联络俄国人而遭逮捕；俄国人不久前刚从奥斯曼手中夺取亚速。他以叛国罪受到草率审判，于6月27日被处死。依英国驻士麦那领事保罗·赖考特所言，卢卡里斯戏剧性人生的这一悲剧结局，使罗马教廷付出了50,000克朗。[^p220-23] 孔塔里斯终于以基里尔二世之名继任普世牧首，但只在1638—1639年间任职数月。他有足够时间召集会议，谴责卢卡里斯为异端告白作者；这使他在加拉塔耶稣会学校的旧日教师大为满意。然而，正教会后来于1638、1642、1672、1691年在君士坦丁堡、1642年在雅西及1672年在耶路撒冷召开的会议，都谴责《告白》为异端，却没有将基里尔一世谴责为其作者或加尔文主义者。[^p220-24] 尽管缺乏确证，使作者问题至本书成书时仍未解决，正教界对于谴责《告白》本身却意见一致。天主教传统中，对它的漫长论战持续不息；罗马天主教神学家指责正教接纳新教，因为<a id="pdf-221"></a><!-- PDF page 221; original page 200 -->正教没有谴责卢卡里斯本人。为回应这些批评，基辅都主教彼得·莫吉拉撰写另一篇正教信仰告白，获四位正教牧首批准，于1667年在阿姆斯特丹出版。

尽管史料庞大、学术争论广泛，要对卢卡里斯立场作最终判断，仍是历史学家面临的未决挑战。毫无疑问，他与西方的接触、对教会状况的批判认识，以及归根结底，其基督教信仰本身，激发了通过信仰更新重振正教的真诚愿望。在这一寻求中，卢卡里斯似乎完全在个人层面，对新教思想有所试探。但身为牧首，他甚至考虑偏离严格正教，将新教观点强加于正教会的可能性，看来很低。在这一点上，现代学院神学家与历史学家，同表达正教会真实态度的早期编年史家判断一致。[^p221-25] 那么，宗教改革对卢卡里斯意味着什么？如何影响其牧灵态度、教会策略，以及正教会愿景？看来，在危机、衰落与天主教持续压力之时，他在宗教改革中看到的，不仅是反天主教盟友，也是重建正教的模式与挑战。卢卡里斯从未承认宗教改革——包括加尔文主义版本——自称正统的主张，却承认它开辟了基督教更新的路径。因此，在基督教实践的某些方面，他愿意追随新教的先行；他祝福将《新约》译为现代希腊语，便是一例。

这项翻译，也许是牧首最重要的牧灵倡议。1629年，任务交给加利波利的博学司祭修士马克西莫斯·罗迪奥斯，故亦称卡利乌波利提斯。他曾在牧首学院从学科里达莱夫斯，忠实追随卢卡里斯。翻译期间，马克西莫斯住在荷兰使馆，与莱热密切合作，以迪奥达蒂的现代意大利语《新约》为范本。1632年，荷兰大使已向本国政府报告译文完成，但仍须对原文修订。然而，马克西莫斯于1633年9月24日意外去世，未完成最后润饰。剩余工作留给莱热与卢卡里斯本人，但日内瓦的出版一直<a id="pdf-222"></a><!-- PDF page 222; original page 201 -->延至1638年；悲剧性的是，那已是基里尔去世数月之后。[^p222-26]

在其他牧灵与行政工作中，牧首始终忠于正教传统，从未试图以任何使之偏离正教原则的方式加以改变。他本人及其领导、在世奋斗的教会，是同一悲剧的受害者：为了推行捍卫与更新正教的策略，这位“自圣佛提奥斯以来，可能担任牧首职位的最杰出人物”，卷入政治阴谋，不仅成为新教保护者的囚徒，也在东方专制的暴虐面前毫无防御。[^p222-27] 于是，三十年战争引入的权力政治无情逻辑，牺牲了他的正教更新策略。

卢卡里斯任内剧变的长期后果，是十七世纪余下时期，正教会盛行强烈反新教精神。若干地方会议谴责加尔文主义，以及署于卢卡里斯名下的1629年《告白》。甚至塞浦路斯教会也于1668年在总主教尼基弗鲁斯主持下，举行会议谴责加尔文主义。彼得·莫吉拉1640年的《告白》，由于拉丁来源，危险地接近天主教。此后，耶路撒冷牧首多西提奥斯（1669—1707年）又提出一篇告白，逐点回应基里尔的《告白》；但为此，他大量借用拉丁资料，在基本教义问题上，朝天主教神学方向走了很远。这种反新教精神，解释了十七世纪最后数十年天主教与正教的接近，否则便令人惊讶；在地方层面，这种接近尤其显著。在爱琴海若干宗教人口混杂的岛屿，共用礼拜场所、参与彼此传统，虽未必共同领受圣事，却已是相当普遍的做法。[^p222-28] 但这种接近很快因天主教在某些地区的强硬做法而受挫，例如十七世纪末，威尼斯人从奥斯曼手中<a id="pdf-223"></a><!-- PDF page 223; original page 202 -->夺取的伯罗奔尼撒。

## 正教与启蒙运动

十八世纪开始时，希腊东方的正教，与西方基督教两大分支都已疏远。它直到十九世纪都拒绝同西方基督教开展灵性对话，却仍须面对西方以世俗学问形式提出的新知识挑战。这既给正教世界带来机会，也带来危险。传统观点认为，正教会从一开始、也在原则上，便敌视来自西方的各种世俗学问，只专注于希腊东方文化传承的宗教学问。这是过度概括。若要准确描述史料呈现的态度与实践，就必须大幅修正、细化。以牧首学院历史为例，它曾拥有科里达莱夫斯这样的学者，后者正是西方世俗学问的杰出代表。即使他得任出于卢卡里斯牧首，在赞助者倒台后不久也失去职位，正教会仍继续倚重受西方训练的学者。例如，1665年，亚历山大·马夫罗科尔达托斯获任牧首学院院长，将现代科学教学的最初要素引入课程。[^p223-29]

十八世纪，每当教会计划改革、提升重要教会教育机构，便聘用受西方训练、代表启蒙文化不同倾向的学者，表现出对西方学问值得注意的开放。最显著的一次，发生于1753年：牧首基里尔五世与会议颁令，将瓦托佩迪院长梅勒提奥斯于1748年在阿索斯山创建的高等学校，置于君士坦丁堡牧首区庇护之下。此举旨在创办学院，为教会培养所需教士与学者。计划交给当时希腊世界启蒙文化最杰出的代表欧根尼奥斯·武尔加里斯（1716—1806年）。他在十八世纪五十年代主持阿索斯学院的经历，成为正教与启蒙相遇之可能及其限度的经典<a id="pdf-224"></a><!-- PDF page 224; original page 203 -->检验案例。[^p224-30] 武尔加里斯虔诚，是正教资历无可指摘的教士。十八世纪五十年代住在阿索斯期间，他甚至因圣山最受尊崇的圣像之一——迪奥尼修修道院的《不坐颂》圣母像——而获得奇迹般的医治。然而，他也是理性主义者，研究现代哲学与科学。他在威尼斯和帕多瓦学习后回到希腊，任教于约阿尼纳与科扎尼学校，与捍卫传统学问的保守学者发生个人及思想冲突；对方因其理性主义和科学观而指控他为异端。教会官方似乎并不持这种疑虑，而看出争执实质，是学者间的职业对抗与代际冲突。牧首与会议将更新教会教育的任务交给他，是认为他具备当时最出色的才干。

在瓦托佩迪修道院上方山丘上的学校，武尔加里斯试图把西方高等教育模式引入正教文化环境。最初，只要有基里尔五世支持，前景似乎很好。1756年初，他写给在约阿尼纳教过的旧学生、塞浦路斯的基普里亚诺斯一封信，以生动抒情文字赞颂学校自然环境之美，接着令人意外地描述了阿索斯学院课程：

> 那里，德摩斯梯尼奋力激励雅典人反抗马其顿人；那里，荷马在吟诵中歌唱伊利昂周围的英雄事迹；那里，修昔底德以崇高文体叙述希腊人的内争；那里，历史之父以伊奥尼亚文体叙述更早的历史，以及战胜蛮族的功业；这里，柏拉图阐发神学，亚里士多德以多种方式揭示自然奥秘；法国人、德国人和英国人，则教授他们新颖的哲学体系。[^p224-31]

从这一教学概况可见，武尔加里斯为正教会复兴、提升学问所设想的模式，是扎实古典训练与接触现代欧洲哲学相结合。他在阿索斯教授的“法国、德国和英国”哲学家，是笛卡尔、莱布尼茨<a id="pdf-225"></a><!-- PDF page 225; original page 204 -->与沃尔夫，以及约翰·洛克。唯有始终获得教会最高权力完整、坚定的支持，这种课程才可能在修道环境中讲授。基里尔五世失去普世牧首座后，退居阿索斯，开始干预学校事务，鼓励其他派别公开反对武尔加里斯开创的现代化课程。武尔加里斯感到遭遗弃与背叛，于1759年辞去院长。

然而，这并非启蒙时期教会对西方学问开放的终点。接替武尔加里斯任阿索斯学院院长的，是希腊文化中最早倡导牛顿科学者之一尼古拉奥斯·泽尔祖利斯。武尔加里斯本人在1759年辞职后不久，受牧首塞拉菲姆二世召至君士坦丁堡，负责改革牧首学院。任期太短，无法作重大改变，但他仍将数学与现代科学引入课程。他停留君士坦丁堡，却产生一项重要政治后果：促进大教会与俄罗斯帝国接近，结束了彼得大帝对俄罗斯教会强行改革以来的冷淡关系。这一倡议使塞拉菲姆二世于1761年3月失去牧首座；随着其被罢黜，武尔加里斯在牧首学院的任职也告结束。泽尔祖利斯在这里同样短暂接替了他。

其他十八世纪牧首，尤其是当时教会政治中的重要人物撒母耳一世（1763—1768年、1773—1774年），敌视西方学问及现代哲学。他们或许偏好更熟悉、常规的亚里士多德哲学，却从未试图停止现代哲学教学。此外，直到1789年，教会作为机构，从未通过会议决议，采取敌视西方世俗学问的政策。十八世纪，传统派与现代化学者为控制重要教育机构，展开激烈思想冲突。然而，值得注意的是，1789年之前，教会仅一次因哲学观点谴责一位学者。此事发生于1723年，对象是美多迪奥斯·安斯拉基提斯。他在卡斯托里亚教授马勒伯朗士与笛卡尔，而非亚里士多德，引起其他学者敌意。但尽管地方对手煽动反对，只有在他被控接受西班牙神秘主义者米格尔·德·莫利诺斯的异端宗教观点时，才被传至君士坦丁堡会议。他未出席，<a id="pdf-226"></a><!-- PDF page 226; original page 205 -->会议便针对其被推定的宗教偏离，而非哲学观点，颁下绝罚。安斯拉基提斯悔悟出席后，会议撤销绝罚，却命他此后只教授亚里士多德。[^p226-32] 他之后的许多重要思想人物，尽管观点先进，也未受教会谴责，尤其包括武尔加里斯本人，以及公开教授牛顿物理学的尼基弗鲁斯·狄奥托基斯；更有约西波斯·莫伊西奥达克斯，他因强烈拥护启蒙的哲学与科学原则，同传统派发生无数冲突。[^p226-33] 这印证了曼努埃尔·格德翁的判断：不论“旧”“新”哲学家如何争执，教会官方政策从未积极敌视现代世俗学问和启蒙思想，尽管在教义、信仰问题上始终警觉、不妥协。[^p226-34]

1789年之后，情况将根本改变。法国大革命如同在欧洲其他地区一样，成为希腊东方深刻思想转变的催化剂。关键时刻是1793年法国弑君。西方反革命论述发出的文明末日景象，很快被正教东方保守环境接受。正教反对西方自由思想的新论战态度，首先表现于1793年在的里雅斯特匿名出版的《自负智者之不幸》。它很可能出自阿塔纳西奥斯·帕里奥斯之手，后者是教会内部最激烈的反启蒙学者。[^p226-35]

教会对启蒙与现代性意识形态的新态度，也体现于1793年将克里斯托杜洛斯·潘布莱基斯逐出教会。这是自整整六十年前安斯拉基提斯以来，首次因哲学与宗教观点，将一位学者逐出教会。潘布莱基斯于十八世纪五十年代在阿索斯学院从学武尔加里斯，后来任教于中欧希腊学校。1786年，他出版关于哲学性质的著作，借用、转述《百科全书》。六年之后，书中观点<a id="pdf-227"></a><!-- PDF page 227; original page 206 -->招致普拉塔蒙主教狄奥尼修斯的攻击，形式是对宗教礼拜的戏仿；两人从阿索斯学院时期就已是旧敌。潘布莱基斯同年以长篇论著回应，副题为《论神权统治》。他在文中表示，以敌人称自己为新的卢梭或伏尔泰为荣，全面攻击教会、修道生活和正教信仰基础，最终采取泛神论立场。这是希腊语启蒙文献中，首次也是唯一一次对基督教信仰基础公开、系统的攻击。他的敌人迅速提请教会注意。1793年11月，牧首涅奥菲托斯七世与君士坦丁堡会议颁令，将潘布莱基斯逐出教会，诅咒其观点。然而，作者已于当年8月在莱比锡去世，争议著作当时尚在印刷；因此，他没有机会撤回观点，教会的绝罚也从未解除。[^p227-36]

1798年，正教东方对世界局势的焦虑与担忧，达到重大危机的顶点。这一年，法国革命军在波拿巴将军率领下登陆埃及，实际上跨入奥斯曼世界门槛；此前，他于1797年废除威尼斯共和国，把包括七个伊奥尼亚岛在内的威尼斯领土，置于法国革命占领之下。同一年，一项受雅各宾思想启发、旨在推翻奥斯曼专制，在巴尔干与小亚细亚建立自由“希腊共和国”的密谋，被奥地利当局破获；其主角里加斯·韦莱斯廷利斯及七位同伴，在的里雅斯特和维也纳被捕。[^p227-37] 奥斯曼朝廷担心帝国安全，这种警觉传给新牧首格里高利五世，并深深影响了他。他此前任士麦那都主教，已以活力、牧灵工作和虔敬著称。在三次任期（1797—1798年、1806—1808年、1818—1821年）中，他将推动、领导教会反对启蒙的运动。牧灵热忱、渊博学识、对传统的忠诚与不屈意志，都以非凡坚韧投入这一事业。他登上普世牧首座后的首批行动之一，就是重建牧首印刷所，复兴卢卡里斯最初<a id="pdf-228"></a><!-- PDF page 228; original page 207 -->虽未成功的倡议。此后二十五年，牧首印刷所成为格里高利五世攻击启蒙思想的有效工具。1797年8月或9月，即法国占领后不久，他向伊奥尼亚群岛正教居民发出牧函，警告“上古之蛇”以自由、平等承诺为伪装，谋害真信仰。1798年，牧首与会议谴责里加斯在维也纳印行的革命小册子，“因为其中充满腐朽”，要求教阶保持警觉，搜集各教区出现的一切副本，送往伊斯坦布尔焚毁。致伊庇鲁斯、克里特、爱琴海诸岛及士麦那教区教阶、教士和平信徒的通谕，警告法国革命思想这一“新近出现的疾病”。[^p228-38]

正教反对启蒙和法国革命思想的最重要表现，是1798年由牧首印刷所出版的两部小册子。一部题为《父训》，归于耶路撒冷牧首安西莫斯名下。文本强烈反对新出现的“自由体系”，称其为魔鬼使虔诚信徒误入歧途的最新诡计。针对无神的自由言论，作者劝人服从强大的奥斯曼君主政体：上帝使它高于世上一切君主政体，为的是约束拉丁异端，并作为拯救正教的工具。这些论点激起自由派强烈反应。启蒙思想家阿达曼蒂奥斯·科拉伊斯立即匿名出版《兄弟训》，质疑将《父训》归于虔诚耶路撒冷牧首的说法，逐点反驳“1798年拜占庭教条家”的奴性论据。[^p228-39]

牧首印刷所出版的另一反革命小册子，是帕里奥斯的《基督教护教论》。他警告信众，自由和平等的虚妄主张，必然导致无神论与沉沦。印刷所当局似乎擅改其文本，缓和论证，因此他又出版两部更完整的版本，<a id="pdf-229"></a><!-- PDF page 229; original page 208 -->使自己有空间表达更极端的观点。两版分别于1800、1805年在莱比锡出版，与牧首审查保持安全距离。

格里高利五世第一任期采取的措施，代表了一项明确策略，针对人们所恐惧的启蒙政治后果。在更广的文化层面，十八世纪九十年代，正教护教著作不断涌现，反对世俗哲学的宗教后果。这批基督教护教文献，包括安东尼奥斯·曼努埃尔（1791年）及伯罗奔尼撒人普罗科皮奥斯（1792年）的作品。曾经倡导启蒙学问、如今担任俄罗斯教会高级教职的武尔加里斯与狄奥托基斯，也加入其中。多数作品译自或改写西方反对伏尔泰及启蒙宗教批判的著述，为进一步论战提供弹药，如马卡里奥斯·卡瓦迪亚斯1802年反伏尔泰的作品。[^p229-40] 法国革命论战在希腊文化中激起回响，造成思想争议，为超越护教范围的反启蒙攻击提供了广阔背景。面对现代性批判思潮的挑战，依附君士坦丁堡牧首区的教会知识阶层，试图提出捍卫传统世界观的另一种视角。[^p229-41] 现代化学者与传统派的对抗，沿多种方向展开，也包含鲜明、有时过度的反教士主义表达。[^p229-42]

尽管十八世纪九十年代争议激烈，1804年卡利尼科斯五世任内再次改革牧首学院时，半个世纪前基里尔五世与塞拉菲姆二世任内对启蒙的开放，在新学校蓝图中重现。学校由法纳尔迁至博斯普鲁斯沿岸的库鲁切什梅。若干在希腊启蒙文化中成就显著的学者受邀合作，包括曾在艾瓦勒克学院与反哥白尼派激烈争论的莱斯博斯的本雅明。学校由温和教士多罗提奥斯·普罗伊奥斯主持，他以<a id="pdf-230"></a><!-- PDF page 230; original page 209 -->与科拉伊斯的友谊著称。除广泛的古典研究与宗教教育外，课程包括实验物理、高等数学和现代哲学。普罗伊奥斯离职，担任菲拉德尔斐亚都主教，继任者则包括斯特凡诺斯·敦加斯、君士坦丁诺斯·库马斯等著名启蒙学者。[^p230-43]

1821年希腊革命爆发前十年，希腊社会思想冲突的激烈程度，最终决定了教会态度。这在格里高利五世第三任期（1818—1821年）显现。他从阿索斯流放地返回牧首座，满怀捍卫信仰的热忱，与会议实施一系列牧灵措施，试图阻止思想变化的浪潮。1819年一份通谕警告，教授现代科学和数学，可能损害真信仰与灵魂得救。一部题为《克里托的思考》的小册子，批评为某高级教士建造豪华宅邸，主张钱款更宜用于资助学校；依牧首印刷所首席审查官的建议，它被郑重地焚毁于牧首区庭院。最后，1821年3月，在对即将爆发风暴的惊惧中，牧首召集会议，任务是彻底谴责“哲学教学”及其在世的主要代表。[^p230-44]

这便是教会与现代性意识形态三十年对抗的结局。这场对抗，由对法国大革命的反应引发，结束了正教会一项长期传统：教会原本乐于借助温和启蒙，开展牧灵工作，推进教育倡议。
