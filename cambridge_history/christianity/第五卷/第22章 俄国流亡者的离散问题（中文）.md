# 第22章 俄国流亡者的离散问题

**谢尔盖·哈克尔**

## 离散

本书写作时，离散问题仍拟列入长期延宕的正教会“神圣大会议”议程；1976年起，甚至居首，须“尽快”解决。[^p560-1] 无此解决，教会论、牧灵多因素，继续困扰全体正教徒。

《旧约》离散概念，指导不足。既假设全体单一信仰，对现代正教徒尚合理，也假设单一神圣中心。任何替代，纵持很久，必有限期；永盼返原中心，如《诗篇》137篇渴慕耶路撒冷。

尽管君士坦丁以后，耶路撒冷朝圣具吸引，基督教思想却难占同等突出角色，也非信徒被分散所离“家园”。罗马、安提阿、亚历山大等使徒中心，同样重要，虽方式异。330年君士坦丁堡建立，东方首都渐显；381年第二次大公会议，升主要主教座第二，最终更编使徒渊源，确认角色。[^p560-2] 早在470—480年代，便主张“普世”称号，表明广泛、乃至普遍地位诉求。至少主张“<a id="pdf-561"></a><!-- PDF page 561; original page 540 -->调查、回答整个普世诸教会急迫问题的特权”。[^p561-3]

## 君士坦丁堡

历史，尤与罗马日益分离，增称号显著性。即便1453年，不再为基督教帝国中心，自尊、抱负未弃。奥斯曼臣属地位，须调措辞，但穆斯林统治者，准牧首在全疆教务居先，纵涉其他古牧首区。早在1370年，拜占庭牧首菲洛狄奥斯，已自称“遍居有人世界全体基督徒领袖”，“全都依赖我”。[^p561-4] 后世仍具某种道德力量。

但即东方，也须容其他重要中心，常在帝国外。多由其传教，一度臣属，部分成熟为各辖区，各有独立神话。保加利亚首都特尔诺沃设牧首教会，强帝国诉求，至称第三罗马。[^p561-5] 堡陷后，形象入俄思想，先关联诺夫哥罗德，[^p561-6] 莫斯科很快全占神话，[^p561-7] 或助辩另设牧首区，1589年须君士坦丁堡牧首祝福。后来，莫斯科成数个各有自身<a id="pdf-562"></a><!-- PDF page 562; original page 541 -->离散社群的辖区之一，族群、教会论基础，与以往大异。

## 族群主义

正教人口迁各地，原因多样，不再统一、明确、忠单一母会。不同起源、前景，以及本地各教会管理演变，共定性质。旧属教会纵忠诚似稳、至少形式维持，时间也可能促改。

美国许多俄人，即苏联时期条件不利，仍模糊认母会；1924年更主张实际独立，生活方式却仍“俄国”。直到1970年，新大陆俄国总教区，即都主教区（metropolia），才与莫斯科议正式独立，[^p562-8] 不顾君士坦丁堡抗议。[^p562-9]

独立或为离散解决形式：获新身份，不再仅母体延伸，同时求“不受民族主义支配”。[^p562-10] 美国俄离散，初求收入，也可如阿拉斯加，成殖民扩张；另一原因，是帝国解体，原帝国曾确保不同臣属民族教会共存。

脱土统治，巴尔干数独立教会兴。君士坦丁堡1832年接受塞尔维亚自治，1879年自主。希腊1852年建民族教会，在三十年前民族起义成功后；罗马尼亚诸省，1885年确教会独立。牧首区<a id="pdf-563"></a><!-- PDF page 563; original page 542 -->几无选择，只能接受，却一例外，引重要回应。1870年，新复保加利亚教会，欲确对君士坦丁堡、周边离散群体权利，牧首视不当侵入。族群身份可凌教规？原则问题，1872年召地方会议，界定、维护，宣“族群主义”“违福音教导、圣教父神圣教规”。即“依民族界定”诸教会并存，坚谴；同地无论如何，不应竞争辖权。[^p563-11] 此类教会续存，似嘲弄决议，离散却随后增。

1922年，土耳其强逐小亚细亚希腊人口，越古居地，堡也遇自身离散。一些融邻教会，如希腊，另保旧属，1922年设美、欧特派辖区。离散成常态，实际君士坦丁堡教区常住人口，却削为脆弱残余；优先地位理解犹存。

## 俄国离散社群

1917年革命，改旧帝国西疆，随后数十年，波兰、拉脱维亚、爱沙尼亚、芬兰，建民族正教会，部分二战后又生自身离散。但人数更大，是1918—1922年内战后，逾百万俄人散各地，源苏维埃统治、宗教打击。离散社群既牧养难民，也支援遥远受苦母会。

对故土态度不同，致长久分裂；另分歧，流亡教会人士，如何在萌芽合一运动中，与西方基督徒交往？

无先例，只能临时应对。1917年恢复的莫斯科、全俄罗斯牧首区，广泛1917—1918年会议，也无暇讨论，留牧首、主教会议、顾问，在紧急状态定政策。1920年令，促与莫斯科隔绝主教，自设独立机构，宜联邻主教，原假设旧疆内发生。[^p564-12] 依教规先例，身在君士坦丁堡辖区俄人，求居留祝福。领袖原预拒，如半世纪前保加利亚；时势已变，1920年不顾语言、方式，正式认当地教会协作者。但俄人几未停下来感念所得恩惠；塞尔维亚似供更大独立，翌年多迁塞尔维亚人、克罗地亚人和斯洛文尼亚人王国，教会效忠又变。

这只是调整之始。随后十年，一些求维、复莫斯科联系，苏联干预，却愈难；另遵1920令，自设自治组织，初称“境外俄罗斯正教会临时最高管理局”。君士坦丁堡、塞尔维亚一次认可，后来失效，却不觉须续。另有人视认可不可或缺；1931年，西欧教区领袖叶夫洛吉·格奥尔吉耶夫斯基都主教，与莫斯科断，即归君士坦丁堡。离散已难挽回分裂，纵本书写作时，差异可能看似无关紧要。

## 统一的离散社群？

初盼统一境外总教区。塞尔维亚斯雷姆斯基卡尔洛夫齐的临时最高管理局，初准辖内行事，也欲伸全球。1922年，叶夫洛吉考虑策略，提联邦结构；此时已改名“俄罗斯境外正教会临时神圣主教会议”。[^p565-13] 他同时获“国内”、境外支持：奉牧首命，掌西欧，仍为卡尔洛夫齐资深成员，无人挑战。当时仅微震，却不再重演。其方案部分超越短暂统一，但仅在独立俄罗斯境外正教会内。机会失太早，未使全球俄侨连贯展示信仰、教制。方案拟西欧、巴尔干、远东、北美半独立教省，年会共议，几未过草拟。其自身地位反受境外会议质疑，1926年离；北美普拉通都主教，同期同因断。各自离散，成常态。[^p565-14]

此时境外会议，已与莫斯科冲突，涉君主主义，被认为拟呈1922年热那亚会议，求武复罗曼诺夫。印象来自右翼操纵媒体，新闻稿呼“十字军”反苏，却无共识、更非流亡会议决定；该会<a id="pdf-566"></a><!-- PDF page 566; original page 545 -->于前一年举行。很快视为教会干世俗事务，苏联加压国内教会，[^p566-15] 莫斯科牧首、会议，遂与境外会议疏离。1922年5月5日，甚至令“解散”其结构。[^p566-16] 叶夫洛吉也未长得宠；原以牧首代表任西欧，但迫害增，署理继任者谢尔吉·斯特拉戈罗德斯基都主教，1927年屈国家要求，令流亡教士宣忠苏。他说：“我们要求境外教士，书面承诺，对苏联政府一切社会领域举措，完全忠诚。”[^p566-17] 处境不可能接受，叶夫洛吉提替代，仅承诺不以讲坛作政治，已是莫斯科所能期，谢尔吉同意，[^p566-18] 却不掌自身处境，后更恶。

1930年春，叶夫洛吉参加坎特伯雷大主教所办、为受迫害俄国基督徒祈祷日，谢尔吉指其反苏。斯大林攻宗教巅峰，不能再改要求，夏季罢免，更停圣职。

教区不接受受制莫斯科裁定，另求教规支持；依先例，1931年诉君士坦丁堡。福提奥斯二世颁托莫斯，顾“异常、有害处境”，“临时整顿西欧俄罗斯正教会众情势”，设新特派辖区，仍“作为独具俄国性质、自由安排自身事务的正教<a id="pdf-567"></a><!-- PDF page 567; original page 546 -->组织，保独立”。此前尝试未成，谨称“临时”，却延数十年。[^p567-19] 巴黎、柏林两堂区，另试忠莫斯科，仅数十人。

## 国家的角色

革命后离散，起于共同故土，战前却无法接触受迫害教会。苏联似欲毁建筑、结构、人事，众信徒拘，部分处决。唯远方可储备，将来助国内同胞，方式不一：一派忠守过去，革命前“神圣俄罗斯”抱负、成就续启，无须重大更新，境外教会大体如此。叶夫洛吉辖区，却倡创造重思遗产，也关未来俄国。玛利亚·斯科布佐娃修女1937年写：

> 我们〔西欧〕教会，从未如此自由，自由得头晕。使命是显示，自由教会能行奇迹。若把新精神——自由、创造、勇敢——带回俄国，使命完成；否则，耻辱灭亡。[^p567-20]

1941年希特勒侵苏，阻此使命。战前，已藉外交、命令，试统离散。1938年，纳粹官员对叶夫洛吉辖区重要人物，坚说：“不想要两个〔流亡〕教会，也不容。”德国承认境外教会，视“无可争事实”，至考虑对竞争者“警察措施”。[^p567-21] 纳粹赞许的<a id="pdf-568"></a><!-- PDF page 568; original page 547 -->象征，是1936—1938年，由国家全额出资，在柏林建宏丽俄罗斯主教座堂。境外教会，觉提德裔改宗者塞拉菲姆·拉德，掌柏林、全德，属便宜。但他无意成路德维希·米勒那样的路德宗帝国主教，及其纳粹控制“德意志基督徒”领袖。纳粹从未用其团结占领区正教徒，也不准赴旧苏区；立顺从莫斯科牧首的失败计划，更舍他、取华沙都主教狄奥尼西·瓦列金斯基。[^p568-22] 最多能牧养悲惨新离散，即纳粹劳动营、劳工队俄人。[^p568-23]

占领区自发复兴，常为国防军人员容忍，甚至1941年俄战初，个别纳粹领袖也容。但希特勒自有最终消灭俄土教会、以异教崇拜取代计划。1941年，虽支持筹俄侨教士返“解放”故土传信，[^p568-24] 战中未推进。

战也改变另一独裁者反宗教政策。急求苏民爱国支持，斯大林1943年准严控复兴，为交涉西方重要要素，足使1945年牧首全权代表尼古拉·亚鲁舍维奇都主教，获乔治六世接见。英国当权者未问，无神论犹存，俄教士何以代表旧盟友。

但复兴若真，离散地位岂不受影响？苏宣传，画众疏离俄人返母会怀抱，图解疑；须趁流亡者仍信战争有益催化全苏社会，速行。叶夫洛吉甚至想即返，<a id="pdf-569"></a><!-- PDF page 569; original page 548 -->“该回家了”，“灵魂流亡异地，已够苦”，“〔莫斯科〕最高教权，允教会平静发展”。[^p569-25] 因而设想率全羊群返国，[^p569-26] 近《圣经》离散结束图景，所幸未成。

苏联急促其复1931年前身份。致新牧首阿列克谢·西曼斯基，他坚持重要条件：“向圣座呈请前，仍须求普世牧首，祝福与母会重新联合。”[^p569-27] 尼古拉迅给虚假保证，称堡已同意。1945年9月，协议签封，却11月莫斯科才通堡，新安排多不足。

1946年叶夫洛吉死，未决。西欧继任总主教弗拉基米尔·吉洪尼茨基，不愿接受莫斯科所求服从，也不欲复旧分裂。为弥合，向境外首领阿纳斯塔西·格里巴诺夫斯基都主教，提与西欧联合，条件境外重归君士坦丁堡，如1920年短期。他愿让掌教位，[^p569-28] 罕见复脆弱统一机会，但阿纳斯塔西拒舍独立。

复莫斯科处置虽差，莫斯科仍得地。会众分二，多数重申堡联系，另为尊叶夫洛吉，留莫斯科。于是<a id="pdf-570"></a><!-- PDF page 570; original page 549 -->添少量堂区于1931年忠莫斯科者，整合成独立西欧特派辖区，再设中欧，皆俄教前哨，也推进牧首外交；政策必由苏联宗教事务委员会定。移民通常非主要推动者，但独立教士，因海外信誉可掩饰、乃至为政策提供正当性，受国家欢迎。奉斯大林命，1948年安排全球正教会聚莫斯科，庆自宣独立五百周年。[^p570-29] 俄教权似可趁机，把周年变大公会议，压堡，终圆第三罗马旧梦。[^p570-30]

实缩成一般教会会议，未有大公会议。但莫斯科应居先观念，远超斯大林时代。已非1931、甚至1948，俄教表面平稳，赫鲁晓夫1959—1964年迫害仔细隐藏，更显如此。堡仍护俄侨，合理吗？莫斯科施压，1965年突停俄辖区，促返“家”；影响小，数年自证独立，为法国、西欧正教总教区，1971年重归堡。若独立更久，或须重思母会认可重要性。问题非新，1920年代已提，1970年新大陆俄都主教区，议莫斯科正式独立，才解；此前只是“临时”独立。[^p570-31]

苏维埃促成、延分裂，结束后仍存，莫斯科振兴，初不足促合。牧首区未忘帝国主义旧梦，1975、1976年提议，2003年以诱人措辞重拟，牧首签为己文，[^p571-32] 广及大部欧洲，却忽堡及其辖区，欲降地位，也忽罗马尼亚、塞尔维亚、安提阿离散，只致俄人，至少“俄罗斯传统”者。鼓俄源辖区思统一西欧都主教省，最终或独立，暗示莫斯科可孵育资助。

引争议，许多欧洲莫斯科支持者，视合理、无私，堡辖俄人也有赞；多数却困惑。方案似负莫斯科式、甚至过度族群主义“愿望清单”（Wunschzettel）：未来西欧教会，必只关俄人、或“俄国背景”正教徒？另有数十年隔绝后的境外对话。此前莫斯科屡疑其教规合法，境外更拒，视莫斯科“无恩典”。皆须放下。2004年，两领袖可在莫斯科礼貌会晤；当时总统弗拉基米尔·普京促成，说即现在也不能说两教会：“在我们人民意识中，俄罗斯教会是一。”[^p571-33] 民粹、甚至族群主义取向；教会领袖更慎，历史负担难轻卸。同时，<a id="pdf-572"></a><!-- PDF page 572; original page 551 -->境外教会求莫斯科“承认”、非“授予”既有自治，因授予便多少承认莫斯科为“母会”。[^p572-34]

## 离散社群与基督教西方

另欲谈与非正教、跨宗派组织关系，起初同意应符传统。[^p572-35] 但境外历来否定，视合一主义背正教、前提异端，[^p572-36] 深反莫斯科参加合一运动，苏联却有自身理由鼓励。唯苏维埃终、莫斯科投入缩，才可恰议其他群体关系。

叶夫洛吉却始积极。1924年，后来作巴黎神学院的教堂祝圣，既盼急难俄人聚，也说：“更愿代表西方基督教的外国朋友，找到此共同体……愿众人在此接近，〔在此〕所有基督徒共享弟兄之爱。”[^p572-37] 不只是参与辩论，虽离散让西方空前接触东方，讨论重要。实际参与对方礼拜，更让两大教会家族得洞见。谢尔吉·布尔加科夫神父，1920年代起在信仰与教制运动引此，尼古拉·泽尔诺夫等，也倡其为新设圣阿尔班与圣谢尔吉团契<a id="pdf-573"></a><!-- PDF page 573; original page 552 -->（1928年）等合一集会核心。鼓西方“重返传统”，发现曾共有、却遗忘之路；格奥尔基·弗洛罗夫斯基，最著名司祭之一，笃信如此。苏联无人可参磋商，离散担俄利益代表，也其他领域。弗洛罗夫斯基，成早期世基联要人；巴黎毕业约翰·梅延多夫、亚历山大·施梅曼神父，后在美国续，前者任信仰与教制委员会主席。

## 学术

1928至1945年，苏俄无教会高教机构，也难出神学作品；离散须补，故1925年建圣谢尔吉学院。[^p573-38] 首院长布尔加科夫，令西欧教区训数代学生、服务全教会，部分成专家；专任教师更丰产。多俄文，许多当时、后来译欧洲主要语言，贡献西方。大部俄作由西方基督徒供、维的出版社刊。1920年，保罗·安德森、约翰·穆德、唐纳德·劳里、古斯塔夫·库尔曼等朋友，获美国基督教青年会（YMCA）支持，资助六十余年，出版社至成书时仍以其名。

西方赞助，使境外惊恐，合一本已问题，又疑共济会；有时主教确信，1932年宣：“俄罗斯流亡社群<a id="pdf-574"></a><!-- PDF page 574; original page 553 -->彻底被共济会毒化。”[^p574-39] 后来对青年会却渐缓。[^p574-40] 不仅可随用出版社，更关作者正统。格奥尔基·费多托夫教史自由主义，或能过关；神学新表教义真理，却不同。评流亡期布尔加科夫，各辖区借争议，表不同立场。

安东尼·赫拉波维茨基都主教代表境外，1920年代起不满，1936年向会议呈详述“异端”论著，至顶。无人料困境莫斯科忙此，谢尔吉却迅应巴黎孤立据点成员告发，也用驻立陶宛代表叶列夫费里·博戈亚夫连斯基都主教证词。显然无从读作品，仍谴“常歪正教教义，某些直接呼应会议已谴谬教……与基督神圣正教会格格不入”。[^p574-41]

叶夫洛吉护的不止布尔加科夫，也自由：“忽教会自由，便失教会生活、良好牧灵关怀”；“须依使徒保罗教导（《加拉太书》5:3），守内在灵性自由，护其不受政治攻、形式理解上帝真理所致束缚。”[^p574-42] 正式认可布尔加科夫，旁有其他创新者，塑此时此地正教；尼古拉·<a id="pdf-575"></a><!-- PDF page 575; original page 554 -->阿法纳西耶夫神父等，甚至影响他教会。[^p575-43] 离散鼓不止仿古。但事件再显关注异。境外自有出版，与青年会几无重。1922年斯洛伐克设波恰耶夫圣约夫印刷所，主要牧灵，祈祷书、袖珍福音书、一般读者教会期刊。

1938年纳粹侵斯洛伐克，查德国发行，显其重要。也有德国机构，后有影响，部分叶夫洛吉追随者约翰·沙霍夫斯科伊神父之功。但侵苏后，禁教会文献、物品输新占地，斯洛伐克出版修士深失望，原盼返故土，证明流亡圣召：“随俄国教会解放，我们续急备传教文献，也备自己赴外传教。”[^p575-44]

战争另使俄人接近。1945年后，大批俘虏、强迫劳工，归西方盟军监管，不同情莫斯科，多感恩入境外；纳粹压力下，忠叶夫洛吉的西德堂区，鲜存，更促此。

大批流离者迁新大陆，1946年境外总部移美，也重振1928年建乔丹维尔修院兼神学院，成辖内最丰出版社，吸收波恰耶夫，供牧灵、礼仪，不拟青年会新考既有真理。此领域美国正教会居先，<a id="pdf-576"></a><!-- PDF page 576; original page 555 -->1968年设圣弗拉基米尔神学院出版社，学院前三十年设，初俄取向，后跨文化、超原离散。乔丹维尔却以“最纯粹俄罗斯风格”建，[^p576-45] 映单一民族理想旧世。

莫斯科派也有重要学者，战后数人教1944年巴黎所设、法语西向正教研究中心圣德尼学院。但终偏信仰、实践，多离；创办叶夫格拉夫·科瓦列夫斯基神父，1953年另设法国大公正教会，离散发展异路，涵化为首。批评者却视可能挑战“真理的柱石和根基”（《提摩太前书》3:15）。其他西方礼正教中心，虽“不同”，无此挑战，多却未越创办者寿命。[^p576-46] 时在1930年代末至1960年代。较低调者，莫斯科1953年在巴黎附近维尔穆瓦松设神学院，弗拉基米尔·洛斯基，教师翘楚。[^p576-47]

## 文化

欧洲离散，以学术影响西方，也贡艺术、音乐。新识中世纪圣像，滋移民画家，非每堂均愿赞助重发现的规范。20世纪后半，格里戈里·克鲁格、[^p576-48] 列昂尼德·乌斯宾斯基等，作杰出复兴圣像。后者巴黎设校，并<a id="pdf-577"></a><!-- PDF page 577; original page 556 -->出精深研究。[^p577-49] 两人皆属巴黎莫斯科辖区。曾任境外主教的伊凡·加德纳，研、演俄旧合唱，也写全景研究。[^p577-50]

众合唱团，鲜如圣谢尔吉有影响。I. K. 杰尼索夫、奥索尔金父子领导，复修院男声传统。目标同圣像画家，在敬拜发挥生命作用；录音、巡演，也及广众。不论合唱、绘画，皆图保、丰故国实际被遮传统。

## 敬拜

最终，更不显者，向外也向自身，显离散价值。若无圣餐基础，结构、公共善贡献，皆无关紧要；许多神学家认为，无敬拜共同体，其余只是布景，或可援复杂传统自辩，仅此。信徒敬拜活力，却显示“神圣俄罗斯”，可为前景、纲领，非虔敬神话。愿把普通客厅、破兵营改堂，化为“天国门槛”。许多人确信，敬拜支撑生活、紧联成员。此层面，“不可少的只有一件”（《路加福音》10:42），先于辖区问题，因敬拜比任何牧首令，更真实彰教会。巴黎流亡者阿法纳西耶夫说：“有圣餐之处，<a id="pdf-578"></a><!-- PDF page 578; original page 557 -->便有教会的圆满。”[^p578-51] 此为离散最真认可。

## 未来前景

离散并非永须认可。长年“海外”，有人思离散心态，是否应续提醒昔日、并因此应有之物；未来是否效益递减？

1970年，莫斯科正式认新大陆“俄国”总教区独立；2004年，安提阿牧首让美国离散实际自治。[^p578-52] 堡辖美国也有人盼更分，认为持续依附，过联先辈遥远过去。但不同起源、旧族群愿望，少可望整合为单一教会，虽欲成为“唯一、至圣、大公、使徒所传”的教会。

“神圣大会议”召开时，定须慎答：偏向祖籍民族教会管理机构的党派忠诚，会否妨碍委身众人之主（《罗马书》10:12）？
