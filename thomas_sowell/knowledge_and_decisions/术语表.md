# 《知识与决策》术语表

以下为已采用的译法，后续须结合上下文补充，不对外文书目作机械替换。

| 原词 | 译法 | 说明 |
|---|---|---|
| knowledge | 知识 | 不限于学校中传授的抽象、系统化知识 |
| ideas | 观念 | 知识生产的原料，与经过确证的知识区分 |
| information | 信息 | 不与知识无条件互换 |
| authentication | 确证 | 观念接受检验并获得知识地位的过程 |
| verification | 检验／验证 | 依搭配使用 |
| systematic authentication | 系统性确证 | 包括内部逻辑一致性与外部经验一致性检验 |
| consensual approval | 共识性认可 | 可以是公众或某特定参照群体的认可 |
| vision | 图景 | 本章首次保留visions；指先于系统论证的总体印象 |
| theory | 理论 | 经过系统准备、可接受确证的观念 |
| illusion | 幻觉 | 依作者本章分类：经不起合理确证的观念 |
| myth | 神话 | 本章泛指免受确证的观念，不限于神话故事 |
| falsehood | 虚假观念 | 在本章包括错误与谎言 |
| belief | 信念／看法 | 依语境，不自动提高为知识 |
| decision-making unit | 决策单位 | 可以是个人、家庭或各种组织 |
| decision-making process | 决策过程 | 与决策者的品格、宣称目标分开考察 |
| general knowledge | 一般性知识 | 如专业知识、统计资料 |
| specific knowledge | 具体知识 | 有关特定时间、地点、对象的知识 |
| incentive | 激励 | 包括正面奖励与负面惩罚 |
| structure of incentives | 激励结构 | 也译作“激励的安排”，按句法使用 |
| constraint | 约束 | 与激励搭配，不能省略 |
| feedback | 反馈 | 包括信息及相应影响 |
| trade-off | 权衡 | 根据语境体现得失，不机械译成单一目标的解决方案 |
| binary decision | 二元决定 | 是／否等选择 |
| incremental decision | 增量决定 | 可连续变化的数量或程度选择 |
| instantaneous decision | 单次决策 | 在一个时点完整作出，与考虑所用时间、可逆性不同 |
| sequential decision | 序贯决策 | 随时间、先前结果和新信息逐步形成 |
| decision-making costs | 决策成本 | 比较可选过程的全部后果，不仅是官员工资或货币支出 |
| intellectuals | 知识分子 | 不把其专业资历等同于全部人类知识 |
| institutional | 制度性的／机构的 | institution按语境译为制度或机构 |
| transactions costs | 交易成本 | 包括获取信息、协商、组织、监督等成本，不限于货币支出 |
| psychic costs | 心理成本 | 包括焦虑、难堪、精神负担等 |
| social overhead capital | 社会间接资本 | 第二章按作者广义用法，收益可由投资者之外的人取得 |
| incremental cost | 增量成本 | 随额外行动或产出而增加的成本，与平均成本区分 |
| diminishing returns | 收益递减 | 依上下文区分增量收益递减与总收益绝对减少 |
| investment | 投资 | 本书也指牺牲当前收益、增加未来物质或心理福祉的活动 |
| disinvestment | 减资 | 本书指消耗未来资产以增加当前收益，不限于公司减资手续 |
| residual claim | 剩余索取权 | 指权利时用此译法；涉及所得金额时按句法译作剩余收益或剩余额 |
| physical fallacy | 实物谬误 | 把同一实物误认为在不同人、时间和地点都具有相同价值 |
| Pareto optimality | 帕累托最优 | 各人按自己的偏好标准评价改善与损失 |
| merit | 功绩 | 第三章讨论与产出、消费者评价有别的投入品质及其应得回报 |
| sorting and labeling | 分类与标识 | 第四章泛指对人、事物、活动分类，并传递其类别信息 |
| time horizon | 时间视野 | 当前决定会考虑到多远的未来，并非单指剩余寿命 |
| animistic fallacy | 泛灵论谬误 | 把观察到的结果一概归于有意设计；首次保留英文，不等同于说所有有意行动都无效 |
| systemic analysis | 系统分析／从制度整体分析 | 考察相互约束的关系及其结果，不以个人意图直接解释制度结果 |
| rationalism | 理性主义 | 本书指偏重明确表达的理据，不与理性本身混同 |
| retrospective justice | 追溯性公正 | 对过去行为或得失作公正裁断与补救，与未来激励或社会效果分别衡量 |
| unmonitored monitor | 无须受监督的监督者 | 自身利益或情感纽带提供激励，并非完全不受法律约束 |
| force | 强力 | 与权力power区分，涉及武力或以武力为后盾的强制，不泛指有吸引力的选择 |
| democratic fallacy | 民主谬误 | 假定投票可以使多数或某一群体得到任何所欲组合，忽略内在约束 |
| property rights | 财产权 | 依本书含义，包括各种经济制度中的排他使用和决策权 |
| marginal cost pricing | 边际成本定价 | 按增量成本定价，与分摊间接费用后的平均成本区分 |
| sunk costs | 沉没成本 | 已发生而不可追回的过去成本，不等于当前决定新增的成本 |
| cross-subsidy | 交叉补贴 | 一组使用者支付超出自身成本的价格，以补贴另一组 |
| first-class mail | 第一类邮件 | 第八章美国邮件分类名称，首次保留英文，与垃圾邮件区分 |
| price fixing | 固定价格／合谋定价 | 政府强行定价与私人串通定价，依语境分别译出 |
| fair-trade laws（美国转售定价语境） | “公平交易”法 | 第八、十章限制价格竞争的法规语境，不泛指国际贸易 |
| jitney | 五分钱车 | 二十世纪初美国车主自行经营的低价载客服务，首次保留原词 |
| franchise | 特许经营权／选举权 | 本章企业准入语境为前者；政治参与语境为后者 |
| meritocracy | 功绩制 | 第八章对按功绩安排回报的道德争论，不机械译为精英统治 |
| state action | 州行为 | 美国宪法争议中的州行为与纯私人行为之别，保留本书具体语境 |
| affirmative action | 平权行动 | 1935年一般性补救语境译为积极行动；种族与雇用政策语境用平权行动 |
| hearsay | 传闻证据 | 英美证据规则概念，并非仅指闲言碎语 |
| writ of habeas corpus | 人身保护令 | 第九章相关联邦复审程序 |
| validation of tests | 测试效度验证 | 不与authentication的确证混同 |
| Hispanics | 西语裔 | 本书美国族群统计类别，非单指西班牙国籍 |
| substantive due process | 实体性正当程序 | 与只审查法定程序的程序性正当程序区分 |
| decisiveness / precision | 能否作出确定判断／精确性 | 可判断两者孰大，不等于能精确测量各自数值；不把decisiveness译作重要性意义的决定性 |
| insurgency | 变革运动 | 法律制度语境中的反对既有安排、争取制度改变，不径译为武装叛乱 |
| status ascription / ascribed status | 地位认定／被认定的地位 | 与按行为表现评估区分；本章所指不限于出生所赋的先赋地位 |
| maldistribution | 分配不当 | 可能涉及地位、权利或经济利益，不机械译为分配不均 |
| intellectual process | 智识过程 | 以明确表达、论证和确证为核心的认识活动；与智力高低及知识分子职业区分 |
| omnicompetence | 全能 | 指能够胜任一切；不与表示全知的omniscience混同 |
| intelligence（认知能力） | 智力 | 可通过经验和非明确表达的方式体现，不与知识分子职业混同 |
| relevance（政治语境） | “切合现实” | 本章指与当下政治议题、决策要求相接，不等于论证已经得到确证 |
| Neo-Confucianism（宋明语境） | 新儒学／理学 | 第十章古代中国语境，与二十世纪现代新儒家区分 |
| accountability / accountable | 责任约束／对某方负责 | 本书包含反馈与损益后果，不只指明确说明理由或正式追责 |
| middleman / middlemen（经济语境） | 中间商 | 商品与资金流通中的交易中介；不机械套用于其他人际中介 |
| just price | 公平价格 | 中世纪定价学说，正文与索引统一；不与一般价格评价混同 |
