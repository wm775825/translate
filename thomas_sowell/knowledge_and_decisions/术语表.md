# 《知识与决策》术语表

以下为已采用的译法，后续须结合上下文补充，不对外文书目作机械替换。

| 原词 | 译法 | 说明 |
|---|---|---|
| knowledge | 知识 | 不限于学校中传授的抽象、系统化知识 |
| ideas | 观念 | 知识生产的原料，与经过确证的知识区分 |
| information | 信息 | 不与知识无条件互换 |
| authentication | 确证 | 观念接受检验并获得知识地位的过程 |
| verification | 检验／验证 | 依搭配使用 |
| systematic authentication | 系统性确证 | 包括内部逻辑一致性与外部经验一致性检验 |
| consensual approval | 共识性认可 | 可以是公众或某特定参照群体的认可 |
| vision | 图景 | 本章首次保留visions；指先于系统论证的总体印象 |
| theory | 理论 | 经过系统准备、可接受确证的观念 |
| illusion | 幻觉 | 依作者本章分类：经不起合理确证的观念 |
| myth | 神话 | 本章泛指免受确证的观念，不限于神话故事 |
| falsehood | 虚假观念 | 在本章包括错误与谎言 |
| belief | 信念／看法 | 依语境，不自动提高为知识 |
| decision-making unit | 决策单位 | 可以是个人、家庭或各种组织 |
| decision-making process | 决策过程 | 与决策者的品格、宣称目标分开考察 |
| general knowledge | 一般性知识 | 如专业知识、统计资料 |
| specific knowledge | 具体知识 | 有关特定时间、地点、对象的知识 |
| incentive | 激励 | 包括正面奖励与负面惩罚 |
| structure of incentives | 激励结构 | 也译作“激励的安排”，按句法使用 |
| constraint | 约束 | 与激励搭配，不能省略 |
| feedback | 反馈 | 包括信息及相应影响 |
| trade-off | 权衡 | 根据语境体现得失，不机械译成单一目标的解决方案 |
| binary decision | 二元决定 | 是／否等选择 |
| incremental decision | 增量决定 | 可连续变化的数量或程度选择 |
| instantaneous decision | 单次决策 | 在一个时点完整作出，与考虑所用时间、可逆性不同 |
| sequential decision | 序贯决策 | 随时间、先前结果和新信息逐步形成 |
| decision-making costs | 决策成本 | 比较可选过程的全部后果，不仅是官员工资或货币支出 |
| intellectuals | 知识分子 | 不把其专业资历等同于全部人类知识 |
| institutional | 制度性的／机构的 | institution按语境译为制度或机构 |
