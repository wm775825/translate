# 知识与决策

托马斯·索维尔，*Knowledge and Decisions*。正文初版于1980年，所用电子底本附1996年版序言，共568个物理页。

## 完成情况

整本中文校订版已完成，正式PDF共376页，位于`output/pdf/知识与决策（中文校订版）.pdf`。收入十章正文、1996年版序言、致谢、版权与原书目录、全部1001条原注、索引、封底和电子版导航。正文注号与原注编号可往返跳转。

由同一AI逐段对照翻译，另行通读全部中文，完成术语一致性校订、重点原文复核及排版检查；未经独立专业译者逐句精校。文中“今天”“目前”及统计、机构信息均保留原书时点。

自动校核已核对合订稿3315个可见文字单元、568个来源页锚、原注、图片、字形、文字边界和链接。实际查看全书缩略图，并放大检查封面、目录、各章首页、代表原注及索引。成品身份和具体范围见reports/全书交付记录.json及PDF校核记录。

## 底本问题

底本由电子文字重排，并未保留纸本逐页边界。索引保留原书纸本页码、英文字母顺序、主分项与中英文词目，适合全文检索；无法可靠换算为中文页码。

第五章第29、30注的原呼应位置仍有不确定性；第十章源PDF第402页开头文字损坏，译文依据可辨内容重建并明确说明。损坏注号、可疑数字、姓名、书目与原书事实疑误的具体处理，保留在对应译校说明和逐章记录中。

原注位于底本第461—529页，索引位于第530—565页。第1页、第566页是图像封面、封底，其文字已译；末尾两份重复导航保留来源。原书25个图像资源已清点，封面、封底与出版标志嵌入成品，装饰横线在重排时以统一版式呈现。

## 后续维护

从本书目录运行，使用Python及ReportLab、pdfplumber、pypdf、Pillow和Poppler。当前版式使用Windows宋体、黑体、楷体及拉丁字体。

~~~powershell
# 按来源页读取中英文
python -X utf8 scripts/read_source.py 47 51
python -X utf8 scripts/read_chinese.py 47 51

# 检查原书、分章稿、来源标识和原注
python -X utf8 scripts/check_book.py

# 从维护稿重新合订，试排到本书tmp/pdfs
python -X utf8 scripts/assemble_book.py
python -X utf8 scripts/build_pdf.py
python -X utf8 scripts/qa_pdf.py
python -X utf8 scripts/render_pdf.py --contacts --pages 1 2 3
~~~

实际查看渲染结果并更新对应视觉记录后，scripts/finalize_book.py才会将核验版本保存到正式输出目录并同步进度。Poppler可由环境变量TRANSLATIONS_POPPLER指定。scripts/extract_source.py仅用于首次导入；旧临时分块不作为重新合订的输入。
