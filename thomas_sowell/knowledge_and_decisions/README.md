# 知识与决策

托马斯·索维尔，*Knowledge and Decisions*。本书初版版权年份为1980年，所用电子版包含1996年版序言；当前PDF由电子文本重新排版，共568个物理页。

## 当前进度

第一章《知识的作用》已译出，正文对应PDF第26—46页，另保留第462页的本章原注1—4。当前由同一代理逐段对照原文并通读中文，尚未经独立专业译者复审。全书其余章节及卷首卷末资料待译。

本书尚未完成，不将单章译稿标为全书译本。全书翻译、校订和排版核验完成后，正式中文PDF保存到output/pdf，随仓库发布。

## 原书核对

正文共十章。PDF书签不能直接作为章首边界：有的指向前一页，且原电子文本将第1、5、10章的章次写成了“i”“S”“io”。分章范围已依据正文与原目录核对。

原书注释位于PDF第461—529页，索引位于第530—565页，第566页为图像封底，第567—568页为重复的电子版导航目录。第1页和第566页没有可提取文字，但均有原图，不据此认定缺页。

当前第一章的四条原注已核对。第9、10章有五处注号识别异常，逐页原文完整保留，具体编号在原书审计记录中列出，到对应章节时结合原页修复。

正文没有保留纸本逐页边界。原目录中的纸本章首页码另存于结构数据，不能以固定偏移量换算成当前PDF页码；后续索引定位也须据可核验的对应关系处理。

## 日常使用

从本书目录运行，使用可用的Python解释器及pdfplumber、pypdf。

~~~powershell
# 分块读取原文；一次最多6页
python -X utf8 scripts/read_source.py 47 51

# 读取某章原注
python -X utf8 scripts/read_source.py --notes chapter2

# 核对源文件、页范围、图片、译稿来源标识和原注链接
python -X utf8 scripts/check_book.py
~~~

scripts/extract_source.py仅用于首次导入，已有翻译进度时会拒绝初始化，不应在继续翻译时重跑。
