# 第28章 威克里夫主义与罗拉德派

坎蒂克·高什（Kantik Ghosh）

<a id="pdf-453"></a>
<!-- PDF page 453; original page 433 -->

本章标题，提出一个与研究中世纪晚期英格兰“异端”，根本相关的问题。[^p453-1]无论当时、今日，评论者，大体同意：约翰·威克里夫（卒于1384年），[^p453-2]及直接学术追随者的哲学、论战思想，是一种异议心态形成的必要部分。其特色，是以英语、拉丁文，对宗教权威既定含义、来源，作有根据、能明确表达的批判性探讨。[^p453-3]但这种异议，与另一范围更弥散、模糊、难把握的领域，究竟有何关系，共识远少。前者，从威克里夫思想，取得令人印象深刻的智识连贯性，在隐含的身份构想中，显出重要一致，并体现于极多样、庞大的文本产出；后者，则逐渐在<a id="pdf-454"></a><!-- PDF page 454; original page 434 -->官方教会立法，以及不断增长、多种多样的论战中，被感知、界定，也被生活、实践为“罗拉德异端”。因此，本章重新提出：至少为分析目的，是否有意义，把“威克里夫主义”“罗拉德派”，用来指概念上不同的现象，无论两者在中世纪晚期英格兰，实际如何相联？

支持这种方式，可指出无争议的事实：威克里夫本人，常以独特方式，借用、发展既有批评、异议传统，最主要，但并非仅有的，是一般归为“反教士主义”的传统。因此，若干学者强调，至少十四世纪最后几十年、十五世纪最初十年，所谓“改革派”或“激进正统”立场，与一种新生的根本性修订质疑，相互重叠。前者的批评，不质疑等级教会的基本结构、存在理由；[^p454-4]后者则在威克里夫及其继承者思想中，开始追问中世纪制度化基督教的根基。回头看，两者区别，足够清楚；但当时人的感知中，自然常模糊，界定“异端”类别，因此混乱。尤其“Lollard”，有些人更愿写作小写“lollard”，既被用作明确威克里夫思想追随者的同义词，也被当作不精确的论战贬称，攻击任何被认为不合规范、批评权威的宗教，乃至准宗教行为。[^p454-5]

因此，本章提出一个工作假说，在概念上，区分威克里夫思想的“生产端”与“接受端”。前者，是他自身作品，以及明确可辨认受其影响的拉丁文、俗语著作群；后者，包括逐渐出现的“异端”定义，一面是立法、司法程序，一面是学术性或较少学术性的论战；也包括威克里夫派及相关文本的读者群，尤其值得注意的是，<a id="pdf-455"></a><!-- PDF page 455; original page 435 -->这些文本，与保守性质的宗教著作，一道传播的问题，以及某些作品意识形态取向，很不清楚的棘手问题。此处须强调，这并非要复活旧有区分：一边是具有显著神学、哲学、政治意义的学术威克里夫主义，一边是被认为与前者关系较少、粗陋的“大众”罗拉德基要主义。[^p455-6]本章主要论点之一，是学术思辨，与跨越社会阶层的校外宗教生活，彼此影响，方式足以使这一方便的二分失效。“罗拉德派”，以及“正统”，最终呈现的形态，都由两者丰富互动决定；这种互动，未必总像历史学家希望的那样，令人满意地连贯。

威克里夫本人，在大量著作中，把多种思想、论战传统，独特地融合，开启这一互动。他的作品，对一种有特色的中世纪晚期话语形成，贡献重大：它把来自经院复杂、分化的专业领域的哲学神学思辨，与改革论战议程，综合起来，面向更广泛的校外“公众”。[^p455-7]尤其，他融合两个可区分、却重叠的话语领域：反教士主义，以及大量讨论哲学、神学相互关系的学术思想，特别是巴黎主教唐皮耶，1277年谴责亚里士多德命题，这一分水岭之后的思想。[^p455-8]

1277年，主教谴责219条据称获巴黎大学艺学院成员支持的亚里士多德命题，有漫长前史，也有同样重要的后续影响。它把<a id="pdf-456"></a><!-- PDF page 456; original page 436 -->制度化经院内部，职业、伦理、认识论上的冲突、张力，推到顶点，并以贯穿十四世纪的方式，持续回响。这些冲突，是界定经院使命及其意义，以及理解不同学术方法，在研究上帝时应有何种角色的核心。[^p456-9]唐皮耶谴责的研究，自成领域；此处简述大卫·皮谢，在所编版本结论中的话：

> 关于1277年被谴责的艺学硕士，我们所知、能够确定地说的，只是：他们试图为自己，安排一个认识论与制度的领域，以便不受宗教考虑支配，为哲学本身而教授、实践，并过哲学的生活……这种哲学的“自主论”观念，无论思辨维度，还是实践效力，都正面冲撞保守神学家的智慧统一图景，这毫无疑问。1277年巴黎谴责，正出自这些神学家；他们不接受艺学者提倡的“多元”视野。[^p456-10]

研究威克里夫者，会在皮谢概括中，认出“福音博士”著作，若干重要、反复主题的雏形：本应服从或协同于单一明确的基督教真理的智识话语，竟分裂、冲突，令人沮丧；哲学方法，尤其逻辑、辩证法，在多大程度上，取代想象中的纯净《圣经》研究，令人惊骇；最重要的，是热切探讨经院使命本身的意义，无论个人，还是制度形式。因此，他的作品，虽在中世纪学术话语传统内运作，却具有显著的<a id="pdf-457"></a><!-- PDF page 457; original page 437 -->“元经院”意识，即对经院活动本身的反思。

其论战中，同样重要的是反教士主义。这个庞大话语领域，不限于拉丁文争论，遍布欧洲，形式多样；[^p457-11]但威克里夫讨论神圣、世俗领域不相容，赋予它亚历山大·帕乔夫斯基所谓“有力的理论基础”。[^p457-12]中世纪晚期，欧洲早已有成熟批评路线，强调既成教会，与理想原始教会（ecclesia primitiva）的灵性二分，相应强调个人基督徒，回归使徒生活（vita apostolica）。[^p457-13]它隐含认可平信徒、制度之外的灵性权威，有时伴随质疑圣事效力、施行。这类或多或少的异议虔敬，彼此分散，未合成连贯教义、教会论；教会以多种方式，尤其以“异端”名义，对抗。[^p457-14]威克里夫思想，则把反教士主义许多持久重点，塑成连贯、理论可辩护、毫不妥协的根本改革方案。严格经院哲学，与宗教论战的这种独特综合，持续成为威克里夫主义的特色，见于数十年间，其拉丁文、俗语传播。甚至较晚的英语论著《论恒常祭的奉献》（De oblacione Iugis sacrificii），编者据内部证据，系于1413至1414年，[^p457-15]仍能轻易把激烈反教士、反教宗论战，融入对圣餐神学，细致、精微的探讨，包括逻辑、语义层面。

精确、范围广泛的学术思辨，与聚焦宗教政治问题的论战结合，力量巨大，尤其俗语<a id="pdf-458"></a><!-- PDF page 458; original page 438 -->成为传播思想的优先语言时，更是如此。[^p458-16]中世纪晚期经院学术，虽反复遭教宗等谴责，内部审查机制，也日益精细，仍培养出达马苏斯·特拉普，恰当描述的“智识领域中……令人屏息的自由”。[^p458-17]这种提问、分析、解构体系的自由，应用于宗教确定性的来源时，即使限于拉丁文、学校技术性专业领域，也可能、确实引发爆炸性争论。来源包括《圣经》，涉及文本性、正典性、语言、诠释学、历史真实；教会基本结构，涉及权力主张真伪、教宗史，以及修会等“私人宗教”的历史；还有圣事，尤其圣餐。[^p458-18]若以俗语，或虽用拉丁文，却面向可能超出学界的更广公众，[^p458-19]开展这类智识活动，并在论战中，支持制度改革方案，其破坏既有秩序的力量，不可低估。当权机构，觉得既定边界、约束结构，正在崩溃，尤其大学以外传播学术知识，鲜明显示这一点，回应因此日益紧张。[^p458-20]这种回应，并非，或不只是，有时看来那样，针对“其实”微小、<a id="pdf-459"></a><!-- PDF page 459; original page 439 -->边缘、陌生异议形式的夸张、不成比例、偏执反应；它也来自充分相关的认识：威胁，针对制度化信仰的存在理由本身，严重且可能影响广阔。十五世纪，反对“异端”的综合学术巨著，例如托马斯·内特《公教会信仰古义教本》（Doctrinale antiquitatum fidei ecclesiae catholicae，十五世纪二十年代），或以极不同方式写成的雷金纳德·皮科克俗语综合论著，约十五世纪四十年代，只有置于这一背景，才开始显出其常令人困惑的意义。

威克里夫派学问，如何传播到学界之外，确切细节，仍不明。但俗语文本产出的数量、内容，令人印象深刻，也反复使当局深感忧虑：两种完整《圣经》译本，一种直译，一种流畅意译，传播最广；一套包含294篇讲章的长篇讲道系列，同样广泛流传；称为《附注福音书》的链式注释，有若干抄本；百科式参考资料，《花圃》（Floretum）、《玫瑰园》（Rosarium），拉丁文多本、英语一本；还有许多论战、理论著作，现存较少，有的仅一本。尤其值得注意，许多俗语作品，例如《英语威克里夫派讲道集》，不仅精确、有力地传播其神学、教会论思想，同时把一整套新专业词，引入英语；也重现他对学科本身的反思，常以复杂、多声部方式，探讨经院方法的含义、目的论意义。威克里夫，既使用，也批评中世纪经院可用的学术理性主义工具。因此，论战能同时显得反智、又极具技术性：正当质疑当代以智识研究上帝的全部存在理由时，语言、部分方法，却取自学校。英语威克里夫派作品，因此不仅是精深的“俗语神学”“俗语哲学”，也同样激进地纳入，对经院努力与“真理”关系的元话语考察。学术理性主义、反思话语自身、论战的特殊综合，当时已获认识，尤其皮科克。他试图以英语，促成平信徒，借亚里士多德哲学，探讨道德问题，著作因而凸显重要的方法自觉。[^p459-21]

事实上，以俗语传播一套常挑衅、煽动的哲学政治观念，只是威克里夫主义影响的一面。同样令人不安，甚至可以说更令人不安的一面，是这种“异端”，在相对受规管、有边界的大学思想之外，以俗语，培育独特的智识态度、批判方法；[^p460-22][^p460-23]换言之，一种心态，未必与任何特定教义倾向结盟。人们只是逐渐认识这一点。这种心态，以我在别处所称“智识素养”（intellectual literacy）为特色，即有能力，检验一系列关键权威话语的基础、批评其上层结构、争论其主张。[^p460-24]这些话语，几乎总建立在对《圣经》，以及相关教父、经院传统，有争议、受争论的阅读之上。威克里夫自身思想的语言哲学意识，在这方面，他充分属于中世纪晚期学术环境，尤其对诠释学的标志性关注，因此在平信徒“智识素养”的运作中，起到格外重要、动摇秩序的作用。因为《圣经》，在中世纪权威构想中，理论地位居中；如果以足够严密的俗语，检验神学、政治体系的语言、诠释基础，又明示或暗示，邀请平信徒参与，而社会缺少容纳、规管这种平信徒智识<a id="pdf-461"></a><!-- PDF page 461; original page 441 -->主动性的机制，[^p461-25]必然导致失衡感，仿佛世界颠倒。[^p461-26]

中世纪处理受威胁失衡的经典方式之一，当然是运用“异端”政治。英格兰无大规模前例，欧洲大陆却历史悠久。亚历山大·帕乔夫斯基，在一篇影响深远的文章中，把“异端”，描述为“〔中世纪社会〕体系内部矛盾的必然表达”。他说：“从教义上说，〔异端的使用〕，完全不具特定性。它仅用于污名化政治宗教对手，别无其他。”[^p461-27]这一认识，有助于处理一个棘手问题：中世纪英格兰，“异端”的一般意义、定义，以及威克里夫主义、大小写L／l的罗拉德派的特定意义、定义。近来学术争论，聚焦若干相连主题：中世纪晚期英格兰，如何辨认、定义“异端者”“异端性”？这些定义，与威克里夫思想，有何联系？“L／lollard”，意味着什么？能否、在多大程度上，假定被如此称呼者，具有教派性、社会学或教义身份？“异端”究竟真正威胁世俗、教会秩序，还是纯粹宣传工具，或是重要性被新教辩护者、左倾史家，同时夸大的边缘现象？

这些重大问题，需要进一步、细致、不预设纲领结论的研究。伊恩·福雷斯特的工作，照明中世纪晚期英格兰教会，试图划定异端分类、设立侦察根除程序的立法过程，也揭示：立法、程序倡议，与实际地方侦察、举报异端之间，存在令人困惑的复杂互动。后者，必然涉及<a id="pdf-462"></a><!-- PDF page 462; original page 442 -->大多不通拉丁文、未经训练的平信徒，积极合作。[^p462-28]同样复杂的，是教会立法，与学术“异端”，以及学术异端，与俗语论战之间，确切有何关系。立法、学术哲学、俗语论战与反论战，这些以“异端”为内容的不同话语领域，如何促成对“异端”的人物、抽象两个维度的构想？科普兰、高什、萨默塞特，[^p462-29]考察拉丁文与俗语，以及“教士学问”（clergy）常令人生畏的专业性，与宗教政治要求简化之间，如何复杂调适，其研究与此相关。但要求的，是简化，还是复杂化？考察英格兰自十四世纪八十年代，持续到下一世纪及更后的“L／lollard”及其变体用法时，这一问题，更尖锐。人们常忘记，或未充分强调一事实：早在英格兰异端出现以前，以及同时，欧洲大陆宗教论战，已广泛、弥散地使用这一词，指称多种被认为“不合规范”的宗教信念、实践。[^p462-30]其滑动含义、难捉摸的意味，在多大程度上可固定？这一根本含混的词，与多种社会现实，如何相连？[^p462-31]这些“社会现实”，又是什么，究竟能否与“想象现实”区分？保罗·斯特罗姆提出，“异端”，及其孪生者煽乱，只是方便的对抗焦点；一个篡位、合法性薄弱的王朝，可围绕它，更有说服力地安排防卫宣传。[^p462-32]理查德·雷克斯则认为，异端统计发生率，微乎其微；我们与中世纪当局，虽原因不同，却同样耸人听闻地想象，到处异端，而“实际上”很少。[^p462-33]安妮·哈德森的工作，至今仍是英格兰异端研究的主要基础，却提供相反<a id="pdf-463"></a><!-- PDF page 463; original page 443 -->解释的证据。她认为，威克里夫直接及较疏远的追随者，构成连贯“运动”，有明确、有效的改革意识形态；《过早的宗教改革》中，神学、教会论、政治，是三大类别。

关键问题，因此关乎身份：什么构成“身份”，它如何形成、维持、被感知、想象？这不只涉及“异端”的定义，也涉及“正统”，因而隐含关系到，中世纪晚期英格兰宗教智识景观的地理分布本身。一方面，从十四世纪八十年代，至少到十五世纪一十年代中期，有大量威克里夫派作品，明确证明，一群学者、译者、教育者、论战者，教义连贯，政治发声积极。韦尔热会称他们“知识之人”（les gens de savoir）；[^p463-34]或许还包括追随者、学生。其身份感，显著统一，不只反映于意识形态大问题，也反映在词汇细节的微观层面。[^p463-35]另一方面，证据含混，指向远更模糊的领域：“异端”“正统”的意义、边界，不断被界定、塑造、重塑。证据来自审判记录、借更古老诋毁异端模式的反威克里夫论战，以及含有我们认定为威克里夫派文本的手稿。这里，身份模糊，轮廓变化，可能主要服务论战；唯一可有把握说的，是异端、正统的概念对立，随时间强化，即使两方实际内容，仍变化多端，或被简化为粗陋公式，以便塑为宗教裁判术语的类别，如异端审判中所见。[^p463-36]界定、重新界定，持续到十五世纪相当晚的时期，可以说，从未定局；皮科克简化的亚里士多德哲学，被定为异端，或一次异端<a id="pdf-464"></a><!-- PDF page 464; original page 444 -->审判中，引用乔叟《坎特伯雷故事集》，都显示这一点。[^p464-37]此外，最初与典型威克里夫立场相联的某些心态、方法重点，例如诠释学、教父学、《圣经》学术研究、思辨神学，逐渐被自称“正统”的对立一方，吸收。[^p464-38]手稿证据，更令人困惑。我们认为，意识形态相距甚远的文本，常在中世纪汇编中并存：这是伪装企图，还是确实不分界限的接受世界，抄写需要与虔敬上的兼收并蓄，彼此合作？[^p464-39]那些以多种形态流传、威克里夫色彩程度不同的文本，又如何，例如理查德·罗尔的英语《诗篇注释》，或《贫苦卑微者》（Pore Caitif）？它们是否再次证明，异议者，把异端“嫁接”（ymping，即插入）到无可指摘的著作中，[^p464-40]暗中向毫不怀疑的听众，传递观点？还是显示一种宗教生活领域，在那里，整齐、黑白分明的身份、意识形态标记，根本无关、不适用？因此，最稳妥的，是否应假定一条不合常规的宗教行为、信念谱系，从激进威克里夫主义，到并无预设纲领，却批判性探究个人救恩、宗教权威、<a id="pdf-465"></a><!-- PDF page 465; original page 445 -->教会风习者？随论战时机不同，“异端”，可被放在谱系任何位置。能否在这一有限定的意义上，把复数的“罗拉德派现象”（lollardies），[^p465-41]与“异端”等同：既能指威克里夫核心价值，也能指更弥散的权威质疑，尤其“平信徒一方”？后者是皮科克，称呼自己误入歧途的同代人时，随处使用的措辞。

更深理解威克里夫—罗拉德“异端”现象，以及一般的中世纪晚期英格兰宗教文化，有赖于更细致、精微地把握：“异端者”的身份，如何变动；辨认、构想“异端”的基础，如何不稳定。威克里夫，或许更重要的是追随者，创造一种宗教智识心态，刻意使多种真实、想象边界，变得有问题、可穿透：异端与正统，平信徒与教士，英语与拉丁文，学术思辨与宗教政治，经院哲学理性，与有组织宗教实践必需的情感，即马修·阿诺德所谓“诗”。在最安稳时候，智识性检验信仰的基础、上层结构、圣事，也可能动摇秩序；“圣事”，我同时用其专业、非专业含义。中世纪，这种检验，始终限于有自身监督、约束机制的学术精英阶层。即使只是文本分析、辩论、争论的初步工具、技巧，传播到学校之外，也从很早起，就正确地被视为，对整个秩序体系，具有根本、惊人的破坏力。这一体系的概念中心，位于一部文本，以及声称拥有诠释权威的相关传统、制度。因此，古老、包容范围广的“异端”话语，不可避免地被援引、运用，以多样、有时较连贯、有时较不连贯的方式，反击具有深远文化含义的挑战。威克里夫主义—罗拉德派的故事，部分是一段社会努力处理，自身织物经纬之中裂缝、矛盾的历史。因为再引帕乔夫斯基的话：“异端”，应置于“中世纪社会的基础，而非边缘”。[^p465-42]
