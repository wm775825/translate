# 第31章 十五世纪的《圣经》

克里斯托弗·奥克尔（Christopher Ocker）

<a id="pdf-492"></a>
<!-- PDF page 492; original page 472 -->

中世纪《圣经》，几乎不能算单一本书，而是一组译成拉丁文的古代作品。即使没有释文、其他注释装点，这种情形很少，它的六十六卷、八篇次经，也仍难与层层解释分开。耶柔米等人的翻译，是第一层：武加大译本若干卷，取自早于耶柔米的拉丁译本；《诗篇》，则是他据希腊文《七十士译本》所作第二次翻译，而非根据希伯来原文。序言，是第二层。《旧约》序，取自耶柔米不同著作；《新约》序，来源多样，却以这位圣徒之名流传。较少装点、罕见的武加大译本，成为早期印刷《圣经》的形态：正文加序言，序常传统，有时却新作，如德语、捷克语译本。[^p492-1]通常，人们分部读经，配合注释，或阅读半《圣经》式叙事。它与其说一本书，不如说古代文学群，居于过去、当下，重述、改编、探究、再现其话语的尝试核心，是“极富想象力的注释、道德阐释、用以照明《圣经》意义的修辞形象”的“基础文本”。[^p492-2]

它也是受控制的文学。朗根施泰因的亨利，十四世纪八十年代，任维也纳神学教授时，先讲耶柔米《圣经》序，才转《五经》序、《创世记》。他作出有趣观察：《圣经》语言的意义，包含作者、读者的意图。写者、读者的灵魂，都带着特定兴趣、道德能力，来从事各自任务。这意味着，一个跨越时间的文本<a id="pdf-493"></a><!-- PDF page 493; original page 473 -->共同体，以及受圣灵作用支配的意志交融；圣灵在《圣经》读写两端，文本源头、人的接受端，负责启示。亨利认为，《圣经》持续活着的状态，防止其意义，被如舞台道具般，任意扭转。他用一个别扭比喻，说：“《圣经》没有蜡鼻子，却有铁铸、火热的鼻子！”[^p493-3]一个世纪后，奥古斯丁会士、马丁·路德的导师、朋友，约翰内斯·施陶皮茨，指出圣灵内住者，能够听见上帝语言。[^p493-4]灵感，并非机械生产词句，而关乎神圣写者、读者的状态，以及彼此一致。启示从未停止；神学家，从十四世纪方济各会奥卡姆的威廉，学到这一点。他列出公教真理来源：《圣经》、使徒口传、习惯、从前三者推得的结论，以及新启示。中世纪晚期神学家，不论如何看奥卡姆、十四世纪中叶的谴责，大体同意。[^p493-5]从古代记录，到三段论结论，整条受启示序列，都在上帝作用之下、旁边，或与之共同发生；这是可争的神学问题。上帝作用，是衡量、约束、控制，与一段经文相关的无数可能思想、结论的尺度。甚至怀疑预言者，也信启示；例如十五世纪，巴黎大学教务长让·热尔松，把个人灵感，与《圣经》、传统，并列为三项第一层次真理来源。[^p493-6]学者<a id="pdf-494"></a><!-- PDF page 494; original page 474 -->对一种书籍有灵的看法，提供科学解释、纠正：书在制作、保存、使用中，活着。他们并非否定超自然书观，而是理性化、限定它。此外，教会流行的释经传统，被原则性地视为，与《圣经》教导一致。连续性，可以预设；十三、十四世纪之交，影响巨大的方济各会神学家约翰·邓斯·司各脱，便如此提出。[^p494-7]研究者发现，十四世纪晚期，英根的马西利乌斯、奥伊塔的海因里希·托廷、威克里夫，以及十五世纪胡斯、热尔松、奥古斯蒂诺·法韦罗尼、丹尼斯·范·莱文，即嘉尔笃会的狄奥尼修、文德林·施泰因巴赫等，虽如此不同，均预设连续性。[^p494-8]在某一点，人人向惯例低头，甚至被控罗拉德派的英格兰异议者，也以自己的方式如此，下文再谈；他们争论的是，传统信念的内容、定义。共识，由受教育男性专业阶层记录，再接受辩证试验；可以说，经院注释、神学，无论拉丁文，还是俗语改编，都成为十五世纪《圣经》读写的首要智识背景。

中世纪经院注释体裁、释经方法，1350年前，已完成发展。[^p494-9]十五世纪，《圣经》学术最重要的创新，是洛伦佐·瓦拉约1448年，对希腊文《新约》的语文学注释；直到伊拉斯谟发现、于1505年出版，才有影响。[^p494-10]但瓦拉的<a id="pdf-495"></a><!-- PDF page 495; original page 475 -->语文学，在十二世纪修道学校、早期大学的语法、修辞解释中，已有先例；不过，那里希伯来知识有限，几乎不通希腊语，文本批判，也只限于武加大译本，缺希腊、希伯来原文。[^p495-11]

我们对中世纪晚期《圣经》学者，所知仍相对少。例外，是威克里夫；围绕他的争议之后，英格兰异议者，承认其遗产。学界对俗语宗教著作，远比对拉丁文，更有兴趣，尽管许多人，已指出两种文化的联系。[^p495-12]1959年，维尔弗里德·韦尔贝克，研究来自阿拉贡、瓦伦西亚的奥古斯丁会士海梅·佩雷斯《诗篇》解释，出版以来，少有详细、持续的十五世纪经院注释研究。[^p495-13]亨利·德·吕巴克《中世纪释经：圣经的四重意义》，最后部分于1964年出版，把中世纪晚期注释，称为“衰败”，或使人不愿关注此期。[^p495-14]马克斯·昂加马尔，在考察文艺复兴时期《雅歌》时，概览其<a id="pdf-496"></a><!-- PDF page 496; original page 476 -->解释。[^p496-15]萨尔瓦托雷·I. 坎波雷亚莱，研究瓦拉《圣经》工作，与其争论的关系。[^p496-16]赫尔穆特·费尔德，编刊、研究十五世纪晚期，蒂宾根教授施泰因巴赫的注释。[^p496-17]另有少量人物短论。巴黎大学直言不讳的教务长热尔松，写几篇简短释经作品；卡尔弗里德·弗勒利希，曾作重要研究，但至今无人考察其仅有的完整《圣经》注释，一部论悔罪诗篇，一部论《雅歌》。[^p496-18]住在鲁尔蒙德嘉尔笃会院的丹尼斯·范·莱文，1434至1457年间，写四十三部经注。[^p496-19]丹尼斯·特纳，讨论其《雅歌》解释，但至今无人，以完整专著，研究任何一部经注，或这位会士184部真实作品中的大多数其他著作。[^p496-20]近来论文，讨论意大利多明我会锡耶纳的乔尔乔、世纪中叶西班牙在俗司祭阿方索·德·马德里加尔，以及世纪末，佛罗伦萨多明我会萨沃纳罗拉的字面释经；也讨论本笃会特里特米乌斯，颇带怀旧地倡导《圣经》四重意义。[^p496-21]近来一文，揭示萨沃纳罗拉，在佛罗伦萨民众政体最初几个月的讲道中，寓意阅读与预言的关系，如何变化<a id="pdf-497"></a><!-- PDF page 497; original page 477 -->（1494年）。[^p497-22]最有影响的注释之一，是里拉的尼古拉，覆盖全《圣经》的《字面义释经疏》（Postilla litteralis）；其接受史，迄今只在西班牙，得到研究。[^p497-23]犹太改宗者、后来升任主教的布尔戈斯的巴勃罗，在该世纪第二个四分之一时期早期，为里拉作注，自称要补救其对希伯来原文、基督教意义理解的问题。他在里拉序言后，又加自己的序。[^p497-24]世纪中叶，以反对德意志严规改革扩张闻名的方济各会士马蒂亚斯·德林，为捍卫里拉，纠正布尔戈斯。里拉著作的早期版本，首版由韦因海姆（Weynheym）、潘纳尔茨，于1471至1472年，在罗马印行，始终合收三文本：里拉字面义释经疏、布尔戈斯注解、德林复评，还附里拉《道德义释经疏》、布列塔尼的威廉，对《圣经》序言的阐释，以及里拉反犹太教小论著。[^p497-25]因此，版本记录了观点、论证的复杂对话，至今只获极零碎研究。[^p497-26]《圣经》主题的视觉表现，对异象状态的产生，作用众所周知；但异象著作、图像、虔敬，与经院阅读、解释方法间，可能存在何种联系，仍待探索。[^p497-27]

这只是巨大冰山一角。要认识这一点，须暂把新虔敬运动创始人格罗特（1340—1384年）的说法，放在一旁；这一运动，或是北欧最有影响的有组织虔敬运动。他曾著名地抱怨，经院思辨，破坏《圣经》研究；神学家似也常作类似指责。[^p498-28]若属实，我们的研究工夫，可很短。但学校仍继续研经，直到十六世纪相当晚的时候，神学学士、硕士，仍须讲授《圣经》，如同必须讲《四部语录》、参加辩论。[^p498-29]至少某些地方，例如牛津，研经甚至增加。食者彼得（Peter Comestor）《经院史》（Historia scholastica）、里拉的尼古拉《释经疏》等早期注释，仍受师生欢迎；十五世纪牛津，又有若干部注释存世。[^p498-30]剑桥、巴黎，也继续要求经文讲授；鉴于巴黎神学课程影响，欧洲日益增多的大学，大概每个神学院，都如此。[^p498-31]中欧，硕士也讲经，直到十五世纪末，终于在神学教授之外，并置《圣经》教授，<a id="pdf-499"></a><!-- PDF page 499; original page 479 -->例如奥古斯丁会士马丁·路德。[^p499-32]有些遭史家忽视的作品，规模巨大。多明我会索斯特的雅各，在科隆，讲《德训篇》《所罗门智训》《希伯来书》《马太福音》的部分内容，留下639页手稿。[^p499-33]讲义被认作学士阶段作品，但篇幅惊人，似不太可能；或是后来在多明我会学校，对学士讲义的修订。科隆在俗司祭、神学家迪特里希·克尔克林，曾代表大学，参加康斯坦茨会议，也讲授《圣经》。[^p499-34]多尔斯滕的约翰内斯，与十五世纪若干重要奥古斯丁会士一样，先在大学取得艺学硕士，再入会；其他如帕尔茨的约翰内斯、约翰内斯·纳廷、约翰内斯·施陶皮茨。他在爱尔福特本会学校，任在任硕士，广泛讲经，页边批注，尚未获研究。[^p499-35]

十五世纪神学家，如前人，相信《圣经》，是连贯的文学群。他们以多种方式解释，其安排，依神学结构。[^p499-36]结构代表上帝与人，交往的历史记录，从应许、预期，到成全，从《旧约》到《新约》。[^p499-37]两约各三分的传统，在十五世纪注释中，仍出现：律法、先知、圣录；福音、使徒、教父，例如丹尼斯·范·莱文。学者知道，如何用两约对照，组织一卷书，如十四世纪，加尔默罗会贝肯索普、方济各会里拉的尼古拉，对《马太福音》所作。他们也会知道，十四世纪初，巴黎方济各会硕士皮埃尔·奥雷奥尔，<a id="pdf-500"></a><!-- PDF page 500; original page 480 -->写过一部《圣经》纲要，范围、简明程度，可与食者彼得《经院史》相比。他按文学风格，依“所采用的八种教导方法”，分八部分。《圣经》目的，被界定为“目的因”，是人类得救，即完满人性的状态。[^p500-38]耶柔米致司祭保利努斯的信，充当多数《圣经》总序；信中，一种文风悖论，既显露，也实现这一目的：《圣经》语言，粗俗、冒犯，唯有属灵洞察者，不如此看；对他们，它是神圣谦卑、交谈的崇高记录。[^p500-39]它属于一种由持续释经史，记录、培育的“实用读写”。[^p500-40]因此，《圣经》，是一部与后来基督教传统，及其主观效果缠绕的文本；按吉尔贝尔·达昂的说法，是“演变中的文本”。作为这样的文本，它在大学研习，日益用欧洲俗语，讲说、阅读，在教会仪式、私人祈祷中反复出现，也以图画，展示于虔敬书、图像、绘画、雕塑。[^p500-41]

从有学问司祭、修士的特权圈层，追踪《圣经》读写，到较开放地方，相对容易；只须追随书籍。中世纪晚期，《圣经》知识媒介增多；同时，教士扩大宗教生活转化的努力，起于十一、十二世纪修道改革，随后两百年，远超修院。[^p500-42]最重要征兆，或是俗语译经。十三世纪起，欧洲各地，法语、德语、荷兰语、英语、意大利语、西班牙语、捷克语、波兰语，及其方言译本，纷纷增多，还包含多种半《圣经》体裁，反映礼仪、祈祷、研究用途：韵文福音，受难记，或塔提安《四福音合参》（Diatessaron）的其他改编；福音读经集、其他选读经集；韵文、散文《诗篇》，有些附彼得·伦巴德取自《常用注释》（Glossa ordinaria）的释文，或其他注释；《雅歌》、<a id="pdf-501"></a><!-- PDF page 501; original page 481 -->《启示录》，以及历史书，或《旧约》选篇叙事。[^p501-43]十三世纪中叶，为法国国王路易九世，编成一部部分《圣经》；大致同时，也有西班牙语部分译本。1280年，完整法译完成。十四世纪，首次出现完整德译，1350年，捷克译，约1357至1360年，荷兰译，1360年，英语译，约1390年；法语《圣经》，继续重抄、重译，零散意大利译本，也被汇成较完整版本。1417年，完整瓦伦西亚语译本完成。

早期经院产生的两部最持久注释，是《常用注释》，以及食者彼得《经院史》。《常用注释》，覆盖整部《圣经》，十三世纪，从巴黎制作中心，传到欧洲所有学校，成为标准注释。[^p501-44]它提供取自教父文学的解释。十三世纪后半叶，拉丁文《常用注释》抄制下降，但部分内容，被纳入一些<a id="pdf-502"></a><!-- PDF page 502; original page 482 -->上述译本，表明它，仍有用途。[^p502-45]《经院史》，是《圣经》手册，混合叙事、释经，协调《圣经》内部，以及经文与世俗历史之间的不同来源。[^p502-46]它被扩写，译为法语，1280年，加泰罗尼亚语，1287年，荷兰语，1361年；十三世纪起，即使非所有，也在多数欧洲语言中，获局部改编。[^p502-47]多数文本，存自修院藏书；平信徒委托或拥有者，通常属贵族、王室。[^p502-48]还应考虑，俗语改编、手册、半《圣经》作品，如詹姆斯·莫里，近来以英格兰为例强调。包括1220至1226年，为法国路易八世，以拉丁文编成的原始《道德诠释圣经》，汇集转述、注释、解释性图像，是后来俗语版本原型；卡乌利布斯的约翰《基督生平默想》，以圣波纳文图拉之名，广泛流传；嘉尔笃会萨克森的鲁道夫《基督传》；奥古斯丁隐修会卡夏的西蒙内·菲达蒂《主救主的事迹》；《黄金传说》选篇、改编；十三世纪晚期，意大利语附注《四福音合参》；1370年前，一部含《常用注释》的荷兰语讲道集；以及以Mammotrectus为基础的拉丁—捷克《圣经》词典。后者原是一部十四世纪早期，方济各会乔瓦尼·马尔凯西尼，所编词典，1500年前，拉丁本出版约二十次。[^p502-49]最早完整捷克、英语《圣经》，也配新序。

所有这些产出，经院注释、不断增加的翻译、多样经文及改编，显示兴旺的教士文化，日益吸引平信徒跟随。但不应高估受益者数量、多样性。许多书，为欧洲最富有的人制作。[^p503-50]另一些，明确显示读者扩大，却只能在有限意义上，称“大众”。著名的中世纪晚期雕版书《穷人圣经》（Biblia pauperum），也存八十余手稿，可提示最广泛读者的性质。它大概1300年前，写于德意志，广传中欧。克里斯托弗·德·哈梅尔，近来称之为“中世纪《圣经》注释中，智识最精深者之一”，显然不为业余者。[^p503-51]如武加大译本、译经早期印本，多数主人，似为修院，许多仅存残片。[^p503-52]它为受训练的眼睛设计：四十幅图，每页两幅，每幅有两场附题注的《旧约》景象，中间纵列基督、玛利亚生平场景，两侧四个《旧约》小人物，以及《诗篇》等引句。显然意在呈现，由属灵主题连接、两约均衡的对应。其他书，设计类似。普瓦捷的彼得（1167—1205年）《基督生平谱系》，以手稿、木刻版流传，图绘基督、荣福圣母生平，与《旧约》预言协调。《人类救恩之镜》，约1310至1324年，也如《穷人圣经》，分四十幅图，通常每幅，含四个插图，现存约394手稿。[^p503-53]《时祷书》，改编自神圣日课、修道每日祈祷周期，尤其敬玛利亚的《荣福圣母时祷》，使用诗篇，以及《约伯记》《雅歌》等《旧约》段落，配图，有些与《穷人圣经》相同。[^p503-54]这些作品，记录<a id="pdf-504"></a><!-- PDF page 504; original page 484 -->预言在过去的成全；此外，《启示录》雕版书，展示未来预言，大概该世纪中叶，首次在荷兰印行，多数流传于十五世纪第三个四分之一时期，包含预言图绘。《雅歌》雕版书，则提示寓意解释。[^p504-55]最后，名为《大卫史》（Historia David）的文本，依旧称《列王纪》诸卷，绘述古代国王生平。

有些作品，尤其《时祷书》，把教士文本，改给非教士读者；但并非如附大赦的荣福圣母、基督受难器具（arma Christi）木刻图，那样设计为大量流通。它们较少代表自由的平信徒虔敬，更多代表受教士指导的敬礼。增加的传播，许多仍用拉丁文。[^p504-56]教会禁令，不鼓励脱离教士控制的《圣经》读写。旧有禁止瓦勒度派译经之外，又有巴塞尔会议（1431—1448年），出于恐惧威克里夫派、罗拉德派、胡斯派的新禁令。[^p504-57]或因威克里夫及追随者引起的动荡、胡斯革命危险、印刷机出现、新教起源，人们倾向看英格兰、德意志，中世纪晚期反译经现象；在那里，翻译、字面阅读，已明确政治化。[^p504-58]1407年，禁止译经、以英语读经，与其他旨在阻碍威克里夫观念、争论的禁令，并列，反映异端、俗语阅读的关联；这在英格兰，直到十四世纪末，才加强。[^p504-59]神圣罗马帝国，皇帝西吉斯蒙德秘书、吕贝克主教约翰内斯·舍勒，1433年，禁止翻译《福音书》《诗篇》，或整个《圣经》；他说，这会在教士中，产生异端、混乱。[^p504-60]1486年，<a id="pdf-505"></a><!-- PDF page 505; original page 485 -->美因茨当选主教亨内贝格的贝尔托尔德，颁令反对从希腊文、拉丁文译经，理由是圣文中，某些语言不能译为德语，未受教育者，也无法理解。一年后，英诺森八世，命所有主教，控制宗教文学出版。[^p505-61]但这些，都不构成压倒性的反对，远不像十六世纪翻译政治。教会立场，是“原则上容忍，实践中不信任”。[^p505-62]

除威克里夫派外，似无人提倡不受限制地读经；十五世纪，俗语神学产出，整体可能下降。[^p505-63]1361年，荷兰语《经院史》，即Historiebijbel的匿名译者，否认宗教读写由教士垄断；但资助者、布鲁塞尔显贵扬·泰耶，仍须反复劝说，才使他着手《智慧书》诸卷。译者为平信徒读者，规避危险的方法，是在序言指导，绝不可过分按字面理解。[^p505-64]除威克里夫派，最著名的中世纪晚期，平信徒阅读倡导者，是新虔敬运动推广者；有人赞其为路德《圣经》首要性原则，或《圣经》人文主义先驱，也有人贬为狭隘反智者。运动重复，荷兰语Historiebijbel序言的保留意见。[^p505-65]聚特芬的杰拉德·泽尔博尔特，在1393／1394年《论德语书籍》（De libris teutonicalibus）中，捍卫平信徒学习，却倡导有限阅读：经卷中，平信徒只有读《福音书》《使徒行传》，才无危险。《旧约》历史书，尤为危险，因为呈现的规范、习俗，不应效法。[^p505-66]这是一种传统教士<a id="pdf-506"></a><!-- PDF page 506; original page 486 -->对平信徒神学能力的保留。[^p506-67]但真正目标，是为德行而读，下文将见。有人认为，泽尔博尔特的谨慎，回应十四世纪末，对共同生活弟兄、姐妹的异端指控。[^p506-68]十五世纪趋势，只会强化有限灵性阅读所暗示的文化边界。整个世纪，弟兄、姐妹，没有成为宗教改革中盛开的平信徒运动之芽；相反，愈重会院内部生活，运动愈具修道性质。[^p506-69]

平信徒阅读，可能好，也可能坏。十五世纪教会，不知有全面禁止译经的禁令。泽尔博尔特后一代，德意志奥古斯丁会士戈特沙尔克·霍伦，认为德语俗语读经，对德意志人的好处，正如古代对希腊人、希伯来人、迦勒底人、哥特人、斯拉夫人、俄罗斯人的好处；真正危险，是哲学文学，使人以智辩机巧为荣。[^p506-70]多少人，会同意？大概很多，但这不等于争相取得宗教书籍。

《圣经》知识，属于教士社会，因而包含教会治理形式，以及经常把圣灵分施于人的圣事经纶，也依赖教会文化先锋；这些先锋，与现代学者常钦佩者，并非同一批。十五世纪，真正教会先锋，并非人文主义者；也并非常被误认如此、倡导受控制阅读的新虔敬运动。几无迹象，表明这种有生命的文本观，连同超越时间的教会共识预设，以及跨世纪真诚心灵相通的信念，在任何地方，被任何人破坏；或许最不曾破坏它的，恰是中世纪晚期异端的《圣经》主义，尽管正统担忧，坏的<a id="pdf-507"></a><!-- PDF page 507; original page 487 -->字面阅读，潜藏于权威危机背后。[^p507-71]先锋，倒可能是热尔松那样的人，憎恶异端，关注道德秩序，坚持阅读与传统连续。[^p507-72]

且看被控者。瓦勒度派运动，始于十二世纪晚期，对福音的一种解释，以及俗语读经。但尽管定期起诉那些被控持有混合瓦勒度教说的异端，1230至1520年整个时期，只有五篇作品，声称是原生瓦勒度派著作，没有一篇属《圣经》作品。[^p507-73]全写于约1368年。若真实，学者倾向相信如此，也仍不足以使我们认为，瓦勒度派，推动大众《圣经》读写；不过，神学家、裁判官，确把《圣经》主义，与此异端相连。[^p507-74]十六世纪二十年代，再有人以瓦勒度派身份，制作书籍，内容却是较通俗的公教敬礼、宗教诗、译经残片，旁有少量胡斯派、新教材料。[^p507-75]除这些片段，与正统作者所见相同。英格兰，对威克里夫的回应，围绕俗语神学地位，引发长期争论，不论其追随者，是否真削弱与神学读经相关的教士特权。[^p507-76]反对者，相信<a id="pdf-508"></a><!-- PDF page 508; original page 488 -->使用俗语经文，导致异端、叛乱。但异议运动的程度、性质，仍难评估，因为“罗拉德”书，呈现的宗教，没有那么戏剧性地独特；它们使教士文化、研经工具，更广泛可及，并非单纯否定既有方法、工具。[^p508-77]威克里夫派释文，争论教义，也遵循学校惯例，引用《常用注释》、里拉的尼古拉、正统神学家。[^p508-78]把教宗认作敌基督，指控托钵修士、教士腐败，也见于拉丁文学，至少部分正统；反修士指控，广为共享。虽威克里夫派《圣经》主义，强调俗语阅读，其释文、讲道，仍含传统内容，例如按四重意义解释段落。[^p508-79]

这是教会保守的世纪，以回应胡斯派、威克里夫派，努力恢复教宗君主制，以及适应教宗在意大利以外，越来越难施世俗影响，为特征。《圣经》读写，应成为有效教士文化的标志，从顶层开始。克拉科夫的马太，在1403年，谴责教宗分裂的悲愤檄文《论教廷污秽》（De squaloribus curie）中，认为教宗对教士的统属，受福音、全部正典经文、教会会议限制。[^p508-80]普法尔茨选帝侯鲁普雷希特三世，1400年，获选德意志国王时，马太已任其告解神师、顾问数年。罗马基督教世界第一位主教，须如此，各地主教，也须如此。法国著名大公会议主义者皮埃尔·达伊（1350／1351—1420年），在康斯坦茨会议（1414—1418年），坚持高级教长，培养像院长般的属灵习惯。他们应年长、审慎、重灵性，更关心教会，而非自身领主事务；并应是“研读<a id="pdf-509"></a><!-- PDF page 509; original page 489 -->神圣经文，而非全然依附实务、法律学科的人”。学习内在于德行，他们应作信徒榜样。克己风度，应包括朴素衣着、节制饮食，进餐听经文讲读。[^p509-81]要点，不是阅读、听闻，而是养成人格；这是奥古斯丁，把研经视为享受上帝的工具、绝非自身目的的德行导向版本。[^p509-82]库萨的尼古拉，在1458／1459年《全面改革》（Reformacio generalis）中，劝庇护二世：登上使徒位置者，即主教，必须成为基督的样式（Christiformes），才能塑造他人，如同基督。一切受神启示经文，都揭示渴望，对基督的渴望；他是德行、不朽生命、永恒幸福的形式。[^p509-83]

库萨，改用一项经院常见观念：读经，塑造灵魂，一个有特定道德能力的自我。[^p509-84]新虔敬运动，系统推广，把神圣阅读、制作书籍，作为核心实践，如克莱尔沃的伯尔纳、圣维克多的雨果、圣蒂埃里的威廉、奥格斯堡的大卫，这些十二、十三世纪，中世纪晚期仍著名的修道作者，所倡导的灵性纪律。[^p509-85]但并非任意阅读。弗洛伦斯·拉德韦因斯《虔敬小论》，指导信徒，明确为了从灵魂根除恶习、种下美德而读：“不应仅为知道而读，而要为知识而读”（Et non debet simpliciter studere propter scire, vel propter scienciam）。他效法波纳文图拉，安排根除恶习训练的阶段：阅读、默想、再祈祷。[^p509-86]他以实际、虽平常的方式，扩展波纳文图拉：使一切神圣阅读，关联爱德、美德；读整书，不只段落；循时间安排；挑出要点，记忆、反刍；让自己受感动、祈祷；选择引向纯心、爱德的书。阅读轨迹，与受难敬礼，向内的轨迹相同，<a id="pdf-510"></a><!-- PDF page 510; original page 490 -->在这方面，弗洛伦斯也少有原创。[^p510-87]每日默想基督受难，应循每周安排；因此，他按日列受难场景，配劝诫提示，帮助默想。

与读经相连的同一目的性，也见于教士影响聚集民众，最直接的努力，即公开演说。如拉丁文、俗语《圣经》，讲道也非纯粹体裁，而是“流动体裁”“中介话语”，与宗教生活转变、自我塑造的努力相合。[^p510-88]听闻，或许比阅读，更应使经文叙事，与德行塑造的灵魂结合。讲道者，也受启示；其预设，是从经文作者，到当代读者，延伸的一条神圣、受启示连续体。[^p510-89]如前所述，这原是教士预设。讲道，如上述《圣经》、注释、半经文改编，长期主要属教士事务：大学、禁院修士、教会会议、宫廷，教宗宫廷，是最显赫讲道场所。但十三世纪起，讲道沿修道影响的路径，进入贝居安院区、医院、平信徒修会、兄弟会。[^p510-90]星期日、节日，祈求游行之旁，特别恩典宣布时，游行路上，以及城市、郊区堂区教堂、主教座堂、修院教堂、诸侯礼拜堂、王室大厅、公共广场，都有讲道。[^p510-91]所有《圣经》知识媒介中，可以假定，经历这种口头媒介者，<a id="pdf-511"></a><!-- PDF page 511; original page 491 -->多于任何其他媒介；理由简单：绝大多数读者能听，远非所有听者能读。

问题在于，讲道代表、促进何种《圣经》读写？如我们对十五世纪欧洲宗教的许多知识，仍有大量待学，不只讲道制作，也包括旧集子的传播、使用。[^p511-92]可以提出两点一般观察。第一，讲道的《圣经》读写，肯定包含一项经院对神圣言说的预设：神圣话语，如古代预言，反映神、人意志、声音交融。但这一预设，可能逐渐不如后一观念有力：好讲道，重现《圣经》雄辩；这一观念，反映古典修辞的人文主义框架。[^p511-93]第二，讲道所显宗教知识，与上文拉丁文、俗语经文及半经文文学中，所构想的有生命《圣经》文本，一致。

经院讲道范型，部分提示这一点。十三世纪晚期起，“讲道术”（Artes praedicandi）手册，在全欧洲推广“新式”讲道，离开古代基督教，逐句阐述经文叙事的简单方式。[^p511-94]新式讲道，主题通常取自福音选读，以拉丁文引用，再经一系列分题、辨析，按<a id="pdf-512"></a><!-- PDF page 512; original page 492 -->较多或较少具有辩证性的框架，组织话语，结合《圣经》、教父、哲学家、神学家、其他古代作者的材料。[^p512-95]我们或预期强调个人宗教经验的神秘讲道，通常也循类似结构。[^p512-96]新式讲道释经方法，与经院经注模式相合：把一段经文字面义的词、观念，与当代思想、宗教情感、道德教导，相联。[^p512-97]看似以外来观念，淹没经文意义；但在常见经院权威、道德例证混合中，《圣经》仍是引用最多的来源：“经节是根，讲道之树，由此长出。”[^p512-98]要点，是把经文文学，与宗教真理、其对个人心灵的效果，连接。注释，也意图产生同样效果。[^p512-99]明星讲道者，例如费雷尔、卡皮斯特拉诺的约翰、贝尔纳迪诺、萨沃纳罗拉，在面对大批听众的公共场面中，加强内在效果，把谴责奢华、仇斗、自恋，与要求人，在末日毁灭，即《圣经》历史终点前，立即悔改，结合。[^p512-100]其讲道，或许较少关乎，在心内重新构想经文叙事，如基督受难敬礼中常见者；更多关乎反复提出，属于内化福音的道德要求。[^p512-101]至少英格兰，新式讲道，从未完全<a id="pdf-513"></a><!-- PDF page 513; original page 493 -->取代古式；两者边界，不宜过尖，以免照单全收，威克里夫对经院讲道的否定，他称之为托钵修士的智辩。[^p513-102]这种否定，把中世纪晚期讲道者的多样，缩成虚假的《圣经》支持者、诋毁者对比。相反，《圣经》读写，属于与各式正式宗教表达，缠绕的有生命文本。

讲道，把多样来源，与经文话语结合，完全符合中世纪晚期《圣经》，作为文化造物的性质。人们相信，经文叙事，在《圣经》、其他著作、口头文本之间，传递、接受意义；上帝意图，把过去、当下，一切人的反思，汇聚成明亮真理讯号。这是对复杂、难把握的书，一种极理想化的看法。它容许释经，适应无数可争辩用途，同时自居全能、单一明确的声音。十五世纪《圣经》，并未造成平信徒叛乱、反教士主义，虽有时与之相连；教士等级体系、特定意识形态，也无法完全控制解释。所有关注经文者，必都同意，其功能，与教会属灵目标相同：逐渐使人，恢复理想生活形式，即救恩。然而，披着如此仁善外衣，《圣经》却能渗入、动摇中世纪晚期欧洲，任何文化世界。

## 译校说明

第489页，拉德韦因斯读书目的的原书英句，译为“不应仅为知道而读，而要为知识而读”；但随后所录拉丁文，直译为“不应仅仅为了知晓，或为了知识而学习”，两者不尽一致。正文保留英句、拉丁文，后文关于为爱德、美德而读的论述，也完整保留。

第484页，约翰内斯·舍勒的皇帝秘书、吕贝克主教身份，按同一人表述；[州档案所录文书](https://arcinsys.schleswig-holstein.de/arcinsys/showArchivalDescriptionDetails.action?archivalDescriptionId=110901&request_locale=de)也称其为吕贝克主教。书中研究现状、“尚无人研究”等措辞，均属原书2009年出版时的判断。
