# 第22章 十字军与征服

马库斯·布尔（Marcus Bull）

<a id="pdf-360"></a>
<!-- PDF page 360; original page 340 -->

十字军，是中世纪基督教文明中，具有鲜明当代回响的现象。它唤起的形象与联想，常遭误解、误用，“9·11”之后尤其如此。自哥特小说兴起，以及浪漫主义者钟情骑士精神以来，中世纪世界的许多方面，都曾以某种方式流行于大众文化中，或享其利，或受其害；但少有像十字军这样，遭严重歪曲。中世纪史上，也没有其他事件或过程，曾促使现代基督徒，无论教宗还是福音派，出面致歉。不过，十字军成为重要研究领域，并非仅因现代耸人听闻的名声，也因它深刻影响中世纪教会与文化。例如，要理解十一至十六世纪，教宗权威如何运作，王权政府如何在意识形态上塑造自身，教会与世俗权威的微妙关系如何起伏，国际性修会如何传播并产生影响，贵族文化如何构成，以及大众虔敬如何表达，就必须了解十字军运动。十字军本属相对新颖的事物，却渗入最根本、最传统的社会关系。例如，1201年，教宗英诺森三世（1198—1216年），颁教令宣告，十字军誓愿，不能被较早的婚姻誓愿取消。由此，教会法处理婚姻的一项核心原则，顷刻被推翻；而教会对此领域的生活，实际上已极认真地介入一个多世纪。与英诺森时代接近的作者，例如威尔士的杰拉尔德（1146—1223年）、海斯特巴赫的凯撒里乌斯（约1180—约1240年），叙述新募十字军战士，挣脱绝望妻子紧抓的双手，故事引人注目。它们或许更多显示，讲道者如何以虚构家庭小景，为讲道增添趣味，而非可观察的现实；但也说明，英诺森回应的是<a id="pdf-361"></a><!-- PDF page 361; original page 341 -->真实的社会张力，直接由十字军运动及其吸引力、要求造成。[^p361-1]

十字军对更广泛理解中世纪生活的意义，在许多背景下，都很明显。有人说，十字军是欧洲税收史的核心，这只是略有夸张；因为巨大费用，迫使教会与世俗统治者，创新汲取臣民财富的方式，再使之常规化。任何讨论犹太人在拉丁基督教世界中地位的历史，都必须充分考虑十字军的影响。第一次十字军（1095—1101年）以前，已有基督徒敌视犹太人的某些证据；但此次十字军宣讲，在法国北部与莱茵兰，引发迫害；其后年代中，宣讲十字架与反犹煽动，又常相伴出现。这表明，十字军使犹太人历史，进入一个新的、充满困扰的阶段。讲道对招募十字军的重要性，以及尤其十三世纪起，教会对此投入日益精密的安排，显示十字军对讨论中世纪传播、读写与口传，以及精英文化、大众文化交流的重要性。十字军也与当代学界，关于中世纪后期西欧文化中心与边缘关系的争论，密切相关。它由改革后的教宗制度构想，主要参与者，来自旧加洛林核心地带，显然出自一个自信、扩张的中心；但其行动，大多发生在拉丁基督教世界边缘，或边界之外，因此又必须适应地方传统与需要。

十字军远征，尤其较成功者，常成为详尽历史叙事的题材；这一事实，揭示它们对讨论中世纪纪念与记忆的重要性。值得注意，最早的大篇幅古法语散文，是两部第四次十字军（1202—1204年）记述，均在所述事件后约十年内写成。作者维尔阿杜安的若弗鲁瓦（约1150—约1212年），以及克莱里的罗贝尔（卒于1216年以后），都是目击者，属于参与者兼历史作者的悠久传统。[^p361-2]这提醒我们，十字军另一个值得关注之处，<a id="pdf-362"></a><!-- PDF page 362; original page 342 -->是它打破观察者与被观察者之间的史学边界，并产生刻意模糊，甚至玩弄文类区分的文本：编年史、史诗歌谣、建基神话、圣杯追寻、君王传记、朝圣指南、旅行记、民族志。此外，十字军的魅力，还在于它们或许独一无二，至少以无与伦比的程度，检验了西方基督徒想象力的边界。所谓想象力，不仅是心中地图，不仅是基督教世界觉得自己，在多大程度上受地理、宗教疆界限制，也包括普通基督徒的能力：他们能清楚表达共同历史、弟兄情谊和爱德的观念，而这些观念，原本可能含混无形、未获实现。

尽管如此，仍须把握分寸。十字军虽然常常重要、影响广泛，却不是整个文明的主旋律。它是一项新事物，同时表达一些根深蒂固的观念；这些观念，早于它、超出它，有时也比它更长久。其间展开一些奇特悖论。十字军是格列高利式教宗制度的创造物；这一制度的改革政策，立足于教士应脱离世俗世界污染性影响的观念。但十字军又是教会，深入最世俗活动——战争——的实践，从而显示，教会需要格列高利主义教导它不信任的世俗权威援助。或许早在第二次十字军（1145—1149年），至少到法国国王路易九世（1226—1270年在位），于1248至1254年发动其第一次十字军时，教宗已严重依赖国王的组织与资源，开展大规模远征。这一过程，换了一种形式，重新造出教宗、皇帝相互依赖的格局；格列高利改革者，曾明确憎恶这种格局，最初发明十字军，正为绕过它。

因此，十字军在中世纪文明中，是一种重要而有限的存在。近几十年，十字军学术研究，之所以拓宽、深化，是因为研究者试图理解它对于中世纪教会、基督教文化意义的复杂性；过去则主要着眼于复述激动人心的故事。二十世纪六七十年代以来，许多令人振奋的中世纪新研究，考察传统史学视野排除的人群，例如女性、穷人、异端和少数群体。新的方法，又为传统主题的理解注入活力，例如<a id="pdf-363"></a><!-- PDF page 363; original page 343 -->借社会人类学与性别研究所得的认识，研究政治冲突。但在中世纪史的旧经典范围内，也就是至少可追溯到十九世纪这一学科创立时的那些领域，十字军或许是近来重新构造得最深刻的一部分。这回应了多方面视角变化。最明显、也可能最重要的一项，是扩大主题的地理范围。从近代早期最初的十字军史家，经沃尔特·司各特（1771—1832年）的《护符》（1825年），到史蒂文·朗西曼（1903—2000年）畅销且不断再版的《十字军史》（1951—1954年），传统图景一向直截了当：十字军在地中海东部作战；事实上，基本由这一事实来界定。为容纳战略上的进退变化，行动区域可以划得相当宽，包括小亚细亚、北非沿岸；但巴勒斯坦与叙利亚，本质上仍被视为十字军的根本活动地区，反映耶路撒冷与圣地，在十字军战士志向中的中心地位。

近几十年，至少对多数学者而言，这一单一图景，已扩大并多样化。如今，人们承认，十字军也在其他地区作战，因而对手，并不只有地中海东部的穆斯林。它们也针对西班牙摩尔居民、意大利部分地区的教宗政治对手、异端，尤其法国南部的卡特里派，以及波罗的海地区、拉丁基督教世界东北边缘以外的异教徒。早在十二世纪四十年代第二次十字军时，就曾尝试在三条大致战线上，同步发动多支远征军：中东、西班牙、欧洲东北部。这次行动的得失，乏善可陈；基督徒攻占里斯本，是唯一持久成果。但彼此真正相连的总体意识，仍持续存在。十二世纪后半叶，虽然西班牙与波罗的海两个战区极为不同，仍可见教宗有时同时对两地十字军产生浓厚兴趣。英诺森三世任期起，教宗试图统筹所有形式的十字军。例如，为鼓励别处远征的招募，可以撤回某地区十字军的大赦，使它“关停”。

这种对于十字军及其目的的广阔视野，反映一种观念：教宗指明的一切具体问题，作为对整个教会的威胁，都具有超越性。这里的教会，可以理解为<a id="pdf-364"></a><!-- PDF page 364; original page 344 -->神意的流出、一种服从关系、一套崇敬传统、一组教义、一系列制度、一个人群、在基督教故事中具有历史作用的地方，或建筑与物品。人们认为，十字军回应的是针对教会这些层面、以不同方式组合而成的威胁。这有助于解释：早在1095年克莱蒙会议发动第一次十字军时，经十三世纪第四次拉特朗会议（1215年）、第一次里昂会议（1245年）、第二次里昂会议（1274年）达到高峰，甚至可以说一直延续至十六世纪特伦托会议，关于十字军的讨论，始终与更广泛的改革努力相连。十字军逐渐不只被看作更新教会、基督教社会所可能附带产生的益处；它代表验证这一雄心的目标，是更新已奏效的确凿证明。

十字军史地理范围扩大，相应也使时间边界延伸。这或许是同样重要的、与旧范式的决裂。传统十字军故事，是一条简单的兴衰轨迹。依此观点，叙事应在1291年终止：马穆鲁克苏丹国，攻占阿卡，以及拉丁基督徒在巴勒斯坦、叙利亚海岸所余的其他据点，结束西方人在此地近两世纪的存在；这种存在，始于第一次十字军期间及紧接其后的征服。诚然，拉丁人并未完全退出地中海东部；他们仍控制塞浦路斯，以及短命的君士坦丁堡拉丁帝国（1204—1261年）的残余地区。但最后的拉丁人，惊慌争抢、挤上离开阿卡的最后船只，这一场景，似乎具有终局性与象征意义，仿佛1975年，人们拼命爬上撤离西贡的最后直升机。无论如何，这一解释认为，当时西欧对十字军的热情，正急剧衰退；这也是事态陷入危局的原因之一。十字军的生命有限，辉煌已过。近来，修正旧说的学者，把十字军年代范围，延伸到十六世纪；某些制度形式，例如军事修会，还延伸得更远。结果显示，旧叙事轨迹，过分简单，且有误导性。的确，若所谓“衰退”，仅指西欧重演第一次十字军的能力、意愿下降，就可以说，十三世纪后期，十字军已衰退。但这一衡量标准，并不比以下说法更合理：1300年的城堡，因不同于两百年前的土丘—围郭式城堡，就某种意义上更差；或<a id="pdf-365"></a><!-- PDF page 365; original page 345 -->认为主教座堂本该继续采用罗马式，而不是哥特式设计。

十字军不断适应、变形，以应对新挑战。例如，十四、十五世纪，它更加侧重海军，反映地中海东部战争的性质；同时，吸纳贵族骑士文化的新重点。大规模集结远征减少，因为战争费用上升，国家又日益控制武人精英的活动，使十字军有时必须嵌入欧洲战争，尤其百年战争的间歇。但1365年，塞浦路斯的彼得一世（1359—1369年），虽短暂却成功攻占亚历山大；1456年，在卡皮斯特拉诺的约翰（1386—1456年）讲道、领导鼓舞下，守住贝尔格莱德，抵抗奥斯曼人；克雷芒六世（1342—1352年）、庇护二世（1458—1464年）等教宗，热心支持十字军事业；1571年，一支西班牙主导的海军联盟，在科林斯湾勒班陀外海，击败土耳其舰队，广受庆贺。这些都证明，十字军作为理想，仍有活力。

那么，什么才是“十字军”？尽管对此著述极多，或许也正因为如此，这始终充满争议。核心难题在于，现代学术使用的术语，来自一系列调和：中世纪受教育精英的拉丁文专业用语；未必能与拉丁文对应词整齐对应的中世纪俗语；开创该领域研究的近代早期学者，所创造的概念与类别，尤其包括大规模东方十字军的编号；以及现代学术话语。中世纪缺少明确性与共识，十分突出：词源上来自“十字架”、且专门用于军事远征的俗语词，证据直到十三世纪才出现，距第一次十字军，已逾一百年。另一方面，没有精确词汇，并不必然意味着，起初没有某些明确观念、形象在发挥作用。近来的用法中，“十字军”常被宽泛用于一切基督徒对穆斯林的战争，或至少其中很大一部分，即有证据表明，一方或双方，有意识地赋予其宗教色彩的战争。这样，就把跨越时空的巨大多样性，压进同一类别。例如，中世纪西班牙基督徒与穆斯林冲突的研究，直到近来，都受一种不愿约束“十字军”词义的态度困扰；使用如此宽泛，终至失去意义。

另一个极端，定义过于精细、狭窄，会使十字军历史，呈现碎点式画面，低估中世纪人，凭想象建立联系、自行化解不一致的能力。然而，要理解十字军对中世纪欧洲的影响，仍有必要尝试定义。它的边缘，或许模糊；但若干核心制度、观念、价值与形象，累积起来，足以使我们称之为十字军“运动”。今天，多数学者，会指出以下主要界定要素：教宗授权，并授予大赦，其具体形式，可能随背后神学而变化；参与者立誓并佩戴十字，誓愿与朝圣誓愿相联系，但并不相同；以及一套本质上回应侵害的正当理由，援引传统正义战争标准，主张解放基督徒与基督教领土，或补救所受损害。

某种清晰定义的价值，也得到以下事实确认：第一次十字军宣讲时，人们为其新颖而震动，尽管这新事物，由熟悉的要素组成。教宗乌尔班二世（1088—1099年），在1095至1096年提出的号召，有许多前例。他回应拜占庭皇帝阿莱克修斯一世·科穆宁（1081—1118年）的求援；这是罗马与君士坦丁堡长期外交往来中的最新一环。他呼吁志愿军，解放耶路撒冷及不信者统治下的东方基督徒，与格列高利改革者的修辞相呼应；乌尔班本人，也是改革者之一。对耶路撒冷、圣墓的强调，以及向有意参加者提出的悔罪性质的任务，汇入十一世纪大众虔敬的强大潮流，也呼应前往东方朝圣的吸引力。有人把乌尔班描述为工匠：重新组合旧材料，创造新配置。这或许低估其个人成就；但创造生于传统的基本图景，是准确的。回头看，可以发现，克莱蒙会议前，事态已逐步酝酿：与格列高利七世（1073—1085年）相关的激进思想者，已试探性地把战争与悔罪相连；乌尔班在自己任期较早时，也提出过作战与朝圣的类比。但不应低估新事物带来的震撼；这本身，就能在很大程度上，解释号召为何成功。卡昂的拉乌尔（约1080—约1130年），为第一代十字军战士坦克雷德（约1076—1112年）所写历史的开头，有一段著名小景：主人公深陷抑郁、焦虑，在领主与<a id="pdf-367"></a><!-- PDF page 367; original page 347 -->武士的责任，以及福音训诫之间撕裂。前者会拖他犯罪，后者实际上意味着转入修道生活。随后，他听到十字军号召，精神骤然完全恢复：因为他领会到，十字军已把骑士身份，从救恩的障碍，转变为得救的途径。[^p367-3]

十字军号召，显然主要针对西欧军事精英构想。早在第一次十字军，乌尔班二世现存的有关言论，就把milites，即骑士，列为主要对象；这一重点，成为十字军最持久、一贯的主题之一。但实践中，十字军的贵族性质，常在两方面受到修正。第一，任何骑士，都不可能脱离照料本人、装备和马匹的附从支持队伍，孤身光荣行动。十二世纪起，勇敢、独行的游侠骑士，成为文学想象偏爱的母题，却与十字军战士的实际经验无关。第二，十字军号召，在根本上具有牧灵性质，强调赦罪，并吸纳朝圣；而朝圣自古向各阶层开放，因此不可能排除不从军的大多数。估计参加第一次十字军的总人数中，骑士约占百分之十；其他大众参与的十字军，大概也有类似比例。十三世纪，东方十字军越来越常乘船出行，较高海运费用，起到社会筛选作用，强化其贵族面貌。从这一时期起，例如1212、1251、1309、1320年，也开始出现大众十字军热潮，并非巧合。这些热潮，通常由官方十字军讲道触发，却又在某种程度上，表现为对贵族常规的反对，自认为更纯洁、更有功德的改进。敌意观察者，常把这些贫穷热心者，称为“儿童”或“牧童”，仿佛要强调其天真误入歧途或颠覆性、社会边缘地位，以及不适合作战。儿童与牧童，可能成为不稳定力量，缺少强有力领导、明确方向时，容易走向过激。但他们至少证明：十字军意识形态，虽首先在贵族文化的优越圈子中安家，其吸引力，在圈外也经久不衰。

这种刻意、持续的精英色彩，既关乎实际到场人数，也同样关乎人们的看法。因此，要评估十字军对整个基督教文化的影响，主要须考察贵族社会。多数骑士，多数时候，并未成为十字军战士；但教会对十字军号召的表达，明显超出其非定期、自愿、仅少数人参与的性质，意图重新界定骑士身份本身。例如，克莱尔沃的伯尔纳（1090—1153年），是最伟大的十字军讲道者、辩护者之一。他在约1130年的《赞新骑士》中论证，为侍奉上帝而作的功德战争，力量如此强大，以至颠倒骑士平常理解自身及地位时，那些安稳的类别与假设。这部论著，直接面向初生的圣殿军事修会，但许多观念，也适用于一般十字军战士。[^p368-4]伯尔纳利用拉丁文militia（骑士身份）与malitia（邪恶）的近似，主张卷入传统内斗的骑士，不能理解为坏骑士：他们根本不配称骑士。沿着这一惊人主题，他进一步挑战：选择malitia而不选择militia，就是丧失男子气概。这是对社会角色性别划分的极大胆正面攻击；而这种划分，实际上构成男性贵族自我塑造的组织原则。指责柔弱女性化，伤人极深。伯尔纳的话，当然是娴熟修辞家为新观念辩护的夸张；但他把男性身份问题，推到话语表面，说明教会希望十字军，对贵族习俗提出根本挑战。

最终，十字军的持久性、适应力，意味着它必须随贵族文化而变化。十三至十五世纪，骑士崇尚发展，对贵族炫示与仪式日益友好，尤其明显。中世纪晚期骑士文化，至今仍常被描绘为形式胜过内容、姿态胜过情感；因此，它与十字军关系紧密，很容易被误解为十字军本身空洞的证据。这会低估骑士文化，作为文化力量的重要性。1454年，勃艮第好人公爵菲利普（1396—1467年），在里尔举行著名、奢华的“雉鸡宴”；宴会上，公爵与许多贵族宾客，隆重宣誓<a id="pdf-369"></a><!-- PDF page 369; original page 349 -->十字军誓愿。这很容易被斥为空洞装饰，却会忽略：像菲利普这样成功、雄心勃勃的政权，能够赋予骑士文化怎样的政治、文化工具价值；进而，也忽略十字军作为激活更广价值体系的理想，有何意义。骑士式炫示，可以与务实的献身并存。众所周知，十四世纪及十五世纪最初二十年，条顿骑士军事修会，吸引西欧贵族、骑士，来到普鲁士总部，再从那里带领远征，穿越大片难行的森林、沼泽，攻击立陶宛敌人。这些Reisen，即“旅行”，多少带有骑士式包办游程的意味；活动结束时，一整套仪式化宴饮、纹章炫示，更印证这种感觉。但这些绝非散步：必须在夏季干热，或隆冬冰冻时，地面才可通行；战役对手，又足智多谋、组织日益严密。因此，尽管贵族经历诸多文化、社会变化，普鲁士远征的要求，仍在十分真实的意义上，直承乌尔班二世第一次十字军时的观念：行动的属灵功德，与其危险、耗时、花费，以及巨大身心努力，直接相关；乌尔班精明地估量过，十字军必然包含这些代价。这一核心价值，使十字军对贵族生活的影响，具有根本连续性，也解释它为何能够渗入个人、群体自我认同的基本方面，例如性别、声誉、仪式和炫示等观念。

十字军还与贵族文化，并在一定程度上，与更广泛大众文化共鸣，因为它使人们有机会，以日常生活少有的方式，把自己置于时间之中。在亲密的家庭层面，这表现为参加十字军的家族传统；值得注意，这些传统，既可经男性，也可经女性世系传递。它们在人们意识中，如此突出，讲道者常用来激起听众本能、深沉的情感反应。早在第二次十字军，教宗欧根三世（1145—1153年），就在十字军通谕《Quantum praedecessores》中，强调这一主题，提醒当时贵族，先辈的成就；并警告，若一代的功业，不能在下一代重现，将蒙受可耻污名。[^p369-5]属于某种连续传统的<a id="pdf-370"></a><!-- PDF page 370; original page 350 -->感觉，也超越家庭，伸展为更广泛的历史责任感。多明我会前总会长罗芒的洪贝尔（约1199—1277年），为第二次里昂会议（1274年），撰写讨论十字军现状、未来的文件时，试图预先回应一种批评：浪费基督徒鲜血，尤其圣路易等受敬爱领袖的鲜血，毫无意义；圣路易不久前，死于十字军行动。洪贝尔唤起查理·马特（684—741年）、查理曼（747—814年），与撒拉森人作战的功业，以及布永的戈弗雷（约1061—1100年），在第一次十字军中的成就。[^p370-6]

看到这一名单，或许会怀疑：洪贝尔为了掩饰基督徒近来的糟糕战绩，已到何种无物可取的地步？三个榜样中，两个已死去四百五十多年，连戈弗雷的功业，也距今近两世纪。这些人物对十三世纪贵族而言，同样活在史诗歌谣英雄的身份中；至少在现代人看来，这更显示洪贝尔历史论证的牵强。但更要紧的是，洪贝尔作为十字军讲道者的经验，必使他相信，这些联系有意义，当时人也重视把自身经验，置于漫长年代框架的能力。事实上，他论证的另一部分，追溯得更远，直到《旧约》时代，唤起十字军与以色列民的对应；自第一次十字军编年史以来，这已是十字军辩护论的惯用材料。《圣经》的联系，还不止于此。十字军，尤其东方远征的吸引力，预设福音事件与当下之间的年代距离，可以消除。圣地是基督生活、死亡、复活的场所，因此仍是他的产业。这样，即使过了一千多年，人们所认为加诸圣地及其居民的伤害，仍应理解为直接、真实地伤害基督本人；他便能通过代言者教宗，召唤追随者，伸雪这一不义，如同世俗领主召集骑士，展开复仇。因此，十字军运转所依靠的，是《圣经》时间、神话历史时间与王朝时间，一种令人振奋、独特的混合。

全面评估十字军对基督教的影响，绝非易事，因为这一运动，以多样的制度、思维习惯和文化<a id="pdf-371"></a><!-- PDF page 371; original page 351 -->形式表达出来。它对基督徒宗教思想，因而对一般教士、平信徒互动，最重要的单项贡献，或许是大赦。大赦成为基准，使教会能在广泛情境中，衡量所提供的属灵奖赏。十字军大赦各种表述的神学基础，以及民众如何接受，都是历史学家激烈争论的问题。第一次十字军时，它大概始于宽厚免除补赎；到英诺森三世任期，转变为免除罪所招致、须在今世及炼狱中承受的暂罚。但民众理解，从不与有时犹疑、含混的官方表述，整齐对应。早在第一次十字军目击记述中，就可见对其属灵益处的最大化解读：作者谈到阵亡同伴时，借用殉道语言。十字军究竟带来何种属灵效果，教士与平信徒，多半同意各持己见，或不提出太多难答的问题。在这一程度上，十字军也是一种创造性遮掩：掩盖受教育者、大众，对功德、奖赏等概念理解的不一致。

就促进宗教虔敬表达而言，十字军最明显的效果，是1099年至萨拉丁于1187年率穆斯林收复期间，拉丁人控制耶路撒冷与圣地。西方前往东方的朝圣，十一世纪已在增长；第一次十字军成功，使真正的朝圣热潮成为可能。拉丁人兴建宏伟的圣墓教堂，以及可容纳数百名贫病朝圣者的圣约翰骑士团医院，显示这一热潮有多重要。在一定程度上，耶路撒冷可以向外传播：受眷顾的朝圣者带回西方的圣物，包括髑髅地及圣墓本身的岩石碎屑，也包括真十字架木片，以及无数其他珍贵物品。仿建圣地建筑，也能强烈表达虔诚依恋。1185年，由耶路撒冷宗主教祝圣的伦敦圣殿教堂，是这种通过模仿实现认同的例子；约1500年，在萨克森东部格尔利茨，兴建的圣墓小堂精巧复制品，是另一个例子。有人主张，十二世纪圣地开放的效果之一，是在西方大众虔敬中，加强对基督人性，并进而对荣福圣母玛利亚的依恋；这种情感，十三<a id="pdf-372"></a><!-- PDF page 372; original page 352 -->世纪起，虽拉丁人已失去圣地控制权，托钵修会仍能维持、发展。这一论点，很有吸引力；但也暴露难题：难以从基督教生活的诸多变化中，单独划出明确、专属十字军的效果。对基督人性的关注，有许多早于十字军的复杂根源；西方对圣地的依恋，也表达一般朝圣热情，并非仅属朝圣意识形态中的十字军这一支。

人们常说，中世纪在整个欧洲大舞台展开的诸多事件、过程中，十字军最常闯入编年记录、编年史、奇迹集、圣徒传、城市史和家谱；这类文本，通常由地方事务主导，视野十分有限。换言之，至少按这一指标，十字军最有助于打破地方局限，促进彼此相连的基督教世界意识。这一看法，多有可取，却不宜夸大：即使十字军打开新视野，这些文本的范围，大多仍牢牢局限于本地。同样，十一世纪起，拉丁文明中心与边缘的诸多深刻重组，从来不只由十字军造成。十字军的重要，在于它是更完整图景的一部分；这幅图景还包括教宗改革运动、国际性修会的成长、讲道等传播技术的变化、海上扩张、军事技术发展，以及伊比利亚半岛、东欧和较有限程度上的中东，向边界及跨越边界的人口移动。十字军要求西欧人，重新审视基本身份；但其表达方式，又肯定他们熟悉的参照，尤其贵族地位、家庭，以及附着于财产、忠诚与义务、服役与奖赏的价值。十字军是一项非凡创新；一位第一次十字军的历史作者，称它为“获得救恩的新道路”。但其效果，是使中世纪后期欧洲文明的基督教身份，发生转调，而非根本重构。
