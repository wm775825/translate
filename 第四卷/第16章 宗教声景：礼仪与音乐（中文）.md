# 第16章 宗教声景：礼仪与音乐

苏珊·博因顿（Susan Boynton）

<a id="pdf-258"></a>
<!-- PDF page 258; original page 238 -->

音乐在中世纪基督教世界至关重要。演奏、演唱与创作，不只反映历史神学环境，也主动决定礼仪、虔敬经验。中世纪盛期与晚期，音乐家继续经营传统圣咏，也创作礼仪内外表演的新音乐。本章旨在说明这些趋势在宗教文化的位置。[^p258-1]

1100—1500年，圣乐功能、场景不断扩展，不只守规教士礼拜、堂区居民参与的礼仪游行，也有平信徒和教士赞助者专门委托的祈愿演出，以及平信徒团体集体歌唱。行会及其他团体，愈参与宗教音乐赞助、表演；托钵修会重属灵教导，培育唱俗语歌的平信徒善会。[^p258-2] 礼仪表演，仍是修会成员集体身份基石。但并非人人同样献身司祭职。十三至十五世纪，发展培训专业教会歌者的机构，许多<a id="pdf-259"></a><!-- PDF page 259; original page 239 -->隶属咏祷教士团教堂、主教座堂的音乐家，仍只具低级圣职。守规教士，一日大部分时间唱礼仪，这是团体生活本质；希尔德加德、海斯特巴赫的凯撒里乌斯等修道作者，生动展示。[^p259-3]

中世纪晚期，弥撒、日课以外的虔敬纪念仪式，音乐也愈重要。通常关联教堂特定空间，如追思弥撒堂、圣母小堂、侧祭坛。纪念亡者，超越长期的亡者日课、为亡者祈愿弥撒传统，纳入捐赠者指定、专门资助的追思礼。非全部唱出，但带音乐者增多，证明十四、十五世纪宗教声乐复调真正爆发。[^p259-4] 现知首组同一作曲家所作复调弥撒常用部分乐章，是纪尧姆·德·马肖（1300—1377年）《圣母弥撒曲》（Messe de Notre Dame），为圣母祈愿弥撒，可能旨在每年于其任咏祷教士的兰斯主教座堂演唱，纪念他本人。[^p259-5] 作品体现1100—1500年圣乐创作两大力量交汇：相信为亡者唱祷有效，及崇敬圣母，视其为有独特代求能力、帮助求援者的圣徒。赞助者相信，祈祷可减灵魂在炼狱时间，使音乐祈祷在代求文化居核心。

音乐始终是基督教思想组成部分，中世纪盛期晚期，神学意义持续丰富。拉丁礼仪，新旧文字音乐互动，经文与非经文交织，创造<a id="pdf-260"></a><!-- PDF page 260; original page 240 -->展演式释经：实时表达多层《圣经》阅读，在一场礼仪、一天、一节期、整个教会年反复演出。[^p260-6] 经文并置、交织、扩展，实际演出预象、寓意、末世意义。历代注释者，以基督教预象解释《诗篇》为预言；自古代晚期渗透礼仪的诗篇吟唱，每日实践此解释。诗篇音乐表现涵盖连续风格：从日课、部分弥撒的诗篇吟唱，连续诗节用相同、简短重复旋律，至为单节或数组诗节——有时结合其他文本——谱成长度、复杂度悬殊的圣咏。

教士须背诗篇，在日课合唱，反复歌唱，加频繁阅读反思，使经文深印心中。音乐表演赋诗篇、其他经文以多层意义，依其特定礼仪功能形成联想，储存敬拜者记忆，塑造评注传统。

呼应礼仪诠释倾向，许多新作是应用经文评注技术的诗，解释所庆节日意义。继叙咏（sequence）是成对短句组成的诗，在弥撒哈利路亚后唱，九世纪起源，初近散文，十二、十三世纪显著发展。日耳曼地区，以加洛林晚期核心曲目，不断累积新作；西欧其他地区，十二世纪起主要类型，却以简短易记乐句、节奏富感染力的押韵歌词为特征。

<!-- PDF page 261; original page 241 -->

圣维克多的亚当、阿伯拉尔、希尔德加德等宗教作者，创作这类新继叙咏，反映当时神学话语，歌词密布经文意象、多层预象。[^p261-7]

本质上更具释经性，是附加段（trope）：在既存圣咏加入新词、新音乐，形成结构上融入圣咏自身的礼仪评注。它们呈现诗人作曲家与音乐礼仪环境，以及基础圣咏经文与中世纪释经传统间，引人入胜的对话。[^p261-8] 有些更以对话写成，如复活节早晨的半戏剧《你们寻找谁》（Quem queritis）。[^p261-9] 约1300年，西欧多数附加段较少见，虽德语地区仍兴盛。[^p261-10] 一些修会把它排除于礼仪，多地继叙咏似已取代它，成为新创作首选。奥古斯丁守规咏祷教士、多明我会等，发展自身继叙咏曲目，表现宗教共同体集体身份。[^p261-11] 其他如十二世纪熙笃会，修订圣咏旋律，创造自认为更真实的版本。[^p261-12]

<!-- PDF page 262; original page 242 -->

1100—1500年，礼仪音乐修订创作从未衰减，留下大量中世纪晚期圣咏，至今大体未获学者探索。许多为新教会年节庆，如基督圣体节，或庄严程度提高的圣徒纪念、其他庆节，提供弥撒日课新曲。新词可配既有旋律，形成音乐学家称“换词曲”（contrafact或contrafactum）的类型。通过原圣咏文字音乐的回响，可建立超越当下所唱文本表面意义的多层意涵。[^p262-13] 但有些目的，需创全新成套圣咏；尤其圣徒韵文日课，十一世纪起增多，十三世纪极普遍。[^p262-14] 十三世纪，坎特伯雷的托马斯、多米尼克、方济各等广受崇敬圣徒的日课，为其他圣徒日课提供词曲范本。新册封的平信徒圣徒，尤其匈牙利的伊丽莎白、查理大帝、法国路易九世等王室圣徒，也有专用日课；为适应不同机构环境，常有多版本。[^p262-15] 一些创作说明塑造中世纪世界的重要历史变化。例如，殉道挪威王奥拉夫·哈拉尔德松日课的创作传播，反映王室推动挪威基督教化。[^p262-16] 同样，为巴黎圣礼拜堂取得荆冠圣物，促成新日课，<a id="pdf-263"></a><!-- PDF page 263; original page 243 -->在国外某种程度成为礼仪地位象征。[^p263-17] 与早期圣咏曲目不同，新日课并非全匿名；作曲家的个人身份、艺术家地位，愈受重视。[^p263-18] 庞大晚期日课库，构成可比同时期文字圣徒传的声音圣徒传，自有惯例，反映宗教、社会经济、政治变迁。

个别节庆成套圣咏之外，也有整部曲目，为特定共同体需要而生。十二世纪，阿伯拉尔为埃洛伊丝保惠师修院，编赞美诗集，包括许多自作。[^p263-19] 十四世纪中叶，瑞典的布里吉特创建布里吉特会（Brigittine，亦拼Bridgettine），修女有独特曲目，称“修女圣咏”（cantus sororum），含新作与传统成分。从瑞典母院瓦德斯泰纳，远传亨利五世创建的锡安修院；无论个别圣咏风格，或每周礼仪循环中大量重复材料，都反映此默观修会重简朴严峻。[^p263-20] 保惠师、布里吉特会是修道共同体，但也有为平信徒参与礼仪发展的宗教曲目，如意大利劳达赞歌（laude）。波希米亚胡斯运动，产生捷克语礼仪译本，及全新俗语圣咏，首次见于十五世纪二十年代晚期、或三十年代早期手稿，与<a id="pdf-264"></a><!-- PDF page 264; original page 244 -->非礼仪捷克语宗教歌曲同存。[^p264-21] 十五世纪新虔敬运动（devotio moderna），产生配拉丁、荷兰语歌词的音乐。[^p264-22]

1100—1500年最重要发展之一，是书写复调愈突出，形式功能愈复杂多样，同时更简单的口传复调，仍繁荣。[^p264-23] 现知最早书写实例中，有十一世纪手稿，将教会年某些庆节弥撒、日课圣咏的独唱部分配复调，尤其弥撒哈利路亚、升阶咏、晚祷答唱。以弥撒专用圣咏为基础的奥尔加农（organa），构成十二世纪晚期、十三世纪巴黎圣母院复调曲目核心。[^p264-24] 至十五世纪末，主导者转为弥撒常用部分复调：垂怜经、荣耀颂、信经、圣哉经、羔羊经。该世纪后半，许多弥撒，取世俗法语歌曲音乐，而非传统圣咏旋律。十五世纪中叶至十七世纪末，数十部弥撒使用《武装的人》（L’homme armé）一曲，可能联系纪念朗基努斯的“武装者”仪式，或神学上以武装者为基督的理解。[^p264-25] 弥撒回响熟悉的法语歌曲（香颂，chansons），因此把新的词曲联想带入礼仪。借世俗音乐习惯，更生一层音乐互文：香颂弥撒，常与先前同曲为基础的弥撒相连。

香颂弥撒这类曲种存在，证明世俗、宗教音乐文化的边界，即使<a id="pdf-265"></a><!-- PDF page 265; original page 245 -->存在，也可穿透；我们视宗教的音乐，当然并非全为礼仪而作。十一至十三世纪，许多可唱的拉丁节奏诗，反映圣母、道成肉身等当时教义关切，谱曲贴切传达文本思想。[^p265-26] 有些拉丁歌的世俗词，显露宗教争论，可联系大学环境。[^p265-27] 同样，俗语中世纪歌，让人理解平信徒宗教经验。某些有特定仪式功能，如意大利善会唱劳达赞歌。[^p265-28] 即使似为娱乐，如南法游吟诗人（troubadours）、北法游吟诗人（trouvères）的歌，也见证创作者宗教观，有时吸收教会影响。庞大曲集，似结合平信徒表演、虔敬、娱乐，是俗语圣母奇迹大全《圣母颂歌集》（Cantigas de Santa Maria）：十三世纪加利西亚—葡萄牙语宗教歌集，归于卡斯蒂利亚、莱昂王阿方索十世。[^p265-29]

礼仪、宫廷曲种交相滋养的最佳例子之一，是经文歌（motet），多声部作品，十三世纪生于法国北部，十四世纪传遍西欧。[^p265-30] 早期是新旧互动沃土：多数有以礼仪圣咏旋律为基础的定旋律声部（tenor），其他声部词则新诗，常法语。有些把不同文本分给不同声部，产生延及作品之外、与其他作品的互文。许多十三世纪俗语经文歌，共用称叠句（refrains）的短文本；它们及其他联系，<a id="pdf-266"></a><!-- PDF page 266; original page 246 -->形成复杂互文网络。[^p266-31] 起源虽有争论，最初手稿即与其他新宗教、世俗声乐并存，见其流行。十三世纪法语经文歌，接近北法游吟歌；诗词代表宫廷爱情传统，却经常取自既有圣咏的定旋律，与礼仪相连。好例是十三世纪晚期《蒙彼利埃抄本》的《比花更美／花是她的儿子》（Plus bele que flors/flos filius eius；章末例1）。[^p266-32] 它从十一世纪早期、归沙特尔主教富尔贝尔的圣母答唱《耶西之根干》（Stirps Jesse），取乐句作定旋律声部基础，完全融入另三声部构成的复调整体，每部唱不同法语词。定旋律词“花是她的儿子”（flos filius eius），借代唤起整篇答唱，以基督解释《以赛亚书》11:1—12：“耶西根干生枝条，枝条开花；滋养之灵安息花上。枝条是童贞的上帝之母，花是她儿子。滋养之灵安息花上。”[^p266-33]

此类作品的丰厚织体，使个别歌词身份，基本消融。虽多文本同时演唱，使每个无法持续清晰可闻，但独特元音、节奏型，从声响群突出；歌者、读者能感知个别文本及彼此关系。例如三篇法语词都出现flor（花），联系定旋律flos，意指基督。表面类型多样，实则微妙相连。最高的第四声部（quadruplum），以宫廷爱情效劳方式表达圣母虔敬；同样方式，也见于歌爱情、春至的第三声部（triplum）。直到<a id="pdf-267"></a><!-- PDF page 267; original page 247 -->第四声部唱到中段，说话者才透露，所爱是童贞女玛利亚。第二声部（motetus）也歌爱情，却用牧歌叙事，春日起兴，带情欲意味：叙事者遇见的非牧羊女，而是衣着精美女士，诉爱之苦，仍宣布决意坚持。转述话语末两行，采用众多十三世纪法语歌中的著名叠句。西尔维娅·于奥指出，第三声部，在音乐上处复调整体中央，在文本上中介第四声部的圣母虔敬，与第二声部暗含诱惑的园中遇女；回响渗透圣母礼仪文本的《雅歌》语言。[^p267-34] 因而，结合诸歌词，加上作品外部却影响效果的回响，形成广泛互文网络。演出中，各部融成平滑听觉织体，多样曲种、意象汇流，生既宫廷又虔敬的情歌，如许多十三世纪俗语宗教歌。[^p267-35]

圣俗相似共生，也见博韦《但以理剧》，十二世纪晚期音乐剧，汇音乐诗歌多风格、拉丁俗语对话、生动人物。玛戈·法斯勒论证，它反映法国北部座堂教士文化，尤其副执事世界；博韦割礼节喜庆日课，也可窥见，似与愚人庆节有关。[^p267-36] 十三世纪某些受难剧，纳入俗语歌，提供早期圣母哀歌例子。[^p267-37]

宗教、世俗、拉丁、俗语互动，尤其生动者，是十四世纪早期、插入音乐的《福韦尔传奇》（Roman de Fauvel）手稿。这部独特、插图丰富的汇编，结合并置礼仪圣咏、法语歌曲、复调，将它们穿插于<a id="pdf-268"></a><!-- PDF page 268; original page 248 -->叙事段落之间，叙事略加掩饰地讽刺当时法国宫廷权贵。[^p268-38] 十四世纪稍后，马肖作品代表圣俗融合，尤其经文歌，以礼仪圣咏定旋律，结合世俗法语歌曲、拉丁诗风格的声部。安妮·沃尔特斯·罗伯逊近来认为，其早期经文歌构成连贯套曲，反映晚期神学，尤其海因里希·苏索《智慧时钟》等神秘著作。[^p268-39] 单首或整体，均以展演推演复杂神学、音乐、诗歌思想。

马肖拉丁经文歌《福乐童贞女／无玷生母／我们向你叹息》（Felix virgo / Inviolata genitrix / Ad te suspiramus），展示晚期经文歌词曲交织、丰富生义（例2）。[^p268-40] 定旋律取《又圣母经》（Salve regina，“万福，母后”），十二世纪起，日常、每周纪念圣母所唱四大圣母对经之一。不像与诗篇或颂歌同唱的对经，如晚祷《尊主颂》、终祷《今释仆颂》，圣母对经单独唱，在某些礼仪后，尤其礼仪日末的终祷后，先游行至圣母像，再唱。这晚间敬礼，广至在俗、守规、托钵教士、善会、行会，成为西欧宗教共同体共有声景。终祷游行，及关联圣母代求功能的其他仪式，产生无数复调，许多以圣母对经为基础。《又圣母经》比另三大对经更突出：乔叟等作家提及，多明我会文学与奇迹相连，更有自身评注传统。[^p268-41]

每日唱《又圣母经》的教士歌者，必能听出马肖经文歌贯穿引用。如第三声部，称玛利亚“我们唯一的希望”（sola nostra spes），回响对经“我们的希望”（spes nostra）。第二声部末节，“啊，因此”（Eia ergo）、“并转向我们”（et versus nos converte），也引用该经。第二声部还引熟悉圣母赞美诗《万福，海星》（Ave maris stella）：“为我们预备安全道路”（para nobis tutum iter），可能出自诗的“预备安全道路”（iter para tutum）；第一节末“海星”（stella maris），也可能暗指它。第三声部第一节，“你如此摧毁异端”（sic hereses peremisti），结合“童贞女”（virgo）、“喜悦”（gaudium），可能暗引圣母答唱：“欢乐吧，童贞女玛利亚：整个世界，唯你摧毁一切异端”（Gaude Maria virgo: cunctas haereses sola interemisti in universo mundo）。词之外，经文歌高声部，又以对经开头乐句，微妙唤起《又圣母经》旋律；定旋律声部没有它，而取其后乐句。通过巧妙引用、扩展，缺席的旋律片段遂在场。

罗伯逊认为，经文歌把敌人入侵、折磨、迫害，与惯常求圣母慈悲代求交织，可能暗指创作时百年战争，包括兰斯围城，使《又圣母经》普遍祈求，带上当下历史迫切关切。她更扩展引用网络，提出作品用于兰斯座堂中殿、每日终祷后的圣母纪念礼。此礼由查理五世1380年创设，含继叙咏《无玷、完整、贞洁的玛利亚》（Inviolata, integra, et casta Maria），开头圣母称谓，与经文歌一声部相同；并有圣母对经，可能即词曲贯穿作品的《又圣母经》。[^p269-42] 地方因素，与广泛集体求代祷形式交汇，使马肖作品演出，获植根兰斯座堂仪式生活的具体意义。

<a id="pdf-270"></a>
<!-- PDF page 270; original page 250 -->

某些经文歌，为特定场合的庆典创作，既紧连某堂礼仪实践，也反映更普遍传统。名例是纪尧姆·迪费《近日玫瑰花》（Nuper rosarum flores），为1436年佛罗伦萨座堂奉献礼而作。复杂构造，成为教会及奉献礼神学的强化论述。整体时间结构，据《列王纪》所罗门圣殿相关数字；两个定旋律声部，用教堂奉献弥撒标准进堂咏，另两个高声部词，则专属佛罗伦萨座堂，紧连专为奉献礼所作继叙咏。[^p270-43] 北方人迪费为该座堂作曲，见晚期音乐国际性：法语、佛兰德语地区作曲家，广在意大利工作，赞助者、演奏者、手稿，又把英格兰作曲家音乐带大陆。不论原乡，仍为礼仪作乐、创经文歌，包括歌词日益多样的圣母经文歌。

马肖独特引用《又圣母经》约百年后，十五世纪七十、八十年代三首圣母经文歌，除代表大集体，更有为具体个人代求含义。洛伊塞·孔佩尔《充满一切美善》（Omnium bonorum plena），取极流行香颂旋律，标题也回响海内·范·希泽赫姆《充满一切美善》（De tous biens playne），恳圣母怜悯一系列具名歌者，包括作者自己。若斯坎·德·普雷《万福玛利亚，充满恩典／主与你同在》（Ave maria gratia plena / Dominus tecum），纪念教会年圣母节庆循环，结尾以惊人简朴的音乐宣叙：“上帝之母，请记念我”（Mater dei memento mei）；这词常见于连捐赠者也画入的圣母祈愿图像。[^p270-44] 正是具体普遍、新旧、俗语拉丁、宫廷礼仪等意义汇流，揭示音乐在中世纪宗教文化核心地位。[^p270-45]
