# 第9章 重新界定天主教：特伦托及其后

作者：罗伯特·比雷利，耶稣会士（Robert Bireley, SJ）

<a id="pdf-168"></a>
<!-- PDF page 168; original page 145 -->

1563年12月4日下午约四时，特伦托大公会议二百三十五名有表决权的成员，从图恩宫列队走向座堂，卡塔尼亚主教在那里主持圣神弥撒。随后，会议以压倒多数通过前数周拟定的五项改革法令。接着，宣读过去十八年会议所通过教义法令的全文，再读改革法令的开头各段。主教向与会教长提出两个问题：是否同意宣布会议结束，并请罗马教皇庇护四世确认全部法令？第一问，他们重申前一天的肯定答复。第二问也得到同样回应，只有一票反对；这意味着明确承认教皇权威，标志教皇制的一次重大胜利。会议主席乔瓦尼·莫罗内枢机，遂在全场不胜欢欣之中，宣布会议结束。[^p168-1]天主教会内部的改革更新运动，由此达到重要里程碑。

多年来，历史学家使用不同名称描述16至17世纪天主教。“反宗教改革”把其发展基本视为对新教改革的回应，令人想到宗教裁判所、《禁书目录》，以及宗教战争的政治、军事措施。许多天主教徒长期以同样带有党派性的立场，反驳这一片面看法。他们偏爱“天主教改革”，认为教会早在1517年前，就已开始必要改革；因此，基督教整体分裂，应由新教改革负责。第二次世界大战后，重视教会合一的数十年间，一种折衷得到广泛接受：

1517年前教会内部的改革运动如同溪流，直到路德攻击带来震动，才汇成河流，最终抵达教皇制，促成1545年召开特伦托大公会议。因此，“天主教改革”与“反宗教改革”共同描述直至17世纪末的天主教会。[^p169-2]但仍没有单一名称能概括这一时期。两词虽标示近代早期教会的重要面向，却主要按其与宗教改革的关系界定，忽略16世纪天主教许多与新教无甚关系的发展，例如新修会兴起和海外传教。此外，“改革”暗示宗教改革前夕，教会一直衰败，而近来许多研究已挑战这种看法。因此，虽显平淡、涵盖面却更广的“近代早期天主教”，似乎日益获得接受。[^p169-3]或许最有成果的路径，是把天主教与新教运动都视为竞争性的努力：面对16世纪初变化的世界，使基督教会更新。这些变化包括现代国家显著成长、人口经济扩张、首批欧洲殖民帝国出现、包括印刷术发明和科学革命在内的文艺复兴；对天主教，还当然包括新教挑战。如过去屡次发生，16世纪基督教再次面对适应变化中之文化社会的需要。因此，在当时天主教中发现近代早期态度与价值，并不令人惊讶。[^p169-4]

早在特伦托之前，不大关注北方事态的新修会与团体，已在富有感召力者领导下自下兴起，开创新的宗教生活及服务形式；最重要者是嘉布遣会、耶稣会和乌尔苏拉会。意大利方济各会严守派的马泰奥·达·巴肖聚集小群体，旨在复兴原初方济各精神，1524年获最初教皇认可，1536年会宪获批。他们因佩戴尖头兜帽（capuche），很快称嘉布遣会；17世纪“黄金时代”，人数近三万。新成立的耶稣会，最初源自西班牙贵族依纳爵·罗耀拉的属灵经历。1537年末，他与十名同伴到达罗马，随后严寒冬季中，讲道并<a id="pdf-170"></a><!-- PDF page 170; original page 147 -->服务穷人；1540年，教皇保禄三世正式批准为新修会。1556年依纳爵去世时，会士约一千名，遍布欧洲大部，远至亚洲和美洲；此时创办三十三所学院，显示其转向教育，这是当时一种创新的服务形式。1516年，约四十岁的虔诚未婚平信徒安杰拉·梅里奇，从威尼托故乡迁至布雷西亚，很快与当地神爱祈祷会合作，帮助新设不治病院的妇女部。活动逐步扩展到照顾孤儿、教导少女基督教教义；她的目标很快成为建立贞女与寡妇团体，如初期教会前辈般在世间服务。约三十五人的群体，1535年首次正式组织；1544年，即安杰拉死后五年，最初会规获教皇批准。随后，她们扩及其他意大利城市，再主要进入法国，越来越转向教育，并在压力下具有隐修修会的特征。

查理五世皇帝、法国国王弗朗索瓦一世与保禄三世长期谈判后，教皇最初于1536年召集的大公会议，终于1545年12月15日“喜乐主日”（Laetare Sunday）在特伦托开幕。这座城市位于阿尔卑斯山意大利一侧，却仍属帝国。会议分三期举行：1545年12月至1547年3月，1551年5月至1552年4月，停顿十年后，再于1562年1月至1563年12月举行。开幕时，仅四名总主教、二十一名主教和五名修会总会长，以有表决权成员身份，在三位教皇使节指导下出席。会议起初面对：先澄清界定教义，还是先制定改革法？查理希望先处理纪律，以期一旦显出明确改革意志，新教徒便来与会，开启教义理解之路。但教皇坚持先明确天主教教义，消除信众普遍疑虑；他也担心，为和解而作可疑神学妥协。最终，各方同意交替处理教义与改革。后来，特伦托被批评阻碍同新教和解，但这忽略当时新教教会已制度化，也忽略1540年沃尔姆斯、1541年雷根斯堡宗教会谈均告失败。

正如会议的伟大史家胡贝特·耶丁所说，特伦托的历史意义在于两项成就。[^p171-5]第一，澄清多数遭新教质疑的天主教教义；第二，提出系列改革，不仅消除弊端，也建立更新的牧灵方案，把主教和堂区神父置于教会使命中心。面对“唯独《圣经》”，会议主张神圣启示以两种形式传递：《圣经》与可追溯使徒的未成文传统，并坚持教会有权威解释经文。法令初稿说，启示部分包含于成文经书，部分包含于未成文传统，暗示两者是独立渠道。但少数教长反对，认为《圣经》以某种方式包含全部启示，因此更接近路德。措辞遂修改，使两渠道关系较含混。[^p171-6]实际而言，多数主教大概确把传统理解为经文的补充，后来多数天主教神学也明确如此。哈恩主教、西班牙枢机佩德罗·帕切科领头的许多主教，希望禁止被视为异端之母的本国语文《圣经》译本，正如西班牙、法国和英格兰教会或世俗当局已下令。但特伦托主教诸侯克里斯托福罗·马德鲁佐率领反对，阻止措施通过。后文将见，宗教裁判所后来又回到此问题。

最重要的教义法令关乎称义，回应路德“唯独信仰”立场，并深刻影响天主教灵修。教长和神学顾问自1546年6月末着手，直到1547年1月13日正式一致通过。法令精心撰写，之前至少有四稿，大量依靠经文，常被视为神学杰作。它不仅有谴责不同立场的三十三项教规或绝罚条款，还有十六章正面阐明教义，解释教规，旨在为讲道提供基础。最终法令有三大特征：首先，在强调罪人绝不能凭自己称义、称义完全是上帝白白恩赐，并将全部主动归于上帝的同时，<a id="pdf-172"></a><!-- PDF page 172; original page 149 -->肯定个人必须合作，因此自由意志在过程中具有积极作用。第二，宣布称义不仅包括赦罪，还包括与基督结合、圣神灌注之后的内在转变更新，而非仅把基督功绩施加于人，或给予神圣恩宠的好处。最后，会议主张，已称义者必须继续行善；正因与基督结合，善行能获更多恩宠及永恒赏报，而这种功德本身也是恩赐。[^p172-7]

两个问题引发大量争论。会议最终拒绝，却未谴责，所谓“双重称义”的新观念。这是意在与路德宗妥协的公式，曾由加斯帕罗·孔塔里尼枢机提出，1541年雷根斯堡会谈上获梅兰希通接受，却遭罗马和路德拒绝；奥古斯丁会总会长吉罗拉莫·塞里潘多又向会议提出。第二，教长谴责路德认为称义之信包括对个人得救之完全确信的立场；经过努力，他们找到这样的表述：“没有人能凭那种排除一切错误的信仰确据，知道自己已获得上帝恩宠”，或知道自己属于预定永生者，除非特别启示。[^p172-8]

会议也重申天主教关于基督在圣体中真实临在、弥撒具有祭献性质的立场。其他法令阐明圣事性质，列举七件圣事，包括有私下耳语告解的悔罪圣事、圣秩与婚配。面对教长认为过度的社会压力，会议宣布，双方自由同意是婚姻有效的必要条件。所谓秘密婚姻，长期引发严重牧灵问题：仅凭双方同意——这确实构成婚配圣事本质——缔结婚姻，却无正式公开承认。一位在特伦托的葡萄牙神学家说，里斯本教区一百名听告解神父，九十四名曾处理秘密婚姻后果。经过长期辩论，不顾相当少数反对，会议才颁布《虽然》（Tametsi）法令，要求婚姻有效须有堂区神父或其代表，以及另两三名见证人在场。许多反对者认为，此举超出教会权力。

主教和堂区神父，不仅应是教会官员，也应是与羊群同住、有效牧养讲道的人。一个教省的主教，应每三年在总主教主持下举行教省会议。大公会议加强主教在本教区的地位，回应他们常用的不驻牧借口：自己在家中不能作主。如今，主教控制教区中谁能受圣秩，并在讲道、听告解等牧灵事务上获得更大监督权。教区会议应每年举行，主教应定期巡察教区；堂区神父也应常住、定期讲道。《圣秩法令》规定，每教区建立培养神父的修院。会议最后数日通过的其他法令，旨在结束圣像、圣徒及圣髑敬礼、炼狱和大赦方面的滥用，同时重申它们对天主教敬虔的作用。

但会议也避免在重要问题上表态。许多教长原期待一项改革诸侯的法令，天主教统治者却无热情；教长深知教会改革需要诸侯支持，遂作罢。因此，会议没有声明教会与世俗政府关系，也不挑战许多诸侯在教会任命方面的特权。教长同样未能立法全面改革罗马教廷，实现中世纪后期改革者所谓“首脑与肢体的改革”。新修会与团体，以及亚洲、美洲不断扩大的传教活动，也未获认真关注。

尤其是，会议没有处理教皇的角色及其与主教整体的关系。鉴于新教攻击教皇制，人们当然可能期待它处理此事。教皇派为防大公会议至上论复兴，努力把问题排除议程，大体成功。但在讨论主教驻牧时，问题两次浮现。尤其西班牙主教主张，只有宣布神圣法本身要求主教住在教区，才能真正阻止教皇给予豁免，并足以有力诉诸主教良心。枢机及其他教廷官员反对，因为许多人就是不驻牧的主教，也认为这限制教皇权力。后来一项法令草案，没有说明主教职分本身是<a id="pdf-174"></a><!-- PDF page 174; original page 151 -->按神圣法存在，留下教皇制是主教权力来源的解释空间。此问题引发紧张，压力似乎促成两位教皇使节于1563年3月去世。庇护四世遂派莫罗内枢机到特伦托，任新会议主席，成功安排妥协。《圣秩法令》宣布，教会圣统制按“神圣设立”存在；配套法令则说，主教按“神圣命令”必须住在教区，却不再说明义务性质。这明确适用于教廷官员，但也容许，特定情况下，基督徒爱德及教会更大利益，可准许主教离任。[^p174-9]

会议确实大幅增加教皇权威。教长请求教皇确认法令；庇护四世以《天主当受赞颂》（Benedictus Deus）诏书批准，日期倒署1564年1月26日，直到6月30日才公布，之前罗马官员确保教皇获得解释会议法令之权，并设立新的解释大公会议圣部。会议后积极有为的庇护五世（1565—1572）、格列高利十三世（1572—1585）、西克斯图斯五世（1585—1590），加强教皇地位；国际修会，尤其新成立嘉布遣会和耶稣会，则成为盟友。会议结束时，委托教皇一些提升其威望的任务。依会议请求，庇护四世于1564年3月出版《禁书目录》；同年稍后，《特伦托信仰宣认》问世，总结会议教义法令，包括服从教皇的承诺。此后，所有主教、修会上司、堂区牧者、教授和学位申请者，在就职或授学位之前都必须签署。1568年，庇护五世任内，出版多数教士每日诵读的《日课经》新版本；两年后又出版新的《罗马弥撒经书》。

特伦托之后，全教会主教素质最终逐渐提高。许多教省和教区会议，把决议转为区域与地方方案，但欧洲各地数量差异很大，除法国外，1600年前后明显减少。主教巡察更为持久，留下有关近代早期教会生活的丰富文献。但主教相对于世俗权力和教皇的权威，都有所下降。教皇常在诸侯与主教冲突时支持前者，<a id="pdf-175"></a><!-- PDF page 175; original page 152 -->因为对抗新教、推动改革，都需要诸侯支持。1565至1584年的米兰总主教、圣洁而严肃的嘉禄·鲍荣茂，长期被视为特伦托模范主教的化身；但近来研究发现，他倡导一种以主教权为重心的特伦托解释，却未获胜。他虽忠于罗马，却不满罗马监督，尤其格列高利十三世时期。与西班牙世俗当局冲突时，教皇不愿热情支持，使他烦恼。1583年，格列高利与巴伐利亚公爵威廉五世缔结协定，也令当地主教不快。教皇让公爵有权向教士征税、作许多教会任命，并监督广大教产。尽管特伦托禁止兼领圣职，格列高利却准其在德意志实行，尤其哈布斯堡与维特尔斯巴赫这些教会坚定盟友，因为它们提供能在政治上加强德意志脆弱天主教的主教候选人。西克斯图斯五世颁新规，要求世界各地主教定期赴罗马述职（ad limina），但直到1600年后才逐渐实施。他也重组已超出中世纪行政能力的罗马教廷，设六个圣部或部门治理教皇国，另九个管理普世教会，各由一名枢机主持。他把枢机人数大增至七十，成员几乎全为意大利人，逐渐由定期会见教皇的顾问，变成教会官僚。这一重组削弱枢机团作为国际代表机构近似宪制性的角色。枢机会议由每周两三次，减至1600年后每月两次，决策权更集中教皇本人。

教廷仍有裙带与庇护关系，但不妨碍情况改善。敬虔成为风尚，教皇官员兼领圣职减少，不过驻任规定常放宽，例如对教廷大使，因为根本没有其他供养办法。自15世纪中叶发展的君主式教皇制趋势，带来17世纪宫廷的排场。教皇实际上也治理一个诸侯国。直接赠与、年金及非教会职位，把资金输往教皇家族及其依附者。保禄五世·博尔盖塞（1605—1621）的家族，由罗马城市贵族升为意大利大地主家族之一；一个依赖教皇恩宠的新罗马贵族阶层兴起。其他人则在教廷寻求较有限的社会<a id="pdf-176"></a><!-- PDF page 176; original page 153 -->和政治晋升。反宗教改革时期的教皇，同文艺复兴前任一样，致力确立罗马作为基督教世界中心的应有地位，主持无可匹敌的城市更新与艺术资助计划，鼓励富戏剧性、宏伟纪念性的巴洛克风格。新圣彼得大殿，是其最佳成果的典范：1506年儒略二世任内开工，1626年由乌尔班八世祝圣，广场柱廊1666年亚历山大七世任内完成。米开朗琪罗与贝尔尼尼都留下印记。

西克斯图斯五世重组的教廷圣部中，居首的是宗教裁判所。1542年，保禄三世改组中世纪宗教裁判制度，以对抗新教威胁；1571年又设禁书圣部，监督出版和书籍审查。宗教裁判所最初被设想为遍及基督教世界、审理异端的法院网络。但西班牙、葡萄牙已有运作的裁判所，法国及多数天主教国家，也不肯容它在境内活动。实践中，其执行决定的能力仅限意大利部分地区；不过，罗马希望它与禁书圣部的决定，成为全教会规范，正如其继承者信理部的决定直至今日仍然如此。

宗教裁判法院在意大利最活跃于约1580至1620年。到1580年，异端威胁已退，法院更多转向“非法巫术”，以及其他偏重道德而非神学的越轨。近来研究反驳长期神话，指出罗马宗教裁判所一般遵循审慎法律程序，比同时代其他法院更尊重嫌疑人权利。学者发现，判词常不应照字面理解，例如“终身监禁”可能意味着囚禁三年。最可靠的数字显示，1542至1761年间，宗教裁判所处死约一百人；最著名的是焦尔达诺·布鲁诺，1600年在鲜花广场被焚。[^p176-10]或许其最有害影响，在于恐惧和对思想生活的威吓，但这些难以可靠衡量。1596年，克莱孟八世的《禁书目录》长期犹豫后，因本国语文经文常与异端相联，禁止《圣经》译成意大利文，从而<a id="pdf-177"></a><!-- PDF page 177; original page 154 -->追随西班牙、葡萄牙宗教裁判所。但禁令不适用于阿尔卑斯山以北。[^p177-11]

天主教改革同新教改革一样，旨在向普通人传播福音。宗教信仰无法衡量，但大概总体关联宗教知识与实践。有些地区到1600年已有增长，另一些直到18世纪之交以后。新教改革先在城市扎根，天主教改革也一样：慕尼黑、里昂、巴塞罗那等城市，常因耶稣会学院创立而受到促进。运动逐渐进入腹地，再深入乡村。从地域看，意大利北部、西属尼德兰、莱茵地区、阿尔萨斯、洛林及周边、巴伐利亚和伊比利亚半岛部分地区，最先受影响。法国大部在17世纪上半叶，哈布斯堡奥地利与波希米亚大部则直到下半叶。

天主教徒和新教徒都认识到必须争取青年，也都把学校视为主要传教手段。历史运动很少像两者这样重视教育，它们共享文艺复兴对教育的热情。新修会与团体成员常担任男女教师，耶稣会与乌尔苏拉会都如此，这是修会生活史上的新发展。耶稣会1548年在西西里墨西拿设首所学院，到1600年已有236所；据估1630年法国学生达四万。学生社会组成各异。意大利贵族比例似高，其他地方却不然。1620年代，法国羊毛贸易中心马恩河畔沙隆，官员、商人和手工业者家庭都大量送儿子入学。学院成功有数因：通常由诸侯、教士或市政府捐资，免费教学，并提供社会上升途径。资助者喜爱它们，因为既培养政府官员，也培养教区与修会神父。许多家庭和学生，认同其结合基督教、人文主义，以及高阶经院因素的课程，以学识和敬虔培养青年。其他团体也追随创办学院：巴尔纳伯会1533年最初在米兰成立，旨在牧灵与教理教育；西班牙人若瑟·加拉桑于1602年在罗马设立的虔诚学校修会，<a id="pdf-178"></a><!-- PDF page 178; original page 155 -->原为贫困男童提供免费初等教育；还有祈祷会法国支会，它附属于圣斐理伯·内里1575年在罗马建立的团体，在教皇压力下，到1631年已管理三十一所学院。

妇女方面，安杰拉·梅里奇的乌尔苏拉会，于1567年应鲍荣茂召赴米兰，协助宗教教育计划，转向教育。1598年，教皇领地阿维尼翁成为其进入法国的跳板，再扩至西属尼德兰。1612年巴黎团体的两项举措，具有决定意义。其一，接受修道院围禁制度，部分由于法国圣统制和社会施压：人们不赞成单身妇女在家庭或隐修院之外生活；部分也出于自身愿望，效法当时正在法国建立的阿维拉德肋撒之赤足加尔默罗会。其二，巴黎乌尔苏拉会获得教皇批准，另发专门从事教育的誓愿。由此形成兼顾默观与课堂教学的新女性修会生活形式。乌尔苏拉学校成为使天主教欧洲人口基督教化的重要力量。到1700年，仅法国就有三百余所会院；因此，17世纪法国教会女性化进程中，该会充当先锋。[^p178-12]许多其他团体继起，包括路易丝·德·马里亚克与文生·德·保禄的仁爱修女会，源头可追溯1629年，致力于照顾穷人，而非教育。

1551至1650年，新建或恢复的大学，天主教四十五所，新教二十六所。[^p178-13]最重要者之一，是依纳爵1551年亲自为耶稣会修生设立的罗马学院；1580年代格列高利十三世重建其稳固财务基础，因此今日称格里高利大学。1552年成立的日耳曼学院，很快与其联系，并成为希腊学院（1577）、英格兰学院（1578）及其他民族学院的模式，旨在为大部分非天主教地区培养教士。罗马由此成为教士教育中心。

特伦托教长认识到，教区神父的培育教育，是改革关键，因此要求每教区设修院。法令最终影响深远，实施却耗数十年，甚至数世纪。到17世纪初，一些地区的教区神父素质<a id="pdf-179"></a><!-- PDF page 179; original page 156 -->有所提高，部分或许归功于耶稣会学院等因素；但到18世纪初堂区神父显著改善，修院功不可没。特伦托式修院在法国最为成功，虽然最初进步也缓慢：1620年已有十六所，多数只供少至十名学生住宿，学生去本地耶稣会学院上课；但1642至1660年，新设四十所。法国修院教育，深受一种新现象帮助，即共同生活团体：神父共同居住，实践福音的贫穷、贞洁和服从，却不正式发愿。包括皮埃尔·德·贝吕勒1611年创立的法国祈祷会，文生·德·保禄1625年创立的遣使会，1642年开始的圣叙尔皮斯会，以及1643年开始的欧德会。它们后来管理法国许多修院。其灵修聚焦司铎职。贝吕勒说：“人有两类：领受耶稣的神、光和恩宠者，以及传递这些者。前者是全体信徒，后者是司铎。”[^p179-14]法国教区神父日益明显的共同精神，部分源于这一崇高司铎观。但这种角色观，加上教育、如今常穿的长袍，以及更加矜持的举止，也使他们更疏离堂区信众。

近代早期教会，运用新旧多种方法向信众传福音。托钵修会早已派传道者深入民间；如今，先由嘉布遣会、耶稣会，后尤其在法国由遣使会、欧德会和祈祷会展开的民众传教，其新处在于明确策略方法。国内传教者先在城镇，后在乡村讲道；意大利和西班牙耶稣会士，因乡村居民宗教无知、举止粗野，称那里为自己的“印度”。更关键的是城乡堂区的定期讲道。特伦托坚持，主教与堂区牧者的主要任务都在讲道。会后数十年，许多讲道著作出版，建议不同修辞风格；也有讲道集帮助牧者履行星期日和节日讲道义务，例如乌赫尔主教安德鲁·卡佩利亚，1593年出版六百页加泰罗尼亚文讲道集。[^p179-15]但仍需很久，尤其<a id="pdf-180"></a><!-- PDF page 180; original page 157 -->乡村牧者，才会充分准备，并愿定期讲道。责任仍落在修会，尤其城镇广受欢迎的将临期与四旬期系列讲道。

与学校、讲道的基督教化作用重叠，是定期宗教教育，即教理讲授。16世纪可以称为教理问答时代。1536年，意大利神父卡斯泰利诺·达·卡斯泰洛在米兰发起青年民众教理教育，形成基督教教义善会。1584年鲍荣茂枢机去世时，米兰总教区约四万男女童，在740所学校——几乎每堂区一所——由近三千教师指导。[^p180-16]特伦托要求牧者定期、至少星期日和节日，教导儿童教理。许多教理问答上市，帮助牧者及其他宗教教育者；或许最重要的是德意志耶稣会士伯多禄·加尼削的作品，1555至1566年分别为大学生、青少年和儿童出版，直到1597年去世前，合计印行二百余版。但教理教育常遇牧者和父母反对，他们不愿让儿童星期日下午待在室内。有些牧者在弥撒讲道后教理。当时开始在首次告解、首次领圣体前，系统准备教学，似乎更加成功。到世纪中叶，许多法国牧者已定期教理。

弥撒，尤其堂区星期日与节日弥撒，仍是天主教礼拜中心，乡村更如此。城镇中，修会教堂成功与堂区教堂竞争，在礼仪风格和灵修上提供选择，有时与堂区教士产生争端。到17世纪初，对虔诚者而言，每月，或至少每年四次告解、领圣体，成为标准。有些历史学家认为，告解前仔细省察良心，是走向系统、有条理思维的一步。耶稣会士胡安·波兰科按依纳爵指示编写、1564年应罗马当局敦促出版的流行听告解手册，把安慰悔罪者视为圣事主要果实之一。[^p180-17]更频繁告解，使信众经常接触教士，扩大<a id="pdf-181"></a><!-- PDF page 181; original page 158 -->其作用。新兴或复兴的敬礼凸显，许多与善会相联，常涉及区分天主教与新教的实践教义，从而促进宗派认同，例如朝拜临在圣体的基督、敬礼童贞玛利亚、为炼狱灵魂祈祷。当局努力清除游行、朝圣及其他仪式中凡俗或迷信因素，成效不一。天主教徒一般比新教徒更易容忍地方习俗和民间方式，宗教当局与地方领袖往往达成默契。

16世纪，善会在天主教生活中作用更重要，教会当局也努力加强控制。克里斯托弗·布莱克估计，到1600年，意大利大城市每三四名男子，就有一人在生涯某时加入善会，妇女与青少年人数较少。[^p181-18]善会种类极多。其数量和成员扩张，以及新近强调慈善工作，在一定程度上回应不断增加的贫困、不幸者，尤其城市人口。许多善会与修会相联，尤其在城镇，提供堂区之外的选择。主教常推动每堂区，即使偏远者，至少设一善会，以争取支持牧者。堂区牧者与平信徒善会领袖间，无疑有摩擦，但不清楚多常发生。

天主教改革与新教改革，都肯定世俗、或平信徒召命的正当性。这一肯定，以及示范如何在世间过基督徒生活，构成基督教适应近代早期的进一步努力。它重申文艺复兴人文主义，以及从巴黎传播至西班牙、罗马的复兴托马斯主义立场；后者产生多明我会的多明戈·德·索托、耶稣会的弗朗西斯科·苏亚雷斯等杰出神学家。两者都对人性提出乐观看法，认为自然与其在恩宠中的完成之间，广泛和谐。持续存在、强调人类罪性的奥古斯丁式悲观潮流，与之相反，尤其在法国冉森主义中突出，却未占上风。依纳爵1528至1534年在巴黎求学，后来耶稣会会宪推荐阿奎那《神学纲要》作神学教材，并不奇怪。他的《神操》培育了<a id="pdf-182"></a><!-- PDF page 182; original page 159 -->肯定世界的灵修。即使有原罪，后来人类又滥用上帝恩赐，创造在根本上仍然良善。这也意味着，基督徒能在任何职业或生活身份中追随基督。

这方面，比依纳爵更重要的，是温和而坚定的日内瓦主教方济各·沙雷氏。他通过大量通信作属灵指导，尤其指导女性；她们对更深基督徒生活的渴望，令他印象深刻。其中有萨伏依公爵驻伯尔尼共和国大使二十岁的妻子路易丝·德·沙泰尔。方济各在她身上，认出上帝召唤她过“虔敬”生活。1607年，他为她写一套灵性指引，1609年以《虔敬生活入门》出版，对象是虚构的“斐洛德亚”（Philothea），即爱上帝或与上帝相爱的灵魂，无论男女，“生活在城里、家庭中或宫廷，其生活身份要求他们在外表上过普通生活”。[^p182-19]他描写性、心理性的方法，令人想起他熟悉的蒙田《随笔》。1622年去世前，本书至少出四十版；新教徒和天主教徒都读，常用删节本，至今仍是基督教经典。

许多人沿同一路径写作，虽未必同样文笔清晰，也示范人如何能够，而且应当，在世间作基督徒。1612至1615年，西班牙耶稣会士路易斯·德·拉·普恩特写出四卷《基督徒各生活身份中的成全》。法国耶稣会士尼古拉·科桑，1624年末在巴黎出版《神圣宫廷》，直到世纪末，欧洲各主要语言持续出现版本译本。他主张，连朝臣和宫女也能作好基督徒，举大量例证。这一文类也包括反马基雅维利传统，旨在反驳《君主论》之说：始终遵守基督教道德原则的统治者或政治人物，无法按取得、维持权力的标准获得成功。两位作者开创传统，都于1589年出版：佛兰德斯人文主义者尤斯图斯·利普修斯《政治六书，或论国家》，以及意大利神父乔瓦尼·博泰罗《国家理性》。他们尝试在马基雅维利自己的政治实践领域与其交锋，说明其方案只会毁灭国家，而明智地依基督教道德原则行事，却能够，而且必将，建立稳定强大国家。这两本书是<a id="pdf-183"></a><!-- PDF page 183; original page 160 -->17世纪上半叶阅读最广的政治著作，其流行显示，同时代人意识到国家成长时，多么关注宗教、道德和政治关系。

法国耶稣会与冉森派长期、痛苦的争论，围绕基督徒与世界关系，更具体说，是救恩过程人类活动相对于神圣行动的价值，以及教会是否须调整道德教导、适应变化世界。鲁汶神学家科尔内利乌斯·冉森的《奥古斯丁》，于1640年、他死后两年出版，充满对原罪后果的深刻神学悲观，似乎否认自由意志在人得救中的作用。耶稣会神学家认为，这仿佛返回新教改革者立场。此外，冉森同道、神父圣西朗院长让·迪韦尔日耶·德·奥朗，以及显赫高等法院官员家庭之子安托万·阿尔诺，质疑当代，尤其耶稣会的道德神学。特伦托要求听告解者受更好教育，促成道德神学论著编写，准备神父面对可能遇见的良心案例，即教导决疑术。这些巨著为求周全，有时铺陈异常复杂、似乎荒唐的例子。但决疑家发挥关键作用：把传统原则应用于变化社会，例如贷款收息，或少女自由选择婚姻伴侣。数学家、科学家布莱兹·帕斯卡，在1656至1657年匿名连载、精彩却片面的《外省人信札》中，嘲讽耶稣会恩宠立场，以及他归于该会的宽松道德神学。耶稣会作者回应，却敌不过其论战技巧。冉森主义争论长期存在，但1650年代后，更多成为政治而非神学问题。帕斯卡似乎担心，自己的信札不仅伤害耶稣会，也伤害基督教事业，遂着手为信仰写辩护，即《思想录》，1662年去世仍未完成。

诸侯对推进天主教事业作用显著，其好战也助燃宗教战争。教会需要国家支持，国家则日益控制教会。反宗教改革的显赫统治者，有西班牙国王腓力二世（1556—1598）、先为巴伐利亚公爵后为选侯的马克西米连（1598—1651），以及皇帝斐迪南二世（1619—1637）。三人都真诚追求天主教胜利，也倾向将之等同<a id="pdf-184"></a><!-- PDF page 184; original page 161 -->自身政治利益。1596年末，斐迪南以大公身份开始统治内奥地利后不久，尽管顾问警告此举政治上不智，仍开展严格、常常严酷的再天主教化。受耶稣会鼓励，他觉得蒙上帝召唤，要恢复领地天主教；内奥地利出乎预料的成功，又强化使命感。1618年波希米亚叛乱尘埃初定、1619年当选皇帝后不久，他在奥地利与波希米亚领地发动反宗教改革，最终会有效恢复天主教，但要到世纪末才实现。天主教与王朝、贵族一道，成为多民族哈布斯堡君主国三大支柱。

他日益卷入后来成为三十年战争的德意志冲突。1627年末，他与盟友马克西米连的军队，控制德意志北、中部大部。耶稣会听告解神父威廉·拉莫尔迈尼敦促，天主教选侯支持，他于1629年颁布影响深远的《归还敕令》，要求把1555年《奥格斯堡和约》后，新教徒夺取、天主教视为非法占有的广大教产，归还天主教会。这项极端措施，显示战争对斐迪南和马克西米连的宗教性质，疏远此前效忠的新教邦国，尤其萨克森与勃兰登堡，并助促1630年瑞典入侵。1631年9月，古斯塔夫·阿道夫在布赖滕费尔德决定性击败天主教军，逆转整个战局。1634年讷德林根战役重建军事平衡后，斐迪南放弃好战方案，就《归还敕令》妥协，1635年与萨克森缔结《布拉格和约》，多数德意志邦国后来加入。它为1648年《威斯特伐利亚和约》铺路，最终结束欧洲大陆的宗教战争。漫长战争扰乱欧洲许多地区后，改革与宗派化进程，还将至少持续到18世纪初。
