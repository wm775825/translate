# 第六卷翻译规范

## 范围与方法

- 《剑桥基督教史》第六卷《改革与扩张：1500—1660》，夏伯嘉（R. Po-chia Hsia）编，2007年出版，共774个PDF页面、六编30章。
- 继续由当前代理逐章翻译，不启用并行翻译代理，不调用外部翻译服务。通用术语继承前五卷；前卷的出版年份、专有疑点及例外仅适用于各原卷。
- 正文、引文、解释性脚注完整译为中文；参考文献作者、原文题名、刊名和出版定位保留原文，以便检索。文献标题出现在正文时，可译成中文并于首见处保留原文。
- 保留原PDF逐页锚点。正文原页码为PDF物理页码减23；原书无印刷页码的空白页，按连续页序推定时明确注明。
- 章节、段落、长引文和论证顺序依原文；跨页句子连续衔接。脚注编号以来源页和原注号组合，避免章节和分节重新起号所致冲突。
- 保留推测、否定、主语归属与宗派论争语气；原书“目前”“近来”等均依2007年出版语境理解，不更新为今日情况。
- 英文转换完成、中文翻译完成、源文核对、全卷校订和PDF导出分别记录；自动底稿不等于校定英文文本。未译章节的特殊字库、上下标、图表及分栏继续逐章复核。
- 对原书明显的内部矛盾，保留原载并另加译校说明，不悄然重写原文。正文不调用外网补写史实。
- 插图保留原图，图题和说明译成中文；目录和索引中的原书页码，不当作中文PDF页码。

## 宗教改革通用术语

| 原文 | 译法与区分 |
|---|---|
| Reformation / reform | 宗教改革／改革；按事件与一般行为区分 |
| Protestant / Protestantism | 新教徒／新教 |
| evangelical，16世纪语境 | 福音派的、福音的；不专指现代福音派 |
| Lutheran / Lutheranism | 路德宗的、路德派／路德宗 |
| Reformed / Calvinist / Calvinism | 改革宗的／加尔文宗的、加尔文派／加尔文主义；依制度、信徒与思想分别处理 |
| confession | 宗派；具体信仰声明为信仰告白、信纲，不与告解混同 |
| confessionalisation | 宗派化 |
| Catholic Renewal / Counter-Reformation | 天主教更新／反宗教改革 |
| Orthodox，路德宗争论 | 正统派；不译成东正教 |
| Eastern Orthodoxy | 东正教；与上一项区分 |
| Anabaptist / Spiritualist | 重洗派／属灵派 |
| magisterial Reformation | 世俗当局支持或主持的宗教改革；不机械译为教权改革 |
| state-church / territorial church | 国家教会／领地教会 |
| Estates，帝国宪制 | 帝国等级；与社会阶层、地产区分 |
| Reichstag / Imperial Chamber Court | 帝国议会／帝国最高法院（Reichskammergericht） |
| magistrates / magistracy | 城市执政官、城市当局；不机械译为治安法官 |
| ius reformandi | 宗教改革权 |
| cuius regio, eius religio | 谁统治，便信谁的宗教；必要时简称教随国定 |
| justification / sanctification | 称义／成圣 |
| righteousness / grace | 义／恩典 |
| sacrament | 西方传统一般用圣事；新教尤其路德宗语境用圣礼 |
| penance / absolution | 悔罪、告解圣事／赦罪、赦罪宣告，按语境区分 |
| indulgence | 赎罪券；明确作为教义效力讨论时可用大赦 |
| Nominalism / scholastic theology | 唯名论／经院神学 |
| chapter，教会机构 | 教士团；不译作章节 |
| consistory | 教会法庭、教务会议；依各地机构职能说明 |

## 已确认的原书疑点

- 第一章原书第3页威克里夫生卒年1384—1443，原样保留并说明。
- 编者序说“第一、二编的十二篇”，实际两编合计八章；前三编才共十二章。已在译文标明。
- 第二章原书第23页加尔文生卒年列作1509—1559，保留原载；第29页把1530至1580写成三十年，保留并指出算术不一致。
- 第二章原书第34页同段Krell／Kress，中文依上下文统一“克雷尔”；第28页隐秘加尔文派的临在教义表述，已查看原图，未自行更改归属。
- 第二章注7原页码398—397，保留；注29的奥西安德尔生年1498与正文约1496不同，各依原载。
- 目录Miriam Bodiam和作者简介Oliver Christin，按原印保留外文；中文用“米里亚姆·博迪安”“奥利维耶·克里斯坦”，另说明后者与章目Olivier的差别。


## 后续章节术语与交付状态

- social disciplining：社会规训；church discipline：教会纪律。Geneva Consistory：日内瓦教会法庭；Lutheran Consistory：路德宗教务会议。
- beatification／canonization：宣福／封圣；beata：在世虔敬妇女，不一律视为已获正式宣福。
- chorale／plainchant／motet／polyphony：众赞歌／素歌／经文歌／复调音乐。
- natural theology／mechanical philosophy：自然神学／机械论哲学；Christian Hebraism：基督教希伯来学。
- huaca／ayllu／cofradía：瓦卡／阿尤／善会；按安第斯语境说明，不预设单一宗教归属。
- cultural imperative／communities of effective rituals：文化要求／有效仪式共同体。
