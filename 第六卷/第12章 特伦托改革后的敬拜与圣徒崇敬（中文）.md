## 1. 引言：特伦托之后的礼仪改革

特伦托重申神圣罗马教会出于神圣设立，其核心是肯定教皇训导权。与世俗当局围绕一般教职荐举权、尤其主教任命的冲突，长期受学者注意；但特伦托后不久，教皇明显率先行动的另一领域，却较少受到关注：礼仪改革。大公会议最后的第25会期，已将此完全交教皇裁量。从1568年修订《罗马日课经》出版，到1614年修订《罗马礼典》发行，不到五十年，罗马教会前所未有地提供意在具有普遍效力与权威的文本。下文聚焦《日课经》改革，不仅因其问题最直接关联圣徒崇敬，也因相关过程，能说明特伦托改革整体如何被接受、解释。

改革委员会成员不求创新，而是“使日课回归古代［的简朴］”（ridur l’officio all’antico）。按庇护五世所言，目标是恢复“教父原初准则”（pristina patrum norma），让平日，即非庆日的日课，更常诵念。[^p224-1]平日日课以《诗篇》为中心，原定每周诵完一百五十篇，并配其他重要经文，其中许多附简短讲道，常出自教父。庆日则删去这些经文及评注，<a id="pdf-225"></a><!-- PDF page 225; original page 202 -->腾出篇幅读所纪念圣人之生平。数世纪间，圣人历不断增补，1100至1500年约增二百，结果到16世纪，平日日课实际上被纪念圣人的庆日日课边缘化。[^p225-2]使用者重读圣徒传，却忽略许多诗篇、《圣经》重要部分及相应讲道。这种失衡对修会成员和虔诚信众学习天主教教义与敬虔，影响显然，却仍须重申；因为历史学家过度关注特伦托要求每教区设修院培训俗世神父的效果，遮蔽了礼仪、祈祷及圣徒崇敬的教育作用。

重新规定庆日重要程度与应读圣徒传篇数的关系，为平日日课清出许多空间。普通单式庆日（simplex），圣徒传限一篇，总共三篇，另有经文、讲道各一；双式或半双式庆日（duplex、semi-duplex），上限三篇，总共九篇，另有讲道三、经文三。重要的是，单式庆日不再准以专门编写的日课，取代平日日课。常有多位圣人同日庆祝，因此必须分等级、定优先。尤其庆日碰上将临期主日或圣周，或与基督生平有关的重要节日之八日庆期——主显、割损、圣神降临、耶稣升天、圣体，或教堂、教区主保日——重叠时，较小庆日移至下一可用日期。总体结果，每年约一百五十七日可诵平日日课，尤其集中四旬期。

必须强调，删减圣人历并非新关切。例如1414至1418年康斯坦茨大公会议已讨论，也构成基尼奥内斯枢机激进得多的《圣十字日课经》（Breviarium sanctae crucis，1535／1536）背后动机。后者旨在私人敬虔，而非修会团体在教堂咏经席共同诵念，<a id="pdf-226"></a><!-- PDF page 226; original page 203 -->被列1557、1559年《禁书目录》前，已印百余版。但读1568年新特伦托《日课经》前的教皇诏书Quod a nobis，立刻可见另一层雄心：明确禁止继续使用无法证明至少连续二百年的一切地方变体，意在提供普世适用的历书。不过，一些特定修会日课确符二百年规定，得以合法继续。例如1568至1660年，本笃会日课至少印八十五版，多明我会二十六版。[^p226-3]米兰安博礼等无可争议的古老礼仪，也获保存。[^p226-4]教区日课方面，法国尤其大规模坚持地方传统，欧洲他处无法相比；同期间约三十九教区印自己日课，共九十八版。[^p226-5]此外，修订《罗马日课经》六十余年中，又有1602、1632两次版本，均须纳入新增、恢复的圣人敬礼，因此本卷所涉时期结束时，那些优先于平日日课的圣人庆日，从1568年104个，增至1686年145个。

合看这些因素，以粗略的自上而下模式解释礼仪改革，并不适宜。而且，事情并非中心追求统一、被边缘实践障碍挫败这么简单。特伦托之后最早数年，证据就显示，主教不仅请求罗马准许继续诵念地方主保日课，罗马圣统制地位最高、思想影响最重要的人，也亲自参与必要文本修订，富创造而灵活地调和特定教区敬礼与普遍规定。例如，<a id="pdf-227"></a><!-- PDF page 227; original page 204 -->致古列尔莫·西尔莱托枢机的信，显示仅意大利就有约二十二教区，于1570至1584年间求助。他也是负责1568年日课修订委员会的重要成员。[^p227-6]1588年，专门处理此问题及相关封圣程序的礼仪与典礼圣部建立后，可见罗伯特·贝拉明、切萨雷·巴罗尼奥等显赫人物，认真、细致地处理这些琐节。[^p227-7]

但要理解地方教区与罗马之间对话何以如此广泛，须了解作为最终参照的《罗马日课经》之复合结构。正如名字所示，它实际上多书合一，整体结构反映这一点。读者先见圣人历，附计算复活节等移动节日的表；接着《诗篇》；再是节期专用日课（Proprium de tempore），包含诵每日平日日课所用祷文、答唱、经文及讲道读经。随后，特为某些圣人写成、在其庆日诵念的专用日课，包括圣徒传，称圣人专用日课（Proprium sanctorum）；再后，是为精修者、殉道者等不同类别准备的通用日课，供没有专用日课的圣人使用，称圣人通用日课（Commune sanctorum）。最后主要部分，是追思亡者日课、圣母小日课等附加礼仪。

卷首《总礼规》（Rubricae generales）引导读者在各部分往返，拼合每日正确的读经、祷文与诗篇。但主要部分外，还常有第二套圣人专用日课，这次限于某地区、教区特别或专门敬礼的圣人。地方专用日课（propria）的存在，以及罗马承认其持续意义引发的问题，在修订《日课经》的《总礼规》第一栏，<a id="pdf-228"></a><!-- PDF page 228; original page 205 -->已强烈暗示。那里说，只要罗马批准，“即使［上述］庆日未列罗马历”，也可庆祝。[^p228-8]地方日课有时装订主书末，有时单独印刷，位置从属、容易散失，因此较晚才受书目学家注意。最全面，却肯定不完整的目录，列出1568至1660年西欧一百个教区及地区的约197种地方专用日课。[^p228-9]

## 2. 反宗教改革与圣徒崇敬

乍看两者联系如此自明，似无须多言。路德宗与加尔文宗改革使天主教徒最初惊慌失措，到1555年，中欧逾半已在新教手中；但他们借特伦托（1545—1563）教义法令所得的明确方向与重点反攻，到世纪末，不仅阻止异端推进，也收复失地。[^p228-10]信心恢复的象征对应，是教皇封圣在停顿六十五年后，于1588年恢复。[^p228-11]随后七十七年，直到1665年，至少十四次封圣；[^p228-12]另有二十七次列真福，<a id="pdf-229"></a><!-- PDF page 229; original page 206 -->若计入耶稣会三木保禄与方济各会伯多禄·巴蒂斯塔·布拉斯克斯的二十四名同伴，合计五十一次；他们全在日本长崎被处死。[^p229-13]最后，还有两次普遍敬礼确认、八次非普遍敬礼确认，以及两次“等效列真福”宣告。[^p229-14]造就圣人的复兴，伴随空前规范敬礼的尝试。如前所见，最初由西尔莱托枢机在特伦托后立即承担，后来归新礼仪圣部管辖；但其权威受到1542年成立、更熟知为宗教裁判所的圣职部挑战。

正如传统自上而下的特伦托礼仪改革观，须考虑“不平等中的互惠”——借威廉·泰勒简洁措辞——把圣徒崇敬仅视为“伴随神圣事物，或界定神圣权利之中央控制增加的复兴”，<a id="pdf-230"></a><!-- PDF page 230; original page 207 -->也须细化。[^p230-15]首先，须超越把圣徒崇敬史等同封圣史，认识到这个时期，来自全部基督教历史的圣人，以空前数量纳入罗马天主教礼拜与敬虔。此外，1588至1665年获教皇承认者，包含非普遍敬礼获罗马认可的人，也指向特伦托置于中心的问题：如何调和特殊地方实践，与普遍罗马规定？

## 3. 造就圣人：政治与程序

不仅须记得封圣程序改革晚于特伦托，也须理解：程序复杂，加之礼仪圣部与圣职部共享且争夺司法权，难把变化归于单一创新或年份。传统上，封圣史新时代定于1588年：出现1523年以来首次教皇封圣，西班牙方济各会传教士阿尔卡拉的迪耶戈，稍后又成立礼仪圣部。但次序显示，封圣复兴早于监督程序变革的机关。此外，圣部处理的最早四例——雅采克，即雅钦多·奥德罗翁日，雷蒙多·佩尼亚福特，弗朗切斯卡·蓬齐亚尼，以及嘉禄·鲍荣茂——仍按长期确立、自中世纪以来基本未变的程序。[^p230-16]也须记得，封圣停顿，并不意味着非普遍敬礼获教皇认可也不活跃；1524至1588年，至少十四位圣男圣女获此荣誉。[^p230-17]

早在约1170年致瑞典国王克努特的Audivimus信函，已明确宣告封圣专属教皇；1234年载入教会法，即格列高利九世《教令集》III,45,1。两级收集证词的审判模式，也有数世纪历史。首先是教区普通调查（processus ordinarius），有时称审查与取证程序（processus inquisitionis et informationis），由候选人生前居住或去世地的主教发起，确立圣德声誉（fama sanctitatis）。积极结果，加上支持个人、机构向教皇递呈请愿书的有效游说，决定能否进入宗座调查（processus apostolicus）。后者也称processus remissorialis et compulsorialis，源自调查前罗马必须发出的特别训令书之名，常由罗马教廷最高法院圣轮法院的资深审判官（auditori）拟定。虽尽量用普通调查的同批证人，却提出更严格的问题（interrogatorii），核实可信度，以及对两阶段所查候选人的了解。关于生平、美德、奇迹的问题，依一系列可达数百项命题（articuli）的既定格式。每位证人接受其中若干项，证实自己能评论的命题。两套问题都由礼仪圣部法律人员产生。质询书一贯由圣部最资深教会法学家拟写，1631年起是信仰维护官（promotore della fede），更以“魔鬼代言人”之称闻名；命题或论证文书（articuli／positiones），则由支持案件的修会或机构所任申请负责人（postulator）或代理人（procurator）撰写。调查可在多个地点同时举行，取决候选人生死所在地。最终文献由枢机团两三名成员审查，再向教皇提交报告。到16世纪，圣轮法院审判官<a id="pdf-232"></a><!-- PDF page 232; original page 209 -->也关键性参与把材料汇成报告（relatio）。但1634年后案件庞大，加之礼仪圣部相关法律官员、尤其信仰维护官日趋专业化，审判官角色渐被边缘化。例如1632年8月24日圣部会议，圣轮法院审判官与信仰维护官争执，后者主张有权拟定报告中供枢机成员审议案件的各项标题（positiones）。[^p232-18]报告结构大体决定随后圣部会议议程，因此争论重要。总体上，报告通常三分：先简述生平及敬礼史，再列美德，先向主三德——信、望、爱——再四枢德——正义、明智、勇毅、节制——最后详陈奇迹证据，死后奇迹最受重视。

特伦托后的新处，是教皇决意前所未有地明确区分普通调查的地方性质与宗座调查的普世权威，并以更严规范，保证前者不构成任何程度的正式圣德认可，也不预断第二阶段。教皇对此关注，可较精确追溯1602年克莱孟八世设特别“真福者委员会”（Congregazione de Beati）。[^p232-19]最初包括九神学家、十七枢机，有意思的是，礼仪圣部仅一人，圣职部却至少八人，另两人来自禁书圣部。临时委员会，专为应对从修会到王室各种利益集团压力：它们要求把新近去世、享圣德声誉，以至未经教皇特许便已有公开敬礼者封圣。克莱孟称“新真福者”（beati moderni），有意区别于能证明具有久远地方、区域敬礼（ab immemorabili tempore）的候选人。似促成教皇行动、使他不安地认识到压力集团能支持尴尬争议人选的，<a id="pdf-233"></a><!-- PDF page 233; original page 210 -->是费拉拉多明我会传道者萨沃纳罗拉（1452—1498）。他的候选资格与正统性，不仅获本会，也获内里领导的祈祷会力辩，虽终未成功。[^p233-20]

但控制这些敬礼的问题更广，可以说直到1620年代中期，教皇才掌握局面。[^p233-21]此前情形流动，政策远非一致。例如1600年，正式准出版两幅版画，方济各·沙勿略与依纳爵都带光环，周围画奇迹；两人尚未正式获称号，却已明确标为“真福”（beatus）。[^p233-22]教皇没有撤销许可，而命已印者继续公开销售，不得再印。另两位以圣德声誉去世的年轻会士，1568年的斯坦尼斯劳斯·科斯特卡、1591年的类思·贡扎加，保禄五世1605年都授真福称号；但后者才于1603至1604年开始调查，前者直到1621年才开始。祈祷会圣徒传家、真福者委员会顾问安东尼奥·加洛尼奥，1596年写的手稿论著《应如何呈现尚未封圣者》，正应放在这种流动气氛中理解。[^p233-23]

其论著务实，尤其温和：他认为私人敬礼正当，甚至可用图像、蜡烛，但公开墓所只能饰灯。死后即可称“圣人”、出版庆扬事迹，其他公开认可则只应限于逝世纪念日弥撒。他也肯定教皇封圣方面的完整权力，包括如其所愿，能在圣男圣女去世后<a id="pdf-234"></a><!-- PDF page 234; original page 211 -->立即将名列圣人名录。[^p234-24]他继而追溯至少六十八次不间断的教皇封圣，从8世纪中叶斯德望三世认可隐修者特鲁德佩特敬礼，到1594年克莱孟八世封雅采克·奥德罗翁日为圣。[^p234-25]不过，他也承认一定重叠：主教认可敬礼持续到1159年亚历山大三世即位，随后才宣告教皇独占此领域。[^p234-26]

委员会讨论的一端，是强硬派弗朗西斯科·佩尼亚，圣轮法院审判官，参与当时所有最终封圣的调查。他另任禁书顾问，又编14世纪尼古拉·艾梅里希的宗教裁判手册，提醒我们，圣德调查与异端调查、封圣与审查，相互共生。他认为，圣职部地方委员应判断，死时有“圣德声誉”者的非官方敬礼，是否因带“异端气味”（sapore di eresia）而应取缔。[^p234-27]意见光谱另一端，则认为决定属地方主教权力，基本是特伦托未动的传统立场。这也大体是贝拉明枢机的观点；他赞同顾问加洛尼奥1602年12月5日备忘录的论证。[^p234-28]两人认为，未正式封圣者可受敬礼，只要私下进行。同时，为更紧控制中间性的非普遍敬礼，佩尼亚等要求将教皇专属权，从封圣扩至列真福。16世纪早期教皇虽有认可非普遍敬礼的例子，例如克莱孟七世准雅采克仅在波兰国王领地受敬，但beatus与sanctus两词，仍未一致使用、区分。1601年6月19日，克莱孟八世<a id="pdf-235"></a><!-- PDF page 235; original page 212 -->授特许（indultum），准萨阿贡的若望在严格地方范围受敬，最初限萨拉曼卡教区；是否可视为真正“列真福”，仍有争议。[^p235-29]同年，安杰洛·罗卡出版特伦托后首部封圣论著《论圣人封圣》，讨论此例时，用“半封圣”（semicanonizatio），反映其中间地位，更支持此疑。首部明确论“列真福”的，是费利切·孔特洛里1634年《圣人封圣论及实践》；但此时该词至少自1608年保禄五世宣告多明我传教士路易斯·贝尔特兰“可以称为真福”起，已公开使用。[^p235-30]众所周知，圣彼得大殿首次列真福礼，是1662年的方济各·沙雷氏；较少人知，早在1609年，教皇已准罗马特定教堂，为数位修会创办人举行列真福庆典。那年耶稣会在耶稣堂庆祝依纳爵列真福，但为尽可能表明荣誉的中间性质，保禄五世禁止在场枢机参加弥撒：“免得礼仪看来像［正式枢机］御前弥撒，这［荣誉］只属于已封圣者。”[^p235-31]

德肋撒调查有两项影响深远的创新。首先，宗座调查明确分两阶段：一般调查（in genere，1604—1606），重点证明圣德声誉；具体调查（in specie，1609—1610），重点美德与奇迹。后来，像沙雷氏这样声誉无疑者，可免一般调查。其次，1602年2月2日，萨拉曼卡大学致克莱孟八世支持德肋撒的请愿信，似首次用“英雄”形容候选人行美德的程度。[^p235-32]到1614至1616年，词语进入<a id="pdf-236"></a><!-- PDF page 236; original page 213 -->圣轮法院审判官报告，1624年首次以方济各·博尔贾为对象，使用公式：“圣德与英雄美德应获证实”（constare de sanctitate et heroicis virtutibus）。[^p236-33]其本质，是反复、看似毫不费力地实行有德行为。[^p236-34]这项创新备受强调，甚至被视为圣德现代化的证据：从施行奇迹力量的魔法观，转成更纯粹伦理观。当时人因此较易将其与“假装或矫饰的圣德”（finta ò affettata santità）区分；17世纪地方圣职部法庭，对后者空前关注。[^p236-35]但无论创新何等重要，对本章时期及其他时期绝大多数圣德“消费者”，圣人功效首在能否奇迹治病。而且，特伦托后一世纪左右，宗派对圣徒崇敬的论战高峰时，奇迹是证明罗马天主教为唯一“真教会”（vera ecclesia）的重要标记。[^p236-36]最后，候选人列真福后，也只有再行奇迹，才有封圣资格。

封圣程序史真正分水岭，是让真福者委员会工作成为多余的立法。[^p236-37]最重要者，是1625年3月13日由圣职部，而非礼仪圣部颁发的法令。它不仅禁止在未经教皇正式承认圣德者的绘画、雕塑前放灯或还愿物，也禁止印刷、持有这些非官方候选人声称经历之奇迹异象的记述。[^p236-38]

法令正式确立一种实际上针对所有未来候选人的预备调查，须证明他们没有公开敬礼。由于同时又必须<a id="pdf-237"></a><!-- PDF page 237; original page 214 -->证明圣德声誉，这道“关于未受敬礼”（super non cultu）的法令，使推动者须掌握极困难、微妙的平衡。效果是除最初普通调查外，将封圣全程移出主教控制。前后，礼仪圣部另颁两限制，进一步控制新真福者。1624年9月28日Per decem annos，要求普通调查结束与宗座调查开始间，停十年；1627年11月20日法令，则禁止候选人去世不足半世纪时，讨论美德或殉道，即“五十年规则”。但尊重地方主教死后立即收集目击证词的权利。唯一例外，是能证明至少一百年敬礼连续者，称ab immemorabili。不过，1628年11月20日法令认定，笼统证明“自古以来”崇敬不够，必须以礼仪体现：持续诵其日课、为其举行弥撒。而且，批准这种“等效封圣”（canonizzazione equipollente）虽属许可性质，仍须礼仪圣部明确颁令。唯有如此，教皇专属权才能同时覆盖非普遍、普遍敬礼。

随后数年，圣部运作再修改。最重要者，是1631年1月27日规定，每年只在一、五、九月三次，由教皇出席，讨论列真福与封圣；较次要的候选事务，可无教皇讨论。同一时期，如今必须为每候选人担任提案者的枢机（cardinale ponente），每次会议也只准提出一项奇迹。1631年又正式设信仰维护官，其针对支持证据提出疑难（dubia）、写成对论证的正式驳议（animadversiones），格式更一致。法令数量和重要性如此高，乌尔班八世于1634年7月5日汇编，<a id="pdf-238"></a><!-- PDF page 238; original page 215 -->以简诏Coelestis Ierusalem cives重发；1642年3月12日，再加少数相关法令，以《圣人封圣与列真福应守法令》出版。它们构成两程序总体框架，直到1983年《神圣成全的导师》（Divinus perfectionis magister）公布。

立法显然奏效：1630年代，礼仪圣部虽大量处理至少八十八案，同期间却没有一次教皇封圣、列真福，甚至未确认既有久远敬礼。失败例包括格列高利十世，1272至1276年任教皇，1622年重开案件，1645年停止。理由是，墓上列奇迹的中世纪羊皮文书，其历史可信性可疑，显示1634年后法律—历史标准压倒性重要。[^p238-39]相应地，1713年其区域敬礼最终获承认，依据是证明1534年前已有久远敬礼，即1634年简诏前一世纪，故可豁免乌尔班规则。这表明教皇高度重视，只要可能，即使地方、区域敬礼不符普世历法律标准，也要找官方位置，甚至以正式认可的绕行立法实现。若承认普遍敬礼，行为名就叫“等效封圣”，正反映此意。如前所见，1588至1666年，只有两人符合：1594年拉文纳的罗穆亚尔多，以及1664年赎虏会创办人伯多禄·诺拉斯科。

分析当时封圣数字，不仅须考虑敬礼获确认者，也须考虑更多只到教区普通调查就止步的人。全罗马天主教世界，数百男女仅享地方圣德声誉；那不勒斯王国1540至1660年独有五十七案，故数百并非不合理推测。应把他们同1588至1665年仅十四名教皇封圣者并列。[^p238-40]障碍重重，因此十四人中，只有农人依西多禄是<a id="pdf-239"></a><!-- PDF page 239; original page 216 -->平信徒，并不奇怪；葡萄牙伊撒伯尔属方济各第三会。十二名修会人士，至少五名创办人，这是最重要封圣道路。其次，是善牧模式，包括鲍荣茂、安德烈亚·科尔西尼、沙雷氏与维拉诺瓦的托马斯。性别失衡明显，只有三女——罗马方济加、阿维拉德肋撒、葡萄牙伊撒伯尔——对十一男。最后，十四人十二来自意大利、伊比利亚，显示罗马天主教地中海腹地，对阿尔卑斯山以北欧洲重新强势确立；当时霸权强国西班牙领头，至少七人成功。例如阿尔卡拉迪耶戈封圣，可合理视为西克斯图斯五世奖励腓力二世派无敌舰队攻击异端伊丽莎白女王的自觉姿态。[^p239-41]罗恩·菲纽肯重建雅采克封圣的重要研究，也显示西克斯图斯五世、克莱孟八世希望建立联合反土耳其阵线，认为强大天主教波兰有重要地缘战略角色，这一点起决定作用。他无疑有理：宗派分裂的近代早期，教皇封圣越来越是政治行为，王朝权力、地理比偏爱圣德模式，甚至更严司法程序，更有分量。但转向非普遍敬礼控制，自上而下解释，也须结合地方区域如何生产、消费敬礼的理解。

## 4. 清点圣人：神圣事物的普查

只享地方、区域敬礼者，在特伦托教会有何合法位置？鲜明对比是，1568年《罗马日课经》一月圣人历，列二十五位有名圣人，另有耶稣割损、无辜婴孩与主显节；而有史以来最全面的神圣普查，即耶稣会让·博兰主持、1643年开始的附详细批判评注圣人生平汇编《圣徒行实》（Acta Sanctorum），同月头两卷，提供至少一千一百七十位圣人生平。而且，1578年重新发现、<a id="pdf-240"></a><!-- PDF page 240; original page 217 -->随后探索罗马地下墓窟，提供当时人看来取之不尽的初期基督教殉道者圣髑，许多人从未列官方殉道录，事迹甚至未进《圣徒行实》。这又在特伦托结束后一百五十年，激励主教充当业余考古者，不仅在天主教地中海历史腹地，常怀激烈竞争精神，证明本教会也有来自教会史最英雄时代的无价遗迹（vestigia）。

地方敬礼与普世圣人历如何调和，基本解决于建立机制，仔细区别普遍与地方、区域敬礼，即圣人（sanctus／sancta）与真福（beatus／beata）。中世纪宣告教皇独占普遍敬礼，并未伴随罗马系统规范、监督地方特殊敬礼的尝试；特伦托后，则不仅明确区分两者，也确保地方敬礼遵守普遍准则。成果是更新既有“真福”用语，指明确界定的中间地位；不仅是通往封圣的中途站，更关键地，也独立存在，表示某些敬礼在地方区域享完整圣人荣誉，同时负遵守普遍教会法规的全部义务。因此，可以说两过程同时发展：一面普遍规范特殊化，即地方圣人日课须按普遍标准礼规；另一面特殊实践普遍化。后者鲜明体现于礼仪圣部1630年3月23日《今后选择主保的法令》，要求善会、村庄、城镇或国家主保，只能从教皇已封圣，或姓名已列《罗马殉道录》、有正式普遍敬礼证明者中选。

这种细致分层的圣德等级，位居特伦托圣徒崇敬改革核心，使地方实践符合普遍规范。但礼仪之外，全球天主教的教区、修会，仍能充分表达地方爱国情怀：

## 5. 享用圣人：世界宗教中敬礼的生产与消费

近代早期，几乎不间断地抬送圣髑、圣像与圣者遗体的游行，更加频繁。彼得·布朗研究使我们看见，自圣安博认识到通过这些行为，“更多力量可沿更强、绝缘更好的线路，流向作为共同体领袖的主教”以来，游行便是圣徒崇敬特色。[^p241-43]宗派分裂世界中，圣徒敬礼是高度可见的天主教身份标志，与日益精巧镀金、造型复杂、<a id="pdf-242"></a><!-- PDF page 242; original page 219 -->在游行中盛放圣体的圣体光座一道。因此，标记改革后圣徒崇敬复兴，或许1580年比1588年更恰当。那年，巴伐利亚维特尔斯巴赫统治者策动一场，可能是1204年威尼斯人洗劫拜占庭以来，象征最浓的圣髑“神圣营救”（furta sacra）：把迈森的本诺遗体，从新教萨克森移到首都慕尼黑。尤其有意义，他是1523年最后两位获封圣者之一。

布朗笔下神圣电路大师、4世纪米兰主教，在近代早期的对应者，恰是同城枢机总主教鲍荣茂。他把圣徒崇敬直接联系教会治理与敬虔的“最佳实践”。1582年5月，他将早期神圣前任辛普利恰诺、贝尼尼奥，以及同时代殉道者西西尼奥、马尔蒂里奥、亚历山德罗，抬出游行。不仅提醒出席第六届教省会议的高级教士，其都主教职分古老、历史连续，且对他们有权威——总主教宫装饰历任主教肖像，也强调此意——还让全体民众，从贵族到小民，为极公开的敬礼作属灵准备。游行连接城市与腹地，谨慎加强社会等级及教会位序，唱的诗篇、祷文也专为此作、印行。引述材料唯一缺少，是我们知道后来圣嘉禄本人在圣辛普利恰诺圣殿所作讲道。[^p242-44]

米兰例也提醒我们，圣徒敬礼多么是一种多媒介经验、一件“总体艺术作品”（Gesamtkunstwerk）：绘画、建筑、雕塑、言词、音乐、印刷，经眼耳感动心灵。圣嘉禄的圣髑游行，不仅是典型，也成为重要效法模式；传播不只通过巴斯卡佩的拉丁文传、朱萨尼的意大利文传，也通过影响极大的主教立法汇编《米兰教会行实》（Acta Ecclesiae Mediolanensis，1582），直到18世纪，旧、新世界仍阅读参考。全球天主教各教区礼仪年，确常有类似但往往没那么华美的游行；但也须认识，<a id="pdf-243"></a><!-- PDF page 243; original page 220 -->它们庆祝城市和睦、独特教区传统，并非发生真空，而与竞争、常相冲突的解释相关。

1648年1月15日，圣徒传家、教会史家彼得罗·马里亚·坎皮（1569—1649），中断屡延的毕生著作《皮亚琴察教会史》印刷，补入详细记述：1643至1647年，约二十具初期殉道者遗体及另八十八位圣髑，抵达这座意大利北城。[^p243-45]它们来自撒丁卡利亚里城墙外，圣萨图尔尼诺、圣卢奇费罗、圣毛罗与莱洛教堂下及周围地下墓窟。1614年，总主教弗朗西斯科·德·埃斯基韦尔亲自发起挖掘，直接回应同年稍早萨萨里总主教加维诺·曼卡·德·切德雷列斯的发现：萨萨里附近托雷斯港圣加维诺圣殿下，找到戴克里先时期殉道的加维诺、普罗托与贾努阿里奥遗体。争点是长期争论：卡利亚里还是萨萨里，历史上有全岛首席地位？最英雄时代的圣髑发现，成为各自论证的实物证据。埃斯基韦尔及1624年继任的安布罗焦·马金，自信而从容地策动运动：1614年11月6日圣萨图尔尼诺庆日，公证人和许多显要在场，发现“SINNU”或“SINUM”铭文，被视为“无数圣人”（SANCTI INNUMERABILES）缩写，继而挖出至少338具遗体；又严密监督大量圣髑，分往皮亚琴察及西地中海其他城市、地方，包括利古里亚阿拉西奥，1624年首批收到八十六殉道者；以及加泰罗尼亚、那不勒斯。[^p243-46]持续宣传配合，依次出版埃斯基韦尔1617年亲述发现喜事、嘉布遣会斯特法诺·埃斯基罗1624年更详“考古”论述、迪奥尼焦·邦凡特1635年全面“历史”记述，全用西班牙本国语文。两位总主教希望争取当时统治岛屿的西班牙国王支持。

1637至1640年，罗马教廷最高圣轮法院一系列决定，明确驳回萨萨里的首席头衔要求，运动成功告终。

下一例则考察，巴黎主保圣女热纳维耶芙一人的敬礼，如何同时承载多重意义。莫谢·斯卢霍夫斯基研究中世纪后期至法国革命间的崇敬，显示它如何灵活回应迅速扩张城市的压力。[^p244-47]传统上，她保护免洪水；1552年后，越来越被求为城市生计主保、粮食提供者。其养育形象，对负责家庭粮食供应、养育的女性产生新的性别吸引，恰逢女性角色被重新界定、日受限制。但要看清动乱冲突时，敬礼同时在多少层面运作，须看1652年6月11日圣髑游行。当时投石党之乱政治冲突激烈，当年严重干旱更恶化局势。商人、高等法院官员与善会联合要求游行，巴黎总主教强烈反对。他要对附近圣热纳维耶芙修院，以及叛逆的本座堂教士确立权威，理由之一是，不应在圣体节八日庆期游行，必分散圣体敬礼。仪式开始后，又被投石党领袖“大孔代”挪作政治。他为取悦小民，挤进人群，多次亲吻圣髑匣，再赶到巴黎圣母院西门，检阅前来队伍；既尊重巴黎保护者，也获参与者尊为事实统治者。不同群体各自使用圣女，说明再强的单一权威，也常无法完全控制、占有敬礼；此处，实际上无人全权掌控。

圣徒敬礼不仅帮助城市、区域身份面对内外挑战，也能成为那些被拒绝传统权力表达者，武库中重要的<a id="pdf-245"></a><!-- PDF page 245; original page 222 -->“弱者武器”。1662年，慕尼黑方济各女修团体，经嘉布遣修士协助，从罗马地下墓窟这一丰饶圣德矿藏，取得某位圣多罗泰娅完整遗体。乌尔里克·施特拉瑟有力分析，修女想用这项时新的神圣珍藏，在城市争取公开存在；1621年强制围禁后约四十年，这一直被剥夺。[^p245-48]负责修院属灵照管的改革派方济各会会省长莫德斯图斯·赖哈特，虽竭力要求，修女仍成功阻止其私下验尸。否则须拆开骨匣认证封印，反而令主教无法正式确认真实性。有意思的是，她们援引围禁身份，阻止他进入。因此，姐妹得以按自己条件，在必要见证人面前开匣，再悉心准备公开展示。最终虽由男修士抬圣女穿过慕尼黑街道，修女却可独享华丽装饰之功，并从其留在本教堂受益；教堂作为为炼狱灵魂服务的“祈祷工厂”，功效由此加强、重申。

这里强调运动，不仅物理移动，也有意义流动。圣人是符号，更确切说是能指，确切意义由背景赋予，因此如热纳维耶芙一例，同一圣人，即使同一时地，对不同人也有不同意义。这本来显然，但对理解“地方”宗教的重要含义，却常未深入。圣人能同时承载多种意义、体现多重身份，提醒我们，圣徒及神圣空间的敬礼，绝不可能完全只是“地方”的。

新世界方面，有人指出，最迟17世纪中叶，今日墨西哥的纳瓦人，其宗教实践已围绕圣人：“没有其他基督教信仰与礼仪方面，对［纳瓦人］广泛活动的影响，能略为相比，尤其若考虑耶稣基督、常还有十字架，也被看作另外的<a id="pdf-246"></a><!-- PDF page 246; original page 223 -->圣人。”[^p246-49]

纳瓦人一旦理解圣徒崇敬意义，几乎所有无人监督、供自己阅读使用的文字，包括遗嘱、市政敕令、财产买卖、租约、编年史，都反映相信圣人积极行动，或求其代祷援助。圣人被视为人民父母、共同体土地真正所有者。天上保护者与受保护聚落如此紧密，以至殖民地本土治理基本单位阿尔特佩特尔（altepetl）中，名为卡尔波利（calpolli）的分部，统称桑托潘（santopan），直意“圣人所在之处”。

日本是新近归信的非西方人如何取用圣徒崇敬、使之发挥作用的极生动例。当地基督徒遭受当时世界最猛烈的宗教迫害，由德川幕府实行，1614至1645年最强，约两千人殉道，包括七十一欧洲人。信仰要存续，代价是完全消除公开敬礼，改由外表被迫作佛教徒的“隐匿基督徒”（Kakure Kirishitan）在家敬奉“纳户神”（nandogami，字面“壁橱之神”），其中有称“御前样”（gozensama）的圣徒、殉道者图像，最常见是绘画挂轴（kakemono），可卷起隐藏、安全保存，画周以纹绸、织锦等织物装裱。[^p246-50]《雪中圣母》是极精美早期例，最终原型出于圣母大殿的博尔盖塞圣母像。高文·贝利有力主张，画者是受训于耶稣会尼科洛学院的日本本土艺术家；虽明显遵欧洲模式，却把“图像每一元素，转成相应日本风格技巧”，最鲜明见圣母高弓眉、细眼。[^p246-51]如此精巧取用西方宗教艺术，有力证明圣徒崇敬不只充当传教宣传载体，也能扎根非西方基督徒心灵。

<a id="pdf-247"></a>
<!-- PDF page 247; original page 224 -->

新世界消费者取用圣徒敬礼的例子，不表示旧世界没有。尤其大卫·真蒂尔科雷，生动描述近代早期奥特朗托地区，圣人在世、死后，都完全融入“神圣体系”，供人汲取治愈能力。他指出，所谓“精英”与“民众”文化，共信能够接触超自然力；在他笔下，两者由主教与女巫体现，彼此处于连续谱，并非占据分离信仰区域。[^p247-52]让—米歇尔·萨尔曼强调那不勒斯王国消费者的圣德感知，也把圣人作为萨满式治疗者、行奇迹者的角色，牢置中心。[^p247-53]

## 6. 结论：作为动词的宗教

本章核心主张，是更完整理解礼仪改革，尤其对圣徒崇敬的影响，有助看见，特伦托勾勒的改革，不能用中心／边缘，或精英／民众理解；应回到前引泰勒措辞，留意不平等中互惠的动力。采用这一视角，更可能摆脱仍萦绕的执念：追问当时天主教“是什么”，即应贴什么名词标签；转问它“做了什么”，即承担什么文化工作，用哪些主动词描述其中互动。[^p247-54]如此，或许更易理解：在地球第一种世界宗教形成中，各地方罗马天主教呈现何等变化多端的形态。
