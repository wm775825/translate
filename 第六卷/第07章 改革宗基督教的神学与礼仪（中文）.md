# 第7章 改革宗基督教的神学与礼仪

作者：马克·格林格拉斯（Mark Greengrass）

<a id="pdf-127"></a>
<!-- PDF page 127; original page 104 -->

近代早期科学史家教给我们一个后现代的认识：真理也有“社会史”。17世纪后期，“新科学”的倡导者提出基于实验与观察的科学知识主张，依赖于一些预设：谁的观察算数、什么实验可信，以及什么构成科学真理。[^p127-1]宗教改革时代的新教神学家和教士，虽会拒绝这种观念——上帝的真理是启示的、永恒的、不可改变的——但事实是，改革宗新教的神学与礼仪传统形成时，改革者自己也重新界定了：何者构成宗教真理，以及如何验证它。

“唯独信仰”（sola fide）是路德的重新界定；“唯独《圣经》”（sola scriptura）是新教改革者为之提供验证、震撼人心的手段。通过后者，新教徒宣称，教会可以回到根源——基督的福音，以及他最早追随者的教会。这一学说侵蚀了教会会议、罗马宣告与经院神学家著作中层层积累的规范传统。路德对罗马教会的核心批评，是其被人为传统压得不堪重负；教皇、枢机及教会权威却声称这些传统“神圣”，将神与人混淆，僭取唯独属于上帝的宣告真理之权。唯有上帝之道构成教会真正的“传统”。《圣经》记录了他自世界之初向人类发出的言语应许；应许在《旧约》中更新，在基督里实现。教会通过福音的宣讲和圣礼，从基督承受这一应许；圣礼体现基督对它的成全。没有什么比这应许在“字面上”更真，因为上帝自己<a id="pdf-128"></a><!-- PDF page 128; original page 105 -->是信仰中值得信靠的。从这一化繁为简、惊世骇俗的真理主张，衍生出许多其他事情，尤其是新教内部一场巨大的神学意见分裂：究竟该多么“按字面”理解它？

分裂的起源，在于上莱茵地区一个卓越的《圣经》学术群体，中心位于巴塞尔、苏黎世和斯特拉斯堡。巴塞尔是重要大学城，伊拉斯谟1515年在此完成希腊文《新约》（Novum instrumentum），1516年2月由约翰·弗罗本出版。也是1515年，沃尔夫冈·卡皮托，德文名沃尔夫冈·克普费尔（1478？—1541），成为座堂传道者、教授及伊拉斯谟助手。又在同年，约翰内斯·厄科兰帕迪乌斯，德文名约翰内斯·胡斯根（1482—1531），应伊拉斯谟出版商弗罗本之邀抵达巴塞尔，协助完成《新约》注释与评注。约同时，乌尔里希·慈运理（1484—1531）访问巴塞尔，拜见“所有学者中最博学的”伊拉斯谟，购买《新约》，开始专心学习希腊文，以掌握其内容。四年后，他登上瑞士东部大州首府苏黎世大教堂的讲坛。八年后，卡皮托在斯特拉斯堡圣托马斯协同教堂担任教长，马丁·布策尔，德文名马丁·布策尔（1491—1551），另一位巴塞尔毕业生卡斯帕尔·赫迪奥，德文名卡斯帕尔·赛勒（1494或1495—1552），以及马蒂亚斯·策尔（1477—1548），也来到那里。他们共同成为上莱茵改革的关键推动者。对于萨克森的马丁·路德提出的新教改革真理主张，他们勾勒出独特的神学路径。他们的神学，正是后来所谓“改革宗传统”的源头；这一称谓出于历史叙述便利，并非绝对精确。

16世纪神学首先是阅读、写作与反思的活动。神圣事物涉及人类知识每一分支，因此神学是诸学之王。神学家运用众多文类写作，但唯独《圣经》把重心放在经文真理上：真理是什么，如何、由谁取得，又产生何种作用，是新教改革的核心问题。答案受到当时文学与思想文化影响，尤其文学人文主义、文本研究和语文学。伊拉斯谟《新约》是这种文学文化的胜利：它用希腊文呈现基督教经文，在扉页大胆宣称，这是经过与其他文本仔细校勘的原始真本文；又提供与希腊文并列的新拉丁译文，取代圣热罗尼莫的官方版本。随后，是他付出最多心力、也最引以为傲的“注释”。这些不是通行<a id="pdf-129"></a><!-- PDF page 129; original page 106 -->学术模式下的字句训释，而是对《通行本新约》的论说式评注。序言《劝勉》（Paraclesis）、《方法》（Methodus）和《辩护》（Apologia），是对重新发现之真理的宣言。伊拉斯谟说，在这个新编文本中，“真理本身”（ipsa veritas）向我们显明。基督是作者，通过他写下的文字，为我们真实临在；他的临在保证真理。《新约》呈现的是活的“神圣心灵之形象，以及讲话、医治、复活的基督本人”。[^p129-2]怀着“虔诚而开放的心”和“纯洁、单纯的信仰”阅读，基督就让我们在内里感受其临在。伊拉斯谟的比喻极具吸引力，由此产生的神学也引人入胜。[^p129-3]但这部著作同时提供了攻击其自身完整性的弹药。

路德对伊拉斯谟释经方法和神学的批评，不是这里的直接主题。但他提出了“语法”与“恩典”关系的核心问题，正如一位近来研究者的表述；此后一个半世纪，改革宗神学家反复返回这些问题：原罪、自由意志和预定。[^p129-4]路德察觉诸多危险，包括使圣经历史化、使真理相对化，以及限制上帝的主权大能。他一如既往，将自己的立场界定为捍卫真理、反对谬误者。但对上莱茵神学家，伊拉斯谟方法的潜能，以及上帝之道一旦释放、得到正确理解便能改变人生的能力，仍丝毫不减。他们共享伊拉斯谟的《圣经》诠释与释经路径。路德和维滕贝格学派按彼此关联的神学主题，即“论题”（loci communes），组织经文评注；而在巴塞尔、斯特拉斯堡和苏黎世，布策尔、卡皮托、厄科兰帕迪乌斯与慈运理，则将经文分为段落，逐段以不同方式评述。[^p129-5]有时意译重述；语文学问题按伊拉斯谟模式作注；更大的神学问题则另作旁论。这些评注博学，充分利用最新拉比学和教父学成果，也重视《圣经》的象征语言。这是一种自觉在揭示上帝真理、而且具有实际后果的经文学术。慈运理1529年以“上帝所教的基督徒”（Christianus Theodidactus）为笔名，出版《以赛亚书》评注，<a id="pdf-130"></a><!-- PDF page 130; original page 107 -->题为《〈以赛亚先知书〉平直阐释之初生》（Complanationis Isiae prophetae fœtura prima）。慈运理在献给上莱茵新近结盟的基督徒城市同盟（Christliche Burgrecht）的序信中指出，标题中的Fœtura与Complanatio是双关：“诞生／新生长”，以及“理清意义／修直”主的道路。[^p130-6]早在1522年《论上帝之道的明晰与确定性》中，他便借用伊拉斯谟关于光与真理的比喻，描述自己受上帝之灵引向光照的经历。[^p130-7]他说，我们必须成为“theodidacti，也就是受上帝，而非受人教导；真理本身就是如此说的［《约翰福音》6:45］，它不可能说谎”。[^p130-8]我们必须信靠上帝之灵，引领我们抵达真理。[^p130-9]这些思想推动了1525年6月开始在苏黎世大教堂举行的每周《圣经》讲座“先知讲经”（Prophezei）：“先知”用拉丁文、希腊文与希伯来文阐释经文，名称取自《哥林多前书》14:3。这一实践促成《苏黎世圣经》出版，后来广泛嵌入16世纪改革宗传统，包括布策尔的斯特拉斯堡、朗贝尔的黑森、加尔文的日内瓦、东弗里斯兰，又由扬·拉斯基从后者带到伦敦。[^p130-10]先知讲经体现了改革宗对学养深厚、定期履职的讲道职分之重视。[^p130-11]

16世纪神学家提出的问题，也处于公共政策与论争中心。理解《圣经》的新方法后果深远，尤其在礼拜必须完全取自经文字句时。1523年，慈运理在苏黎世两次公开辩论，这些影响开始显现，随后又在上莱茵城市出现。[^p130-12]慈运理宣称，禁食、节日、朝圣、宗教标记和图像，都背离在圣言中显明的上帝之灵，剥夺基督徒自由。[^p130-13]圣像、圣徒崇敬，乃至音乐，都有诱惑人、遮蔽上帝真理的能力，必须舍弃或替换。苏黎世、巴塞尔和伯尔尼的礼仪书被毁，或转卖给杂货商、药剂师。在苏黎世，由慈运理主持的审查委员会决定<a id="pdf-131"></a><!-- PDF page 131; original page 108 -->保留什么。[^p131-14]他的朋友、希伯来文学者利奥·犹德（1482—1542）于1523年9月讲道时指出，十诫有不同编号法。犹太传统和东方基督教把“不可为自己雕刻偶像，也不可作什么形像”，单列为第二诫；奥古斯丁则成功推行另一种排序，只将它作为第一诫的从属部分。慈运理以及后来的改革宗传统，采用前一模式；路德和路德宗则保留奥古斯丁旧排序，因而认为圣像本身并无关紧要。这最能说明，经文学术及支持它的文学文化，如何剧烈影响周围世界。1523年10月第二次辩论后，教会当局永久合上三联祭坛画，婚礼禁止使用金银及其他装饰。[^p131-15]当民众自行行动、推倒地方圣像与圣龛，市当局于1524年6月15日介入，正式“清理”苏黎世各教堂的宗教图像和彩色玻璃。慈运理惊叹，墙面“简直发光……洁白美丽”。[^p131-16]与此同时，印刷敬虔文献的木刻与版画，以普通虔诚者取代圣徒，作为神圣形象。[^p131-17]1527年，约翰内斯·科普出版新教会《历书》，废除圣徒节，改以《旧约》人物和杰出改革者纪日。这份历书在16世纪改革宗欧洲传播，例如通过约翰·福克斯1563年版《殉道者之书》传入英格兰。[^p131-18]1525年，慈运理又根据《马太福音》6:6和《以弗所书》5:19，禁止苏黎世礼仪使用器乐与合唱。[^p131-19]他认为教会合唱团炫耀卖弄、令人分心。改革宗欧洲各地实施情况不同；例如巴塞尔从未禁绝圣诗歌唱，苏黎世却一直如此，直到1598年。[^p131-20]但走过欧洲，仍可在教会建筑上看到改革宗清除宗教图像的视觉影响。《圣经》反对偶像崇拜的禁令，<a id="pdf-132"></a><!-- PDF page 132; original page 109 -->发展成针对广泛宗教再现形式的神学反对。约1529年，斯特拉斯堡改革宗圈子首次使用后来熟悉的“隐匿的上帝”（deus absconditus）来表达上帝。彼得·扬斯·萨恩雷丹描绘荷兰改革宗教堂内部的画作，呈现有序、整洁、冷清的空间，除纪念公民美德与共和骄傲的图像外，其余图像均已清除。[^p132-21]改革宗传统畏惧图像的倾向难以忽视，其对色彩和声音的排斥也一样。“字面”真理，最好用朴素的黑白表达。

1523年10月第二次辩论，还有一个相关问题：弥撒。含义很清楚——弥撒是否也应视为一种偶像图像？慈运理最初的思路，体现伊拉斯谟印记。[^p132-22]如果《新约》可以如此历史化，使基督的话虽说于特定时刻，如今仍像当初一样“真实”而临在——伊拉斯谟甚至敢说“更加真实”——教会核心圣礼为何不能同样如此？慈运理最爱用的证明经文之一，是《约翰福音》6:63：“叫人活着的乃是灵，肉体是无益的。”他的神学洞见，以一边是圣灵压倒性的大能、一边是肉体令人僵死的影响之间的区分为基础。他欣然赞同路德，承认弥撒不是祭献，化质说荒谬。因此，为何不放弃基督在圣餐饼酒中肉身临在的一切观念？他推论，如果还要把弥撒称为圣礼——这一词既不见于《圣经》，或许本属多余——就必须把它视为上帝的“保证”或“誓约”：“心灵赖以滋养的道……因此，灵魂的粮就是上帝之道，因为人活着不是单靠食物，乃靠上帝口里所出的一切话”，也是基督赦免我们罪的“确实记号与印证”。[^p132-23]两年后，慈运理发表关于圣餐的主要神学论述。也在那年，苏黎世决定以“最后晚餐的形式或方式”取代弥撒。礼规说：“指定的服事者将无酵饼传递各处，每位信徒亲手从中取一小块或一口，或由服事者递给他……其他服事者同样随后传酒。”福音派圣餐礼由此诞生；1525年4月苏黎世复活节期间，大教堂从尚未重新安置的祭坛上，分发符合《圣经》的饼，<a id="pdf-133"></a><!-- PDF page 133; original page 110 -->以及盛在朴素木杯中的普通葡萄酒。到1525年，慈运理的圣餐观已经更复杂：上帝设立圣礼的行动中，包含赦罪的“保证”（Pflicht），如今又与我们纪念那一次为我们作出的祭献，以及领受时彼此作证结合。因此，圣餐不仅关乎上帝为我们做什么，也关乎我们为上帝、为彼此做什么。到1525年，语文学训练已引领慈运理追寻拉丁词sacramentum的起源。他在瓦罗著作中发现，早期拉丁教会采用此词，指诉讼者在祭坛前缴存、胜诉后取回的保证物，而它原出于罗马军队表示士兵誓言的词。正如迪尔梅德·麦卡洛克指出，这在欧洲雇佣军腹地引起共鸣。领受圣餐，相当于一支部队在军旗前庄严敬礼。[^p133-24]由此，我们加强内在信仰，把《圣经》所告诉的实在刻入内心：基督在十字架上，为全人类一次而永远作出祭献。

圣餐既如此，另一项有经文根据的圣礼——洗礼——也必如此。起初，慈运理难以提出一套连贯、基于《圣经》、又符合其发展中神学的论证，反驳新兴重洗派支持成人重新受洗的主张。但到1525年，他已能说，婴儿洗礼是盟约的记号或保证，“人借此向教会证明，自己愿成为，或已经是基督的士兵；它告知整个教会，而非你自己，你的信仰是什么”。[^p133-25]经文早有此意，最初体现在上帝赐给亚伯拉罕及其后裔的割礼中：不是为确认亚伯拉罕的信仰，而是保证他会引导儿女归向上帝。慈运理不信服原罪罪责，因此洗礼不是洗去罪，而只是进入新的生命与共同体。实践上，洗礼应在星期日礼拜中举行。同圣餐一样，一种化繁为简的原则发挥作用：洗礼池与金银器具，被陶、锌、铜或玻璃碗及朴素水壶取代。这些礼器后来广泛见于法国、尼德兰和苏格兰改革宗传统。罗马礼中的盐、油、蜡烛与驱魔礼，则永久废除。

到1525年，慈运理读到一封公开信，作者是代尔夫特的人文主义者科内利斯·胡恩。他接续15世纪弗里斯兰人韦塞尔·汉斯福特的论证，加以发展。在苏黎世出版的版本中，胡恩的主张简短而切中要点：基督说“这是我的身体”时，是在用比喻，正如他此前多次对门徒说话那样。“是”意味着“象征”。化质说——或者那些“被字词迷住的经院学者”为饼酒变成别物而选择的任何术语——与四旬期不吃香肠一样无关紧要。这便是那场最著名、完全未能达成理解的会面的背景：1529年9月末，慈运理、厄科兰帕迪乌斯、路德与梅兰希通，在黑森的菲利普注视下，聚于马尔堡上方的城堡。他们就圣餐激烈争执，按路德坚持使用德语，也许是为了嘲笑慈运理的瑞士德语方言。厄科兰帕迪乌斯的圣餐神学与慈运理略有差别，他问路德：“博士，《圣经》哪里说，我们应闭眼不看它的意义？”路德答：“即使辩论一百年，也不会有不同。把经文拿来，我就满足。我们不可给亲爱之主的话加上诠释。”[^p134-26]分歧的本质尽在其中。此后一个世纪，改革宗各宗派逐步巩固，正如路德预言，天下所有神学辩论也不能让分歧消失。

---

下一代，上莱茵神学继续展开，部分回应事件压力，部分受强势人物影响而演进。本卷其他章节讨论的事件，包括慈运理于1531年卡佩尔战役阵亡，以及继任者海因里希·布林格（1504—1575）的努力。布林格以具有政治家才干的苏黎世教会首长（antistes）身份，成功稳定并维护慈运理改革模式，又在更大舞台上争取支持，从思想与政治两面强化它。那个舞台最主要的宗教事件，是天主教对新教信息日益增强的政治与制度反击，尤其针对其“激进”形式，即重洗派，以及“圣餐象征说”形式，即慈运理派。结果，在中西欧政治与语言的缝隙中，从埃姆登、韦塞尔向南沿莱茵至上莱茵和瑞士各州，形成了“难民宗教改革”。多数城市中，“外来者”是少数，位居边缘。但在日内瓦，“外来者”改变了城市，为约翰·加尔文（1509—1564）提供独特平台。

布林格与加尔文：改革宗传统的基础有两个中心，这也使“改革宗传统”一词具有历史上的必要性。直到加尔文1564年去世，这一时期最显著的发展，就是二人思想的结合；当路德宗神学的动脉也日益硬化时，它提供了坚实、可捍卫的神学遗产。

布林格最独特的神学洞见，发展了慈运理神学中强调“圣约”的一面。圣约，德文Bund、法文Alliance、拉丁文Foedum，是上帝与人类之间的纽带。路德宗菲利普派神学虽也探索圣约，其印记在改革宗传统中却持久得多。布林格对该主题最专注的探讨，见于1534年《论上帝独一而永恒的约》（De testamento seu fædere Dei unico et œterno）；但这一主题也常见于其他著作，包括1549至1551年出版、将五十篇讲道每十篇分组的《家庭讲道集》（德文Hausbook，拉丁文及英文Decades）。它广泛影响欧洲改革宗讲道，正如他后来1557年的一百篇讲道，开启了改革宗传统的启示末世写作。[^p135-27]圣约也出现在他的主要信仰声明中，尤其《第二瑞士信仰告白》。[^p135-28]难处在于，《旧约》呈现不同的圣约观。有时，是上帝与选民之间具有约束力、违约会有后果的协议，例如伊甸园的亚当（《创世记》2:15—17），或西奈山的摩西（《出埃及记》34:27）；另一些时候，则似乎是上帝“遗赠”人类的无条件遗产，例如告诉挪亚不再以洪水淹没世界（《创世记》9:8—17）。布林格试图将这些因素调和为一个决定人类历史进程、有条件却恒常不变的约。只要人遵守上帝的法，信靠他、爱邻人，上帝便守其应许。因此，责任是相互的，尽管很大部分落在传道者和执政者肩上：他们继承《旧约》先知与君王，应保守信仰，规训基督徒共同体。圣约神学在16世纪后期与17世纪找到追随者，吸引那些声称拥有上帝选民“印记”的人。它赋予平信徒重要作用；16世纪后期，改革宗传统孕育许多杰出平信徒神学家，例如菲利普·迪普莱西—莫尔奈（1549—1623）、菲利普·马尔尼克斯·范·圣阿尔德贡德（1540—1598），以及托马斯·埃拉斯都，<a id="pdf-136"></a><!-- PDF page 136; original page 113 -->德文名托马斯·吕伯（1524—1583）。当人们需要论证特定情况下反抗合法统治者的正当性时，圣约神学具有政治回响。在瑞士各州及后来的荷兰共和国等政体中，它也很合适，因为这些近似联邦国家的结构，建立在复杂的共同责任模式上。直到16世纪末，海德堡的改革宗经院神学家，尤其吉罗拉莫·赞基（1516—1590），以及英国学院神学家达德利·芬纳（1558—1587）、托马斯·卡特赖特（1535—1603）和罗伯特·罗洛克，才逐步形成“行为之约”的概念，说明圣约之下对人的行为有何要求，作为“恩典之约”的补充。[^p136-29]

尽管布林格作为经文评注者影响很大，改革宗传统却只产生一位首屈一指的神学体系建构者：约翰·加尔文。要用短篇幅公允说明其神学影响，非常困难，尤其因为其神学无法与他作为拉丁文、尤其法文作家的卓越说服力分开，也无法与日内瓦难民宗教改革对一代西欧流亡者的影响分开。他压倒一切的抱负，是创造一个统一、总括的神学框架，将上帝真理与人类智慧结合。为此，他运用非凡的人文主义语法、逻辑及修辞才能，目的不是“证明”上帝真理——中世纪经院学者曾试图这样做，却失败了——而是“教育”世界“聆听”上帝之道。对他而言，这不是死的、疏远而制度化的真理，而是个人性的、动态的、改变生命的真理。[^p136-30]其神学体系由三个相互加强的基础支撑：精校的《圣经》文本；各卷评注中环环相扣的释经框架；以及《基督教要义》（Christianae Religionis Institutio）这部神学总论。institutio既有“教导”之意，如昆体良修辞教科书所用，也有“制度”或“建立”之意。

这三个部分都见证他掌握人文主义的学习、阐释与逻辑技术。杰出的法国流亡印刷商罗贝尔·埃蒂安，在通常的章节编号外，设计逐节编号体系，如今我们早已习以为常。它首次见于他在日内瓦出版的希腊文《新约》。后来，日内瓦版《圣经》又加上边注与脚注，运用人文主义<a id="pdf-137"></a><!-- PDF page 137; original page 114 -->文学技术。加尔文则增加经文评注，其基础是他大量讲道的活动，评注又反过来滋养讲道。直到1549年，他每周平日傍晚五时讲道三次，星期日三次，另给星期五聚集的牧师团讲授；他对时间的严密安排，足以说明其为人。此后改为隔周的每个平日各一次、每个星期日两次，并先后由两名速记员记录。1549年至1564年去世，讲道应超过两千篇，但1805年日内瓦执政当局把文集卖出；近两世纪后，人们仍在陆续寻回。[^p137-31]除《启示录》外，加尔文对《圣经》各卷都作过评注和／或讲道。1551年起出版的评注，为其神学提供释经基础。其方法首先宣布于《罗马书》评注，1540年3月由斯特拉斯堡印刷商文德林·里赫尔出版。他追求“明晰的简洁”（perspicua brevitas），开篇介绍书信“主题”，运用文本内在“方法”，阐明“字词的确切意义”，并“展开作者的心意”。[^p137-32]字词背后有符合作者心意的“真实意义”；短暂的“符号”旁边，有真实、内蕴的“所指”。[^p137-33]

《基督教要义》是整个神学的拱顶石。1536年初版，写于他离开法国、流亡的第一年，在伊拉斯谟腹地巴塞尔，以拉丁文快速完成。后来不断改造、扩充，至1559年定版。他这样解释它与评注、《圣经》的互补关系：[^p137-34]

> 我作此书，是要预备并教导神圣神学的研习者阅读上帝之道，使他们容易入门，也能前进而不致绊倒。因为我相信，我已把宗教全部内容的总和包容在内，并依次安排；人若正确掌握，就不难判断在经文中尤其该寻求什么，又该把其内容归向何种目的。道路仿佛已铺好，此后若出版经文评注，我便始终可以简练，因为不必再作漫长的教义讨论，也无须离题讨论一般论题……

<!-- PDF page 138; original page 115 -->

1536年便已出现的著名开篇句，记录了加尔文的抱负：“Tota fere sapientiae nostrae summa, quae vera demum ac solida sapientia censeri debeat, duobus partibus constat, Dei cognitione et nostri。”意即：“我们的智慧，凡应称为真实、稳固智慧的，其总和几乎由两部分组成：认识上帝，以及认识自己。”1536年，他依路德《小教理问答》，把余下内容编成六部分。到1559年，材料重新归并为四卷。篇幅越增长，他越难保住前两卷关键、鲜明对照的修辞冲击：一边是在《圣经》中向我们显明的上帝——永恒、宇宙与人的创造者、智慧良善完美、全能、处处超越的灵、至高统治者，以及公义而仁慈的审判者；另一边则是悲惨可耻的人类。[^p138-35]他描写人类处境的语言充满修辞力量：我们被罪的“轭”“迷宫”“深渊”——如《诗篇》所说“深而干涸的井”——囚禁。[^p138-36]我们“像稻草里的老鼠，乱作一团”奔跑；16世纪法文paille有双关，既是“稻草”，也是“罪”。这是承袭而来的“败坏”与“堕落”，亚当的“原”罪。[^p138-37]凭自己的智慧，我们一无所能：“《圣经》教导，人因罪与上帝疏离，承受震怒，服在永死的咒诅下，被排除于一切得救盼望之外，失去上帝一切福分，作撒但奴仆，被罪轭掳住，最终注定落入可怕灭亡，而且已陷其中。”[^p138-38]罪是普遍的败坏，以具体“行为”和“果实”表现。他照例列出揭示性的清单：“通奸、淫乱、偷窃、仇恨、谋杀、荒宴［comessationes］……”[^p138-39]罪源于混杂，即“掺污”；其神学逻辑就是建立防火墙，区分圣洁与凡俗、神圣与罪恶、得救者与被定罪者。因此，以为自己能参与成就救恩，本身就是掺污。唯有上帝特别、白白施恩的行动，才能拯救我们：“自由意志若无恩典帮助，不足以使人行善……我们需要恩典的应许，向我们见证父是慈悲的；因为别无他途可以亲近他，人心也唯独能安息于恩典。”[^p138-40]加尔文接受路德重申的奥古斯丁式神学核心，努力将之纳入<a id="pdf-139"></a><!-- PDF page 139; original page 116 -->莱茵地区《圣经》本位主义者的方法与视角。在伊拉斯谟回避之处，他毫不退缩，希望由此——按其理解——呼召如今已与自己疏离的天主教法国，回归真正的基督教根源。一种“对立结构”，处处织入其神学逻辑，使他能运用一位学者所谓“信仰演算”（calculus fidei），即依经文作区分的逻辑，直至界限明确。[^p139-41]

预定论是加尔文奥古斯丁式“关于上帝的双重认识”（duplex cognitio domini）——上帝既是创造者，也是救赎者——令人不安的逻辑后果；路德已承认它，慈运理和布林格也开始探索。[^p139-42]它无法回避：“没有人敢简单否认预定：上帝借此收纳一些人，使其盼望生命，又判定其他人永远死亡。”[^p139-43]上帝的护理，是希伯来人流亡、《旧约》先知，以及加尔文理解自身避难经历背后的力量，属于其神学的中枢神经系统。它又是双向的，即“双重预定”（duplex predestinatio）：“并非所有人受造时处境相同；有些人被预定永生，另一些则永远被定罪。”[^p139-44]加尔文运用人文主义的理解与阐释技术，限制这一主张打开的神学思辨视野。对人而言，这是“难解的问题”，原因很简单：人的知识无法充分把握。若试图解开神圣护理的秘密，神学家便成了他谴责的占星家，再次跌入掺污知识的“深渊”。[^p139-45]“因此，首先，当他们探究预定时，应记得自己正在深入神圣智慧的隐秘处；自以为稳妥而满怀信心地猛冲向前者，非但不能满足好奇，反会进入无法脱身的迷宫。”[^p139-46]这里的“他们”，是1559年版留下的一道瘀痕，源于他与法国难民神学家、前加尔默罗会士热罗姆·博尔塞克的冲突。1551年，后者向牧师团发表演讲，声称双重预定把上帝变成暴君和罪的作者。牧师团随后从文本抽取十三项命题，日内瓦执政当局以侮辱言辞、亵渎和异端罪将其监禁。[^p139-47]数月内，他被宣布为不受欢迎人物、逐出日内瓦；但这并未阻止他，也未阻止其他人——私下里包括布林格——对加尔文的预定逻辑表达根本不安。从<a id="pdf-140"></a><!-- PDF page 140; original page 117 -->1539年版《基督教要义》起，加尔文借鉴布策尔在此问题上的洞见。[^p140-48]所有基督徒共同体都有一种“可变几何”：一个“酵母”核心，向外扩展成信仰共同体之圆，再到几乎尚未、或完全没有受信仰吸引者构成的“外围半影”。[^p140-49]这解释了新教改革何以在一些地方成功，在另一些地方陷于苦战；为信仰受苦的现实，从未远离成熟加尔文的神学。他正援引这一无可争辩的现实，加强《要义》第三卷的预定论讨论：“实际上，生命之约（foedus vitae）并非同等传给所有人；即便在听见宣讲者中，也并不总获相同接纳。这种差异显示神圣判断不可测度的深渊……”无论探测自然最深奥秘，还是上帝不可探究之护理的运作，“有学识的无知”（docta ignorantia）都是文艺复兴时期一种可以捍卫的认识方法。它为为何一些人——法国、尼德兰、玛丽女王治下英格兰及苏格兰那些“在十字架下”的会众——为信仰受苦，而另一些人没有受苦，提供了最终止于此的解释。

加尔文体系化本能所遇最大挑战，是圣餐。此问题界定了他1549年同布林格达成的协议，也巩固了新教欧洲逐渐出现的宗派断层。他谨慎接近这一主题：最早充分展开的陈述，是1541年以法文而非拉丁文写成、面向平信徒而非神学家的论著。[^p140-50]观点只是渐渐渗入其更广泛的作品。起初，他怀疑慈运理式观念，意识到它早已招致的核心批评：把圣餐变成“赤裸”或“空洞”的记号。1541年，他顺带评论慈运理与厄科兰帕迪乌斯说，他们“更努力于摧毁恶，而非建立善”（sont plus efforcez de ruiner le mal, que d’edifier le bien）。[^p140-51]同时，他无法接受路德宗圣餐神学，因为它混淆了世俗与神圣、肉体与属灵；沿此方向便是偶像崇拜。他欣然采用奥古斯丁对圣礼的定义——“神圣事物的可见记号”——再运用人文主义技巧，细化“能指”与“所指”的区别。[^p140-52]问题又一次成为思想与语言的关系，<a id="pdf-141"></a><!-- PDF page 141; original page 118 -->即意义与字句（sensus与littera）、事物与言辞（res与verba）的关系。后现代语言理论奠基者费尔迪南·德·索绪尔出身日内瓦，也就不令人意外。记号不是实在，却与实在有对应关系：可见、物质的记号，与圣礼不可见、属灵的实在之间，是一种“类比”；二者如此接近，足可称“转喻”。类比关系是必要的，才能防止神圣与世俗掺杂，防止记号与所指混淆。但所指的实在如此强大，能够使我们“活过来”。因此，圣礼要求把圣礼之物吃下，而非仅仅观看。借助圣餐的“奥秘”，上帝真正“接枝”于我们之内；加尔文保留了“圣礼”的这一奥秘意义。

经过数年神学通信、一次亲自访问，以及双方相当圆融的交涉，加尔文与布林格才于1549年在关于圣餐和洗礼的联合声明上署名。后来称为《苏黎世共识》（Consensus Tigurinus）的二十六条，界定了“改革宗传统”的圣餐神学。双方都有让步，某些内容也容许双重理解。但随着路德宗对其基本表述的反对日趋坚定，这份协议成为下一代各教会信仰告白中相关论述的基础：波兰（1557）、法国（1559）、苏格兰（1560），以及莱茵普法尔茨（1563）。改革宗共识得以实现。

不过，在礼仪一个重要方面，加尔文对形成中改革宗传统的贡献具有压倒性，那就是本国语文的格律诗篇集。把《诗篇》改写成本国语文诗歌，供私人敬虔使用，原是承袭而来的基督教传统；新教改革使之成为公共礼拜的组成部分。例如，最早的路德宗众赞歌集（1524）便在敬虔圣诗中收录若干诗篇改写。但莱茵地区《圣经》本位改革者坚持，唯有《圣经》中上帝的话适合公共礼拜，遂尝试将歌词限于诗篇改写，以及少量其他经文。他们采用流行歌曲的诗体，帮助记忆，也希望说服人们放弃熟悉的感官性、愚蠢歌曲，改唱诗篇。加尔文不同于慈运理及其苏黎世继任者，全力支持斯特拉斯堡正在形成的传统。1539年，他在那里出版首部汇编，收录法国诗人克莱芒·马罗十三篇精彩的押韵译作，以及自己改写的另外六篇诗篇和三首圣歌，若干<a id="pdf-142"></a><!-- PDF page 142; original page 119 -->曲调借自较早的斯特拉斯堡歌集。[^p142-53]返回日内瓦后，他出版第二部诗篇集《教会祷告与歌唱的形式》（La forme des prières et chantz ecclesiastiques，1542），收录更多马罗与自己的作品、自己论圣礼和诗篇歌唱的重要序言，以及礼拜时诵读的主要礼仪祷文。[^p142-54]完整的日内瓦格律诗篇集，终于1562年在日内瓦出版，152篇歌词——150首诗篇、两首圣歌——配125种不同曲调。[^p142-55]负责出版的安托万·樊尚统筹大规模印行和发行，涉及日内瓦、巴黎、里昂、卡昂、圣洛等地；仅巴黎便有二十四家印刷商出版，单1562至1564三年，可考版本就超过四十四种。[^p142-56]它也迅速译成其他语言。安布罗修斯·洛布瓦塞尔的德译本，1565年完成、1573年在莱比锡出版，既受加尔文宗，也受路德宗会众欢迎。彼得鲁斯·达特努斯的荷兰文译本1566年问世，1568年获韦塞尔教会会议接受，此后二百余年一直是荷兰加尔文宗教会的官方歌集。日内瓦诗篇集，也影响苏格兰和英格兰改革宗重要的格律诗篇传统。这是新教改革史上，将礼仪与印刷相联结的最大单项成功。

从1564年加尔文去世，到1618年三十年战争爆发，改革宗神学受到宗派基础显著扩展的影响。到1600年，苏格兰、英格兰、贝阿恩和一批德意志小邦，已有确立的改革宗教会；法国、波兰—立陶宛、匈牙利、波希米亚和莱茵地区，也有法律容许的改革宗会众。本卷另一章会说明，这些教会彼此关系及事务管理方式，差异很大。主要信仰声明迅速出现：法国（1559）、比利时／荷兰（1561）、《三十九条信纲》（1563）、《海德堡教理问答》（1563），反映共同神学取向，但也有地方差异。不过，维持神学统一的，不仅是信仰告白，还有外敌存在、应对扩张问题，以及多数改革宗教会内部纪律框架的影响。约瑟夫·霍尔于1645年称它们为“宗教改革的姊妹”；要使其信仰告白“和谐一致”，更多是善意的<a id="pdf-143"></a><!-- PDF page 143; original page 120 -->幻觉，而非可实现的目标。[^p143-57]改革宗礼仪与礼拜方式，确实差异很大，甚至圣餐也是如此。遵奉伊丽莎白时期主教制所定礼仪的英格兰人，跪在祭坛栏杆前，由身穿白罩衣的牧师分送“圣餐”，同时提醒他们应如何看待此圣礼。但也有许多人不愿遵奉。这些人，包括伊丽莎白时期清教徒、后来的“分离派”，以及查理一世时期长老派，坐在桌子“周围”领餐。苏格兰人则坐在桌子“旁”，由长老传递饼酒；英格兰查理一世时期长老派也追随这一做法，1640年代威斯敏斯特会议曾详细讨论。荷兰教会作出信仰告白的成员，在“神圣晚餐”（heilig avondmaal）中同样如此，十二人一组，围坐圣坛区的桌子；这似乎可追溯慈运理在苏黎世建立的模式。法国会众中有资格领“晚餐”（cène）者，则排队向教会管理员或长老交纳领餐凭牌（méreaux），然后安静地从牧师手中领饼酒。牧师身穿朴素长袍，或许还没有后来胡格诺牧师成为标准装束的领片。德意志地区，改革宗与路德宗围绕“擘饼”、使用薄饼及洗礼礼仪争论，甚至延烧街头。[^p143-58]

扩展不可避免的后果之一，是必须提供训练良好的教职人员。在法语地区，这主要不得不在传统大学之外进行，新学院仿效洛桑（1537）与日内瓦（1559）的模式。到1620年，蒙托邦、尼姆、迪、索米尔与色当学院，获法国教会会议承认和支持。尼德兰则创立新学院，纪念荷兰起义的重大事件：莱顿1575年、根特1580年，后者后来迁至弗拉讷克。17世纪，乌得勒支（1636）、哈德韦克（1647）和格罗宁根（1647）学院，为尼德兰及更广泛北欧地区培训改革宗牧师，作用重大。德意志加尔文宗学术机构在三十年战争前，也有繁荣时期：模范学院赫尔博恩最终升为大学，与加尔文宗的海德堡、马尔堡、奥得河畔法兰克福，以及短期内的柯尼斯堡并列。此外，还应加上<a id="pdf-144"></a><!-- PDF page 144; original page 121 -->苏格兰和英格兰各大学、新建都柏林三一学院，以及北美的哈佛学院。

学院中的神学，不同于书斋中的神学。它受到学生课程要求影响：教科书、系统学习、考试。加尔文出版比布林格多，16世纪后半叶也被更多地翻译、重印。[^p144-59]他的经文评注成为争论对象。《罗马书》评注受贝扎赞扬，1593年又被路德宗的埃吉迪乌斯·胡尼乌斯指有“犹太化”影响；大卫·帕雷乌斯为之辩护，1594年流亡鲁汶的英国天主教徒托马斯·斯特普尔顿又重新攻击其不准确，甚至更糟。[^p144-60]《基督教要义》被节略、制成表格，供觉得原书含混难懂的读者使用。[^p144-61]加尔文著作本身成为专设教席与讲座课程的对象。卡斯帕尔·奥莱维亚努斯（1537—1586）获任赫尔博恩这种教席时，向泰奥多尔·贝扎（1519—1605）解释，自己每学期讲授一卷。1586年出版的内容，可能类似其讲课：保留加尔文原话，删去反天主教论战。三年后，同校约翰内斯·皮斯卡托尔（1546—1625）出版从加尔文作品摘取的《箴言》（Aphorisms），以便于学生撰写论辩文章的形式，总结讲课。[^p144-62]选择“箴言”而非“论题”，是自觉之举，因为后者意味着亚里士多德式学习法：一个必须被“证明”的命题，而不是可以“讨论”的主题。16世纪后期，许多，甚至可能多数改革宗学院，倾向拉米主义学习方法。皮埃尔·德·拉·拉梅，拉丁名拉米（1515—1572），提出激进的本科课程改革，简化逻辑教学、扩大修辞学习。因此，那些年受过学校教育、在17世纪初开始主导改革宗神学的人，其教学带有拉米主义影响。但教学风尚有来有去。面对运用体系神学、并以经院逻辑工具加强论证的路德宗和天主教对手，改革宗神学家发现不得不回应，尤其在德意志。[^p144-63]修辞学教席让位于哲学教席，教授通过正式阐释改革宗教义建立名望。

学术探究也往往逐渐暴露信仰体系的内在弱点。

雅各布·赫尔曼斯宗，拉丁名雅各布斯·阿明尼乌斯（1559—1609），就是莱顿这样一位神学博士。他的资历无可挑剔：1575年莱顿围城时经历家人死亡的童年，在当地新加尔文宗大学求学，按惯例赴日内瓦学术游历（peregrinatio academica），又在阿姆斯特丹城市教会担任过牧师。他并非情愿地接过预定论问题，却使之成为改革宗神学中分裂而非统一的力量。在日内瓦，他听贝扎深入探究加尔文认为最好不碰的神学敏感部位。亚当和夏娃尚未犯罪，上帝已定神圣计划，即“堕落前预定论”（supralapsarianism或antelapsarianism）；基督为众人死，实际上只为选民而死。这些观点已令不那么强调预定的改革宗人士不安。哈勒姆的自学公证人、带有平民倾向的德尔克·沃尔克赫茨·科恩赫特（1522—1590），于1578年莱顿教会会议上否认此教义有经文依据。1586年，新教小飞地蒙贝利亚尔的教会会议，使贝扎在这一及其他问题上直接面对批评者。英格兰的塞缪尔·哈斯内特，1585年在伦敦圣保罗十字架讲坛讲道，质疑双重预定，随即被要求闭嘴。讨论渐渐扩大、深化，尤其通过手稿论著与私人谈论。阿明尼乌斯最初介入，是作为牧师受代尔夫特教会法庭邀请，反驳其两名牧师针对贝扎堕落前预定论的著作。他最充分、直接的探讨，是回应威廉·珀金斯1598年《论预定的次序与方式》的文章，1600年已完成，直到他死后1612年才出版。他对救恩论的区分极其精细：上帝指定基督为救赎主；继而应许接纳信他者；又提供产生信仰的必要手段；最后，选择拯救那些他知道会接受并坚持这信仰的人。这是神圣“预知”，而非“预定”。这些区分容许亚当、夏娃先创生罪，随后上帝才将救恩赐予愿意接受者，同时仍坚持，唯有他的恩典是一切救恩之源。

阿明尼乌斯的观点未免过于细微，尤其在他1609年去世后，成为神学、政治与教会论冲突的对象，最终在著名的荷兰改革宗全国教会会议达到高潮。会议于1618年11月13日在多德雷赫特开幕，亦称Dordt，英文Dort。荷兰教会五十八名牧师与<a id="pdf-146"></a><!-- PDF page 146; original page 123 -->长老、代表世俗利益的联省议会十八名世俗代表、荷兰大学五位神学家，以及外国二十六位改革宗神学家出席。这是改革宗神学传统最接近一次总会集结的时刻。西蒙·埃皮斯科皮乌斯，荷兰文名西蒙·埃赫贝茨宗（1583—1634），率十三名阿明尼乌斯派抗辩者，于12月6日抵达。他们受召而来，并非作为代表，而是见证自身观点受到谴责；尽管六个月举行154次正式会议，这一结果早已注定。会议争论尖锐，不时出现的宽容与教会合一呼吁，必须放在代表之间复杂分裂的背景中理解，也体现人们意识到，“教士的争吵”无助于造就教会。然而，代表发现改革宗传统远非统一。连新荷兰文《圣经》译本是否收入次经，也引发激辩。外国访客觉得荷兰教会礼仪有些古怪。例如爱德华·戴文南特注意到，人们在新近死者门旁石头下留一小撮稻草的习俗：“不为他们鸣钟，也不讲道，只有两三个人邀请死者邻里亲友，在指定时刻前来陪他安葬；任何女人都不许参加。”[^p146-64]反过来，荷兰代表称英格兰与苏格兰的严格守安息日观为“英国人的虚构”（figmentum Anglicanum）。一位瑞士代表发现，自己寄宿家中，母亲和女儿是加尔文宗，祖母是门诺派，叔父却是耶稣会士，不禁困惑。[^p146-65]

最终，九人委员会起草著名的五项“教规”，亦称“五章”，各附条文；自17世纪起，人们以极具荷兰特色的首字母缩写“TULIP”，即“郁金香”，记忆它们。这些决议常被视为加尔文宗预定论的最高峰，实际教义表述却相当温和。[^p146-66]它们没有为保障“永恒定旨”，将创造与拣选锁在狭窄的堕落前预定框架中，而是努力用能被理解、赞同的公式表达“既受教义”。事情也不是温和抗辩派神学家面对不宽容的经院加尔文派；若一定要说，反倒是阿明尼乌斯派把经院区分带到会议。[^p146-67]但多特并非“普世教会会议”，只是荷兰教会一次有重要外国参与的全国集会，其决议对其他改革宗<a id="pdf-147"></a><!-- PDF page 147; original page 124 -->神学家并无约束权威。它没有终结改革宗神学争论，尤其普遍恩典问题：尼德兰继续争论，英格兰对会议决议发生阿明尼乌斯派之争，法国则有莫伊兹·阿米罗及其追随者提出“假设普救论”。17世纪，改革宗神学家的书架上，仍摆着加尔文与布林格的著作。但仅举一例，思想独立的英国清教徒理查德·巴克斯特（1615—1691）如何使用它们，便与积极投入宗派事务的同时代人、梅斯牧师亚伯拉罕·德·拉·克洛什（卒于1656）大不相同。[^p147-68]到17世纪后期，持怀疑态度的经文学术与理性主义神学兴起的一代，这些分歧只会更大。
